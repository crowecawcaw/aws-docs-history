# Document history

The following table describes important changes in each release of the *AWS Deadline Cloud Developer Guide*. 



| Change | Description | Date |
| --- | --- | --- |
| Added worker host configuration scripts | Added documentation for using worker host configuration scripts that run with elevated privileges. For more information, see [Run scripts as an administrator to configure workers](smf-admin.md "smf-admin.md"). | May 12, 2025 |
| Updated security section about using AWS PrivateLink | Updated the instructions for accessing Deadline Cloud using AWS PrivateLink and the new dual-stack endpoints. For more information, see [Access Deadline Cloud using an interface endpoint](vpc-interface-endpoints.md "vpc-interface-endpoints.md"). | March 17, 2025 |
| Updated customer-managed fleet credentials information | Updated the instructions for creating credentials for a customer-managed fleet to provide more information about securing your fleet. For more information, see [Configuring AWS credentials](aws-credentials.md "aws-credentials.md"). | February 10, 2025 |
| Reorganized content from the user guide | Moved developer focused content from the user guide to the developer guide: <br>• Moved instructions for creating a customer-managed fleet from the user guide to a new [Customer-managed fleets](manage-cmf.md "manage-cmf.md") chapter. <br>• Created a new [Using software licenses](license.md "license.md") chapter with information on usage-based licensing and using your own licenses with service- and customer-managed fleets. <br>• Moved details about monitoring with CloudTrail, CloudWatch, and EventBridge from the user guide to the [Monitoring](monitoring-overview.md "monitoring-overview.md") chapter. | January 6, 2025 |
| Create a conda package | Added information about how to create a conda package for an application. For more information, see [Create a conda package](conda-package.md "conda-package.md"). | August 29, 2024 |
| [New guide](what-is-deadline-cloud.md "what-is-deadline-cloud.md") | This is the initial release of the *Deadline Cloud Developer Guide*. | July 26, 2024 |
