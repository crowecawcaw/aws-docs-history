

# Deploying and operating
<a name="deploy-and-operate"></a>

Once your Amazon Cognito design is in place, you operate it as part of a production service. This section covers the operational concerns of running Amazon Cognito at scale: request-rate and resource quotas, provisioned capacity, multi-Region replication, resource tagging, and troubleshooting. For logging and monitoring—CloudWatch metrics and CloudTrail event history—see [Logging and monitoring in Amazon Cognito](monitoring.md) in the Security chapter.
