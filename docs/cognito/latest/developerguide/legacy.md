

# Legacy
<a name="legacy"></a>

**Important**  
Amazon Cognito Sync is closed to new customers. If you are starting a new application, use a current alternative such as [AWS AppSync](https://docs.aws.amazon.com/appsync/) and [DynamoDB](https://docs.aws.amazon.com/dynamodb/) instead. The content in this section is retained for customers with existing Amazon Cognito Sync implementations.

This section collects earlier-generation Amazon Cognito features. Amazon Cognito Sync is closed to new customers, as noted above. The classic hosted UI is an earlier branding version that you can still select per app client, but managed login is the current branding version for new work; to move an app client from the classic hosted UI to managed login, see [Migrating from the classic hosted UI to managed login](migrate-classic-hosted-ui-to-managed-login.md).
