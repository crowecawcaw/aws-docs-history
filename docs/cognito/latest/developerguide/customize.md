

# Customizing user pools
<a name="customize"></a>

Cognito user pools expose extension points so that you can shape the sign-up and sign-in experience to your application. Use Lambda triggers to run your own code at key moments in the user lifecycle, and configure the messages and analytics that your user pool sends.
