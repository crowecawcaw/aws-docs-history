# Platform

The platform-related details about the AWS DataSync agent, such as the version
number.

## Contents

**Version**

The version of the DataSync agent.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 256.

Pattern: `^[a-zA-Z0-9\s+=._:@/-]+$`

Required: No
