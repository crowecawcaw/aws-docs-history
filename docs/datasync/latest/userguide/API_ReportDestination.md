# ReportDestination

Specifies where DataSync uploads your [task report](task-reports.md "task-reports.md").

## Contents

**S3**

Specifies the Amazon S3 bucket where DataSync uploads your task
report.

Type: [ReportDestinationS3](API_ReportDestinationS3.md "API_ReportDestinationS3.md") object

Required: No
