# SourceManifestConfig

Specifies the manifest that you want AWS DataSync to use and where it's hosted.
For more information and configuration examples, see [Specifying what DataSync transfers by using a manifest](transferring-with-manifest.md "transferring-with-manifest.md").

## Contents

**S3**

Specifies the S3 bucket where you're hosting your manifest.

Type: [S3ManifestConfig](API_S3ManifestConfig.md "API_S3ManifestConfig.md") object

Required: Yes
