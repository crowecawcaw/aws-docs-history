# Understanding how DataSync handles file and object

metadata

AWS DataSync can preserve your file or object metadata during a data transfer. How
your metadata gets copied depends on your transfer locations and if those locations
use similar types of metadata.

## System-level metadata

In general, DataSync doesn't copy system-level metadata. For example, when
transferring from an SMB file server, the permissions you configured at the file
system level aren't copied to the destination storage system.

There are exceptions. When transferring between Amazon S3 and other object storage,
DataSync does copy some [system-defined object metadata](#metadata-copied-between-object-s3 "#metadata-copied-between-object-s3").
