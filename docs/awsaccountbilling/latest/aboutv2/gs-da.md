

# Create an organization-wide agent

In the delegated administrator account, after you set up the management account, you create the agent that reads the dataset. A delegated administrator account cannot create an organization-wide dataset, so the Data Hub step in its agent wizard carries the setting and no **Create dataset** button. The agent reads the dataset in your management account.

1. Sign in to the delegated administrator account, open AWS FinOps Agent, and choose **Create organization-wide agent**.

1. On **Step 3, Set up Billing and Cost Management tools**, leave **Use Data Hub for this agent** selected. The checkbox is selected by default.

1. Finish the remaining steps and, on the **Review and create** step, choose **Create agent**.
