

# Connect an existing agent

An agent created before the preview does not read Data Hub yet. Open the agent and connect it to Data Hub on its Data Hub tab.

1. Open AWS FinOps Agent in the account that runs the agent.

1. On the **Agents** page, choose the agent to open it.

1. Choose the **Billing and Cost Management Data Hub** tab.

1. Choose **Connect**.

Connecting an agent does not create a dataset. If the account has no dataset, the agent answers at the service and account level until you create a dataset and the dataset is **Active**. The agent starts answering at the individual resource level on its first question after a dataset appears.
