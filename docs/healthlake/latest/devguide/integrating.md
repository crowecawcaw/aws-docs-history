# Integrating AWS HealthLake

The following AWS services integrate directly with AWS HealthLake to enable integrated natural
language processing, SQL query, and data warehousing.

- _Amazon Comprehend Medical_ is a HIPAA eligible natural language processing service
  (NLP) that uses machine learning libraries to extract meaningful health data from unstructured medical
  text in HealthLake. For more information, see the [_Amazon Comprehend Medical
  Developer Guide_](../../../comprehend-medical/latest/dev/comprehendmedical-welcome.md "../../../comprehend-medical/latest/dev/comprehendmedical-welcome.md").
- _Amazon Athena_ is an interactive query service that enables you analyze
  HealthLake data directly in Amazon Simple Storage Service (Amazon S3) buckets using standard SQL.
  For more information, see the [_Amazon Athena Developer
  Guide_](../../../athena/latest/ug/what-is.md "../../../athena/latest/ug/what-is.md").
