# Getting started with AWS HealthLake

To start using AWS HealthLake, set up an AWS account and create an AWS Identity and Access Management user. To use the
[AWS CLI](../../../cli/latest/userguide/getting-started-install.md "../../../cli/latest/userguide/getting-started-install.md") or the [AWS SDKs](https://aws.amazon.com/developer/tools/ "https://aws.amazon.com/developer/tools/"), you
must install and configure them.

###### Note

The [Reference](reference.md "reference.md") chapter of this guide
provides supporting content for SMART on FHIR, FHIR R4, and AWS HealthLake. For instance, you can
find information about SMART on FHIR configuration, supported FHIR profile validations, and
HealthLake endpoints.

After learning about HealthLake concepts and setting up, a short tutorial with code examples is
available to help get you started.
