# Quotas for Oracle Database@AWS

Oracle Database@AWS is a multicloud offering. AWS doesn't set or enforce quotas for Oracle Database@AWS
resources. Quotas are enforced by Oracle Cloud Infrastructure (OCI). For more information about OCI
quotas, see [Quotas and Service Limits](https://docs.oracle.com/en-us/iaas/Content/database-at-aws/oaaws-service-limits.htm "https://docs.oracle.com/en-us/iaas/Content/database-at-aws/oaaws-service-limits.htm") in the Oracle Cloud Infrastructure documentation.
