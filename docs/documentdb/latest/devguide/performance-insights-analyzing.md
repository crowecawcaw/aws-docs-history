# Analyzing metrics with the Performance Insights dashboard

The Performance Insights dashboard contains database performance information to help
you analyze and troubleshoot performance issues. On the main dashboard page, you can
view information about the database load (DB load). You can "slice" DB load by
dimensions such as wait states or query.
