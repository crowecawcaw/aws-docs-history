# Amazon DocumentDB Cluster settings

When you create or modify a cluster, it is important to understand
which parameters are immutable and which are modifiable after the cluster
has been created. The following table lists all the settings, or parameters,
that are specific to a cluster. As specified in the table, some are
modifiable, others are not.

###### Note

These settings should not be confused with Amazon DocumentDB cluster
parameter groups and their parameters. For more information about
cluster parameter groups, see [Managing Amazon DocumentDB cluster parameter groups](cluster_parameter_groups.md "cluster_parameter_groups.md").

| Parameter                     | Modifiable | Notes                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DBClusterIdentifier`         | Yes        | Naming constraints:<br>• Length is [1—63] letters, numbers, or hyphens.<br>• First character must be a letter.<br>• Cannot end with a hyphen or contain two consecutive<br>hyphens.<br>• Must be unique for all clusters across Amazon RDS, Amazon Neptune, and Amazon DocumentDB per AWS account, per Region.                                  |
| `Engine`                      | No         | Must be `docdb`.                                                                                                                                                                                                                                                                                                                                |
| `BackupRetentionPeriod`       | Yes        | Must be between [1-35] days.                                                                                                                                                                                                                                                                                                                    |
| `DBClusterParameterGroupName` | Yes        | Naming constraints:<br>• Length is [1—255] alphanumeric characters.<br>• First character must be a letter.<br>• Cannot end with a hyphen or contain two<br>consecutive hyphens.                                                                                                                                                                 |
| `DBSubnetGroupName`           | No         | After a cluster has been created, you cannot modify the<br>cluster's subnet.                                                                                                                                                                                                                                                                    |
| `EngineVersion`               | No         | Value can be `5.0.0` (default), `4.0.0`, or `3.6.0`.                                                                                                                                                                                                                                                                                            |
| `KmsKeyId`                    | No         | If you choose to encrypt your cluster, you cannot change<br>the AWS KMS key that you used to encrypt your cluster.                                                                                                                                                                                                                              |
| `MasterUsername`              | No         | After a cluster has been created, you cannot modify the<br>`MasterUsername`.<br>Naming constraints:<br>• Length is [1—63] alphanumeric characters.<br>• First character must be a letter.<br>• Cannot be a word reserved by the database engine.                                                                                                |
| `MasterUserPassword`          | Yes        | Constraints:<br>• Length is [8—100] printable ASCII characters.<br>• Can use any printable ASCII characters except<br>for the following:<br>+ `/`<br>(forward slash)<br>+ `"`<br>(double quotation mark)<br>+ `@`<br>(at symbol)                                                                                                                |
| `Port`                        | Yes        | The port number applies to all instances in the cluster.                                                                                                                                                                                                                                                                                        |
| `PreferredBackupWindow`       | Yes        |                                                                                                                                                                                                                                                                                                                                                 |
| `PreferredMaintenanceWindow`  | Yes        |                                                                                                                                                                                                                                                                                                                                                 |
| `StorageEncrypted`            | No         | If you choose to encrypt your cluster, it cannot be<br>unencrypted.                                                                                                                                                                                                                                                                             |
| `StorageType`                 | Yes        | The storage type for the DB cluster: Standard (`standard`) or I/O-Optimized (`iopt1`).<br>Default: `standard`<br>This parameter can be configured with `CreateDBCluster` and `ModifyDBCluster`.<br>For more information, see [Amazon DocumentDB cluster storage configurations](db-cluster-storage-configs.md "db-cluster-storage-configs.md"). |
| `Tags`                        | Yes        |                                                                                                                                                                                                                                                                                                                                                 |
| `VpcSecurityGroupIds`         | No         | After a cluster has been created, you cannot modify the<br>VPC that the cluster resides in.                                                                                                                                                                                                                                                     |
