# Amazon DocumentDB cluster parameters reference

When you change a dynamic parameter and save the cluster parameter group, the change is applied immediately regardless of the _Apply immediately_ setting. When you change a static parameter and save the cluster parameter group, the parameter change takes effect after you manually reboot the instance. You can reboot an instance using the Amazon DocumentDB console or by explicitly calling `reboot-db-instance`.
