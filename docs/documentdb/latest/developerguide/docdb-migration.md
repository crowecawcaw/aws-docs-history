# Migrating to Amazon DocumentDB

Amazon DocumentDB is a fully managed database service that is compatible with the MongoDB API.
You can migrate your data to Amazon DocumentDB from MongoDB databases running on premises or on Amazon Elastic Compute Cloud (Amazon EC2) using the process
detailed in this section.
