# SQL support and limitations

The Amazon DocumentDB ODBC driver is a read-only driver that supports a subset of SQL-92 and some common extensions.
Refer to the [ODBC support and limitations](https://github.com/aws/amazon-documentdb-odbc-driver/blob/develop/src/markdown/support/odbc-support-and-limitations.md "https://github.com/aws/amazon-documentdb-odbc-driver/blob/develop/src/markdown/support/odbc-support-and-limitations.md") documentation for more information.
