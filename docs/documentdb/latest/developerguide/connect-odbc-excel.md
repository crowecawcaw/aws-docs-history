# Connect to Amazon DocumentDB from Microsoft Excel

1. Ensure that the Amazon DocumentDB driver has been correctly installed and configured.
   For additional information, refer to [Setting up the ODBC driver in Windows](connect-odbc-setup-windows.md "connect-odbc-setup-windows.md").
2. Launch Microsoft Excel.
3. Navigate to **Data** > **Get Data** > **From Other Sources**.
4. Choose **From ODBC**:

![The Get Data dropdown shows the From Other Sources submenu. The From ODBC option is selected.](images/excel-odbc-1.png) 5. Select the data source from the **Data source name (DSN)** drop down menu that is associated with Amazon DocumentDB:

![The Data source name dropdown with the DocumentDB DSN option selected.](images/excel-odbc-dsn-select-1.png) 6. Choose the collection from which you want to load data into Excel:

![The Navigator interface with the salaries table selected and a preview of its data.](images/excel-odbc-collect-1.png) 7. Load data into Excel:

![Excel spreadsheet showing five rows of data from the selected salaries table.](images/excel-data-load-1.png)
