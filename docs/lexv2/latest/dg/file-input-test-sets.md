# Test set columns supported by Test

Workbench

Below is the complete list of test set columns supported by Test Workbench and the
instruction on how to use them with Amazon Lex V2.

| Column Name                 | Test set type  | Value Type             | Multiple Columns Support | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------------- | -------------- | ---------------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Line Number                 | Text and Audio | Number                 | No                       | This is a user column which is ignored by Amazon Lex V2. It is<br>intended to help a test set author to sort and filter the<br>test-set rows. "Line #" can be used as an alternative column<br>name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Conversation Number         | Text and Audio | Number                 | No                       | This column allows you to put rows in a conversation<br>together. "Conversation #" can be used as an alternative column<br>name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Source                      | Text and Audio | Enum ("User", "Agent") | No                       | The value in this column indicates if the row is for a user<br>or an agent. "Conversation Participant" can be used as an<br>alternative column name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Input                       | Text           | String                 | No                       | This column is used to add the transcript for text test<br>set. Text input should be used in User rows. The Agent prompt<br>should be used in Agent rows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Expected Transcription      | Audio          | String                 | No                       | This column is used to add the transcript for the audio<br>test set. Expected transcription of the audio file should be<br>used in User rows with audio input. DTMF input can be used in<br>User rows with DTMF input. The Agent prompt should be used in<br>Agent rows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| S3 Audio Location           | Audio          | String                 | No                       | This column is used to add the audio file location and is<br>applicable only to audio test sets. The S3 path should be used<br>in the User rows with the audio input. This field should be left<br>empty in User rows with DTMF input. This field should be left<br>empty in Agent rows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Input Context Tag           | Text and Audio | String                 | Yes                      | This column is used to provide name of an input context<br>which will be used in input to Lex while executing the row in<br>the test set. This refers to input context in [Setting intent context for your Lex V2 bot](context-mgmt-active-context.md "context-mgmt-active-context.md"). Note<br>that Test Workbench only supports name of context. It does not<br>support the parameters in a context. Multiple columns named such<br>as 'Input Context Tag 1', 'Input Context Tag 2', and so on, may<br>be used.                                                                                                                                                                                                                                                                                                                                                                                   |
| Request Attribute           | Text and Audio | String                 | Yes                      | This column is used to provide a request attribute which<br>will be used in input to Lex while executing the row in the test<br>set. Value in a column should be provided in format<br>`<request-attribute-name> =<br><request-attribute-value>`. Spaces can be<br>added around '=' for readability. For example: request-attribute-foo = this is a dummy<br>response request-attribute-foo = 'this is a "dummy<br>response"' request-attribute-foo = "this is a 'dummy<br>response'". Multiple columns named such as 'Request Attribute<br>1', 'Request Attribute 2', and so on, may be<br>used.                                                                                                                                                                                                                                                                                                    |
| Session Attribute           | Text and Audio | String                 | Yes                      | This column is used to provide a session attribute which<br>will be used in input to Lex while executing the row in the test<br>set.<br>• Value in a column should be provided in format<br>`<session-attribute-name> =<br><session-attribute-value>`. Spaces can be<br>added around '=' for readability.<br>• Examples:<br>+ session-attribute-foo = this is a dummy<br>response<br>+ session-attribute-foo = 'this is a "dummy<br>response"'<br>+ session-attribute-foo = "this is a 'dummy<br>response'"<br>• Multiple columns named such as: 'Session Attribute<br>1', 'Session Attribute 2', and so on, may be<br>used.                                                                                                                                                                                                                                                                         |
| RunTime Hint                | Text and Audio | String                 | Yes                      | This column is used to provide a Runtime Hint for a slot<br>within an intent which will be used in input to Lex while<br>executing the row in the test set. Below are examples:<br>• Value in a column should be provided in format<br>`<intent-name>.<slot -name> = <<br>slot-value>`. Spaces may be added around '=' for<br>readability.<br>• Examples:<br>+ IntentNameFoo.slotNameFoo = a dummy<br>value<br>+ IntentNameFoo.slotNameFoo = 'a "dummy<br>value"'<br>+ IntentNameFoo.slotNameFoo = "a 'dummy<br>value'"<br>• Test workbench does not support composite slots<br>for runtime hints.<br>• Multiple columns named such as 'RunTime Hint 1',<br>'RunTime Hint 2', and so on, may be used.                                                                                                                                                                                                |
| Barge In                    | Audio          | Boolean                | No                       | This column is used specify if Test Workbench should<br>barge-in when sending audio file to Lex Runtime for the row in<br>the test set.<br>• Only applicable for audio test set for the<br>streaming API.<br>• This column is ignored when executing a test set<br>in non-streaming API mode.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Expected Output Intent      | Text and Audio | String                 | No                       | This column is used specify name of an intent expected in<br>output from Lex for the row in the test set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Expected Output Slot        | Text and Audio | String                 | Yes                      | This column is used to provide a slot value expected in<br>output from Lex while executing the row in the test set.<br>• Value in a column should be provided in format<br>`<slot -name> = < slot-value>`. Spaces<br>may be added around '=' for readability.<br>• Examples for slots that are neither multi-value<br>slots nor composite slots:<br>+ slotNameFoo = a dummy value<br>+ slotNameFoo = 'a "dummy value"'<br>+ slotNameFoo = "a 'dummy value'"<br>• Examples for multi-value slots:<br>+ slotNameFoo = value1, value2<br>+ slotNameFoo = value1, "Foo's item"<br>+ slotNameFoo = value1, 'value2'<br>• Examples for composite slots where slot name is<br>‘Car’ and sub slot name is ‘Make’:<br>+ Car.Make = Toyota<br>+ Car.Make = "Toyota"<br>+ Car.Make = 'Toyota'<br>• Multiple columns named such as: 'Expected Output<br>Slot 1', 'Expected Output Slot 2', etc., may be<br>used. |
| Expected Output Context Tag | Text and Audio | String                 | Yes                      | This column is used to specify name of an output context<br>expected in output from Lex for the row in the test set.<br>• This refers to output context in [Setting intent context for your Lex V2<br>bot](context-mgmt-active-context.md "context-mgmt-active-context.md").<br>• Note that Test Workbench only supports name of<br>context and does not yet support parameters inside<br>the context.<br>• Multiple columns named such as: 'Expected Output<br>Context Tag 1', 'Expected Output Context Tag 2',<br>etc., may be used.                                                                                                                                                                                                                                                                                                                                                               |
