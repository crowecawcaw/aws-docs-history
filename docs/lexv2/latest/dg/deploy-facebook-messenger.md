# Integrating an Amazon Lex V2 bot

with Facebook Messenger

You can host your Amazon Lex V2 bot in Facebook Messenger. When you do,
Facebook users can interact with your bot to fulfill intents.

Before you start, you need to sign up for a Facebook developer account
at [https://developers.facebook.com](https://developers.facebook.com "https://developers.facebook.com").
