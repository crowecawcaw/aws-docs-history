# Importing and exporting bots in Lex V2

You can export a bot definition, a bot locale or a custom vocabulary
and then import it back to create a new resource or to overwrite an
existing resource in an AWS account. For example, you can export a bot
from a test account and then create a copy of the bot in your production
account. You can also copy a bot from one AWS Region to another
Region.

You can change the resources of the exported resource before importing
it. For example, you can export a bot and then edit the JSON file for a
slot to add or remove slot value elicitation utterances from a specific
slot. After you finish editing the definition, you can import the
modified file.
