# Expressions

You can add expressions strings to perform functions in Amazon Lex V2. This table shows the syntax and examples that can be used in SRGS expressions.

| Expression type             | Syntax                                                                                                                                                                                                                            | Example                                                | Supported?                              |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------- | ------------------------------ | ----------------------------- | ------------------ | ------------------ | ------------------- | --- |
| Regular expression literal  | String literal containing valid [regex special characters](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions "https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions") | `<br>"^\d\.$"<br>`                                     | **No**                                  |
| Function                    | `function functionName(parameters) {<br>functionBody}`                                                                                                                                                                            | `<br>var x = function calc() {<br>return 10;<br>}<br>` | **No**                                  |
| Delete                      | `delete expression`                                                                                                                                                                                                               | `<br>delete obj.property;<br>`                         | **No**                                  |
| Void                        | `void expression`                                                                                                                                                                                                                 | `<br>void (2 == '2');<br>`                             | **No**                                  |
| Typeof                      | `typeof expression`                                                                                                                                                                                                               | `<br>typeof 42;<br>`                                   | **No**                                  |
| Member index                | `expression [ expressions<br>]`                                                                                                                                                                                                   | `<br>var fruits = ["apple"];<br>fruits[0];<br>`        | Yes                                     |
| Member dot                  | `expression . identifier`                                                                                                                                                                                                         | `<br>out.value<br>`                                    | yes                                     |
| Arguments                   | `expression (arguments)`                                                                                                                                                                                                          | `<br>new Date('1994-10-11')<br>`                       | Yes                                     |
| Post increment              | `expression++`                                                                                                                                                                                                                    | `<br>var x=10; x++;<br>`                               | Yes                                     |
| Post decrement              | `expression--`                                                                                                                                                                                                                    | `<br>var x=10; x--;<br>`                               | Yes                                     |
| Pre increment               | `++expression`                                                                                                                                                                                                                    | `<br>var x=10; ++x;<br>`                               | Yes                                     |
| Pre decrement               | `--expression`                                                                                                                                                                                                                    | `<br>var x=10; --x;<br>`                               | Yes                                     |
| Unary plus / Unary minus    | `+expression /<br>-expression`                                                                                                                                                                                                    | `<br>+x / -x;<br>`                                     | Yes                                     |
| Bit not                     | `~ expression`                                                                                                                                                                                                                    | `<br>const a = 5;<br>console.log( ~a );<br>`           | Yes                                     |
| Logical not                 | `! expression`                                                                                                                                                                                                                    | ```<br>!(a > 0                                         |                                         | b > 0)<br>```                  | Yes                           |
| Multiplicative              | `expression ('\*'                                                                                                                                                                                                                 | '/'                                                    | '%')<br>expression`                     | `<br>(x + y)<br>• (a / b)<br>` | Yes                           |
| Additive                    | `expression ('+'                                                                                                                                                                                                                  | '-')<br>expression`                                    | `<br>(a + b)<br>• (a<br>• (a + b))<br>` | Yes                            |
| Bit shift                   | `expression ('<<'                                                                                                                                                                                                                 | '>>'                                                   | '>>>')<br>expression`                   | `<br>(a >> b) >>> c<br>`       | Yes                           |
| Relative                    | `expression ('<'                                                                                                                                                                                                                  | '>'                                                    | '<='                                    | <br>'>=') expression`          | `<br>if (a > b) { ... }<br>`  | Yes                |
| In                          | `expression in expression`                                                                                                                                                                                                        | `<br>fruits[0] in otherFruits;<br>`                    | Yes                                     |
| Equality                    | `expression ('=='                                                                                                                                                                                                                 | '!='                                                   | '==='                                   | <br>'!===') expression`        | `<br>if (a == b) { ... }<br>` | Yes                |
| Bit and / xor / or          | `expression ('&'                                                                                                                                                                                                                  | '^'                                                    | '                                       | ')<br>expression`              | ```<br>a & b / a ^ b / a      | b<br>```           | Yes                |
| Logical and / or            | `expression ('&&'                                                                                                                                                                                                                 | '                                                      |                                         | ')<br>expression`              | ```<br>if (a && (b            |                    | c)) { ...}<br>```  | Yes                 |
| Ternary                     | `expression ? expression :<br>expression`                                                                                                                                                                                         | `<br>a > b ? obj.prop : 0<br>`                         | Yes                                     |
| Assignment                  | `expression = expression`                                                                                                                                                                                                         | `<br>out.value = "string";<br>`                        | Yes                                     |
| Assignment operator         | `expression ('\*='                                                                                                                                                                                                                | '/='                                                   | '+='                                    | '-='                           | <br>'%=') expression`         | `<br>a *= 10;<br>` | Yes                |
| Assignment bitwise operator | `expression ('<<='                                                                                                                                                                                                                | '>>='                                                  | <br>'>>>='                              | '&='                           | '^='                          | '                  | =')<br>expression` | `<br>a <<= 10;<br>` | Yes |
| Identifier                  | `identifierSequence` where<br>\*identifierSequence<br>• is a<br>sequence of [valid characters](https://developer.mozilla.org/en-US/docs/Glossary/Identifier "https://developer.mozilla.org/en-US/docs/Glossary/Identifier")       | `<br>fruits=[10, 20, 30];<br>`                         | Yes                                     |
| Null literal                | `null`                                                                                                                                                                                                                            | `<br>x = null;<br>`                                    | Yes                                     |
| Boolean literal             | `true                                                                                                                                                                                                                             | false`                                                 | `<br>x = true;<br>`                     | Yes                            |
| String literal              | `'string' / "string"`                                                                                                                                                                                                             | `<br>a = 'hello',<br>b = "world";<br>`                 | Yes                                     |
| Decimal literal             | `integer [.] digits<br>[exponent]`                                                                                                                                                                                                | `<br>111.11 e+12<br>`                                  | Yes                                     |
| Hex literal                 | `0 (x                                                                                                                                                                                                                             | X)[0-9a-fA-F]`                                         | `<br>0x123ABC<br>`                      | Yes                            |
| Octal literal               | `O [0-7]`                                                                                                                                                                                                                         | `<br>"O51"<br>`                                        | Yes                                     |
| Array literal               | `[ expression, ... ]`                                                                                                                                                                                                             | `<br>v = [a, b, c];<br>`                               | Yes                                     |
| Object literal              | `{property: value, ...}`                                                                                                                                                                                                          | `<br>out = {value: 1, flag: false};<br>`               | Yes                                     |
| Parenthesized               | `( expressions )`                                                                                                                                                                                                                 | `<br>x + (x + y)<br>`                                  | Yes                                     |
