# Required ports

To integrate Amazon GameLift Streams, ensure that your network infrastructure has the necessary ports open and accessible. The following is a list of
the ports you should plan to have open on your network to communicate with Amazon GameLift Streams.

| Port        | Protocol    | Purpose                                     |
| ----------- | ----------- | ------------------------------------------- |
| 443         | (HTTPS) TCP | AWS APIs, including Amazon GameLift Streams |
| 33435-33465 | UDP         | Web RTC                                     |
