# Using Maven

The Maven repository format is used by many different languages, including Java, Kotlin,
Scala, and Clojure. It's supported by many different build tools, including Maven, Gradle,
Scala SBT, Apache Ivy, and Leiningen.

We have tested and confirmed compatibility with CodeCatalyst for the following versions:

- Latest **Maven** version: 3.6.3.
- Latest **Gradle** version: 6.4.1. Version 5.5.1 has
  also been tested.
