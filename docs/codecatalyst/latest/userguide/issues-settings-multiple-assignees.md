# Enabling or disabling multiple assignees

Follow these steps to configure the setting for multiple assignees for issues in CodeCatalyst.

###### To enable or disable multiple assignees

1. In the navigation pane, choose **Issues**.
2. Choose **Active issues** to open the **issues view switcher** dropdown
   menu and choose **Settings**.
3. In **Assignee** in the **Basic settings** section,
   toggle the indicator to enable multiple assignees to be assigned to the same
   issue. An issue can have up to 10 assignees. If you do not enable this option, you
   will only be able to assign one assignee to an issue.
