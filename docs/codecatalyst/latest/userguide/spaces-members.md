# Granting users space permissions

You can manage members for a space by viewing, adding, removing, or changing roles for
users who join the space.

The information in this guide is provided for inviting and managing users in spaces in
CodeCatalyst that support AWS Builder ID users. To learn more about the steps to set up and administer a
space that supports identity federation, see [Setup and administration for
CodeCatalyst spaces](../adminguide/what-is.md "../adminguide/what-is.md") in the _Amazon CodeCatalyst Administrator
Guide_.
