# To create a status

1. In the navigation pane, choose **Issues**.
2. Choose **Active issues** to open the **issues view switcher** dropdown
   menu and choose **Settings**.
3. In **Statuses**, choose the plus icon next to the category you
   want the status to be in.
4. Name the status, then choose check mark icon.

###### Note

Choose the X icon to cancel adding a status.

The custom status is now visible on your board and shows as an option when
creating an issue.
