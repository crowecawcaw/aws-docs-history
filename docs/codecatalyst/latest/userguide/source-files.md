# Managing

source code files in Amazon CodeCatalyst

In Amazon CodeCatalyst, a file is a version-controlled, self-contained piece of information
available to you and other users of the source repository and branch where the file is
stored. You can organize your repository files with a directory structure. CodeCatalyst
automatically tracks every committed change to a file. You can store different versions of a
file in different repository branches.

To add or edit multiple files in a source repository, you can use a Git client, a
Dev Environment, or an integrated development environment (IDE). To add or edit a single file,
you can use the CodeCatalyst console.
