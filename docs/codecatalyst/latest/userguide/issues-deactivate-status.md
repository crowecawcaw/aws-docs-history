# To deactivate a status

1. In the navigation pane, choose **Issues**.
2. Choose **Active issues** to open the **issues view switcher** dropdown
   menu and choose **Settings**.
3. In **Statuses**, choose a status you want to deactivate.
4. On the status you want to deactivate, choose the toggle on the status. The status
   is now grayed out.

###### Note

The deactivated status appears on the board until all issues are moved out of
it. Issues cannot be added to a deactivated status. 5. To reactivate a deactivated status, choose the toggle on the status. The status
is no longer grayed out.

###### Note

There must be at least one active status in each category. If there is only one
status in the category, you cannot deactivate it.
