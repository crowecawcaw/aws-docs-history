# Contribute

The blueprints software development kit (SDK) is an open-source library that you can contribute to. As a
contributor, consider the contribution guidelines, feedback, and defects. For more information,
see the [blueprints GitHub repository](https://github.com/aws/codecatalyst-blueprints "https://github.com/aws/codecatalyst-blueprints").
