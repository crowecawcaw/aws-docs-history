# Tracking work with custom statuses

You can add custom statuses on your board. Each custom status must belong to one of the
following categories: **Draft**, **Not started**,
**Started**, or **Completed**. Status categories are used to help
organize statuses and populate default views. For more information about statuses and status categories, see
[Status and status categories](issues-concepts.md#issues-concepts-status-definition "issues-concepts.md#issues-concepts-status-definition") and for more
information about views, see [Finding and viewing issues](issues-view.md "issues-view.md").
