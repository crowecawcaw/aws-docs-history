# Exporting issues

You can export issues in your current view into a .xlsx file. To export issues, perform the following steps.

###### To export issues

1. Navigate to your project.
2. In the navigation bar choose **Issues**.
3. Choose **Active issues** to open the **issues view switcher** dropdown menu and
   navigate to the view containing the issues you want to export. Only issues shown in the view will be exported.
4. Choose the ellipses menu and choose **Export to Excel**.
5. The .xlsx file downloads. By default, it is titled the name of the project and the
   date the export was completed.
