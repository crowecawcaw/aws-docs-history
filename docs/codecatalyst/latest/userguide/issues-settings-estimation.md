# Configuring issue effort estimation

Follow these steps to configure the setting for effort estimations for issues in CodeCatalyst.

###### To configure effort estimation for issues

1. In the navigation pane, choose **Issues**.
2. Choose **Active issues** to open the **issues view switcher** dropdown
   menu and choose **Settings**.
3. In **Estimation** in the **Basic settings** section,
   choose how the estimation values will be displayed. The types of estimates available are **T-shirt sizing**,
   **Fibonacci sequencing**, or **Hide estimates**. When
   the estimation type is updated, no data will be lost and the estimation value of all
   issues will be converted automatically. The conversion mapping is shown in the following table.

| T-shirt size | Fibonacci sequence |
| ------------ | ------------------ |
| XS           | 1                  |
| XS           | 2                  |
| S            | 3                  |
| M            | 5                  |
| L            | 8                  |
| XL           | 13                 |
