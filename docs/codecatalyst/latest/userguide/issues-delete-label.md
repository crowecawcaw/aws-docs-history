# Deleting a label

You cannot currently delete an issues label in CodeCatalyst. If you remove a label from all issues, the label will appear in the
**Unused labels** section in the **Labels** section of issue **settings**.
Unused labels appear at the end of the list of labels when using filters or adding labels to an issue.
You can find an overview of all labels (used and unused) and issues that have them in the issue **settings**.
