# Starting a workflow run manually

In Amazon CodeCatalyst, you can start a workflow run manually from the CodeCatalyst console.

For more information about workflow runs, see [Running a workflow](workflows-working-runs.md "workflows-working-runs.md").

###### Note

You can also start a workflow run automatically by [configuring a trigger](workflows-add-trigger.md "workflows-add-trigger.md").

###### To start a workflow run manually

1. Open the CodeCatalyst console at [https://codecatalyst.aws/](https://codecatalyst.aws/ "https://codecatalyst.aws/").
2. Choose your project.
3. In the navigation pane, choose **CI/CD**, and then choose **Workflows**.
4. Choose the name of your workflow. You can filter by the source repository or
   branch name where the workflow is defined, or filter by workflow name or
   status.
5. Choose **Run**.
