# Deleting a project

You can delete a project to remove all access to the project's resources. You must have the
Space administrator or Project administrator role to delete a project. Once you have deleted a
project, project members will be unable to access project resources, and any workflows that are
prompted by third-party source repositories will be stopped.

###### To delete your project

1. Open the CodeCatalyst console at [https://codecatalyst.aws/](https://codecatalyst.aws/ "https://codecatalyst.aws/").
2. Navigate to the space with the project you want to view. Under
   **Projects**, choose your project.
3. In the navigation pane, choose **Project settings**.
4. Choose **Delete project**.
5. Enter
   `delete` to confirm the deletion.
6. Choose **Delete project**.
