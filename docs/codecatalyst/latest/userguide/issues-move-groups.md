# Moving issues between groups

You can [group issues](issues-grouping.md "issues-grouping.md") in the **All
issues** and **Board** views by various parameters. If
the issues are grouped, you can move issues from one group to another. Moving an
issue from one group to another will automatically edit the field that the issues
are grouped on to match the target group.

As an example scenario, assume there is a company using CodeCatalyst that has issues
assigned to two people, Wang Xiulan and Saanvi Sarkar. The board is
grouped by `Assignee`, and there are two groups, one for each assignee.
Moving an issue from the Wang Xiulan group to the Saanvi Sarkar group will
update the issue's assignee to Saanvi Sarkar.
