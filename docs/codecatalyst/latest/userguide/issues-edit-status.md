# To edit a status

1. In the navigation pane, choose **Issues**.
2. Choose **Active issues** to open the **issues view switcher** dropdown
   menu and choose **Settings**.
3. In **Statuses**, choose the edit icon next to the status you want
   to edit or change.
4. Edit the status, then choose the check mark icon.

The edited status is now visible on your board.
