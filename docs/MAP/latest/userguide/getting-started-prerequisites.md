

# Prerequisites
<a name="getting-started-prerequisites"></a>

Before you begin tagging your workloads, you must have the following:
+ Your AWS Migration Program Engagement number (MPE ID number), also known as your project number, in your Migration Plan.
+ Access to the AWS management (payer) account(s) listed in your Migration Plan.
+ Ensure that Cost Explorer is enabled. To learn how to enable Cost Explorer, see [Enabling Cost Explorer](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-enable.html).
+ IAM permissions to tag migrated workloads.
