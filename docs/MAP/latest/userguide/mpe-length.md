

# MPE ID length
<a name="mpe-length"></a>

Your project number found within your migration plan is also known as your MPE ID, and consists of 5-digits (short MPE ID) or 10 alphanumeric characters (long MPE ID). 

For example:
+ **Project 12345**: MPE ID = 12345 (short MPE ID)
+ **Project ABCDE12345**: MPE ID = ABCDE12345 (long MPE ID)



**Note**  
The alphanumeric MPE ID uses uppercase letters.

Refer to the first page below the title of your migration plan to find your project number as shown in the following image:
