# Reservation columns

Reservation columns contain data about a reservation that applies to the line
item.

| Column name                                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Data type |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| reservation_amortized_upfront_cost_for_usage                    | The initial upfront payment for all upfront RIs and partial upfront RIs amortized for<br>usage time. The value is equal to:<br>`RIAmortizedUpfrontFeeForBillingPeriod` \<br>• `The<br>normalized usage amount for DiscountedUsage line items` /<br>`The normalized usage amount for the RIFee`. Because<br>there are no upfront payments for no upfront RIs, the value for a no<br>upfront RI is `0`. We don't provide this value for<br>Dedicated Host reservations at this time. The change will be made in<br>a future update. | double    |
| reservation_amortized_upfront_fee_for_billing_period            | Describes how much of the upfront fee for this reservation is costing you for the<br>billing period. The initial upfront payment for all upfront RIs<br>and partial upfront RIs, amortized over this month. Because<br>there are no upfront fees for no upfront RIs, the value for no<br>upfront RIs is `0`. We don't provide this value for<br>Dedicated Host reservations at this time. The change will be<br>made in a future update.                                                                                          | double    |
| reservation_availability_zone                                   | The Availability Zone of the resource that is associated with<br>this line item.                                                                                                                                                                                                                                                                                                                                                                                                                                                  | string    |
| reservation_effective_cost                                      | The sum of both the upfront and hourly rate of your RI, averaged into an effective<br>hourly rate. `EffectiveCost` is calculated by taking the<br>`amortizedUpfrontCostForUsage` and adding it to the<br>`recurringFeeForUsage`.                                                                                                                                                                                                                                                                                                  | double    |
| reservation_end_time                                            | The end date of the associated RI lease term.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | string    |
| reservation_modification_status                                 | Shows whether the RI lease was modified or if it is<br>unaltered.<br>**Original:\*<br>• The purchased RI<br>was never modified.<br>**System:_<br>• The purchased RI was<br>modified using the console or API.<br>\*\*Manual:_<br>• The purchased RI was<br>modified using AWS Support assistance.<br>\*_ManualWithData:_<br>• The purchased<br>RI was modified using AWS Support assistance, and AWS<br>calculated estimates for the RI.                                                                                          | string    |
| reservation_net_amortized_upfront_cost_for_usage                | The initial upfront payment for All Upfront RIs and Partial<br>Upfront RIs amortized for usage time, if applicable. This column<br>is included in your report only when your account has a discount<br>in the applicable billing period.                                                                                                                                                                                                                                                                                          | double    |
| reservation_net_amortized_upfront_fee_for_billing_period        | The cost of the reservation's upfront fee for the billing<br>period. This column is included in your report only when your<br>account has a discount in the applicable billing period.                                                                                                                                                                                                                                                                                                                                            | double    |
| reservation_net_effective_cost                                  | The sum of both the upfront fee and the hourly rate of your<br>RI, averaged into an effective hourly rate. This column is<br>included in your report only when your account has a discount in<br>the applicable billing period.                                                                                                                                                                                                                                                                                                   | double    |
| reservation_net_recurring_fee_for_usage                         | The after-discount cost of the recurring usage fee. This<br>column is included in your report only when your account has a<br>discount in the applicable billing period.                                                                                                                                                                                                                                                                                                                                                          | double    |
| reservation_net_unused_amortized_upfront_fee_for_billing_period | The net unused amortized upfront fee for the billing period.<br>This column is included in your report only when your account<br>has a discount in the applicable billing period.                                                                                                                                                                                                                                                                                                                                                 | double    |
| reservation_net_unused_recurring_fee                            | The recurring fees associated with unused reservation hours<br>for Partial Upfront and No Upfront RIs after discounts. This<br>column is included in your report only when your account has a<br>discount in the applicable billing period.                                                                                                                                                                                                                                                                                       | double    |
| reservation_net_upfront_value                                   | The upfront value of the RI with discounts applied. This<br>column is included in your report only when your account has a<br>discount in the applicable billing period.                                                                                                                                                                                                                                                                                                                                                          | double    |
| reservation_normalized_units_per_reservation                    | The number of normalized units for each instance of a<br>reservation subscription.                                                                                                                                                                                                                                                                                                                                                                                                                                                | string    |
| reservation_number_of_reservations                              | The number of reservations that are covered by this<br>subscription. For example, one RI subscription might have four<br>associated RI reservations.                                                                                                                                                                                                                                                                                                                                                                              | string    |
| reservation_recurring_fee_for_usage                             | The recurring fee amortized for usage time, for partial upfront RIs and no upfront<br>RIs. The value is equal to: `The unblended cost of the<br>RIFee` \<br>• `The sum of the normalized usage amount of<br>Usage line items` / `The normalized usage amount of<br>the RIFee for size flexible Reserved Instances`. Because<br>all upfront RIs don't have recurring fee payments greater than 0,<br>the value for all upfront RIs is `0`.                                                                                         | double    |
| reservation_reservation_a_r_n                                   | The Amazon Resource Name (ARN) of the RI that this line item<br>benefited from. This is also called the "RI Lease ID". This is a<br>unique identifier of this particular AWS Reserved Instance.<br>The value string also contains the AWS service name and the<br>Region where the RI was purchased.                                                                                                                                                                                                                              | string    |
| reservation_start_time                                          | The start date of the term of the associated Reserved<br>Instance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                | string    |
| reservation_subscription_id                                     | A unique identifier that maps a line item with the associated<br>offer. We recommend you use the RI ARN as your identifier of an<br>AWS Reserved Instance, but both can be used.                                                                                                                                                                                                                                                                                                                                                  | string    |
| reservation_total_reserved_normalized_units                     | The total number of reserved normalized units for all instances for a reservation<br>subscription. AWS computes total normalized units by multiplying<br>the `reservation/NormalizedUnitsPerReservation` with<br>`reservation/NumberOfReservations`.                                                                                                                                                                                                                                                                              | string    |
| reservation_total_reserved_units                                | `TotalReservedUnits` populates for both Fee and RIFee line items with<br>distinct values.                                                                                                                                                                                                                                                                                                                                                                                                                                         | string    |
| reservation_units_per_reservation                               | `UnitsPerReservation` populates for both Fee and RIFee line items with<br>distinct values.                                                                                                                                                                                                                                                                                                                                                                                                                                        | string    |
| reservation_unused_amortized_upfront_fee_for_billing_period     | The amortized-upfront-fee-for-billing-period-column amortized portion of the initial<br>upfront fee for all upfront RIs and partial upfront RIs. Because<br>there are no upfront payments for no upfront RIs, the value for<br>no upfront RIs is `0`. We don't provide this value<br>for Dedicated Host reservations at this time. The change will be<br>made in a future update.                                                                                                                                                 | double    |
| reservation_unused_normalized_unit_quantity                     | The number of unused normalized units for a size-flexible<br>Regional RI that you didn't use during this billing<br>period.                                                                                                                                                                                                                                                                                                                                                                                                       | double    |
| reservation_unused_quantity                                     | The number of RI hours that you didn't use during this billing<br>period.                                                                                                                                                                                                                                                                                                                                                                                                                                                         | double    |
| reservation_unused_recurring_fee                                | The recurring fees associated with your unused reservation<br>hours for partial upfront and no upfront RIs. Because all<br>upfront RIs don't have recurring fees greater than<br>`0`, the value for All Upfront RIs is<br>`0`.                                                                                                                                                                                                                                                                                                    | double    |
| reservation_upfront_value                                       | The upfront price paid for your AWS Reserved Instance. For<br>no upfront RIs, this value is `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                  | double    |
