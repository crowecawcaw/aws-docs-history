# Resource tags details

You can use the **resource** columns in AWS Cost and Usage Reports to
find information about the specific resources covered by a line item. These columns
include user-defined cost allocation tags. Examples include the following:

## resourceTags/user:creator

Use a **user:Creator** tag to track which user created a
resource.

## resourceTags/user:name

Use a **user:Name** tag to track which resources are associated
with a specific user.

## resourceTags/user:owner

Use a **user:Owner** tag to track which user owns a
resource.

## resourceTags/user:purpose

Use a **user:Purpose** tag to track why a resource was
created.
