# Product columns

Product columns contain data about the product that is being charged in the line
item.

| Column name                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Data type            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------- |
| product                    | A map column containing key-value pairs of multiple product attributes and their<br>values for a given line item.<br>A product attribute only appears in the map column if it has a value that applies to<br>the specific line item.<br>NoteAny product column that appeared in legacy CUR, but is not<br>part of the CUR 2.0 static schema, appears in this map<br>column.<br>The keys of this column can be queried as individual columns by using the dot<br>operator. For more information, see [Data query](dataexports-data-query.md "dataexports-data-query.md"). | map <string, string> |
| product_comment            | A comment regarding the product.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | string               |
| product_fee_code           | The code that refers to the fee.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | string               |
| product_fee_description    | The description for the product fee.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | string               |
| product_from_location      | Describes the location where the usage originated from.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | string               |
| product_from_location_type | Describes the location type where the usage originated<br>from.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | string               |
| product_from_region_code   | Describes the source Region code for the AWS service.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | string               |
| product_instanceSKU        | The SKU of the product instance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | string               |
| product_instance_family    | Describes your Amazon EC2 instance family. Amazon EC2 provides<br>you with a large number of options across 10 different instance<br>types, each with one or more size options, organized into<br>distinct instance families optimized for different types of<br>applications.                                                                                                                                                                                                                                                                                           | string               |
| product_instance_type      | Describes the instance type, size, and family, which define<br>the CPU, networking, and storage capacity of your<br>instance.                                                                                                                                                                                                                                                                                                                                                                                                                                            | string               |
| product_location           | Describes the Region that your Amazon S3 bucket resides<br>in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | string               |
| product_location_type      | Describes the endpoint of your task.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | string               |
| product_operation          | Describes the specific AWS operation that this line item<br>covers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | string               |
| product_pricing_unit       | The smallest billing unit for an AWS service. For example,<br>0.01c per API call.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | string               |
| product_product_family     | The category for the type of product.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | string               |
| product_region_code        | A Region is a physical location around the world where data centers are clustered.<br>AWS calls each group of logical data centers an Availability<br>Zone (AZ). Each AWS Region consists of multiple, isolated, and<br>physically separate AZs within a geographical area. The Region<br>code attribute has the same name as an AWS Region, and<br>specifies where the AWS service is available.                                                                                                                                                                        | string               |
| product_sku                | A unique code for a product. The SKU is created by combining<br>the `ProductCode`, `UsageType`, and<br>`Operation`. For size-flexible RIs, the SKU uses<br>the instance that was used. For example, if you used a<br>`t2.micro` instance and AWS applied a<br>`t2.small` RI discount to the usage, the line<br>item SKU is created with the `t2.micro`.                                                                                                                                                                                                                  | string               |
| product_servicecode        | This identifies the specific AWS service to the customer as<br>a unique short abbreviation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | string               |
| product_to \_location_type | Describes the destination location of the service<br>usage.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | string               |
| product_to_location        | Describes the location usage destination.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | string               |
| product_to_region_code     | Describes the source Region code for the AWS service.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | string               |
| product_usagetype          | Describes the usage details of the line item.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | string               |
