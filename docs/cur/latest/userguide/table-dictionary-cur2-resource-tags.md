# Resource tags columns

Resource tags columns contain data about resource tags that apply to the line
item.

| Column name   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Data type            |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| resource_tags | A map column containing key-value pairs of resource tags and their values for a given line item. The values in this column are all of data type "string". Resource tag keys only appear in this column if they've been enabled as cost allocation tags in the Billing console. After being enabled, a particular key only appears in the map column if it has a value that applies to the specific line item. The keys of this column can be queried as individual columns using the dot operator. For more information, see [Data query](dataexports-data-query.md "dataexports-data-query.md"). | map <string, string> |
