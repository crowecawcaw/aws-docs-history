# Cost category columns

Cost category columns contain data about cost categories that apply to the line
item. Note that you don’t need to select this column if you selected the Tags column because resource tags are also included under the Tags column.

| Column name   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Data type            |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| cost_category | A map column containing key-value pairs of the cost categories and their values for a<br>given line item. These keys and values are populated based on<br>the categorization rules you create in the cost categories<br>feature.<br>A cost category key only appears in the map column if it has a value that applies to<br>the specific line item.<br>The keys of this column can be queried as individual columns using the dot operator.<br>For more information, see [Data query](dataexports-data-query.md "dataexports-data-query.md"). | map <string, string> |
