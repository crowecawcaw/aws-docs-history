# Discount columns

Discount columns contain data about any discounts you are receiving.

| Column name               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Data type            |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| discount                  | \*_Table configuration:_<br>• Removed by: INCLUDE MANUAL DISCOUNT COMPATIBILITY<br>A "struct" column containing key-value pairs of any specific discounts that apply to this line item. The keys correspond to a discount type and the values correspond to either the discount value or other information. The values in this column are either data type "numeric" or "string" depending on the specific key.<br>The keys of this column can be queried as individual columns by using the dot operator. For more information, see [Data query](dataexports-data-query.md "dataexports-data-query.md").<br>This column is not available when "Manual discount compatibility" is enabled. When it's enabled, discounts are populated as separate line items and not in this column.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | map <string, double> |
| discount_bundled_discount | The bundled discount applied to the line item. A bundled discount is a usage-based discount that provides free or discounted usage of a service or feature based on the usage of another service or feature.<br>As of August 2025, bundled discounts are applied using an "Owner-first approach" where discounts are first applied to the account that generates the source usage. Within the source account, discounts are applied based on the following sequence:<br>• Highest per-unit price<br>• Earlier usage timestamps<br>• Larger usage amounts when other factors are equal<br>Any remaining discounts are distributed across other accounts in the Consolidated Billing Family (CBF) based on the following sequence:<br>• Highest per-unit price<br>• Ascending order of account Id<br>• Earlier usage timestamps<br>• Larger usage amounts<br>Examples of bundled discounts include:<br>• If you use AWS Shield Advanced, then you don't have to pay for AWS WAF separately. AWS WAF usage is bundled with AWS Shield Advanced. For more information about AWS Shield Advanced, see [Amazon CloudFront pricing](http://aws.amazon.com/cloudfront/pricing/ "http://aws.amazon.com/cloudfront/pricing/").<br>• If you create a NAT gateway with AWS Network Firewall, then the standard NAT gateway processing and per-hour usage charges are waived on a one-to-one basis with the firewall's processing per GB and usage hours. For more information, see [AWS Network Firewall pricing](http://aws.amazon.com/network-firewall/pricing/ "http://aws.amazon.com/network-firewall/pricing/").<br>• With Amazon Interactive Video Service (IVS) Chat, for every hour of video input sent, you get 2,700 sent messages and 270,000 delivered messages at no additional cost. For more information, see [Amazon Interactive Video Service pricing](http://aws.amazon.com/ivs/pricing/ "http://aws.amazon.com/ivs/pricing/"). | double               |
| discount_total_discount   | \*_Table configuration:_<br>• Removed by: `INCLUDE MANUAL DISCOUNT COMPATIBILITY`<br>The sum of all the discount columns for the corresponding line item.<br>This column is not available when "Manual discount compatibility" is enabled. When it's enabled, discounts are populated as separate line items and not in this column.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | double               |
