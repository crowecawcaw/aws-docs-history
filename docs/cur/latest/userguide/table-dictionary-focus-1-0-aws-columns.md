# FOCUS 1.0 with AWS columns

| Column name                | Description                                                                                                                                                                                             | Data type              | Null value allowed |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------ |
| AvailabilityZone           | A provider-assigned identifier for a physically separated and<br>isolated area within a Region that provides high availability and<br>fault tolerance.                                                  | string                 | Yes                |
| BilledCost                 | A charge that is the basis for invoicing, inclusive of all<br>reduced rates and discounts while excluding the amortization of<br>relevant purchases paid to cover future eligible charges.              | double                 | No                 |
| BillingAccountId           | A provider-assigned identifier for a billing account.                                                                                                                                                   | string                 | No                 |
| BillingAccountName         | A provider-assigned name for a billing account.                                                                                                                                                         | string                 | Yes                |
| BillingCurrency            | An identifier that represents the currency that a charge for<br>resources or services was billed in.                                                                                                    | string                 | No                 |
| BillingPeriodEnd           | The end date and time of the billing period.                                                                                                                                                            | timestamp_milliseconds | No                 |
| BillingPeriodStart         | The start date and time of the billing period.                                                                                                                                                          | timestamp_milliseconds | No                 |
| ChargeCategory             | An indicator of whether the row represents an upfront or<br>recurring fee, cost of usage that already occurred, an<br>after-the-fact adjustment (for example, credits), or taxes.                       | string                 | No                 |
| ChargeClass                | An indicator of whether the row represents a regular charge, or a<br>correction to one or more previous charges.                                                                                        | string                 | Yes                |
| ChargeDescription          | A high-level context of a row without requiring additional<br>discovery.                                                                                                                                | string                 | Yes                |
| ChargeFrequency            | An indicator of how often a charge will occur.                                                                                                                                                          | string                 | No                 |
| ChargePeriodEnd            | The end date and time of the charge period.                                                                                                                                                             | timestamp_milliseconds | No                 |
| ChargePeriodStart          | The start date and time of the charge period.                                                                                                                                                           | timestamp_milliseconds | No                 |
| CommitmentDiscountCategory | An indicator of whether the commitment-based discount identified<br>in the CommitmentDiscountId column is based on usage quantity or<br>cost (that is, spend).                                          | string                 | Yes                |
| CommitmentDiscountId       | A provider-assigned identifier for a commitment-based<br>discount.                                                                                                                                      | string                 | Yes                |
| CommitmentDiscountName     | The display name assigned to a commitment-based discount.                                                                                                                                               | string                 | Yes                |
| CommitmentDiscountStatus   | An indicator of whether the charge corresponds to a used or<br>unused commitment discount.                                                                                                              | string                 | Yes                |
| CommitmentDiscountType     | A provider-assigned name to identify the type of commitment-based<br>discount applied to the row.                                                                                                       | string                 | Yes                |
| ConsumedQuantity           | The volume of a given resource or service used or purchased based<br>on the ConsumedUnit.                                                                                                               | double                 | Yes                |
| ConsumedUnit               | A provider-assigned measurement unit indicating how a provider<br>measures usage of a given SKU associated with a resource or<br>service.                                                               | string                 | Yes                |
| ContractedCost             | The cost calculated by multiplying ContractedUnitPrice and the<br>corresponding PricingQuantity.                                                                                                        | double                 | No                 |
| ContractedUnitPrice        | The agreed-upon unit price for a single PricingUnit of the<br>associated SKU, inclusive of any negotiated discounts while<br>excluding negotiated commitment-based discounts or any other<br>discounts. | double                 | Yes                |
| EffectiveCost              | A cost that includes all reduced rates and discounts, augmented<br>with the amortization of relevant purchases (one-time or recurring)<br>paid to cover future eligible charges.                        | double                 | No                 |
| InvoiceIssuerName          | An entity responsible for invoicing the sources or services<br>consumed. It is commonly used for cost analysis and reporting<br>scenarios.                                                              | string                 | No                 |
| ListCost                   | The cost calculated by multiplying ListUnitPrice and the<br>corresponding PricingQuantity.                                                                                                              | double                 | No                 |
| ListUnitPrice              | The suggested unit price, published by the provider, for a single<br>PricingUnit of the associated SKU, excluding any discounts.                                                                        | double                 | Yes                |
| PricingCategory            | The pricing model used for a charge at the time of use or<br>purchase.                                                                                                                                  | string                 | Yes                |
| PricingQuantity            | The volume of a given SKU associated with a resource or service<br>used or purchased, based on the PricingUnit.                                                                                         | double                 | Yes                |
| PricingUnit                | A provider-assigned measurement unit for determining unit prices,<br>indicating how the provider rates measured usage and purchase<br>quantities after applying pricing rules such as block<br>pricing. | string                 | Yes                |
| ProviderName               | The entity that made the resources or services available for<br>purchase.                                                                                                                               | string                 | No                 |
| PublisherName              | The entity that produced the resources or services that were<br>purchased.                                                                                                                              | string                 | No                 |
| RegionId                   | A provider-assigned identifier for an isolated geographic area<br>where a *resource<br>• is provisioned<br>or a *service<br>• is provided.                                                              | string                 | Yes                |
| RegionName                 | The name of an isolated geographic area where a *resource<br>• is provisioned or a *service<br>• is provided.                                                                                           | string                 | Yes                |
| ResourceId                 | A provider-assigned identifier for a resource.                                                                                                                                                          | string                 | Yes                |
| ResourceName               | A display name assigned to a resource.                                                                                                                                                                  | string                 | Yes                |
| ResourceType               | The type of resource the charge applies to.                                                                                                                                                             | string                 | Yes                |
| ServiceCategory            | The highest-level classification of a service based on the core<br>function of the service.                                                                                                             | string                 | No                 |
| ServiceName                | A display name for the offering that was purchased.                                                                                                                                                     | string                 | No                 |
| SkuId                      | A unique identifier that defines a provider-supported construct<br>for organizing properties that are common across one or more SKU<br>prices.                                                          | string                 | Yes                |
| SkuPriceId                 | A unique identifier that defines the unit price used to calculate<br>the charge.                                                                                                                        | string                 | Yes                |
| SubAccountId               | An ID assigned to a grouping of resources or services, often used<br>to manage access and/or cost.                                                                                                      | string                 | Yes                |
| SubAccountName             | A name assigned to a grouping of resources or services, often<br>used to manage access and/or cost.                                                                                                     | string                 | Yes                |
| Tags                       | The set of tags assigned to tag sources that also account for<br>potential provider-defined or user-defined tag evaluations.                                                                            | map <string, string>   | Yes                |
| x_CostCategories           | A map column containing key-value pairs of the cost categories<br>and their values for a given line item.                                                                                               | map <string, string>   | Yes                |
| x_Discounts                | A map column containing key-value pairs of any specific discounts<br>that apply to this line item.                                                                                                      | map <string, double>   | Yes                |
| x_Operation                | The specific AWS operation covered by this line item. This<br>describes the specific usage of the line item.                                                                                            | string                 | Yes                |
| x_ServiceCode              | The code of the service used in this line item.                                                                                                                                                         | string                 | Yes                |
| x_UsageType                | The usage details of the line item.                                                                                                                                                                     | string                 | Yes                |
