# Identity columns

Identity columns contain data to identify a line item.

| Column name            | Description                                                                                                                                                                                                                                                                                                                                                                                | Data type |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------- |
| identity_line_item_id  | This field is generated for each line item and is unique in a<br>given partition. This does not guarantee that the field will be<br>unique across an entire delivery (that is, all partitions in an<br>update) of the AWS CUR. The line item ID isn't consistent<br>between different Cost and Usage Reports and can't be used to<br>identify the same line item across different reports. | string    |
| identity_time_interval | The time interval that this line item applies to, in the following format:<br>`YYYY-MM-DDTHH:mm:ssZ/YYYY-MM-DDTHH:mm:ssZ`. The<br>time interval is in UTC and can either be daily or hourly,<br>depending on the report granularity.                                                                                                                                                       | string    |
