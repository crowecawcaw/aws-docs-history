

# Split line item columns

Columns under the **split\_line\_item** header are fields that appear in Data Exports if you've opted in to the split cost allocation data feature. For more information, see [Understanding split cost allocation data](https://docs.aws.amazon.com/cur/latest/userguide/split-cost-allocation-data.html). Split cost allocation data supports Amazon ECS (including Fargate), AWS Batch, Amazon EKS, AWS PCS, Amazon S3, and networking flexible cost allocation. For networking, it allocates supported NAT gateway, Amazon EC2 instance, and VPC peering connection charges.



| Column name | Description | Data type | 
| --- | --- | --- | 
| split\_line\_item\_actual\_usage | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The usage for vCPU, memory, or accelerator resources (based on lineItem/UsageType) you incurred for the specified time period for the Amazon ECS task or Kubernetes pod. This column is empty for AWS PCS Slurm jobs, because AWS PCS costs are based on requested resources only. For networking, the data attributed to the resource that generated it for the line item's time period. The value uses the usage type's unit, such as GB. On the unattributed line item, this is the usage that couldn't be traced to a resource. | double | 
| split\_line\_item\_net\_split\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The effective cost for Amazon ECS tasks, Kubernetes pods, or AWS PCS Slurm jobs after all discounts have been applied. This column is included in your report only when your account has a discount in the applicable billing period. For networking, the share of the networking resource's charge after discounts that is assigned to the resource that generated usage, or to unattributed usage. For Amazon S3, this is the cost allocated to the prefix after discounts. | double | 
| split\_line\_item\_net\_unused\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The effective unused cost for Amazon ECS tasks, Kubernetes pods, or AWS PCS Slurm jobs after all discounts have been applied. This column is included in your report only when your account has a discount in the applicable billing period. | double | 
| split\_line\_item\_parent\_resource\_id | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The resource ID of the parent resource whose cost is split. For Amazon ECS tasks and Amazon EKS pods with the EC2 launch type, and for all AWS PCS Slurm jobs, this is the EC2 instance that the task, pod, or job ran on. For networking, the resource whose charge is split: the NAT gateway ARN for a NAT gateway's data processing and data transfer charges, or the Amazon EC2 instance ID for an instance's data transfer charges. For Amazon S3, this is the name of the bucket whose charge is allocated. | string | 
| split\_line\_item\_public\_on\_demand\_split\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The cost for vCPU or memory (based on lineItem/UsageType) allocated for the time period to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job based on public On-Demand Instance rates (referenced in the pricing/publicOnDemandRate column).<br />For networking, the share of the networking resource's charge at public On-Demand rates that is assigned to the resource that generated usage, or to unattributed usage. | double | 
| split\_line\_item\_public\_on\_demand\_unused\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The unused cost for vCPU or memory (based on lineItem/UsageType) allocated for the time period to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job based on public On-Demand Instance rates. Unused costs are costs associated with resources (CPU or memory) on the EC2 instance (referenced in the splitLineItem/ParentResourceIdcolumn) that were not utilized for the specified time period. | double | 
| split\_line\_item\_reserved\_usage | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The usage for vCPU, memory, or accelerator resources (based on lineItem/UsageType) that you configured for the specified time period for the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job. | double | 
| split\_line\_item\_split\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The cost for vCPU or memory (based on lineItem/UsageType) allocated for the time period to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job. This includes amortized costs if the EC2 instance (referenced in the splitLineItem/parentResourceId column) has upfront or partial upfront charges for reservations or Savings Plans. For networking, the share of the networking resource's unblended charge assigned to the resource that generated usage, or to unattributed usage. For Amazon S3, this is the unblended cost allocated to the prefix. | double | 
| split\_line\_item\_split\_usage | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The usage for vCPU or memory (based on lineItem/UsageType) allocated for the specified time period to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job. This is defined as the maximum usage of splitLineItem/ReservedUsage or splitLineItem/ActualUsage. For networking, the data attributed to the resource that generated it for the line item's time period. The value uses the usage type's unit, such as GB. Networking has no reserved usage, so the usage charged is the usage that occurred. For Amazon S3, this is the storage in GB-Mo or the number of requests allocated to the prefix. | double | 
| split\_line\_item\_split\_usage\_ratio | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The ratio of vCPU, memory, or accelerator resources (based on lineItem/UsageType) allocated to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job compared to the overall CPU, memory, or accelerator resources available on the EC2 instance (referenced in the splitLineItem/ParentResourceId column). | double | 
| split\_line\_item\_unused\_cost | **Table configuration:** Added by: INCLUDE SPLIT COST ALLOCATION DATA<br />The unused cost for vCPU, memory, or accelerator resources (based on lineItem/UsageType) allocated for the time period to the Amazon ECS task, Kubernetes pod, or AWS PCS Slurm job. Unused costs are costs associated with resources (CPU, memory, or accelerator resources) on the EC2 instance (referenced in the splitLineItem/ParentResourceId column) that were not utilized for the specified time period. This includes amortized costs if the EC2 instance (splitLineItem/parentResourceId) has upfront or partial upfront charges for reservations or Savings Plans. For Amazon S3 line items, this column is empty. Usage that matches no prefix is reported on the unattributed line item. | double |
