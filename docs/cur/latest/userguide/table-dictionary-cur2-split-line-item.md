# Split line item

columns

Columns under the **split_line_item** header are
fields that appear in Data Exports if you've opted in to the split cost allocation
data feature. For more information, see [Understanding split cost allocation data](split-cost-allocation-data.md "split-cost-allocation-data.md"). The feature is limited to
Amazon ECS (including Fargate), AWS Batch, and Amazon EKS only.
