# Amazon VPC network ACLs

Another option for securing access to the file system within your VPC is to
establish network access control lists (network ACLs). Network ACLs are separate
from security groups, but have similar functionality to add an additional layer of
security to the resources in your VPC. For more information on implementing access control using network ACLs, see
[Control traffic to subnets using Network ACLs](../../../vpc/latest/userguide/vpc-network-acls.md "../../../vpc/latest/userguide/vpc-network-acls.md") in
the _Amazon VPC User Guide_.
