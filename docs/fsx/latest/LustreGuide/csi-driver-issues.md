# Troubleshooting FSx for Lustre CSI driver issues

Amazon FSx for Lustre supports access from containers running on Amazon EKS using the open-source
FSx for Lustre CSI driver. For deployment information, see
[Use Amazon FSx for Lustre Storage](../../../eks/latest/userguide/fsx-csi.md "../../../eks/latest/userguide/fsx-csi.md")
in the **Amazon EKS User Guide**.

If you’re experiencing issues with the FSx for Lustre CSI driver for containers
running on Amazon EKS, see
[Troubleshooting CSI Driver (Common Issues)](https://github.com/kubernetes-sigs/aws-fsx-csi-driver/blob/master/docs/troubleshooting.md "https://github.com/kubernetes-sigs/aws-fsx-csi-driver/blob/master/docs/troubleshooting.md") which is available on GitHub.
