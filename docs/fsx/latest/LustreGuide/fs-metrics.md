## FSx for Lustre object storage server metrics

The `AWS/FSx` namespace includes the following object storage server (OSS) metrics.
All of these metrics take two dimensions, `FileSystemId` and `FileServer`.

- `FileSystemId` – Your file system's AWS resource ID.
- `FileServer` – The name of the object storage server (OSS) in your
  Lustre file system. Each OSS is provisioned with one or more object storage targets (OSTs).
  OSS use the naming convention of OSS<HostIndex>, where `HostIndex` represents
  a 4-digit hexadecimal value (for example, `OSS0001`). An OSS's ID is the ID of the first OST
  attached to it. For example, the first OSS attached to `OST0000` and `OST0001`, will
  use `OSS0000`, and the second OSS attached to `OST0002`, `OST0003` will
  use `OSS0002`.

| Metric                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NetworkThroughputUtilization`        | Network throughput utilization as a percentage of available network<br>throughput for your file system. This metric is equivalent to the sum of<br>`NetworkSentBytes` and `NetworkReceivedBytes` as a percentage<br>of the network throughput capacity of one OSS for your file system. There is one<br>metric emitted each minute for each of your file system's OSSs.<br>The `Average` statistic is the average network throughput utilization<br>for the given OSS over the specified period.<br>The `Minimum` statistic is the lowest network throughput utilization<br>for the given OSS over one minute, for the specified period.<br>The `Maximum` statistic is the highest network throughput utilization<br>for the given OSS over one minute, for the specified period.<br>Unit: Percent<br>Valid statistics: `Average`, `Minimum`,<br>`Maximum`                                                                                                                                      |
| `NetworkSentBytes`                    | The number of bytes sent by the file system. All traffic is considered in this<br>metric, including data movement to and from linked data repositories. There is one metric<br>emitted each minute for each of your file system's OSSs.<br>The `Sum` statistic is the total number of bytes sent over the network<br>by the given OSS over the specified period.<br>The `Average` statistic is the average number of bytes sent over the<br>network by the given OSS over the specified period.<br>The `Minimum` statistic is the lowest number of bytes sent over the network<br>by the given OSS over the specified period.<br>The `Maximum` statistic is the highest number of bytes sent over the<br>network by the given OSS over the specified period.<br>To calculate sent throughput (bytes per second) for any statistic, divide the statistic<br>by the seconds in the specified period.<br>Unit: Bytes<br>Valid statistics: `Sum`, `Average`, `Minimum`,<br>`Maximum`                |
| `NetworkReceivedBytes`                | The number of bytes received by the file system. All traffic is considered in<br>this metric, including data movement to and from linked data repositories. There is one<br>metric emitted each minute for each of your file system's OSSs.<br>The `Sum` statistic is the total number of bytes received over the network<br>by the given OSS over the specified period.<br>The `Average` statistic is the average number of bytes received over the<br>network by the given OSS over the specified period.<br>The `Minimum` statistic is the lowest number of bytes received over the network by<br>the given OSS over the specified period.<br>The `Maximum` statistic is the highest number of bytes received over the<br>network by the given OSS over the specified period.<br>To calculate throughput (bytes per second) for any statistic, divide the statistic<br>by the seconds in the specified period.<br>Unit: Bytes<br>Valid statistics: `Sum`, `Average`, `Minimum`,<br>`Maximum` |
| `FileServerDiskThroughputUtilization` | The disk throughput between your OSS and associated OSTs, as a percentage of the<br>provisioned limit determined by throughput capacity. This metric is equivalent to the<br>sum of `DiskReadBytes` and `DiskWriteBytes` as a percentage of the<br>OSS's disk throughput capacity for your file system. There is one metric emitted<br>each minute for each of your file system's OSSs.<br>The `Average` statistic is the average OSS disk throughput utilization for<br>the given OSS over the specified period.<br>The `Minimum`statistic is the lowest OSS disk throughput utilization for<br>the given OSS over the specified period.<br>The `Maximum` statistic is the highest OSS disk throughput utilization<br>for the given OSS over the specified period.<br>Unit: Percent<br>Valid statistics: `Average`, `Minimum`,<br>`Maximum`                                                                                                                                                    |

## FSx for Lustre object storage target metrics

The `AWS/FSx` namespace includes the following object storage target
(OST) metrics. All of these metrics take two dimensions, `FileSystemId` and
`StorageTargetId`.

###### Note

`DiskReadOperations` and `DiskWriteOperations` metrics are
not available on Scratch file systems, and `DiskIopsUtilization` metrics are not
available on Scratch and Persistent HDD file systems.

| `DiskReadBytes`       | The number of bytes (disk IO) from any disk reads from this OST.<br>There is one metric emitted each minute for each of your file system's OSTs.<br>The `Sum` statistic is the total number of bytes read in a minute<br>from the given OST over the specified period.<br>The `Average` statistic is the average number of bytes read<br>each minute from the given OST over the specified period.<br>The `Minimum` statistic is the lowest number of bytes<br>read each minute from the given OST over the specified period.<br>The `Maximum` statistic is the highest number of bytes read<br>each minute from the given OST over the specified period.<br>To calculate read disk throughput (bytes per second) for any statistic, divide<br>the statistic by the seconds in the period.<br>Unit: Bytes<br>Valid statistics: `Sum`, `Average`, `Minimum`,<br>and, `Maximum`                          |
| `DiskWriteBytes`      | The number of bytes (disk IO) from any disk writes from this OST.<br>There is one metric emitted each minute for each of your file system's OSTs.<br>The `Sum` statistic is the total number of bytes written each minute<br>from the given OST over the specified period.<br>The `Average` statistic is the average number of bytes written<br>each minute from the given OST over the specified period.<br>The `Minimum` statistic is the lowest number of bytes written each<br>minute from the given OST over the specified period.<br>The `Maximum` statistic is the highest number of bytes written each<br>minute from the given OST over the specified period.<br>To calculate read disk throughput (bytes per second) for any statistic,<br>divide the statistic by the seconds in the period<br>Unit: Bytes<br>Valid statistics: `Sum`, `Average`, `Minimum`,<br>and, `Maximum`              |
| `DiskReadOperations`  | The number of read operations (disk IO) to this OST.<br>There is one metric emitted each minute for each of your file system's OSTs.<br>The `Sum` statistic is the total number of read operations<br>performed by the given OST over the specified period.<br>The `Average` statistic is the average number of read operations<br>performed each minute by the given OST over the specified period.<br>The `Minimum` statistic is the lowest number of read operations<br>performed each minute by the given OST over the specified period.<br>The `Maximum` statistic is the highest number of read operations<br>performed each minute by the given OST over the specified period.<br>To calculate average disk IOPS over the period, use the `Average`<br>statistic and divide the result by 60 (seconds).<br>Units: Count<br>Valid statistics: `Sum`, `Average`, `Minimum`,<br>and `Maximum`      |

## FSx for Lustre metadata metrics

The `AWS/FSx` namespace includes the following metadata metrics. The `CPUUtilization`
metric takes the `FileSystemId` and `FileServer` dimensions, while the other metrics
take the `FileSystemId` and `StorageTargetId` dimensions.

- `FileSystemId` – Your file system's AWS resource ID.
- `StorageTargetId` – The name of the metadata target (MDT).
  MDTs use the naming convention of MDT<MDTIndex> (for example, `MDT0001`).
- `FileServer` – The name of the metadata server (MDS) in your Lustre file
  system. Each MDS is provisioned with one metadata target (MDT). MDS use the naming convention of
  MDS<HostIndex>, where `HostIndex` represents a 4-digit hexadecimal value derived
  using the MDT index on the server. For example, the first MDS provisioned with `MDT0000`
  will use `MDS0000`, and the second MDS provisioned with `MDT0001` will use
  `MDS0001`. Your file system contains multiple metadata servers if your file system has
  a metadata configuration specified.

| Metric                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CPUUtilization`       | The percent utilization of your file system's MDS CPU resources.<br>There is one metric emitted each minute for each of your file system's MDSs.<br>The `Average` statistic is the average CPU utilization of the<br>MDS over a specified period.<br>The `Minimum` statistic is the lowest CPU utilization for the<br>given MDS over the specified period.<br>The `Maximum` statistic is the highest CPU utilization for the<br>given MDS over the specified period.<br>Unit: Percent<br>Valid statistics: `Average`, `Minimum` and<br>`Maximum` |
| `FileCreateOperations` | Total number of file create operations.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `FileOpenOperations`   | Total number of file open operations.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `FileDeleteOperations` | Total number of file delete operations.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `StatOperations`       | Total number of stat operations.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `RenameOperations`     | Total number of directory renames, whether in-place directory<br>renames or cross directory renames.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                                              |

## FSx for Lustre dimensions

Amazon FSx for Lustre metrics use the `AWS/FSx` namespace and use the following dimensions.

- The `FileSystemId` dimension denotes a file system's ID and
  filters the metrics that you request to that individual file system. You can find
  the ID on the Amazon FSx console on the **Summary** panel of the file
  system details page, in the **File system ID** field. The file
  system ID takes the form of `fs-01234567890123456`. You
  can also see the ID in the response of a
  [`describe-file-systems`](../../../cli/latest/reference/fsx/describe-file-systems.md "../../../cli/latest/reference/fsx/describe-file-systems.md") CLI command (the equivalent API action
  is [`DescribeFileSystems`](../APIReference/API_DescribeFileSystems.md "../APIReference/API_DescribeFileSystems.md")).
- The `StorageTargetId` dimension denotes which OST (object storage
  target) or MDT (metadata target) published the metadata metrics. A `StorageTargetId`
  takes the form of `OSTxxxx` (for example, `OST0001`) or
  `MDTxxxx` (for example, `MDT0001`).
- The `FileServer` dimension denotes the following
  - For OSS metrics: the name of the object storage server (OSS). OSS use
    the `OSSxxxx` naming convention (for example, `OSS0002`).
  - For the CPUUtilization metric: the name of a metadata server (MDS). MDS use
    the `MDSxxxx` naming convention (for example, `MDS0002`).

- The `Publisher` dimension is available in CloudWatch and AWS CLI
  for the `AutoImport` and `AutoImport` metrics to denote which
  service published the metrics.

For more information about dimensions, see [Dimensions](../../../AmazonCloudWatch/latest/monitoring/cloudwatch_concepts.md#Dimension "../../../AmazonCloudWatch/latest/monitoring/cloudwatch_concepts.md#Dimension")
in the _Amazon CloudWatch User Guide_.
