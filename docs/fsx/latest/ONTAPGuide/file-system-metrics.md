# File system metrics

Your Amazon FSx for NetApp ONTAP file system metrics are classified as either **File system
metrics** or **Detailed file system metrics**.

- **File system metrics** are aggregate performance and storage metrics for a
  single file system that take a single dimension, `FileSystemId`. These
  metrics measure network performance and storage capacity usage for your file system.
- **Detailed file system metrics** measure your file system's
  storage capacity and used storage in each storage tier (for example, SSD storage and
  capacity pool storage). Each metric includes a `FileSystemId`, `StorageTier`,
  and `DataType` dimension.
  Note the following about when Amazon FSx publishes data points for these metrics to CloudWatch:

- For the utilization metrics (any metric whose name ends in _Utilization_,
  such as `NetworkThroughputUtilization`), there is a data point emitted each period for every
  active file server or aggregate. For example, Amazon FSx emits one minutely metric per active file server
  for `FileServerDiskIopsUtilization`, and one minutely metric per aggregate for `DiskIopsUtilization`.
- For all other metrics, there is a single data point emitted each period, corresponding
  to the total value of the metric across all of your active file servers (such as `DataReadBytes`
  for file server metrics) or all of your aggregates (such as `DiskReadBytes` for storage metrics).

## Storage capacity metrics

All of these metrics take one dimension, `FileSystemId`.

| Metric                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StorageEfficiencySavings` | The bytes saved from storage efficiency features (compression,<br>deduplication, and compaction).<br>The `Average` statistic is the average storage efficiency savings<br>over a specified period. To calculate storage efficiency savings as a percentage<br>of all data stored, over a one minute period, divide<br>`StorageEfficiencySavings` by the sum of<br>`StorageEfficiencySavings` and the `StorageUsed` file<br>system metric, using the `Sum` statistic for<br>`StorageUsed`.<br>The `Minimum` statistic is the minimum storage efficiency savings<br>over a specified period.<br>The `Maximum` statistic is the maximum storage efficiency savings<br>over a specified period.<br>Units: Bytes<br>Valid statistics: `Average`, `Minimum`, and<br>`Maximum`                                                                                                                                                                |
| `StorageUsed`              | The total amount of physical data stored on the file system, on both the<br>primary (SSD) tier and the capacity pool tier. This metric includes savings from<br>storage-efficiency features, such as data compression and deduplication.<br>Units: Bytes<br>Valid statistics: `Average`, `Minimum`, and<br>`Maximum`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `LogicalDataStored`        | The total amount of logical data stored on the file system, considering both the SSD tier and<br>the capacity pool tier. This metric includes the total logical size of snapshots and FlexClones,<br>but does not include storage efficiency savings achieved through compression, compaction, and deduplication.<br>To compute storage-efficiency savings in bytes, take the<br>`Average` of `StorageUsed` over a given period and<br>subtract it from the `Average` of `LogicalDataStored` over<br>the same period.<br>To compute storage-efficiency savings as a percentage of total logical data<br>size, take the `Average` of `StorageUsed` over a given<br>period and subtract it from the `Average` of<br>`LogicalDataStored` over the same period. Then divide the<br>difference by the `Average` of `LogicalDataStored` over<br>the same period.<br>Units: Bytes<br>Valid statistics: `Average`, `Minimum`, and<br>`Maximum` |

## Detailed file system metrics

Detailed file system metrics are detailed storage-utilization metrics for each of your
storage tiers. Detailed file system metrics all have the dimensions
`FileSystemId`, `StorageTier`, and `DataType`.

- The `StorageTier` dimension indicates the storage tier that the metric measures,
  with possible values of `SSD` and `StandardCapacityPool`.
- The `DataType` dimension indicates the type of data that the metric measures, with
  the possible value `All`.

There is a row for each unique combination of a given metric and dimensional key-value
pairs, with a description of what that combination measures.

| Metric                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StorageCapacityUtilization` | The storage capacity utilization for each of your file system's<br>aggregates. There is one metric emitted each minute for each of your<br>file system's aggregates.<br>The `Average` statistic is the average amount of storage<br>capacity utilization for your file system's performance tier over the<br>specified period.<br>The `Minimum` statistic is the lowest amount of storage<br>capacity utilization for your file system's performance tier over the<br>specified period.<br>The `Maximum` statistic is the highest amount of storage<br>capacity utilization for your file system's performance tier over the<br>specified period.<br>Units: Percent<br>Valid statistics: `Average`, `Minimum`,<br>and `Maximum`                                                                                                                                                                                                                                                                                                                                                                                  |
| `StorageCapacity`            | The total storage capacity of the primary (SSD) tier.<br>Units: Bytes<br>Valid statistics: `Maximum`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `StorageUsed`                | The used physical storage capacity in bytes, specific to the storage tier.<br>This value includes savings from storage-efficiency features, such as data<br>compression and deduplication. Valid dimension values for<br>`StorageTier` are `SSD` and<br>`StandardCapacityPool`, corresponding to the storage tier that this<br>metric measures. This metric also requires the `DataType` dimension<br>with the value `All`.<br>The `Average`, `Minimum`, and `Maximum`<br>statistics are per-tier storage consumption in bytes for the given period.<br>To calculate storage capacity utilization of your primary (SSD) storage<br>tier, divide any of these statistics by the `Maximum`<br>`StorageCapacity` over the same period, with the<br>`StorageTier` dimension equal to `SSD`.<br>To calculate the free storage capacity of your primary (SSD) storage tier in<br>bytes, subtract any of these statistics from the `Maximum`<br>`StorageCapacity` over the same period, with the dimension<br>`StorageTier` equal to `SSD`.<br>Units: Bytes<br>Valid statistics: `Average`, `Minimum`, and<br>`Maximum` |
