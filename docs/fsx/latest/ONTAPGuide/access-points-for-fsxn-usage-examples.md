# Using access points

The following examples demonstrate how to use access points to access file data stored on an FSx for ONTAP volume
using the S3 API. For a full list of the Amazon S3 API operations supported by access points attached to an FSx for ONTAP volume,
see [Access point compatibility](access-points-for-fsxn-object-api-support.md "access-points-for-fsxn-object-api-support.md").

###### Note

Files on FSx for ONTAP volumes are identified with a `StorageClass` of `FSX_ONTAP`.
