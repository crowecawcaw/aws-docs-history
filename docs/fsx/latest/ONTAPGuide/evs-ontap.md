# Using Amazon Elastic VMware Service with FSx for ONTAP

You can use FSx for ONTAP as an external datastore for Amazon Elastic VMware Service (Amazon EVS) Software-Defined Data Centers (SDDCs). For more information, see
[Run high-performance workloads with Amazon FSx for NetApp ONTAP](../../../evs/latest/userguide/fsx-ontap.md "../../../evs/latest/userguide/fsx-ontap.md").
For detailed instructions, see [Configure Amazon FSx for NetApp ONTAP as an NFS datastore](../../../evs/latest/userguide/config-fsx-nfs-datastore.md "../../../evs/latest/userguide/config-fsx-nfs-datastore.md")
and [Configure Amazon FSx for NetApp ONTAP as an iSCSI datastore](../../../evs/latest/userguide/config-fsx-iscsi-datastore.md "../../../evs/latest/userguide/config-fsx-iscsi-datastore.md").
