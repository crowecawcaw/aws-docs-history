# Creating a shadow copy

To manually create a shadow copy, enter the following command in a remote PowerShell session
on your file system. For instructions on launching a remote PowerShell session on your file
system, see [Using the Amazon FSx CLI for PowerShell](administering-file-systems.md#remote-pwrshell "administering-file-systems.md#remote-pwrshell").

```
`[fs-0123456789abcdef1]PS>``New-FsxShadowCopy`

Shadow Copy {ABCDEF12-3456-7890-ABCD-EF1234567890} taken successfully
```
