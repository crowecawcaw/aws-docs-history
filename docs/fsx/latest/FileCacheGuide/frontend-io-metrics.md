# Front-end I/O metrics

The following metrics report cache-level information on system read and write
operations. All these metrics take one dimension (`FileCacheId`) and are
published into the `AWS/FSx` namespace in CloudWatch.

| Metric                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DataReadBytes`       | The number of bytes for cache read operations.<br>The `Sum` statistic is the total number of bytes associated with<br>read operations during the period. The `Minimum` statistic is the<br>minimum number of bytes associated with read operations on a single disk. The<br>`Maximum` statistic is the maximum number of bytes associated with<br>read operations on the disk. The `Average` statistic is the average<br>number of bytes associated with read operations per disk. The<br>`SampleCount` statistic is the number of disks.<br>To calculate the average throughput (bytes per second) for a period, divide<br>the `Sum` statistic by the number of seconds in the period.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`,<br>and `Average`.<br>• Count for `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`. |
| `DataWriteBytes`      | The number of bytes for cache write operations.<br>The `Sum` statistic is the total number of bytes associated with<br>write operations. The `Minimum` statistic is the minimum number of<br>bytes associated with write operations on a single disk. The `Maximum`<br>statistic is the maximum number of bytes associated with write operations on the<br>disk. The `Average` statistic is the average number of bytes associated<br>with write operations per disk. The `SampleCount` statistic is the<br>number of disks.<br>To calculate the average throughput (bytes per second) for a period, divide<br>the `Sum` statistic by the number of seconds in the period.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`,<br>and `Average`.<br>• Count for `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`.              |
| `DataReadOperations`  | The number of read operations.<br>The `Sum` statistic is the total number of read operations. The<br>`Minimum` statistic is the minimum number of read operations on a<br>single disk. The `Maximum` statistic is the maximum number of read<br>operations on the disk. The `Average` statistic is the average number<br>of read operations per disk. The `SampleCount` statistic is the number<br>of disks.<br>To calculate the average number of read operations (operations per second) for<br>a period, divide the `Sum` statistic by the number of seconds in the<br>period.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`,<br>and `Average`.<br>\*<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`.                                                                                                                               |
| `DataWriteOperations` | The number of write operations.<br>The `Sum` statistic is the total number of write operations. The<br>`Minimum` statistic is the minimum number of write operations on a<br>single disk. The `Maximum` statistic is the maximum number write<br>operations on the disk. The `Average` statistic is the average number<br>of write operations per disk. The `SampleCount` statistic is the number<br>of disks.<br>To calculate the average number of write operations (operations per second)<br>for a period, divide the `Sum` statistic by the number of seconds in<br>the period.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`,<br>and `Average`.<br>• Count for `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`.                                                                                                    |
| `MetadataOperations`  | The number of metadata operations.<br>The `Sum` statistic is the count of metadata operations. The<br>`Minimum` statistic is the minimum number of metadata operations per<br>disk. The `Maximum` statistic is the maximum number of metadata<br>operations per disk. The `Average` statistic is the average number of<br>metadata operations per disk. The `SampleCount` statistic is the number<br>of disks.<br>To calculate the average number of metadata operations (operations per second)<br>for a period, divide the `Sum` statistic by the number of seconds in<br>the period.<br>Units:<br>• Count for `Sum`, `Minimum`, `Maximum`,<br>`Average`, and `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`.                                                                                                                |
