# Getting started with Amazon File Cache

Learn how to start using Amazon File Cache. These steps walk you through creating an
Amazon File Cache resource and accessing it from your compute instances. Amazon File Cache can
link to an Amazon Simple Storage Service (Amazon S3) or Network File System (NFS) data repository (but not to both types
at the same time). This exercise uses an Amazon S3 bucket as the data repository, and shows how to use
your cache to process the data in your Amazon S3 bucket with your file-based applications.

This getting started exercise includes the following steps.
