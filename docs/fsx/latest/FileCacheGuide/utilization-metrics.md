# Cache utilization metrics

The following metrics report cache-level storage information. These metrics take
one dimension (`FileCacheId`) and are published into the `AWS/FSx`
namespace in CloudWatch.

| Metric                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FreeDataStorageCapacity`     | The amount of available data storage capacity.<br>The `Sum` statistic is the total number of bytes available in the cache<br>The `Minimum` statistic is the total number bytes available in the fullest<br>disk. The `Maximum` statistic is the total number of bytes available in<br>the disk with the most remaining available storage. The `Average`<br>statistic is the average number of bytes available per disk. The<br>`SampleCount` statistic is the number of disks.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`.<br>• Count for `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`.                                                                      |
| `FreeMetadataStorageCapacity` | The amount of available metadata storage capacity.<br>The `Sum` statistic is the total number of bytes of metadata<br>storage available in the cache. The `Minimum` statistic is the<br>total number of bytes available in the fullest metadata target (MDT) disk.<br>The `Maximum` statistic is the total number of bytes available<br>in the MDT disk with the most remaining storage. The `Average`<br>statistic is the average number of bytes available per MDT disk. The<br>`SampleCount` statistic is the number of MDT disks.<br>Units:<br>• Bytes for `Sum`, `Minimum`, `Maximum`,<br>`Average`.<br>• Count for `SampleCount`.<br>Valid statistics: `Sum`, `Minimum`,<br>`Maximum`, `Average`, `SampleCount`. |
