# Quotas in AWS CodeCommit

The following table describes quotas in CodeCommit. For information about quotas that can be
changed, see [AWS CodeCommit Endpoints and Quotas](../../../general/latest/gr/codecommit.md "../../../general/latest/gr/codecommit.md").
For information about requesting a service quota increase, see [AWS Service Quotas](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md"). For
information about required versions of Git and other software, see [Compatibility for CodeCommit, Git, and other components](setting-up.md#setting-up-compat "setting-up.md#setting-up-compat").
