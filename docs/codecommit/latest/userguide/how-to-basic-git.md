# Basic Git commands

You can use Git to work with a local repo and the CodeCommit repository to which you've
connected the local repo.

The following are some basic examples of frequently used Git commands.

For more options, see your Git documentation.

## Configuration variables

|                                                                                                                                                                                                                                                                       |                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | -------- | ------------------------------------------------- |
| Lists all configuration variables.                                                                                                                                                                                                                                    | `git config --list`                             |
| Lists only local configuration variables.                                                                                                                                                                                                                             | `git config --local -l`                         |
| Lists only system configuration variables.                                                                                                                                                                                                                            | `git config --system -l`                        |
| Lists only global configuration variables.                                                                                                                                                                                                                            | `git config --global -l`                        |
| Sets a configuration variable in the specified configuration file.                                                                                                                                                                                                    | `git config [--local                            | --global | --system]<br>`variable-name`<br>`variable-value`` |
| Sets the default branch name to \*main<br>• for all<br>local repositories when an initial commit is made to a repository that does not yet<br>have a default branch                                                                                                   | **git config --global init.defaultBranch main** |
| Edits a configuration file directly. Can also be used to discover the location<br>of a specific configuration file. To exit edit mode, typically you type<br>`:q` (to exit without saving changes) or `:wq` (to save<br>changes and then exit), and then press Enter. | `git config [--local                            | --global | --system] --edit`                                 |

## Remote repositories

|                                                                                                                                                                                                                                                                                                                                                                                                                   |                                                    |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Initializes a local repo in preparation for connecting it to an<br>CodeCommit repository.                                                                                                                                                                                                                                                                                                                         | `git init`                                         |
| Can be used to set up a connection between a local repo and a remote<br>repository (such as a CodeCommit repository) using the specified nickname the<br>local repo has for the CodeCommit repository and the specified URL to the<br>CodeCommit repository.                                                                                                                                                      | `git remote add `remote-name`<br>`remote-url``     |
| Creates a local repo by making a copy of a CodeCommit repository at the specified<br>URL, in the specified subfolder of the current folder on the local machine. This<br>command also creates a remote tracking branch for each branch in the cloned<br>CodeCommit repository and creates and checks out an initial branch that is forked from<br>the current default branch in the cloned CodeCommit repository. | `git clone `remote-url`<br>`local-subfolder-name`` |
| Shows the nickname the local repo uses for the CodeCommit repository.                                                                                                                                                                                                                                                                                                                                             | `git remote`                                       |
| Shows the nickname and the URL the local repo uses for fetches and pushes<br>to the CodeCommit repository.                                                                                                                                                                                                                                                                                                        | `git remote -v`                                    |
| Pushes finalized commits from the local repo to the CodeCommit repository,<br>using the specified nickname the local repo has for the CodeCommit repository and<br>the specified branch. Also sets up upstream tracking information for the<br>local repo during the push.                                                                                                                                        | `git push -u `remote-name`<br>`branch-name``       |
| Pushes finalized commits from the local repo to the CodeCommit repository after<br>upstream tracking information is set.                                                                                                                                                                                                                                                                                          | `git push`                                         |
| Pulls finalized commits to the local repo from the CodeCommit repository,<br>using the specified nickname the local repo has for the CodeCommit repository and<br>the specified branch                                                                                                                                                                                                                            | `git pull `remote-name`<br>`branch-name``          |
| Pulls finalized commits to the local repo from the CodeCommit repository after<br>upstream tracking information is set.                                                                                                                                                                                                                                                                                           | `git pull`                                         |
| Disconnects the local repo from the CodeCommit repository, using the specified<br>nickname the local repo has for the CodeCommit repository.                                                                                                                                                                                                                                                                      | `git remote rm `remote-name``                      |

## Commits

|                                                                                                                                                                                                                                                                                            |                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ | -------------------- |
| Shows what has or hasn't been added to the pending commit in the local<br>repo.                                                                                                                                                                                                            | `git status`                                                 |
| Shows what has or hasn't been added to the pending commit in the<br>local repo in a concise format.<br>(`M` = modified, `A` = added,<br>`D` = deleted, and so on)                                                                                                                          | `git status -sb`                                             |
| Shows changes between the pending commit and the latest commit in the<br>local repo.                                                                                                                                                                                                       | `git diff HEAD`                                              |
| Adds specific files to the pending commit in the local repo.                                                                                                                                                                                                                               | `git add [`file-name-1 file-name-2 file-name-N`              | <br>`file-pattern`]` |
| Adds all new, modified, and deleted files to the pending commit in the local<br>repo.                                                                                                                                                                                                      | `git add`                                                    |
| Begins finalizing the pending commit in the local repo, which displays an<br>editor to provide a commit message. After the message is entered, the pending commit is<br>finalized.                                                                                                         | `git commit`                                                 |
| Finalizes the pending commit in the local repo, including specifying a<br>commit message at the same time.                                                                                                                                                                                 | `git commit -m "`Some meaningful commit<br>comment`"`        |
| Lists recent commits in the local repo.                                                                                                                                                                                                                                                    | `git log`                                                    |
| Lists recent commits in the local repo in a graph format.                                                                                                                                                                                                                                  | `git log --graph`                                            |
| Lists recent commits in the local repo in a predefined condensed<br>format.                                                                                                                                                                                                                | `git log --pretty=oneline`                                   |
| Lists recent commits in the local repo in a predefined condensed format,<br>with a graph.                                                                                                                                                                                                  | `git log --graph --pretty=oneline`                           |
| Lists recent commits in the local repo in a custom format, with a<br>graph.<br>(For more options, see [Understanding History: Commits](https://git-scm.com/docs/user-manual#understanding-commits "https://git-scm.com/docs/user-manual#understanding-commits") in the Git documentation.) | `git log --graph --pretty=format:"%H (%h) : %cn : %ar : %s"` |

## Branches

|                                                                                                                                                                                                                                                                                                  |                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Lists all branches in the local repo with an asterisk<br>(`*`) displayed next to your current branch.                                                                                                                                                                                            | `git branch`                                                                 |
| Pulls information about all existing branches in the CodeCommit repository to the<br>local repo.                                                                                                                                                                                                 | `git fetch`                                                                  |
| Lists all branches in the local repo and remote tracking branches in the<br>local repo.                                                                                                                                                                                                          | `git branch -a`                                                              |
| Lists only remote tracking branches in the local repo.                                                                                                                                                                                                                                           | `git branch -r`                                                              |
| Creates a new branch in the local repo using the specified branch<br>name.                                                                                                                                                                                                                       | `git branch `new-branch-name``                                               |
| Switches to another branch in the local repo using the specified branch<br>name.                                                                                                                                                                                                                 | `git checkout `other-branch-name``                                           |
| Creates a new branch in the local repo using the specified branch name,<br>and then switches to it.                                                                                                                                                                                              | `git checkout -b `new-branch-name``                                          |
| Pushes a new branch from the local repo to the CodeCommit repository using the<br>specified nickname the local repo has for the CodeCommit repository and the<br>specified branch name. Also sets up upstream tracking information for the branch in<br>the local repo during the push.          | `git push -u `remote-name`<br>`new-branch-name``                             |
| Creates a new branch in the local repo using the specified branch name.<br>Then connects the new branch in the local repo to an existing branch in the<br>CodeCommit repository, using the specified nickname the local repo has for the<br>CodeCommit repository and the specified branch name. | `git branch --track `new-branch-name`<br>`remote-name`/`remote-branch-name`` |
| Merges changes from another branch in the local repo to the current branch<br>in the local repo.                                                                                                                                                                                                 | `git merge `from-other-branch-name``                                         |
| Deletes a branch in the local repo unless it contains work that has not<br>been merged.                                                                                                                                                                                                          | `git branch -d `branch-name``                                                |
| Deletes a branch in the CodeCommit repository using the specified nickname the<br>local repo has for the CodeCommit repository and the specified branch name. (Note<br>the use of the colon (`:`).)                                                                                              | `git push `remote-name`<br>:`branch-name``                                   |

## Tags

|                                                                                                                                                                                               |                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Lists all tags in the local repo.                                                                                                                                                             | `git tag`                                           |
| Pulls all tags from the CodeCommit repository to the local repo.                                                                                                                              | `git fetch --tags`                                  |
| Shows information about a specific tag in the local repo.                                                                                                                                     | `git show `tag-name``                               |
| Creates a "lightweight" tag in the local repo.                                                                                                                                                | `git tag `tag-name`<br>`commit-id-to-point-tag-at`` |
| Pushes a specific tag from the local repo to the CodeCommit repository using<br>the specified nickname the local repo has for the CodeCommit repository and the<br>specified tag name.        | `git push `remote-name`<br>`tag-name``              |
| Pushes all tags from the local repo to the CodeCommit repository using the<br>specified nickname the local repo has for the CodeCommit repository.                                            | `git push `remote-name` --tags`                     |
| Deletes a tag in the local repo.                                                                                                                                                              | `git tag -d `tag-name``                             |
| Deletes a tag in the CodeCommit repository using the specified nickname the<br>local repo has for the CodeCommit repository and the specified tag name. (Note the<br>use of the colon (`:`).) | `git push `remote-name`<br>:`tag-name``             |
