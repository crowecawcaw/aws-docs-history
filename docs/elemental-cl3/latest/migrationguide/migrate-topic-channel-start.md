# Restarting channels

**To restart one channel**

1. To decide which channels to restart, use the list of running channels that you
   made when you stopped the channel. This list identifies the node that each
   channel is assigned to.
2. Choose the **Channels** page, then select the start button
   beside the channel to start.
   **To restart several or all channels**

3. On the web interface for the primary Conductor node, choose the
   **Channels** page.
4. Toward the top of the page, choose **Tasks**, then choose
   **Start Channels**.
5. Choose **Select all channels**.

Or select individual channels. If you are starting channels on a specific
node, use the list of running channels that you made when you stopped the
channel. This list identifies the node that each channel is assigned to. 4. Choose **Next**, then choose **Process
Now**.
