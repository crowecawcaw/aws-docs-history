# Creating a standard

MPTS

With Conductor Live there are two steps to creating an MPTS—you create the
MPTS, then you add SPTS channels to it. You perform all these steps in
Conductor Live. You don't perform these steps in Elemental Statmux.

For guidelines for creating an MPTS workflow, see [Designing an MPTS
workflow](container-design-mpts-workflow.md "container-design-mpts-workflow.md").
