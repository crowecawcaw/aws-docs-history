# Output tab

| Field                                  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| URI, Interface, Virtual Source Address | Required. The address to the destination on the<br>downstream system. Conductor Live will deliver the MPTS to<br>this address.                                                                                                                                                                                                                                                                                                                                                                                     |
| Output listening                       | Check this field if you want to enable output<br>listening, which is a form of resiliency that<br>protects against failures within the muxing<br>pipeline. You can only enable output listening if<br>you have set up Elemental Statmux for 1-to-1 node redundancy<br>because the feature requires two nodes.<br>For information about how this feature works<br>when the MPTS is running, see [Resiliency features<br>in Elemental Statmux](worker-nodes-other-resiliency.md "worker-nodes-other-resiliency.md"). |
| Add Destination                        | Choose this button if you are implementing<br>statmux output redundancy. With this redundancy<br>feature, you want the Elemental Statmux node to deliver the<br>MPTS to two different downstream systems. You must<br>specify the destination of the second downstream<br>system.<br>For information about how this feature works<br>when the MPTS is running, see [Resiliency features<br>in Elemental Statmux](worker-nodes-other-resiliency.md "worker-nodes-other-resiliency.md").                             |
