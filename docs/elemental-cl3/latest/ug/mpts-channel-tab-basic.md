# Basic tab

| Field                              | Description                                                                                                                                                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **#**                              | Read only, numerical ID for each program in<br>this MPTS. Unique within this MPTS.                                                                                                                                                                                                    |
| **ID**                             | Read only, numerical ID for each program. Must<br>be unique among all MPTSes in this Conductor Live<br>cluster.                                                                                                                                                                       |
| **Encoders**                       | Read only, the number of Elemental Live encoders that are<br>currently providing programs (channels) to this<br>MPTS.                                                                                                                                                                 |
| **Outgoing Program<br>Number**     | The PMT PID for this program. Must be unique<br>within this MPTS.<br>If you let Elemental Statmux assign this number for all the<br>programs, then all the numbers are guaranteed to<br>be unique. You can change this number, but you<br>must make sure that the numbers are unique. |
| **Service Name, Provider<br>Name** | Enter this information if the source program<br>doesn't include it. Or leave the field empty to use<br>the information from the source program.Or<br>leave the field empty if you don't want this<br>program to appear in the SDT for the<br>MPTS.                                    |
| **Quality Priority Offset**        | Complete this field in one or more programs to<br>assign relative priorities to the<br>programs.                                                                                                                                                                                      |
| **Min and Max Bitrate**            | Typically leave these fields empty. Elemental Statmux will<br>assign values for all the programs when you save<br>the MPTS.                                                                                                                                                           |
