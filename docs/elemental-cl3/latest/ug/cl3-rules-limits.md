# Conductor Live rules and limits

The following table provides a summary of the rules and constraints that apply to AWS Elemental Conductor Live
features.

| Feature or topic                                                                                      | Rule or limit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hardware in a cluster                                                                                 | A Conductor Live cluster can include a maximum of 50 worker<br>nodes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Physical location of nodes in a cluster                                                               | Within a cluster, the Conductor Live and encoder nodes must be located<br>in the same physical<br>location.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Within a cluster, the communications among cluster members<br>shouldn't traverse the public internet. |
| Software versions in a cluster                                                                        | We strongly recommend that all the software versions on the<br>nodes in one cluster have the same software version, down to the<br>patch level. So, for example, 2.21.3 on all Live nodes, and 3.21.3<br>on all Conductor Live nodes in the cluster.<br>You might perform upgrades in such a way that you have two<br>nodes with the same major version but different patch versions.<br>For example, 2.21.3 and 2.21.5. If you experience a problem with<br>interaction in those two nodes, AWS Elemental Support will probably<br>request that you set up all the nodes on the same patch<br>version. |
