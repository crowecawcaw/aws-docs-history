# Working with AWS Elemental Live in a cluster

Running AWS Elemental Live in a AWS Elemental Conductor Live cluster provides two key benefits that are not available
when you run Elemental Live in stand-alone mode:

- Centralized creation and control of channels on the nodes.
- Resiliency through configuration of _redundancy
  groups_ of nodes.
