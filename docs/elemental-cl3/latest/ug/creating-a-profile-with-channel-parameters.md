# Working with

channel parameters in a profile

You can create an AWS Elemental Live profile in which some fields have values that are variable rather
than absolute. Then when you create a channel using that profile, you assign real values to those
fields. In AWS Elemental Conductor Live, these variable fields are called _channel
parameters_.

Setting up a profile in this way makes the profile more flexible. You
can use it with multiple channels simply by entering different values in the
channel parameters.

Fields that can be set up with parameters have a blue background in the
web interface. For a list of these fields, go to the AWS Elemental User Community
and search for _supported channel
parameters_. You will definitely need this list if you create
profiles using the REST API.
