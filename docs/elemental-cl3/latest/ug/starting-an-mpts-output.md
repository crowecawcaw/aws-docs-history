# Starting or stopping an

MPTS

On the Conductor Live main menu, choose **MPTS**.

To start an MPTS, select the **Start** icon. Note
that starting an MPTS doesn't automatically start the programs
(channels) on the Elemental Live nodes.

To stop an MPTS, select the **Stop** icon at the
right side of the MPTS. Note that the sources in the MPTS (the
channels, passthrough programs, and passthrough streams) do not stop.
