# Monitoring the

load on worker nodes

You can view information about the overall load on any worker node in an AWS Elemental Conductor Live
cluster.

On the **Nodes** page, choose the hostname of the
node. (Don't choose the IP Address. Doing so will open the web
interface for that node in another tab.)

The **Node Details** page appears for that node,
showing these charts:

- Bandwidth
- CPU Utilization
- Disk
- GPU Frames/Second (if the node is running GPU-enabled
  software)
- GPU Temperature (if the node is running GPU-enabled
  software)
- Memory
- Realtime
- Total Frames/Second
