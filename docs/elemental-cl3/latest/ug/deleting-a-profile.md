# Deleting a profile

###### To delete a profile

1. Verify that the profile is not being used:
   - On the AWS Elemental Conductor Live main menu, choose **Profiles**. Look at the
     **Channels** column for this profile.
   - If it specifies a number, display the **Channels**
     page and filter the list (if necessary) to show only channels that use
     this profile.
   - Modify the channels to use a different profile.

2. Go back to the **Profiles** page and choose
   **Delete** next to the profile name. Then choose
   **OK**.
