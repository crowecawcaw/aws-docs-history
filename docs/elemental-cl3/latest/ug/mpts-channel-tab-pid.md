# PID Controls tab

On this tab, you can assign the output PIDs for the streams
that are in the source program. You can leave one, several or all
the fields empty, and Elemental Statmux will assign a unique ID.

If you do enter a PID, you must make sure that each PID is
unique in the entire MPTS. You should also assign PIDs only to
streams that you know are in the stream, otherwise you are
wasting a number.

If you leave the fields empty, Elemental Statmux assigns PIDs after you
save. It makes sure that each stream has a PID that is unique in
the entire MPTS.
