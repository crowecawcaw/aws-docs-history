# Setup: Designing the

cluster

You must design the cluster to suit the number of workflows you plan
to create. You could be creating the following types of
workflows:

- Encoding workflows. These workflows require only Elemental Live.
- MPTS workflows. These workflows require both Elemental Live and
  Elemental Statmux.
