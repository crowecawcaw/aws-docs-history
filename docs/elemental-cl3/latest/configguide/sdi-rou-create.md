

# Step C: Add the router
<a name="sdi-rou-create"></a>

Perform this procedure on the primary Conductor Live node.

1. On the web interface for the primary Conductor Live node, go to the **Settings** page and choose **Routers**. 

1. On the **Routers** page, choose **Add Router** and select the type of router protocol. These are the available options:
   + Videohub Ethernet Protocol (previously BlackMagic VideoHub)
   + XY Terminal Protocol (previously Harris Panacea)
   + NV9000 Protocol (previously Miranda nVision)
   + SW-P-08 Protocol (previously Snell Aurora)
   + PassThrough Protocol
   + LRC Protocol

1. Complete the **Add New Router ** fields as described in the table and choose **Add**. 



<table>
<thead>
  <tr><th>Field</th><th>Description</th></tr>
</thead>
<tbody>
  <tr><td><b>Name</b></td><td>The name that appears in the <b>Inputs</b> field on events and profiles.</td></tr>
  <tr><td><b>IP Address</b></td><td>The IP address of the router, excluding the protocol.</td></tr>
  <tr><td><b>Level</b></td><td>Applies to the XY Terminal, NV9000, SW-P-08, and PassThrough.</td></tr>
  <tr><td><b>User</b></td><td>Applies to the NV9000.</td></tr>
  <tr><td><b>Matrix ID</b></td><td>Applies to the SW-P-08.</td></tr>
</tbody>
</table>
