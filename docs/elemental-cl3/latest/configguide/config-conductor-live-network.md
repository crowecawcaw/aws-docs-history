# Configuring nodes for connectivity

This section describe how to configure the node so that it can communicate
with Conductor Live, and with upstream systems and downstream systems.

###### Note

If your deployment involves several Conductor Live clusters, we
strongly recommend that you set up each cluster in its own network.
