

# Document history for the agent workspace developer guide
<a name="doc-history"></a>

The following table describes the documentation releases for agent workspace.

| Change | Description | Date | 
| --- |--- |--- |
| [Integration of AWS-managed applications and additional APIs](#doc-history) | Connect Customer agent workspace introduces support for integrating AWS-managed applications with existing applications built using Streams. For details, see [Building third-party services](https://docs.aws.amazon.com/agentworkspace/latest/devguide/building-3P-services.html). | December 22, 2025 | 
| [Enhanced third-party capabilities and new AppController API](#doc-history) | Connect Customer agent workspace introduces support for third-party services and a new App Controller API. Third-party services are headless applications that run in the background of the agent workspace, enabling automated tasks and enhanced workflows. The App Controller API allows developers to manage third-party applications programmatically. For details, see [Building third-party services](https://docs.aws.amazon.com/agentworkspace/latest/devguide/building-3P-services.html) and [App Controller API](https://docs.aws.amazon.com/agentworkspace/latest/devguide/api-reference-3P-apps-app-controller.html). | July 25, 2025 | 
| [API version 1.0.5](#doc-history) | API version 1.0.5 released. For more information, see the [Connect Customer agent workspace API reference for third-party applications](https://docs.aws.amazon.com/agentworkspace/latest/devguide/api-reference-3P-apps-events-and-requests.html). | April 24, 2025 | 
| [Initial release](#doc-history) | Initial release of the agent workspace developer guide | October 27, 2023 |
