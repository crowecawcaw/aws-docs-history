

# Create your application for Connect Customer agent workspace
<a name="getting-started-create-application"></a>

An application is a website that can be loaded from an HTTPS URL into an iframe in the Connect Customer agent workspace. It can be built using any frontend framework and hosted anywhere as long as it can be loaded by the user’s browser and supports being embedded. The application must integrate the [Connect Customer SDK](https://github.com/amazon-connect/AmazonConnectSDK) on the GitHub website to send or receive events and data from the workspace. The SDK establishes secure communication between the application and the agent workspace.
