# TimestampRange

The range of timestamps for which to return fragments.

## Contents

**EndTimestamp**

The ending timestamp in the range of timestamps for which to return fragments.

Type: Timestamp

Required: Yes

**StartTimestamp**

The starting timestamp in the range of timestamps for which to return
fragments.

Type: Timestamp

Required: Yes
