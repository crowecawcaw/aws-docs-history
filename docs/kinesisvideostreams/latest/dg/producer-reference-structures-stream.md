# Kinesis video stream structures

You can use the following structures to provide data to an instance of a
Kinesis video stream.

###### Topics

- [StreamDefinition/StreamInfo](#producer-reference-structures-stream-streaminfo "#producer-reference-structures-stream-streaminfo")
- [ClientMetrics](#producer-reference-structures-stream-clientmetrics "#producer-reference-structures-stream-clientmetrics")
- [StreamMetrics](#producer-reference-structures-stream-streammetrics "#producer-reference-structures-stream-streammetrics")

## StreamDefinition/StreamInfo

The `StreamDefinition` object in the C++ layer wraps the
`StreamInfo` object in the platform-independent code, and provides
some default values in the constructor.

## ClientMetrics

The **ClientMetrics** object is filled by calling
`getKinesisVideoMetrics`.

### Member fields

| Field                         | Data type | Description                                                                                                                                                                                                                             |
| ----------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **version**                   | `UINT32`  | The version of the structure, defined in the<br>`CLIENT_METRICS_CURRENT_VERSION` macro.                                                                                                                                                 |
| **contentStoreSize**          | `UINT64`  | The overall content store size in bytes. This is the value<br>specified in<br>`DeviceInfo.StorageInfo.storageSize`.                                                                                                                     |
| **contentStoreAvailableSize** | `UINT64`  | Current available storage size in bytes.                                                                                                                                                                                                |
| **contentStoreAllocatedSize** | `UINT64`  | Current allocated size. The allocated plus the available sizes should be slightly<br>smaller than the overall storage size, due to the internal bookkeeping and the implementation of the<br>content store.                             |
| **totalContentViewsSize**     | `UINT64`  | The size of the memory allocated for all content views for all streams. This<br>isn't counted against the storage size. This memory is allocated using the `MEMALLOC`<br>macro, which can be overwritten to provide a custom allocator. |
| **totalFrameRate**            | `UINT64`  | The total observed frame rate across all the streams.                                                                                                                                                                                   |
| **totalTransferRate**         | `UINT64`  | The total observed stream rate in bytes per second across all<br>the streams.                                                                                                                                                           |

## StreamMetrics

The **StreamMetrics** object is filled by calling
`getKinesisVideoMetrics`.

### Member fields

| Field                   | Data type | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **version**             | `UINT32`  | The version of the structure, defined in the<br>`STREAM_METRICS_CURRENT_VERSION` macro.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **currentViewDuration** | `UINT64`  | The duration of the accumulated frames. In the fast networking case, this<br>duration is either zero or the frame duration (as the frame is being transmitted). If the duration<br>becomes longer than the `max_latency` specified in the `StreamDefinition`, the<br>stream latency callback is called if it's specified. The duration is specified in 100 ns units, which<br>is the default time unit for the PIC layer.                                                                                                          |
| **overallViewDuration** | `UINT64`  | The overall view duration. If the stream is configured with no ACKs or<br>persistence, this value grows as the frames are put into the Kinesis video stream and becomes equal to the<br>`buffer_duration` in the `StreamDefinition`. When ACKs are enabled and the<br>persisted ACK is received, the buffer is trimmed to the next key frame. This is because the ACK<br>timestamp indicates the beginning of the entire fragment. The duration is specified in 100-ns units,<br>which is the default time unit for the PIC layer. |
| **currentViewSize**     | `UINT64`  | The size in bytes of the current buffer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **overallViewSize**     | `UINT64`  | The overall view size in bytes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **currentFrameRate**    | `UINT64`  | The observed frame rate for the current stream.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **currentTransferRate** | `UINT64`  | The observed transfer rate in bytes per second for the<br>current stream.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
