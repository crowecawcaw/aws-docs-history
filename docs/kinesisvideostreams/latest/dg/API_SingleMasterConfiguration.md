# SingleMasterConfiguration

A structure that contains the configuration for the `SINGLE_MASTER` channel
type.

## Contents

**MessageTtlSeconds**

The period of time (in seconds) a signaling channel retains undelivered messages
before they are discarded. Use [UpdateSignalingChannel](API_UpdateSignalingChannel.md "API_UpdateSignalingChannel.md") to update
this value.

Type: Integer

Valid Range: Minimum value of 5. Maximum value of 120.

Required: No
