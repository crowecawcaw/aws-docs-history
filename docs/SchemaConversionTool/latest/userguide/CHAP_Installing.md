# Installing and Configuring AWS Schema Conversion Tool

The AWS Schema Conversion Tool (AWS SCT) is a standalone application that provides a project-based
user interface. AWS SCT is available for Microsoft Windows, Fedora Linux, and Ubuntu
Linux. AWS SCT is supported only on 64-bit operating systems.

To ensure that you get the correct version of the AWS SCT distribution file we provide
verification steps after you download the compressed file. You can verify the file using the
steps provided.

AWS SCT is available as both a standalone application and a command-line tool. For information
about the command line tool, see [AWS Schema Conversion Tool CLI](CHAP_Installing.md "CHAP_Installing.md").
