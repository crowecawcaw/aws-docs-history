

# Document history

The following table describes important changes to the AWS for SAP MCP Server User Guide.


| Change | Description | Date | 
| --- | --- | --- | 
| Okta inbound and outbound authentication | Added support for Okta as an inbound and outbound identity provider. Added Okta as an `InboundAuthProvider` value, and as an identity provider for the M2M and User Federation flows. For the On-Behalf-Of Token Exchange authentication flow with Okta, added the `OboAudience` parameter. | November 2026 | 
| SAP SuccessFactors support | Added support for SAP SuccessFactors as an `SapSystemType` value, with Basic Authentication, custom-catalog-only service discovery, and OData V2 or V4. | October 15, 2026 | 
| Initial release | Initial release of the AWS for SAP MCP Server User Guide. | April 30, 2026 |
