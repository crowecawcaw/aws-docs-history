

# Pricing
<a name="pricing"></a>

The AWS for SAP MCP Server package (Container and AWS CloudFormation) has no cost. Costs depend on the underlying infrastructure and services that you use, including:
+  **Amazon Bedrock AgentCore** – For more information, see [Amazon Bedrock AgentCore pricing](https://aws.amazon.com/bedrock/agentcore/pricing/) on the AWS website.

Additionally, the following references provide pricing related to MCP Clients:
+  **Amazon Quick** – For more information, see [Amazon Quick pricing](https://aws.amazon.com/quick/pricing/) on the AWS website.
+  **Other MCP Clients using Amazon Bedrock LLMs** – For more information, see [Amazon Bedrock pricing](https://aws.amazon.com/bedrock/pricing/) on the AWS website.

For all other questions, contact your AWS account team.
