# Analyzing data access using CloudWatch contributor insights for

DynamoDB

Amazon CloudWatch Contributor Insights for Amazon DynamoDB is a diagnostic tool for identifying the
most frequently accessed and throttled keys in your table or index at a glance. This tool uses
[CloudWatch contributor insights](../../../AmazonCloudWatch/latest/monitoring/ContributorInsights.md "../../../AmazonCloudWatch/latest/monitoring/ContributorInsights.md").

By enabling CloudWatch Contributor Insights for DynamoDB on a table or global secondary index,
you can view the most accessed and throttled items in those resources.

###### Note

CloudWatch charges apply for Contributor Insights for DynamoDB. For more information about pricing,
see [Amazon CloudWatch
pricing](https://aws.amazon.com/cloudwatch/pricing/ "https://aws.amazon.com/cloudwatch/pricing/").
