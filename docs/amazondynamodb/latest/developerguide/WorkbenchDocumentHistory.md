# Release history for NoSQL Workbench

The following table describes the important changes in each release of the _NoSQL Workbench_ client tool.

| Version | Change                                                                                    | Description                                                                                                                                                                                                                                                                                                                    | Date               |
| ------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------ |
| 3.13.5  | Capacity mode for default table settings is now on-demand                                 | When you create a table with default settings, DynamoDB creates a<br>table that uses on-demand capacity mode instead of provisioned<br>capacity mode.                                                                                                                                                                          | February 24, 2025  |
| 3.13.0  | NoSQL Workbench operation builder improvements                                            | NoSQL Workbench now includes native support for dark mode. Improved table and item<br>operations in the operations builder. Item results and operation<br>builder request information is available in JSON format.                                                                                                             | April 24, 2024     |
| 3.12.0  | Cloning tables with NoSQL Workbench and returning capacity<br>consumed                    | You can now clone tables between DynamoDB local and a DynamoDB web service<br>account or between DynamoDB web service accounts for faster development<br>iterations. View RCU or WCU consumed after running an operation using the<br>Operations Builder. We fixed the overwrite data issue when importing from a<br>CSV file. | February 26, 2024  |
| 3.11.0  | DynamoDB local improvements                                                               | You can now specify port when launching the built-in DynamoDB local<br>instance. NoSQL Workbench can now be installed on Windows without admin<br>rights. We have updated the data model templates.                                                                                                                            | January 17, 2024   |
| 3.10.0  | Native support for Apple silicon                                                          | NoSQL Workbench now includes native support for Mac with Apple<br>silicon. You can now configure sample data generation format for<br>attributes of type `Number`.                                                                                                                                                             | December 5, 2023   |
| 3.9.0   | Data modeler improvements                                                                 | Visualizer now supports committing data models to DynamoDB local with<br>the option to overwrite existing tables.                                                                                                                                                                                                              | November 3, 2023   |
| 3.8.0   | Sample data generation                                                                    | NoSQL Workbench now supports generating sample data for your DynamoDB<br>data models.                                                                                                                                                                                                                                          | September 25, 2023 |
| 3.6.0   | Improvements in the Operations builder                                                    | Connections management improvements in the Operations builder.<br>Attribute names in Data Modeler can now be changed without deleting<br>data. Other bug fixes.                                                                                                                                                                | April 11, 2023     |
| 3.5.0   | Support for new AWS Regions                                                               | NoSQL Workbench now supports the ap-south-2, ap-southeast-3,<br>ap-southeast-4, eu-central-2, eu-south-2, me-central-1, and me-west-1<br>regions.                                                                                                                                                                              | February 23, 2023  |
| 3.4.0   | Support for DynamoDB local                                                                | NoSQL Workbench now supports installing DynamoDB local as part of the<br>installation process.                                                                                                                                                                                                                                 | December 6, 2022   |
| 3.3.0   | Support for control plane operations                                                      | Operation Builder now supports control plane operations.                                                                                                                                                                                                                                                                       | June 1, 2022       |
| 3.2.0   | CSV import and export                                                                     | You can now import sample data from a CSV file in the Visualizer tool,<br>and also export the results of an Operation Builder query to a CSV<br>file.                                                                                                                                                                          | October 11, 2021   |
| 3.1.0   | Save operations                                                                           | The Operation Builder in NoSQL Workbench now supports saving<br>operations for later use.                                                                                                                                                                                                                                      | July 12, 2021      |
| 3.0.0   | Capacity settings and CloudFormation import/export                                        | NoSQL Workbench for Amazon DynamoDB now supports specifying a read/write<br>capacity mode for tables, and can now import and export data models in<br>CloudFormation format.                                                                                                                                                   | April 21, 2021     |
| 2.2.0   | Support for PartiQL                                                                       | NoSQL Workbench for Amazon DynamoDB adds support for building PartiQL<br>statements for DynamoDB.                                                                                                                                                                                                                              | December 4, 2020   |
| 1.1.0   | Support for Linux.                                                                        | NoSQL Workbench for Amazon DynamoDB is supported on Linux—Ubuntu,<br>Fedora, and Debian.                                                                                                                                                                                                                                       | May 4, 2020        |
| 1.0.0   | NoSQL Workbench for Amazon DynamoDB – GA.                                                 | NoSQL Workbench for Amazon DynamoDB is generally<br>available.                                                                                                                                                                                                                                                                 | March 2, 2020      |
| 0.4.1   | Support for IAM roles and temporary security<br>credentials.                              | NoSQL Workbench for Amazon DynamoDB adds support for AWS Identity and Access Management<br>(IAM) roles and temporary security credentials.                                                                                                                                                                                     | December 19, 2019  |
| 0.3.1   | Support for [DynamoDB local (Downloadable Version)](DynamoDBLocal.md "DynamoDBLocal.md"). | The NoSQL Workbench now supports connecting to [DynamoDB local (Downloadable Version)](DynamoDBLocal.md "DynamoDBLocal.md") to design, create, query,<br>and manage DynamoDB tables.                                                                                                                                           | November 8, 2019   |
| 0.2.1   | NoSQL Workbench preview released.                                                         | This is the initial release of NoSQL Workbench for DynamoDB. Use NoSQL<br>Workbench to design, create, query, and manage DynamoDB<br>tables.                                                                                                                                                                                   | September 16, 2019 |
