

# Setting up DynamoDB

In addition to the Amazon DynamoDB web service, you can develop and test applications against two tools that are compatible with DynamoDB and that run on your computer. For new projects, we recommend ExtendDB, an open-source adapter released by AWS under the Apache License 2.0. AWS also provides a downloadable version of DynamoDB. With either option, you can write and test applications locally without accessing the DynamoDB web service.

 The topics in this section describe how to set up the DynamoDB web service, ExtendDB, and DynamoDB (downloadable version).
