

# ExtendDB behavior differences from DynamoDB

For a complete list of the behavior differences between ExtendDB and the Amazon DynamoDB web service, see [Differences from DynamoDB](https://github.com/ExtendDB/extenddb/blob/main/docs/differences-from-dynamodb.md) on the GitHub website.

The `extenddb-dev` image is for local development and continuous integration only. It serves plain HTTP and grants every holder of a seeded credential full access to every table. For a durable deployment with TLS and access control, download the `extenddb-postgres` deployment image from the [Docker Hub website](https://hub.docker.com/r/extenddb/extenddb-postgres).

For source code and the issue tracker, see [ExtendDB on the GitHub website](https://github.com/ExtendDB/extenddb).
