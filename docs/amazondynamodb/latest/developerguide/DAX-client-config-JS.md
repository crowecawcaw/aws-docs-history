# Default client configuration for Node.js

When configuring the DAX JavaScript SDK client, you can customize various
parameters to optimize performance, connection handling, and error resilience.
The following table outlines the default configuration settings that control how
your client interacts with the DAX cluster, including timeout values, retry
mechanisms, credential management, and health monitoring options. For more
information, see [DynamoDBClient Operations](../../../AWSJavaScriptSDK/v3/latest/client/dynamodb.md "../../../AWSJavaScriptSDK/v3/latest/client/dynamodb.md").

| DAX JS SDK client defaults                    | Parameter               | Type                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `region`<br>optional                          | `string`                | The AWS Region to use for the DAX client (example -<br>'us-east-1'). This is a required parameter if not provided<br>through the environment variable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `endpoint`<br>required                        | `string`                | The endpoint of the Cluster to which the SDK<br>connects.<br>Examples:<br>Non-encrypted –<br>dax-cluster-name.region.amazonaws.com<br>Encrypted –<br>daxs://my-cluster.l6fzcv.dax-clusters.us-east-1.amazonaws.com                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `requestTimeout`<br>default 6000 ms           | `number`                | This defines the maximum time the client will wait for<br>a response from DAX.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `writeRetries`<br>default 1                   | `number`                | The number of retries to attempt for write requests<br>that fail.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `readRetries`<br>default 1                    | `number`                | The number of retries to attempt for read requests that<br>fail.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `maxRetries`<br>default 1                     | `number`                | The maximum number of retries to attempt on failed<br>requests.<br>If readRetries/writeRetries are set, then the<br>configuration set in readRetries and writeRetries take<br>priority over maxRetries.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `connectTimeout`<br>default 10000 ms          | `number`                | The timeout (in milliseconds) for establishing a<br>connection to any of the cluster nodes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `maxConcurrentConnections`<br>default 100     | `number`                | Limits the total number of concurrent connections that<br>a client instance can create per node in a DAX<br>cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `maxRetryDelay`<br>default 7000 ms            | `number`                | When the DAX server indicates recover is needed by<br>setting `waitForRecoveryBeforeRetrying` flag to<br>true, the client will pause before retry attempts. During<br>these recovery periods, the `maxRetryDelay`<br>parameter determines the maximum waiting time between<br>retries. This recovery-specific configuration only applies<br>when the DAX server is in recovery mode. For all other<br>scenarios, retry behavior follows one of two patterns:<br>either an exponential delay based on the retry count<br>(governed by `writeRetries`,<br>`readRetries`, or `maxRetries`<br>parameters), or an immediate retry depending on the<br>exception type. |
| `credentials`<br>optional                     | `AwsCredentialIdentity` | `AwsCredentialIdentityProvider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | The AWS credentials to use for authenticating requests.<br>This can be provided as an AwsCredentialIdentity or an<br>AwsCredentialIdentityProvider. If not provided, the AWS<br>SDK will automatically use the default credentials provider<br>chain. Example: `{ accessKeyId: 'AKIA...', secretAccessKey:<br>'...', sessionToken: '...' }` \<br>• @default Uses default AWS<br>credentials provider chain. |
| `healthCheckInterval`<br>default 5000 ms      | `number`                | The interval (in milliseconds) between cluster health<br>checks. A lower interval will check more frequently.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `healthCheckTimeout`<br>default 1000 ms       | `number`                | The timeout (in milliseconds) for the health check to<br>complete.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `skipHostnameVerification`<br>default false   | `boolean`               | Skip hostname verification of TLS connections. This has no<br>impact on un-encrypted clusters. The default is to perform<br>hostname verification, setting this to True will skip<br>verification. Be sure you understand the implication of<br>turning it off, which is the inability to authenticate the<br>cluster that you are connecting to.                                                                                                                                                                                                                                                                                                                |
| `unhealthyConsecutiveErrorCount`<br>default 5 | `number`                | Sets the number of consecutive errors required to<br>signal node unhealthy within health check interval.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `clusterUpdateInterval`<br>default 4000 ms    | `number`                | Returns the interval between polling of cluster members<br>for membership changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `clusterUpdateThreshold`<br>default 125       | `number`                | Returns the threshold below which the cluster will not<br>be polled for membership changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `credentailProvider`<br>optional              | default null            | `AwsCredentialIdentityProvider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | User Defined Provider for AWS credentials used to<br>authenticate requests to DAX.                                                                                                                                                                                                                                                                                                                          |
