# Using the AWS Management Console with our new AWS experience

###### Warning

We're currently releasing our new experience to a limited number of customers. You
might not be able to access this experience yet.

If you signed up using our [new AWS experience](../../../accounts/latest/reference/sign-in-new.md "../../../accounts/latest/reference/sign-in-new.md"), you
have access to a simplified version of the AWS Management Console. This version of the AWS Management Console
includes the following:

- **Generate your AWS credentials** – You can
  generate your AWS credentials and use our set up script to let your AI coding
  tools create AWS resources in your project.
- **Navigate to AWS service consoles** – You
  can use Unified Navigation to access recently visited service consoles, view and add
  services to your **Favorites** list, access your console settings,
  and access AWS User Notifications. Not every AWS service is supported with our new AWS
  experience. For more information, see [Supported
  AWS services for Sign up for AWS (new)](../../../accounts/latest/reference/supported-services-sign-up-new.md "../../../accounts/latest/reference/supported-services-sign-up-new.md").
- **Search for AWS services and other AWS
  information** – Use Unified Search to search for AWS services and
  features, and AWS Marketplace products.
- **Menu** – Use the menu to
  move between the AWS Management Console and AWS Settings, switch between active sessions, and
  customize the various aspects of the AWS Management Console.
- **Run CLI commands** – Amazon CloudSearch is accessible
  directly from the console. You can use Amazon CloudSearch to run AWS CLI commands against your
  favorite services.
- **Access all AWS event notifications** – You
  can use the AWS Management Console to access notifications from AWS User Notifications and .
- **Chat with Amazon Q** – You can get
  generative artificial intelligence (AI) assistant powered answers to your AWS
  service questions directly from the console.
  Certain tasks are not supported in the AWS Management Console but are supported in AWS Settings. For
  more information, see [Compare sign-up options](../../../accounts/latest/reference/sign-up-for-aws.md "../../../accounts/latest/reference/sign-up-for-aws.md").
