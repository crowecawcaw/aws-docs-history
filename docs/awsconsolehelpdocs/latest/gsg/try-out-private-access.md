# Try AWS Management Console Private Access

This section describes how to set up and test AWS Management Console Private Access in a new
account.

AWS Management Console Private Access is an advanced security feature and requires prior knowledge
about networking and setting up VPCs. This topic describes how you can try out AWS Management Console
Private Access without a full scale infrastructure.
