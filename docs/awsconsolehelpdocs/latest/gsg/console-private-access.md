# AWS Management Console Private Access

AWS Management Console Private Access is an advanced security feature to control access to the AWS Management Console.
Console Private Access is useful when you want to prevent users from signing in to unexpected
AWS accounts from within your network. With this feature, you can limit access to the
AWS Management Console only to a specified set of known AWS accounts when the traffic originates from
within your network. Console Private Access is also useful when you want to ensure that all calls from the AWS Management Console to AWS services
originate from within your network and from allowed accounts.
