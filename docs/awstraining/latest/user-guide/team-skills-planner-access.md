

# Access
<a name="team-skills-planner-access"></a>

If you’re interested in Team Skills Planner and don’t have access, contact your AWS Training representative. Team Skills Planner is available globally, and some information is currently available in English only.

 **Prerequisites** 
+ An AWS Skill Builder Team Subscription, which includes Team Skills Planner.
+ Learning Administrator access for your organization in AWS Skill Builder.

 **Supported browsers** 

Team Skills Planner supports Google Chrome and Microsoft Edge 111 or later, Firefox 113 or later, and Safari 16.2 or later. In earlier versions, the page loads, but some styling is missing.
