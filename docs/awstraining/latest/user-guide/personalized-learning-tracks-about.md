

# What is a personalized learning track?
<a name="personalized-learning-tracks-about"></a>

An AI feature in AWS Skill Builder, a personalized learning track is a structured set of lessons and assessments built around a learner’s specific goal, experience level, and schedule. Describe what you want to learn in a short conversation (such as preparing for an AWS Certification exam, building a project on AWS, getting started in a new topic, or growing into a specific role), and Skill Builder assembles a personalized learning track from learning objectives developed by AWS subject matter experts.

 **How is a learning track different from a Learning Plan?** 

A standard Learning Plan is the same fixed sequence of content for everyone. A personalized learning track is built around your stated goal and background. A learning track also includes multiple learning formats so that you can choose how you want to learn (including short lessons, Digital Training, AWS Builder Labs, AWS SimuLearn scenarios, and official practice exams). A learning track also provides milestone assessments to validate what you learn.

 **Does a learning track replace existing training such as Learning Plans or Exam Prep?** 

No. Personalized learning tracks are offered alongside Learning Plans and Exam Prep, which remain available.
