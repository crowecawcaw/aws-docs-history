# Introduction

All versions of SimSpace Weaver are supported. The main documentation only
covers the latest version. If you use a version that isn't the latest, you
can use this catalog to find the documentation for it.

###### Important

We only perform critical updates to guides for previous versions. Each of
those guides remain as they were for the last version the guide applies to.
