# Starting a Python simulation

You can start your Python-based simulation the same way as a regular SimSpace Weaver simulation,
both in SimSpace Weaver Local and in SimSpace Weaver in the AWS Cloud. For more information, see the tutorials in
[Getting started with SimSpace Weaver](getting-started.md "getting-started.md").

The `PythonBubblesSample` includes its own Python sample client. For more
information, see [The sample Python client](working-with_python_client.md "working-with_python_client.md").
