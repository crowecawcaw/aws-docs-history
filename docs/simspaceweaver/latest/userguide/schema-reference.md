# SimSpace Weaver simulation schema reference

SimSpace Weaver uses a YAML file to configure the properties of a simulation. This file
is called the _simulation schema_ (or just _schema_). The sample simulation included in the SimSpace Weaver app SDK
includes a schema that you can copy and edit for your own simulation.
