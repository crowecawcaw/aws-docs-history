# SDK version

The `sdk_version` section (required) identifies the version of the SimSpace Weaver app SDK
that supports this schema. Valid values: `1.17`, `1.16`, `1.15`, `1.14`, `1.13`, `1.12`

###### Important

The value of `sdk_version` only includes the major version number and first minor version number.
For example, the value `1.12` specifies all versions `1.12.x`, such as `1.12.0`, `1.12.1`, and `1.12.2`.

```
sdk_version: "1.17"
```
