# Loading streaming data from OpenSearch Ingestion

You can use Amazon OpenSearch Ingestion to load data into an OpenSearch Service domain. You configure your
data producers to send data to OpenSearch Ingestion, and it automatically delivers the data
to the collection that you specify. You can also configure OpenSearch Ingestion to transform
your data before delivering it. For more information, see [Overview of Amazon OpenSearch Ingestion](ingestion.md "ingestion.md").
