# Loading streaming data from Amazon CloudWatch

You can load streaming data from CloudWatch Logs to your OpenSearch Service domain by using a CloudWatch Logs
subscription. For information about Amazon CloudWatch subscriptions, see [Real-time processing of log data with subscriptions](../../../AmazonCloudWatch/latest/DeveloperGuide/Subscriptions.md "../../../AmazonCloudWatch/latest/DeveloperGuide/Subscriptions.md"). For configuration
information, see [Streaming CloudWatch Logs data to Amazon OpenSearch Service](../../../AmazonCloudWatch/latest/logs/CWL_OpenSearch_Stream.md "../../../AmazonCloudWatch/latest/logs/CWL_OpenSearch_Stream.md") in the _Amazon CloudWatch
Developer Guide_.
