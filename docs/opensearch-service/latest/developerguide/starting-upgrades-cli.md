# Upgrading a domain (CLI)

You can use the following operations to identify the correct version of OpenSearch or
Elasticsearch for your domain, start an in-place upgrade, perform the pre-upgrade check,
and view progress:

- `get-compatible-versions`
  (`GetCompatibleVersions`)
- `upgrade-domain` (`UpgradeDomain`)
- `get-upgrade-status` (`GetUpgradeStatus`)
- `get-upgrade-history` (`GetUpgradeHistory`)
  For more information, see the [AWS CLI command reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/opensearch/index.html "https://awscli.amazonaws.com/v2/documentation/api/latest/reference/opensearch/index.html") and [Amazon OpenSearch Service API
  Reference](../APIReference/Welcome.md "../APIReference/Welcome.md").
