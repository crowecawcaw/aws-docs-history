# Comparing OpenSearch Service and OpenSearch Serverless

In OpenSearch Serverless, some concepts and features are different than their corresponding
feature for a provisioned OpenSearch Service domain. For example, one important difference is that
OpenSearch Serverless doesn't have the concept of a cluster or node.

The following table describes how important features and concepts in OpenSearch Serverless differ
from the equivalent feature in a provisioned OpenSearch Service domain.

| Feature                                   | OpenSearch Service                                                                                                                                                                                                                                                                                          | OpenSearch Serverless                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Domains versus<br>collections**         | Indexes are held in _domains_, which are<br>pre-provisioned OpenSearch clusters.<br>For more information, see [Creating and managing Amazon OpenSearch Service domains](createupdatedomains.md "createupdatedomains.md").                                                                                   | Indexes are held in _collections_, which<br>are logical groupings of indexes that represent a specific<br>workload or use case.<br>For more information, see [Managing Amazon OpenSearch Serverless collections](serverless-manage.md "serverless-manage.md").                                                                                                                       |
| **Node types and capacity<br>management** | You build a cluster with node types that meet your cost and<br>performance specifications. You must calculate your own storage<br>requirements and choose an instance type for your domain.<br>For more information, see [Sizing Amazon OpenSearch Service domains](sizing-domains.md "sizing-domains.md"). | OpenSearch Serverless automatically scales and provisions additional compute<br>units for your account based on your capacity usage.<br>For more information, see [Managing capacity limits for Amazon OpenSearch Serverless](serverless-scaling.md "serverless-scaling.md").                                                                                                        |
| **Billing**                               | You pay for each hour of use of an EC2 instance and for the<br>cumulative size of any EBS storage volumes attached to your<br>instances.<br>For more information, see [Pricing for Amazon OpenSearch Service](what-is.md#pricing "what-is.md#pricing").                                                     | You're charged in OCU-hours for compute for data ingestion,<br>compute for search and query, and storage retained in S3.<br>For more information, see [Pricing](serverless-overview.md#serverless-pricing "serverless-overview.md#serverless-pricing").                                                                                                                              |
| **Encryption**                            | Encryption at rest is \*optional<br>• for<br>domains.<br>For more information, see [Encryption of data at rest for Amazon OpenSearch Service](encryption-at-rest.md "encryption-at-rest.md").                                                                                                               | Encryption at rest is \*required<br>• for<br>collections.<br>For more information, see [Encryption in Amazon OpenSearch Serverless](serverless-encryption.md "serverless-encryption.md").                                                                                                                                                                                            |
| **Data access control**                   | Access to the data within domains is determined by IAM<br>policies and [fine-grained access<br>control](fgac.md "fgac.md").                                                                                                                                                                                 | Access to data within collections is determined by [data access<br>policies](serverless-data-access.md "serverless-data-access.md").                                                                                                                                                                                                                                                 |
| **Supported OpenSearch<br>operations**    | OpenSearch Service supports a subset of all of the OpenSearch API<br>operations.<br>For more information, see [Supported operations in Amazon OpenSearch Service](supported-operations.md "supported-operations.md").                                                                                       | OpenSearch Serverless supports a different subset of OpenSearch API<br>operations.<br>For more information, see [Supported operations and plugins in Amazon OpenSearch Serverless](serverless-genref.md "serverless-genref.md").                                                                                                                                                     |
| **Dashboards sign-in**                    | Sign in with a username and password.<br>For more information, see [Accessing OpenSearch Dashboards as the master user](fgac.md#fgac-dashboards "fgac.md#fgac-dashboards").                                                                                                                                 | If you're logged into the AWS console and navigate to your<br>Dashboard URL, you'll automatically log in.<br>For more information, see [Accessing OpenSearch Dashboards](serverless-dashboards.md "serverless-dashboards.md").                                                                                                                                                       |
| **APIs**                                  | Interact programmatically with OpenSearch Service using the [OpenSearch Service API operations](../APIReference/Welcome.md "../APIReference/Welcome.md").                                                                                                                                                   | Interact programmatically with OpenSearch Serverless using the [OpenSearch Serverless API operations](../ServerlessAPIReference/Welcome.md "../ServerlessAPIReference/Welcome.md").                                                                                                                                                                                                  |
| **Network access**                        | Network settings for a domain apply to the domain endpoint as<br>well as the OpenSearch Dashboards endpoint. Network access for both<br>is tightly coupled.                                                                                                                                                 | Network settings for the domain endpoint and the<br>OpenSearch Dashboards endpoint are decoupled. You can choose to not<br>configure network access for OpenSearch Dashboards.<br>For more information, see [Network access for Amazon OpenSearch Serverless](serverless-network.md "serverless-network.md").                                                                        |
| **Signing requests**                      | Use the OpenSearch high and low-level REST clients to sign<br>requests. Specify the service name as `es`.                                                                                                                                                                                                   | At this time, OpenSearch Serverless supports a subset of clients that OpenSearch Service<br>supports.<br>When you sign requests, specify the service name as<br>`aoss`. The `x-amz-content-sha256`<br>header is required. For more information, see [Signing HTTP requests with other clients](serverless-clients.md#serverless-signing "serverless-clients.md#serverless-signing"). |
| **OpenSearch version<br>upgrades**        | You manually upgrade your domains as new versions of OpenSearch<br>become available. You're responsible for ensuring that your<br>domain meets the upgrade requirements, and that you've addressed<br>any breaking changes.                                                                                 | OpenSearch Serverless automatically upgrades your collections to new<br>OpenSearch versions. Upgrades don't necessarily happen as soon as<br>a new version is available.                                                                                                                                                                                                             |
| **Service software updates**              | You manually apply service software updates to your domain as<br>they become available.                                                                                                                                                                                                                     | OpenSearch Serverless automatically updates your collections to consume the<br>latest bug fixes, features, and performance improvements.                                                                                                                                                                                                                                             |
| **VPC access**                            | You can [provision your domain within a<br>VPC](vpc.md "vpc.md").<br>You can also create additional [OpenSearch Service-managed VPC<br>endpoints](vpc-interface-endpoints.md "vpc-interface-endpoints.md") to access the domain.                                                                            | You create one or more [OpenSearch Serverless-managed VPC endpoints](serverless-vpc.md "serverless-vpc.md") for your account. Then,<br>you include these endpoints within [network policies](serverless-network.md "serverless-network.md").                                                                                                                                         |
| **SAML authentication**                   | You enable SAML authentication on a per-domain basis.<br>For more information, see [SAML authentication for OpenSearch Dashboards](saml.md "saml.md").                                                                                                                                                      | You configure one or more SAML providers at the account level,<br>then you include the associated user and group IDs within data<br>access policies.<br>For more information, see [SAML authentication for Amazon OpenSearch Serverless](serverless-saml.md "serverless-saml.md").                                                                                                   |
| **Transport Layer Security<br>(TLS)**     | OpenSearch Service supports TLS 1.2 but it is recommend you use TLS<br>1.3.                                                                                                                                                                                                                                 | OpenSearch Serverless supports TLS 1.2 but it is recommended you use TLS<br>1.3.                                                                                                                                                                                                                                                                                                     |
