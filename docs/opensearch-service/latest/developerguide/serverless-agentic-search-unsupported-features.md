# Unsupported agentic search APIs and features

Only flow agents with the `QueryPlanningTool` are currently supported
on Amazon OpenSearch Serverless.

## Unsupported agent types

The following agent types are not supported on Amazon OpenSearch Serverless:

- Conversational agents

## Unsupported features

The following agentic search features are not supported on Amazon OpenSearch Serverless:

- Search templates
- Memory APIs
- MCP Server APIs
- Custom prompts
