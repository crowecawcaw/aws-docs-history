# Supported instance types in Amazon OpenSearch Service

Amazon OpenSearch Service supports the following instance types. Not all Regions
support all instance types. For availability details, see [Amazon OpenSearch Service
pricing](https://aws.amazon.com/opensearch-service/pricing/ "https://aws.amazon.com/opensearch-service/pricing/").

For information about which instance type is appropriate for your use case, see [Sizing Amazon OpenSearch Service domains](sizing-domains.md "sizing-domains.md"), [EBS volume size quotas](limits.md#ebsresource "limits.md#ebsresource"), and [Network quotas](limits.md#network-limits "limits.md#network-limits").
