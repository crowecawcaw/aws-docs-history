# Delete an Amazon OpenSearch Service domain

Because the _movies_ domain from this tutorial is for
test purposes, make sure to delete it when you're done experimenting to avoid incurring
charges.

###### To delete an OpenSearch Service domain from the console

1. Sign in to the **Amazon OpenSearch Service** console.
2. Under **Domains**, select the **movies**
   domain.
3. Choose **Delete** and confirm deletion.
