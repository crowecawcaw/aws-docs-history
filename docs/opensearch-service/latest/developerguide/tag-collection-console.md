# Tagging collections (console)

The console is the simplest way to tag a collection.

###### **To create a tag (console)**

1. Sign in to the Amazon OpenSearch Service console at [https://console.aws.amazon.com/aos/home](https://console.aws.amazon.com/aos/home "https://console.aws.amazon.com/aos/home ").
2. Expand **Serverless** in the left navigation pane and choose
   **Collections**.
3. Select the collection that you want to add tags to, and go to the
   **Tags** tab.
4. Choose **Manage** and **Add new
   tag**.
5. Enter a tag key and an optional value.
6. Choose **Save**.
   To delete a tag, follow the same steps and choose **Remove** on the
   **Manage tags** page.

For more information about using the console to work with tags, see [Tag
Editor](../../../awsconsolehelpdocs/latest/gsg/tag-editor.md "../../../awsconsolehelpdocs/latest/gsg/tag-editor.md") in the _AWS Management Console Getting Started
Guide_.
