

# Authentication and access control for OpenSearch UI
<a name="application-auth"></a>

Every OpenSearch UI application authenticates its users with AWS Identity and Access Management (IAM), with AWS IAM Identity Center, or with SAML federation through IAM. For information about the permissions that each method requires, see [Getting started with the OpenSearch user interface in Amazon OpenSearch Service](application-getting-started.md).
