# Setting up Amazon Q for

OpenSearch Service

Complete the following steps to set up Amazon Q for OpenSearch Service.

1. Verify that you have configured OpenSearch Service fine-grained access control. For more
   information, see [Fine-grained access control in Amazon OpenSearch Service](fgac.md "fgac.md").
2. Verify that your data source is on OpenSearch version 2.17 or later.
3. Verify that you selected the **Enable natural language query
   generation** checkbox in the **Artificial Intelligence (AI)
   and Machine Learning (ML)** section during domain creation or by
   editing the cluster configuration.

###### Note

Amazon Q for Developer OpenSearch features are available with the Q free tier. For
more information, see [Understanding tiers of
service](../../../amazonq/latest/qdeveloper-ug/q-tiers.md "../../../amazonq/latest/qdeveloper-ug/q-tiers.md") in _Amazon Q User Guide_.
