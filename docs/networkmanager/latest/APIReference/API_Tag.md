# Tag

Describes a tag.


## Contents





**Key** 


The tag key.


Constraints: Maximum length of 128 characters.


Type: String


Length Constraints: Minimum length of 0. Maximum length of 10000000.


Pattern: `[\s\S]*`



Required: No




**Value** 


The tag value.


Constraints: Maximum length of 256 characters.


Type: String


Length Constraints: Minimum length of 0. Maximum length of 10000000.


Pattern: `[\s\S]*`



Required: No
