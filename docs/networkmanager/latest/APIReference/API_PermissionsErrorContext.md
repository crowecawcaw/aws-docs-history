# PermissionsErrorContext

Describes additional information about missing permissions. 


## Contents





**MissingPermission** 


The missing permissions.


Type: String


Length Constraints: Minimum length of 0. Maximum length of 10000000.


Pattern: `[\s\S]*`



Required: No
