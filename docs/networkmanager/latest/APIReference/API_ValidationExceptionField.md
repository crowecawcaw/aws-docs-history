# ValidationExceptionField

Describes a validation exception for a field.


## Contents





**Message** 


The message for the field.


Type: String


Length Constraints: Minimum length of 0. Maximum length of 10000000.


Pattern: `[\s\S]*`



Required: Yes




**Name** 


The name of the field.


Type: String


Length Constraints: Minimum length of 0. Maximum length of 10000000.


Pattern: `[\s\S]*`



Required: Yes
