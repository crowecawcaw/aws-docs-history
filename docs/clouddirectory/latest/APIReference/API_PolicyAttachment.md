# PolicyAttachment

Contains the `PolicyType`, `PolicyId`, and the `ObjectIdentifier` to which it is
 attached. For more
 information, see [Policies](../developerguide/key_concepts_directory.md#key_concepts_policies "../developerguide/key_concepts_directory.md#key_concepts_policies").


## Contents





**ObjectIdentifier** 


The `ObjectIdentifier` that is associated with
 `PolicyAttachment`.


Type: String


Required: No




**PolicyId** 


The ID of `PolicyAttachment`.


Type: String


Required: No




**PolicyType** 


The type of policy that can be associated with `PolicyAttachment`.


Type: String


Required: No
