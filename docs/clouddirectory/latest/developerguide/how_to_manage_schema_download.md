# Download a Schema

Use the following procedure to download a schema.

###### To download a schema

1. In the [AWS Directory Service console](https://console.aws.amazon.com/directoryservicev2/ "https://console.aws.amazon.com/directoryservicev2/") navigation pane, under **Cloud Directory**, select **Schemas**.
2. Select the option in the table next to the schema name you want to download.
3. Choose **Actions**.
4. Choose **Download schema**
