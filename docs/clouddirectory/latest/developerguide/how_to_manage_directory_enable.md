# Enable Your Directory

Use the following procedure to enable a previously disabled directory in Cloud Directory.

###### To enable a directory

1. In the [AWS Directory Service console](https://console.aws.amazon.com/directoryservicev2/ "https://console.aws.amazon.com/directoryservicev2/") navigation pane, under **Cloud Directory**, select **Directories**.
2. Select the option in the table next to the directory ID you want to enable.
3. Choose **Actions**.
4. Choose **Enable**
