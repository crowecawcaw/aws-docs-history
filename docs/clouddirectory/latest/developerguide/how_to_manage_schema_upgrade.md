# Upgrade Your Schema

Upgrading a schema adds the facets and attributes you choose to the published schema or applied schema you
select.

- To upgrade a published schema call the [`UpgradePublishedSchema`](../APIReference/API_UpgradePublishedSchema.md "../APIReference/API_UpgradePublishedSchema.md") CLI action.
- To upgrade an applied schema, call the
  [`UpgradeAppliedSchema`](../APIReference/API_UpgradeAppliedSchema.md "../APIReference/API_UpgradeAppliedSchema.md") CLI action.
