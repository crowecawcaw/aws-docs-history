# Upgrade Your Schema
<a name="how_to_manage_schema_upgrade"></a>

Upgrading a schema adds the facets and attributes you choose to the published schema or applied schema you select. 
+ To upgrade a published schema call the [`UpgradePublishedSchema`](https://docs.aws.amazon.com/clouddirectory/latest/APIReference/API_UpgradePublishedSchema.html) CLI action.
+ To upgrade an applied schema, call the [`UpgradeAppliedSchema`](https://docs.aws.amazon.com/clouddirectory/latest/APIReference/API_UpgradeAppliedSchema.html) CLI action.
