# Delete Your Directory

Use the following procedure to delete a directory in Cloud Directory.

###### Note

Before you can delete a directory, you must first disable it. For instructions, see [Disable Your Directory](how_to_manage_directory_disable.md "how_to_manage_directory_disable.md").

###### To delete a directory

1. In the [AWS Directory Service console](https://console.aws.amazon.com/directoryservicev2/ "https://console.aws.amazon.com/directoryservicev2/") navigation pane, under **Cloud Directory**, select **Directories**.
2. Select the option in the table next to the directory ID you want to delete.
3. Choose **Actions**.
4. Choose **Delete**
5. In the **Delete directory** dialog, confirm the operation by typing in
 the name of your directory, and then choose **Delete**.
