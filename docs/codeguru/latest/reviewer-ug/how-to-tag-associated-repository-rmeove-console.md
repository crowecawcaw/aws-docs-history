# Remove tags from a CodeGuru Reviewer associated repository (console)

###### To remove tags from an associated repository

1. Open the Amazon CodeGuru Reviewer console at
   [https://console.aws.amazon.com/codeguru/reviewer/](https://console.aws.amazon.com/codeguru/reviewer/ "https://console.aws.amazon.com/codeguru/reviewer/").
2. In the navigation pane, choose **Repositories**.
3. Choose the association ID of the associated repository with the tags you
   want to edit.
4. In **Tags**, choose **Manage tags**.
5. Choose **Remove** next to each tag you want to remove.
6. Choose **Save changes**.
