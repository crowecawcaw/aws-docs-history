# Creating your Amazon Lookout for Vision model

An Amazon Lookout for Vision model is a machine learning model that predicts the presence of anomalies in
new images by finding patterns in images used to train the model. This section shows you how
to create and train a model. After you train your model, you evaluate its performance. For
more information, see [Improving your Amazon Lookout for Vision model](improve.md "improve.md").

Before you create your first model, we recommend that you read [Understanding Amazon Lookout for Vision](understanding.md "understanding.md") and [Getting started with Amazon Lookout for Vision](getting-started.md "getting-started.md"). If you are using the AWS
SDK, read [Call an Amazon Lookout for Vision operation](su-sdk-list-projects.md "su-sdk-list-projects.md").
