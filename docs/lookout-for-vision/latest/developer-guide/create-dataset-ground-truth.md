# Creating a dataset using an Amazon SageMaker AI

Ground Truth manifest file

A manifest file contains information about the images and image labels that you
can use to train and test a model. You can store a manifest file in an Amazon S3 bucket
and use it to create a dataset. You can create your own manifest file or you can use
an existing manifest file, such as the output from an Amazon SageMaker AI Ground Truth
job.
