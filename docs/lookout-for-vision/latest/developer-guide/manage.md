# Managing your Amazon Lookout for Vision resources

You can manage your Amazon Lookout for Vision resources by using the console or the AWS SDK. Amazon Lookout for Vision
has the following resources:

- Projects
- Datasets
- Models
- Trial detections

###### Note

You can't delete a trial detection task. Also, you can't manage trial detections by using the AWS SDK.
