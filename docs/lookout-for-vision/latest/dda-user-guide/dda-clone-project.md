# Cloning a project

You can use the Defect Detection App to create a clone (copy) of an existing project. Cloning a
project is useful if you want to make a backup of the dataset used to train a model. You
might also clone a project so that you can experiment with new dataset images before
training a new version of a model.

###### To clone a project (Defect Detection App)

1. If you're not on the project details page, do the following:
   1. [Sign in](dda-signin-dda-web-app.md "dda-signin-dda-web-app.md") to the Defect Detection App Console.
   2. In the top navigation pane, choose **Projects**.
   3. On the projects page, choose the project. The console opens the project details page.

2. Choose **Clone** to open the **Clone
   project** page.
3. In **Project name**, enter a name for the cloned
   project.
4. In **Description**, enter a description for the cloned
   project.
5. In **Model type**, choose the model type for the cloned project.
6. Choose **Clone project** to clone the project. It might take a few
   seconds to complete the operation. If successful, Defect Detection App shows the message
   **Success, you have created {Project Name}.** in an alert
   at the top of the page.
