# Getting all workflow results

The Station App lets you view the analysis results for the last analyzed image. To see
the results for all analyzed images, you need to look at the files that the workflow
stores for each image it analyzes. You set the location for these file when you
configure the workflow. For more information, see [Configuring a workflow](dda-configure-workflow.md "dda-configure-workflow.md"). If necessary, you can get the location
from the workflow configuration page in the Station App.

For information about intepreting the workflow results, see [Getting all workflow results (SDK)](dda-hmi-sdk.md#dda-hmi-sdk-get-all-workflow-results "dda-hmi-sdk.md#dda-hmi-sdk-get-all-workflow-results").
