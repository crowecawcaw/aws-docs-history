# GET /workflows

Gets a list of the active workflows. For more information, see [Workflow](api-dt-Workflow.md "api-dt-Workflow.md").

## Endpoint

```
GET /workflows
```

## Request

parameters

None

## Response

A list of [Workflow](api-dt-Workflow.md "api-dt-Workflow.md") objects. Each object is a single workflow.

Format: JSON
