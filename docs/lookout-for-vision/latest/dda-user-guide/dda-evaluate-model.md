# Evaluating your model

During training Defect Detection App tests your model and uses the results to create performance metrics.
You can use performance metrics to evaluate the performance of your model. If necessary, you can
take steps to improve your datasets and then retrain your model.

If you're satisfied with the performance of your model, you can deploy it to a station. For
more information, see [Deploying your model to a station](dda-deploy-model.md "dda-deploy-model.md").
