# GET /snapshot

Gets the location of a snapshot (TAR archive file) of the station logs.
Call [GET /snapshotfile/{path}](api-get-snapshotfile.md "api-get-snapshotfile.md") to download
the snapshot file.

## Endpoint

```
GET /snapshot
```

## Request

parameters

None

## Response

The location of the log files snapshot.

Format: String
