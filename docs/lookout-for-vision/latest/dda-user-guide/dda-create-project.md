# Creating a project

Create a project using the Defect Detection App Console.
A project manages the training and test datasets and also manages the trained versions of the model.
We recommend that you use a project for a single use case, such as detecting anomalies in a single type of machine part.

###### To create a project

1. [Sign in](dda-signin-dda-web-app.md "dda-signin-dda-web-app.md") to the Defect Detection App Console.
2. In the top navigation pane, choose **Projects**.
3. On the projects page, choose **Create project**.
4. In **Projects details**, enter a project name and an optional description.
5. For **Model type**, select the type of model for the project.
6. Choose **Create project**.
