# GET /image-sources

Gets a list of the image sources available on the Defect Detection Station App.

## Endpoint

```
GET /image-sources
```

## Request

parameters

None

## Response

A list of [ImageSource](api-dt-ImageSource.md "api-dt-ImageSource.md") objects. Each object is a single
image source.

Format: JSON
