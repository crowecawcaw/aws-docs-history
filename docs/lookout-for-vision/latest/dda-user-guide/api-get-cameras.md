# GET /cameras

Gets a list of the cameras discovered by Defect Detection App.

## Endpoint

```
GET /cameras
```

## Request

parameters

None

## Response

A list of [Camera](api-dt-Camera.md "api-dt-Camera.md")
objects. Each object is a single camera discovered by Defect Detection App.

Format: JSON
