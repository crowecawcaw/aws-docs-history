# GET /workflows/{workflowId}

Gets an individual workflow. For more information, see [Workflow](api-dt-Workflow.md "api-dt-Workflow.md").

## Endpoint

```
GET /workflows/{workflowId}
```

`workflowId` is the identifier for the workflow that you want
to get.

## Request

parameters

None

## Response

A [Workflow](api-dt-Workflow.md "api-dt-Workflow.md") object
for the requested workflow.

Format: JSON
