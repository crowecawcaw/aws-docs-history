# Training and deploying a model

A Defect Detection App model is a machine learning model that you train to find visual defects in industrial products.
These instructions show you how create and deploy a model to a station with the Defect Detection App.

Before starting these instructions, we recommend that you read [What is Defect Detection App?](what-is.md "what-is.md").
