# GET

/system-health

Gets the system health for a station. For more information, see [Managing station health](dda-managing-system-health.md "dda-managing-system-health.md").

## Endpoint

```
GET /system-health
```

## Request

parameters

None

## Response

A [SystemHealth](api-dt-SystemHealth.md "api-dt-SystemHealth.md") object that contains health information for the station.

Format: JSON
