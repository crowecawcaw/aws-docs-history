# Deleting a project

If you are no longer using a project, you can delete it by using the Defect Detection App. Note that you can't recover a deleted project.
Also, Defect Detection App won't delete a project until you delete all models that you trained in this project.

###### To delete a project (Defect Detection App)

1. If you're not on the project details page, do the following:
   1. [Sign in](dda-signin-dda-web-app.md "dda-signin-dda-web-app.md") to the Defect Detection App Console.
   2. In the top navigation pane, choose **Projects**.
   3. On the projects page, choose the project. The console opens the project details page.

2. Choose **Delete project** to open the **Delete project** page.
3. In the `Delete` dialog box, enter the name of the project to confirm that you want to delete it.
4. Choose **Delete** to delete the project. It might take a few seconds to complete the operation. If successful,
   Defect Detection App shows the message **Success, you have deleted {Project Name}.** in an alert at the top of the page.
