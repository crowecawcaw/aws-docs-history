# GET

/image-sources/{imageSourceId}

Gets an individual image source. For more information, see [ImageSource](api-dt-ImageSource.md "api-dt-ImageSource.md").

## Endpoint

```
GET /image-source/{imageSourceId}
```

`imageSourceId` is the identifier for the image source that you
want to get.

## Request

parameters

None

## Response

A [ImageSource](api-dt-ImageSource.md "api-dt-ImageSource.md")
object for the requested image source.

Format: JSON
