# Glossary for AWS User Notifications

| Term                         | Definition                                                                                                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AWS managed notifications    | An _AWS managed notification_ is a notification that is generated by default. For example, notifications about payment updates.                                                                        |
| Event                        | An _event_ indicates a change in an environment. AWS User Notifications uses Amazon EventBridge events to generate notifications. For example, an Amazon EC2 instance state changed to failed.         |
| Event pattern                | An _event pattern_ has the same structure as the events that they match. Rules use event patterns to select events and notify users. An event pattern either matches an event or it doesn't.           |
| Event rule                   | A _rule_ matches incoming events and generates a notification. When you create rules for events, User Notifications notifies you when it receives an event that matches the event pattern in the rule. |
| Notification Center          | A dedicated user interface of the AWS Management Console where users can configure and view notifications.                                                                                             |
| Notification configuration   | A logical container of event rules.                                                                                                                                                                    |
| Notification hub             | An account-level setting that you use to select the Regions where you want to store, process, and replicate your notifications.                                                                        |
| User-Configured Notification | A _user-configured notification_ is a notification generated by a user's notification configuration.                                                                                                   |
