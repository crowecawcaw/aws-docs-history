# Glossary for AWS User Notifications

| Term                         | Definition                                                                                                                                                                                                        |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AWS managed notifications    | An \*AWS managed notification<br>• is a notification that is generated by default. For example, notifications about payment updates.                                                                              |
| Event                        | An \*event<br>• indicates a change in an environment. AWS User Notifications uses<br>Amazon EventBridge events to generate notifications. For example, an Amazon EC2 instance state<br>changed to failed.         |
| Event pattern                | An \*event pattern<br>• has the same structure as the events that<br>they match. Rules use event patterns to select events and notify users. An event<br>pattern either matches an event or it doesn't.           |
| Event rule                   | A \*rule<br>• matches incoming events and generates a notification.<br>When you create rules for events, User Notifications notifies you when it receives an event that<br>matches the event pattern in the rule. |
| Notification Center          | A dedicated user interface of the AWS Management Console where users can configure and view<br>notifications.                                                                                                     |
| Notification configuration   | A logical container of event rules.                                                                                                                                                                               |
| Notification hub             | An account-level setting that you use to select the Regions where you want to<br>store, process, and replicate your notifications.                                                                                |
| User-Configured Notification | A \*user-configured notification<br>• is a notification generated by a user's notification configuration.                                                                                                         |
