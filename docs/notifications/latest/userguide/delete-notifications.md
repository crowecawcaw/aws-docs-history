

# Deleting notification configurations in AWS User Notifications
<a name="delete-notifications"></a>

You can stop receiving notifications by deleting notification configurations.

**To delete a configuration**

1. Open AWS User Notifications in the AWS Management Console.

1. In the navigation pane, choose **Notification configurations**.

1. Select the configuration you want to delete.

1. Choose **Delete**.

1. In the **Delete notification configuration?** dialog box, choose **Delete** again.
