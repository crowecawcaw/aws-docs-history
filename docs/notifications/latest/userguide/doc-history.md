

# Document history for the AWS User Notifications User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for User Notifications.

| Change | Description | Date | 
| --- |--- |--- |
| [AWS Billing and Cost Management added to AWS managed notifications](#doc-history) | You can now receive AWS managed notifications from AWS Billing and Cost Management, including sensitive events and attachments. For more information, see [AWS managed notifications in AWS User Notifications](https://docs.aws.amazon.com/notifications/latest/userguide/managed-notifications.html). | September 16, 2026 | 
| [AWS Marketplace Buyer added to AWS managed notifications](#doc-history) | You can now receive AWS managed notifications from AWS Marketplace – Buyer. For more information, see [AWS managed notifications in AWS User Notifications](https://docs.aws.amazon.com/notifications/latest/userguide/managed-notifications.html). | August 3, 2026 | 
| [AWS managed policies documentation added](#doc-history) | We documented which AWS managed policies include AWS User Notifications actions, and clarified the resource-level policy examples. For more information, see [Identity and Access Management for AWS User Notifications](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam.html). | April 16, 2026 | 
| [AWS managed notifications enabled by default for AWS Health](#doc-history) | We now enable AWS managed notifications for AWS Health by default in AWS accounts. If you previously disabled AWS managed notifications, your existing preferences remain unchanged. For more information, see [AWS managed notifications in AWS User Notifications](https://docs.aws.amazon.com/notifications/latest/userguide/managed-notifications.html). | September 15, 2025 | 
| [Organization notifications page added](#doc-history) | You can now manage notifications across AWS Organizations. For more information, see [Managing notifications across your organization](https://docs.aws.amazon.com/notifications/latest/userguide/managing-org-notifications.html). | September 2, 2025 | 
| [Managed policy updated](#doc-history) | The AWS managed policy `AWSUserNotificationsServiceLinkedRolePolicy` is updated. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html). | September 2, 2025 | 
| [Managed policy updated](#doc-history) | The AWS managed policy `AWSUserNotificationsServiceLinkedRolePolicy` is updated. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html). | January 15, 2025 | 
| [AWS managed notifications and Enabling AWS Organizations added](#doc-history) | Added [AWS managed notifications](https://docs.aws.amazon.com/notifications/latest/userguide/managed-notifications.html) and [enabling AWS Organizations](https://docs.aws.amazon.com/notifications/latest/userguide/uno-orgs.html) topics to describe managed notifications and how to use them with AWS Organizations | January 15, 2025 | 
| [Managed policy added](#doc-history) | Added the AWS managed policies for AWS User Notifications topic to describe the AWS managed policies for User Notifications and recent changes to those policies. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html) | April 20, 2023 | 
| [Initial release](#doc-history) | Initial release of the User Notifications User Guide. | April 20, 2023 |
