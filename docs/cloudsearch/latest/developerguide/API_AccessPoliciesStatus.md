# AccessPoliciesStatus

## Description

The configured access rules for the domain's document and search endpoints, and the current status of those rules.

## Contents

**Options**

Access rules for a domain's document or search service endpoints. For more information, see [Configuring Access for a Search Domain](configuring-access.md "configuring-access.md") in the _Amazon CloudSearch Developer Guide_. The maximum size of a policy document is 100 KB.

Type:
String

Required: Yes

**Status**

The status of domain configuration option.

Type:
[OptionStatus](API_OptionStatus.md "API_OptionStatus.md")

Required: Yes
