| Integration with Amazon CloudWatch and support for index field<br>statistics | You can now use Amazon CloudWatch to monitor your Amazon CloudSearch domains. CloudWatch is a<br>monitoring service for AWS cloud resources and the applications you run<br>on AWS. Amazon CloudSearch automatically sends metrics to CloudWatch so that you can gather<br>and analyze performance statistics. You can monitor these metrics by<br>using the Amazon CloudSearch console, or by using the CloudWatch console, AWS CLI, or AWS<br>SDKs. There is no charge for the Amazon CloudSearch metrics that are reported through<br>CloudWatch. For more information about using CloudWatch to monitor search domains,<br>see [Monitoring a Domain with<br>Amazon CloudWatch](cloudwatch-monitoring.md "cloudwatch-monitoring.md").<br>You also can now retrieve statistics against facet-enabled numeric<br>fields. Amazon CloudSearch can return the following statistics against indexed numeric<br>fields in the documents: count, min, max, mean, missing, stddev, sum,<br>and sumOfSquares. To learn more about index field statistics, see [Querying For More Information](querying-for-more-info.md "querying-for-more-info.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 5 March 2015      |

For more information about newly available<br>instance types and how to modify existing domains, see [Configuring Scaling Options in Amazon CloudSearch](configuring-scaling-options.md "configuring-scaling-options.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | 10 February 2015  |
| Support for Dynamic Fields                                                   | Dynamic fields provide a way to index documents without knowing in<br>advance exactly what fields they contain. A dynamic field's name defines<br>a pattern that contains a wildcard (\*) as the first, last, or only<br>character. Any unrecognized document field that matches the pattern is<br>configured with the dynamic field's indexing options. For more<br>information, see [Using Dynamic Fields in Amazon CloudSearch](using-dynamic-fields.md "using-dynamic-fields.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | 11 December 2014  |
| Enhanced Japanese Language Processing and CloudTrail Support                 | You can now control how Amazon CloudSearch tokenizes Japanese by<br>adding a custom Japanese tokenization dictionary to the analysis scheme<br>that you use for fields that contain Japanese. Configuring a custom<br>tokenization dictionary can improve search result accuracy by<br>facilitating indexing and retrieval of domain-specific phrases. To learn<br>more about using custom dictionaries, see [Customizing Japanese Tokenization](configuring-analysis-schemes.md#customizing-japanese-tokenization "configuring-analysis-schemes.md#customizing-japanese-tokenization"). You can also<br>index bigrams for Chinese, Japanese, and Korean. For more information,<br>see [Indexing Bigrams for Chinese, Japanese, and Korean](configuring-analysis-schemes.md#processing-cjk-fields "configuring-analysis-schemes.md#processing-cjk-fields").<br>You can also now use AWS CloudTrail to get a history of Amazon CloudSearch configuration<br>API calls and related events for your account. CloudTrail is a web service<br>that records your account's API calls and delivers the resulting log<br>files to your Amazon S3 bucket. You can also use CloudTrail to track changes that<br>were made to your AWS resources. For example, you can use the API call<br>history to perform a security analysis or troubleshoot operational<br>issues. CloudTrail also makes it easier for you to demonstrate compliance with<br>internal policies or regulatory standards. For more information, see the<br>[Security at Scale: Logging in AWS](https://d1.awsstatic.com/whitepapers/compliance/AWS_Security_at_Scale_Logging_in_AWS_Whitepaper.pdf "https://d1.awsstatic.com/whitepapers/compliance/AWS_Security_at_Scale_Logging_in_AWS_Whitepaper.pdf") whitepaper.
