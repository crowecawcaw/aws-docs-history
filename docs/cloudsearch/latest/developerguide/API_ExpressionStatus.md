# ExpressionStatus

## Description

The value of an `Expression` and its current status.

## Contents

[Expression](API_Expression.md "API_Expression.md")

Required: Yes

**Status**

The status of domain configuration option.

Type:
[OptionStatus](API_OptionStatus.md "API_OptionStatus.md")

Required: Yes
