# Configuration API Reference for Amazon CloudSearch

You use the Amazon CloudSearch Configuration API to create, configure, and manage search domains. For more information configuring search domains, see [Creating and Managing Search Domains](creating-managing-domains.md "creating-managing-domains.md").

The other APIs you use to interact with Amazon CloudSearch are:

- [Document Service API](document-service-api.md "document-service-api.md")—Submit the data you want to search.
- [Search API](search-api.md "search-api.md")—Search your domain.
