# Amazon CloudSearch API Reference

You use three APIs to interact with Amazon CloudSearch:

- [Configuration API](configuration-api.md "configuration-api.md")—Set up
  and manage your search domain.
- [Document Service API](document-service-api.md "document-service-api.md")—Submit the data you want to search.
- [Search API](search-api.md "search-api.md")—Search your domain.
