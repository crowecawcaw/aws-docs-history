# Post-deployment steps for AWS Launch Wizard Active

Directory

Post-deployment steps for AWS Launch Wizard for Active Directory.

## Run Windows Updates

###### To ensure that the operating systems on deployed servers and installed applications have

the latest Microsoft updates, run Windows Update on each server.

1. For each deployed server, create an RDP session.
2. Open the **Settings** application.
3. Open **Update & Security**.
4. Click **Check for updates**.
5. Install any updates, and restart your server, if necessary.
