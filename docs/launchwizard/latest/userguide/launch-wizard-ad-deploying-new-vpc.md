# Deploy Active Directory to a new VPC

(Console)

You can use AWS Launch Wizard to deploy Active Directory to a new virtual private cloud (VPC) as a
self-managed directory on Amazon Elastic Compute Cloud instances, extend your existing active directory into a
new VPC with Amazon EC2 instances, or create an AWS Directory Service for Microsoft Active Directory directory in a new VPC.
