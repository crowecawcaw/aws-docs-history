

# Kiro Permissions
<a name="kiro-permissions"></a>

 *Kiro Permissions* is Kiro’s core safety mechanism, and AWS Coding Plugin for SAP ABAP surfaces it in the Eclipse UI for the developer. By default, every tool call is gated through an explicit approval prompt. An approval covers exactly one tool call unless the approver chooses to apply a pattern to the approved resource. The permission model itself (the choices, the scopes, and how rules are matched) is built into Kiro. See [Permissions](https://kiro.dev/docs/permissions/) in the Kiro documentation.
