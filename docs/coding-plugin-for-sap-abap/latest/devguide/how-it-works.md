

# How AWS Coding Plugin for SAP ABAP works
<a name="how-it-works"></a>

 AWS Coding Plugin for SAP ABAP ("Coding Plugin") brings agentic development, powered by Kiro, to the Eclipse environment and SAP ABAP Development Tools (ADT) that you already use. It runs inside Eclipse as a plug-in. It adds an agentic chat window with Kiro-powered spec-driven development workflows, launches and manages Kiro CLI, connects it to a set of built-in MCP servers, and reaches your SAP system through the SAP ADT SDK over your existing ADT connection. By integrating with both Eclipse and Kiro, it makes Kiro a true partner of the human developer throughout the SAP ABAP development process.
