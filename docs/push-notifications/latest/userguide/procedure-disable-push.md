

# Disabling push channels
<a name="procedure-disable-push"></a>

Follow these directions to disable any of the push channels.

1. Open the AWS End User Messaging Push console at [https://console.aws.amazon.com/push-notifications/](https://console.aws.amazon.com/push-notifications/).

1. Choose the application that contains your push credentials.

1. (Optional) For **Apple Push Notification service (APNs)** clear **Enable**.

1. (Optional) For **Firebase Cloud Messaging (FCM)** clear **Enable**.

1. (Optional) For **Baidu Cloud Push** clear **Enable**.

1. (Optional) For **Amazon Device Messaging** clear **Enable**.

1. Choose **Save changes**.
