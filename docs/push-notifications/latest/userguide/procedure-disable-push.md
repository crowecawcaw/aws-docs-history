# Disabling push channels

Follow these directions to disable any of the push channels.

1. Open the AWS End User Messaging Push console at
   [https://console.aws.amazon.com/push-notifications/](https://console.aws.amazon.com/push-notifications/ "https://console.aws.amazon.com/push-notifications/").
2. Choose the application that contains your push credentials.
3. (Optional) For **Apple Push Notification service (APNs)** clear
   **Enable**.
4. (Optional) For **Firebase Cloud Messaging (FCM)** clear
   **Enable**.
5. (Optional) For **Baidu Cloud Push** clear
   **Enable**.
6. (Optional) For **Amazon Device Messaging** clear
   **Enable**.
7. Choose **Save changes**.
