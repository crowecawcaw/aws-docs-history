# Terminate an Amazon EMR cluster from Studio or

Studio Classic

The following procedure shows how to terminate an Amazon EMR cluster from a Studio or
Studio Classic notebook.

###### To terminate a cluster in a `Running` state, navigate to the list of

available Amazon EMR clusters.

1. In the Studio UI, scroll down to the **Data** node in
   the left navigation menu.
2. Navigate down to the **EMR Clusters** node. This opens up a
   page listing the Amazon EMR clusters that you have access to.
3. Select the name of the cluster that you want to terminate, and then choose
   **Terminate**.
4. This opens up a confirmation window informing you that any pending work or
   data on your cluster will be lost permanently after termination. Confirm by
   choosing **Terminate** again.
