# Supported data formats

When you create an input manifest file for a [built-in task types](sms-task-types.md "sms-task-types.md")
manually, your input data must be in one of the following support file formats for
the respective input data type. To learn about automated data setup, see [Automate data setup for labeling jobs](sms-console-create-manifest-file.md "sms-console-create-manifest-file.md").

###### Tip

When you use the automated data setup, additional data formats can be used
to generate an input manifest file for video frame and text based task
types.

| Named Entity Recognition, Text Classification (Single and<br>Multi-Label)                                                | Text                                                                 | Raw text                                                                                                                                                                                                        | ``<br>{"source": "`Lorem ipsum dolor sit amet`"}<br>``                                                                                                                    |
| Video Classification                                                                                                     | Video clips                                                          | .mp4, .ogg, and .webm                                                                                                                                                                                           | ``<br>{"source-ref": "`s3:///example-video.mp4`"}<br>``                                                                                                                   |
