# Sequence-to-Sequence Hyperparameters

The following table lists the hyperparameters that you can set when training with the
Amazon SageMaker AI Sequence-to-Sequence (seq2seq) algorithm.

| Parameter Name                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `batch_size`                       | Mini batch size for gradient descent.<br>**Optional**<br>Valid values: positive integer<br>Default value: 64                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `beam_size`                        | Length of the beam for beam search. Used during training for<br>computing `bleu` and used during inference.<br>**Optional**<br>Valid values: positive integer<br>Default value: 5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `bleu_sample_size`                 | Number of instances to pick from validation dataset to decode<br>and compute `bleu` score during training. Set to -1 to<br>use full validation set (if `bleu` is chosen as<br>`optimized_metric`).<br>**Optional**<br>Valid values: integer<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `bucket_width`                     | Returns (source,target) buckets up to<br>(`max_seq_len_source`,<br>`max_seq_len_target`). The longer side of the data<br>uses steps of `bucket_width` while the shorter side uses<br>steps scaled down by the average target/source length ratio. If one<br>sided reaches its maximum length before the other, width of extra<br>buckets on that side is fixed to that side of<br>`max_len`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 10                                                                                                                                                                                                                 |
| `bucketing_enabled`                | Set to `false` to disable bucketing, unroll to<br>maximum length.<br>**Optional**<br>Valid values: `true` or `false`<br>Default value: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `checkpoint_frequency_num_batches` | Checkpoint and evaluate every x batches. This checkpointing hyperparameter is passed to the<br>SageMaker AI's seq2seq algorithm for early stopping and retrieving the best<br>model. The algorithm's checkpointing runs locally in the algorithm's<br>training container and is not compatible with SageMaker AI checkpointing.<br>The algorithm temporarily saves checkpoints to a local path and<br>stores the best model artifact to the model output path in S3 after<br>the training job has stopped.<br>**Optional**<br>Valid values: positive integer<br>Default value: 1000                                                                                                 |
| `checkpoint_threshold`             | Maximum number of checkpoints model is allowed to not improve in `optimized_metric`<br>on validation dataset before training is stopped. This checkpointing<br>hyperparameter is passed to the SageMaker AI's seq2seq algorithm for early<br>stopping and retrieving the best model. The algorithm's<br>checkpointing runs locally in the algorithm's training container and<br>is not compatible with SageMaker AI checkpointing. The algorithm temporarily<br>saves checkpoints to a local path and stores the best model artifact<br>to the model output path in S3 after the training job has<br>stopped.<br>**Optional**<br>Valid values: positive integer<br>Default value: 3 |
| `clip_gradient`                    | Clip absolute gradient values greater than this. Set to<br>negative to disable.<br>**Optional**<br>Valid values: float<br>Default value: 1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `cnn_activation_type`              | The `cnn` activation type to be used.<br>**Optional**<br>Valid values: String. One of `glu`, `relu`,<br>`softrelu`, `sigmoid`, or<br>`tanh`.<br>Default value: `glu`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `cnn_hidden_dropout`               | Dropout probability for dropout between convolutional<br>layers.<br>**Optional**<br>Valid values: Float. Range in [0,1].<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `cnn_kernel_width_decoder`         | Kernel width for the `cnn` decoder.<br>**Optional**<br>Valid values: positive integer<br>Default value: 5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `cnn_kernel_width_encoder`         | Kernel width for the `cnn` encoder.<br>**Optional**<br>Valid values: positive integer<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `cnn_num_hidden`                   | Number of `cnn` hidden units for encoder and<br>decoder.<br>**Optional**<br>Valid values: positive integer<br>Default value: 512                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `decoder_type`                     | Decoder type.<br>**Optional**<br>Valid values: String. Either `rnn` or<br>`cnn`.<br>Default value: _rnn_                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `embed_dropout_source`             | Dropout probability for source side embeddings.<br>**Optional**<br>Valid values: Float. Range in [0,1].<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `embed_dropout_target`             | Dropout probability for target side embeddings.<br>**Optional**<br>Valid values: Float. Range in [0,1].<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `encoder_type`                     | Encoder type. The `rnn` architecture is based on<br>attention mechanism by Bahdanau et al. and _cnn_<br>architecture is based on Gehring et al.<br>**Optional**<br>Valid values: String. Either `rnn` or<br>`cnn`.<br>Default value: `rnn`                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `fixed_rate_lr_half_life`          | Half life for learning rate in terms of number of checkpoints<br>for `fixed_rate_`\<br>• schedulers.<br>**Optional**<br>Valid values: positive integer<br>Default value: 10                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `learning_rate`                    | Initial learning rate.<br>**Optional**<br>Valid values: float<br>Default value: 0.0003                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `loss_type`                        | Loss function for training.<br>**Optional**<br>Valid values: String. `cross-entropy`<br>Default value: `cross-entropy`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `lr_scheduler_type`                | Learning rate scheduler type. `plateau_reduce` means<br>reduce the learning rate whenever `optimized_metric` on<br>`validation_accuracy` plateaus. `inv_t` is<br>inverse time decay.<br>`learning_rate`/(1+`decay_rate`\*t)<br>**Optional**<br>Valid values: String. One of `plateau_reduce`,<br>`fixed_rate_inv_t`, or<br>`fixed_rate_inv_sqrt_t`.<br>Default value: `plateau_reduce`                                                                                                                                                                                                                                                                                              |
| `max_num_batches`                  | Maximum number of updates/batches to process. -1 for<br>infinite.<br>**Optional**<br>Valid values: integer<br>Default value: -1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `max_num_epochs`                   | Maximum number of epochs to pass through training data before<br>fitting is stopped. Training continues until this number of epochs<br>even if validation accuracy is not improving if this parameter is<br>passed. Ignored if not passed.<br>**Optional**<br>Valid values: Positive integer and less than or equal to<br>max_num_epochs.<br>Default value: none                                                                                                                                                                                                                                                                                                                    |
| `max_seq_len_source`               | Maximum length for the source sequence length. Sequences longer<br>than this length are truncated to this length.<br>**Optional**<br>Valid values: positive integer<br>Default value: 100                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `max_seq_len_target`               | Maximum length for the target sequence length. Sequences longer<br>than this length are truncated to this length.<br>**Optional**<br>Valid values: positive integer<br>Default value: 100                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `min_num_epochs`                   | Minimum number of epochs the training must run before it is<br>stopped via `early_stopping` conditions.<br>**Optional**<br>Valid values: positive integer<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `momentum`                         | Momentum constant used for `sgd`. Don't pass this<br>parameter if you are using `adam` or<br>`rmsprop`.<br>**Optional**<br>Valid values: float<br>Default value: none                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `num_embed_source`                 | Embedding size for source tokens.<br>**Optional**<br>Valid values: positive integer<br>Default value: 512                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `num_embed_target`                 | Embedding size for target tokens.<br>**Optional**<br>Valid values: positive integer<br>Default value: 512                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `num_layers_decoder`               | Number of layers for Decoder *rnn<br>• or<br>*cnn\*.<br>**Optional**<br>Valid values: positive integer<br>Default value: 1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `num_layers_encoder`               | Number of layers for Encoder `rnn` or<br>`cnn`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `optimized_metric`                 | Metrics to optimize with early stopping.<br>**Optional**<br>Valid values: String. One of `perplexity`,<br>`accuracy`, or `bleu`.<br>Default value: `perplexity`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `optimizer_type`                   | Optimizer to choose from.<br>**Optional**<br>Valid values: String. One of `adam`, `sgd`,<br>or `rmsprop`.<br>Default value: `adam`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `plateau_reduce_lr_factor`         | Factor to multiply learning rate with (for<br>`plateau_reduce`).<br>**Optional**<br>Valid values: float<br>Default value: 0.5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `plateau_reduce_lr_threshold`      | For `plateau_reduce` scheduler, multiply learning<br>rate with reduce factor if `optimized_metric` didn't<br>improve for this many checkpoints.<br>**Optional**<br>Valid values: positive integer<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `rnn_attention_in_upper_layers`    | Pass the attention to upper layers of _rnn_,<br>like<br>Google<br>NMT paper. Only applicable if more than one layer<br>is used.<br>**Optional**<br>Valid values: boolean (`true` or<br>`false`)<br>Default value: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `rnn_attention_num_hidden`         | Number of hidden units for attention layers. defaults to<br>`rnn_num_hidden`.<br>**Optional**<br>Valid values: positive integer<br>Default value: `rnn_num_hidden`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `rnn_attention_type`               | Attention model for encoders. `mlp` refers to concat<br>and bilinear refers to general from the<br>Luong<br>et al. paper.<br>**Optional**<br>Valid values: String. One of `dot`, `fixed`,<br>`mlp`, or `bilinear`.<br>Default value: `mlp`                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `rnn_cell_type`                    | Specific type of `rnn` architecture.<br>**Optional**<br>Valid values: String. Either `lstm` or<br>`gru`.<br>Default value: `lstm`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `rnn_decoder_state_init`           | How to initialize `rnn` decoder states from<br>encoders.<br>**Optional**<br>Valid values: String. One of `last`, `avg`,<br>or `zero`.<br>Default value: `last`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `rnn_first_residual_layer`         | First \*rnn<br>• layer to have a residual<br>connection, only applicable if number of layers in encoder or<br>decoder is more than 1.<br>**Optional**<br>Valid values: positive integer<br>Default value: 2                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `rnn_num_hidden`                   | The number of \*rnn<br>• hidden units for encoder and decoder. This must be a<br>multiple of 2 because the algorithm uses bi-directional Long Term<br>Short Term Memory (LSTM) by default.<br>**Optional**<br>Valid values: positive even integer<br>Default value: 1024                                                                                                                                                                                                                                                                                                                                                                                                            |
| `rnn_residual_connections`         | Add residual connection to stacked _rnn_.<br>Number of layers should be more than 1.<br>**Optional**<br>Valid values: boolean (`true` or<br>`false`)<br>Default value: `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `rnn_decoder_hidden_dropout`       | Dropout probability for hidden state that combines the context<br>with the \*rnn<br>• hidden state in the<br>decoder.<br>**Optional**<br>Valid values: Float. Range in [0,1].<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `training_metric`                  | Metrics to track on training on validation data.<br>**Optional**<br>Valid values: String. Either `perplexity` or<br>`accuracy`.<br>Default value: `perplexity`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `weight_decay`                     | Weight decay constant.<br>**Optional**<br>Valid values: float<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `weight_init_scale`                | Weight initialization scale (for `uniform` and<br>`xavier` initialization).<br>**Optional**<br>Valid values: float<br>Default value: 2.34                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `weight_init_type`                 | Type of weight initialization.<br>**Optional**<br>Valid values: String. Either `uniform` or<br>`xavier`.<br>Default value: `xavier`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `xavier_factor_type`               | Xavier factor type.<br>**Optional**<br>Valid values: String. One of `in`, `out`, or<br>`avg`.<br>Default value: `in`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
