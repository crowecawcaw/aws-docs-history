# Suspend your RSessions

The following procedure demonstrates how to suspend an RSession from the RStudio Launcher when using RStudio on Amazon SageMaker AI. For information about accessing the RStudio Launcher, see [Launch RSessions from the RStudio Launcher](rstudio-launcher.md "rstudio-launcher.md").

1. From the RStudio Launcher, identify the RSession that you want to suspend.
2. Select **Suspend** for the session.
