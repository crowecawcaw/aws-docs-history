# RStudio on Amazon SageMaker AI management

The following topics give information on managing RStudio on Amazon SageMaker AI. This includes
information about your RStudio environment configuration, user sessions, and necessary
resources. For information on how to use RStudio on SageMaker AI, see [RStudio on Amazon SageMaker AI user guide](rstudio-use.md "rstudio-use.md").

For information about creating a Amazon SageMaker AI domain with RStudio enabled,
see [Amazon SageMaker AI domain overview](gs-studio-onboard.md "gs-studio-onboard.md"). 

For information about the AWS Regions that RStudio on SageMaker AI is supported in, see [Supported Regions and Quotas](regions-quotas.md "regions-quotas.md").
