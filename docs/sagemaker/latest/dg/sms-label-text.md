# Text labeling with Ground Truth

Use Ground Truth to label text. Ground Truth supports labeling text for named entity recognition, single
label text classification, and multi-label text classification. The following topics give
information about these built-in task types, as well as instructions to help you create a
labeling job using that task type.

###### Tip

To learn more about supported file types and input data quotas, see [Input data](sms-data-input.md "sms-data-input.md").
