# LDA Hyperparameters

In the `CreateTrainingJob` request, you specify the training algorithm. You
can also specify algorithm-specific hyperparameters as string-to-string maps. The
following table lists the hyperparameters for the LDA training algorithm provided by
Amazon SageMaker AI. For more information, see [How LDA Works](lda-how-it-works.md "lda-how-it-works.md").

| Parameter Name    | Description                                                                                                                                                                                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `num_topics`      | The number of topics for LDA to find within the data.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                     |
| `feature_dim`     | The size of the vocabulary of the input document corpus.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                  |
| `mini_batch_size` | The total number of documents in the input document corpus.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                               |
| `alpha0`          | Initial guess for the concentration parameter: the sum of the<br>elements of the Dirichlet prior. Small values are more likely to<br>generate sparse topic mixtures and large values (greater than 1.0)<br>produce more uniform mixtures.<br>**Optional**<br>Valid values: Positive float<br>Default value: 1.0                             |
| `max_restarts`    | The number of restarts to perform during the Alternating Least<br>Squares (ALS) spectral decomposition phase of the algorithm. Can be<br>used to find better quality local minima at the expense of<br>additional computation, but typically should not be adjusted.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 10 |
| `max_iterations`  | The maximum number of iterations to perform during the ALS phase<br>of the algorithm. Can be used to find better quality minima at the<br>expense of additional computation, but typically should not be<br>adjusted.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 1000                                              |
| `tol`             | Target error tolerance for the ALS phase of the algorithm. Can be<br>used to find better quality minima at the expense of additional<br>computation, but typically should not be adjusted.<br>**Optional**<br>Valid values: Positive float<br>Default value: 1e-8                                                                           |
