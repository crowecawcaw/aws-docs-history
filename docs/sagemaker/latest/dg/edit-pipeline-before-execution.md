# Edit a pipeline

To make changes to a pipeline before running it, do the following:

1. Open SageMaker Studio by following the instructions in [Launch
   Amazon SageMaker Studio](studio-updated-launch.md "studio-updated-launch.md").
2. In the left navigation pane of Studio, select **Pipelines**.
3. Select a pipeline name to view details about the pipeline.
4. Choose the **Executions** tab.
5. Select the name of a pipeline execution.
6. Choose **Edit** to open the Pipeline Designer.
7. Update the edges between steps or the step configuration as required and click
   **Save**.

Saving a pipeline after editing automatically generates a new version number. 8. Choose **Run**.
