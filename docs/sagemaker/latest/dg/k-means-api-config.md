# K-Means Hyperparameters

In the [`CreateTrainingJob`](../APIReference/API_CreateTrainingJob.md "../APIReference/API_CreateTrainingJob.md")
request, you specify the training algorithm that you want to use. You can also specify
algorithm-specific hyperparameters as string-to-string maps. The following table lists
the hyperparameters for the k-means training algorithm provided by Amazon SageMaker AI. For more
information about how k-means clustering works, see [How K-Means Clustering Works](algo-kmeans-tech-notes.md "algo-kmeans-tech-notes.md").

| Parameter Name            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feature_dim`             | The number of features in the input data.<br>**Required**<br>Valid values: Positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `k`                       | The number of required clusters.<br>**Required**<br>Valid values: Positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `epochs`                  | The number of passes done over the training data.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 1                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `eval_metrics`            | A JSON list of metric types used to report a score for the model. Allowed values are<br>`msd` for Means Square Deviation and `ssd`<br>for Sum of Square Distance. If test data is provided, the score is<br>reported for each of the metrics requested.<br>**Optional**<br>Valid values: Either `[\"msd\"]` or<br>`[\"ssd\"]` or `[\"msd\",\"ssd\"]`<br>.<br>Default value: `[\"msd\"]`                                                                                                                                                                              |
| `extra_center_factor`     | The algorithm creates K centers = `num_clusters` \*<br>`extra_center_factor` as it runs and reduces the<br>number of centers from K to `k` when finalizing the<br>model.<br>**Optional**<br>Valid values: Either a positive integer or<br>`auto`.<br>Default value: `auto`                                                                                                                                                                                                                                                                                           |
| `half_life_time_size`     | Used to determine the weight given to an observation when<br>computing a cluster mean. This weight decays exponentially as more<br>points are observed. When a point is first observed, it is assigned<br>a weight of 1 when computing the cluster mean. The decay constant<br>for the exponential decay function is chosen so that after observing<br>`half_life_time_size` points, its weight is 1/2. If<br>set to 0, there is no decay.<br>**Optional**<br>Valid values: Non-negative integer<br>Default value: 0                                                 |
| `init_method`             | Method by which the algorithm chooses the initial cluster<br>centers. The standard k-means approach chooses them at random. An<br>alternative k-means++ method chooses the first cluster center at<br>random. Then it spreads out the position of the remaining initial<br>clusters by weighting the selection of centers with a probability<br>distribution that is proportional to the square of the distance of<br>the remaining data points from existing centers.<br>**Optional**<br>Valid values: Either `random` or<br>`kmeans++`.<br>Default value: `random` |
| `local_lloyd_init_method` | The initialization method for Lloyd's expectation-maximization<br>(EM) procedure used to build the final model containing<br>`k` centers.<br>**Optional**<br>Valid values: Either `random` or<br>`kmeans++`.<br>Default value: `kmeans++`                                                                                                                                                                                                                                                                                                                            |
| `local_lloyd_max_iter`    | The maximum number of iterations for Lloyd's<br>expectation-maximization (EM) procedure used to build the final<br>model containing `k` centers.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 300                                                                                                                                                                                                                                                                                                                                             |
| `local_lloyd_num_trials`  | The number of times the Lloyd's expectation-maximization (EM)<br>procedure with the least loss is run when building the final model<br>containing `k` centers.<br>**Optional**<br>Valid values: Either a positive integer or<br>`auto`.<br>Default value: `auto`                                                                                                                                                                                                                                                                                                     |
| `local_lloyd_tol`         | The tolerance for change in loss for early stopping of Lloyd's<br>expectation-maximization (EM) procedure used to build the final<br>model containing `k` centers.<br>**Optional**<br>Valid values: Float. Range in [0, 1].<br>Default value: 0.0001                                                                                                                                                                                                                                                                                                                 |
| `mini_batch_size`         | The number of observations per mini-batch for the data<br>iterator.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 5000                                                                                                                                                                                                                                                                                                                                                                                                                         |
