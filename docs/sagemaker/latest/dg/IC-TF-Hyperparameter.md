# Image Classification - TensorFlow

Hyperparameters

Hyperparameters are parameters that are set before a machine learning model begins
learning. The following hyperparameters are supported by the Amazon SageMaker AI built-in Image
Classification - TensorFlow algorithm. See [Tune an Image Classification - TensorFlow model](IC-TF-tuning.md "IC-TF-tuning.md") for information on hyperparameter tuning.

| Parameter Name                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `augmentation`                 | Set to `"True"` to apply<br>`augmentation_random_flip`,<br>`augmentation_random_rotation`, and<br>`augmentation_random_zoom` to the training data.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                                                                                                                                                                             |
| `augmentation_random_flip`     | Indicates which flip mode to use for data augmentation when<br>`augmentation` is set to `"True"`. For<br>more information, see [RandomFlip](https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomFlip "https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomFlip") in the TensorFlow documentation.<br>Valid values: string, any of the following:<br>(`"horizontal_and_vertical"`,<br>`"vertical"`, or `"None"`).<br>Default value: `"horizontal_and_vertical"`.                                                                                |
| `augmentation_random_rotation` | Indicates how much rotation to use for data augmentation when<br>`augmentation` is set to `"True"`. Values<br>represent a fraction of 2π. Positive values rotate<br>counterclockwise while negative values rotate clockwise.<br>`0` means no rotation. For more information, see<br>[RandomRotation](https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomRotation "https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomRotation") in the TensorFlow documentation.<br>Valid values: float, range: [`-1.0`,<br>`1.0`].<br>Default value: `0.2`. |
| `augmentation_random_zoom`     | Indicates how much vertical zoom to use for data augmentation when<br>`augmentation` is set to `"True"`.<br>Positive values zoom out while negative values zoom in.<br>`0` means no zoom. For more information, see [RandomZoom](https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomZoom "https://www.tensorflow.org/api_docs/python/tf/keras/layers/RandomZoom") in the TensorFlow documentation.<br>Valid values: float, range: [`-1.0`,<br>`1.0`].<br>Default value: `0.1`.                                                                             |
| `batch_size`                   | The batch size for training. For training on instances with<br>multiple GPUs, this batch size is used across the GPUs.<br>Valid values: positive integer.<br>Default value: `32`.                                                                                                                                                                                                                                                                                                                                                                                        |
| `beta_1`                       | The beta1 for the `"adam"` optimizer. Represents the<br>exponential decay rate for the first moment estimates. Ignored for<br>other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.9`.                                                                                                                                                                                                                                                                                                                                               |
| `beta_2`                       | The beta2 for the `"adam"` optimizer. Represents the<br>exponential decay rate for the second moment estimates. Ignored for<br>other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.999`.                                                                                                                                                                                                                                                                                                                                            |
| `binary_mode`                  | When `binary_mode` is set to `"True"`, the<br>model returns a single probability number for the positive class and<br>can use additional `eval_metric` options. Use only for<br>binary classification problems.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                                                                                                                |
| `dropout_rate`                 | The dropout rate for the dropout layer in the top classification layer.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.2`                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `early_stopping`               | Set to `"True"` to use early stopping logic during<br>training. If `"False"`, early stopping is not<br>used.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                                                                                                                                                                                                                   |
| `early_stopping_min_delta`     | The minimum change needed to qualify as an improvement. An absolute<br>change less than the value of `early_stopping_min_delta` does not<br>qualify as improvement. Used only when `early_stopping` is<br>set to `"True"`.Valid values: float, range:<br>[`0.0`, `1.0`].Default value:<br>`0.0`.                                                                                                                                                                                                                                                                         |
| `early_stopping_patience`      | The number of epochs to continue training with no improvement.<br>Used only when `early_stopping` is set to<br>`"True"`.<br>Valid values: positive integer.<br>Default value: `5`.                                                                                                                                                                                                                                                                                                                                                                                       |
| `epochs`                       | The number of training epochs.<br>Valid values: positive integer.<br>Default value: `3`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `epsilon`                      | The epsilon for `"adam"`, `"rmsprop"`,<br>`"adadelta"`, and `"adagrad"` optimizers.<br>Usually set to a small value to avoid division by 0. Ignored for<br>other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `1e-7`.                                                                                                                                                                                                                                                                                                                 |
| `eval_metric`                  | If `binary_mode` is set to `"False"`,<br>`eval_metric` can only be `"accuracy"`. If<br>`binary_mode` is `"True"`, select any of<br>the valid values. For more information, see [Metrics](https://www.tensorflow.org/api_docs/python/tf/keras/metrics "https://www.tensorflow.org/api_docs/python/tf/keras/metrics") in the TensorFlow documentation.<br>Valid values: string, any of the following:<br>(`"accuracy"`, `"precision"`,<br>`"recall"`, `"auc"`, or<br>`"prc"`).<br>Default value: `"accuracy"`.                                                             |
| `image_resize_interpolation`   | Indicates interpolation method used when resizing images. For more<br>information, see [image.resize](https://www.tensorflow.org/api_docs/python/tf/image/resize "https://www.tensorflow.org/api_docs/python/tf/image/resize") in the TensorFlow documentation.<br>Valid values: string, any of the following:<br>(`"bilinear"`, `"nearest"`,<br>`"bicubic"`, `"area"`,`"lanczos3"` , `"lanczos5"`,<br>`"gaussian"`, or<br>`"mitchellcubic"`).<br>Default value: `"bilinear"`.                                                                                           |
| `initial_accumulator_value`    | The starting value for the accumulators, or the per-parameter<br>momentum values, for the `"adagrad"` optimizer. Ignored<br>for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.0001`.                                                                                                                                                                                                                                                                                                                                          |
| `label_smoothing`              | Indicates how much to relax the confidence on label values. For<br>example, if `label_smoothing` is `0.1`, then<br>non-target labels are `0.1/num_classes` and target labels<br>are `0.9+0.1/num_classes`.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.1`.                                                                                                                                                                                                                                                                                    |
| `learning_rate`                | The optimizer learning rate. Valid values: float, range:<br>[`0.0`, `1.0`].Default value:<br>`0.001`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `momentum`                     | The momentum for `"sgd"`, `"nesterov"`, and<br>`"rmsprop"` optimizers. Ignored for other<br>optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.9`.                                                                                                                                                                                                                                                                                                                                                                                       |
| `optimizer`                    | The optimizer type. For more information, see [Optimizers](https://www.tensorflow.org/api_docs/python/tf/keras/optimizers "https://www.tensorflow.org/api_docs/python/tf/keras/optimizers") in the TensorFlow documentation.<br>Valid values: string, any of the following: (`"adam"`,<br>`"sgd"`, `"nesterov"`,<br>`"rmsprop"`, `"adagrad"` ,<br>`"adadelta"`).<br>Default value: `"adam"`.                                                                                                                                                                             |
| `regularizers_l2`              | The L2 regularization factor for the dense layer in the<br>classification layer.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `.0001`.                                                                                                                                                                                                                                                                                                                                                                                                            |
| `reinitialize_top_layer`       | If set to `"Auto"`, the top classification layer<br>parameters are re-initialized during fine-tuning. For incremental<br>training, top classification layer parameters are not re-initialized<br>unless set to `"True"`.<br>Valid values: string, any of the following: (`"Auto"`,<br>`"True"` or `"False"`).<br>Default value: `"Auto"`.                                                                                                                                                                                                                                |
| `rho`                          | The discounting factor for the gradient of the<br>`"adadelta"` and `"rmsprop"` optimizers.<br>Ignored for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.95`.                                                                                                                                                                                                                                                                                                                                                                  |
| `train_only_top_layer`         | If `"True"`, only the top classification layer<br>parameters are fine-tuned. If `"False"`, all model<br>parameters are fine-tuned.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                                                                                                                                                                                             |
