# Check the version of Code Editor

The following steps show how to check the version of your Code Editor application.

###### To check the Code Editor application version

1. Launch and run a Code Editor space and navigate to the Code Editor application UI. For more
   information, see [Launch a Code Editor application in Studio](code-editor-use-studio.md "code-editor-use-studio.md").
2. In the upper-left corner of the Code Editor UI, choose the menu button (
   ![Hamburger menu icon with three horizontal lines.](images/code-editor/code-editor-menu-icon.png)
   ). Then, choose **Help**. Then, choose
   **About**.
