# Object2Vec Hyperparameters

In the `CreateTrainingJob` request, you specify the training algorithm. You
can also specify algorithm-specific hyperparameters as string-to-string maps. The
following table lists the hyperparameters for the Object2Vec training algorithm.

| Parameter Name                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `enc0_max_seq_len`                 | The maximum sequence length for the enc0 encoder.<br>**Required**<br>Valid values: 1 ≤ integer ≤ 5000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `enc0_vocab_size`                  | The vocabulary size of enc0 tokens.<br>**Required**<br>Valid values: 2 ≤ integer ≤ 3000000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `bucket_width`                     | The allowed difference between data sequence length when bucketing<br>is enabled. To enable bucketing, specify a non-zero value for this<br>parameter.<br>**Optional**<br>Valid values: 0 ≤ integer ≤ 100<br>Default value: 0 (no bucketing)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `comparator_list`                  | A list used to customize the way in which two embeddings are<br>compared. The Object2Vec comparator operator layer takes the<br>encodings from both encoders as inputs and outputs a single vector.<br>This vector is a concatenation of subvectors. The string values<br>passed to the `comparator_list` and the order in which<br>they are passed determine how these subvectors are assembled. For<br>example, if `comparator_list="hadamard, concat"`, then<br>the comparator operator constructs the vector by concatenating the<br>Hadamard product of two encodings and the concatenation of two<br>encodings. If, on the other hand,<br>`comparator_list="hadamard"`, then the comparator<br>operator constructs the vector as the hadamard product of only two<br>encodings.<br>**Optional**<br>Valid values: A string that contains any combination of the names<br>of the three binary operators: `hadamard`,<br>`concat`, or `abs_diff`. The Object2Vec<br>algorithm currently requires that the two vector encodings have the<br>same dimension. These operators produce the subvectors as<br>follows:<br>• `hadamard`: Constructs a vector as the [Hadamard (element-wise) product](<https://en.wikipedia.org/wiki/Hadamard_product_(matrices)> "https://en.wikipedia.org/wiki/Hadamard_product_(matrices)") of two<br>encodings.<br>• `concat`: Constructs a vector as the<br>concatenation of two encodings.<br>• `abs_diff`: Constructs a vector as the absolute<br>difference between two encodings.<br>Default value: `"hadamard, concat, abs_diff"` |
| `dropout`                          | The dropout probability for network layers. \*Dropout<br>• is a form of regularization<br>used in neural networks that reduces overfitting by trimming<br>codependent neurons.<br>**Optional**<br>Valid values: 0.0 ≤<br>float<br>≤ 1.0<br>Default value: 0.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `early_stopping_patience`          | The number of consecutive epochs without improvement allowed<br>before early stopping is applied. Improvement is defined by with the<br>`early_stopping_tolerance` hyperparameter.<br>**Optional**<br>Valid values: 1 ≤ integer ≤ 5<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `early_stopping_tolerance`         | The reduction in the loss function that an algorithm must achieve<br>between consecutive epochs to avoid early stopping after the number<br>of consecutive epochs specified in the<br>`early_stopping_patience` hyperparameter<br>concludes.<br>**Optional**<br>Valid values: 0.000001 ≤ float ≤ 0.1<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `enc_dim`                          | The dimension of the output of the embedding layer.<br>**Optional**<br>Valid values: 4 ≤ integer ≤ 10000<br>Default value: 4096                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `enc0_network`                     | The network model for the enc0 encoder.<br>**Optional**<br>Valid values: `hcnn`, `bilstm`, or<br>`pooled_embedding`<br>• `hcnn`: A hierarchical convolutional neural<br>network.<br>• `bilstm`: A bidirectional long short-term<br>memory network (biLSTM), in which the signal propagates<br>backward and forward in time. This is an appropriate<br>recurrent neural network (RNN) architecture for sequential<br>learning tasks.<br>• `pooled_embedding`: Averages the embeddings of<br>all of the tokens in the input.<br>Default value: `hcnn`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `enc0_cnn_filter_width`            | The filter width of the convolutional neural network (CNN) enc0<br>encoder.<br>**Conditional**<br>Valid values: 1 ≤ integer ≤ 9<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `enc0_freeze_pretrained_embedding` | Whether to freeze enc0 pretrained embedding weights.<br>**Conditional**<br>Valid values: `True` or `False`<br>Default value: `True`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `enc0_layers`                      | The number of layers in the enc0 encoder.<br>**Conditional**<br>Valid values: `auto` or 1 ≤ integer ≤ 4<br>• For `hcnn`, `auto` means 4.<br>• For `bilstm`, `auto` means 1.<br>• For `pooled_embedding`, `auto`<br>ignores the number of layers.<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `enc0_pretrained_embedding_file`   | The filename of the pretrained enc0 token embedding file in the<br>auxiliary data channel.<br>**Conditional**<br>Valid values: String with alphanumeric characters, underscore, or<br>period. [A-Za-z0-9\.\\_]<br>Default value: "" (empty string)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `enc0_token_embedding_dim`         | The output dimension of the enc0 token embedding layer.<br>**Conditional**<br>Valid values: 2 ≤ integer ≤ 1000<br>Default value: 300                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `enc0_vocab_file`                  | The vocabulary file for mapping pretrained enc0 token embedding<br>vectors to numerical vocabulary IDs.<br>**Conditional**<br>Valid values: String with alphanumeric characters, underscore, or<br>period. [A-Za-z0-9\.\\_]<br>Default value: "" (empty string)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `enc1_network`                     | The network model for the enc1 encoder. If you want the enc1<br>encoder to use the same network model as enc0, including the<br>hyperparameter values, set the value to `enc0`.<br>NoteEven when the enc0 and enc1 encoder networks<br>have symmetric architectures, you can't shared parameter values<br>for these networks.<br>**Optional**<br>Valid values: `enc0`, `hcnn`,<br>`bilstm`, or `pooled_embedding`<br>• `enc0`: The network model for the enc0<br>encoder.<br>• `hcnn`: A hierarchical convolutional neural<br>network.<br>• `bilstm`: A bidirectional LSTM, in which the<br>signal propagates backward and forward in time. This is an<br>appropriate recurrent neural network (RNN) architecture for<br>sequential learning tasks.<br>• `pooled_embedding`: The averages of the<br>embeddings of all of the tokens in the input.<br>Default value: `enc0`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `enc1_cnn_filter_width`            | The filter width of the CNN enc1 encoder.<br>**Conditional**<br>Valid values: 1 ≤ integer ≤ 9<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `enc1_freeze_pretrained_embedding` | Whether to freeze enc1 pretrained embedding weights.<br>**Conditional**<br>Valid values: `True` or `False`<br>Default value: `True`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `enc1_layers`                      | The number of layers in the enc1 encoder.<br>**Conditional**<br>Valid values: `auto` or 1 ≤ integer ≤ 4<br>• For `hcnn`, `auto` means 4.<br>• For `bilstm`, `auto` means 1.<br>• For `pooled_embedding`, `auto`<br>ignores the number of layers.<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `enc1_max_seq_len`                 | The maximum sequence length for the enc1 encoder.<br>**Conditional**<br>Valid values: 1 ≤ integer ≤ 5000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `enc1_pretrained_embedding_file`   | The name of the enc1 pretrained token embedding file in the<br>auxiliary data channel.<br>**Conditional**<br>Valid values: String with alphanumeric characters, underscore, or<br>period. [A-Za-z0-9\.\\_]<br>Default value: "" (empty string)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `enc1_token_embedding_dim`         | The output dimension of the enc1 token embedding layer.<br>**Conditional**<br>Valid values: 2 ≤ integer ≤ 1000<br>Default value: 300                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `enc1_vocab_file`                  | The vocabulary file for mapping pretrained enc1 token embeddings<br>to vocabulary IDs.<br>**Conditional**<br>Valid values: String with alphanumeric characters, underscore, or<br>period. [A-Za-z0-9\.\\_]<br>Default value: "" (empty string)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `enc1_vocab_size`                  | The vocabulary size of enc0 tokens.<br>**Conditional**<br>Valid values: 2 ≤ integer ≤ 3000000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `epochs`                           | The number of epochs to run for training.<br>**Optional**<br>Valid values: 1 ≤ integer ≤ 100<br>Default value: 30                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `learning_rate`                    | The learning rate for training.<br>**Optional**<br>Valid values: 1.0E-6 ≤ float ≤ 1.0<br>Default value: 0.0004                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `mini_batch_size`                  | The batch size that the dataset is split into for an<br>`optimizer` during training.<br>**Optional**<br>Valid values: 1 ≤ integer ≤ 10000<br>Default value: 32                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `mlp_activation`                   | The type of activation function for the multilayer perceptron<br>(MLP) layer.<br>**Optional**<br>Valid values: `tanh`, `relu`, or<br>`linear`<br>• `tanh`: Hyperbolic tangent<br>• `relu`: Rectified linear unit (ReLU)<br>• `linear`: Linear function<br>Default value: `linear`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

| `mlp_layers`                       | The number of MLP layers in the network.<br>**Optional**<br>Valid values: 0 ≤ integer ≤ 10<br>Default value: 2                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `negative_sampling_rate`           | The ratio of negative samples, generated to assist in training the<br>algorithm, to positive samples that are provided by users. Negative<br>samples represent data that is unlikely to occur in reality and are<br>labelled negatively for training. They facilitate training a model<br>to discriminate between the positive samples observed and the<br>negative samples that are not. To specify the ratio of negative<br>samples to positive samples used for training, set the value to a<br>positive integer. For example, if you train the algorithm on input<br>data in which all of the samples are positive and set<br>`negative_sampling_rate` to 2, the Object2Vec<br>algorithm internally generates two negative samples per positive<br>sample. If you don't want to generate or use negative samples during<br>training, set the value to 0.<br>**Optional**<br>Valid values: 0 ≤ integer<br>Default value: 0 (off)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `num_classes`                      | The number of classes for classification training. Amazon SageMaker AI<br>ignores this hyperparameter for regression problems.<br>**Optional**<br>Valid values: 2 ≤ integer ≤ 30<br>Default value: 2                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `optimizer`                        | The optimizer type.<br>**Optional**<br>Valid<br>values: `adadelta`, `adagrad`,<br>`adam`, `sgd`, or<br>`rmsprop`.<br>• `adadelta`: A [per-dimension<br>learning rate method for gradient descent](https://arxiv.org/pdf/1212.5701.pdf "https://arxiv.org/pdf/1212.5701.pdf")<br>• `adagrad`: The [adaptive gradient algorithm](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#AdaGrad "https://en.wikipedia.org/wiki/Stochastic_gradient_descent#AdaGrad")<br>• `adam`: The [adaptive moment estimation algorithm](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam "https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam")<br>• `sgd`: [Stochastic gradient descent](https://en.wikipedia.org/wiki/Stochastic_gradient_descent "https://en.wikipedia.org/wiki/Stochastic_gradient_descent")<br>• `rmsprop`: [Root mean square<br>propagation](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#RMSProp "https://en.wikipedia.org/wiki/Stochastic_gradient_descent#RMSProp")<br>Default value: `adam`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `output_layer`                     | The type of output layer where you specify that the task is<br>regression or classification.<br>**Optional**<br>Valid values: `softmax` or<br>`mean_squared_error`<br>• `softmax`: The [Softmax function](https://en.wikipedia.org/wiki/Softmax_function "https://en.wikipedia.org/wiki/Softmax_function") used for<br>classification.<br>• `mean_squared_error`: The [MSE](https://en.wikipedia.org/wiki/Mean_squared_error "https://en.wikipedia.org/wiki/Mean_squared_error") used for regression.<br>Default value: `softmax`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `tied_token_embedding_weight`      | Whether to use a shared embedding layer for both encoders. That's<br>because both sentences and documents are composed of word tokens<br>from the same vocabulary.<br>**Optional**<br>Valid values: `True` or `False`<br>Default value: `False`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `token_embedding_storage_type`     | The mode of gradient update used during training: when the<br>`dense` mode is used, the optimizer calculates the<br>full gradient matrix for the token embedding layer even if most rows<br>of the gradient are zero-valued. When `sparse` mode is<br>used, the optimizer only stores rows of the gradient that are<br>actually being used in the mini-batch. If you want the algorithm to<br>perform lazy gradient updates, which calculate the gradients only in<br>the non-zero rows and which speed up training, specify<br>`row_sparse`. Setting the value to<br>`row_sparse` constrains the values available for<br>other hyperparameters, as follows:<br>• The `optimizer` hyperparameter must be set to<br>`adam`, `adagrad`, or<br>`sgd`. | `weight_decay`                     | The weight decay parameter used for optimization.<br>**Optional**<br>Valid values: 0 ≤ float ≤ 10000<br>Default value: 0 (no decay)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
