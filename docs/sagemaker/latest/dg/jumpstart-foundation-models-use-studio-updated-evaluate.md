# Evaluate a model in Studio

Amazon SageMaker JumpStart has integrations with SageMaker Clarify foundation model evaluations (FME) in
Studio. If a JumpStart model has built-in evaluation capabilities available, you
can choose **Evaluate** in the upper right corner of the model
detail page in the JumpStart Studio UI. For more information, see [Evaluate
a foundation model](jumpstart-foundation-models-evaluate.md "jumpstart-foundation-models-evaluate.md").
