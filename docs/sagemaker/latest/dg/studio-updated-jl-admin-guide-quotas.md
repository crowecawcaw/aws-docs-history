# Quotas

JupyterLab, has quotas for the following:

- The sum of all Amazon EBS volumes within an AWS account.
- The instance types that are available for your users.
- The number of instances for a particular that your users can launch.
  To get more storage and compute for your users, request an increase to your AWS
  quotas. For more information about requesting a quota increase, see [Amazon SageMaker AI endpoints and
  quotas](../../../general/latest/gr/sagemaker.md "../../../general/latest/gr/sagemaker.md").
