# Update a SageMaker HyperPod

cluster on training plans using the SageMaker AI console

You can update, remove, or add a training plan to an existing SageMaker HyperPod cluster using
the SageMaker AI console UI. To update the instance group of an SageMaker HyperPod cluster, follow these
steps:

1. Navigate to the SageMaker AI console at [https://console.aws.amazon.com/sagemaker/](https://console.aws.amazon.com/sagemaker/ "https://console.aws.amazon.com/sagemaker/").
2. In the left navigation pane, choose **Hyperpod**.
3. Navigate to the cluster's details page by following the hyperlink associated with the
   cluster name.
4. When configuring an instance group, you can update your plan to align with your new
   compute capacity needs.
