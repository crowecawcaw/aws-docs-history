# Worker instructions

This topic provides an overview of the Ground Truth worker portal and the tools available to
complete your 3D Point Cloud labeling task. First, select the type of task you are working
on from **Topics**.

For adjustment jobs, select the original labeling job task type that produced the labels
you are adjusting. Review and adjust the labels in your task as needed.

###### Important

It is recommended that you complete your task using a Google Chrome or Firefox web
browser.
