# Hyperparameter Tuning with Amazon SageMaker AI RL

You can run a hyperparameter tuning job to optimize hyperparameters for Amazon SageMaker AI RL.
The Roboschool example in the sample notebooks in the [SageMaker AI examples repository](https://github.com/awslabs/amazon-sagemaker-examples/tree/master/reinforcement_learning "https://github.com/awslabs/amazon-sagemaker-examples/tree/master/reinforcement_learning") shows how you can do this with RL Coach. The
launcher script shows how you can abstract parameters from the Coach preset file and
optimize them.
