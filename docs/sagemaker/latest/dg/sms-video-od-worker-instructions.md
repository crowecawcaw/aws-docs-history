# Video Frame Object

Detection Tasks

Video frame object detection tasks required you to classify and identify the
location of objects in video frames using annotations. A video frame is a still
image from a video scene.
You can use the worker UI to navigate between video frames and create annotations
to identify objects of interest. Use the following topics to learn how to
navigate your worker UI, use the tools provided, and complete your task.

It is recommended that you complete your task using a Google Chrome web browser.

###### Important

If you see annotations have already been added to one or more video frames
when you open your task, adjust those annotations and add additional annotations
as needed.
