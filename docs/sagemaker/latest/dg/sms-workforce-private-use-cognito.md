# Amazon Cognito Workforces

Create and manage your private workforce using Amazon Cognito when you want to create your
workforce using the Amazon SageMaker AI console or you don't want the overhead of managing worker
credentials and authentication. When you create a private workforce with Amazon Cognito, it
provides authentication, authorization, and user management for your private workers.
