# Edit your automatic configurations

After setting up a configuration, you might want to make changes to it. For automatic
dataset updates, you can update the Amazon S3 location for Canvas to import data, the
frequency of the updates, and the starting time. For automatic batch predictions, you
can change the dataset that the configuration tracks for updates. You can also turn off
the automation to temporarily pause updates until you choose to resume them.

The following sections show you how to update each type of configuration.

###### Note

You can’t change the frequency for automatic batch predictions because
automatic batch predictions run every time the target dataset is updated.
