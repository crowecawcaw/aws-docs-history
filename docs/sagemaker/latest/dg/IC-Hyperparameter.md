# Image Classification Hyperparameters

Hyperparameters are parameters that are set before a machine learning model begins
learning. The following hyperparameters are supported by the Amazon SageMaker AI built-in Image
Classification algorithm. See [Tune an Image Classification Model](IC-tuning.md "IC-tuning.md") for
information on image classification hyperparameter tuning.

| Parameter Name              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `num_classes`               | Number of output classes. This parameter defines the dimensions<br>of the network output and is typically set to the number of classes<br>in the dataset.<br>Besides multi-class classification, multi-label classification is<br>supported too. Please refer to [Input/Output Interface for the Image Classification<br>Algorithm](image-classification.md#IC-inputoutput "image-classification.md#IC-inputoutput") for details on how to work with<br>multi-label classification with augmented manifest files.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `num_training_samples`      | Number of training examples in the input dataset.<br>If there is a mismatch between this value and the number of<br>samples in the training set, then the behavior of the<br>`lr_scheduler_step` parameter is undefined and<br>distributed training accuracy might be affected.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `augmentation_type`         | Data augmentation type. The input images can be augmented in<br>multiple ways as specified below.<br>• `crop`: Randomly crop the image and flip the<br>image horizontally<br>• `crop_color`: In addition to ‘crop’, three<br>random values in the range [-36, 36], [-50, 50], and [-50,<br>50] are added to the corresponding Hue-Saturation-Lightness<br>channels respectively<br>• `crop_color_transform`: In addition to<br>`crop_color`, random transformations,<br>including rotation, shear, and aspect ratio variations are<br>applied to the image. The maximum angle of rotation is 10<br>degrees, the maximum shear ratio is 0.1, and the maximum<br>aspect changing ratio is 0.25.<br>**Optional**<br>Valid values: `crop`, `crop_color`, or<br>`crop_color_transform`.<br>Default value: no default value                                                                                                                                                                                                                                                                           |
| `beta_1`                    | The beta1 for `adam`, that is the exponential decay<br>rate for the first moment estimates.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.9                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `beta_2`                    | The beta2 for `adam`, that is the exponential decay<br>rate for the second moment estimates.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.999                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `checkpoint_frequency`      | Period to store model parameters (in number of epochs).<br>Note that all checkpoint files are saved as part of the final<br>model file "model.tar.gz" and uploaded to S3 to the specified model<br>location. This increases the size of the model file proportionally<br>to the number of checkpoints saved during training.<br>**Optional**<br>Valid values: positive integer no greater than<br>`epochs`.<br>Default value: no default value (Save checkpoint at the epoch that<br>has the best validation accuracy)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `early_stopping`            | `True` to use early stopping logic during training.<br>`False` not to use it.<br>**Optional**<br>Valid values: `True` or `False`<br>Default value: `False`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `early_stopping_min_epochs` | The minimum number of epochs that must be run before the early<br>stopping logic can be invoked. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 10                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `early_stopping_patience`   | The number of epochs to wait before ending training if no<br>improvement is made in the relevant metric. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `early_stopping_tolerance`  | Relative tolerance to measure an improvement in accuracy<br>validation metric. If the ratio of the improvement in accuracy<br>divided by the previous best accuracy is smaller than the<br>`early_stopping_tolerance` value set, early stopping<br>considers there is no improvement. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: 0 ≤ float ≤ 1<br>Default value: 0.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `epochs`                    | Number of training epochs.<br>**Optional**<br>Valid values: positive integer<br>Default value: 30                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `eps`                       | The epsilon for `adam` and `rmsprop`. It<br>is usually set to a small value to avoid division by 0.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 1e-8                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `gamma`                     | The gamma for `rmsprop`, the decay factor for the<br>moving average of the squared gradient.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.9                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `image_shape`               | The input image dimensions, which is the same size as the input layer of the network. The<br>format is defined as '`num_channels`, height, width'. The<br>image dimension can take on any value as the network can handle<br>varied dimensions of the input. However, there may be memory<br>constraints if a larger image dimension<br>is used. Pretrained models can use<br>only a fixed 224 x 224 image size. Typical image dimensions for<br>image classification are '3,224,224'. This is similar to the<br>ImageNet dataset.<br>For training, if any input image is smaller than this parameter in any dimension, training fails.<br>If an image is larger, a portion of the image is cropped, with the cropped area specified by this parameter.<br>If hyperparameter `augmentation_type` is set, random crop is taken; otherwise, central crop is taken.<br>At inference, input images are resized to the `image_shape` that was used during training. Aspect ratio is not preserved, and images are not cropped.<br>**Optional**<br>Valid values: string<br>Default value: ‘3,224,224’ |
| `kv_store`                  | Weight update synchronization mode during distributed training.<br>The weight updates can be updated either synchronously or<br>asynchronously across machines. Synchronous updates typically<br>provide better accuracy than asynchronous updates but can be slower.<br>See distributed training in MXNet for more details.<br>This parameter is not applicable to single machine<br>training.<br>• `dist_sync`: The gradients are synchronized<br>after every batch with all the workers. With<br>`dist_sync`, batch-size now means the batch<br>size used on each machine. So if there are n machines and we<br>use batch size b, then `dist_sync` behaves like<br>local with batch size n\*b<br>• `dist_async`: Performs asynchronous updates.<br>The weights are updated whenever gradients are received from<br>any machine and the weight updates are atomic. However, the<br>order is not guaranteed.<br>**Optional**<br>Valid values: `dist_sync` or<br>`dist_async`<br>Default value: no default value                                                                                |
| `learning_rate`             | Initial learning rate.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `lr_scheduler_factor`       | The ratio to reduce learning rate used in conjunction with the<br>`lr_scheduler_step` parameter, defined as<br>`lr_new` = `lr_old` \*<br>`lr_scheduler_factor`.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `lr_scheduler_step`         | The epochs at which to reduce the learning rate. As explained<br>in the `lr_scheduler_factor` parameter, the learning rate<br>is reduced by `lr_scheduler_factor` at these epochs. For<br>example, if the value is set to "10, 20", then the learning rate is<br>reduced by `lr_scheduler_factor` after 10th epoch and<br>again by `lr_scheduler_factor` after 20th epoch. The<br>epochs are delimited by ",".<br>**Optional**<br>Valid values: string<br>Default value: no default value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `mini_batch_size`           | The batch size for training. In a single-machine multi-GPU<br>setting, each GPU handles `mini_batch_size`/num_gpu<br>training samples. For the multi-machine training in dist_sync mode,<br>the actual batch size is `mini_batch_size`\*number of<br>machines. See MXNet docs for more details.<br>**Optional**<br>Valid values: positive integer<br>Default value: 32                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `momentum`                  | The momentum for `sgd` and `nag`, ignored<br>for other optimizers.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.9                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `multi_label`               | Flag to use for multi-label classification where each sample can<br>be assigned multiple labels. Average accuracy across all classes is<br>logged.<br>**Optional**<br>Valid values: 0 or 1<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `num_layers`                | Number of layers for the network. For data with large image<br>size (for example, 224x224<br>• like ImageNet), we suggest selecting<br>the number of layers from the set [18, 34, 50, 101, 152, 200]. For<br>data with small image size (for example, 28x28<br>• like CIFAR), we<br>suggest selecting the number of layers from the set [20, 32, 44, 56,<br>110]. The number of layers in each set is based on the ResNet paper.<br>For transfer learning, the number of layers defines the architecture<br>of base network and hence can only be selected from the set [18, 34,<br>50, 101, 152, 200].<br>**Optional**<br>Valid values: positive integer in [18, 34, 50, 101, 152, 200] or<br>[20, 32, 44, 56, 110]<br>Default value: 152                                                                                                                                                                                                                                                                                                                                                      |
| `optimizer`                 | The optimizer type. For more details of the parameters for the<br>optimizers, please refer to MXNet's API.<br>**Optional**<br>Valid values: One of `sgd`, `adam`,<br>`rmsprop`, or `nag`.<br>• `sgd`: [Stochastic gradient descent](https://en.wikipedia.org/wiki/Stochastic_gradient_descent "https://en.wikipedia.org/wiki/Stochastic_gradient_descent")<br>• `adam`: [Adaptive momentum estimation](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam "https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam")<br>• `rmsprop`: [Root mean square propagation](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#RMSProp "https://en.wikipedia.org/wiki/Stochastic_gradient_descent#RMSProp")<br>• `nag`: [Nesterov accelerated gradient](https://calculus.subwiki.org/wiki/Nesterov%27s_gradient_acceleration "https://calculus.subwiki.org/wiki/Nesterov%27s_gradient_acceleration")<br>Default value: `sgd`                                                                                                                                                  |
| `precision_dtype`           | The precision of the weights used for training. The algorithm<br>can use either single precision (`float32`) or half<br>precision (`float16`) for the weights. Using<br>half-precision for weights results in reduced memory<br>consumption.<br>**Optional**<br>Valid values: `float32` or `float16`<br>Default value: `float32`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `resize`                    | The number of pixels in the shortest side of an image after<br>resizing it for training. If the parameter is not set, then the<br>training data is used without resizing. The parameter should be larger<br>than both the width and height components of `image_shape`<br>to prevent training failure.<br>**Required\*<br>• when using image content<br>types<br>**Optional\*<br>• when using the RecordIO<br>content type<br>Valid values: positive integer<br>Default value: no default value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `top_k`                     | Reports the top-k accuracy during training. This parameter has<br>to be greater than 1, since the top-1 training accuracy is the same<br>as the regular training accuracy that has already been<br>reported.<br>**Optional**<br>Valid values: positive integer larger than 1.<br>Default value: no default value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `use_pretrained_model`      | Flag to use pre-trained model for training. If set to 1, then<br>the pretrained model with the corresponding number of layers is<br>loaded and used for training. Only the top FC layer are<br>reinitialized with random weights. Otherwise, the network is trained<br>from scratch.<br>**Optional**<br>Valid values: 0 or 1<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `use_weighted_loss`         | Flag to use weighted cross-entropy loss for multi-label<br>classification (used only when `multi_label` = 1), where<br>the weights are calculated based on the distribution of<br>classes.<br>**Optional**<br>Valid values: 0 or 1<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `weight_decay`              | The coefficient weight decay for `sgd` and<br>`nag`, ignored for other optimizers.<br>**Optional**<br>Valid values: float. Range in [0, 1].<br>Default value: 0.0001                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
