# Object Detection Hyperparameters

In the [`CreateTrainingJob`](../APIReference/API_CreateTrainingJob.md "../APIReference/API_CreateTrainingJob.md") request, you specify the training algorithm
that you want to use. You can also specify algorithm-specific hyperparameters that are
used to help estimate the parameters of the model from a training dataset. The following
table lists the hyperparameters provided by Amazon SageMaker AI for training the object detection
algorithm. For more information about how object training works, see [How Object Detection Works](algo-object-detection-tech-notes.md "algo-object-detection-tech-notes.md").

| Parameter Name              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `num_classes`               | The number of output classes. This parameter defines the<br>dimensions of the network output and is typically set to the number<br>of classes in the dataset.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `num_training_samples`      | The number of training examples in the input dataset.<br>NoteIf there is a mismatch between this value and the number of<br>samples in the training set, then the behavior of the<br>`lr_scheduler_step` parameter will be undefined<br>and distributed training accuracy may be affected.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `base_network`              | The base network architecture to use.<br>**Optional**<br>Valid values: 'vgg-16' or 'resnet-50'<br>Default value: 'vgg-16'                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `early_stopping`            | `True` to use early stopping logic during training.<br>`False` not to use it.<br>**Optional**<br>Valid values: `True` or `False`<br>Default value: `False`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `early_stopping_min_epochs` | The minimum number of epochs that must be run before the early<br>stopping logic can be invoked. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 10                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `early_stopping_patience`   | The number of epochs to wait before ending training if no<br>improvement, as defined by the `early_stopping_tolerance`<br>hyperparameter, is made in the relevant metric. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: positive integer<br>Default value: 5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `early_stopping_tolerance`  | The tolerance value that the relative improvement in<br>`validation:mAP`, the mean average precision (mAP),<br>is required to exceed to avoid early stopping. If the ratio of the<br>change in the mAP divided by the previous best mAP is smaller than<br>the `early_stopping_tolerance` value set, early stopping<br>considers that there is no improvement. It is used only when<br>`early_stopping` = `True`.<br>**Optional**<br>Valid values: 0 ≤ float ≤ 1<br>Default value: 0.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `image_shape`               | The image size for input images. We rescale the input image to a<br>square image with this size. We recommend using 300 and 512 for<br>better performance.<br>**Optional**<br>Valid values: positive integer ≥300<br>Default: 300                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `epochs`                    | The number of training epochs.<br>**Optional**<br>Valid values: positive integer<br>Default: 30                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `freeze_layer_pattern`      | The regular expression (regex) for freezing layers in the base<br>network. For example, if we set `freeze_layer_pattern` =<br>`"^(conv1\_                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | conv2*).\*"`, then any layers with a name<br>that contains `"conv1*"`or`"conv2\_"` are<br>frozen, which means that the weights for these layers are not<br>updated during training. The layer names can be found in the network<br>symbol files [vgg16-symbol.json](http://data.mxnet.io/models/imagenet/vgg/vgg16-symbol.json "http://data.mxnet.io/models/imagenet/vgg/vgg16-symbol.json ") and [resnet-50-symbol.json](http://data.mxnet.io/models/imagenet/resnet/50-layers/resnet-50-symbol.json "http://data.mxnet.io/models/imagenet/resnet/50-layers/resnet-50-symbol.json").<br>Freezing a layer means that its weights can not be modified further.<br>This can reduce training time significantly in exchange for modest<br>losses in accuracy. This technique is commonly used in transfer<br>learning where the lower layers in the base network do not need to<br>be retrained.<br>**Optional**<br>Valid values: string<br>Default: No layers frozen. |
| `kv_store`                  | The weight update synchronization mode used for distributed<br>training. The weights can be updated either synchronously or<br>asynchronously across machines. Synchronous updates typically<br>provide better accuracy than asynchronous updates but can be slower.<br>See the [Distributed Training](https://mxnet.apache.org/api/faq/distributed_training "https://mxnet.apache.org/api/faq/distributed_training") MXNet tutorial for details.<br>NoteThis parameter is not applicable to single machine<br>training.<br>**Optional**<br>Valid values: `'dist_sync'` or<br>`'dist_async'`<br>• `'dist_sync'`: The gradients are synchronized<br>after every batch with all the workers. With<br>`'dist_sync'`, batch-size now means the batch<br>size used on each machine. So if there are n machines and we<br>use batch size b, then dist_sync behaves like a single<br>machine with batch size n\*b.<br>• `'dist_async'`: Performs asynchronous updates.<br>The weights are updated whenever gradients are received from<br>any machine and the weight updates are atomic. However, the<br>order is not guaranteed.<br>Default: - |
| `label_width`               | The force padding label width used to sync across training and<br>validation data. For example, if one image in the data contains at<br>most 10 objects, and each object's annotation is specified with 5<br>numbers, [class\_id, left, top, width, height], then the<br>`label_width` should be no smaller than (10\*5 +<br>header information length). The header information length is usually<br>2. We recommend using a slightly larger `label_width` for<br>the training, such as 60 for this example.<br>**Optional**<br>Valid values: Positive integer large enough to accommodate the<br>largest annotation information length in the data.<br>Default: 350                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `learning_rate`             | The initial learning rate.<br>**Optional**<br>Valid values: float in (0, 1]<br>Default: 0.001                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `lr_scheduler_factor`       | The ratio to reduce learning rate. Used in conjunction with the<br>`lr_scheduler_step` parameter defined as<br>`lr_new` = `lr_old` \*<br>`lr_scheduler_factor`.<br>**Optional**<br>Valid values: float in (0, 1)<br>Default: 0.1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `lr_scheduler_step`         | The epochs at which to reduce the learning rate. The learning rate<br>is reduced by `lr_scheduler_factor` at epochs listed in a<br>comma-delimited string: "epoch1, epoch2, ...". For example, if the<br>value is set to "10, 20" and the `lr_scheduler_factor` is<br>set to 1/2, then the learning rate is halved after 10th epoch and<br>then halved again after 20th epoch.<br>**Optional**<br>Valid values: string<br>Default: empty string                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `mini_batch_size`           | The batch size for training. In a single-machine multi-gpu<br>setting, each GPU handles<br>`mini_batch_size`/`num_gpu` training<br>samples. For the multi-machine training in `dist_sync`<br>mode, the actual batch size is `mini_batch_size`\*number<br>of machines. A large `mini_batch_size` usually leads to<br>faster training, but it may cause out of memory problem. The memory<br>usage is related to `mini_batch_size`,<br>`image_shape`, and `base_network`<br>architecture. For example, on a single p3.2xlarge instance, the<br>largest `mini_batch_size` without an out of memory error<br>is 32 with the base_network set to "resnet-50" and an<br>`image_shape` of 300. With the same instance, you can<br>use 64 as the `mini_batch_size` with the base network<br>`vgg-16` and an `image_shape` of<br>300.<br>**Optional**<br>Valid values: positive integer<br>Default: 32                                                                                                                                                                                                                                            |
| `momentum`                  | The momentum for `sgd`. Ignored for other<br>optimizers.<br>**Optional**<br>Valid values: float in (0, 1]<br>Default: 0.9                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `nms_threshold`             | The non-maximum suppression threshold.<br>**Optional**<br>Valid values: float in (0, 1]<br>Default: 0.45                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `optimizer`                 | The optimizer types. For details on optimizer values, see [MXNet's<br>API](https://mxnet.apache.org/api/python/docs/api/ "https://mxnet.apache.org/api/python/docs/api/").<br>**Optional**<br>Valid values: ['sgd', 'adam', 'rmsprop', 'adadelta']<br>Default: 'sgd'                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `overlap_threshold`         | The evaluation overlap threshold.<br>**Optional**<br>Valid values: float in (0, 1]<br>Default: 0.5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `use_pretrained_model`      | Indicates whether to use a pre-trained model for training. If set<br>to 1, then the pre-trained model with corresponding architecture is<br>loaded and used for training. Otherwise, the network is trained from<br>scratch.<br>**Optional**<br>Valid values: 0 or 1<br>Default: 1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `weight_decay`              | The weight decay coefficient for `sgd` and<br>`rmsprop`. Ignored for other optimizers.<br>**Optional**<br>Valid values: float in (0, 1)<br>Default: 0.0005                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
