# Connection parameters

The following tables detail the supported Python properties for AWS Glue connections per data
store.

## Amazon Redshift connection parameters

The following Python connection parameters are supported by AWS Glue connections to
Amazon Redshift.

| Key                                 | Type                                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Constraints                            | Required |
| ----------------------------------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | -------- |
| `auto_create`                       | Type: `boolean`                               | Indicates whether the user should be created if they do not exist. Defaults to<br>`false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `true`, `false`                        | No       |
| `aws_secret_arn`                    | Type: `string`                                | The ARN of the secret used to retrieve the additional parameters for the<br>connection.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Valid<br>ARN                           | No       |
| `cluster_identifier`                | Type: `string`<br>• maxLength: 63             | The cluster identifier of the Amazon Redshift cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | ^(?!.\*—)[a-z][a-z0-9-]{0,61}[a-z0-9]$ | No       |
| `database`                          | Type: `string`<br>• maxLength: 127            | The name of the database to connect<br>to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                        | No       |
| `database_metadata_current_db_only` | Type: `boolean`                               | Indicates if the application supports multi-database datashare catalogs. | `host`                              | Type: `string`<br>• maxLength: 256            | The hostname of the Amazon Redshift cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |                                        | No       |
| `iam`                               | Type: `boolean`                               | Flag to enable or disable IAM based authentication for a connection. | `iam_disable_cache`                 | Type: `boolean`                               | This option specifies whether the IAM credentials are cached. Defaults to<br>`true`. ## Athena connection parameters

The following Python connection parameters are supported by AWS Glue connections to
Athena.

| Key                     | Type                                                 | Description                                                                                                                                                                                                                                                      | Constraints                                                                                       | Required                                            |
| ----------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `aws_access_key_id`     | Type: `string`<br>• maxLength: 256                   | Specifies an AWS access key associated with an IAM account. We<br>recommend storing this information in the `aws_secret`.                                                                                                                                        | Length 16-128                                                                                     | No                                                  |
| `aws_secret_access_key` | Type: `string`<br>• maxLength: 256                   | Secret part of an AWS access key. We recommend storing this<br>information in the `aws_secret`.                                                                                                                                                                  |                                                                                                   | No                                                  |
| `aws_secret_arn`        | Type: `string`                                       | The ARN of the secret used to retrieve the additional parameters for the<br>connection.                                                                                                                                                                          | Valid ARN                                                                                         | No                                                  |
| `catalog_name`          | Type: `string`<br>• maxLength: 256                   | The catalog that contains the databases and the tables that are accessed with the<br>driver. For information about catalogs, see [DataCatalog](../../../athena/latest/APIReference/API_DataCatalog.md "../../../athena/latest/APIReference/API_DataCatalog.md"). |                                                                                                   | No                                                  |
| `duration_seconds`      | Type: `number`                                       | The duration, in seconds, of the role session. This setting can have a value from<br>1 hour to 12 hours. By default the duration is set to 3600 seconds (1 hour).                                                                                                | Range from 900 seconds (15 minutes) up to the maximum session duration setting<br>for the<br>role | No                                                  |
| `encryption_option`     | Type: enum[`SSE_S3`, `SSE_KMS`, `CSE_KMS`,<br>null]) | Encryption at rest for Amazon S3. See the \*Encryption at<br>rest<br>• section in [Athena guide](../../../athena/latest/ug/encryption.md "../../../athena/latest/ug/encryption.md").                                                                             | `SSE_S3`, `SSE_KMS`, `CSE_KMS`                                                                    | No                                                  |
| `kms_key`               | Type: `string`<br>• maxLength: 256                   | AWS KMS key if using `CSE_KMS` in<br>`encrytion_option`.                                                                                                                                                                                                         |                                                                                                   | No                                                  |
| `poll_interval`         | Type: `number`                                       | Interval in seconds to poll the status of query results in Athena.                                                                                                                                                                                               |                                                                                                   | No                                                  |
| `profile_name`          | Type: `string`<br>• maxLength: 256                   | The name of the AWS configuration profile whose credentials should<br>be used to authenticate the request to Athena.                                                                                                                                             |                                                                                                   | No                                                  |
| `region_name`           | Type: `string`                                       | The AWS Region where queries are run.                                                                                                                                                                                                                            | Valid AWS Region                                                                                  | No                                                  |
| `result_reuse_enable`   | Type: `boolean`                                      | Enable the reuse of previous query result.                                                                                                                                                                                                                       | `true`, `false`                                                                                   | No                                                  |
| `result_reuse_minutes`  | Type: `integer`                                      | Specifies, in minutes, the maximum age of a previous query result that Athena<br>should consider for reuse. The default is 60.                                                                                                                                   | >= 1                                                                                              | No                                                  |
| `role_arn`              | Type: `string`                                       | Role to be used for running queries.                                                                                                                                                                                                                             | Valid<br>ARN                                                                                      | No                                                  |
| `schema_name`           | Type: `string`<br>• maxLength: 256                   | Name of the default schema to use for the database.                                                                                                                                                                                                              |                                                                                                   | No                                                  |
| `s3_staging_dir`        | Type: `string`<br>• maxLength: 1024                  | The location in Amazon S3 where the query results are stored.                                                                                                                                                                                                    |                                                                                                   | Either `s3_staging_dir` or `work_group` is required |
| `work_group`            | Type: `string`                                       | The workgroup in which queries will run. ## Snowflake connection parameters

The following Python connection parameters are supported by AWS Glue connections to
Snowflake.

Snowflake connection parameters

| Key                           | Type                               | Description                                                                                                                                                                                                                                                                                                  | Constraints                                           | Required |
| ----------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- | -------- |
| `account`                     | Type: `string`<br>• maxLength: 256 | The Snowflake account identifier. The account identifier does not include the<br>`snowflakecomputing.com` suffix.                                                                                                                                                                                            |                                                       | Yes      |
| `arrow_number_to_decimal`     | Type: `boolean`                    | False by default, which means that NUMBER column values are returned as<br>double-precision floating point numbers (`float64`). Set this to True to<br>return DECIMAL column values as decimal numbers (`decimal.Decimal`) when<br>calling the `fetch_pandas_all()` and `fetch_pandas_batches()`<br>methods. | `true`, `false`                                       | No       |
| `autocommit`                  | Type: `boolean`                    | Defaults to `false`, which honors the Snowflake parameter<br>`AUTOCOMMIT`. Set to `true` or `false` to enable or<br>disable the `autocommit` mode in the session, respectively.                                                                                                                              | `true`, `false`                                       | No       |
| `aws_secret_arn`              | Type: `string`                     | The ARN of the secret used to retrieve the additional parameters for the<br>connection.                                                                                                                                                                                                                      | Valid ARN                                             | No       |
| `client_prefetch_threads`     | Type: `integer`                    | The number of threads used to download the result sets (4 by default). Increasing<br>the value improves the fetch performance but requires more memory.                                                                                                                                                      |                                                       | No       |
| `database`                    | Type: `string`<br>• maxLength: 256 | The name of the default database to use.                                                                                                                                                                                                                                                                     |                                                       | No       |
| `login_timeout`               | Type: `integer`                    | The timeout in seconds for the login request. Defaults to 60 seconds. The login<br>request gives up after the timeout length if the HTTP response is not<br>`success`.                                                                                                                                       |                                                       | No       |
| `network_timeout`             | Type: `integer`                    | The timeout in seconds for all other operations. Defaults to `none`<br>(infinite). A general request gives up after the timeout length if the HTTP response<br>is not `success`.                                                                                                                             |                                                       | No       |
| `paramstyle`                  | Type: `string`<br>• maxLength: 256 | Placeholder syntaxes used for parameter substitution when executing SQL queries<br>from Python code. Defaults to `pyformat` for client side binding. Specify<br>`qmark` or `numeric` to change the bind variable formats for<br>server side binding.                                                         |                                                       | No       |
| `role`                        | Type: `string`<br>• maxLength: 256 | The name of the default role to use.                                                                                                                                                                                                                                                                         |                                                       | No       |
| `schema`                      | Type: `string`<br>• maxLength: 256 | The name of the default schema to use for the database.                                                                                                                                                                                                                                                      |                                                       | No       |
| `timezone`                    | Type: `string`<br>• maxLength: 128 | None by default, which honors the Snowflake parameter `TIMEZONE`. Set<br>to a valid time zone (such as `America/Los_Angeles`) to set the session<br>time zone.                                                                                                                                               | Timezone in a format similar to `America/Los_Angeles` | No       |
| `validate_default_parameters` | Type: `boolean`                    | Set to `true` to raise an exception if the specified database, schema,<br>or warehouse doesn’t exist. Defaults to `false`.                                                                                                                                                                                   |                                                       | No       |
| `warehouse`                   | Type: `string`<br>• maxLength: 256 | The name of the default warehouse to use.                                                                                                                                                                                                                                                                    |                                                       | No       |
