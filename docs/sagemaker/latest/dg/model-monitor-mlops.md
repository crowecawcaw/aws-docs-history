# SageMaker Model Monitor

Once a model is in production, you can monitor its performance in real time with Amazon SageMaker Model Monitor.
Model Monitor helps you maintain model quality by detecting violations of user-defined thresholds
for data quality, model quality, bias drift and feature attribution drift. In addition,
you can configure alerts so you can troubleshoot violations as they arise and promptly
initiate retraining. Model Monitor is integrated with SageMaker Clarify to improve visibility into potential
bias.

To learn about SageMaker Model Monitor, see [Data and model quality monitoring with Amazon SageMaker Model Monitor](model-monitor.md "model-monitor.md").
