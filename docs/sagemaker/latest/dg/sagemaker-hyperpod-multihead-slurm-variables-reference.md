# Reviewing environment

variables reference

The following environment variables are defined and used in the tutorial of [Setting up multiple controller
nodes for a SageMaker HyperPod Slurm cluster](sagemaker-hyperpod-multihead-slurm-setup.md "sagemaker-hyperpod-multihead-slurm-setup.md"). These environment variables are
only available in the current session unless explicitly preserved. They are defined
using the `$variable_name` syntax. Variables with key/value pairs
represent AWS-created resources, while variables without keys are user-defined.
