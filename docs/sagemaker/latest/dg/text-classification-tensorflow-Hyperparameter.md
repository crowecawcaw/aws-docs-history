# Text Classification - TensorFlow

Hyperparameters

Hyperparameters are parameters that are set before a machine learning model begins
learning. The following hyperparameters are supported by the Amazon SageMaker AI built-in Object
Detection - TensorFlow algorithm. See [Tune a Text Classification -
TensorFlow model](text-classification-tensorflow-tuning.md "text-classification-tensorflow-tuning.md") for information on
hyperparameter tuning.

| Parameter Name              | Description                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `batch_size`                | The batch size for training. For training on instances with<br>multiple GPUs, this batch size is used across the GPUs.<br>Valid values: positive integer.<br>Default value: `32`.                                                                                                                                                                                                                   |
| `beta_1`                    | The beta1 for the `"adam"` and `"adamw"`<br>optimizers. Represents the exponential decay rate for the first<br>moment estimates. Ignored for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.9`.                                                                                                                                                           |
| `beta_2`                    | The beta2 for the `"adam"` and `"adamw"`<br>optimizers. Represents the exponential decay rate for the second<br>moment estimates. Ignored for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.999`.                                                                                                                                                        |
| `dropout_rate`              | The dropout rate for the dropout layer in the top classification layer. Used only when<br>`reinitialize_top_layer` is set to<br>`"True"`.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.2`                                                                                                                                                                                 |
| `early_stopping`            | Set to `"True"` to use early stopping logic during<br>training. If `"False"`, early stopping is not<br>used.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                                              |
| `early_stopping_min_delta`  | The minimum change needed to qualify as an improvement. An absolute<br>change less than the value of `early_stopping_min_delta` does<br>not qualify as improvement. Used only when `early_stopping`<br>is set to `"True"`.Valid values: float, range:<br>[`0.0`, `1.0`].Default value:<br>`0.0`.                                                                                                    |
| `early_stopping_patience`   | The number of epochs to continue training with no improvement.<br>Used only when `early_stopping` is set to<br>`"True"`.<br>Valid values: positive integer.<br>Default value: `5`.                                                                                                                                                                                                                  |
| `epochs`                    | The number of training epochs.<br>Valid values: positive integer.<br>Default value: `10`.                                                                                                                                                                                                                                                                                                           |
| `epsilon`                   | The epsilon for `"adam"`, `"rmsprop"`,<br>`"adadelta"`, and `"adagrad"` optimizers.<br>Usually set to a small value to avoid division by 0. Ignored for<br>other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `1e-7`.                                                                                                                                            |
| `initial_accumulator_value` | The starting value for the accumulators, or the per-parameter<br>momentum values, for the `"adagrad"` optimizer. Ignored<br>for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.0001`.                                                                                                                                                                     |
| `learning_rate`             | The optimizer learning rate. Valid values: float, range:<br>[`0.0`, `1.0`].Default value:<br>`0.001`.                                                                                                                                                                                                                                                                                               |
| `momentum`                  | The momentum for the `"sgd"` and<br>`"nesterov"` optimizers. Ignored for other<br>optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.9`.                                                                                                                                                                                                                            |
| `optimizer`                 | The optimizer type. For more information, see [Optimizers](https://www.tensorflow.org/api_docs/python/tf/keras/optimizers "https://www.tensorflow.org/api_docs/python/tf/keras/optimizers") in the TensorFlow documentation.<br>Valid values: string, any of the following: (`"adamw"`,<br>`"adam"`, `"sgd"`,<br>`"nesterov"`, `"rmsprop"`,`"adagrad"` , `"adadelta"`).<br>Default value: `"adam"`. |
| `regularizers_l2`           | The L2 regularization factor for the dense layer in the<br>classification layer. Used only when<br>`reinitialize_top_layer` is set to<br>`"True"`.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.0001`.                                                                                                                                                                    |
| `reinitialize_top_layer`    | If set to `"Auto"`, the top classification layer<br>parameters are re-initialized during fine-tuning. For incremental<br>training, top classification layer parameters are not re-initialized<br>unless set to `"True"`.<br>Valid values: string, any of the following: (`"Auto"`,<br>`"True"` or `"False"`).<br>Default value: `"Auto"`.                                                           |
| `rho`                       | The discounting factor for the gradient of the<br>`"adadelta"` and `"rmsprop"` optimizers.<br>Ignored for other optimizers.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.95`.                                                                                                                                                                                             |
| `train_only_on_top_layer`   | If `"True"`, only the top classification layer<br>parameters are fine-tuned. If `"False"`, all model<br>parameters are fine-tuned.<br>Valid values: string, either: (`"True"` or<br>`"False"`).<br>Default value: `"False"`.                                                                                                                                                                        |
| `validation_split_ratio`    | The fraction of training data to randomly split to create<br>validation data. Only used if validation data is not provided<br>through the `validation` channel.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.2`.                                                                                                                                                          |
| `warmup_steps_fraction`     | The fraction of the total number of gradient update steps, where<br>the learning rate increases from 0 to the initial learning rate as a<br>warm up. Only used with the `adamw` optimizer.<br>Valid values: float, range: [`0.0`,<br>`1.0`].<br>Default value: `0.1`.                                                                                                                               |
