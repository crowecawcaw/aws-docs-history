# User guide

The following topics cover accessing and using models in your Amazon SageMaker JumpStart curated
model hubs. Learn how to access your curated hub models through the Amazon SageMaker Studio interface
or programmatically with the SageMaker Python SDK. Additionally, learn how to fine-tune curated hub
models to adapt them for your specific use cases and business needs.
