# Icons Guide

Use this table to learn about the icons you see in your UI. You can
automatically select some of these icons using the keyboard shortcuts found in
the **Shortcuts** menu.

| Icon                         | Action             | Description                                                                                                                                                                                                                                                                          |
| ---------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The Brightness icon.         | brightness         | Choose this icon to adjust the brightness of all video<br>frames.                                                                                                                                                                                                                    |
| The Contrast icon.           | contrast           | Choose this icon to adjust the contrast of all video<br>frames.                                                                                                                                                                                                                      |
| The Zoom in icon.            | zoom in            | Choose this icon to zoom into all of the video<br>frames.                                                                                                                                                                                                                            |
| The Zoom out icon.           | zoom out           | Choose this icon to zoom out of all of the video frames.                                                                                                                                                                                                                             |
| The Move icon.               | move screen        | After you've zoomed into a video frame, choose this icon<br>to move around in that video frame. You can move around the<br>video frame using your mouse by clicking and dragging the<br>frame in the direction you want it to move. This will change<br>the view in all view frames. |
| The Fit screen icon.         | fit screen         | Reset all video frames to their original position.                                                                                                                                                                                                                                   |
| The Undo icon.               | undo               | Undo an action. You can use this icon to remove a bounding<br>box that you just added, or to undo an adjustment you made<br>to a bounding box.                                                                                                                                       |
| The Redo icon.               | redo               | Redo an action that was undone using the undo icon.                                                                                                                                                                                                                                  |
| The Delete labels icon.      | delete label       | Delete a label. This will delete the bounding box associated<br>with the label in a single frame.                                                                                                                                                                                    |
| The Show or hide label icon. | show or hide label | Select this icon to show a label that has been hidden. If<br>this icon has a slash through it, select it to hide the label.                                                                                                                                                          |
| The Edit icon.               | edit label         | Select this icon to open the \*_Edit<br>instance_<br>• menu. Use this menu to edit a label<br>category, ID, and to add or edit label attributes.                                                                                                                                     |
