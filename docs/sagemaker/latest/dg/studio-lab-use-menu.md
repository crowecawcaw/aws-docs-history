# Use the Amazon SageMaker Studio Lab notebook toolbar

Amazon SageMaker Studio Lab notebooks extend the JupyterLab interface. For an overview of the basic
JupyterLab interface, see [The JupyterLab
Interface](https://jupyterlab.readthedocs.io/en/latest/user/interface.html "https://jupyterlab.readthedocs.io/en/latest/user/interface.html").

The following image shows the toolbar and an empty cell from a Studio Lab notebook.

![The layout of the notebook toolbar, including the toolbar icons.](images/studio-lab-menu.png)
When you hover over a toolbar icon, a tooltip displays the icon function. You can find
additional notebook commands in the Studio Lab main menu. The toolbar includes the following
icons:

| Icon                                         | Description                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The Save and checkpoint icon.                | **Save and checkpoint**<br>Saves the notebook and updates the checkpoint file.                                                                                                                                                                                                                                |
| The Insert cell icon.                        | **Insert cell**<br>Inserts a code cell below the current cell. The current cell is noted by the blue<br>vertical marker in the left margin.                                                                                                                                                                   |
| The Cut, copy, and paste cells icon.         | **Cut, copy, and paste cells**<br>Cuts, copies, and pastes the selected cells.                                                                                                                                                                                                                                |
| The Run cells icon.                          | **Run cells**<br>Runs the selected cells. The cell that follows the last-selected cell becomes the<br>new-selected cell.                                                                                                                                                                                      |
| The Interrupt kernel icon.                   | **Interrupt kernel**<br>Interrupts the kernel, which cancels the currently-running operation. The kernel<br>remains active.                                                                                                                                                                                   |
| The Restart kernel icon.                     | **Restart kernel**<br>Restarts the kernel. Variables are reset. Unsaved information is not<br>affected.                                                                                                                                                                                                       |
| The Restart kernel and re-run notebook icon. | **Restart kernel and re-run notebook**<br>Restarts the kernel. Variables are reset. Unsaved information is not affected.<br>Then re-runs the entire notebook.                                                                                                                                                 |
| The Cell type icon.                          | **Cell type**<br>Displays or changes the current cell type. The cell types are:<br>• Code – Code that the kernel runs.<br>• Markdown – Text rendered as markdown.<br>• Raw – Content, including Markdown markup, that's displayed as<br>text.                                                                 |
| The Checkpoint diff icon.                    | **Checkpoint diff**<br>Opens a new tab that displays the difference between the notebook and the<br>checkpoint file. For more information, see [Get notebook differences](studio-lab-use-diff.md "studio-lab-use-diff.md").                                                                                   |
| The Git diff icon.                           | **Git diff**<br>Only enabled if the notebook is opened from a Git repository. Opens a new tab that<br>displays the difference between the notebook and the last Git commit. For more<br>information, see [Get notebook differences](studio-lab-use-diff.md "studio-lab-use-diff.md").                         |
| **default**                                  | **Kernel**<br>Displays or changes the kernel that processes the cells in the notebook.<br>`No Kernel` indicates that the notebook was opened without specifying a<br>kernel. You can edit the notebook, but you can't run any cells.                                                                          |
| The Kernel busy status icon.                 | **Kernel busy status**<br>Displays a kernel's busy status by showing the circle's edge and its interior as<br>the same color. The kernel is busy when it is starting and when it is processing<br>cells. Additional kernel states are displayed in the status bar at the bottom-left<br>corner of Studio Lab. |
