# Linear learner hyperparameters

The following table contains the hyperparameters for the linear learner algorithm.
These are parameters that are set by users to facilitate the estimation of model
parameters from data. The required hyperparameters that must be set are listed first, in
alphabetical order. The optional hyperparameters that can be set are listed next, also
in alphabetical order. When a hyperparameter is set to `auto`, Amazon SageMaker AI will
automatically calculate and set the value of that hyperparameter.

| Parameter Name                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `num_classes`                                | The number of classes for the response variable. The algorithm<br>assumes that classes are labeled `0`, ...,<br>`num_classes<br>• 1`.<br>\*_Required_<br>• when<br>`predictor_type` is<br>`multiclass_classifier`. Otherwise, the algorithm<br>ignores it.<br>Valid values: Integers from 3 to 1,000,000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `predictor_type`                             | Specifies the type of target variable as a binary classification,<br>multiclass classification, or regression.<br>**Required**<br>Valid values: `binary_classifier`,<br>`multiclass_classifier`, or<br>`regressor`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `accuracy_top_k`                             | When computing the top-k accuracy metric for multiclass<br>classification, the value of _k_.<br>If the model assigns one of the top-k scores to the true label, an<br>example is scored as correct.<br>**Optional**<br>Valid values: Positive integers<br>Default value: 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `balance_multiclass_weights`                 | Specifies whether to use class weights, which give each class<br>equal importance in the loss function. Used only when the<br>`predictor_type` is<br>`multiclass_classifier`.<br>**Optional**<br>Valid values: `true`, `false`<br>Default value: `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `beta_1`                                     | The exponential decay rate for first-moment estimates. Applies<br>only when the `optimizer` value is<br>`adam`.<br>**Optional**<br>Valid values: `auto` or floating-point value between 0<br>and 1.0<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `beta_2`                                     | The exponential decay rate for second-moment estimates. Applies<br>only when the `optimizer` value is<br>`adam`.<br>**Optional**<br>Valid values: `auto` or floating-point integer between<br>0 and 1.0<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `bias_lr_mult`                               | Allows a different learning rate for the bias term. The actual<br>learning rate for the bias is `learning_rate` \*<br>`bias_lr_mult`.<br>**Optional**<br>Valid values: `auto` or positive floating-point<br>integer<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `bias_wd_mult`                               | Allows different regularization for the bias term. The actual L2<br>regularization weight for the bias is `wd` \*<br>`bias_wd_mult`. By default, there is no<br>regularization on the bias term.<br>**Optional**<br>Valid values: `auto` or non-negative floating-point<br>integer<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `binary_classifier_model_selection_criteria` | When `predictor_type` is set to<br>`binary_classifier`, the model evaluation criteria<br>for the validation dataset (or for the training dataset if you don't<br>provide a validation dataset). Criteria include:<br>• `accuracy`—The model with the highest<br>accuracy.<br>• `f_beta`—The model with the highest F1<br>score. The default is F1.<br>• `precision_at_target_recall`—The model<br>with the highest precision at a given recall target.<br>• `recall_at_target_precision`—The model<br>with the highest recall at a given precision target.<br>• `loss_function`—The model with the<br>lowest value of the loss function used in training.<br>**Optional**<br>Valid values: `accuracy`, `f_beta`,<br>`precision_at_target_recall`,<br>`recall_at_target_precision`, or<br>`loss_function`<br>Default value: `accuracy`                                                                                                                                                                                                                  |
| `early_stopping_patience`                    | If no improvement is made in the relevant metric, the number of<br>epochs to wait before ending training. If you have provided a value for<br>`binary_classifier_model_selection_criteria`. the metric<br>is that value. Otherwise, the metric is the same as the value specified<br>for the `loss` hyperparameter. The metric is evaluated<br>on the validation data. If you haven't provided validation data, the<br>metric is always the same as the value specified for the<br>`loss` hyperparameter and is evaluated on the<br>training data. To disable early stopping, set<br>`early_stopping_patience` to a value greater than the<br>value specified for `epochs`.**Optional**Valid values:<br>Positive integerDefault value: 3                                                                                                                                                                                                                                                                                                               |
| `early_stopping_tolerance`                   | The relative tolerance to measure an improvement in loss. If the<br>ratio of the improvement in loss divided by the previous best loss<br>is smaller than this value, early stopping considers the improvement<br>to be zero.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 0.001                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `epochs`                                     | The maximum number of passes over the training data.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 15                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `f_beta`                                     | The value of beta to use when calculating F score metrics for<br>binary or multiclass classification. Also used if the value<br>specified for<br>`binary_classifier_model_selection_criteria` is<br>`f_beta`.<br>**Optional**<br>Valid values: Positive floating-point integers<br>Default value: 1.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `feature_dim`                                | The number of features in the input data.<br>**Optional**<br>Valid values: `auto` or positive integer<br>Default values: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `huber_delta`                                | The parameter for Huber loss. During training and metric<br>evaluation, compute L2 loss for errors smaller than delta and L1<br>loss for errors larger than delta.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 1.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `init_bias`                                  | Initial weight for the bias term.<br>**Optional**<br>Valid values: Floating-point integer<br>Default value: 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `init_method`                                | Sets the initial distribution function used for model weights.<br>Functions include:<br>• `uniform`—Uniformly distributed between<br>(-scale, +scale)<br>• `normal`—Normal distribution, with mean<br>0 and sigma<br>**Optional**<br>Valid values: `uniform` or `normal`<br>Default value: `uniform`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `init_scale`                                 | Scales an initial uniform distribution for model weights. Applies<br>only when the `init_method` hyperparameter is set to<br>`uniform`.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 0.07                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `init_sigma`                                 | The initial standard deviation for the normal distribution.<br>Applies only when the `init_method` hyperparameter is set<br>to `normal`.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `l1`                                         | The L1 regularization parameter. If you don't want to use L1<br>regularization,<br>set<br>the value to 0.<br>**Optional**<br>Valid values: `auto` or non-negative float<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `learning_rate`                              | The step size used by the optimizer for parameter updates.<br>**Optional**<br>Valid values: `auto` or positive floating-point<br>integer<br>Default value: `auto`, whose value depends on the<br>optimizer chosen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `loss`                                       | Specifies the loss function.<br>The available loss functions and their default values depend on<br>the value of `predictor_type`:<br>• If the `predictor_type` is set to<br>`regressor`, the available options are<br>`auto`, `squared_loss`,<br>`absolute_loss`,<br>`eps_insensitive_squared_loss`,<br>`eps_insensitive_absolute_loss`,<br>`quantile_loss`, and `huber_loss`.<br>The default value for `auto` is<br>`squared_loss`.<br>• If the `predictor_type` is set to<br>`binary_classifier`, the available options<br>are `auto`,`logistic`, and<br>`hinge_loss`. The default value for<br>`auto` is `logistic`.<br>• If the `predictor_type` is set to<br>`multiclass_classifier`, the available<br>options are `auto` and `softmax_loss`.<br>The default value for `auto` is<br>`softmax_loss`.<br>Valid values: `auto`, `logistic`,<br>`squared_loss`, `absolute_loss`,<br>`hinge_loss`,<br>`eps_insensitive_squared_loss`,<br>`eps_insensitive_absolute_loss`,<br>`quantile_loss`, or `huber_loss`<br>**Optional**<br>Default value: `auto` |
| `loss_insensitivity`                         | The parameter for the epsilon-insensitive loss type. During<br>training and metric evaluation, any error smaller than this value is<br>considered to be zero.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `lr_scheduler_factor`                        | For every `lr_scheduler_step` hyperparameter, the<br>learning rate decreases by this quantity. Applies only when the<br>`use_lr_scheduler` hyperparameter is set to<br>`true`.<br>**Optional**<br>Valid values: `auto` or positive floating-point integer<br>between 0 and 1<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `lr_scheduler_minimum_lr`                    | The learning rate never decreases to a value lower than the value<br>set for `lr_scheduler_minimum_lr`. Applies only when the<br>`use_lr_scheduler` hyperparameter is set to<br>`true`.<br>**Optional**<br>Valid values: `auto` or positive floating-point<br>integer<br>Default values: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `lr_scheduler_step`                          | The number of steps between decreases of the learning rate.<br>Applies only when the `use_lr_scheduler` hyperparameter<br>is set to `true`.<br>**Optional**<br>Valid values: `auto` or positive integer<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `margin`                                     | The margin for the `hinge_loss` function.<br>**Optional**<br>Valid values: Positive floating-point integer<br>Default value: 1.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `mini_batch_size`                            | The number of observations per mini-batch for the data<br>iterator.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 1000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `momentum`                                   | The momentum of the `sgd` optimizer.<br>**Optional**<br>Valid values: `auto` or a floating-point integer<br>between 0 and 1.0<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `normalize_data`                             | Normalizes the feature data before training. Data normalization<br>shifts the data for each feature to have a mean of zero and scales<br>it to have unit standard deviation.<br>**Optional**<br>Valid values: `auto`, `true`, or<br>`false`<br>Default value: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `normalize_label`                            | Normalizes the label. Label normalization shifts the label to have<br>a mean of zero and scales it to have unit standard deviation.<br>The `auto` default value normalizes the label for<br>regression problems but does not for classification problems. If you<br>set the `normalize_label` hyperparameter to<br>`true` for classification problems, the algorithm<br>ignores it.<br>**Optional**<br>Valid values: `auto`, `true`, or<br>`false`<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `num_calibration_samples`                    | The number of observations from the validation dataset to use for<br>model calibration (when finding the<br>best<br>threshold).<br>**Optional**<br>Valid values: `auto` or positive integer<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `num_models`                                 | The number of models to train in parallel. For the default,<br>`auto`, the algorithm decides the number of parallel<br>models to train. One model is trained according to the given<br>training parameter (regularization, optimizer, loss), and the rest<br>by<br>close<br>parameters.<br>**Optional**<br>Valid values: `auto` or positive integer<br>Default values: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `num_point_for_scaler`                       | The number of data points to use for calculating normalization or<br>unbiasing of terms.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 10,000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `optimizer`                                  | The optimization algorithm to use.<br>**Optional**<br>Valid values:<br>• `auto`—The default value.<br>• `sgd`—Stochastic gradient<br>descent.<br>• `adam`—[Adaptive<br>momentum estimation](https://arxiv.org/pdf/1412.6980.pdf "https://arxiv.org/pdf/1412.6980.pdf").<br>• `rmsprop`—A gradient-based optimization<br>technique that uses a moving average of squared gradients to<br>normalize the gradient.<br>Default value: `auto`. The default setting for<br>`auto` is `adam`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `positive_example_weight_mult`               | The weight assigned to positive examples when training a binary<br>classifier. The weight of negative examples is fixed at 1. If you<br>want the algorithm to choose a weight so that errors in classifying<br>negative \*vs.<br>• positive examples<br>have equal impact on training loss, specify `balanced`.<br>If you want the algorithm to choose the weight that optimizes<br>performance, specify `auto`.<br>**Optional**<br>Valid values: `balanced`, `auto`, or a<br>positive floating-point integer<br>Default value: 1.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `quantile`                                   | The quantile for quantile loss. For quantile q, the model attempts<br>to produce predictions so that the value of `true_label`<br>is greater than the prediction with probability q.<br>**Optional**<br>Valid values: Floating-point integer between 0 and 1<br>Default value: 0.5                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `target_precision`                           | The target precision. If<br>`binary_classifier_model_selection_criteria` is<br>`recall_at_target_precision`, then precision is held<br>at this value while recall is maximized.<br>**Optional**<br>Valid values: Floating-point integer between 0 and 1.0<br>Default value: 0.8                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `target_recall`                              | The target recall. If<br>`binary_classifier_model_selection_criteria` is<br>`precision_at_target_recall`, then recall is held at<br>this value while precision is maximized.<br>**Optional**<br>Valid values: Floating-point integer between 0 and 1.0<br>Default value: 0.8                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `unbias_data`                                | Unbiases the features before training so that the mean is 0. By<br>default data is unbiased as the `use_bias` hyperparameter<br>is set to `true`.<br>**Optional**<br>Valid values: `auto`, `true`, or<br>`false`<br>Default value:<br>`auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `unbias_label`                               | Unbiases labels before training so that the mean is 0. Applies to<br>regression only if the `use_bias` hyperparameter is set<br>to `true`.<br>**Optional**<br>Valid values: `auto`, `true`, or<br>`false`<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `use_bias`                                   | Specifies whether the model should include a bias term, which is<br>the intercept term in the linear equation.<br>**Optional**<br>Valid values: `true` or `false`<br>Default value: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `use_lr_scheduler`                           | Whether to use a scheduler for the learning rate. If you want to<br>use a scheduler, specify `true`.<br>**Optional**<br>Valid values: `true` or `false`<br>Default value: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `wd`                                         | The weight decay parameter, also known as the L2 regularization<br>parameter. If you don't want to use L2 regularization, set the value<br>to 0.<br>**Optional**<br>Valid values:`auto` or non-negative floating-point<br>integer<br>Default value: `auto`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
