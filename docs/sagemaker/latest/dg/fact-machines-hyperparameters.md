# Factorization Machines

Hyperparameters

The following table contains the hyperparameters for the Factorization Machines algorithm.
These are parameters that are set by users to facilitate the estimation of model
parameters from data. The required hyperparameters that must be set are listed first, in
alphabetical order. The optional hyperparameters that can be set are listed next, also
in alphabetical order.

| Parameter Name        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feature_dim`         | The dimension of the input feature space. This could be very<br>high with sparse input.<br>**Required**<br>Valid values: Positive integer. Suggested value range:<br>[10000,10000000]                                                                                                                                                                                                                                                                                                                                                                                                             |
| `num_factors`         | The dimensionality of factorization.<br>**Required**<br>Valid values: Positive integer. Suggested value range: [2,1000],<br>64 typically generates good outcomes and is a good starting point.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `predictor_type`      | The type of predictor.<br>• `binary_classifier`: For binary classification<br>tasks.<br>• `regressor`: For regression tasks.<br>**Required**<br>Valid values: String: `binary_classifier` or<br>`regressor`                                                                                                                                                                                                                                                                                                                                                                                       |
| `bias_init_method`    | The initialization method for the bias term:<br>• `normal`: Initializes weights with random<br>values sampled from a normal distribution with a mean of<br>zero and standard deviation specified by<br>`bias_init_sigma`.<br>• `uniform`: Initializes weights with random<br>values uniformly sampled from a range specified by<br>[-`bias_init_scale`,<br>+`bias_init_scale`].<br>• `constant`: Initializes the weights to a scalar<br>value specified by `bias_init_value`.<br>**Optional**<br>Valid values: `uniform`, `normal`, or<br>`constant`<br>Default value: `normal`                   |
| `bias_init_scale`     | Range for initialization of the bias term. Takes effect if<br>`bias_init_method` is set to `uniform`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                          |
| `bias_init_sigma`     | The standard deviation for initialization of the bias term.<br>Takes effect if `bias_init_method` is set to<br>`normal`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                       |
| `bias_init_value`     | The initial value of the bias term. Takes effect if<br>`bias_init_method` is set to `constant`.<br>**Optional**<br>Valid values: Float. Suggested value range: [1e-8, 512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                                                |
| `bias_lr`             | The learning rate for the bias term.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.1                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `bias_wd`             | The weight decay for the bias term.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `clip_gradient`       | Gradient clipping optimizer parameter. Clips the gradient by<br>projecting onto the interval [-`clip_gradient`,<br>+`clip_gradient`].<br>**Optional**<br>Valid values: Float<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                                               |
| `epochs`              | The number of training epochs to run.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `eps`                 | Epsilon parameter to avoid division by 0.<br>**Optional**<br>Valid values: Float. Suggested value: small.<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `factors_init_method` | The initialization method for factorization terms:<br>• `normal` Initializes weights with random values<br>sampled from a normal distribution with a mean of zero and<br>standard deviation specified by<br>`factors_init_sigma`.<br>• `uniform`: Initializes weights with random<br>values uniformly sampled from a range specified by<br>[-`factors_init_scale`,<br>+`factors_init_scale`].<br>• `constant`: Initializes the weights to a scalar<br>value specified by `factors_init_value`.<br>**Optional**<br>Valid values: `uniform`, `normal`, or<br>`constant`.<br>Default value: `normal` |
| `factors_init_scale`  | The range for initialization of factorization terms. Takes<br>effect if `factors_init_method` is set to<br>`uniform`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                          |
| `factors_init_sigma`  | The standard deviation for initialization of factorization<br>terms. Takes effect if `factors_init_method` is set to<br>`normal`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.001                                                                                                                                                                                                                                                                                                                                             |
| `factors_init_value`  | The initial value of factorization terms. Takes effect if<br>`factors_init_method` is set to<br>`constant`.<br>**Optional**<br>Valid values: Float. Suggested value range: [1e-8, 512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                                    |
| `factors_lr`          | The learning rate for factorization terms.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.0001                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `factors_wd`          | The weight decay for factorization terms.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.00001                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `linear_lr`           | The learning rate for linear terms.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.001                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `linear_init_method`  | The initialization method for linear terms:<br>• `normal` Initializes weights with random values<br>sampled from a normal distribution with a mean of zero and<br>standard deviation specified by<br>`linear_init_sigma`.<br>• `uniform` Initializes weights with random<br>values uniformly sampled from a range specified by<br>[-`linear_init_scale`,<br>+`linear_init_scale`].<br>• `constant` Initializes the weights to a scalar<br>value specified by `linear_init_value`.<br>**Optional**<br>Valid values: `uniform`, `normal`, or<br>`constant`.<br>Default value: `normal`              |
| `linear_init_scale`   | Range for initialization of linear terms. Takes effect if<br>`linear_init_method` is set to `uniform`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                         |
| `linear_init_sigma`   | The standard deviation for initialization of linear terms.<br>Takes effect if `linear_init_method` is set to<br>`normal`.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.01                                                                                                                                                                                                                                                                                                                                                      |
| `linear_init_value`   | The initial value of linear terms. Takes effect if<br>`linear_init_method` is set to<br>_constant_.<br>**Optional**<br>Valid values: Float. Suggested value range: [1e-8, 512].<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                                            |
| `linear_wd`           | The weight decay for linear terms.<br>**Optional**<br>Valid values: Non-negative float. Suggested value range: [1e-8,<br>512].<br>Default value: 0.001                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `mini_batch_size`     | The size of mini-batch used for training.<br>**Optional**<br>Valid values: Positive integer<br>Default value: 1000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `rescale_grad`        | Gradient rescaling optimizer parameter. If set, multiplies the<br>gradient with `rescale_grad` before updating. Often<br>choose to be 1.0/`batch_size`.<br>**Optional**<br>Valid values: Float<br>Default value: None                                                                                                                                                                                                                                                                                                                                                                             |
