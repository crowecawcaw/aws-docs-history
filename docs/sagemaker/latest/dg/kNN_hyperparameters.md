# k-NN Hyperparameters

The following table lists the hyperparameters that you can set for the Amazon SageMaker AI
k-nearest neighbors (k-NN) algorithm.

| Parameter Name               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `feature_dim`                | The number of features in the input data.<br>**Required**<br>Valid values: positive integer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `k`                          | The number of nearest neighbors.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `predictor_type`             | The type of inference to use on the data labels.<br>**Required**<br>Valid values: *classifier<br>• for classification<br>or *regressor<br>• for regression.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `sample_size`                | The number of data points to be sampled from the training data<br>set.<br>**Required**<br>Valid values: positive integer                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `dimension_reduction_target` | The target dimension to reduce to.<br>\*_Required_<br>• when you specify the<br>`dimension_reduction_type` parameter.<br>Valid values: positive integer greater than 0 and less than<br>`feature_dim`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `dimension_reduction_type`   | The type of dimension reduction method.<br>**Optional**<br>Valid values: *sign<br>• for random projection or<br>*fjlt<br>• for the fast Johnson-Lindenstrauss<br>transform.<br>Default<br>value:<br>No dimension reduction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `faiss_index_ivf_nlists`     | The number of centroids to construct in the index when<br>`index_type` is *faiss.IVFFlat<br>• or<br>*faiss.IVFPQ*.<br>**Optional**<br>Valid values: positive integer<br>Default value:<br>*auto\*,<br>which resolves to<br>`sqrt(sample_size)`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `faiss_index_pq_m`           | The number of vector sub-components to construct in the index when<br>`index_type` is set to<br>_faiss.IVFPQ_.<br>The FaceBook AI Similarity Search (FAISS) library requires that<br>the value of `faiss_index_pq_m` is a divisor of the<br>data<br>dimension. If `faiss_index_pq_m` is<br>not a divisor of the data dimension, we increase the data dimension<br>to smallest integer divisible by `faiss_index_pq_m`. If<br>no dimension reduction is applied, the algorithm adds a padding of<br>zeros. If dimension reduction is applied,<br>the algorithm<br>increase<br>the value of the `dimension_reduction_target`<br>hyper-parameter.<br>**Optional**<br>Valid values: One of the following positive integers: 1, 2, 3, 4,<br>8, 12, 16, 20, 24, 28, 32, 40, 48, 56, 64, 96 |
| `index_metric`               | The metric to measure the distance between points when finding<br>nearest neighbors. When training with `index_type` set to<br>`faiss.IVFPQ`,<br>the<br>`INNER_PRODUCT` distance and `COSINE`<br>similarity are not supported.<br>**Optional**<br>Valid values: *L2<br>• for Euclidean-distance,<br>*INNER_PRODUCT<br>• for inner-product distance,<br>*COSINE<br>• for cosine<br>similarity.<br>Default value: *L2\*                                                                                                                                                                                                                                                                                                                                                                |
| `index_type`                 | The type of index.<br>**Optional**<br>Valid values:<br>_faiss.Flat_, _faiss.IVFFlat_,<br>_faiss.IVFPQ_.<br>Default values:<br>_faiss.Flat_                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `mini_batch_size`            | The number of observations per mini-batch for the data iterator.<br>**Optional**<br>Valid values: positive integer<br>Default value: 5000                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
