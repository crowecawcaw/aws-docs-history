

# Find your Atlassian installation ID
<a name="find-atlassian-installation-id"></a>

The Atlassian installation ID uniquely identifies the AWS Security Agent Forge app installed on your Atlassian site, so AWS can securely link your site to your AWS account during integration setup. You need this ID when you register a Bitbucket, Confluence, or Jira integration in the AWS Console. Find the installation ID from the AWS Security Agent Forge app installed on your Atlassian site, then paste it into the registration flow.

## For Bitbucket
<a name="_for_bitbucket"></a>

To copy the installation ID in Bitbucket, do the following:

1. In Bitbucket, navigate to your **Workspace settings**.

1. On the sidebar, select **Forge Apps**.

1. In the list of installed apps, locate **Connect with AWS Security Agent**.

1. Choose **Copy to Clipboard** to copy the installation ID.

## For Confluence
<a name="_for_confluence"></a>

To copy the installation ID in Confluence, do the following:

1. In Confluence, navigate to **Confluence administration**.

1. On the sidebar, select **Apps**.

1. In the list of installed apps, locate **Connect with AWS Security Agent**.

1. Choose **Copy to Clipboard** to copy the installation ID.

## For Jira
<a name="_for_jira"></a>

To copy the installation ID in Jira, do the following:

1. In Jira, navigate to **Jira administration**.

1. On the sidebar, select **Apps**.

1. In the list of installed apps, locate **Connect with AWS Security Agent**.

1. Choose **Copy to Clipboard** to copy the installation ID.

You will need this installation ID when completing the registration in the AWS Security Agent Management Console.
