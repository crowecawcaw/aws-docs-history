# Find your Atlassian installation ID

Before registering a Bitbucket or Confluence integration in the AWS Console, you need to find the installation ID from the AWS Security Agent Forge app installed on your Atlassian site. You paste this ID into the registration flow.

## For Bitbucket

1. In Bitbucket, navigate to your **Workspace settings**.
2. Select **Forge Apps** from the sidebar.
3. Locate **Connect with AWS Security Agent** in the list of installed apps.
4. Choose **Copy to Clipboard** to copy the installation ID.

## For Confluence

1. In Confluence, navigate to **Confluence administration**.
2. Select **Apps** from the sidebar.
3. Locate **Connect with AWS Security Agent** in the list of installed apps.
4. Choose **Copy to Clipboard** to copy the installation ID.

You will need this installation ID when completing the registration in the AWS Security Agent Management Console.
