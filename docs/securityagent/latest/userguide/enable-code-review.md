# Enable pull request code review for GitHub repositories

Pull request code review is now configured as part of the code review setup wizard. When you connect GitHub repositories to your Agent Space, you can enable pull request comments for individual repositories to have AWS Security Agent automatically analyze pull requests and post security findings.

For complete setup instructions, see [Enable code review](enable-code-review-scan.md "enable-code-review-scan.md").

For information about how pull request findings appear in GitHub and how to respond to them, see [Review code security findings in GitHub pull requests](review-code-findings-github.md "review-code-findings-github.md").
