# Working with CloudWatch Logs using the AWS Toolkit

You can use Amazon CloudWatch Logs to centralize the logs from all of your systems and applications and
 the AWS services that you use, in a single, highly scalable service. You can then easily view
 them, search them for specific error codes or patterns, filter them based on specific fields, or
 archive them securely for future analysis. For more information, see [What Is Amazon CloudWatch Logs?](../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatchLogs.md "../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatchLogs.md") in the
 *Amazon CloudWatch User Guide*.
