# Enabling AWS Toolkit code lenses

This step shows how you can enable AWS Toolkit code lenses.

1. On the menu bar, choose **AWS Cloud9**, and then
   **Preferences**.
2. On the **Preferences** tab, in the sidebar, choose
   **AWS Toolkit**.
3. To enable code lenses, choose **Enable Code Lenses**.
