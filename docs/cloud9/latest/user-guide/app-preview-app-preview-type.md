# Change the application preview type

To change the application preview type, choose the following option:

On the application preview tab, choose one of the following from the preview type
 list:


* **Browser**: Previews the output in a web browser format.
* **Raw Content (UTF-8)**: Attempts to preview the output in Unicode
 Transformation Format 8-bit (UTF-8) format, if applicable.
* **Markdown**: Attempts to preview the output in the Markdown format,
 if applicable.
