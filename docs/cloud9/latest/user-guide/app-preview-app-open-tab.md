# Open an application preview in a separate web
 browser tab

To open an application preview in a separate web browser tab, choose the following option:

On the application preview tab, choose **Pop Out Into New
 Window**.

The AWS Cloud9 IDE must also be running in at least one other tab in
 the same web browser. Otherwise, the application preview isn't displayed in a separate
 web browser tab.
