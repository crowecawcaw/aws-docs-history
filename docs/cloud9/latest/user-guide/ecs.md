# Working with Amazon Elastic Container Service

The AWS Cloud9 IDE provides some support for [Amazon Elastic Container Service (Amazon ECS)](../../../AmazonECS/latest/developerguide.md "../../../AmazonECS/latest/developerguide.md"). You
can use the AWS Cloud9 IDE to manage Amazon ECS resources. For example, you can create task
definitions.
