# Working with Amazon EventBridge

The AWS Toolkit for AWS Cloud9 provides support for [Amazon EventBridge](https://aws.amazon.com/eventbridge/ "https://aws.amazon.com/eventbridge/"). Using the
 AWS Toolkit for AWS Cloud9, you can work with certain aspects of EventBridge, such as schemas.
