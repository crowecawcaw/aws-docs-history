# Go to the active cursor of an

environment member

This step shows how you can navigate the active cursor of an
environment member.

1. With the shared environment open, in the **Collaborate** window, expand
   **Environment Members**, if the list of members isn't
   visible.
2. Open the context (right-click) menu for the member name, and then choose
   **Show Location**.
