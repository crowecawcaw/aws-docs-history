

# View data governance
<a name="view-data-governance"></a>

The data governance page is a read-only page that displays your data retention and data residency settings. To view it, navigate to **Settings** > **Data Management** > **Data governance**.

## Data retention
<a name="view-data-governance-retention"></a>

By default, Amazon Connect Talent deletes interview transcripts, candidate assessment results, and application materials after one year. To request custom retention periods, see [Requesting custom data retention periods](data-retention.md).

## Data residency and encryption
<a name="view-data-governance-residency"></a>

Your data resides in the AWS Region where your instance is hosted, and all data at rest is encrypted. For more information, see [Data protection in Amazon Connect Talent](data-protection.md).
