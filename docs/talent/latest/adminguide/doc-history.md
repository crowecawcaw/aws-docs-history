

# Document history for the Amazon Connect Talent Administrator Guide
<a name="doc-history"></a>

The following table describes the important changes to the documentation since the last release of the *Amazon Connect Talent Administrator Guide*. For notification about updates to this documentation, you can subscribe to an RSS feed.

| Change | Description | Date | 
| --- |--- |--- |
| [Service quotas and endpoints](#doc-history) | Updates the service quotas and endpoints information with quota tables and links to the Service Quotas console for requesting quota increases. For more information, see [Service quotas and endpoints for Amazon Connect Talent](https://docs.aws.amazon.com/talent/latest/adminguide/endpoints-quotas.html). | October 1, 2026 | 
| [Delete your Amazon Connect Talent instance](#doc-history) | Describes how to delete an Amazon Connect Talent instance and remove the resources that remain in your account after deletion. For more information, see [Delete your Amazon Connect Talent instance](https://docs.aws.amazon.com/talent/latest/adminguide/getting-started-delete.html). | October 1, 2026 | 
| [Request Amazon SES production access](#doc-history) | Adds step-by-step instructions for moving Amazon Simple Email Service (Amazon SES) out of the sandbox and requesting production access so that you can send evaluation invitations to candidates. For more information, see [Move Amazon SES out of sandbox mode](https://docs.aws.amazon.com/talent/latest/adminguide/getting-started-create.html#getting-started-ses). | September 17, 2026 | 
| [Initial release](#doc-history) | Initial release of the *Amazon Connect Talent Administrator Guide*. | September 1, 2026 |
