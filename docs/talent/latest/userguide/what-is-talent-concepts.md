

# Key concepts
<a name="what-is-talent-concepts"></a>

A few core ideas make up how Amazon Connect Talent measures candidates:
+ **Evaluations** – An evaluation is what a candidate completes for a job. It can include assessments, an AI-led interview, or both. Amazon Connect Talent builds each evaluation from the job's competencies. For more information, see [Evaluations](evaluations.md).
+ **AI-led interviews** – Voice-based interviews conducted by AI agents that evaluate candidates against job-specific competencies. For more information, see [How AI-led interviews work](ai-led-interviews.md).
+ **Assessments** – Digital tests that evaluate a candidate's skills through various question formats. For more information, see [How assessments work](assessments.md).
