# BuiltinSlotTypeMetadata

Provides information about a built in slot type.

## Contents

**signature**

A unique identifier for the built-in slot type. To find the
signature for a slot type, see [Slot Type Reference](https://developer.amazon.com/public/solutions/alexa/alexa-skills-kit/docs/built-in-intent-ref/slot-type-reference "https://developer.amazon.com/public/solutions/alexa/alexa-skills-kit/docs/built-in-intent-ref/slot-type-reference") in the _Alexa Skills
Kit_.

Type: String

Required: No

**supportedLocales**

A list of target locales for the slot.

Type: Array of strings

Valid Values: `de-DE | en-AU | en-GB | en-IN | en-US | es-419 | es-ES | es-US | fr-FR | fr-CA | it-IT | ja-JP | ko-KR`

Required: No
