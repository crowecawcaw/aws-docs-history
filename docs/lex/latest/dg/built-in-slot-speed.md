# AMAZON.SpeedUnit

Converts words that represent speed units into the
corresponding abbreviation. For example, "miles per hour" is
converted to `mph`.

This slot type is available only in the English (US) (en-US)
locale.

The following examples show how the
`AMAZON.SpeedUnit` slot type captures speed
units.

| Speed unit                                         | Abbreviation |
| -------------------------------------------------- | ------------ |
| miles per hour, mph, MPH, m/h                      | mph          |
| kilometers per hour, km per hour, kmph, KMPH, km/h | kmph         |
| meters per second, mps, MPS, m/s                   | mps          |
| nautical miles per hour, knots, knot               | knot         |
