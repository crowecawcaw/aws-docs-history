# Integrating an Amazon Lex Bot

with Slack

This exercise provides instructions for integrating an Amazon Lex bot
with the Slack messaging application. You perform the following
steps:

1. Create an Amazon Lex bot.
2. Create a Slack messaging application.
3. Integrate the Slack application with your bot
   Amazon Lex.
4. Test the integration by engaging in conversation with your
   Amazon Lex bot. You send messages with the Slack application and test
   in a browser window.
