# InputContext

The name of a context that must be active for an intent to be selected
by Amazon Lex.

## Contents

**name**

The name of the context.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 100.

Pattern: `^([A-Za-z]_?)+$`

Required: Yes
