# AMAZON.FirstName

Commonly used first names. This slot type recognizes both
formal names and informal nicknames. The name sent to your
intent is the value sent by the user. Amazon Lex doesn't convert from
the nick name to the formal name.

For first names that sound alike but are spelled differently,
Amazon Lex sends your intent a single common form.

In the English (US) (en-US) locale, use the slot name
AMAZON.US_First_Name.

Examples:

- Emily
- John
- Sophie
