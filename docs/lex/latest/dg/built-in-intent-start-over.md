# AMAZON.StartOverIntent

Responds to words and phrases that enable the user to stop
processing the current intent and start over from the beginning.
You can use your Lambda function or the `PutSession`
operation to elicit the first slot value again.

Common utterances:

- start over
- restart
- start again
