# Languages Supported in Amazon Lex

Amazon Lex V1 supports a variety of languages and locales. The languages supported and the
features that support them are listed in the following tables.

Amazon Lex V2 supports additional languages, see [Languages
Supported in Amazon Lex V2](../../../lexv2/latest/dg/how-languages.md "../../../lexv2/latest/dg/how-languages.md")

## Supported

Languages and Locales

Amazon Lex V1 supports the following languages and locales.

| Code   | Language and locale     |
| ------ | ----------------------- |
| de-DE  | German (German)         |
| en-AU  | English (Australia)     |
| en-GB  | English (UK)            |
| en-IN  | English (India)         |
| en-US  | English (US)            |
| es-419 | Spanish (Latin America) |
| es-ES  | Spanish (Spain)         |
| es-US  | Spanish (US)            |
| fr-CA  | French (Canada)         |
| fr-FR  | French (France)         |
| it-IT  | Italian (Italy)         |
| ja-JP  | Japanese (Japan)        |
| ko-KR  | Korean (Korea)          |

## Languages and Locales

Supported by Amazon Lex Features

All Amazon Lex features are supported in all languages and locales
except as listed in this table.

| -------------------------------------------------------------------------------------------- | ------------------------------- |
