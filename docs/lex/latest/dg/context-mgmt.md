# Managing Conversation Context

_Conversation context_ is the
information that a user, your application, or a Lambda function provides
to an Amazon Lex bot to fulfill an intent. Conversation context includes slot
data that the user provides, request attributes set by the client
application, and session attributes that the client application and
Lambda functions create.
