# AMAZON.LastName

Commonly used last names. For names that sound alike that are
spelled differently, Amazon Lex sends your intent a single common
form.

In the English (US) (en-US) locale, use the slot name
AMAZON.US_Last_Name.

Examples:

- Brosky
- Dasher
- Evers
- Parres
- Welt
