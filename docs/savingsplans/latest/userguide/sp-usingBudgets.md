# Using budgets for Savings Plans

You can use AWS Budgets to set budgets for your Savings Plan utilization, coverage,
and costs. You can track your costs as you continue to optimize through AWS.

You can create and set up a budget for your Savings Plans in two ways:

- [Using a template (simplified)](sp-create-savingsplans-budget-template.md "sp-create-savingsplans-budget-template.md")
- [Customizing a budget (advanced)](sp-create-savingsplans-budget.md "sp-create-savingsplans-budget.md")
  For more
  information, see [Managing Your Costs with AWS Budgets](../../../awsaccountbilling/latest/aboutv2/budgets-managing-costs.md "../../../awsaccountbilling/latest/aboutv2/budgets-managing-costs.md") in the _AWS Cost Management User Guide_.
