

# Document history for the AWS Continuum User Guide

The following table describes the documentation releases for AWS Continuum.

| Change | Description | Date | 
| --- |--- |--- |
| [GitLab integration security](doc-history.md) | Added a topic that describes the security controls for GitLab integrations. It covers access token handling, the private-projects requirement, and how AWS Continuum keeps continuous integration and continuous delivery (CI/CD) pipelines from running generated patches before you review them. For more information, see [Security for GitLab integrations in AWS Continuum](https://docs.aws.amazon.com/continuum/latest/userguide/gitlab-integration-security.html). | November 4, 2026 | 
| [Customer managed keys](doc-history.md) | You can now encrypt Environments and GitHub and GitLab integrations with a customer managed key from AWS Key Management Service. For more information, see [Encryption at rest](https://docs.aws.amazon.com/continuum/latest/userguide/encryption-at-rest.html). | October 29, 2026 | 
| [Collector service-linked role documentation](doc-history.md) | Updated the service-linked role documentation for `AWSServiceRoleForContinuumCollector`. The guide now describes the `AWSContinuumCollectorServiceRolePolicy` permissions policy. | October 13, 2026 | 
| [Initial release](doc-history.md) | Initial release of the AWS Continuum User Guide | December 31, 2020 |
