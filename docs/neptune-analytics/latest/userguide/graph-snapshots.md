# Graph snapshots

Neptune Analytics provides you the ability to create a named snapshot of your analytics graph, and also the ability to restore from
existing graph snapshots. A graph snapshot is a compacted deep copy of your entire graph. Snapshots are created
asynchronously, and do not affect the performance of your running graph. You can restore a snapshot into a new graph
at any time.
