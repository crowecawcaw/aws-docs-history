# Document history for the AWS End User Messaging Social User Guide

The following table describes the documentation releases for AWS End User Messaging Social.

| Change                                          | Description                                                                                                                                                                                                                                                              | Date               |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------ |
| Support added for Amazon EventBridge events     | Added support for sending WhatsApp message events to EventBridge. For more information see [Monitoring with EventBridge](monitor-event-bridge.md "monitor-event-bridge.md")                                                                                              | October 3, 2025    |
| Support added for new MessageFee types          | Six new `MessageFee` types that provide additional billing information are now available. For more information see [Understanding your bill](billing.md "billing.md").                                                                                                   | September 30, 2025 |
| Deprecated the Charged per conversation topic   | The Charged per conversation topic in the Understanding your bill section has been deprecated.                                                                                                                                                                           | September 30, 2025 |
| New API for creating WhatsApp message templates | Added support for creating WhatsApp message templates using the AWS End User Messaging Social API. For more information, see [Creating message templates with the CreateWhatsAppMessageTemplate API](create-message-templates-api.md "create-message-templates-api.md"). | July 25, 2025      |
| Charged per message                             | Starting on July 1 2025, AWS End User Messaging Social, charges per message instead of per conversation for WhatsApp messages. For more information, see [Charged per message](charged-per-message.md "charged-per-message.md").                                         | June 30, 2025      |
| Regional availability                           | Added support for Europe (Frankfurt) region. For more information, see [Regional availability](what-is-service.md#social-regions "what-is-service.md#social-regions").                                                                                                   | December 5, 2024   |
| Add a message and event destination             | Added support for Amazon Connect as an event destination. For more information, see [Add a message and event destination](managing-event-destinations-add.md "managing-event-destinations-add.md").                                                                      | December 1, 2024   |
| AWS PrivateLink                                 | Added support for AWS PrivateLink. For more information, see [AWS PrivateLink](vpc-interface-endpoints.md "vpc-interface-endpoints.md").                                                                                                                                 | October 22, 2024   |
| Initial release                                 | Initial release of the AWS End User Messaging Social User Guide                                                                                                                                                                                                          | October 10, 2024   |
