

# Document history for the AWS End User Messaging Social User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for AWS End User Messaging Social.

| Change | Description | Date | 
| --- |--- |--- |
| [Conversions API support](#doc-history) | AWS End User Messaging Social now supports sending conversion events for "Ads that Click to WhatsApp" campaigns to Meta for ad attribution and optimization. For more information, see [Sending WhatsApp conversion events](https://docs.aws.amazon.com/social-messaging/latest/userguide/conversions-api.html). | August 7, 2026 | 
| [WhatsApp Flows support](#doc-history) | AWS End User Messaging Social now supports creating and managing WhatsApp Flows for interactive, multi-screen experiences. For more information, see [Managing WhatsApp Flows](https://docs.aws.amazon.com/social-messaging/latest/userguide/managing-flows.html). | June 8, 2026 | 
| [Meta's Marketing Messages (MM) API support](#doc-history) | AWS End User Messaging Social now supports Meta's Marketing Messages API for marketing template messages. For more information, see [What is AWS End User Messaging Social?](https://docs.aws.amazon.com/social-messaging/latest/userguide/what-is-service.html). | April 23, 2026 | 
| [Regional availability](#doc-history) | Added support for Asia Pacific (Hong Kong), Asia Pacific (Taipei), Asia Pacific (Osaka), Asia Pacific (Jakarta), Asia Pacific (Melbourne), Asia Pacific (Malaysia), Asia Pacific (Thailand), Europe (Zurich), Europe (Milan), Europe (Paris), Israel (Tel Aviv), and US West (N. California) regions. For more information, see [Regional availability](https://docs.aws.amazon.com/social-messaging/latest/userguide/what-is-service.html#social-regions). | March 30, 2026 | 
| [Regional availability](#doc-history) | Added support for Asia Pacific (New Zealand), Canada West (Calgary), Europe (Stockholm), Middle East (Bahrain), Middle East (UAE), and Mexico (Central) regions. For more information, see [Regional availability](https://docs.aws.amazon.com/social-messaging/latest/userguide/what-is-service.html#social-regions). | February 3, 2026 | 
| [Support added for template management in the AWS Console](#doc-history) | Added support for WhatsApp template management in the AWS Console. For more information, see [Managing message templates in the AWS Console](https://docs.aws.amazon.com/social-messaging/latest/userguide/managing-templates-console-detailed.html). | December 18, 2025 | 
| [Support added for Amazon EventBridge events](#doc-history) | Added support for sending WhatsApp message events to EventBridge. For more information see [Monitoring with EventBridge](https://docs.aws.amazon.com/social-messaging/latest/userguide/monitor-event-bridge.html) | October 3, 2025 | 
| [Support added for new `MessageFee` types](#doc-history) | Six new `MessageFee` types that provide additional billing information are now available. For more information see [Understanding your bill](https://docs.aws.amazon.com/social-messaging/latest/userguide/billing.html). | September 30, 2025 | 
| [Deprecated the Charged per conversation topic](#doc-history) | The Charged per conversation topic in the Understanding your bill section has been deprecated. | September 30, 2025 | 
| [New API for creating WhatsApp message templates](#doc-history) | Added support for creating WhatsApp message templates using the AWS End User Messaging Social API. For more information, see [ Creating message templates with the CreateWhatsAppMessageTemplate API](https://docs.aws.amazon.com/social-messaging/latest/userguide/create-message-templates-api.html). | July 25, 2025 | 
| [Charged per message](#doc-history) | Starting on July 1 2025, AWS End User Messaging Social, charges per message instead of per conversation for WhatsApp messages. For more information, see [Charged per message](https://docs.aws.amazon.com/social-messaging/latest/userguide/charged-per-message.html).  | June 30, 2025 | 
| [Regional availability](#doc-history) | Added support for Europe (Frankfurt) region. For more information, see [Regional availability](https://docs.aws.amazon.com/social-messaging/latest/userguide/what-is-service.html#social-regions).  | December 5, 2024 | 
| [Add a message and event destination](#doc-history) | Added support for Connect Customer as an event destination. For more information, see [Add a message and event destination](https://docs.aws.amazon.com/social-messaging/latest/userguide/managing-event-destinations-add.html).  | December 1, 2024 | 
| [AWS PrivateLink](#doc-history) | Added support for AWS PrivateLink. For more information, see [AWS PrivateLink](https://docs.aws.amazon.com/social-messaging/latest/userguide/vpc-interface-endpoints.html).  | October 22, 2024 | 
| [Initial release](#doc-history) | Initial release of the AWS End User Messaging Social User Guide | October 10, 2024 |
