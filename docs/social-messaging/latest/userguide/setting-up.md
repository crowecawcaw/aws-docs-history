# Setting up AWS End User Messaging Social

Before you can use AWS End User Messaging Social for the first time, you must complete the following steps.

###### Topics

- [Sign up for an AWS account](#sign-up-for-aws "#sign-up-for-aws")
- [Next steps](#next-steps-setting-up "#next-steps-setting-up")

## Sign up for an AWS account

To get started with AWS, you need an AWS account. For information about creating an AWS account, see
[Getting started with an AWS account](../../../accounts/latest/reference/getting-started.md "../../../accounts/latest/reference/getting-started.md")
in the _AWS Account Management Reference Guide_.

## Next steps

Now that you're prepared to work with AWS End User Messaging Social, see [Getting started with AWS End User Messaging Social](getting-started-whatsapp.md "getting-started-whatsapp.md") for creating your WhatsApp Business Account (WABA) or
migrating your existing WABA.
