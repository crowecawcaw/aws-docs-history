# Document history for the AWS Entity Resolution User Guide

The following table describes the documentation releases for AWS Entity Resolution.

For notification about updates to this documentation, you can subscribe to the RSS feed. To
subscribe to RSS updates, you must have an RSS plug-in enabled for the browser you are
using.

| Change                                                                                                                                                                                     | Description                                                                                                                                                                                                                                                                                                               | Date               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| [Support for FIPS](vpc-interface-endpoints.md "vpc-interface-endpoints.md")                                                                                                                | AWS Entity Resolution now supports Federal Information Processing Standard (FIPS) 140-2 compliant endpoints through AWS PrivateLink.                                                                                                                                                                                      | October 21, 2025   |
| [ID mapping workflow – update](create-IDMW-rule-based-one-acct.md "create-IDMW-rule-based-one-acct.md")                                                                                    | Customers can now use incremental processing in a rule-based ID mapping workflow to more efficiently process large datasets. Customers can also delete records from an ID mapping workflow to help comply with data management regulations.                                                                               | September 22, 2025 |
| [Support for cross-Region](creating-matching-workflow-rule-based.md "creating-matching-workflow-rule-based.md")                                                                            | Customers can now use data in another AWS Region as input to an ID namespace, Mapping workflow, or an ID mapping workflow.                                                                                                                                                                                                | September 8, 2025  |
| [Support for enhanced rule conditions and incremental deletions](creating-matching-workflow-rule-based.md "creating-matching-workflow-rule-based.md")                                      | Customers can now use rule conditions with Boolean operators and new matching functions like ExactManyToMany, allowing for more precise matching criteria with combinations of exact and fuzzy matching. Additionally, customers can delete records incrementally in advanced matching workflows using an Amazon S3 file. | July 30, 2025      |
| [Match ID processing clarification](edit-matching-workflow.md "edit-matching-workflow.md")                                                                                                 | Added clarification that the **Modify or generate match ID** and the **Look up match ID** options require **Automatic** processing cadence in matching workflows.                                                                                                                                                         | July 17, 2025      |

| [Provider service-based matching workflow – update](prepare-third-party-input-data.md#prepare-third-party-data-tables "prepare-third-party-input-data.md#prepare-third-party-data-tables") | Customers can now use Digital Identifiers such as IPV4, IPV6, and MAID when using the TransUnion provider service-based matching workflow.                                                                                                                                                                                | April 21, 2025     |
| [Amazon CloudWatch Logs](cloudwatch-logs.md "cloudwatch-logs.md")                                                                                                                          | AWS Entity Resolution now supports CloudWatch Logs integration, allowing you to enable detailed workflow logging that captures job execution metrics, timing, and processing statistics which can be delivered to CloudWatch Logs, Amazon S3, or Amazon Data Firehose destinations.                                       | April 14, 2025     |
| [ID mapping workflow – update](create-id-mapping-workflow.md "create-id-mapping-workflow.md")                                                                                              | Customers can now set up AWS Glue partitioning when using an ID mapping workflow.                                                                                                                                                                                                                                         | March 25, 2025     |
| [Quotas – update](quotas.md "quotas.md")                                                                                                                                                   | Documentation-only update. Customers needing higher limits are directed to contact the service team.                                                                         | February 7, 2025   |
| [Schema mapping – update](create-schema-mapping.md "create-schema-mapping.md")                                                                                                             | Documentation-only update to clarify that normalization is supported for Full name, Full address, and Full phone attribute types.                                                                                                                                                                                         | January 17, 2025   |
| [Provider integration](provider-integration.md "provider-integration.md")                                                                                                                  | Documentation-only update. Customers can learn how to integrate as a provider service with AWS Entity Resolution.                                                                                                                                                                                                         | August 8, 2024     |
| [ID mapping workflow – update](create-id-mapping-workflow.md "create-id-mapping-workflow.md")                                                                                              | Customers can now use matching rules to translate first-party data in an ID mapping workflow.                                                                                                                                                                                                                             | July 23, 2024      |
| [Matching workflow – update](manage-matching-workflows.md#delete-records "manage-matching-workflows.md#delete-records")                                                                    | Customers can now delete the records from either a rule-based or ML-based matching workflow to help comply with data management regulations.                                                                                                                                                                              | April 8, 2024      |
| [ID mapping workflow – update](create-id-mapping-workflow.md "create-id-mapping-workflow.md")                                                                                              | Customers can now use an ID mapping workflow across multiple AWS accounts.                                                                                                                                                                                                                                                | April 2, 2024      |
