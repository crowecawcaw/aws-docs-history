| AWS IoT Device Defender now supports monitoring of device disconnect durations                                          | AWS IoT Device Defender Rules Detect now supports a new disconnect duration metric to monitor the duration<br>of disconnect of each device. You can also configure alarms<br>at predefined threshold levels and be alerted in the case of persistent device connectivity<br>issues. It also inspects for use of<br>MQTT wildcards in deny statements that could potentially be circumvented by devices when<br>replacing wildcards with specific strings. Besides setting static alarms manually with Rules Detect, you can now<br>use machine learning to automatically learn your fleet's expected behaviors on custom metrics.<br>Further, with the new [Dimensions filter](../../../iot/latest/developerguide/scoping-security-behavior.md "../../../iot/latest/developerguide/scoping-security-behavior.md") support for ML Detect, you can define attributes to evaluate more<br>precise metrics in your ML security profile. [Cloud-side<br>metrics](detect-cloud-side-metrics.md "detect-cloud-side-metrics.md") in the _AWS IoT Device Defender Developer Guide_ | September 14, 2022 |
