# Required permissions

To access Assurance Assistant, you can configure fine-grained access control with
IAM permissions. To simplify this process, two managed policies are available:

- `AWSArtifactComplianceInquiriesReadOnlyAccess` – Provides
  read-only access to Assurance Assistant.
- `AWSArtifactComplianceInquiriesFullAccess` – Provides full
  access to Assurance Assistant.
  For more information about IAM permissions for AWS Artifact, see
  [Identity and access management in AWS Artifact](security-iam.md "security-iam.md"). For a complete list of
  AWS Artifact actions, see [Actions defined
  by AWS Artifact](../../../service-authorization/latest/reference/list_awsartifact.md "../../../service-authorization/latest/reference/list_awsartifact.md"). For more information about managed policies, see
  [Using AWS managed policies for AWS Artifact](security-iam-awsmanpol.md "security-iam-awsmanpol.md").
