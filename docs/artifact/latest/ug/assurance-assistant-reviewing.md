# Reviewing AI-generated responses

After Assurance Assistant processes your questionnaire, you can review each generated
response before exporting.

###### To review AI-generated responses

1. Open the [AWS Artifact
   console](https://console.aws.amazon.com/artifact/home "https://console.aws.amazon.com/artifact/home").
2. In the navigation pane, choose **Assurance
   Assistant**.
3. If you entered a question manually and submitted, review the response summary
   and citations generated.
4. If you uploaded a file, on the **Compliance inquiries
   list**, select the question or questionnaire you want to
   review.
5. On the questionnaire detail page, review each question and its generated
   response along with the citations.
