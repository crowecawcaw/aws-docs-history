# Glossary

| Term               | Definition                                                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DDQ                | Due Diligence Questionnaire – a structured set of<br>questions used in vendor assessments and security reviews to<br>evaluate an organization's security and compliance<br>posture. |
| CAIQ               | Consensus Assessments Initiative Questionnaire – a<br>standardized due diligence questionnaire published by the Cloud<br>Security Alliance (CSA).                                   |
| SIG                | Standardized Information Gathering questionnaire – a<br>widely used due diligence questionnaire format for assessing<br>third-party vendors.                                        |
| SOC                | System and Organization Controls – a set of audit<br>report types (SOC 1, SOC 2, SOC 3) that evaluate service<br>organizations' controls.                                           |
| ISO                | International Organization for Standardization – a<br>globally recognized body that publishes standards, including ISO<br>27001 for information security management.                |
| Citation           | A reference to a specific statement in a verified AWS<br>compliance document that supports an AI-generated response,<br>allowing independent verification.                          |
| IAM                | AWS Identity and Access Management – the service<br>used to manage permissions and access to AWS resources,<br>including AWS Artifact features.                                     |
| Compliance inquiry | A record in Assurance Assistant that contains a submitted<br>question or questionnaire and the AI-generated<br>responses.                                                           |
