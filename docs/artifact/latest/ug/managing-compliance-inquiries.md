# Using Assurance Assistant in AWS Artifact

You can use Assurance Assistant in AWS Artifact to generate AI-powered responses to your
compliance and due diligence questions. Assurance Assistant maps your questions to AWS
security controls and generates pre-validated responses, reducing the time required to
complete compliance questionnaires.
