# Supported questionnaire formats

Assurance Assistant supports the following questionnaire formats for file
upload:

- **Excel (.xlsx)** – Supported with column
  mapping for question identification.
  Assurance Assistant is optimized for custom file formats and also supports the
  following industry-standard questionnaire types:

- **CAIQ** (Consensus Assessments Initiative
  Questionnaire)
- **SIG** (Standardized Information Gathering
  Questionnaire)
- **Custom DDQs** – Supported via the
  column mapping feature.
