# Submitting a questionnaire

You can use the AWS Artifact console to submit a Customer Due Diligence Questionnaire (DDQ)
for AI-powered response generation.

###### To submit a questionnaire using Assurance Assistant

1. Open the [AWS Artifact
   console](https://console.aws.amazon.com/artifact/home "https://console.aws.amazon.com/artifact/home").
2. In the navigation pane, choose **Assurance
   Assistant**.
3. Choose **Ask question**.
4. On the **Ask** page, do one of the following:
   - To upload a file, choose **Choose file**, select
     your questionnaire file, and then choose
     **Open**.
   - Enter questions manually into the text field.

5. If you uploaded a file, select at least one tab from the uploaded file for
   Assurance Assistant to process. Choose
   **Configure**.
6. If you entered a question manually, choose
   **Submit**.
