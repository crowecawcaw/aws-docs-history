# Networking with App Runner

This chapter describes networking configurations for your AWS App Runner services.

From this chapter you will learn the following:

- How to configure your incoming traffic for private and public endpoints. For more
  information, see [Setting up networking configurations for
  incoming traffic](network-incoming.md "network-incoming.md").
- How to configure your outgoing traffic to access to other applications running in an
  Amazon VPC. For more information, see [Enabling VPC access for
  outgoing traffic](network-vpc.md "network-vpc.md").
