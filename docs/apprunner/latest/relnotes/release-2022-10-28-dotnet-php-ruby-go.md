# Release: App Runner adds .Net, PHP, Ruby, and Go platforms on October 28, 2022

AWS App Runner added four new platforms for building and running web applications.

**Release date:** October 28, 2022

## Changes

AWS App Runner added support for building and running web applications with the following new platforms:

- .NET
  6

For more information about using the platform and the runtime release information, see [Using the .NET
platform](../dg/service-source-code-net6.md "../dg/service-source-code-net6.md") in the _AWS App Runner Developer Guide_.

- PHP
  8.1

For more information about using the platform and the runtime release information, see [Using
the PHP platform](../dg/service-source-code-php.md "../dg/service-source-code-php.md") in
the _AWS App Runner Developer Guide_.

- Ruby
  3.1

For more information about using the platform and the runtime release information, see [Using the Ruby
platform](../dg/service-source-code-ruby.md "../dg/service-source-code-ruby.md") in the _AWS App Runner Developer Guide_.

- Go
  1

For more information about using the platform and the runtime release information, see [Using
the Go platform](../dg/service-source-code-go1.md "../dg/service-source-code-go1.md") in the
_AWS App Runner Developer Guide_.
