# Release: App Runner adds support for FIPS endpoints on March 4, 2022

AWS App Runner added support for FIPS endpoints.

**Release date:** March 4, 2022

## Changes

AWS App Runner added support for FIPS endpoints in
AWS Regions within the United States. For information about AWS compliance with FIPS, see [Federal Information Processing Standard (FIPS) 140-2](https://aws.amazon.com/compliance/fips/ "https://aws.amazon.com/compliance/fips/").

For more information, see [AWS App Runner service endpoints](../../../general/latest/gr/apprunner.md#apprunner_region "../../../general/latest/gr/apprunner.md#apprunner_region") in the
_Amazon Web Services General Reference_.
