# Overview of Amazon Titan models

Amazon Titan foundation models (FMs) are a family of FMs pretrained by AWS on large datasets, making them powerful,
general-purpose models built to support a variety of use cases. Use them as-is or privately customize them
with your own data.

Amazon Titan supports the following models for Amazon Bedrock.

- **Amazon Titan Text**
- **Amazon Titan Text Embeddings V2**
- **Amazon Titan Multimodal Embeddings G1**
- **Amazon Titan Image Generator G1 V1**
