# Cohere Embed and Cohere Embed v4 models

You make inference requests to an Embed model with [InvokeModel](../APIReference/API_runtime_InvokeModel.md "../APIReference/API_runtime_InvokeModel.md") You need the model ID
for the model that you want to use. To get the model ID, see [Supported foundation models in Amazon Bedrock](models-supported.md "models-supported.md").

###### Note

Amazon Bedrock doesn't support streaming responses from Cohere Embed models.
