# API reference overview

The [Amazon Bedrock API Reference](../APIReference/welcome.md "../APIReference/welcome.md") provides detailed information about the Amazon Bedrock API actions and their parameters. For more information about setting up the Amazon Bedrock APIs, see [Set up the Amazon Bedrock API](api-setup.md "api-setup.md").

## Amazon Bedrock API endpoints

To connect programmatically to an AWS service, you use an endpoint. Refer to the [Amazon Bedrock endpoints and quotas](../../../general/latest/gr/bedrock.md "../../../general/latest/gr/bedrock.md") chapter in the AWS General Reference for information about the endpoints that you can use for Amazon Bedrock.

Amazon Bedrock provides the following service endpoints.

- `bedrock` – Contains control plane APIs for managing, training, and deploying models. For more information, see [Amazon Bedrock Actions](../APIReference/API_Operations_Amazon_Bedrock.md "../APIReference/API_Operations_Amazon_Bedrock.md") and [Amazon Bedrock Data Types](../APIReference/API_Types_Amazon_Bedrock.md "../APIReference/API_Types_Amazon_Bedrock.md").
- `bedrock-runtime` – Contains data plane APIs for making inference requests for models hosted in Amazon Bedrock. For more information, see [Amazon Bedrock Runtime Actions](../APIReference/API_Operations_Amazon_Bedrock_Runtime.md "../APIReference/API_Operations_Amazon_Bedrock_Runtime.md") and [Amazon Bedrock Runtime Data Types](../APIReference/API_Types_Amazon_Bedrock_Runtime.md "../APIReference/API_Types_Amazon_Bedrock_Runtime.md").
- `bedrock-agent` – Contains control plane APIs for creating and managing agents, knowledge bases, prompt management, and prompt flows. For more information, see [Amazon Bedrock Agents Actions](../APIReference/API_Operations_Agents_for_Amazon_Bedrock.md "../APIReference/API_Operations_Agents_for_Amazon_Bedrock.md") and [Amazon Bedrock Agents Data Types](../APIReference/API_Types_Agents_for_Amazon_Bedrock.md "../APIReference/API_Types_Agents_for_Amazon_Bedrock.md").
- `bedrock-agent-runtime` – Contains data plane APIs for invoking agents and flows, and querying knowledge bases. For more information, see [Amazon Bedrock Agents Runtime Actions](../APIReference/API_Operations_Agents_for_Amazon_Bedrock_Runtime.md "../APIReference/API_Operations_Agents_for_Amazon_Bedrock_Runtime.md") and [Amazon Bedrock Agents Runtime Data Types](../APIReference/API_Types_Agents_for_Amazon_Bedrock_Runtime.md "../APIReference/API_Types_Agents_for_Amazon_Bedrock_Runtime.md").

###### Note

Check that you're using the correct endpoint when making an API request.

## AWS SDK references

AWS software development kits (SDKs) are available for many popular programming languages. Each SDK provides an API, code examples, and documentation that make it easier for developers to build applications in their preferred language. SDKs automatically perform useful tasks for you, such as:

- Cryptographically sign your service requests
- Retry requests
- Handle error responses
