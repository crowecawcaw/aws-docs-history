# Custom model hyperparameters

The following reference content covers the hyperparameters that are available for training
each Amazon Bedrock custom model.

A hyperparameter is a parameter that controls the training process, such as the learning
rate or epoch count. You set hyperparameters for custom model training when you [submit](model-customization-submit.md "model-customization-submit.md") the fine tuning job
with the Amazon Bedrock console or by calling the [CreateModelCustomizationJob](../APIReference/API_CreateModelCustomizationJob.md "../APIReference/API_CreateModelCustomizationJob.md") API operation.
For guidelines on hyperparameter settings, see [Guidelines for model customization](custom-models.md#model-customization-guidelines "custom-models.md#model-customization-guidelines").
