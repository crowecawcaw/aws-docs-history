# Deploy and use an Amazon Bedrock agent in your application

Before you can use an agent, you must deploy the agent by creating an alias.
You can then use the agent in your application by calling the [InvokeAgent](../APIReference/API_agent-runtime_InvokeAgent.md "../APIReference/API_agent-runtime_InvokeAgent.md") operation.
In this section, you learn how to create and manage an alias and how to call your
agent from an application.

- [Invoke an agent from your application](agents-invoke-agent.md "agents-invoke-agent.md")
