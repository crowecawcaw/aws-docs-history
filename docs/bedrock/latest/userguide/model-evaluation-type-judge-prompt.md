# Built-in metric evaluator prompts for model-as-a-judge evaluation jobs

When you run a judge-based model evaluation job the _evaluator model_ scores the _generator model's_ responses according
to a set of metrics you define. Amazon Bedrock offers a number of built-in metrics, or you can define your own [custom metrics](model-evaluation-custom-metrics-prompt-formats.md "model-evaluation-custom-metrics-prompt-formats.md").

Refer to the following sections to see the prompts used by the available evaluator models for the Amazon Bedrock built-in metrics.
