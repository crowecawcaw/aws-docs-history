# Discover a model

You can discover both Amazon Bedrock Marketplace models and Amazon Bedrock serverless models from the
model catalog.

Use the following procedure to discover an Amazon Bedrock Marketplace model.

###### To discover an Amazon Bedrock Marketplace

model

1. Sign in to the AWS Management Console using an IAM role with Amazon Bedrock permissions.
2. In the search bar, specify "Amazon Bedrock" and choose the **Amazon Bedrock**
   from the
   dropdown
   list.
3. From
   the navigation pane, choose
   **Model
   Catalog**.
4. Filter for **Model Collection** = **Bedrock
   Marketplace** to load Amazon Bedrock Marketplace models.
5. Alternatively, you can search for the model name directly in the search
   bar.

###### Note

You must subscribe to proprietary models in Amazon Bedrock Marketplace to get access to
them.
