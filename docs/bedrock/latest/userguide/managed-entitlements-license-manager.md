

# Distribute through AWS License Manager
<a name="managed-entitlements-license-manager"></a>

Use AWS License Manager, the AWS Command Line Interface (AWS CLI), or the License Manager API to distribute any third-party Bedrock model subscription. Use this option for public offers and for private offers that you accept as part of an offer set. Also use it to distribute a private offer to specific accounts or organizational units (OUs), or to distribute a private offer that you didn't distribute when you accepted it.

You set up License Manager once for your organization, and then create and activate grants for each subscription.
