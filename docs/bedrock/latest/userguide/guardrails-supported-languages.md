# Languages supported by Amazon Bedrock Guardrails

Amazon Bedrock Guardrails supports a variety of languages. The following sections detail language support
for the specific policies offered by Amazon Bedrock Guardrails.

###### Important

We strongly recommend that you test the intended languages for your guardrails use
case. Guardrails are ineffective with languages that aren't supported.

**Key terms**

- **Optimized and supported** – The
  underlying models supporting the particular policy are tuned and tested for the
  specific language.
- **Supported** – The underlying models
  supporting the particular policy are tested but not tuned for the specific
  language.
