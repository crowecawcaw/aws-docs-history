# Models at a glance

Amazon Bedrock provides access to **104** foundation models
from **17** providers. Each model card below includes the
following details to help you evaluate and integrate a model into your application:

- **Model details** — Input/output modalities, supported APIs, and endpoints.
- **Capabilities and features** — Context window, and supported Amazon Bedrock features.
- **Pricing** — Link to the Amazon Bedrock pricing page.
- **Programmatic access** — Model IDs and endpoint URLs for API calls.
- **Service tiers** — Availability across Standard, Priority, Flex, and Reserved tiers.
- **Regional availability** — AWS Regions where the model is available and supported inference options.
- **Quotas and limits** — Default requests-per-minute and tokens-per-minute limits by Region.
- **Sample code** — Ready-to-run code examples for calling the model.
  For cross-model comparisons, see
  [API compatibility](apis.md "apis.md"),
  [Endpoint availability](endpoints.md "endpoints.md"), and
  [Regional availability](models-regions.md "models-regions.md").
