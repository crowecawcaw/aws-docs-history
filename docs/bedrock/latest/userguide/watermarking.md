

# Watermarking in Amazon Bedrock
<a name="watermarking"></a>

A watermark is a machine-readable signal embedded in AI-generated content. Some models in Amazon Bedrock add a watermark to the content that they generate. In text, the watermark is a statistical pattern in the model's token choices. In speech, it is a signal embedded in the media. Watermarks are not perceptible to people. Instead, detection tools, where the model provider makes them available, can identify the watermark.

### Amazon Nova Sonic models
<a name="watermarking-nova-sonic"></a>

Amazon Nova 2.5 Sonic and Amazon Nova 2 Sonic add an inaudible watermark to all speech that they generate. The watermark is enabled by default, and you can't disable it. The text transcripts in their responses don't carry a watermark.

To request watermark detection for an audio file, contact your AWS account team. For more information about these models, see [Amazon Nova 2.5 Sonic](https://docs.aws.amazon.com/ai/responsible-ai/nova-2-5-sonic/overview.html) and [Amazon Nova 2 Sonic](https://docs.aws.amazon.com/ai/responsible-ai/nova-2-sonic/overview.html) in *AWS AI Service Cards*.

### Anthropic Claude models
<a name="watermarking-anthropic-claude"></a>

The Claude models in the table add a text watermark to their output. The watermark is enabled by default, and you can't disable it. You don't need to change your requests to receive it, and it doesn't change the format of the API response.

Anthropic offers watermark detection for eligible organizations. For more information about how the watermark works and how to request detection access, see [How Claude marks AI-generated content](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content) on the Anthropic website.

## Limitations
<a name="watermarking-limitations"></a>

A detected watermark indicates that content was likely generated by a model that applies that watermark. A watermark is one input to customers' own transparency measures. It has the following limits:
+ A watermark does not prove who created the content, whether someone edited it, or whether the content is accurate.
+ A missing watermark does not prove that a person created the content.
+ Not every model in Amazon Bedrock adds a watermark, and editing, paraphrasing, translating, compressing, or cropping content can weaken or remove it.
+ Detection is probabilistic. Detection tools can miss a watermark or incorrectly report one, and detection is less reliable for short text.
+ A watermark is not a visible label or notice.

You are responsible for the content that you generate with Amazon Bedrock and for how your application uses it. This includes evaluating and meeting any transparency obligations that might apply.
