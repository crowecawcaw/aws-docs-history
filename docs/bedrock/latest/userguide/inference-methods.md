# Learn about use cases for different model inference methods

You can directly run model inference in the following ways:

| Method                                                                                                                                                                                                                                                                 | Use case                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [Amazon Bedrock console playgrounds](playgrounds.md "playgrounds.md")                                                                                                                                                                                                  | Run inference in a user-friendly graphical interface. Convenient for exploration.                                                 |
| [Converse](../APIReference/API_runtime_Converse.md "../APIReference/API_runtime_Converse.md") or [ConverseStream](../APIReference/API_runtime_ConverseStream.md "../APIReference/API_runtime_ConverseStream.md")                                                       | Implement conversational applications with a unified API for model input.                                                         |
| [InvokeModel](../APIReference/API_runtime_InvokeModel.md "../APIReference/API_runtime_InvokeModel.md") or [InvokeModelWithResponseStream](../APIReference/API_runtime_InvokeModelWithResponseStream.md "../APIReference/API_runtime_InvokeModelWithResponseStream.md") | Submit a single prompt and generate a response synchronously. Useful for generating responses in real time or for search queries. |
| [StartAsyncInvoke](../APIReference/API_runtime_StartAsyncInvoke.md "../APIReference/API_runtime_StartAsyncInvoke.md")                                                                                                                                                  | Submit a single prompt and generate a response asynchronously. Useful for generating responses at a large scale.                  |
| [CreateModelInvocationJob](../APIReference/API_CreateModelInvocationJob.md "../APIReference/API_CreateModelInvocationJob.md")                                                                                                                                          | Prepare a dataset of prompts and generate responses in batches.                                                                   |

The following Amazon Bedrock features also use model inference as a step in a larger workflow:

- [Model evaluation](evaluation.md "evaluation.md") uses the model invocation process to evaluate the performance of different models after you submit a [CreateEvaluationJob](../APIReference/API_CreateEvaluationJob.md "../APIReference/API_CreateEvaluationJob.md") request.
- [Knowledge bases](knowledge-base.md "knowledge-base.md") use model invocation when using the [RetrieveAndGenerate](../APIReference/API_agent-runtime_RetrieveAndGenerate.md "../APIReference/API_agent-runtime_RetrieveAndGenerate.md") API to generate a response based on results retrieved from a knowledge base.
- [Agents](agents.md "agents.md") use model invocation to generate responses in various stages during an [InvokeAgent](../APIReference/API_agent-runtime_InvokeAgent.md "../APIReference/API_agent-runtime_InvokeAgent.md") request.
- [Flows](flows.md "flows.md") include Amazon Bedrock resources, such as prompts, knowledge bases, and agents, which use model invocation.
  After testing out different foundation models with different prompts and inference parameters, you can configure your application to call these APIs with your desired specifications.
