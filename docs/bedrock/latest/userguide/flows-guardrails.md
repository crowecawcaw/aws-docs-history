# Include guardrails in your flow in Amazon Bedrock

Amazon Bedrock Flows integrates with Amazon Bedrock Guardrails to let you identify and block or filter unwanted content in your flow. To learn how to apply guardrails to supported node types in a flow, see the following table:

| Node type           | Console                                                                                                                                                                                                                                                                                   | API                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Prompt node         | When you [create](flows-create.md "flows-create.md") or [update](flows-modify.md "flows-modify.md") a flow, select the prompt node and specify the guardrail in the **Configure** section.                                                                                                | When you define the prompt node in the `nodes` field in a [CreateFlow](../APIReference/API_agent_CreateFlow.md "../APIReference/API_agent_CreateFlow.md") or [UpdateFlow](../APIReference/API_agent_UpdateFlow.md "../APIReference/API_agent_UpdateFlow.md") request, include a `guardrailConfiguration` field in the [PromptFlowNodeConfiguration](../APIReference/API_agent_PromptFlowNodeConfiguration.md "../APIReference/API_agent_PromptFlowNodeConfiguration.md").                                                                                                                                 |
| Knowledge base node | When you [create](flows-create.md "flows-create.md") or [update](flows-modify.md "flows-modify.md") a flow, select the knowledge base node and specify the guardrail in the **Configure** section. You can only include a guardrail when generating responses based on retrieved results. | When you define the knowledge base node in the `nodes` field in a [CreateFlow](../APIReference/API_agent_CreateFlow.md "../APIReference/API_agent_CreateFlow.md") or [UpdateFlow](../APIReference/API_agent_UpdateFlow.md "../APIReference/API_agent_UpdateFlow.md") request, include a `guardrailConfiguration` field in the [KnowledgeBaseFlowNodeConfiguration](../APIReference/API_agent_KnowledgeBaseFlowNodeConfiguration.md "../APIReference/API_agent_KnowledgeBaseFlowNodeConfiguration.md"). You can only include a guardrail when using `RetrieveAndGenerate` so you must include a `modelId`. | For more information about guardrails, see [Detect and filter harmful content by using Amazon Bedrock Guardrails](guardrails.md "guardrails.md"). For more information about node types, see [Node types for your flow](flows-nodes.md "flows-nodes.md"). |
