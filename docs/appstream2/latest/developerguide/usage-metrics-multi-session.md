# Fleet Usage Metrics for Multi-session Fleets

The following are fleet usage metrics for multi-session fleets.

| Metric                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Dimensions | Statistics                     | Units   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- | ------------------------------ | ------- |
| `CapacityUtilization`                | The percentage of sessions in a fleet that are being used,<br>using the following formula.<br>`<br>CapacityUtilization = (ActiveUserSessionCapacity / ActualUserSessionCapacity)<br>• 100<br>`<br>Monitoring this metric helps with decisions about increasing<br>or decreasing the value of a fleet's desired<br>capacity.                                                                                                                                                                                                                                                                                                          | [Fleet]    | Average, Minimum, Maximum      | Percent |
| `ActualUserSessionCapacity`          | The total number of session slots that are available for<br>streaming or are currently streaming.<br>`<br>ActualUserSessionCapacity = AvailableUserSessionCapacity + ActiveUserSessionCapacity<br>`                                                                                                                                                                                                                                                                                                                                                                                                                                  | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `AvailableUserSessionCapacity`       | The number of idle session slots currently available for user<br>sessions.<br>`<br>AvailableUserSessionCapacity = ActualUserSessionCapacity<br>• ActiveUserSessions<br>`                                                                                                                                                                                                                                                                                                                                                                                                                                                             | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `DesiredUserSessionCapacity`         | The total number of session slots that are either running or<br>pending. This represents the total number of concurrent<br>streaming sessions your fleet can support in a steady<br>state.<br>`<br>DesiredUserSessionCapacity = ActualUserSessionCapacity + PendingUserSessionCapacity<br>`                                                                                                                                                                                                                                                                                                                                          | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `ActiveUserSessionCapacity`          | The number of user sessions currently being used for streaming<br>sessions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `PendingUserSessionCapacity`         | The number of session slots being provisioned by WorkSpaces Applications.<br>Represents the additional number of streaming sessions the fleet<br>can support after provisioning is complete. When provisioning<br>starts, it usually takes 10-20 minutes for an instance to become<br>available for streaming.                                                                                                                                                                                                                                                                                                                       | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `RunningUserSessionCapacity`         | The total number of session slots currently that are available<br>for streaming or are currently streaming. Represents the number<br>of concurrent streaming sessions that can be supported by the<br>fleet in its current state.<br>This metric is provided for Always-On fleets only, and has the<br>same value as the `ActualUserSessionCapacity`<br>metric.                                                                                                                                                                                                                                                                      | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `DrainingCapacity`                   | The number of instances in Drain Mode.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `DrainModeActiveUserSessionCapacity` | The number of active user sessions on instances in Drain Mode.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `DrainModeUnusedUserSessionCapacity` | The number of unused session slots on instances in Drain Mode which cannot be used for user session provisioning.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `ActualCapacity`                     | The total number of instances that are available for streaming<br>or are currently streaming. For multi-session fleets, this metric<br>represents instance-level capacity. The relationship between<br>instance-level and session-level capacity is as follows:<br>`<br>ActualUserSessionCapacity = ActualCapacity × (Maximum number of user sessions per instance)<br>`<br>`<br>ActualCapacity = ActualUserSessionCapacity / (Maximum number of user sessions per instance)<br>`                                                                                                                                                    | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `DesiredCapacity`                    | The total number of instances that are either running or<br>pending. This represents the total number of instances your fleet<br>targets in a steady state. For multi-session fleets, the<br>relationship between instance-level and session-level capacity is<br>as follows:<br>`<br>DesiredUserSessionCapacity = DesiredCapacity × (Maximum number of user sessions per instance)<br>`<br>`<br>DesiredCapacity = DesiredUserSessionCapacity / (Maximum number of user sessions per instance)<br>`                                                                                                                                  | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `InUseCapacity`                      | The number of instances currently being used for streaming<br>sessions. For multi-session fleets, an instance is considered in<br>use if it has at least one active user session. The relationship<br>between instance-level and session-level capacity is as<br>follows:<br>`<br>ActiveUserSessionCapacity = InUseCapacity × (Maximum number of user sessions per instance)<br>`<br>`<br>InUseCapacity = ActiveUserSessionCapacity / (Maximum number of user sessions per instance)<br>`                                                                                                                                            | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `PendingCapacity`                    | The number of instances being provisioned by WorkSpaces Applications. Represents<br>the additional number of instances the fleet will have after<br>provisioning is complete. When provisioning starts, it usually<br>takes 10-20 minutes for an instance to become available for<br>streaming. For multi-session fleets, the relationship between<br>instance-level and session-level capacity is as follows:<br>`<br>PendingUserSessionCapacity = PendingCapacity × (Maximum number of user sessions per instance)<br>`<br>`<br>PendingCapacity = PendingUserSessionCapacity / (Maximum number of user sessions per instance)<br>` | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `RunningCapacity`                    | The total number of instances currently running. Represents the<br>number of instances that can support streaming sessions in the<br>fleet's current state. For multi-session fleets, the<br>relationship between instance-level and session-level capacity is<br>as follows:<br>`<br>RunningUserSessionCapacity = RunningCapacity × (Maximum number of user sessions per instance)<br>`<br>`<br>RunningCapacity = RunningUserSessionCapacity / (Maximum number of user sessions per instance)<br>`<br>This metric is provided for Always-On fleets only, and has the<br>same value as the `ActualCapacity` metric.                  | [Fleet]    | Average, Minimum, Maximum      | Count   |
| `InsufficientCapacityError`          | The number of session requests rejected due to lack of capacity.<br>This metric applies the same way for both single-session and<br>multi-session fleets.<br>You can set alarms to use this metric to be notified of users<br>waiting for streaming sessions.                                                                                                                                                                                                                                                                                                                                                                        | [Fleet]    | Average, Minimum, Maximum, Sum | Count   |
