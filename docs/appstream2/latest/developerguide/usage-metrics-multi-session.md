# Fleet Usage Metrics for Multi-session Fleets

The following are fleet usage metrics for multi-session fleets.

| Metric                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CapacityUtilization`          | The percentage of sessions in a fleet that are being used,<br>using the following formula.<br>`<br>CapacityUtilization = (ActiveUserSessionCapacity / ActualUserSessionCapacity)<br>• 100<br>`<br>Monitoring this metric helps with decisions about increasing<br>or decreasing the value of a fleet's desired<br>capacity.<br>Units: Percent<br>Valid statistics: Average, Minimum, Maximum                                   |
| `ActualUserSessionCapacity`    | The total number of session slots that are available for<br>streaming or are currently streaming.<br>`<br>ActualUserSessionCapacity = AvailableUserSessionCapacity + ActiveUserSessionCapacity<br>`<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum                                                                                                                                                             |
| `AvailableUserSessionCapacity` | The number of idle session slots currently available for user<br>sessions.<br>`<br>AvailableUserSessionCapacity = ActualUserSessionCapacity<br>• ActiveUserSessions<br>`<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum                                                                                                                                                                                        |
| `DesiredUserSessionCapacity`   | The total number of session slots that are either running or<br>pending. This represents the total number of concurrent<br>streaming sessions your fleet can support in a steady<br>state.<br>`<br>DesiredUserSessionCapacity = ActualUserSessionCapacity + PendingUserSessionCapacity<br>`<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum                                                                     |
| `ActiveUserSessionCapacity`    | The number of user sessions currently being used for streaming<br>sessions.<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum                                                                                                                                                                                                                                                                                     |
| `PendingUserSessionCapacity`   | The number of session slots being provisioned by WorkSpaces Applications.<br>Represents the additional number of streaming sessions the fleet<br>can support after provisioning is complete. When provisioning<br>starts, it usually takes 10-20 minutes for an instance to become<br>available for streaming.<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum                                                  |
| `RunningUserSessionCapacity`   | The total number of session slots currently that are available<br>for streaming or are currently streaming. Represents the number<br>of concurrent streaming sessions that can be supported by the<br>fleet in its current state.<br>This metric is provided for Always-On fleets only, and has the<br>same value as the `ActualUserSessionCapacity`<br>metric.<br>Units: Count<br>Valid statistics: Average, Minimum, Maximum |
