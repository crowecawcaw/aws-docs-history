# Instance and Session Performance Metrics for Multi-session Fleets

The following are instance and session performance metrics for multi-session fleets.

| Metric                          | Description                                                                                                                      |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `CpuUtilizationInstance`        | The percentage of allocated compute units that are currently<br>in use on the instance.<br>Units: Percent                        |
| `MemoryUtilizationInstance`     | The percentage of allocated physical memory units that are<br>currently in use on the instance.<br>Units: Percent                |
| `PagingFileUtilizationInstance` | The percentage of the paging file that is currently in use to<br>extend the Memory (RAM) capacity.<br>Units: Percent             |
| `DiskUtilizationInstance`       | The percentage of disk units that are currently in use to run<br>programs and carry out tasks on the instance.<br>Units: Percent |
| `CpuUtilizationSession`         | The percentage of allocated compute units that are currently<br>in use by the session.<br>Units: Percent                         |
| `MemoryUtilizationSession`      | The percentage of allocated physical memory units that are<br>currently in use by the session.<br>Units: Percent                 |
