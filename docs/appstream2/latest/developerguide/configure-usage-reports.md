# AppStream 2.0 Usage Reports

You can subscribe to Amazon AppStream 2.0 usage reports to receive detailed reports about how your
users are using the service. Two .csv files are exported to an Amazon Simple Storage Service (Amazon S3) bucket in
your account every day.

###### Note

To enable AppStream 2.0 usage reports, you must use an image that uses a version of the AppStream 2.0 agent released on or after May 7, 2019.
