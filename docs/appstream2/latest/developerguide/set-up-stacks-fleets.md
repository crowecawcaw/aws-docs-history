# Create an Amazon AppStream 2.0 Fleet and Stack

To stream your applications, Amazon AppStream 2.0 requires an environment that includes a fleet that
is associated with a stack, as well as at least one application image. This tutorial
describes the steps to set up a fleet and stack, and how to give users access to the stack.
If you haven't already done so, we recommend that you try the procedures in [Get Started with Amazon AppStream 2.0: Set Up With Sample Applications](getting-started.md "getting-started.md") first.

If you want to create an image to use, see [Tutorial: Create a Custom AppStream 2.0 Image by Using the
AppStream 2.0 Console](tutorial-image-builder.md "tutorial-image-builder.md").

If you plan to join a fleet to an Active Directory domain, configure your Active Directory
domain before completing the following steps. For more information, see [Using Active Directory with AppStream 2.0](active-directory.md "active-directory.md").
