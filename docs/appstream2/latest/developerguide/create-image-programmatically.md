# Programmatically Create a New Image in Amazon AppStream 2.0

You can create AppStream 2.0 images programmatically by connecting to an image builder and using the Image Assistant command line interface (CLI) operations. For more information, see [Create Your Amazon AppStream 2.0 Image Programmatically by Using the Image Assistant CLI Operations](programmatically-create-image.md "programmatically-create-image.md").
