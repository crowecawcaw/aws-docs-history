# Setup and installation for macOS

Follow these steps to download and install the client application.

1. On your macOS device, open [Amazon AppStream 2.0
   Downloads](https://clients.amazonappstream.com/ "https://clients.amazonappstream.com/"), and choose the macOS link.
2. Download and install the application.
3. Verify that the AppStream 2.0 client application icon appears on your Mac
   Launchpad, or check in
   `/Users/username/Applications/` or
   `~/Applications`.
