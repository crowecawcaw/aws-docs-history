# AppStream 2.0 Client Release Notes

The AppStream 2.0 client is a native application that is designed for users who require additional functionality during their AppStream 2.0 streaming sessions. The following table describes the latest updates that are available in released versions
of the AppStream 2.0 client.

For more information about the client, see [Provide Access Through the AppStream 2.0 Client](client-application.md "client-application.md").
