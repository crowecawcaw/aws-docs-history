

# Provide agents access to WorkSpaces
<a name="agent-access"></a>

Amazon WorkSpaces Applications enables AI agents to connect to streaming sessions and interact with desktop applications using a managed Model Context Protocol (MCP) service. You can also enable human observers to watch agent sessions in real time and stop agents if needed. Use the topics in this section to set up, configure, and build agents that use Amazon WorkSpaces Applications.
