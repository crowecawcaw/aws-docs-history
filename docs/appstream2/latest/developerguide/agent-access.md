

# Provide agents access to WorkSpaces
<a name="agent-access"></a>

Amazon WorkSpaces Applications enables AI agents to connect to remote compute environments and operate desktop applications using a managed Model Context Protocol (MCP) server. You can also let human observers watch agent sessions in real time and stop them if needed. Use the topics in this section to set up, configure, and build agents that use Amazon WorkSpaces Applications.
