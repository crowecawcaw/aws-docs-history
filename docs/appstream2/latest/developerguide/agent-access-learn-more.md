

# Why WorkSpaces for AI agents?
<a name="agent-access-learn-more"></a>

WorkSpaces for AI agents gives AI agents a mouse, keyboard, and screen to operate desktop, legacy, and browser-based applications just like a person does, so agents can take on tasks that previously required a human operator. WorkSpaces for AI agents is the agent access feature of Amazon WorkSpaces Applications. This section helps you decide whether it fits your needs. It covers what kinds of work agents can do, how it works, which agents and models you can use, what to expect for performance and cost, and best practices for building and evaluating computer-use agents.
