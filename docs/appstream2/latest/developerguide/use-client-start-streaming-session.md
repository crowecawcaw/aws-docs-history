# Configure a Connection Method for Your AppStream 2.0 Client Users

After you install the AppStream 2.0 client on your users' local computers, they can use
the AppStream 2.0 client to connect to a streaming session. Depending on your
organizational requirements, you can provide client users with access to AppStream 2.0 by doing one of the following: Setting up identity federation using SAML 2.0, using an AppStream 2.0 user pool, or creating a streaming URL.
