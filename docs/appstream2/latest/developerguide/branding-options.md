# Custom Branding Options for Amazon WorkSpaces Applications

You can customize the appearance of the streaming application catalog page by using
the following branding options.

###### Note

Custom branding is not available for the user pool sign-in portal or for the email notifications that WorkSpaces Applications sends to user pool users.

| Branding element           | Description                                                                                                                                                                                                                                                                                                                                     | Requirements and recommendations                                                                                                                                                                                            |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Organization logo          | Enables you to display an image that is familiar to your users. The image appears in the<br>header of the streaming application catalog page, which is displayed<br>to users after they sign in to WorkSpaces Applications.                                                                                                                     | File type: .png, jpg, .jpeg, or .gif<br>Maximum dimensions: 1000 px x 500 px<br>Maximum file size: 300 KB                                                                                                                   |
| Organization website links | Enables you to display links to helpful resources for your users,<br>such as your organization's IT support and product marketing sites.<br>The links are displayed in the footer of the streaming application<br>catalog page.                                                                                                                 | Maximum number of links: 3<br>Format (URL): https://example.com or http://example.com<br>Maximum length (display name): 100 letters, spaces, and<br>numbers<br>Special characters allowed (display name): @ . / # & +<br>$  |
| Color theme                | Applied to website links, text, and buttons. These colors are also applied as accents in the<br>background for the streaming application catalog page.                                                                                                                                                                                          | Predefined themes from which to choose: 4<br>For information about each color theme, see [Color Theme Palettes in Amazon WorkSpaces Applications](branding-color-themes.md "branding-color-themes.md") later in this topic. |
| Page title                 | Displayed at the top of the browser tab during users' application<br>streaming sessions.                                                                                                                                                                                                                                                        | Maximum length: 200 letters, spaces, and numbers.<br>Special characters allowed: @ . / # & + $                                                                                                                              |
| Favicon                    | Enables your users to recognize their application streaming site in a browser full of tabs or<br>bookmarks. The favicon icon is displayed at the top of the browser<br>tab for the application streaming site during users' streaming<br>sessions.                                                                                              | File type: .png, .jpg, .jpeg, .gif, or .ico<br>Maximum dimensions: 128 px x 128 px<br>Maximum file size: 50 KB                                                                                                              |
| Redirect URL               | Enables you to specify a URL to which users are redirected when they<br>end a streaming session.                                                                                                                                                                                                                                                | Format: https://example.com or http://example.com<br>This URL is configured in the **Details\*<br>• page<br>for a stack when you create or edit a stack, not in the<br>**Branding\*<br>• page.                              |
| Feedback URL               | Enables you to specify a URL for a **Send Feedback**<br>link, so that your users can submit feedback to the organization. If you<br>do not specify a URL, the **Send Feedback\*<br>• link is not<br>displayed. Your users can still submit new portal feedback by selecting<br>**Provide New Portal Feedback\*\*, which is submitted<br>to AWS. | Format: https://example.com or http://example.com<br>This URL is configured in the **Details\*<br>• page<br>for a stack when you create or edit a stack, not in the<br>**Branding\*<br>• page.                              |
