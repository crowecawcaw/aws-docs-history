# Enable Regional Settings for Your WorkSpaces Applications Users

WorkSpaces Applications lets you or your users configure certain Windows settings that are specific to your
users' location or language. WorkSpaces Applications also lets you configure regional settings while creating
Linux images. For more information, see [Tutorial: Enable Japanese Support for Your Linux Images](enable-japanese-support-linux.md "enable-japanese-support-linux.md").
