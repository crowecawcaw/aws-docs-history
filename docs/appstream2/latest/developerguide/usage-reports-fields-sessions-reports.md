# Sessions Report Fields

The following table describes the fields included in WorkSpaces Applications sessions reports.

| Field name                                       | Description                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- | -------------- |
| `user_session_id`                                | The unique identifier (ID) for the session.                                                                                                                                                                                                                                                      |
| `aws_account_id`                                 | The Amazon Web Services account ID.                                                                                                                                                                                                                                                              |
| `region`                                         | The AWS Region.                                                                                                                                                                                                                                                                                  |
| `session_start_time`                             | The date and time that the session started. Must be specified<br>in ISO 8601 format and as UTC.                                                                                                                                                                                                  |
| `session_end_time`                               | The date and time that the session ended. Must be specified in<br>ISO 8601 format and as UTC.                                                                                                                                                                                                    |
| `session_duration_in_seconds`                    | The duration of the session in seconds.                                                                                                                                                                                                                                                          |
| `user_id`                                        | The unique ID for the user within the authentication<br>type.                                                                                                                                                                                                                                    |
| `user_arn`                                       | The Amazon Resource Name (ARN) for the user.                                                                                                                                                                                                                                                     |
| `authentication_type`                            | The method used to authenticate the user.<br>Possible values: `CUSTOM`                                                                                                                                                                                                                           | `SAML`          | <br>`USERPOOL` |
| `authentication_type_user_id`                    | The concatenation of the user ID and authentication type, which<br>uniquely identifies the user for the purpose of assessing user fees.<br>For more information, see [WorkSpaces Applications Pricing](https://aws.amazon.com/appstream2/pricing/ "https://aws.amazon.com/appstream2/pricing/"). |
| `fleet_name`                                     | The name of the fleet associated with the session.                                                                                                                                                                                                                                               |
| `stack_name`                                     | The name of the stack associated with the session.                                                                                                                                                                                                                                               |
| `instance_type`                                  | The WorkSpaces Applications instance type used for the session. For a list of<br>instance types, see [WorkSpaces Applications Pricing](https://aws.amazon.com/appstream2/pricing/ "https://aws.amazon.com/appstream2/pricing/").                                                                 |
| `eni_private_ip_address`                         | The IP address of the elastic network interface used by the<br>WorkSpaces Applications instance for network communications.                                                                                                                                                                      |
| `connected_at_least_once`                        | Indicates whether the user connected to the session at least<br>once.<br>Possible values: `true`                                                                                                                                                                                                 | `false`         |
| `client_ip_addresses`                            | The IP addresses associated with the user device or devices used<br>to connect to the session. If the user connected and then<br>disconnected from the session more than once, up to the last 10<br>distinct IP addresses are stored, separated by semicolons.                                   |
| `google_drive_enabled`                           | Indicates whether Google Drive was enabled as a persistent<br>storage option for the session. For more information, see [Enable and Administer Google Drive for Your WorkSpaces Applications<br>Users](google-drive.md "google-drive.md").<br>Possible values: `true`                            | `false`         |
| `one_drive_enabled`                              | Indicates whether OneDrive was enabled as a persistent storage<br>option for the session. For more information, see [Enable and Administer Google Drive for Your WorkSpaces Applications<br>Users](google-drive.md "google-drive.md").<br>Possible values: `true`                                | `false`         |
| `home_folders_storage_location`                  | The Amazon S3 bucket used for files that are stored using home<br>folders.                                                                                                                                                                                                                       |
| `user_settings_clipboard_copy_from_local_device` | Indicates whether the user was able to copy data from the<br>local device to the streaming session using the clipboard during<br>the session.<br>Possible values: `ENABLED`                                                                                                                      | <br>`DISABLED`  |
| `user_settings_clipboard_copy_to_local_device`   | Indicates whether the user was able to copy data from the<br>streaming session to the local device using the clipboard during<br>the session.<br>Possible values: `ENABLED`                                                                                                                      | <br>`DISABLED`  |
| `user_settings_file_upload`                      | Indicates whether the user was able to upload files from the<br>local device to the streaming session during the session.<br>Possible values: `ENABLED`                                                                                                                                          | <br>`DISABLED`  |
| `user_settings_file_download`                    | Indicates whether the user was able to download files from the<br>streaming session to the local device during the session.<br>Possible values: `ENABLED`                                                                                                                                        | <br>`DISABLED`  |
| `user_settings_printing_to_local_device`         | Indicates whether the user was able to print files from the<br>streaming session to the local device during the session.<br>Possible values: `ENABLED`                                                                                                                                           | <br>`DISABLED`  |
| `application_settings_enabled`                   | Indicates whether application settings persistence was enabled<br>for the session.<br>Possible values: `true`                                                                                                                                                                                    | `false`         |
| `domain_joined`                                  | Indicates whether the WorkSpaces Applications streaming instance was joined to<br>an Active Directory domain at session launch. For more<br>information, see [Using Active Directory with WorkSpaces Applications](active-directory.md "active-directory.md").<br>Possible values: `Y`           | `N`             |
| `max_session_duration`                           | The maximum allowed duration of the session, in seconds.                                                                                                                                                                                                                                         |
| `session_type`                                   | The session type.<br>Possible values: `ALWAYS_ON`                                                                                                                                                                                                                                                | <br>`ON_DEMAND` |
| `stream_view`                                    | The stream view.<br>Possible values: `APPLICATION`                                                                                                                                                                                                                                               | <br>`DESKTOP`   |
| `streaming_experience_settings_protocol`         | The protocol that the session ended streaming with.<br>Possible values: `UDP`                                                                                                                                                                                                                    | `TCP`           |
| `instance_id`                                    | The instance ID associated with the user session.                                                                                                                                                                                                                                                |
| `is_multisession`                                | Indicates whether the session belongs to a multi-session<br>fleet.<br>Possible values: `true`                                                                                                                                                                                                    | `false`         |
