# Configure a Connection Method for Your AppStream 2.0 Users (Web Browser)

Depending on your
organizational requirements, you can provide users with access to AppStream 2.0 through a web browser by doing one of the following: Setting up identity federation using SAML 2.0, using an AppStream 2.0 user pool, or creating a streaming URL.
