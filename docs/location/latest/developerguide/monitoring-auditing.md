# Monitoring and Auditing

Monitoring and Auditing provides capabilities to track, monitor, and log activities in your Amazon Location Services environment. With Amazon CloudWatch and AWS CloudTrail,
you can ensure the reliability, security, and compliance of your applications.

These tools help you observe resource performance metrics, detect anomalies,
and log API activity for auditing and troubleshooting. Use them to enhance operational insights, diagnose issues, and ensure adherence to compliance standards.
