# Create your first Geofences and Trackers

application

In this section, you'll create an application that demonstrates the key features of
using the Amazon Location Geofences and Trackers. The applications demonstrate how a tracker
and geofence interact using a combination of Lambda, AWS IoT, and Amazon Location features.
Choose iOS or Android platform to get started.

Before you start to build your application, follow the procedures in [Use the Amazon Location Service console to authenticate](set-up-auth.md "set-up-auth.md") to grant appropriate access.

###### Continue with the procedures for your preferred operating

system:

- [Create an iOS application](ios-geofence-app.md "ios-geofence-app.md")
- [Create an Android application](android-geofence-app.md "android-geofence-app.md")
