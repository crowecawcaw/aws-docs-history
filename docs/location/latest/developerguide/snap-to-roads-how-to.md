# Learn how to use SnapToRoads

This topic explains how to use `SnapToRoads` to align GPS traces with road
networks, enhancing positional accuracy for navigation and fleet management applications.
This API corrects GPS drift and signal loss by snapping coordinates to the nearest road
segments, while also respecting travel mode restrictions. Examples illustrate practical uses,
such as overlaying GPS traces, filling data gaps, and reducing noise for clearer route
visualization.
