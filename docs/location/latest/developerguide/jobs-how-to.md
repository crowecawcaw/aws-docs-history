# How to

This section provides step-by-step instructions for performing specific tasks with the
Amazon Location Jobs APIs. These guides are designed to help you quickly and effectively
implement key functionality. Each topic focuses on a distinct use case, ensuring you
have the practical knowledge needed to integrate Jobs API features into your
applications.

## Set up prerequisites

Before running jobs, set up the required AWS resources.

###### Note

The Amazon S3 input and output buckets you create must exist in the same
AWS Region where you plan to run your jobs. The IAM resources you create must be created in the same account.

- [Create Amazon S3 buckets](create-s3-buckets-jobs-apis.md "create-s3-buckets-jobs-apis.md")
- [Configure IAM permissions](configure-iam-role-policy-credentials.md "configure-iam-role-policy-credentials.md")
- [Prepare input data](preparing-input-data.md "preparing-input-data.md")
- [Upload input data](uploading-input-data.md "uploading-input-data.md")
