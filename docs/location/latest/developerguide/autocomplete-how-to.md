# How to use Autocomplete

This topic demonstrates how to use the Autocomplete API to efficiently retrieve address
suggestions based on user input. It covers two key applications: basic address
autocompletion, which suggests addresses as users type, and filtered autocompletion,
allowing users to narrow results by criteria such as region or specific location types.
These examples provide practical guidance for integrating Autocomplete into applications to
enhance search relevance and user experience.
