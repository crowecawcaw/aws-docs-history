# Manage billing and costs with AWS Billing and Cost Management

AWS Billing and Cost Management is a web service that provides features that helps you pay your bills and optimize your costs. Amazon Web Services bills your account for usage, which ensures that you pay only for what you use.

###### How to see bills and manage cost

1. Open [Billing and Cost Management](https://console.aws.amazon.com/billing "https://console.aws.amazon.com/billing")
   in the AWS Management Console.
2. Search for location
   service in Amazon Web Services, Inc. charges by service
3. Choose **[+] Location service**
4. Choose **[+] Region Name**
   To learn more, see [Billing and Cost Management](https://console.aws.amazon.com/costmanagement/home#/getting-started "https://console.aws.amazon.com/costmanagement/home#/getting-started") in the AWS Management Console.
