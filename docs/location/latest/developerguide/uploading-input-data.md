

# Upload input data
<a name="uploading-input-data"></a>

After preparing your input data in Apache Parquet format, upload the files to your Amazon S3 input bucket.

For detailed instructions on uploading files to Amazon S3, see [Uploading objects](https://docs.aws.amazon.com/AmazonS3/latest/userguide/upload-objects.html) in the *Amazon S3 User Guide*.

After uploading your input files, you can start a job. For more information, see [Start a job](starting-a-job.md).
