# Upload input data

After preparing your input data in Apache Parquet format, upload the files to your Amazon S3 input bucket.

For detailed instructions on uploading files to Amazon S3, see [Uploading objects](../../../AmazonS3/latest/userguide/upload-objects.md "../../../AmazonS3/latest/userguide/upload-objects.md") in the _Amazon S3 User Guide_.

After uploading your input files, you can start a job. For more information, see [Start a job](starting-a-job.md "starting-a-job.md").
