# Map Rendering SDK by language

We recommend rendering Amazon Location Service maps using the [MapLibre](https://github.com/maplibre/maplibre-gl-js "https://github.com/maplibre/maplibre-gl-js") rendering engine.

MapLibre is an engine for displaying maps in web or mobile applications. MapLibre
also has a plugin model and supports user interfaces for searching and routes in some
languages and platforms.

To learn more about using MapLibre and the functionality it provides, see [Use MapLibre tools and related libraries with Amazon Location](dev-maplibre.md "dev-maplibre.md") and [How to use dynamic maps](dynamic-maps-how-to.md "dynamic-maps-how-to.md").

The following tables provide information about Map Rendering SDKs versions for
languages and frameworks, by application type: web or mobile application.

Web frontend
The following Map Rendering SDKs are available for web frontend
application development.
