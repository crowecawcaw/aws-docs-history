# Comparison Operators

Comparison operators are applied to a single attribute and are lexicographical in nature.
When designing an application, you should carefully think through storing data in its appropriate
string representation. For more information, see [Working with Numerical Data](NumericalData.md "NumericalData.md").

The following table shows all Amazon SimpleDB comparison operators.

| Comparison Operator | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Select Example                                                                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| =                   | Attribute value or itemName() equals the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `select<br>• from mydomain where city = 'Seattle'`<br>`select<br>• from mydomain where city = 'Seattle' or city = 'Portland'`                              |
| !=                  | Attribute value or itemName() does not equal to the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `select<br>• from mydomain where name != 'John'`<br>`select<br>• from mydomain where name != 'John' and name != 'Humberto'`                                |
| >                   | Attribute value or itemName() is greater than the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `select<br>• from mydomain where weight > '0034'`                                                                                                          |
| >=                  | Attribute value or itemName() is greater than or equal to the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `select<br>• from mydomain where weight >= '065'`                                                                                                          |
| <                   | Attribute value or itemName() is less than the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `select<br>• from mydomain where weight < '0034'`                                                                                                          |
| <=                  | Attribute value or itemName() is less than or equal to the specified constant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `select<br>• from mydomain where year <= '2000'`                                                                                                           |
| like                | Attribute value or itemName() contains the specified constant.<br>The `like` operator can be used to evaluate the start of a string<br>('`string`%'), the end of a string ('%`string`'),<br>or any part of a string ('%`string`%').<br>Note<br>Using the `like` operator to evaluate the end of a string or any part of a string is an<br>expensive operation. Make sure to combine it with other predicates to reduce number of items<br>it has to evaluate.<br>To search for strings that contain the percent sign (%), you must escape it. For example, to search<br>for a string that ends in '3%', you enter `select<br>• from mydomain where name like '%3\%'`. To search<br>for a string that begins with '3%', you enter `select<br>• from mydomain where name like '3\%%'`. To search<br>for a string that contains '3%', you enter `select<br>• from mydomain where name like '%3\%%'`. | `select<br>• from mydomain where author like 'Henry%'`<br>`select<br>• from mydomain where keyword = 'Book' and author like '%Miller'`                     |
| not like            | Attribute value or itemName() does not contain the specified constant.<br>The `not like` operator can be used to evaluate the start of a string<br>('`string`%'), the end of a string ('%`string`'),<br>or any part of a string ('%`string`%').<br>Note<br>Using the `not like` operator to evaluate the end of a string or any part of a string is an<br>expensive operation. Make sure to combine it with other predicates to reduce number of items<br>it has to evaluate.                                                                                                                                                                                                                                                                                                                                                                                                                     | `select<br>• from mydomain where author not like 'Henry%'`<br>`select<br>• from mydomain where keyword = 'Book' and author not like '%Miller'`             |
| between             | Attribute value or itemName() falls within a range, including the start and end value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `select<br>• from mydomain where year between '1998' and '2000'`                                                                                           |
| in                  | Attribute value or itemName() is equal to one of the specified constants. When used with items,<br>`in` acts as a batch get.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `select<br>• from mydomain where year in('1998','2000','2003')`<br>`select<br>• from mydomain where itemName() in('0385333498','0802131786','B000T9886K')` |
| is null             | Attribute does not exist. If an item has the attribute with an empty string, it is not returned.<br>Note<br>Due to performance issues, this operator is not recommended when most items have the specified attribute.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `select<br>• from mydomain where year is null`                                                                                                             |
| is not null         | Attribute value or itemName() contains any value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `select<br>• from mydomain where year is not null`                                                                                                         |
| every()             | For multi-valued attributes, every attribute value must satisfy the constraint.<br>Note<br>Due to the cost of running more complex queries, this operator is only recommended for multi-valued attributes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `select<br>• from mydomain where every(keyword) = 'Book'`<br>`select<br>• from mydomain where every(keyword) like '***%'`                                  |
