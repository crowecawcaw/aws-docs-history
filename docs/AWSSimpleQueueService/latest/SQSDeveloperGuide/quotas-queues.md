# Amazon SQS standard queue quotas

The following table lists quotas related to standard queues.

| Quota                                                                                                                                                                                                                                                                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Delay queue                                                                                                                                                                                                                                                                 | The default (minimum) delay for a queue is 0 seconds. The maximum is 15 minutes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Listed queues                                                                                                                                                                                                                                                               | 1,000 queues per [`ListQueues`](../APIReference/API_ListQueues.md "../APIReference/API_ListQueues.md") request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Long polling wait time                                                                                                                                                                                                                                                      | The maximum long polling wait time is 20 seconds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Messages per queue (backlog)                                                                                                                                                                                                                                                | The number of messages that an Amazon SQS queue can store is unlimited.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Messages per queue (in flight)                                                                                                                                                                                                                                              | For most standard queues (depending on queue traffic and message backlog), there can be a maximum of approximately 120,000 in flight messages (received from a queue by a consumer, but not yet deleted from the queue).<br>If you reach this quota while using [short polling](sqs-short-and-long-polling.md#sqs-short-polling "sqs-short-and-long-polling.md#sqs-short-polling"), Amazon SQS returns the `OverLimit` error message. If you use [long polling](sqs-short-and-long-polling.md#sqs-long-polling "sqs-short-and-long-polling.md#sqs-long-polling"), Amazon SQS returns no error messages.<br>To avoid reaching the quota, you should delete messages from the queue after they're processed. You can also increase the number of queues you use to process your messages.<br>To request a quota increase, [submit a support request](https://console.aws.amazon.com/servicequotas/home/services/sqs/quotas "https://console.aws.amazon.com/servicequotas/home/services/sqs/quotas"). |
| Queue name                                                                                                                                                                                                                                                                  | A queue name can have up to 80 characters. The following characters are accepted: alphanumeric characters, hyphens (`-`), and underscores (`_`).<br>NoteQueue names are case-sensitive (for example,<br>`Test-queue` and `test-queue` are<br>different queues).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Queue tag                                                                                                                                                                                                                                                                   | We don't recommend adding more than 50 tags to a queue. Tagging supports Unicode characters in UTF-8.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| The tag `Key` is required, but the tag `Value`<br>is optional.                                                                                                                                                                                                              |
| The tag `Key` and tag `Value` are<br>case-sensitive.                                                                                                                                                                                                                        |
| The tag `Key` and tag `Value` can include<br>Unicode alphanumeric characters in UTF-8 and whitespaces. The following<br>special characters are allowed: `_ . : / = +<br>• @`                                                                                                |
| The tag `Key` or `Value` must not include the<br>reserved prefix `aws:` (you can't delete tag keys or values<br>with this prefix).                                                                                                                                          |
| The maximum tag `Key` length is 128 Unicode characters in<br>UTF-8. The tag `Key` must not be empty or null.                                                                                                                                                                |
| The maximum tag `Value` length is 256 Unicode characters<br>in UTF-8. The tag `Value` may be empty or null.                                                                                                                                                                 |
| Tagging actions are limited to 30 TPS per AWS account. If your application requires a higher throughput, [submit a request](https://console.aws.amazon.com/servicequotas/home/services/sqs/quotas "https://console.aws.amazon.com/servicequotas/home/services/sqs/quotas"). |
