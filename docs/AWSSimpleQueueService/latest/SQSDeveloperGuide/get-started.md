# Common tasks for getting started with Amazon SQS

Once you've created a queue and learned how to send, receive, and delete messages,
you might want to try the following:

- Trigger a [Lambda
  function](sqs-configure-lambda-function-trigger.md "sqs-configure-lambda-function-trigger.md") to process incoming messages automatically, enabling
  event-driven workflows without the need for continuous polling.
- [Configure queues, including SSE and other
  features](sqs-configuring.md "sqs-configuring.md").
- [Send a message with
  attributes](sqs-using-send-message-with-attributes.md "sqs-using-send-message-with-attributes.md").
- [Send a message from a
  VPC](sqs-sending-messages-from-vpc.md "sqs-sending-messages-from-vpc.md").
- Discover the [functionality](sqs-queue-types.md "sqs-queue-types.md") and [architecture](welcome.md#sqs-basic-architecture "welcome.md#sqs-basic-architecture") of Amazon SQS.
- Discover [guidelines and caveats](sqs-best-practices.md "sqs-best-practices.md") that
  will help you make the most of Amazon SQS.
- Explore the Amazon SQS examples for an AWS SDK, such as the [AWS SDK for Java 2.x Developer Guide](../../../sdk-for-java/latest/developer-guide.md "../../../sdk-for-java/latest/developer-guide.md").
- Learn about [Amazon SQS AWS CLI commands](../../../cli/latest/reference/sqs.md "../../../cli/latest/reference/sqs.md").
- Learn about [Amazon SQS
  API actions](../APIReference/API_Operations.md "../APIReference/API_Operations.md").
- Learn how to interact with Amazon SQS programmatically. See [Working with APIs](sqs-making-api-requests-xml.md "sqs-making-api-requests-xml.md") and explore
  the [AWS Development
  Center](https://aws.amazon.com/developer/ "https://aws.amazon.com/developer/"):
  - [Java](https://aws.amazon.com/java/ "https://aws.amazon.com/java/")
  - [JavaScript](https://aws.amazon.com/javascript/ "https://aws.amazon.com/javascript/")
  - [PHP](https://aws.amazon.com/php/ "https://aws.amazon.com/php/")
  - [Python](https://aws.amazon.com/python/ "https://aws.amazon.com/python/")
  - [Ruby](https://aws.amazon.com/ruby/ "https://aws.amazon.com/ruby/")
  - [Windows & .NET](https://aws.amazon.com/net/ "https://aws.amazon.com/net/")

- Learn how to monitor [costs and
  resources](sqs-queue-tags.md "sqs-queue-tags.md").
- Learn how to [protect your
  data](data-protection.md "data-protection.md").
- Learn more about the [Amazon SQS
  workflow](sqs-creating-custom-policies-process-workflow.md "sqs-creating-custom-policies-process-workflow.md").
