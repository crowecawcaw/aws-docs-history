# AWS

policy: SageMakerStudioAdminProjectUserRolePolicy

This IAM policy grants an IAM role full access to AWS Glue Data Catalog (metadata)
and Amazon S3 (actual data) for data lake operations, with access scoped by account, and
role tags. You can attach SageMakerStudioAdminProjectUserRolePolicy to your users,
groups, and roles.

To view the permissions for this policy, see [SageMakerStudioAdminProjectUserRolePolicy](../../../aws-managed-policy/latest/reference/SageMakerStudioAdminProjectUserRolePolicy.md "../../../aws-managed-policy/latest/reference/SageMakerStudioAdminProjectUserRolePolicy.md") in the _AWS Managed Policy Reference_.
