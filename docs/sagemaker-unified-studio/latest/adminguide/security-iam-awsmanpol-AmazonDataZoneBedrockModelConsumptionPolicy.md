# AWS policy: AmazonDataZoneBedrockModelConsumptionPolicy

Provides permissions to consume Amazon Bedrock models, including invoking Amazon
Bedrock application inference profile created for particular Amazon DataZone
domain.

To view the permissions for this policy, see [AmazonDataZoneBedrockModelConsumptionPolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneBedrockModelConsumptionPolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneBedrockModelConsumptionPolicy.md") in the _AWS Managed Policy Reference_.
