

# Edit domain units in Amazon SageMaker Unified Studio
<a name="edit-domain-unit"></a>

**To edit a domain unit**

1. Navigate to Amazon SageMaker Unified Studio using the URL from your administrator and log in using your SSO or AWS credentials. 

1. In the left navigation pane, choose **Manage**, then under **Govern**, choose **Domain units**.

1. Choose the domain unit that you want to edit.
**Note**  
You cannot edit the root domain unit.

1. Expand **Actions** and choose **Edit**.

1. Make your changes to the domain unit name and description, then choose **Save changes**.
