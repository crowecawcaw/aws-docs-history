

# Blueprints in Amazon SageMaker Unified Studio

A blueprint defines the AWS tools and services that project members can use to work with data in the Amazon SageMaker catalog. Blueprints can be included in a project profile, or deployed on demand as resource blueprints in projects.

![The Blueprints page in the Amazon SageMaker Unified Studio console, showing the blueprint gallery and the Grant access to deploy blueprints panel.](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/adminguide/images/resource-blueprints/resource-blueprints.png)
