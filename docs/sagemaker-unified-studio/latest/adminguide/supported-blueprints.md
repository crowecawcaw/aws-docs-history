# Supported blueprints

In the current release of Amazon SageMaker Unified Studio, the following default blueprints are
supported:

| Blueprint name                                                                         | Description                                                                                                                                                                                                                                                                                                                                     | Resources created                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AmazonBedrockGenerativeAI                                                              | This is the combined Amazon Bedrock blueprint which contains seven<br>sub-Amazon Bedrock blueprints. It enables users to build generative AI<br>applications using tools such as Agents, Knowledge Bases, Guardrails,<br>Flows, Functions, and Model Evaluation.                                                                                |
| AmazonBedrockChatAgent                                                                 | Provides a reusable AWS CloudFormation template to create an Amazon<br>Bedrock Agent and supporting resources, including an execution role and<br>a consumption role.                                                                                                                                                                           | Bedrock Agent, Bedrock Agent Execution role, Bedrock Agent<br>Consumption role                                                                                                                                                                                                                                                                                                                                                                                     |
| AmazonBedrockEvaluation                                                                | Creates one IAM role as the service role for an Amazon Bedrock<br>evaluation job.                                                                                                                                                                                                                                                               | Bedrock Evaluation job execution role                                                                                                                                                                                                                                                                                                                                                                                                                              |
| AmazonBedrockFlow                                                                      | Provides a reusable AWS CloudFormation template to create an Amazon<br>Bedrock Prompt Flow and supporting resources such as an execution<br>role.                                                                                                                                                                                               | Amazon Bedrock Flow, Amazon Bedrock Flow Execution role                                                                                                                                                                                                                                                                                                                                                                                                            |
| AmazonBedrockFunction                                                                  | Provides a reusable AWS CloudFormation template to create an AWS<br>Lamda function and supporting resources, such as an execution role, and<br>a secret manager.                                                                                                                                                                                | Secrets Manager secret, AWS Lambda function, AWS Lambda function<br>execution role, Log group                                                                                                                                                                                                                                                                                                                                                                      |
| AmazonBedrockGuardrail                                                                 | Provides an AWS CloudFormation template to create an Amazon Bedrock<br>Guardrail and supporting resources such as an execution role.                                                                                                                                                                                                            | Amazon Bedrock Guardrail                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| AmazonBedrockKnowledgeBase                                                             | Provides an AWS CloudFormation template to create a reusable Amazon<br>Bedrock Knowledge Base and supporting resources such as an execution<br>role.                                                                                                                                                                                            | Amazon Bedrock Knowledge Base, OpenSearch Serverless collection,<br>Amazon Bedrock Knowledge Base Execution role, AWS Lambdas, including<br>OpenSearch Index Lambda and KB Ingestion Trigger Lambda, AWS Lambda<br>Execution role, Amazon Bedrock Knowledge Base data source                                                                                                                                                                                       |
| AmazonBedrockPrompt                                                                    | Provides a reusable AWS CloudFormation template to create an Amazon<br>Bedrock Prompt and supporting resources, such as an execution role, and<br>a consumption role.                                                                                                                                                                           | Amazon Bedrock Prompt, Amazon Bedrock Prompt Consumption role                                                                                                                                                                                                                                                                                                                                                                                                      |
| LakeHouseDatabaseNote: If you search using API/CLI, the<br>blueprint name is DataLake. | Provides a reusable AWS CloudFormation template to create a data<br>lake environment with a AWS Glue database for data management and an<br>Amazon Athena workgroup for querying data.                                                                                                                                                          | AWS Glue databases, lake formation permissions, Amazon Athena<br>workgroups                                                                                                                                                                                                                                                                                                                                                                                        |
| EMRonEC2                                                                               | Provides a reusable AWS CloudFormation template to create an Amazon<br>EMR on EC2 cluster to run and scale Apache Spark, Hive, and other big<br>data workloads. For more information about enabling this blueprint see,<br>[Specify PEM certificate for EmrOnEc2<br>blueprint](enable-emr-on-ec2-blueprint.md "enable-emr-on-ec2-blueprint.md") | EMR on EC2 clusters                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| EMRServerless                                                                          | Provides a reusable AWS CloudFormation template to create an Amazon<br>EMR Serverless application that is ready to serve Apache Spark batch<br>jobs and interactive sessions.                                                                                                                                                                   | EMR on Serverless applications                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| LakehouseCatalog                                                                       | Provisions a new catalog in the Amazon SageMaker Lakehouse that is<br>backed by Amazon Redshift Managed Storage                                                                                                                                                                                                                                 |
| MLExperiments                                                                          | Provides OnDemand blueprint to enable MLflow tracking server for the<br>experimentation inside a project.                                                                                                                                                                                                                                       | MLflow tracking server (on demand)                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| PartnerApps                                                                            | Creates an IAM role and a Connection that enables access to Partner<br>AI Apps. Through Partner AI Apps you can leverage integrated and<br>fully-managed thrid-party solutions for AI/Ml development.                                                                                                                                           | Amazon SageMaker Partner AI Apps IAM role, Amazon SageMaker Partner<br>AI Apps Connection                                                                                                                                                                                                                                                                                                                                                                          |
| RedshiftServerless                                                                     | Provides a reusable AWS CloudFormation template to create an Amazon<br>Redshift Serverless environment to get insights from data without<br>managing infrastructure.                                                                                                                                                                            | Amazon Redshift Serverless warehouses                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Tooling                                                                                | Creates resources for the project, including IAM user roles, security<br>groups, and Amazon SageMaker unified domains.                                                                                                                                                                                                                          | IAM user roles, Amazon SageMaker unified domains, security<br>groups                                                                                                                                                                                                                                                                                                                                                                                               |
| Workflows                                                                              | Provides an AWS CloudFormation template to create the MWAA<br>environment for Airflow based Workflows                                                                                                                                                                                                                                           | Enables project workflows on MWAA                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Quicksight                                                                             | Enables visualization of data within an Amazon SageMaker Unified Studio project using<br>Amazon QuickSight.                                                                                                                                                                                                                                     | For each project with the QuickSight blueprint, Amazon SageMaker Unified Studio creates a<br>restricted folder in Amazon QuickSight. Additionally, it creates Amazon<br>Athena and Amazon Redshift data sources in the restricted folder<br>depending on other blueprints in the project. For more information, see<br>[Amazon QuickSight in Amazon SageMaker Unified<br>Studio](../userguide/quicksight-integration.md "../userguide/quicksight-integration.md"). |
