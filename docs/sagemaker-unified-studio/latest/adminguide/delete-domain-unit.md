

# Delete domain units in Amazon SageMaker Unified Studio
<a name="delete-domain-unit"></a>

**To delete a domain unit**

1. Navigate to Amazon SageMaker Unified Studio using the URL from your administrator and log in using your SSO or AWS credentials. 

1. In the left navigation pane, choose **Manage**, then under **Govern**, choose **Domain units**.

1. Choose the domain unit that you want to delete.

1. Expand Actions and choose **Delete domain unit**.

1. In the **Delete domain unit** window, confirm the deletion, then choose **Delete**.
