# AWS

policy: SageMakerStudioQueryExecutionRolePolicy

This is the default policy for the SageMakerQueryExecutionRole role. This policy
provides permissions to run query executions on federated connections.

To view the permissions for this policy, see [SageMakerStudioQueryExecutionRolePolicy](../../../aws-managed-policy/latest/reference/SageMakerStudioQueryExecutionRolePolicy.md "../../../aws-managed-policy/latest/reference/SageMakerStudioQueryExecutionRolePolicy.md") in the _AWS Managed Policy Reference_.
