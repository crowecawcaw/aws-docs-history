# Regions where Amazon SageMaker Unified Studio is supported

In the current release, Amazon SageMaker Unified Studio is supported in the following AWS regions:

- Asia Pacific (Tokyo)
- Europe (Ireland)
- US East (N. Virginia)
- US East (Ohio)
- US West (Oregon)
- Europe (Frankfurt)
- South America (São Paulo)
- Asia Pacific (Seoul)
- Europe (London)
- Asia Pacific (Singapore)
- Asia Pacific (Sydney)
- Canada (Central)
- Asia Pacific (Mumbai)
- Europe (Paris)
- Europe (Stockholm)
