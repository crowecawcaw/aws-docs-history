# AWS

policy: SageMakerStudioEMRServiceRolePolicy

Amazon SageMaker Unified Studio creates IAM roles for project users to perform data
analytics, artificial intelligence, and machine learning actions, and uses this policy
when creating these roles to define the permissions related to EMR.

To view the permissions for this policy, see [SageMakerStudioEMRServiceRolePolicy](../../../aws-managed-policy/latest/reference/SageMakerStudioEMRServiceRolePolicy.md "../../../aws-managed-policy/latest/reference/SageMakerStudioEMRServiceRolePolicy.md") in the _AWS
Managed Policy Reference_.
