# AWS policy: AmazonDataZoneBedrockModelManagementPolicy

Provides permissions to manage Amazon Bedrock model access, including creating,
tagging and deleting application inference profiles.

To view the permissions for this policy, see [AmazonDataZoneBedrockModelManagementPolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneBedrockModelManagementPolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneBedrockModelManagementPolicy.md") in the _AWS Managed Policy Reference_.
