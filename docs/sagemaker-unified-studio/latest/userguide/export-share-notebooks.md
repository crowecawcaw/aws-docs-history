# Export and share notebooks

## Overview

You can export Amazon SageMaker Unified Studio notebooks in multiple formats for sharing and documentation purposes. Export options include Jupyter notebook format for compatibility with other tools, and Python files for script execution.

## Procedure

To export a notebook:

1. Open the notebook you want to export.
2. Click the export button in the notebook toolbar.
3. Select your desired format: - Jupyter (.ipynb) for use with other Jupyter environments - Python (.py) to extract code as a script
4. The exported file downloads to your local machine.

To download results and data:

1. Execute code that generates output files or processed datasets.
2. Use the download interface to save files to your local machine or Copy to clipboard.
3. Select the output format (CSV or JSON).
