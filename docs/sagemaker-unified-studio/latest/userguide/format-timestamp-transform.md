# Format timestamp transform

Use this transform to convert a timestamp colum into a formatted string.

###### To add a Format Timestamp transform:

1. Navigate to your visual ETL job in Amazon SageMaker Unified Studio.
2. Choose the plus icon to open the **Add nodes** menu.
3. Under **Transforms**, choose **Format
   Timestamp**.
4. Select the diagram to add the node to your visual ETL job.
5. Select the node on the diagram to view details about the transform.
6. Under **Column**, choose the column that contains the
   timestamps.
7. Under **Timestamp format**, input the format you want to use for
   the strings.
8. (Optional) Enter a name for the new formatted column.
