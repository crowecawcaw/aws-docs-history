# Checking the version of Code Editor in Amazon SageMaker Unified Studio

The following steps show how to check the version of your Code Editor application.

1. Navigate to Amazon SageMaker Unified Studio using the URL from your admin and log in
   using your SSO or AWS credentials.
2. Navigate to your project.
3. In the **Build** menu, choose **Spaces**.
4. Choose **Open** next to the Code Editor space you want to open.
5. In the upper-left corner of the Code Editor UI, choose the three-bar menu button.
6. Choose **Help**. Then choose **About**.
