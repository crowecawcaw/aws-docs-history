# Browse data you have access to

Use browsing when you know where your data is located. You can also use it to explore
your existing data assets. Expand catalog hierarchies to view databases and tables. Navigate
through Amazon S3 bucket folders to find specific files and objects.

###### To browse data assets you have access to

1. In the Amazon SageMaker Unified Studio, choose **Data** in the left navigation
   panel.
2. To browse catalog assets:
   1. Choose the **Catalogs** tab to view available data
      catalogs.
   2. Expand AwsDataCatalog to see your databases.
   3. Expand any database to view its tables.
   4. Choose a table to view its schema, columns, and metadata in the right
      panel.
   5. For selected table, use the **Overview**, **Preview
      data**, and **Details** tabs to explore additional
      metadata and sample data.

3. To browse Amazon S3 bucket contents:
   1. Choose the **Amazon S3 buckets** tab to view accessible Amazon S3
      buckets.
   2. Expand any Amazon S3 bucket to navigate through its folder structure.
   3. Choose folders to view their contents.
   4. Select files to view their properties and metadata.
