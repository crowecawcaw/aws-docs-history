# Search and find data

###### Note

For files in Amazon S3, the search is limited to locations that can be accessed by your
IAM role

###### To search and find data

1. Use the search bar at the top of the Amazon SageMaker Unified Studio interface.
2. Enter your search terms, such as:
   - Table names (for example, "churn")
   - Database names
   - Model names
   - Asset descriptions or metadata

3. Use the search suggestions and filters to refine your results:
   1. Select **Show all results for "[search term]"** to see all the
      results.
   2. Use the **Tables**, **Files** and
      **Models** filter tabs to focus on specific asset types.

4. Choose any search result to view available details and metadata.
5. Use the **Select**, **Open**, and **Open
   in new tab** options to work with assets.
