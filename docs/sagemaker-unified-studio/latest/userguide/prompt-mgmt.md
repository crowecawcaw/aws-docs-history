# Reuse and share Amazon Bedrock prompts

You can create and manage reusable prompts for use in
a flow app or you can share them with other users. With a flow app you can pre-configure a
prompt for a flow, by choosing the model and inference parameters that the model uses. You can
also customize the prompt for different use cases by using variables. For example, you could have
a prompt that creates a playlist of songs about topics that a user chooses. You can also share
prompts that you create with other users.
