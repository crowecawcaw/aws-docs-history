## Overview of Amazon Quick Suite in Amazon SageMaker Unified Studio

Amazon SageMaker Unified Studio integrates with Amazon Quick Suite, enabling direct launch of Quick Suite from within
Amazon SageMaker Unified Studio for seamless data visualization and dashboard publishing. This integration allows
users to explore and visualize data with a single click, while maintaining security and
governance.

## Prerequisite for using the Amazon Quick Suite in Amazon SageMaker Unified Studio feaure

To use the Amazon Quick Suite in Amazon SageMaker Unified Studio feature, you need a valid Amazon Quick Suite license to
_create_ datasets and visualize project data, you need a **Author** or **Admin** license. If you have
a **Reader** license, you can only _view_
dashboards.
