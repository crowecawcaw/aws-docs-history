# Supported connectors for Visual ETL

Visual ETL in Amazon SageMaker Unified Studio supports the connectors listed at [Data connections in the lakehouse architecture of Amazon SageMaker](../../../sagemaker-lakehouse-architecture/latest/userguide/lakehouse-data-connection.md#lakehouse-data-connection-supported "../../../sagemaker-lakehouse-architecture/latest/userguide/lakehouse-data-connection.md#lakehouse-data-connection-supported"), in addition to Amazon S3 and
Amazon SageMaker AI Lakehouse.

For instructions on how to add a new connection, see [Adding data sources in lakehouse architecture](../../../sagemaker-lakehouse-architecture/latest/userguide/lakehouse-create-connection.md "../../../sagemaker-lakehouse-architecture/latest/userguide/lakehouse-create-connection.md").
