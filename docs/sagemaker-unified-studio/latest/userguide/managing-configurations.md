# Managing configurations

You can edit your JupyterLab configurations on the JupyterLab page by choosing Configure
in the top right corner. A popup appears where you can change the instance type. You can also
increase the EBS volume up to 16 GB if allowed by your admin.

1. Navigate to Amazon SageMaker Unified Studio using the URL from your admin and log in
   using your SSO or AWS credentials.
2. Expand the **Build** menu in the top navigation, then choose
   **JupyterLab**.
3. Choose the Configure button in the top right corner of the page. A popup appears where
   you can change the instance type and increase the EBS volume.
4. Specify the instance type and EBS volume that you want for testing.
   1. NOTE: After you increase the EBS volume, you cannot decrease it.
