# Launch your custom image in Amazon SageMaker Unified Studio

The following section provides information on how to launch your custom image in
Amazon SageMaker Unified Studio. If you have not already created a custom image, see [How to BYOI](byoi-how-to.md "byoi-how-to.md").

###### To launch your custom image in Amazon SageMaker Unified Studio

1. Navigate to Amazon SageMaker Unified Studio using the URL from your admin and log in using your IAM Identity Center
   (SSO) or AWS credentials. For more information, see [Access Amazon SageMaker Unified Studio](getting-started-access-the-portal.md "getting-started-access-the-portal.md").
2. Navigate to the Amazon SageMaker Unified Studio home page by choosing the icon located at the top left
   corner of the page.
3. You can choose to create a project or choose an existing one.
4. Once you choose a project you will be taken to the **Project
   overview** page.
5. On the **Project overview** page, open your notebook. To do
   so:
   1. Choose **New** to expand the dropdown menu, located at
      the top right of the page.
   2. Choose **Notebook**, then continue with the following
      steps.

6. Once your notebook is open, choose **Configure space**, located
   at the top right of the page.
7. In the **Configure space** section, you can choose the image from
   the **Image** dropdown menu.
8. After you have verified the settings, choose **Save and
   restart**.
   Once completed, this will start a new JupyterLab instance with the custom image.
