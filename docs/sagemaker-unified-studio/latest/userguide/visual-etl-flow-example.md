# Authoring a visual ETL job using generative

AI

To author a Visual ETL job using generative AI in Amazon SageMaker Unified Studio:

1. Verify Amazon Q is enabled for your domain.
2. Open the Visual ETL editor.
3. In the "Add nodes" panel click on the Amazon Q icon.

![The Amazon SageMaker Unified Studio UI showing the Q icon under the "Add nodes" menu .](images/vis-etl/qdev-icon-genAI.png) 4. (Optional) Click on “What can I ask?” and copy a prompt. 5. Enter the desired prompt in the chat box and click on ‘Submit’.

![The Amazon SageMaker Unified Studio UI showing an ETL job described and ready for submission to Q.](images/vis-etl/vis-etl-ask-questions.png) 6. Click on each node in the Visual ETL editor and configure its settings.

![The Amazon SageMaker Unified Studio UI showing an ETL job completed in the visual ETL editor.](images/vis-etl/vis-etl-flow-completed.png)
