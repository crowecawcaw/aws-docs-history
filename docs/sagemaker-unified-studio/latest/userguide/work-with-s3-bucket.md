# Work with Amazon S3 bucket

###### To manage Amazon S3 bucket

1. In the data explorer, choose the **Amazon S3 buckets** tab.
2. Expand the Amazon S3 bucket nodes to view available buckets in your account.
3. Select a bucket to view its contents.
4. To create a new folder:
   1. Choose the **Actions** menu in the bucket view.
   2. Select **Create folder**.
   3. Enter a folder name and choose **Create**.

5. To upload files:
   1. Choose **Upload files** from the **Actions**
      menu.
   2. Select files from your local system.
   3. Monitor the upload progress.

6. To create a table from existing Amazon S3 data:
   1. Choose **Create table from contents** from the
      **Actions** menu.
   2. Follow the table creation workflow to define schema and properties.
