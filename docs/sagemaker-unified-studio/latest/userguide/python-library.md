# Using

Amazon SageMaker Unified Studio Library for Python

The Amazon SageMaker Unified Studio library is an open source library for interacting with Amazon SageMaker Unified Studio resources.
With this library, you can access resources such as domains, projects, connections, and
databases, all in one place with minimal code. The following examples demonstrate how to use
the library in local and remote sessions.

###### Note

For IAM-based domains, the Amazon SageMaker Unified Studio Library for Python is supported only when using
Space Distribution Image version 2.11+ or 3.6+ in JupyterLab Notebooks or the Code
Editor. Earlier versions (e.g., 2.9 or 3.2) do not support the Amazon SageMaker Unified Studio Library for Python.
