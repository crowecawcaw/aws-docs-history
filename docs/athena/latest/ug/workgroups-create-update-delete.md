# Manage workgroups

In the Athena console at [https://console.aws.amazon.com/athena/](https://console.aws.amazon.com/athena/home "https://console.aws.amazon.com/athena/home"), you can perform the following tasks:

| Statement                                                                                                                                         | Description                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Create a workgroup](creating-workgroups.md "creating-workgroups.md")                                                                             | Create a new workgroup.                                                                                                                                                                                                                                                                                                                                     |
| [View the workgroup's details](viewing-details-workgroups.md "viewing-details-workgroups.md")                                                     | View the workgroup's details, such as its name, description, data usage<br>limits, location of query results, expected query results bucket owner,<br>encryption, and control of objects written to the query results bucket. You<br>can also verify whether this workgroup enforces its settings, if<br>\*_Override client-side settings_<br>• is checked. |
| [Specify a workgroup<br>for queries](specify-wkgroup-to-athena-in-which-to-run-queries.md "specify-wkgroup-to-athena-in-which-to-run-queries.md") | Before you can run queries, you must specify to Athena which workgroup<br>to use. You must have permissions to the workgroup.                                                                                                                                                                                                                               |
| [Switch workgroups](switching-workgroups.md "switching-workgroups.md")                                                                            | Switch between workgroups to which you have access.                                                                                                                                                                                                                                                                                                         |
| [Edit a workgroup](editing-workgroups.md "editing-workgroups.md")                                                                                 | Edit a workgroup and change its settings. You cannot change a workgroup's<br>name, but you can create a new workgroup with the same settings and a<br>different name.                                                                                                                                                                                       |
| [Enable or disable a workgroup](workgroups-enabled-disabled.md "workgroups-enabled-disabled.md")                                                  | Enable or disable a workgroup. When a workgroup is disabled, its users<br>cannot run queries, or create new named queries. If you have access to<br>it, you can still view metrics, data usage limit controls, workgroup's<br>settings, query history, and saved queries.                                                                                   |
| [Copy a saved query between<br>workgroups](copy-a-query-between-workgroups.md "copy-a-query-between-workgroups.md")                               | Copy a saved query between workgroups. You might want to do this if, for<br>example, you created a query in a preview workgroup and you want to make it<br>available in a nonpreview workgroup.                                                                                                                                                             |
| [Delete a workgroup](deleting-workgroups.md "deleting-workgroups.md")                                                                             | Delete a workgroup. If you delete a workgroup, query history, saved<br>queries, the workgroup's settings and per-query data limit controls are<br>deleted. The workgroup-wide data limit controls remain in CloudWatch, and you<br>can delete them individually.<br>The primary workgroup cannot be deleted.                                                |
| [Use IAM policies to control workgroup<br>access](workgroups-iam-policy.md "workgroups-iam-policy.md")                                            | Use IAM policies to control workgroup access. For example workgroup<br>policies, see [Example workgroup policies](example-policies-workgroup.md "example-policies-workgroup.md").                                                                                                                                                                           |
| [Create an Athena workgroup<br>that uses IAM Identity Center authentication](workgroups-identity-center.md "workgroups-identity-center.md")       | To use IAM Identity Center identities with Athena, you must create an IAM Identity Center enabled<br>workgroup. After you create the workgroup, you can use the IAM Identity Center console or<br>API to assign IAM Identity Center users or groups to the workgroup.                                                                                       |
| [Configure minimum encryption for a workgroup](workgroups-minimum-encryption.md "workgroups-minimum-encryption.md")                               | Enforce a minimal level of encryption in Amazon S3 for all query results from<br>the workgroup. Use this feature to ensure that query results are never<br>stored in an Amazon S3 bucket in an unencrypted state.                                                                                                                                           |
