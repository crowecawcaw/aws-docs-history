# Choose a SerDe for your data

The following table lists the data formats supported in Athena and their corresponding
SerDe libraries.

| Supported data formats and SerDes | Data format                                                                                                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                                   | SerDe types supported in Athena |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Amazon Ion                        | Amazon Ion is a richly-typed, self-describing data format that is a<br>superset of JSON, developed and open-sourced by Amazon.              | Use the [Amazon Ion Hive SerDe](ion-serde.md "ion-serde.md").                                                                                                                                                                                                                                                                                                                                                                                 |
| Apache Avro                       | A format for storing data in Hadoop that uses JSON-based schemas for<br>record values.                                                      | Use the [Avro SerDe](avro-serde.md "avro-serde.md").                                                                                                                                                                                                                                                                                                                                                                                          |
| Apache Parquet                    | A format for columnar storage of data in Hadoop.                                                                                            | Use the [Parquet SerDe](parquet-serde.md "parquet-serde.md")<br>and SNAPPY compression.                                                                                                                                                                                                                                                                                                                                                       |
| Apache WebServer logs             | A format for storing logs in Apache WebServer.                                                                                              | Use the [Grok SerDe](grok-serde.md "grok-serde.md") or<br>[Regex SerDe](regex-serde.md "regex-serde.md").                                                                                                                                                                                                                                                                                                                                     |
| CloudTrail logs                   | A format for storing logs in CloudTrail.                                                                                                    | • Use the [Hive JSON SerDe](hive-json-serde.md "hive-json-serde.md"). For more information, see<br>[Query AWS CloudTrail logs](cloudtrail-logs.md "cloudtrail-logs.md").                                                                                                                                                                                                                                                                      |
| CSV (Comma-Separated Values)      | For data in CSV, each line represents a data record, and each record<br>consists of one or more fields, separated by commas.                | • Use the [Lazy Simple SerDe for CSV, TSV, and custom-delimited files](lazy-simple-serde.md "lazy-simple-serde.md") if your data does not<br>include values enclosed in quotes or if it uses the<br>`java.sql.Timestamp` format.<br>• Use the [Open CSV SerDe for processing CSV](csv-serde.md "csv-serde.md")<br>when your data includes quotes in values or uses the UNIX<br>numeric format for `TIMESTAMP` (for example,<br>`1564610311`). |
| Custom-Delimited                  | For data in this format, each line represents a data record, and<br>records are separated by a custom single-character delimiter.           | Use the [Lazy Simple SerDe for CSV, TSV, and custom-delimited files](lazy-simple-serde.md "lazy-simple-serde.md") and specify a custom<br>single-character delimiter.                                                                                                                                                                                                                                                                         |
| JSON (JavaScript Object Notation) | For JSON data, each line represents a data record, and each record<br>consists of attribute-value pairs and arrays, separated by<br>commas. | • Use the [Hive JSON SerDe](hive-json-serde.md "hive-json-serde.md").<br>• Use the [OpenX JSON SerDe](openx-json-serde.md "openx-json-serde.md").                                                                                                                                                                                                                                                                                             |
| Logstash logs                     | A format for storing logs in Logstash.                                                                                                      | Use the [Grok SerDe](grok-serde.md "grok-serde.md").                                                                                                                                                                                                                                                                                                                                                                                          |
| ORC (Optimized Row Columnar)      | A format for optimized columnar storage of Hive data.                                                                                       | Use the [ORC SerDe](orc-serde.md "orc-serde.md") and ZLIB<br>compression.                                                                                                                                                                                                                                                                                                                                                                     |
| TSV (Tab-Separated Values)        | For data in TSV, each line represents a data record, and each record<br>consists of one or more fields, separated by tabs.                  | Use the [Lazy Simple SerDe for CSV, TSV, and custom-delimited files](lazy-simple-serde.md "lazy-simple-serde.md") and specify the separator<br>character as `FIELDS TERMINATED BY '\t'`.                                                                                                                                                                                                                                                      |
