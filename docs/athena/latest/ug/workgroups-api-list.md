# Use Athena workgroup APIs

The following are some of the REST API operations used for Athena workgroups. In all of the
following operations except for `ListWorkGroups`, you must specify a workgroup.
In other operations, such as `StartQueryExecution`, the workgroup parameter is
optional and the operations are not listed here. For the full list of operations, see [Amazon Athena API Reference](../APIReference.md "../APIReference.md").

- [CreateWorkGroup](../APIReference/API_CreateWorkGroup.md "../APIReference/API_CreateWorkGroup.md")
- [DeleteWorkGroup](../APIReference/API_DeleteWorkGroup.md "../APIReference/API_DeleteWorkGroup.md")
- [GetWorkGroup](../APIReference/API_GetWorkGroup.md "../APIReference/API_GetWorkGroup.md")
- [ListWorkGroups](../APIReference/API_ListWorkGroups.md "../APIReference/API_ListWorkGroups.md")
- [UpdateWorkGroup](../APIReference/API_UpdateWorkGroup.md "../APIReference/API_UpdateWorkGroup.md")
