# Ping

Ping is a SAML based plugin that works with the [PingFederate](https://www.pingidentity.com/en/platform/capabilities/authentication-authority/pingfederate.html "https://www.pingidentity.com/en/platform/capabilities/authentication-authority/pingfederate.html") identity provider.
