# Analyze network security with AWS assistant
<a name="nsd-security-insights"></a>

The AWS assistant is a generative artificial intelligence (generative AI)-powered assistant that works with network security director to help answer your questions and provide recommendations about network security and remediation options.

You can interact with the AWS assistant by choosing the AWS assistant icon or **Explore with AWS assistant** anywhere it appears in the network security director console. This section guides you through the steps to ask the AWS assistant questions from the network security director **Dashboard**.

**To engage with the AWS assistant**
**Note**  
You must have a completed network analysis before you can chat with the AWS assistant.

1. Sign in to the AWS Management Console and open the AWS Shield network security director console at [https://console.aws.amazon.com/wafv2/network-security-director/](https://console.aws.amazon.com/wafv2/network-security-director/).

1. From the network security director home page, choose **Dashboard**.

1. In the **Ask AWS assistant** widget, choose a question to use as a prompt in the AWS assistant chat interface.

1. In the AWS assistant chat interface, submit your request.

## Example questions
<a name="nsd-q-examples"></a>

Following are example questions about network security that you can ask the AWS assistant:
+ Identify my top network security findings
+ Identify my top network security findings in the account 123456789010
+ Identify my top network security findings in us-west-2
+ Summarize the network security of my environment
+ Are my systems at risk of DDoS attacks?
+ How can I improve my network security?
+ Do I have any resources without WAF protection?
+ Which resources are not protected from common web vulnerabilities?
+ What are the common network security issues on my EC2 instances?
+ Do I have any WAF web ACLs that aren't protecting anything?
