# Getting started with AWS Shield network security director

Before you begin using network security director, make sure you've completed the setup steps described in [Setting up your account to use AWS Shield network security director](nsd-setting-up.md "nsd-setting-up.md").

The following workflow guides you through analyzing and improving your network security configuration:

1. [Run a network analysis](nsd-system-analysis.md "nsd-system-analysis.md") - Run your first network analysis to identify potential security issues in your AWS environment.
2. [Identify resources with security issues](nsd-findings.md "nsd-findings.md") - Review the Dashboard to understand which of your resources have security findings that need attention.
3. [Find remediation steps for your highest severity resources](nsd-remediation-steps.md "nsd-remediation-steps.md") - Get recommendations for improving the security configuration of your resources.
4. [Analyze network security with Amazon Q Developer](nsd-security-insights.md "nsd-security-insights.md") - Use Amazon Q Developer to analyze your network security configurations in natural language.
