# Options for rate limiting in rate-based rules and

targeted Bot Control rules

This section compares rate-based mitigation options.

The targeted level of the AWS WAF Bot Control rule group and the AWS WAF rate-based rule
statement both provide web request rate limiting. The following table compares the
two options.

| Comparison of options for rate-based detection and mitigation                                    |                                                                                                                                                                 | AWS WAF rate-based rule                                                                                                                                                                                   | AWS WAF Bot Control targeted rules |
| ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| **How rate limiting is<br>applied**                                                              | Acts on groups of requests that are coming at too high a rate. You can apply any<br>action except for Allow.                                                    | Enforces human-like access patterns and applies dynamic rate<br>limiting, through the use of request tokens.                                                                                              |
| **Based on historical traffic baselines?**                                                       | No                                                                                                                                                              | Yes                                                                                                                                                                                                       |
| **Time required to accumulate historic<br>traffic baselines**                                    | N/A                                                                                                                                                             | Five minutes for dynamic thresholds. N/A for token<br>absent.                                                                                                                                             |
| **Mitigation lag**                                                                               | Usually 30-50 seconds. Can be up to several minutes.                                                                                                            | Usually less than 10 seconds. Can be up to several minutes.                                                                                                                                               |
| **Mitigation targets**                                                                           | Configurable. You can group requests using a scope-down statement and by one or more<br>aggregation keys, such as IP address, HTTP method, and query<br>string. | IP addresses and client sessions                                                                                                                                                                          |
| **Traffic volume level required to trigger<br>mitigations**                                      | Medium<br>• can be as low as 10 requests in the specified time window                                                                                           | Low<br>• intended to detect client patterns such as slow scrapers                                                                                                                                         |
| **Customizable thresholds**                                                                      | Yes                                                                                                                                                             | No                                                                                                                                                                                                        |
| **Default mitigation<br>action**                                                                 | Console default is Block. No default setting in the API; the setting is<br>required. You can set this to any rule action except<br>Allow.                       | The rule group rule action settings are Challenge for<br>token absent and CAPTCHA for high volume traffic from a<br>single client session. You can set either of these rules to<br>any valid rule action. |
| **Resiliency against highly distributed<br>attacks**                                             | Medium<br>• 10,000 IP address maximum for IP address limiting on its own                                                                                        | Medium<br>• limited to 50,000 total between IP addresses and tokens                                                                                                                                       |
| **[AWS WAF Pricing](https://aws.amazon.com/waf/pricing/ "https://aws.amazon.com/waf/pricing/")** | Included in the standard fees for AWS WAF.                                                                                                                      | Included in the fees for the targeted level of Bot Control intelligent threat mitigation.                                                                                                                 |
