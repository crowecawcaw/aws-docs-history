# Security Lake Regions and endpoints

For a list of supported Regions and service endpoints for Security Lake, see
[Amazon Security Lake endpoints](../../../general/latest/gr/securitylake.md "../../../general/latest/gr/securitylake.md") in the
_AWS General Reference_.

We recommend that you enable Security Lake in all supported AWS Regions. This allows you to use Security Lake to detect and investigate unauthorized or
unusual activity even in Regions that you aren't actively using.
