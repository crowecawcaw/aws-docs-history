# Tagging Security Lake resources

A _tag_ is an optional label that you can define and assign
to AWS resources, including certain types of Amazon Security Lake resources. Tags can help you
identify, categorize, and manage resources in different ways, such as by purpose, owner,
environment, or other criteria. For example, you can use tags to apply policies, allocate
costs, distinguish between resources, or identify resources that support certain compliance
requirements or workflows.

You can assign tags to the following types of Security Lake resources: subscribers, and the data
lake configuration for your AWS account in individual AWS Regions.
