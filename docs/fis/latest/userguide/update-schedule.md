# Update an experiment schedule

You can update an experiment schedule so that it occurs at a specific date and time that
suits
you.

To update an experiment execution using the console

1. Open the [Amazon FIS console](../../../fis.md "../../../fis.md").
2. In the navigation pane, choose **Experiment Templates**.
3. Choose **Resource type: Experiment Template** for which a
   schedule is already created.
4. Click on the Experiment ID for the template. Then navigate to schedules
   Tab.
5. Check if there is a existing schedule associated with the experiment.
   Select the schedule associated and Click the button **Update
   Schedule**.
