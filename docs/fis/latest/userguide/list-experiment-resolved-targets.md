# List resolved targets

You can view information for resolved targets for an experiment after target resolution has ended.

###### To view resolved targets using the console

1. Open the AWS FIS console at [https://console.aws.amazon.com/fis/](https://console.aws.amazon.com/fis/ "https://console.aws.amazon.com/fis/").
2. In the navigation pane, choose **Experiments**.
3. Select the experiment, and choose **Report**.
4. View resolved target information under **Resources**.

###### To view resolved targets using the CLI

Use the [list-experiment-resolved-targets](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/fis/list-experiment-resolved-targets.html "https://awscli.amazonaws.com/v2/documentation/api/latest/reference/fis/list-experiment-resolved-targets.html")
command.
