

# AzureRegionsQuery

A query that lists the Azure Regions that have resources in scope.

## Contents
<a name="API_AzureRegionsQuery_Contents"></a>

 ** Scope **   <a name="cwoa-Type-AzureRegionsQuery-Scope"></a>
Limits the query to a management group or to specific subscriptions.  
Type: [AzureQueryScope](API_AzureQueryScope.md) object  
Required: No
