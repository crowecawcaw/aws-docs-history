

# AzureManagementGroupsQuery

A query that lists Azure management groups.

## Contents
<a name="API_AzureManagementGroupsQuery_Contents"></a>

 ** ParentManagementGroupId **   <a name="cwoa-Type-AzureManagementGroupsQuery-ParentManagementGroupId"></a>
Lists the management groups under this management group. If you omit this value, the query starts at the tenant root group.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 90.  
Pattern: `[-\w._()]+`   
Required: No
