

# SourceProfilesConfiguration

Configuration for selecting source profiles for centralization.

## Contents
<a name="API_SourceProfilesConfiguration_Contents"></a>

 ** ProfilesSelectionCriteria **   <a name="cwoa-Type-SourceProfilesConfiguration-ProfilesSelectionCriteria"></a>
The filter expression that selects which source profiles to centralize.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 2000.  
Required: No
