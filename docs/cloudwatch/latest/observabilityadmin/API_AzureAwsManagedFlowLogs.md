

# AzureAwsManagedFlowLogs

Configuration for Flow Log Storage Accounts that the setup creates, one in each Region that ingests Flow Logs.

## Contents
<a name="API_AzureAwsManagedFlowLogs_Contents"></a>

 ** RetentionDays **   <a name="cwoa-Type-AzureAwsManagedFlowLogs-RetentionDays"></a>
The number of days that the created Storage Accounts keep Flow Logs.  
Type: Integer  
Valid Range: Minimum value of 1. Maximum value of 365.  
Required: Yes
