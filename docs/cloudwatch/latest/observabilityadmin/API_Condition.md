# Condition

A single condition that can match based on WAF rule action or label name.

## Contents

**ActionCondition**

Matches log records based on the WAF rule action taken (ALLOW, BLOCK, COUNT, etc.).

Type: [ActionCondition](API_ActionCondition.md "API_ActionCondition.md") object

Required: No

**LabelNameCondition**

Matches log records based on WAF rule labels applied to the request.

Type: [LabelNameCondition](API_LabelNameCondition.md "API_LabelNameCondition.md") object

Required: No
