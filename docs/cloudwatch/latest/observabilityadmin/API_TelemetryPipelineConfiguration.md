# TelemetryPipelineConfiguration

Defines the configuration for a telemetry pipeline, including how data flows from sources
through processors to destinations.

## Contents

**Body**

The pipeline configuration body that defines the data processing rules and
transformations.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 24000.

Required: Yes
