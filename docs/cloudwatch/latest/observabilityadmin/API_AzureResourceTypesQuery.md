

# AzureResourceTypesQuery

A query that lists the Azure resource types that have resources in scope.

## Contents
<a name="API_AzureResourceTypesQuery_Contents"></a>

 ** Scope **   <a name="cwoa-Type-AzureResourceTypesQuery-Scope"></a>
Limits the query to a management group or to specific subscriptions.  
Type: [AzureQueryScope](API_AzureQueryScope.md) object  
Required: No
