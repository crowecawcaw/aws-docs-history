

# MskMonitoringParameters
<a name="API_MskMonitoringParameters"></a>

 Configuration parameters for Amazon MSK cluster monitoring, including enhanced monitoring level settings. 

## Contents
<a name="API_MskMonitoringParameters_Contents"></a>

 ** EnhancedMonitoring **   <a name="cwoa-Type-MskMonitoringParameters-EnhancedMonitoring"></a>
 The level of enhanced monitoring for the MSK cluster.   
Type: String  
Valid Values: `DEFAULT | PER_BROKER | PER_TOPIC_PER_BROKER | PER_TOPIC_PER_PARTITION`   
Required: No
