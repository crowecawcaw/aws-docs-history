# MskMonitoringParameters

Configuration parameters for Amazon MSK cluster monitoring, including enhanced monitoring
level settings.

## Contents

**EnhancedMonitoring**

The level of enhanced monitoring for the MSK cluster.

Type: String

Valid Values: `DEFAULT | PER_BROKER | PER_TOPIC_PER_BROKER | PER_TOPIC_PER_PARTITION`

Required: No
