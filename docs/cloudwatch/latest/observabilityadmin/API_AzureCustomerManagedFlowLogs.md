

# AzureCustomerManagedFlowLogs

Configuration for existing Azure Storage Accounts that already receive your Flow Logs.

## Contents
<a name="API_AzureCustomerManagedFlowLogs_Contents"></a>

 ** StorageAccounts **   <a name="cwoa-Type-AzureCustomerManagedFlowLogs-StorageAccounts"></a>
The Storage Accounts that store your Flow Logs, listed by Azure Region. Each Region can appear only once, and each Storage Account can appear only once across all Regions.  
Type: Array of [AzureFlowLogStorageAccountScope](API_AzureFlowLogStorageAccountScope.md) objects  
Array Members: Minimum number of 1 item. Maximum number of 100 items.  
Required: Yes
