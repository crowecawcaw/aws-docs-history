

# AzureSubscriptionsQuery

A query that lists Azure subscriptions.

## Contents
<a name="API_AzureSubscriptionsQuery_Contents"></a>

 ** ManagementGroupId **   <a name="cwoa-Type-AzureSubscriptionsQuery-ManagementGroupId"></a>
Limits the results to subscriptions under this management group.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 90.  
Pattern: `[-\w._()]+`   
Required: No
