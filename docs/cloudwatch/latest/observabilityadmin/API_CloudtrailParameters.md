

# CloudtrailParameters
<a name="API_CloudtrailParameters"></a>

 Parameters specific to AWS CloudTrail telemetry configuration. 

## Contents
<a name="API_CloudtrailParameters_Contents"></a>

 ** AdvancedEventSelectors **   <a name="cwoa-Type-CloudtrailParameters-AdvancedEventSelectors"></a>
 The advanced event selectors to use for filtering AWS CloudTrail events.   
Type: Array of [AdvancedEventSelector](API_AdvancedEventSelector.md) objects  
Required: Yes
