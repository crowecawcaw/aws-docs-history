# Record

Represents a test record structure used for pipeline testing operations to validate data
processing.

## Contents

**Data**

The data content of the test record used for pipeline validation.

Type: String

Required: No

**Type**

The type of the test record, indicating the format or category of the data.

Type: String

Valid Values: `STRING | JSON`

Required: No
