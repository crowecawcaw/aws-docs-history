

# AzureManagementGroupSummary

Information about an Azure management group.

## Contents
<a name="API_AzureManagementGroupSummary_Contents"></a>

 ** Id **   <a name="cwoa-Type-AzureManagementGroupSummary-Id"></a>
The ID of the management group.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 90.  
Pattern: `[-\w._()]+`   
Required: Yes

 ** DisplayName **   <a name="cwoa-Type-AzureManagementGroupSummary-DisplayName"></a>
The display name of the management group.  
Type: String  
Required: No

 ** Name **   <a name="cwoa-Type-AzureManagementGroupSummary-Name"></a>
The name of the management group.  
Type: String  
Required: No
