

# TelemetrySourceConfigurationInput

The configuration of the third-party telemetry source that a new enrichment collects resource metadata from. Specify exactly one member.

## Contents
<a name="API_TelemetrySourceConfigurationInput_Contents"></a>

**Important**  
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** Azure **   <a name="cwoa-Type-TelemetrySourceConfigurationInput-Azure"></a>
The configuration for a Microsoft Azure source.  
Type: [AzureTelemetrySourceConfigurationInput](API_AzureTelemetrySourceConfigurationInput.md) object  
Required: No
