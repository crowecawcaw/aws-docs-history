

# ActionCondition
<a name="API_ActionCondition"></a>

 Condition that matches based on the specific WAF action taken on the request. 

## Contents
<a name="API_ActionCondition_Contents"></a>

 ** Action **   <a name="cwoa-Type-ActionCondition-Action"></a>
 The WAF action to match against (ALLOW, BLOCK, COUNT, CAPTCHA, CHALLENGE, EXCLUDED\_AS\_COUNT).   
Type: String  
Valid Values: `ALLOW | BLOCK | COUNT | CAPTCHA | CHALLENGE | EXCLUDED_AS_COUNT`   
Required: No
