# MetricsBackupConfiguration

Configuration for backing up centralized metrics data to a secondary region.

## Contents

**Region**

Metrics specific backup destination region within the primary destination account to which
metrics data should be centralized.

Type: String

Length Constraints: Minimum length of 1.

Required: Yes
