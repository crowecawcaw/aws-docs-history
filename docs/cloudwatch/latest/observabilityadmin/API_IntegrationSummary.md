

# IntegrationSummary
<a name="API_IntegrationSummary"></a>

Contains summary information about an S3 Table integration for listing operations.

## Contents
<a name="API_IntegrationSummary_Contents"></a>

 ** Arn **   <a name="cwoa-Type-IntegrationSummary-Arn"></a>
The Amazon Resource Name (ARN) of the S3 Table integration.  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 1011.  
Pattern: `arn:aws([a-z0-9\-]+)?:([a-zA-Z0-9\-]+):([a-z0-9\-]+)?:([0-9]{12})?:(.+)`   
Required: No

 ** Status **   <a name="cwoa-Type-IntegrationSummary-Status"></a>
The current status of the S3 Table integration.  
Type: String  
Valid Values: `ACTIVE | DELETING`   
Required: No
