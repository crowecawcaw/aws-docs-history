# Data Types

The CloudWatch Observability Admin Service API contains several data types that various actions use. This section describes each data type in detail.

###### Note

The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:

- [CentralizationRule](API_CentralizationRule.md "API_CentralizationRule.md")
- [CentralizationRuleDestination](API_CentralizationRuleDestination.md "API_CentralizationRuleDestination.md")
- [CentralizationRuleSource](API_CentralizationRuleSource.md "API_CentralizationRuleSource.md")
- [CentralizationRuleSummary](API_CentralizationRuleSummary.md "API_CentralizationRuleSummary.md")
- [DestinationLogsConfiguration](API_DestinationLogsConfiguration.md "API_DestinationLogsConfiguration.md")
- [LogsBackupConfiguration](API_LogsBackupConfiguration.md "API_LogsBackupConfiguration.md")
- [LogsEncryptionConfiguration](API_LogsEncryptionConfiguration.md "API_LogsEncryptionConfiguration.md")
- [SourceLogsConfiguration](API_SourceLogsConfiguration.md "API_SourceLogsConfiguration.md")
- [TelemetryConfiguration](API_TelemetryConfiguration.md "API_TelemetryConfiguration.md")
- [TelemetryDestinationConfiguration](API_TelemetryDestinationConfiguration.md "API_TelemetryDestinationConfiguration.md")
- [TelemetryRule](API_TelemetryRule.md "API_TelemetryRule.md")
- [TelemetryRuleSummary](API_TelemetryRuleSummary.md "API_TelemetryRuleSummary.md")
- [VPCFlowLogParameters](API_VPCFlowLogParameters.md "API_VPCFlowLogParameters.md")
