# PipelineOutput

Contains the output from pipeline test operations, including processed records and any
errors encountered.

## Contents

**Error**

Any error that occurred during the pipeline test operation for this record.

Type: [PipelineOutputError](API_PipelineOutputError.md "API_PipelineOutputError.md") object

Required: No

**Record**

The processed record output from the pipeline test operation.

Type: [Record](API_Record.md "API_Record.md") object

Required: No
