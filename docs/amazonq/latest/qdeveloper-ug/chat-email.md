

# Chatting about email sending
<a name="chat-email"></a>

This conversational experience is now part of the AWS assistant.

For current documentation, see [Chatting about message delivery](https://docs.aws.amazon.com/assistant/latest/userguide/service-insights.html#email-insights) in the *AWS assistant User Guide*.

In chat applications, this capability is still part of Amazon Q Developer. For more information, see [Chatting with Amazon Q Developer in chat applications](q-in-chat-applications.md).
