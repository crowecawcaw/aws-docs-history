

# Using Amazon Q Developer on AWS apps and websites
<a name="q-on-aws"></a>

**Amazon Q Developer in the AWS Management Console is now the AWS assistant**  
Chatting with Amazon Q Developer in the AWS Management Console is now the AWS assistant. For current documentation, see the [AWS assistant User Guide](https://docs.aws.amazon.com/assistant/latest/userguide/what-is.html).

Use Ask AWS on the AWS Marketing website and the AWS documentation assistant on the AWS Documentation website to ask questions about AWS. You can ask about AWS architecture, best practices, support, and documentation. You can also get help with code that you're writing with the AWS SDKs and AWS Command Line Interface (AWS CLI).

In the AWS Management Console and AWS Console Mobile Application, this experience is now the AWS assistant. In the AWS Management Console, you can ask the AWS assistant about your AWS resources and costs, contact Support directly, and diagnose common console errors. For more information, see the [AWS assistant User Guide](https://docs.aws.amazon.com/assistant/latest/userguide/what-is.html).

To quickly provide access to features of Amazon Q Developer on AWS, attach the ` AmazonQDeveloperAccess` AWS managed policy to the IAM identity using Amazon Q. For permissions needed for specific features, see the topic for the feature you want to use.
