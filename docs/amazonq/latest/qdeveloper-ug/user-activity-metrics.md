# User activity report metrics

The following table describes the metrics that are included in the user activity reports generated
by Amazon Q Developer.

For more information about these reports, see [Viewing the activity of specific users in Amazon Q Developer](q-admin-user-telemetry.md "q-admin-user-telemetry.md").

| Metric name                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chat_AICodeLines                     | Lines of code suggested by Amazon Q and accepted by the user. This metric includes<br>code that was generated through the [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")<br>(not [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md")) and inserted into<br>the IDE.                                                                                                                                                                                        |
| Chat_MessagesInteracted              | Number of chat messages where the user has interacted positively with Amazon Q.<br>Examples of positive interactions: clicking a link, inserting a suggestion, and<br>upvoting a response from Amazon Q. This metric includes messages that were generated by<br>[Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md") (not [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md")).                                                                                 |
| Chat_MessagesSent                    | Number of messages sent to and from Amazon Q. This metric includes the user prompts<br>and Amazon Q responses in the [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md") (not [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md")).                                                                                                                                                                                                                             |
| CodeFix_AcceptanceEventCount         | Number of code fixes suggested by Amazon Q and accepted by the user. This metric<br>applies to code fixes generated through the [code review<br>feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                                  |
| CodeFix_AcceptedLines                | Lines of code suggested by Amazon Q and accepted by the user. This metric applies to<br>lines of code generated through the [code review<br>feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                                      |
| CodeFix_GeneratedLines               | Lines of code suggested by Amazon Q. This metric applies to lines of code generated<br>through the [code review feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                                                                  |
| CodeFix_GenerationEventCount         | Number of code fixes suggested by Amazon Q. This metric applies to code fixes<br>generated through the [code review feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                                                              |
| CodeReview_FailedEventCount          | Number of code issues that were found but for which Amazon Q could not suggest a code<br>fix. This metric applies to code issues generated using the [code review feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                |
| CodeReview_FindingsCount             | Number of code issues found by Amazon Q. This metric applies to code issues found<br>using the [code review feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                                                                                      |
| CodeReview_SucceededEventCount       | Number of code issues that were found and for which Amazon Q was able to generate a<br>suggested code fix. This metric applies to code issues found using the [code review feature](code-reviews.md "code-reviews.md").                                                                                                                                                                                                                                                       |
| Dev_AcceptanceEventCount             | Number of code features suggested by Amazon Q and accepted by the user. This metric<br>applies to code features generated through the [/dev<br>command](q-in-IDE-chat.md#develop-code "q-in-IDE-chat.md#develop-code").                                                                                                                                                                                                                                                       |
| Dev_AcceptedLines                    | Lines of code suggested by Amazon Q and accepted by the user. This metric applies to<br>lines of code generated through the [/dev<br>command](q-in-IDE-chat.md#develop-code "q-in-IDE-chat.md#develop-code").                                                                                                                                                                                                                                                                 |
| Dev_GeneratedLines                   | Lines of code suggested by Amazon Q. This metric applies to lines of code generated<br>through the [/dev command](q-in-IDE-chat.md#develop-code "q-in-IDE-chat.md#develop-code").                                                                                                                                                                                                                                                                                             |
| Dev_GenerationEventCount             | Number of code features suggested by Amazon Q. This metric applies to code features<br>generated through the [/dev command](q-in-IDE-chat.md#develop-code "q-in-IDE-chat.md#develop-code").                                                                                                                                                                                                                                                                                   |
| DocGeneration_AcceptedFileUpdates    | Number of file updates suggested by Amazon Q and accepted by the user. This metric<br>applies to file updates generated through the [/doc<br>command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                     |
| DocGeneration_AcceptedFilesCreations | Number of file creations suggested by Amazon Q and accepted by the user. This metric<br>applies to file creations generated through the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                    |
| DocGeneration_AcceptedLineAdditions  | Lines of documentation additions suggested by Amazon Q and accepted by the user. This<br>metric applies to documentation generated through the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                             |
| DocGeneration_AcceptedLineUpdates    | Lines of documentation updates suggested by Amazon Q and accepted by the user. This<br>metric applies to documentation generated using the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                 |
| DocGeneration_EventCount             | Number of times the user engaged with Amazon Q using the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                                                                                                   |
| DocGeneration_RejectedFileCreations  | Number of file creations suggested by Amazon Q and rejected by the user. This metric<br>applies to file creations generated through the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                    |
| DocGeneration_RejectedFileUpdates    | Number of file updates suggested by Amazon Q and rejected by the user. This metric<br>applies to file updates generated through the [/doc<br>command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                     |
| DocGeneration_RejectedLineAdditions  | Lines of documentation additions suggested by Amazon Q and rejected by the user. This<br>metric applies to documentation generated through the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                             |
| DocGeneration_RejectedLineUpdates    | Lines of documentation updates suggested by Amazon Q and rejected by the user. This<br>metric applies to documentation generated using the [/doc command](q-in-IDE-chat.md#doc-generation "q-in-IDE-chat.md#doc-generation").                                                                                                                                                                                                                                                 |
| InlineChat_AcceptedLineAdditions     | Lines of code additions suggested by Amazon Q and accepted by the user. This metric<br>includes code additions generated through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q<br>chat](q-in-IDE-chat.md "q-in-IDE-chat.md")).                                                                                                                                                                                                          |
| InlineChat_AcceptedLineDeletions     | Lines of code deletions suggested by Amazon Q and accepted by the user. This metric<br>includes code deletions suggested through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q<br>chat](q-in-IDE-chat.md "q-in-IDE-chat.md")).                                                                                                                                                                                                          |
| InlineChat_AcceptanceEventCount      | Number of [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")) suggestions that were accepted by the<br>user.                                                                                                                                                                                                                                                                                          |
| InlineChat_DismissalEventCount       | Number of [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")) suggestions that were abandoned by<br>the user. By 'abandoned', we mean that the code suggestion was displayed but the<br>user kept typing or performing other operations in their IDE, and did not<br>explicitly accept or reject the code suggestion.                                                                                 |
| InlineChat_DismissedLineAdditions    | Lines of code additions suggested by Amazon Q and abandoned by the user. By<br>'abandoned', we mean that the code suggestion was displayed but the user kept<br>typing or performing other operations in their IDE, and did not explicitly accept<br>or reject the code suggestion. This metric includes code additions generated<br>through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")). |
| InlineChat_DismissedLineDeletions    | Lines of code deletions suggested by Amazon Q and abandoned by the user. By<br>'abandoned', we mean that the code suggestion was displayed but the user kept<br>typing or performing other operations in their IDE, and did not explicitly accept<br>or reject the code suggestion. This metric includes code deletions suggested<br>through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")). |
| InlineChat_EventCount                | Number of [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")) sessions that the user engaged<br>in.                                                                                                                                                                                                                                                                                                   |
| InlineChat_RejectedLineAdditions     | Lines of code additions suggested by Amazon Q and rejected by the user. This metric<br>includes code additions generated through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q<br>chat](q-in-IDE-chat.md "q-in-IDE-chat.md")).                                                                                                                                                                                                          |
| InlineChat_RejectedLineDeletions     | Lines of code deletions suggested by Amazon Q and rejected by the user. This metric<br>includes code deletions suggested through the [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q<br>chat](q-in-IDE-chat.md "q-in-IDE-chat.md")).                                                                                                                                                                                                          |
| InlineChat_RejectionEventCount       | Number of [inline chat](q-in-IDE-inline-chat.md "q-in-IDE-inline-chat.md") (not [Amazon Q chat](q-in-IDE-chat.md "q-in-IDE-chat.md")) suggestions that were rejected by the<br>user.                                                                                                                                                                                                                                                                                          |
| Inline_AICodeLines                   | Lines of code suggested by Amazon Q and accepted by the user. This metric includes<br>code that was accepted as [inline<br>suggestions](inline-suggestions.md "inline-suggestions.md").                                                                                                                                                                                                                                                                                       |
| Inline_AcceptanceCount               | Number of [inline suggestions](inline-suggestions.md "inline-suggestions.md") accepted<br>by the user.                                                                                                                                                                                                                                                                                                                                                                        |
| Inline_SuggestionsCount              | Number of [inline suggestions](inline-suggestions.md "inline-suggestions.md") displayed<br>to the user.                                                                                                                                                                                                                                                                                                                                                                       |
| TestGeneration_AcceptedLines         | Lines of code suggested by Amazon Q and accepted by the user. This metric applies to<br>lines of code generated through the [/test<br>command](q-in-IDE-chat.md#unit-tests "q-in-IDE-chat.md#unit-tests").                                                                                                                                                                                                                                                                    |
| TestGeneration_AcceptedTests         | Number of unit tests suggested by Amazon Q and accepted by the user. This metric<br>applies to unit tests generated through the [/test<br>command](q-in-IDE-chat.md#unit-tests "q-in-IDE-chat.md#unit-tests").                                                                                                                                                                                                                                                                |
| TestGeneration_EventCount            | Number of times the user engaged with Amazon Q through the [/test command](q-in-IDE-chat.md#unit-tests "q-in-IDE-chat.md#unit-tests").                                                                                                                                                                                                                                                                                                                                        |
| TestGeneration_GeneratedLines        | Lines of code suggested by Amazon Q. This metric applies to lines of code generated<br>through the [/test command](q-in-IDE-chat.md#unit-tests "q-in-IDE-chat.md#unit-tests").                                                                                                                                                                                                                                                                                                |
| TestGeneration_GeneratedTests        | Number of unit tests suggested by Amazon Q. This metric applies to unit tests<br>generated through the [/test command](q-in-IDE-chat.md#unit-tests "q-in-IDE-chat.md#unit-tests").                                                                                                                                                                                                                                                                                            |
| Transformation_EventCount            | Number of times the user engaged with Amazon Q through the [/transform command](transform-in-IDE.md "transform-in-IDE.md"), excluding the times when<br>the when the user [transformed code on the command<br>line](transform-CLI.md "transform-CLI.md").                                                                                                                                                                                                                     |
| Transformation_LinesGenerated        | Lines of code suggested by Amazon Q. This metric applies to code generated through<br>the [/transform command](transform-in-IDE.md "transform-in-IDE.md"), excluding code<br>[transformed on the command line](transform-CLI.md "transform-CLI.md").                                                                                                                                                                                                                          |
| Transformation_LinesIngested         | Lines of code provided to Amazon Q for transformation. This metric applies to code<br>that is provided through the [/transform<br>command](transform-in-IDE.md "transform-in-IDE.md"), excluding code provided for [transformation on the command line](transform-CLI.md "transform-CLI.md"), or for an [SQL conversion](transform-sql.md "transform-sql.md").                                                                                                                |
