# Overview

The following table gives an overview of the Amazon Q Business
Amazon S3 connector and its supported features.

| Category                                                                                                                                   | Feature                                                                                                                                                                                                                                                                                                                                                                    | Support           |
| ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| **Security**                                                                                                                               | **Authentication type**                                                                                                                                                                                                                                                                                                                                                    | Assume Role Based |
| **[Access Control List (ACL)](connector-concepts.md#connector-authorization "connector-concepts.md#connector-authorization")<br>crawling** | Yes. For more information, see [ACL crawling](s3-user-management.md "s3-user-management.md").                                                                                                                                                                                                                                                                              |
| **[Identity<br>crawling](connector-concepts.md#connector-identity-crawler "connector-concepts.md#connector-identity-crawler")**            | No. Use [User Store APIs](connector-principal-store.md "connector-principal-store.md") if you want to crawl<br>users and groups.                                                                                                                                                                                                                                           |
| **[VPC](connector-concepts.md#connector-vpc "connector-concepts.md#connector-vpc")**                                                       | Yes                                                                                                                                                                                                                                                                                                                                                                        |
| **Crawl features**                                                                                                                         | **Custom metadata**                                                                                                                                                                                                                                                                                                                                                        | Yes               |
| **Entities**                                                                                                                               | Yes. The following entities are supported:<br>• Document<br>See [What is a document?](connector-doc-crawl.md "connector-doc-crawl.md") for more<br>details on what each connector crawls as a document.                                                                                                                                                                    |
| **[Field mappings](connector-concepts.md#connector-field-mappings "connector-concepts.md#connector-field-mappings")**                      | Yes. Supports both default and custom field mappings. For more<br>information, see [Field mappings](s3-field-mappings.md "s3-field-mappings.md").                                                                                                                                                                                                                          |
| **Filters**                                                                                                                                | Yes. The following filters are supported:<br>• Include/exclude by prefix (for example `Data/`,<br>where `Data` is a folder containing<br>documents)<br>• Include/exclude by file types (for example<br>`.*\.pdf`, or `.*\.txt`)<br>• Include/exclude by glob patterns (for example<br>`*.java`, which specifies a pattern that<br>represents file names ending in `.java`) |
| **[Sync mode](connector-concepts.md#connector-sync-mode "connector-concepts.md#connector-sync-mode")**                                     | Supports full and incremental sync.                                                                                                                                                                                                                                                                                                                                        |
| **[File types](doc-types.md "doc-types.md")**                                                                                              | Supports all files supported by Amazon Q.                                                                                                                                                                                                                                                                                                                                  |
