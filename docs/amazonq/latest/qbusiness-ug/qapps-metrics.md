# Amazon Q Apps metrics

The following table shows the metrics that Amazon Q Apps sends to CloudWatch in real
time.

| Metric name                               | Unit  | Description                                                                                                                                                                                                                                                                  | Namespace |
| ----------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `ActiveQAppsUsers`                        | Count | The number of Active Q App users. A user is a person who creates, edits or<br>runs the apps. The metric is emitted once every day on UTC midnight.<br>Valid dimensions: `ApplicationId`                                                                                      | AWS/QApps |
| `ActiveQAppsCreators`                     | Count | The number of Active Q App creators. A creator is a user who creates a Q App<br>in any way, including through magic wand, magic builder, create blank app or<br>duplicate an app. The metric is emitted once every day on UTC midnight.<br>Valid dimensions: `ApplicationId` | AWS/QApps |
| `QAppCreated`                             | Count | The number of Q Apps created. This metric is emitted every time a Q App is<br>created<br>Valid dimensions: `ApplicationId`                                                                                                                                                   | AWS/QApps |
| `ActiveQApps`                             | Count | The number of active Q Apps. The active Q App is defined as the app being<br>created, updated or run.<br>Valid dimensions: `ApplicationId`                                                                                                                                   | AWS/QApps |
| `QAppPublished`                           | Count | The number of Q Apps that are shared to the library. This metric is emitted<br>every time a Q App is shared to the library.<br>Valid dimensions: `ApplicationId`                                                                                                             | AWS/QApps |
| `QAppExecuted`                            | Count | The number of Q Apps run. This metric is emitted every time a Q App is<br>run.<br>Valid dimensions: `ApplicationId`                                                                                                                                                          | AWS/QApps |
| `ResourceCount (QAppCountPerApplication)` | Count | The number of total Q Apps in the application environment. This metric is emitted every<br>5 minutes with Resource dimension populated as<br>`QAppCountPerApplication`.<br>Valid dimensions: `Resouce, ResourceId, Service, Type`.                                           | Usage     |
| `ResourceCount (QAppCountPerUser)`        | Count | The number of total users set up for the application environment. This metric is emitted<br>every 5 minutes with Resource dimension populated as<br>`QAppCountPerUser`.<br>Valid dimensions: `Resource, ResourceId, Service, Type`.                                          | Usage     |
