supported features.

| **[Identity crawling](connector-concepts.md#connector-identity-crawler "connector-concepts.md#connector-identity-crawler")** | Yes                                                                                                                                                            |                                                                                                                                         | **[VPC](connector-concepts.md#connector-vpc "connector-concepts.md#connector-vpc")**                                                    | Yes                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Supported versions**                                                                                                       | <br>• API 30-56 <br>• Lightning, Classic <br>• Sandbox                                                                                                         |
