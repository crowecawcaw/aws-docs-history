# Upload documents directly into a Amazon Q Business application using APIs

Amazon Q Business supports direct document uploads into an Amazon Q Business index using both the console and the APIs.

| API action                                                                                                       | API description                                                                                                   | Relevant User Guide topic                                                  |
| ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [BatchPutDocument](../api-reference/API_BatchPutDocument.md "../api-reference/API_BatchPutDocument.md")          | Adds one or more documents to an Amazon Q Business index                                                          | [Upload documents](upload-docs.md "upload-docs.md")                        |
| [BatchDeleteDocument](../api-reference/API_BatchDeleteDocument.md "../api-reference/API_BatchDeleteDocument.md") | Asynchronously deletes one or more documents added using the BatchPutDocument API from an Amazon Q Business index | [Deleting uploaded documents](delete-doc-upload.md "delete-doc-upload.md") |
