# Web Crawler connector overview

The following table gives an overview of the Amazon Q Business
Web Crawler connector and its supported features.

| Category                                                                                                                                   | Feature                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Support                                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |

| **Authentication credentials**                                                                                                             | **Basic authentication**<br>• Website username<br>• Website password<br>**NTLM/Kerberos<br>authentication**<br>• NTLM/Kerberos username<br>• NTLM/Kerberos password<br>**Form authentication**<br>• Login page URL<br>• Website username<br>• Website password<br>• Username field Xpath<br>• Password field Xpath<br>• Password button Xpath<br>• (Optional) Username button Xpath<br>**SAML authentication**<br>• Login page URL<br>• Website username<br>• Website password<br>• Username field Xpath<br>• Password field Xpath<br>• Password button Xpath<br>• (Optional) Username button Xpath |
| **[Access Control List (ACL)](connector-concepts.md#connector-authorization "connector-concepts.md#connector-authorization")<br>crawling** | No                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **[Identity<br>crawling](connector-concepts.md#connector-identity-crawler "connector-concepts.md#connector-identity-crawler")**            | No                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Crawl features**                                                                                                                         | **Custom metadata**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Yes                                                                                                                                           |
| **Visual content processing**                                                                                                              | Yes. Amazon Q Business can extract and index content from images<br>embedded in webpages and the following supported document types: PDF,<br>PowerPoint, Microsoft Word (DOCX), Google Slides, Google Docs                                                                                                                                                                                                                                                                                                                                                                                          |
| **Entities**                                                                                                                               | Yes. The following entities are supported:<br>• Web page<br>• Attachment<br>See [What is a document?](connector-doc-crawl.md "connector-doc-crawl.md") for more<br>details on what each connector crawls as a document.                                                                                                                                                                                                                                                                                                                                                                             |
