| **Authentication credentials**                                                                                                             | **Basic**<br>• Username<br>• Password<br>• Client email<br>• Private key<br>**OAuth 2.0 with Client Credentials<br>Flow**<br>• Username<br>• Password<br>• Client ID<br>• Client Secret                                                                                                                                                                                                                                                                                                                            |

| **[Identity<br>crawling](connector-concepts.md#connector-identity-crawler "connector-concepts.md#connector-identity-crawler")**            | Yes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **[VPC](connector-concepts.md#connector-vpc "connector-concepts.md#connector-vpc")**                                                       | Yes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Crawl features**                                                                                                                         | **Custom metadata**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Yes                                           |

The following entities are supported:<br>• Contents<br>• Comments<br>• Attachments<br>See [What is a document?](connector-doc-crawl.md "connector-doc-crawl.md") for more<br>details on what each connector crawls as a document.                                                                                                                                                                                                                                                                             |
