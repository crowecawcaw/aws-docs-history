# Getting data insights from Amazon Quick answers

After you complete [Configuring the
plugin](quicksight-plugin-configuring-application.md "quicksight-plugin-configuring-application.md"), end users
automatically start getting insights from Quick as they submit queries. Unlike other
plugins in Amazon Q Business, you don't have to enable Quick insights for end
users.

The following example shows the results of a query with Quick answers enabled. It
shows a response from Amazon Q Business and a Quick dashboard visual. To navigate to
Quick and view details for the insights, choose **Explore
insights**.

![Screenshot showing query results with QuickSight answers enabled, displaying both an Amazon Q Business response and a QuickSight dashboard visual with an "Explore insights" button for accessing more detailed information.](images/quicksight-plugin-results.png)
