# User feedback using Amazon Q Business APIs

Amazon Q Business captures end user feedback to chat responses to help address
any technical issues. You can't configure this feature using the console.

| API action                                                                               | API description                                                                                | Relevant User Guide topic                                                                                   |
| ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| [PutFeedback](../api-reference/API_PutFeedback.md "../api-reference/API_PutFeedback.md") | Enables your end user to provide feedback on their Amazon Q Business generated chat responses. | [Using web experience](using-web-experience.md#provide-feedback "using-web-experience.md#provide-feedback") |
