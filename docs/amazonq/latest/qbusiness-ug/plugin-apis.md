# Creating Amazon Q Business plugins using APIs

Amazon Q Business supports plugin creation through both the console and the
APIs.

| API action                                                                                                                | API description                                                                                                                                                             | Relevant User Guide topic                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [CreatePlugin](../api-reference/API_CreatePlugin.md "../api-reference/API_CreatePlugin.md")                               | Creates an Amazon Q Business plugin                                                                                                                                         | [Configuring plugins with Amazon Q Business](plugins.md "plugins.md")                                                                |
| [DeletePlugin](../api-reference/API_DeletePlugin.md "../api-reference/API_DeletePlugin.md")                               | Deletes an Amazon Q Business plugin                                                                                                                                         | [Deleting a plugin](plugin-management.md#plugin-delete "plugin-management.md#plugin-delete")                                         |
| [GetPlugin](../api-reference/API_GetPlugin.md "../api-reference/API_GetPlugin.md")                                        | Gets information about an existing Amazon Q Business<br>plugin                                                                                                              | [Getting plugin properties](plugin-management.md#plugin-properties "plugin-management.md#plugin-properties")                         |
| [UpdatePlugin](../api-reference/API_UpdatePlugin.md "../api-reference/API_UpdatePlugin.md")                               | Updates an Amazon Q Business plugin                                                                                                                                         | [Updating a plugin](plugin-management.md#plugin-update "plugin-management.md#plugin-update")                                         |
| [ListPlugins](../api-reference/API_ListPlugins.md "../api-reference/API_ListPlugins.md")                                  | Lists properties of an Amazon Q Business plugin                                                                                                                             | [Listing plugins](plugin-management.md#plugin-list "plugin-management.md#plugin-list")                                               |
| [ListPluginActions](../api-reference/API_ListPluginActions.md "../api-reference/API_ListPluginActions.md")                | Lists configured Amazon Q Business actions for a specific<br>plugin in an Amazon Q Business application. Returns empty<br>responses for custom and legacy built-in plugins. | [Listing configured plugin<br>actions](plugin-management.md#plugin-list-actions "plugin-management.md#plugin-list-actions")          |
| [ListPluginTypeActions](../api-reference/API_ListPluginTypeActions.md "../api-reference/API_ListPluginTypeActions.md")    | Lists configured Amazon Q Business actions for any plugin type.<br>Returns empty responses for custom and legacy built-in plugins.                                          | [Listing available plugin<br>actions](plugin-management.md#plugin-list-actions-type "plugin-management.md#plugin-list-actions-type") |
| [ListPluginTypeMetadata](../api-reference/API_ListPluginTypeMetadata.md "../api-reference/API_ListPluginTypeMetadata.md") | Lists metadata for all Amazon Q Business plugin types. Returns<br>empty responses for custom and legacy built-in plugins.                                                   | [Listing plugin metadata](plugin-management.md#plugin-list-metadata "plugin-management.md#plugin-list-metadata")                     |
