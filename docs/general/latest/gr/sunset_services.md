

# Services in Sunset
<a name="sunset_services"></a>

Customers already using services and features in the sunset stage should plan to migrate to alternatives as recommended in the product pages and documentation. Sunset services have a sunset time line (typically 12 months). The sunset date is the date AWS will end operations and support of the service.
