

# Services in Sunset

Customers already using services and features in the sunset stage should plan to migrate to alternatives as recommended in the product pages and documentation. Sunset services have a sunset time line (typically 12 months). The sunset date is the date AWS will end operations and support of the service.



| Service | Announcement Date | End of Support Date | Recommended alternative | 
| --- | --- | --- | --- | 
| AWS Backint Agent for SAP ASE | September 29, 2026 | September 29, 2027 | SAP ASE native Amazon S3 backup (recommended). Also: Amazon S3 File Gateway, or third-party backup tools.<br />For details, see [AWS Backint Agent for SAP ASE end of support](https://docs.aws.amazon.com/sap/latest/sap-AnyDB/ase-backint-end-of-support.html). | 
| Amazon DevOps Guru | September 29, 2026 | September 29, 2027 | For anomaly detection and alerting: Amazon CloudWatch. For investigating operational issues: AWS DevOps Agent.<br />For details, see [Amazon DevOps Guru end of support](https://docs.aws.amazon.com/devops-guru/latest/userguide/devops-guru-end-of-support.html). |
