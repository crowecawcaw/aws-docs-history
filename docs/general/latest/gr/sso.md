

# AWS IAM Identity Center endpoints and quotas
<a name="sso"></a>

To connect programmatically to an AWS service, you use an endpoint. AWS services offer the following endpoint types in some or all of the AWS Regions that the service supports: IPv4 endpoints, dual-stack endpoints, and FIPS endpoints. Some services provide global endpoints. For more information, see [AWS service endpoints](rande.md).

Service quotas, also referred to as limits, are the maximum number of service resources or operations for your AWS account. For more information, see [AWS service quotas](aws_service_limits.md).

The following are the service endpoints and service quotas for this service.

| Number of permission sets allowed per AWS account | Each supported Region: 500 |  [Yes](https://console.aws.amazon.com/servicequotas/home/services/sso/quotas/L-89954265)  | The default number of permission sets allowed per AWS account. | 
| Number of users supported in IAM Identity Center | Each supported Region: 200,000 |  [Yes](https://console.aws.amazon.com/servicequotas/home/services/sso/quotas/L-3C8D41A0)  | The default number of users supported in IAM Identity Center. | 
| Total number of AWS accounts or applications that can be configured | Each supported Region: 7,000 |  [Yes](https://console.aws.amazon.com/servicequotas/home/services/sso/quotas/L-0299121C)  | The default number of AWS accounts or applications that can be configured. | Total number of groups that can be assigned to a permission set per AWS account, or to an application | Each supported Region: 100 | No | Total number of groups that can be assigned to a permission set per AWS account, or to an application. |
