# AWS Management Console endpoints and quotas

AWS Management Console has Regional endpoints that allow you to directly access the console in a given
AWS Region. The general syntax of a Regional endpoint is as follows:

```
https://region-code.console.aws.amazon.com
```

For example, `https://us-west-2.console.aws.amazon.com` is the endpoint for
the AWS Management Console service in the US West (Oregon) Region.
