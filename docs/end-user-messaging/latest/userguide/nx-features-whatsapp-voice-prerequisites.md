

# Prerequisites for WhatsApp calling
<a name="nx-features-whatsapp-voice-prerequisites"></a>

Before you can use WhatsApp calling, the following must be true:
+ The business phone number that you call from must belong to a WhatsApp Business Account (WABA) that is linked to your AWS account. For more information about linking a WABA, see [Setup WhatsApp](nx-whatsapp.md).
+ Your business must meet Meta's eligibility requirements for the WhatsApp calling APIs.
+ A user must grant your business permission before you can call them. For more information, see [Check calling permission for a user](nx-features-whatsapp-voice-permission.md).
