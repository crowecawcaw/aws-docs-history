

# RCS registration
<a name="nx-rcs-registration"></a>

To send RCS messages in production, you register your AWS RCS Agent for each country you want to launch in. Each country launch creates a separate RCS for Business ID that is approved for each carrier in that country, and each country has its own registration type and requirements. For the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md). Select a country to review its registration requirements.
