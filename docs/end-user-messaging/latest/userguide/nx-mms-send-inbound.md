

# Inbound messaging
<a name="nx-mms-send-inbound"></a>

AWS End User Messaging does not support inbound (two-way) MMS. You cannot receive MMS messages from your customers.

A phone number that you use to send MMS can still receive inbound SMS messages in response to an outbound MMS message, if the number is enabled for two-way SMS. To set up two-way SMS so that your number can receive incoming SMS messages, see [Inbound messaging](nx-sms-send-inbound.md).
