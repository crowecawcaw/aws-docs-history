

# Launching RCS in Mexico
<a name="nx-rcs-launch-mx"></a>

To launch your AWS RCS Agent in Mexico, submit a country launch registration using the `MX_RCS_LAUNCH_REGISTRATION` registration type. The Mexico registration form includes an additional company name field beyond the standard baseline. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).
