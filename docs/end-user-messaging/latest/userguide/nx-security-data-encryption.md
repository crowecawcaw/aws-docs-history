

# Data encryption
<a name="nx-security-data-encryption"></a>

AWS End User Messaging data is encrypted in transit and at rest within the AWS boundary. When you submit data to AWS End User Messaging, it encrypts the data as it is received and stores it. When you retrieve data from AWS End User Messaging, it transmits the data to you by using current security protocols. When you use AWS End User Messaging to send an SMS message to an external mobile device, your data is transferred outside the AWS boundary through the SMS protocol and is subject to the technical limitations of SMS. When you use AWS End User Messaging to send a message through the WhatsApp channel, your data is transferred outside the AWS boundary to Meta for delivery to the recipient.
