

# Launching RCS in Austria
<a name="nx-rcs-launch-at"></a>

To launch your AWS RCS Agent in Austria, submit a country launch registration using the `AT_RCS_LAUNCH_REGISTRATION` registration type. Austria uses the standard baseline registration form. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).
