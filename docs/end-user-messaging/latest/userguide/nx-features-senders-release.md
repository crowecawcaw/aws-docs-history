

# Release a sender ID
<a name="nx-features-senders-release"></a>

If you don't need a sender ID anymore, you can remove it from your account. When you remove a sender ID, we stop charging you for it in your bill for the next calendar month.

**Release a sender ID**

1. Open the AWS End User Messaging console at [https://console.aws.amazon.com/end-user-messaging/](https://console.aws.amazon.com/end-user-messaging/).

1. In the navigation pane, under **Configurations**, choose **Sender IDs**.

1. Choose the sender ID that you want to release and then choose **Delete**.

1. On the **Release sender ID** dialog enter **release** and choose **Release sender ID**.
