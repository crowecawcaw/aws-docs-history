

# Lebanon
<a name="nx-country-reg-lb"></a>

To send messages that use a sender ID in Lebanon, you must complete the Lebanon sender ID registration.

**ISO code:** LB \| **Number type:** sender ID \| **Registration:** Required

To register, complete the following steps in the console. Fields marked optional can be left blank.

1. Open the console, choose **Registrations**, then choose **Create registration**.

1. In the **Sender ID info** section, enter the following, then choose **Next**:
   + For **Sender ID**, the sender ID to register. Must be between 3 and 11 alphanumeric characters. The value must be 3 to 11 characters.
   + For **Sender ID description (optional)**, if it is not obvious, explain the connection between your company name and this sender ID. The value must be 1 to 500 characters.
   + For **Proof of sender ID connection (optional)**, if the connection between your company name and this sender ID is not obvious, then you are required to provide evidence of your intellectual property rights to the brand. Valid upload file types are PDF, PNG, and JPEG.

1. In the **Company info** section, enter the following, then choose **Next**:
   + For **Company name**, legal name of your company. The value must be 1 to 100 characters.
   + For **Company identification number**, legal identification number of your company (such as EIN or VAT). The value must be 1 to 30 characters.
   + For **DBA (Doing Business As) name (optional)**, dBA (Doing Business As) or brand name if different from the legal name of your company. The value must be 1 to 100 characters.
   + For **Company website**, full URL of your company's website. The value must be 4 to 100 characters.
   + For **Area of business**, select the vertical which most closely aligns with your company's area of business.

1. In the **Company address** section, enter the following, then choose **Next**:
   + For **Address 1**, physical street address associated with your company. The value must be 1 to 100 characters.
   + For **Address 2 (optional)**, unit number of the physical address, if applicable. The value must be 1 to 100 characters.
   + For **City**, city where the physical address is located. The value must be 1 to 100 characters.
   + For **State / Province (optional)**, state, province, or region where the physical address is located. The value must be 1 to 50 characters.
   + For **Postal code (optional)**, postal / ZIP code where the physical address is located. The value must be 1 to 20 characters.
   + For **Country code**, two-digit ISO country code where the physical address is located. The value must be 2 to 2 characters.

1. In the **Contact info** section, enter the following, then choose **Next**:
   + For **Contact email address**, email address of your company's point of contact. The value must be 5 to 100 characters.
   + For **Contact phone number**, phone number of your company's point of contact. The value must be 3 to 30 characters.

1. In the **Messaging Use Case** section, enter the following, then choose **Next**:
   + For **Use case category**, select the category which most closely aligns with your use case.
   + For **Use case description**, description of your use case for sending SMS messages with this sender ID. The value must be 1 to 500 characters.
   + For **Monthly SMS volume**, estimated number of SMS messages which will be sent from this sender ID each month.
   + For **Opt-in workflow description**, description of how your end-users will opt-in to receiving SMS messages from this sender ID. The value must be 1 to 500 characters.

1. In the **Message Samples** section, enter the following, then choose **Next**:
   + For **Message sample 1**, at least one sample is required of an SMS message which will be sent from this sender ID. The value must be 1 to 306 characters.
   + For **Message sample 2 (optional)**, you may provide an additional sample of your SMS messaging content, if applicable. The value must be 1 to 306 characters.
   + For **Message sample 3 (optional)**, you may provide an additional sample of your SMS messaging content, if applicable. The value must be 1 to 306 characters.

1. Review your entries on the **Review and submit** page, then choose **Submit registration**. After you submit, the registration is reviewed and its status is updated.
