

# Quotas
<a name="nx-push-scale-quotas"></a>

AWS End User Messaging Push applies quotas to resources such as applications and channels, and to the rate at which you can send push notifications. The push notification services that deliver your messages, such as APNs, FCM, ADM, and Baidu Cloud Push, also apply their own delivery limits. For the quotas that apply across AWS End User Messaging, see [Quotas](nx-features-quotas.md).
