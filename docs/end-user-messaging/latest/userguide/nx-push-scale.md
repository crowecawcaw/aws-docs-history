

# Scale
<a name="nx-push-scale"></a>

After you have tested your push notification setup, this section helps you run AWS End User Messaging Push at scale. It covers regional availability, the quotas that apply, how to monitor your messaging, and how to disable a push channel when you no longer need it.

## In this section
<a name="nx-push-scale-in-section"></a>



|  |  | 
| --- |--- |
| [Regional availability](nx-push-scale-regions.md) | See the AWS Regions where AWS End User Messaging Push is available. | 
| [Quotas](nx-push-scale-quotas.md) | Review the quotas that apply to applications, channels, and your send rate. | 
| [Monitoring](nx-push-scale-monitoring.md) | Track delivery with per-message events, operational CloudWatch metrics, and CloudTrail logs. | 
| [Disable a push channel](nx-push-scale-disable.md) | Disable a push channel when you rotate credentials or retire a platform. |
