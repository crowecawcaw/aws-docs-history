

# Launching RCS in Spain
<a name="nx-rcs-launch-es"></a>

To launch your AWS RCS Agent in Spain, submit a country launch registration using the `ES_RCS_LAUNCH_REGISTRATION` registration type. The Spain registration form includes additional company detail fields beyond the standard baseline. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).
