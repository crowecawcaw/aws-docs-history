

# How to get set up
<a name="nx-push-get-set-up"></a>

This topic takes you from a new AWS account to sending your first push notification with AWS End User Messaging Push. Complete the following steps.


**Setup steps**  

| Step | What you do | 
| --- | --- | 
| [Prerequisites](nx-push-get-set-up-prerequisites.md) | Set up your AWS account, IAM permissions, the AWS CLI, and your push provider accounts. | 
| [Step 1: Obtain provider credentials](nx-push-get-set-up-credentials.md) | Obtain the provider credentials for each push notification service you want to use. | 
| [Step 2: Create an application and enable push channels](nx-push-get-set-up-create-app.md) | Create an application and enable the push channels you want to send on. |
