

# Using the AWS End User Messaging console
<a name="nx-security-iam-id-based-examples-console"></a>

To access the AWS End User Messaging console, you must have a minimum set of permissions. These permissions must allow you to list and view details about the AWS End User Messaging resources in your AWS account. Grant permissions for the actions in the namespace that matches the channel you use: `sms-voice` for SMS, MMS, voice, and RCS, or `social-messaging` for WhatsApp.
