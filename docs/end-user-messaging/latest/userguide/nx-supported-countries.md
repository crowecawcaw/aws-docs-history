

# Supported countries
<a name="nx-supported-countries"></a>

AWS End User Messaging supports different countries and regions depending on the messaging channel that you use. The following pages group the supported countries and regions by geographic region. Each region page lists its countries in a single table that shows whether AWS End User Messaging supports SMS, MMS, voice, and RCS messaging in that country, along with the SMS origination identities that are available. Use these tables to determine which channels and origination identities will work best for the recipients that you want to reach.

These tables describe channel capability by country and region only. The steps to register an origination identity or complete any country-specific requirements are documented with each channel in that channel's setup section, not here.


**How to read the channel support tables**  

| Column | What it tells you | 
| --- | --- | 
| Country or region | The country or region that the row describes. | 
| ISO code | The two-letter ISO 3166-1 country code for the country or region. | 
| SMS short codes | Whether you can send SMS messages from a short code in this country or region. | 
| SMS long codes | Whether you can send SMS messages from a long code (a standard phone number) in this country or region. | 
| SMS Sender IDs | Whether you can send SMS messages from an alphanumeric sender ID in this country or region. | 
| SMS two-way | Whether you can receive inbound SMS messages (two-way messaging) in this country or region. | 
| International sending | Whether you can send SMS messages to this country or region from an internationally enabled number, such as a toll-free number, when you do not have a local origination identity there. International messages are delivered on a best-effort basis and may be sent from a shared phone number or sender ID. | 
| MMS | Whether you can send MMS messages in this country or region. | 
| Voice | Whether you can send voice messages in this country or region. | 
| RCS | Whether you can send RCS messages in this country or region. | 
| WhatsApp | Whether you can send WhatsApp messages in this country or region. | 

Each cell shows **Yes** when the channel or origination identity is available in that country or region, and **No** when it is not. A cell marked **Needs confirmation** is pending verification.
