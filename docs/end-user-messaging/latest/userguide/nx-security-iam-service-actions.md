

# Policy actions for AWS End User Messaging
<a name="nx-security-iam-service-actions"></a>

**Supports policy actions: Yes**

Administrators can use AWS JSON policies to specify who has access to what. That is, which principal can perform actions on what resources, and under what conditions. The `Action` element of a JSON policy describes the actions that you can use to allow or deny access in a policy. AWS End User Messaging actions use the `sms-voice` and `social-messaging` prefixes. To see a list of AWS End User Messaging actions, see the [Service Authorization Reference](https://docs.aws.amazon.com/service-authorization/latest/reference/).
