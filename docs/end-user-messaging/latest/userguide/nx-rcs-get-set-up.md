

# How to get set up
<a name="nx-rcs-get-set-up"></a>

This topic takes you from a new AWS account to sending your first RCS message with AWS End User Messaging. For background on how RCS works, including the two-level identity model, see [Setup RCS](nx-rcs.md). Complete the following steps.


**Setup steps**  

| Step | What you do | 
| --- | --- | 
| [Prerequisites](nx-rcs-gsu-prerequisites.md) | Set up your AWS account, IAM permissions, and the AWS CLI. | 
| [Step 1: Create an AWS RCS test agent](nx-rcs-gsu-agent.md) | Create an AWS RCS Agent and submit a testing registration. | 
| [Step 2: Add a test device](nx-rcs-gsu-test-device.md) | Add a test device and accept the tester invitation so you can receive test messages. | 
| [Step 3: Set up a phone pool (optional)](nx-rcs-gsu-pool.md) | (Optional) Create a phone pool that includes your agent and an SMS number to enable SMS fallback. |
