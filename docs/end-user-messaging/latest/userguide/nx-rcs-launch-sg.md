

# Launching RCS in Singapore
<a name="nx-rcs-launch-sg"></a>

To launch your AWS RCS Agent in Singapore, submit a country launch registration using the `SG_RCS_LAUNCH_REGISTRATION` registration type. Singapore has a significant prerequisite: you must have a registered SMS sender on the SGNIC portal before you can register for RCS. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).

**Important**  
Before you can register for RCS in Singapore, you must have a registered SMS sender ID on the SGNIC (Singapore Network Information Centre) portal. Your RCS agent display name must exactly match your registered SMS sender name. This is required regardless of whether you intend to send SMS in Singapore.
