

# Oceania
<a name="nx-supported-countries-oceania"></a>

AWS End User Messaging supports 18 countries and regions in Oceania. The following table lists each country along with the messaging channels and SMS origination identities that AWS End User Messaging supports there. A value of **No** means that AWS End User Messaging does not support that capability in the country.


**Channel support by country in Oceania**  

| Country or region | ISO code | SMS short codes | SMS long codes | SMS Sender IDs | SMS two-way | International sending | MMS | Voice | RCS | WhatsApp | 
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | 
| Australia | AU | No | Yes | Registration required | Yes | Yes | No | Yes | No | Yes | 
| Cook Islands | CK | No | No | Yes | Yes | Yes | No | No | No | Yes | 
| Fiji | FJ | No | No | Yes | No | Yes | No | No | No | Yes | 
| French Polynesia | PF | No | No | Yes | No | No | No | No | No | Yes | 
| Guam | GU | No | Yes | No | Yes | Yes | No | No | No | Yes | 
| Marshall Islands | MH | No | No | No | No | No | No | No | No | Yes | 
| Micronesia | FM | No | No | No | No | No | No | No | No | Yes | 
| New Caledonia | NC | No | No | Yes | No | Yes | No | No | No | Yes | 
| New Zealand | NZ | Yes | No | No | Yes | Yes | No | Yes | No | Yes | 
| Niue | NU | No | No | Yes | No | Yes | No | No | No | Yes |
