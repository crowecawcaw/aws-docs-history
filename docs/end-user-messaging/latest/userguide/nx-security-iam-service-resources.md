

# Policy resources for AWS End User Messaging
<a name="nx-security-iam-service-resources"></a>

**Supports policy resources: Yes**

Administrators can use AWS JSON policies to specify who has access to what. That is, which principal can perform actions on what resources, and under what conditions. The `Resource` JSON policy element specifies the object or objects to which the action applies. To see a list of AWS End User Messaging resource types and their ARNs, see the [Service Authorization Reference](https://docs.aws.amazon.com/service-authorization/latest/reference/).
