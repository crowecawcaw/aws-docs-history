

# Regional availability
<a name="nx-push-scale-regions"></a>

AWS End User Messaging Push is available in several AWS Regions in North America, Europe, Asia, and Oceania. In each Region, AWS maintains multiple Availability Zones that are physically isolated from each other and connected by low-latency, high-throughput, and highly redundant networking to provide high availability. For the current list of Regions where AWS End User Messaging Push is available and the endpoint for each Region, see the AWS service endpoints in the AWS General Reference.
