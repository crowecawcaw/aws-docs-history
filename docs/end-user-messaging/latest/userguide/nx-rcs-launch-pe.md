

# Launching RCS in Peru
<a name="nx-rcs-launch-pe"></a>

**Important**  
RCS in Peru is available only to businesses with a local presence in Peru. International companies without Peruvian operations or a locally-registered entity cannot register for RCS in Peru.

To launch your AWS RCS Agent in Peru, submit a country launch registration using the `PE_RCS_LAUNCH_REGISTRATION` registration type. Peru uses the standard baseline registration form. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).
