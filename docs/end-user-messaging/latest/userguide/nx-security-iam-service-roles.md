

# Service roles and service-linked roles for AWS End User Messaging
<a name="nx-security-iam-service-roles"></a>

**Supports service roles: Yes.** AWS End User Messaging supports service roles, for example a role that lets the service publish events to an Amazon Kinesis Data Firehose or Amazon SNS destination on your behalf.

**Supports service-linked roles: Yes.** For details about creating or managing the AWS End User Messaging service-linked role, see [Using service-linked roles for AWS End User Messaging](nx-security-slr.md).
