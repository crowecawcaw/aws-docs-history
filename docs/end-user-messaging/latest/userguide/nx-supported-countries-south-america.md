

# South America
<a name="nx-supported-countries-south-america"></a>

AWS End User Messaging supports 13 countries and regions in South America. The following table lists each country along with the messaging channels and SMS origination identities that AWS End User Messaging supports there. A value of **No** means that AWS End User Messaging does not support that capability in the country.


**Channel support by country in South America**  

| Country or region | ISO code | SMS short codes | SMS long codes | SMS Sender IDs | SMS two-way | International sending | MMS | Voice | RCS | WhatsApp | 
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | 
| Argentina | AR | Yes | No | No | No | Yes | No | Yes | No | Yes | 
| Bolivia | BO | No | No | Yes | No | Yes | No | No | No | Yes | 
| Brazil | BR | Yes | No | No | Yes | Yes | No | Yes | Yes | Yes | 
| Chile | CL | Yes | Yes | No | Yes | Yes | No | Yes | No | Yes | 
| Colombia | CO | Yes | No | No | No | Yes | No | Yes | Yes | Yes | 
| Ecuador | EC | Yes | No | No | Yes | Yes | No | Yes | No | Yes | 
| French Guiana | GF | No | No | Yes | No | Yes | No | No | No | Yes | 
| Guyana | GY | No | No | Yes | No | Yes | No | No | No | Yes | 
| Paraguay | PY | No | No | No | No | Yes | No | No | No | Yes | 
| Peru | PE | Yes | No | No | Yes | Yes | No | Yes | Yes | Yes | 
| Suriname | SR | No | No | Yes | No | Yes | No | No | No | Yes | 
| Uruguay | UY | Yes | No | No | Yes | Yes | No | Yes | No | Yes | 
| Venezuela | VE | No | No | No | No | Yes | No | Yes | No | Yes |
