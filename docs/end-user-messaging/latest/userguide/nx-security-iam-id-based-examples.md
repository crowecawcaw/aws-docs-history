

# Identity-based policy examples for AWS End User Messaging
<a name="nx-security-iam-id-based-examples"></a>

By default, users and roles do not have permission to create or modify AWS End User Messaging resources. They also cannot perform tasks by using the AWS Management Console, AWS Command Line Interface (AWS CLI), or AWS API. To grant users permission to perform actions on the resources that they need, an IAM administrator can create IAM policies. The administrator can then add the IAM policies to roles, and users can assume the roles.
