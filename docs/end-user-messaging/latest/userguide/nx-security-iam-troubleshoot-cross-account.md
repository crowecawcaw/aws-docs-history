

# I want to allow people outside of my AWS account to access my AWS End User Messaging resources
<a name="nx-security-iam-troubleshoot-cross-account"></a>

You can create a role that users in other accounts or people outside of your organization can use to access your resources. You can specify who is trusted to assume the role. For more information, see [Providing access to AWS accounts owned by third parties](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_common-scenarios_third-party.html) in the *IAM User Guide*.
