

# Edit a configuration set protect configuration association in AWS End User Messaging
<a name="nx-features-configuration-sets-edit-protect"></a>

To change a configuration set's associated protect configuration, you can use the AWS End User Messaging console, the `AssociaterotectConfiguration` action in the AWS End User Messaging and voice v2 API, or the `aws sms-voice associate-protect-configuration` command in the AWS CLI. This section shows how to change a configuration set's protect configuration using the AWS End User Messaging console and the AWS CLI.

To learn more about protect configurations see protect configurations.

------
#### [ Edit a configuration set's protect configuration association (Console) ]

1. Open the AWS End User Messaging console at [https://console.aws.amazon.com/end-user-messaging/](https://console.aws.amazon.com/end-user-messaging/).

1. In the navigation pane, under **Configurations**, choose **Configuration sets**.

1. On the **Configuration sets** page, choose a configuration set. 

1. On the **Configuration set details page** choose the **Protect configuration** tab and then **Edit settings**.

1. Under **Protect configuration management** for **Protect configuration**, choose the protect configuration to associate with the configuration set. This replaces the current protect configuration association. Choose **No association** to disassociate the configuration set from a protect configuration.

1. Choose **Save changes**

------
#### [ Edit a configuration set's protect configuration association (AWS CLI) ]

To change a configuration set's protect configuration association in the AWS CLI follow the direction in the Edit a protect configuration association (AWS CLI) instructions on the Edit a protect configuration association (AWS CLI) tab.
