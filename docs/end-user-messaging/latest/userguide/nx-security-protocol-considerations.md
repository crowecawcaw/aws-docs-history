

# SMS protocol security considerations
<a name="nx-security-protocol-considerations"></a>

It is important to understand the inherent limitations of the SMS protocol itself. Unlike secure messaging apps, SMS does not provide end-to-end encryption, message revocation, inherent sender authentication, or checksum error detection, and in some cases may store SMS messages in plain text on the device. There are also practical limitations, such as message size, that can impact how recipients view your message. For more information, see [Limits and quotas](nx-sms-scale-limits.md).
