

# Finland
<a name="nx-reg-short-fi"></a>

To send messages that use a short code in Finland, you must complete the Finland short code registration.

**ISO code:** FI \| **Number type:** short code \| **Registration:** Required

To register, complete the following steps in the console. Fields marked optional can be left blank.

1. Open the console, choose **Registrations**, then choose **Create registration**.

1. In the **Company info** section, enter the following, then choose **Next**:
   + For **Company name**, legal name of your company. The value must be 1 to 100 characters.
   + For **Company identification number**, legal identification number of your company (such as EIN or VAT). The value must be 1 to 30 characters.
   + For **DBA (Doing Business As) name (optional)**, dBA (Doing Business As) or brand name if different from the legal name of your company. The value must be 1 to 100 characters.
   + For **Company website**, full URL of your company's website. The value must be 4 to 100 characters.
   + For **Contact first name**, first name of company point of contact. The value must be 1 to 100 characters.
   + For **Contact last name**, last name of company point of contact. The value must be 1 to 100 characters.
   + For **Contact email address**, business email address for company point of contact. The value must be 5 to 100 characters.
   + For **Contact phone number**, phone number for company point of contact. Include country code. The value must be 3 to 30 characters.

1. In the **Company address** section, enter the following, then choose **Next**:
   + For **Address 1**, physical street address associated with your company. The value must be 1 to 100 characters.
   + For **Address 2 (optional)**, unit number of the physical address, if applicable. The value must be 1 to 100 characters.
   + For **City**, city where the physical address is located. The value must be 1 to 100 characters.
   + For **State / province**, state, province, or region where the physical address is located. The value must be 1 to 50 characters.
   + For **Postal code (optional)**, postal code / ZIP code where the physical address is located. The value must be 1 to 20 characters.
   + For **Country code**, two-digit ISO country code where the physical address is located. The value must be 2 to 2 characters.

1. In the **Service Info And Use Case** section, enter the following, then choose **Next**:
   + For **Service name**, name of your SMS service or feature. The value must be 1 to 100 characters.
   + For **Use case category**, select the category which most closely aligns with your use case.
   + For **Use case description**, description of your use case for sending SMS messages with this short code. The value must be 1 to 500 characters.
   + For **Monthly outbound SMS volume**, estimated number of SMS messages which will be sent from this short code each month.
   + For **Monthly inbound SMS volume**, estimated number of SMS messages which will be received by this short code each month.
   + For **Estimated monthly contacts**, the estimated number of unique users you expect to contact in one month. The value must be 1 to 50 characters.
   + For **Peak volume hours**, specify the days and hours when expect your highest volume of messages (e.g., Mon-Fri 08:00-09:00). The value must be 1 to 100 characters.
   + For **Is this a one-way or two-way program?**, select whether you require only sending outbound messages with this number or if you require 2-way messaging (both outbound and inbound).
   + For **Opt-in method**, how the user will opt-in.
   + For **Opt-in method other (optional)**, if you chose Other, please explain. The value must be 1 to 100 characters.
   + For **Opt-in method user experience flow 1 (optional)**, provide a step-by-step description of the end user experience when signing up for the SMS service. The value must be 1 to 1500 characters.
   + For **Opt-in mock-up 1 (optional)**, attach a mock up showing the call-to-action or opt-in location. Valid upload file types are PDF, PNG, and JPEG.
   + For **Opt-in method user experience flow 2 (optional)**, provide a step-by-step description of the end user experience when signing up for the SMS service. The value must be 1 to 1500 characters.
   + For **Opt-in mock-up 2 (optional)**, attach a mock up showing the call-to-action or opt-in location. Valid upload file types are PDF, PNG, and JPEG.
   + For **Opt-in method user experience flow 3 (optional)**, provide a step-by-step description of the end user experience when signing up for the SMS service. The value must be 1 to 1500 characters.
   + For **Opt-in mock-up 3 (optional)**, attach a mock up showing the call-to-action or opt-in location. Valid upload file types are PDF, PNG, and JPEG.
   + For **Customer service email address**, the email address your users can use to contact customer service. The value must be 5 to 100 characters.
   + For **Customer service phone number**, the phone number your users can call to contact customer service. The value must be 3 to 30 characters.
   + For **Customer service hours**, hours of availability for customer support. The value must be 1 to 100 characters.

1. In the **Message Samples** section, enter the following, then choose **Next**:
   + For **HELP response (optional)**, provide the response when end users reply to your number with the keyword HELP. The value must be 1 to 160 characters.
   + For **STOP response (optional)**, provide the response when end users reply to your number with the keyword STOP. The value must be 1 to 160 characters.
   + For **Message sample 1**, provide at least 1 sample message per message type you intend to send from this number. The value must be 1 to 306 characters.
   + For **Message sample 2 (optional)**, The value must be 1 to 306 characters.
   + For **Message sample 3 (optional)**, The value must be 1 to 306 characters.

1. Review your entries on the **Review and submit** page, then choose **Submit registration**. After you submit, the registration is reviewed and its status is updated.
