

# Launching RCS in Germany
<a name="nx-rcs-launch-de"></a>

To launch your AWS RCS Agent in Germany, submit a country launch registration using the `DE_RCS_LAUNCH_REGISTRATION` registration type. Germany requires an additional out-of-band brand verification step that you must complete outside the AWS End User Messaging console. Germany uses the standard baseline registration form. For the baseline country launch registration fields and the overall registration and compliance process, see [How to get set up](nx-rcs-get-set-up.md).

**Important**  
Your privacy policy and terms of service URLs must link to pages written in the German language. Non-German privacy policies or terms of service will result in registration denial by German carriers.
