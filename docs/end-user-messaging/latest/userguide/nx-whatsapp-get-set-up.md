

# How to get set up
<a name="nx-whatsapp-get-set-up"></a>

This topic takes you from a new AWS account to sending your first WhatsApp message with AWS End User Messaging. Complete the following steps.


**Setup steps**  

| Step | What you do | 
| --- | --- | 
| [Prerequisites](nx-whatsapp-gsu-prereqs.md) | Set up your AWS account, IAM permissions, the AWS CLI, and a Meta Business account. | 
| [Step 1: Link your WhatsApp Business Account](nx-whatsapp-gsu-link-waba.md) | Link a WhatsApp Business Account (WABA) to connect Meta's WhatsApp Business Platform to your AWS account. | 
| [Step 2: Add a WhatsApp business phone number](nx-whatsapp-gsu-add-number.md) | Add a WhatsApp business phone number to send from. |
