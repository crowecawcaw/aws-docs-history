

# Shared routes
<a name="nx-features-phone-numbers-shared-routes"></a>

In some countries, AWS End User Messaging maintains a pool of shared origination identities. When you activate shared routes, AWS End User Messaging makes an effort to deliver your message using one of the shared identities. Shared identities are unavailable in some countries, including the United States.

**Enable shared routes (Console)**

1. Open the AWS End User Messaging console at [https://console.aws.amazon.com/end-user-messaging/](https://console.aws.amazon.com/end-user-messaging/).

1. In the navigation pane, under **Configurations**, choose **Phone numbers**.

1. On the **Phone numbers** page, choose the phone number that will have shared routes enabled.

1. On the **Shared routes** tab, choose the **Edit settings** button.

1. Choose **Enable shared routes** and then **Save changes**.
