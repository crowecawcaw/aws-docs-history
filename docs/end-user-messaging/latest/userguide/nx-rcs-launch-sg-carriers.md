

# Carrier coverage
<a name="nx-rcs-launch-sg-carriers"></a>

Singapore has four carriers with different requirements. Singtel requires the full SGNIC prerequisite, Bizfile, and LOA described above. M1, StarHub, and TPG follow the standard approval process with no additional requirements beyond the registration form.

**Note**  
Your agent may reach PARTIAL status (approved on M1, StarHub, and TPG) while Singtel completes their additional review process. You can begin sending RCS messages to recipients on approved carriers while waiting for Singtel approval.

For general compliance guidance that applies to all countries, see [How to get set up](nx-rcs-get-set-up.md).
