

# Policy condition keys for AWS End User Messaging
<a name="nx-security-iam-service-conditions"></a>

**Supports service-specific policy condition keys: Yes**

Administrators can use AWS JSON policies to specify who has access to what. That is, which principal can perform actions on what resources, and under what conditions. The `Condition` element (or `Condition` block) lets you specify conditions in which a statement is in effect.
