## Task 3.1: Design architectures based on AWS pricing models.
<a name="solutions-architect-professional-03-domain3-task1"></a>
+ Skill 3.1.1: Select appropriate purchase options based on usage patterns, including commitment-based and capacity-based options (for example, provisioned capacity, Reserved Instances, AWS Savings Plans, Spot Instances, On-Demand Instances).
+ Skill 3.1.2: Design cost-optimized architectures to meet workload requirements (for example, by using Graviton-based instances, AWS Step Functions Standard Workflows or Express Workflows, AWS Lambda functions).
+ Skill 3.1.3: Implement rightsizing and scaling strategies based on performance metrics (for example, by using AWS Compute Optimizer, scheduled scaling, target tracking policies, AWS Fargate Spot).
+ Skill 3.1.4: Optimize costs for AI/ML workloads by selecting the appropriate service tier, implementing batching strategies, and designing caching patterns (for example, by using Amazon Bedrock, Amazon SageMaker AI).

## Task 3.2: Optimize data transfer and network costs.
<a name="solutions-architect-professional-03-domain3-task2"></a>
+ Skill 3.2.1: Design content delivery architectures, origin selection strategies, caching strategies, and failover patterns (for example, by using Amazon CloudFront, Amazon CloudFront Origin Shield).
+ Skill 3.2.2: Optimize data transfer costs by using strategies such as private connectivity, Regional traffic patterns, and inter-Availability Zone/inter-Region strategies (for example, by using VPC endpoints, NAT gateways, Availability Zone-aware architectures).
+ Skill 3.2.3: Configure cost-aware, multi-Region data replication (for example, by using Amazon S3 Cross-Region Replication, Amazon DynamoDB global tables).
+ Skill 3.2.4: Design cost-effective network architectures (for example, by using AWS Transit Gateway data processing charges, AWS PrivateLink pricing models).
+ Skill 3.2.5: Optimize data transfer costs for AI/ML workloads by using strategies such as cross-Region inference routing.

## Task 3.3: Design cost allocation and visibility solutions.
<a name="solutions-architect-professional-03-domain3-task3"></a>
+ Skill 3.3.1: Design tagging strategies for cost allocation (for example, by using tags for business units, projects, and environments).
+ Skill 3.3.2: Configure cost reporting and analytics solutions that use detailed billing data (for example, by using AWS Cost Explorer, AWS Cost and Usage Reports).
+ Skill 3.3.3: Implement policy-based tagging enforcement for cost allocation (for example, by using SCPs, AWS Config rules, tag policies).
+ Skill 3.3.4: Implement chargeback and showback capabilities for cost allocation (for example, by using cost categories, split cost allocation, token usage monitoring for Amazon Bedrock).
+ Skill 3.3.5: Configure cost monitoring and alerting solutions that include budget thresholds and anomaly detection (for example, by using AWS Budgets, AWS Cost Anomaly Detection).

## Task 3.4: Optimize storage and database costs.
<a name="solutions-architect-professional-03-domain3-task4"></a>
+ Skill 3.4.1: Implement intelligent storage tiering and lifecycle policies (for example, by using Amazon S3 Intelligent-Tiering, S3 Lifecycle policies, S3 Glacier storage classes, Amazon EFS lifecycle policies).
+ Skill 3.4.2: Optimize block storage costs by selecting appropriate volume types and provisioning appropriate input/output operations per second (IOPS) (for example, Amazon EBS gp3 volumes, EBS gp2 volumes, Provisioned IOPS).
+ Skill 3.4.3: Optimize database costs by selecting appropriate capacity modes and reserved capacity (for example, DynamoDB capacity modes, Amazon RDS reserved DB instances, Amazon Aurora serverless, Aurora I/O-Optimized, Database Savings Plans).
+ Skill 3.4.4: Implement backup and disaster recovery mechanisms that use cost-optimized retention policies (for example, by using AWS Backup, Amazon Data Lifecycle Manager).
+ Skill 3.4.5: Design cost-effective observability solutions that include features such as log filtering, metric aggregation, and retention optimization.
