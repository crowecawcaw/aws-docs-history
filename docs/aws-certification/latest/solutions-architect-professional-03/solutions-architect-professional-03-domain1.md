## Task 1.1: Design architectures built for the cloud.
<a name="solutions-architect-professional-03-domain1-task1"></a>
+ Skill 1.1.1: Design event-driven architectures that use appropriate messaging patterns such as idempotency, ordering, and delivery guarantees (for example, by using Amazon EventBridge, Amazon SQS FIFO queues and standard queues, Amazon SNS, Amazon Kinesis with partition keys).
+ Skill 1.1.2: Design stateless applications that use externalized state management (for example, by using Amazon DynamoDB, Amazon S3, Amazon ElastiCache).
+ Skill 1.1.3: Design serverless data processing and analysis pipelines (for example, by using Amazon Kinesis Data Streams, AWS Glue, Amazon Athena, AWS Lambda).
+ Skill 1.1.4: Design multi-step workflows that have durable execution patterns (for example, by using AWS Step Functions, durable Lambda functions).
+ Skill 1.1.5: Implement cross-account and cross-Region event routing patterns that use event buses and event forwarding.
+ Skill 1.1.6: Design container orchestration for microservices by using managed services (for example, Amazon EKS, Amazon ECS, AWS Fargate).
+ Skill 1.1.7: Design service mesh architectures that facilitate microservice communication and observability (for example, by using Amazon VPC Lattice, Amazon ECS Service Connect).
+ Skill 1.1.8: Manage container images by configuring security scans and lifecycle policies (for example, by using Amazon ECR).
+ Skill 1.1.9: Design auto scaling patterns for serverless and containerized workloads (for example, by using Lambda concurrency, Horizontal Pod Autoscaler, Cluster Autoscaler, Amazon ECS service auto scaling, AWS Application Auto Scaling).
+ Skill 1.1.10: Design ingress patterns and optimize resources for specific usage patterns (for example, Application Load Balancer, Network Load Balancer, AWS Load Balancer Controller, Amazon API Gateway).
+ Skill 1.1.11: Design edge architectures to meet latency requirements (for example, by using Amazon CloudFront Functions, Lambda@Edge).
+ Skill 1.1.12: Design architectures that support real-time data processing by using WebSocket and publish-subscribe patterns (for example, by using API Gateway WebSocket APIs).
+ Skill 1.1.13: Design multi-tenant architectures that use tenant isolation patterns (for example, siloed or pooled resources, Amazon Cognito tenant context, row-level security, tenant-specific encryption).

## Task 1.2: Integrate AI and ML services into architectures.
<a name="solutions-architect-professional-03-domain1-task2"></a>
+ Skill 1.2.1: Design generative AI integrations for applications, including for multi-account deployment patterns (for example, by using Amazon Bedrock).
+ Skill 1.2.2: Design AI agent architectures that integrate with tools (for example, by using Amazon Bedrock AgentCore, Amazon Bedrock Knowledge Bases).
+ Skill 1.2.3: Design ML inference architectures (for example, Amazon SageMaker AI endpoints).
+ Skill 1.2.4: Design RAG architectures, including ingestion and retrieval strategies (for example, Amazon Bedrock knowledge bases that use vector stores).

## Task 1.3: Design hybrid cloud integration patterns.
<a name="solutions-architect-professional-03-domain1-task3"></a>
+ Skill 1.3.1: Design hybrid connectivity that provides redundancy and failover capabilities (for example, by using AWS Direct Connect, AWS VPN, AWS Transit Gateway).
+ Skill 1.3.2: Design data synchronization strategies for hybrid workloads (for example, by using AWS DataSync, AWS Storage Gateway, AWS Transfer Family).
+ Skill 1.3.3: Design integration patterns to modernize legacy systems by using data transformations (for example, by using API Gateway, Lambda, Amazon MQ).
+ Skill 1.3.4: Design DNS solutions for hybrid environments (for example, by using Amazon Route 53 Resolver endpoints, Route 53 private hosted zones, split-horizon DNS, conditional forwarding).
+ Skill 1.3.5: Design hybrid compute patterns (for example, by using Amazon EKS Anywhere, Amazon ECS Anywhere, AWS Outposts, AWS Local Zones).

## Task 1.4: Design network architectures.
<a name="solutions-architect-professional-03-domain1-task4"></a>
+ Skill 1.4.1: Design multi-VPC architectures that provide hybrid and multi-account connectivity (for example, VPC peering, AWS PrivateLink).
+ Skill 1.4.2: Design VPC architectures by using subnet strategies, IP address management, and network segmentation (for example, by using Amazon VPC IP Address Manager [IPAM], public and private subnets).
+ Skill 1.4.3: Design network security architectures that include traffic inspection, traffic filtering, and application layer protection (for example, by using AWS Network Firewall, AWS WAF, Gateway Load Balancers, security groups, network ACLs, VPC Flow Logs).
+ Skill 1.4.4: Design IPv6 adoption and dual-stack migration strategies.
+ Skill 1.4.5: Design global traffic routing strategies for multi-Region applications (for example, by using Route 53 routing policies, AWS Global Accelerator).

## Task 1.5: Design data, storage, and database architectures.
<a name="solutions-architect-professional-03-domain1-task5"></a>
+ Skill 1.5.1: Design data lake and lakehouse architectures (for example, by using Amazon S3, AWS Lake Formation, Amazon Redshift Spectrum, Apache Iceberg).
+ Skill 1.5.2: Design real-time and batch analytics pipelines (for example, by using Amazon EMR, Amazon Redshift, Amazon Managed Streaming for Apache Kafka [Amazon MSK], Amazon AppFlow).
+ Skill 1.5.3: Select appropriate database services based on workload requirements such as access patterns, consistency needs, and scalability (for example, Amazon RDS, Amazon Aurora, Amazon DynamoDB, Amazon Redshift).
+ Skill 1.5.4: Design database scaling solutions to provide high availability (for example, by using read replicas, Amazon Aurora Global Database, Amazon DynamoDB global tables, Amazon RDS Multi-AZ deployments).
+ Skill 1.5.5: Design storage architectures based on access patterns and performance requirements (for example, by using Amazon S3, Amazon EBS, Amazon EFS, Amazon FSx).
+ Skill 1.5.6: Design data caching strategies to optimize performance (for example, by using ElastiCache, DynamoDB Accelerator [DAX]).
+ Skill 1.5.7: Design data cataloging and cross-account data sharing patterns (for example, AWS Glue Data Catalog, Lake Formation, AWS Clean Rooms).
