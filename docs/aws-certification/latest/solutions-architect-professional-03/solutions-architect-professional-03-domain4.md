## Task 4.1: Design migration strategies by using AWS frameworks.
<a name="solutions-architect-professional-03-domain4-task1"></a>
+ Skill 4.1.1: Design discovery and portfolio assessment solutions to map dependencies and plan migration waves.
+ Skill 4.1.2: Implement rehosting strategies (for example, by using AWS Transform MGN [previously known as AWS Application Migration Service], AWS Transform).
+ Skill 4.1.3: Design database and data migration strategies (for example, by using AWS Database Migration Service, AWS DataSync).
+ Skill 4.1.4: Design replatforming strategies that use managed services to reduce operational overhead (for example, Amazon RDS, Amazon Aurora, Amazon ECS, AWS Lambda).
+ Skill 4.1.5: Implement refactor strategies such as microservices decomposition, serverless adoption, and incremental modernization patterns (for example, strangler fig pattern).
+ Skill 4.1.6: Modernize legacy workloads, including mainframes, applications, and databases.

## Task 4.2: Design disaster recovery architectures.
<a name="solutions-architect-professional-03-domain4-task2"></a>
+ Skill 4.2.1: Design disaster recovery solutions to meet business requirements (for example, RTO, RPO, costs).
+ Skill 4.2.2: Configure continuous replication to recover quickly from incidents (for example, by using AWS Elastic Disaster Recovery).
+ Skill 4.2.3: Establish disaster recovery assessment and recovery procedures (for example, by using AWS Resilience Hub, AWS Systems Manager runbooks).
+ Skill 4.2.4: Implement multi-Region disaster recovery solutions that include features such as data replication and failover (for example, by using Amazon Route 53 health checks, AWS Global Accelerator, Amazon Application Recovery Controller).
+ Skill 4.2.5: Establish disaster recovery testing and validation procedures (for example, by using AWS Resilience Hub).
+ Skill 4.2.6: Implement multi-cluster container strategies to provide high availability and disaster recovery (for example, by using Amazon EKS, Amazon ECS).

## Task 4.3: Design solutions to meet business continuity and resiliency requirements.
<a name="solutions-architect-professional-03-domain4-task3"></a>
+ Skill 4.3.1: Configure centralized backup governance and cross-account backup policies (for example, by using AWS Backup).
+ Skill 4.3.2: Design failover tests and measure recovery times (for example, by using AWS Fault Injection Service, Amazon Route 53 health checks).
+ Skill 4.3.3: Design technically resilient architectures that have features such as redundancy, fault tolerance, and self-healing capabilities.
+ Skill 4.3.4: Protect data against ransomware and accidental deletion (for example, by using Amazon S3 Object Lock, Amazon EBS snapshot lock, AWS Backup Vault Lock).
+ Skill 4.3.5: Implement chaos engineering with controlled failure scenarios (for example, by using AWS Fault Injection Service experiment templates, steady-state hypotheses).
