an Amazon Managed Workflows for Apache Airflow environment. For more examples of using Apache Airflow with AWS services, refer to the
[`dags`](https://github.com/aws-samples/amazon-mwaa-examples/tree/main/dags "https://github.com/aws-samples/amazon-mwaa-examples/tree/main/dags") directory in the Apache Airflow GitHub repository.
