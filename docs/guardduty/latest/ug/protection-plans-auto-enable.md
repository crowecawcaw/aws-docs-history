

# Auto-enable options
<a name="protection-plans-auto-enable"></a>

Each protection plan provides the following auto-enable options for organization accounts:

Enable for all accounts  
Enable the feature for all active GuardDuty accounts in the organization. This includes new accounts that join the organization.

Enable for new accounts  
This will apply to any new accounts when they are added to the organization.

Do not auto enable  
The feature is not automatically enabled for organization accounts.

For the **Foundational GuardDuty** container, the auto-enable options use AWS Organizations-specific wording:
+ **Enable for all AWS Organizations accounts** – Enable GuardDuty for all active accounts in your AWS Organizations.
+ **Enable for new AWS Organizations accounts** – This will apply to any new accounts when they are added to your AWS Organizations.
