# Configuring all protection plans

To configure protection plans from the unified page, use the following steps:

1. Open the GuardDuty console at [https://console.aws.amazon.com/guardduty/](https://console.aws.amazon.com/guardduty/ "https://console.aws.amazon.com/guardduty/").
2. In the navigation pane, choose **Protection Plans**.
3. Choose **Configure all enablements**. All protection plan
   containers switch to edit mode.
4. Make changes across any or all protection plans. For each plan, you can toggle
   the feature on or off and configure the auto-enable setting for organization
   accounts.
5. Choose **Save all**. A confirmation modal appears summarizing
   all changes, including the feature name, status, and auto-enable value for each
   modified plan.
6. Review the changes and choose **Confirm and save**. All
   changes are saved in batch.
