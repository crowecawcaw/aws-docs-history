# Set up an Amazon SNS event destination in AWS End User Messaging SMS

Amazon Simple Notification Service (Amazon SNS) is a web service that enables applications, end-users, and devices to
instantly send and receive notifications. To learn more about Amazon SNS, see the
[Amazon Simple Notification Service Developer Guide](../../../sns/latest/dg.md "../../../sns/latest/dg.md").

Some of the examples in this section assume that you've already installed and configured
the AWS Command Line Interface. For more information about setting up the AWS CLI, see the
[AWS Command Line Interface User Guide](../../../cli/latest/userguide.md "../../../cli/latest/userguide.md").
