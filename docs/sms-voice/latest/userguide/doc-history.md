

# Document history for the AWS End User Messaging SMS User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for AWS End User Messaging SMS.

| Change | Description | Date | 
| --- |--- |--- |
| [Added support for rich RCS messaging](#doc-history) | Added support for sending rich, interactive RCS content with the `SendRcsMessage` API action, including rich cards, carousels, file messages (image, video, audio, and PDF), and interactive suggestions. This release also adds per-message SMS or MMS fallback, message expiration (time-to-live), inbound media, message events, and a console message composer. You can use rich RCS messaging in all countries where RCS is supported. For more information, see [Sending rich RCS messages](https://docs.aws.amazon.com/sms-voice/latest/userguide/rcs-rich-messaging.html). | June 30, 2026 | 
| [RCS country expansion — 22 countries](#doc-history) | Expanded RCS messaging support from 2 countries to 22 countries across North America, South America, Europe, and Asia Pacific. For more information, see [Supported countries for RCS](https://docs.aws.amazon.com/sms-voice/latest/userguide/rcs-supported-countries.html) and [Launching RCS in countries](https://docs.aws.amazon.com/sms-voice/latest/userguide/rcs-country-launch.html). | May 30, 2026 | 
| [Added support for RCS messaging](#doc-history) | Added support for Rich Communication Services (RCS) messaging with verified brand identity, delivery receipts, and automatic SMS fallback. For more information, see [RCS messaging](https://docs.aws.amazon.com/sms-voice/latest/userguide/rcs.html). | March 31, 2026 | 
| [Added support for Notify](#doc-history) | Added support for Notify, a managed messaging solution for sending templated OTP and verification messages using AWS-managed origination identities.
