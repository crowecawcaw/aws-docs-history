# Delete a keyword from a phone number in AWS End User Messaging SMS

Use the AWS End User Messaging SMS console to delete a keyword from your phone number.

###### Note

Required opt-out keywords can't be deleted.

###### To delete a keyword

1. Open the AWS End User Messaging SMS console at
   [https://console.aws.amazon.com/sms-voice/](https://console.aws.amazon.com/sms-voice/ "https://console.aws.amazon.com/sms-voice/").
2. In the navigation pane, under **Configurations**,
   choose **Phone numbers**.
3. On the **Phone numbers** page, choose the phone
   number that contains the keyword.
4. On the **Keywords** tab, choose the keyword to
   delete and then **Remove keyword**.
