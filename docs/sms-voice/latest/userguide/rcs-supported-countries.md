# Supported countries for RCS

AWS End User Messaging supports RCS country launches in the following countries. Each country
has a specific registration type that you use when submitting a country launch
registration. Some countries have additional requirements beyond the standard
registration form — see the country-specific sections for
details.

Countries that link to the standard country launch registration page use the same
baseline registration fields (brand information, use case, screen recording, privacy
policy, and terms of service). Countries with custom forms or out-of-band
requirements have additional steps documented in their country-specific pages.
