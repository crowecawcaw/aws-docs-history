# Rename a protect configuration in

AWS End User Messaging SMS

To help manage your protect configurations you should give them descriptive names. You can
add or edit the name of a protect configuration at any time. You need to add a tag with the
**Key** set to `Name` and the
**Value** set to the name to use.

1. Open the AWS End User Messaging SMS console at
   [https://console.aws.amazon.com/sms-voice/](https://console.aws.amazon.com/sms-voice/ "https://console.aws.amazon.com/sms-voice/").
2. In the navigation pane, under **Protect**,
   choose **Protect configuration**.
3. On the **Protect configuration** page, choose the protect configuration
   to add a tag to.
4. On the **Tags** tab, choose **Manage tags**. In
   **Manage tags**, choose **Add new tag**.
5. For **Key** enter `Name` and for **Value** enter a friendly name.
6. Choose **Save changes**.
