

# China SMS template registration form
<a name="phone-numbers-sms-template-registration"></a>

**China SMS template registration has moved**  
You no longer register China SMS templates by opening a support case. China SMS registration is now self-service in the AWS End User Messaging SMS console, and you register your message templates as part of the registration. Choose the registration that fits what you want to send to China:  
**To register a sender ID** (an alphanumeric sender) – see [China sender ID registration](registrations-china.md).
**To register a short code** (for two-way messaging) – see [China short code registration](registrations-china-short-code.md).

When you create either registration, you provide your message templates as part of the registration. Your message content is matched exactly against the templates you register, so content that is not registered is blocked.
