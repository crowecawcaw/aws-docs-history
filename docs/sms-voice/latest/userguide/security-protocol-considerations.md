# SMS protocol security considerations

It's important to understand the inherent limitations of the SMS protocol itself. Unlike
secure messaging apps, SMS does not provide end-to-end encryption, message revocation, or
inherent sender authentication, checksum error detection, and in some cases may store
SMS in plain text on the device. There are also practical limitations such as message
size that can impact how recipients view your message, see [SMS and MMS limits and restrictions](sms-limitations.md "sms-limitations.md").
