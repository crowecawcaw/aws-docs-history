# OnSalesforceCaseCreate

## AccountId condition

###### Parameters

- Operator - "EQUALS"
- Operands – An array of string, array length can only be 1. Value is an
  account Id string.
- ComparisonValue –
  "$.ThirdParty.Salesforce.CaseCreate.AccountId"
- Negate - true or false. If set to true, it means _If account
  id does not equal to the account id specified in the
  Operands_.
