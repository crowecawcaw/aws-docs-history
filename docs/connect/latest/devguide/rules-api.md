# Rules actions

The following API actions are available for rules:

- [CreateRule](../APIReference/API_CreateRule.md "../APIReference/API_CreateRule.md")
- [DeleteRule](../APIReference/API_DeleteRule.md "../APIReference/API_DeleteRule.md")
- [DescribeRule](../APIReference/API_DescribeRule.md "../APIReference/API_DescribeRule.md")
- [ListRules](../APIReference/API_ListRules.md "../APIReference/API_ListRules.md")
- [UpdateRule](../APIReference/API_UpdateRule.md "../APIReference/API_UpdateRule.md")
  To create a CloudFormation template for rules, see the following topic:

- [AWS::Connect::Rule](../../../AWSCloudFormation/latest/UserGuide/aws-resource-connect-rule.md "../../../AWSCloudFormation/latest/UserGuide/aws-resource-connect-rule.md")
  Use the [Rules Function
  language](../APIReference/connect-rules-language.md "../APIReference/connect-rules-language.md") to code conditions for the rules.

For more information about Connect Customer rules, see [Create rules](../adminguide/connect-rules.md "../adminguide/connect-rules.md") and [Create rules with
Contact Lens](../adminguide/build-rules-for-contact-lens.md "../adminguide/build-rules-for-contact-lens.md") in the _Connect Customer Administrator
Guide_.
