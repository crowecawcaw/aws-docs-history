

# DisconnectParticipant
<a name="participant-actions-disconnectparticipant"></a>

Disconnects the participant from the contact and stops this flow from running. 

## Parameter object
<a name="disconnectparticipant-parameter"></a>

No parameters are expected.

## Results and conditions
<a name="disconnectparticipant-results"></a>

None. Conditions are not supported.

## Errors
<a name="disconnectparticipant-errors"></a>

None.

## Restrictions
<a name="disconnectparticipant-restrictions"></a>

This action is supported for all channels and in contact flows, transfer flows, and customer queue flows.
