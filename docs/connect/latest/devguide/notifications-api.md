

# Notifications actions
<a name="notifications-api"></a>

The following API actions are available for notifications:
+ [CreateNotification](https://docs.aws.amazon.com/connect/latest/APIReference/API_CreateNotification.html)
+ [DeleteNotification](https://docs.aws.amazon.com/connect/latest/APIReference/API_DeleteNotification.html)
+ [DescribeNotification](https://docs.aws.amazon.com/connect/latest/APIReference/API_DescribeNotification.html)
+ [ListNotifications](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListNotifications.html)
+ [ListUserNotifications](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListUserNotifications.html)
+ [SearchNotifications](https://docs.aws.amazon.com/connect/latest/APIReference/API_SearchNotifications.html)
+ [UpdateNotificationContent](https://docs.aws.amazon.com/connect/latest/APIReference/API_UpdateNotificationContent.html)
+ [UpdateUserNotificationStatus](https://docs.aws.amazon.com/connect/latest/APIReference/API_UpdateUserNotificationStatus.html)

For more information about notifications, see [Notifications Connect Customer](https://docs.aws.amazon.com/connect/latest/adminguide/amazon-connect-notifications.html) in the *Connect Customer Administrator Guide*.
