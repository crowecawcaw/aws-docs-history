

# Chat actions
<a name="chat-api"></a>

 The following API actions are available for chats:
+ [CreatePersistentContactAssociation](https://docs.aws.amazon.com/connect/latest/APIReference/API_CreatePersistentContactAssociation.html)
+ [SendChatIntegrationEvent](https://docs.aws.amazon.com/connect/latest/APIReference/API_SendChatIntegrationEvent.html)
+ [StartChatContact](https://docs.aws.amazon.com/connect/latest/APIReference/API_StartChatContact.html)

For more information about chat, see [Concepts: Web and mobile chat capabilities in Connect Customer](https://docs.aws.amazon.com/connect/latest/adminguide/chat.html) in the *Connect Customer Administrator Guide*.
