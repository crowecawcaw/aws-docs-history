

# Metrics actions
<a name="metrics-api"></a>

The following API actions are available for metrics:
+ [GetContactMetrics](https://docs.aws.amazon.com/connect/latest/APIReference/API_GetContactMetrics.html)
+ [GetCurrentMetricData](https://docs.aws.amazon.com/connect/latest/APIReference/API_GetCurrentMetricData.html)
+ [GetCurrentUserData](https://docs.aws.amazon.com/connect/latest/APIReference/API_GetCurrentUserData.html)
+ [GetMetricData](https://docs.aws.amazon.com/connect/latest/APIReference/API_GetMetricData.html)
+ [GetMetricDataV2](https://docs.aws.amazon.com/connect/latest/APIReference/API_GetMetricDataV2.html)

For more information about metrics, see [Metrics, dashboards, and reports in Connect Customer](https://docs.aws.amazon.com/connect/latest/adminguide/amazon-connect-metrics.html) in the *Connect Customer Administrator Guide*.
