

# Evaluation actions
<a name="evaluation-api"></a>

 The following API actions are available for evaluations:
+ [ActivateEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_ActivateEvaluationForm.html)
+ [CreateEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_CreateEvaluationForm.html)
+ [DeactivateEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_DeactivateEvaluationForm.html)
+ [DeleteContactEvaluation](https://docs.aws.amazon.com/connect/latest/APIReference/API_DeleteContactEvaluation.html)
+ [DescribeContactEvaluation](https://docs.aws.amazon.com/connect/latest/APIReference/API_DescribeContactEvaluation.html)
+ [DeleteEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_DeleteEvaluationForm.html)
+ [DescribeEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_DescribeEvaluationForm.html)
+ [ListContactEvaluations](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListContactEvaluations.html)
+ [ListEvaluationForms](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListEvaluationForms.html)
+ [ListEvaluationFormVersions](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListEvaluationFormVersions.html)
+ [StartContactEvaluation](https://docs.aws.amazon.com/connect/latest/APIReference/API_StartContactEvaluation.html)
+ [SubmitContactEvaluation](https://docs.aws.amazon.com/connect/latest/APIReference/API_SubmitContactEvaluation.html)
+ [UpdateContactEvaluation](https://docs.aws.amazon.com/connect/latest/APIReference/API_UpdateContactEvaluation.html)
+ [UpdateEvaluationForm](https://docs.aws.amazon.com/connect/latest/APIReference/API_UpdateEvaluationForm.html)

To create a CloudFormation template for evaluation forms, see the following topic:
+  [AWS::Connect::EvaluationForm](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-resource-connect-evaluationform.html) resource in the *CloudFormation User Guide*

For more information about evaluations, see [Evaluate agent performance](https://docs.aws.amazon.com/connect/latest/adminguide/evaluations.html) in the *Connect Customer Administrator Guide*.
