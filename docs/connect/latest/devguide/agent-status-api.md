

# Agent status actions
<a name="agent-status-api"></a>

 The following API actions are available for agent status:
+ [CreateAgentStatus](https://docs.aws.amazon.com/connect/latest/APIReference/API_CreateAgentStatus.html)
+ [DescribeAgentStatus](https://docs.aws.amazon.com/connect/latest/APIReference/API_DescribeAgentStatus.html)
+ [ListAgentStatuses](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListAgentStatuses.html)
+ [PutUserStatus](https://docs.aws.amazon.com/connect/latest/APIReference/API_PutUserStatus.html)
+ [SearchAgentStatuses](https://docs.aws.amazon.com/connect/latest/APIReference/API_SearchAgentStatuses.html)
+ [UpdateAgentStatus](https://docs.aws.amazon.com/connect/latest/APIReference/API_UpdateAgentStatus.html)

**Note**  
Agent status ARNs cannot be deleted but can be renamed or disabled if needed.

For more information about agent status, see [About agent status](https://docs.aws.amazon.com/connect/latest/adminguide/metrics-agent-status.html) in the *Connect Customer Administrator Guide*.
