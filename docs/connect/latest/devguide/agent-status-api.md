# Agent status actions

The following API actions are available for agent status:

- [CreateAgentStatus](../APIReference/API_CreateAgentStatus.md "../APIReference/API_CreateAgentStatus.md")
- [DescribeAgentStatus](../APIReference/API_DescribeAgentStatus.md "../APIReference/API_DescribeAgentStatus.md")
- [ListAgentStatuses](../APIReference/API_ListAgentStatuses.md "../APIReference/API_ListAgentStatuses.md")
- [PutUserStatus](../APIReference/API_PutUserStatus.md "../APIReference/API_PutUserStatus.md")
- [SearchAgentStatuses](../APIReference/API_SearchAgentStatuses.md "../APIReference/API_SearchAgentStatuses.md")
- [UpdateAgentStatus](../APIReference/API_UpdateAgentStatus.md "../APIReference/API_UpdateAgentStatus.md")

###### Note

Agent status ARNs cannot be deleted but can be renamed or disabled if needed.

For more information about agent status, see [About agent status](../adminguide/metrics-agent-status.md "../adminguide/metrics-agent-status.md")
in the _Connect Customer Administrator Guide_.
