

# Tag actions
<a name="tags-api"></a>

The following API actions are available for tags:
+ [SearchResourceTags](https://docs.aws.amazon.com/connect/latest/APIReference/API_SearchResourceTags.html)
+ [TagResource](https://docs.aws.amazon.com/connect/latest/APIReference/API_TagResource.html)
+ [ListTagsForResource](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListTagsForResource.html)
+ [UntagResource](https://docs.aws.amazon.com/connect/latest/APIReference/API_UntagResource.html)

For more information about tags, see [Tagging resources in Connect Customer](https://docs.aws.amazon.com/connect/latest/adminguide/tagging.html) in the *Connect Customer Administrator Guide*.
