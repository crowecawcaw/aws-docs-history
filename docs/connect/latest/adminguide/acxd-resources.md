

# Working with resources
<a name="acxd-resources"></a>

Resources are reusable building blocks that help you create, manage, and scale experiences in agentic CX designer.

Instead of configuring the same content, data, or settings repeatedly, you can create resources once and reuse them wherever they're needed in the workspace. This keeps things easier to manage and helps teams build more consistent conversational AI applications.

Use Resources to manage shared items such as:
+ *Context variables* for session-wide memory
+ *Data requests* for connecting to external data
+ *Knowledge bases* for trusted answer content
+ *Modalities* for rich UI interactions
+ *Secrets* for secure reusable values
+ *Custom slots* for structured user selections
+ *Resource tags* for organization and search
+ *Translations* for multilingual content

To access Resources, select it from your workspace navigation and select the resource type you want to create or manage.
