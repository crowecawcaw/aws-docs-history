# Working with resources

Resources are reusable building blocks that help you create, manage, and scale
experiences in agentic CX designer.

Instead of configuring the same content, data, or settings repeatedly, you can
create resources once and reuse them wherever they're needed in the workspace.
This keeps things easier to manage and helps teams build more consistent
conversational AI applications.

Use Resources to manage shared items such as:

- _Context variables_ for session-wide memory
- _Data requests_ for connecting to external data
- _Knowledge bases_ for trusted answer content
- _Modalities_ for rich UI interactions
- _Secrets_ for secure reusable values
- _Custom slots_ for structured user selections
- _Resource tags_ for organization and search
- _Translations_ for multilingual content
  To access Resources, select it from your workspace navigation and select the resource
  type you want to create or manage.
