

# Use views to create custom workspace pages
<a name="use-views-to-create-persona-based-workspace-pages"></a>

With views, you can create customized pages within workspaces that are assigned to different Connect Customer users. To create a new view, begin by selecting the appropriate Workspace purpose. After you access the UI builder, you can filter and select from the available UI components that are ready to use in your view.

Views designed for workspace pages function as single-step interfaces tailored to specific user groups. To ensure optimal functionality, use compatible components such as Alert, Carousel, and Containers. With workspace views, you can incorporate the Data Table component to manage contact center operations in real time. This includes critical use cases such as call routing adjustments and implementing emergency protocols.

## Pass input data from the workspace onto the view
<a name="pass-input-data-from-workspace-onto-view"></a>

When using views to create workspace pages, you can pass input data at runtime through the page configuration wizard. This dynamic approach means you can create reusable views that adapt to different contexts without requiring separate implementations for each use case.

For example, when creating a view for home pages, you might want to display personalized greetings to different users. Rather than building a unique view for each workspace, you can create a single view with dynamic header components and reuse that view across multiple workspaces, each with its own customized message content.
