# Using Views to create persona-based Workspace pages

Views enable you to create customized pages within persona-based Workspaces that are assigned to different Connect users. To create a new view, begin by selecting the appropriate Workspace purpose. After you access the UI builder, you can filter and select from the available UI components that are ready to use in your Workspace view.

Views designed for Workspace pages function as single-step interfaces tailored to specific user groups. To ensure optimal functionality, use compatible components such as Alert, Carousel, and Containers. Workspace views can also incorporate the Data Table component, which empowers business users to manage contact center operations in real time. This includes critical use cases such as call routing adjustments and implementing emergency protocols.

## Passing input data from the Workspace onto the View

When using Views to create Workspace pages, you can pass input data at runtime through the page configuration wizard. This dynamic approach enables you to create reusable Views that adapt to different contexts without requiring separate implementations for each use case.

For example, when creating a View for user homepages, you might want to display personalized greetings to different users. Rather than building a unique View for each Workspace, you can create a single View with dynamic header components and reuse that View across multiple Workspaces, each with its own customized message content.
