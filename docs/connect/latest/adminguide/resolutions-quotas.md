

# Resolutions quotas

## Resolutions
<a name="resolutions-quotas-resolutions"></a>


| Resource | Quota | 
| --- | --- | 
| Work plans per instance | 20 | 
| Versions per Work plan | 10 | 
|  Work plan versions associated with one Case template at a time  | 1 | 
| Maximum wait between Step completions on a Resolutions Case | 7 days | 
| Maximum duration of a Work plan on a Resolutions Case | 90 days. The Work plan closes when it reaches this limit. | 

## Attachments that a Work plan reads
<a name="resolutions-quotas-attachments-that-a-work-plan-reads"></a>


| Resource | Quota | 
| --- | --- | 
| Size of one attachment that a Work plan can read | 4.5 MB | 
| Attachment formats that a Work plan can read | .pdf, .txt, .csv, .html, .md, .xls, .xlsx | 

## Quotas for the features that Resolutions uses
<a name="resolutions-quotas-quotas-for-the-features-that-resolutions-uses"></a>

 Email, attachments, Cases, and Tasks have their own quotas, such as email addresses per instance, message size, and attachments per email. See [Connect Customer feature specifications](feature-limits.md) and [Connect Customer service quotas](amazon-connect-service-limits.md).
