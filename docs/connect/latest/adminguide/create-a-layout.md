# Create a layout

Create additional layouts to design new dashboard configurations without
affecting the layout currently shown to your users.

1. On the **Profile layouts** page, choose **Create
   layout**.
2. Use the layout editor to name your layout, add and arrange widgets, and
   organize tabs. For more information about editing a layout, see [Get started with Connect Customer Customer Profiles Profile Explorer](getting-started-profile-explorer.md "getting-started-profile-explorer.md").
3. When you're ready to save, choose **Save layout**.
4. In the **Save your layout** dialog, optionally select
   **Set as default layout** to immediately make this the
   layout your users see. Leave this option cleared to save the layout without
   changing your domain's current default.
5. Choose **Save**.

###### Note

You can leave the layout editor at any time by choosing **Cancel**. If you have unsaved
changes, you're asked to confirm before your changes are discarded.
