# Object type mapping in Amazon Connect

Customer Profiles

Object type mapping tells Customer Profiles how to ingest a specific type of data. It provides Customer Profiles
with essential information, such as:

- How data should be populated from the object and ingested into the standard
  profile object.
- What fields should be indexed in the object and how those fields should then
  be used to assign objects of this type to a specific profile.
  The topics in this section provide information and steps to help you set up object
  type mapping, including how to create object type mapping, mapping definition details,
  and key concepts and terminology.
