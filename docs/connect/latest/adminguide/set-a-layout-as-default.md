

# Set a layout as default
<a name="set-a-layout-as-default"></a>

You don't have to set a layout as default when you create it. You can promote any saved layout to be the default at a later time.

1. On the **Profile layouts** page, select the layout you want to make the default.

1. Choose **Make default**.

**Note**  
**Make default** is disabled if no layout is selected, or if the selected layout is already the default.
