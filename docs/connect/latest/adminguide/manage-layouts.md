# Manage layouts

Manage layouts lets administrators maintain multiple Profile explorer layouts for a
domain, choose which layout is shown to users by default, and create new layouts
without disrupting the layout your users currently see. This is useful if you want to
build and test a new layout before rolling it out, or if you want to keep multiple
layouts on hand for different use cases.
