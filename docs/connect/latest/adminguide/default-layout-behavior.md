# Default layout behavior

Each Connect Customer Customer Profiles domain has a single default Profile explorer layout. This is the
layout that all users with view access see when they open Profile explorer for a
customer profile. Only one layout can be the default at a time—setting a new
layout as default automatically removes default status from the previous
one.

When you open Profile explorer, the board is read-only. To make changes, choose
**Manage layouts** to create a new layout or edit an existing
one. This keeps the layout your users see stable while you build and test
changes.

If your domain doesn't have a default layout yet, Profile explorer displays a
system-provided starter layout until an administrator creates and sets a default.
The first layout you save with **Set as default layout** selected
becomes the default for your domain.
