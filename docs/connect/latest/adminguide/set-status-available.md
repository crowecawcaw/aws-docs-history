# Set your status to "Available" in the Contact

Control Panel (CCP)

As a call center agent, set an **Available** status when
you’re ready to handle contacts.

Amazon Connect uses information in the agent's [routing
profile](routing-profiles.md "routing-profiles.md") to determine which contacts to route to them.

For more information about agent statuses, see [Agent status in the Contact Control Panel
(CCP)](metrics-agent-status.md "metrics-agent-status.md"). For information about how Amazon Connect counts the
Available status in the real-time metrics report, see [Available](metrics-definitions.md#available-real-time "metrics-definitions.md#available-real-time").
