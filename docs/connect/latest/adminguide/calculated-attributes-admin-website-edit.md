# Edit calculated

attributes in Amazon Connect

1. To edit a calculated attribute, choose an attribute in the table view
   by selecting the radio button, which enables the
   **Edit** button. Choose
   **Edit**.

![edit a calculated attribute](images/calculated-attributes-admin-website-edit-1.png) 2. You can edit the **Description**, **Number of
events**, and **Time period**. When done,
choose **Save**.

![Edit a calculated attribute.](images/calculated-attributes-admin-website-edit-2.png)
