# Enter a script in a Contact Lens rule

for agents to follow

Enter a script in a Contact Lens rule when you need agents to use exact
wording in customer calls.

To enter a script in a rule, enter phrases. For example, if you want to
highlight when agents say _Thank you for being a member. We appreciate
your business_, enter two phrases:

- Thank you for being a member.
- We appreciate your business.
  To apply the rule to certain lines of businesses, add a condition for which
  queues it applies to, or contact attributes. For example, the following image
  shows a rule that applies when an agent is working the BasicQueue or Billing and
  Payments queues, the customer is for auto insurance, and the agent is located in
  Seattle.
