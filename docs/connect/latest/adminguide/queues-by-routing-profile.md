# List queues grouped by routing profile

in Amazon Connect

This topic explains how to display a list of queues organized by routing profile
in your Amazon Connect contact center.

1. On the Amazon Connect admin website, choose **Analytics and optimization**,
   **Real-time metrics**,
   **Queues**.
2. Access the **Settings** menu: look for and choose the
   "Settings" icon.

![The settings icon for the queues table.](images/rtm-settings.png) 3. In the Settings menu, select the **Groupings** tab. 4. Choose the option **Queues grouped by routing
profiles**. 5. Choose **Apply** to apply your changes.
After completing these steps, your queues will be displayed grouped by their
associated routing profiles.
