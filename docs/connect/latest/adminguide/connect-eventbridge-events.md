# EventBridge events emitted by Amazon Connect

Amazon Connect emits a variety of events related to the contact center, including but
not limited to the following types of events:

- [Contact events](contact-events.md "contact-events.md") - contact (voice calls, chat,
  and task) events.
- [Contact Lens events](contact-lens-rules-eventbridge-event.md "contact-lens-rules-eventbridge-event.md") - create
  rules that generate EventBridge events.
- [Screen recording events](track-screen-recording-status.md "track-screen-recording-status.md") - events for tracking agent screen recording status.
- [Voice ID events](voiceid-event-schema.md "voiceid-event-schema.md") - events for every
  transaction: enrollment, authentication, or detection of fraudsters in a watchlist.
  Events are sent to the EventBridge default event bus.
