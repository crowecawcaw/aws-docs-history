

# Show Profile Explorer in the agent workspace
<a name="add-profileexplorer-to-agentworkspace"></a>

By default, the Customer Profiles app in the agent workspace uses a fixed layout. You can replace it with a Profile Explorer layout, so agents see the customer data that are relevant to their work. For example, a travel company might show loyalty status and upcoming trips, while a telecommunications provider might show churn risk and service addresses.

You choose the layout for each workspace. Agents see the layout after you assign the workspace to them.

## Before you begin
<a name="begin-petoaw"></a>
+ Create and save the Profile Explorer layout you want agents to see. For more information, see [Create a layout](create-a-layout.md).
+ Give agents the **Profile explorer - View** permission in their security profile. For more information, see [Enable users to view Profile Explorer](enabling-profile-explorer.md#enable-users-view-profile-explorer).

## Choose a Profile Explorer layout for a workspace
<a name="add-pe-console"></a>

1. Open the Connect Customer admin workspace.

1. Go to **UI Management** > **Workspaces**, and choose the workspace.

1. In the **Pages** section, add or edit the **Agent Workspace** page. For more information, see [Create a workspace and set the layout](assign-agent-workspace-layout.md#assign-agent-workspace-layout-create).

1. In the **Customize apps on Agent Workspace** section, for **Customer Profiles**, choose **Enhanced view (Profile Explorer)**.

1. For **Profile Explorer layout**, choose the layout.

1. Choose **Save**.

To return to the fixed layout, follow the same steps and choose **Legacy view** in step 4.
