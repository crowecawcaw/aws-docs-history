# Outbound campaigns data in the

Amazon Connect analytics data lake

This topic details the content in the Amazon Connect analytics data lake outbound campaign
events table. The table lists the column, type, and description of the
content.

There are two ways to access the analytics data lake and configure data to be
shared:

- [Option 1: Use the Amazon Connect
  console](access-datalake.md#option1-configure-data-to-be-shared "access-datalake.md#option1-configure-data-to-be-shared")
- [Option 2: Use CLI or
  CloudShell](access-datalake.md#option2-configure-data-to-be-shared "access-datalake.md#option2-configure-data-to-be-shared")
  If you are unable to access the scheduling tables by using Option 1, try using
  Option 2.

## Outbound campaign events

Table name: outbound_campaign_events

Composite primary key: `campaign_event_id`,
`instanceId`

The data for campaign_initiation_type, campaign_execution_timestamp, and
campaign_event_type: TARGETED, DROPPED_ALREADY_IN_PROGRESS, DROPPED_REJECTED,
and DROPPED_EXPIRED will be available starting April 30, 2025.

| campaign_event_type                | String    | The specific outbound campaign event type. Campaign events: <br>• CAMPAIGN_EXPIRED: The send request is successfully attempted but expired due to insufficient resources. The system will automatically retry when sufficient resources are available. <br>• CAMPAIGN_FAILURE_PERMANENT: The send request encountered an unknown error, invalid parameter, or insufficient permissions. There are no systematic retries. <br>• CAMPAIGN_SUCCESS: The send request is successful and Amazon Connect will attempt to deliver the campaign to the recipient. <br>• DROPPED_CAMPAIGN_ENDED: The targeted user was dropped from the campaign because the campaign ended prior to a communication attempt. <br>• DROPPED_DELIVERY_ERROR: The targeted user was dropped because of a user configuration error. Examples include improper channel configurations or an incorrect message template. <br>• DROPPED_DELIVERY_FAILURE: The targeted user was dropped because we didn't receive delivery confirmation following three 60-minute waiting periods. <br>• DROPPED_INVALID_CONTACT_TYPE: The targeted user was dropped because the contact type specified in the engagement preference were incorrectly configured. <br>• DROPPED_INVALID_ENGAGEMENT_PREFERENCE: The targeted user was dropped because the engagement preferences were incorrectly configured. <br>• DROPPED_INVALID_TARGET: The targeted user was dropped because it was invalid or was deleted during execution <br>• DROPPED_LIMIT_BREACHED: The targeted user was dropped because the configured campaign communication limits were exceeded. <br>• DROPPED_MISSING_CHANNEL: The targeted user was dropped from the campaign because they were missing channel endpoint (such as email or phone number) <br>• DROPPED_MISSING_TIMEZONE: The targeted user was dropped from the campaign because a contact timezone could not be determined as configured in the campaign. This may also occur if Amazon Connect is unable to estimate a timezone. Email events: <br>• Delivery: The message is delivered. <br>• Send: Amazon Connect accepted the message and attempted to deliver it. <br>• Reject: Amazon Connect detected malware and rejected the message. <br>• Bounce: An issue related to the email or server prevented Amazon Connect from delivering the message. <br>• DeliveryDelay: A temporary error occurred that delayed the delivery of the message. Amazon Connect systematically reattempts message delivery. <br>• Open: The message is received and the recipient opened it. <br>• Click: The message is received and the recipient clicked a link in it. SMS events: <br>• TEXT_DELIVERED: The message is delivered to the specified location. <br>• TEXT_SUCCESSFUL: The message is successfully accepted by the recipient's carrier. <br>• TEXT_QUEUED: The message is queued and ready to be delivered to the recipient. <br>• TEXT_PENDING: The message hasn't yet been delivered. <br>• TEXT_BLOCKED: The recipient's device or carrier is blocking SMS messages. <br>• TEXT_TTL-EXPIRED: The SMS message couldn't be delivered within the specified time frame. <br>• TEXT_CARRIER_UNREACHABLE: An issue with the mobile network prevented the message from being delivered. This error is usually temporary. You can try to send the message again later. <br>• TEXT_INVALID: The destination phone number is not valid. <br>• TEXT_INVALID_MESSAGE: The body of the SMS message is invalid. For example: message doesn't meet the content or format requirements; and can't be delivered. <br>• TEXT_CARRIER_BLOCKED: The carrier has blocked delivery of this message. This often occurs when the carrier identifies the contents of the message as unsolicited or malicious. <br>• TEXT_UNREACHABLE: The recipient's device is currently unreachable or unavailable. For example, the device might be powered off, or might be disconnected from the network. You can try to send the message again later. <br>• TEXT_SPAM: The mobile carrier identified the contents of the message as spam and blocked delivery. <br>• TEXT_UNKNOWN: An error occurred that prevented the delivery of the message. This error is usually temporary. You can try to send the message again later. Telephony events: <br>• AMD_DISABLED: Answering machine detection is disabled. <br>• INITIATED: An outbound call was initiated or transferred. <br>• CONNECTED_TO_SYSTEM: The contact has established media (for example, it was answered by a person or by voicemail). This event is generated for any of the [AnsweringMachineDetectionStatus](contact-events.md#AnsweringMachineDetectionStatus "contact-events.md#AnsweringMachineDetectionStatus") codes. <br>• CONTACT_DATA_UPDATED: One or more of the following contact properties were updated on an outbound call: user-defined attributes and tags, routing criteria is updated or step is expired, or if Contact Lens is enabled for a given contact. <br>• QUEUED: An outbound call is queued to be assigned to an agent. <br>• CONNECTED_TO_AGENT: An outbound call is connected to an agent. |
