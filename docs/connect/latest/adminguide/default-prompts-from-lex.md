# Default prompts from Amazon Lex: Sorry

If you add an Amazon Lex classic bot (not Amazon Lex V2) to your contact center, know that it
also has some default prompts that it uses for error handling. For example:

- Sorry, can you please repeat that?
- Sorry, I could not understand. Goodbye.

###### To change default Amazon Lex prompts

1. In Amazon Lex, go to your bot.
2. On the Editor tab, choose Error Handling.
3. Change the text as needed. Choose **Save**, then
   **Build** and **Publish**.
