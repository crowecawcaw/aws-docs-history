# Determine the number of

contacts in a queue on a specific date

The historical metrics reports don't provide a way for you to determine how many
contacts were in queue on a specific date, at a specific time.

To get this information in a historical report, you need the help of a developer.
The developer uses the [GetCurrentMetricData](../APIReference/API_GetCurrentMetricData.md "../APIReference/API_GetCurrentMetricData.md") API to store the data so you can look it up
later.
