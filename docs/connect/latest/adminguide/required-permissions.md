

# Required permissions
<a name="required-permissions"></a>

Before you use Connect Customer testing and simulation capabilities, you must have access to all test case permissions. If you use an admin security profile, all testing and simulation permissions are granted by default. Admin can grant permissions to onboard other user profiles with the new testing and simulation security profile.
