# Troubleshoot issues in Connect Customer conversational analytics

## Why don't I see or hear unredacted content?

If your organization is using the conversational analytics redaction feature, by
default only redacted content appears in the Connect Customer admin website.

You must have permissions to view unredacted content. For more information,
see [Assign permissions to use conversational analytics in Connect Customer](permissions-for-contact-lens.md "permissions-for-contact-lens.md").
