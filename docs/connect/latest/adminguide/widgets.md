# Widgets

Explore the different widget types available in Profile explorer.

## Overview

Widgets in Profile explorer are composite elements built from JSON components
within your layout definition. While these widgets represent complex JSON
structures, our UI builder handles the technical composition automatically,
making dashboard management straightforward and accessible.
