

# Global Resiliency for chat
<a name="global-resiliency-for-chat"></a>

By adopting Connect Customer Global Resiliency for the chat channel, you can provide customers and agents a consistent chat experience across your linked AWS Regions.

Connect Customer Global Resiliency provides conversation context, metadata, and transcripts across the Regions, so customers get a consistent experience and agents keep a complete view of the conversation regardless of which active Region serves the contact.

With this feature set, you can:

1. Adopt global routing for chat, so you can evenly distribute agents across both Regions and keep both Regions active at all times.

1. Start new chat contacts in an alternate Region, and maintain business continuity for the chat channel.

1. Resume chat contacts across Regions, so customers continue earlier conversations with full context and agents deliver continued personalized service.
