# Manage contacts from the Contact details page in Connect Customer

On the **Contact details** page, you can transfer, reschedule, end, or
update the task template for an in-progress contact. You can also add or remove tags from an
in-progress or completed contact that you can access.

You can also perform these actions programmatically using the [TransferContact](../APIReference/API_TransferContact.md "../APIReference/API_TransferContact.md"),
[UpdateContactSchedule](../APIReference/API_UpdateContactSchedule.md "../APIReference/API_UpdateContactSchedule.md"), [StopContact](../APIReference/API_StopContact.md "../APIReference/API_StopContact.md"), [UpdateContactTaskTemplate](../APIReference/API_UpdateContactTaskTemplate.md "../APIReference/API_UpdateContactTaskTemplate.md"), [TagContact](../APIReference/API_TagContact.md "../APIReference/API_TagContact.md"), and [UntagContact](../APIReference/API_UntagContact.md "../APIReference/API_UntagContact.md")
operations.

This section explains how to manage contacts by using the Connect Customer admin website.
