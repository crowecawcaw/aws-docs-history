

# Save and publish views
<a name="no-code-ui-builder-saving-and-publishing"></a>

Views are versioned, so you can audit and reuse earlier versions of a view.

1. Enter a name for your view, if you haven't already done so. You can't save a view without a name.

1. After you change the view, choose **Save**.

1. When the view is ready to use in a flow, choose **Publish**. The view then appears in the [Show view](show-view-block.md) block. Only published versions appear in the block.
