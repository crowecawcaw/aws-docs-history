# Flow block definitions in the flow designer in

Amazon Connect

Use flow blocks to create flows in the flow designer. Drag flow blocks and drop them onto
a canvas to arrange a flow.

The following table lists all available flow blocks that you can use. Choose any block
name in the Block column for more information.

| Block                                                                                                                                               | Description                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Connect assistant](connect-assistant-block.md "connect-assistant-block.md")                                                                        | Associates an Connect AI agents domain to a contact to enable real-time<br>recommendations.                                                                                                                        |
| [Authenticate Customer](authenticate-customer.md "authenticate-customer.md")                                                                        | Enables the customer to authenticate by leveraging Amazon Cognito and<br>Amazon Connect Customer Profiles.                                                                                                         |
| [Call phone number](call-phone-number.md "call-phone-number.md")                                                                                    | Initiates an outbound call from an outbound whisper<br>flow.                                                                                                                                                       |
| [Cases](cases-block.md "cases-block.md")                                                                                                            | Gets, updates, and creates cases.                                                                                                                                                                                  |
| [Change routing priority /<br>age](change-routing-priority.md "change-routing-priority.md")                                                         | Changes the priority of the contact in queue. You may want to do this,<br>for example, based on the contact's issue or other variable.                                                                             |
| [Check call progress](check-call-progress.md "check-call-progress.md")                                                                              | Engages with the output provided by an answering machine, and provides<br>branches to route the contact accordingly. This block works with<br>outbound campaigns only.                                             |
| [Check contact<br>attributes](check-contact-attributes.md "check-contact-attributes.md")                                                            | Checks the values of contact attributes.                                                                                                                                                                           |
| [Check hours of<br>operation](check-hours-of-operation.md "check-hours-of-operation.md")                                                            | Checks whether the contact is occurring within or outside of the hours<br>of operation defined for the queue.                                                                                                      |
| [Check queue status](check-queue-status.md "check-queue-status.md")                                                                                 | Checks the status of the queue based on specified conditions.                                                                                                                                                      |
| [Check Voice ID](check-voice-id.md "check-voice-id.md")                                                                                             | Branches based on the enrollment status, voice authentication status,<br>or status of detection of fraudsters in a watchlist of the caller returned by<br>Voice ID.                                                |
| [Check staffing](check-staffing.md "check-staffing.md")                                                                                             | Checks the current working queue, or queue you specify in the block,<br>for whether agents are available, staffed, or online. Staffed<br>availability could be on call, or after contact work status.              |
| [Contact tags](contact-tags-block.md "contact-tags-block.md")                                                                                       | Create and apply user-defined tags (key:value pairs) to your<br>contacts.                                                                                                                                          |
| [Create<br>persistent contact association](create-persistent-contact-association-block.md "create-persistent-contact-association-block.md")         | Specify an attribute to create a persistent contact association,<br>enabling conversations to continue from where they left off.                                                                                   |
| [Create task](create-task-block.md "create-task-block.md")                                                                                          | Creates a new task, sets the tasks attributes, and initiates a contact<br>flow to start the task. To learn more about Amazon Connect Tasks, see [The task channel in Amazon Connect](tasks.md "tasks.md").         |
| [Customer profiles](customer-profiles-block.md "customer-profiles-block.md")                                                                        | Enables you to retrieve, create, and update a customer profile.                                                                                                                                                    |
| [Data Table](data-table-block.md "data-table-block.md")                                                                                             | Evaluate, list, or write data from data tables within your contact flows.                                                                                                                                          |
| [Disconnect / hang up](disconnect-hang-up.md "disconnect-hang-up.md")                                                                               | Disconnects a contact.                                                                                                                                                                                             |
| [Distribute by<br>percentage](distribute-by-percentage.md "distribute-by-percentage.md")                                                            | Routes customers randomly based on a percentage.                                                                                                                                                                   |
| [End flow / Resume](end-flow-resume.md "end-flow-resume.md")                                                                                        | Ends the current flow without disconnecting the contact.                                                                                                                                                           |
| [Get customer input](get-customer-input.md "get-customer-input.md")                                                                                 | Branches based on customer intent.                                                                                                                                                                                 |
| [Get queue metrics](get-queue-metrics.md "get-queue-metrics.md")                                                                                    | Retrieves real-time metrics about queues and agents in your contact<br>center and returns them as attributes.                                                                                                      |
| [Get stored content](get-stored-content.md "get-stored-content.md")                                                                                 | Retrieves content stored in S3 and returns them as attributes to be used within flows.                                                                                                                             |
| [Hold customer or agent](hold-customer-agent.md "hold-customer-agent.md")                                                                           | Places a customer or agent on or off hold.                                                                                                                                                                         |
| [AWS Lambda<br>function](invoke-lambda-function-block.md "invoke-lambda-function-block.md")                                                         | Calls AWS Lambda, optionally returns key-value pairs.                                                                                                                                                              |
| [Invoke module](invoke-module-block.md "invoke-module-block.md")                                                                                    | Calls a published module.                                                                                                                                                                                          |
| [Loop](loop.md "loop.md")                                                                                                                           | Loops through, or repeats, the \*_Looping_<br>• branch for<br>the number of loops specified or the number of elements in the provided<br>array.                                                                    |
| [Loop prompts](loop-prompts.md "loop-prompts.md")                                                                                                   | Loops a sequence of prompts while a customer or agent is on hold or in<br>queue.                                                                                                                                   |
| [Play prompt](play.md "play.md")                                                                                                                    | Plays an interruptible audio prompt, delivers a text-to-speech<br>message, or delivers a chat response.                                                                                                            |
| [Resume contact](resume-contact.md "resume-contact.md")                                                                                             | Resumes a contact from a paused state.                                                                                                                                                                             |
| [Return (from module)](return-module.md "return-module.md")                                                                                         | Exits the flow module after it has run successfully.                                                                                                                                                               |
| [Send message](send-message.md "send-message.md")                                                                                                   | Sends a message to your customer based on a template or custom message<br>you specify.                                                                                                                             |
| [Set callback number](set-callback-number.md "set-callback-number.md")                                                                              | Sets a callback number.                                                                                                                                                                                            |
| [Set contact<br>attributes](set-contact-attributes.md "set-contact-attributes.md")                                                                  | Stores key-value pairs as contact attributes.                                                                                                                                                                      |
| [Set customer queue<br>flow](set-customer-queue-flow.md "set-customer-queue-flow.md")                                                               | Specifies the flow to invoke when a customer is transferred to a<br>queue.                                                                                                                                         |
| [Set disconnect flow](set-disconnect-flow.md "set-disconnect-flow.md")                                                                              | Sets the flow to run after a disconnect event.                                                                                                                                                                     |
| [Set event flow](set-event-flow.md "set-event-flow.md")                                                                                             | Specifies which flow to run during a contact event.                                                                                                                                                                |
| [Set hold flow](set-hold-flow.md "set-hold-flow.md")                                                                                                | Links from one flow type to another.                                                                                                                                                                               |
| [Set logging behavior](set-logging-behavior.md "set-logging-behavior.md")                                                                           | Enables flow logs so you can track events as contacts interact with<br>flows.                                                                                                                                      |
| [Set recording and analytics<br>behavior](set-recording-behavior.md "set-recording-behavior.md")                                                    | Sets options for recording conversations.                                                                                                                                                                          |
| [Set recording, analytics and processing behavior](set-recording-analytics-processing-behavior.md "set-recording-analytics-processing-behavior.md") | Sets options to configure recording behavior for agent and customer, enable automated interaction, enable screen recording, set analytics behavior for contacts, and set custom processing behavior.               |
| [Set routing criteria](set-routing-criteria.md "set-routing-criteria.md")                                                                           | Sets routing criteria on contacts of any channel, such as Voice, Chat,<br>and Task, to define how the contact should be routed within its queue. A<br>routing criteria is a sequence of one or more routing steps. |
| [Set Voice ID](set-voice-id.md "set-voice-id.md")                                                                                                   | When the call is connected to a flow, sends audio to Amazon Connect Voice ID to<br>verify the caller's identity and match against fraudsters on a watch<br>list.                                                   |
| [Set voice](set-voice.md "set-voice.md")                                                                                                            | Sets the text-to-speech (TTS) language and voice to be used in the<br>flow.                                                                                                                                        |
| [Set whisper flow](set-whisper-flow.md "set-whisper-flow.md")                                                                                       | Overrides the default whisper by linking to a whisper flow.                                                                                                                                                        |
| [Set working queue](set-working-queue.md "set-working-queue.md")                                                                                    | Specifies the queue to be used when \*_Transfer to<br>queue_<br>• is invoked.                                                                                                                                      |
| [Show view](show-view-block.md "show-view-block.md")                                                                                                | Configures UI based workflows that you can surface to users in<br>front end applications.                                                                                                                          |
| [Start media streaming](start-media-streaming.md "start-media-streaming.md")                                                                        | Starts capturing customer audio for a contact.                                                                                                                                                                     |
| [Stop media streaming](stop-media-streaming.md "stop-media-streaming.md")                                                                           | Stops capturing customer audio after it is started with a<br>\*_Start media streaming_<br>• block.                                                                                                                 |
| [Store customer input](store-customer-input.md "store-customer-input.md")                                                                           | Stores numerical input to a contact attribute.                                                                                                                                                                     |
| [Transfer to agent<br>(beta)](transfer-to-agent-block.md "transfer-to-agent-block.md")                                                              | Transfers the customer to an agent.                                                                                                                                                                                |
| [Transfer to flow](transfer-to-flow.md "transfer-to-flow.md")                                                                                       | Transfers the customer to another flow.                                                                                                                                                                            |
| [Transfer to phone<br>number](transfer-to-phone-number.md "transfer-to-phone-number.md")                                                            | Transfers the customer to a phone number external to your<br>instance.                                                                                                                                             |
| [Transfer to queue](transfer-to-queue.md "transfer-to-queue.md")                                                                                    | In most flows, this block ends the current flow and places the<br>customer in queue. When used in a customer queue flow, this block<br>transfers a contact already in a queue to another queue.                    |
| [Wait](wait.md "wait.md")                                                                                                                           | Pauses the flow.                                                                                                                                                                                                   |
