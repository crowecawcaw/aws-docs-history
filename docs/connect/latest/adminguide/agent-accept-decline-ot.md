# Contact center agent ability to accept or

decline overtime in Amazon Connect

The following image shows pending Overtime requests in the agent calendars.
Managers and agents can see overtime requests.

![The published schedule calendar tab, pending overtime requests.](images/accept-decline-view-wfm.png)
Agents can accept or decline overtime in the Agent application schedule calendar.

## Required security profile

permissions

To accept or decline the request, an agent must have **Agent
application schedule calendar - Edit** permissions in their
security profile. This permission is shown in the following image of
Agent Applications permissions on the security profiles
page.

![A diagram showing permissions in the agent application schedule calendar.](images/security-profile-perms-accept-decline-wfm.png)
