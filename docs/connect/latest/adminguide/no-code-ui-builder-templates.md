

# Use templates in the UI builder
<a name="no-code-ui-builder-templates"></a>

The UI builder includes templates that fill the canvas with components.

**Important**  
A template replaces any components already on the canvas. The change takes effect when you save. If you apply a template by mistake, leave the page without saving and come back to return to the last saved version.

To use a template:

1. In the UI builder, open the **Create** panel.

1. Choose the **Templates** tab.

1. Drag the template you want onto the canvas.

After the template appears on the canvas, you can:
+ Add more components
+ Delete components
+ Configure the view the same way as a view you build from scratch
