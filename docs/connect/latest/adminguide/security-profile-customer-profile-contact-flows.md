# Update Customer Profiles

permissions for flows

1. Go to the Security profiles page, choose the security profile you would
   like to edit, or choose **Add new security
   profile**.

![Security profiles page.](images/security-profile-customer-profile-contact-flows-1.png) 2. Select the **View** permission for Customer Profiles.

![Select view permissions in the security profiles page.](images/security-profile-customer-profile-contact-flows-2.png) 3. Choose **Save**. You can now navigate to the
**User management** section and provide this security
profile to the users of your choice.
