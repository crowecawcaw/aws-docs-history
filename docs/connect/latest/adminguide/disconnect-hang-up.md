# Flow block in Amazon Connect: Disconnect / hang up

This topic defines the flow block for disconnecting a contact at the end of a
call.

## Description

- Disconnects the contact.

## Supported channels

The following table lists how this block routes a contact that is using the
specified channel.

| Channel | Supported? |
| ------- | ---------- |
| Voice   | Yes        |
| Chat    | Yes        |
| Task    | Yes        |
| Email   | Yes        |

## Flow types

You can use this block in the following [flow
types](create-contact-flow.md#contact-flow-types "create-contact-flow.md#contact-flow-types"):

- Inbound flow
- Customer queue flow
- Transfer to Agent flow
- Transfer to Queue flow
