

# How agents enter shift preferences
<a name="scheduling-shift-bid-agents"></a>

When a bid is open, agents rank the shifts they prefer from their calendar in the agent workspace. Agents can rank shifts at any time while the bid is open, before the bidding deadline. For more information about the agent calendar, see [How agents view their schedule in the Connect Customer agent workspace](scheduling-view-schedule-agents.md).

1. While a bid is open, the agent calendar displays a **Shift bidding open** banner that shows the schedule period and the date and time when bidding ends. To start ranking, the agent chooses **Rank your shifts**.  
![The agent calendar with the Shift bidding open banner and the Rank your shifts button.](https://docs.aws.amazon.com/connect/latest/adminguide/images/wfm-shift-bid-agent-calendar-banner.png)

   Alternatively, the agent can open the **Requests** panel, choose the **Shift bids** tab, and then choose **Rank your shifts** for the bid under **Active bids**. This tab also shows the bidding window and schedule period for each active bid, and any past bids.  
![The Requests panel with the Shift bids tab selected, showing an active bid with its bidding window, schedule period, and the Rank your shifts button.](https://docs.aws.amazon.com/connect/latest/adminguide/images/wfm-shift-bid-agent-requests.png)

1. On the bid page, the agent reviews the available shifts. Each row is a shift with its weekly schedule (the start and end times for each day) and the total **Hours**. To narrow the list, the agent can use the filter box to filter shifts by the following properties: **Days off**, **Days working**, **Earliest start time**, **Latest start time**, and **Hours working**.

1. To rank a shift, the agent enters a rank in the rank field, or uses the up and down arrows to change its position. Rank 1 is the most preferred shift. Agents rank all the shift patterns in the list.  
![The bid page showing the ranked list of shifts and the Save ranking button.](https://docs.aws.amazon.com/connect/latest/adminguide/images/wfm-shift-bid-agent-rank-shifts.png)

1. To submit the rankings, the agent chooses **Save ranking**. The agent can update the ranking at any time while the bid is open.

**Note**  
If an agent is unavailable to rank their shift patterns, someone can submit preferences on their behalf in either of the following ways:  
A supervisor can submit preferences from the published calendar view.
A scheduler can submit preferences from the bid management page.
