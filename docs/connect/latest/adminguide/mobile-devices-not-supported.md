# Agent workspace and CCP do not support

mobile phones (iPhone, Android) and iPads

The Amazon Connect admin website, Contact Control Panel (CCP), and agent workspace do not support mobile
browsers / mobile devices such as iPhones and iPads.

You can set up your CCP to forward the audio portion of the call to your mobile
device. For instructions, see [Forward calls in the Amazon Connect CCP to a
mobile device (iPhone, Android)](forward-calls-to-mobile-device.md "forward-calls-to-mobile-device.md").
