# Add a pre-contact or pre-chat form

You can capture customer
information before starting a contact:

- **Pre-contact form**: Add to capture information from the customer before
  starting a task or email contact.
- **Pre-chat form**: Add to capture information
  from the customer before starting a chat contact.
  After you capture the information, you can display it
  to the agent through the Contact Control Panel (CCP), or use it elsewhere in the
  flow.

To create the form, you create a custom view and use the connect action
button component. For more information on views, see [Use the UI builder in Amazon Connect for resources
in step-by-step guides](no-code-ui-builder.md "no-code-ui-builder.md").

The connect action button allows you to take in user input from the form and select
what action to take when the form is submitted - start a task/email or chat.
