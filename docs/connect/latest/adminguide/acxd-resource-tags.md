# Resource tags

Resource tags help you organize, search, and identify resources in an agentic CX
designer workspace.

A resource tag is a custom keyword or label that can be applied to workspace
resources. Tags are useful when you want to group resources by purpose, team,
environment, audience, status, or any other category that helps builders quickly
find and understand them.

Resource tags are especially helpful in larger workspaces where many applications,
flows, knowledge bases, guardrails, Data requests, or other resources may exist.

To access Resource tags, select your username from your workspace menu,
choose **Settings**, then select **Resource tags**.

## Reviewing resource tags

The Resource tags page helps you review which tags exist and where they are being used.

For each tag, you can:

- View the tag name
- Review its color, if one has been assigned
- Expand the tag to see which resources use it
- Identify where tags may need to be updated or removed

Resource tags only appear in this list when they are currently assigned to at least
one resource in the workspace.

## Color coding tags

You can assign colors to resource tags to make them easier to visually identify.

###### To color code a tag

1. Open **Settings**.
2. Select **Resource tags**.
3. Expand the tag you want to update.
4. Select the color indicator.
5. Choose a color.
6. Save your changes.

Use colors to help distinguish tags by category, such as environment, team, status, or priority.

## Viewing tag usage

###### To see where a tag is used

1. Open **Settings**.
2. Select **Resource tags**.
3. Expand the tag.

The expanded view lists resources where that tag is applied.

Use this when you want to understand which resources belong to a category, find
resources tied to a project, or confirm whether a tag is still in use.

You can also use global workspace Search to find resources associated with a tag.

Search by the tag keyword to locate matching resources more quickly.

This is useful when you need to find resources by business unit, environment,
status, or feature area.

If a tag is removed from all resources, it no longer appears in the Resource tags list.

This helps keep the Resource tags page focused on tags that are actively used in
the workspace.

Before removing a tag from multiple resources, confirm that it is no longer needed
for search, organization, review, or governance workflows.

## Best practices

- Use clear tag names that are easy for teammates to understand.
- Keep tag naming consistent across the workspace.
- Use tags to distinguish resources by environment, team, project, audience, or status.
- Avoid creating multiple tags with similar meanings.
- Use colors to make important categories easier to identify (e.g., "Prod" in red).
- Use global Search to quickly find resources by tag.
