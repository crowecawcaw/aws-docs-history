

# Set up outbound calling in Connect Customer
<a name="outbound-communications"></a>

You can send outbound calls to customers for a variety of reasons, such as appointment reminders, subscription renewals, and debt collection. Connect Customer provides both normal and outbound campaign capabilities. For more information about campaigns, see [Set up Connect Customer outbound campaigns](enable-outbound-campaigns.md) in this guide.
