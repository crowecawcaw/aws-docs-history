# Sample Screenpop flow in Connect Customer

###### Note

This topic explains a sample flow that is included with Connect Customer. For information
about locating the sample flows in your instance, see [Sample flows in Connect Customer](contact-flow-samples.md "contact-flow-samples.md").

Type: Flow (inbound)

This flow shows you how to use Screenpop, a Contact Control Panel feature, to load a
web page with parameters based on attributes.

In this sample flow, a **Set contact attributes** block is used to
create an attribute from a text string. As an attribute, the text can be passed to the
CCP to display a note to an agent.
