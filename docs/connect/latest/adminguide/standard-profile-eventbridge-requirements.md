

# Amazon EventBridge access requirements in Customer Profiles
<a name="standard-profile-eventbridge-requirements"></a>

Use the following Amazon EventBridge access requirements to create and delete Segment and Shopify integrations with Connect Customer Customer Profiles:
+ `events:ListTargetsByRule`
+ `events:PutRule`
+ `events:PutTargets`
+ `events:DeleteRule`
+ `events:RemoveTargets`
