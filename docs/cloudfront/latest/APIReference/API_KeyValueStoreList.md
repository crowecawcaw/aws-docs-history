# KeyValueStoreList

The key value store list.


## Contents





**MaxItems** 


The maximum number of items in the key value store list.


Type: Integer


Required: Yes




**Quantity** 


The quantity of the key value store list.


Type: Integer


Required: Yes




**Items** 


The items of the key value store list.


Type: Array of [KeyValueStore](API_KeyValueStore.md "API_KeyValueStore.md") objects


Required: No




**NextMarker** 


The next marker associated with the key value store list.


Type: String


Required: No
