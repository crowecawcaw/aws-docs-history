# ResponseHeadersPolicyRemoveHeadersConfig

A list of HTTP header names that CloudFront removes from HTTP responses to requests that match the
 cache behavior that this response headers policy is attached to.


## Contents





**Quantity** 


The number of HTTP header names in the list.


Type: Integer


Required: Yes




**Items** 


The list of HTTP header names.


Type: Array of [ResponseHeadersPolicyRemoveHeader](API_ResponseHeadersPolicyRemoveHeader.md "API_ResponseHeadersPolicyRemoveHeader.md") objects


Required: No
