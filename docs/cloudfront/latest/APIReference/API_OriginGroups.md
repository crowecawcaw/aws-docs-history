# OriginGroups

A complex data type for the origin groups specified for a distribution.


## Contents





**Quantity** 


The number of origin groups.


Type: Integer


Required: Yes




**Items** 


The items (origin groups) in a distribution.


Type: Array of [OriginGroup](API_OriginGroup.md "API_OriginGroup.md") objects


Required: No
