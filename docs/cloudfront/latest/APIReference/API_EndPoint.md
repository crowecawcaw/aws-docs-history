# EndPoint

Contains information about the Amazon Kinesis data stream where you're sending real-time log data in a real-time log configuration.


## Contents





**StreamType** 


The type of data stream where you are sending real-time log data. The only valid value
 is `Kinesis`.


Type: String


Required: Yes




**KinesisStreamConfig** 


Contains information about the Amazon Kinesis data stream where you are sending real-time
 log data in a real-time log configuration.


Type: [KinesisStreamConfig](API_KinesisStreamConfig.md "API_KinesisStreamConfig.md") object


Required: No
