# KeyGroup

A key group.

A key group contains a list of public keys that you can use with [CloudFront signed URLs and signed cookies](../../../AmazonCloudFront/latest/DeveloperGuide/PrivateContent.md "../../../AmazonCloudFront/latest/DeveloperGuide/PrivateContent.md").


## Contents





**Id** 


The identifier for the key group.


Type: String


Required: Yes




**KeyGroupConfig** 


The key group configuration.


Type: [KeyGroupConfig](API_KeyGroupConfig.md "API_KeyGroupConfig.md") object


Required: Yes




**LastModifiedTime** 


The date and time when the key group was last modified.


Type: Timestamp


Required: Yes
