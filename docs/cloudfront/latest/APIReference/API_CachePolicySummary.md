# CachePolicySummary

Contains a cache policy.


## Contents





**CachePolicy** 


The cache policy.


Type: [CachePolicy](API_CachePolicy.md "API_CachePolicy.md") object


Required: Yes




**Type** 


The type of cache policy, either `managed` (created by AWS) or
 `custom` (created in this AWS account).


Type: String


Valid Values: `managed | custom`



Required: Yes
