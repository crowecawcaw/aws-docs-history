# ResponseHeadersPolicySummary

Contains a response headers policy.


## Contents





**ResponseHeadersPolicy** 


The response headers policy.


Type: [ResponseHeadersPolicy](API_ResponseHeadersPolicy.md "API_ResponseHeadersPolicy.md") object


Required: Yes




**Type** 


The type of response headers policy, either `managed` (created by AWS) or
 `custom` (created in this AWS account).


Type: String


Valid Values: `managed | custom`



Required: Yes
