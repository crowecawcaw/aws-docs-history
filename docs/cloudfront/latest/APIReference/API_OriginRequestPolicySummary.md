# OriginRequestPolicySummary

Contains an origin request policy.


## Contents





**OriginRequestPolicy** 


The origin request policy.


Type: [OriginRequestPolicy](API_OriginRequestPolicy.md "API_OriginRequestPolicy.md") object


Required: Yes




**Type** 


The type of origin request policy, either `managed` (created by AWS) or
 `custom` (created in this AWS account).


Type: String


Valid Values: `managed | custom`



Required: Yes
