# Tagging keys

In AWS Payment Cryptography, you can add tags to a AWS Payment Cryptography key when you [create a key](create-keys.md "create-keys.md"), and tag or untag existing keys unless they are
pending deletion. Tags are optional, but they can be very useful.

For general information about
tags, including best practices, tagging strategies, and the format and syntax of tags, see
[Tagging AWS resources](../../../tag-editor/latest/userguide/tagging.md "../../../tag-editor/latest/userguide/tagging.md") in the
_Amazon Web Services General Reference_.
