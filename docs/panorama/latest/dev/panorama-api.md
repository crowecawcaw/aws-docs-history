# The AWS Panorama API

You can use the AWS Panorama service's public API to automate device and application management workflows. With the
AWS Command Line Interface or the AWS SDK, you can develop scripts or applications that manage resources and deployments. This
guide's GitHub repository includes scripts that you can use as a starting point for your own code.
