# How AWS Panorama works with IAM

Before you use IAM to manage access to AWS Panorama, you should understand what IAM features are available to use
with AWS Panorama. To get a high-level view of how AWS Panorama and other AWS services work with IAM, see [AWS services that work with IAM](../../../IAM/latest/UserGuide/reference_aws-services-that-work-with-iam.md "../../../IAM/latest/UserGuide/reference_aws-services-that-work-with-iam.md")
in the _IAM User Guide_.

For an overview of permissions, policies, and roles as they are used by AWS Panorama, see [AWS Panorama permissions](panorama-permissions.md "panorama-permissions.md").
