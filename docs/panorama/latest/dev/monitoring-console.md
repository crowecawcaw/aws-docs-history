# Monitoring in the AWS Panorama console

You can use the AWS Panorama console to monitor your AWS Panorama Appliance and cameras. The console uses AWS IoT to monitor
the state of the appliance.

###### To monitor your appliance in the AWS Panorama console

1. Open the [AWS Panorama console](https://console.aws.amazon.com/panorama/home "https://console.aws.amazon.com/panorama/home").
2. Open the AWS Panorama console [Devices page](https://console.aws.amazon.com/panorama/home#devices "https://console.aws.amazon.com/panorama/home#devices").
3. Choose an appliance.
4. To see the status of an application instance, choose it from the list.
5. To see the status of the appliance's network interfaces, choose **Settings**.
   The overall status of the appliance appears at the top of the page. If the status is
   **Online**, then the appliance is connected to AWS and sending regular status updates.
