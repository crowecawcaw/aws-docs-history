# Viewing Your Pipelines

You can view your pipelines using the command line interface
(CLI).

###### To view your pipelines using the AWS CLI

- Use the following [list-pipelines](../../../cli/latest/reference/datapipeline/list-pipelines.md "../../../cli/latest/reference/datapipeline/list-pipelines.md") command to list your pipelines:

```
`aws datapipeline list-pipelines`
```
