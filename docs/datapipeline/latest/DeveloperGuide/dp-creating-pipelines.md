# Creating a pipeline

AWS Data Pipeline provides several ways for you to create pipelines:

- Use the AWS Command Line Interface (CLI) with a template provided for your convenience. For more information, see [Create a pipeline from Data Pipeline templates using the CLI](dp-cli-templates.md "dp-cli-templates.md").
- Use the AWS Command Line Interface (CLI) with a pipeline definition file in JSON
  format.
- Use an AWS SDK with a language-specific API. For more information, see
  [Working with the API](dp-program-pipeline.md "dp-program-pipeline.md").
