# Date and Time

Functions

The following functions are available for working with DateTime values. For the
examples, the value of `myDateTime` is `May 24, 2011 @ 5:10 pm
 GMT`.

###### Note

The date/time format for AWS Data Pipeline is Joda Time, which is a replacement for the
Java date and time classes. For more information, see [Joda Time - Class DateTimeFormat](http://joda-time.sourceforge.net/apidocs/org/joda/time/format/DateTimeFormat.html "http://joda-time.sourceforge.net/apidocs/org/joda/time/format/DateTimeFormat.html").
