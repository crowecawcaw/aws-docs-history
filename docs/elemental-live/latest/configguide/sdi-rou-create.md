

# Step B: Create the router
<a name="sdi-rou-create"></a>

Create the router on the Elemental Live node.

**To create the router**

1. On the Elemental Live web interface, hover over **Settings**, and choose **Routers**. 

1. On the **Routers** screen, choose **New Router** and select the type of router protocol. These are the available options:
   + Videohub Ethernet Protocol (previously BlackMagic VideoHub)
   + XY Terminal Protocol (previously Harris Panacea)
   + NV9000 Protocol (previously Miranda nVision)
   + SW-P-08 Protocol (previously Snell Aurora)
   + Pass-Through Protocol
   + LRC Protocol

1. Complete the **Add New Router ** fields as described in the table and choose **Create**.



<table>
<thead>
  <tr><th>Field</th><th>Description</th></tr>
</thead>
<tbody>
  <tr><td><b>Name</b></td><td>The name that appears in the <b>Inputs</b> field on events and profiles.</td></tr>
  <tr><td><b>IP Address</b></td><td>The IP address of the router, excluding the protocol.</td></tr>
  <tr><td><b>Max Inputs</b></td><td>Typically, the number of physical inputs on the router.</td></tr>
  <tr><td><b>Max Outputs</b></td><td>Typically, the number physical outputs on the router.</td></tr>
  <tr><td><b>Level</b></td><td>Available for XY Terminal, NV9000, SW-P-08, and Pass-Through.</td></tr>
  <tr><td><b>User</b></td><td>Available for NV9000.</td></tr>
  <tr><td><b>Matrix ID</b></td><td>Available for SW-P-08</td></tr>
</tbody>
</table>
