# Verify the licenses for the cluster

Make sure that you have the appropriate AWS Elemental Live licenses installed.

###### To view installed licenses

1. On the Elemental Live web interface, go to the **Settings** page and
   choose **Licenses**.
2. Verify that information for a standalone license (`eme.lic`) is
   displayed.
3. If you see a **`No license file detected`** message, follow the steps on the screen to upload a license. For additional assistance, see the [Elemental Live Installation Guide](../installguide.md "../installguide.md").
