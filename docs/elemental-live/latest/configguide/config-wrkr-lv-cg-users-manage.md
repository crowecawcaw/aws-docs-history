

# Manage global access features
<a name="config-wrkr-lv-cg-users-manage"></a>

You can set some access features that apply globally to all users on the AWS Elemental Live node.

**To manage access**

1. Log in to the Elemental Live web interface using administrator credentials.

1. Go to the **Settings** page and choose **Authentication**. 

1. Review the current values for the fields. Make any changes and choose **Save**.
