

# Version 2.28.0 and 3.28.0
<a name="rn-2-28-0"></a>

This release includes AWS Elemental Live and AWS Elemental Statmux version 2.28.0, and AWS Elemental Conductor Live version 3.28.0.

Security updates  
This release includes updates that address potential security issues.
