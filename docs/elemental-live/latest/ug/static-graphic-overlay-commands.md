# Static graphic

overlay commands

| Nickname                             | Action | Signature                                                                                                                                                                                                                                                                                                                                                                    | Description                                                                                                     |
| ------------------------------------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Create Event                         | `POST` | `<Live IP<br>address>/live_events`                                                                                                                                                                                                                                                                                                                                           | Create an event that includes static<br>overlay information.                                                    |
| Modify Event                         | `PUT`  | `<Live IP<br>address>/live_events/live_event/<event ID>`                                                                                                                                                                                                                                                                                                                     | Modify an event (that is not running) and<br>add, modify or delete static overlay information.                  |
| Modify Static Overlay, Running Event | `POST` | `/live_event/<event<br>ID>/image_inserter`                                                                                                                                                                                                                                                                                                                                   | All outputs: add, modify or delete static<br>information in a running event.                                    |
| Modify Static Overlay, Running Event | `POST` | `<Live IP Address>/live_events/<event ID>/<br>image_inserter/output/<output id>`<br>Where `<output id>` is the unique ID automatically assigned<br>to this output when the event is created.                                                                                                                                                                                 | Specific output: add, modify or delete<br>static information in a running event.                                |
| Modify Static Overlay, Running Event | `POST` | `<Live IP Address>/live_events/<event ID>/<br>image_inserter/output/by_stream/<stream id>`<br>Where `<stream id>` is the unique ID automatically assigned<br>to this stream when the event is created. The ID can change while the event<br>is running (for example, if another stream is deleted), so you may need to<br>obtain the current ID before sending this command. | All outputs associated with a specific<br>stream: add, modify or delete static information in a running event.  |
| Modify Static Overlay, Running Event | `POST` | `<Live IP Address>/live_events/<event ID>/<br>image_inserter/input/<input id>`<br>Where `<input id>` is the unique ID automatically assigned<br>to this input when the event is created or when the input is added to the<br>event.                                                                                                                                          | Specific input, all outputs associated<br>with it: add, modify or delete static information in a running event. |
| Modify Static Overlay, Running Event | `POST` | `<Live IP Address>/live_events/<event ID>/<br>image_inserter/input/by_label/<input label>`<br>Where `<input label>` is the input label you assigned when<br>you created this event or created this input. Input labels are always<br>optional.                                                                                                                               | Specific input, all outputs associated<br>with it: add, modify or delete static information in a running event. |
