# Features that affect

performance

## Motion graphic

overlays

Motion graphic overlays in the video output can add up to 50% density,
compared to an output without overlays.

For more information, see [Insert a motion graphic overlay
in Elemental Live](motion-graphic-overlay.md "motion-graphic-overlay.md").

## Color space

conversions

Color space conversions add compute complexity and require more CPU
usage.

For more information, see [Working with color space](hdr-working-with.md "hdr-working-with.md").

## Noise reducer

filters

Noise reducer filters add up to 10% density when compared to an output without noise
reduction.

For more information, see [Noise reduction](vq-noise-reduction.md "vq-noise-reduction.md").
