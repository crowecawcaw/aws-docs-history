# Static graphic overlay

You can insert a static overlay into the event so that it appears on
the video in one or more of the video outputs. You can configure the
static overlay with a start time and duration. You can insert the static
overlay at any position on the video frame, as specified by x/y
coordinates. You can configure with an opacity and with fade-in and/or
fade- out.

You can insert any number of static overlays in the event.
