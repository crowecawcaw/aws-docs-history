# List of commands

| Nickname                        | Action | Signature                                                 | Description                                                                                                                                                                                                                                                     |
| ------------------------------- | ------ | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Add dynamic playlist inputs     | POST   | /live_events/<event<br>ID>/inputs                         | In the specified event (which must be<br>currently running), add the specified input<br>or inputs to the end of the dynamic<br>playlist.                                                                                                                        |
| Replace dynamic playlist        | POST   | /live_events/<event<br>ID>/playlist                       | In the specified event (which must be<br>currently running), remove all non-Active<br>inputs from the dynamic playlist and append<br>the specified input or inputs. After this<br>command, only the Active input remains from<br>the original dynamic playlist. |
| Get event                       | GET    | /live_events/<event ID>                                   | Gets the contents of the event, including<br>the list of inputs.                                                                                                                                                                                                |
| Modify dynamic playlist input   | PUT    | /live_events/<event ID>/inputs/<br><input ID>             | In the specified event (which must be<br>currently running), modify the specified<br>dynamic playlist input (which must be<br>non-Active).                                                                                                                      |
|                                 | PUT    | /live_events/<event ID>/inputs/<br>by_label/<input_label> | In the specified event (which must be<br>currently running), modify the specified<br>input (which must be non-Active).                                                                                                                                          |
| Delete dynamic playlist input   | DELETE | /live_events/<event ID>/inputs/<br><input ID>             | In the specified event (which must be<br>currently running), delete the specified<br>non-Active input from the dynamic playlist.                                                                                                                                |
|                                 | DELETE | /live_events/<event ID>/inputs/<br>by_label/<input_label> | In the specified event (which must be<br>currently running), delete the specified<br>non-Active input from the dynamic playlist.                                                                                                                                |
| Activate dynamic playlist input | POST   | /live_events/<event ID>/<br>activate_input                | In the specified event (which must be<br>currently running), activate the specified<br>dynamic playlist input either at the<br>specified time or immediately.                                                                                                   |
| Prepare dynamic playlist input  | POST   | /live_events/<event ID>/<br>prepare_input                 | In the specified event (which must be<br>currently running), prepare the specified<br>dynamic playlist input and optionally<br>activate encoding at the specified time or<br>immediately.                                                                       |
| Get status                      | GET    | /live_events/<event ID>status                             | Gets the status of the specified event, including information<br>about the stage and state of each input.                                                                                                                                                       |
