# Step 2: Create captions

selectors

After you have created a list of captions selectors, you can create the captions
selectors in the event.

###### To create the captions selectors

1. In the event, in the **Input** section, choose
   **Advanced**.
2. Choose **Add Caption Selector**.
3. For **Source**, choose the format of the source captions.

To identify SMPTE-TT as the source captions, choose **TTML**. When
Elemental Live ingests the captions, it automatically detects that they are
SMPTE-TT. 4. For most formats, more fields appear. For details about a field, choose the Info
link next to the field. In addition, see extra information about [DVB-Sub or SCTE-27](dvb-sub-or-scte27.md "dvb-sub-or-scte27.md"), on [Embedded](embedded.md "embedded.md"), on [SCC](captions-input-scc.md "captions-input-scc.md"), on [SMI, SRT, STL, TTML](captions-input-other-sidecars.md "captions-input-other-sidecars.md"), on [teletext](teletext.md "teletext.md"), or on [Null](captions-input-null.md "captions-input-null.md"). 5. Create more captions selector, as required.
