# Requirements for

inputs

**Supported input types**

AWS Elemental Live can work with the color space in all [supported input types](ref-inputs-and-codecs.md "ref-inputs-and-codecs.md").

**Input requirements for producing Dolby Vision
outputs**

There are specific requirements for a source that you plan to convert
to Dolby Vision. These requirements are stipulated by Dolby Vision, and
relate to the minimal video quality required to produce Dolby Vision outputs
that meet the Dolby Vision standard::

- The video source must be HD or 4K resolution. In other words, the
  source must be 1080p or better.

- The video source must be in the HDR10 color space.
