# Assessing performance by

measuring

There are several features of the appliance that affect
performance:

- CPU usage
- RAM usage
- I/O bandwidth
- Memory bandwidth
  You should look at all these features when measuring performance and
  attempting to increase density. For example, it is possible that your
  workflows aren't stressing the CPU capabilities, but they are making maximum
  demands on the I/O bandwidth.
