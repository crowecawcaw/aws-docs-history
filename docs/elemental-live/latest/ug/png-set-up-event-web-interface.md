# Using the web interface

###### To configure the event using the web interface

1.  In the **Global Processors** section,
    go to the **Image Inserter** field and
    choose **On**. More fields appear.
2.  Complete the fields. You can configure some or all the
    information in the non-running event, but you must at least
    set the following fields:

        * **Insertion Mode**
        * **Enable REST Control**

    You must also configure the motion overlay behavior when
    the event first starts:

        * If you want the motion overlay to appear as soon
         as the event starts, specify all the fields. Make
         sure that you check **Active**, and
         make sure that you leave the **Action
         Time** empty.
        * If you don't want the motion overlay to appear as
         soon as the event starts, leave
         **Active** unchecked.

    You can configure the remaining fields after you've
    started the event, when you want to run the first motion
    overlay.

For detailed information about the fields, see [Fields for a PNG asset](png-set-up-event-fields.md "png-set-up-event-fields.md").
