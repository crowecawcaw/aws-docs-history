# Captions and input

switching setups

Your input might include a backup input that is only switched to if
the first input fails. (This feature is called Input Switching or Input
Switching with “Hot Hot” backup.) Or your input might include multiple
inputs, each with its own backup input – several “input pairs.” The same
rules apply as for multiple inputs: the captions in all the inputs must
be identical for captions to work smoothly in the output.
