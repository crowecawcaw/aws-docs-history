# Completing the

fields in the Captions Selector Group

- **Source**: Choose **Teletext**.
- **Page**: This field specifies the page of the desired language.
  Complete as follows:
  - If you are setting up teletext passthrough captions (you are creating only one
    captions selector for the input captions), leave blank: the value is
    ignored.
  - If you are converting teletext to another format (you are creating several
    captions selectors, one for each language), specify the page for the desired
    language. If you leave this field blank, you get a validation error when you save
    the event.
