# Procedure to

enable ad avail blanking

###### To enable ad avail blanking

1. In the Profile or Event screen, click Advanced Avail Controls (in the Input
   section towards the top of the screen):
2. Select
   or
   clear
   the two restriction fields:
   - **Cleared**
     (default): Observe the restriction and blank the content
     for the ad avail event.
   - **Selected**:
     Ignore the restriction and do _not_ blank the content for the ad avail
     event.

3. Go down to the Global Processors section and complete the following
   fields:
   - **Ad Avail Blanking**: Click to turn on.
     The **Blanking Image** field appears.
   - **Blanking Image**: Specify a
     `.bmp` or `.png` file to use for the blanking. If
     you leave this field blank, a plain black image is inserted.
