# Ingesting SMPTE 2110 content

You can create a SMPTE 2110 input in AWS Elemental Live in order to ingest a source that is
compliant with the SMPTE 2110 specification. You can optionally configure the input to use
SMPTE 2022-7, if the source offers it.

You can configure the SMPTE 2110 input by specifying an SDP file that contains information
about the SMPTE 2110 content. Or you can configure the input to use NMOS to provide that
information.

For more information about SMPTE 2110 video content, SMPTE 2022-7, NMOS, and SDP files, see
[Working with SMPTE 2110](SMPTE-ST-2110.md "SMPTE-ST-2110.md").
