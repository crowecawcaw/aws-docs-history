# Working with captions

You can set up Elemental Live to extract captions when it ingests the source and to include
those captions in the output in either the same or a different format. You can include several
captions in the output. For example, you can include captions for several languages. You can
take a source captions asset and convert it to one format in one output and to another format in
a different output.

You perform the setup for captions in your Elemental Live event. The information in this section assumes that you are familiar with the general steps for
creating an event.

By default, Elemental Live does not ingest any captions (not even captions that are embedded
in the video). You must explicitly identify the captions to ingest and the captions to
output.

The information in this section assumes that you are familiar with the
general steps for creating an event.
