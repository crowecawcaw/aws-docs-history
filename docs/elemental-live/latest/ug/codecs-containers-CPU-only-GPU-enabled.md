# Codec

support for CPU-only and GPU-enabled deployments

The codecs listed in the table below are supported with
equivalent video quality at equivalent operating points on both
CPU-only and GPU-enabled appliances.

| Output Codec         | Equivalent VQ, CPU-Only and GPU-Enabled Systems | Accelerated Encoding on GPU-Enabled Systems |
| -------------------- | ----------------------------------------------- | ------------------------------------------- |
| H.264 (AVC)          | Yes                                             | Yes                                         |
| HEVC (H.265)         | Yes                                             | Yes                                         |
| MPEG-2 (H.262)       | Yes                                             | Yes                                         |
| ProRes               | Yes                                             | No                                          |
| Uncompressed YUV     | Yes                                             | No                                          |
| JPEG (Frame Capture) | Yes                                             | No                                          |
