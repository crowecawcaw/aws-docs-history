# Interfaces for Elemental Live

Elemental Live can be controlled, configured, and monitored through the following interfaces.

| Interface                   | Description                                                                                                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Web browser via HTML        | Using a web browser is the easiest way to control, configure, and monitor Elemental Live. This interface is used when a human is<br>interacting with the server or when no automation or integration with other systems is required. |
| Web Services REST Interface | The REST-based interface supports all features of the web interface as well as automation features.                                                                                                                                  |
| SNMP Interface              | The SNMP interface allows basic monitoring and control of Elemental Live. It allows a management system to query the state of the<br>service and content it manages.                                                                 |
