# Multiple overlays and

layers

You can set up the event to insert more than one static overlay. Overlays are stored
in the event in a queue that has a maximum of 8 layers.

This means that you can display up to:

- 8 static overlays if you are using only the web interface to set up the event.
- As many static overlays as you want over the duration of the event if you are
  using the REST API. See [Step
  C: Manage overlays on a running event](step-c-manage-overlays-on-a-running-event.md "step-c-manage-overlays-on-a-running-event.md"). A maximum of 8 static overlays can be “queued” at one time (one in each
  layer).
