

# SCTE-35 message insertion into currently running events
<a name="scte-35-message-insertion"></a>

You can use the Elemental Live REST API to insert SCTE-35 messages into an Elemental Live event that is currently running. The API supports insertion of a SCTE-35 message of type **splice\_insert** or **time signal **([Working with time signals](working-with-time-signals.md)).
