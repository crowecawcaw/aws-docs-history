# Supported content

The following table describes the content that Elemental Live supports in SMPTE 2110 sources
(inputs) and SMPTE 2110 outputs.

- For inputs, Elemental Live supports ingest of one instance of each type of stream—one video
  stream, zero or one audio stream, and zero or one ancillary data stream.
- For outputs, Elemental Live supports one video stream, zero or more audio streams, and zero
  or one ancillary data stream.
  For detailed instructions for setting up a SMPTE 2110 input or output, see [Ingesting SMPTE 2110 content](input-2110.md "input-2110.md") and [Configuring SMPTE 2110 outputs](output-2110.md "output-2110.md").

###### Note

Elemental Live can't ingest more than one audio stream in one SMPTE 2110 input.
