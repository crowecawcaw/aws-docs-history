# Definition of

containers and codecs

| Codec or Container                                                   | Direction | Statement                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MXF input container for video                                        | Input     | Complete list of supported containers is: AS-02; OP-1a,<br>OP-1b, OP-1c, OP-2a, OP-2b, and OP-2c.                                                                                                                                                                                                                                                                                                       |
| Apple ProRes video codec                                             | Input     | Complete list of supported codecs is: Apple Prores 444<br>(all profiles), Apple Prores 4444 (all profiles), and Apple<br>Prores 422 (all profiles). Apple Prores 444 and 4444 are<br>converted to Apple Prores 422 during input<br>handling.                                                                                                                                                            |
| MPEG-2 video codec                                                   | Input     | Complete list of supported codecs is: MPEG-2, and ATSC<br>(A/53).                                                                                                                                                                                                                                                                                                                                       |
| AAC audio codec                                                      | Input     | Complete list of supported profiles is: LC-AAC, HE-AAC<br>v1, and HE-AAC v2.                                                                                                                                                                                                                                                                                                                            |
| Dolby Digital audio codec                                            | Input     | Dolby Digital is also known as AC-3.<br>Dolby Digital is a licensed codec; however, no<br>license is required to decode this codec in<br>input.<br>For more notes, see [Audio:<br>Transcode support and passthrough support for Dolby audio<br>codecs](codecs-containers-transcode-support.md "codecs-containers-transcode-support.md").                                                                |
| Dolby Digital Plus audio codec                                       | Input     | Dolby Digital Plus is also known as Enhanced AC-3 and<br>is frequently abbreviated as DD+ or EC-3 and E-AC-3.<br>Decoding of Dolby Digital Plus requires the Elemental<br>Audio Decode Package license option.<br>For more notes, see [Audio:<br>Transcode support and passthrough support for Dolby audio<br>codecs](codecs-containers-transcode-support.md "codecs-containers-transcode-support.md"). |
| Dolby E frames carried in PCM audio streams tagged with<br>SMPTE-337 | Input     | Decoding of Dolby E in PCM stream requires the<br>Elemental Audio Decode Package license option.                                                                                                                                                                                                                                                                                                        |
| Apple ProRes video codec in output                                   | Output    | Complete list of supported codecs is: Apple Prores 422<br>(all profiles).                                                                                                                                                                                                                                                                                                                               |
| Dolby Digital audio codec                                            | Output    | Encoding with Dolby Digital requires the Elemental<br>Advanced Audio Package license option.<br>For more notes, see [Audio:<br>Transcode support and passthrough support for Dolby audio<br>codecs](codecs-containers-transcode-support.md "codecs-containers-transcode-support.md").                                                                                                                   |
| Dolby Digital Plus audio codec                                       | Output    | Encoding with Dolby Digital Plus requires the<br>Elemental Advanced Audio Package license option.<br>For more notes, see [Audio:<br>Transcode support and passthrough support for Dolby audio<br>codecs](codecs-containers-transcode-support.md "codecs-containers-transcode-support.md").                                                                                                              |
| Dolby E pass-through                                                 | Output    | See [Audio:<br>Transcode support and passthrough support for Dolby audio<br>codecs](codecs-containers-transcode-support.md "codecs-containers-transcode-support.md").                                                                                                                                                                                                                                   |
| DTS Express                                                          | Output    | Encoding with DTS Express requires the Elemental<br>Advanced Audio Package license option.                                                                                                                                                                                                                                                                                                              |
| MPEG Audio codec                                                     | Output    | MPEG-1 Audio Layer II only                                                                                                                                                                                                                                                                                                                                                                              |
