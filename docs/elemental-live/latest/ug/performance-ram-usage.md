# RAM usage

RAM usage is the percentage of the memory being used on the appliance
memory cards.

You can measure free memory using the `top` or
`free` commands.

In Elemental Live versions 2.19.1 and later, the status bar at the top
of the Elemental Live web interface includes a memory usage
indicator.

Typically, RAM usage doesn't create performance problems on Elemental Live appliances.
However, you should still monitor RAM usage to make sure that you always have enough free
memory. If the appliance runs out of memory and starts to swap memory, there will be performance
and video quality issues.
