

# Supported source captions and output captions in a GPP output container
<a name="captions-gpp-output-container"></a>

To read this table, find the type of container and captions from your input. The supported captions formats for this *output *container are then shown in the last column. 

<a name="table-captions-gpp-output-container"></a>

- **HLS Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** SCTE-20 / **Supported output captions:** Burn-in

- **MP4 Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** SCTE-20 / **Supported output captions:** Burn-in

- **MXF Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** Ancillary Data / **Supported output captions:** Burn-in
  - **Source caption format:** Teletext / **Supported output captions:** Burn-in

- **QuickTime Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** Ancillary Data / **Supported output captions:** Burn-in

- **Raw Container**
  - **Source caption format:** SRT / **Supported output captions:** Burn-in
  - **Source caption format:** SMI / **Supported output captions:** Burn-in
  - **Source caption format:** TTML / **Supported output captions:** Burn-in
  - **Source caption format:** STL / **Supported output captions:** Burn-in
  - **Source caption format:** SCC / **Supported output captions:** Burn-in

- **RTMP Container**
  - **Source caption format:** Embedded
  - **Supported output captions:** Burn-in

- **SDI Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** Teletext / **Supported output captions:** Burn-in
  - **Source caption format:** ARIB / **Supported output captions:** None

- **MPEG2-TS Container**
  - **Source caption format:** Embedded / **Supported output captions:** Burn-in
  - **Source caption format:** SCTE-20 / **Supported output captions:** Burn-in
  - **Source caption format:** Teletext / **Supported output captions:** Burn-in
  - **Source caption format:** ARIB / **Supported output captions:** None
  - **Source caption format:** DVB-Sub / **Supported output captions:** Burn-in
  - **Source caption format:** SCTE-27 / **Supported output captions:** Burn-in
