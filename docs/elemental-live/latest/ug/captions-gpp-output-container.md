# Supported source captions

and output captions in a GPP output container

To read this table, find the type of container and captions from your
input. The supported captions formats for this _output_ container are then shown in the last column.

| Ancillary Data         | Burn-in               |

| STL                    | Burn-in               |                           | SCC      | Burn-in |
| RTMP Container         | Embedded              | Burn-in                   |
| SDI Container          | Embedded              | Burn-in                   |
| Teletext               | Burn-in               |                           | ARIB     | None    |
| MPEG2-TS Container     | Embedded              | Burn-in                   |
| SCTE-20                | Burn-in               |                           | Teletext | Burn-in |
