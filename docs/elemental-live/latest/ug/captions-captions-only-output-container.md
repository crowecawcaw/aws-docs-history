

# Supported source captions and output captions in a captions-only output container
<a name="captions-captions-only-output-container"></a>

This table describes the caption formats that can be included on their own in an output. With this option, *the container is always a raw container that contains only the captions* (video would be in another container that may be a raw container or may be some other type).

If you have one of the source caption formats listed in the first column – regardless of the source container – you can convert it to an external captions file and include it in a raw container that contains only that captions file.

<a name="table-captions-captions-only-output-container"></a>

- **Any container**
  - **Source caption format:** SRT / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** SMI / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** TTML / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** SMPTE-TT / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** STL / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** Embedded / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** SCC / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** SCTE-20 / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** SCTE-20\+Embedded / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** Embedded\+SCTE-20 / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** Ancillary Data / **Supported output captions:** SCC, SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** Teletext / **Supported output captions:** SMI, SMPTE-TT, SRT, TTML, EBU-TT-D, Web-VTT
  - **Source caption format:** DVBSub / **Supported output captions:** SMPTE-TT
  - **Source caption format:** SCTE-27 / **Supported output captions:** SMPTE-TT
