# Installing AWS Elemental Live on a

virtual machine (VM)

This section is for IT administrators who will perform the first-time
installation of AWS Elemental Live software on a virtual machine
(VM).

###### VM guest requirements

AWS Elemental software can run only on a VM generated by VMware
virtualization software. You must use VMware vCenter Server to
create the VM. The vSphere client by itself doesn't work.

For version and system requirements and other information about
VMware, see [System requirements for Virtual Machines (VMs)](vm-req.md "vm-req.md").

**Prerequisite knowledge**

To complete this process, you must have the following
knowledge:

- You have a basic understanding of server
  virtualization.
- You have installed and know how to use VMware Center and the
  VMware vSphere client interface, including Open Console.
- You know how to move files from a VM guest to other systems
  over the network. We recommend using a utility such as
  SCP.
- You know how to locate recently downloaded files.

###### Note

In this procedure, we show how to
install version 2.25.4 of the software. Modify your commands to specify the
version that you are installing.
