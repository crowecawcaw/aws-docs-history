# Changing site name

The following procedure details how to change the site name for your device.

###### To change the site name

1. Open the Amazon One Enterprise console at [https://console.aws.amazon.com/one-enterprise](https://console.aws.amazon.com/one-enterprise/ "https://console.aws.amazon.com/one-enterprise/").
2. In the navigation pane, choose **Site**.
3. Under **Sites**, select the site you intend
   to edit the name for.
4. Choose **Edit**.
5. Under **Site information** enter the desired site name and site description (optional).
6. Choose **Save changes** to update.
