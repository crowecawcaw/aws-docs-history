# Device Instance Management

A device instance is a logical representation of a device with configurations. Use of device instances allows for swapping Amazon One devices
while automatically inheriting the previously set configurations and names. A device instance has a user-defined name
(shared naming convention with your access control software) and a set of communication configurations.
