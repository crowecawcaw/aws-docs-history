# Rebooting an Amazon One device

The following procedure details how to reboot your Amazon One device.

###### To reboot an Amazon One device

1. Open the Amazon One Enterprise console at [https://console.aws.amazon.com/one-enterprise](https://console.aws.amazon.com/one-enterprise/ "https://console.aws.amazon.com/one-enterprise/").
2. In the navigation pane, choose **Device instance**.
3. Under **Activated instances**, choose the instance name of
   the device that you want to reboot.
4. Choose **Reboot** to restart the Amazon One device.
