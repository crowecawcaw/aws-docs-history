# Viewing enrolled users

The following procedure details how to enroll users.

###### To view enrolled users

1. Open the Amazon One Enterprise console at [https://console.aws.amazon.com/one-enterprise](https://console.aws.amazon.com/one-enterprise/ "https://console.aws.amazon.com/one-enterprise/").
2. In the navigation pane, choose **Enrolled user management**.
3. Under **Enrolled users**, you'll find all of the enrolled users
   and the following details:
   - **Badge ID** — Badge identifier
     information captured by an RFID badge reader at the time of
     enrollment.
   - **Enrollment source** — Details of the
     Amazon One device that was used for enrollment.
   - **Enrollment date** — Date and time of
     enrollment.
