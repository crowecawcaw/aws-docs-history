# Viewing device instance status

The following procedure details how to view the status of your device instance.

###### To view device instance status

1. Open the Amazon One Enterprise console at [https://console.aws.amazon.com/one-enterprise](https://console.aws.amazon.com/one-enterprise/ "https://console.aws.amazon.com/one-enterprise/").
2. In the navigation pane, choose **Device instance**.
3. Under **Activated instances**, you'll see a list of activated
   Amazon One devices.
4. Choose a device instance name to view device instance details.
