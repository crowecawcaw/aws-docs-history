# Quotas in AWS Elemental MediaStore

The Service Quotas console provides information about AWS Elemental MediaStore quotas. Along with
viewing the default quotas, you can use the Service Quotas console to [request quota increases](https://console.aws.amazon.com/servicequotas/home?region=us-east-1#!/services/mediastore/quotas "https://console.aws.amazon.com/servicequotas/home?region=us-east-1#!/services/mediastore/quotas") for adjustable quotas.

The following table describes quotas, formerly referred to as _limits_, in AWS Elemental MediaStore. Quotas are the maximum number of service
resources or operations for your AWS account.

###### Note

To assign quotas to individual containers within your account, contact AWS Support or
your account manager. This option can help you divide up the account-level limits among
your containers, to prevent one container from using up your entire quota.
