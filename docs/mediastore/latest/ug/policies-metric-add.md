# Adding a metric policy

A metric policy contains rules that dictate which metrics AWS Elemental MediaStore sends to Amazon CloudWatch. For examples of metric policies, see [Example metric policies](policies-metric-examples.md "policies-metric-examples.md").

###### To add a metric policy (console)

1. Open the MediaStore console at [https://console.aws.amazon.com/mediastore/](https://console.aws.amazon.com/mediastore/ "https://console.aws.amazon.com/mediastore/").
2. On the **Containers** page, choose the name of the container that you want to add a metric policy to.

The container details page appears. 3. In the **Metric policy** section, choose **Create metric policy**. 4. Insert the policy in JSON format, and then choose **Save**.
