# Troubleshooting access

logging in AWS Elemental MediaStore

When AWS Elemental MediaStore access logs do not appear in Amazon CloudWatch, refer to the
following table for potential causes and resolutions.

###### Note

Be sure to enable AWS CloudTrail Logs to assist with the troubleshooting
process.
