# Encrypting your terminology

Amazon Translate endeavors to protect all your data and your custom terminologies are no different. When
created, each custom terminology is encrypted so it accessible only by you.

Three encryption options are available:

- Using AWS encryption. AWS encryption is the default option to safeguard your
  information.
- Using an encryption key associated with your account. A menu in the console provides you with
  a choice of associated encryption keys to use.
- Using an encryption key not associated with your account. The console displays an input field
  for you to enter the Amazon Resource Name (ARN) of the encryption key.
