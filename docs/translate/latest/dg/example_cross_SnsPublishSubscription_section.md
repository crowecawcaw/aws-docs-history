# Build a publish and subscription application that translates messages

The following code examples show how to create an application that has subscription and publish functionality and translates messages.

.NET

**SDK for .NET**

Shows how to use the Amazon Simple Notification Service .NET API to
create a web application that has
subscription and publish functionality. In addition, this
example application also translates messages.

For complete source code and instructions on how to set up and run, see the full example on
[GitHub](https://github.com/awsdocs/aws-doc-sdk-examples/tree/main/dotnetv3/cross-service/SubscribePublishTranslate "https://github.com/awsdocs/aws-doc-sdk-examples/tree/main/dotnetv3/cross-service/SubscribePublishTranslate").

###### Services used in this example

- Amazon SNS
- Amazon Translate
