# Requirements to set up

motion graphic overlay files

The following table describes how to set up motion graphic overlay files.

| Motion graphic file requirement | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File type                       | QuickTime (.mov)<br>• Container: QuickTime<br>• Codec: QuickTime Animation (RLE)<br>• Color space: RGBA<br>Sequential PNG (.png)<br>• Make sure that the names of the .png files end with<br>sequential numbers that specify the order that they are<br>played in. For example, overlay_000.png,<br>overlay_001.png, overlay_002.png, and so on.<br>• Pad your initial file name with enough zeros to<br>complete the sequence. For example, if the first image<br>is overlay_0.png, there can be only 10 images in the<br>sequence, with the last image being overlay_9.png.<br>However, if the first image is overlay_00.png, there can<br>be 100 images in the sequence.<br>• Make sure that the number of images in your series<br>matches the frame rate and your intended overlay<br>duration. For example, if you want a 30-second overlay<br>at 30 fps, you should have 900 .png images.<br>• Requires an alpha channel. |
| Frame rate                      | QuickTime (.mov)<br>• Use any frame rate. The frame rate that you use<br>doesn't have to match the frame rate of the underlying<br>video.<br>Sequential PNG (.png)<br>• Use any frame rate. The frame rate that you use<br>doesn't have to match the frame rate of the underlying<br>video.<br>• Specify the frame rate when you set up the<br>overlay.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Aspect ratio                    | Use any aspect ratio. It doesn't have to match the aspect ratio<br>of the underlying video.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Size in pixels                  | Use any size. MediaConvert scales the motion graphic with any<br>outputs that have video scaling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
