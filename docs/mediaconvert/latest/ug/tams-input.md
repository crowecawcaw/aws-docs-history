# Processing content from TAMS servers

When you create jobs with AWS Elemental MediaConvert, you can process live and archived content directly from
Time-addressable Media Store (TAMS) servers. MediaConvert communicates with your TAMS server to
retrieve specific time segments and automatically generates the necessary manifests for
processing.

Some use cases for TAMS inputs might include:

- Extract highlights from live events for social media distribution.
- Process archived broadcast content for new programming or documentaries.
- Integrate with existing broadcast infrastructure and content management systems.
