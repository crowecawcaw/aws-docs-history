# Accelerated transcoding job settings requirements

Before you enable Accelerated transcoding, make sure that your job conforms to the following
requirements and limitations.

###### Video inputs supported with Accelerated transcoding

The following table shows the video input codecs and containers that MediaConvert supports
with Accelerated transcoding.
