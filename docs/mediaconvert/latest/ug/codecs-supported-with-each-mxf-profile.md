# List of codecs supported within each MXF profile

This table shows the codecs that AWS Elemental MediaConvert supports with each MXF
profile.

| MXF profile       | Supported video codecs                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------- |
| Generic OP1a      | VC-3 (SD, HD)<br>AVC Intra (SD, HD)<br>AVC (H.264) (SD, HD, 4K)<br>MPEG-2 (all resolutions) |
| D10 (SMPTE-386)   | MPEG-2 (SD)                                                                                 |
| Sony XDCAM        | MPEG-2 (HD)                                                                                 |
| Sony XAVC (RDD32) | XAVC (HD, 4K)                                                                               |
| XDCAM RDD9        | MPEG-2 (HD)                                                                                 |
