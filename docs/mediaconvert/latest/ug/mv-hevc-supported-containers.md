

# Supported containers for MV-HEVC
<a name="mv-hevc-supported-containers"></a>

The following table shows the containers and video codec that AWS Elemental MediaConvert supports for MV-HEVC outputs.


| Container | Supported video codec | 
| --- | --- | 
| MP4 | H.265 (HEVC) | 
| MOV | H.265 (HEVC) | 

**Note**  
H.265 (HEVC) is the only video codec supported for MV-HEVC outputs. You cannot use other codecs such as H.264 (AVC) with multi-view inputs.
