# Removing tags from an AWS Elemental MediaConvert

resource

The following procedure shows you how to remove tags from existing job templates,
output presets, and queues using the AWS Elemental MediaConvert console.

To do this using the API, see the `PUT` method in the [Tags](../apireference/tags.md "../apireference/tags.md") endpoint section of the _MediaConvert API Reference_.

###### To remove tags from a job template, output preset, or queue (console)

1. Open the MediaConvert console at [https://console.aws.amazon.com/mediaconvert](https://console.aws.amazon.com/mediaconvert "https://console.aws.amazon.com/mediaconvert").
2. Choose the three-bar icon on the left to access the left navigation pane.
3. Choose **Job templates**, **Output
   presets**, or **Queues**.
4. Choose the name of the specific resource that has tags that you want to
   change.
5. Choose the **Update**, **Edit queue**, or
   **Update preset** button in the upper right.
6. Next to any tag that you want to delete, choose
   **Remove**.
7. Choose **Save**.
