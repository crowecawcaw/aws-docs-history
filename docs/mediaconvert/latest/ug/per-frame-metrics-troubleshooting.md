# Troubleshooting

The following is a list of troubleshooting tips for issues that you might encounter while
working with per-frame metric reports:

**Missing metric reports**

Verify that you've enabled the metrics at either the output group level or
individual output level.

**QVBR metrics not appearing**

Confirm that your output settings include the QVBR rate control mode.

**Unexpected metric values**

Check that your content is appropriate for the selected metrics and review the
interpretation guidelines for each metric type.

**Job taking too long**

Consider reducing the number of selected metrics or applying them to fewer outputs
to reduce processing time.
