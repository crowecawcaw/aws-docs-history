# Listing reserved queues

You can list the AWS Elemental MediaConvert queues that are associated with your AWS account and
get details about those queues. The following tabs show two options for listing your
queues.

Console
To list your reserved queues by using the MediaConvert console, open
the [Queues](https://console.aws.amazon.com/mediaconvert/home#/queues/list "https://console.aws.amazon.com/mediaconvert/home#/queues/list") page.

AWS CLI
The following `list-queues` example lists all of your
queues.

```
aws mediaconvert list-queues
```

For more information about how list queues by using the AWS CLI, see the
[AWS CLI Command Reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/mediaconvert/list-queues.html "https://awscli.amazonaws.com/v2/documentation/api/latest/reference/mediaconvert/list-queues.html").
