# Supported output formats for audio-only workflows

MediaConvert supports the following combinations of output container and codec for
creating audio-only outputs.

Some containers and codecs have additional restrictions. For more information about
the audio container or audio codec choose its link in the following reference table. Or
see [Supported containers and codecs
reference tables](supported-containers-codecs-details.md "supported-containers-codecs-details.md").
