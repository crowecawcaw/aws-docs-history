# List of MediaConvert CloudWatch metrics

AWS Elemental MediaConvert sends the following metrics to CloudWatch at the end of every job.

| Metric name                   | Unit            | Description                                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Errors`                      | Count           | Tracks errors encountered when making a particular API<br>call.Operations include: `CreateJob`,<br>`GetJob`, `ListJobs`,<br>`ListPresets`, `ListQueues`,<br>`ListTagsForResource`, and<br>`Subscribe`                                                                                                                                                                                      |
| `AudioOutputDuration`         | Milliseconds    | The number of milliseconds of audio-only output for a<br>queue.                                                                                                                                                                                                                                                                                                                            |
| `SDOutputDuration`            | Milliseconds    | The number of milliseconds of standard definition (SD) output for<br>a queue.<br>For the definition of each video resolution category, see the<br>[AWS Elemental MediaConvert pricing page](https://aws.amazon.com/mediaconvert/pricing "https://aws.amazon.com/mediaconvert/pricing").                                                                                                    |
| `HDOutputDuration`            | Milliseconds    | The number of milliseconds of high-definition (HD) output for a<br>queue.<br>For the definition of each video resolution category, see the<br>[AWS Elemental MediaConvert pricing page](https://aws.amazon.com/mediaconvert/pricing "https://aws.amazon.com/mediaconvert/pricing").                                                                                                        |
| `UHDOutputDuration`           | Milliseconds    | The number of milliseconds of ultra-high-definition (UHD) output<br>for a queue.<br>For the definition of each video resolution category, see the<br>[AWS Elemental MediaConvert pricing page](https://aws.amazon.com/mediaconvert/pricing "https://aws.amazon.com/mediaconvert/pricing").                                                                                                 |
| `8KOutputDuration`            | Milliseconds    | The number of milliseconds of 8K output for a queue.<br>For the definition of each video resolution category, see the<br>[AWS Elemental MediaConvert pricing page](https://aws.amazon.com/mediaconvert/pricing "https://aws.amazon.com/mediaconvert/pricing").                                                                                                                             |
| `JobsCompletedCount`          | Count           | The number of jobs completed in a queue.                                                                                                                                                                                                                                                                                                                                                   |
| `JobsCanceled`                | Count           | The number of jobs canceled in a queue.                                                                                                                                                                                                                                                                                                                                                    |
| `JobsErroredCount`            | Count           | The number of jobs that failed because of invalid inputs, such as<br>a request to transcode a file that is not in the specified input<br>bucket.                                                                                                                                                                                                                                           |
| `StandbyTime`                 | Milliseconds    | The amount of time a job is in a queue before MediaConvert starts<br>processing it, in milliseconds.                                                                                                                                                                                                                                                                                       |
| `TranscodingTime`             | Milliseconds    | The number of milliseconds for MediaConvert to complete transcoding.                                                                                                                                                                                                                                                                                                                       |
| `BlackVideoDetected`          | Milliseconds    | The total duration of black video frames in your output that are<br>also present in your input in milliseconds.<br>`BlackVideoDetected` does not include any black frames<br>inserted by MediaConvert.                                                                                                                                                                                     |
| `BlackVideoDetectedRatio`     | Ratio           | The ratio of black video frames to the total duration of your<br>output.<br>Higher ratios show outputs with more black frames.                                                                                                                                                                                                                                                             |
| `LongestBlackSegmentDetected` | Milliseconds    | The location in your output with the longest continuous segment of<br>black video frames, in milliseconds.                                                                                                                                                                                                                                                                                 |
| `VideoPaddingInserted`        | Milliseconds    | The total duration of blank frames MediaConvert inserted across<br>all outputs in your job, in milliseconds.<br>Video padding inserts blank frames to help keep audio and video<br>durations aligned. Large `VideoPaddingInserted` values<br>show that more blank frames were inserted. They also show to what<br>extent your input audio tracks either start late, end early, or<br>both. |
| `VideoPaddingInsertedRatio`   | Ratio           | The ratio of blank frames MediaConvert inserted to the overall<br>duration of your output.<br>Higher ratios may signal audio video sync issues in your<br>input.                                                                                                                                                                                                                           |
| `AvgBitrateTop`               | Bits per second | The average bitrate of the highest bitrate output in the output<br>group.                                                                                                                                                                                                                                                                                                                  |
| `AvgBitrateBottom`            | Bits per second | The average bitrate of the lowest bitrate output in the output<br>group.                                                                                                                                                                                                                                                                                                                   |
| `QVBRAvgQualityHighBitrate`   | Score           | The average QVBR quality score of the highest bitrate output in<br>the output group.                                                                                                                                                                                                                                                                                                       |
| `QVBRAvgQualityLowBitrate`    | Score           | The average QVBR quality score of the lowest bitrate output in the<br>output group.                                                                                                                                                                                                                                                                                                        |
| `QVBRMinQualityHighBitrate`   | Score           | The minimum QVBR quality score of the highest bitrate output in<br>the output group.                                                                                                                                                                                                                                                                                                       |
| `QVBRMinQualityLowBitrate`    | Score           | The minimum QVBR quality score of the lowest bitrate output in the<br>output group.                                                                                                                                                                                                                                                                                                        |
