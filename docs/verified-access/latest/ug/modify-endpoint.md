

# Modify a Verified Access endpoint
<a name="modify-endpoint"></a>

Use the following procedure to modify a Verified Access endpoint.

**To modify a Verified Access endpoint using the console**

1. Open the Amazon VPC console at [https://console.aws.amazon.com/vpc/](https://console.aws.amazon.com/vpc/).

1. In the navigation pane, choose **Verified Access endpoints**.

1. Select the endpoint.

1. Choose **Actions**, **Modify Verified Access endpoint**.

1. Modify the endpoint details as needed.

1. Choose **Modify Verified Access endpoint**.

**To modify a Verified Access endpoint using the AWS CLI**  
Use the [modify-verified-access-endpoint](https://docs.aws.amazon.com/cli/latest/reference/ec2/modify-verified-access-endpoint.html) command.
