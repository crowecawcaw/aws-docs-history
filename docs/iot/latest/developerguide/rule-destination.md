# Working with HTTP topic rule

destinations

An HTTP topic rule destination is a web service to which the rules engine can
route data from a topic rule. An AWS IoT Core resource describes the web service
for AWS IoT. Topic rule destination resources can be shared by different
rules.

Before AWS IoT Core can send data to another web service, it must confirm that it
can access the service's endpoint.
