# Set up AWS account

Before you use AWS IoT Core for the first time, complete the following tasks:

###### Topics

- [Sign up for an AWS account](#sign-up-for-aws "#sign-up-for-aws")
- [Open the AWS IoT console](#iot-console-signin "#iot-console-signin")

## Sign up for an AWS account

To get started with AWS, you need an AWS account. For information about creating an AWS account, see
[Getting started with an AWS account](../../../accounts/latest/reference/getting-started.md "../../../accounts/latest/reference/getting-started.md")
in the _AWS Account Management Reference Guide_.

- [Open the AWS IoT console](#iot-console-signin "#iot-console-signin")

## Open the AWS IoT console

Most of the console-oriented topics in this section start from the AWS IoT console.
If you aren't already signed in to your AWS account, sign in, then open the [AWS IoT console](https://console.aws.amazon.com/iot/home "https://console.aws.amazon.com/iot/home") and continue to the next
section to continue getting started with AWS IoT.
