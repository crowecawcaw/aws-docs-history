# AWS IoT Core pricing

You can find information about AWS IoT Core pricing in the _AWS Marketing
page_ and the _[AWS Pricing
Calculator](https://calculator.aws/#/addService "https://calculator.aws/#/addService")_.

- To check AWS IoT Core pricing information, see [AWS IoT Core Pricing](https://aws.amazon.com/iot-core/pricing/ "https://aws.amazon.com/iot-core/pricing/").
- To estimate the cost of your architect solution, see [AWS Pricing Calculator](https://calculator.aws/#/addService "https://calculator.aws/#/addService").
