# Create custom job templates

You can create job templates by using the AWS CLI and the AWS IoT console. You can also
create jobs from job templates by using the AWS CLI, the AWS IoT console, and
Fleet Hub for AWS IoT Device Management web applications. For more information about working with job templates
in Fleet Hub applications, see [Working with
job templates in Fleet Hub for AWS IoT Device Management](../fleethubuserguide/aws-iot-monitor-technician-job-templates.md "../fleethubuserguide/aws-iot-monitor-technician-job-templates.md").

###### Note

The total number of substitution patterns in a job document should be less than or
equal to ten.
