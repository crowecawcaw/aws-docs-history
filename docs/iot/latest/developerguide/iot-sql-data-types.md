# Data types

The AWS IoT rules engine supports all JSON data types.

| Supported data types | Type                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Meaning |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `Int`                | A discrete `Int`. 34 digits maximum.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Decimal`            | A `Decimal` with a precision of 34 digits, with a<br>minimum non-zero magnitude of 1E-999 and a maximum magnitude<br>9.999...E999.<br>NoteSome functions return `Decimal` values with double<br>precision rather than 34-digit precision. With SQL V2 (2016-03-23), numeric values that are whole<br>numbers, such as `10.0`, are processed as an<br>`Int` value (`10`) instead of the<br>expected `Decimal` value (`10.0`). To<br>reliably process whole number numeric values as<br>`Decimal` values, use SQL V1 (2015-10-08) for the<br>rule query statement.                                                                                                                                              |
| `Boolean`            | `True` or `False`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `String`             | A UTF-8 string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `Array`              | A series of values that don't have to have the same type.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `Object`             | A JSON value consisting of a key and a value. Keys must be strings.<br>Values can be any type.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `Null`               | `Null` as defined by JSON. It's an actual value that<br>represents the absence of a value. You can explicitly create a<br>`Null` value by using the `Null` keyword in<br>your SQL statement. For example: `"SELECT NULL AS n FROM<br>'topic/subtopic'"`                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `Undefined`          | Not a value. This isn't explicitly representable in JSON except by<br>omitting the value. For example, in the object `{"foo":<br>null}`, the key "foo" returns NULL, but the key "bar"<br>returns `Undefined`. Internally, the SQL language treats<br>`Undefined` as a value, but it isn't representable in<br>JSON, so when serialized to JSON, the results are<br>`Undefined`.<br>`<br>{"foo":null, "bar":undefined}<br>`<br>is serialized to JSON as:<br>`<br>{"foo":null}<br>`<br>Similarly, `Undefined` is converted to an empty string<br>when serialized by itself. Functions called with invalid arguments<br>(for example, wrong types, wrong number of arguments, and so on)<br>return `Undefined`. |

## Conversions

The following table lists the results when a value of one type is converted to
another type (when a value of the incorrect type is given to a function). For
example, if the absolute value function "abs" (which expects an `Int` or
`Decimal`) is given a `String`, it attempts to convert the
`String` to a `Decimal`, following these rules. In this
case, 'abs("-5.123")' is treated as 'abs(-5.123)'.

###### Note

There are no attempted conversions to `Array`, `Object`,
`Null`, or `Undefined`.

| To decimal | Argument type                                                                                                                                                                                                                                                           | Result |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `Int`      | A `Decimal` with no decimal point.                                                                                                                                                                                                                                      |
| `Decimal`  | The source value.                                                                                                                                                                                                                                                       |
| `Boolean`  | `Undefined`. (You can explicitly use the cast function<br>to transform true = 1.0, false = 0.0.)                                                                                                                                                                        |
| `String`   | The SQL engine tries to parse the string as a<br>`Decimal`. AWS IoT attempts to parse strings matching<br>the regular expression:`^-?\d+(\.\d+)?((?i)E-?\d+)?$`.<br>"0", "-1.2", "5E-12" are all examples of strings that are converted<br>automatically to `Decimal`s. |
| Array      | `Undefined`.                                                                                                                                                                                                                                                            |
| Object     | `Undefined`.                                                                                                                                                                                                                                                            |
| Null       | `Null`.                                                                                                                                                                                                                                                                 |
| Undefined  | `Undefined`.                                                                                                                                                                                                                                                            |

| To int    | Argument type                                                                                                                                                                                                                                                                                                                                                                                                       | Result |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `Int`     | The source value.                                                                                                                                                                                                                                                                                                                                                                                                   |
| `Decimal` | The source value rounded to the nearest `Int`.                                                                                                                                                                                                                                                                                                                                                                      |
| `Boolean` | `Undefined`. (You can explicitly use the cast function<br>to transform true = 1.0, false = 0.0.)                                                                                                                                                                                                                                                                                                                    |
| `String`  | The SQL engine tries to parse the string as a<br>`Decimal`. AWS IoT attempts to parse strings matching<br>the regular expression:`^-?\d+(\.\d+)?((?i)E-?\d+)?$`.<br>"0", "-1.2", "5E-12" are all examples of strings that are converted<br>automatically to `Decimal`s. AWS IoT attempts to convert<br>the `String` to a `Decimal`, and then<br>truncates the decimal places of that `Decimal` to make an<br>`Int`. |
| Array     | `Undefined`.                                                                                                                                                                                                                                                                                                                                                                                                        |
| Object    | `Undefined`.                                                                                                                                                                                                                                                                                                                                                                                                        |
| Null      | `Null`.                                                                                                                                                                                                                                                                                                                                                                                                             |
| Undefined | `Undefined`.                                                                                                                                                                                                                                                                                                                                                                                                        |

| To Boolean | Argument type                                                                                                     | Result |
| ---------- | ----------------------------------------------------------------------------------------------------------------- | ------ |
| `Int`      | `Undefined`. (You can explicitly use the<br>`cast` function to transform 0 = False,<br>any_nonzero_value = True.) |
| `Decimal`  | `Undefined`. (You can explicitly use the cast function<br>to transform 0 = False, any_nonzero_value = True.)      |
| `Boolean`  | The original value.                                                                                               |
| `String`   | "true"=True and "false"=False (case insensitive). Other string<br>values are `Undefined`.                         |
| Array      | `Undefined`.                                                                                                      |
| Object     | `Undefined`.                                                                                                      |
| Null       | `Undefined`.                                                                                                      |
| Undefined  | `Undefined`.                                                                                                      |

| To string | Argument type                                                                                                                                                                                                               | Result |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `Int`     | A string representation of the `Int` in standard<br>notation.                                                                                                                                                               |
| `Decimal` | A string representing the `Decimal` value, possibly in<br>scientific notation.                                                                                                                                              |
| `Boolean` | "true" or "false". All lowercase.                                                                                                                                                                                           |
| `String`  | The original value.                                                                                                                                                                                                         |
| Array     | The `Array` serialized to JSON. The resultant string<br>is a comma-separated list, enclosed in square brackets. A<br>`String` is quoted. A `Decimal`,<br>`Int`, `Boolean`, and `Null` is<br>not.                            |
| Object    | The object serialized to JSON. The resultant string is a<br>comma-separated list of key-value pairs and begins and ends with<br>curly braces. A `String` is quoted. A<br>`Decimal`, `Int`, `Boolean`,<br>and `Null` is not. |
| Null      | `Undefined`.                                                                                                                                                                                                                |
| Undefined | Undefined.                                                                                                                                                                                                                  |
