# Example thing queries

Specify queries in a query string using a query syntax. The queries are passed to the
[`SearchIndex`](../apireference/API_SearchIndex.md "../apireference/API_SearchIndex.md") API. The
following table lists some example query strings.

| Query string                                                                                    | Result                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `abc`                                                                                           | Queries for "abc" in any registry, shadow (classic unnamed shadow and named<br>shadow), or Device Defender violations field.                                                                                                                                                   |
| `thingName:myThingName`                                                                         | Queries for a thing with name "myThingName".                                                                                                                                                                                                                                   |
| `thingName:my*`                                                                                 | Queries for things with names that begin with "my".                                                                                                                                                                                                                            |
| `thingName:*my`                                                                                 | Queries for things with names that end in "my". Leading wildcard use is limited<br>to 1 query term per query. Queries that include a leading wildcard have a max<br>query length of 100 characters.                                                                            |
| `thingName:*my*`                                                                                | Queries for things that contain the substring "my". Leading wildcard use is<br>limited to 1 query term per query. Queries that include a leading wildcard have a max<br>query length of 100 characters.                                                                        |
| `thingName:ab?`                                                                                 | Queries for things with names that have "ab" plus one additional character (for<br>example, "aba", "abb", "abc", and so on.                                                                                                                                                    |
| `thingTypeName:aa`                                                                              | Queries for things that are associated with type "aa".                                                                                                                                                                                                                         |
| `thingGroupNames:a`                                                                             | Queries for things with a parent thing group or billing group name "a".                                                                                                                                                                                                        |
| `thingGroupNames:a*`                                                                            | Queries for things with a parent thing group or billing group name matching the<br>pattern "a\*".                                                                                                                                                                              |
| `attributes.myAttribute:75`                                                                     | Queries for things with an attribute named "myAttribute" that has the value<br>75.                                                                                                                                                                                             |
| `attributes.myAttribute:[75 TO 80]`                                                             | Queries for things with an attribute named "myAttribute" that has a value that<br>falls within a numeric range (75–80, inclusive).                                                                                                                                             |
| `attributes.myAttribute:{75 TO 80]`                                                             | Queries for things with an attribute named "myAttribute" that has a value that<br>falls within the numeric range (>75 and <=80).                                                                                                                                               |
| `attributes.serialNumber:["abcd" TO "abcf"]`                                                    | Queries for things with an attribute named "serialNumber" that has a value<br>within an alphanumeric string range. This query returns things with a "serialNumber"<br>attribute with values "abcd", "abce", or "abcf".                                                         |
| `attributes.myAttribute:i*t`                                                                    | Queries for things with an attribute named "myAttribute" where the value is 'i',<br>followed by any number of characters, followed by 't'.                                                                                                                                     |
| `attributes.attr1:abc AND attributes.attr2<5 NOT attributes.attr3>10`                           | Queries for things that combine terms using Boolean expressions. This query<br>returns things that have an attribute named "attr1" with a value "abc", an attribute<br>named "attr2" that's less than 5, and an attribute named "attr3" that' not greater<br>than 10.          |
| `shadow.hasDelta:true`                                                                          | Queries for things with an unnamed shadow that has a delta element.                                                                                                                                                                                                            |
| `NOT attributes.model:legacy`                                                                   | Queries for things where the attribute named "model" is not "legacy".                                                                                                                                                                                                          |
| `shadow.reported.stats.battery:{70 TO 100} (v2 OR v3) NOT<br>attributes.model:legacy`           | Queries for things with the following:<br>• The thing's shadow `stats.battery` attribute has a value between<br>70 and 100.<br>• The text "v2" or "v3" occurs in a thing's name, type name, or attribute<br>values.<br>• The thing's `model` attribute is not set to "legacy". |
| `shadow.reported.myvalues:2`                                                                    | Queries for things where the `myvalues` array in the shadow's<br>reported section contains a value of 2.                                                                                                                                                                       |
| `shadow.reported.location:<br>• NOT shadow.desired.stats.battery:*`                             | Queries for things with the following:<br>• The `location` attribute exists in the shadow's<br>`reported` section.<br>• The `stats.battery` attribute doesn't exist in the shadow's<br>`desired` section.                                                                      |
| `shadow.name.<shadowName>.hasDelta:true`                                                        | Queries for things that have a shadow with the given name and also a delta<br>element.                                                                                                                                                                                         |
| `shadow.name.<shadowName>.desired.filament:*`                                                   | Queries for things that have a shadow with the given name and also a desired<br>filament property.                                                                                                                                                                             |
| `shadow.name.<shadowName>.reported.location:*`                                                  | Queries for things that have a shadow with the given name and where the<br>`location` attribute exists in the named shadow's reported<br>section.                                                                                                                              |
| `connectivity.connected:true`                                                                   | Queries for all connected devices.                                                                                                                                                                                                                                             |
| `connectivity.connected:false`                                                                  | Queries for all disconnected devices.                                                                                                                                                                                                                                          |
| `connectivity.connected:true AND connectivity.timestamp : [1557651600000 TO<br>1557867600000]`  | Queries for all connected devices with a connect timestamp >= 1557651600000<br>and <= 1557867600000. Timestamps are given in milliseconds since epoch.                                                                                                                         |
| `connectivity.connected:false AND connectivity.timestamp : [1557651600000 TO<br>1557867600000]` | Queries for all disconnected devices with a disconnect timestamp >=<br>1557651600000 and <= 1557867600000. Timestamps are given in milliseconds since<br>epoch.                                                                                                                |
| `connectivity.connected:true AND connectivity.timestamp > 1557651600000`                        | Queries for all connected devices with a connect timestamp > 1557651600000.<br>Timestamps are given in milliseconds since epoch.                                                                                                                                               |
| `connectivity.connected:*`                                                                      | Queries for all devices with connectivity information present.                                                                                                                                                                                                                 |
| `connectivity.disconnectReason:*`                                                               | Queries for all devices with connectivity disconnectReason present.                                                                                                                                                                                                            |
| `connectivity.disconnectReason:CLIENT_INITIATED_DISCONNECT`                                     | Queries for all devices disconnected due to CLIENT_INITIATED_DISCONNECT.                                                                                                                                                                                                       |
| `deviceDefender.violationCount:[0 TO 100]`                                                      | Queries for things with a Device Defender violations count value that falls<br>within the numeric range (0-100, inclusive).                                                                                                                                                    |
| `deviceDefender.<device-SecurityProfile>.disconnectBehavior.inViolation:true`                   | Queries for things that are in violation for the behavior<br>`disconnectBehavior` as defined in the security profile<br>`device-SecurityProfile`. Note that \*inViolation:false<br>• is not a valid query.                                                                     |
| `deviceDefender.<device-SecurityProfile>.disconnectBehavior.lastViolationValue.number>2`        | Queries for things that are in violation for the behavior<br>`disconnectBehavior` as defined in the security profile<br>device-SecurityProfile with a last violation event value greater than 2.                                                                               |
| `deviceDefender.<device-SecurityProfile>.disconnectBehavior.lastViolationTime>1634227200000`    | Queries for things that are in violation for the behavior<br>`disconnectBehavior` as defined in the security profile<br>device-SecurityProfile with a last violation event after a specified epoch time.                                                                       |
| `shadow.name.gps-tracker.reported.coordinates:geo_distance,47.6204,-122.3491,15.5km`            | Queries for things that are within the radial distance of 15.5 km from the<br>coordinates of 47.6204,-122.3491. This query string applies to when your location data<br>is stored in a named shadow.                                                                           |
| `shadow.reported.coordinates:geo_distance,47.6204,-122.3491,15.5km`                             | Queries for things that are within the radial distance of 15.5 km from the<br>coordinates of 47.6204,-122.3491. This query string applies to when your location data<br>is stored in a classic shadow.                                                                         |
