# Use operators in formula expressions

You can use the following common operators in formula expressions.

| Operator                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `+`                         | If both operands are numbers, this operator adds the left and right<br>operands.<br>If either operand is a string, this operator concatenates the left and right operands as strings.<br>For example, the expression `1 + 2 + " is three"` evaluates to `"3 is three"`.<br>The concatenated string can have up to 1024 characters. If the string exceeds 1024 characters, then<br>AWS IoT SiteWise doesn't output a data point for that computation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `-`                         | Subtracts the right operand from the left operand.<br>You can only use this operator with numeric operands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `/`                         | Divides the left operand by the right operand.<br>You can only use this operator with numeric operands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `*`                         | Multiplies the left and right operands.<br>You can only use this operator with numeric operands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `^`                         | Raises the left operand to the power of the right operand<br>(exponentiation).<br>You can only use this operator with numeric operands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `%`                         | Returns the remainder from dividing the left operand by the right operand.<br>The result has the same sign as the left operand. This behavior differs from<br>the modulo operation.<br>You can only use this operator with numeric operands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `x < y`                     | Returns `1` if `x` is less than `y`,<br>otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `x > y`                     | Returns `1` if `x` is greater than `y`,<br>otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `x <= y`                    | Returns `1` if `x` is less than or equal to<br>`y`, otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `x >= y`                    | Returns `1` if `x` is greater than or equal to<br>`y`, otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `x == y`                    | Returns `1` if `x` is equal to `y`,<br>otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `x != y`                    | Returns `1` if `x` is not equal to `y`,<br>otherwise `0`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `!x`                        | Returns `1` if `x` is evaluated to `0`<br>(false), otherwise `0`.<br>`x` is evaluated to false if:<br>• `x` is a numeric operand and it's evaluated to<br>`0`.<br>• `x` is evaluated to an empty string.<br>• `x` is evaluated to an empty array.<br>• `x` is evaluated to `None`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `x and y`                   | Returns `0` if `x` is evaluated to `0`<br>(false). Otherwise, returns the evaluated result of `y`.<br>`x` or `y` is evaluated to false if:<br>• `x` or `y` is a numeric operand and it's<br>evaluated to `0`.<br>• `x` or `y` is evaluated to an empty<br>string.<br>• `x` or `y` is evaluated to an empty<br>array.<br>• `x` or `y` is evaluated to<br>`None`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `x or y`                    | Returns `1` if `x` is evaluated to `1`<br>(true). Otherwise, returns the evaluated result of `y`.<br>`x` or `y` is evaluated to false if:<br>• `x` or `y` is a numeric operand and it's<br>evaluated to `0`.<br>• `x` or `y` is evaluated to an empty<br>string.<br>• `x` or `y` is evaluated to an empty<br>array.<br>• `x` or `y` is evaluated to<br>`None`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `not x`                     | Returns `1` if `x` is evaluated to `0`<br>(false), otherwise `0`.<br>`x` is evaluated to false if:<br>• `x` is a numeric operand and it's evaluated to<br>`0`.<br>• `x` is evaluated to an empty string.<br>• `x` is evaluated to an empty array.<br>• `x` is evaluated to `None`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `[]`<br>`s[index]`          | Returns the character at an index `index` of the string<br>`s`. This is equivalent to the index syntax in Python.<br>Examples<br>• `"Hello!"[1]` returns `e`.<br>• `"Hello!"[-2]` returns `o`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `[]`<br>`s[start:end:step]` | Returns a slice of the string `s`. This is equivalent to the<br>slice syntax in Python. This operator has the following arguments:<br>• `start` – (Optional) The inclusive start index of<br>the slice. Defaults to `0`.<br>• `end` – (Optional) The exclusive end index of the<br>slice. Defaults to the length of the string.<br>• `step` – (Optional) The number to increment for each<br>step in the slice. For example, you can specify `2` to return a<br>slice with every other character, or specify `-1` to reverse<br>the slice. Defaults to `1`.<br>You can omit the `step` argument to use its default value. For<br>example, `s[1:4:1]` is equivalent to `s[1:4]`.<br>The arguments must be integers or the [none](expression-constants.md#none-definition "expression-constants.md#none-definition") constant. If you specify `none`, AWS IoT SiteWise uses the<br>default value for that argument.<br>Examples<br>• `"Hello!"[1:4]` returns `"ell"`.<br>• `"Hello!"[:2]` returns `"He"`.<br>• `"Hello!"[3:]` returns `"lo!"`.<br>• `"Hello!"[:-4]` returns `"He"`.<br>• `"Hello!"[::2]` returns `"Hlo"`.<br>• `"Hello!"[::-1]` returns `"!olleH"`. |
