# Use formula expressions

With formula expressions, you can define the mathematical functions to transform and
aggregate your raw industrial data to gain insights about your operation. Formula expressions combine literals, operators, functions, and variables to
process data. For more information about how to define asset properties that use formula expressions, see [Transform data (transforms)](transforms.md "transforms.md") and [Aggregate data from properties and other assets (metrics)](metrics.md "metrics.md"). Transforms and metrics are formula properties.
