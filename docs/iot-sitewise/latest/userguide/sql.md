# AWS IoT SiteWise query language

With the AWS IoT SiteWise data retrieval [ExecuteQuery](../APIReference/API_ExecuteQuery.md "../APIReference/API_ExecuteQuery.md") API operation, you can retrieve information about declarative structural
definitions, and the timeseries data associated with them, from the following:

- models
- assets
- measurements
- metrics
- transforms
- aggregates
  This can be done with SQL like query statements, in a single API request.

###### Note

This feature is available in all Regions where AWS IoT SiteWise is available,
except AWS GovCloud (US-West), Canada (Central), China (Beijing) and
US East (Ohio).
