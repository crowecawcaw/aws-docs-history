# Use conditional functions in formula

expressions

In [transforms](transforms.md "transforms.md") and [metrics](metrics.md "metrics.md"), you can use the following function to check a condition and return
different results, whether the condition evaluates to true or false.

| Function                                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `if(condition, result_if_true, result_if_false)` | Evaluates the `condition` and returns<br>`result_if_true` if the condition evaluates to true or<br>`result_if_false` if the condition evaluates to `false`.<br>`condition` must be a number. This function considers<br>`0` and an empty string as<br>`false`<br>and everything else (including `NaN`) as<br>`true`.<br>Booleans convert to `0` (false) and `1` (true).<br>You can return the [none constant](expression-constants.md#none-definition "expression-constants.md#none-definition")<br>from this function to discard the output for a particular condition. This<br>means you can filter out data points that don't meet a condition. For more<br>information, see [Filter data points](expression-tutorials.md#filter-data "expression-tutorials.md#filter-data").<br>Examples<br>• `if(0, x, y)` returns the variable<br>`y`.<br>• `if(5, x, y)` returns the variable<br>`x`.<br>• `if(gt(temp, 300), x, y)` returns the variable<br>`x` if the variable `temp` is greater than<br>`300`.<br>• `if(gt(temp, 300), temp, none)` returns the variable<br>`temp` if it's greater than or equal to `300`,<br>or `none` (no value) if `temp` is less than<br>`300`.<br>We recommend that you use UFCS for nested conditional functions where<br>one or more arguments are conditional functions. You can use<br>`if(condition, result_if_true)` to evaluate a condition and<br>`elif(condition, result_if_true, result_if_false)` to evaluate<br>additional conditions.<br>For example, you can use `if(condition1,<br>result1_if_true).elif(condition2, result2_if_true,<br>result2_if_false)` instead of `if(condition1, result1_if_true,<br>if(condition2, result2_if_true, result2_if_false))`.<br>You can also chain additional intermediate conditional functions. For<br>example, you can use `if(condition1, result1_if_true).elif(condition2,<br>result2_if_true).elif(condition3, result3_if_true,<br>result3_if_false)` instead of nesting multiple `if`<br>statements, such as `if(condition1, result1_if_true, if(condition2,<br>result2_if_true, if(condition3, result3_if_true<br>result3_if_false)))`.<br>ImportantYou must use `elif(condition, result_if_true,<br>result_if_false)` with UFCS. |
