# Use comparison functions in formula

expressions

In [transforms](transforms.md "transforms.md") and [metrics](metrics.md "metrics.md"), you can use the following comparison functions to compare two
values and output `1` (true) or `0` (false). AWS IoT SiteWise compares
strings by [lexicographic order](https://en.wikipedia.org/wiki/Lexicographic_order "https://en.wikipedia.org/wiki/Lexicographic_order").

| Function    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gt(x, y)`  | Returns `1` if `x` is greater than `y`,<br>otherwise `0` (`x > y`).<br>This function doesn't return a value if<br>`x` and `y` are incompatible types, such as a number and a<br>string.                                                                                                                                                                                                                                                                                                       |
| `gte(x, y)` | Returns `1` if `x` is greater than or equal to<br>`y`, otherwise `0` (`x ≥ y`).<br>AWS IoT SiteWise considers the arguments equal if they are<br>within a relative tolerance of `1E-9`. This behaves similar to the [isclose](https://docs.python.org/3/library/math.html#math.isclose "https://docs.python.org/3/library/math.html#math.isclose") function in<br>Python.<br>This function doesn't return a value if<br>`x` and `y` are incompatible types, such as a number and a<br>string. |
| `eq(x, y)`  | Returns `1` if `x` is equal to `y`,<br>otherwise `0` (`x == y`).<br>AWS IoT SiteWise considers the arguments equal if they are<br>within a relative tolerance of `1E-9`. This behaves similar to the [isclose](https://docs.python.org/3/library/math.html#math.isclose "https://docs.python.org/3/library/math.html#math.isclose") function in<br>Python.<br>This function doesn't return a value if<br>`x` and `y` are incompatible types, such as a number and a<br>string.                |
| `lt(x, y)`  | Returns `1` if `x` is less than `y`,<br>otherwise `0` (`x < y`).<br>This function doesn't return a value if<br>`x` and `y` are incompatible types, such as a number and a<br>string.                                                                                                                                                                                                                                                                                                          |
| `lte(x, y)` | Returns `1` if `x` is less than or equal to<br>`y`, otherwise `0` (`x ≤ y`).<br>AWS IoT SiteWise considers the arguments equal if they are<br>within a relative tolerance of `1E-9`. This behaves similar to the [isclose](https://docs.python.org/3/library/math.html#math.isclose "https://docs.python.org/3/library/math.html#math.isclose") function in<br>Python.<br>This function doesn't return a value if<br>`x` and `y` are incompatible types, such as a number and a<br>string.    |
| `isnan(x)`  | Returns `1` if `x` is equal to `NaN`,<br>otherwise `0`.<br>This function doesn't return a value if `x` is a<br>string.                                                                                                                                                                                                                                                                                                                                                                        |
