# Use string functions in formula

expressions

In [transforms](transforms.md "transforms.md") and [metrics](metrics.md "metrics.md"), you can use the following functions to operate on strings. For more
information, see [Use strings in formulas](expression-tutorials.md#use-strings-in-formulas "expression-tutorials.md#use-strings-in-formulas").

###### Important

Formula expressions can only output double or string values. Nested
expressions can output other data types, such as strings, but the formula as a whole must
evaluate to a number or string. You can use the [jp function](#jp-definition "#jp-definition") to
convert a string to a number. The Boolean value must be 1 (true) or 0 (false).
For more information, see [Undefined, infinite, and overflow values](expression-tutorials.md#undefined-values "expression-tutorials.md#undefined-values").

| `jp(s, json_path)`                                                  | Evaluates the string `s` with the [JsonPath](https://github.com/json-path/JsonPath "https://github.com/json-path/JsonPath") expression<br>`json_path` and returns the result.<br>Use this function to do the following:<br>• Extract a value, array, or object from a serialized JSON<br>structure.<br>• Convert a string to a number. For example, the formula<br>`jp('111', '$')` returns `111` as a<br>number.<br>To extract a string value from a JSON structure and return it as a<br>number, you must use multiple nested `jp` functions. The outer<br>`jp` function extracts the string from the JSON structure, and<br>the inner `jp` function converts the string to a number.<br>The string `json_path` must contain a string literal. This<br>means that `json_path` can't be an expression that evaluates to a<br>string.<br>Examples<br>• `jp('{"status":"active","value":15}', '$.value')`<br>returns `15`.<br>• `jp('{"measurement":{"reading":25,"confidence":0.95}}',<br>'$.measurement.reading')` returns `25`.<br>• `jp('[2,8,23]', '$[2]')` returns<br>`23`.<br>• `jp('{"values":[3,6,7]}', '$.values[1]')` returns<br>`6`.<br>• `jp('111', '$')` returns `111`.<br>• `jp(jp('{"measurement":{"reading":25,"confidence":"0.95"}}',<br>'$.measurement.confidence'), '$')` returns<br>`0.95`. |
| `join(s0, s1, s2, s3, ...)`                                         | Returns a concatenated string with a delimiter. This function uses the<br>first input string as a delimiter and joins the remaining input strings<br>together. | `format(expression: "format")` or `format("format",<br>expression)` | Returns a string in the specified format. This function evaluates<br>`expression` to a value, and then returns the value in the<br>specified format. This behaves similar to the [format(String format, Object... args)](https://docs.oracle.com/javase/8/docs/api/java/lang/String.html#format-java.lang.String-java.lang.Object...<br>• "https://docs.oracle.com/javase/8/docs/api/java/lang/String.html#format-java.lang.String-java.lang.Object...-") function in Java. For more<br>information about supported formats, see Conversions under [Class Formatter](https://docs.oracle.com/javase/7/docs/api/java/util/Formatter.html "https://docs.oracle.com/javase/7/docs/api/java/util/Formatter.html") in the _Java Platform, Standard Edition<br>7 API Specification_.<br>Examples<br>• `format(100+1: "d")` returns a string,<br>`101`.<br>• `format("The result is %d", 100+1)` returns a string,<br>`The result is 101`.                                                                                                                                                                                                                                                                                                                                                                             |
| `f'expression'`                                                     | Returns a concatenated string. With this formatted function, you can use<br>a simple expression to concatenate and format strings. These functions may<br>contain nested expressions. You can use `{}` (curly braces) to<br>interpolate expressions. This behaves similar to the [formatted string literals](https://docs.python.org/3/reference/lexical_analysis.html#f-strings "https://docs.python.org/3/reference/lexical_analysis.html#f-strings") in Python.<br>Examples<br>• `f'abc{1+2: "f"}d'` returns `abc3.000000d`.<br>To evaluate this example expression, do the following:<br>1. `format(1+2: "f")` returns a floating point number,<br>`3.000000`.<br>2. `join('', "abc", 1+2, 'd')` returns a string,<br>`abc3.000000d`.<br>You can also write the expression in the following way:<br>`join('', "abc", format(1+2: "f"), 'd')`.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
