# Document history for the AMB Query User Guide

The following table describes the documentation releases for AMB Query.

| Change                                                                                                                                                                                                   | Description                                                                                                                                                                                                                                                                                                                                                                     | Date              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| [AMB Query supports Bitcoin transaction identifiers and transaction hashes](key-concepts.md#bitcoin-enhancement "key-concepts.md#bitcoin-enhancement")                                                   | For Bitcoin networks, AMB Query API operations support both the transaction identifier<br>(`transactionId`) and the transaction hash (`transactionHash`).                                                                                                                                                                                                                       | March 21, 2024    |
| [Support for API usage metrics on Amazon CloudWatch](cw-usage-metrics.md "cw-usage-metrics.md")                                                                                                          | AMB Query added support for API usage metrics on CloudWatch. These usage metrics correspond to the<br>AMB Query service quotas.                                                                                                                                                                                                                                                 | February 8, 2024  |
| [Support for transactions that have not reached finality](../AMBQ-APIReference/API_GetTransaction.md "../AMBQ-APIReference/API_GetTransaction.md")                                                       | AMB Query added support for transactions that have not reached *[*finality*](key-concepts.md#finality "key-concepts.md#finality")*. It also removes support for the `status` property<br>from the response of the `GetTransaction` operation. Instead, you will use the<br>`confirmationStatus` and `executionStatus` properties to determine the status<br>of the transaction. | February 1, 2024  |
| [Deprecation of the `status` property in the Transaction data type](../AMBQ-APIReference/API_Transaction.md#API_Transaction_Contents "../AMBQ-APIReference/API_Transaction.md#API_Transaction_Contents") | Amazon Managed Blockchain (AMB) Query has deprecated the `status` property in the Transaction data type.<br>You must use the `confirmationStatus` and `executionStatus` fields to<br>determine if the `status` of the transaction is `FINAL` or<br>`FAILED`.                                                                                                                    | December 20, 2023 |
| [Support for Sepolia Testnet](key-concepts.md#ambq-considerations "key-concepts.md#ambq-considerations")                                                                                                 | Amazon Managed Blockchain (AMB) Query now supports queries on the Ethereum Sepolia Testnet.                                                                                                                                                                                                                                                                                     | October 19, 2023  |
| [Support for asset contracts](query-usecases.md#query-contract-info "query-usecases.md#query-contract-info")                                                                                             | You can use the `ListAssetContracts` API operation to list deployed by<br>a given address. Additionally, if you have the contract address, you can use the<br>`GetAssetContract` API operation to retrieve the<br>contract's details.                                                                                                                                           | October 16, 2023  |
| [Support for Bitcoin Testnet](key-concepts.md#ambq-considerations "key-concepts.md#ambq-considerations")                                                                                                 | Amazon Managed Blockchain (AMB) Query now supports queries on the Bitcoin Testnet.                                                                                                                                                                                                                                                                                              | October 16, 2023  |
| [Initial release](what-is-service.md "what-is-service.md")                                                                                                                                               | Initial release of the AMB Query service.                                                                                                                                                                                                                                                                                                                                       | July 27, 2023     |
