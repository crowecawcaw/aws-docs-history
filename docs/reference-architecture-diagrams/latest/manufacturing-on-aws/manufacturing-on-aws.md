# Manufacturing on AWS

Publication date: **October 28, 2020 ([Diagram history](#mfg-diagram-history "#mfg-diagram-history"))**

With this architectural blueprint, you can see how AWS Cloud enables digital
transformation for manufacturers. This architecture highlights how a smart factory, smart
products, enterprise applications, and engineering workloads integrate through a central
data lake.

The following diagrams describe the architecture:

- [Overview](mfg-overview.md "mfg-overview.md") — How manufacturing workloads connect through a
  central data lake.
- [Data ingestion](mfg-data-ingestion.md "mfg-data-ingestion.md") — Bringing data from factory floors and
  enterprise applications into AWS.
- [Data lake and analytics](mfg-data-lake-analytics.md "mfg-data-lake-analytics.md") — Processing, analyzing, and deriving
  insights from manufacturing data.
- [Application hosting](mfg-app-hosting.md "mfg-app-hosting.md") — Running enterprise and engineering
  applications on AWS.
- [Smart products](mfg-smart-products.md "mfg-smart-products.md") — Connecting manufactured products and
  machines to AWS.
