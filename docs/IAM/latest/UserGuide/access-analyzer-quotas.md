| Maximum organization-level internal access analyzers per AWS organization per Region                        | 1                                                                                                                                                                                                                        | 1                                                                                                                                                      |
| Maximum archive rules per analyzer                                                                          | 100 Each archive rule can have up to 20 values per criterion.                                                                                                                                                            | 1,000¹                                                                                                                                                 |
