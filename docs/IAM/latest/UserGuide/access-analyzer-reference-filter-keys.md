# IAM Access Analyzer filter keys

You can use the filter keys below to define an archive rule ([`CreateArchiveRule`](../../../access-analyzer/latest/APIReference/API_CreateArchiveRule.md "../../../access-analyzer/latest/APIReference/API_CreateArchiveRule.md")), update an archive rule ([`UpdateArchiveRule`](../../../access-analyzer/latest/APIReference/API_UpdateArchiveRule.md "../../../access-analyzer/latest/APIReference/API_UpdateArchiveRule.md")), retrieve a list of findings ([`ListFindings`](../../../access-analyzer/latest/APIReference/API_ListFindings.md "../../../access-analyzer/latest/APIReference/API_ListFindings.md") and [`ListFindingsV2`](../../../access-analyzer/latest/APIReference/API_ListFindingsV2.md "../../../access-analyzer/latest/APIReference/API_ListFindingsV2.md")), or retrieve a list of access preview findings
for a resource ([`ListAccessPreviewFindings`](../../../access-analyzer/latest/APIReference/API_ListAccessPreviewFindings.md "../../../access-analyzer/latest/APIReference/API_ListAccessPreviewFindings.md")). There is no difference between
using IAM API and CloudFormation for configuring archive rules.
