# Work with Amazon ElastiCache using agent skills

The [Amazon ElastiCache skill in the AWS Agent Toolkit](https://github.com/aws/agent-toolkit-for-aws/tree/main/skills/specialized-skills/database-skills/amazon-elasticache "https://github.com/aws/agent-toolkit-for-aws/tree/main/skills/specialized-skills/database-skills/amazon-elasticache")
helps AI coding agents evaluate, create, connect, and operate ElastiCache workloads. Use the skill
when you are using agent-assisted coding tools to work with ElastiCache for Valkey, Redis OSS, or
Memcached workloads. The ElastiCache skill provides service-specific instructions, reference material,
and safety checks to guide agents through the full ElastiCache lifecycle, from setup and data modeling
to vector search and monitoring. The skill helps an AI coding agent achieve better task
completion on ElastiCache tasks.

The skill covers use-cases like application caching, session storage, rate limiting,
leaderboards, pub/sub, streams, durable caching, semantic caching for Agentic AI, AI agent
memory, retrieval augmented generation, and vector search.
