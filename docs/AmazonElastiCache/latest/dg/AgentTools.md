# Agent tools for ElastiCache

AI coding agents can use ElastiCache through purpose-built integrations from the AWS Agent Toolkit.
These integrations provide service-specific guidance, reference material, and safety checks so an
agent can evaluate, create, connect to, and operate ElastiCache workloads correctly.

This section covers the available agent tools and how to set them up.
