# Organize

an AWS DeepRacer community race

_Community races_ are races organized by AWS DeepRacer users who are not officially
sponsored by AWS.

You can create your own community race and invite your colleagues, classmates, or friends by sharing a race invitation
link.

If you want to organize a race for students, see the [Educator tools for AWS DeepRacer Student](educator.md "educator.md").
