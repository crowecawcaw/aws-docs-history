# Document history for the AWS DeepRacer Developer Guide

The following table describes the important changes to the documentation since the last
release of AWS DeepRacer.

| Change                                                                                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Date              |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------- |
| Updates for the 2023 AWS DeepRacer League                                                      | Updated multiple topics that reference the AWS DeepRacer League. For more information about the 2023 AWS DeepRacer League season, see the [terms and conditions](https://aws.amazon.com/deepracer/league/ "https://aws.amazon.com/deepracer/league/").                                                                                                                                                                                                                   | March 1, 2023     |
| Train and Evaluate AWS DeepRacer Models Using SageMaker AI Notebooks topic removed temporarily | The topic, Train and Evaluate AWS DeepRacer Models Using SageMaker AI Notebooks, was removed from<br>[Train and evaluate AWS DeepRacer models](create-deepracer-project.md "create-deepracer-project.md"). Currently, the procedures for using an AWS SageMaker AI notebook with AWS DeepRacer<br>are being updated.                                                                                                                                                     | November 1, 2022  |
| Updates to IAM managed policies for multi-user feature                                         | New managed policies, `AWSDeepRacerAccountAdminAccess` and<br>`AWSDeepRacerDefaultMultiUserAccess`, added so you can sponsor multiple<br>participants under one AWS DeepRacer account using multi-user mode, see [AWSDeepRacerAccountAdminAccess managed policy for<br>AWS DeepRacer administrators](security-iam-awsmanpol.md#security-iam-awsmanpol-AWSDeepRacerAccountAdminAccess "security-iam-awsmanpol.md#security-iam-awsmanpol-AWSDeepRacerAccountAdminAccess"). | October 26, 2021  |
| Updates for multi-user feature                                                                 | AWS DeepRacer now supports the multi-user feature which allows one AWS account to<br>sponsor multiple participants to race and train. For more information, see [Multi-user mode](multi-user-mode.md "multi-user-mode.md").                                                                                                                                                                                                                                              | October 26, 2021  |
| Updates for multi-vehicle racing and obstacle avoidance                                        | AWS DeepRacer now supports new sensor types of stereo camera and LIDAR that allows<br>multi-vehicle racing and obstacle avoidance. For more information, see [Understanding racing types and enabling sensors<br>supported by AWS DeepRacer](deepracer-choose-race-type.md "deepracer-choose-race-type.md").                                                                                                                                                             | December 2, 2019  |
| Updates for community races                                                                    | AWS DeepRacer now allows AWS DeepRacer users to organize their own racing events, known as<br>community races, with private leaderboards open to invited users only. For more<br>information, see [Join an AWS DeepRacer race](deepracer-racing-series.md "deepracer-racing-series.md").                                                                                                                                                                                 | December 2, 2019  |
| Updates for general availability                                                               | AWS DeepRacer now features more robust methods to train and evaluate deep learning<br>models. The user interface is updated and explained. More options and precise<br>data is available to build your own physical tracks. Troubleshooting information<br>is available.                                                                                                                                                                                                 | April 29, 2019    |
| Initial release AWS DeepRacer Developer Guide                                                  | Initial release of the documentation to help the AWS DeepRacer user to learn<br>reinforcement learning and explore its applications for autonomous racing, using<br>the AWS DeepRacer console, the AWS DeepRacer simulator, and a AWS DeepRacer scale model vehicle.                                                                                                                                                                                                     | November 28, 2018 |
