# Troubleshoot issues when sending from Kinesis Agent

This table provides troubleshooting information and solutions for common issues faced
when using the Amazon Kinesis Agent.

| Issue                                                                                 | Solution                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Why does Kinesis Agent not work on Windows?                                           | [Kinesis Agent for Windows](../../../kinesis-agent-windows/latest/userguide/what-is-kinesis-agent-windows.md "../../../kinesis-agent-windows/latest/userguide/what-is-kinesis-agent-windows.md") is different software than<br>Kinesis Agent for Linux platforms.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Why is Kinesis Agent slowing down and/or<br>`RecordSendErrors` increasing?            | This is usually due to throttling from Kinesis. Check the<br>`WriteProvisionedThroughputExceeded` metric for Kinesis Data Streams<br>or the `ThrottledRecords` metric for Firehose streams. Any<br>increase from 0 in these metrics indicates that the stream limits<br>need to be increased. For more information, see [Kinesis<br>Data Stream limits](../../../streams/latest/dev/service-sizes-and-limits.md "../../../streams/latest/dev/service-sizes-and-limits.md") and [Firehose streams](limits.md "limits.md").<br>Once you rule out throttling, see if the Kinesis Agent is<br>configured to tail a large amount of small files. There is a delay<br>when Kinesis Agent tails a new file, so Kinesis Agent should be<br>tailing a small amount of larger files. Try consolidating your log<br>files into larger files. |
| How to resolve the `java.lang.OutOfMemoryError`<br>exceptions?                        | This happends when Kinesis Agent does not have enough memory to<br>handle its current workload. Try increasing `JAVA_START_HEAP`<br>and `JAVA_MAX_HEAP` in<br>`/usr/bin/start-aws-kinesis-agent` and restarting the<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| How to resolve the `IllegalStateException : connection pool shut<br>down` exceptions? | Kinesis Agent does not have enough connections to handle its current<br>workload. Try increasing `maxConnections` and<br>`maxSendingThreads` in your general agent configuration<br>settings at `/etc/aws-kinesis/agent.json`. The default value<br>for these fields is 12 times the runtime processors available. See<br>[AgentConfiguration.java](https://github.com/awslabs/amazon-kinesis-agent/blob/master/src/com/amazon/kinesis/streaming/agent/config/AgentConfiguration.java "https://github.com/awslabs/amazon-kinesis-agent/blob/master/src/com/amazon/kinesis/streaming/agent/config/AgentConfiguration.java") for more about advanced agent<br>configurations settings.                                                                                                                                              |
| How can I debug another issue with Kinesis Agent?                                     | `DEBUG` level logs can be enabled in<br>`/etc/aws-kinesis/log4j.xml` .                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| How should I configure Kinesis Agent?                                                 | The smaller the `maxBufferSizeBytes`, the more frequently<br>Kinesis Agent will send data. This can be good as it decreases delivery<br>time of records, but it also increases the requests per second to<br>Kinesis.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Why is Kinesis Agent sending duplicate records?                                       | This occurs due to a misconfiguration in file tailing. Make sure that<br>each `fileFlow’s filePattern` is only matching one file. This<br>can also occur if the `logrotate` mode being used is in<br>`copytruncate` mode. Try changing the mode to the default<br>or create mode to avoid duplication. For more information on handling<br>duplicate records, see [Handling Duplicate Records](../../../streams/latest/dev/kinesis-record-processor-duplicates.md "../../../streams/latest/dev/kinesis-record-processor-duplicates.md").                                                                                                                                                                                                                                                                                          |
