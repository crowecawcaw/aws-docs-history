# Publish a selection in your private re:Post
<a name="publish-selection"></a>

Follow these steps to publish a selection in your private re:Post:

1. From any page in your private re:Post application, choose **Post content**. Then, choose **Create selection**.

   -or-

   From any page in your private re:Post application, choose **Create selection**.

1. On the **Create a draft** page, for **Selection title**, enter a title.

1. For **Selection description**, enter a description.

1. For **Short description**, enter a meta title.

   In this field, include a few words to briefly describe the selection to improve search engine optimization.

1. For **Channel**, select the channel where you want to publish the selection. If you don't want to select a specific channel, select **Default**.

   You don't see this option if you aren't a user in any channel within your private re:Post.

1. For **Your organization-specific tags**, select custom tags that apply to the selection.

1. For **AWS Tags**, select up to five tags that apply to the selection.

1. For **Title image**, upload a cover image that describes the selection. The maximum size for the title image 2 MiB. The supported file types are jpg, .peg, and .png.

1. In the **Content** section, for **Title**, enter a title for your first section.

1. For **Description**, enter a description for your section.

1. For each resource that you want to add to the selection, choose **Add link**.

1. Complete the following steps for each link that you add:

   For **Add a link**, enter the link for the resource. The **Title** field is auto populated.

   (Optional) For **Description**, enter a short description.

   (Optional) For **Add image**, upload a cover image that describes the resource. The maximum size of the cover image is 2 MiB. The supported file types are .jpg, .peg, and .png.

1. (Optional) Choose **Add body** to include text and in-line images for the section.

1. To add another section, choose **Add another section**. Repeat steps 7 to 11.

1. Choose **Create draft**.

1. To edit your selection draft, choose **Edit**.

1. Choose **Publish**.

Your selection is published under the **Selections** tab.
