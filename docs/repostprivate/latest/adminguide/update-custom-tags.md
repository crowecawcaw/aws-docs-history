# Update custom tags in your

private re:Post

As an AWS re:Post Private administrator, you can update the custom tags in your
private re:Post.

Follow these steps to update the tags in your private re:Post:

1. In your re:Post Private web application, choose your profile, and then choose **Administration**.
2. Choose **Content classification**.
3. From the list, select the tag that you want to update.
4. Choose **Edit tag**.
5. In the **Edit tag** dialog box, delete the existing tag, and then enter the new tag. Then, choose **Save changes**.

###### Note

    * You can't start the tags with `AWS` or
     `Amazon`.
    * You can't enter duplicate tags.

The updated tags are displayed under the **Tags** section.
