# Add users to a group in your private re:Post
<a name="add-users-to-groups"></a>

Use IAM Identity Center to add new users to an existing group in your private re:Post. For more information, see [Add users to groups](https://docs.aws.amazon.com/singlesignon/latest/userguide/adduserstogroups.html) in the *AWS IAM Identity Center User Guide*.
