# Customize your private re:Post

You can add one or more administrators to your private re:Post after you create it. Administrators use the re:Post Private application to launch the private re:Post and manage users within it. They can customize branding for the private re:Post, add tags to classify content, and select topics of interest for automatic population of content. For more information, see [AWS re:Post Private Administration Guide](../adminguide/what-is.md "../adminguide/what-is.md").
