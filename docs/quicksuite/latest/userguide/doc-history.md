# Document history for the Amazon Quick Suite User Guide

This page describes changes to the _Quick Suite User Guide_. For
notifications about these documentation changes, subscribe to the RSS feed using the link
near the top of this page.

To find out what's new in Quick Suite, see [What's New with Analytics](https://aws.amazon.com/about-aws/whats-new/analytics/?whats-new-content.sort-by=item.additionalFields.postDateTime&whats-new-content.sort-order=desc&awsf.whats-new-products=general-products%23amazon-quicksight "https://aws.amazon.com/about-aws/whats-new/analytics/?whats-new-content.sort-by=item.additionalFields.postDateTime&whats-new-content.sort-order=desc&awsf.whats-new-products=general-products%23amazon-quicksight"). To find out about changes to the Quick Suite
service, sign up for the [Quick Suite newsletter](https://pages.awscloud.com/NewsletterSignup.html "https://pages.awscloud.com/NewsletterSignup.html").

New Amazon Quick Suite releases appear in different AWS Regions over a period of time,
beginning with the first Region on the initial release date. Documentation is released in
coordination with this process. If you have questions, contact [AWS Support](https://aws.amazon.com//premiumsupport/ "https://aws.amazon.com//premiumsupport/") or your technical account
manager.
