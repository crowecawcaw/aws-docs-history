# Get started with Generative BI

To get started with Quick Sight Generative BI capabilities, upgrade your
account's users to Admin Pro, Author Pro, or Reader Pro roles. Pro roles grant
users access to all Generative BI capabilities that are relevant to the role that's
assigned to the user. Pro users can share generative Q&A topics with another user. To
understand which Generative BI capabilities are available to the different user roles in
Quick Suite, see the table below.
To understand how subscription names map to user
roles, see [Understanding Amazon Quick Suite subscriptions and
roles](../../../quicksight/latest/user/user-types.md#subscription-role-mapping "../../../quicksight/latest/user/user-types.md#subscription-role-mapping").

###### Note

Non-Pro Authors and Readers can still access Generative Q&A topics if an
Author Pro or Admin Pro user shares the topic with them. Non-Pro Authors and Readers
can also access data stories if a Reader Pro, Author Pro, or Admin Pro shares one
with them.

Any Quick Suite administrator can upgrade a user to a Pro role with the
following procedure.

###### To upgrade a user to a Pro role

1. Open the [Quick Suite console](https://quicksight.aws.amazon.com/ "https://quicksight.aws.amazon.com/").
2. Choose the user icon at the top right, and then choose **Manage
   Quick Suite**.
3. Choose **Manage users** to open the **Manage
   Users** page.
4. To change the role of an existing user, locate that user on the
   **Manage Users** table and choose the role that you want to
   grant them from the **Role** dropdown.
   For more information about managing Quick Suite users, see [Managing user access inside Amazon Quick Suite](managing-users.md "managing-users.md").
