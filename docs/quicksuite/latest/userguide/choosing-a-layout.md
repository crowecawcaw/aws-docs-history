# Choosing a layout

###### To change a dashboard's layout

1. Open the [Quick Suite console](https://quicksight.aws.amazon.com/ "https://quicksight.aws.amazon.com/").
2. From the Quick Suite homepage, choose **Analyses**,
   and then choose the analysis that you want to change.
3. On the analysis page, choose **Edit** and then choose
   **Analysis Settings**.
4. Expand **Sheet layout** and choose the layout that you
   want to use.
5. When finished, choose **Apply**.
