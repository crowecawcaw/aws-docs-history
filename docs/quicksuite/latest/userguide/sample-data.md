# Sample data

To get a first look at how Amazon Quick Sight works, you can explore Amazon Quick Sight using the
following sample data:

- [B2b sales data](samples/b2b-sales.csv.md "samples/b2b-sales.csv.md")
- [Business overview
  data](samples/business-overview.csv.md "samples/business-overview.csv.md") (revenue)
- [ML insights data](samples/ml-insights.csv.md "samples/ml-insights.csv.md")
- [People overview data](samples/people-overview.csv.md "samples/people-overview.csv.md")
  (human resources)
- [Sales pipeline
  data](samples/sales-pipeline.csv.md "samples/sales-pipeline.csv.md")
- [Web and social media
  analytics data](samples/web-and-social-analytics.csv.md "samples/web-and-social-analytics.csv.md") (marketing)
  Also, a variety of datasets are available free online that you can use with
  Amazon Quick Sight, for example the [AWS
  public datasets](https://aws.amazon.com/public-datasets/ "https://aws.amazon.com/public-datasets/"). These datasets come in a variety of formats.
