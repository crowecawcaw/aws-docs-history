# Excluding visual elements

When viewing visuals, you can choose an element on the visual, and then choose
to focus on the element. Elements to focus on can include, for example, a bar or
bubble, or a row or column header in the case of a pivot table. The exception is
that you can't exclude elements that are mapped to date fields. You can
exclude multiple elements on a single chart.

Excluding the element creates a filter that removes only that element from the
visual.

To see the excluded element again, you can either choose
**Undo** on the application bar, or you can disable or
delete the filter.

For more information about filters, see [Filtering data in Amazon Quick Sight](adding-a-filter.md "adding-a-filter.md").
