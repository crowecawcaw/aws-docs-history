# Data tables

- **Sort table** - Orders a table by a column. Used to organize your data in ascending or descending order.
- **Filter table** - Keeps rows matching a criteria. Used to extract relevant rows from a larger data set.
- **Lookup value** - Searches a value in a table. Used to lookup a value in one column and get the corresponding value from another column in the same row.
- **Add columns** - Creates new columns in a table. Newly added columns are appended to the end of the existing table.
- **Remove columns** - Deletes columns from a table. Outputs a table with all of the remaining columns.
- **Keep columns** - Drops extra columns from a table. Used to select a specific subset of columns you want to keep.
- **Add new row** - Appends a new row to a table. The new row can be created with specific values or as a blank row and will be added to the bottom of the table.
- **Remove rows** - Deletes rows from a table. Outputs a table with all of the remaining rows.
- **Remove duplicates** - Deletes duplicate rows. Used to create a dataset of unique rows based on specific columns.
- **Append tables** - Combines the rows of two tables. Used to add data from one table to another.
- **Create new table** - Creates an empty table. Used to set up a table with required columns to add rows to in subsequent steps. The new table will have no rows.
- **Convert text to table** - Creates a table from text. Used to convert delimited text such as comma-separated values into a table.
- **Convert table to HTML** - Creates an HTML formatted table. Used to output your table as formatted text for a document, email, and more.
