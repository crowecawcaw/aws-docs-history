# Use a chat agent

You can use a Amazon Quick Suite chat agent to ask questions and to accomplish your tasks.
When you ask a question, the chat agent analyzes the latest approved data shared with
you to generate a comprehensive response.

You can ask complex questions in plain language and get a detailed response. You can
also use a Quick Suite chat agent to perform tasks for you, such as draft an email
message, create a ticket, or use flows.

###### To use custom chat agents

1. Log in to the Quick Suite console.
2. From the left navigation menu, select **Chat agents**
3. Then, from the **Actions** column for the chat agent you want
   to share, select the menu icon, and then select
   **Chat**.

This will open a chat interface that you use to interact with your chat
agent.
You can interact with a chat agent in the following ways:

- View and access example prompts to demonstrate possible questions and
  tasks
- Get contextual responses from organizational data sources
- Continue or start new conversations
- Analyze data, including summarization and comparative analysis
- Take actions like scheduling meetings and creating tickets
- View source citations to responses with clickable numbered references
- Upload files
- View conversation history
