# Using the Amazon Quick Sight Embedding SDK to

enable shareable links to embedded dashboard views

Amazon Quick Sight developers can use the Amazon Quick Sight Embedding SDK (version 2.8.0
and higher) to allow readers of embedded dashboards to receive and distribute
shareable links to their view of an embedded dashboard. Developers can use dashboard
or console embedding to generate a shareable link to their application page with
Amazon Quick Sight's reference encapsulated using the Amazon Quick Sight
Embedding SDK. Amazon Quick Sight Readers can then send this shareable link to their
peers. When their peer accesses the shared link, they are taken to the page on the
application that contains the embedded Amazon Quick Sight dashboard. Developers can
also generate and save shareable links of dashboard views that can be used as a
bookmarks for anonymous readers of Amazon Quick Sight when using anonymous
embedding.

**Prerequisites**

Before you get started, make sure that you are using the Amazon Quick Sight
Embedding SDK version 2.8.0 or higher
