# Adding themes and animations to a data

story in Amazon Quick Sight

You can add themes and animations to the stories that you generate. To add a theme or
animation to a data story, choose the **Story style** icon.

In the **Story style** pane that appears, you can perform the
following actions:

- For **THEMES**, choose a theme that you think best fits your
  data story.
- For **ANIMATIONS**, choose an animation style and speed. For
  animation types, you can choose **None**,
  **Fade**, or **Slide**. The default
  animation is **None**. For **Speed**, choose
  **Slow**, **Medium**, or
  **Fast**. The default speed is
  **Medium**.
