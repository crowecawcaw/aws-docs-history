# Add system parameters

to repeating sections

You can use text boxes to add system parameters to your paginated
report's repeating section. This makes it possible to access dimensions
that have been used to configure repeating sections. Repeating sections and
dimensions need to be configured before you can access the dimensions in a
text box. The system parameters can only be used within a repeating
section.

###### To add system parameters to a repeating section from a text

box

1. Choose the text box visual that you want, and then choose the
   **System parameters** icon in the far right of
   the text box toolbar.
2. From the dropdown that appears, choose the parameter that you
   want.
