# Add page breaks to

repeating sections

Similar to section page breaks, you can add page breaks to repeating
sections.

###### To add a page break to a repeating section

1. Navigate to the section that contains the repeating behavior that
   you want to change and choose the **Edit repeating
   section** (triple panel) icon.
2. In the **Repeating** tab of the **Edit
   section** pane that appears, check the box titled
   **Page break after each instance**.
   An instance is defined as a distinct value of a dimension or a unique
   combination of values of multipledimensions. If you clear the **Page
   break after each instance** checkbox, the page break is
   removed.
