# Viewing visual details

When viewing a visual, you can hover your cursor over any graphical element to
get details on that element. For example, when you hover over a single bar on a
bar chart, information about that specific bar displays in a tooltip.

![](../images/bar-detail.png)
Hovering your cursor over a single data point on a scatter plot also displays
information about that specific data point.

![](../images/scatter-plot-detail.png)
You can customize the information that appears when you hover your cursor over
data in a chart. For more information, see [Tooltips](customizing-visual-tooltips.md "customizing-visual-tooltips.md").
