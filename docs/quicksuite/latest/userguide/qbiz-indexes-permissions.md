# Setting up permissions

To use Amazon Q Business indexes in Amazon Quick Suite, you need to set up the appropriate permissions:

1. Sign in to the Amazon Quick Suite console as an administrator.
2. Navigate to the **Admin** section.
3. Select **AWS Resources**.
4. Choose **Amazon Q Business** from the list of available data sources.
5. Enable permissions for Amazon Quick Suite to access Amazon Q Business indexes in your AWS account.
   Once permissions are set up, Amazon Q Business becomes available as a data source in Amazon Quick Suite, and Author users can create knowledge bases from Amazon Q Business indexes.
