# Managing user access inside Amazon Quick Suite

|                                                                                 |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Intended audience: System administrators and Amazon Quick Suite administrators  | Amazon Quick Suite administrators manage user access in Quick Suite. User access management in Quick Suite is determined by your Quick Suite account identity configuration. For accounts that use IAM Identity Center or Active Directory, groups are assigned to Quick Suite roles. Groups can be assigned the Admin, Author, Reader, Admin Pro, Author Pro, or Reader Pro roles. For more information about Pro roles in Quick Suite see [Get started with Generative BI](../../../quicksight/latest/user/generative-bi-get-started.md "../../../quicksight/latest/user/generative-bi-get-started.md"). Note that Reader Pro maps to Amazon Quick Suite Professional subscription and Author Pro maps to Amazon Quick Suite Enterprise subscription. For more information about integrating your Amazon Quick Suite account with IAM Identity Center, see [Managing access for IAM Identity Center users](../../../quicksight/latest/user/managing-user-access-idc.md "../../../quicksight/latest/user/managing-user-access-idc.md"). To understand how subscription names relate to user roles and their capabilities, see [Understanding Amazon Quick Suite subscriptions and roles](user-types.md "user-types.md"). Amazon Quick Suite accounts that use Quick Suite and IAM users create users directly in Quick Suite. These users and their roles are managed at the user level. For more details, see [Managing access for Quick Suite and IAM users](../../../quicksight/latest/user/managing-user-access-qs-iam.md "../../../quicksight/latest/user/managing-user-access-qs-iam.md"). ###### Topics <br>• [Managing access for IAM Identity Center users](managing-user-access-idc.md "managing-user-access-idc.md") <br>• [Managing access for Amazon Quick Suite and IAM users](managing-user-access-qs-iam.md "managing-user-access-qs-iam.md") |
