control sign-up for users when you set up an Amazon Quick Suite instance.

an AWS account, signing up for an Amazon Quick Suite subscription, and signing in to
Amazon Quick Suite, see [Setting up and signing into Amazon Quick Suite](setting-up.md "setting-up.md").
