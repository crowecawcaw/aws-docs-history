

# Update AWS Regions for an account in AWS Organizations
<a name="orgs_manage_accounts_update_enabled_regions"></a>

You can update enabled AWS Regions for accounts within your organization using the AWS Organizations console. To learn how to update enabled AWS Regions, see [Enable or disable AWS Regions in your account](https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-regions.html) in the * AWS Account Management Reference*.
