# Logging and monitoring in AWS Organizations

As a best practice, you should monitor your organization to ensure that changes are
logged. This helps you to ensure that any unexpected change can be investigated and unwanted
changes can be rolled back. AWS Organizations currently supports two AWS services that enable you
to monitor your organization and the activity that happens within it.
