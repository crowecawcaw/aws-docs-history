# Update the alternate contacts for an account in AWS Organizations

You can update alternate contacts for accounts within your organization using the AWS
Organizations console, or programmatically using the AWS CLI or AWS SDKs. To learn how to update
alternate contacts, see [Update the alternate contacts for any AWS account in your organization](../../../accounts/latest/reference/manage-acct-update-contact-alternate.md#manage-acct-update-contact-alternate-orgs.html "../../../accounts/latest/reference/manage-acct-update-contact-alternate.md#manage-acct-update-contact-alternate-orgs.html") in the _AWS Account Management
Reference_.
