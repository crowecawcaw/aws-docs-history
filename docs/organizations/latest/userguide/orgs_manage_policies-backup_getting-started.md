# Getting started with

backup policies

Follow these steps to get started using backup policies.

1. [Learn about the
   permissions you must have to perform backup policy tasks](orgs_manage_policies_prereqs.md "orgs_manage_policies_prereqs.md").
2. [Learn about some
   best practices we recommend when using backup policies](orgs_manage_policies_backup_best-practices.md "orgs_manage_policies_backup_best-practices.md").
3. [Enable backup policies for
   your organization](enable-policy-type.md "enable-policy-type.md").
4. [Create a backup
   policy](orgs_policies_create.md#create-backup-policy-procedure "orgs_policies_create.md#create-backup-policy-procedure").
5. [Attach the backup policy to
   your organization's root, OU, or account](orgs_policies_attach.md "orgs_policies_attach.md").
6. [View the combined
   effective backup policy that applies to an account](orgs_manage_policies_effective.md "orgs_manage_policies_effective.md").
   For all of these steps, you sign in as an IAM user, assume an IAM role, or sign in
   as the root user ([not recommended](../../../IAM/latest/UserGuide/best-practices.md#lock-away-credentials "../../../IAM/latest/UserGuide/best-practices.md#lock-away-credentials")) in the organization's management account.
