# Using tags

Tags help you to organize resources in your organization by enabling you to group them by whatever
categories are useful to you. For example, you can assign a "Department" tag that tracks
the owning department. You can assign an "Environment" tag to track whether a given
resource is part of your alpha, beta, gamma, or production environments.

You can also use tags to:

- [Enforce tagging standards on your
  resources](orgs_manage_policies_tag-policies.md#what-are-tag-policies "orgs_manage_policies_tag-policies.md#what-are-tag-policies").
- [Control who can access your
  resources](orgs_tagging_abac.md "orgs_tagging_abac.md").
