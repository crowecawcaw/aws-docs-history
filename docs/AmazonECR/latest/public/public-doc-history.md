# Document history

The following table describes the important changes to the documentation since the last
release of Amazon ECR Public. We also update the documentation frequently to address the feedback
that you send us.

| Change                                     | Description                                                                                                                                                                                                                                                          | Date          |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| IPv6 support                               | Added support for making requests to Amazon ECR Public registries using both<br>IPv4-only and dual-stack (IPv4 and IPv6) endpoints. For more<br>information, see [Making requests to Amazon ECR Public registries](public-ecr-requests.md "public-ecr-requests.md"). | 30 April 2025 |
| AWS Managed Policies for Amazon ECR Public | Amazon ECR Public added documentation of AWS managed policies. For more<br>information, see [AWS managed policies for Amazon ECR Public](public-security-iam-awsmanpol.md "public-security-iam-awsmanpol.md").                                                       | 24 June 2021  |
| Tagging support                            | Added support for tagging your public repositories. For more<br>information, see [Tag an Amazon ECR Public repository](ecr-public-using-tags.md "ecr-public-using-tags.md").                                                                                         | 24 Feb 2021   |
| Amazon ECR Public general availability     | Amazon Elastic Container Registry Public is a public AWS container image registry service<br>that is secure, scalable, and reliable.                                                                                                                                 | 1 Dec 2020    |
