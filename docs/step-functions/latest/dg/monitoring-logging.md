# Logging and monitoring AWS Step Functions service performance

Learn how to log and monitor Step Functions to maintain the reliability, availability, and
performance of Step Functions and your AWS solutions.

There are several tools available
to use with Step Functions:

###### Topics

- [Metrics in CloudWatch](procedure-cw-metrics.md "procedure-cw-metrics.md")
- [Automate event delivery](eventbridge-integration.md "eventbridge-integration.md")
- [API calls in CloudTrail](procedure-cloud-trail.md "procedure-cloud-trail.md")
- [Logging in CloudWatch Logs](cw-logs.md "cw-logs.md")
- [Trace data in X-Ray](concepts-xray-tracing.md "concepts-xray-tracing.md")
- [Events using User Notifications](using-user-notifications-sfn.md "using-user-notifications-sfn.md")

###### Tip

To deploy a sample workflow and learn how to monitor metrics, logs, and traces of the workflow execution, see [Adding observability](https://catalog.workshops.aws/stepfunctions/adding-observability "https://catalog.workshops.aws/stepfunctions/adding-observability") in _The AWS Step Functions Workshop_.
