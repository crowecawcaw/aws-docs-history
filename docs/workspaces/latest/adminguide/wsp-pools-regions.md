WorkSpaces Pools

###### Note

For the AWS Regions that apply to WorkSpaces Personal, see [Amazon WorkSpaces endpoints and quotas](../../../general/latest/gr/wsp.md "../../../general/latest/gr/wsp.md") in the
_AWS General Reference Reference guide_.
