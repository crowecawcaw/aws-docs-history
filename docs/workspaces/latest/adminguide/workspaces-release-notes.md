# DCV host agent versions in WorkSpaces Personal

DCV host agent is a host agent that runs inside your WorkSpace. It streams the pixels of
your WorkSpace to a client application and includes in-session features, such as two-way audio
and video, and printing. For more information about DCV, see [Protocols for Amazon WorkSpaces](amazon-workspaces-protocols.md "amazon-workspaces-protocols.md").

We recommend keeping your host agent software updated with the latest version. You can
manually reboot your WorkSpaces to update the DCV host agent. The DCV host agent is also updated
automatically during the regular WorkSpaces default maintenance window. For more information about
maintenance windows, see [WorkSpace maintenance](workspace-maintenance.md "workspace-maintenance.md"). Some of these features require the latest WorkSpaces client version.
For more information about the latest client versions, see
[WorkSpaces Clients](../userguide/amazon-workspaces-clients.md "../userguide/amazon-workspaces-clients.md").
