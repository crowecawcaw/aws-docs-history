# Delete a pool

You can delete pools to free up resources and to avoid unintended charges to your
account. We recommend stopping any unused, running pools.

###### To delete a pool

1. In the navigation pane, choose **WorkSpaces**,
   **Pools**.
2. Select the pool that you want to stop, and then choose
   **Stop**. It takes about 5 minutes to stop a pool.
3. When the status of the pool is **Stopped**, choose
   **Delete**.
