# USB redirection for WorkSpaces

Universal Serial Bus (USB) redirection enables access to local USB devices within
your virtual desktop environment. USB redirection is supported on both PCoIP and DCV-based WorkSpaces.
The implementation varies depending on the protocol used by your WorkSpace.
