# WorkSpaces clients

You can connect to your WorkSpace using the client application for a supported device or a web browser.
To start using your WorkSpace, see [Getting started with your WorkSpace](workspaces-user-getting-started.md "workspaces-user-getting-started.md").

###### Important

WorkSpaces Pool is supported only on the macOS, Web Access, and Windows
client Application version 5.20.0 or greater.
