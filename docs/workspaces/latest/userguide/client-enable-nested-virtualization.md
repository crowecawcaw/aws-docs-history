

# Enabling nested virtualization

With nested virtualization, you can run a virtual machine inside your WorkSpace. Your administrator must make nested virtualization available to you as a self-service capability. When it's available, you can enable or disable it yourself from the WorkSpaces client.

**Important**  
This feature requires the WorkSpaces Windows client, version 5.37 or later.
You must be using the New Client Experience. For more information about the Windows client, see [WorkSpaces Windows client application](amazon-workspaces-windows-client.md).

**To enable or disable nested virtualization**

1. Choose the WorkSpaces logo from the menu bar.

1. Choose **My WorkSpace**.

1. Choose **Manage nested virtualization**.

1. Choose **Enable** or **Disable**.

1. Choose **Apply**.

1. Wait a few minutes as your WorkSpace reboots to apply the change.
