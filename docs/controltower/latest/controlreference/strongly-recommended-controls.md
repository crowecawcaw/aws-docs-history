# Strongly recommended

controls

Strongly recommended controls are owned by AWS Control Tower. They are based on best
practices for well-architected multi-account environments. These controls are
not enabled by default, and they can be deactivated through the AWS Control Tower console
or the control APIs. Following, you'll find a reference for each of the strongly
recommended controls available in AWS Control Tower.
