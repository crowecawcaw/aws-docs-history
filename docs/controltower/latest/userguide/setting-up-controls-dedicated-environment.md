# Setting up your controls dedicated environment

With AWS Control Tower landing zone 4.0, you can now create a controls-only environment without implementing a full landing zone.
This deployment option is designed for customers who have an established AWS Organizations setup and want
to focus on adopting managed controls through the [The AWS Control Tower Control Catalog](../controlreference.md "../controlreference.md").
