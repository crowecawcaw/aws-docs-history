## Account Factory for Terraform (AFT) supports plan-only customization runs
<a name="aft-plan-only"></a>

**September 16, 2026**

(No update required for AWS Control Tower landing zone.)

The AWS Control Tower account customization framework, Account Factory for Terraform (AFT), now supports plan-only (read-only) customization runs. You can pass the `plan_only` input to the `aft-invoke-customizations` state machine to preview the Terraform changes an account would receive. This lets you review the changes without applying them. AFT runs `terraform plan` instead of `terraform apply` across all supported Terraform distributions. AFT can export the plan JSON output to an encrypted Amazon S3 bucket in the AFT management account. On the Community Edition (open source) distribution, AFT exports the output by default. On Terraform Cloud and Terraform Enterprise, export is opt-in through `aft_plan_output_export_enabled`, and you can also view results in the HCP Terraform run UI.

For more information, see [Account customizations](https://docs.aws.amazon.com/controltower/latest/userguide/aft-account-customization-options.html).

## AWS Control Tower available in the European Sovereign Cloud

AWS Control Tower is now available in the European Sovereign Cloud. For more information about AWS Control Tower in the European Sovereign Cloud, see the [AWS Control Tower User Guide for the European Sovereign Cloud](https://docs.aws.eu/esc/latest/userguide/controltower.html).
