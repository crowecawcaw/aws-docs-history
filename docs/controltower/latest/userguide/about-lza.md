# AWS Control Tower and Landing zone accelerator

This section describes the benefits of working with AWS Control Tower and the **Landing Zone Accelerator** (LZA) solution, together.

_You can customize your AWS Control Tower landing zone with Landing Zone Accelerator (LZA) on AWS ._

LZA is a solution that deploys a foundational set of capabilities designed to align with AWS best practices, and with multiple global compliance frameworks, to help you manage and govern a multi-account environment. LZA is built using the AWS Cloud Development Kit (CDK).

LZA automatically sets up a cloud environment that's suitable for hosting secure workloads. This solution can be deployed in all AWS Regions, to help you maintain consistency of operations and governance. The LZA solution is architected to align with AWS best practices, and to conform with multiple global compliance frameworks.

We recommend that you deploy AWS Control Tower as your foundational landing zone, and then enhance your landing zone capabilities with LZA, as needed. The combination of LZA and AWS Control Tower provides a comprehensive, no-code solution that helps you manage and govern a multi-account environment—it's built to support highly-regulated workloads and complex compliance requirements. Together, AWS Control Tower and the Landing Zone Accelerator help you establish platform readiness, including security, compliance, and operational capabilities.

Source code for LZA is available in a [GitHub repository](https://github.com/awslabs/landing-zone-accelerator-on-aws "https://github.com/awslabs/landing-zone-accelerator-on-aws").

For more information on how to combine LZA and AWS Control Tower, see [the LZA implementation guide](../../../solutions/latest/landing-zone-accelerator-on-aws/prerequisites.md "../../../solutions/latest/landing-zone-accelerator-on-aws/prerequisites.md").
