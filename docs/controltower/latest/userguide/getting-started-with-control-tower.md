# Getting started with AWS Control Tower

This getting started procedure is intended for AWS Control Tower administrators. Follow this
procedure when you're ready to set up your landing zone using the AWS Control Tower console or APIs.

If you are an AWS customer currently, but new to AWS Control Tower, you may wish to review the
section called [Plan your AWS Control Tower landing zone](planning-your-deployment.md "planning-your-deployment.md"), before you proceed.
