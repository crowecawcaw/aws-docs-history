# Edit user

settings

To change your user settings, perform the following steps.

1. From the left navigation pane of the Microservice Extractor tool, choose
   **Settings**.
2. On the **Settings** page, select
   **Edit**.
3. On the **Edit settings** page, you can update your
   **AWS named profile** and your **Microservice Extractor
   usage data sharing** option. You cannot change your working
   directory after your application is set up.
