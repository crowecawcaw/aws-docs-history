# Discovery Connector

###### Important

We recommend that customers who are currently using Discovery Connector transition to the new
Agentless Collector. Starting November 17, 2025, AWS Application Discovery Service will stop
accepting new data from Discovery Connectors.

This section describes how to transition from AWS Agentless Discovery Connector (Discovery Connector) to
Application Discovery Service Agentless Collector (Agentless Collector).

We recommend that customers who are currently using Discovery Connector transition to the new
Agentless Collector.

To learn how to start using Agentless Collector, see [Application Discovery Service Agentless Collector](agentless-collector.md "agentless-collector.md").

After you deploy the Agentless Collector, you can delete the Discovery Connector virtual
machine. All data previously collected will continue to be available in AWS Migration Hub
(Migration Hub).
