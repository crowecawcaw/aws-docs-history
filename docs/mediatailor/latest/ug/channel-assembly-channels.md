# Working with channels

A channel assembles your source manifests into a linear stream. Each channel contains one or
more outputs that correspond to your package configurations.

First you create a channel, then you add your VOD sources and live sources to the channel's
schedule by creating _programs_. Each program is associated with a VOD source
or a live source.
