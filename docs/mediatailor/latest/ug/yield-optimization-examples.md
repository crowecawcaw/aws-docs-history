

# Example templates
<a name="yield-optimization-examples"></a>

This page provides complete, working template configurations for common use cases. Each example includes the template JSON, required player parameters, and notes on what to customize.

**Note**  
Examples use placeholder values (for example, `com.example.myapp`, `your_aps_slot_id_here`) that will return HTTP 204 (no-bid) from APS. Replace all values with your real app bundle, store URL, APS slot ID, device user agent, and IP address to receive bid responses.
