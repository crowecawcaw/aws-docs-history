# Configuring Connector Settings (Jira Project Enablement and Request Type)

In addition to configuring AWS accounts, the AWS Service
Management Connector contains AWS services and UI settings
(AWS Service Catalog) that enable projects and configure AWS Systems Manager
OpsCenter.

###### Note

There are no per-account settings for AWS Config and AWS Systems Manager
Automation through the JSM Connector.
