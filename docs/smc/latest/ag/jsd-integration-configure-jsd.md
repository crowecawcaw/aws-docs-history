# Configuring Jira Service

Management

The AWS Service Management Connector for Jira
Service Management is a conventional Jira Service Management add-on.
Add-ons are code changes to the Jira software that extend its
functionality or extend the functionality of Jira Service Management
software. The Connector for Jira Service Management add-on is available to
download in the [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1221283/aws-service-catalog-connector-for-jsd "https://marketplace.atlassian.com/apps/1221283/aws-service-catalog-connector-for-jsd").
