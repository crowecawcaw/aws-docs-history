# Service management

alignment

This Connector aligns to industry best practices, such as ITIL®’s
service management areas by enabling tools (services) with the
intersection of people, processes and partners. The Connector also
addresses a baseline set of service management practices you can use in
existing operational tooling:

| Service management area                                         | AWS service(s) integration                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Service Catalog management deployment management (Provisioning) | [AWS Service Catalog](https://aws.amazon.com/servicecatalog/ "https://aws.amazon.com/servicecatalog/"), AWS CloudFormation, and AWS Systems Manager Automation requests and<br>provisions vetted and predictable products and performs<br>post-provision actions.                                                                                                                                                                                                                                                                                                           |
| Incident management (Ticketing)                                 | [Support](https://aws.amazon.com/premiumsupport/ "https://aws.amazon.com/premiumsupport/") (AWS services and platform incidents).<br>[AWS Systems Manager](https://aws.amazon.com/hsystems-manager/ "https://aws.amazon.com/hsystems-manager/") OpsCenter (Jira operational Issues derived and<br>detected for solutions built on AWS platform).<br>[AWS Security Hub](https://aws.amazon.com/security-hub/ "https://aws.amazon.com/security-hub/") (Jira Issues from security Findings).<br>AWS Systems Manager Incident Manager (AWS services and platform<br>incidents). |
| Service configuration management (CMDB)                         | [AWS Config](https://aws.amazon.com/config/ "https://aws.amazon.com/config/") (Track AWS resources related to the Jira<br>Issue).                                                                                                                                                                                                                                                                                                                                                                                                                                           |

In addition, [Atlassian Jira Service Management](https://www.atlassian.com/software/jira/service-management/features/service-desk "https://www.atlassian.com/software/jira/service-management/features/service-desk") (JSM) is service desk
software for modern IT teams. Jira Service Management request types enable
self-service for developers and end users to order IT services based on
request fulfillment approvals and workflows.
