# Installing AWS Service Management Connector

Learn how to install Service Management Connector in the Atlassian site.

1. Log in to your Atlassian site as an administrator.
2. Navigate to the **Settings** menu, and then
   choose **Apps**.
3. In the **Atlassian Marketplace menu**, choose
   **Find new Apps**.
4. Select **AWS Service Management Connector for Jira Service
   Management**, and then choose **Get App**.
