# Integrating AWS Systems Manager Incident Manager

To allow the Connector to synchronize Incidents from AWS Systems Manager Incident Manager for a
specific Region, you must enable Incident Manager in that account and Region.

For more information, refer to [What is AWS Systems Manager Incident Manager](../../../incident-manager/latest/userguide/what-is-incident-manager.md "../../../incident-manager/latest/userguide/what-is-incident-manager.md").
