# AWS Service Management Connector end of support

End of support notice: As of March 31, 2026, AWS Service Management Connector is no longer available to new
customers. If you are an existing customer, you can continue using the service until March 31, 2027. After March 31, 2027, you will no longer be able to access AWS Service Management Connector
functionality.

We recommend migrating to AWS Partner solutions or building direct SDK integrations.

## Migration options

AWS Partner solutions

Explore qualified partners through the [AWS Partner
Solution Finder](https://partners.amazonaws.com/ "https://partners.amazonaws.com/") to find partners with ServiceNow, Atlassian, and AWS integration
expertise.

Direct SDK Integration

Build native integrations using AWS SDKs and APIs for AWS Config, Service Catalog, Security Hub CSPM, Support, and
Systems Manager. For more information, see the following API documentation:

- [AWS Service Catalog
  API Reference](../../../servicecatalog/latest/dg/API_Reference.md "../../../servicecatalog/latest/dg/API_Reference.md")
- [AWS Config API
  Reference](../../../config/latest/APIReference/Welcome.md "../../../config/latest/APIReference/Welcome.md")
- [AWS Security Hub CSPM
  API Reference](../../../securityhub/1.0/APIReference/Welcome.md "../../../securityhub/1.0/APIReference/Welcome.md")
- [Support
  API Reference](../../../awssupport/latest/user/about-support-api.md "../../../awssupport/latest/user/about-support-api.md")
- [AWS Systems Manager API Reference](../../../systems-manager/latest/APIReference/Welcome.md "../../../systems-manager/latest/APIReference/Welcome.md")

AWS native alternatives

For Security Hub CSPM specifically, AWS provides native integrations with Jira Cloud and
ServiceNow:

- [Jira
  Cloud integration with AWS Security Hub](../../../securityhub/latest/userguide/jiracloud.md "../../../securityhub/latest/userguide/jiracloud.md")
- [ServiceNow integration with AWS Security Hub](../../../securityhub/latest/userguide/servicenow.md "../../../securityhub/latest/userguide/servicenow.md")

This change does not impact AWS Config, AWS Service Catalog, AWS Security Hub CSPM, Support, or AWS Systems Manager.
