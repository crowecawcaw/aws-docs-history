# Service management

alignment

This Connector aligns with industry best practices, such as ITIL
service management areas, and addresses a baseline set of service
management practices you can use in existing tools:

| Service management area                              | AWS service(s) integration                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Service Catalog deployment management (provisioning) | AWS Service Catalog or AWS CloudFormation: Requesting and provisioning<br>vetted or predictable products and performing post-provisioning<br>actions.<br>AWS Systems Manager Automation: Allows users to safely automate common<br>and repetitive tasks using a predefined or custom-built<br>automated runbacks. |
| Incident management (ticketing)                      | AWS Systems Manager Incident Manager: Generating incidents according to response<br>plans.<br>Support (AWS incidents, service requests, and support<br>cases).                                                                                                                                                    |
| Security event and incident management               | AWS Security Hub: Managing incidents resulting from security<br>findings.                                                                                                                                                                                                                                         |
