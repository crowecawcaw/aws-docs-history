# AWS Service Catalog in ServiceNow

After you create two IAM users with baseline permissions in each account, the next
step is to configure AWS Service Catalog.

Use the Amazon S3 template in [Creating an Amazon S3 Bucket for Website Hosting for your preliminary product](../../../AWSCloudFormation/latest/UserGuide/quickref-s3.md#scenario-s3-bucket-website "../../../AWSCloudFormation/latest/UserGuide/quickref-s3.md#scenario-s3-bucket-website").
Copy and save the Amazon S3 template to your device.

For an interactive workshop using ServiceNow,
review the [ServiceNow Connector workshop](https://catalog.us-east-1.prod.workshops.aws/workshops/d40750d7-a330-49be-9945-cde864610de9/en-US/5-itsm/getting-started "https://catalog.us-east-1.prod.workshops.aws/workshops/d40750d7-a330-49be-9945-cde864610de9/en-US/5-itsm/getting-started")
in the _AWS workshop studio_.
