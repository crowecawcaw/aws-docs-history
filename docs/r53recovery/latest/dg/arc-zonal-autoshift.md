# Canceling a practice run zonal shift

The steps in this section explain how to cancel a zonal shift on the ARC console.
To work with zonal shift and zonal autoshift programmatically, see the [Zonal Shift and Zonal Autoshift API Reference Guide](../../../arc-zonal-shift/latest/api/Welcome.md "../../../arc-zonal-shift/latest/api/Welcome.md").

You can cancel zonal shifts or practice runs that you initiate yourself. You can also cancel zonal shifts
that AWS starts for a resource for a practice run for zonal autoshift.

# To cancel a practice run zonal shift

1. Open the ARC console at [https://console.aws.amazon.com/route53recovery/zonalshift/home#/](https://console.aws.amazon.com/route53recovery/zonalshift/home#/ "https://console.aws.amazon.com/route53recovery/zonalshift/home#/").
2. Select a practice run zonal shift that you want to cancel, and then choose
   **Cancel zonal shift** or **Cancel practice
   run**.
3. On the confirmation modal dialog, choose **Confirm**.
