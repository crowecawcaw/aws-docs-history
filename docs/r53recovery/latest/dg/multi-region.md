# Use routing control to recover multi-Region applications in ARC

This section explains how to use the routing control capability in Amazon Application Recovery Controller (ARC) to minimize disruption and
help provide continuity for your users when you have an AWS application deployed in multiple AWS Regions.

You can also learn about readiness check, a capability in ARC that you can use to gain insights into whether your applications
and resources are prepared for recovery.

The topics in this section describe the routing control and readiness check capabilities, how to set them up,
and how to use them.
