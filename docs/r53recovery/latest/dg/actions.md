# Zonal shift API operations

The following table lists ARC API operations that you can use using zonal shift, which moves traffic away
from an Availability Zone for multi-AZ applications. The table also includes links to relevant documentation.

For examples of how to use common zonal shift API operations with the
AWS Command Line Interface, see [Examples of
using the AWS CLI with zonal shift](getting-started-cli-zonalshift.md "getting-started-cli-zonalshift.md").

| Action                 | Using the ARC console                                                                                                                          | Using the ARC API                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Start a zonal shift    | See [Starting a zonal shift](arc-zonal-shift.md#arc-zonal-shift.start "arc-zonal-shift.md#arc-zonal-shift.start")                              | See [StartZonalShift](../../../arc-zonal-shift/latest/api/API_StartZonalShift.md "../../../arc-zonal-shift/latest/api/API_StartZonalShift.md")                |
| Update a zonal shift   | See [Updating or canceling a zonal shift](arc-zonal-shift.md#arc-zonal-shift.update-cancel "arc-zonal-shift.md#arc-zonal-shift.update-cancel") | See [UpdateZonalShift](../../../arc-zonal-shift/latest/api/API_UpdateZonalShift.md "../../../arc-zonal-shift/latest/api/API_UpdateZonalShift.md")             |
| List zonal shifts      | See [Zonal shift in ARC](arc-zonal-shift.md "arc-zonal-shift.md")                                                                              | See [ListZonalShifts](../../../arc-zonal-shift/latest/api/API_ListZonalShifts.md "../../../arc-zonal-shift/latest/api/API_ListZonalShifts.md")                |
| List managed resources | See [Supported resources](arc-zonal-shift.md "arc-zonal-shift.md")                                                                             | See [ListManagedResources](../../../arc-zonal-shift/latest/api/API_ListManagedResources.md "../../../arc-zonal-shift/latest/api/API_ListManagedResources.md") |
| Get managed resource   | See [Supported resources](arc-zonal-shift.md "arc-zonal-shift.md")                                                                             | See [GetManagedResource](../../../arc-zonal-shift/latest/api/API_GetManagedResource.md "../../../arc-zonal-shift/latest/api/API_GetManagedResource.md")       |
| Cancel a zonal shift   | See [Updating or canceling a zonal shift](arc-zonal-shift.md#arc-zonal-shift.update-cancel "arc-zonal-shift.md#arc-zonal-shift.update-cancel") | See [CancelZonalShift](../../../arc-zonal-shift/latest/api/API_CancelZonalShift.md "../../../arc-zonal-shift/latest/api/API_CancelZonalShift.md")             |
