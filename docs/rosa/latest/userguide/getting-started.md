# Get started with ROSA

Red Hat OpenShift Service on AWS (ROSA) is a managed service that you can use to build, scale, and deploy containerized applications with the Red Hat OpenShift enterprise Kubernetes platform on AWS.

You can use the following guides to create your first ROSA cluster, grant user access, deploy your first application, and learn how to revoke user access and delete your cluster.

- [Create a ROSA with HCP cluster using the ROSA CLI](getting-started-hcp.md "getting-started-hcp.md") - Create your first ROSA with HCP cluster using AWS STS and the ROSA CLI.
- [Create a ROSA classic cluster that uses AWS PrivateLink](getting-started-classic-private-link.md "getting-started-classic-private-link.md") - Create your first ROSA classic cluster using AWS PrivateLink.
- [Create a ROSA classic cluster using the ROSA CLI](getting-started-classic-cli.md "getting-started-classic-cli.md") - Create your first ROSA classic cluster using AWS STS and the ROSA CLI.
