# Offboarding an EDI account

After you send an EDI Service Termination Request with at least a 30-day notice, ECO offboards your account. The Service Termination Date is the last day
of the calendar month following the end of the required 30-day termination notice period. If the end of the termination notice period is after the 20th day
of the calendar month, then the Service Termination Date is the last day of the following calendar month.

To request offboarding an account you must take the following actions:

1. Submit a formal service request to offboard the account. The request must include all the EDI instances that you want to offboard.
2. Inform your E-SDM about the EDI instances that you want to offboard and request their help with the offboarding process.
