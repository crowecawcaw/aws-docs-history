# Track changes in your EDI accounts

ECO provides log management and an interface that you can query through the Amazon Athena console to help you track ECO automation and changes that the ECO
operations team makes.

For details on tracking changes in ECO, see
[Tracking changes in your AMS Accelerate accounts](../../../managedservices/latest/accelerate-guide/acc-change-record.md "../../../managedservices/latest/accelerate-guide/acc-change-record.md")
in the _AMS Accelerate User Guide_.
