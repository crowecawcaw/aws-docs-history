

# ECO backup monitoring and reporting
<a name="eco-backup-reports"></a>

ECO generates daily self-service reports and monthly reports on resource coverage and backup job status. Your ESDM shares the monthly reports are in Monthly Business Reviews (MBRs). To learn more about daily backup reports, see [Backup report (daily)](https://docs.aws.amazon.com/managedservices/latest/accelerate-guide/daily-backup-report.html) in the *AMS Accelerate User Guide*.

ECO experts monitor all your backup tasks. If a backup fails, ECO investigates the failure and informs you of the root cause and remediation options, if available.
