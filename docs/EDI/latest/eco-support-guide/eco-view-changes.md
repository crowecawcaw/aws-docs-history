

# View your EDI accounts' change records
<a name="eco-view-changes"></a>

To view your EDI account change records, submit a ticket with ECO or use the Amazon Athena console.

For more information on viewing change records using the Amazon Athena console, see [Viewing your change records](https://docs.aws.amazon.com/managedservices/latest/accelerate-guide/acc-change-record.html#acc-cr-using) in the *AMS Accelerate User Guide*.
