# View your EDI accounts' change records

To view your EDI account change records, submit a ticket with ECO or use the Amazon Athena console.

For more information on viewing change records using the Amazon Athena console, see
[Viewing your change records](../../../managedservices/latest/accelerate-guide/acc-change-record.md#acc-cr-using "../../../managedservices/latest/accelerate-guide/acc-change-record.md#acc-cr-using")
in the _AMS Accelerate User Guide_.
