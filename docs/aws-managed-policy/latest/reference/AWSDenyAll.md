# AWSDenyAll

**Description**: Deny all access.

`AWSDenyAll` is an [AWS managed policy](../../../IAM/latest/UserGuide/access_policies_managed-vs-inline.md#aws-managed-policies "../../../IAM/latest/UserGuide/access_policies_managed-vs-inline.md#aws-managed-policies").

## Using this policy

You can attach `AWSDenyAll` to your users, groups, and roles.

## Policy

details

- **Type**: AWS managed policy
- **Creation time**: May 01, 2019, 22:36 UTC
- **Edited time:** December 18, 2023, 16:42 UTC
- **ARN**:
  `arn:aws:iam::aws:policy/AWSDenyAll`

## Policy version

**Policy version:** v2 (default)

The policy's default version is the version that defines the permissions for the policy. When a user or role with the policy makes a
request to access an AWS resource, AWS checks the default version of the policy to determine whether to allow the request.
