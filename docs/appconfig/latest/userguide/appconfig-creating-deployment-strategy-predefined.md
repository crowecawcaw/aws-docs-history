# Using predefined

deployment strategies

AWS AppConfig includes predefined deployment strategies to help you quickly deploy a
configuration. Instead of creating your own strategies, you can choose one of the following
when you deploy a configuration.

| Deployment strategy                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AppConfig.Linear20PercentEvery6Minutes  | **AWS recommended**:<br>This strategy deploys the configuration to 20% of all targets every six<br>minutes for a 30 minute deployment. The system monitors for Amazon CloudWatch alarms for 30<br>minutes. If no alarms are received in this time, the deployment is complete. If an<br>alarm is triggered during this time, AWS AppConfig rolls back the<br>deployment.We recommend using this strategy for production<br>deployments because it aligns with AWS best practices and includes additional<br>emphasis on deployment safety due to its long duration and bake time. |
| AppConfig.Canary10Percent20Minutes      | **AWS recommended**:<br>This strategy processes the deployment exponentially using a 10% growth factor<br>over 20 minutes. The system monitors for CloudWatch alarms for 10 minutes. If no alarms<br>are received in this time, the deployment is complete. If an alarm is triggered<br>during this time, AWS AppConfig rolls back the deployment.We recommend using<br>this strategy for production deployments because it aligns with AWS best<br>practices for configuration deployments.                                                                                      |
| AppConfig.AllAtOnce                     | **Quick**:<br>This strategy deploys the configuration to all targets immediately. The system<br>monitors for CloudWatch alarms for 10 minutes. If no alarms are received in this time,<br>the deployment is complete. If an alarm is triggered during this time, AWS AppConfig<br>rolls back the deployment.                                                                                                                                                                                                                                                                      |
| AppConfig.Linear50PercentEvery30Seconds | **Testing/demonstration**:<br>This strategy deploys the configuration to half of all targets every 30<br>seconds for a one-minute deployment. The system monitors for Amazon CloudWatch alarms for 1<br>minute. If no alarms are received in this time, the deployment is complete. If an<br>alarm is triggered during this time, AWS AppConfig rolls back the<br>deployment.We recommend using this strategy only for testing or<br>demonstration purposes because it has a short duration and bake time.                                                                        |
