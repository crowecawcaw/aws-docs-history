# Defining rules for multi-variant feature flags

A variant rule is an expression comprised of one or more operands and an operator.
An operand is a specific value used during the evaluation of a rule. Operand values
can be either static, such as a literal number or string, or variable, such as the
value found in a context or the result of another expression. An operator, such as
"greater than", is a test or action applied to its operands that produces a value. A
variant rule expression must produce either a "true" or "false" to be valid.

**Operands**

| Type          | Description                                                                                                                                                      | Example                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| String        | A sequence of UTF-8 characters, enclosed in double-quotes.                                                                                                       | `<br>"apple", "Ḽơᶉëᶆ ȋṕšᶙṁ"<br>`             |
| Integer       | A 64-bit integer value.                                                                                                                                          | `<br>-7, 42<br>`                             |
| Float         | A 64-bit IEEE-754 floating-point value.                                                                                                                          | `<br>3.14, 1.234e-5<br>`                     |
| Timestamp     | A specific moment in time as described by the [W3C note on date and time<br>formats](https://www.w3.org/TR/NOTE-datetime "https://www.w3.org/TR/NOTE-datetime"). | `<br>2012-03-04T05:06:07-08:00, 2024-01<br>` |
| Boolean       | A true or false value.                                                                                                                                           | `<br>true, false<br>`                        |
| Context value | A parameterized value in the form of $`key`<br>that is retrieved from the context during rule evaluation.                                                        | `<br>$country, $userId<br>`                  |

**Comparison operators**

| Operator | Description                                                                      | Example                          |
| -------- | -------------------------------------------------------------------------------- | -------------------------------- |
| eq       | Determines whether a context value is equal to a given value.                    | `<br>(eq $state "Virginia")<br>` |
| gt       | Determines whether a context value is greater than a given value.                | `<br>(gt $age 65)<br>`           |
| gte      | Determines whether a context value is greater than or equal to a given<br>value. | `<br>(gte $age 65)<br>`          |
| lt       | Determines whether a context value is less than a given value.                   | `<br>(lt $age 65)<br>`           |
| lte      | Determines whether a context value is less than or equal to a given<br>value.    | `<br>(lte $age 65)<br>`          |

**Logical operators**

| Operator | Description                                         | Example                                                       |
| -------- | --------------------------------------------------- | ------------------------------------------------------------- |
| and      | Determines if both operands are true.               | `<br>(and<br>(eq $state "Virginia")<br>(gt $age 65)<br>)<br>` |
| or       | Determines if at least one of the operands is true. | `<br>(or<br>(eq $state "Virginia")<br>(gt $age 65)<br>)<br>`  |
| not      | Reverses the value of an expression.                | `<br>(not (eq $state "Virginia"))<br>`                        |

**Custom operators**

| Operator    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Example                                           |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| begins_with | Determines whether a context value begins with a given prefix.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `<br>(begins_with $state "A")<br>`                |
| ends_with   | Determines whether a context value ends with a given prefix.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `<br>(ends_with $email "amazon.com")<br>`         |
| contains    | Determines whether a context value contains a given substring.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `<br>(contains $promoCode "WIN")<br>`             |
| in          | Determines whether a context value is contained within a list of<br>constants.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `<br>(in $userId ["123", "456"])<br>`             |
| matches     | Determines whether a context value matches a given regex pattern.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | `<br>(matches in::$greeting pattern::"h.*y")<br>` |
| exists      | Determines whether any value was provided for a context key.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `<br>(exists key::"country")<br>`                 |
| split       | Evaluates to `true` for a given percentage of traffic based<br>on a consistent hash of the provided context value(s). For a detailed<br>explanation of how `split` works, see the next section in this<br>topic, [Understanding the split operator](appconfig-creating-multi-variant-feature-flags-rules.md#appconfig-creating-multi-variant-feature-flags-rules-operators-split "appconfig-creating-multi-variant-feature-flags-rules.md#appconfig-creating-multi-variant-feature-flags-rules-operators-split").<br>Note that `seed` is an optional property. If you don't<br>specify `seed`, the hash is _locally_<br>consistent, meaning traffic will be split consistently for that flag, but<br>other flags receiving the same context value may split traffic differently.<br>If `seed` is provided, each unique value is guaranteed to split<br>traffic consistently across feature flags, configuration profiles, and<br>AWS accounts. | `<br>(split pct::10 by::$userId seed::"abc")<br>` |
