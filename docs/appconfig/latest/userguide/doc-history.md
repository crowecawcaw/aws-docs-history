| AWS AppConfig integration with Amazon ECS and Amazon EKS                                            | You can integrate AWS AppConfig with Amazon Elastic Container Service (Amazon ECS) and Amazon Elastic Kubernetes Service (Amazon EKS)<br>by using the AWS AppConfig agent. The agent functions as a sidecar<br>container running alongside your Amazon ECS and Amazon EKS container<br>applications. The agent enhances containerized application<br>processing and management in the following ways:<br>• The agent calls AWS AppConfig on your behalf by<br>using an AWS Identity and Access Management (IAM) role and managing a<br>local cache of configuration data. By pulling<br>configuration data from the local cache, your<br>application requires fewer code updates to manage<br>configuration data, retrieves configuration data<br>in milliseconds, and isn't affected by network<br>issues that can disrupt calls for such<br>data.<br>• The agent offers a native experience for<br>retrieving and resolving AWS AppConfig feature<br>flags.<br>• Out of the box, the agent provides best<br>practices for caching strategies, polling<br>intervals, and local configuration data<br>availability while tracking the configuration<br>tokens needed for subsequent service calls.<br>• While running in the background, the agent<br>periodically polls the AWS AppConfig data plane for<br>configuration data updates. Your containerized<br>application can retrieve the data by connecting to<br>localhost on port 2772 (a customizable default<br>port value) and calling HTTP GET to retrieve the<br>data.<br>• The AWS AppConfig agent updates configuration data<br>in your containers without having to restart or<br>recycle those containers.<br>For more information, see [AWS AppConfig integration with Amazon ECS and<br>Amazon EKS](appconfig-integration-containers-agent.md "appconfig-integration-containers-agent.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                     | December 2, 2022   |
