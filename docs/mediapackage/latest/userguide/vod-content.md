

# Delivering VOD content from AWS Elemental MediaPackage
<a name="vod-content"></a>

At this time, MediaPackage v2 doesn't support video on demand (VOD) workflows. If you're looking to support VOD workflows, see the [AWS Elemental MediaPackage v1 User Guide](https://docs.aws.amazon.com/mediapackage/latest/ug/what-is.html).
