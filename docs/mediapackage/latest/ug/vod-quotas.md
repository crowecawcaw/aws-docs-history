# VOD content quotas

This section describes the quotas for video on demand (VOD) content in AWS Elemental MediaPackage.
For information about requesting an increase to soft quotas, see [AWS Service Quotas](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md"). Hard quotas can't be changed.

## VOD soft quotas

The following table describes quotas in AWS Elemental MediaPackage for VOD content that can be
increased. For information about changing quotas, see [AWS
Service Quotas](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md").

For some customers, your account quota might be below these published quotas. If you
believe that you encountered a **`Resource limit exceeded`** error wrongfully,
use the Service Quotas console to
[request quota increases](https://console.aws.amazon.com/servicequotas/home?region=us-east-1#!/services/mediapackage/quotas "https://console.aws.amazon.com/servicequotas/home?region=us-east-1#!/services/mediapackage/quotas").

| Resource                                             | Default quota                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Maximum Packaging Groups                             | 10NoteIncreasing your packaging group quota doesn't always mean that you also need to<br>increase your assets or packaging configurations. For example, if you need 14 groups and<br>want to serve HLS, HLS encrypted, and DASH content from each asset, you need only 3<br>packaging configurations for each asset (one for each output type). You do need to<br>increase your packaging group quota, but not the packaging configuration quota because you<br>have fewer than 10 configurations per packaging group.                 |
| Maximum Packaging Configurations per Packaging Group | 10This is a \*per packaging group<br>• quota. Each<br>packaging configuration represents the output package that you use. If one packaging group<br>has configurations for HLS, HLS encrypted, DASH, DASH encrypted, Microsoft Smooth, and<br>Microsoft Smooth encrypted content, then that group has 6 packaging configurations and<br>falls within the 10 configurations quota. If you have 10 packaging groups set up this same<br>way, then you still haven't exceeded the quota because each group uses only 6<br>configurations. |
| Maximum Assets per Packaging Group                   | 10,000This is a \*per packaging group<br>• quota. For example, if<br>you have 10,500 assets spread out over multiple packaging groups, then you still haven't<br>exceeded the quota if each group has no more than 10,000 assets.                                                                                                                                                                                                                                                                                                      |
