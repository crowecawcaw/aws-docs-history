# Viewing harvest job details

View all harvest jobs that you created within the last 90 days. After 90 days, a
harvest job expires from your account.

You can use the MediaPackage console, the AWS CLI, or the MediaPackage API to view a
harvest job. For information about viewing a job through the AWS CLI or MediaPackage API,
see the [AWS Elemental MediaPackage API Reference](../apireference.md "../apireference.md").

###### To view harvest job details (console)

1. Open the MediaPackage console at [https://console.aws.amazon.com/mediapackage/](https://console.aws.amazon.com/mediapackage/ "https://console.aws.amazon.com/mediapackage/").
2. In the navigation pane, under **Live**, choose **Harvest
   jobs**.
3. On the **Harvest jobs** page, choose the harvest job to view its details.
