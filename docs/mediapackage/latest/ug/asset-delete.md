# Deleting an asset

To remove the packaging group URLs and to stop AWS Elemental MediaPackage from delivering
further content, delete an asset.

To delete an asset, you can use the MediaPackage console, the AWS CLI, or the
MediaPackage API.
For information about creating a packaging configuration with the AWS CLI or MediaPackage API, see [Assets id](../../../mediapackage-vod/latest/apireference/assets-id.md "../../../mediapackage-vod/latest/apireference/assets-id.md") in the _AWS Elemental MediaPackage VOD API Reference_.

###### To delete an asset (console)

1. Open the MediaPackage console at [https://console.aws.amazon.com/mediapackage/](https://console.aws.amazon.com/mediapackage/ "https://console.aws.amazon.com/mediapackage/").
2. In the navigation pane, under **Video on demand**, choose
   **Assets**.
3. On the **Assets** page, select the asset that you want to delete.
4. Choose **Delete**.
