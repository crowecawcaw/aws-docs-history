# Adding an endpoint to a channel

Add an endpoint to a channel to allow downstream video players and content
delivery networks (CDNs) to start requesting content playback.

You can use the AWS Elemental MediaPackage console, the AWS CLI, or the MediaPackage API to
add an endpoint to a channel. For information about adding through the AWS CLI or
MediaPackage API, see the [AWS Elemental MediaPackage API Reference](../apireference.md "../apireference.md").

For instructions on adding endpoints to a channel from the MediaPackage console,
see [Working with endpoints in AWS Elemental MediaPackage](endpoints.md "endpoints.md").
