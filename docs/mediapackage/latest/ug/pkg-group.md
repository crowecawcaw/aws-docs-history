# Working with packaging groups in AWS Elemental MediaPackage

A packaging group holds one or more packaging configurations. When a packaging group is
associated with an asset, the packaging configurations define the outputs that are available
from the asset. You can associate multiple assets with one packaging group. This enables you
to apply the same configurations to multiple assets.
