# Creating a Distribution

A distribution in Amazon CloudFront holds all information about content delivery, including
where content is coming from and how it's tracked and managed. The distribution holds
origins (where content is originating from) and behaviors (where content requests are
routed based on specified patterns in the request).

You can create a distribution
from the CloudFront
console. The following section describes this approach.
