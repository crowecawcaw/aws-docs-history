# Deleting a harvest job

You can't delete a harvest job.

- To create a harvest job with different settings, see [Creating a harvest job](hj-create.md "hj-create.md").
- To delete a VOD asset that MediaPackage created with a harvest job, see [Delete an Object and a Bucket](../../../AmazonS3/latest/gsg/DeletingAnObjectandBucket.md "../../../AmazonS3/latest/gsg/DeletingAnObjectandBucket.md") in the _Amazon Simple Storage Service Getting Started Guide._
