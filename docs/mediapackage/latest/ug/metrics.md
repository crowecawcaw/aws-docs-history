# AWS Elemental MediaPackage live content metrics

The `AWS/MediaPackage` namespace includes the following metrics for live
content. AWS Elemental MediaPackage publishes metrics to CloudWatch every minute, if not sooner.

| Metric                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ActiveInput`         | Indicates if an input has been used as the source for an endpoint in<br>MediaPackage (it has been active). A value of 1 indicates that the input was active,<br>and a 0 (zero) indicates that it wasn't. Units: NoneValid dimension:<br>• Combination of `IngestEndpoint` and `OriginEndpoint`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `EgressBytes`         | Number of bytes that MediaPackage successfully sends for each request. If<br>MediaPackage doesn't receive any requests for output in the specified interval, then no<br>data is given.Units: BytesValid statistics:<br>• `Average` – Average bytes<br>(`Sum`/`SampleCount`) that AWS Elemental MediaPackage outputs over the<br>configured interval.<br>• `Maximum` – Largest individual output request (in bytes) made to<br>AWS Elemental MediaPackage.<br>• `Minimum` – Smallest individual output request (in bytes) made to<br>AWS Elemental MediaPackage.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total number of bytes that AWS Elemental MediaPackage outputs over<br>the configured interval.<br>Valid dimensions:<br>• `Channel`<br>• Combination of `Channel` and `OriginEndpoint`<br>• `PackagingConfiguration`<br>• No dimension                                                                                                                                                               |
| `EgressRequestCount`  | Number of content requests that AWS Elemental MediaPackage receives. If MediaPackage<br>doesn't receive any requests for output in the specified interval, then no data is<br>given.Units: CountValid statistics:<br>• `Sum` – Total number of output requests that AWS Elemental MediaPackage<br>receives.<br>Valid dimensions:<br>• `Channel`<br>• Combination of `Channel` and `OriginEndpoint`<br>• `StatusCodeRange`<br>• Combination of `Channel` and `StatusCodeRange`<br>• Combination of `Channel`, `OriginEndpoint`, and<br>`StatusCodeRange`<br>• `PackagingConfiguration`<br>• Combination of `PackagingConfiguration` and<br>`StatusCodeRange`<br>• No dimension                                                                                                                                                                                                                                                                                                                                                                                           |
| `EgressResponseTime`  | The time that it takes MediaPackage to process each output request. If<br>MediaPackage doesn't receive any requests for output in the specified interval, then no<br>data is given.Units: MillisecondsValid statistics:<br>• `Average` – Average amount of time<br>(`Sum`/`SampleCount`) that it takes AWS Elemental MediaPackage to process<br>output requests over the configured interval.<br>• `Maximum` – Longest amount of time (in milliseconds) that it takes<br>AWS Elemental MediaPackage to process an output request and provide a response.<br>• `Minimum` – Shortest amount of time (in milliseconds) that it<br>takes AWS Elemental MediaPackage to process an output request and provide a response.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total amount of time that it takes AWS Elemental MediaPackage to<br>process output requests over the configured interval.<br>Valid dimensions:<br>• `Channel`<br>• Combination of `Channel` and `OriginEndpoint`<br>• `PackagingConfiguration` |
| `IngressBytes`        | Number of bytes of content that AWS Elemental MediaPackage receives for each input<br>request. If MediaPackage doesn't receive any requests for input in the specified interval,<br>then no data is given.Units: BytesValid statistics:<br>• `Average` – Average bytes<br>(`Sum`/`SampleCount`) that MediaPackage receives over the<br>configured interval.<br>• `Maximum` – Largest individual input request (in bytes) made to<br>AWS Elemental MediaPackage.<br>• `Minimum` – Smallest individual input request (in bytes) made to<br>AWS Elemental MediaPackage.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total number of bytes that AWS Elemental MediaPackage receives over<br>the configured interval.<br>Valid dimensions:<br>• `Channel`<br>• Combination of `Channel` and `IngestEndpoint`<br>• No dimension                                                                                                                                                                                       |
| `IngressResponseTime` | The time that it takes MediaPackage to process each input request. If<br>MediaPackage doesn't receive any requests for input in the specified interval, then no<br>data is given.Units: MillisecondsValid statistics:<br>• `Average` – Average amount of time<br>(`Sum`/`SampleCount`) that it takes MediaPackage to process<br>input requests over the configured interval.<br>• `Maximum` – Longest amount of time (in milliseconds) that it takes<br>AWS Elemental MediaPackage to process an input request and provide a response.<br>• `Minimum` – Shortest amount of time (in milliseconds) that it<br>takes AWS Elemental MediaPackage to process an input request and provide a response.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total amount of time that it takes MediaPackage to<br>process input requests over the configured interval.<br>Valid dimensions:<br>• `Channel`<br>• Combination of `Channel` and `IngestEndpoint`<br>• No dimension                                               |

## AWS Elemental MediaPackage live dimensions

You can filter the `AWS/MediaPackage` data using the following
dimensions.

| Dimension         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| No Dimension      | Metrics are aggregated and shown for all channels, endpoints, or status<br>codes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `Channel`         | Metrics are shown only for the specified channel.<br>Value: The autogenerated GUID of the channel.<br>Can be used alone or with other dimensions:<br>• Alone to show metrics for only the specified channel.<br>• With the `originEndpoint` dimension to show metrics for the specified<br>endpoint that's associated with the specified channel.                                                                                                                                                                                                                                                |
| `IngestEndpoint`  | Metrics are shown only for the specified ingest endpoint on a channel.<br>Value: The autogenerated GUID of the ingest endpoint.<br>Can be used with the following dimensions:<br>• With the `channel` dimension to show metrics for the specified ingest<br>endpoint that's associated with the specified channel.<br>• With the `originEndpoint` dimension to show metrics for the specified<br>ingest endpoint that's associated with the specified endpoint.                                                                                                                                  |
| `OriginEndpoint`  | Metrics are shown for the specified channel and endpoint combination.<br>Value: The autogenerated GUID of the endpoint.<br>Must be used with the `channel` dimension.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `StatusCodeRange` | Metrics are shown for the specified status code range.<br>Value: `2xx`, `3xx`, `4xx`, or<br>`5xx`.<br>Can be used alone or with other dimensions:<br>• Alone to show all output requests for the specified status range.<br>• With the `channel` dimension to show output requests for all endpoints<br>that are associated with the specified channel, with the specified status code<br>range.<br>• With the `channel` and `originEndpoint` dimensions to show<br>output requests with a specific status code range on the specified endpoint that's<br>associated with the specified channel. |
