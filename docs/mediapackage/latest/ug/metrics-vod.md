# AWS Elemental MediaPackage VOD content metrics

The `AWS/MediaPackage` namespace includes the following metrics for video on
demand (VOD) content. AWS Elemental MediaPackage publishes metrics to CloudWatch every minute, if not
sooner.

| Metric               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `EgressBytes`        | Number of bytes that MediaPackage successfully sends for each request. If<br>MediaPackage doesn't receive any requests for output in the specified interval, then no<br>data is given.Units: BytesValid statistics:<br>• `Average` – Average bytes<br>(`Sum`/`SampleCount`) that MediaPackage outputs over the<br>configured interval.<br>• `Maximum` – Largest individual output request (in bytes) made to<br>MediaPackage.<br>• `Minimum` – Smallest individual output request (in bytes) made to<br>MediaPackage.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total number of bytes that MediaPackage outputs over<br>the configured interval.<br>Valid dimensions:<br>• `PackagingConfiguration`                                                                                                                                                                                 |
| `EgressRequestCount` | Number of content requests that MediaPackage receives. If MediaPackage<br>doesn't receive any requests for output in the specified interval, then no data is<br>given.Units: CountValid statistics:<br>• `Sum` – Total number of output requests that MediaPackage<br>receives.<br>Valid dimensions:<br>• `PackagingConfiguration`<br>• Combination of `PackagingConfiguration` and<br>`StatusCodeRange`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `EgressResponseTime` | The time that it takes MediaPackage to process each output request. If<br>MediaPackage doesn't receive any requests for output in the specified interval, then no<br>data is given.Units: MillisecondsValid statistics:<br>• `Average` – Average amount of time<br>(`Sum`/`SampleCount`) that it takes MediaPackage to process<br>output requests over the configured interval.<br>• `Maximum` – Longest amount of time (in milliseconds) that it takes<br>MediaPackage to process an output request and provide a response.<br>• `Minimum` – Shortest amount of time (in milliseconds) that it<br>takes MediaPackage to process an output request and provide a response.<br>• `SampleCount` – Number of requests that's used in the statistical<br>calculation.<br>• `Sum` – Total amount of time that it takes MediaPackage to<br>process output requests over the configured interval.<br>Valid dimensions:<br>• `PackagingConfiguration` |

## AWS Elemental MediaPackage VOD dimensions

You can filter the `AWS/MediaPackage` data using the following
dimensions.

| Dimension                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| No Dimension             | Metrics are aggregated and shown for all packaging configurations and status<br>codes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `PackagingConfiguration` | Metrics are shown only for the specified packaging configuration.<br>Value: The autogenerated GUID of the configuration.<br>Can be used alone or with other dimensions:<br>• Alone to show metrics for only the specified configuration.<br>• With the `statusCodeRange` dimension to show metrics for the specified<br>configuration that's associated with the specified status code.                                                                                                                                                                                                          |
| `StatusCodeRange`        | Metrics are shown for the specified status code range.<br>Value: `2xx`, `3xx`, `4xx`, or<br>`5xx`.<br>Can be used alone or with other dimensions:<br>• Alone to show all output requests for the specified status range.<br>• With the `channel` dimension to show output requests for all endpoints<br>that are associated with the specified channel, with the specified status code<br>range.<br>• With the `channel` and `originEndpoint` dimensions to show<br>output requests with a specific status code range on the specified endpoint that's<br>associated with the specified channel. |
