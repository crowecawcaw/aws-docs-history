# MetricAttribution

Contains information about a metric attribution associated with an event. For more information about metric attributions, see [Measuring impact of recommendations](measuring-recommendation-impact.md "measuring-recommendation-impact.md").

## Contents

**eventAttributionSource**

The source of the event, such as a third party.

Type: String

Length Constraints: Maximum length of 1024.

Pattern: `^[\x20-\x7E]*[\x21-\x7E]+[\x20-\x7E]*$`

Required: Yes
