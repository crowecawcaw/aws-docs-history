# Document history for the AWS IoT TwinMaker User Guide

The following table describes the documentation releases for AWS IoT TwinMaker.

| Change                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Date              |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| New service-linked role and new IAM policy | AWS IoT TwinMaker added a new service-linked role, called [AWSServiceRoleForIoTTwinMaker](using-service-linked-roles.md "using-service-linked-roles.md").<br>AWS IoT TwinMaker added this new service-linked role to allow AWS IoT TwinMaker to call other AWS services and to<br>sync their resources on your behalf. The new AWSIoTTwinMakerServiceRolePolicy IAM policy is attached to<br>this role, and the policy grants permission to AWS IoT TwinMaker to call other AWS services and to<br>sync their resources on your behalf. | November 17, 2023 |
| Initial release                            | Initial release of the AWS IoT TwinMaker User Guide                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | November 30, 2021 |
