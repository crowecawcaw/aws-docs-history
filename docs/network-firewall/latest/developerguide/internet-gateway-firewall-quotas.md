

# Service quotas

The following table lists the service quotas for automated internet firewall.


**Automated Internet Firewall service quotas**  

| Quota | Value | Adjustable | Source | 
| --- | --- | --- | --- | 
| Throughput per Availability Zone per VPC | 100 Gbps | No | automated internet firewall | 
| Simultaneous connections per NAT IP address per destination | Same as NAT gateway. For the NAT gateway quotas, see [Amazon VPC quotas](https://docs.aws.amazon.com/vpc/latest/userguide/amazon-vpc-limits.html#vpc-limits-gateways) in the Amazon VPC User Guide. | Same as NAT gateway | NAT gateway | 

Policy quotas are managed in Network Security Manager (NSM). For details, see [Quotas for Network Security Manager](https://docs.aws.amazon.com/network-security-manager/latest/devguide/quotas.html).
