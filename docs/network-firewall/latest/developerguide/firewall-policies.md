# Firewall policies in AWS Network Firewall

An AWS Network Firewall _firewall policy_ defines the monitoring and protection behavior for a
firewall. The details of the behavior are defined in the rule groups that you add to your
policy, and in some policy default settings. To use a firewall policy, you associate it with
one or more firewall endpoints or firewall endpoint associations.
