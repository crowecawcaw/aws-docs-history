# AWS Network Firewall quotas

AWS Network Firewall is subject to the following quotas (formerly referred to as limits). These
quotas are the same for all AWS Regions in which Network Firewall is available. Each Region
is subject to these quotas individually. The quotas are not cumulative across
Regions.

Network Firewall has the following default quotas on the maximum number of entities you can
have per account per Region.
You can request an increase in these adjustable quotas through the [Service Quotas console](https://console.aws.amazon.com/servicequotas/home/services/network-firewall/quotas "https://console.aws.amazon.com/servicequotas/home/services/network-firewall/quotas").
