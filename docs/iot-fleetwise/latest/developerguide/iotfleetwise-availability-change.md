# AWS IoT FleetWise availability change
<a name="iotfleetwise-availability-change"></a>

AWS IoT FleetWise is no longer open to new customers. Existing AWS IoT FleetWise customers can continue using the service. The [Guidance for Connected Mobility on AWS](https://aws.amazon.com/solutions/guidance/connected-mobility-on-aws/) provides guidance on how to develop and deploy modular services for connected mobility solutions that can be used to achieve equivalent capabilities as AWS IoT FleetWise.

As an active customer using AWS IoT FleetWise, you will be able to continue using AWS IoT FleetWise as normal (and add team members to your active account). While we will not be adding new features to the service, we remain committed to providing security updates and maintaining service availability to ensure your ongoing projects continue to run smoothly.

With the AWS guidance for connected mobility solutions, you can create a robust connected mobility platform that adapts vehicle software configurations to each production stage, ensuring reliable service delivery with minimal latency worldwide. The guidance enables implementation of cost-efficient architectures that automatically adjust to changing vehicle connectivity demands. The guidance comes with sample code to help you accelerate.

If you have additional questions, contact [AWS Support](https://aws.amazon.com/support) or read our FAQs:

## Frequently asked questions
<a name="iotfleetwise-availability-change.faq"></a>

**What does this mean for the service (are you going to shut the service down)**?  
AWS IoT FleetWise is no longer accepting new customers. The service will continue to operate for existing customers but there will be no new feature development on the service.

**How will existing customers be impacted?**  
Existing customers will not experience any disruption to their workloads. They can continue using AWS IoT FleetWise as normal and security updates will continue to be deployed to maintain service reliability.

**How can I get help if I have issues?**  
If you're experiencing issues, contact [AWS Support](https://aws.amazon.com/support).

**What are alternatives to AWS IoT FleetWise?**  
We recommend you use the [Guidance for Connected Mobility on AWS](https://aws.amazon.com/solutions/guidance/connected-mobility-on-aws/), which provides guidance on solution architecture and sample code to build a connected vehicle platform for ingesting and processing vehicle data.
