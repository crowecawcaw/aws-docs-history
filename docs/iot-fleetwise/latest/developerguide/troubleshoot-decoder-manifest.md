# AWS IoT FleetWise decoder manifest issues

Troubleshoot decoder manifest issues.

| Diagnosing decoder manifest API calls                                                                    | Error                                                                                                                                                                                                                                                                                                                                               | Troubleshooting guidelines |
| -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `UpdateOperationFailure.ConflictingDecoderUpdate`                                                        | The same decoder manifest has multiple update requests. Wait and try<br>again.                                                                                                                                                                                                                                                                      |
| `UpdateOperationFailure.InternalFailure`                                                                 | InternalFailure is launched as an encapsulated exception. The problem<br>itself depends on the exception encapsulated.                                                                                                                                                                                                                              |
| `UpdateOperationFailure.ActiveDecoderUpdate`                                                             | The decoder manifest is in an `Active` state and can't be<br>updated. Change the decoder manifest state to `DRAFT`, and<br>then try again.                                                                                                                                                                                                          |
| `UpdateOperationFailure.ConflictingModelUpdate`                                                          | AWS IoT FleetWise is trying to validate against a vehicle model (model manifest)<br>that's being modified by someone else. Wait and try again.                                                                                                                                                                                                      |
| `UpdateOperationFailure.ModelManifestValidationResponse :<br>FailureReason.MODEL_DATA_ENTRIES_NOT_FOUND` | The vehicle model doesn't have any signals associated with it. Add<br>signals to the vehicle model and verify that the signals can be found in<br>the associated signal catalog.                                                                                                                                                                    |
| `UpdateOperationFailure.ModelManifestValidationResponse :<br>FailureReason.MODEL_NOT_ACTIVE`             | Update the vehicle model so that it's in `ACTIVE` state,<br>and then try again.                                                                                                                                                                                                                                                                     |
| `UpdateOperationFailure.ModelManifestValidationResponse :<br>FailureReason.MODEL_NOT_FOUND`              | AWS IoT FleetWise can't find the vehicle model associated with the decoder<br>manifest. Verify the Amazon Resource Name (ARN) of the vehicle model and try<br>again.                                                                                                                                                                                |
| `UpdateOperationFailure.ModelManifestValidationResponse(FailureReason.MODEL_DATA_ENTRIES_READ_FAILURE`   | The validation of the vehicle model failed because signal names from<br>the vehicle model weren't found in the signal catalog. Verify that the<br>signals in the vehicle model are all included in the associated signal<br>catalog.                                                                                                                |
| `UpdateOperationFailure.ValidationFailure`                                                               | Signals or network interfaces that aren't valid were found in the<br>request to update the decoder manifest. Verify that all signals and<br>network interfaces returned by the exception exist, that all signals<br>used are associated with an available interface, and that you won't<br>remove an interface that has signals associated with it. |
| `UpdateOperationFailure.KmsKeyAccessDenied`                                                              | There's a permission issue on the AWS Key Management Service (AWS KMS) key used for the<br>operation. Verify that you're using a role that has access to the key<br>and try again.                                                                                                                                                                  |
| `UpdateOperationFailure.DecoderDoesNotExist`                                                             | The decoder manifest doesn't exist. Verify the decoder manifest name<br>and try again.                                                                                                                                                                                                                                                              |

Vision system data error messages with the
`SIGNAL_DECODER_INCOMPATIBLE_WITH_SIGNAL_CATALOG` reason will include a
hint in the response that provides information about why the request failed. You can use
the hint to determine which troubleshooting guidelines to follow.

###### Note

Vision system data is in preview release and is subject to change.

| Diagnosing decoder manifest vision system data validation                                                               | Error                                                                                                                                                                                                                                                                                                          | Troubleshooting guidelines |
| ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.NO_SIGNAL_IN_CATALOG_FOR_DECODER_SIGNAL)`                   | AWS IoT FleetWise didn't find the root signal structure used in the signal<br>decoder using the signal catalog. Verify that the root signal of the<br>structure is properly defined in the signal catalog.                                                                                                     |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.SIGNAL_DECODER_TYPE_INCOMPATIBLE_WITH_MESSAGE_SIGNAL_TYPE)` | A primitive message in the signal catalog wasn't defined with the<br>same data type in the decoder manifest update request. Verify that the<br>primitive messages defined in the request match their corresponding<br>signal catalog definition.                                                               |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.STRUCT_SIZE_MISMATCH)`                                      | The number of properties defined in a struct in the signal catalog<br>don't match the number of properties you're trying to decode in the<br>decoder manifest. Verify that you have the correct number of signals to<br>decode by comparing it with the signals defined in the signal<br>catalog.              |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.SIGNAL_DECODER_INCOMPATIBLE_WITH_SIGNAL_CATALOG)`           | AWS IoT FleetWise found a signal defined as a STRUCT in the signal catalog<br>without a structuredMessageDefinition defined in the decoder manifest<br>request. Make sure that each struct is defined as a<br>structuredMessageDefinition in the decoder manifest update<br>request.                           |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.SIGNAL_DECODER_INCOMPATIBLE_WITH_SIGNAL_CATALOG)`           | The root signal of the structure used in the decoder manifest is not<br>properly defined as a structure in the signal catalog. The root signal<br>structure used in the decoder manifest must have its field<br>structFullyQualifiedName defined. It also needs a STRUCT node with that<br>fullyQualifiedName. |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.SIGNAL_DECODER_INCOMPATIBLE_WITH_SIGNAL_CATALOG)`           | One of the leaf messages used in the decoder manifest request is not<br>defined as a primitive message. Verify that all leaf objects in the<br>request are defined as primitive messages.                                                                                                                      |
| `InvalidSignalDecoder.withReason(SignalDecoderFailureReason.SIGNAL_DECODER_INCOMPATIBLE_WITH_SIGNAL_CATALOG)`           | An array object in the signal catalog wasn't defined as a<br>structuredMessageListDefinition in the decoder manifest update request.<br>Verify that all array properties are defined as<br>structuredMessageListDefinition in the decoder manifest update<br>request.                                          |
