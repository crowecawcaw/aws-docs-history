# How it works

Amazon Bedrock AgentCore Evaluations provides capabilities to assess the performance of AI agents. It can
compute metrics such as an agent's end-to-end task completion (goal attainment) correctness,
the accuracy of a tool invoked by the agent while handling a user request, and any custom
metric defined to evaluate specific dimensions of an agent's behavior. The AgentCore Evaluations can
evaluate the AI agents that are hosted under AgentCore Runtime as well as AI agents hosted outside
of AgentCore.

You can create and manage evaluation or relevant resources using the
AgentCore starter toolkit, the AgentCore Python SDK, the AWS Management Console or directly through AWS
SDKs.
