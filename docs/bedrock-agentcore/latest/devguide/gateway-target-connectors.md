

# Built-in connectors as targets

Amazon Bedrock AgentCore lets you add the following built-in connectors as targets in your gateway:
+ Amazon Bedrock Managed Knowledge Bases
+ Web Search Tool
+ Web Answer
+  AWS Step Functions
+  AWS Marketplace
