# Get started with AgentCore Runtime

You can use the following tutorials to get started with Amazon Bedrock AgentCore Runtime.

The [Amazon Bedrock AgentCore Starter Toolkit](https://github.com/aws/bedrock-agentcore-starter-toolkit "https://github.com/aws/bedrock-agentcore-starter-toolkit") is a Command Line Interface (CLI) that
simplifies the infrastructure setup for containerizing and deploying an agent to an
AgentCore Runtime.

  toolkit](runtime-get-started-toolkit.md "runtime-get-started-toolkit.md")
- [Get started without the starter toolkit](getting-started-custom.md "getting-started-custom.md")
