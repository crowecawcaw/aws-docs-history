# Document history for the AgentCore User Guide

The following table describes the documentation releases for Amazon Bedrock AgentCore.

| Change                                                  | Description                                                                                                                                                                                                                                                                              | Date               |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Runtime identity service-linked role                    | Added documentation for the new runtime identity service-linked role that manages workload identity access tokens and OAuth credentials. Updated BedrockAgentCoreFullAccess policy to include permission for creating the Amazon Bedrock AgentCore runtime identity service-linked role. | October 13, 2025   |
| General release                                         | Amazon Bedrock AgentCore is now generally available.                                                                                                                                                                                                                                     | October 13, 2025   |
| Model Context Protocol (MCP) servers as Gateway targets | Added documentation for the Model Context Protocol (MCP) servers as Gateway targets and using synchronization operations.                                                                                                                                                                | October 10, 2025   |
| Model Context Protocol (MCP) server support             | Added documentation for the Model Context Protocol (MCP) server that helps you transform, deploy, and test AgentCore-compatible agents directly from your development environment. The MCP server works with popular MCP clients including Kiro, Cursor, Claude Code, and Amazon Q CLI.  | October 2, 2025    |
| Managed policy updates                                  | Updated managed policy documentation. Added documentation for the BedrockAgentCoreNetworkServiceRolePolicy managed policy. Updated BedrockAgentCoreFullAccess policy to include permission for creating the Amazon Bedrock AgentCore network service-linked role.                        | September 19, 2025 |
| Initial release (preview)                               | Initial release of the Amazon Bedrock AgentCore Developer Guide                                                                                                                                                                                                                          | July 16, 2025      |
