# Sequences and identity columns

Sequences and identity columns generate integer values and are useful when
compact or human-readable identifiers are needed. These values involve allocation and caching
behavior described in the [CREATE SEQUENCE](create-sequence-syntax-support.md "create-sequence-syntax-support.md") documentation.
