

# Amazon SQS

 AWS Systems Manager Automation provides predefined runbooks for Amazon Simple Queue Service (Amazon SQS). For more information about runbooks, see [Working with runbooks](https://docs.aws.amazon.com/systems-manager/latest/userguide/automation-documents.html). For information about how to view runbook content, see [View runbook content](automation-runbook-reference.md#view-automation-json).
