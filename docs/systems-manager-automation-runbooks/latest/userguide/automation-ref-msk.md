

# Amazon MSK
<a name="automation-ref-msk"></a>

AWS Systems Manager Automation provides predefined runbooks for Amazon Managed Streaming for Apache Kafka. For more information about runbooks, see [Working with runbooks](https://docs.aws.amazon.com/systems-manager/latest/userguide/automation-documents.html). For information about how to view runbook content, see [View runbook content](automation-runbook-reference.md#view-automation-json).
