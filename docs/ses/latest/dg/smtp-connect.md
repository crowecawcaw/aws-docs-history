

# Choose SMTP connection settings

Your SMTP endpoint, ports, and encryption options depend on how you created your credentials. Use the connection guidance for your credential type.

Credentials using Mail Manager  
See [Connect to Mail Manager SMTP](smtp-credentials-mail-manager.md#smtp-credentials-mail-manager-connect) for the supported ports and STARTTLS guidance.

Credentials using IAM  
See [Connect to the Amazon SES SMTP interface](smtp-credentials.md#smtp-credentials-connect) for endpoints, ports, STARTTLS, and TLS Wrapper guidance.
