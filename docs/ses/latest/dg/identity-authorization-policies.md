# Using identity authorization in

Amazon SES

Identity authorization policies define how individual verified identities can use Amazon SES by
specifying which SES API actions are allowed or denied for the identity and under
what conditions.

Through the use of these authorization polices, you can maintain control over your
identities by changing or revoking permissions at any time. You can even authorize other
users to use the identities that you own (domains or email addresses) with their own
SES accounts.
