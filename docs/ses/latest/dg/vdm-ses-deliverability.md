

# SES deliverability
<a name="vdm-ses-deliverability"></a>

SES deliverability provides insights and recommendations for email sent through Amazon SES—helping you monitor delivery rates, track engagement, identify reputation issues, and resolve configuration problems that affect inbox placement.

SES deliverability is enabled at the account level when you enable Virtual Deliverability Manager through the onboarding wizard in the Amazon SES console.

**Key features**  
SES deliverability includes the following features:
+ **Dashboard** – Provides insights into your deliverability data focusing on account, ISP, sending identity, and configuration set levels. This helps you quickly see problematic areas and trends, and catch possible problems before they turn into larger deliverability issues like deferrals or blocks. See [Virtual Deliverability Manager dashboard](vdm-dashboard.md).
+ **Advisor** – Provides recommendations to improve your email sending by flagging configuration issues that are negatively affecting your email deliverability and reputation. It recommends solutions to resolve specific issues in the infrastructure of your sending domain, IP space, and authentication records. See [Virtual Deliverability Manager advisor](vdm-advisor.md).

**Getting started**  
To start using SES deliverability, enable Virtual Deliverability Manager from the onboarding wizard in the Amazon SES console. See [Getting started with Virtual Deliverability Manager](vdm-get-started.md).
