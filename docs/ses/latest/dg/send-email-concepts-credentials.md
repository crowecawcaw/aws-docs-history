# Types of Amazon SES credentials

To interact with Amazon Simple Email Service (Amazon SES), you use security credentials to verify who you are and
whether you have permission to interact with Amazon SES. There are different types of
credentials, and the credentials you use depend on what you want to do. For example, you use
AWS access keys when you send an email using the Amazon SES API, and SMTP credentials when you
send an email using the Amazon SES SMTP interface.

The following table lists the types of credentials you might use with Amazon SES, depending on
what you are doing.
