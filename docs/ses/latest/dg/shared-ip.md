

# Shared IP addresses for Amazon SES

When you create a new Amazon SES account, by default your emails are sent from IP addresses that are shared with other SES users. Shared IP addresses are ready to use immediately and don't require any additional setup.

If you want IP addresses that are reserved for your exclusive use, see [Dedicated IP addresses for Amazon SES](dedicated-ip.md).
