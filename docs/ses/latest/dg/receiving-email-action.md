# Action options

Each receipt rule for Amazon SES email receiving contains an ordered list of actions.
This section describes the specific options for each action type.

The action types are the following:

- [Add header action](receiving-email-action-add-header.md "receiving-email-action-add-header.md")
- [Return bounce response action](receiving-email-action-bounce.md "receiving-email-action-bounce.md")
- [Invoke Lambda function action](receiving-email-action-lambda.md "receiving-email-action-lambda.md")
- [Deliver to S3 bucket action](receiving-email-action-s3.md "receiving-email-action-s3.md")
- [Publish to Amazon SNS topic action](receiving-email-action-sns.md "receiving-email-action-sns.md")
- [Stop rule set action](receiving-email-action-stop.md "receiving-email-action-stop.md")
- [Integrate with Amazon WorkMail action](receiving-email-action-workmail.md "receiving-email-action-workmail.md")
