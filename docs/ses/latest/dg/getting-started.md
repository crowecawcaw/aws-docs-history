

# Getting started with Amazon Simple Email Service

Amazon Simple Email Service (Amazon SES) sends email from your domain. Start with [Sending email](getting-started-sending.md): it takes you from a new AWS account to your first message, with AWS CLI and console instructions. On that page, you do the following:
+ Verify your domain.
+ Request production access.
+ Apply safe defaults.
+ Send your first email.

To receive email with SES, see [Email receiving with Amazon SES](receiving-email.md). To filter, route, archive, or relay mail, see [Mail Manager for Amazon SES](eb.md).

**Tip**  
Using an AI coding agent? Connect it to AWS with the [Agent setup guide](agent-setup-guide.md), and then ask it to set up your domain for Amazon SES.
