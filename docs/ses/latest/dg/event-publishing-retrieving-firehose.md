# Retrieving Amazon SES event data from

Firehose

Amazon SES publishes email sending events to Firehose as JSON records. Firehose then publishes the
records to the AWS service destination that you chose when you set up the delivery stream
in Firehose. For information about setting up Firehose delivery streams, see [Creating an Firehose Delivery Stream](../../../firehose/latest/dev/basic-create.md "../../../firehose/latest/dev/basic-create.md") in the
_Amazon Data Firehose Developer Guide_.
