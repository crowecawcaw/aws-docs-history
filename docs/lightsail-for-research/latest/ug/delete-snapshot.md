# Delete a snapshot in the Lightsail for Research console

Complete the following steps to delete a snapshot.

1. Sign in to the [Lightsail for Research console](https://lfr.console.aws.amazon.com/ls/research "https://lfr.console.aws.amazon.com/ls/research").
2. Choose **Snapshots** in the navigation pane.
3. On the **Snapshots** page, locate the name of the computer or
   disk snapshot want to delete. Choose the **Snapshots** dropdown
   menu to view a list of available snapshots for that resource.
4. Select the snapshot that you want to delete.
5. Choose the **Actions** dropdown menu. Then, choose
   **Delete snapshot**.
6. Verify that the snapshot name is correct. Then, choose **Delete
   snapshot**.
