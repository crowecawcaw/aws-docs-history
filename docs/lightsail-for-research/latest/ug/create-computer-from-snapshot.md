# Create a virtual computer or disk from a

snapshot

Complete the following steps to create a new Lightsail for Research virtual computer or disk from a
snapshot.

When you create a virtual computer from a snapshot, use a plan that's the same size or
larger than the one used for the original computer. You can't use a smaller plan than
the original virtual computer.

When you create a disk from a snapshot, choose a disk size that's larger than the
original disk. You can't use a smaller disk than the original.

1. Sign in to the [Lightsail for Research console](https://lfr.console.aws.amazon.com/ls/research "https://lfr.console.aws.amazon.com/ls/research").
2. Choose **Snapshots** in the navigation pane.
3. On the **Snapshots** page, locate the name of the computer or
   disk snapshot you'll use for creating the new computer or disk. Choose the
   **Snapshots** dropdown menu to view a list of available
   snapshots for that resource.
4. Select the snapshot that you want to use to create the virtual
   computer.
5. Choose the **Actions** dropdown menu. Then, choose
   **Create virtual computer** or **Create
   disk**.
