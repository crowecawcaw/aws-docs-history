# Manage cost control rules in Lightsail for Research

Cost control uses rules that you define to help manage the usage and cost of your Lightsail for Research
virtual computers.

You can create a **Stop virtual computer on idle** rule that
stops a running computer when it reaches a specified percentage of its CPU utilization
during a given period. For example, a rule can automatically stop a specific computer when
its CPU utilization is equal to or less than 5% during a 30-minute period. This signifies
that the computer is idle, and Lightsail for Research stops the computer. You no longer incur the standard
hourly charges after the virtual computer is stopped.
