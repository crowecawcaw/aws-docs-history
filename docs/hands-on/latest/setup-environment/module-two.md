# Module 2: (Optional) For Multiple AWS Accounts Managed Through AWS Organizations

## Overview

For multiple AWS accounts managed through AWS Organizations, assign
administrative access to an administrative user in IAM Identity Center. For
instructions, see [Set
up AWS account access for an IAM Identity Center administrative user](../../../singlesignon/latest/userguide/get-started-assign-account-access-admin-user.md "../../../singlesignon/latest/userguide/get-started-assign-account-access-admin-user.md") in
the _IAM Identity Center User Guide_.
