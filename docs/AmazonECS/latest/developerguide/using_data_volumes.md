# Storage options for Amazon ECS tasks

Amazon ECS provides you with flexible, cost effective, and easy-to-use data storage options
depending on your needs. Amazon ECS supports the following data volume options for
containers:

| Data volume                             | Supported capacity                                                | Supported operating systems         | Storage persistence                                                                                                | Use cases                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------- | ----------------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Amazon Elastic Block Store (Amazon EBS) | Fargate, Amazon EC2, Amazon ECS Managed Instances                 | Linux, Windows (on Amazon EC2 only) | Can be persisted when attached to a standalone task. Ephemeral when<br>attached to a task maintained by a service. | Amazon EBS volumes provide cost-effective, durable, high-performance block<br>storage for data-intensive containerized workloads. Common use cases include<br>transactional workloads such as databases, virtual desktops and root<br>volumes, and throughput intensive workloads such as log processing and ETL<br>workloads. For more information, see [Use Amazon EBS volumes with Amazon ECS](ebs-volumes.md "ebs-volumes.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Amazon Elastic File System (Amazon EFS) | Fargate, Amazon EC2, Amazon ECS Managed Instances                 | Linux                               | Persistent                                                                                                         | Amazon EFS volumes provide simple, scalable, and persistent shared file<br>storage for use with your Amazon ECS tasks that grows and shrinks automatically<br>as you add and remove files. Amazon EFS volumes support concurrency and are<br>useful for containerized applications that scale horizontally and need<br>storage functionalities like low latency, high throughput, and<br>read-after-write consistency. Common use cases include workloads such as<br>data analytics, media processing, content management, and web serving. For<br>more information, see [Use Amazon EFS volumes with Amazon ECS](efs-volumes.md "efs-volumes.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Amazon FSx for Windows File Server      | Amazon EC2                                                        | Windows                             | Persistent                                                                                                         | FSx for Windows File Server volumes provide fully managed Windows file servers that you<br>can use to provision your Windows tasks that need persistent, distributed,<br>shared, and static file storage. Common use cases include .NET applications<br>that might require local folders as persistent storage to save application<br>outputs. Amazon FSx for Windows File Server offers a local folder in the container which<br>allows for multiple containers to read-write on the same file system that's<br>backed by a SMB Share. For more information, see [Use FSx for Windows File Server volumes with Amazon ECS](wfsx-volumes.md "wfsx-volumes.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Amazon FSx for NetApp ONTAP             | Amazon EC2 (native mount); Fargate (via S3 Access Points for FSx) | Linux                               | Persistent                                                                                                         | Amazon FSx for NetApp ONTAP volumes provide fully managed NetApp ONTAP file systems that you<br>can use to provision your Linux tasks that need persistent, high-performance,<br>and feature-rich shared file storage. Amazon FSx for NetApp ONTAP supports NFS and SMB protocols<br>and provides enterprise-grade features like snapshots, cloning, and data<br>deduplication. Common use cases include high-performance computing workloads,<br>content repositories, and applications requiring POSIX-compliant shared storage.<br>For more information, see [Mounting Amazon FSx for NetApp ONTAP file systems from Amazon ECS containers](../../../fsx/latest/ONTAPGuide/mount-ontap-ecs-containers.md "../../../fsx/latest/ONTAPGuide/mount-ontap-ecs-containers.md").<br>While native volume mounting of FSx for NetApp ONTAP is available only on the<br>Amazon EC2 launch type, you can access your FSx for NetApp ONTAP data from Fargate tasks<br>using S3 Access Points for FSx. This approach lets your containerized applications read and write<br>FSx for ONTAP data through the Amazon Simple Storage Service API without requiring a direct NFS or<br>SMB mount. For more information, see [Creating an Amazon S3 access point for FSx for ONTAP](../../../fsx/latest/ONTAPGuide/create-access-points.md "../../../fsx/latest/ONTAPGuide/create-access-points.md"). |
| Amazon S3 Files                         | Fargate, Amazon ECS Managed Instances                             | Linux                               | Persistent                                                                                                         | Amazon S3 Files is a high-performance file system that provides fast,<br>cached access to Amazon S3 data through a mountable file system interface.<br>S3 Files volumes give your containers direct file-system access to data<br>stored in S3 buckets. Common use cases include data analytics, machine<br>learning training, and applications that need high-throughput access to S3<br>data. For more information, see [Configuring S3 Files for Amazon ECS](s3files-volumes.md "s3files-volumes.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Docker volumes                          | Amazon EC2                                                        | Windows, Linux                      | Persistent                                                                                                         | Docker volumes are a feature of the Docker container runtime that allow<br>containers to persist data by mounting a directory from the file system of<br>the host. Docker volume drivers (also referred to as plugins) are used to<br>integrate container volumes with external storage systems. Docker volumes<br>can be managed by third-party drivers or by the built in `local`<br>driver. Common use cases for Docker volumes include providing persistent data volumes or<br>sharing volumes at different locations on different containers on the same<br>container instance. For more information, see [Use Docker volumes with Amazon ECS](docker-volumes.md "docker-volumes.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Bind mounts                             | Fargate, Amazon EC2, Amazon ECS Managed Instances                 | Windows, Linux                      | Ephemeral                                                                                                          | Bind mounts consist of a file or directory on the host, such as an Amazon EC2<br>instance or AWS Fargate, that is mounted onto a container. Common use cases for bind mounts<br>include sharing a volume from a source container with other containers in<br>the same task, or mounting a host volume or an empty volume in one or more<br>containers. For more information, see [Use bind mounts with Amazon ECS](bind-mounts.md "bind-mounts.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
