# Resolve Amazon ECS stopped task errors

When your task fails to start, you see an error message in the console and in the
`describe-tasks` output parameters (`stoppedReason` and
`stopCode`).

You can view stopped tasks in the console for one hour. In order to see stopped tasks, you
must change the filter option. For more information, see [Viewing Amazon ECS stopped task errors](stopped-task-errors.md "stopped-task-errors.md").

[Amazon ECS stopped task error messages updates](stopped-tasks-error-messages-updates.md "stopped-tasks-error-messages-updates.md")
