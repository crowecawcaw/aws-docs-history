# Adding tags to Amazon ECS resources

You can tag new or existing tasks, services, task definitions, or clusters. For
information about tagging your container instances, see [Adding tags to an Amazon EC2 container instance for
Amazon ECS](instance-details-tags.md "instance-details-tags.md").

###### Warning

Do not add personally identifiable information (PII) or other confidential or
sensitive information in tags. Tags are accessible to many AWS services, including
billing. Tags are not intended to be used for private or sensitive data.

You can use the following resources to specify tags when you create the
resource.
