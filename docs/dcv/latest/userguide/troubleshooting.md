

# Troubleshooting Amazon DCV
<a name="troubleshooting"></a>

This chapter describes how to identify and troubleshoot problems that you might have with Amazon DCV client.

**Topics**
+ [Using the Log Files](troubleshooting-logs.md)

For additional support, use any of the following resources.
+ If you are a Amazon DCV on-premises customer and you need additional help, contact your Amazon DCV reseller.
+ If you are using Amazon DCV on Amazon EC2, you can log a support ticket with [AWS support](https://docs.aws.amazon.com/awssupport/latest/user/case-management.html).
+ If you do not have an AWS support plan, you can seek help from the Amazon DCV community by posting your question on the [AWS re:Post](https://forums.aws.amazon.com/forum.jspa?forumID=366).
