# Step 1: Get the Amazon DCV session

information

After the Amazon DCV session is running on the Amazon DCV server, you must have specific information to
connect to it. Contact your Amazon DCV administrator if you don't have the following
information:

- The IP address or host name of the Amazon DCV server
- The port that the Amazon DCV server is configured to communicate over. By default, port 8443 is
  used by the Amazon DCV server.
- The session ID
- Sign-in credentials to connect to the Amazon DCV host server
