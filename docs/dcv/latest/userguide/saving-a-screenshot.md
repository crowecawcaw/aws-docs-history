

# Saving a screenshot
<a name="saving-a-screenshot"></a>

You can use Amazon DCV to save a screenshot of the Amazon DCV session. This functionality is available on the Windows, web browser, Linux, and macOS clients.

**Important**  
You must be authorized to use this feature. If you aren't authorized, the functionality isn't available in the client. For more information, see [ Configuring Amazon DCV Authorization](https://docs.aws.amazon.com/dcv/latest/adminguide/security-authorization.html) in the *Amazon DCV Administrator Guide*.

**Note**  
If you aren't authorized to save screenshots, the client also avoids the external tools that are running on your client computer to capture a screenshot of the Amazon DCV client. Images that are obtained by these tools either show a black rectangle instead of the Amazon DCV client window or only show the background desktop. This screenshot protection is available only on Windows and macOS clients.

Launch the client, and connect to the Amazon DCV session. The steps depend on the client used.

------
#### [ Windows ]

1. In the client, choose **Session**, **Save a Screenshot**.  
![Save a screenshot option that's located on the native client toolbar.](https://docs.aws.amazon.com/dcv/latest/userguide/images/screenshot.png)

1. Choose a location and the name for the screenshot file.

------
#### [ macOS ]

1. In the menu bar, choose the **Connection** menu, then select **Save Screenshot…**.  
![Connection menu showing the Save Screenshot option.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-save-screenshot.png)

1. Choose a location and the name for the screenshot file.

------
#### [ Linux ]

1. Go to the **Application menu** and choose **Save Screenshot**.  
![Application menu with the Save Screenshot option highlighted.](https://docs.aws.amazon.com/dcv/latest/userguide/images/linux-save-screenshot.png)

1. Choose a location and the name for the screenshot file.

------
