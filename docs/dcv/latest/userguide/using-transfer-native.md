

# Transferring files using Windows, Linux and macOs clients
<a name="using-transfer-native"></a>

The steps for uploading, downloading, and renaming files depend on the client used.

## Downloading a file
<a name="using-transfer-download-native"></a>

The steps depend on the client used.

------
#### [ Windows ]

The file is downloaded to your desktop.

1. In the client, choose **Storage**.  
![Storage button located in the top-left corner of the interface.](https://docs.aws.amazon.com/dcv/latest/userguide/images/storage.png)

1. In the **File Storage** window, either select the file to download, or choose the down arrow next to the file and then choose **Download**.

------
#### [ macOS ]

Downloaded files are saved to your Downloads folder.

1. Choose the **File Storage** toolbar button.  
![File Storage toolbar button.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-filestorage.png)
**Tip**  
You can also open File Storage from the menu bar. Choose the **View** menu, then select **File Storage…**.

1. Navigate to the file using the breadcrumb bar, back/forward buttons, or the search field.  
![File Storage window showing a sortable table with breadcrumb bar and search field.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-filestorage-list.png)

1. Do one of the following:
   + Double-click the file.
   + Select the file and press **Return**.
   + Open the file's context menu and choose **Download**.  
![Context menu showing Download, Rename, and Delete options.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-filestorage-download.png)

**Tip**  
You can select multiple files, then choose the **Download** toolbar button to download them all.

------
#### [ Linux ]

Downloaded files are saved to your Downloads folder.

1. In the client, choose **Storage**.

1. Navigate to the file using the breadcrumb buttons at the top of the **File Storage** window.

1. Choose the down arrow next to the file and then choose **Download**.

------

## Uploading a file
<a name="using-transfer-upload-native"></a>

Files that you upload to a session are saved to a path that's specified by the Amazon DCV server administrator. 

The steps depend on the client used.

------
#### [ Windows ]

**To upload a file**

1. Choose **Storage** in the client.

1. Do one of the following:
   + To upload the file to an existing folder:

     Navigate to the folder within the **File Storage** window.
   + To upload the file to a new folder

     1. Choose **Create Folder**.

     1. Enter folder name.

     1. Open the new folder.

1. Choose **Upload File** in the **File Storage** window.

1. Select the file to upload.

1. Choose **Open**.

**To drag and drop a file**

1. Navigate to **File Storage**, the folder, or the subfolder you would like to upload the file and open it.

1. On your local computer, select one or more files or folders you would like to upload.

1. Drag the selected file(s) or folder(s) onto the Amazon DCV session window.
**Note**  
If the **File Storage** window is closed, it will automatically open.

1. Drop your files within the drop area of your desired location in **File Storage**, selected folder, or selected subfolder window.

------
#### [ macOS ]

**To upload a file**

1. Choose the **File Storage** toolbar button.

1. Navigate to the destination folder.

1. Choose the **Upload** toolbar button and select the files to upload.  
![File Storage toolbar showing the Upload button.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-filestorage-upload.png)

**To drag and drop files**

1. Open the **File Storage** window and navigate to the destination folder.

1. Drag files from Finder onto the **File Storage** window.

**Tip**  
To create a new folder, choose the **New Folder** toolbar button, enter a name, and choose **Create**.

------
#### [ Linux ]

**To upload a file**

1. Choose **Storage** in the client.

1. Navigate to the destination folder using the breadcrumb buttons.

1. Do one of the following:
   + To create a new folder, choose the **Create folder** button, enter a name, and choose **Create**.

1. Choose the **Upload** button and select the files to upload.

**To drag and drop a file**

1. Open the **File Storage** window and navigate to the destination folder.

1. Drag files from your file manager onto the **File Storage** window.

------

## Renaming a file
<a name="using-transfer-rename-native"></a>

You can change the name of the file in session storage. The steps depend on the client used.

------
#### [ Windows ]

1. In the client, choose **Storage**.

1. Choose the down arrow that's next to the file to rename, and choose **Rename**.

1. Enter the new file name and press **Enter**.

------
#### [ macOS ]

1. Choose the **File Storage** toolbar button.

1. Do one of the following:
   + Open the item's context menu and choose **Rename**.
   + Click once on an already selected item's name to enter edit mode.  
![Context menu showing the Rename option.](https://docs.aws.amazon.com/dcv/latest/userguide/images/mac-filestorage-rename.png)

1. Enter the new name and press **Return**.

**Tip**  
To delete files on the macOS client, select one or more items, open the context menu, and choose **Delete**.

------
#### [ Linux ]

1. In the client, choose **Storage**.

1. Choose the down arrow next to the file to rename, and choose **Rename**.

1. Enter the new file name and press **Enter**.

**Tip**  
To delete files on the Linux client, choose the down arrow next to the file and choose **Delete**.

------
