# Agent Configuration File

The agent configuration file (`/etc/dcv-session-manager-agent/agent.conf` for Linux and macOS, and
`C:\Program Files\NICE\DCVSessionManagerAgent\conf\agent.conf` for Windows) includes
parameters that can be configured to customize the Session Manager functionality. You can edit the configuration file
using your preferred text editor.

The following table lists the parameters in the agent configuration file.

| Parameter name                           | Required | Default value                                                                                                              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent.broker_host`                      | Yes      |                                                                                                                            | Specifies the DNS name of the broker host.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `agent.broker_port`                      | Yes      | `8445`                                                                                                                     | Specifies the port over which to communicate with the broker.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `agent.ca_file`                          | No       |                                                                                                                            | Only needed if `tls_strict` is set to `true`. Specifies the path<br>to the certificate (.pem) file needed to validate the TLS certificate.<br>Copy the self-signed certificate from the broker to the agent.                                                                                                                                                                                                                                                                                                                  |
| `agent.init_folder`                      | No       | • `/var/lib/dcv-session-manager-agent/init` (Linux)                                                                        | Specifies the path to a folder on the host server used to store custom scripts allowed to<br>initialize Amazon DCV server sessions when they are created. You must specify an absolute path. The folder must<br>be accessible and the files must be executable by users who make use of the **InitFile\*<br>• request parameter of the **CreateSessions\*<br>• API.                                                                                                                                                           |
| `agent.tls_strict`                       | No       | `true`                                                                                                                     | Indicates whether strict TLS validation should be used.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `agent.software_statement_path`          | No       |                                                                                                                            | Only needed if the default software statement is not used. Specifies the path to the software<br>statement file. For more information, see [generate-software-statement](generate-software-statement.md "generate-software-statement.md").                                                                                                                                                                                                                                                                                    |
| `agent.tags_folder`                      | No       | • `/etc/dcv-session-manager-agent` (Linux/macOS)<br>• `C:\Program Files\NICE\DCVSessionManagerAgent\conf\tags` (Windows)   | Specifies the path to the folder in which the tag files are located. For more information, see<br>[Using tags to target Amazon DCV servers](targeting.md "targeting.md").                                                                                                                                                                                                                                                                                                                                                     |
| `agent.autorun_folder`                   | No       | • `/var/lib/dcv-session-manager-agent/autorun` (Linux)<br>• `C:\ProgramData\NICE\DcvSessionManagerAgent\autorun` (Windows) | Specifies the path to a folder on the host server used to store scripts and apps that<br>are allowed to be automatically run at session startup. You must specify an absolute path.<br>The folder must be accessible and the files must be executable by users who make use of<br>the **AutorunFile\*<br>• request parameter of the **CreateSessions\*<br>• API.                                                                                                                                                              |
| `agent.max_virtual_sessions`             | No       | -1 (no limit)                                                                                                              | The maximum number of virtual sessions that can be created on a Amazon DCV server using Amazon DCV Session Manager.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `agent.max_concurrent_sessions_per_user` | No       | 1                                                                                                                          | The maximum number of virtual sessions that can be created on a Amazon DCV server by a single<br>user using Amazon DCV Session Manager.                                                                                                                                                                                                                                                                                                                                                                                       |
| `agent.broker_update_interval`           | No       | 30                                                                                                                         | Specifies the amount of seconds to wait before sending updated data to the broker.<br>Sent data includes Amazon DCV server and host status, as well as updated session information.<br>Lower values make the Session Manager more aware of changes happening on the system where the agent runs,<br>but increase system load and network traffic.<br>Higher values decrease system and network load, but the Session Manager becomes less responsive to system changes,<br>thus values higher than `120` are not recommended. |
| `agent.enable_query_logged_in_users`     | No       | true                                                                                                                       | Enable getting logged users on Windows. When true, queries system for actual logged-in users.<br>When false, returns "unknown"                                                                                                                                                                                                                                                                                                                                                                                                |
| `agent.preferred_network_interface`      | No       |                                                                                                                            | Specifies the network interface name to use for host IP detection. Examples: `eth0` (Linux), `Ethernet 4` (Windows).<br>Linux/macOS names are case-sensitive, Windows names are case-insensitive.<br>If not specified or if the specified network interface is not found, first non-loopback interface is selected.                                                                                                                                                                                                           |
| `log.level`                              | No       | `info`                                                                                                                     | Specifies the verbosity level of the log files. The following verbosity levels are available:<br>• `error`—Provides the least detail. Includes errors only.<br>• `warning`—Includes errors and warnings.<br>• `info`—The default verbosity level. Includes errors, warnings, and information messages.<br>• `debug`—Provides the most detail. Provides detailed information that is useful for debugging issues.                                                                                                              |
| `log.directory`                          | No       | • `/var/log/dcv-session-manager-agent/` (Linux/macOS)<br>• `C:\ProgramData\NICE\DCVSessionManagerAgent\log` (Windows)      | Specifies the directory in which to create log files.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `log.rotation`                           | No       | `daily`                                                                                                                    | Specifies the log file rotation. Valid values are:<br>• `hourly`—Log files are rotated hourly.<br>• `daily`—Log files are rotated daily.                                                                                                                                                                                                                                                                                                                                                                                      |
| `log.max-file-size`                      | No       | `10485760`                                                                                                                 | When a log file size reaches the specified size in bytes, it will be rotated. A new log file will be created and further log events will be placed in the new file.                                                                                                                                                                                                                                                                                                                                                           |
| `log.rotate`                             | No       | `9`                                                                                                                        | The maximum number of log files preserved in the rotation. Each time a rotation happens and this number is reached, the oldest log file will be deleted.                                                                                                                                                                                                                                                                                                                                                                      |
