# Step 1: Install the Amazon DCV Server

The following topics describe how to install the latest version of the Amazon DCV server on Windows
and Linux. Follow these steps if you're installing Amazon DCV on an Amazon EC2 instance or other
on-premises or cloud-based server.

###### Note

If you're upgrading from an earlier version of the Amazon DCV server to the latest version, see [Upgrading the Amazon DCV Server](setting-up-upgrading.md "setting-up-upgrading.md").

- [Installing the Amazon DCV Server on Linux](setting-up-installing-linux.md "setting-up-installing-linux.md")
