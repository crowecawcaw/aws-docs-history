

# Installing the Amazon DCV Server on Linux
<a name="setting-up-installing-linux"></a>

You can install the Amazon DCV server on a Linux server to run your Amazon DCV sessions on it. The installation steps depend on the display protocol your operating system uses. Find your operating system in the following table to see its display protocol, then follow the linked installation instructions.


| Operating system | Display protocol | Installation instructions | 
| --- | --- | --- | 
| Amazon Linux 2023 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| RHEL, CentOS, and Rocky Linux 8 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| RHEL, CentOS, and Rocky Linux 9 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| RHEL, CentOS, and Rocky Linux 10 | Wayland | [Installing the Amazon DCV Server on Linux with Wayland](setting-up-installing-linux-wayland.md) | 
| SUSE Linux Enterprise 15 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| Ubuntu 22.04 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| Ubuntu 24.04 | X11 | [Installing the Amazon DCV Server on Linux with X11](setting-up-installing-linux-x11.md) | 
| Ubuntu 26.04 | Wayland | [Installing the Amazon DCV Server on Linux with Wayland](setting-up-installing-linux-wayland.md) |
