# Understanding permissions files

You can create a custom permissions file or update an existing permissions file using your preferred text editor. A permissions file
typically takes the following format:

```
#import `file_to_import`

[groups]
`group_definitions`

[aliases]
`alias_definitions`

[permissions]
`user_permissions`

```

The following sections explain how to populate the sections when updating or creating a permissions file.
