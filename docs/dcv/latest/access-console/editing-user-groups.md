# Editing user groups

You can edit a user group directly from the Access Console, and are able to modify
the group name, users in the group and templates assigned to the group.

###### To edit a user group

1. Go to the **User groups** page.
2. Select the user group you want to edit.
3. Select the **Edit** button.
4. Edit the name, add or remove users, or add or remove session
   templates.
5. Select the **Submit** button.
