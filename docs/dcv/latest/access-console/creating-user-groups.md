# Creating user groups

You can create a user group directly from the Access Console, by selecting users
and assigning templates.

###### To create a user group

1. Go to the **User groups** page.
2. Select the **Create user group** button.
3. In **Group ID**, enter a unique identifier for your
   group. After you create the group, you cannot edit the ID.
4. In **Name**, enter a user friendly name for your group.
5. In **Add users**, select the users you wish to add to the
   group.
6. In **Template**, select the templates you wish to assign
   to the group.
7. Select the **Submit** button.
