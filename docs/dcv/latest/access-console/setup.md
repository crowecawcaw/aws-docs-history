# Setting up Amazon DCV Access Console

When setting up your Amazon DCV Access Console, you can choose whether you want to run the
console on a single host or, if you choose, across a set of multiple hosts. Using multiple
hosts can improve scalability and performance. The Console works with either
configuration.

The following section explains how to set up Amazon DCV Access Console on a single host and on
separate multiple hosts.
