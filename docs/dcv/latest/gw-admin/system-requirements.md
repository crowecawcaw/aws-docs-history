# System requirements

For Amazon DCV Connection Gateway to run properly, your system must meet the following requirements.

|                      |                                                                                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Operating system** | <br>• Amazon Linux 2 <br>• Amazon Linux 2023 <br>• RHEL 8/Rocky 8 <br>• RHEL 9/Rocky 9 <br>• CentOS Stream 9 <br>• Ubuntu 22.04 <br>• Ubuntu 24.04 |
| **Architecture**     | <br>• 64-bit x86 <br>• 64-bit ARM                                                                                                                  |
