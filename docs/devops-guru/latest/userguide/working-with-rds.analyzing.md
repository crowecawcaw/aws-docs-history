# Viewing insights

Access the **Insights** page in the DevOps Guru console to find reactive and proactive insights. From there, you can choose an insight from the list
to view a detailed page of metrics, recommendations, and more information about the insight.

###### To view an insight

1. Open the Amazon DevOps Guru console at [https://console.aws.amazon.com/devops-guru/](https://console.aws.amazon.com/devops-guru/ "https://console.aws.amazon.com/devops-guru/").
2. Open the navigation pane, and then choose **Insights**.
3. Choose the **Reactive** tab to view reactive insights,
   or choose **Proactive** to view proactive insights.
4. Choose the name of an insight, prioritizing by status and severity.

The detailed insight page appears.
