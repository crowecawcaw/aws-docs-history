# SessionActionDefinitionSummary

The details of a session action definition.


## Contents


###### Important

This data type is a UNION, so only one of the following members can be specified when used or returned.

Type: [EnvironmentEnterSessionActionDefinitionSummary](API_EnvironmentEnterSessionActionDefinitionSummary.md "API_EnvironmentEnterSessionActionDefinitionSummary.md") object


Required: No

Type: [EnvironmentExitSessionActionDefinitionSummary](API_EnvironmentExitSessionActionDefinitionSummary.md "API_EnvironmentExitSessionActionDefinitionSummary.md") object


Required: No




**syncInputJobAttachments**

Type: [SyncInputJobAttachmentsSessionActionDefinitionSummary](API_SyncInputJobAttachmentsSessionActionDefinitionSummary.md "API_SyncInputJobAttachmentsSessionActionDefinitionSummary.md") object
