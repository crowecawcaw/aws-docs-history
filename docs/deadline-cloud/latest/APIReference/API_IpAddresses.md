# IpAddresses

The IP addresses for a host.


## Contents





**ipV4Addresses** 


The IpV4 address of the network.


Type: Array of strings


Pattern: `(?:[0-9]{1,3}\.){3}[0-9]{1,3}`



Required: No




**ipV6Addresses** 


The IpV6 address for the network and node component.


Type: Array of strings


Pattern: `(?:[A-F0-9]{1,4}:){7}[A-F0-9]{1,4}`



Required: No
