# PathMappingRule

The details of a source and destination path.


## Contents





**destinationPath** 


The destination path.


Type: String


Required: Yes




**sourcePath** 


The source path.


Type: String


Required: Yes




**sourcePathFormat** 


The source path format.


Type: String


Valid Values: `windows | posix`



Required: Yes
