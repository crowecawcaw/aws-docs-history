# VCpuCountRange

The allowable range of vCPU processing power for the fleet.


## Contents





**min** 


The minimum amount of vCPU.


Type: Integer


Valid Range: Minimum value of 1. Maximum value of 10000.


Required: Yes




**max** 


The maximum amount of vCPU.


Type: Integer


Valid Range: Minimum value of 1. Maximum value of 10000.


Required: No
