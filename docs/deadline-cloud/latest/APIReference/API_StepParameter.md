# StepParameter

The details of a step parameter.


## Contents





**name** 


The name of the parameter.


Type: String


Length Constraints: Minimum length of 1. Maximum length of 64.


Required: Yes




**type** 


The data type of the parameter.


Type: String


Valid Values: `INT | FLOAT | STRING | PATH | CHUNK_INT`



Required: Yes
