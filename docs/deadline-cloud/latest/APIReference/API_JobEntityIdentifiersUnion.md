# JobEntityIdentifiersUnion

The details of a job entity identifier.


## Contents


###### Important

This data type is a UNION, so only one of the following members can be specified when used or returned.





**environmentDetails** 


The environment details.


Type: [EnvironmentDetailsIdentifiers](API_EnvironmentDetailsIdentifiers.md "API_EnvironmentDetailsIdentifiers.md") object


Required: No




**jobAttachmentDetails** 


The job attachment details.


Type: [JobAttachmentDetailsIdentifiers](API_JobAttachmentDetailsIdentifiers.md "API_JobAttachmentDetailsIdentifiers.md") object


Required: No




**jobDetails** 


The job details.


Type: [JobDetailsIdentifiers](API_JobDetailsIdentifiers.md "API_JobDetailsIdentifiers.md") object


Required: No




**stepDetails** 


The step details.


Type: [StepDetailsIdentifiers](API_StepDetailsIdentifiers.md "API_StepDetailsIdentifiers.md") object


Required: No
