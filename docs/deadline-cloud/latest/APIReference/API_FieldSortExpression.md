# FieldSortExpression

The field sorting order and name of the field.


## Contents





**name** 


The name of the field.


Type: String


Required: Yes




**sortOrder** 


The sort order for the field.


Type: String


Valid Values: `ASCENDING | DESCENDING`



Required: Yes
