# Stats

The minimum, maximum, average, and sum.


## Contents





**avg** 


The average of the usage statistics.


Type: Double


Required: No




**max** 


The maximum among the usage statistics.


Type: Double


Required: No




**min** 


The minimum of the usage statistics.


Type: Double


Required: No




**sum** 


The sum of the usage statistics.


Type: Double


Required: No
