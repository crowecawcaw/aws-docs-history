# AwsCredentials

The AWS Identity and Access Management credentials.


## Contents





**accessKeyId** 


The IAM access key ID.


Type: String


Required: Yes




**expiration** 


The expiration date and time of the IAM credentials.


Type: Timestamp


Required: Yes




**secretAccessKey** 


The IAM secret access key.


Type: String


Required: Yes




**sessionToken** 


The IAM session token


Type: String


Required: Yes
