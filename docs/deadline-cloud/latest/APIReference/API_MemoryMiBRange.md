# MemoryMiBRange

The range of memory in MiB.


## Contents





**min** 


The minimum amount of memory (in MiB).


Type: Integer


Valid Range: Minimum value of 512. Maximum value of 2147483647.


Required: Yes




**max** 


The maximum amount of memory (in MiB).


Type: Integer


Valid Range: Minimum value of 512. Maximum value of 2147483647.


Required: No
