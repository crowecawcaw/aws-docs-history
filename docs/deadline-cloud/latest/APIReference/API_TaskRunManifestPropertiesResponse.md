# TaskRunManifestPropertiesResponse

The manifest properties for a task run, corresponding to the manifest properties in the job.


## Contents





**outputManifestHash** 


The hash value of the file.


Type: String


Required: No




**outputManifestPath** 


The manifest file path.


Type: String


Required: No
