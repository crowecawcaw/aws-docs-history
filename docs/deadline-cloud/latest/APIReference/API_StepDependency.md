# StepDependency

The details of step dependency.


## Contents





**status** 


The step dependency status.


Type: String


Valid Values: `RESOLVED | UNRESOLVED`



Required: Yes




**stepId** 


The step ID.


Type: String


Pattern: `step-[0-9a-f]{32}`



Required: Yes
