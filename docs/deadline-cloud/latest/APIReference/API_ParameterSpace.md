# ParameterSpace

The details of a search for two or more step parameters.


## Contents





**parameters** 


The parameters to search for.


Type: Array of [StepParameter](API_StepParameter.md "API_StepParameter.md") objects


Required: Yes




**combination** 


The combination expression to use in the search.


Type: String


Length Constraints: Minimum length of 1. Maximum length of 1280.


Required: No
