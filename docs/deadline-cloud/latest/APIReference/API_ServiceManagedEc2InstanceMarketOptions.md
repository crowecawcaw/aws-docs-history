# ServiceManagedEc2InstanceMarketOptions

The details of the Amazon EC2 instance market options for a service managed fleet.


## Contents





**type** 


The Amazon EC2 instance type.


Type: String


Valid Values: `on-demand | spot | wait-and-save`



Required: Yes
