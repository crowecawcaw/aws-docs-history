

# Work with Deadline Cloud workers
<a name="workers"></a>

A worker is a host in a fleet that runs the tasks that make up your jobs. The topics in this chapter apply to workers on both service-managed and customer-managed fleets. For topics that apply to one fleet type, see [Configure and use Deadline Cloud service-managed fleets](smf.md) or [Create and use Deadline Cloud customer-managed fleets](manage-cmf.md). For how a step's host requirements match the capabilities of a fleet's workers, see [Host requirements and fleet capabilities](host-requirements-overview.md).
