

# Use every Open Job Description GUI control on Deadline Cloud
<a name="examples-jb-gui-controls"></a>

The [gui\_control\_showcase job bundle](https://github.com/aws-deadline/deadline-cloud-samples/tree/mainline/job_bundles/gui_control_showcase) on the GitHub website shows every GUI control supported by user interface metadata on Open Job Description job parameters. Use it as a reference when you add GUI controls to your own job templates. For more information about the parameter schema, see [JobParameterDefinition](https://github.com/OpenJobDescription/openjd-specifications/wiki/2023-09-Template-Schemas#2-jobparameterdefinition) on the GitHub website.

Open the GUI submitter to see every control:

```
deadline bundle gui-submit job_bundles/gui_control_showcase
```

![The job-specific settings tab for the gui_control_showcase bundle, showing generated controls grouped by type.](http://docs.aws.amazon.com/deadline-cloud/latest/developerguide/images/gui-control-showcase.png)
