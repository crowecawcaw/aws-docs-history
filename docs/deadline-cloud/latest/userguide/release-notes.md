# Deadline Cloud release notes

This page contains information about the latest releases and updates to AWS Deadline Cloud.

| Date       | Title                                                                                                                                                                                                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2025-12-11 | [Deadline Cloud developer guide now includes guidance on using AI agents](../developerguide/ai-agents.md "../developerguide/ai-agents.md")                                                                    | The Deadline Cloud developer guide now includes best practices for using AI agents with AWS Deadline Cloud in order to write job bundles, develop conda packages, and troubleshoot jobs more efficiently.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 2025-12-11 | [User guide now available for Autodesk VRED submitter](https://aws-deadline.github.io/vred/ "https://aws-deadline.github.io/vred/")                                                                           | Documentation for the AWS Deadline Cloud submitter for Autodesk VRED is now available. The guide covers how to install the submitter and submit rendering jobs to Deadline Cloud. This helps VRED users get started quickly with cloud rendering.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 2025-12-10 | [Deadline Cloud documentation now includes LicensesInUse metric](../developerguide/cloudwatch-metrics.md#cloudwatch-metrics-licensing "../developerguide/cloudwatch-metrics.md#cloudwatch-metrics-licensing") | The Deadline Cloud documentation now includes information about the LicensesInUse metric. This metric helps you monitor how many licenses your jobs are currently consuming across your fleets. You can use this information to optimize license usage and to avoid running out of licenses when scaling out workloads.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 2025-12-10 | [Cinema 4D 2026.1 Support on Service-Managed Fleets](create-queue-environment.md "create-queue-environment.md")                                                                                               | Maxon Cinema 4D 2026.1 is now supported on Linux and Windows service-managed fleets. This release includes Redshift 2026.2.0. Cross-platform font rendering support has also been added for all versions of Cinema 4D. This release allows customers to use the latest Cinema 4D features. It also enables customers to use custom fonts on cross-platform setups, such as when submitting jobs from Windows while using the faster startup time and lower cost of Linux workers.                                                                                                                                                                                                                                                         |
| 2025-12-09 | [Enhanced Autodesk Maya Submitter Setup and Usage Documentation](https://aws-deadline.github.io/maya/ "https://aws-deadline.github.io/maya/")                                                                 | New setup and usage documentation added for the AWS Deadline Cloud Submitter for Autodesk Maya.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 2025-12-09 | [Deadline Cloud Release Notes](release-notes.md "release-notes.md")                                                                                                                                           | All major changes to Deadline Cloud features, applications, integrations, samples and documentation will now be listed on the Release Notes page in the User Guide going forward. You can find previous major Deadline Cloud releases at [AWS What's New](https://aws.amazon.com/new/?ams%23article-feed%23pattern-data--111430994.filter=%257B%2522search%2522%253A%2522deadline%2520cloud%2522%257D "https://aws.amazon.com/new/?ams%23article-feed%23pattern-data--111430994.filter=%257B%2522search%2522%253A%2522deadline%2520cloud%2522%257D") and CLI/Worker/integration-specific release notes in the repositories of the [Deadline Cloud github organization](https://github.com/aws-deadline "https://github.com/aws-deadline") |
| 2025-12-09 | [After Effects submitter 0.4.4 improves macOS installation and font support](https://aws-deadline.github.io/after-effects/releases/ "https://aws-deadline.github.io/after-effects/releases/")                 | The After Effects submitter now automatically installs to the user preferences directory on macOS, removing the need for manual installation. This release also adds support for most TrueType Collection (TTC) font files, allowing you to submit and render jobs that use these fonts. These improvements simplify setup and expand font compatibility for After Effects users.                                                                                                                                                                                                                                                                                                                                                         |
