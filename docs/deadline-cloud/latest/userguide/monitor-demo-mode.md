

# Explore the Deadline Cloud monitor in demo mode
<a name="monitor-demo-mode"></a>

The AWS Deadline Cloud monitor (Deadline Cloud monitor) has a demo mode that fills the web monitor with sample data, so you can explore the monitor without signing in or creating any AWS resources. To start, open the [Deadline Cloud monitor demo](https://_demo.us-east-1.deadlinecloud.amazonaws.com/?demo=moonrise).

The sample data belongs to a fictional studio with two farms in different AWS Regions. The farms have queues of running and finished jobs, fleets of workers, budgets, and usage history. Jobs in the demo progress over time, as they do on a working farm. The demo generates its data in your browser and doesn't connect to an AWS account, so nothing that you do in the demo changes any resources.

While demo mode is on, the monitor shows a **Demo** badge next to the Deadline Cloud name in the header. Demo mode stays on in the browser tab until you close the tab or sign out. To leave demo mode, open the user menu in the upper-right corner and choose **Sign out**.

Pages in this guide that describe a monitor feature link to that feature in the demo, so you can try it while you read.
