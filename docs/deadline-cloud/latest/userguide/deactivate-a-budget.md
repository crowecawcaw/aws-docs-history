# Deactivate a budget for a Deadline Cloud queue

You can deactivate any active budget. Deactivating a budget changes its status from
 **Active** to **Inactive**. When a budget is
 deactivated, it no longer tracks a resource to that budgetâs amount.

To deactivate a budget, use the following procedure.

1. If you haven't already, sign in to the AWS Management Console, open the Deadline Cloud [console](https://us-west-2.console.aws.amazon.com/deadlinecloud/home "https://us-west-2.console.aws.amazon.com/deadlinecloud/home"), choose a farm, and then choose **Manage
 jobs**.
2. From the **Budget manager** page, in the **Active
 Budgets** tab, choose the button next to the budget that you want
 to deactivate.
3. From the **Actions** dropdown menu, select
 **Deactivate budget**. In a few moments, the selected
 budget will change from **Active** to
 **Inactive** and will move from the **Active
 Budgets** tab to the **Inactive Budgets**
 tab.
