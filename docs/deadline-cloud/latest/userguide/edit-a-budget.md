# Edit a budget for a Deadline Cloud queue

You can edit any active budget. To edit an active budget, use the following
procedure.

1. If you haven't already, sign in to the AWS Management Console, open the Deadline Cloud [console](https://us-west-2.console.aws.amazon.com/deadlinecloud/home "https://us-west-2.console.aws.amazon.com/deadlinecloud/home"), choose a farm, and then choose **Manage
   jobs**.
2. From the **Budget Manager** page, in the **Active
   budgets** tab, choose the button next to the budget you want to
   edit.
3. From the **Actions** dropdown menu, select **Edit
   budget**.
4. Make the changes that you want, and then choose **Update
   budget**.
