

# Managing your Amazon Connect Decisions instance
<a name="getting-started-managing-your-amazon-connect-decisions-instance"></a>

 Creating an instance in Amazon Connect Decisions establishes a dedicated environment for supply chain management and analytics. To set up an instance, you configure basic details, establish settings, and define initial user access permissions. 

 Only the AWS Management Console administrator can create an instance. The AWS Management Console administrator who creates the Amazon Connect Decisions instance should have all permissions listed under [Identity-based policy examples](https://docs.aws.amazon.com/connect-decisions/latest/adminguide/identity-based-policy-examples.html). This administrator should invite an IAM user as an Amazon Connect Decisions administrator to manage Amazon Connect Decisions.
