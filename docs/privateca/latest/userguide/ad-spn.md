# Configuring the service principal name

Learn how to configure the service principal name for the connector.

Console

**To manage manage service principal names using the console**

The service principal name (SPN) of an existing AD connector can be managed from the
details page of the connector. For more information, see Managing directory registration
[View connector
details](view-connector-for-ad.md "view-connector-for-ad.md")

API

**To manage service principal names using the API**

**Create**: [CreateServicePrincipalName](../../../pca-connector-ad/latest/APIReference/API_CreateServicePrincipalName.md "../../../pca-connector-ad/latest/APIReference/API_CreateServicePrincipalName.md") action in the AWS Private CA Connector for Active Directory API.

**Retrieve**: [GetServicePrincipalName](../../../pca-connector-ad/latest/APIReference/API_GetServicePrincipalName.md "../../../pca-connector-ad/latest/APIReference/API_GetServicePrincipalName.md") action in the AWS Private CA Connector for Active Directory API.

**List**: [ListServicePrincipalNames](../../../pca-connector-ad/latest/APIReference/API_ListServicePrincipalNames.md "../../../pca-connector-ad/latest/APIReference/API_ListServicePrincipalNames.md") action in the AWS Private CA Connector for Active Directory API.

**Delete**: [DeleteServicePrincipalName](../../../pca-connector-ad/latest/APIReference/API_DeleteServicePrincipalName.md "../../../pca-connector-ad/latest/APIReference/API_DeleteServicePrincipalName.md") action in the AWS Private CA Connector for Active Directory API.

CLI

**To manage service principal names using the CLI**

**Create**: [create-service-principal-name](../../../cli/latest/reference/pca-connector-ad/create-service-principal-name.md "../../../cli/latest/reference/pca-connector-ad/create-service-principal-name.md") command in the AWS Private CA Connector for Active Directory section of
the AWS CLI.

**Retrieve**: [get-service-principal-name](../../../cli/latest/reference/pca-connector-ad/get-service-principal-name.md "../../../cli/latest/reference/pca-connector-ad/get-service-principal-name.md") command in the AWS Private CA Connector for Active Directory section of the
AWS CLI.

**List**: [list-service-principal-names](../../../cli/latest/reference/pca-connector-ad/list-service-principal-names.md "../../../cli/latest/reference/pca-connector-ad/list-service-principal-names.md") command in the AWS Private CA Connector for Active Directory section of
the AWS CLI.

**Delete**: [delete-service-principal-name](../../../cli/latest/reference/pca-connector-ad/delete-service-principal-name.md "../../../cli/latest/reference/pca-connector-ad/delete-service-principal-name.md") command in the AWS Private CA Connector for Active Directory section of
the AWS CLI.
