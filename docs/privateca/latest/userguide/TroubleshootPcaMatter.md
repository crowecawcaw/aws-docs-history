# Troubleshoot AWS Private CA Matter-compliant certificate errors

The [Matter connectivity
standard](https://github.com/project-chip/connectedhomeip "https://github.com/project-chip/connectedhomeip") specifies certificate configurations that improve the security and
consistency of internet of things (IoT) devices. Java samples for creating
Matter-compliant root CA, intermediate CA, and end-entity certificates can be found at
[Use AWS Private CA to implement Matter certificates](API-CBR-intro.md "API-CBR-intro.md").

To assist with troubleshooting, the Matter developers provide a certificate
verification tool called [chip-cert](https://github.com/project-chip/connectedhomeip/tree/master/src/tools/chip-cert "https://github.com/project-chip/connectedhomeip/tree/master/src/tools/chip-cert"). Errors that the tool reports are listed in the following table
with remediations.

| 0x00000014 | Certificate chain validation failure.                                                             | This error may be encountered if you attempt to create a<br>Matter-compliant end-entity certificate without using the provided<br>[Java examples](API-CBR-intro.md "API-CBR-intro.md"), which use<br>the AWS Private CA API to pass a properly configured KeyUsage.<br>By default, AWS Private CA generates nine-bit KeyUsage extension<br>values, with the ninth bit resulting in an extra byte.
