# Use AWS Private CA to implement mDL certificates

You can use the AWS Private Certificate Authority API to create certificates that conform to the [ISO/IEC standard for mobile driving
license (mDL)](https://www.iso.org/standard/69084.html "https://www.iso.org/standard/69084.html") . This standard establishes interface specifications for the
implementation of a driving license in association with a mobile device, including
certificate configurations.
