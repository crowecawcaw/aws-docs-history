# Monitor Kubernetes with AWS Private CA

To monitor the Kubernetes cluster private CA, use the techniques outlined in [Monitor AWS Private CA resources](logging-and-monitoring.md "logging-and-monitoring.md"). You can use
the following to monitor a private CA:

- [AWS Private CA CloudWatch metrics](PcaCloudWatch.md "PcaCloudWatch.md")
- [Monitor AWS Private CA with CloudWatch Events](CloudWatchEvents.md "CloudWatchEvents.md")
- [Logging AWS Private Certificate Authority API calls using AWS CloudTrail](logging-using-cloudtrail-pca.md "logging-using-cloudtrail-pca.md")
