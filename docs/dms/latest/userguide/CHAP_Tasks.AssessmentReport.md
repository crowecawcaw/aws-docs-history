# Individual assessments

This section describes individual premigration assessments.

To create an individual premigration assessment using the AWS DMS API, use the listed API key for the `IncludeOnly`
parameter of the [StartReplicationTaskAssessmentRun](../APIReference/API_StartReplicationTaskAssessmentRun.md "../APIReference/API_StartReplicationTaskAssessmentRun.md") action.
