

# PostgreSQL to MySQL conversion settings
<a name="schema-conversion-postgresql-mysql"></a>

The PostgreSQL to MySQL conversion path has no pair-specific conversion settings. Only the common settings that apply to every conversion path are available, such as the severity level for action-item comments in converted SQL and the option to use generative AI for conversion.

To configure these common settings, see [Common conversion settings](schema-conversion-settings.md#schema-conversion-settings-common).
