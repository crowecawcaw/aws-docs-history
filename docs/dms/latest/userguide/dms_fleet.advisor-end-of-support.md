

# AWS DMS Fleet Advisor end of support
<a name="dms_fleet.advisor-end-of-support"></a>

**Important**  
End of support notice: On May 20, 2026, AWS will end support for AWS Database Migration Service Fleet Advisor. After May 20, 2026, you will no longer be able to access the AWS DMS Fleet Advisor console or AWS DMS Fleet Advisor resources. For more information, see [AWS DMS Fleet Advisor end of support](https://docs.aws.amazon.com/dms/latest/userguide/dms_fleet.advisor-end-of-support.html).

## AWS DMS Fleet Advisor end of support details
<a name="CHAP_FleetAdvisor_disc.details"></a>

### End of support plan
<a name="CHAP_FleetAdvisor_disc.plan"></a>

After careful consideration, we decided to end support for AWS DMS Fleet Advisor, effective May 20, 2026. AWS DMS Fleet Advisor will no longer accept new customers beginning May 20, 2025. As an existing customer with an account signed up for AWS DMS before May 20, 2025 you can continue to use AWS DMS Fleet Advisor and its features. After May 20, 2026, you will no longer be able to use AWS DMS Fleet Advisor.

To help you plan and migrate away from Fleet Advisor, we will discontinue the offering gradually over 12 months. There are two important dates to note: May 20, 2025 and May 20, 2026.

We will discontinue the service on May 20, 2026. You will not be able to download or use AWS DMS Fleet Advisor capabilities. Support will no longer be available for AWS DMS Fleet Advisor from that time. We recommend that you migrate your database assessment projects to AWS Migration Evaluator before May 20, 2026.

### FAQ
<a name="CHAP_FleetAdvisor_disc.faq"></a>

**What is the cutoff point for “current customers”?**  
We maintain an allow list of account IDs who have used AWS DMS Fleet Advisor in last 90 days, including detectors, within the service. If an existing customer is having difficulties using service, [create a support case](https://docs.aws.amazon.com/awssupport/latest/user/case-management.html).

**What does AWS mean by “access” to the service?**  
Existing AWS DMS Fleet Advisor customers can do all the things they could previously. The only change is that non-existing customers will not be able to use AWS DMS Fleet Advisor or any of its capabilities, including [Data Collectors tool](https://docs.aws.amazon.com/dms/latest/userguide/fa-data-collectors.html), [Discovering OS and database servers](https://docs.aws.amazon.com/dms/latest/userguide/fa-discovery.html), [Collecting data](https://docs.aws.amazon.com/dms/latest/userguide/fa-collecting.html), and generating [Target recommendations](https://docs.aws.amazon.com/dms/latest/userguide/fa-recommendations.html).

**Can existing AWS DMS Fleet Advisor customers download [Data Collectors tool](https://docs.aws.amazon.com/dms/latest/userguide/fa-data-collectors.html), [Discovering OS and database servers](https://docs.aws.amazon.com/dms/latest/userguide/fa-discovery.html), [Collecting data](https://docs.aws.amazon.com/dms/latest/userguide/fa-collecting.html), and generating [Target recommendations](https://docs.aws.amazon.com/dms/latest/userguide/fa-recommendations.html)?**  
Yes. if you have any difficulties, [create a support case](https://docs.aws.amazon.com/awssupport/latest/user/case-management.html).

**Why are you no longer offering AWS DMS Fleet Advisor?**  
We have identified that customers prefer [Migration Evaluator](https://aws.amazon.com/migration-evaluator/) for their database migration assessment projects as an alternative to AWS DMS Fleet Advisor. Migration Evaluator provides both business and technical stakeholders visibility into the projected cost of running their on-premises workloads in the AWS Cloud. Business stakeholders can download a one-page summary highlighting the estimated savings to re-host at AWS based on usage patterns with costs broken down by infrastructure and software licenses. For more a technical audience, detailed per-server and per-SQL-server data is also available. This export combines on-premises discovery data (server hardware provisioning, SQL configurations, and resource utilization) with recommendations.

**What are my options now?**  
We recommend using [AWS Migration Evaluator](https://aws.amazon.com/migration-evaluator/) for all new and ongoing database migration assessment projects. If you have already downloaded Fleet Advisor's Data Collectors tool, you may continue to use them. However, support and updates for these tools will cease after May 20, 2025. For existing Fleet Advisor users, we recommend completing any in-progress assessments with Fleet Advisor, then transitioning to Migration Evaluator to benefit from critical patches, security updates, performance improvements, and new features.
