# Using an IBM Db2 for z/OS to

Amazon RDS for Db2 conversion settings

IBM for z/OS to Amazon RDS for DB2 conversion settings in DMS Schema Conversion include the
following:

- **Comments in converted SQL code**: This
  setting includes comments in the converted code for the action items of the
  selected severity and higher. This setting supports the following values:
  - Errors only
  - Errors and warnings
  - All messages
