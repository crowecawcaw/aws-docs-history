# Creating a replication instance

Your first task in migrating a database is to create a replication instance. This
replication instance requires sufficient storage and processing power to perform the
tasks that you assign and migrate data from your source database to the target database.
The required size of this instance varies depending on the amount of data you need to
migrate and the tasks that you need the instance to perform. For more information about
replication instances, see [Working with an AWS DMS replication
instance](CHAP_ReplicationInstance.md "CHAP_ReplicationInstance.md").

###### To create a replication instance by using the AWS console

1. Choose **Replication instances** in the navigation pane of
   the AWS DMS console and then choose **Create replication
   instance**.
2. On the **Create replication instance** page, specify your
   replication instance information. The following table describes the settings you
   can make.

| Option                                                     | Action                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Name**                                                   | Enter a name for the replication instance that contains<br>from 8 to 16 printable ASCII characters (excluding /,",<br>and @). The name should be unique for your account for the<br>AWS Region you selected. You can choose to add some<br>intelligence to the name, such as including the AWS Region<br>and task you are performing, for example<br>`west2-mysql2mysql-instance1`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Descriptive Amazon Resource Name (ARN)<br>• _Optional_** | A friendly name to override the default DMS ARN. You can't modify it after creation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Description**                                            | Enter a brief description of the replication<br>instance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Instance class**                                         | Choose an instance class with the configuration you need<br>for your migration. Keep in mind that the instance must have<br>enough storage, network, and processing power to<br>successfully complete your migration.<br>For more information on how to determine which<br>instance class is best for your migration, see<br>[Working with an AWS DMS replication<br>instance](CHAP_ReplicationInstance.md "CHAP_ReplicationInstance.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Engine version**                                         | In the AWS DMS console, you can choose any supported engine<br>version that you want. From the AWS CLI, the replication<br>instance runs the latest non-beta version of the AWS DMS<br>replication engine unless you specify a different engine<br>version in the AWS CLI.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **High Availability**                                      | Use this optional parameter to create a standby replica of<br>your replication instance in another Availability Zone for<br>failover support. If you intend to use change data capture<br>(CDC) or ongoing replication, you should turn on this<br>option.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Allocated storage (GiB)**                                | Storage is primarily consumed by log files and cached<br>transactions. For caches transactions, storage is used only<br>when the cached transactions need to be written to disk.<br>Therefore, AWS DMS doesn't use a significant amount of<br>storage. Some exceptions include the following:<br>• Very large tables that incur a significant<br>transaction load. Loading a large table can take<br>some time, so cached transactions are more likely to<br>be written to disk during a large table load.<br>• Tasks that are configured to pause before loading<br>cached transactions. In this case, all transactions<br>are cached until the full load completes for all<br>tables. With this configuration, a fair amount of<br>storage might be consumed by cached<br>transactions.<br>• Tasks configured with tables being loaded into<br>Amazon Redshift. However, this configuration isn't an<br>issue when Amazon Aurora is the target.<br>In most cases, the default allocation of storage is<br>sufficient. However, it's always a good idea to pay<br>attention to storage-related metrics. Make sure to scale up<br>your storage if you find you are consuming more than the<br>default allocation. |
| **Network type**                                           | DMS supports the **IPv4\*<br>• addressing<br>protocol network type, and supports both IPv4 and IPv6<br>addressing protocol network types in<br>**Dual-stack*<br>• mode. When you have<br>resources that must communicate with your replication<br>instance using an IPv6 addressing protocol network type, use<br>\*\*Dual-stack*<br>• mode. For information<br>about limitations in dual-stack mode, see [Limitations for dual-stack network DB instances](../../../AmazonRDS/latest/UserGuide/USER_VPC.md#USER_VPC.IP_addressing.dual-stack-limitations "../../../AmazonRDS/latest/UserGuide/USER_VPC.md#USER_VPC.IP_addressing.dual-stack-limitations") in the [Amazon Relational Database Service](../../../AmazonRDS/latest/UserGuide/Welcome.md "../../../AmazonRDS/latest/UserGuide/Welcome.md") userguide.                                                                                                                                                                                                                                                                                                                                                                                                |
| **VPC**                                                    | Choose the VPC that you want to use. If your source or<br>your target database is in a VPC, choose that VPC. If your<br>source and your target databases are in different VPCs,<br>ensure that they are both in public subnets and are publicly<br>accessible. Then choose the VPC where the replication<br>instance is to be located. The replication instance must be<br>able to access the data in the source VPC. If neither your<br>source or target database is in a VPC, choose a VPC where<br>the replication instance is to be located.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Replication Subnet Group**                               | Choose the replication subnet group in your selected VPC<br>where you want the replication instance to be created. If<br>your source database is in a VPC, choose the subnet group<br>that contains the source database as the location for your<br>replication instance. For more information about replication<br>subnet groups, see [Creating a replication subnet group](CHAP_ReplicationInstance.md#CHAP_ReplicationInstance.VPC.Subnets "CHAP_ReplicationInstance.md#CHAP_ReplicationInstance.VPC.Subnets").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Publicly accessible**                                    | Choose this option if you want the replication instance to<br>be accessible from the internet. The default is publicly accessible, and<br>once the option is chosen, you can't modify it after you create the<br>replication instance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

3. Choose the **Advanced** tab to set values for network and encryption settings
   if you need them. The following table describes the settings.

| Option                    | Action                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Availability zone**     | Choose the Availability Zone where your source database is<br>located.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **VPC Security group(s)** | The replication instance is created in a VPC. If your<br>source database is in a VPC, choose the VPC security group<br>that provides access to the DB instance where the database<br>resides.                                                                                                                                                                                                                                                                                                                                                              |
| **KMS key**               | Choose the encryption key to use to encrypt replication<br>storage and connection information. If you choose<br>**(Default) aws/dms**, the default AWS Key Management Service (AWS KMS) key associated with your<br>account and AWS Region is used. A description and your<br>account number are shown, along with the key's ARN. For more<br>information on using the encryption key, see [Setting an encryption key and<br>specifying AWS KMS permissions](CHAP_Security.md#CHAP_Security.EncryptionKey "CHAP_Security.md#CHAP_Security.EncryptionKey"). |

4. Specify the **Maintenance** settings. The following table describes the
   settings. For more information about maintenance settings, see [Working with the AWS DMS
   maintenance window](CHAP_ReplicationInstance.md "CHAP_ReplicationInstance.md").

| Option                        | Action                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Automatic version upgrade** | AWS DMS doesn't differentiate between major and minor versions. For example, upgrading from version 3.4.x to 3.5.x<br>isn't considered a major upgrade, so all changes should be backward-compatible.<br>When **Automatic version upgrade\*<br>• is enabled, DMS automatically<br>upgrades the replication instance's version during the maintenance window if<br>it is deprecated.<br>When **AutoMinorVersionUpgrade*<br>• is enabled, DMS uses the current<br>default engine version when you create a replication instance. For example, if you set<br>\*\*Engine version*<br>• to a lower version number than the current default<br>version, DMS uses the default version.<br>If **AutoMinorVersionUpgrade\*<br>• isn't enabled when you create<br>a replication instance, DMS uses the engine version specified by the<br>**Engine version\*<br>• parameter. |
| **Maintenance window**        | Choose a weekly time range during which system maintenance<br>can occur, in Universal Coordinated Time (UTC).<br>Default: A 30-minute window selected at random from an<br>8-hour block of time per AWS Region, occurring on a random<br>day of the week.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

5. Choose **Create replication instance**.
