# Running homogeneous data migrations in AWS DMS

You can use [Homogeneous data migrations](data-migrations.md "data-migrations.md") in AWS DMS
to migrate data from your source database to the equivalent engine on Amazon Relational Database Service (Amazon RDS)
, Amazon Aurora, or Amazon DocumentDB. AWS DMS automates the data migration process by using native database tools in your
source and target databases.

After you create an instance profile and compatible data providers for homogeneous data migrations, create
a migration project. For more information, see [Creating migration projects](migration-projects-create.md "migration-projects-create.md").
