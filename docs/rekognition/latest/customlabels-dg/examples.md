# Custom Labels Examples

This section contains examples that show you how you make use Amazon Rekognition Custom Labels's capabilities.

| Example                                                                                               | Description                                                                                                                                                                                                                                                                |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Improving a model with Model feedback](ex-feedback.md "ex-feedback.md")                              | Shows how to improve a model using human verification to create a new<br>training dataset.                                                                                                                                                                                 |
| [Amazon Rekognition Custom Labels demonstration](ex-custom-labels-demo.md "ex-custom-labels-demo.md") | Demonstration of a user interface that displays the results of a call<br>to `DetectCustomLabels`.                                                                                                                                                                          |
| [Detecting Custom Labels in videos](ex-video-extraction.md "ex-video-extraction.md")                  | Shows how you can use `DetectCustomLabels` with frames<br>extracted from a video.                                                                                                                                                                                          |
| [Analyzing images with an AWS Lambda function](ex-lambda.md "ex-lambda.md")                           | Shows how you can use `DetectCustomLabels` with a Lambda<br>function.                                                                                                                                                                                                      |
| [Creating a manifest file from a CSV<br>file](ex-csv-manifest.md "ex-csv-manifest.md")                | Shows how to use a CSV file to create a manifest file suitable for<br>finding [objects, scenes, and<br>concepts](understanding-custom-labels.md#tm-classification "understanding-custom-labels.md#tm-classification") associated with an entire image<br>(classification). |
