# Converting other dataset formats to a

manifest file

You can use the following information to create Amazon SageMaker AI format manifest files
from a variety of source dataset formats. After creating the manifest file, use
it to create to a dataset. For more information, see [Using a manifest file to import
images](md-create-dataset-ground-truth.md "md-create-dataset-ground-truth.md").
