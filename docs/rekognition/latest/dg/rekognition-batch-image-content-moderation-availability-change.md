# Rekognition Batch Image Content Moderation availability change

###### Note

Amazon Rekognition Streaming Video Analysis will no longer be
open to new customers starting April 30, 2026. If you would like to use Streaming Video Analysis, sign up prior to
that date. Existing customers for accounts that have used this feature within the last 12 months can continue
to use the service as normal. For more information, see
[Rekognition Streaming Video Analysis availability change](rekognition-streaming-video-analysis-availability-change.md "rekognition-streaming-video-analysis-availability-change.md").

After careful consideration, we decided to close Amazon Rekognition Batch Image Content Moderation
to new customers starting April 30, 2026. If you would like to use Amazon Rekognition Batch Image
Content Moderation, sign up prior to that date. Existing customers for accounts that have
used this feature within the last 12 months can continue to use the service as normal.

**Resources to help with the migration to alternative
solutions**

For information about using Rekognition Image API to process a batch of images stored in S3, see
this [Creating a serverless face blurring service for photos in Amazon S3](https://aws.amazon.com/blogs/compute/creating-a-serverless-face-blurring-service-for-photos-in-amazon-s3/ "https://aws.amazon.com/blogs/compute/creating-a-serverless-face-blurring-service-for-photos-in-amazon-s3/") on the AWS
Blog.

If you have additional questions, please reach out to [AWS Support](https://aws.amazon.com/support "https://aws.amazon.com/support").
