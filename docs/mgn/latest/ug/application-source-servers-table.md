# Review application source servers

The **Source servers** table lists all the servers
that are associated with the application.

To perform batch operations on all the servers, use the application **Actions** menu at the top of the page. To perform an
operation on a single server, go to the specific server's **Server details** page by clicking the server **Source server name**.
