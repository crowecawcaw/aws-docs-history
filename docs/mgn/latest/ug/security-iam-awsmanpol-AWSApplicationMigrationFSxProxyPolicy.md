# AWS managed policy: AWSApplicationMigrationFSxProxyPolicy

This policy is attached to the AWS Transform MGN FSx proxy service role.

This policy provides permissions to manage ONTAP file systems as part of the
AWS Transform MGN file system migration process. The policy allows the service
to read secrets, describe and create FSx volumes, and manage tags on FSx resources.
We do not recommend that you attach this policy to your users or roles.

**Permissions details**

To view the policy permission details see [AWSApplicationMigrationFSxProxyPolicy](../../../aws-managed-policy/latest/reference/AWSApplicationMigrationFSxProxyPolicy.md "../../../aws-managed-policy/latest/reference/AWSApplicationMigrationFSxProxyPolicy.md") in the AWS Managed Policy Reference Guide.
