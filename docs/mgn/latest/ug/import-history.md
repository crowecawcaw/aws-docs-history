# View import history

Select the **Import history** tab to view the files imported in
the last 7 days, including their status and the task’s start and end time.

You can change the settings according to your preferences by clicking on the settings icon
located in the right-hand corner of the screen.

To see all the related task messages, click the task ID. To copy the messages, click
**Copy**.
