# Source server actions in AWS Transform MGN

When you install the AWS Replication Agent on a source server in your on-premises
environment, AWS Transform MGN begins replicating that server to AWS. Throughout the migration
lifecycle, you can perform a variety of actions on your source servers directly from the
AWS Transform MGN console. These actions are organized by migration phase: before migration begins,
during active replication, and after cutover is complete.

Understanding which actions are available at each phase helps you plan your migration
project, minimize downtime, and ensure a successful outcome.
