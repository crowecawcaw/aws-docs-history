# Reinstalling the Agent

To reinstall the AWS Replication Agent, download the latest version of the agent and
follow the installation instructions. The AWS Replication Agent can be installed over an
existing agent installation. You do not need to remove any previous versions prior to
install.

- [Installing the AWS Replication Agent on Linux servers](linux-agent.md "linux-agent.md")
- [Installing the AWS Replication Agent on Windows
  servers](windows-agent.md "windows-agent.md")
