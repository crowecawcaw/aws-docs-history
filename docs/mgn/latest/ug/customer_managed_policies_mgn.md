# Customer-managed policies in

AWS MGN

You can create your own custom IAM policies to allow permissions for
AWS Application Migration Service actions and resources. You can attach these custom policies to the
users, roles, or groups that require those permissions. You can also create
your own custom IAM policies for integration between AWS Application Migration Service and other
AWS services. The next few topics provide example of the IAM policies which grants permission for
various AWS Application Migration Service actions. Use them to limit AWS Application Migration Service
access for your users and roles.
