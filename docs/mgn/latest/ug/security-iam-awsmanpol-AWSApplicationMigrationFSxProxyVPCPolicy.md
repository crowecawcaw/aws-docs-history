# AWS managed policy: AWSApplicationMigrationFSxProxyVPCPolicy

This policy is attached to the AWS Transform MGN FSx proxy VPC service role.

This policy provides permissions to manage PrivateLink connectivity between
AWS Transform MGN and customer's FSx file system. The policy allows the service
to create and manage security groups, VPC endpoint service configurations, Network
Load Balancers, and target groups required for the PrivateLink connection.
We do not recommend that you attach this policy to your users or roles.

**Permissions details**

To view the policy permission details see [AWSApplicationMigrationFSxProxyVPCPolicy](../../../aws-managed-policy/latest/reference/AWSApplicationMigrationFSxProxyVPCPolicy.md "../../../aws-managed-policy/latest/reference/AWSApplicationMigrationFSxProxyVPCPolicy.md") in the AWS Managed Policy Reference Guide.
