# Start instance upon launching

Choose whether you want to start your test and cutover instances automatically upon
launch or whether you want to launch them in a stopped state.

If you choose **Yes**, the test or cutover AWS instances are
launched and started automatically upon test or cutover launch.

If you choose **No**, the instances are launched in a
stopped state and you have to start the test or cutover AWS instance manually from the
Amazon EC2 console.
