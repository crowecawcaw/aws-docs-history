

# Setting up for the AWS Console Mobile Application
<a name="setting-up"></a>

Complete the tasks in this section to get set up to use the Console Mobile Application.

**Steps**
+  [Sign up for an AWS account](#sign-up-for-aws) 
+  [Step 1: Check system requirements](#step-1-check-system-requirements) 
+  [Step 2: Download the app](#step-2-download-the-app) 

When you’re finished, you will be ready for the [Getting started with AWS Console Mobile Application](getting-started.md) tutorial.

## Sign up for an AWS account
<a name="sign-up-for-aws"></a>

To get started with AWS, you need an AWS account. For information about creating an AWS account, see [Getting started with an AWS account](https://docs.aws.amazon.com/accounts/latest/reference/getting-started.html) in the *AWS Account Management Reference Guide*.

## Step 1: Check system requirements
<a name="step-1-check-system-requirements"></a>

### Mobile devices
<a name="mobile-devices"></a>

We support iOS 16.4 and above, and Android 8.0 and above.

### Tablets
<a name="tablets"></a>

The Console Mobile Application is optimized for iOS and Android mobile devices with a screen size smaller than 7 inches, but it works on larger screen sizes as well.

## Step 2: Download the app
<a name="step-2-download-the-app"></a>

Download the Console Mobile Application from the [iOS App Store](https://apps.apple.com/us/app/aws-console/id580990573), [Google Play](https://play.google.com/store/apps/details?id=com.amazon.aws.console.mobile), [Amazon Appstore](https://www.amazon.com/AWS-Mobile-LLC-Console/dp/B00ATSN730), or by scanning the following QR code:
