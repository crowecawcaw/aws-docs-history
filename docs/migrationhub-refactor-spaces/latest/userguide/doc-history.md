

AWS Migration Hub Refactor Spaces is no longer open to new customers as of November 7, 2025. For capabilities similar to AWS Migration Hub Refactor Spaces, explore [AWS Transform](https://aws.amazon.com/transform).

For more information, see [AWSMigrationHubRefactorSpaces-SSMAutomationPolicy](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/userguide/security-iam-awsmanpol.html#SSMAutomationPolicy). | August 10, 2023 |

For more information, see [Create a service](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/userguide/getting-started-create-service.html). Also, see [CreateService](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_CreateService.html) and [LambdaEndpointInput](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_LambdaEndpointInput.html) in the *AWS Migration Hub Refactor Spaces API Reference*. | December 15, 2022 |

With this feature, you can create services with Domain Name System (DNS) names in the URL. Refactor Spaces automatically re-resolves the DNS name when the DNS time-to-live (TTL) expires (or every 60 seconds for TTLs less than 60 seconds). For more information, see [Refactor Spaces concepts](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/userguide/welcome-concepts.html) and [CreateRoute](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_CreateRoute.html) in the *AWS Migration Hub Refactor Spaces API Reference*.  | November 16, 2022 |
