# Prerequisites

The following are the prerequisites for using AWS Migration Hub Refactor Spaces.

- You must have one or more AWS accounts, and IAM users set up for
  these accounts. For more information, see [Setting up](setting-up.md "setting-up.md").
- Designate one of the IAM users as the Refactor Spaces environment owner.
