# Gateways managed by MediaConnect Gateway

Gateways serve as the logical grouping for instances and bridges in the MediaConnect
architecture, facilitating communication between on-premises networks and the
AWS Cloud for media workflows.

This section covers the fundamental procedures for working with gateways.
