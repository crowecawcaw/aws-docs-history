# Security group considerations for VPC

interfaces

When you set up a virtual private cloud (VPC) in Amazon Virtual Private Cloud, you create security groups
that control inbound and outbound traffic.
Then,
when you create a VPC interface in AWS Elemental MediaConnect, you specify the security groups
that you want MediaConnect to use when it sends and receives content from your
VPC.

To ensure that content can flow between your VPC and MediaConnect, adhere to the
following guidelines:

| If you have...                                            | Make sure that the VPC interface has a security group with...                                                                                                                                                        | Additional information                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A VPC source                                              | An inbound rule that allows the private IP address of the resource<br>within the VPC that is sending content.                                                                                                        | \*_Zixi sources:_<br>• When you create a VPC<br>source using Zixi protocol, the inbound port is automatically assigned<br>by MediaConnect. The assigned port will be in the range of 2090-2099 and<br>assigned at the time of source creation. You should create the Zixi VPC<br>source first and note the assigned port. After you have the assigned<br>port information, you can configure your security groups.                                                                                                                                |
| A VPC output                                              | An outbound rule that allows all outbound traffic. By default, all<br>security groups include this rule. As long as you haven't deleted<br>that rule from the security group, you don't need to create a new<br>one. | On the resource that receives traffic from your flow, you also<br>need to set up a security group with an inbound rule that allows the<br>private IP of the network interface ID that is associated with the<br>VPC interface. (In MediaConnect, you can look at the flow details<br>to find the network interface ID. Then in EC2, you [view details](../../../AWSEC2/latest/UserGuide/using-eni.md#view_eni_details "../../../AWSEC2/latest/UserGuide/using-eni.md#view_eni_details") about the network interface to obtain the<br>IP address.) |
| A VPC source and a VPC output from the same VPC interface | An inbound rule and an outbound rule that meet the requirements<br>listed above.                                                                                                                                     | You can use one security group that has both rules or two security<br>groups (one for each rule).<br>For CDI flows, the security group specified for the VPC interfaces<br>must be self referential. Verify that the security group used has<br>the same security group ID added to both inbound and outbound<br>rules.                                                                                                                                                                                                                           |

For more information about security groups, see the [Amazon VPC User Guide](../../../vpc/latest/userguide/VPC_SecurityGroups.md "../../../vpc/latest/userguide/VPC_SecurityGroups.md").
