# Removing a media stream

You can remove a media stream from a flow if the flow is not active and if the media
stream is not associated with a source or any outputs.

###### To remove a media stream from a flow

1. Open the MediaConnect console at [https://console.aws.amazon.com/mediaconnect/](https://console.aws.amazon.com/mediaconnect/ "https://console.aws.amazon.com/mediaconnect/").
2. On the **Flows** page, choose the name of the flow that is
   associated with the media stream that you want to remove.

The details page for that flow appears. 3. Choose the **Media streams** tab. 4. Choose the media stream, and then choose **Remove**.
