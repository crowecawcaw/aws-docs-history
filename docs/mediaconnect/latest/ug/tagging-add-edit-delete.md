# Managing tags

Tags are made up of the `Key` and `Value` properties on a resource. You can use the AWS Elemental MediaConnect console, the AWS CLI, or the
AWS Elemental MediaConnect API to add, edit, or delete the values for these properties. For information about working with tags, see the following:

- [Resources](../api/resources.md "../api/resources.md") in the _AWS Elemental MediaConnect API Reference_
- [Managing tags on a flow](flows-manage-tags.md "flows-manage-tags.md") in this guide
- [Managing tags on a MediaConnect source](sources-manage-tags.md "sources-manage-tags.md") in this guide
- [Managing tags on a MediaConnect output](outputs-manage-tags.md "outputs-manage-tags.md") in this guide
- [Managing tags on an entitlement](entitlements-manage-tags.md "entitlements-manage-tags.md") in this guide
