# SPEKE encryption in AWS Elemental MediaConnect

You can use Secure Packager and Encoder Key Exchange (SPEKE) with AWS Elemental MediaConnect to encrypt an [entitlement](entitlements.md "entitlements.md"). This gives you, as the content
originator, full control of permissions for this content. This usage is a
customization of the SPEKE cloud-based architecture described in the [SPEKE
documentation](../../../speke/latest/documentation/what-is.md#services-architecture "../../../speke/latest/documentation/what-is.md#services-architecture").
