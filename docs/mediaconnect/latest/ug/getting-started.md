

# Getting started with AWS Elemental MediaConnect
<a name="getting-started"></a>

AWS Elemental MediaConnect supports two ways to move live video: **flows**, which ingest, replicate, and share live video streams, and the **MediaConnect router**, which dynamically routes live video between independent inputs and outputs in real time. The following tutorials show you how to get started with each.
