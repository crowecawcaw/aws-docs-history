

# Sharing endpoints across accounts in MediaConnect
<a name="sharing-endpoints"></a>

You share endpoints with other AWS accounts by using AWS Resource Access Manager (AWS RAM). In the sharing account, you add the endpoints that you want to share to a resource share and choose the accounts, organizations, or organizational units to share them with. A consuming account accepts the resource share before it can use the shared endpoints in its endpoint registry. For an overview of AWS RAM, see [What is AWS Resource Access Manager](https://docs.aws.amazon.com/ram/latest/userguide/what-is.html) in the [AWS RAM User Guide](https://docs.aws.amazon.com/ram/latest/userguide/).
