# Removing tags from a MediaConnect source

You can remove a tag from a source if you no longer want to use it to track the billing and organization for it.

###### To remove tags from a source (console)

1. Open the MediaConnect console at [https://console.aws.amazon.com/mediaconnect/](https://console.aws.amazon.com/mediaconnect/ "https://console.aws.amazon.com/mediaconnect/").
2. On the **Flows** page, choose the name of the flow that is
   associated with the source that you want to remove tags from.
3. Choose the **Sources** tab.

A list of sources for that flow appears. 4. Choose the source that you want to remove tags from. 5. Choose **Manage tags**. 6. Choose **Manage tags** again. 7. Choose **Remove tag** next to each tag that you want to
delete. 8. Choose **Update**.
