# Managing tags on a MediaConnect source

You can use tags to help you track the billing and organization for your
AWS Elemental MediaConnect flows, sources, outputs, and entitlements. These are the same tags that
AWS Billing and Cost Management provides for organizing your AWS bill. For more information about using tags
for cost allocation, see [Use Cost Allocation
Tags for Custom Billing Reports](../../../awsaccountbilling/latest/aboutv2/allocation.md "../../../awsaccountbilling/latest/aboutv2/allocation.md") in the
_AWS Billing User Guide_.
