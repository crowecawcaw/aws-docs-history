# AWS Elemental MediaConnect

metrics to monitor flow health

AWS Elemental MediaConnect sends metrics to CloudWatch. You can review specific metrics to
evaluate the health of your flow. If the flow is unhealthy, these metrics can help
you determine where the issue originates. For details about each metric, see the
tables in this section.

For information about source metrics, see [Metrics
to monitor source health](monitor-with-cloudwatch-metrics-source-health.md "monitor-with-cloudwatch-metrics-source-health.md").

###### Note

Metrics tracked by MediaConnect adhere to the standard as defined by the TR
101 290 spec.
