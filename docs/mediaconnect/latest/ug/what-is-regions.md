# Regions and endpoints for MediaConnect

To reduce data latency in your applications, AWS Elemental MediaConnect offers a regional endpoint to make your requests:

```
https://mediaconnect.`<region>`.amazonaws.com
```

To view the complete list of AWS Regions where MediaConnect is available, see [AWS Elemental MediaConnect endpoints and quotas](../../../general/latest/gr/mediaconnect.md "../../../general/latest/gr/mediaconnect.md") in the AWS General Reference.
