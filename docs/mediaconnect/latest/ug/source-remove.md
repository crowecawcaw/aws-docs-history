# Removing a source from a MediaConnect flow

If a flow has more than one source, you can remove one of the sources even when the
flow is currently running.

###### To remove a source from a flow (console)

1. Open the MediaConnect console at [https://console.aws.amazon.com/mediaconnect/](https://console.aws.amazon.com/mediaconnect/ "https://console.aws.amazon.com/mediaconnect/").
2. On the **Flows** page, choose the name of the flow.
3. Choose the **Source** tab.
4. Choose the source that you want to remove.
5. Choose **Remove**.
