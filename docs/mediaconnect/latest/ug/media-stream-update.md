# Updating a media stream a MediaConnect flow

You can update media streams even if the flow is running. However, if the media stream
is associated with a source or any outputs, you can't update its type.

###### To update a media stream on a flow

1. Open the MediaConnect console at [https://console.aws.amazon.com/mediaconnect/](https://console.aws.amazon.com/mediaconnect/ "https://console.aws.amazon.com/mediaconnect/").
2. On the **Flows** page, choose the name of the flow that is
   associated with the media stream that you want to update.
3. Choose the **Media streams** tab.

A list of media streams for that flow appears. 4. Choose the media stream that you want to update. 5. Choose **Update**. 6. Make the appropriate changes, and then choose
**Save**.
