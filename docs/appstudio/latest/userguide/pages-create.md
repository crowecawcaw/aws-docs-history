# Creating a page

Use the following procedure to create a page in an application in App Studio. For information about duplicating an existing page, see
[Duplicating a page](pages-duplicate.md "pages-duplicate.md").

###### To create a page

1. If necessary, navigate to the Development environment of your application by editing it.
2. Navigate to the **Pages** tab.
3. In the left-side **Pages** menu, choose **+ Add**.
