# Duplicating a page

Use the following procedure to duplicate a page in an application in App Studio.

###### To duplicate a page

1. If necessary, navigate to the Development environment of your application by editing it.
2. Navigate to the **Pages** tab.
3. In the left-side **Pages** menu, choose the ellipses menu next to the name of the page you
   want to duplicate and choose **Duplicate**. The duplicated page is added directly after the original page.
