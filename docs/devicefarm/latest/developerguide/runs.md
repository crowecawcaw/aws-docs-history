# Test runs in AWS Device Farm

A run in Device Farm represents a specific build of your app, with a specific set of tests, to be run on a specific set of devices.
A run produces a report that contains information about the results of the run. A run contains one or more jobs. For more information, see [Runs](test-runs.md "test-runs.md").

You can use the AWS Device Farm console, AWS Command Line Interface (AWS CLI), or AWS Device Farm API to work with test runs.
