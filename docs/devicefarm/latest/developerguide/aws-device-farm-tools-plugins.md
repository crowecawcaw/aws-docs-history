# Tools and plugins for AWS Device Farm

This section contains links and information about working with AWS Device Farm tools and plugins. You can find Device Farm plugins on [AWS Labs on GitHub](https://github.com/awslabs/ "https://github.com/awslabs/").

If you are an Android developer, we also have an [AWS Device Farm sample app for
Android on GitHub](https://github.com/awslabs/aws-device-farm-sample-app-for-android "https://github.com/awslabs/aws-device-farm-sample-app-for-android"). You can use the app and example tests as a reference for your own Device Farm test scripts.
