# Analyzing test results in AWS Device Farm

In the standard test environment, you can use the Device Farm console to view reports for each
test in your test run. Vewing the reports helps you understand which tests passed or failed,
and provides you with details on the performance and behavior of your app across different
device configurations.

Device Farm also gathers other artifacts such as files, logs, and images that you can download
when your test run is complete. This information can help you analyze how your app is
behaving on real devices, identify issues or bugs, and diagnose problems.
