# Step 7 – Terminate the

temporary instance

After you have confirmed that your AMI works as intended with AWS PCS, you can terminate
the temporary instance to stop incurring charges for it.

###### To terminate the temporary instance

1. Open the [Amazon EC2 console](https://console.aws.amazon.com/ec2 "https://console.aws.amazon.com/ec2").
2. In the navigation pane, choose **Instances**.
3. Select the temporary instance that you created and choose **Actions**,
   **Instance state**, **Terminate instance**.
4. When prompted to confirm, choose **Terminate**.
