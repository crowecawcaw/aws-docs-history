# Step 3 – Install Slurm

on the instance

When the instance has launched and becomes active, connect to it using your preferred
mechanism. Use the Slurm installer provided by AWS to install Slurm onto the instance. For more
information, see [Slurm installer](working-with_ami_installers.md#working-with_ami_installers_slurm "working-with_ami_installers.md#working-with_ami_installers_slurm").

Download the Slurm installer, uncompress it, and use the `installer.sh` script to
install Slurm. For more information, see [Step 3 – Install Slurm](working-with_ami_custom_install-slurm.md "working-with_ami_custom_install-slurm.md").
