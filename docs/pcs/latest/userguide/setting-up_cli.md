# Install the AWS CLI for AWS PCS

You must use the latest version of the AWS CLI. For information, see [Install or update to the latest version
of the AWS CLI](../../../cli/latest/userguide/getting-started-install.md "../../../cli/latest/userguide/getting-started-install.md") in the _AWS Command Line Interface User Guide for Version 2_.

You must configure the AWS CLI. For more information,
see [Configure
the AWS CLI](../../../cli/latest/userguide/cli-chap-configure.md "../../../cli/latest/userguide/cli-chap-configure.md") in the _AWS Command Line Interface User Guide for Version 2_.

Enter the following command at a command prompt to check your AWS CLI; it should display help information.

```
aws pcs help
```
