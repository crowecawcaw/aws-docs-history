# (Optional) Create a

placement group

We recommended you launch all instances that use EFA in a cluster placement group to
minimize the physical distance between them. Create a placement group for each
compute node group where you plan to use EFA. See [Placement groups for EC2 instances in
AWS PCS](working-with_networking_placement-groups.md "working-with_networking_placement-groups.md") to create a placement group for your
compute node group.
