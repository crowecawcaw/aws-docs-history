# Amazon Machine Images (AMIs) for AWS PCS

AWS PCS works with AMIs that you provide, affording great flexibility in the software and
configuration found on nodes in your cluster. If you are trying out AWS PCS, you can use a sample
AMI provided by and maintained by AWS. If you are using AWS PCS in production, we recommend you
build your own AMIs. This topic covers how to discover and use the sample AMIs, as well as how to
build and use your own customized AMIs.
