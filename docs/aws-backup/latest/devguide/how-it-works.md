# AWS Backup: How it works

AWS Backup is a fully managed backup service that makes it easy to centralize and automate the
backing up of data across AWS services. With AWS Backup, you can create backup policies called
_backup plans_. You can use these plans to define your backup requirements,
such as how frequently to back up your data and how long to retain those backups.

AWS Backup lets you apply backup plans to your AWS resources by simply tagging them. AWS Backup then
automatically backs up your AWS resources according to the backup plan that you
defined.
