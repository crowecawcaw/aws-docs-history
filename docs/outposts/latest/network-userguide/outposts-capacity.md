# Capacity management for AWS Outposts

An Outpost provides a pool of AWS compute and storage capacity at
your site as a private extension of an Availability Zone in an AWS Region. Because the compute
and storage capacity available in the Outpost is finite and determined by the size and number of
assets that AWS installs at your site, you get to decide how much Amazon EC2 and Amazon EBS on AWS Outposts
capacity you need to run your initial workloads, accommodate future growth, and to provide extra
capacity to mitigate server failures and maintenance events.
