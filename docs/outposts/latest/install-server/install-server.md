# Installing an AWS Outposts server

When you order an Outposts server, you are responsible for installing the server. You can
install the server yourself or contract a third party. The party installing the server must have
specific permissions to verify the identity of the new device.

###### Prerequisites

You must have an Outposts server at your site. For more information, see [Site requirements](outposts-requirements.md "outposts-requirements.md") in this guide, and [Create an Outpost and order capacity](../server-userguide/order-outpost-capacity.md "../server-userguide/order-outpost-capacity.md") in the _AWS Outposts User Guide for Outposts servers_.

###### Tasks

1. [Grant permissions](install-grant.md "install-grant.md") to install the Outposts server
2. [Inspect](install-inspect.md "install-inspect.md") the Outposts server equipment
3. (Optional) [Mount the Outposts server](install-mount.md "install-mount.md") in a rack
4. [Connect the power source](install-power.md "install-power.md") and verify power
5. [Connect the Outposts server](install-network.md "install-network.md") to your network
6. [Configure connection and authorize the server](install-authorize.md "install-authorize.md")
