# AWS Outposts connectivity to AWS Regions

AWS Outposts supports wide area network (WAN) connectivity through the service link
connection.

###### Note

You can't use private connectivity for your service link connection that connects your
Outposts server to your AWS Region or AWS Outposts home Region.
