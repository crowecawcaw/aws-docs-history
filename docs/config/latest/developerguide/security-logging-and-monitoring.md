# Logging and Monitoring in AWS Config

AWS Config is integrated with AWS CloudTrail, a service that provides a record of actions taken by a
user, role, or an AWS service in AWS Config. Monitoring is an important part of maintaining the
reliability, availability, and performance of AWS Config and your AWS solutions.
