

# Managed Conformance Pack Catalog for AWS Config

The Managed Conformance Pack Catalog provides details about the managed conformance packs that are available in AWS Config. Managed conformance packs are predefined collections of AWS Config rules that are created and maintained by AWS. For more information, see [How managed conformance packs work in AWS Config](managed-conformance-packs-how-it-works.md).

Each managed conformance pack includes AWS Config rules selected to help you evaluate your AWS resource configurations against the requirements or best practices represented by the pack. The catalog provides a description of each managed conformance pack and the AWS Config rules included in it.

**Important**  
Managed conformance packs provide a general-purpose compliance framework to help you evaluate the configuration of your AWS resources against security, operational, or compliance requirements. Managed conformance packs, including those related to compliance standards and industry benchmarks, aren't designed to ensure your compliance with a specific governance standard. They don't replace your internal compliance efforts or guarantee that you will pass a compliance assessment.

**Note**  
AWS Config automatically regionalizes managed conformance packs based on AWS Config rule availability. When you deploy a managed conformance pack to an AWS Region, only the rules in the pack that are supported in that Region are deployed. As a result, the rules deployed for a managed conformance pack can vary by Region.
