

# bedrockagentcore-browsercustom-network-mode-not-public
<a name="bedrockagentcore-browsercustom-network-mode-not-public"></a>

Checks if an Amazon Bedrock AgentCore custom browser is configured with public network mode. The rule is NON\_COMPLIANT if the NetworkMode is set to PUBLIC. 



**Identifier:** BEDROCKAGENTCORE\_BROWSERCUSTOM\_NETWORK\_MODE\_NOT\_PUBLIC

**Resource Types:** AWS::BedrockAgentCore::BrowserCustom

**Trigger type:** Configuration changes

**AWS Region:** Only available in Europe (Stockholm), Asia Pacific (Mumbai), Europe (Paris), US East (Ohio), Europe (Ireland), Europe (Frankfurt), US East (N. Virginia), Asia Pacific (Seoul), Europe (London), Asia Pacific (Tokyo), US West (Oregon), Asia Pacific (Singapore), Asia Pacific (Sydney), Canada (Central) Region

**Parameters:**

None
