# Monitoring

You can use other AWS services to monitor AWS Config resources.

- You can use Amazon Simple Notification Service (SNS) to send you notifications every
  time a supported AWS resource is created, updated, or otherwise modified as a result of
  user API activity.
- You can use Amazon EventBridge to detect and react to changes in the status of AWS Config
  events.
