

# CIS Critical Security Controls v8 - Implementation Group 3 (IG3)

This AWS Config managed conformance pack provides a curated mapping between the Center for Internet Security (CIS) Critical Security Controls Version 8 Implementation Group 3 (IG3) safeguards and AWS Config managed rules. Each Config rule evaluates specific AWS resources and is associated with one or more CIS safeguards. AWS Config maintains and automatically updates the managed conformance pack as supported rules and resource types evolve. Refer to the table below for details on the rules, associated controls, guidance, and AWS Region availability.

**Source identifier:** CIS\_V8\_IG3

This conformance pack is available in all commercial AWS Regions (Regions other than the AWS GovCloud (US) Regions and the China Regions). It's also available in AWS GovCloud (US) Regions.

This conformance pack contains up to 259 AWS Config managed rules. The rules deployed vary by Region. The following table lists each rule, its control IDs, guidance, and the Regions where it's available. To see details about a rule, choose its name.
