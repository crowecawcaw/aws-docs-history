# Getting Started with AWS Config

AWS Config provides a detailed view of the configuration of AWS resources in your AWS account.
With AWS Config, you can review changes in configurations and relationships between AWS resources,
explore resource configuration history, and use rules to determine compliance. For more
information, see [What Is AWS Config?](WhatIsConfig.md "WhatIsConfig.md") and [How AWS Config Works](how-does-config-work.md "how-does-config-work.md").
