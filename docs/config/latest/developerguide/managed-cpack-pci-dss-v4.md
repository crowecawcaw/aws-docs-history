

# Payment Card Industry Data Security Standard (PCI DSS) v4

This AWS Config managed conformance pack provides a curated mapping between the Payment Card Industry Data Security Standard (PCI DSS) Version 4 requirements and AWS Config managed rules. Each Config rule evaluates specific AWS resources and is associated with one or more PCI DSS requirements. AWS Config maintains and automatically updates the managed conformance pack as supported rules and resource types evolve. Refer to the table below for details on the rules, associated controls, guidance, and AWS Region availability.

**Source identifier:** PCI-DSS\_V4

This conformance pack is available in all commercial AWS Regions (Regions other than the AWS GovCloud (US) Regions and the China Regions). It's also available in AWS GovCloud (US) Regions.

This conformance pack contains up to 351 AWS Config managed rules. The rules deployed vary by Region. The following table lists each rule, its control IDs, guidance, and the Regions where it's available. To see details about a rule, choose its name.
