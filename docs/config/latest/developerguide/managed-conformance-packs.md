

# Managed Conformance Packs for AWS Config

AWS Config managed conformance packs are predefined collections of AWS Config rules that are created and maintained by AWS. Managed conformance packs help you evaluate the configuration of your AWS resources against common security, operational, and compliance requirements without having to create and maintain your own conformance pack templates.

You can select a managed conformance pack and deploy it to an AWS account and Region. AWS defines the rules included in each managed conformance pack and maintains the pack as AWS Config rules and mapped requirements change.

To see the managed conformance packs that are available and the AWS Config rules included in each pack, see [Managed Conformance Pack Catalog for AWS Config](managed-conformance-pack-catalog.md).
