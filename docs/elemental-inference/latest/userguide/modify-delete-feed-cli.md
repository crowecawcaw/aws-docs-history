# Revising using the CLI

To add or delete features in a feed, use the `AssociateFeed` or
`UpdateFeed` action. `AssociateFeed` is a PATCH operation.
`UpdateFeed` is a PUT operation.

For information about the differences between these two operations and about which
operation to use for specific changes, see the information about these operations in the
[https://docs.aws.amazon.com/elemental-inference/latest/APIReference/Welcome](../APIReference/Welcome.md "../APIReference/Welcome.md")AWS Elemental Inference API Reference.
