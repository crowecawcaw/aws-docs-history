

# Limits and text rules for question sets

Elemental Inference checks the name, text, and question count rules when you create or update a question set. If a request breaks one of these rules, it fails with a `ValidationException`. Elemental Inference checks the version limit when you publish a version, and the number of question sets in your account when you create one, as described later in this section. All of these limits are fixed, and you can't request an increase.
