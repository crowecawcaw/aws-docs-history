

# Pricing
<a name="playground-pricing"></a>

Playground jobs incur both AWS Elemental Inference and AWS Elemental MediaConvert charges, and you're charged only when a job completes successfully. There are no charges when a job fails. For pricing details, see [AWS Elemental Inference pricing](https://aws.amazon.com/elemental-inference/pricing/) and [AWS Elemental MediaConvert pricing](https://aws.amazon.com/mediaconvert/pricing/).
