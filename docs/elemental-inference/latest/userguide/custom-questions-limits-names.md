

# Name rules

The following rules apply to names:
+ **Question set name** – 1–128 characters. Use letters, digits, hyphens (-), and underscores (\_). The name must start and end with a letter or digit.
+ **Question name and option name** – 1–64 characters. Use letters, digits, and underscores (\_). The name must start with a letter or an underscore. Hyphens aren't allowed.
+ **Unique question names** – Each question name must be unique across all three lists of the question set.
+ **Unique option names** – Each option name must be unique within its question.

Elemental Inference compares question names and option names exactly, so the comparison is case sensitive.
