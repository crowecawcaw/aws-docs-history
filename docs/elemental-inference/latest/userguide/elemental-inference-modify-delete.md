

# Work with existing Elemental Inference feeds
<a name="elemental-inference-modify-delete"></a>

You can make the following changes to an existing feed:
+ Edit a feed. You can change the configuration of its outputs, add outputs up to the maximum allowed in one feed, remove outputs, and enable or disable outputs. For information about the status of outputs, see [Status of an output](monitor-inference-feed-lifecycle.md#monitor-inference-status-output).
+ Archive a feed.
+ Delete a feed.

You can make these changes using the Elemental Inference console or the AWS CLI.
