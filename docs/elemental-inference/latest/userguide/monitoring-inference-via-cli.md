# Monitoring AWS Elemental Inference using the AWS CLI

To monitor feeds and outputs using an AWS API, use the `GetFeed` operation of
Elemental Inference. For more information, see [GetFeed](../APIReference/API_GetFeed.md "../APIReference/API_GetFeed.md") in the
_AWS Elemental Inference API Reference_.

For information about how the feed and outputs change status through the lifetime of the
feed, see [Lifecycle of an AWS Elemental Inference workflow](monitor-inference-feed-lifecycle.md "monitor-inference-feed-lifecycle.md").
