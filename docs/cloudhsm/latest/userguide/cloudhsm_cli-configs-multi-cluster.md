# Connecting to multiple clusters with CloudHSM CLI

With AWS CloudHSM Client SDK 5, you can configure CloudHSM CLI to allow connections to multiple CloudHSM
clusters from a single CLI instance.

The following topics describe how to use the CloudHSM CLI multi-cluster functionality to
connect with multiple clusters.
