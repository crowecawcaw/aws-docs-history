# The user category in CloudHSM CLI

In the CloudHSM CLI, **user** is a parent category for a group of commands
that, when combined with the parent category, create a command specific to users. Currently, the
user category consists of the following commands:

- [user change-mfa](cloudhsm_cli-user-change-mfa.md "cloudhsm_cli-user-change-mfa.md")
- [user change-password](cloudhsm_cli-user-change-password.md "cloudhsm_cli-user-change-password.md")
- [user create](cloudhsm_cli-user-create.md "cloudhsm_cli-user-create.md")
- [user delete](cloudhsm_cli-user-delete.md "cloudhsm_cli-user-delete.md")
- [user list](cloudhsm_cli-user-list.md "cloudhsm_cli-user-list.md")
- [user replicate](cloudhsm_cli-user-replicate.md "cloudhsm_cli-user-replicate.md")
