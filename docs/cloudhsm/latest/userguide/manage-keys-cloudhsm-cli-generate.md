# Generate keys with CloudHSM CLI

Before you can generate a key, you must start [CloudHSM CLI](cloudhsm_cli.md "cloudhsm_cli.md") and log in as a crypto user (CU). To generate keys on the HSM, use the command that corresponds to the type of key that you want to generate.
