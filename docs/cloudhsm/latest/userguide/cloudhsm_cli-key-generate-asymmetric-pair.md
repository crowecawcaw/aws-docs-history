# The generate-asymmetric-pair

category in CloudHSM CLI

In the CloudHSM CLI, **key generate-asymmetric-pair** is a parent category for
a group of commands that, when combined with the parent category, create a command that
generates asymmetric key pairs. Currently, this category consists of the following
commands:

- [key generate-asymmetric-pair ec](cloudhsm_cli-key-generate-asymmetric-pair-ec.md "cloudhsm_cli-key-generate-asymmetric-pair-ec.md")
- [key generate-asymmetric-pair rsa](cloudhsm_cli-key-generate-asymmetric-pair-rsa.md "cloudhsm_cli-key-generate-asymmetric-pair-rsa.md")
