# AWS CloudHSM Client SDK 3 configuration syntax

The following table illustrates the syntax for AWS CloudHSM configuration files for Client SDK 3.


```
configure -h | --help
          -a `<ENI IP address>`
          -m [-i `<daemon_id>`]
          --ssl --pkey `<private key file>` --cert `<certificate file>`
          --cmu `<ENI IP address>`
```
