# Delete keys with KMU and CMU

Use the [deleteKey](key_mgmt_util-deleteKey.md "key_mgmt_util-deleteKey.md") command to delete a key,
as in the following example. Only the key owner can delete a key.

```
`Command:` `deleteKey -k 524300``Cfm3DeleteKey returned: 0x00 : HSM Return: SUCCESS

Cluster Error Status
Node id 0 and err state 0x00000000 : HSM Return: SUCCESS
Node id 1 and err state 0x00000000 : HSM Return: SUCCESS
Node id 2 and err state 0x00000000 : HSM Return: SUCCESS`
```
