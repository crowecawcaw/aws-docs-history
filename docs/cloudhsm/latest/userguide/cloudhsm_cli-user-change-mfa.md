# The user change-mfa category in
 CloudHSM CLI

In the CloudHSM CLI, **user change-mfa** is a parent category for a group of
 commands that, when combined with the parent category, create a command specific to changing
 multi-factor authentication (MFA) for users.

Currently, this category consists of the following sub-command:


* [token-sign](cloudhsm_cli-user-change-mfa-token-sign.md "cloudhsm_cli-user-change-mfa-token-sign.md")
