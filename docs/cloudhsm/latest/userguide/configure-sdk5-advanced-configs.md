# Advanced configurations for the Client SDK 5 configure tool

The AWS CloudHSM Client SDK 5 configure tool includes advanced configurations that are not part of the general features most customers utilize. 
 Advanced configurations provide additional capabilities.

###### Important

After making any changes to your configuration, you need to restart your application for the changes to take effect.
