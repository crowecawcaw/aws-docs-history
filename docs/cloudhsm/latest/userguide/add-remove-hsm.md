# Scaling HSMs in an AWS CloudHSM cluster

To scale up or down your AWS CloudHSM cluster, add or remove HSMs by using the [AWS CloudHSM console](https://console.aws.amazon.com/cloudhsm/ "https://console.aws.amazon.com/cloudhsm/") or one of the [AWS SDKs or command line tools](https://aws.amazon.com/tools/ "https://aws.amazon.com/tools/"). We recommend load testing your cluster to determine the peak load you should anticipate, and then add one more HSM to it to ensure high availability.
