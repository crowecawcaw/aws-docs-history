# Exit the AWS CloudHSM KMU

Use the **exit** command in the AWS CloudHSM key_mgmt_util to exit the key_mgmt_util. Upon
successful exit, you will be returned to your standard command line.

Before you run any key_mgmt_util command, you must [start key_mgmt_util](key_mgmt_util-setup.md#key_mgmt_util-start "key_mgmt_util-setup.md#key_mgmt_util-start").

## Syntax

```
exit
```

## Parameters

There are no parameters for this command.
