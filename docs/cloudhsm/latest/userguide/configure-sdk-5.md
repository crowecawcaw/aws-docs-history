# AWS CloudHSM Client SDK 5 configure tool

Use the AWS CloudHSM Client SDK 5 configure tool to update client-side configuration files.

Each component in Client SDK 5 includes a configure tool with a designator of the component
in the file name of the configure tool. For example, the PKCS #11 library for Client SDK 5 includes a
configure tool named `configure-pkcs11` on Linux or
`configure-pkcs11.exe` on Windows.
