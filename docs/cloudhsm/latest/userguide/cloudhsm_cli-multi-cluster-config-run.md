# Configure the CloudHSM CLI for multi-cluster functionality

To configure your CloudHSM CLI for multi-cluster functionality, follow these steps:

1. Identify the clusters you want to connect to.
2. Add these clusters to your CloudHSM CLI configuration using the [configure-cli](configure-sdk-5.md "configure-sdk-5.md") subcommand `add-cluster` as described below.
3. Restart any CloudHSM CLI processes in order for the new configuration to take effect.
