# AWS Supply Chain web application APIs

The APIs listed in this section are called by AWS Supply Chain applications on behalf of federated users. These APIs are not visible in the CloudTrail logs and are not captured in the _Service Authorization Reference_ document,
see [AWS Supply Chain](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md"). Access to these APIs are controlled
by AWS Supply Chain applications based on federated user role permissions. You shouldn’t try to control access to these APIs to prevent distrupting the AWS Supply Chain applications.
