# Configuring AWS Supply Chain Analytics as an administrator

You must configure AWS Supply Chain Analytics to use Analytics dashboard.

1. In the left navigation pane on the AWS Supply Chain dashboard, choose
   **Analytics** or choose **Go to Analytics** from the AWS Supply Chain dashboard.

The **Set up AWS Supply Chain Analytics** page appears.

###### Note

If you have not ingested data into Data Lake, you need to ingest data before using AWS Supply Chain Analytics. To ingest data, see [Data lake](data-connections.md "data-connections.md"). 2. Choose **Set up Analytics**.

The Quick Suite dashboard page appears. 3. Choose **Analyses**.

You can view all the existing analysis.
