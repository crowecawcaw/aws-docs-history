# Data Validation Rules

The validations performed prior to forecast creation are below. For more information, see [Demand Planning](required_entities.md "required_entities.md").

| Rule Type                          | Rule                                             | Datasets                                                | Description                                                                                                                                                                                                                                                                                                                                                                                         | Export error records? |
| ---------------------------------- | ------------------------------------------------ | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Data Structure Validation          | Mandatory columns existence validation           | Product, Outbound order line, Supplementary time series | Verifies presence of critical columns in datasets in required<br>datasets:<br>Outbound order line: product_id, order_date, final_quantity_requested<br>Product: id, description<br>Verifies presence of critical columns in recommended datasets, if<br>provided:<br>Supplementary Time Series: id, order_date, time_series_name,<br>time_series_value                                              | No                    |
| Data Structure Validation          | Granularity columns existence validation         | Product, Outbound order line                            | Verifies presence of columns set as forecast granularity, if set in the<br>demand plan settings.<br>Outbound order line: product_id, ship_from_site_id, ship_to_site_id,<br>ship_to_site_address_city, ship_to_address_state, ship_to_address_country,<br>channel_id, customer_tpartner_id<br>Product: id, product_group_id, product_type, brand_name, color,<br>display_desc, parent_product_id    | No                    |
| Data Structure Validation          | Active product's history validation              | Product, Outbound order line,Product Alternate          | Verifies that there is atleast one active product that has history on its own<br>or through product lineage                                                                                                                                                                                                                                                                                         | No                    |
| Data Quality Validation            | Missing values in mandatory columns validation   | Product, Outbound order line, Supplementary time series | Verifies for null/empty values in mandatory columns specified in Mandatory<br>columns existence check                                                                                                                                                                                                                                                                                               | Yes                   |
| Data Quality Validation            | Missing values in granularity columns validation | Product, Outbound order line                            | Verifies for null/empty values in mandatory columns specified in Granularity<br>columns existence check                                                                                                                                                                                                                                                                                             | Yes                   |
| Data Quality Validation            | Date Range validation                            | OutboundOrderLine, SupplementaryTimeSeries              | The order_date column in the dataset must contain dates in a sane time range:<br>Anywhere from 01/01/1900 00:00:00 to 12/31/2050 00:00:00.                                                                                                                                                                                                                                                          | Yes                   |
| Forecasting Eligibility Validation | Timeseries per Predictor validation              | OutboundOrderLine                                       | The timeseries per predictor must not exceed 5,000,000.<br>"Timeseries per predictor" is calculated by taking the count of unique<br>values for the product_id column and each of the forecast granularity columns<br>and then taking the product of all those counts.                                                                                                                              | No                    |
| Forecasting Eligibility Validation | Count of active products validation              | Product                                                 | The number of active products with records in the OOL dataset must not exceed<br>800,000.                                                                                                                                                                                                                                                                                                           | No                    |
| Forecasting Eligibility Validation | Historical data sufficiency validation           | Outbound order line                                     | Verifies if at least one product in the dataset has sufficient historical<br>demand data to generate reliable forecasts<br>The forecast horizon must be no greater than 1/3 the time range in the<br>dataset (if training a new auto predictor) or 1/4 the time range in the dataset<br>(if training an existing auto predictor).<br>There is also a global maximum forecast horizon, which is 500. | No                    |
| Forecasting Eligibility Validation | Row Count validation                             | Partitioned OutboundOrderLine                           | The number of records in the partitioned OOL dataset must not exceed<br>3,000,000,000. There are certain forecast models that have smaller limits that are<br>checked here as well, if those models are being used.                                                                                                                                                                                 | No                    |
| Forecasting Eligibility Validation | Maximum Timeseries validation                    | Partitioned OutboundOrderLine                           | The number of distinct timeseries must not exceed the model's limit, if<br>there is one.<br>"Distinct timeseries" is defined as the number of distinct rows in the<br>dataset when product_id + all forecast granularity columns are<br>considered.                                                                                                                                                 | No                    |
| Forecasting Eligibility Validation | Data Density validation                          | Partitioned OutboundOrderLine                           | The Data density of the dataset must be at least 5.<br>Data density is defined as (number of distinct products in the dataset) /<br>(total number of rows in the dataset). In other words it is "average rows per<br>product".<br>NoteThe rule applies only when Prophet is selected as the forecasting algorithm.                                                                                  | No                    |
