# Order Planning and Tracking

###### Note

To generate an order insight, in addition to ingesting the required data entities and columns, you must configure your milestone and process definitions. For more information on configuring orders, see [Configuring Order Planning and Tracking for the first time](setting-up-work-orders.md "setting-up-work-orders.md").
