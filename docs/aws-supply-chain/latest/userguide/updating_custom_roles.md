# Updating existing custom user roles to access Amazon Q in AWS Supply Chain

To update an existing user permission role in AWS Supply Chain, perform the following procedure:

1. In the left navigation pane on the AWS Supply Chain dashboard, choose the
   **Settings** icon.
2. Under **Users and Permissions**, choose **Permission Roles**.

The **Permission Roles** page appears. 3. Under **Role**, select the role for which you would want to add the Amazon Q in AWS Supply Chain permission role and choose the **Edit** icon.

The **Manage Permission Role** page appears. 4. Slide the **Amazon Q in AWS Supply Chain** button to add Amazon Q in AWS Supply Chain permission role. 5. Choose **Save**.
