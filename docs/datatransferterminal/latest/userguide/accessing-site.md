# Make a data transfer at the Data Transfer Terminal facility

The Data Transfer Terminal is a secure, co-owned location that provides secure access to the AWS network. To access the Data Transfer Terminal facility, ensure that you have a confirmation email with the location description and access instructions. Refer to the topics below for more information about accessing and using the Data Transfer Terminal facility.

## What to bring

Data transfer specialists should bring in the items necessary to perform a data transfer, such as a laptop computer, flash drives, Solid State Drives (SSDs), and [AWS Snowball Edge](https://aws.amazon.com/snow/ "https://aws.amazon.com/snow/"). Ensure that your equipment is optimized to use the fiber network cables at the Data Transfer Terminal facility. For more information about optimal equipment and configurations, see [Technical requirements for using Data Transfer Terminal](tech-requirements.md "tech-requirements.md").

You are responsible for the installation, use, and removal of the equipment and items you and accompanying Data transfer specialists bring into the Data Transfer Terminal facility. Anything brought into the suite must be removed when leaving. AWS Data Transfer Terminal is not responsible for forgotten or lost items.

## The Data Transfer Terminal facility physical address

The physical address for the Data Transfer Terminal facility will not be provided. Instead, the Process owner and Data transfer specialists specified in the reservation will receive an email with the searchable public name of the Data Transfer Terminal facility. AWS Data Transfer Terminal uses the same location identification system as AWS Direct Connect so you can search for the public name on the internet to locate the Data Transfer Terminal facility. If you do not have an email with this information, confirm with your AWS Data Transfer Terminal account manager that you are included in the Transfer team and that your email information is correct.

## Accessing the building

To access the Data Transfer Terminal facility, each Data transfer specialist must provide proof of identity or a government-issued ID. Once admitted to the building, security will escort you to your Data Transfer Terminal suite.

## Expected equipment in the Data Transfer Terminal suite.

Each Data Transfer Terminal facility should only have two (2) fiber optic cables, a table or desk, and chairs. If there is any other equipment or items in the room, report it to [Support](https://aws.amazon.com/contact-us/ "https://aws.amazon.com/contact-us/") immediately.
