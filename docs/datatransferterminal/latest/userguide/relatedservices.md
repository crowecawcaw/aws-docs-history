# Related services

The following AWS services provide an optimal experience while using Data Transfer Terminal.

| AWS service                                                                      | Description                                                                                                                                                      |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS Snowball Edge](https://aws.amazon.com/snow/ "https://aws.amazon.com/snow/") | AWS Data Transfer Terminal complements Snowball products by providing a location for faster upload to your AWS cloud, minimizing wait times to access your data. |
| [Amazon S3](https://aws.amazon.com/s3/ "https://aws.amazon.com/s3/")             | Bring your own device to a Data Transfer Terminal to quickly and securely upload your data to your Amazon S3 service.                                            |
