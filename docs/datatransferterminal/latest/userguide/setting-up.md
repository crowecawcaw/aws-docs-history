# Schedule a Data Transfer Terminal reservation

To get started using AWS Data Transfer Terminal, you need to have an AWS account and logged into your Data Transfer Terminal console at https://console.aws.amazon.com/datatransferterminal. Once you’re logged into your Data Transfer Terminal console, you can see existing reservations or make a new one. To schedule a reservation, you’ll need to do the following:

1. Create a Transfer team. You will need to create a designated group of users to create a reservation and access the Data Transfer Terminal facility to make a data transfer. To learn more about this topic, see [Create a Transfer team](createteam.md "createteam.md").
2. Once your team is set up, you will need to add personnel to it. To learn more about adding personnel to your Transfer team, see [Add personnel](addusers.md "addusers.md").
3. The Process owner can schedule the data transfer with teams on the account. For more information about how to schedule the reservation, see [Specify reservation details](reservationdetails.md "reservationdetails.md").
4. Ensure that the details of the reservation are correct before submitting your request. Once submitted, a reservation request cannot be modified for at least 24 hours. For more information, see [Review and confirm your reservation](confirmreservation.md "confirmreservation.md").
   Once your reservation is processed and confirmed, your Transfer team will be able to access the Data Transfer Terminal facility at the scheduled time. For more information, see [Make a data transfer at the Data Transfer Terminal facility](accessing-site.md "accessing-site.md").
