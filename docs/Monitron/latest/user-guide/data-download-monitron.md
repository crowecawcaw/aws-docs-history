# Exporting your Amazon Monitron data to Amazon S3

You may sometimes want to access the raw data that Amazon Monitron is storing for you, in order
to stay informed about exactly what kind of data you’re securely storing with
AWS.

You can get your raw data by filing a support ticket with AWS, and by giving Amazon Monitron
permission to deliver your data to you.

To get real time operational data for Amazon Monitron resources that can be consumed
programmatically, consider exporting your data using Kinesis streams. For more
information, see [Amazon Monitron Kinesis data export v2](monitron-kinesis-export-v2.md "monitron-kinesis-export-v2.md").
