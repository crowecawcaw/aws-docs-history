# Identity and Access Management for Amazon Monitron

AWS Identity and Access Management (IAM) is an AWS service that helps an administrator securely control access
to AWS resources. IAM administrators control who can be _authenticated_ (signed in) and _authorized_
(have permissions) to use Amazon Monitron resources. IAM is an AWS service that you can
use with no additional charge.
