# Sites

After setting up a project, you can organize it into sites to make it easier to manage. A
_site_ is a collection of assets, gateways, and sensors
that share a purpose. Organizing a project into sites is helpful if your project has a large
pool of assets, gateways, and sensors. You can use sites to control access and permissions
to specific parts of that pool.

You can create up to 50 sites within a project, and add up to 100 assets and 200 gateways
to each site.
