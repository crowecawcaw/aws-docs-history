# Renaming a sensor position
<a name="as-edit-sensorposition"></a>

**Topics**
+ [Renaming a sensor position on the mobile app](#rename-position-mobile)
+ [Renaming a sensor position on the web app](#rename-position-web)

## Renaming a sensor position on the mobile app
<a name="rename-position-mobile"></a>

1. From the **Assets** list, choose the asset with the sensor position whose name you want to change. 

1. Choose the sensor with the position whose name you want to change.

1. Choose the **Sensor details** tab.

1. Under **Position details**, choose **Actions**.

1. Choose **Edit position details**. 

1. For **Position name**, enter a new name.   
![Edit position details dialog with Position name field showing Left bearing 1.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/position-details-name.png)

1. Choose **Save**. 

## Renaming a sensor position on the web app
<a name="rename-position-web"></a>

1. Select the position.

   Choose the **Actions** button in the **Positions** table.  
![Dashboard showing asset positions with warning status for Position name 3 and vibration data graph.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/vibration-web-changing-sensor-position-name-1.png)

1. Choose **Edit position name**.

1. For **Position name**, enter a new name.

1. Choose **Save**.
