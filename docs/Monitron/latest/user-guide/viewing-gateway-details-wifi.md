# Viewing Wi-Fi gateway details
<a name="viewing-gateway-details-wifi"></a>

You can view gateway details on your mobile or web app. The following gateway details are viewable:
+ IP address
+ Firmware version
+ Last time commissioned

**Note**  
You can also view and copy gateway MAC addresses. See [Retrieving MAC address details](https://docs.aws.amazon.com/Monitron/latest/user-guide/mac-address-wifi-gateway.html).

You can view sensor details on both the mobile and web app. The following section shows you how.

**Topics**
+ [To view Wi-Fi gateway details in the mobile app](#w2aac19c17c43c13)
+ [To view Wi-FI gateway details in the web app](#w2aac19c17c43c15)

## To view Wi-Fi gateway details in the mobile app
<a name="w2aac19c17c43c13"></a>

1. From the **Gateways** list, choose the gateway whose details you want to view.  
![Gateway 2 selected from a list of three gateways, each showing WiFi type and online status.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/wifi-gateway-details-mobile-v1.png)

1. From the options box that pops open, select **View gateway details**.  
![Options menu with Edit gateway name, View gateway details, and Delete gateway options.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/wifi-gateway-details-mobile-v2.png)

1. The **Gateway details** page is displayed.  
![Gateway details page showing status, physical ID, IP address, and other network information.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/wifi-gateway-details-mobile-v3.png)

## To view Wi-FI gateway details in the web app
<a name="w2aac19c17c43c15"></a>

1. From the **Gateways** list, choose the gateway whose details you want to view.  
![Gateway name MonitronGateway-e837456fe770 selected in the Gateways list.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/ethernet-gateway-web-app-1.png)

1. The **Gateway details** page is displayed.  
![Gateway details interface showing device information, status, and network statistics.](http://docs.aws.amazon.com/Monitron/latest/user-guide/images/wifi-gateway-details-web.png)
