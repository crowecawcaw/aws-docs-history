# Editing Ethernet gateway name
<a name="editing-gateway-ethernet"></a>

You can change the display name for your Ethernet gateway to find it faster. To edit a gateway name, open your web or mobile app and do the following.

**Topics**
+ [To edit an Ethernet gateway name](#editing-gateway-name-ethernet)

## To edit an Ethernet gateway name
<a name="editing-gateway-name-ethernet"></a>

1. Select the gateway name you want to edit from the **Gateways** page.

</tbody>
</table>


1. A pop-up will appear prompting you to add a customized name for the gateway.


<table>
<tbody>
  <tr><td><img src="https://docs.aws.amazon.com/Monitron/latest/user-guide/images/edit-mobile-gateway-prompt.png" alt="Edit gateway name screen with text field containing Gateway-c22as48gsedif and keyboard displayed." />Mobile app view</td><td><img src="https://docs.aws.amazon.com/Monitron/latest/user-guide/images/edit-web-gateway-prompt.png" alt="Edit gateway name dialog box with text field containing Gateway-c22as48gsedif." />Web app view</td></tr>
</tbody>
</table>


1. Enter the new name for the gateway and choose **Save**.

<tbody>

</table>


1. You will see a success message confirming the new gateway name.
