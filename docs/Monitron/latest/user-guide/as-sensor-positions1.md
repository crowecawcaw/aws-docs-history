# Sensors

Sensors collect the data from your equipment, then Amazon Monitron uses that data to
detect developing abnormalities. Where you mount a sensor (the
_position_) is extremely important for collecting and analyzing data.

To get a more detailed picture of your asset's health, you might need to collect data from
multiple positions on your asset. You can place sensors on up to 20 positions on each asset.
Each sensor position can be assigned a different machine class. If you have complex
machinery with more than one potential point of failure, we recommend that you collect data
from multiple positions.
