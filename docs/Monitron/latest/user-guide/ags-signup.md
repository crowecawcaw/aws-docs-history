# Step 1: Create an account

## Sign up for an AWS account

To get started with AWS, you need an AWS account. For information about creating an AWS account, see
[Getting started with an AWS account](../../../accounts/latest/reference/getting-started.md "../../../accounts/latest/reference/getting-started.md")

###### Important

Amazon Monitron supports all IAM Identity Center regions except opt-in and government
regions. For a list of supported regions, see [Understanding SSO requirements](mu-adding-user.md#sso-requirements "mu-adding-user.md#sso-requirements").
