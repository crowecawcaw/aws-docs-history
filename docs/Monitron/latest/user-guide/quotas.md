# Quotas in Amazon Monitron

You can request an increase for many of the Amazon Monitron quotas if your applications require
it. For information about service quotas and to request a quota increase, see [AWS Service
Quotas](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md"). You can also contact your IT Manager for assistance with requesting a
quota increase.

## Supported Regions

Amazon Monitron is currently supported in the following regions:

- US East (N. Virginia): us-east-1
- Europe (Ireland): eu-west-1
- Asia Pacific (Sydney): ap-southeast-2

## Quotas

All Amazon Monitron operations have the following quotas.

| Description                                           | Quota |
| ----------------------------------------------------- | ----- |
| Maximum number of sites per project                   | 50    |
| Maximum number of assets per site                     | 100   |
| Maximum number of positions (or sensors) per<br>asset | 20    |
| Maximum number of gateways per site                   | 200   |
| Maximum number of users per site                      | 20    |
| Maximum number of custom classes per project          | 25    |
| Maximum number of positions per custom class          | 500   |
