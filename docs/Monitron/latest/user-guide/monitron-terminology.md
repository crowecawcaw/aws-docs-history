# Amazon Monitron concepts

An Amazon Monitron implementation is structured in the following way:

|                                                                                                        |
| ------------------------------------------------------------------------------------------------------ |
| **PROJECT**<br>**→**<br>**SITE**<br>**→**<br>**ASSET**<br>**→**<br>**SENSOR**<br>**→**<br>**POSITION** |

The following table explains the Amazon Monitron concepts and terminology you need
to know to get started with Amazon Monitron:

| Concept name                                                            | Concept definition                                                                                                                                                                                                | Key facts                                                                                                                                                                                                                                                                                                                                                                                   | Common users                                           |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **[Project](projects-chapter.md "projects-chapter.md")**                | • Where you set up the gateways, assets, and sensors used by<br>Amazon Monitron<br>• Captures details of Amazon Monitron detected machine<br>abnormalities that can lead to equipment failure                     | • Resources can't be shared between projects<br>• Can only be created on the [Amazon Monitron console](https://console.aws.amazon.com/monitron "https://console.aws.amazon.com/monitron ")<br>• Can only be created and managed by IT managers or users<br>with access to the [Amazon Monitron console](https://console.aws.amazon.com/monitron "https://console.aws.amazon.com/monitron ") | • IT administrators/managers                           |
| **[Site](site-management-chapterSM.md "site-management-chapterSM.md")** | • A collection of assets, gateways, and sensors that share a<br>purpose<br>• Used to organize projects to make them easier to<br>manage                                                                           | • Helpful for organization if your project has a large pool<br>of assets, gateways, and sensors<br>• Can be used to control access and permissions<br>• Can create up to 50 sites within a project and add up to<br>100 assets and 200 gateways to each site<br>• Must be a project-level admin user to add a site to a<br>project<br>• Can be configured using both the mobile and web app | • IT administrators/managers<br>• Reliability managers |
