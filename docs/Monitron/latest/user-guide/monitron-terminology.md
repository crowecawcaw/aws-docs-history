# Amazon Monitron concepts

An Amazon Monitron implementation is structured in the following way:

|                                                                                |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **PROJECT** **→** **SITE** **→** **ASSET** **→** **SENSOR** **→** **POSITION** | The following table explains the Amazon Monitron concepts and terminology you need to know to get started with Amazon Monitron:                                                                            |
| Concept name                                                                   | Concept definition                                                                                                                                                                                         | Key facts                                                                                                                                                                                                                                                                                                                                                                                      | Common users                                                |
| ---                                                                            | ---                                                                                                                                                                                                        | ---                                                                                                                                                                                                                                                                                                                                                                                            | ---                                                         |
| **[Project](projects-chapter.md "projects-chapter.md")**                       | <br>• Where you set up the gateways, assets, and sensors used by Amazon Monitron <br>• Captures details of Amazon Monitron detected machine abnormalities that can lead to equipment failure               | <br>• Resources can't be shared between projects <br>• Can only be created on the [Amazon Monitron console](https://console.aws.amazon.com/monitron "https://console.aws.amazon.com/monitron ") <br>• Can only be created and managed by IT managers or users with access to the [Amazon Monitron console](https://console.aws.amazon.com/monitron "https://console.aws.amazon.com/monitron ") | <br>• IT administrators/managers                            |
| **[Site](site-management-chapterSM.md "site-management-chapterSM.md")**        | <br>• A collection of assets, gateways, and sensors that share a purpose <br>• Used to organize projects to make them easier to manage                                                                     | <br>• Helpful for organization if your project has a large pool of assets, gateways, and sensors <br>• Can be used to control access and permissions <br>• Can create up to 50 sites within a project and add up to 100 assets and 200 gateways to each site <br>• Must be a project-level admin user to add a site to a project <br>• Can be configured using both the mobile and web app     | <br>• IT administrators/managers <br>• Reliability managers |
| **[Gateway](gateways.md "gateways.md")**                                       | <br>• Wi-Fi or Ethernet devices that transfer the data collected by Amazon Monitron senors to the AWS Cloud.                                                                                               | <br>• Helpful for keeping track of whether sensor data is being correctly transferred to the Cloud. <br>• Must be commissioned using the mobile app                                                                                                                                                                                                                                            | <br>• Reliability managers <br>• Technicians                |
| **[Asset](assets-chapter.md "assets-chapter.md")**                             | <br>• The pieces of equipment on your factory floor <br>• Can be: + individual machines + sections of a large piece of equipment + part of an industrial process + any element of your manufacturing model | <br>• Basis for viewing the health of your machines <br>• Amazon Monitron sensors are paired to assets and their parts <br>• Can place sensors on up to 20 positions on an asset <br>• Can be configured using both mobile and web app                                                                                                                                                         | <br>• Reliability managers <br>• Technicians                |
| **[Sensor](as-sensor-positions1.md "as-sensor-positions1.md")**                | <br>• Collects temperature and vibration data from your equipment <br>• Amazon Monitron uses the data to detect developing issues                                                                          | <br>• Can place sensors on up to 20 positions on each asset <br>• Can be assigned a machine class corresponding to the machine part it's placed on <br>• Can be configured using mobile app only                                                                                                                                                                                               | <br>• Technicians <br>• Reliability managers                |
| **[Position](as-where-sensors.md "as-where-sensors.md")**                      | <br>• The place on the asset where you mount a sensor <br>• Important for collecting and analyzing data                                                                                                    | <br>• Can place sensors on up to 20 positions on each asset <br>• Positions on the same asset can be assigned different machine classes for a fine-grained view of machine health ImportantIf you have complex machinery with more than one potential point of failure, we recommend that you collect data from multiple positions.                                                            | <br>• Technicians <br>• Reliability managers                |
