# DR for SAP Data Services

As described earlier in the [HA for SAP Data Services](bobi-ha-dr-win-ha-for-sap-data-services.md "bobi-ha-dr-win-ha-for-sap-data-services.md") section, you can install SAP Data Services on either an existing SAP BusinessObjects BI Platform node or on SAP BusinessObjects Information Platform Services (IPS). In both cases, the DR approach described previously in this section applies to SAP Data Services as well.
