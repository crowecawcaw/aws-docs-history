# Migration Scenarios

The following table lists the migration scenarios that we will cover in detail in this guide. The tools and methodologies listed in the table were discussed in the [previous section](migrating-hana-tools.md "migrating-hana-tools.md").

| Migration scenario                                                                     | Source database                                                                          | Target database | Migration tool or methodology                                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| \*_Migration of anyDB from other platforms to AWS_<br>• \*                             | \*anyDB<br>• (any non-SAP HANA database such as IBM DB2, Oracle Database, or SQL Server) | SAP HANA        | SAP HANA classical migration<br>SAP DMO with System Move<br>SAP DMO move to SAP S/4 HANA (on hyperscaler) DMOVE2S4                                                                                                                                                                                                         |
| \*_Migration of SAP HANA from other platforms to AWS_<br>• \*                          | SAP HANA (scale-up and scale-out considerations apply here as well)                      | SAP HANA        | AWS Migration Hub Orchestrator<br>SAP HANA backup and restore<br>SAP HANA classical migration (considered a homogeneous system copy in this scenario)\*\*<br>SAP HANA HSR<br>SAP HANA HSR with initialization via backup and restore<br>SAP DMO with system move<br>SAP DMO move to SAP S/4 HANA (on hyperscaler) DMOVE2S4 |
| **Migration of SAP HANA from an existing EC2 instance to an EC2 High Memory instance** | SAP HANA                                                                                 | SAP HANA        | Instance resize<br>Amazon Machine Image (AMI)<br>SAP HANA HSR<br>AWS Migration Hub Orchestrator<br>SAP HANA backup and restore                                                                                                                                                                                             |

\*\*\*\*\* Other platforms include on-premises infrastructures and other cloud infrastructures outside of AWS.

\*\*\*\*\*\* See [SAP Note 1844468 – Homogeneous system copy on SAP HANA](https://service.sap.com/sap/support/notes/1844468 "https://service.sap.com/sap/support/notes/1844468").
