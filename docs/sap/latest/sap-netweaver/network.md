# Network

Ensure that your network constructs are set up to deploy resources related to SAP NetWeaver. If you haven’t already set up network components like Amazon VPC, subnets, route tables, and so on, you can use [AWS Quick Start for VPC](https://aws.amazon.com/quickstart/architecture/vpc/ "https://aws.amazon.com/quickstart/architecture/vpc/") to easily deploy scalable VPC architecture.
