# Deployment Options

Microsoft SQL Server 2008 R2 or later is supported for SAP applications on AWS. See [SAP Note 1656099 - SAP Applications on AWS: Supported DB/OS and Amazon EC2 products](https://launchpad.support.sap.com/#/notes/1656099 "https://launchpad.support.sap.com/#/notes/1656099") for supported SAP applications and databases on AWS.
