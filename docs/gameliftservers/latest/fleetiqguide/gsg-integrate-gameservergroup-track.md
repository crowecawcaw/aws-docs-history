# Track game server group

instances

After you create and deploy instances to your game server group and Auto Scaling
group, you can track the status of game server instances by calling [DescribeGameServerInstances()](../../../gamelift/latest/apireference/API_DescribeGameServerInstances.md "../../../gamelift/latest/apireference/API_DescribeGameServerInstances.md"). You can use this operation to track instance
status.. For more information on game server group status, see [Life of a game server
group](gsg-howitworks-lifecycle-gameservergroup.md "gsg-howitworks-lifecycle-gameservergroup.md").

You can also use the [Amazon GameLift Servers console](https://console.aws.amazon.com/gamelift/ "https://console.aws.amazon.com/gamelift/"), under **Game server groups**, to
monitor the status of your game server groups.
