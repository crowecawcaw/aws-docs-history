# Describe the rule set (required)

Provide details for the rule set.

- _name_ (optional) – A descriptive label for your own
  use. This value isn't associated with the rule set name that you specify when
  creating the rule set with Amazon GameLift Servers.
- _ruleLanguageVersion_ – The version of the property
  expression language used to create FlexMatch rules. The value must be
  `1.0`.
