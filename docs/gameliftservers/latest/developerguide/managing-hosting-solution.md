# Managing an Amazon GameLift Servers hosting solution (launch and beyond)

This section provides guidance on how to manage your Amazon GameLift Servers resources for the long term. Successfully launching your multiplayer game is just the beginning. Managing a production hosting solution requires
ongoing attention to performance, cost optimization, security updates, and player experience. This section provides guidance
on the operational aspects of running Amazon GameLift Servers in production, from day-one launch activities through long-term maintenance
and optimization.

Whether you're preparing for launch, managing a live game, or optimizing an established hosting solution,
