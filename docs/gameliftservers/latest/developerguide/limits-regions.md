

# Amazon GameLift Servers endpoints and quotas
<a name="limits-regions"></a>
+ For service endpoints and beacon endpoints that you can use to connect programmatically with the service, see [Amazon GameLift Servers service endpoints](https://docs.aws.amazon.com/general/latest/gr/gamelift.html#gamelift_region).
+ For Amazon GameLift Servers quotas on the use of service resources or operations per AWS account, see [Amazon GameLift Servers service quotas](https://docs.aws.amazon.com/general/latest/gr/gamelift.html#limits_gamelift). For more information on quotas and how to request an increase, see [AWS service quotas](https://docs.aws.amazon.com/general/latest/gr/aws_service_limits.html). You can request quota increases by using the Amazon GameLift Servers console.
