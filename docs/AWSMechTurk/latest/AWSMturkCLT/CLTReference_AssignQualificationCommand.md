There are two ways to use this operation: <br>• Bulk Operation— If you want to assign multiple Qualifications, use this command with a file that contains the Qualification Type ID and the list of Workers to be assigned the Qualfication. <br>• Single Assignmentn— You can specify the Qualification Type ID, the Worker, and the assigned Qualification score on the command line. ## Arguments The following table describes the arguments for the `assignQualification` command.   |
