| Name                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Description                                                                                                                                                                                                   | Required |
| ---                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | ---                                                                                                                                                                                                           | ---      |

| `-qualtypeid [Qualification Type ID]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | The Qualification Type ID of the Qualification to revoke from the Worker. | `-reason [text]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | The reason you are revoking the Qualification. The text must be enclosed in quotation marks. Example: `-reason "I'm sorry but your work quality is below acceptable standards."`                              | No       |
| `-sandbox`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Runs this command in the Amazon Mechanical Turk sandbox for testing. Example: `-workerid A3C4G8DMXFG5PQ`                                                                                                        | Yes      | ## Example The following examples for Unix and Windows show how to use the `revokeQualification` command.
