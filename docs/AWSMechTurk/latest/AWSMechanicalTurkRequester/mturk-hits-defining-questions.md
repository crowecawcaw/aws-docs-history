# Define questions

The central component of a task in Amazon Mechanical Turk (Mechanical Turk) is the interface you provide for
workers to give you the data you need. In Mechanical Turk tasks are presented via a web interface with
which workers can interact and submit completed tasks. The following sections outline how to
define a _question_ in Mechanical Turk.
