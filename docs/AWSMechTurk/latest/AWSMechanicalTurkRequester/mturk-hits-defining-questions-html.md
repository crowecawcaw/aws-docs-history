# Use HTML to define questions

Because workers access tasks (HITs) on Amazon Mechanical Turk (Mechanical Turk) using a web browser, the most
common approach for creating a task interface for Mechanical Turk is to use HTML, CSS, and JavaScript.
The following describes how the Mechanical Turk worker website works and the necessary steps to define
an HTML task interface.
