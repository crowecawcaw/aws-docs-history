# Approve and reject assignments

A Requester approves or rejects assignments that Workers submit. When you approve an
assignment, the Worker gets paid. When you reject an assignment, the Worker doesn't get
paid.

You can approve results individually or all at once. Also, you can sort the results
based on the Worker ID so you can review the results from a specific Worker all at once.
