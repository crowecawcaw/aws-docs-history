

# Assign a qualification to a Worker
<a name="AssigningaQualificationTypetoaWorker"></a>

This section shows how to assign a qualification type to a Worker. You must first create a qualification type before you can assign the type to a Worker. For information about creating qualification types, see [Managing qualification types](ManagingQualificationTypes.md).

**To assign a qualification type to a Worker**

1. On the Mechanical Turk Requester website at [https://requester.mturk.com/](https://requester.mturk.com/), choose the **Manage** tab and then choose **Workers**.

1. On the **Manage Workers** page, choose the Worker ID of the Worker you want to assign a qualification type to.

1. On the **Manage Individual Worker** page, choose **Assign Qualification Type**.

1. On the **Assign Qualification Type** page, select the check boxes next to the qualification types you want to assign to the Worker.

1. In the **Score** text box that appears beneath each selected qualification type, enter a score (0 to 100) and choose **Assign**. Use scores to differentiate Workers that have the same Qualification Type. The Worker's qualification appears at the bottom of the window.

1. In the **Score** column, choose the **edit** link to change the qualification score.
