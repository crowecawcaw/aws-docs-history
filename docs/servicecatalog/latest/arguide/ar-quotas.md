# AWS Service Catalog AppRegistry default service quotas

This topic describes the default service quotas for AWS Service Catalog AppRegistry.
For more information, see[What is Service Quotas?](../../../servicequotas/latest/userguide/intro.md "../../../servicequotas/latest/userguide/intro.md") in the _Service Quotas_.

###### AppRegistry service quotas

- Applications per AWS Region: 2,000
- Attribute groups per AWS Region: 2,000
- Resources per application: 1,000
- Attribute groups per application: 1,000
- Applications per attribute group: 1,000
- Attribute group size: 8,000 characters

###### Note

You can request a quota increase.
For more information, see [Requesting a quota increase](../../../servicequotas/latest/userguide/request-quota-increase.md "../../../servicequotas/latest/userguide/request-quota-increase.md") in the _Service Quotas_.
