# Using Attribute group details

You can view the following details for an attribute group
from the **Attribute group details** screen:

- Name
- Description
- Date created
- Attribute group ID
- Attribute group ARN
- Created by
- Share configuration

For more information,
see [Viewing Attribute group details](view-attr-group.md "view-attr-group.md").

You can also perform the following actions
from this screen:

- Edit attribute groups.
  For more information,
  see [Editing attribute groups](edit-attr-group.md "edit-attr-group.md").
- Delete attribute groups.
  For more information,
  see [Deleting attribute groups](delete-attr-group.md "delete-attr-group.md").
- View and edit attribute group metadata.
  For more information,
  see [Viewing attribute group metadata](manage-metatdata.md "manage-metatdata.md").
- View resource shares
  associated
  to attribute groups.
  You can also create and delete resource shares.
  For more information,
  see [Sharing resources with accounts in your organization](sharing-definitions.md "sharing-definitions.md").
- View attribute group tags.
  You can also add and delete attribute group tags.
  For more information,
  see [Managing tags](add-tags.md "add-tags.md").
