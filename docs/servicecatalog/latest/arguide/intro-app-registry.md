# What is AppRegistry?

With AppRegistry, you create applications to store associated resources.
You can create attribute groups that describe the context of your applications based on metadata you provide.
You can create tags that assign metadata to applications and attribute groups and associate resources with applications.
You can also share applications and attribute groups to accounts, organizations, and organizational units.

## AWS service integrations

The following AWS services integrate with AppRegistry:

- **AWS Billing**

With [Billing](../../../awsaccountbilling/latest/aboutv2/billing-what-is.md "../../../awsaccountbilling/latest/aboutv2/billing-what-is.md"), you can use [cost allocation tags](../../../awsaccountbilling/latest/aboutv2/custom-tags.md "../../../awsaccountbilling/latest/aboutv2/custom-tags.md") to analyze cost trends for your applications and resources.

- **Amazon CloudWatch**

With [CloudWatch](../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md "../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md"), you can use a feature called [Application Insights](../../../AmazonCloudWatch/latest/monitoring/cloudwatch-application-insights.md "../../../AmazonCloudWatch/latest/monitoring/cloudwatch-application-insights.md") to monitor application resources and detect issues with applications.

- **AWS Management Console**

With the [AWS Management Console](https://aws.amazon.com/console/ "https://aws.amazon.com/console/"), you can access and view your applications and associated resources.

- **AWS Resource Access Manager (AWS RAM)**

With [AWS RAM](../../../ram/latest/userguide/what-is.md "../../../ram/latest/userguide/what-is.md"), you can [share applications and attribute groups](../../../ram/latest/userguide/working-with.md "../../../ram/latest/userguide/working-with.md") through AWS Organizations.

- **AWS Resilience Hub**

With [Resilience Hub](../../../resilience-hub/latest/userguide/what-is.md "../../../resilience-hub/latest/userguide/what-is.md"), you can [collect application resources](../../../resilience-hub/latest/userguide/applications.md "../../../resilience-hub/latest/userguide/applications.md") to create a resiliency policy.

- **AWS Resource Groups**

With [Resource Groups](../../../ARG/latest/userguide/resource-groups.md "../../../ARG/latest/userguide/resource-groups.md"), you can use tags to [share applications and attribute groups](../../../ARG/latest/userguide/integrated-services-list.md "../../../ARG/latest/userguide/integrated-services-list.md"), as well as organize application resources.

- **AWS Service Catalog**

With [Service Catalog](../adminguide/introduction.md "../adminguide/introduction.md"), you can [create provisioned products](../adminguide/provisioned-products.md "../adminguide/provisioned-products.md"), which are AWS CloudFormation stacks, that you can associate with applications.

- **AWS Service Management Connector**

With [Service Management Connector](../adminguide/integrations-servicenow.md "../adminguide/integrations-servicenow.md"), you can view applications in a ServiceNow Configuration Management Database.

- **AWS Systems Manager**

With [Systems Manager](../../../systems-manager/latest/userguide/what-is-systems-manager.md "../../../systems-manager/latest/userguide/what-is-systems-manager.md"), you can use a feature called [Application Manager](../../../systems-manager/latest/userguide/application-manager.md "../../../systems-manager/latest/userguide/application-manager.md") to detect and fix issues with resources in the context of their applications and clusters.

- **AWS Well-Architected Tool**

With [AWS WA Tool](../../../wellarchitected/latest/userguide/intro.md "../../../wellarchitected/latest/userguide/intro.md"), you can extend AWS Well-Architected functionality, best practices, measurements, and learnings into your existing architecture governance processes, applications, and workflows.
