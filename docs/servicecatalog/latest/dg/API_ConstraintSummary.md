# ConstraintSummary

Summary information about a constraint.

## Contents

**Description**

The description of the constraint.

Type: String

Length Constraints: Maximum length of 2000.

Required: No

**Type**

The type of constraint.

- `LAUNCH`
- `NOTIFICATION`
- STACKSET
- `TEMPLATE`

Type: String

Length Constraints: Minimum length of 1. Maximum length of 1024.

Required: No
