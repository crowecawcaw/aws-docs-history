# LaunchPath

A launch path object.

## Contents

**Id**

The identifier of the launch path.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 100.

Pattern: `^[a-zA-Z0-9_\-]*`

Required: No

**Name**

The name of the launch path.

Type: String

Required: No
