# ShareDetails

Information about the portfolio share operation.

## Contents

**ShareErrors**

List of errors.

Type: Array of [ShareError](API_ShareError.md "API_ShareError.md") objects

Required: No

**SuccessfulShares**

List of accounts for whom the operation succeeded.

Type: Array of strings

Pattern: `^[0-9]{12}$`

Required: No
