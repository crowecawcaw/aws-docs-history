# Step 3: Create a AWS Service Catalog portfolio

You can create a portfolio in your AWS Service Catalog administrator account (hub account) for easy product
organization and distribution to end user accounts (spoke accounts).

###### To create a portfolio

1. Open the AWS Service Catalog console at [https://console.aws.amazon.com/servicecatalog/](https://console.aws.amazon.com/servicecatalog/ "https://console.aws.amazon.com/servicecatalog/") and sign in as an administrator.
2. In the left navigation panel, choose **Portfolios**, and then choose
   **Create portfolio**.
3. Enter the following values:
   - **Portfolio name** –
     `S3 bucket`
   - **Portfolio description** – `Sample
portfolio for Terraform configurations.`
   - **Owner** – `IT
(it@example.com)`

4. Choose **Create**.
