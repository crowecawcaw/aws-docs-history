# Step 3: Create a portfolio

To provide users with products, begin by creating a portfolio for those products.

###### To create a portfolio

1. Open the Service Catalog console at [https://console.aws.amazon.com/servicecatalog/](https://console.aws.amazon.com/servicecatalog/ "https://console.aws.amazon.com/servicecatalog/").
2. In the left navigation panel, choose **Portfolios**, and then choose
   **Create portfolio**.
3. Type the following values:
   - **Portfolio name** –
     `Engineering Tools`
   - **Portfolio description** – `Sample
portfolio that contains a single product.`
   - **Owner** – `IT
(it@example.com)`

4. Choose **Create**.
