# Step 7: Grant end users access to the portfolio

Now that you have created a portfolio and added a product, you are ready to grant access to
end users.

###### Prerequisites

If you haven't created an IAM group for the endusers, see [Grant permissions to AWS Service Catalog end users](getstarted-iamenduser.md "getstarted-iamenduser.md").

###### To provide access to the portfolio

1. On the portfolio details page, choose the **Access** tab.
2. Choose **Grant access**.
3. On the **Groups** tab, select the checkbox for the IAM group for the end
   users.
4. Choose **Add Access**.
