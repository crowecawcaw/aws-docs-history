# Personally identifiable information (PII) recipe steps

Use these recipe steps to perform transformations on personally identifiable information (PII) in a dataset.

###### Note

In addition to the recipe steps in this section, there are DataBrew recipe steps not designed specifically for
PII that you can use to handle PII. An example is [DELETE](recipe-actions.DELETE.md "recipe-actions.DELETE.md"), a basic column recipe step that deletes a column.
