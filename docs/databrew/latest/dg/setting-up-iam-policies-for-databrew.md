# Setting up IAM policies for DataBrew

You use IAM policies to manage permissions. A policy makes it easier to add related
permissions all at once, rather than one at a time.

We recommend that you create the policies using the same names we provide. We use the
names shown following for these policies throughout the documentation. Using these names
also makes it easier if you ever need to contact AWS Support. However, you can choose to
change both the policy names and their contents. For more information about IAM
policies, see [Create a customer managed
policy](../../../IAM/latest/UserGuide/tutorial_managed-policies.md "../../../IAM/latest/UserGuide/tutorial_managed-policies.md") in the _IAM User Guide_.

After you create the policies needed to use DataBrew, you attach them to users and roles.
How to do this is covered later in this section.
