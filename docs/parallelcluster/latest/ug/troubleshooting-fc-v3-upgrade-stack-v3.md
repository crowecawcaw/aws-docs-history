# Trying to upgrade the AWS ParallelCluster

API stack

If you get an error such as `UPDATE_FAILED` when you try to upgrade the
AWS ParallelCluster API stack, we recommend that you check for a solution in the **Known
Issues** sections of the [AWS ParallelCluster Wiki](https://github.com/aws/aws-parallelcluster/wiki "https://github.com/aws/aws-parallelcluster/wiki") on
GitHub. For example, see [ParallelCluster API Stack Upgrade Fails for ECR resources](<https://github.com/aws/aws-parallelcluster/wiki/(3.0.0-3.1.4)-ParallelCluster-API-Stack-Upgrade-Fails-for-ECR-resources> "https://github.com/aws/aws-parallelcluster/wiki/(3.0.0-3.1.4)-ParallelCluster-API-Stack-Upgrade-Fails-for-ECR-resources"), which identifies one
possible issue and provides mitigation options.
