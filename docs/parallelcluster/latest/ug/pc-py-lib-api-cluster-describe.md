# `describe_cluster`
<a name="pc-py-lib-api-cluster-describe"></a>

```
describe_cluster(cluster_name, region)
```

Get detailed information about an existing cluster.Parameters:

**`cluster_name` (required)**  
The cluster name.

**`region`**  
The cluster AWS Region.
