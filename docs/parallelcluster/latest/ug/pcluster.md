# `pcluster version`

Displays the version of AWS ParallelCluster.

```
pcluster version [-h] [--debug]
```

## Named arguments

`-h, --help`

Shows the help text for `pcluster version`.

`--debug`

Enables debug logging.

**Example using AWS ParallelCluster version 3.1.4:**

```
`$` `pcluster version``{
 "version": "3.1.4"
}`
```
