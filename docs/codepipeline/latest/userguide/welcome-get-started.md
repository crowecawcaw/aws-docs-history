# How do I get started with CodePipeline?

To get started with CodePipeline:

1. **Learn** how CodePipeline works by reading the [CodePipeline concepts](concepts.md "concepts.md") section.
2. **Prepare** to use CodePipeline by following the steps
   in [Getting started with CodePipeline](getting-started-codepipeline.md "getting-started-codepipeline.md").
3. **Experiment** with CodePipeline by following the steps
   in the [CodePipeline tutorials](tutorials.md "tutorials.md") tutorials.
4. **Use** CodePipeline for your new or existing projects
   by following the steps in [Create a pipeline, stages, and actions](pipelines-create.md "pipelines-create.md").
