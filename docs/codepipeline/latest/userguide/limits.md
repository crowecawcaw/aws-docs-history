# Quotas in AWS CodePipeline

CodePipeline has quotas for the number of pipelines, stages, actions, and webhooks that an AWS
account can have in each AWS Region.

These quotas apply per Region and can be increased. It can take up to two weeks to process
requests for a quota increase.

For variable values, there is a maximum length of 1000 characters For variable values, all characters are allowed.
