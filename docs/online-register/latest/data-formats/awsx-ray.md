# Data retrieval APIs for AWS X-Ray

AWS X-Ray provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                                 | Description                                                                                                                                                                        | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetTraceSummaryById](../../../xray/latest/devguide/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-console "../../../xray/latest/devguide/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-console") | Retrieve metadata for a list of traces specified by ID                                                                                                                             | Read         |
| [BatchGetTraces](../../../xray/latest/api/API_BatchGetTraces.md "../../../xray/latest/api/API_BatchGetTraces.md")                                                                                                                                                       | Retrieve a list of traces specified by ID. Each trace is a collection of segment documents that originates from a single request. Use GetTraceSummaries to get a list of trace IDs | List         |
| [CancelTraceRetrieval](API_CancelTraceRetrieval.md "API_CancelTraceRetrieval.md")                                                                                                                                                                                       | Cancel an ongoing trace retrieval job initiated by StartTraceRetrieval using the provided RetrievalToken. A successful cancellation will return an HTTP 200 response               | Read         |
| [GetDistinctTraceGraphs](../../../xray/latest/devguide/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-console "../../../xray/latest/devguide/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-console")   | Retrieve distinct service graphs for one or more specific trace IDs                                                                                                                | Read         |
| [GetEncryptionConfig](../../../xray/latest/api/API_GetEncryptionConfig.md "../../../xray/latest/api/API_GetEncryptionConfig.md")                                                                                                                                        | Retrieve the current encryption configuration for X-Ray data                                                                                                                       | Read         |
| [GetGroup](../../../xray/latest/api/API_GetGroup.md "../../../xray/latest/api/API_GetGroup.md")                                                                                                                                                                         | Retrieve group resource details                                                                                                                                                    | Read         |
| [GetGroups](../../../xray/latest/api/API_GetGroups.md "../../../xray/latest/api/API_GetGroups.md")                                                                                                                                                                      | Retrieve all active group details                                                                                                                                                  | Read         |
| [GetIndexingRules](../../../xray/latest/api/API_GetIndexingRules.md "../../../xray/latest/api/API_GetIndexingRules.md")                                                                                                                                                 | Retrieve all indexing rules. Indexing rules are used to determine the server-side sampling rate for spans ingested through the CloudWatchLogs destination and indexed by X-Ray     | Read         |
| [GetInsight](../../../xray/latest/api/API_GetInsight.md "../../../xray/latest/api/API_GetInsight.md")                                                                                                                                                                   | Retrieve the details of a specific insight                                                                                                                                         | Read         |
| [GetInsightEvents](../../../xray/latest/api/API_GetInsightEvents.md "../../../xray/latest/api/API_GetInsightEvents.md")                                                                                                                                                 | Retrieve the events of a specific insight                                                                                                                                          | Read         |
| [GetInsightImpactGraph](../../../xray/latest/api/API_GetInsightImpactGraph.md "../../../xray/latest/api/API_GetInsightImpactGraph.md")                                                                                                                                  | Retrieve the part of the service graph which is impacted for a specific insight                                                                                                    | Read         |
| [GetInsightSummaries](../../../xray/latest/api/API_GetInsightSummaries.md "../../../xray/latest/api/API_GetInsightSummaries.md")                                                                                                                                        | Retrieve the summary of all insights for a group and time range with optional filters                                                                                              | Read         |
| [GetRetrievedTracesGraph](API_GetRetrievedTracesGraph.md "API_GetRetrievedTracesGraph.md")                                                                                                                                                                              | Retrieve a service graph for traces based on the specified RetrievalToken from the Transaction Search CloudWatch log group                                                         | Read         |
| [GetSamplingRules](../../../xray/latest/api/API_GetSamplingRules.md "../../../xray/latest/api/API_GetSamplingRules.md")                                                                                                                                                 | Retrieve all sampling rules                                                                                                                                                        | Read         |
| [GetSamplingStatisticSummaries](../../../xray/latest/api/API_GetSamplingStatisticSummaries.md "../../../xray/latest/api/API_GetSamplingStatisticSummaries.md")                                                                                                          | Retrieve information about recent sampling results for all sampling rules                                                                                                          | Read         |
| [GetSamplingTargets](../../../xray/latest/api/API_GetSamplingTargets.md "../../../xray/latest/api/API_GetSamplingTargets.md")                                                                                                                                           | Request a sampling quota for rules that the service is using to sample requests                                                                                                    | Read         |
| [GetServiceGraph](../../../xray/latest/api/API_GetServiceGraph.md "../../../xray/latest/api/API_GetServiceGraph.md")                                                                                                                                                    | Retrieve a document that describes services that process incoming requests, and downstream services that they call as a result                                                     | Read         |
| [GetTimeSeriesServiceStatistics](../../../xray/latest/api/API_GetTimeSeriesServiceStatistics.md "../../../xray/latest/api/API_GetTimeSeriesServiceStatistics.md")                                                                                                       | Retrieve an aggregation of service statistics defined by a specific time range bucketed into time intervals                                                                        | Read         |
| [GetTraceGraph](../../../xray/latest/api/API_GetTraceGraph.md "../../../xray/latest/api/API_GetTraceGraph.md")                                                                                                                                                          | Retrieve a service graph for one or more specific trace IDs                                                                                                                        | Read         |
| [GetTraceSegmentDestination](../../../xray/latest/api/API_GetTraceSegmentDestination.md "../../../xray/latest/api/API_GetTraceSegmentDestination.md")                                                                                                                   | Retrieve the current destination of data sent to PutTraceSegments and OpenTelemetry API                                                                                            | Read         |
| [GetTraceSummaries](../../../xray/latest/api/API_GetTraceSummaries.md "../../../xray/latest/api/API_GetTraceSummaries.md")                                                                                                                                              | Retrieve IDs and metadata for traces available for a specified time frame using an optional filter. To get the full traces, pass the trace IDs to BatchGetTraces                   | Read         |
| [ListResourcePolicies](../../../xray/latest/api/API_ListResourcePolicies.md "../../../xray/latest/api/API_ListResourcePolicies.md")                                                                                                                                     | List resource policies                                                                                                                                                             | List         |
| [ListRetrievedTraces](API_ListRetrievedTraces.md "API_ListRetrievedTraces.md")                                                                                                                                                                                          | Retrieve a list of traces for a given RetrievalToken from the Transaction Search CloudWatch log group                                                                              | List         |
| [ListTagsForResource](../../../xray/latest/api/API_ListTagsForResource.md "../../../xray/latest/api/API_ListTagsForResource.md")                                                                                                                                        | List tags for an X-Ray resource                                                                                                                                                    | List         |
| [StartTraceRetrieval](API_StartTraceRetrieval.md "API_StartTraceRetrieval.md")                                                                                                                                                                                          | Initiate a trace retrieval process using the specified time range and for the given trace IDs on the Transaction Search CloudWatch log group                                       | Read         |
