# Data retrieval APIs for AWS Budget Service

AWS Budget Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                              | Description                                                                                                                                                                    | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeBudgetAction](../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetAction.md "../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetAction.md")                                  | Retrieve the details of a specific budget action associated with a budget                                                                                                      | Read         |
| [DescribeBudgetActionHistories](../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionHistories.md "../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionHistories.md")       | Retrieve a historical view of the budget actions statuses associated with a particular budget action. These status include statues such as 'Standby', 'Pending' and 'Executed' | Read         |
| [DescribeBudgetActionsForAccount](../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionsForAccount.md "../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionsForAccount.md") | Retrieve the details of all of the budget actions associated with your account                                                                                                 | Read         |
| [DescribeBudgetActionsForBudget](../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionsForBudget.md "../../../aws-cost-management/latest/APIReference/API_budgets_DescribeBudgetActionsForBudget.md")    | Retrieve the details of all of the budget actions associated with a budget                                                                                                     | Read         |
| [ListTagsForResource](../../../aws-cost-management/latest/APIReference/API_budgets_ListTagsForResource.md "../../../aws-cost-management/latest/APIReference/API_budgets_ListTagsForResource.md")                                     | View resource tags for a budget or budget action                                                                                                                               | Read         |
| [ViewBudget](../../../aws-cost-management/latest/APIReference/API_Operations_AWS_Budgets.md "../../../aws-cost-management/latest/APIReference/API_Operations_AWS_Budgets.md")                                                        | View budgets and budget details                                                                                                                                                | Read         |
