| [GetCoverageStatistics](../../../guardduty/latest/APIReference/API_GetCoverageStatistics.md "../../../guardduty/latest/APIReference/API_GetCoverageStatistics.md")                                     | List Amazon GuardDuty coverage statistics for the specified GuardDuty account in a Region                                   | Read         |
