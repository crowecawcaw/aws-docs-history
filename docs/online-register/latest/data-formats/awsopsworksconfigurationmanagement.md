

# Data retrieval APIs for AWS OpsWorks Configuration Management
<a name="awsopsworksconfigurationmanagement"></a>

AWS OpsWorks Configuration Management provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="opsworks-cm-DescribeAccountAttributes"></a>[DescribeAccountAttributes](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_DescribeAccountAttributes.html) | Describe the service limits for the user's account | List | 
| <a name="opsworks-cm-DescribeBackups"></a>[DescribeBackups](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_DescribeBackups.html) | Describe a single backup, all backups of a specified server or all backups of the user's account | List | 
| <a name="opsworks-cm-DescribeEvents"></a>[DescribeEvents](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_DescribeEvents.html) | Describe all events of the specified server | List | 
| <a name="opsworks-cm-DescribeNodeAssociationStatus"></a>[DescribeNodeAssociationStatus](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_DescribeNodeAssociationStatus.html) | Describe the association status for the specified node token and the specified server | List | 
| <a name="opsworks-cm-DescribeServers"></a>[DescribeServers](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_DescribeServers.html) | Describe the specified server or all servers of the user's account | List | 
| <a name="opsworks-cm-ExportServerEngineAttribute"></a>[ExportServerEngineAttribute](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_ExportServerEngineAttribute.html) | Export an engine attribute from a server | Read | 
| <a name="opsworks-cm-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/opsworks-cm/latest/APIReference/API_ListTagsForResource.html) | List the tags that are applied to the specified server or backup | Read |
