# Data retrieval APIs for Amazon Pinpoint Email Service

Amazon Pinpoint Email Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                   | Description                                                                                                                | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetAccount](../../../pinpoint-email/latest/APIReference/API_GetAccount.md "../../../pinpoint-email/latest/APIReference/API_GetAccount.md")                                                                               | Get information about the email-sending status and capabilities                                                            | Read         |
| [GetBlacklistReports](../../../pinpoint-email/latest/APIReference/API_GetBlacklistReports.md "../../../pinpoint-email/latest/APIReference/API_GetBlacklistReports.md")                                                    | Retrieve a list of the deny lists on which your dedicated IP addresses appear                                              | Read         |
| [GetConfigurationSet](../../../pinpoint-email/latest/APIReference/API_GetConfigurationSet.md "../../../pinpoint-email/latest/APIReference/API_GetConfigurationSet.md")                                                    | Get information about an existing configuration set                                                                        | Read         |
| [GetConfigurationSetEventDestinations](../../../pinpoint-email/latest/APIReference/API_GetConfigurationSetEventDestinations.md "../../../pinpoint-email/latest/APIReference/API_GetConfigurationSetEventDestinations.md") | Retrieve a list of event destinations that are associated with a configuration set                                         | Read         |
| [GetDedicatedIp](../../../pinpoint-email/latest/APIReference/API_GetDedicatedIp.md "../../../pinpoint-email/latest/APIReference/API_GetDedicatedIp.md")                                                                   | Get information about a dedicated IP address                                                                               | Read         |
| [GetDedicatedIps](../../../pinpoint-email/latest/APIReference/API_GetDedicatedIps.md "../../../pinpoint-email/latest/APIReference/API_GetDedicatedIps.md")                                                                | List the dedicated IP addresses that are associated with your account                                                      | Read         |
| [GetDeliverabilityDashboardOptions](../../../pinpoint-email/latest/APIReference/API_GetDeliverabilityDashboardOptions.md "../../../pinpoint-email/latest/APIReference/API_GetDeliverabilityDashboardOptions.md")          | Get the status of the Deliverability dashboard                                                                             | Read         |
| [GetDeliverabilityTestReport](../../../pinpoint-email/latest/APIReference/API_GetDeliverabilityTestReport.md "../../../pinpoint-email/latest/APIReference/API_GetDeliverabilityTestReport.md")                            | Retrieve the results of a predictive inbox placement test                                                                  | Read         |
| [GetDomainDeliverabilityCampaign](../../../pinpoint-email/latest/APIReference/API_GetDomainDeliverabilityCampaign.md "../../../pinpoint-email/latest/APIReference/API_GetDomainDeliverabilityCampaign.md")                | Retrieve all the deliverability data for a specific campaign                                                               | Read         |
| [GetDomainStatisticsReport](../../../pinpoint-email/latest/APIReference/API_GetDomainStatisticsReport.md "../../../pinpoint-email/latest/APIReference/API_GetDomainStatisticsReport.md")                                  | Retrieve inbox placement and engagement rates for the domains that you use to send email                                   | Read         |
| [GetEmailIdentity](../../../pinpoint-email/latest/APIReference/API_GetEmailIdentity.md "../../../pinpoint-email/latest/APIReference/API_GetEmailIdentity.md")                                                             | Get information about a specific identity associated with your account                                                     | Read         |
| [ListConfigurationSets](../../../pinpoint-email/latest/APIReference/API_ListConfigurationSets.md "../../../pinpoint-email/latest/APIReference/API_ListConfigurationSets.md")                                              | List all of the configuration sets associated with your account                                                            | List         |
| [ListDedicatedIpPools](../../../pinpoint-email/latest/APIReference/API_ListDedicatedIpPools.md "../../../pinpoint-email/latest/APIReference/API_ListDedicatedIpPools.md")                                                 | List all of the dedicated IP pools that exist in your account                                                              | List         |
| [ListDeliverabilityTestReports](../../../pinpoint-email/latest/APIReference/API_ListDeliverabilityTestReports.md "../../../pinpoint-email/latest/APIReference/API_ListDeliverabilityTestReports.md")                      | Retrieve a list of the predictive inbox placement tests that you've performed, regardless of their statuses                | List         |
| [ListDomainDeliverabilityCampaigns](../../../pinpoint-email/latest/APIReference/API_ListDomainDeliverabilityCampaigns.md "../../../pinpoint-email/latest/APIReference/API_ListDomainDeliverabilityCampaigns.md")          | Retrieve deliverability data for all the campaigns that used a specific domain to send email during a specified time range | Read         |
| [ListEmailIdentities](../../../pinpoint-email/latest/APIReference/API_ListEmailIdentities.md "../../../pinpoint-email/latest/APIReference/API_ListEmailIdentities.md")                                                    | List all of the email identities that are associated with your account                                                     | List         |
| [ListTagsForResource](../../../pinpoint-email/latest/APIReference/API_ListTagsForResource.md "../../../pinpoint-email/latest/APIReference/API_ListTagsForResource.md")                                                    | Retrieve a list of the tags (keys and values) that are associated with a specific resource                                 | Read         |
