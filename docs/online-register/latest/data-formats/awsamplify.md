

# Data retrieval APIs for AWS Amplify
<a name="awsamplify"></a>

AWS Amplify provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="amplify-GetApp"></a>[GetApp](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve an existing Amplify App by appId | Read | 
| <a name="amplify-GetArtifactUrl"></a>[GetArtifactUrl](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve artifact info that corresponds to a artifactId | Read | 
| <a name="amplify-GetBackendEnvironment"></a>[GetBackendEnvironment](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve a backend environment for an Amplify App | Read | 
| <a name="amplify-GetBranch"></a>[GetBranch](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve a branch for an Amplify App | Read | 
| <a name="amplify-GetDomainAssociation"></a>[GetDomainAssociation](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve domain info that corresponds to an appId and domainName | Read | 
| <a name="amplify-GetJob"></a>[GetJob](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Get a job for a branch, part of an Amplify App | Read | 
| <a name="amplify-GetWebACLForResource"></a>[GetWebACLForResource](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve the WebACL associated with a Resource | Read | 
| <a name="amplify-GetWebHook"></a>[GetWebHook](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | Retrieve webhook info that corresponds to a webhookId | Read | 
| <a name="amplify-ListApps"></a>[ListApps](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List existing Amplify Apps | List | 
| <a name="amplify-ListArtifacts"></a>[ListArtifacts](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List artifacts with an app, a branch, a job and an artifact type | List | 
| <a name="amplify-ListBackendEnvironments"></a>[ListBackendEnvironments](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List backend environments for an Amplify App | List | 
| <a name="amplify-ListBranches"></a>[ListBranches](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List branches for an Amplify App | List | 
| <a name="amplify-ListDomainAssociations"></a>[ListDomainAssociations](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List domains with an app | List | 
| <a name="amplify-ListJobs"></a>[ListJobs](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List Jobs for a branch, part of an Amplify App | List | 
| <a name="amplify-ListResourcesForWebACL"></a>[ListResourcesForWebACL](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List the Resources associated with a WebACL | List | 
| <a name="amplify-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List tags for an AWS Amplify Console resource | Read | 
| <a name="amplify-ListWebHooks"></a>[ListWebHooks](https://docs.aws.amazon.com/amplify/latest/userguide/welcome.html) | List webhooks on an App | List |
