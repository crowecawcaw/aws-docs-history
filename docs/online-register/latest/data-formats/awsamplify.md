# Data retrieval APIs for AWS Amplify

AWS Amplify provides the following APIs for data retrieval.

| Actions                                                                                                                | Description                                                      | Access level |
| ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------ |
| [GetApp](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")                  | Retrieve an existing Amplify App by appId                        | Read         |
| [GetArtifactUrl](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")          | Retrieve artifact info that corresponds to a artifactId          | Read         |
| [GetBackendEnvironment](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")   | Retrieve a backend environment for an Amplify App                | Read         |
| [GetBranch](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")               | Retrieve a branch for an Amplify App                             | Read         |
| [GetDomainAssociation](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")    | Retrieve domain info that corresponds to an appId and domainName | Read         |
| [GetJob](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")                  | Get a job for a branch, part of an Amplify App                   | Read         |
| [GetWebACLForResource](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")    | Retrieve the WebACL associated with a Resource                   | Read         |
| [GetWebHook](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")              | Retrieve webhook info that corresponds to a webhookId            | Read         |
| [ListApps](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")                | List existing Amplify Apps                                       | List         |
| [ListArtifacts](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")           | List artifacts with an app, a branch, a job and an artifact type | List         |
| [ListBackendEnvironments](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md") | List backend environments for an Amplify App                     | List         |
| [ListBranches](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")            | List branches for an Amplify App                                 | List         |
| [ListDomainAssociations](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")  | List domains with an app                                         | List         |
| [ListJobs](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")                | List Jobs for a branch, part of an Amplify App                   | List         |
| [ListResourcesForWebACL](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")  | List the Resources associated with a WebACL                      | List         |
| [ListTagsForResource](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")     | List tags for an AWS Amplify Console resource                    | Read         |
| [ListWebHooks](../../../amplify/latest/userguide/welcome.md "../../../amplify/latest/userguide/welcome.md")            | List webhooks on an App                                          | List         |
