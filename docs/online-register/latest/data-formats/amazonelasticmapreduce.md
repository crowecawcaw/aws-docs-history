# Data retrieval APIs for Amazon Elastic MapReduce

Amazon Elastic MapReduce provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                     | Description                                                                                                                                                                                                         | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeCluster](../../../emr/latest/APIReference/API_DescribeCluster.md "../../../emr/latest/APIReference/API_DescribeCluster.md")                                                                        | Get details about a cluster, including status, hardware and software configuration, VPC settings, and so on                                                                                                         | Read         |
| [DescribeEditor](../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md "../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md")                                     | View information about a notebook, including status, user, role, tags, location, and more                                                                                                                           | Read         |
| [DescribeJobFlows](../../../emr/latest/APIReference/API_DescribeJobFlows.md "../../../emr/latest/APIReference/API_DescribeJobFlows.md")                                                                     | Describe details of clusters (job flows). This API is deprecated and will eventually be removed. We recommend you use ListClusters, DescribeCluster, ListSteps, ListInstanceGroups and ListBootstrapActions instead | Read         |
| [DescribeNotebookExecution](../../../emr/latest/ManagementGuide/emr-managed-notebooks-headless.md "../../../emr/latest/ManagementGuide/emr-managed-notebooks-headless.md")                                  | View information about a notebook execution                                                                                                                                                                         | Read         |
| [DescribePersistentAppUI](../../../emr/latest/ManagementGuide/emr-studio-debug.md "../../../emr/latest/ManagementGuide/emr-studio-debug.md")                                                                | Describe a persistent application history server                                                                                                                                                                    | Read         |
| [DescribeReleaseLabel](../../../emr/latest/APIReference/API_DescribeReleaseLabel.md "../../../emr/latest/APIReference/API_DescribeReleaseLabel.md")                                                         | View information about an EMR release, such as which applications are supported                                                                                                                                     | Read         |
| [DescribeRepository](../../../emr/latest/ManagementGuide/emr-managed-notebooks.md#emr-managed-notebooks-editor "../../../emr/latest/ManagementGuide/emr-managed-notebooks.md#emr-managed-notebooks-editor") | Describe an EMR notebook repository                                                                                                                                                                                 | Read         |
| [DescribeSecurityConfiguration](../../../emr/latest/APIReference/API_DescribeSecurityConfiguration.md "../../../emr/latest/APIReference/API_DescribeSecurityConfiguration.md")                              | Get details of a security configuration                                                                                                                                                                             | Read         |
| [DescribeStep](../../../emr/latest/APIReference/API_DescribeStep.md "../../../emr/latest/APIReference/API_DescribeStep.md")                                                                                 | Get details about a cluster step                                                                                                                                                                                    | Read         |
| [DescribeStudio](../../../emr/latest/ManagementGuide/emr-studio.md "../../../emr/latest/ManagementGuide/emr-studio.md")                                                                                     | View information about an EMR Studio                                                                                                                                                                                | Read         |
| [GetAutoTerminationPolicy](../../../emr/latest/APIReference/API_GetAutoTerminationPolicy.md "../../../emr/latest/APIReference/API_GetAutoTerminationPolicy.md")                                             | Retrieve the auto-termination policy associated with a cluster                                                                                                                                                      | Read         |
| [GetBlockPublicAccessConfiguration](../../../emr/latest/APIReference/API_GetBlockPublicAccessConfiguration.md "../../../emr/latest/APIReference/API_GetBlockPublicAccessConfiguration.md")                  | Retrieve the EMR block public access configuration for the AWS account in the Region                                                                                                                                | Read         |
| [GetManagedScalingPolicy](../../../emr/latest/APIReference/API_GetManagedScalingPolicy.md "../../../emr/latest/APIReference/API_GetManagedScalingPolicy.md")                                                | Retrieve the managed scaling policy associated with a cluster                                                                                                                                                       | Read         |
| [GetStudioSessionMapping](../../../emr/latest/ManagementGuide/emr-studio.md "../../../emr/latest/ManagementGuide/emr-studio.md")                                                                            | View information about an EMR Studio session mapping                                                                                                                                                                | Read         |
| [ListBootstrapActions](../../../emr/latest/APIReference/API_ListBootstrapActions.md "../../../emr/latest/APIReference/API_ListBootstrapActions.md")                                                         | Get details about the bootstrap actions associated with a cluster                                                                                                                                                   | Read         |
| [ListClusters](../../../emr/latest/APIReference/API_ListClusters.md "../../../emr/latest/APIReference/API_ListClusters.md")                                                                                 | Get the status of accessible clusters                                                                                                                                                                               | List         |
| [ListEditors](../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md "../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md")                                        | List summary information for accessible EMR notebooks                                                                                                                                                               | List         |
| [ListInstanceFleets](../../../emr/latest/APIReference/API_ListInstanceFleets.md "../../../emr/latest/APIReference/API_ListInstanceFleets.md")                                                               | Get details of instance fleets in a cluster                                                                                                                                                                         | Read         |
| [ListInstanceGroups](../../../emr/latest/APIReference/API_ListInstanceGroups.md "../../../emr/latest/APIReference/API_ListInstanceGroups.md")                                                               | Get details of instance groups in a cluster                                                                                                                                                                         | Read         |
| [ListInstances](../../../emr/latest/APIReference/API_ListInstances.md "../../../emr/latest/APIReference/API_ListInstances.md")                                                                              | Get details about the Amazon EC2 instances in a cluster                                                                                                                                                             | Read         |
| [ListNotebookExecutions](../../../emr/latest/ManagementGuide/emr-managed-notebooks-headless.md "../../../emr/latest/ManagementGuide/emr-managed-notebooks-headless.md")                                     | List summary information for notebook executions                                                                                                                                                                    | List         |
| [ListReleaseLabels](../../../emr/latest/APIReference/API_ListReleaseLabels.md "../../../emr/latest/APIReference/API_ListReleaseLabels.md")                                                                  | List and filter the available EMR releases in the current region                                                                                                                                                    | List         |
| [ListRepositories](../../../emr/latest/ManagementGuide/emr-managed-notebooks.md#emr-managed-notebooks-editor "../../../emr/latest/ManagementGuide/emr-managed-notebooks.md#emr-managed-notebooks-editor")   | List existing EMR notebook repositories                                                                                                                                                                             | List         |
| [ListSecurityConfigurations](../../../emr/latest/APIReference/API_ListSecurityConfigurations.md "../../../emr/latest/APIReference/API_ListSecurityConfigurations.md")                                       | List available security configurations in this account by name, along with creation dates and times                                                                                                                 | List         |
| [ListSteps](../../../emr/latest/APIReference/API_ListSteps.md "../../../emr/latest/APIReference/API_ListSteps.md")                                                                                          | List steps associated with a cluster                                                                                                                                                                                | Read         |
| [ListStudioSessionMappings](../../../emr/latest/ManagementGuide/emr-studio.md "../../../emr/latest/ManagementGuide/emr-studio.md")                                                                          | List summary information about EMR Studio session mappings                                                                                                                                                          | List         |
| [ListStudios](../../../emr/latest/ManagementGuide/emr-studio.md "../../../emr/latest/ManagementGuide/emr-studio.md")                                                                                        | List summary information about EMR Studios                                                                                                                                                                          | List         |
| [ListSupportedInstanceTypes](../../../emr/latest/APIReference/API_ListSupportedInstanceTypes.md "../../../emr/latest/APIReference/API_ListSupportedInstanceTypes.md")                                       | List the Amazon EC2 instance types that an Amazon EMR release supports                                                                                                                                              | List         |
| [ListWorkspaceAccessIdentities](../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md "../../../emr/latest/ManagementGuide/emr-managed-notebooks-working-with.md")                      | List identities that are granted access to a workspace                                                                                                                                                              | List         |
| [ViewEventsFromAllClustersInConsole](../../../service-authorization/latest/reference/list_amazonelasticmapreduce.md "../../../service-authorization/latest/reference/list_amazonelasticmapreduce.md")       | Use the EMR console to view events from all clusters                                                                                                                                                                | List         |
