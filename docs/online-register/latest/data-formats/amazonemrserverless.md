

# Data retrieval APIs for Amazon EMR Serverless
<a name="amazonemrserverless"></a>

Amazon EMR Serverless provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="emr-serverless-GetApplication"></a>[GetApplication](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetApplication.html) | Get application | Read | 
| <a name="emr-serverless-GetDashboardForJobRun"></a>[GetDashboardForJobRun](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetDashboardForJobRun.html) | Get job run dashboard | Read | 
| <a name="emr-serverless-GetJobRun"></a>[GetJobRun](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetJobRun.html) | Get a job run | Read | 
| <a name="emr-serverless-GetResourceDashboard"></a>[GetResourceDashboard](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetResourceDashboard.html) | Get the resource dashboard | Read | 
| <a name="emr-serverless-GetSession"></a>[GetSession](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetSession.html) | Get details about a session | Read | 
| <a name="emr-serverless-GetSessionEndpoint"></a>[GetSessionEndpoint](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_GetSessionEndpoint.html) | Get the endpoint URL and authentication token for connecting to a session | Read | 
| <a name="emr-serverless-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_ListApplications.html) | List applications | List | 
| <a name="emr-serverless-ListJobRunAttempts"></a>[ListJobRunAttempts](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_ListJobRunAttempts.html) | List job run attempts associated with a job run | List | 
| <a name="emr-serverless-ListJobRuns"></a>[ListJobRuns](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_ListJobRuns.html) | List job runs associated with an application | List | 
| <a name="emr-serverless-ListSessions"></a>[ListSessions](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_ListSessions.html) | List sessions associated with an application | List | 
| <a name="emr-serverless-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/emr-serverless/latest/APIReference/API_ListTagsForResource.html) | List tags for the specified resource | Read |
