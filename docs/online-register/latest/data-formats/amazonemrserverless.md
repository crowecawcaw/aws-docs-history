# Data retrieval APIs for Amazon EMR Serverless

Amazon EMR Serverless provides the following APIs for data retrieval.

| Actions                                                                                                                                                                      | Description                                     | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ------------ |
| [GetApplication](../../../emr-serverless/latest/APIReference/API_GetApplication.md "../../../emr-serverless/latest/APIReference/API_GetApplication.md")                      | Get application                                 | Read         |
| [GetDashboardForJobRun](../../../emr-serverless/latest/APIReference/API_GetDashboardForJobRun.md "../../../emr-serverless/latest/APIReference/API_GetDashboardForJobRun.md") | Get job run dashboard                           | Read         |
| [GetJobRun](../../../emr-serverless/latest/APIReference/API_GetJobRun.md "../../../emr-serverless/latest/APIReference/API_GetJobRun.md")                                     | Get a job run                                   | Read         |
| [ListApplications](../../../emr-serverless/latest/APIReference/API_ListApplications.md "../../../emr-serverless/latest/APIReference/API_ListApplications.md")                | List applications                               | List         |
| [ListJobRunAttempts](../../../emr-serverless/latest/APIReference/API_ListJobRunAttempts.md "../../../emr-serverless/latest/APIReference/API_ListJobRunAttempts.md")          | List job run attempts associated with a job run | List         |
| [ListJobRuns](../../../emr-serverless/latest/APIReference/API_ListJobRuns.md "../../../emr-serverless/latest/APIReference/API_ListJobRuns.md")                               | List job runs associated with an application    | List         |
| [ListTagsForResource](../../../emr-serverless/latest/APIReference/API_ListTagsForResource.md "../../../emr-serverless/latest/APIReference/API_ListTagsForResource.md")       | List tags for the specified resource            | Read         |
