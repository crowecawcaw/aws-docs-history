# Data retrieval APIs for AWS Resource Groups

AWS Resource Groups provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                       | Description                                                                | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------ |
| [GetAccountSettings](../../../ARG/latest/APIReference/API_GetAccountSettings.md "../../../ARG/latest/APIReference/API_GetAccountSettings.md")                                                                                                 | Get the current status of optional features in Resource Groups             | Read         |
| [GetGroup](../../../ARG/latest/APIReference/API_GetGroup.md "../../../ARG/latest/APIReference/API_GetGroup.md")                                                                                                                               | Get information of a specified resource group                              | Read         |
| [GetGroupConfiguration](../../../ARG/latest/APIReference/API_GetGroupConfiguration.md "../../../ARG/latest/APIReference/API_GetGroupConfiguration.md")                                                                                        | Get the service configuration associated with the specified resource group | Read         |
| [GetGroupPolicy](../../../license-manager/latest/userguide/management-role.md#service-linked-role-permissions-management-role "../../../license-manager/latest/userguide/management-role.md#service-linked-role-permissions-management-role") | Get a resource-based policy for the specified group                        | Read         |
| [GetGroupQuery](../../../ARG/latest/APIReference/API_GetGroupQuery.md "../../../ARG/latest/APIReference/API_GetGroupQuery.md")                                                                                                                | Get the query associated with a specified resource group                   | Read         |
| [GetTagSyncTask](../../../ARG/latest/APIReference/API_GetTagSyncTask.md "../../../ARG/latest/APIReference/API_GetTagSyncTask.md")                                                                                                             | Get information of a specified tag-sync task                               | Read         |
| [GetTags](../../../ARG/latest/APIReference/API_GetTags.md "../../../ARG/latest/APIReference/API_GetTags.md")                                                                                                                                  | Get the tags associated with a specified resource group                    | Read         |
| [ListGroupResources](../../../ARG/latest/APIReference/API_ListGroupResources.md "../../../ARG/latest/APIReference/API_ListGroupResources.md")                                                                                                 | List the resources that are members of a specified resource group          | List         |
| [ListGroupingStatuses](../../../ARG/latest/APIReference/API_ListGroupingStatuses.md "../../../ARG/latest/APIReference/API_ListGroupingStatuses.md")                                                                                           | List grouping statuses for a specified application group                   | List         |
| [ListGroups](../../../ARG/latest/APIReference/API_ListGroups.md "../../../ARG/latest/APIReference/API_ListGroups.md")                                                                                                                         | List all resource groups in your account                                   | List         |
| [ListResourceTypes](../../../ARG/latest/userguide/gettingstarted-query.md "../../../ARG/latest/userguide/gettingstarted-query.md")                                                                                                            | List supported resource types                                              | List         |
| [ListTagSyncTasks](../../../ARG/latest/APIReference/API_ListTagSyncTasks.md "../../../ARG/latest/APIReference/API_ListTagSyncTasks.md")                                                                                                       | List all tag-sync tasks in your account                                    | List         |
| [SearchResources](../../../ARG/latest/APIReference/API_SearchResources.md "../../../ARG/latest/APIReference/API_SearchResources.md")                                                                                                          | Search for AWS resources matching the given query                          | List         |
