| Actions                                                                                                                                                                                                                                                       | Description                                                                                                         | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------ |

| [DescribeResource](../../../lake-formation/latest/APIReference/API_DescribeResource.md "../../../lake-formation/latest/APIReference/API_DescribeResource.md")                                                                                                 | Describe a registered location                                                                                      | Read         |
| [DescribeTransaction](../../../lake-formation/latest/APIReference/API_DescribeTransaction.md "../../../lake-formation/latest/APIReference/API_DescribeTransaction.md")                                                                                        | Get status of the given transaction                                                                                 | Read         |
| [GetDataCellsFilter](../../../lake-formation/latest/APIReference/API_GetDataCellsFilter.md "../../../lake-formation/latest/APIReference/API_GetDataCellsFilter.md")                                                                                           | Retrieve a Lake Formation data cell filter                                                                          | Read         |
| [GetDataLakePrincipal](../../../lake-formation/latest/APIReference/API_GetDataLakePrincipal.md "../../../lake-formation/latest/APIReference/API_GetDataLakePrincipal.md")                                                                                     | Retrieve the identity of the invoking principal                                                                     | Read         |
| [GetDataLakeSettings](../../../lake-formation/latest/APIReference/API_GetDataLakeSettings.md "../../../lake-formation/latest/APIReference/API_GetDataLakeSettings.md")                                                                                        | Retrieve data lake settings such as the list of data lake administrators and database and table default permissions | Read         |

| [GetLFTag](../../../lake-formation/latest/APIReference/API_GetLFTag.md "../../../lake-formation/latest/APIReference/API_GetLFTag.md")                                                                                                                         | Retrieve a Lake Formation tag                                                                                       | Read         |
| [GetLFTagExpression](../../../lake-formation/latest/APIReference/API_GetLFTagExpression.md "../../../lake-formation/latest/APIReference/API_GetLFTagExpression.md")                                                                                           | Retrieve a Lake Formation tag expression                                                                            | Read         |
| [GetQueryState](../../../lake-formation/latest/APIReference/API_GetQueryState.md "../../../lake-formation/latest/APIReference/API_GetQueryState.md")                                                                                                          | Retrieve the state of the given query                                                                               | Read         |

| [ListDataCellsFilter](../../../lake-formation/latest/APIReference/API_ListDataCellsFilter.md "../../../lake-formation/latest/APIReference/API_ListDataCellsFilter.md")                                                                                        | List cell filters                                                                                                   | List         |
