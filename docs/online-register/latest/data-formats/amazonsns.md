# Data retrieval APIs for Amazon SNS

Amazon SNS provides the following APIs for data retrieval.

| Actions                                                                                                                                                                     | Description                                                                                                                   | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [CheckIfPhoneNumberIsOptedOut](../../../sns/latest/api/API_CheckIfPhoneNumberIsOptedOut.md "../../../sns/latest/api/API_CheckIfPhoneNumberIsOptedOut.md")                   | Accept a phone number and indicate whether the phone holder has opted out of receiving SMS messages from your account         | Read         |
| [GetDataProtectionPolicy](../../../sns/latest/api/API_GetDataProtectionPolicy.md "../../../sns/latest/api/API_GetDataProtectionPolicy.md")                                  | Return the data protection policy of the topic                                                                                | Read         |
| [GetEndpointAttributes](../../../sns/latest/api/API_GetEndpointAttributes.md "../../../sns/latest/api/API_GetEndpointAttributes.md")                                        | Retrieve the endpoint attributes for a device on one of the supported push notification services, such as GCM and APNS        | Read         |
| [GetPlatformApplicationAttributes](../../../sns/latest/api/API_GetPlatformApplicationAttributes.md "../../../sns/latest/api/API_GetPlatformApplicationAttributes.md")       | Retrieve the attributes of the platform application object for the supported push notification services, such as APNS and GCM | Read         |
| [GetSMSAttributes](../../../sns/latest/api/API_GetSMSAttributes.md "../../../sns/latest/api/API_GetSMSAttributes.md")                                                       | Return the settings for sending SMS messages from your account                                                                | Read         |
| [GetSMSSandboxAccountStatus](../../../sns/latest/api/API_GetSMSSandboxAccountStatus.md "../../../sns/latest/api/API_GetSMSSandboxAccountStatus.md")                         | Retrieve the sandbox status for the calling account in the target region                                                      | Read         |
| [GetSubscriptionAttributes](../../../sns/latest/api/API_GetSubscriptionAttributes.md "../../../sns/latest/api/API_GetSubscriptionAttributes.md")                            | Return all of the properties of a subscription                                                                                | Read         |
| [GetTopicAttributes](../../../sns/latest/api/API_GetTopicAttributes.md "../../../sns/latest/api/API_GetTopicAttributes.md")                                                 | Return all of the properties of a topic                                                                                       | Read         |
| [ListEndpointsByPlatformApplication](../../../sns/latest/api/API_ListEndpointsByPlatformApplication.md "../../../sns/latest/api/API_ListEndpointsByPlatformApplication.md") | List the endpoints and endpoint attributes for devices in a supported push notification service, such as GCM and APNS         | List         |
| [ListOriginationNumbers](../../../sns/latest/api/API_ListOriginationNumbers.md "../../../sns/latest/api/API_ListOriginationNumbers.md")                                     | List all origination numbers, and their metadata                                                                              | List         |
| [ListPhoneNumbersOptedOut](../../../sns/latest/api/API_ListPhoneNumbersOptedOut.md "../../../sns/latest/api/API_ListPhoneNumbersOptedOut.md")                               | Return a list of phone numbers that are opted out, meaning you cannot send SMS messages to them                               | Read         |
| [ListPlatformApplications](../../../sns/latest/api/API_ListPlatformApplications.md "../../../sns/latest/api/API_ListPlatformApplications.md")                               | List the platform application objects for the supported push notification services, such as APNS and GCM                      | List         |
| [ListSMSSandboxPhoneNumbers](../../../sns/latest/api/API_ListSMSSandboxPhoneNumbers.md "../../../sns/latest/api/API_ListSMSSandboxPhoneNumbers.md")                         | List the calling account's current pending and verified destination phone numbers                                             | List         |
| [ListSubscriptions](../../../sns/latest/api/API_ListSubscriptions.md "../../../sns/latest/api/API_ListSubscriptions.md")                                                    | Return a list of the requester's subscriptions                                                                                | List         |
| [ListSubscriptionsByTopic](../../../sns/latest/api/API_ListSubscriptionsByTopic.md "../../../sns/latest/api/API_ListSubscriptionsByTopic.md")                               | Return a list of the subscriptions to a specific topic                                                                        | List         |
| [ListTagsForResource](../../../sns/latest/api/API_ListTagsForResource.md "../../../sns/latest/api/API_ListTagsForResource.md")                                              | List all tags added to the specified Amazon SNS topic                                                                         | Read         |
| [ListTopics](../../../sns/latest/api/API_ListTopics.md "../../../sns/latest/api/API_ListTopics.md")                                                                         | Return a list of the requester's topics                                                                                       | List         |
