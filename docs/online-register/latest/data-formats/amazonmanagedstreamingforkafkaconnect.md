# Data retrieval APIs for Amazon Managed Streaming for Kafka Connect

Amazon Managed Streaming for Kafka Connect provides the following APIs for data retrieval.

| Actions                                                                                                                                                    | Description                                                | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------ |
| [DescribeConnector](../../../MSKC/latest/mskc/API_DescribeConnector.md "../../../MSKC/latest/mskc/API_DescribeConnector.md")                               | Describe an MSK Connect connector                          | Read         |
| [DescribeConnectorOperation](../../../MSKC/latest/mskc/API_DescribeConnectorOperation.md "../../../MSKC/latest/mskc/API_DescribeConnectorOperation.md")    | Describe a MSK Connect connector operation                 | Read         |
| [DescribeCustomPlugin](../../../MSKC/latest/mskc/API_DescribeCustomPlugin.md "../../../MSKC/latest/mskc/API_DescribeCustomPlugin.md")                      | Describe an MSK Connect custom plugin                      | Read         |
| [DescribeWorkerConfiguration](../../../MSKC/latest/mskc/API_DescribeWorkerConfiguration.md "../../../MSKC/latest/mskc/API_DescribeWorkerConfiguration.md") | Describe an MSK Connect worker configuration               | Read         |
| [ListConnectorOperations](../../../MSKC/latest/mskc/API_ListConnectorOperations.md "../../../MSKC/latest/mskc/API_ListConnectorOperations.md")             | List all operations of a given MSK Connect connector       | Read         |
| [ListConnectors](../../../MSKC/latest/mskc/API_ListConnectors.md "../../../MSKC/latest/mskc/API_ListConnectors.md")                                        | List all MSK Connect connectors in this account            | Read         |
| [ListCustomPlugins](../../../MSKC/latest/mskc/API_ListCustomPlugins.md "../../../MSKC/latest/mskc/API_ListCustomPlugins.md")                               | List all MSK Connect custom plugins in this account        | Read         |
| [ListTagsForResource](../../../MSKC/latest/mskc/API_ListTagsForResource.md "../../../MSKC/latest/mskc/API_ListTagsForResource.md")                         | List tags of an MSK Connect resource                       | Read         |
| [ListWorkerConfigurations](../../../MSKC/latest/mskc/API_ListWorkerConfigurations.md "../../../MSKC/latest/mskc/API_ListWorkerConfigurations.md")          | List all MSK Connect worker configurations in this account | Read         |
