# Data retrieval APIs for AWS CodePipeline

AWS CodePipeline provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                   | Description                                                                                                                                                        | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [GetActionType](../../../codepipeline/latest/APIReference/API_GetActionType.md "../../../codepipeline/latest/APIReference/API_GetActionType.md")                                                          | View information about an action type                                                                                                                              | Read         |
| [GetJobDetails](../../../codepipeline/latest/APIReference/API_GetJobDetails.md "../../../codepipeline/latest/APIReference/API_GetJobDetails.md")                                                          | View information about a job (custom actions only)                                                                                                                 | Read         |
| [GetPipeline](../../../codepipeline/latest/APIReference/API_GetPipeline.md "../../../codepipeline/latest/APIReference/API_GetPipeline.md")                                                                | Retrieve information about a pipeline structure                                                                                                                    | Read         |
| [GetPipelineExecution](../../../codepipeline/latest/APIReference/API_GetPipelineExecution.md "../../../codepipeline/latest/APIReference/API_GetPipelineExecution.md")                                     | View information about an execution of a pipeline, including details about artifacts, the pipeline execution ID, and the name, version, and status of the pipeline | Read         |
| [GetPipelineState](../../../codepipeline/latest/APIReference/API_GetPipelineState.md "../../../codepipeline/latest/APIReference/API_GetPipelineState.md")                                                 | View information about the current state of the stages and actions of a pipeline                                                                                   | Read         |
| [GetThirdPartyJobDetails](../../../codepipeline/latest/APIReference/API_GetThirdPartyJobDetails.md "../../../codepipeline/latest/APIReference/API_GetThirdPartyJobDetails.md")                            | View the details of a job for a third-party action (partner actions only)                                                                                          | Read         |
| [ListActionExecutions](../../../codepipeline/latest/APIReference/API_ListActionExecutions.md "../../../codepipeline/latest/APIReference/API_ListActionExecutions.md")                                     | List the action executions that have occurred in a pipeline                                                                                                        | Read         |
| [ListActionTypes](../../../codepipeline/latest/APIReference/API_ListActionTypes.md "../../../codepipeline/latest/APIReference/API_ListActionTypes.md")                                                    | List a summary of all the action types available for pipelines in your account                                                                                     | Read         |
| [ListDeployActionExecutionTargets](../../../codepipeline/latest/APIReference/API_ListDeployActionExecutionTargets.md "../../../codepipeline/latest/APIReference/API_ListDeployActionExecutionTargets.md") | List the deployment details for deploy action executions that have occurred in a pipeline                                                                          | Read         |
| [ListPipelineExecutions](../../../codepipeline/latest/APIReference/API_ListPipelineExecutions.md "../../../codepipeline/latest/APIReference/API_ListPipelineExecutions.md")                               | List a summary of the most recent executions for a pipeline                                                                                                        | List         |
| [ListPipelines](../../../codepipeline/latest/APIReference/API_ListPipelines.md "../../../codepipeline/latest/APIReference/API_ListPipelines.md")                                                          | List a summary of all the pipelines associated with your AWS account                                                                                               | List         |
| [ListRuleExecutions](../../../codepipeline/latest/APIReference/API_ListRuleExecutions.md "../../../codepipeline/latest/APIReference/API_ListRuleExecutions.md")                                           | List the rule executions that have occurred in a pipeline                                                                                                          | Read         |
| [ListRuleTypes](../../../codepipeline/latest/APIReference/API_ListRuleTypes.md "../../../codepipeline/latest/APIReference/API_ListRuleTypes.md")                                                          | List a summary of all the rule types available for pipelines in your account                                                                                       | Read         |
| [ListTagsForResource](../../../codepipeline/latest/APIReference/API_ListTagsForResource.md "../../../codepipeline/latest/APIReference/API_ListTagsForResource.md")                                        | List tags for a CodePipeline resource                                                                                                                              | Read         |
| [ListWebhooks](../../../codepipeline/latest/APIReference/API_ListWebhooks.md "../../../codepipeline/latest/APIReference/API_ListWebhooks.md")                                                             | List all of the webhooks associated with your AWS account                                                                                                          | List         |
