

# Data retrieval APIs for AWS CodePipeline
<a name="awscodepipeline"></a>

AWS CodePipeline provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="codepipeline-GetActionType"></a>[GetActionType](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetActionType.html) | View information about an action type | Read | 
| <a name="codepipeline-GetJobDetails"></a>[GetJobDetails](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetJobDetails.html) | View information about a job (custom actions only) | Read | 
| <a name="codepipeline-GetPipeline"></a>[GetPipeline](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetPipeline.html) | Retrieve information about a pipeline structure | Read | 
| <a name="codepipeline-GetPipelineExecution"></a>[GetPipelineExecution](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetPipelineExecution.html) | View information about an execution of a pipeline, including details about artifacts, the pipeline execution ID, and the name, version, and status of the pipeline | Read | 
| <a name="codepipeline-GetPipelineState"></a>[GetPipelineState](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetPipelineState.html) | View information about the current state of the stages and actions of a pipeline | Read | 
| <a name="codepipeline-GetThirdPartyJobDetails"></a>[GetThirdPartyJobDetails](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_GetThirdPartyJobDetails.html) | View the details of a job for a third-party action (partner actions only) | Read | 
| <a name="codepipeline-ListActionExecutions"></a>[ListActionExecutions](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListActionExecutions.html) | List the action executions that have occurred in a pipeline | Read | 
| <a name="codepipeline-ListActionTypes"></a>[ListActionTypes](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListActionTypes.html) | List a summary of all the action types available for pipelines in your account | Read | 
| <a name="codepipeline-ListDeployActionExecutionTargets"></a>[ListDeployActionExecutionTargets](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListDeployActionExecutionTargets.html) | List the deployment details for deploy action executions that have occurred in a pipeline | Read | 
| <a name="codepipeline-ListPipelineExecutions"></a>[ListPipelineExecutions](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListPipelineExecutions.html) | List a summary of the most recent executions for a pipeline | List | 
| <a name="codepipeline-ListPipelines"></a>[ListPipelines](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListPipelines.html) | List a summary of all the pipelines associated with your AWS account | List | 
| <a name="codepipeline-ListRuleExecutions"></a>[ListRuleExecutions](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListRuleExecutions.html) | List the rule executions that have occurred in a pipeline | Read | 
| <a name="codepipeline-ListRuleTypes"></a>[ListRuleTypes](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListRuleTypes.html) | List a summary of all the rule types available for pipelines in your account | Read | 
| <a name="codepipeline-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListTagsForResource.html) | List tags for a CodePipeline resource | Read | 
| <a name="codepipeline-ListWebhooks"></a>[ListWebhooks](https://docs.aws.amazon.com/codepipeline/latest/APIReference/API_ListWebhooks.html) | List all of the webhooks associated with your AWS account | List |
