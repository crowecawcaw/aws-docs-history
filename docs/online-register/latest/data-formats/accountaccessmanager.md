# Data retrieval APIs for Account access manager

Account access manager provides the following APIs for data retrieval.

| Actions                                                                                                                                                                            | Description                                                    | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------ |
| [GetApplication](../../../service-authorization/latest/reference/list_accountaccessmanager.md "../../../service-authorization/latest/reference/list_accountaccessmanager.md")      | Describe an account access manager instance                    | Read         |
| [GetEntitlement](../../../service-authorization/latest/reference/list_accountaccessmanager.md "../../../service-authorization/latest/reference/list_accountaccessmanager.md")      | Get entitlement details for an account access manager instance | Read         |
| [ListApplications](../../../service-authorization/latest/reference/list_accountaccessmanager.md "../../../service-authorization/latest/reference/list_accountaccessmanager.md")    | List account access manager instances                          | List         |
| [ListEntitlements](../../../service-authorization/latest/reference/list_accountaccessmanager.md "../../../service-authorization/latest/reference/list_accountaccessmanager.md")    | List entitlements for an account access manager instance       | List         |
| [ListTagsForResource](../../../service-authorization/latest/reference/list_accountaccessmanager.md "../../../service-authorization/latest/reference/list_accountaccessmanager.md") | List tags for an account access manager resource               | Read         |
