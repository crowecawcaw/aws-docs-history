

# Data retrieval APIs for Account access manager
<a name="accountaccessmanager"></a>

Account access manager provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="account-access-GetApplication"></a>[GetApplication](https://docs.aws.amazon.com/service-authorization/latest/reference/list_account-access.html) | Describe an account access manager instance | Read | 
| <a name="account-access-GetEntitlement"></a>[GetEntitlement](https://docs.aws.amazon.com/service-authorization/latest/reference/list_account-access.html) | Get entitlement details for an account access manager instance | Read | 
| <a name="account-access-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/service-authorization/latest/reference/list_account-access.html) | List account access manager instances | List | 
| <a name="account-access-ListEntitlements"></a>[ListEntitlements](https://docs.aws.amazon.com/service-authorization/latest/reference/list_account-access.html) | List entitlements for an account access manager instance | List | 
| <a name="account-access-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/service-authorization/latest/reference/list_account-access.html) | List tags for an account access manager resource | Read |
