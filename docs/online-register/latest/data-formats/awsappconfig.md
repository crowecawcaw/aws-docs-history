| [GetApplication](../../../appconfig/2019-10-09/APIReference/API_GetApplication.md "../../../appconfig/2019-10-09/APIReference/API_GetApplication.md")                                                     | View details about an application                                  | Read         |
| [GetConfiguration](../../../appconfig/2019-10-09/APIReference/API_GetConfiguration.md "../../../appconfig/2019-10-09/APIReference/API_GetConfiguration.md")                                               | View details about a configuration                                 | Read         |
| [GetConfigurationProfile](../../../appconfig/2019-10-09/APIReference/API_GetConfigurationProfile.md "../../../appconfig/2019-10-09/APIReference/API_GetConfigurationProfile.md")                          | View details about a configuration profile                         | Read         |
| [GetDeployment](../../../appconfig/2019-10-09/APIReference/API_GetDeployment.md "../../../appconfig/2019-10-09/APIReference/API_GetDeployment.md")                                                        | View details about a deployment                                    | Read         |
| [GetDeploymentStrategy](../../../appconfig/2019-10-09/APIReference/API_GetDeploymentStrategy.md "../../../appconfig/2019-10-09/APIReference/API_GetDeploymentStrategy.md")                                | View details about a deployment strategy                           | Read         |
| [GetEnvironment](../../../appconfig/2019-10-09/APIReference/API_GetEnvironment.md "../../../appconfig/2019-10-09/APIReference/API_GetEnvironment.md")                                                     | View details about an environment                                  | Read         |
| [GetExtension](../../../appconfig/2019-10-09/APIReference/API_GetExtension.md "../../../appconfig/2019-10-09/APIReference/API_GetExtension.md")                                                           | View details about an extension                                    | Read         |

| [GetHostedConfigurationVersion](../../../appconfig/2019-10-09/APIReference/API_GetHostedConfigurationVersion.md "../../../appconfig/2019-10-09/APIReference/API_GetHostedConfigurationVersion.md")        | View details about a hosted configuration version                  | Read         |
| [GetLatestConfiguration](../../../appconfig/2019-10-09/APIReference/API_appconfigdata_GetLatestConfiguration.md "../../../appconfig/2019-10-09/APIReference/API_appconfigdata_GetLatestConfiguration.md") | Retrieve a deployed configuration                                  | Read         |
| [ListApplications](../../../appconfig/2019-10-09/APIReference/API_ListApplications.md "../../../appconfig/2019-10-09/APIReference/API_ListApplications.md")                                               | List the applications in your account                              | List         |
