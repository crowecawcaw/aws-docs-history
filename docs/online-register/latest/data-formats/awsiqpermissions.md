# Data retrieval APIs for AWS IQ Permissions

AWS IQ Permissions provides the following APIs for data retrieval.

| Actions                                                                           | Description              | Access level |
| --------------------------------------------------------------------------------- | ------------------------ | ------------ |
| [GetPermissionRequest](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")   | Get a permission request | Read         |
| [ListPermissionRequests](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/") | List permission requests | Read         |
