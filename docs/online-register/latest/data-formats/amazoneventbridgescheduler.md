# Data retrieval APIs for Amazon EventBridge Scheduler

Amazon EventBridge Scheduler provides the following APIs for data retrieval.

| Actions                                                                                                                                                      | Description                                                           | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- | ------------ |
| [GetSchedule](../../../scheduler/latest/APIReference/API_GetSchedule.md "../../../scheduler/latest/APIReference/API_GetSchedule.md")                         | View details about an Amazon EventBridge Scheduler schedule           | Read         |
| [GetScheduleGroup](../../../scheduler/latest/APIReference/API_GetScheduleGroup.md "../../../scheduler/latest/APIReference/API_GetScheduleGroup.md")          | View details about an Amazon EventBridge Scheduler schedule group     | Read         |
| [ListScheduleGroups](../../../scheduler/latest/APIReference/API_ListScheduleGroups.md "../../../scheduler/latest/APIReference/API_ListScheduleGroups.md")    | List the Amazon EventBridge Scheduler schedule groups in your account | List         |
| [ListSchedules](../../../scheduler/latest/APIReference/API_ListSchedules.md "../../../scheduler/latest/APIReference/API_ListSchedules.md")                   | List the Amazon EventBridge Scheduler schedules in your account       | List         |
| [ListTagsForResource](../../../scheduler/latest/APIReference/API_ListTagsForResource.md "../../../scheduler/latest/APIReference/API_ListTagsForResource.md") | Lists tag for an Amazon EventBridge Scheduler resource                | Read         |
