# Data retrieval APIs for Amazon Elastic Block Store

Amazon Elastic Block Store provides the following APIs for data retrieval.

| Actions                                                                                                                                       | Description                                                                                                                   | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetSnapshotBlock](../../../ebs/latest/APIReference/API_GetSnapshotBlock.md "../../../ebs/latest/APIReference/API_GetSnapshotBlock.md")       | Return the data of a block in an Amazon Elastic Block Store (EBS) snapshot                                                    | Read         |
| [ListChangedBlocks](../../../ebs/latest/APIReference/API_ListChangedBlocks.md "../../../ebs/latest/APIReference/API_ListChangedBlocks.md")    | List the blocks that are different between two Amazon Elastic Block Store (EBS) snapshots of the same volume/snapshot lineage | Read         |
| [ListSnapshotBlocks](../../../ebs/latest/APIReference/API_ListSnapshotBlocks.md "../../../ebs/latest/APIReference/API_ListSnapshotBlocks.md") | List the blocks in an Amazon Elastic Block Store (EBS) snapshot                                                               | Read         |
