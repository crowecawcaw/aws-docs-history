# Data retrieval APIs for AWS User Subscriptions

AWS User Subscriptions provides the following APIs for data retrieval.

| Actions                                                                                                                                                         | Description                                       | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ------------ |
| [GetAutoTopUpRule](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")       | Get a User subscription auto-top-up rule          | Read         |
| [GetEffectiveUsageLimit](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md") | Get a User subscription effective usage limit     | Read         |
| [GetUsageLimitHistory](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")   | Get User subscription usage limit history         | Read         |
| [ListApplicationClaims](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")  | List all User subscription Claims for Application | List         |
| [ListClaimAddOns](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")        | List all User subscription Claim add-ons          | List         |
| [ListClaims](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")             | List all User subscription Claims                 | List         |
| [ListEntitlements](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")       | List all User subscription entitlements           | List         |
| [ListUsageLimits](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")        | List all User subscription usage limits           | List         |
| [ListUserSubscriptions](../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md "../../../amazonq/latest/qdeveloper-ug/security_iam_permissions.md")  | List all User subscriptions                       | List         |
