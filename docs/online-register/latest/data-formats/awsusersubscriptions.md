

# Data retrieval APIs for AWS User Subscriptions
<a name="awsusersubscriptions"></a>

AWS User Subscriptions provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="user-subscriptions-GetAutoTopUpRule"></a>[GetAutoTopUpRule](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | Get a User subscription auto-top-up rule | Read | 
| <a name="user-subscriptions-GetEffectiveUsageLimit"></a>[GetEffectiveUsageLimit](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | Get a User subscription effective usage limit | Read | 
| <a name="user-subscriptions-GetUsageLimitHistory"></a>[GetUsageLimitHistory](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | Get User subscription usage limit history | Read | 
| <a name="user-subscriptions-ListApplicationClaims"></a>[ListApplicationClaims](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscription Claims for Application | List | 
| <a name="user-subscriptions-ListClaimAddOns"></a>[ListClaimAddOns](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscription Claim add-ons | List | 
| <a name="user-subscriptions-ListClaims"></a>[ListClaims](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscription Claims | List | 
| <a name="user-subscriptions-ListEntitlements"></a>[ListEntitlements](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscription entitlements | List | 
| <a name="user-subscriptions-ListUsageLimits"></a>[ListUsageLimits](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscription usage limits | List | 
| <a name="user-subscriptions-ListUserSubscriptions"></a>[ListUserSubscriptions](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_permissions.html) | List all User subscriptions | List |
