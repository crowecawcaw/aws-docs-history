# Data retrieval APIs for AWS Elemental Inference

AWS Elemental Inference provides the following APIs for data retrieval.

| Actions                                                                                                                                                                          | Description                                  | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- | ------------ |
| [GetFeed](../../../elemental-inference/latest/APIReference/API_GetFeed.md "../../../elemental-inference/latest/APIReference/API_GetFeed.md")                                     | Get feed details                             | Read         |
| [GetMetadata](../../../elemental-inference/latest/APIReference/API_GetMetadata.md "../../../elemental-inference/latest/APIReference/API_GetMetadata.md")                         | Retrieve metadata for a specific feed output | Read         |
| [ListFeeds](../../../elemental-inference/latest/APIReference/API_ListFeeds.md "../../../elemental-inference/latest/APIReference/API_ListFeeds.md")                               | List feeds in the account                    | List         |
| [ListTagsForResource](../../../elemental-inference/latest/APIReference/API_ListTagsForResource.md "../../../elemental-inference/latest/APIReference/API_ListTagsForResource.md") | List tags on a resource                      | Read         |
