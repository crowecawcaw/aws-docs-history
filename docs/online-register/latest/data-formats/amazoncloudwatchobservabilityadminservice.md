# Data retrieval APIs for Amazon CloudWatch Observability Admin Service

Amazon CloudWatch Observability Admin Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                            | Description                                                                                  | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------ |
| [GetCentralizationRuleForOrganization](../../../cloudwatch/latest/observabilityadmin/API_GetCentralizationRuleForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_GetCentralizationRuleForOrganization.md")                      | Retrieve the specified organization centralization rule for the organization                 | Read         |
| [GetTelemetryEnrichmentStatus](../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEnrichmentStatus.md "../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEnrichmentStatus.md")                                              | Retrieve the status of the Resource tags for telemetry feature for the account               | Read         |
| [GetTelemetryEvaluationStatus](../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatus.md "../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatus.md")                                              | Retrieve the Telemetry Config feature status for the account                                 | Read         |
| [GetTelemetryEvaluationStatusForOrganization](../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatusForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatusForOrganization.md") | Retrieve the Telemetry Config feature status for the organization                            | Read         |
| [GetTelemetryRule](../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryRule.md "../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryRule.md")                                                                                  | Retrieve the specified telemetry rule for the account                                        | Read         |
| [GetTelemetryRuleForOrganization](../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryRuleForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_GetTelemetryRuleForOrganization.md")                                     | Retrieve the specified organization telemetry rule for the organization                      | Read         |
| [ListCentralizationRulesForOrganization](../../../cloudwatch/latest/observabilityadmin/API_ListCentralizationRulesForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_ListCentralizationRulesForOrganization.md")                | List the centralization rules for the organization                                           | List         |
| [ListResourceTelemetry](../../../cloudwatch/latest/observabilityadmin/API_ListResourceTelemetry.md "../../../cloudwatch/latest/observabilityadmin/API_ListResourceTelemetry.md")                                                                   | Retrieve telemetry configurations for resources associated with the account                  | Read         |
| [ListResourceTelemetryForOrganization](../../../cloudwatch/latest/observabilityadmin/API_ListResourceTelemetryForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_ListResourceTelemetryForOrganization.md")                      | Retrieve telemetry configurations for resources associated with accounts in the organization | Read         |
| [ListTagsForResource](../../../cloudwatch/latest/observabilityadmin/API_ListTagsForResource.md "../../../cloudwatch/latest/observabilityadmin/API_ListTagsForResource.md")                                                                         | List the tags for the specified resource                                                     | List         |
| [ListTelemetryRules](../../../cloudwatch/latest/observabilityadmin/API_ListTelemetryRules.md "../../../cloudwatch/latest/observabilityadmin/API_ListTelemetryRules.md")                                                                            | List the telemetry rules for the account                                                     | List         |
| [ListTelemetryRulesForOrganization](../../../cloudwatch/latest/observabilityadmin/API_ListTelemetryRulesForOrganization.md "../../../cloudwatch/latest/observabilityadmin/API_ListTelemetryRulesForOrganization.md")                               | List the telemetry rules for the organization                                                | List         |
