

# Data retrieval APIs for Amazon CloudWatch Observability Admin Service
<a name="amazoncloudwatchobservabilityadminservice"></a>

Amazon CloudWatch Observability Admin Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="observabilityadmin-GetCentralizationRuleForOrganization"></a>[GetCentralizationRuleForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetCentralizationRuleForOrganization.html) | Retrieve the specified organization centralization rule for the organization | Read | 
| <a name="observabilityadmin-GetS3TableIntegration"></a>[GetS3TableIntegration](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetS3TableIntegration.html) | Retrieve the specified s3 table integration for the account | Read | 
| <a name="observabilityadmin-GetTelemetryEnrichmentStatus"></a>[GetTelemetryEnrichmentStatus](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryEnrichmentStatus.html) | Retrieve the status of the Resource tags for telemetry feature for the account | Read | 
| <a name="observabilityadmin-GetTelemetryEvaluationStatus"></a>[GetTelemetryEvaluationStatus](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatus.html) | Retrieve the Telemetry Config feature status for the account | Read | 
| <a name="observabilityadmin-GetTelemetryEvaluationStatusForOrganization"></a>[GetTelemetryEvaluationStatusForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryEvaluationStatusForOrganization.html) | Retrieve the Telemetry Config feature status for the organization | Read | 
| <a name="observabilityadmin-GetTelemetryPipeline"></a>[GetTelemetryPipeline](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryPipeline.html) | Get the telemetry pipeline with the specified name or arn | Read | 
| <a name="observabilityadmin-GetTelemetryRule"></a>[GetTelemetryRule](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryRule.html) | Retrieve the specified telemetry rule for the account | Read | 
| <a name="observabilityadmin-GetTelemetryRuleForOrganization"></a>[GetTelemetryRuleForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_GetTelemetryRuleForOrganization.html) | Retrieve the specified organization telemetry rule for the organization | Read | 
| <a name="observabilityadmin-ListCentralizationRulesForOrganization"></a>[ListCentralizationRulesForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListCentralizationRulesForOrganization.html) | List the centralization rules for the organization | List | 
| <a name="observabilityadmin-ListResourceTelemetry"></a>[ListResourceTelemetry](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListResourceTelemetry.html) | Retrieve telemetry configurations for resources associated with the account | Read | 
| <a name="observabilityadmin-ListResourceTelemetryForOrganization"></a>[ListResourceTelemetryForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListResourceTelemetryForOrganization.html) | Retrieve telemetry configurations for resources associated with accounts in the organization | Read | 
| <a name="observabilityadmin-ListS3TableIntegrations"></a>[ListS3TableIntegrations](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListS3TableIntegrations.html) | List s3 table integrations for the account | List | 
| <a name="observabilityadmin-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListTagsForResource.html) | List the tags for the specified resource | List | 
| <a name="observabilityadmin-ListTelemetryPipelines"></a>[ListTelemetryPipelines](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListTelemetryPipelines.html) | List telemetry pipelines for the account | List | 
| <a name="observabilityadmin-ListTelemetryRules"></a>[ListTelemetryRules](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListTelemetryRules.html) | List the telemetry rules for the account | List | 
| <a name="observabilityadmin-ListTelemetryRulesForOrganization"></a>[ListTelemetryRulesForOrganization](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ListTelemetryRulesForOrganization.html) | List the telemetry rules for the organization | List | 
| <a name="observabilityadmin-TestTelemetryPipeline"></a>[TestTelemetryPipeline](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_TestTelemetryPipeline.html) | Test a telemetry pipeline configuration with sample data | Read | 
| <a name="observabilityadmin-ValidateTelemetryPipelineConfiguration"></a>[ValidateTelemetryPipelineConfiguration](https://docs.aws.amazon.com/cloudwatch/latest/observabilityadmin/API_ValidateTelemetryPipelineConfiguration.html) | Validate a telemetry pipeline configuration | Read |
