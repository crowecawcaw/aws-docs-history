

# Data retrieval APIs for AWS Startups
<a name="awsstartups"></a>

AWS Startups provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="startups-GetSpendSummary"></a>[GetSpendSummary](https://docs.aws.amazon.com/startupadvisor/latest/userguide/#) | Summarize billing, cost, and cost forecast information for which you have permissions | Read |
