# Data retrieval APIs for AWS Agent Registry

AWS Agent Registry provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                          | Description                                                                                                                                                 | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetDiscoverableRegistryRecord](../../../agent-registry/latest/APIReference/API_BatchGetDiscoverableRegistryRecords.md "../../../agent-registry/latest/APIReference/API_BatchGetDiscoverableRegistryRecords.md") | Retrieve an individual approved registry record. This is a permission-only action used for fine-grained access control with BatchGetApprovedRegistryRecords | Read         |
| [GetRegistry](../../../agent-registry-control/latest/APIReference/API_GetRegistry.md "../../../agent-registry-control/latest/APIReference/API_GetRegistry.md")                                                   | Retrieve an existing registry                                                                                                                               | Read         |
| [GetRegistryRecord](../../../agent-registry-control/latest/APIReference/API_GetRegistryRecord.md "../../../agent-registry-control/latest/APIReference/API_GetRegistryRecord.md")                                 | Retrieve an existing registry record                                                                                                                        | Read         |
| [InvokeRegistryMcp](../../../agent-registry/latest/APIReference/API_InvokeRegistryMcp.md "../../../agent-registry/latest/APIReference/API_InvokeRegistryMcp.md")                                                 | Invoke an MCP operation against an existing registry                                                                                                        | Read         |
| [ListDiscoverableRegistryRecords](../../../agent-registry/latest/APIReference/API_ListDiscoverableRegistryRecords.md "../../../agent-registry/latest/APIReference/API_ListDiscoverableRegistryRecords.md")       | List approved registry records in a registry                                                                                                                | List         |
| [ListRegistries](../../../agent-registry-control/latest/APIReference/API_ListRegistries.md "../../../agent-registry-control/latest/APIReference/API_ListRegistries.md")                                          | List existing registries                                                                                                                                    | List         |
| [ListRegistryRecords](../../../agent-registry-control/latest/APIReference/API_ListRegistryRecords.md "../../../agent-registry-control/latest/APIReference/API_ListRegistryRecords.md")                           | List existing registry records in a registry                                                                                                                | List         |
| [ListTagsForResource](../../../agent-registry-control/latest/APIReference/API_ListTagsForResource.md "../../../agent-registry-control/latest/APIReference/API_ListTagsForResource.md")                           | List tags for an Agent Registry resource                                                                                                                    | List         |
| [SearchDiscoverableRegistryRecords](../../../agent-registry/latest/APIReference/API_SearchDiscoverableRegistryRecords.md "../../../agent-registry/latest/APIReference/API_SearchDiscoverableRegistryRecords.md") | Search for registry records                                                                                                                                 | Read         |
