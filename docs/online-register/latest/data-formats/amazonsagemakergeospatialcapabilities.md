# Data retrieval APIs for Amazon SageMaker geospatial capabilities

Amazon SageMaker geospatial capabilities provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                 | Description                                                                    | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------ |
| [GetEarthObservationJob](../../../sagemaker/latest/APIReference/API_geospatial_GetEarthObservationJob.md "../../../sagemaker/latest/APIReference/API_geospatial_GetEarthObservationJob.md")             | Return details about the earth observation job                                 | Read         |
| [GetRasterDataCollection](../../../sagemaker/latest/APIReference/API_geospatial_GetRasterDataCollection.md "../../../sagemaker/latest/APIReference/API_geospatial_GetRasterDataCollection.md")          | Return details about the raster data collection                                | Read         |
| [GetTile](../../../sagemaker/latest/APIReference/API_geospatial_GetTile.md "../../../sagemaker/latest/APIReference/API_geospatial_GetTile.md")                                                          | Get the tile of an earth observation job                                       | Read         |
| [GetVectorEnrichmentJob](../../../sagemaker/latest/APIReference/API_geospatial_GetVectorEnrichmentJob.md "../../../sagemaker/latest/APIReference/API_geospatial_GetVectorEnrichmentJob.md")             | Return details about the vector enrichment job                                 | Read         |
| [ListEarthObservationJobs](../../../sagemaker/latest/APIReference/API_geospatial_ListEarthObservationJobs.md "../../../sagemaker/latest/APIReference/API_geospatial_ListEarthObservationJobs.md")       | Return an array of earth observation jobs associated with the current account  | List         |
| [ListRasterDataCollections](../../../sagemaker/latest/APIReference/API_geospatial_ListRasterDataCollections.md "../../../sagemaker/latest/APIReference/API_geospatial_ListRasterDataCollections.md")    | Return an array of aster data collections associated with the given model name | List         |
| [ListTagsForResource](../../../sagemaker/latest/APIReference/API_geospatial_ListTagsForResource.md "../../../sagemaker/latest/APIReference/API_geospatial_ListTagsForResource.md")                      | Lists tag for an SageMaker Geospatial resource                                 | List         |
| [ListVectorEnrichmentJobs](../../../sagemaker/latest/APIReference/API_geospatial_ListVectorEnrichmentJobs.md "../../../sagemaker/latest/APIReference/API_geospatial_ListVectorEnrichmentJobs.md")       | Return an array of vector enrichment jobs associated with the current account  | List         |
| [SearchRasterDataCollection](../../../sagemaker/latest/APIReference/API_geospatial_SearchRasterDataCollection.md "../../../sagemaker/latest/APIReference/API_geospatial_SearchRasterDataCollection.md") | Query raster data collections                                                  | Read         |
