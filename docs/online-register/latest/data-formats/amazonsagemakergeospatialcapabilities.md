

# Data retrieval APIs for Amazon SageMaker geospatial capabilities
<a name="amazonsagemakergeospatialcapabilities"></a>

Amazon SageMaker geospatial capabilities provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="sagemaker-geospatial-GetEarthObservationJob"></a>[GetEarthObservationJob](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_GetEarthObservationJob.html) | Return details about the earth observation job | Read | 
| <a name="sagemaker-geospatial-GetRasterDataCollection"></a>[GetRasterDataCollection](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_GetRasterDataCollection.html) | Return details about the raster data collection | Read | 
| <a name="sagemaker-geospatial-GetTile"></a>[GetTile](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_GetTile.html) | Get the tile of an earth observation job | Read | 
| <a name="sagemaker-geospatial-GetVectorEnrichmentJob"></a>[GetVectorEnrichmentJob](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_GetVectorEnrichmentJob.html) | Return details about the vector enrichment job | Read | 
| <a name="sagemaker-geospatial-ListEarthObservationJobs"></a>[ListEarthObservationJobs](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_ListEarthObservationJobs.html) | Return an array of earth observation jobs associated with the current account | List | 
| <a name="sagemaker-geospatial-ListRasterDataCollections"></a>[ListRasterDataCollections](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_ListRasterDataCollections.html) | Return an array of aster data collections associated with the given model name | List | 
| <a name="sagemaker-geospatial-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_ListTagsForResource.html) | Lists tag for an SageMaker Geospatial resource | List | 
| <a name="sagemaker-geospatial-ListVectorEnrichmentJobs"></a>[ListVectorEnrichmentJobs](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_ListVectorEnrichmentJobs.html) | Return an array of vector enrichment jobs associated with the current account | List | 
| <a name="sagemaker-geospatial-SearchRasterDataCollection"></a>[SearchRasterDataCollection](https://docs.aws.amazon.com/sagemaker/latest/APIReference/API_geospatial_SearchRasterDataCollection.html) | Query raster data collections | Read |
