# Data retrieval APIs for AWS Application Auto Scaling

AWS Application Auto Scaling provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                               | Description                                                                               | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------ |
| [DescribeScalableTargets](../../../autoscaling/application/APIReference/API_DescribeScalableTargets.md "../../../autoscaling/application/APIReference/API_DescribeScalableTargets.md")                | Describe one or more scalable targets in the specified namespace                          | Read         |
| [DescribeScalingActivities](../../../autoscaling/application/APIReference/API_DescribeScalingActivities.md "../../../autoscaling/application/APIReference/API_DescribeScalingActivities.md")          | Describe a set of scaling activities or all scaling activities in the specified namespace | Read         |
| [DescribeScalingPolicies](../../../autoscaling/application/APIReference/API_DescribeScalingPolicies.md "../../../autoscaling/application/APIReference/API_DescribeScalingPolicies.md")                | Describe a set of scaling policies or all scaling policies in the specified namespace     | Read         |
| [DescribeScheduledActions](../../../autoscaling/application/APIReference/API_DescribeScheduledActions.md "../../../autoscaling/application/APIReference/API_DescribeScheduledActions.md")             | Describe a set of scheduled actions or all scheduled actions in the specified namespace   | Read         |
| [GetPredictiveScalingForecast](../../../autoscaling/application/APIReference/API_GetPredictiveScalingForecast.md "../../../autoscaling/application/APIReference/API_GetPredictiveScalingForecast.md") | Retrieve the forecast data for a predictive scaling policy                                | List         |
| [ListTagsForResource](../../../autoscaling/application/APIReference/API_ListTagsForResource.md "../../../autoscaling/application/APIReference/API_ListTagsForResource.md")                            | List tags for a scalable target                                                           | Read         |
