

# Data retrieval APIs for AWS Application Auto Scaling
<a name="awsapplicationautoscaling"></a>

AWS Application Auto Scaling provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="application-autoscaling-DescribeScalableTargets"></a>[DescribeScalableTargets](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_DescribeScalableTargets.html) | Describe one or more scalable targets in the specified namespace | Read | 
| <a name="application-autoscaling-DescribeScalingActivities"></a>[DescribeScalingActivities](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_DescribeScalingActivities.html) | Describe a set of scaling activities or all scaling activities in the specified namespace | Read | 
| <a name="application-autoscaling-DescribeScalingPolicies"></a>[DescribeScalingPolicies](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_DescribeScalingPolicies.html) | Describe a set of scaling policies or all scaling policies in the specified namespace | Read | 
| <a name="application-autoscaling-DescribeScheduledActions"></a>[DescribeScheduledActions](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_DescribeScheduledActions.html) | Describe a set of scheduled actions or all scheduled actions in the specified namespace | Read | 
| <a name="application-autoscaling-GetPredictiveScalingForecast"></a>[GetPredictiveScalingForecast](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_GetPredictiveScalingForecast.html) | Retrieve the forecast data for a predictive scaling policy | List | 
| <a name="application-autoscaling-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/autoscaling/application/APIReference/API_ListTagsForResource.html) | List tags for a scalable target | Read |
