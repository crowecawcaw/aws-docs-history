# Data retrieval APIs for Amazon QLDB

Amazon QLDB provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                             | Description                                                          | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ |
| [DescribeJournalKinesisStream](../../../qldb/latest/developerguide/API_DescribeJournalKinesisStream.md "../../../qldb/latest/developerguide/API_DescribeJournalKinesisStream.md")                   | Describe information about a journal kinesis stream                  | Read         |
| [DescribeJournalS3Export](../../../qldb/latest/developerguide/API_DescribeJournalS3Export.md "../../../qldb/latest/developerguide/API_DescribeJournalS3Export.md")                                  | Describe information about a journal export job                      | Read         |
| [DescribeLedger](../../../qldb/latest/developerguide/API_DescribeLedger.md "../../../qldb/latest/developerguide/API_DescribeLedger.md")                                                             | Describe a ledger                                                    | Read         |
| [GetBlock](../../../qldb/latest/developerguide/API_GetBlock.md "../../../qldb/latest/developerguide/API_GetBlock.md")                                                                               | Retrieve a block from a ledger for a given BlockAddress              | Read         |
| [GetDigest](../../../qldb/latest/developerguide/API_GetDigest.md "../../../qldb/latest/developerguide/API_GetDigest.md")                                                                            | Retrieve a digest from a ledger for a given BlockAddress             | Read         |
| [GetRevision](../../../qldb/latest/developerguide/API_GetRevision.md "../../../qldb/latest/developerguide/API_GetRevision.md")                                                                      | Retrieve a revision for a given document ID and a given BlockAddress | Read         |
| [ListJournalKinesisStreamsForLedger](../../../qldb/latest/developerguide/API_ListJournalKinesisStreamsForLedger.md "../../../qldb/latest/developerguide/API_ListJournalKinesisStreamsForLedger.md") | List journal kinesis streams for a specified ledger                  | List         |
| [ListJournalS3Exports](../../../qldb/latest/developerguide/API_ListJournalS3Exports.md "../../../qldb/latest/developerguide/API_ListJournalS3Exports.md")                                           | List journal export jobs for all ledgers                             | List         |
| [ListJournalS3ExportsForLedger](../../../qldb/latest/developerguide/API_ListJournalS3ExportsForLedger.md "../../../qldb/latest/developerguide/API_ListJournalS3ExportsForLedger.md")                | List journal export jobs for a specified ledger                      | List         |
| [ListLedgers](../../../qldb/latest/developerguide/API_ListLedgers.md "../../../qldb/latest/developerguide/API_ListLedgers.md")                                                                      | List existing ledgers                                                | List         |
| [ListTagsForResource](../../../qldb/latest/developerguide/API_ListTagsForResource.md "../../../qldb/latest/developerguide/API_ListTagsForResource.md")                                              | List tags for a resource                                             | Read         |
| [PartiQLHistoryFunction](../../../qldb/latest/developerguide/working.md "../../../qldb/latest/developerguide/working.md")                                                                           | Use the history function on a table                                  | Read         |
| [PartiQLSelect](../../../qldb/latest/developerguide/ql-reference.md "../../../qldb/latest/developerguide/ql-reference.md")                                                                          | Select documents from a table                                        | Read         |
