# Data retrieval APIs for Amazon Cognito Sync

Amazon Cognito Sync provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                     | Description                                                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeDataset](../../../cognitosync/latest/APIReference/API_DescribeDataset.md "../../../cognitosync/latest/APIReference/API_DescribeDataset.md")                                        | Get metadata about a dataset by identity and dataset name                                          | Read         |
| [DescribeIdentityPoolUsage](../../../cognitosync/latest/APIReference/API_DescribeIdentityPoolUsage.md "../../../cognitosync/latest/APIReference/API_DescribeIdentityPoolUsage.md")          | Get usage details (for example, data storage) about a particular identity pool                     | Read         |
| [DescribeIdentityUsage](../../../cognitosync/latest/APIReference/API_DescribeIdentityUsage.md "../../../cognitosync/latest/APIReference/API_DescribeIdentityUsage.md")                      | Get usage information for an identity, including number of datasets and data usage                 | Read         |
| [GetBulkPublishDetails](../../../cognitosync/latest/APIReference/API_GetBulkPublishDetails.md "../../../cognitosync/latest/APIReference/API_GetBulkPublishDetails.md")                      | Get the status of the last BulkPublish operation for an identity pool                              | Read         |
| [GetCognitoEvents](../../../cognitosync/latest/APIReference/API_GetCognitoEvents.md "../../../cognitosync/latest/APIReference/API_GetCognitoEvents.md")                                     | Get the events and the corresponding Lambda functions associated with an identity pool             | Read         |
| [GetIdentityPoolConfiguration](../../../cognitosync/latest/APIReference/API_GetIdentityPoolConfiguration.md "../../../cognitosync/latest/APIReference/API_GetIdentityPoolConfiguration.md") | Get the configuration settings of an identity pool                                                 | Read         |
| [ListDatasets](../../../cognitosync/latest/APIReference/API_ListDatasets.md "../../../cognitosync/latest/APIReference/API_ListDatasets.md")                                                 | List datasets for an identity                                                                      | List         |
| [ListIdentityPoolUsage](../../../cognitosync/latest/APIReference/API_ListIdentityPoolUsage.md "../../../cognitosync/latest/APIReference/API_ListIdentityPoolUsage.md")                      | Get a list of identity pools registered with Cognito                                               | Read         |
| [ListRecords](../../../cognitosync/latest/APIReference/API_ListRecords.md "../../../cognitosync/latest/APIReference/API_ListRecords.md")                                                    | Get paginated records, optionally changed after a particular sync count for a dataset and identity | Read         |
| QueryRecords                                                                                                                                                                                | Query records                                                                                      | Read         |
