# Data retrieval APIs for Amazon Elastic VMware Service

Amazon Elastic VMware Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                            | Description                                                               | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | ------------ |
| [GetAccountSettings](../../../evs/latest/APIReference/API_GetAccountSettings.md "../../../evs/latest/APIReference/API_GetAccountSettings.md")                      | Get EVS account settings                                                  | Read         |
| [GetDepotUrl](../../../evs/latest/APIReference/API_GetDepotUrl.md "../../../evs/latest/APIReference/API_GetDepotUrl.md")                                           | Get an Amazon EVS environment depot url                                   | Read         |
| [GetEnvironment](../../../evs/latest/APIReference/API_GetEnvironment.md "../../../evs/latest/APIReference/API_GetEnvironment.md")                                  | Get an Amazon EVS environment                                             | Read         |
| [GetVersions](../../../evs/latest/APIReference/API_GetVersions.md "../../../evs/latest/APIReference/API_GetVersions.md")                                           | Get versions provided for launch by Amazon EVS                            | Read         |
| [ListEnvironmentConnectors](../../../evs/latest/APIReference/API_ListEnvironmentConnectors.md "../../../evs/latest/APIReference/API_ListEnvironmentConnectors.md") | Retrieve a list of connectors associated with an Amazon EVS environment   | List         |
| [ListEnvironmentHosts](../../../evs/latest/APIReference/API_ListEnvironmentHosts.md "../../../evs/latest/APIReference/API_ListEnvironmentHosts.md")                | Retrieve a list of hosts associated with an Amazon EVS environment        | List         |
| [ListEnvironmentVlans](../../../evs/latest/APIReference/API_ListEnvironmentVlans.md "../../../evs/latest/APIReference/API_ListEnvironmentVlans.md")                | Retrieve a list of Amazon EVS environment VLANs                           | List         |
| [ListEnvironments](../../../evs/latest/APIReference/API_ListEnvironments.md "../../../evs/latest/APIReference/API_ListEnvironments.md")                            | Retrieve a list of Amazon EVS environments in an account                  | List         |
| [ListTagsForResource](../../../evs/latest/APIReference/API_ListTagsForResource.md "../../../evs/latest/APIReference/API_ListTagsForResource.md")                   | List the tags on a specified resource ARN                                 | Read         |
| [ListVmEntitlements](../../../evs/latest/APIReference/API_ListVmEntitlements.md "../../../evs/latest/APIReference/API_ListVmEntitlements.md")                      | Retrieve a list of entitlements associated with an Amazon EVS environment | List         |
