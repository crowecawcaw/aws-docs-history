# Data retrieval APIs for Amazon Simple Workflow Service

Amazon Simple Workflow Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                    | Description                                                                                                                      | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [CountClosedWorkflowExecutions](../../../amazonswf/latest/apireference/API_CountClosedWorkflowExecutions.md "../../../amazonswf/latest/apireference/API_CountClosedWorkflowExecutions.md") | Return the number of closed workflow executions within the given domain that meet the specified filtering criteria               | Read         |
| [CountOpenWorkflowExecutions](../../../amazonswf/latest/apireference/API_CountOpenWorkflowExecutions.md "../../../amazonswf/latest/apireference/API_CountOpenWorkflowExecutions.md")       | Return the number of open workflow executions within the given domain that meet the specified filtering criteria                 | Read         |
| [CountPendingActivityTasks](../../../amazonswf/latest/apireference/API_CountPendingActivityTasks.md "../../../amazonswf/latest/apireference/API_CountPendingActivityTasks.md")             | Return the estimated number of activity tasks in the specified task list                                                         | Read         |
| [CountPendingDecisionTasks](../../../amazonswf/latest/apireference/API_CountPendingDecisionTasks.md "../../../amazonswf/latest/apireference/API_CountPendingDecisionTasks.md")             | Return the estimated number of decision tasks in the specified task list                                                         | Read         |
| [DescribeActivityType](../../../amazonswf/latest/apireference/API_DescribeActivityType.md "../../../amazonswf/latest/apireference/API_DescribeActivityType.md")                            | Return information about the specified activity type                                                                             | Read         |
| [DescribeDomain](../../../amazonswf/latest/apireference/API_DescribeDomain.md "../../../amazonswf/latest/apireference/API_DescribeDomain.md")                                              | Return information about the specified domain, including its description and status                                              | Read         |
| [DescribeWorkflowExecution](../../../amazonswf/latest/apireference/API_DescribeWorkflowExecution.md "../../../amazonswf/latest/apireference/API_DescribeWorkflowExecution.md")             | Return information about the specified workflow execution including its type and some statistics                                 | Read         |
| [DescribeWorkflowType](../../../amazonswf/latest/apireference/API_DescribeWorkflowType.md "../../../amazonswf/latest/apireference/API_DescribeWorkflowType.md")                            | Return information about the specified workflow type                                                                             | Read         |
| [GetWorkflowExecutionHistory](../../../amazonswf/latest/apireference/API_GetWorkflowExecutionHistory.md "../../../amazonswf/latest/apireference/API_GetWorkflowExecutionHistory.md")       | Return the history of the specified workflow execution                                                                           | Read         |
| [ListActivityTypes](../../../amazonswf/latest/apireference/API_ListActivityTypes.md "../../../amazonswf/latest/apireference/API_ListActivityTypes.md")                                     | Return information about all activities registered in the specified domain that match the specified name and registration status | List         |
| [ListClosedWorkflowExecutions](../../../amazonswf/latest/apireference/API_ListClosedWorkflowExecutions.md "../../../amazonswf/latest/apireference/API_ListClosedWorkflowExecutions.md")    | Return a list of closed workflow executions in the specified domain that meet the filtering criteria                             | List         |
| [ListDomains](../../../amazonswf/latest/apireference/API_ListDomains.md "../../../amazonswf/latest/apireference/API_ListDomains.md")                                                       | Return the list of domains registered in the account                                                                             | List         |
| [ListOpenWorkflowExecutions](../../../amazonswf/latest/apireference/API_ListOpenWorkflowExecutions.md "../../../amazonswf/latest/apireference/API_ListOpenWorkflowExecutions.md")          | Return a list of open workflow executions in the specified domain that meet the filtering criteria                               | List         |
| [ListTagsForResource](../../../amazonswf/latest/apireference/API_ListTagsForResource.md "../../../amazonswf/latest/apireference/API_ListTagsForResource.md")                               | List tags for an AWS SWF resource                                                                                                | List         |
| [ListWorkflowTypes](../../../amazonswf/latest/apireference/API_ListWorkflowTypes.md "../../../amazonswf/latest/apireference/API_ListWorkflowTypes.md")                                     | Return information about workflow types in the specified domain                                                                  | List         |
