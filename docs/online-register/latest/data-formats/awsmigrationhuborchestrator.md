# Data retrieval APIs for AWS Migration Hub Orchestrator

AWS Migration Hub Orchestrator provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                               | Description                                                            | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------ |
| [GetMessage](../../../migrationhub-orchestrator/latest/APIReference/API_GetMessage.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetMessage.md")                                     | The plugin to receive information from the service                     | Read         |
| [GetTemplate](../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplate.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplate.md")                                  | Get retrieve metadata for a Template                                   | Read         |
| [GetTemplateStep](../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplateStep.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplateStep.md")                      | Retrieve details of a step associated with a template and a step group | Read         |
| [GetTemplateStepGroup](../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplateStepGroup.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetTemplateStepGroup.md")       | Retrieve metadata of a step group under a template                     | Read         |
| [GetWorkflow](../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflow.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflow.md")                                  | Retrieve metadata asscociated with a workflow                          | Read         |
| [GetWorkflowStep](../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStep.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStep.md")                      | Get details of step associated with a workflow and a step group        | Read         |
| [GetWorkflowStepGroup](../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStepGroup.md "../../../migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStepGroup.md")       | Get details of a step group associated with a workflow                 | Read         |
| [ListPlugins](../../../migrationhub-orchestrator/latest/APIReference/API_ListPlugins.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListPlugins.md")                                  | Get a list all registered Plugins                                      | List         |
| [ListTagsForResource](../../../migrationhub-orchestrator/latest/APIReference/API_ListTagsForResource.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListTagsForResource.md")          | Get a list of all the tags tied to a resource                          | Read         |
| [ListTemplateStepGroups](../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplateStepGroups.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplateStepGroups.md") | Lists step groups of a template                                        | List         |
| [ListTemplateSteps](../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplateSteps.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplateSteps.md")                | Get a list of steps in a step group                                    | List         |
| [ListTemplates](../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplates.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListTemplates.md")                            | Get a list of all Templates available to customer                      | List         |
| [ListWorkflowStepGroups](../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflowStepGroups.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflowStepGroups.md") | Get list of step groups associated with a workflow                     | List         |
| [ListWorkflowSteps](../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflowSteps.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflowSteps.md")                | Get a list of steps within step group associated with a workflow       | List         |
| [ListWorkflows](../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflows.md "../../../migrationhub-orchestrator/latest/APIReference/API_ListWorkflows.md")                            | List all workflows                                                     | List         |
