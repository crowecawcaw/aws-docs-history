

# Data retrieval APIs for AWS Migration Hub Orchestrator
<a name="awsmigrationhuborchestrator"></a>

AWS Migration Hub Orchestrator provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="migrationhub-orchestrator-GetMessage"></a>[GetMessage](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetMessage.html) | The plugin to receive information from the service | Read | 
| <a name="migrationhub-orchestrator-GetTemplate"></a>[GetTemplate](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetTemplate.html) | Get retrieve metadata for a Template | Read | 
| <a name="migrationhub-orchestrator-GetTemplateStep"></a>[GetTemplateStep](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetTemplateStep.html) | Retrieve details of a step associated with a template and a step group | Read | 
| <a name="migrationhub-orchestrator-GetTemplateStepGroup"></a>[GetTemplateStepGroup](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetTemplateStepGroup.html) | Retrieve metadata of a step group under a template | Read | 
| <a name="migrationhub-orchestrator-GetWorkflow"></a>[GetWorkflow](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetWorkflow.html) | Retrieve metadata asscociated with a workflow | Read | 
| <a name="migrationhub-orchestrator-GetWorkflowStep"></a>[GetWorkflowStep](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStep.html) | Get details of step associated with a workflow and a step group | Read | 
| <a name="migrationhub-orchestrator-GetWorkflowStepGroup"></a>[GetWorkflowStepGroup](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_GetWorkflowStepGroup.html) | Get details of a step group associated with a workflow | Read | 
| <a name="migrationhub-orchestrator-ListPlugins"></a>[ListPlugins](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListPlugins.html) | Get a list all registered Plugins | List | 
| <a name="migrationhub-orchestrator-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListTagsForResource.html) | Get a list of all the tags tied to a resource | Read | 
| <a name="migrationhub-orchestrator-ListTemplateStepGroups"></a>[ListTemplateStepGroups](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListTemplateStepGroups.html) | Lists step groups of a template | List | 
| <a name="migrationhub-orchestrator-ListTemplateSteps"></a>[ListTemplateSteps](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListTemplateSteps.html) | Get a list of steps in a step group | List | 
| <a name="migrationhub-orchestrator-ListTemplates"></a>[ListTemplates](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListTemplates.html) | Get a list of all Templates available to customer | List | 
| <a name="migrationhub-orchestrator-ListWorkflowStepGroups"></a>[ListWorkflowStepGroups](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListWorkflowStepGroups.html) | Get list of step groups associated with a workflow | List | 
| <a name="migrationhub-orchestrator-ListWorkflowSteps"></a>[ListWorkflowSteps](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListWorkflowSteps.html) | Get a list of steps within step group associated with a workflow | List | 
| <a name="migrationhub-orchestrator-ListWorkflows"></a>[ListWorkflows](https://docs.aws.amazon.com/migrationhub-orchestrator/latest/APIReference/API_ListWorkflows.html) | List all workflows | List |
