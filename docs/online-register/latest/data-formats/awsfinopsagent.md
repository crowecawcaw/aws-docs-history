

# Data retrieval APIs for AWS FinOps Agent
<a name="awsfinopsagent"></a>

AWS FinOps Agent provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="finops-agent-GetAgentRequest"></a>[GetAgentRequest](https://docs.aws.amazon.com/finops-agent/) | View details of a pending approval request from the agent | Read | 
| <a name="finops-agent-GetAgentSpace"></a>[GetAgentSpace](https://docs.aws.amazon.com/finops-agent/) | View details of a FinOps Agent workspace | Read | 
| <a name="finops-agent-GetArtifactContent"></a>[GetArtifactContent](https://docs.aws.amazon.com/finops-agent/) | Download artifact content | Read | 
| <a name="finops-agent-GetArtifactMetadata"></a>[GetArtifactMetadata](https://docs.aws.amazon.com/finops-agent/) | View artifact metadata | Read | 
| <a name="finops-agent-GetAutomation"></a>[GetAutomation](https://docs.aws.amazon.com/finops-agent/) | View details of an automation | Read | 
| <a name="finops-agent-GetConnection"></a>[GetConnection](https://docs.aws.amazon.com/finops-agent/) | View details of a connection | Read | 
| <a name="finops-agent-GetDocumentContent"></a>[GetDocumentContent](https://docs.aws.amazon.com/finops-agent/) | Download document content | Read | 
| <a name="finops-agent-GetDocumentMetadata"></a>[GetDocumentMetadata](https://docs.aws.amazon.com/finops-agent/) | View document metadata | Read | 
| <a name="finops-agent-GetIntegration"></a>[GetIntegration](https://docs.aws.amazon.com/finops-agent/) | View details of a third-party integration | Read | 
| <a name="finops-agent-GetTask"></a>[GetTask](https://docs.aws.amazon.com/finops-agent/) | View details of a task | Read | 
| <a name="finops-agent-GetTurn"></a>[GetTurn](https://docs.aws.amazon.com/finops-agent/) | View details of a conversation turn | Read | 
| <a name="finops-agent-ListAgentSpaces"></a>[ListAgentSpaces](https://docs.aws.amazon.com/finops-agent/) | List all FinOps Agent workspaces in the account | List | 
| <a name="finops-agent-ListArtifacts"></a>[ListArtifacts](https://docs.aws.amazon.com/finops-agent/) | List artifacts | List | 
| <a name="finops-agent-ListAutomations"></a>[ListAutomations](https://docs.aws.amazon.com/finops-agent/) | List automations | List | 
| <a name="finops-agent-ListConnections"></a>[ListConnections](https://docs.aws.amazon.com/finops-agent/) | List connections | List | 
| <a name="finops-agent-ListConversations"></a>[ListConversations](https://docs.aws.amazon.com/finops-agent/) | List conversations | List | 
| <a name="finops-agent-ListDocuments"></a>[ListDocuments](https://docs.aws.amazon.com/finops-agent/) | List documents | List | 
| <a name="finops-agent-ListIntegrations"></a>[ListIntegrations](https://docs.aws.amazon.com/finops-agent/) | List third-party integrations | List | 
| <a name="finops-agent-ListRecords"></a>[ListRecords](https://docs.aws.amazon.com/finops-agent/) | List records for real-time agent activity display | List | 
| <a name="finops-agent-ListTasks"></a>[ListTasks](https://docs.aws.amazon.com/finops-agent/) | List tasks | List | 
| <a name="finops-agent-ListTurns"></a>[ListTurns](https://docs.aws.amazon.com/finops-agent/) | List turns in a conversation | List |
