# Data retrieval APIs for AWS FinOps Agent

AWS FinOps Agent provides the following APIs for data retrieval.

| Actions                                                                    | Description                                               | Access level |
| -------------------------------------------------------------------------- | --------------------------------------------------------- | ------------ |
| [GetAgentRequest](../../../finops-agent.md "../../../finops-agent.md")     | View details of a pending approval request from the agent | Read         |
| [GetAgentSpace](../../../finops-agent.md "../../../finops-agent.md")       | View details of a FinOps Agent workspace                  | Read         |
| [GetArtifactContent](../../../finops-agent.md "../../../finops-agent.md")  | Download artifact content                                 | Read         |
| [GetArtifactMetadata](../../../finops-agent.md "../../../finops-agent.md") | View artifact metadata                                    | Read         |
| [GetAutomation](../../../finops-agent.md "../../../finops-agent.md")       | View details of an automation                             | Read         |
| [GetConnection](../../../finops-agent.md "../../../finops-agent.md")       | View details of a connection                              | Read         |
| [GetDocumentContent](../../../finops-agent.md "../../../finops-agent.md")  | Download document content                                 | Read         |
| [GetDocumentMetadata](../../../finops-agent.md "../../../finops-agent.md") | View document metadata                                    | Read         |
| [GetIntegration](../../../finops-agent.md "../../../finops-agent.md")      | View details of a third-party integration                 | Read         |
| [GetTask](../../../finops-agent.md "../../../finops-agent.md")             | View details of a task                                    | Read         |
| [GetTurn](../../../finops-agent.md "../../../finops-agent.md")             | View details of a conversation turn                       | Read         |
| [ListAgentSpaces](../../../finops-agent.md "../../../finops-agent.md")     | List all FinOps Agent workspaces in the account           | List         |
| [ListArtifacts](../../../finops-agent.md "../../../finops-agent.md")       | List artifacts                                            | List         |
| [ListAutomations](../../../finops-agent.md "../../../finops-agent.md")     | List automations                                          | List         |
| [ListConnections](../../../finops-agent.md "../../../finops-agent.md")     | List connections                                          | List         |
| [ListConversations](../../../finops-agent.md "../../../finops-agent.md")   | List conversations                                        | List         |
| [ListDocuments](../../../finops-agent.md "../../../finops-agent.md")       | List documents                                            | List         |
| [ListIntegrations](../../../finops-agent.md "../../../finops-agent.md")    | List third-party integrations                             | List         |
| [ListRecords](../../../finops-agent.md "../../../finops-agent.md")         | List records for real-time agent activity display         | List         |
| [ListTasks](../../../finops-agent.md "../../../finops-agent.md")           | List tasks                                                | List         |
| [ListTurns](../../../finops-agent.md "../../../finops-agent.md")           | List turns in a conversation                              | List         |
