# Data retrieval APIs for Amazon Elastic Container Service

Amazon Elastic Container Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                           | Description                                                                                                                                                                                                    | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeCapacityProviders](../../../AmazonECS/latest/APIReference/API_DescribeCapacityProviders.md "../../../AmazonECS/latest/APIReference/API_DescribeCapacityProviders.md")    | Describe one or more Amazon ECS capacity providers                                                                                                                                                             | Read         |
| [DescribeClusters](../../../AmazonECS/latest/APIReference/API_DescribeClusters.md "../../../AmazonECS/latest/APIReference/API_DescribeClusters.md")                               | Describes one or more of your clusters                                                                                                                                                                         | Read         |
| [DescribeContainerInstances](../../../AmazonECS/latest/APIReference/API_DescribeContainerInstances.md "../../../AmazonECS/latest/APIReference/API_DescribeContainerInstances.md") | Describes Amazon ECS container instances                                                                                                                                                                       | Read         |
| [DescribeServiceDeployments](../../../AmazonECS/latest/APIReference/API_DescribeServiceDeployments.md "../../../AmazonECS/latest/APIReference/API_DescribeServiceDeployments.md") | Describe one or more of your service deployments                                                                                                                                                               | Read         |
| [DescribeServiceRevisions](../../../AmazonECS/latest/APIReference/API_DescribeServiceRevisions.md "../../../AmazonECS/latest/APIReference/API_DescribeServiceRevisions.md")       | Describe one or more of your service revisions                                                                                                                                                                 | Read         |
| [DescribeServices](../../../AmazonECS/latest/APIReference/API_DescribeServices.md "../../../AmazonECS/latest/APIReference/API_DescribeServices.md")                               | Describe the specified services running in your cluster                                                                                                                                                        | Read         |
| [DescribeTaskDefinition](../../../AmazonECS/latest/APIReference/API_DescribeTaskDefinition.md "../../../AmazonECS/latest/APIReference/API_DescribeTaskDefinition.md")             | Describe a task definition. You can specify a family and revision to find information about a specific task definition, or you can simply specify the family to find the latest ACTIVE revision in that family | Read         |
| [DescribeTaskSets](../../../AmazonECS/latest/APIReference/API_DescribeTaskSets.md "../../../AmazonECS/latest/APIReference/API_DescribeTaskSets.md")                               | Describe Amazon ECS task sets                                                                                                                                                                                  | Read         |
| [DescribeTasks](../../../AmazonECS/latest/APIReference/API_DescribeTasks.md "../../../AmazonECS/latest/APIReference/API_DescribeTasks.md")                                        | Describe a specified task or tasks                                                                                                                                                                             | Read         |
| [GetTaskProtection](../../../AmazonECS/latest/APIReference/API_GetTaskProtection.md "../../../AmazonECS/latest/APIReference/API_GetTaskProtection.md")                            | Retrieve the protection status of tasks in an Amazon ECS service                                                                                                                                               | Read         |
| [ListAccountSettings](../../../AmazonECS/latest/APIReference/API_ListAccountSettings.md "../../../AmazonECS/latest/APIReference/API_ListAccountSettings.md")                      | List the account settings for an Amazon ECS resource for a specified principal                                                                                                                                 | Read         |
| [ListAttributes](../../../AmazonECS/latest/APIReference/API_ListAttributes.md "../../../AmazonECS/latest/APIReference/API_ListAttributes.md")                                     | Lists the attributes for Amazon ECS resources within a specified target type and cluster                                                                                                                       | List         |
| [ListClusters](../../../AmazonECS/latest/APIReference/API_ListClusters.md "../../../AmazonECS/latest/APIReference/API_ListClusters.md")                                           | Get a list of existing clusters                                                                                                                                                                                | List         |
| [ListContainerInstances](../../../AmazonECS/latest/APIReference/API_ListContainerInstances.md "../../../AmazonECS/latest/APIReference/API_ListContainerInstances.md")             | Get a list of container instances in a specified cluster                                                                                                                                                       | List         |
| [ListServiceDeployments](../../../AmazonECS/latest/APIReference/API_ListServiceDeployments.md "../../../AmazonECS/latest/APIReference/API_ListServiceDeployments.md")             | Get a list of service deployments for a specified service                                                                                                                                                      | List         |
| [ListServices](../../../AmazonECS/latest/APIReference/API_ListServices.md "../../../AmazonECS/latest/APIReference/API_ListServices.md")                                           | Get a list of services that are running in a specified cluster                                                                                                                                                 | List         |
| [ListServicesByNamespace](../../../AmazonECS/latest/APIReference/API_ListServicesByNamespace.md "../../../AmazonECS/latest/APIReference/API_ListServicesByNamespace.md")          | Get a list of services that are running in a specified AWS Cloud Map Namespace                                                                                                                                 | List         |
| [ListTagsForResource](../../../AmazonECS/latest/APIReference/API_ListTagsForResource.md "../../../AmazonECS/latest/APIReference/API_ListTagsForResource.md")                      | Get a list of tags for the specified resource                                                                                                                                                                  | Read         |
| [ListTaskDefinitionFamilies](../../../AmazonECS/latest/APIReference/API_ListTaskDefinitionFamilies.md "../../../AmazonECS/latest/APIReference/API_ListTaskDefinitionFamilies.md") | Get a list of task definition families that are registered to your account (which may include task definition families that no longer have any ACTIVE task definitions)                                        | List         |
| [ListTaskDefinitions](../../../AmazonECS/latest/APIReference/API_ListTaskDefinitions.md "../../../AmazonECS/latest/APIReference/API_ListTaskDefinitions.md")                      | Get a list of task definitions that are registered to your account                                                                                                                                             | List         |
| [ListTasks](../../../AmazonECS/latest/APIReference/API_ListTasks.md "../../../AmazonECS/latest/APIReference/API_ListTasks.md")                                                    | Get a list of tasks for a specified cluster                                                                                                                                                                    | List         |
