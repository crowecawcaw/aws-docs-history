# Data retrieval APIs for Amazon EMR on EKS (EMR Containers)

Amazon EMR on EKS (EMR Containers) provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                      | Description                                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------ |
| [DescribeJobRun](../../../emr-on-eks/latest/APIReference/API_DescribeJobRun.md "../../../emr-on-eks/latest/APIReference/API_DescribeJobRun.md")                                              | Describe a job run                                       | Read         |
| [DescribeJobTemplate](../../../emr-on-eks/latest/APIReference/API_DescribeJobTemplate.md "../../../emr-on-eks/latest/APIReference/API_DescribeJobTemplate.md")                               | Describe a job template                                  | Read         |
| [DescribeManagedEndpoint](../../../emr-on-eks/latest/APIReference/API_DescribeManagedEndpoint.md "../../../emr-on-eks/latest/APIReference/API_DescribeManagedEndpoint.md")                   | Describe a managed endpoint                              | Read         |
| [DescribeSecurityConfiguration](../../../emr-on-eks/latest/APIReference/API_DescribeSecurityConfiguration.md "../../../emr-on-eks/latest/APIReference/API_DescribeSecurityConfiguration.md") | Describe a security configuration                        | Read         |
| [DescribeVirtualCluster](../../../emr-on-eks/latest/APIReference/API_DescribeVirtualCluster.md "../../../emr-on-eks/latest/APIReference/API_DescribeVirtualCluster.md")                      | Describe a virtual cluster                               | Read         |
| [ListJobRuns](../../../emr-on-eks/latest/APIReference/API_ListJobRuns.md "../../../emr-on-eks/latest/APIReference/API_ListJobRuns.md")                                                       | List job runs associated with a virtual cluster          | List         |
| [ListJobTemplates](../../../emr-on-eks/latest/APIReference/API_ListJobTemplates.md "../../../emr-on-eks/latest/APIReference/API_ListJobTemplates.md")                                        | List job templates                                       | List         |
| [ListManagedEndpoints](../../../emr-on-eks/latest/APIReference/API_ListManagedEndpoints.md "../../../emr-on-eks/latest/APIReference/API_ListManagedEndpoints.md")                            | List managed endpoints associated with a virtual cluster | List         |
| [ListSecurityConfigurations](../../../emr-on-eks/latest/APIReference/API_ListSecurityConfigurations.md "../../../emr-on-eks/latest/APIReference/API_ListSecurityConfigurations.md")          | List security configurations                             | List         |
| [ListTagsForResource](../../../emr-on-eks/latest/APIReference/API_ListTagsForResource.md "../../../emr-on-eks/latest/APIReference/API_ListTagsForResource.md")                               | List tags for the specified resource                     | List         |
| [ListVirtualClusters](../../../emr-on-eks/latest/APIReference/API_ListVirtualClusters.md "../../../emr-on-eks/latest/APIReference/API_ListVirtualClusters.md")                               | List virtual clusters                                    | List         |
