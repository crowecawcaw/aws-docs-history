

# Data retrieval APIs for Amazon EMR on EKS (EMR Containers)
<a name="amazonemroneksemrcontainers"></a>

Amazon EMR on EKS (EMR Containers) provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="emr-containers-DescribeJobRun"></a>[DescribeJobRun](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_DescribeJobRun.html) | Describe a job run | Read | 
| <a name="emr-containers-DescribeJobTemplate"></a>[DescribeJobTemplate](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_DescribeJobTemplate.html) | Describe a job template | Read | 
| <a name="emr-containers-DescribeManagedEndpoint"></a>[DescribeManagedEndpoint](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_DescribeManagedEndpoint.html) | Describe a managed endpoint | Read | 
| <a name="emr-containers-DescribeSecurityConfiguration"></a>[DescribeSecurityConfiguration](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_DescribeSecurityConfiguration.html) | Describe a security configuration | Read | 
| <a name="emr-containers-DescribeVirtualCluster"></a>[DescribeVirtualCluster](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_DescribeVirtualCluster.html) | Describe a virtual cluster | Read | 
| <a name="emr-containers-ListJobRuns"></a>[ListJobRuns](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListJobRuns.html) | List job runs associated with a virtual cluster | List | 
| <a name="emr-containers-ListJobTemplates"></a>[ListJobTemplates](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListJobTemplates.html) | List job templates | List | 
| <a name="emr-containers-ListManagedEndpoints"></a>[ListManagedEndpoints](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListManagedEndpoints.html) | List managed endpoints associated with a virtual cluster | List | 
| <a name="emr-containers-ListSecurityConfigurations"></a>[ListSecurityConfigurations](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListSecurityConfigurations.html) | List security configurations | List | 
| <a name="emr-containers-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListTagsForResource.html) | List tags for the specified resource | List | 
| <a name="emr-containers-ListVirtualClusters"></a>[ListVirtualClusters](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_ListVirtualClusters.html) | List virtual clusters | List |
