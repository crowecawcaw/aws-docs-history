

# Data retrieval APIs for Amazon Route 53 Recovery Controls
<a name="amazonroute53recoverycontrols"></a>

Amazon Route 53 Recovery Controls provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="route53-recovery-control-config-DescribeCluster"></a>[DescribeCluster](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster-clusterarn.html) | Describe a cluster | Read | 
| <a name="route53-recovery-control-config-DescribeControlPanel"></a>[DescribeControlPanel](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn.html) | Describe a control panel | Read | 
| <a name="route53-recovery-control-config-DescribeRoutingControl"></a>[DescribeRoutingControl](https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn.html) | Describe a routing control | Read | 
| <a name="route53-recovery-control-config-DescribeSafetyRule"></a>[DescribeSafetyRule](https://docs.aws.amazon.com/recovery-cluster/latest/api/safetyrule-safetyrulearn.html) | Describe a safety rule | Read | 
| <a name="route53-recovery-control-config-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster/resourcepolicy-resourcearn.html) | Get the resource policy of a cluster | Read | 
| <a name="route53-recovery-control-config-ListAssociatedRoute53HealthChecks"></a>[ListAssociatedRoute53HealthChecks](https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn-associatedroute53healthchecks.html) | List associated Route 53 health checks | List | 
| <a name="route53-recovery-control-config-ListClusters"></a>[ListClusters](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster.html) | List clusters | Read | 
| <a name="route53-recovery-control-config-ListControlPanels"></a>[ListControlPanels](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanels.html) | List control panels | Read | 
| <a name="route53-recovery-control-config-ListRoutingControls"></a>[ListRoutingControls](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn-routingcontrols.html) | List routing controls | Read | 
| <a name="route53-recovery-control-config-ListSafetyRules"></a>[ListSafetyRules](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn-safetyrules.html) | List safety rules | Read | 
| <a name="route53-recovery-control-config-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/recovery-cluster/latest/api/tags-resource-arn.html) | List tags for a resource | Read |
