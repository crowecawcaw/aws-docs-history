# Data retrieval APIs for Amazon Data Lifecycle Manager

Amazon Data Lifecycle Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                             | Description                                                       | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------ |
| [GetLifecyclePolicies](../../../dlm/latest/APIReference/API_GetLifecyclePolicies.md "../../../dlm/latest/APIReference/API_GetLifecyclePolicies.md") | Returns a list of summary descriptions of data lifecycle policies | List         |
| [GetLifecyclePolicy](../../../dlm/latest/APIReference/API_GetLifecyclePolicy.md "../../../dlm/latest/APIReference/API_GetLifecyclePolicy.md")       | Return a complete description of a single data lifecycle policy   | Read         |
| [ListTagsForResource](../../../dlm/latest/APIReference/API_ListTagsForResource.md "../../../dlm/latest/APIReference/API_ListTagsForResource.md")    | List the tags associated with a resource                          | Read         |
