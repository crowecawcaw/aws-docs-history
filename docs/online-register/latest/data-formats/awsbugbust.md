# Data retrieval APIs for AWS BugBust

AWS BugBust provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                              | Description                                                                              | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------ |
| [GetEvent](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")              | View customer details about an event                                                     | Read         |
| [GetJoinEventStatus](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")    | View the status of a BugBust player's attempt to join a BugBust event                    | Read         |
| [ListBugs](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")              | View the bugs that were imported into an event for players to work on                    | Read         |
| [ListEventParticipants](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md") | View the participants of an event                                                        | Read         |
| [ListEventScores](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")       | View the scores of an event's players                                                    | Read         |
| [ListEvents](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")            | List BugBust events                                                                      | List         |
| [ListProfilingGroups](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")   | View the profiling groups that were imported into an event for players to work on        | Read         |
| [ListPullRequests](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")      | View the pull requests used by players to submit fixes to their claimed bugs in an event | Read         |
| [ListTagsForResource](../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md "../../../codeguru/latest/bugbust-ug/auth-and-access-control-permissions-reference.md")   | Lists tag for a Bugbust resource                                                         | Read         |
