# Data retrieval APIs for Amazon Machine Learning

Amazon Machine Learning provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                   | Description                                                                                                                  | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeBatchPredictions](../../../machine-learning/latest/APIReference/API_DescribeBatchPredictions.md "../../../machine-learning/latest/APIReference/API_DescribeBatchPredictions.md") | Returns a list of BatchPrediction operations that match the search criteria in the request                                   | List         |
| [DescribeDataSources](../../../machine-learning/latest/APIReference/API_DescribeDataSources.md "../../../machine-learning/latest/APIReference/API_DescribeDataSources.md")                | Returns a list of DataSource that match the search criteria in the request                                                   | List         |
| [DescribeEvaluations](../../../machine-learning/latest/APIReference/API_DescribeEvaluations.md "../../../machine-learning/latest/APIReference/API_DescribeEvaluations.md")                | Returns a list of DescribeEvaluations that match the search criteria in the request                                          | List         |
| [DescribeMLModels](../../../machine-learning/latest/APIReference/API_DescribeMLModels.md "../../../machine-learning/latest/APIReference/API_DescribeMLModels.md")                         | Returns a list of MLModel that match the search criteria in the request                                                      | List         |
| [DescribeTags](../../../machine-learning/latest/APIReference/API_DescribeTags.md "../../../machine-learning/latest/APIReference/API_DescribeTags.md")                                     | Describes one or more of the tags for your Amazon ML object                                                                  | List         |
| [GetBatchPrediction](../../../machine-learning/latest/APIReference/API_GetBatchPrediction.md "../../../machine-learning/latest/APIReference/API_GetBatchPrediction.md")                   | Returns a BatchPrediction that includes detailed metadata, status, and data file information                                 | Read         |
| [GetDataSource](../../../machine-learning/latest/APIReference/API_GetDataSource.md "../../../machine-learning/latest/APIReference/API_GetDataSource.md")                                  | Returns a DataSource that includes metadata and data file information, as well as the current status of the DataSource       | Read         |
| [GetEvaluation](../../../machine-learning/latest/APIReference/API_GetEvaluation.md "../../../machine-learning/latest/APIReference/API_GetEvaluation.md")                                  | Returns an Evaluation that includes metadata as well as the current status of the Evaluation                                 | Read         |
| [GetMLModel](../../../machine-learning/latest/APIReference/API_GetMLModel.md "../../../machine-learning/latest/APIReference/API_GetMLModel.md")                                           | Returns an MLModel that includes detailed metadata, and data source information as well as the current status of the MLModel | Read         |
