

# Data retrieval APIs for AWS Outposts
<a name="awsoutposts"></a>

AWS Outposts provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="outposts-GetCapacityTask"></a>[GetCapacityTask](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetCapacityTask.html) | Get information about the specified capacity task | Read | 
| <a name="outposts-GetCatalogItem"></a>[GetCatalogItem](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetCatalogItem.html) | Get a catalog item | Read | 
| <a name="outposts-GetConnection"></a>[GetConnection](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetConnection.html) | Get information about the connection for your Outpost server | Read | 
| <a name="outposts-GetOrder"></a>[GetOrder](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetOrder.html) | Get information about an order | Read | 
| <a name="outposts-GetOutpost"></a>[GetOutpost](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetOutpost.html) | Get information about the specified Outpost | Read | 
| <a name="outposts-GetOutpostBillingInformation"></a>[GetOutpostBillingInformation](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetOutpostBillingInformation.html) | Get Outpost billing information for the specified Outpost | Read | 
| <a name="outposts-GetOutpostInstanceTypes"></a>[GetOutpostInstanceTypes](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetOutpostInstanceTypes.html) | Get the instance types for the specified Outpost | Read | 
| <a name="outposts-GetOutpostSupportedInstanceTypes"></a>[GetOutpostSupportedInstanceTypes](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetOutpostSupportedInstanceTypes.html) | Get the supported instance types for the specified Outpost | Read | 
| <a name="outposts-GetPrivateConnectivityConfig"></a>[GetPrivateConnectivityConfig](https://docs.aws.amazon.com/outposts/latest/userguide/how-outposts-works.html#private-connectivity) | Get a private connectivity configuration | Read | 
| <a name="outposts-GetQuote"></a>[GetQuote](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetQuote.html) | Get information about a quote | Read | 
| <a name="outposts-GetRenewalPricing"></a>[GetRenewalPricing](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetRenewalPricing.html) | Get renewal pricing for the specified Outpost | Read | 
| <a name="outposts-GetSite"></a>[GetSite](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetSite.html) | Get a site | Read | 
| <a name="outposts-GetSiteAddress"></a>[GetSiteAddress](https://docs.aws.amazon.com/outposts/latest/APIReference/API_GetSiteAddress.html) | Get a site address | Read | 
| <a name="outposts-ListAssetInstances"></a>[ListAssetInstances](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListAssetInstances.html) | List all running instances for the specified Outpost | List | 
| <a name="outposts-ListAssets"></a>[ListAssets](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListAssets.html) | List the assets for your Outpost | List | 
| <a name="outposts-ListBlockingInstancesForCapacityTask"></a>[ListBlockingInstancesForCapacityTask](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListBlockingInstancesForCapacityTask.html) | List all running instances that are blocking the capacity task from running for the specified Outpost | List | 
| <a name="outposts-ListCapacityTasks"></a>[ListCapacityTasks](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListCapacityTasks.html) | List the capacity tasks for your AWS account | List | 
| <a name="outposts-ListCatalogItems"></a>[ListCatalogItems](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListCatalogItems.html) | List all catalog items | List | 
| <a name="outposts-ListOrderableInstanceTypes"></a>[ListOrderableInstanceTypes](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListOrderableInstanceTypes.html) | List the orderable instance types for your AWS account | List | 
| <a name="outposts-ListOrders"></a>[ListOrders](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListOrders.html) | List the orders for your AWS account | List | 
| <a name="outposts-ListOutposts"></a>[ListOutposts](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListOutposts.html) | List the Outposts for your AWS account | List | 
| <a name="outposts-ListQuotes"></a>[ListQuotes](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListQuotes.html) | List quotes for your AWS account | List | 
| <a name="outposts-ListSites"></a>[ListSites](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListSites.html) | List the sites for your AWS account | List | 
| <a name="outposts-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/outposts/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
