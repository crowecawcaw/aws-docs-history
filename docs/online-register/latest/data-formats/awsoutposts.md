# Data retrieval APIs for AWS Outposts

AWS Outposts provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                       | Description                                                                                           | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------ |
| [GetCapacityTask](../../../outposts/latest/APIReference/API_GetCapacityTask.md "../../../outposts/latest/APIReference/API_GetCapacityTask.md")                                                                | Get information about the specified capacity task                                                     | Read         |
| [GetCatalogItem](../../../outposts/latest/APIReference/API_GetCatalogItem.md "../../../outposts/latest/APIReference/API_GetCatalogItem.md")                                                                   | Get a catalog item                                                                                    | Read         |
| [GetConnection](../../../outposts/latest/APIReference/API_GetConnection.md "../../../outposts/latest/APIReference/API_GetConnection.md")                                                                      | Get information about the connection for your Outpost server                                          | Read         |
| [GetOrder](../../../outposts/latest/APIReference/API_GetOrder.md "../../../outposts/latest/APIReference/API_GetOrder.md")                                                                                     | Get information about an order                                                                        | Read         |
| [GetOutpost](../../../outposts/latest/APIReference/API_GetOutpost.md "../../../outposts/latest/APIReference/API_GetOutpost.md")                                                                               | Get information about the specified Outpost                                                           | Read         |
| [GetOutpostBillingInformation](../../../outposts/latest/APIReference/API_GetOutpostBillingInformation.md "../../../outposts/latest/APIReference/API_GetOutpostBillingInformation.md")                         | Get Outpost billing information for the specified Outpost                                             | Read         |
| [GetOutpostInstanceTypes](../../../outposts/latest/APIReference/API_GetOutpostInstanceTypes.md "../../../outposts/latest/APIReference/API_GetOutpostInstanceTypes.md")                                        | Get the instance types for the specified Outpost                                                      | Read         |
| [GetOutpostSupportedInstanceTypes](../../../outposts/latest/APIReference/API_GetOutpostSupportedInstanceTypes.md "../../../outposts/latest/APIReference/API_GetOutpostSupportedInstanceTypes.md")             | Get the supported instance types for the specified Outpost                                            | Read         |
| [GetPrivateConnectivityConfig](../../../outposts/latest/userguide/how-outposts-works.md#private-connectivity "../../../outposts/latest/userguide/how-outposts-works.md#private-connectivity")                 | Get a private connectivity configuration                                                              | Read         |
| [GetSite](../../../outposts/latest/APIReference/API_GetSite.md "../../../outposts/latest/APIReference/API_GetSite.md")                                                                                        | Get a site                                                                                            | Read         |
| [GetSiteAddress](../../../outposts/latest/APIReference/API_GetSiteAddress.md "../../../outposts/latest/APIReference/API_GetSiteAddress.md")                                                                   | Get a site address                                                                                    | Read         |
| [ListAssetInstances](../../../outposts/latest/APIReference/API_ListAssetInstances.md "../../../outposts/latest/APIReference/API_ListAssetInstances.md")                                                       | List all running instances for the specified Outpost                                                  | List         |
| [ListAssets](../../../outposts/latest/APIReference/API_ListAssets.md "../../../outposts/latest/APIReference/API_ListAssets.md")                                                                               | List the assets for your Outpost                                                                      | List         |
| [ListBlockingInstancesForCapacityTask](../../../outposts/latest/APIReference/API_ListBlockingInstancesForCapacityTask.md "../../../outposts/latest/APIReference/API_ListBlockingInstancesForCapacityTask.md") | List all running instances that are blocking the capacity task from running for the specified Outpost | List         |
| [ListCapacityTasks](../../../outposts/latest/APIReference/API_ListCapacityTasks.md "../../../outposts/latest/APIReference/API_ListCapacityTasks.md")                                                          | List the capacity tasks for your AWS account                                                          | List         |
| [ListCatalogItems](../../../outposts/latest/APIReference/API_ListCatalogItems.md "../../../outposts/latest/APIReference/API_ListCatalogItems.md")                                                             | List all catalog items                                                                                | List         |
| [ListOrders](../../../outposts/latest/APIReference/API_ListOrders.md "../../../outposts/latest/APIReference/API_ListOrders.md")                                                                               | List the orders for your AWS account                                                                  | List         |
| [ListOutposts](../../../outposts/latest/APIReference/API_ListOutposts.md "../../../outposts/latest/APIReference/API_ListOutposts.md")                                                                         | List the Outposts for your AWS account                                                                | List         |
| [ListSites](../../../outposts/latest/APIReference/API_ListSites.md "../../../outposts/latest/APIReference/API_ListSites.md")                                                                                  | List the sites for your AWS account                                                                   | List         |
| [ListTagsForResource](../../../outposts/latest/APIReference/API_ListTagsForResource.md "../../../outposts/latest/APIReference/API_ListTagsForResource.md")                                                    | List tags for a resource                                                                              | Read         |
