

# Data retrieval APIs for AWS Direct Connect
<a name="awsdirectconnect"></a>

AWS Direct Connect provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="directconnect-DescribeConnectionLoa"></a>[DescribeConnectionLoa](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeConnectionLoa.html) | Describe the LOA-CFA for a Connection | Read | 
| <a name="directconnect-DescribeConnections"></a>[DescribeConnections](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeConnections.html) | Describe all connections in this region | Read | 
| <a name="directconnect-DescribeConnectionsOnInterconnect"></a>[DescribeConnectionsOnInterconnect](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeConnectionsOnInterconnect.html) | Describe a list of connections that have been provisioned on the given interconnect | Read | 
| <a name="directconnect-DescribeCustomerMetadata"></a>[DescribeCustomerMetadata](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeCustomerMetadata.html) | View a list of customer agreements, along with their signed status and whether the customer is an NNIPartner, NNIPartnerV2, or a nonPartner | Read | 
| <a name="directconnect-DescribeDirectConnectGatewayAssociationProposals"></a>[DescribeDirectConnectGatewayAssociationProposals](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeDirectConnectGatewayAssociationProposals.html) | Describe one or more association proposals for connection between a virtual private gateway and a Direct Connect gateway | Read | 
| <a name="directconnect-DescribeDirectConnectGatewayAssociations"></a>[DescribeDirectConnectGatewayAssociations](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeDirectConnectGatewayAssociations.html) | Describe the associations between your Direct Connect gateways and virtual private gateways | Read | 
| <a name="directconnect-DescribeDirectConnectGatewayAttachments"></a>[DescribeDirectConnectGatewayAttachments](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeDirectConnectGatewayAttachments.html) | Describe the attachments between your Direct Connect gateways and virtual interfaces | Read | 
| <a name="directconnect-DescribeDirectConnectGateways"></a>[DescribeDirectConnectGateways](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeDirectConnectGateways.html) | Describe all your Direct Connect gateways or only the specified Direct Connect gateway | Read | 
| <a name="directconnect-DescribeHostedConnections"></a>[DescribeHostedConnections](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeHostedConnections.html) | Describe the hosted connections that have been provisioned on the specified interconnect or link aggregation group (LAG) | Read | 
| <a name="directconnect-DescribeInterconnectLoa"></a>[DescribeInterconnectLoa](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeInterconnectLoa.html) | Describe the LOA-CFA for an Interconnect | Read | 
| <a name="directconnect-DescribeInterconnects"></a>[DescribeInterconnects](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeInterconnects.html) | Describe a list of interconnects owned by the AWS account | Read | 
| <a name="directconnect-DescribeLags"></a>[DescribeLags](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeLags.html) | Describe all your link aggregation groups (LAG) or the specified LAG | Read | 
| <a name="directconnect-DescribeLoa"></a>[DescribeLoa](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeLoa.html) | Describe the LOA-CFA for a connection, interconnect, or link aggregation group (LAG) | Read | 
| <a name="directconnect-DescribeLocations"></a>[DescribeLocations](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeLocations.html) | Describe the list of AWS Direct Connect locations in the current AWS region | Read | 
| <a name="directconnect-DescribeRouterConfiguration"></a>[DescribeRouterConfiguration](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeRouterConfiguration.html) | Describe Details about the router for a virtual interface | Read | 
| <a name="directconnect-DescribeTags"></a>[DescribeTags](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeTags.html) | Describe the tags associated with the specified AWS Direct Connect resources | Read | 
| <a name="directconnect-DescribeVirtualGateways"></a>[DescribeVirtualGateways](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeVirtualGateways.html) | Describe a list of virtual private gateways owned by the AWS account | Read | 
| <a name="directconnect-DescribeVirtualInterfaces"></a>[DescribeVirtualInterfaces](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_DescribeVirtualInterfaces.html) | Describe all virtual interfaces for an AWS account | Read | 
| <a name="directconnect-ListVirtualInterfaceRoutes"></a>[ListVirtualInterfaceRoutes](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_ListVirtualInterfaceRoutes.html) | List the routes accepted and advertised over a virtual interface | List | 
| <a name="directconnect-ListVirtualInterfaceTestHistory"></a>[ListVirtualInterfaceTestHistory](https://docs.aws.amazon.com/directconnect/latest/APIReference/API_ListVirtualInterfaceTestHistory.html) | List the virtual interface failover test history | List |
