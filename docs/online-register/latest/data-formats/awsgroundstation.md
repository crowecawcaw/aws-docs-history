

# Data retrieval APIs for AWS Ground Station
<a name="awsgroundstation"></a>

AWS Ground Station provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="groundstation-DescribeContact"></a>[DescribeContact](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_DescribeContact.html) | Describe a contact | Read | 
| <a name="groundstation-DescribeContactVersion"></a>[DescribeContactVersion](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_DescribeContactVersion.html) | Describe a specific version of a contact | Read | 
| <a name="groundstation-DescribeEphemeris"></a>[DescribeEphemeris](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_DescribeEphemeris.html) | Describe an ephemeris item | Read | 
| <a name="groundstation-GetAgentConfiguration"></a>[GetAgentConfiguration](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetAgentConfiguration.html) | Get the configuration of an agent | Read | 
| <a name="groundstation-GetAgentTaskResponseUrl"></a>[GetAgentTaskResponseUrl](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetAgentTaskResponseUrl.html) | Retrieve presigned S3 logging URLs | Read | 
| <a name="groundstation-GetConfig"></a>[GetConfig](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetConfig.html) | Return a configuration | Read | 
| <a name="groundstation-GetDataflowEndpointGroup"></a>[GetDataflowEndpointGroup](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetDataflowEndpointGroup.html) | Return a data flow endpoint group | Read | 
| <a name="groundstation-GetMinuteUsage"></a>[GetMinuteUsage](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetMinuteUsage.html) | Return minutes usage | Read | 
| <a name="groundstation-GetMissionProfile"></a>[GetMissionProfile](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetMissionProfile.html) | Retrieve a mission profile | Read | 
| <a name="groundstation-GetSatellite"></a>[GetSatellite](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_GetSatellite.html) | Return information about a satellite | Read | 
| <a name="groundstation-ListAntennas"></a>[ListAntennas](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListAntennas.html) | List antennas for a ground station | List | 
| <a name="groundstation-ListConfigs"></a>[ListConfigs](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListConfigs.html) | Return a list of past configurations | List | 
| <a name="groundstation-ListContactVersions"></a>[ListContactVersions](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListContactVersions.html) | List versions of a contact | List | 
| <a name="groundstation-ListContacts"></a>[ListContacts](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListContacts.html) | Return a list of contacts | List | 
| <a name="groundstation-ListDataflowEndpointGroups"></a>[ListDataflowEndpointGroups](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListDataflowEndpointGroups.html) | List data flow endpoint groups | List | 
| <a name="groundstation-ListEphemerides"></a>[ListEphemerides](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListEphemerides.html) | List ephemerides | List | 
| <a name="groundstation-ListGroundStationReservations"></a>[ListGroundStationReservations](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListGroundStationReservations.html) | List reservations for a ground station | List | 
| <a name="groundstation-ListGroundStations"></a>[ListGroundStations](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListGroundStations.html) | List ground stations | List | 
| <a name="groundstation-ListMissionProfiles"></a>[ListMissionProfiles](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListMissionProfiles.html) | Return a list of mission profiles | List | 
| <a name="groundstation-ListSatellites"></a>[ListSatellites](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListSatellites.html) | List satellites | List | 
| <a name="groundstation-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/ground-station/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
