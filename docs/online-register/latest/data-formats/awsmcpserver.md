# Data retrieval APIs for AWS MCP Server

AWS MCP Server provides the following APIs for data retrieval.

| Actions                                                                                                                   | Description                         | Access level |
| ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- | ------------ |
| [CallReadOnlyTool](../../../aws-mcp/latest/userguide/security-iam.md "../../../aws-mcp/latest/userguide/security-iam.md") | Call read-only tools in MCP service | Read         |
| [InvokeMcp](../../../aws-mcp/latest/userguide/security-iam.md "../../../aws-mcp/latest/userguide/security-iam.md")        | Use MCP service                     | List         |
