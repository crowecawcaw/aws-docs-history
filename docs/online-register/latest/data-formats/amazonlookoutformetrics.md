# Data retrieval APIs for Amazon Lookout for Metrics

Amazon Lookout for Metrics provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                           | Description                                                      | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------ |
| [DescribeAlert](../../../lookoutmetrics/latest/api/API_DescribeAlert.md "../../../lookoutmetrics/latest/api/API_DescribeAlert.md")                                                                | Get details about an alert                                       | Read         |
| [DescribeAnomalyDetectionExecutions](../../../lookoutmetrics/latest/api/API_DescribeAnomalyDetectionExecutions.md "../../../lookoutmetrics/latest/api/API_DescribeAnomalyDetectionExecutions.md") | Get information about an anomaly detection job                   | Read         |
| [DescribeAnomalyDetector](../../../lookoutmetrics/latest/api/API_DescribeAnomalyDetector.md "../../../lookoutmetrics/latest/api/API_DescribeAnomalyDetector.md")                                  | Get details about an anomaly detector                            | Read         |
| [DescribeMetricSet](../../../lookoutmetrics/latest/api/API_DescribeMetricSet.md "../../../lookoutmetrics/latest/api/API_DescribeMetricSet.md")                                                    | Get details about a dataset                                      | Read         |
| [GetAnomalyGroup](../../../lookoutmetrics/latest/api/API_GetAnomalyGroup.md "../../../lookoutmetrics/latest/api/API_GetAnomalyGroup.md")                                                          | Get details about a group of affected metrics                    | Read         |
| [GetDataQualityMetrics](../../../lookoutmetrics/latest/api/API_GetDataQualityMetrics.md "../../../lookoutmetrics/latest/api/API_GetDataQualityMetrics.md")                                        | Get data quality metrics for an anomaly detector                 | Read         |
| [GetFeedback](../../../lookoutmetrics/latest/api/API_GetFeedback.md "../../../lookoutmetrics/latest/api/API_GetFeedback.md")                                                                      | Get feedback on affected metrics for an anomaly group            | Read         |
| [GetSampleData](../../../lookoutmetrics/latest/api/API_GetSampleData.md "../../../lookoutmetrics/latest/api/API_GetSampleData.md")                                                                | Get a selection of sample records from an Amazon S3 datasource   | Read         |
| [ListAlerts](../../../lookoutmetrics/latest/api/API_ListAlerts.md "../../../lookoutmetrics/latest/api/API_ListAlerts.md")                                                                         | Get a list of alerts for a detector                              | List         |
| [ListAnomalyDetectors](../../../lookoutmetrics/latest/api/API_ListAnomalyDetectors.md "../../../lookoutmetrics/latest/api/API_ListAnomalyDetectors.md")                                           | Get a list of anomaly detectors                                  | List         |
| [ListAnomalyGroupRelatedMetrics](../../../lookoutmetrics/latest/api/API_ListAnomalyGroupRelatedMetrics.md "../../../lookoutmetrics/latest/api/API_ListAnomalyGroupRelatedMetrics.md")             | Get a list of related measures in an anomaly group               | List         |
| [ListAnomalyGroupSummaries](../../../lookoutmetrics/latest/api/API_ListAnomalyGroupSummaries.md "../../../lookoutmetrics/latest/api/API_ListAnomalyGroupSummaries.md")                            | Get a list of anomaly groups                                     | List         |
| [ListAnomalyGroupTimeSeries](../../../lookoutmetrics/latest/api/API_ListAnomalyGroupTimeSeries.md "../../../lookoutmetrics/latest/api/API_ListAnomalyGroupTimeSeries.md")                         | Get a list of affected metrics for a measure in an anomaly group | List         |
| [ListMetricSets](../../../lookoutmetrics/latest/api/API_ListMetricSets.md "../../../lookoutmetrics/latest/api/API_ListMetricSets.md")                                                             | Get a list of datasets                                           | List         |
| [ListTagsForResource](../../../lookoutmetrics/latest/api/API_ListTagsForResource.md "../../../lookoutmetrics/latest/api/API_ListTagsForResource.md")                                              | Get a list of tags for a detector, dataset, or alert             | Read         |
