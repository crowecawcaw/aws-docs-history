

# Data retrieval APIs for Amazon Lookout for Metrics
<a name="amazonlookoutformetrics"></a>

Amazon Lookout for Metrics provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="lookoutmetrics-DescribeAlert"></a>[DescribeAlert](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_DescribeAlert.html) | Get details about an alert | Read | 
| <a name="lookoutmetrics-DescribeAnomalyDetectionExecutions"></a>[DescribeAnomalyDetectionExecutions](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_DescribeAnomalyDetectionExecutions.html) | Get information about an anomaly detection job | Read | 
| <a name="lookoutmetrics-DescribeAnomalyDetector"></a>[DescribeAnomalyDetector](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_DescribeAnomalyDetector.html) | Get details about an anomaly detector | Read | 
| <a name="lookoutmetrics-DescribeMetricSet"></a>[DescribeMetricSet](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_DescribeMetricSet.html) | Get details about a dataset | Read | 
| <a name="lookoutmetrics-GetAnomalyGroup"></a>[GetAnomalyGroup](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_GetAnomalyGroup.html) | Get details about a group of affected metrics | Read | 
| <a name="lookoutmetrics-GetDataQualityMetrics"></a>[GetDataQualityMetrics](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_GetDataQualityMetrics.html) | Get data quality metrics for an anomaly detector | Read | 
| <a name="lookoutmetrics-GetFeedback"></a>[GetFeedback](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_GetFeedback.html) | Get feedback on affected metrics for an anomaly group | Read | 
| <a name="lookoutmetrics-GetSampleData"></a>[GetSampleData](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_GetSampleData.html) | Get a selection of sample records from an Amazon S3 datasource | Read | 
| <a name="lookoutmetrics-ListAlerts"></a>[ListAlerts](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListAlerts.html) | Get a list of alerts for a detector | List | 
| <a name="lookoutmetrics-ListAnomalyDetectors"></a>[ListAnomalyDetectors](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListAnomalyDetectors.html) | Get a list of anomaly detectors | List | 
| <a name="lookoutmetrics-ListAnomalyGroupRelatedMetrics"></a>[ListAnomalyGroupRelatedMetrics](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListAnomalyGroupRelatedMetrics.html) | Get a list of related measures in an anomaly group | List | 
| <a name="lookoutmetrics-ListAnomalyGroupSummaries"></a>[ListAnomalyGroupSummaries](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListAnomalyGroupSummaries.html) | Get a list of anomaly groups | List | 
| <a name="lookoutmetrics-ListAnomalyGroupTimeSeries"></a>[ListAnomalyGroupTimeSeries](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListAnomalyGroupTimeSeries.html) | Get a list of affected metrics for a measure in an anomaly group | List | 
| <a name="lookoutmetrics-ListMetricSets"></a>[ListMetricSets](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListMetricSets.html) | Get a list of datasets | List | 
| <a name="lookoutmetrics-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/lookoutmetrics/latest/api/API_ListTagsForResource.html) | Get a list of tags for a detector, dataset, or alert | Read |
