

# Data retrieval APIs for AWS Elemental MediaConnect
<a name="awselementalmediaconnect"></a>

AWS Elemental MediaConnect provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mediaconnect-DescribeBridge"></a>[DescribeBridge](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeBridge.html) | Display the details of a bridge | Read | 
| <a name="mediaconnect-DescribeFlow"></a>[DescribeFlow](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeFlow.html) | Display the details of a flow including the flow ARN, name, and Availability Zone, as well as details about the source, outputs, and entitlements | Read | 
| <a name="mediaconnect-DescribeFlowSourceMetadata"></a>[DescribeFlowSourceMetadata](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeFlowSourceMetadata.html) | View information about the flow's source transport stream and programs | Read | 
| <a name="mediaconnect-DescribeFlowSourceThumbnail"></a>[DescribeFlowSourceThumbnail](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeFlowSourceThumbnail.html) | View flow's source thumbnail | Read | 
| <a name="mediaconnect-DescribeGateway"></a>[DescribeGateway](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeGateway.html) | Display the details of a gateway including the gateway ARN, name, and CIDR blocks, as well as details about the networks | Read | 
| <a name="mediaconnect-DescribeGatewayInstance"></a>[DescribeGatewayInstance](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeGatewayInstance.html) | Display the details of a gateway instance | Read | 
| <a name="mediaconnect-DescribeOffering"></a>[DescribeOffering](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeOffering.html) | Display the details of an offering | Read | 
| <a name="mediaconnect-DescribeReservation"></a>[DescribeReservation](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DescribeReservation.html) | Display the details of a reservation | Read | 
| <a name="mediaconnect-DiscoverGatewayPollEndpoint"></a>[DiscoverGatewayPollEndpoint](https://docs.aws.amazon.com/mediaconnect/latest/api/API_DiscoverGatewayPollEndpoint.html) | Discover gateway poll endpoint | Read | 
| <a name="mediaconnect-GetRouterInput"></a>[GetRouterInput](https://docs.aws.amazon.com/mediaconnect/latest/api/API_GetRouterInput.html) | Retrieve information about a specific router input in AWS Elemental MediaConnect | Read | 
| <a name="mediaconnect-GetRouterInputSourceMetadata"></a>[GetRouterInputSourceMetadata](https://docs.aws.amazon.com/mediaconnect/latest/api/API_GetRouterInputSourceMetadata.html) | Retrieve metadata about a router input source in AWS Elemental MediaConnect | Read | 
| <a name="mediaconnect-GetRouterInputThumbnail"></a>[GetRouterInputThumbnail](https://docs.aws.amazon.com/mediaconnect/latest/api/API_GetRouterInputThumbnail.html) | Retrieve the thumbnail for a router input in AWS Elemental MediaConnect | Read | 
| <a name="mediaconnect-GetRouterNetworkInterface"></a>[GetRouterNetworkInterface](https://docs.aws.amazon.com/mediaconnect/latest/api/API_GetRouterNetworkInterface.html) | Retrieve information about a specific router network interface in AWS Elemental MediaConnect | Read | 
| <a name="mediaconnect-GetRouterOutput"></a>[GetRouterOutput](https://docs.aws.amazon.com/mediaconnect/latest/api/API_GetRouterOutput.html) | Retrieve information about a specific router output in AWS Elemental MediaConnect | Read | 
| <a name="mediaconnect-ListBridges"></a>[ListBridges](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListBridges.html) | Display a list of bridges that are associated with this account and an optionally specified Arn | List | 
| <a name="mediaconnect-ListEntitlements"></a>[ListEntitlements](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListEntitlements.html) | Display a list of all entitlements that have been granted to the account | List | 
| <a name="mediaconnect-ListFlows"></a>[ListFlows](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListFlows.html) | Display a list of flows that are associated with this account | List | 
| <a name="mediaconnect-ListGatewayInstances"></a>[ListGatewayInstances](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListGatewayInstances.html) | Display a list of instances that are associated with this gateway | List | 
| <a name="mediaconnect-ListGateways"></a>[ListGateways](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListGateways.html) | Display a list of gateways that are associated with this account | List | 
| <a name="mediaconnect-ListOfferings"></a>[ListOfferings](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListOfferings.html) | Display a list of all offerings that are available to the account in the current AWS Region | List | 
| <a name="mediaconnect-ListReservations"></a>[ListReservations](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListReservations.html) | Display a list of all reservations that have been purchased by the account in the current AWS Region | List | 
| <a name="mediaconnect-ListRouterInputs"></a>[ListRouterInputs](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListRouterInputs.html) | Retrieve a list of router inputs in AWS Elemental MediaConnect | List | 
| <a name="mediaconnect-ListRouterNetworkInterfaces"></a>[ListRouterNetworkInterfaces](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListRouterNetworkInterfaces.html) | Retrieve a list of router network interfaces in AWS Elemental MediaConnect | List | 
| <a name="mediaconnect-ListRouterOutputs"></a>[ListRouterOutputs](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListRouterOutputs.html) | Retrieve a list of router outputs in AWS Elemental MediaConnect | List | 
| <a name="mediaconnect-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/mediaconnect/latest/api/API_ListTagsForResource.html) | Display a list of all tags associated with a resource | Read |
