# Data retrieval APIs for AWS Elemental MediaConnect

AWS Elemental MediaConnect provides the following APIs for data retrieval.

| Actions                                                                                                                                                                  | Description                                                                                                                                       | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeBridge](../../../mediaconnect/latest/api/API_DescribeBridge.md "../../../mediaconnect/latest/api/API_DescribeBridge.md")                                        | Display the details of a bridge                                                                                                                   | Read         |
| [DescribeFlow](../../../mediaconnect/latest/api/API_DescribeFlow.md "../../../mediaconnect/latest/api/API_DescribeFlow.md")                                              | Display the details of a flow including the flow ARN, name, and Availability Zone, as well as details about the source, outputs, and entitlements | Read         |
| [DescribeFlowSourceMetadata](../../../mediaconnect/latest/api/API_DescribeFlowSourceMetadata.md "../../../mediaconnect/latest/api/API_DescribeFlowSourceMetadata.md")    | View information about the flow's source transport stream and programs                                                                            | Read         |
| [DescribeFlowSourceThumbnail](../../../mediaconnect/latest/api/API_DescribeFlowSourceThumbnail.md "../../../mediaconnect/latest/api/API_DescribeFlowSourceThumbnail.md") | View flow's source thumbnail                                                                                                                      | Read         |
| [DescribeGateway](../../../mediaconnect/latest/api/API_DescribeGateway.md "../../../mediaconnect/latest/api/API_DescribeGateway.md")                                     | Display the details of a gateway including the gateway ARN, name, and CIDR blocks, as well as details about the networks                          | Read         |
| [DescribeGatewayInstance](../../../mediaconnect/latest/api/API_DescribeGatewayInstance.md "../../../mediaconnect/latest/api/API_DescribeGatewayInstance.md")             | Display the details of a gateway instance                                                                                                         | Read         |
| [DescribeOffering](../../../mediaconnect/latest/api/API_DescribeOffering.md "../../../mediaconnect/latest/api/API_DescribeOffering.md")                                  | Display the details of an offering                                                                                                                | Read         |
| [DescribeReservation](../../../mediaconnect/latest/api/API_DescribeReservation.md "../../../mediaconnect/latest/api/API_DescribeReservation.md")                         | Display the details of a reservation                                                                                                              | Read         |
| [ListBridges](../../../mediaconnect/latest/api/API_ListBridges.md "../../../mediaconnect/latest/api/API_ListBridges.md")                                                 | Display a list of bridges that are associated with this account and an optionally specified Arn                                                   | List         |
| [ListEntitlements](../../../mediaconnect/latest/api/API_ListEntitlements.md "../../../mediaconnect/latest/api/API_ListEntitlements.md")                                  | Display a list of all entitlements that have been granted to the account                                                                          | List         |
| [ListFlows](../../../mediaconnect/latest/api/API_ListFlows.md "../../../mediaconnect/latest/api/API_ListFlows.md")                                                       | Display a list of flows that are associated with this account                                                                                     | List         |
| [ListGatewayInstances](../../../mediaconnect/latest/api/API_ListGatewayInstances.md "../../../mediaconnect/latest/api/API_ListGatewayInstances.md")                      | Display a list of instances that are associated with this gateway                                                                                 | List         |
| [ListGateways](../../../mediaconnect/latest/api/API_ListGateways.md "../../../mediaconnect/latest/api/API_ListGateways.md")                                              | Display a list of gateways that are associated with this account                                                                                  | List         |
| [ListOfferings](../../../mediaconnect/latest/api/API_ListOfferings.md "../../../mediaconnect/latest/api/API_ListOfferings.md")                                           | Display a list of all offerings that are available to the account in the current AWS Region                                                       | List         |
| [ListReservations](../../../mediaconnect/latest/api/API_ListReservations.md "../../../mediaconnect/latest/api/API_ListReservations.md")                                  | Display a list of all reservations that have been purchased by the account in the current AWS Region                                              | List         |
| [ListTagsForResource](../../../mediaconnect/latest/api/API_ListTagsForResource.md "../../../mediaconnect/latest/api/API_ListTagsForResource.md")                         | Display a list of all tags associated with a resource                                                                                             | Read         |
