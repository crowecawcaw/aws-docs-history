# Data retrieval APIs for AWS IoT Analytics

AWS IoT Analytics provides the following APIs for data retrieval.

| Actions                                                                                                                                                                     | Description                                                       | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------ |
| [DescribeChannel](../../../iotanalytics/latest/APIReference/API_DescribeChannel.md "../../../iotanalytics/latest/APIReference/API_DescribeChannel.md")                      | Describes the specified channel                                   | Read         |
| [DescribeDataset](../../../iotanalytics/latest/APIReference/API_DescribeDataset.md "../../../iotanalytics/latest/APIReference/API_DescribeDataset.md")                      | Describes the specified dataset                                   | Read         |
| [DescribeDatastore](../../../iotanalytics/latest/APIReference/API_DescribeDatastore.md "../../../iotanalytics/latest/APIReference/API_DescribeDatastore.md")                | Describes the specified datastore                                 | Read         |
| [DescribeLoggingOptions](../../../iotanalytics/latest/APIReference/API_DescribeLoggingOptions.md "../../../iotanalytics/latest/APIReference/API_DescribeLoggingOptions.md") | Describes logging options for the the account                     | Read         |
| [DescribePipeline](../../../iotanalytics/latest/APIReference/API_DescribePipeline.md "../../../iotanalytics/latest/APIReference/API_DescribePipeline.md")                   | Describes the specified pipeline                                  | Read         |
| [GetDatasetContent](../../../iotanalytics/latest/APIReference/API_GetDatasetContent.md "../../../iotanalytics/latest/APIReference/API_GetDatasetContent.md")                | Gets the content of the specified dataset                         | Read         |
| [ListChannels](../../../iotanalytics/latest/APIReference/API_ListChannels.md "../../../iotanalytics/latest/APIReference/API_ListChannels.md")                               | Lists the channels for the account                                | List         |
| [ListDatasetContents](../../../iotanalytics/latest/APIReference/API_ListDatasetContents.md "../../../iotanalytics/latest/APIReference/API_ListDatasetContents.md")          | Lists information about dataset contents that have been created   | List         |
| [ListDatasets](../../../iotanalytics/latest/APIReference/API_ListDatasets.md "../../../iotanalytics/latest/APIReference/API_ListDatasets.md")                               | Lists the datasets for the account                                | List         |
| [ListDatastores](../../../iotanalytics/latest/APIReference/API_ListDatastores.md "../../../iotanalytics/latest/APIReference/API_ListDatastores.md")                         | Lists the datastores for the account                              | List         |
| [ListPipelines](../../../iotanalytics/latest/APIReference/API_ListPipelines.md "../../../iotanalytics/latest/APIReference/API_ListPipelines.md")                            | Lists the pipelines for the account                               | List         |
| [ListTagsForResource](../../../iotanalytics/latest/APIReference/API_ListTagsForResource.md "../../../iotanalytics/latest/APIReference/API_ListTagsForResource.md")          | Lists the tags (metadata) which you have assigned to the resource | Read         |
| [RunPipelineActivity](../../../iotanalytics/latest/APIReference/API_RunPipelineActivity.md "../../../iotanalytics/latest/APIReference/API_RunPipelineActivity.md")          | Runs the specified pipeline activity                              | Read         |
| [SampleChannelData](../../../iotanalytics/latest/APIReference/API_SampleChannelData.md "../../../iotanalytics/latest/APIReference/API_SampleChannelData.md")                | Samples the specified channel's data                              | Read         |
