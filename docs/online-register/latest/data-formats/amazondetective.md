# Data retrieval APIs for Amazon Detective

Amazon Detective provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                | Description                                                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetGraphMemberDatasources](../../../detective/latest/APIReference/API_BatchGetGraphMemberDatasources.md "../../../detective/latest/APIReference/API_BatchGetGraphMemberDatasources.md")          | Retrieve the datasource package history for the specified member accounts in a behavior graph managed by this account                        | Read         |
| [BatchGetMembershipDatasources](../../../detective/latest/APIReference/API_BatchGetMembershipDatasources.md "../../../detective/latest/APIReference/API_BatchGetMembershipDatasources.md")             | Retrieve the datasource package history of the caller account for the specified graphs                                                       | Read         |
| [DescribeOrganizationConfiguration](../../../detective/latest/APIReference/API_DescribeOrganizationConfiguration.md "../../../detective/latest/APIReference/API_DescribeOrganizationConfiguration.md") | View the current configuration related to the Amazon Detective integration with AWS Organizations                                            | Read         |
| [GetFreeTrialEligibility](../../../detective/latest/adminguide/free-trial-overview.md "../../../detective/latest/adminguide/free-trial-overview.md")                                                   | Retrieve a behavior graph's eligibility for a free trial period                                                                              | Read         |
| [GetGraphIngestState](../../../detective/latest/adminguide/detective-source-data-about.md "../../../detective/latest/adminguide/detective-source-data-about.md")                                       | Retrieve the data ingestion state of a behavior graph                                                                                        | Read         |
| [GetInvestigation](../../../detective/latest/APIReference/API_GetInvestigation.md "../../../detective/latest/APIReference/API_GetInvestigation.md")                                                    | Get an investigation's status and metadata                                                                                                   | Read         |
| [GetMembers](../../../detective/latest/APIReference/API_GetMembers.md "../../../detective/latest/APIReference/API_GetMembers.md")                                                                      | Retrieve details on specified members of a behavior graph                                                                                    | Read         |
| [GetPricingInformation](../../../detective/latest/adminguide/usage-projected-cost-calculation.md "../../../detective/latest/adminguide/usage-projected-cost-calculation.md")                           | Retrieve information about Amazon Detective's pricing                                                                                        | Read         |
| [GetUsageInformation](../../../detective/latest/adminguide/tracking-usage-logging.md "../../../detective/latest/adminguide/tracking-usage-logging.md")                                                 | List usage information of a behavior graph                                                                                                   | Read         |
| [InvokeAssistant](../../../detective/latest/userguide/finding-groups-summary.md "../../../detective/latest/userguide/finding-groups-summary.md")                                                       | Invoke Detective's Assistant                                                                                                                 | Read         |
| [ListDatasourcePackages](../../../detective/latest/APIReference/API_ListDatasourcePackages.md "../../../detective/latest/APIReference/API_ListDatasourcePackages.md")                                  | List a graph's datasource package ingest states and timestamps for the most recent state changes in a behavior graph managed by this account | List         |
| [ListGraphs](../../../detective/latest/APIReference/API_ListGraphs.md "../../../detective/latest/APIReference/API_ListGraphs.md")                                                                      | List behavior graphs managed by this account                                                                                                 | List         |
| [ListHighDegreeEntities](../../../detective/latest/userguide/high-volume-entities.md "../../../detective/latest/userguide/high-volume-entities.md")                                                    | Retrieve high volume entities whose relationships cannot be stored by Detective                                                              | List         |
| [ListIndicators](../../../detective/latest/APIReference/API_ListIndicators.md "../../../detective/latest/APIReference/API_ListIndicators.md")                                                          | List the indicators of an investigation                                                                                                      | List         |
| [ListInvestigations](../../../detective/latest/APIReference/API_ListInvestigations.md "../../../detective/latest/APIReference/API_ListInvestigations.md")                                              | List the investigations of a behavior graph                                                                                                  | List         |
| [ListInvitations](../../../detective/latest/APIReference/API_ListInvitations.md "../../../detective/latest/APIReference/API_ListInvitations.md")                                                       | Retrieve details on the behavior graphs to which this account has been invited to join                                                       | List         |
| [ListMembers](../../../detective/latest/APIReference/API_ListMembers.md "../../../detective/latest/APIReference/API_ListMembers.md")                                                                   | Retrieve details on all members of a behavior graph                                                                                          | List         |
| [ListOrganizationAdminAccount](../../../detective/latest/APIReference/API_ListOrganizationAdminAccounts.md "../../../detective/latest/APIReference/API_ListOrganizationAdminAccounts.md")              | View the current Amazon Detective delegated administrator account for an organization                                                        | List         |
| [ListTagsForResource](../../../detective/latest/APIReference/API_ListTagsForResource.md "../../../detective/latest/APIReference/API_ListTagsForResource.md")                                           | List the tag values that are assigned to a behavior graph                                                                                    | List         |
| [SearchGraph](../../../detective/latest/userguide/detective-search.md "../../../detective/latest/userguide/detective-search.md")                                                                       | Search the data stored in a behavior graph                                                                                                   | Read         |
