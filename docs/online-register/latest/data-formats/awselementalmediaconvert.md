# Data retrieval APIs for AWS Elemental MediaConvert

AWS Elemental MediaConvert provides the following APIs for data retrieval.

| Actions                                                                                                                                           | Description                                                                                                                                                                                | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeEndpoints](../../../mediaconvert/latest/apireference/endpoints.md "../../../mediaconvert/latest/apireference/endpoints.md")              | Subscribe to the AWS Elemental MediaConvert service, by sending a request for an account-specific endpoint. All transcoding requests must be sent to the endpoint that the service returns | List         |
| [GetJob](../../../mediaconvert/latest/apireference/jobs-id.md "../../../mediaconvert/latest/apireference/jobs-id.md")                             | Get an AWS Elemental MediaConvert job                                                                                                                                                      | Read         |
| [GetJobTemplate](../../../mediaconvert/latest/apireference/jobtemplates-name.md "../../../mediaconvert/latest/apireference/jobtemplates-name.md") | Get an AWS Elemental MediaConvert job template                                                                                                                                             | Read         |
| [GetPolicy](../../../mediaconvert/latest/apireference/policy.md "../../../mediaconvert/latest/apireference/policy.md")                            | Get an AWS Elemental MediaConvert policy                                                                                                                                                   | Read         |
| [GetPreset](../../../mediaconvert/latest/apireference/presets-name.md "../../../mediaconvert/latest/apireference/presets-name.md")                | Get an AWS Elemental MediaConvert output preset                                                                                                                                            | Read         |
| [GetQueue](../../../mediaconvert/latest/apireference/queues-name.md "../../../mediaconvert/latest/apireference/queues-name.md")                   | Get an AWS Elemental MediaConvert job queue                                                                                                                                                | Read         |
| [ListJobTemplates](../../../mediaconvert/latest/apireference/jobtemplates.md "../../../mediaconvert/latest/apireference/jobtemplates.md")         | List AWS Elemental MediaConvert job templates                                                                                                                                              | List         |
| [ListJobs](../../../mediaconvert/latest/apireference/jobs.md "../../../mediaconvert/latest/apireference/jobs.md")                                 | List AWS Elemental MediaConvert jobs                                                                                                                                                       | List         |
| [ListPresets](../../../mediaconvert/latest/apireference/presets.md "../../../mediaconvert/latest/apireference/presets.md")                        | List AWS Elemental MediaConvert output presets                                                                                                                                             | List         |
| [ListQueues](../../../mediaconvert/latest/apireference/queues.md "../../../mediaconvert/latest/apireference/queues.md")                           | List AWS Elemental MediaConvert job queues                                                                                                                                                 | List         |
| [ListTagsForResource](../../../mediaconvert/latest/apireference/tags-arn.md "../../../mediaconvert/latest/apireference/tags-arn.md")              | Retrieve the tags for a MediaConvert queue, preset, or job template                                                                                                                        | Read         |
| [ListVersions](../../../mediaconvert/latest/apireference/versions.md "../../../mediaconvert/latest/apireference/versions.md")                     | List AWS Elemental MediaConvert job engine versions                                                                                                                                        | List         |
| [Probe](../../../mediaconvert/latest/apireference/probe.md "../../../mediaconvert/latest/apireference/probe.md")                                  | Probe a file                                                                                                                                                                               | Read         |
| [SearchJobs](../../../mediaconvert/latest/apireference/search.md "../../../mediaconvert/latest/apireference/search.md")                           | Search AWS Elemental MediaConvert jobs                                                                                                                                                     | List         |
