

# Data retrieval APIs for AWS Elemental MediaConvert
<a name="awselementalmediaconvert"></a>

AWS Elemental MediaConvert provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mediaconvert-DescribeEndpoints"></a>[DescribeEndpoints](https://docs.aws.amazon.com/mediaconvert/latest/apireference/endpoints.html) | Subscribe to the AWS Elemental MediaConvert service, by sending a request for an account-specific endpoint. All transcoding requests must be sent to the endpoint that the service returns | List | 
| <a name="mediaconvert-GetJob"></a>[GetJob](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs-id.html) | Get an AWS Elemental MediaConvert job | Read | 
| <a name="mediaconvert-GetJobTemplate"></a>[GetJobTemplate](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates-name.html) | Get an AWS Elemental MediaConvert job template | Read | 
| <a name="mediaconvert-GetPolicy"></a>[GetPolicy](https://docs.aws.amazon.com/mediaconvert/latest/apireference/policy.html) | Get an AWS Elemental MediaConvert policy | Read | 
| <a name="mediaconvert-GetPreset"></a>[GetPreset](https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets-name.html) | Get an AWS Elemental MediaConvert output preset | Read | 
| <a name="mediaconvert-GetQueue"></a>[GetQueue](https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues-name.html) | Get an AWS Elemental MediaConvert job queue | Read | 
| <a name="mediaconvert-ListJobTemplates"></a>[ListJobTemplates](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates.html) | List AWS Elemental MediaConvert job templates | List | 
| <a name="mediaconvert-ListJobs"></a>[ListJobs](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs.html) | List AWS Elemental MediaConvert jobs | List | 
| <a name="mediaconvert-ListPresets"></a>[ListPresets](https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets.html) | List AWS Elemental MediaConvert output presets | List | 
| <a name="mediaconvert-ListQueues"></a>[ListQueues](https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues.html) | List AWS Elemental MediaConvert job queues | List | 
| <a name="mediaconvert-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/mediaconvert/latest/apireference/tags-arn.html) | Retrieve the tags for a MediaConvert queue, preset, or job template | Read | 
| <a name="mediaconvert-ListVersions"></a>[ListVersions](https://docs.aws.amazon.com/mediaconvert/latest/apireference/versions.html) | List AWS Elemental MediaConvert job engine versions | List | 
| <a name="mediaconvert-Probe"></a>[Probe](https://docs.aws.amazon.com/mediaconvert/latest/apireference/probe.html) | Probe a file | Read | 
| <a name="mediaconvert-SearchJobs"></a>[SearchJobs](https://docs.aws.amazon.com/mediaconvert/latest/apireference/search.html) | Search AWS Elemental MediaConvert jobs | List |
