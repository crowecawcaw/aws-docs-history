

# Data retrieval APIs for AWS Billing and Cost Management Dashboards
<a name="awsbillingandcostmanagementdashboards"></a>

AWS Billing and Cost Management Dashboards provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="bcm-dashboards-GetDashboard"></a>[GetDashboard](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_GetDashboard.html) | Get dashboard information | Read | 
| <a name="bcm-dashboards-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_GetResourcePolicy.html) | Get the resource policy for a dashboard | Read | 
| <a name="bcm-dashboards-GetScheduledReport"></a>[GetScheduledReport](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_GetScheduledReport.html) | Get scheduled report information | Read | 
| <a name="bcm-dashboards-ListDashboards"></a>[ListDashboards](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_ListDashboards.html) | List information about all of the dashboards for a user | Read | 
| <a name="bcm-dashboards-ListScheduledReports"></a>[ListScheduledReports](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_ListScheduledReports.html) | List information about all of the scheduled reports for a user | List | 
| <a name="bcm-dashboards-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_bcmDashboards_ListTagsForResource.html) | List all of the tags for a resource | Read |
