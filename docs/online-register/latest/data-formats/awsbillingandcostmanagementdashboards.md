# Data retrieval APIs for AWS Billing and Cost Management Dashboards

AWS Billing and Cost Management Dashboards provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                      | Description                                             | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- | ------------ |
| [GetDashboard](../../../aws-cost-management/latest/APIReference/API_bcmDashboards_GetDashboard.md "../../../aws-cost-management/latest/APIReference/API_bcmDashboards_GetDashboard.md")                      | Get dashboard information                               | Read         |
| [GetResourcePolicy](../../../aws-cost-management/latest/APIReference/API_bcmDashboards_GetResourcePolicy.md "../../../aws-cost-management/latest/APIReference/API_bcmDashboards_GetResourcePolicy.md")       | Get the resource policy for a dashboard                 | Read         |
| [ListDashboards](../../../aws-cost-management/latest/APIReference/API_bcmDashboards_ListDashboards.md "../../../aws-cost-management/latest/APIReference/API_bcmDashboards_ListDashboards.md")                | List information about all of the dashboards for a user | Read         |
| [ListTagsForResource](../../../aws-cost-management/latest/APIReference/API_bcmDashboards_ListTagsForResource.md "../../../aws-cost-management/latest/APIReference/API_bcmDashboards_ListTagsForResource.md") | List all of the tags for a resource                     | Read         |
