| [GetHost](../../../codeconnections/latest/APIReference/API_GetHost.md "../../../codeconnections/latest/APIReference/API_GetHost.md")                                                                                                           | Get details about a host resource                                                                                                           | Read         |

| [GetSyncBlockerSummary](../../../codeconnections/latest/APIReference/API_GetSyncBlockerSummary.md "../../../codeconnections/latest/APIReference/API_GetSyncBlockerSummary.md")                                                                 | Describe service sync blockers on a resource (cfn stack or other resources)                                                                 | Read         |
| [GetSyncConfiguration](../../../codeconnections/latest/APIReference/API_GetSyncConfiguration.md "../../../codeconnections/latest/APIReference/API_GetSyncConfiguration.md")                                                                    | Describe a sync configuration                                                                                                               | Read         |
