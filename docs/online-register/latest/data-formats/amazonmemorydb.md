# Data retrieval APIs for Amazon MemoryDB

Amazon MemoryDB provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                       | Description                                                                                                                                                                                    | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAcls](../../../memorydb/latest/APIReference/API_DescribeAcls.md "../../../memorydb/latest/APIReference/API_DescribeAcls.md")                                                                         | Grants permissions to retrieve information about access control lists                                                                                                                          | Read         |
| [DescribeClusters](../../../memorydb/latest/APIReference/API_DescribeClusters.md "../../../memorydb/latest/APIReference/API_DescribeClusters.md")                                                             | Grants permissions to retrieve information about all provisioned clusters if no cluster identifier is specified, or about a specific cluster if a cluster identifier is supplied               | Read         |
| [DescribeEngineVersions](../../../memorydb/latest/APIReference/API_DescribeEngineVersions.md "../../../memorydb/latest/APIReference/API_DescribeEngineVersions.md")                                           | Grants permissions to list of the available engines and their versions                                                                                                                         | Read         |
| [DescribeEvents](../../../memorydb/latest/APIReference/API_DescribeEvents.md "../../../memorydb/latest/APIReference/API_DescribeEvents.md")                                                                   | Grants permissions to retrieve events related to clusters, subnet groups, and parameter groups                                                                                                 | Read         |
| [DescribeMultiRegionClusters](../../../memorydb/latest/APIReference/API_DescribeMultiRegionClusters.md "../../../memorydb/latest/APIReference/API_DescribeMultiRegionClusters.md")                            | Grants permissions to retrieve information about all Multi-Region clusters if no cluster identifier is specified, or about a specific Multi-Region cluster if a cluster identifier is supplied | Read         |
| [DescribeMultiRegionParameterGroups](../../../memorydb/latest/APIReference/API_DescribeMultiRegionParameterGroups.md "../../../memorydb/latest/APIReference/API_DescribeMultiRegionParameterGroups.md")       | Grants permissions to retrieve information about Multi-Region parameter groups                                                                                                                 | Read         |
| [DescribeMultiRegionParameters](../../../memorydb/latest/APIReference/API_DescribeMultiRegionParameters.md "../../../memorydb/latest/APIReference/API_DescribeMultiRegionParameters.md")                      | Grants permissions to retrieve a detailed parameter list for a particular Multi-Region parameter group                                                                                         | Read         |
| [DescribeParameterGroups](../../../memorydb/latest/APIReference/API_DescribeParameterGroups.md "../../../memorydb/latest/APIReference/API_DescribeParameterGroups.md")                                        | Grants permissions to retrieve information about parameter groups                                                                                                                              | Read         |
| [DescribeParameters](../../../memorydb/latest/APIReference/API_DescribeParameters.md "../../../memorydb/latest/APIReference/API_DescribeParameters.md")                                                       | Grants permissions to retrieve a detailed parameter list for a particular parameter group                                                                                                      | Read         |
| [DescribeReservedNodes](../../../memorydb/latest/APIReference/API_DescribeReservedNodes.md "../../../memorydb/latest/APIReference/API_DescribeReservedNodes.md")                                              | Grants permissions to retrieve reserved nodes                                                                                                                                                  | Read         |
| [DescribeReservedNodesOfferings](../../../memorydb/latest/APIReference/API_DescribeReservedNodesOfferings.md "../../../memorydb/latest/APIReference/API_DescribeReservedNodesOfferings.md")                   | Grants permissions to retrieve reserved nodes offerings                                                                                                                                        | Read         |
| [DescribeServiceUpdates](../../../memorydb/latest/APIReference/API_DescribeServiceUpdates.md "../../../memorydb/latest/APIReference/API_DescribeServiceUpdates.md")                                           | Grants permissions to retrieve details of the service updates                                                                                                                                  | Read         |
| [DescribeSnapshots](../../../memorydb/latest/APIReference/API_DescribeSnapshots.md "../../../memorydb/latest/APIReference/API_DescribeSnapshots.md")                                                          | Grants permissions to retrieve information about cluster snapshots                                                                                                                             | Read         |
| [DescribeSubnetGroups](../../../memorydb/latest/APIReference/API_DescribeSubnetGroups.md "../../../memorydb/latest/APIReference/API_DescribeSubnetGroups.md")                                                 | Grants permissions to retrieve a list of subnet group                                                                                                                                          | Read         |
| [DescribeUsers](../../../memorydb/latest/APIReference/API_DescribeUsers.md "../../../memorydb/latest/APIReference/API_DescribeUsers.md")                                                                      | Grants permissions to retrieve information about users                                                                                                                                         | Read         |
| [ListAllowedMultiRegionClusterUpdates](../../../memorydb/latest/APIReference/API_ListAllowedMultiRegionClusterUpdates.md "../../../memorydb/latest/APIReference/API_ListAllowedMultiRegionClusterUpdates.md") | Grants permissions to list available Multi-Region cluster updates                                                                                                                              | Read         |
| [ListAllowedNodeTypeUpdates](../../../memorydb/latest/APIReference/API_ListAllowedNodeTypeUpdates.md "../../../memorydb/latest/APIReference/API_ListAllowedNodeTypeUpdates.md")                               | Grants permissions to list available node type updates                                                                                                                                         | Read         |
| [ListTags](../../../memorydb/latest/APIReference/API_ListTags.md "../../../memorydb/latest/APIReference/API_ListTags.md")                                                                                     | Grants permissions to list cost allocation tags                                                                                                                                                | Read         |
