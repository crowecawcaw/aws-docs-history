

# Data retrieval APIs for Amazon MemoryDB
<a name="amazonmemorydb"></a>

Amazon MemoryDB provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="memorydb-DescribeAcls"></a>[DescribeAcls](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeAcls.html) | Grants permissions to retrieve information about access control lists | Read | 
| <a name="memorydb-DescribeClusters"></a>[DescribeClusters](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeClusters.html) | Grants permissions to retrieve information about all provisioned clusters if no cluster identifier is specified, or about a specific cluster if a cluster identifier is supplied | Read | 
| <a name="memorydb-DescribeEngineVersions"></a>[DescribeEngineVersions](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeEngineVersions.html) | Grants permissions to list of the available engines and their versions | Read | 
| <a name="memorydb-DescribeEvents"></a>[DescribeEvents](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeEvents.html) | Grants permissions to retrieve events related to clusters, subnet groups, and parameter groups | Read | 
| <a name="memorydb-DescribeMultiRegionClusters"></a>[DescribeMultiRegionClusters](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeMultiRegionClusters.html) | Grants permissions to retrieve information about all Multi-Region clusters if no cluster identifier is specified, or about a specific Multi-Region cluster if a cluster identifier is supplied | Read | 
| <a name="memorydb-DescribeMultiRegionParameterGroups"></a>[DescribeMultiRegionParameterGroups](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeMultiRegionParameterGroups.html) | Grants permissions to retrieve information about Multi-Region parameter groups | Read | 
| <a name="memorydb-DescribeMultiRegionParameters"></a>[DescribeMultiRegionParameters](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeMultiRegionParameters.html) | Grants permissions to retrieve a detailed parameter list for a particular Multi-Region parameter group | Read | 
| <a name="memorydb-DescribeParameterGroups"></a>[DescribeParameterGroups](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeParameterGroups.html) | Grants permissions to retrieve information about parameter groups | Read | 
| <a name="memorydb-DescribeParameters"></a>[DescribeParameters](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeParameters.html) | Grants permissions to retrieve a detailed parameter list for a particular parameter group | Read | 
| <a name="memorydb-DescribeReservedNodes"></a>[DescribeReservedNodes](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeReservedNodes.html) | Grants permissions to retrieve reserved nodes | Read | 
| <a name="memorydb-DescribeReservedNodesOfferings"></a>[DescribeReservedNodesOfferings](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeReservedNodesOfferings.html) | Grants permissions to retrieve reserved nodes offerings | Read | 
| <a name="memorydb-DescribeServiceUpdates"></a>[DescribeServiceUpdates](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeServiceUpdates.html) | Grants permissions to retrieve details of the service updates | Read | 
| <a name="memorydb-DescribeSnapshots"></a>[DescribeSnapshots](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeSnapshots.html) | Grants permissions to retrieve information about cluster snapshots | Read | 
| <a name="memorydb-DescribeSubnetGroups"></a>[DescribeSubnetGroups](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeSubnetGroups.html) | Grants permissions to retrieve a list of subnet group | Read | 
| <a name="memorydb-DescribeUsers"></a>[DescribeUsers](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_DescribeUsers.html) | Grants permissions to retrieve information about users | Read | 
| <a name="memorydb-ListAllowedMultiRegionClusterUpdates"></a>[ListAllowedMultiRegionClusterUpdates](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_ListAllowedMultiRegionClusterUpdates.html) | Grants permissions to list available Multi-Region cluster updates | Read | 
| <a name="memorydb-ListAllowedNodeTypeUpdates"></a>[ListAllowedNodeTypeUpdates](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_ListAllowedNodeTypeUpdates.html) | Grants permissions to list available node type updates | Read | 
| <a name="memorydb-ListTags"></a>[ListTags](https://docs.aws.amazon.com/memorydb/latest/APIReference/API_ListTags.html) | Grants permissions to list cost allocation tags | Read |
