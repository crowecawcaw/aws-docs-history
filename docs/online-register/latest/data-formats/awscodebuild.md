# Data retrieval APIs for AWS CodeBuild

AWS CodeBuild provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                             | Description                                                                                                                           | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetBuildBatches](../../../codebuild/latest/APIReference/API_BatchGetBuildBatches.md "../../../codebuild/latest/APIReference/API_BatchGetBuildBatches.md")                                                                                                     | Get information about one or more build batches                                                                                       | Read         |
| [BatchGetBuilds](../../../codebuild/latest/APIReference/API_BatchGetBuilds.md "../../../codebuild/latest/APIReference/API_BatchGetBuilds.md")                                                                                                                       | Get information about one or more builds                                                                                              | Read         |
| [BatchGetCommandExecutions](../../../codebuild/latest/APIReference/API_BatchGetCommandExecutions.md "../../../codebuild/latest/APIReference/API_BatchGetCommandExecutions.md")                                                                                      | Get information about one or more command executions                                                                                  | Read         |
| [BatchGetFleets](../../../codebuild/latest/APIReference/API_BatchGetFleets.md "../../../codebuild/latest/APIReference/API_BatchGetFleets.md")                                                                                                                       | Return an array of the Fleet objects specified by the input parameter                                                                 | Read         |
| [BatchGetProjects](../../../codebuild/latest/APIReference/API_BatchGetProjects.md "../../../codebuild/latest/APIReference/API_BatchGetProjects.md")                                                                                                                 | Get information about one or more build projects                                                                                      | Read         |
| [BatchGetReportGroups](../../../codebuild/latest/APIReference/API_BatchGetReportGroups.md "../../../codebuild/latest/APIReference/API_BatchGetReportGroups.md")                                                                                                     | Return an array of ReportGroup objects that are specified by the input reportGroupArns parameter                                      | Read         |
| [BatchGetReports](../../../codebuild/latest/APIReference/API_BatchGetReports.md "../../../codebuild/latest/APIReference/API_BatchGetReports.md")                                                                                                                    | Return an array of the Report objects specified by the input reportArns parameter                                                     | Read         |
| [BatchGetSandboxes](../../../codebuild/latest/APIReference/API_BatchGetSandboxes.md "../../../codebuild/latest/APIReference/API_BatchGetSandboxes.md")                                                                                                              | Get information about one or more sandboxes                                                                                           | Read         |
| [DescribeCodeCoverages](../../../codebuild/latest/APIReference/API_DescribeCodeCoverages.md "../../../codebuild/latest/APIReference/API_DescribeCodeCoverages.md")                                                                                                  | Return an array of CodeCoverage objects                                                                                               | Read         |
| [DescribeTestCases](../../../codebuild/latest/APIReference/API_DescribeTestCases.md "../../../codebuild/latest/APIReference/API_DescribeTestCases.md")                                                                                                              | Return an array of TestCase objects                                                                                                   | Read         |
| [GetReportGroupTrend](../../../codebuild/latest/APIReference/API_GetReportGroupTrend.md "../../../codebuild/latest/APIReference/API_GetReportGroupTrend.md")                                                                                                        | Analyze and accumulate test report values for the test reports in the specified report group                                          | Read         |
| [GetResourcePolicy](../../../codebuild/latest/APIReference/API_GetResourcePolicy.md "../../../codebuild/latest/APIReference/API_GetResourcePolicy.md")                                                                                                              | Return a resource policy for the specified project or report group                                                                    | Read         |
| [ListBuildBatches](../../../codebuild/latest/APIReference/API_ListBuildBatches.md "../../../codebuild/latest/APIReference/API_ListBuildBatches.md")                                                                                                                 | Get a list of build batch IDs, with each build batch ID representing a single build batch                                             | List         |
| [ListBuildBatchesForProject](../../../codebuild/latest/APIReference/API_ListBuildBatchesForProject.md "../../../codebuild/latest/APIReference/API_ListBuildBatchesForProject.md")                                                                                   | Get a list of build batch IDs for the specified build project, with each build batch ID representing a single build batch             | List         |
| [ListBuilds](../../../codebuild/latest/APIReference/API_ListBuilds.md "../../../codebuild/latest/APIReference/API_ListBuilds.md")                                                                                                                                   | Get a list of build IDs, with each build ID representing a single build                                                               | List         |
| [ListBuildsForProject](../../../codebuild/latest/APIReference/API_ListBuildsForProject.md "../../../codebuild/latest/APIReference/API_ListBuildsForProject.md")                                                                                                     | Get a list of build IDs for the specified build project, with each build ID representing a single build                               | List         |
| [ListCommandExecutionsForSandbox](../../../codebuild/latest/APIReference/API_ListCommandExecutionsForSandbox.md "../../../codebuild/latest/APIReference/API_ListCommandExecutionsForSandbox.md")                                                                    | Get a list of command execution IDs for the specified sandbox, with each command execution ID representing a single command execution | List         |
| [ListConnectedOAuthAccounts](../../../codebuild/latest/userguide/auth-and-access-control-iam-identity-based-access-control.md#console-policies "../../../codebuild/latest/userguide/auth-and-access-control-iam-identity-based-access-control.md#console-policies") | List connected third-party OAuth providers. Only used in the AWS CodeBuild console                                                    | List         |
| [ListCuratedEnvironmentImages](../../../codebuild/latest/APIReference/API_ListCuratedEnvironmentImages.md "../../../codebuild/latest/APIReference/API_ListCuratedEnvironmentImages.md")                                                                             | Get information about Docker images that are managed by AWS CodeBuild                                                                 | List         |
| [ListFleets](../../../codebuild/latest/APIReference/API_ListFleets.md "../../../codebuild/latest/APIReference/API_ListFleets.md")                                                                                                                                   | Get a list of compute fleet ARNs, with each compute fleet ARN representing a single fleet                                             | List         |
| [ListProjects](../../../codebuild/latest/APIReference/API_ListProjects.md "../../../codebuild/latest/APIReference/API_ListProjects.md")                                                                                                                             | Get a list of build project names, with each build project name representing a single build project                                   | List         |
| [ListReportGroups](../../../codebuild/latest/APIReference/API_ListReportGroups.md "../../../codebuild/latest/APIReference/API_ListReportGroups.md")                                                                                                                 | Return a list of report group ARNs. Each report group ARN represents one report group                                                 | List         |
| [ListReports](../../../codebuild/latest/APIReference/API_ListReports.md "../../../codebuild/latest/APIReference/API_ListReports.md")                                                                                                                                | Return a list of report ARNs. Each report ARN representing one report                                                                 | List         |
| [ListReportsForReportGroup](../../../codebuild/latest/APIReference/API_ListReportsForReportGroup.md "../../../codebuild/latest/APIReference/API_ListReportsForReportGroup.md")                                                                                      | Return a list of report ARNs that belong to the specified report group. Each report ARN represents one report                         | List         |
| [ListRepositories](../../../codebuild/latest/userguide/auth-and-access-control-iam-identity-based-access-control.md#console-policies "../../../codebuild/latest/userguide/auth-and-access-control-iam-identity-based-access-control.md#console-policies")           | List source code repositories from a connected third-party OAuth provider. Only used in the AWS CodeBuild console                     | List         |
| [ListSandboxes](../../../codebuild/latest/APIReference/API_ListSandboxes.md "../../../codebuild/latest/APIReference/API_ListSandboxes.md")                                                                                                                          | Get a list of sandbox IDs, with each sandbox ID representing a single sandbox                                                         | List         |
| [ListSandboxesForProject](../../../codebuild/latest/APIReference/API_ListSandboxesForProject.md "../../../codebuild/latest/APIReference/API_ListSandboxesForProject.md")                                                                                            | Get a list of sandbox IDs for the specified sandbox project, with each sandbox ID representing a single sandbox                       | List         |
| [ListSharedProjects](../../../codebuild/latest/APIReference/API_ListSharedProjects.md "../../../codebuild/latest/APIReference/API_ListSharedProjects.md")                                                                                                           | Return a list of project ARNs that have been shared with the requester. Each project ARN represents one project                       | List         |
| [ListSharedReportGroups](../../../codebuild/latest/APIReference/API_ListSharedReportGroups.md "../../../codebuild/latest/APIReference/API_ListSharedReportGroups.md")                                                                                               | Return a list of report group ARNs that have been shared with the requester. Each report group ARN represents one report group        | List         |
| [ListSourceCredentials](../../../codebuild/latest/APIReference/API_ListSourceCredentials.md "../../../codebuild/latest/APIReference/API_ListSourceCredentials.md")                                                                                                  | Return a list of SourceCredentialsInfo objects                                                                                        | List         |
