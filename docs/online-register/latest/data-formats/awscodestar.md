# Data retrieval APIs for AWS CodeStar

AWS CodeStar provides the following APIs for data retrieval.

| Actions                                                                                                                                                    | Description                                                                   | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------ |
| [DescribeProject](../../../codestar/latest/APIReference/API_DescribeProject.md "../../../codestar/latest/APIReference/API_DescribeProject.md")             | Describe a project and its resources                                          | Read         |
| [DescribeUserProfile](../../../codestar/latest/APIReference/API_DescribeUserProfile.md "../../../codestar/latest/APIReference/API_DescribeUserProfile.md") | Describe a user in AWS CodeStar and the user attributes across all projects   | Read         |
| GetExtendedAccess                                                                                                                                          | Extended read APIs                                                            | Read         |
| [ListProjects](../../../codestar/latest/APIReference/API_ListProjects.md "../../../codestar/latest/APIReference/API_ListProjects.md")                      | List all projects in CodeStar associated with your AWS account                | List         |
| [ListResources](../../../codestar/latest/APIReference/API_ListResources.md "../../../codestar/latest/APIReference/API_ListResources.md")                   | List all resources associated with a project in CodeStar                      | List         |
| [ListTagsForProject](../../../codestar/latest/APIReference/API_ListTagsForProject.md "../../../codestar/latest/APIReference/API_ListTagsForProject.md")    | List the tags associated with a project in CodeStar                           | List         |
| [ListTeamMembers](../../../codestar/latest/APIReference/API_ListTeamMembers.md "../../../codestar/latest/APIReference/API_ListTeamMembers.md")             | List all team members associated with a project                               | List         |
| [ListUserProfiles](../../../codestar/latest/APIReference/API_ListUserProfiles.md "../../../codestar/latest/APIReference/API_ListUserProfiles.md")          | List user profiles in AWS CodeStar                                            | List         |
| VerifyServiceRole                                                                                                                                          | Verify whether the AWS CodeStar service role exists in the customer's account | List         |
