

# Data retrieval APIs for Amazon CloudSearch
<a name="amazoncloudsearch"></a>

Amazon CloudSearch provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="cloudsearch-DescribeAnalysisSchemes"></a>[DescribeAnalysisSchemes](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeAnalysisSchemes.html) | Gets the analysis schemes configured for a domain | Read | 
| <a name="cloudsearch-DescribeAvailabilityOptions"></a>[DescribeAvailabilityOptions](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeAvailabilityOptions.html) | Gets the availability options configured for a domain | Read | 
| <a name="cloudsearch-DescribeDomainEndpointOptions"></a>[DescribeDomainEndpointOptions](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeDomainEndpointOptions.html) | Gets the domain endpoint options configured for a domain | Read | 
| <a name="cloudsearch-DescribeDomains"></a>[DescribeDomains](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeDomains.html) | Gets information about the search domains owned by this account | List | 
| <a name="cloudsearch-DescribeExpressions"></a>[DescribeExpressions](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeExpressions.html) | Gets the expressions configured for the search domain | Read | 
| <a name="cloudsearch-DescribeIndexFields"></a>[DescribeIndexFields](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeIndexFields.html) | Gets information about the index fields configured for the search domain | Read | 
| <a name="cloudsearch-DescribeScalingParameters"></a>[DescribeScalingParameters](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeScalingParameters.html) | Gets the scaling parameters configured for a domain | Read | 
| <a name="cloudsearch-DescribeServiceAccessPolicies"></a>[DescribeServiceAccessPolicies](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeServiceAccessPolicies.html) | Gets information about the access policies that control access to the domain's document and search endpoints | Read | 
| <a name="cloudsearch-DescribeSuggesters"></a>[DescribeSuggesters](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_DescribeSuggesters.html) | Gets the suggesters configured for a domain | Read | 
| <a name="cloudsearch-ListDomainNames"></a>[ListDomainNames](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_ListDomainNames.html) | Lists all search domains owned by an account | List | 
| <a name="cloudsearch-ListTags"></a>[ListTags](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/API_ListTags.html) | Displays all of the resource tags for an Amazon CloudSearch domain | Read | 
| <a name="cloudsearch-search"></a>[search](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/configuring-access.html#cloudsearch-actions) | Allows access to the search operations | Read | 
| <a name="cloudsearch-suggest"></a>[suggest](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/configuring-access.html#cloudsearch-actions) | Allows access to the suggest operations | Read |
