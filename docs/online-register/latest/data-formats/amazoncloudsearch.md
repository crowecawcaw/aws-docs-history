# Data retrieval APIs for Amazon CloudSearch

Amazon CloudSearch provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                            | Description                                                                                                  | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeAnalysisSchemes](../../../cloudsearch/latest/developerguide/API_DescribeAnalysisSchemes.md "../../../cloudsearch/latest/developerguide/API_DescribeAnalysisSchemes.md")                   | Gets the analysis schemes configured for a domain                                                            | Read         |
| [DescribeAvailabilityOptions](../../../cloudsearch/latest/developerguide/API_DescribeAvailabilityOptions.md "../../../cloudsearch/latest/developerguide/API_DescribeAvailabilityOptions.md")       | Gets the availability options configured for a domain                                                        | Read         |
| [DescribeDomainEndpointOptions](../../../cloudsearch/latest/developerguide/API_DescribeDomainEndpointOptions.md "../../../cloudsearch/latest/developerguide/API_DescribeDomainEndpointOptions.md") | Gets the domain endpoint options configured for a domain                                                     | Read         |
| [DescribeDomains](../../../cloudsearch/latest/developerguide/API_DescribeDomains.md "../../../cloudsearch/latest/developerguide/API_DescribeDomains.md")                                           | Gets information about the search domains owned by this account                                              | List         |
| [DescribeExpressions](../../../cloudsearch/latest/developerguide/API_DescribeExpressions.md "../../../cloudsearch/latest/developerguide/API_DescribeExpressions.md")                               | Gets the expressions configured for the search domain                                                        | Read         |
| [DescribeIndexFields](../../../cloudsearch/latest/developerguide/API_DescribeIndexFields.md "../../../cloudsearch/latest/developerguide/API_DescribeIndexFields.md")                               | Gets information about the index fields configured for the search domain                                     | Read         |
| [DescribeScalingParameters](../../../cloudsearch/latest/developerguide/API_DescribeScalingParameters.md "../../../cloudsearch/latest/developerguide/API_DescribeScalingParameters.md")             | Gets the scaling parameters configured for a domain                                                          | Read         |
| [DescribeServiceAccessPolicies](../../../cloudsearch/latest/developerguide/API_DescribeServiceAccessPolicies.md "../../../cloudsearch/latest/developerguide/API_DescribeServiceAccessPolicies.md") | Gets information about the access policies that control access to the domain's document and search endpoints | Read         |
| [DescribeSuggesters](../../../cloudsearch/latest/developerguide/API_DescribeSuggesters.md "../../../cloudsearch/latest/developerguide/API_DescribeSuggesters.md")                                  | Gets the suggesters configured for a domain                                                                  | Read         |
| [ListDomainNames](../../../cloudsearch/latest/developerguide/API_ListDomainNames.md "../../../cloudsearch/latest/developerguide/API_ListDomainNames.md")                                           | Lists all search domains owned by an account                                                                 | List         |
| [ListTags](../../../cloudsearch/latest/developerguide/API_ListTags.md "../../../cloudsearch/latest/developerguide/API_ListTags.md")                                                                | Displays all of the resource tags for an Amazon CloudSearch domain                                           | Read         |
| [search](../../../cloudsearch/latest/developerguide/configuring-access.md#cloudsearch-actions "../../../cloudsearch/latest/developerguide/configuring-access.md#cloudsearch-actions")              | Allows access to the search operations                                                                       | Read         |
| [suggest](../../../cloudsearch/latest/developerguide/configuring-access.md#cloudsearch-actions "../../../cloudsearch/latest/developerguide/configuring-access.md#cloudsearch-actions")             | Allows access to the suggest operations                                                                      | Read         |
