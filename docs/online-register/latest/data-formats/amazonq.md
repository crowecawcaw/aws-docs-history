| [BatchGetUsers](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")               | Get multiple users for an Amazon Q Developer Profile                          | Read         |
| [GenerateCodeFromCommands](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")    | Generate code from CLI commands in Amazon Q                                   | Read         |
