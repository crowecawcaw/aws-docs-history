# Data retrieval APIs for Amazon Q

Amazon Q provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                              | Description                                                                   | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------ |
| [GenerateCodeFromCommands](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")    | Generate code from CLI commands in Amazon Q                                   | Read         |
| [GenerateCodeRecommendations](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md") | Generate code recommendations in Amazon Q                                     | Read         |
| [GetConnector](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")                | View information about a specific Amazon Q connector                          | Read         |
| [GetConversation](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")             | Get individual messages associated with a specific conversation with Amazon Q | Read         |
| [GetIdentityMetadata](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")         | Amazon Q to get the identity metadata                                         | Read         |
| [GetPlugin](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")                   | View information about a specific configured Amazon Q plugin                  | Read         |
| [GetTroubleshootingResults](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")   | Get troubleshooting results with Amazon Q                                     | Read         |
| [ListConversations](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")           | List individual conversations associated with a specific Amazon Q user        | Read         |
| [ListDashboardMetrics](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")        | Read metrics to populate Amazon Q dashboard                                   | List         |
| [ListPluginProviders](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")         | List available plugins in Amazon Q                                            | List         |
| [ListPlugins](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")                 | List configured plugins in Amazon Q                                           | List         |
| [ListTagsForResource](../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md "../../../amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.md")         | List all tags associated with an Amazon Q resource                            | List         |
