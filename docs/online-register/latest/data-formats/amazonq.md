

# Data retrieval APIs for Amazon Q
<a name="amazonq"></a>

Amazon Q provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="q-BatchDescribeGroups"></a>[BatchDescribeGroups](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Describe multiple groups for an Amazon Q Developer Profile | Read | 
| <a name="q-BatchDescribeUsers"></a>[BatchDescribeUsers](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Describe multiple users for an Amazon Q Developer Profile | Read | 
| <a name="q-BatchGetGroups"></a>[BatchGetGroups](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Get multiple groups for an Amazon Q Developer Profile | Read | 
| <a name="q-BatchGetUsers"></a>[BatchGetUsers](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Get multiple users for an Amazon Q Developer Profile | Read | 
| <a name="q-GenerateCodeFromCommands"></a>[GenerateCodeFromCommands](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Generate code from CLI commands in Amazon Q | Read | 
| <a name="q-GenerateCodeRecommendations"></a>[GenerateCodeRecommendations](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Generate code recommendations in Amazon Q | Read | 
| <a name="q-GetArtifact"></a>[GetArtifact](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | View an Amazon Q artifact | Read | 
| <a name="q-GetArtifactActionResult"></a>[GetArtifactActionResult](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | View results of an action in an Amazon Q artifact | Read | 
| <a name="q-GetConnector"></a>[GetConnector](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | View information about a specific Amazon Q connector | Read | 
| <a name="q-GetConversation"></a>[GetConversation](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Get individual messages associated with a specific conversation with Amazon Q | Read | 
| <a name="q-GetIdentityMetadata"></a>[GetIdentityMetadata](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Amazon Q to get the identity metadata | Read | 
| <a name="q-GetPlugin"></a>[GetPlugin](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | View information about a specific configured Amazon Q plugin | Read | 
| <a name="q-GetTroubleshootingResults"></a>[GetTroubleshootingResults](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Get troubleshooting results with Amazon Q | Read | 
| <a name="q-ListConversations"></a>[ListConversations](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List individual conversations associated with a specific Amazon Q user | Read | 
| <a name="q-ListDashboardMetrics"></a>[ListDashboardMetrics](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | Read metrics to populate Amazon Q dashboard | List | 
| <a name="q-ListGroups"></a>[ListGroups](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List groups for an Amazon Q Developer Profile | List | 
| <a name="q-ListLoginDomains"></a>[ListLoginDomains](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List login domains for an Amazon Q Developer Profile | List | 
| <a name="q-ListPluginProviders"></a>[ListPluginProviders](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List available plugins in Amazon Q | List | 
| <a name="q-ListPlugins"></a>[ListPlugins](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List configured plugins in Amazon Q | List | 
| <a name="q-ListScimAccessTokens"></a>[ListScimAccessTokens](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List SCIM access tokens for an Amazon Q Developer Profile | List | 
| <a name="q-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List all tags associated with an Amazon Q resource | List | 
| <a name="q-ListUsers"></a>[ListUsers](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/security_iam_manage-access-with-policies.html) | List users for an Amazon Q Developer Profile | List |
