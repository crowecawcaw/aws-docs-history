# Data retrieval APIs for AWS Marketplace Vendor Insights

AWS Marketplace Vendor Insights provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                         | Description                                                                                          | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------ |
| [GetDataSource](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")                        | Retrieve the details of an existing data source                                                      | Read         |
| [GetEntitledSecurityProfileSnapshot](../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md "../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md")   | Return the details of a security profile snapshot that requester is entitled to read                 | Read         |
| [GetProfileAccessTerms](../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md "../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md")                | Get the access terms for a vendor insights profile                                                   | Read         |
| [GetSecurityProfile](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")                   | Return the details of an existing security profile                                                   | Read         |
| [GetSecurityProfileSnapshot](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")           | Return the details of a security profile snapshot                                                    | Read         |
| [ListDataSources](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")                      | List existing data sources                                                                           | List         |
| [ListEntitledSecurityProfileSnapshots](../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md "../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md") | Return the snapshot summary list for an existing security profile that requester is entitled to list | List         |
| [ListEntitledSecurityProfiles](../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md "../../../marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.md")         | List entitled security profiles                                                                      | List         |
| [ListSecurityProfileSnapshots](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")         | Return the snapshot summary list for an existing security profile                                    | List         |
| [ListSecurityProfiles](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")                 | List existing security profiles                                                                      | List         |
| [ListTagsForResource](../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md "../../../marketplace/latest/userguide/vendor-insights-seller-controlling-access.md")                  | List tags for vendor insights resource                                                               | Read         |
