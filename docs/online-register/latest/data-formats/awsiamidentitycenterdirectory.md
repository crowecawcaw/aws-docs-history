# Data retrieval APIs for AWS IAM Identity Center directory

AWS IAM Identity Center directory provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                            | Description                                                                                                      | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeDirectory](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                         | Retrieve information about the directory that AWS IAM Identity Center provides by default                        | Read         |
| [DescribeGroup](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md")                                                         | Query the group data, not including user and group members                                                       | Read         |
| [DescribeGroups](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md")                                                        | Retrieve information about groups from the directory that AWS IAM Identity Center provides by default            | Read         |
| [DescribeProvisioningTenant](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                | Describes the provisioning tenant                                                                                | Read         |
| [DescribeUser](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md")                                                            | Retrieve information about a user from the directory that AWS IAM Identity Center provides by default            | Read         |
| [DescribeUserByUniqueAttribute](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")             | Describe user with a valid unique attribute represented for the user                                             | Read         |
| [DescribeUsers](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md")                                                           | Retrieve information about user from the directory that AWS IAM Identity Center provides by default              | Read         |
| [GetAWSSPConfigurationForDirectory](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")         | Retrieve the AWS IAM Identity Center Service Provider configurations for the directory                           | Read         |
| [GetGroupId](../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupId.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupId.md")                                                                  | Retrieve ID information about group from the directory that AWS IAM Identity Center provides by default          | Read         |
| [GetUserId](../../../singlesignon/latest/IdentityStoreAPIReference/API_GetUserId.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_GetUserId.md")                                                                     | Retrieve ID information about user from the directory that AWS IAM Identity Center provides by default           | Read         |
| [GetUserPoolInfo](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                           | (Deprecated) Grants permission to get UserPool Info                                                              | Read         |
| [IsMemberInGroup](../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md")                                                 | Check if a member is a part of the group in the directory that AWS IAM Identity Center provides by default       | Read         |
| [IsMemberInGroups](../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md")                                                | Check if a member is a part of multiple groups in the directory that AWS IAM Identity Center provides by default | Read         |
| [ListBearerTokens](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                          | List bearer tokens for a given provisioning tenant                                                               | Read         |
| [ListExternalIdPCertificates](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")               | List the external IdP certificates of a given directory and IdP                                                  | Read         |
| [ListExternalIdPConfigurationsForDirectory](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample") | List all the External Identity Provider configurations created for the directory                                 | Read         |
| [ListGroups](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroups.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroups.md")                                                                  | List groups from the directory that AWS IAM Identity Center provides by default                                  | Read         |
| [ListGroupsForMember](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md")                   | List groups of the target member                                                                                 | Read         |
| [ListGroupsForUser](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md")                     | List groups for a user from the directory that AWS IAM Identity Center provides by default                       | Read         |
| [ListMembersInGroup](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMemberships.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMemberships.md")                                      | Retrieve all members that are part of a group in the directory that AWS IAM Identity Center provides by default  | Read         |
| [ListMfaDevicesForUser](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                     | List all active MFA devices and their MFA device metadata for a user                                             | Read         |
| [ListProvisioningTenants](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                   | List provisioning tenants for a given directory                                                                  | Read         |
| [ListUsers](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListUsers.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListUsers.md")                                                                     | List users from the directory that AWS IAM Identity Center provides by default                                   | Read         |
| [SearchGroups](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                              | Search for groups within the associated directory                                                                | Read         |
| [SearchUsers](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                               | Search for users within the associated directory                                                                 | Read         |
