# Data retrieval APIs for Amazon CloudWatch Network Synthetic Monitor

Amazon CloudWatch Network Synthetic Monitor provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                        | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------ |
| [GetMonitor](../../../networkmonitor/latest/APIReference/API_GetMonitor.md "../../../networkmonitor/latest/APIReference/API_GetMonitor.md")                            | Get information about a monitor                    | Read         |
| [GetProbe](../../../networkmonitor/latest/APIReference/API_GetProbe.md "../../../networkmonitor/latest/APIReference/API_GetProbe.md")                                  | Get information about a probe                      | Read         |
| [ListMonitors](../../../networkmonitor/latest/APIReference/API_ListMonitors.md "../../../networkmonitor/latest/APIReference/API_ListMonitors.md")                      | List all monitors in an account and their statuses | List         |
| [ListTagsForResource](../../../networkmonitor/latest/APIReference/API_ListTagsForResource.md "../../../networkmonitor/latest/APIReference/API_ListTagsForResource.md") | List the tags for a resource                       | Read         |
