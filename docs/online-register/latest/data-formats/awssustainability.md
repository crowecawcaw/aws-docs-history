# Data retrieval APIs for AWS Sustainability

AWS Sustainability provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                     | Description                                                                                | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------ |
| [GetCarbonFootprintSummary](../../../cur/latest/userguide/dataexports-create-standard.md "../../../cur/latest/userguide/dataexports-create-standard.md")                                                                                    | Access carbon footprint data from AWS Data Exports                                         | Read         |
| [GetEstimatedCarbonEmissions](../../../sustainability/latest/APIReference/API_GetEstimatedCarbonEmissions.md "../../../sustainability/latest/APIReference/API_GetEstimatedCarbonEmissions.md")                                              | View estimated carbon emission values based on customer grouping and filtering parameters  | Read         |
| [GetEstimatedCarbonEmissionsDimensionValues](../../../sustainability/latest/APIReference/API_GetEstimatedCarbonEmissionsDimensionValues.md "../../../sustainability/latest/APIReference/API_GetEstimatedCarbonEmissionsDimensionValues.md") | View the possible dimension values available for the estimated carbon emission values      | Read         |
| [GetEstimatedWaterAllocation](../../../sustainability/latest/APIReference/API_GetEstimatedWaterAllocation.md "../../../sustainability/latest/APIReference/API_GetEstimatedWaterAllocation.md")                                              | View estimated water allocation values based on customer grouping and filtering parameters | Read         |
| [GetEstimatedWaterAllocationDimensionValues](../../../sustainability/latest/APIReference/API_GetEstimatedWaterAllocationDimensionValues.md "../../../sustainability/latest/APIReference/API_GetEstimatedWaterAllocationDimensionValues.md") | View the possible dimension values available for the estimated water allocation values     | Read         |
