# Data retrieval APIs for AWS SQL Workbench

AWS SQL Workbench provides the following APIs for data retrieval.

| Actions                                                                                                                                              | Description                                            | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------ |
| [BatchGetNotebookCell](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")      | Get notebook cells content on your account             | Read         |
| [ExportNotebook](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")            | Export a notebook on your account                      | Read         |
| [GetAccountInfo](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")            | Get account info                                       | Read         |
| [GetAccountSettings](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")        | Get account settings                                   | Read         |
| [GetAutocompletionMetadata](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md") | Get database structure metadata for auto-completion    | Read         |
| [GetAutocompletionResource](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md") | Get database structure information for auto-completion | Read         |
| [GetChart](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")                  | Get charts on your account                             | Read         |
| [GetConnection](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")             | Get connections on your account                        | Read         |
| [GetNotebook](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")               | Get notebook metadata on your account                  | Read         |
| [GetNotebookVersion](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")        | Get the content of a notebook version on your account  | Read         |
| [GetQCustomContext](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")         | Get account-wide custom context                        | Read         |
| [GetQSqlPromptQuotas](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")       | Get Q generative SQL maximum prompt quotas             | Read         |
| [GetQSqlRecommendations](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")    | Get text to SQL recommendations                        | Read         |
| [GetQueryExecutionHistory](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")  | Get the query execution history on your account        | Read         |
| [GetSavedQuery](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")             | Get saved query on your account                        | Read         |
| [GetSchemaInference](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")        | Get the columns and data types inferred from a file    | Read         |
| [GetSqlGenerationContext](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")   | Get sql generation context                             | Read         |
| [GetSqlRecommendations](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")     | Get text to SQL recommendations                        | Read         |
| [GetUserInfo](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")               | Get user info                                          | Read         |
| [GetUserWorkspaceSettings](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")  | Get workspace settings on your account                 | Read         |
| [ListConnections](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")           | List the connections on your account                   | List         |
| [ListDatabases](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")             | List databases of your redshift cluster                | List         |
| [ListFiles](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")                 | List files and folders                                 | List         |
| [ListNotebookVersions](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")      | Get notebook versions metadata on your account         | List         |
| [ListNotebooks](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")             | List the notebooks on your account                     | List         |
| [ListQueryExecutionHistory](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md") | List the query execution history on your account       | List         |
| [ListRedshiftClusters](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")      | List redshift clusters on your account                 | List         |

| [ListSavedQueryVersions](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")    | List versions of saved query on your account           | List         |
| [ListTabs](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")                  | List tabs on your account                              | List         |
| [ListTaggedResources](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")       | List tagged resources                                  | Read         |
| [ListTagsForResource](../../../redshift/latest/mgmt/redshift-policy-resources.md "../../../redshift/latest/mgmt/redshift-policy-resources.md")       | List the tags of an sqlworkbench resource              | Read         |
