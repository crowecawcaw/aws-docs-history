

# Data retrieval APIs for AWS SQL Workbench
<a name="awssqlworkbench"></a>

AWS SQL Workbench provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="sqlworkbench-BatchGetNotebookCell"></a>[BatchGetNotebookCell](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get notebook cells content on your account | Read | 
| <a name="sqlworkbench-ExportNotebook"></a>[ExportNotebook](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Export a notebook on your account | Read | 
| <a name="sqlworkbench-GetAccountInfo"></a>[GetAccountInfo](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get account info | Read | 
| <a name="sqlworkbench-GetAccountSettings"></a>[GetAccountSettings](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get account settings | Read | 
| <a name="sqlworkbench-GetAutocompletionMetadata"></a>[GetAutocompletionMetadata](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get database structure metadata for auto-completion | Read | 
| <a name="sqlworkbench-GetAutocompletionResource"></a>[GetAutocompletionResource](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get database structure information for auto-completion | Read | 
| <a name="sqlworkbench-GetChart"></a>[GetChart](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get charts on your account | Read | 
| <a name="sqlworkbench-GetConnection"></a>[GetConnection](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get connections on your account | Read |

| <a name="sqlworkbench-GetNotebookVersion"></a>[GetNotebookVersion](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get the content of a notebook version on your account | Read | 
| <a name="sqlworkbench-GetQCustomContext"></a>[GetQCustomContext](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get account-wide custom context | Read | 
| <a name="sqlworkbench-GetQSqlPromptQuotas"></a>[GetQSqlPromptQuotas](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get Q generative SQL maximum prompt quotas | Read |

| <a name="sqlworkbench-GetSchemaInference"></a>[GetSchemaInference](https://docs.aws.amazon.com/redshift/latest/mgmt/redshift-policy-resources.resource-permissions.html) | Get the columns and data types inferred from a file | Read |
