

# Data retrieval APIs for Amazon Nimble Studio
<a name="amazonnimblestudio"></a>

Amazon Nimble Studio provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="nimble-GetEula"></a>[GetEula](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetEula.html) | Get a EULA | Read | 
| <a name="nimble-GetFeatureMap"></a>[GetFeatureMap](https://docs.aws.amazon.com/nimble-studio/latest/userguide/security-iam-service-with-iam.html) | Allow Nimble Studio portal to show the appropriate features for this account | Read | 
| <a name="nimble-GetLaunchProfile"></a>[GetLaunchProfile](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetLaunchProfile.html) | Get a launch profile | Read | 
| <a name="nimble-GetLaunchProfileDetails"></a>[GetLaunchProfileDetails](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetLaunchProfileDetails.html) | Get a launch profile's details, which includes the summary of studio components and streaming images used by the launch profile | Read | 
| <a name="nimble-GetLaunchProfileInitialization"></a>[GetLaunchProfileInitialization](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetLaunchProfileInitialization.html) | Get a launch profile initialization. A launch profile initialization is a dereferenced version of a launch profile, including attached studio component connection information | Read | 
| <a name="nimble-GetLaunchProfileMember"></a>[GetLaunchProfileMember](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetLaunchProfileMember.html) | Get a launch profile member | Read | 
| <a name="nimble-GetStreamingImage"></a>[GetStreamingImage](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStreamingImage.html) | Get a streaming image | Read | 
| <a name="nimble-GetStreamingSession"></a>[GetStreamingSession](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStreamingSession.html) | Get a streaming session | Read | 
| <a name="nimble-GetStreamingSessionBackup"></a>[GetStreamingSessionBackup](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStreamingSessionBackup.html) | Get a streaming session backup | Read | 
| <a name="nimble-GetStreamingSessionStream"></a>[GetStreamingSessionStream](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStreamingSessionStream.html) | Get a streaming session stream | Read | 
| <a name="nimble-GetStudio"></a>[GetStudio](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStudio.html) | Get a studio | Read | 
| <a name="nimble-GetStudioComponent"></a>[GetStudioComponent](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStudioComponent.html) | Get a studio component | Read | 
| <a name="nimble-GetStudioMember"></a>[GetStudioMember](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_GetStudioMember.html) | Get a studio member | Read | 
| <a name="nimble-ListEulaAcceptances"></a>[ListEulaAcceptances](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListEulaAcceptances.html) | List EULA acceptances | Read | 
| <a name="nimble-ListEulas"></a>[ListEulas](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListEulas.html) | List EULAs | Read | 
| <a name="nimble-ListLaunchProfileMembers"></a>[ListLaunchProfileMembers](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListLaunchProfileMembers.html) | List launch profile members | Read | 
| <a name="nimble-ListLaunchProfiles"></a>[ListLaunchProfiles](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListLaunchProfiles.html) | List launch profiles | Read | 
| <a name="nimble-ListStreamingImages"></a>[ListStreamingImages](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListStreamingImages.html) | List streaming images | Read | 
| <a name="nimble-ListStreamingSessionBackups"></a>[ListStreamingSessionBackups](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListStreamingSessionBackups.html) | List streaming session backups | Read | 
| <a name="nimble-ListStreamingSessions"></a>[ListStreamingSessions](https://docs.aws.amazon.com/nimble-studio/latest/APIReference/API_ListStreamingSessions.html) | List streaming sessions | Read |
