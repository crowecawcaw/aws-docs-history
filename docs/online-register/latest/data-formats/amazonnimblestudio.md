# Data retrieval APIs for Amazon Nimble Studio

Amazon Nimble Studio provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                               | Description                                                                                                                                                                    | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [GetEula](../../../nimble-studio/latest/APIReference/API_GetEula.md "../../../nimble-studio/latest/APIReference/API_GetEula.md")                                                                      | Get a EULA                                                                                                                                                                     | Read         |
| [GetFeatureMap](../../../nimble-studio/latest/userguide/security-iam-service-with-iam.md "../../../nimble-studio/latest/userguide/security-iam-service-with-iam.md")                                  | Allow Nimble Studio portal to show the appropriate features for this account                                                                                                   | Read         |
| [GetLaunchProfile](../../../nimble-studio/latest/APIReference/API_GetLaunchProfile.md "../../../nimble-studio/latest/APIReference/API_GetLaunchProfile.md")                                           | Get a launch profile                                                                                                                                                           | Read         |
| [GetLaunchProfileDetails](../../../nimble-studio/latest/APIReference/API_GetLaunchProfileDetails.md "../../../nimble-studio/latest/APIReference/API_GetLaunchProfileDetails.md")                      | Get a launch profile's details, which includes the summary of studio components and streaming images used by the launch profile                                                | Read         |
| [GetLaunchProfileInitialization](../../../nimble-studio/latest/APIReference/API_GetLaunchProfileInitialization.md "../../../nimble-studio/latest/APIReference/API_GetLaunchProfileInitialization.md") | Get a launch profile initialization. A launch profile initialization is a dereferenced version of a launch profile, including attached studio component connection information | Read         |
| [GetLaunchProfileMember](../../../nimble-studio/latest/APIReference/API_GetLaunchProfileMember.md "../../../nimble-studio/latest/APIReference/API_GetLaunchProfileMember.md")                         | Get a launch profile member                                                                                                                                                    | Read         |

| [GetStreamingSession](../../../nimble-studio/latest/APIReference/API_GetStreamingSession.md "../../../nimble-studio/latest/APIReference/API_GetStreamingSession.md")                                  | Get a streaming session                                                                                                                                                        | Read         |
| [GetStreamingSessionBackup](../../../nimble-studio/latest/APIReference/API_GetStreamingSessionBackup.md "../../../nimble-studio/latest/APIReference/API_GetStreamingSessionBackup.md")                | Get a streaming session backup                                                                                                                                                 | Read         |

| [ListEulaAcceptances](../../../nimble-studio/latest/APIReference/API_ListEulaAcceptances.md "../../../nimble-studio/latest/APIReference/API_ListEulaAcceptances.md")                                  | List EULA acceptances                                                                                                                                                          | Read         |
