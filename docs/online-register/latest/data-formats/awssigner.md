# Data retrieval APIs for AWS Signer

AWS Signer provides the following APIs for data retrieval.

| Actions                                                                                                                                       | Description                                                          | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ |
| [DescribeSigningJob](../../../signer/latest/api/API_DescribeSigningJob.md "../../../signer/latest/api/API_DescribeSigningJob.md")             | Return information about a specific Signing Job                      | Read         |
| [GetRevocationStatus](../../../signer/latest/api/API_GetRevocationStatus.md "../../../signer/latest/api/API_GetRevocationStatus.md")          | Query revocation info of signing resources                           | Read         |
| [GetSigningPlatform](../../../signer/latest/api/API_GetSigningPlatform.md "../../../signer/latest/api/API_GetSigningPlatform.md")             | Return information about a specific Signing Platform                 | Read         |
| [GetSigningProfile](../../../signer/latest/api/API_GetSigningProfile.md "../../../signer/latest/api/API_GetSigningProfile.md")                | Return information about a specific Signing Profile                  | Read         |
| [ListProfilePermissions](../../../signer/latest/api/API_ListProfilePermissions.md "../../../signer/latest/api/API_ListProfilePermissions.md") | List the cross-account permissions associated with a Signing Profile | Read         |
| [ListSigningJobs](../../../signer/latest/api/API_ListSigningJobs.md "../../../signer/latest/api/API_ListSigningJobs.md")                      | List all Signing Jobs in your account                                | List         |
| [ListSigningPlatforms](../../../signer/latest/api/API_ListSigningPlatforms.md "../../../signer/latest/api/API_ListSigningPlatforms.md")       | List all available Signing Platforms                                 | List         |
| [ListSigningProfiles](../../../signer/latest/api/API_ListSigningProfiles.md "../../../signer/latest/api/API_ListSigningProfiles.md")          | List all Signing Profiles in your account                            | List         |
| [ListTagsForResource](../../../signer/latest/api/API_ListTagsForResource.md "../../../signer/latest/api/API_ListTagsForResource.md")          | List the tags associated with a Signing Profile                      | Read         |
