# Data retrieval APIs for AWS Billing And Cost Management Data Exports

AWS Billing And Cost Management Data Exports provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                  | Description                      | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- | ------------ |
| [GetExecution](../../../aws-cost-management/latest/APIReference/API_DataExports_GetExecution.md "../../../aws-cost-management/latest/APIReference/API_DataExports_GetExecution.md")                      | Get the execution of an export   | Read         |
| [GetExport](../../../aws-cost-management/latest/APIReference/API_DataExports_GetExport.md "../../../aws-cost-management/latest/APIReference/API_DataExports_GetExport.md")                               | Get an export                    | Read         |
| [GetTable](../../../aws-cost-management/latest/APIReference/API_DataExports_GetTable.md "../../../aws-cost-management/latest/APIReference/API_DataExports_GetTable.md")                                  | Get the details of a table       | Read         |
| [ListExecutions](../../../aws-cost-management/latest/APIReference/API_DataExports_ListExecutions.md "../../../aws-cost-management/latest/APIReference/API_DataExports_ListExecutions.md")                | List all executions of an export | List         |
| [ListExports](../../../aws-cost-management/latest/APIReference/API_DataExports_ListExports.md "../../../aws-cost-management/latest/APIReference/API_DataExports_ListExports.md")                         | List all exports                 | List         |
| [ListTables](../../../aws-cost-management/latest/APIReference/API_DataExports_ListTables.md "../../../aws-cost-management/latest/APIReference/API_DataExports_ListTables.md")                            | List all available tables        | List         |
| [ListTagsForResource](../../../aws-cost-management/latest/APIReference/API_DataExports_ListTagsForResource.md "../../../aws-cost-management/latest/APIReference/API_DataExports_ListTagsForResource.md") | List tags for a resource         | Read         |
