

# Data retrieval APIs for Amazon Kinesis Firehose
<a name="amazonkinesisfirehose"></a>

Amazon Kinesis Firehose provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="firehose-DescribeDeliveryStream"></a>[DescribeDeliveryStream](https://docs.aws.amazon.com/firehose/latest/APIReference/API_DescribeDeliveryStream.html) | Describe the specified delivery stream and gets the status | Read | 
| <a name="firehose-ListDeliveryStreams"></a>[ListDeliveryStreams](https://docs.aws.amazon.com/firehose/latest/APIReference/API_ListDeliveryStreams.html) | List your delivery streams | List | 
| <a name="firehose-ListTagsForDeliveryStream"></a>[ListTagsForDeliveryStream](https://docs.aws.amazon.com/firehose/latest/APIReference/API_ListTagsForDeliveryStream.html) | List the tags for the specified delivery stream | List |
