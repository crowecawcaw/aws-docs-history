# Data retrieval APIs for Amazon Kinesis Firehose

Amazon Kinesis Firehose provides the following APIs for data retrieval.

| Actions                                                                                                                                                                      | Description                                                | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------ |
| [DescribeDeliveryStream](../../../firehose/latest/APIReference/API_DescribeDeliveryStream.md "../../../firehose/latest/APIReference/API_DescribeDeliveryStream.md")          | Describe the specified delivery stream and gets the status | Read         |
| [ListDeliveryStreams](../../../firehose/latest/APIReference/API_ListDeliveryStreams.md "../../../firehose/latest/APIReference/API_ListDeliveryStreams.md")                   | List your delivery streams                                 | List         |
| [ListTagsForDeliveryStream](../../../firehose/latest/APIReference/API_ListTagsForDeliveryStream.md "../../../firehose/latest/APIReference/API_ListTagsForDeliveryStream.md") | List the tags for the specified delivery stream            | List         |
