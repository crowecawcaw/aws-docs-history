# Data retrieval APIs for AWS Systems Manager Incident Manager

AWS Systems Manager Incident Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                   | Description                                                      | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------ |
| [BatchGetIncidentFindings](../../../incident-manager/latest/APIReference/API_BatchGetIncidentFindings.md "../../../incident-manager/latest/APIReference/API_BatchGetIncidentFindings.md") | Retrieve details about specified findings for an incident record | Read         |
| [GetIncidentRecord](../../../incident-manager/latest/APIReference/API_GetIncidentRecord.md "../../../incident-manager/latest/APIReference/API_GetIncidentRecord.md")                      | View the contents of an incident record                          | Read         |
| [GetReplicationSet](../../../incident-manager/latest/APIReference/API_GetReplicationSet.md "../../../incident-manager/latest/APIReference/API_GetReplicationSet.md")                      | View the replication set                                         | Read         |
| [GetResourcePolicies](../../../incident-manager/latest/APIReference/API_GetResourcePolicies.md "../../../incident-manager/latest/APIReference/API_GetResourcePolicies.md")                | View resource policies of a response plan                        | Read         |
| [GetResponsePlan](../../../incident-manager/latest/APIReference/API_GetResponsePlan.md "../../../incident-manager/latest/APIReference/API_GetResponsePlan.md")                            | View the contents of a specified response plan                   | Read         |
| [GetTimelineEvent](../../../incident-manager/latest/APIReference/API_GetTimelineEvent.md "../../../incident-manager/latest/APIReference/API_GetTimelineEvent.md")                         | View a timeline event                                            | Read         |
| [ListIncidentFindings](../../../incident-manager/latest/APIReference/API_ListIncidentFindings.md "../../../incident-manager/latest/APIReference/API_ListIncidentFindings.md")             | List findings for an incident record                             | List         |
| [ListIncidentRecords](../../../incident-manager/latest/APIReference/API_ListIncidentRecords.md "../../../incident-manager/latest/APIReference/API_ListIncidentRecords.md")                | List the contents of all incident records                        | List         |
| [ListRelatedItems](../../../incident-manager/latest/APIReference/API_ListRelatedItems.md "../../../incident-manager/latest/APIReference/API_ListRelatedItems.md")                         | List related items of an incident record                         | List         |
| [ListReplicationSets](../../../incident-manager/latest/APIReference/API_ListReplicationSets.md "../../../incident-manager/latest/APIReference/API_ListReplicationSets.md")                | List all replication sets                                        | List         |
| [ListResponsePlans](../../../incident-manager/latest/APIReference/API_ListResponsePlans.md "../../../incident-manager/latest/APIReference/API_ListResponsePlans.md")                      | List all response plans                                          | List         |
| [ListTagsForResource](../../../incident-manager/latest/APIReference/API_ListTagsForResource.md "../../../incident-manager/latest/APIReference/API_ListTagsForResource.md")                | View a list of resource tags for a specified resource            | Read         |
| [ListTimelineEvents](../../../incident-manager/latest/APIReference/API_ListTimelineEvents.md "../../../incident-manager/latest/APIReference/API_ListTimelineEvents.md")                   | List all timeline events for an incident record                  | List         |
