

# Data retrieval APIs for AWS Systems Manager Incident Manager
<a name="awssystemsmanagerincidentmanager"></a>

AWS Systems Manager Incident Manager provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="ssm-incidents-BatchGetIncidentFindings"></a>[BatchGetIncidentFindings](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_BatchGetIncidentFindings.html) | Retrieve details about specified findings for an incident record | Read | 
| <a name="ssm-incidents-GetIncidentRecord"></a>[GetIncidentRecord](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetIncidentRecord.html) | View the contents of an incident record | Read | 
| <a name="ssm-incidents-GetReplicationSet"></a>[GetReplicationSet](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetReplicationSet.html) | View the replication set | Read | 
| <a name="ssm-incidents-GetResourcePolicies"></a>[GetResourcePolicies](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResourcePolicies.html) | View resource policies of a response plan | Read | 
| <a name="ssm-incidents-GetResponsePlan"></a>[GetResponsePlan](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResponsePlan.html) | View the contents of a specified response plan | Read | 
| <a name="ssm-incidents-GetTimelineEvent"></a>[GetTimelineEvent](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetTimelineEvent.html) | View a timeline event | Read | 
| <a name="ssm-incidents-ListIncidentFindings"></a>[ListIncidentFindings](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentFindings.html) | List findings for an incident record | List | 
| <a name="ssm-incidents-ListIncidentRecords"></a>[ListIncidentRecords](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentRecords.html) | List the contents of all incident records | List | 
| <a name="ssm-incidents-ListRelatedItems"></a>[ListRelatedItems](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListRelatedItems.html) | List related items of an incident record | List | 
| <a name="ssm-incidents-ListReplicationSets"></a>[ListReplicationSets](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListReplicationSets.html) | List all replication sets | List | 
| <a name="ssm-incidents-ListResponsePlans"></a>[ListResponsePlans](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListResponsePlans.html) | List all response plans | List | 
| <a name="ssm-incidents-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListTagsForResource.html) | View a list of resource tags for a specified resource | Read | 
| <a name="ssm-incidents-ListTimelineEvents"></a>[ListTimelineEvents](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListTimelineEvents.html) | List all timeline events for an incident record | List |
