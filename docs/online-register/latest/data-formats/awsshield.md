# Data retrieval APIs for AWS Shield

AWS Shield provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                         | Description                                                                                                                                                  | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeAttack](../../../waf/latest/DDOSAPIReference/API_DescribeAttack.md "../../../waf/latest/DDOSAPIReference/API_DescribeAttack.md")                                                       | Get attack details                                                                                                                                           | Read         |
| [DescribeAttackContributors](../../../service-authorization/latest/reference/list_awsshield.md "../../../service-authorization/latest/reference/list_awsshield.md")                             | Get detailed information about the contributors to a specific DDoS attack                                                                                    | Read         |
| [DescribeAttackStatistics](../../../waf/latest/DDOSAPIReference/API_DescribeAttackStatistics.md "../../../waf/latest/DDOSAPIReference/API_DescribeAttackStatistics.md")                         | Describe information about the number and type of attacks AWS Shield has detected in the last year                                                           | Read         |
| [DescribeDRTAccess](../../../waf/latest/DDOSAPIReference/API_DescribeDRTAccess.md "../../../waf/latest/DDOSAPIReference/API_DescribeDRTAccess.md")                                              | Describe the current role and list of Amazon S3 log buckets used by the DDoS Response team to access your AWS account while assisting with attack mitigation | Read         |
| [DescribeEmergencyContactSettings](../../../waf/latest/DDOSAPIReference/API_DescribeEmergencyContactSettings.md "../../../waf/latest/DDOSAPIReference/API_DescribeEmergencyContactSettings.md") | List the email addresses that the DRT can use to contact you during a suspected attack                                                                       | Read         |
| [DescribeProtection](../../../waf/latest/DDOSAPIReference/API_DescribeProtection.md "../../../waf/latest/DDOSAPIReference/API_DescribeProtection.md")                                           | Get protection details                                                                                                                                       | Read         |
| [DescribeProtectionGroup](../../../waf/latest/DDOSAPIReference/API_DescribeProtectionGroup.md "../../../waf/latest/DDOSAPIReference/API_DescribeProtectionGroup.md")                            | Describe the specification for the specified protection group                                                                                                | Read         |
| [DescribeSubscription](../../../waf/latest/DDOSAPIReference/API_DescribeSubscription.md "../../../waf/latest/DDOSAPIReference/API_DescribeSubscription.md")                                     | Get subscription details, such as start time                                                                                                                 | Read         |
| [GetGlobalThreatData](../../../service-authorization/latest/reference/list_awsshield.md "../../../service-authorization/latest/reference/list_awsshield.md")                                    | Retrieve global threat intelligence data and trends from AWS Shield's threat monitoring systems                                                              | Read         |
| [GetSubscriptionState](../../../waf/latest/DDOSAPIReference/API_GetSubscriptionState.md "../../../waf/latest/DDOSAPIReference/API_GetSubscriptionState.md")                                     | Get subscription state                                                                                                                                       | Read         |
| [ListAttacks](../../../waf/latest/DDOSAPIReference/API_ListAttacks.md "../../../waf/latest/DDOSAPIReference/API_ListAttacks.md")                                                                | List all existing attacks                                                                                                                                    | List         |
| [ListMitigations](../../../service-authorization/latest/reference/list_awsshield.md "../../../service-authorization/latest/reference/list_awsshield.md")                                        | Retrieve a list of mitigation actions that have been applied during DDoS attacks                                                                             | List         |
| [ListProtectionGroups](../../../waf/latest/DDOSAPIReference/API_ListProtectionGroups.md "../../../waf/latest/DDOSAPIReference/API_ListProtectionGroups.md")                                     | Retrieve the protection groups for the account                                                                                                               | List         |
| [ListProtections](../../../waf/latest/DDOSAPIReference/API_ListProtections.md "../../../waf/latest/DDOSAPIReference/API_ListProtections.md")                                                    | List all existing protections                                                                                                                                | List         |
| [ListResourcesInProtectionGroup](../../../waf/latest/DDOSAPIReference/API_ListResourcesInProtectionGroup.md "../../../waf/latest/DDOSAPIReference/API_ListResourcesInProtectionGroup.md")       | Retrieve the resources that are included in the protection group                                                                                             | List         |
| [ListTagsForResource](../../../waf/latest/DDOSAPIReference/API_ListTagsForResource.md "../../../waf/latest/DDOSAPIReference/API_ListTagsForResource.md")                                        | Get information about AWS tags for a specified Amazon Resource Name (ARN) in AWS Shield                                                                      | Read         |
