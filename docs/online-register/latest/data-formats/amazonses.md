# Data retrieval APIs for Amazon SES

Amazon SES provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                             | Description                                                                                                                        | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeActiveReceiptRuleSet](../../../ses/latest/APIReference/API_DescribeActiveReceiptRuleSet.md "../../../ses/latest/APIReference/API_DescribeActiveReceiptRuleSet.md")                         | Return the metadata and receipt rules for the receipt rule set that is currently active                                            | Read         |
| [DescribeConfigurationSet](../../../ses/latest/APIReference/API_DescribeConfigurationSet.md "../../../ses/latest/APIReference/API_DescribeConfigurationSet.md")                                     | Return the details of the specified configuration set                                                                              | Read         |
| [DescribeReceiptRule](../../../ses/latest/APIReference/API_DescribeReceiptRule.md "../../../ses/latest/APIReference/API_DescribeReceiptRule.md")                                                    | Return the details of the specified receipt rule                                                                                   | Read         |
| [DescribeReceiptRuleSet](../../../ses/latest/APIReference/API_DescribeReceiptRuleSet.md "../../../ses/latest/APIReference/API_DescribeReceiptRuleSet.md")                                           | Return the details of the specified receipt rule set                                                                               | Read         |
| [GetAccountSendingEnabled](../../../ses/latest/APIReference/API_GetAccountSendingEnabled.md "../../../ses/latest/APIReference/API_GetAccountSendingEnabled.md")                                     | Return the email sending status of your account                                                                                    | Read         |
| [GetCustomVerificationEmailTemplate](../../../ses/latest/APIReference/API_GetCustomVerificationEmailTemplate.md "../../../ses/latest/APIReference/API_GetCustomVerificationEmailTemplate.md")       | Return the custom email verification template for the template name you specify                                                    | Read         |
| [GetIdentityDkimAttributes](../../../ses/latest/APIReference/API_GetIdentityDkimAttributes.md "../../../ses/latest/APIReference/API_GetIdentityDkimAttributes.md")                                  | Return the current status of Easy DKIM signing for an entity                                                                       | Read         |
| [GetIdentityMailFromDomainAttributes](../../../ses/latest/APIReference/API_GetIdentityMailFromDomainAttributes.md "../../../ses/latest/APIReference/API_GetIdentityMailFromDomainAttributes.md")    | Return the custom MAIL FROM attributes for a list of identities (email addresses and/or domains)                                   | Read         |
| [GetIdentityNotificationAttributes](../../../ses/latest/APIReference/API_GetIdentityNotificationAttributes.md "../../../ses/latest/APIReference/API_GetIdentityNotificationAttributes.md")          | Return a structure describing identity notification attributes for a list of verified identities (email addresses and/or domains), | Read         |
| [GetIdentityPolicies](../../../ses/latest/APIReference/API_GetIdentityPolicies.md "../../../ses/latest/APIReference/API_GetIdentityPolicies.md")                                                    | Return the requested sending authorization policies for the given identity (an email address or a domain)                          | Read         |
| [GetIdentityVerificationAttributes](../../../ses/latest/APIReference/API_GetIdentityVerificationAttributes.md "../../../ses/latest/APIReference/API_GetIdentityVerificationAttributes.md")          | Return the verification status and (for domain identities) the verification token for a list of identities                         | Read         |
| [GetSendQuota](../../../ses/latest/APIReference/API_GetSendQuota.md "../../../ses/latest/APIReference/API_GetSendQuota.md")                                                                         | Return the user's current sending limits                                                                                           | Read         |
| [GetSendStatistics](../../../ses/latest/APIReference/API_GetSendStatistics.md "../../../ses/latest/APIReference/API_GetSendStatistics.md")                                                          | Returns the user's sending statistics                                                                                              | Read         |
| [GetTemplate](../../../ses/latest/APIReference/API_GetTemplate.md "../../../ses/latest/APIReference/API_GetTemplate.md")                                                                            | Return the template object, which includes the subject line, HTML par, and text part for the template you specify                  | Read         |
| [ListConfigurationSets](../../../ses/latest/APIReference/API_ListConfigurationSets.md "../../../ses/latest/APIReference/API_ListConfigurationSets.md")                                              | List all of the configuration sets for your account                                                                                | List         |
| [ListCustomVerificationEmailTemplates](../../../ses/latest/APIReference/API_ListCustomVerificationEmailTemplates.md "../../../ses/latest/APIReference/API_ListCustomVerificationEmailTemplates.md") | List all of the existing custom verification email templates for your account                                                      | List         |
| [ListIdentities](../../../ses/latest/APIReference/API_ListIdentities.md "../../../ses/latest/APIReference/API_ListIdentities.md")                                                                   | List the email identities for your account                                                                                         | List         |
| [ListIdentityPolicies](../../../ses/latest/APIReference/API_ListIdentityPolicies.md "../../../ses/latest/APIReference/API_ListIdentityPolicies.md")                                                 | List all of the email templates for your account                                                                                   | List         |
| [ListReceiptFilters](../../../ses/latest/APIReference/API_ListReceiptFilters.md "../../../ses/latest/APIReference/API_ListReceiptFilters.md")                                                       | List the IP address filters associated with your account                                                                           | Read         |
| [ListReceiptRuleSets](../../../ses/latest/APIReference/API_ListReceiptRuleSets.md "../../../ses/latest/APIReference/API_ListReceiptRuleSets.md")                                                    | List the receipt rule sets that exist under your account                                                                           | Read         |
| [ListTemplates](../../../ses/latest/APIReference/API_ListTemplates.md "../../../ses/latest/APIReference/API_ListTemplates.md")                                                                      | List the email templates present in your account                                                                                   | List         |
| [ListVerifiedEmailAddresses](../../../ses/latest/APIReference/API_ListVerifiedEmailAddresses.md "../../../ses/latest/APIReference/API_ListVerifiedEmailAddresses.md")                               | List all of the email addresses that have been verified in your account                                                            | Read         |
