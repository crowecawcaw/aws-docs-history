# Data retrieval APIs for Amazon Security Lake

Amazon Security Lake provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                 | Description                                                                                                                      | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetDataLakeExceptionSubscription](../../../security-lake/latest/APIReference/API_GetDataLakeExceptionSubscription.md "../../../security-lake/latest/APIReference/API_GetDataLakeExceptionSubscription.md")             | Query the protocol and endpoint that were provided when subscribing to SNS topics for exception notifications                    | Read         |
| [GetDataLakeOrganizationConfiguration](../../../security-lake/latest/APIReference/API_GetDataLakeOrganizationConfiguration.md "../../../security-lake/latest/APIReference/API_GetDataLakeOrganizationConfiguration.md") | Get an organization's configuration setting for automatically enabling Amazon Security Lake access for new organization accounts | Read         |
| [GetDataLakeSources](../../../security-lake/latest/APIReference/API_GetDataLakeSources.md "../../../security-lake/latest/APIReference/API_GetDataLakeSources.md")                                                       | Get a static snapshot of the security data lake in the current region. The snapshot includes enabled accounts and log sources    | Read         |
| [GetSubscriber](../../../security-lake/latest/APIReference/API_GetSubscriber.md "../../../security-lake/latest/APIReference/API_GetSubscriber.md")                                                                      | Get information about subscriber that is already created                                                                         | Read         |
| [ListDataLakeExceptions](../../../security-lake/latest/APIReference/API_ListDataLakeExceptions.md "../../../security-lake/latest/APIReference/API_ListDataLakeExceptions.md")                                           | Get the list of all non-retryable failures                                                                                       | List         |
| [ListDataLakes](../../../security-lake/latest/APIReference/API_ListDataLakes.md "../../../security-lake/latest/APIReference/API_ListDataLakes.md")                                                                      | List information about the security data lakes                                                                                   | List         |
| [ListLogSources](../../../security-lake/latest/APIReference/API_ListLogSources.md "../../../security-lake/latest/APIReference/API_ListLogSources.md")                                                                   | View the enabled accounts. You can view the enabled sources in the enabled regions                                               | List         |
| [ListSubscribers](../../../security-lake/latest/APIReference/API_ListSubscribers.md "../../../security-lake/latest/APIReference/API_ListSubscribers.md")                                                                | List all subscribers                                                                                                             | List         |
| [ListTagsForResource](../../../security-lake/latest/APIReference/API_ListTagsForResource.md "../../../security-lake/latest/APIReference/API_ListTagsForResource.md")                                                    | List all tags for the resource                                                                                                   | List         |
