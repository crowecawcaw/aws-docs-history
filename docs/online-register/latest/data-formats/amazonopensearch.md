

# Data retrieval APIs for Amazon OpenSearch
<a name="amazonopensearch"></a>

Amazon OpenSearch provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="opensearch-GetAutoOptimizeJob"></a>[GetAutoOptimizeJob](https://docs.aws.amazon.com/opensearch-service/latest/developerguide/serverless-auto-optimize.html) | Get the Auto Optimize Job details | Read | 
| <a name="opensearch-GetDirectQuery"></a>[GetDirectQuery](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_GetDirectQuery.html) | Get the query status that are performed on the OpenSearch DataSource resource | Read | 
| <a name="opensearch-GetDirectQueryResult"></a>[GetDirectQueryResult](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_GetDirectQueryResult.html) | Get the results of a query that is performed on the OpenSearch DataSource resource | Read | 
| <a name="opensearch-ListAutoOptimizeJobs"></a>[ListAutoOptimizeJobs](https://docs.aws.amazon.com/opensearch-service/latest/developerguide/serverless-auto-optimize.html) | Retrieve a list of Auto Optimize Jobs | List |
