# Data retrieval APIs for AWS Support

AWS Support provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                             | Description                                                                                                  | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeAttachment](../../../awssupport/latest/APIReference/API_DescribeAttachment.md "../../../awssupport/latest/APIReference/API_DescribeAttachment.md")                                                                         | Describe attachment detail                                                                                   | Read         |
| [DescribeCaseAttributes](../../../awssupport/latest/user/accessing-support.md "../../../awssupport/latest/user/accessing-support.md")                                                                                               | Allow secondary services to read AWS Support case attributes.This is an internally managed function          | Read         |
| [DescribeCaseOptions](../../../awssupport/latest/APIReference/API_DescribeCaseOptions.md "../../../awssupport/latest/APIReference/API_DescribeCaseOptions.md")                                                                      | Describe the available options for a single AWS Support case. This is an internally managed function         | Read         |
| [DescribeCases](../../../awssupport/latest/APIReference/API_DescribeCases.md "../../../awssupport/latest/APIReference/API_DescribeCases.md")                                                                                        | List AWS Support cases that matches the given inputs                                                         | Read         |
| [DescribeCommunication](../../../awssupport/latest/user/accessing-support.md "../../../awssupport/latest/user/accessing-support.md")                                                                                                | Get a single communication and attachments for a single AWS Support case                                     | Read         |
| [DescribeCommunications](../../../awssupport/latest/APIReference/API_DescribeCommunications.md "../../../awssupport/latest/APIReference/API_DescribeCommunications.md")                                                             | List the communications and attachments for one or more AWS Support cases                                    | Read         |
| [DescribeCreateCaseOptions](../../../awssupport/latest/APIReference/API_DescribeCreateCaseOptions.md "../../../awssupport/latest/APIReference/API_DescribeCreateCaseOptions.md")                                                    | Describes the available options for creating a support case                                                  | Read         |
| [DescribeIssueTypes](../../../awssupport/latest/user/accessing-support.md "../../../awssupport/latest/user/accessing-support.md")                                                                                                   | Return issue types for AWS Support cases                                                                     | Read         |
| [DescribeServices](../../../awssupport/latest/APIReference/API_DescribeServices.md "../../../awssupport/latest/APIReference/API_DescribeServices.md")                                                                               | List AWS services and categories that applies to each service                                                | Read         |
| [DescribeSeverityLevels](../../../awssupport/latest/APIReference/API_DescribeSeverityLevels.md "../../../awssupport/latest/APIReference/API_DescribeSeverityLevels.md")                                                             | List severity levels that can be assigned to an AWS Support case                                             | Read         |
| [DescribeSupportLevel](../../../awssupport/latest/user/accessing-support.md "../../../awssupport/latest/user/accessing-support.md")                                                                                                 | Return the support level for an AWS Account identifier                                                       | Read         |
| [DescribeSupportedLanguages](../../../awssupport/latest/APIReference/API_DescribeSupportedLanguages.md "../../../awssupport/latest/APIReference/API_DescribeSupportedLanguages.md")                                                 | Describes the available support languages for a given category code, service code and issue type             | Read         |
| [DescribeTrustedAdvisorCheckRefreshStatuses](../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckRefreshStatuses.md "../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckRefreshStatuses.md") | Get the status of a Trusted Advisor refresh check based on a list of check identifiers                       | Read         |
| [DescribeTrustedAdvisorCheckResult](../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckResult.md "../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckResult.md")                            | Get the results of the Trusted Advisor check that has the specified check identifier                         | Read         |
| [DescribeTrustedAdvisorCheckSummaries](../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckSummaries.md "../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorCheckSummaries.md")                   | Get the summaries of the results of the Trusted Advisor checks that have the specified check identifiers     | Read         |
| [DescribeTrustedAdvisorChecks](../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorChecks.md "../../../awssupport/latest/APIReference/API_DescribeTrustedAdvisorChecks.md")                                           | Get a list of all available Trusted Advisor checks, including name, identifier, category and description     | Read         |
| [GetInteraction](../../../awssupport/latest/APIReference/API_GetInteraction.md "../../../awssupport/latest/APIReference/API_GetInteraction.md")                                                                                     | Retrieve personalized troubleshooting assistance for account and technical issues for a specific interaction | Read         |
| [SearchForCases](../../../awssupport/latest/user/accessing-support.md "../../../awssupport/latest/user/accessing-support.md")                                                                                                       | Return a list of AWS Support cases that matches the given inputs                                             | Read         |
