# Data retrieval APIs for AWS Cloud9

AWS Cloud9 provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                | Description                                                                                                   | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ------------ |
| [CreateEnvironmentToken](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")  | Create an authentication token that allows a connection between the AWS Cloud9 IDE and the user's environment | Read         |
| [DescribeEC2Remote](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")       | Get details about the connection to the EC2 development environment, including host, user, and port           | Read         |
| [DescribeEnvironmentMemberships](../../../cloud9/latest/APIReference/API_DescribeEnvironmentMemberships.md "../../../cloud9/latest/APIReference/API_DescribeEnvironmentMemberships.md")                | Get information about environment members for an AWS Cloud9 development environment                           | Read         |
| [DescribeEnvironmentStatus](../../../cloud9/latest/APIReference/API_DescribeEnvironmentStatus.md "../../../cloud9/latest/APIReference/API_DescribeEnvironmentStatus.md")                               | Get status information for an AWS Cloud9 development environment                                              | Read         |
| [DescribeEnvironments](../../../cloud9/latest/APIReference/API_DescribeEnvironments.md "../../../cloud9/latest/APIReference/API_DescribeEnvironments.md")                                              | Get information about AWS Cloud9 development environments                                                     | Read         |
| [DescribeSSHRemote](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")       | Get details about the connection to the SSH development environment, including host, user, and port           | Read         |
| [GetEnvironmentConfig](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")    | Get configuration information that's used to initialize the AWS Cloud9 IDE                                    | Read         |
| [GetEnvironmentSettings](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")  | Get the AWS Cloud9 IDE settings for a specified development environment                                       | Read         |
| [GetMembershipSettings](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")   | Get the AWS Cloud9 IDE settings for a specified environment member                                            | Read         |
| [GetMigrationExperiences](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix") | Get the migration experience for a cloud9 user                                                                | Read         |
| [GetUserPublicKey](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")        | Get the user's public SSH key, which is used by AWS Cloud9 to connect to SSH development environments         | Read         |
| [GetUserSettings](../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix "../../../cloud9/latest/user-guide/security-iam.md#auth-and-access-control-ref-matrix")         | Get the AWS Cloud9 IDE settings for a specified user                                                          | Read         |
| [ListEnvironments](../../../cloud9/latest/APIReference/API_ListEnvironments.md "../../../cloud9/latest/APIReference/API_ListEnvironments.md")                                                          | Get a list of AWS Cloud9 development environment identifiers                                                  | Read         |
| [ListTagsForResource](../../../cloud9/latest/APIReference/API_ListTagsForResource.md "../../../cloud9/latest/APIReference/API_ListTagsForResource.md")                                                 | List tags for a cloud9 environment                                                                            | Read         |
