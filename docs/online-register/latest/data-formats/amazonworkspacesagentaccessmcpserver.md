# Data retrieval APIs for Amazon WorkSpaces AgentAccess MCP Server

Amazon WorkSpaces AgentAccess MCP Server provides the following APIs for data retrieval.

| Actions                                                                                                              | Description                                        | Access level |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------ |
| [CheckConnectionStatus](../../../appstream2/latest/developerguide.md "../../../appstream2/latest/developerguide.md") | Check the connection status of a streaming session | Read         |
| [GetScreenshot](../../../appstream2/latest/developerguide.md "../../../appstream2/latest/developerguide.md")         | Capture screen state                               | Read         |
