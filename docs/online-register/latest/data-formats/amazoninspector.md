# Data retrieval APIs for Amazon Inspector

Amazon Inspector provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                       | Description                                                                                                                      | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAssessmentRuns](../../../inspector/latest/APIReference/API_DescribeAssessmentRuns.md "../../../inspector/latest/APIReference/API_DescribeAssessmentRuns.md")                         | Describe the assessment runs that are specified by the ARNs of the assessment runs                                               | Read         |
| [DescribeAssessmentTargets](../../../inspector/latest/APIReference/API_DescribeAssessmentTargets.md "../../../inspector/latest/APIReference/API_DescribeAssessmentTargets.md")                | Describe the assessment targets that are specified by the ARNs of the assessment targets                                         | Read         |
| [DescribeAssessmentTemplates](../../../inspector/latest/APIReference/API_DescribeAssessmentTemplates.md "../../../inspector/latest/APIReference/API_DescribeAssessmentTemplates.md")          | Describe the assessment templates that are specified by the ARNs of the assessment templates                                     | Read         |
| [DescribeCrossAccountAccessRole](../../../inspector/latest/APIReference/API_DescribeCrossAccountAccessRole.md "../../../inspector/latest/APIReference/API_DescribeCrossAccountAccessRole.md") | Describe the IAM role that enables Amazon Inspector to access your AWS account                                                   | Read         |
| [DescribeExclusions](../../../inspector/latest/APIReference/API_DescribeExclusions.md "../../../inspector/latest/APIReference/API_DescribeExclusions.md")                                     | Describe the exclusions that are specified by the exclusions' ARNs                                                               | Read         |
| [DescribeFindings](../../../inspector/latest/APIReference/API_DescribeFindings.md "../../../inspector/latest/APIReference/API_DescribeFindings.md")                                           | Describe the findings that are specified by the ARNs of the findings                                                             | Read         |
| [DescribeResourceGroups](../../../inspector/latest/APIReference/API_DescribeResourceGroups.md "../../../inspector/latest/APIReference/API_DescribeResourceGroups.md")                         | Describe the resource groups that are specified by the ARNs of the resource groups                                               | Read         |
| [DescribeRulesPackages](../../../inspector/latest/APIReference/API_DescribeRulesPackages.md "../../../inspector/latest/APIReference/API_DescribeRulesPackages.md")                            | Describe the rules packages that are specified by the ARNs of the rules packages                                                 | Read         |
| [GetAssessmentReport](../../../inspector/latest/APIReference/API_GetAssessmentReport.md "../../../inspector/latest/APIReference/API_GetAssessmentReport.md")                                  | Produce an assessment report that includes detailed and comprehensive results of a specified assessment run                      | Read         |
| [GetExclusionsPreview](../../../inspector/latest/APIReference/API_GetExclusionsPreview.md "../../../inspector/latest/APIReference/API_GetExclusionsPreview.md")                               | Retrieve the exclusions preview (a list of ExclusionPreview objects) specified by the preview token                              | Read         |
| [GetTelemetryMetadata](../../../inspector/latest/APIReference/API_GetTelemetryMetadata.md "../../../inspector/latest/APIReference/API_GetTelemetryMetadata.md")                               | Get information about the data that is collected for the specified assessment run                                                | Read         |
| [ListAssessmentRunAgents](../../../inspector/latest/APIReference/API_ListAssessmentRunAgents.md "../../../inspector/latest/APIReference/API_ListAssessmentRunAgents.md")                      | List the agents of the assessment runs that are specified by the ARNs of the assessment runs                                     | List         |
| [ListAssessmentRuns](../../../inspector/latest/APIReference/API_ListAssessmentRuns.md "../../../inspector/latest/APIReference/API_ListAssessmentRuns.md")                                     | List the assessment runs that correspond to the assessment templates that are specified by the ARNs of the assessment templates  | List         |
| [ListAssessmentTargets](../../../inspector/latest/APIReference/API_ListAssessmentTargets.md "../../../inspector/latest/APIReference/API_ListAssessmentTargets.md")                            | List the ARNs of the assessment targets within this AWS account                                                                  | List         |
| [ListAssessmentTemplates](../../../inspector/latest/APIReference/API_ListAssessmentTemplates.md "../../../inspector/latest/APIReference/API_ListAssessmentTemplates.md")                      | List the assessment templates that correspond to the assessment targets that are specified by the ARNs of the assessment targets | List         |
| [ListEventSubscriptions](../../../inspector/latest/APIReference/API_ListEventSubscriptions.md "../../../inspector/latest/APIReference/API_ListEventSubscriptions.md")                         | List all the event subscriptions for the assessment template that is specified by the ARN of the assessment template             | List         |
| [ListExclusions](../../../inspector/latest/APIReference/API_ListExclusions.md "../../../inspector/latest/APIReference/API_ListExclusions.md")                                                 | List exclusions that are generated by the assessment run                                                                         | List         |
| [ListFindings](../../../inspector/latest/APIReference/API_ListFindings.md "../../../inspector/latest/APIReference/API_ListFindings.md")                                                       | List findings that are generated by the assessment runs that are specified by the ARNs of the assessment runs                    | List         |
| [ListRulesPackages](../../../inspector/latest/APIReference/API_ListRulesPackages.md "../../../inspector/latest/APIReference/API_ListRulesPackages.md")                                        | List all available Amazon Inspector rules packages                                                                               | List         |
| [ListTagsForResource](../../../inspector/latest/APIReference/API_ListTagsForResource.md "../../../inspector/latest/APIReference/API_ListTagsForResource.md")                                  | List all tags associated with an assessment template                                                                             | Read         |
| [PreviewAgents](../../../inspector/latest/APIReference/API_PreviewAgents.md "../../../inspector/latest/APIReference/API_PreviewAgents.md")                                                    | Preview the agents installed on the EC2 instances that are part of the specified assessment target                               | Read         |
