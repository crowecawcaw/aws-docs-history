

# Data retrieval APIs for Amazon Inspector
<a name="amazoninspector"></a>

Amazon Inspector provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="inspector-DescribeAssessmentRuns"></a>[DescribeAssessmentRuns](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeAssessmentRuns.html) | Describe the assessment runs that are specified by the ARNs of the assessment runs | Read | 
| <a name="inspector-DescribeAssessmentTargets"></a>[DescribeAssessmentTargets](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeAssessmentTargets.html) | Describe the assessment targets that are specified by the ARNs of the assessment targets | Read | 
| <a name="inspector-DescribeAssessmentTemplates"></a>[DescribeAssessmentTemplates](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeAssessmentTemplates.html) | Describe the assessment templates that are specified by the ARNs of the assessment templates | Read | 
| <a name="inspector-DescribeCrossAccountAccessRole"></a>[DescribeCrossAccountAccessRole](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeCrossAccountAccessRole.html) | Describe the IAM role that enables Amazon Inspector to access your AWS account | Read | 
| <a name="inspector-DescribeExclusions"></a>[DescribeExclusions](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeExclusions.html) | Describe the exclusions that are specified by the exclusions' ARNs | Read | 
| <a name="inspector-DescribeFindings"></a>[DescribeFindings](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeFindings.html) | Describe the findings that are specified by the ARNs of the findings | Read | 
| <a name="inspector-DescribeResourceGroups"></a>[DescribeResourceGroups](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeResourceGroups.html) | Describe the resource groups that are specified by the ARNs of the resource groups | Read | 
| <a name="inspector-DescribeRulesPackages"></a>[DescribeRulesPackages](https://docs.aws.amazon.com/inspector/latest/APIReference/API_DescribeRulesPackages.html) | Describe the rules packages that are specified by the ARNs of the rules packages | Read | 
| <a name="inspector-GetAssessmentReport"></a>[GetAssessmentReport](https://docs.aws.amazon.com/inspector/latest/APIReference/API_GetAssessmentReport.html) | Produce an assessment report that includes detailed and comprehensive results of a specified assessment run | Read | 
| <a name="inspector-GetExclusionsPreview"></a>[GetExclusionsPreview](https://docs.aws.amazon.com/inspector/latest/APIReference/API_GetExclusionsPreview.html) | Retrieve the exclusions preview (a list of ExclusionPreview objects) specified by the preview token | Read | 
| <a name="inspector-GetTelemetryMetadata"></a>[GetTelemetryMetadata](https://docs.aws.amazon.com/inspector/latest/APIReference/API_GetTelemetryMetadata.html) | Get information about the data that is collected for the specified assessment run | Read | 
| <a name="inspector-ListAssessmentRunAgents"></a>[ListAssessmentRunAgents](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListAssessmentRunAgents.html) | List the agents of the assessment runs that are specified by the ARNs of the assessment runs | List | 
| <a name="inspector-ListAssessmentRuns"></a>[ListAssessmentRuns](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListAssessmentRuns.html) | List the assessment runs that correspond to the assessment templates that are specified by the ARNs of the assessment templates | List | 
| <a name="inspector-ListAssessmentTargets"></a>[ListAssessmentTargets](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListAssessmentTargets.html) | List the ARNs of the assessment targets within this AWS account | List | 
| <a name="inspector-ListAssessmentTemplates"></a>[ListAssessmentTemplates](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListAssessmentTemplates.html) | List the assessment templates that correspond to the assessment targets that are specified by the ARNs of the assessment targets | List | 
| <a name="inspector-ListEventSubscriptions"></a>[ListEventSubscriptions](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListEventSubscriptions.html) | List all the event subscriptions for the assessment template that is specified by the ARN of the assessment template | List | 
| <a name="inspector-ListExclusions"></a>[ListExclusions](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListExclusions.html) | List exclusions that are generated by the assessment run | List | 
| <a name="inspector-ListFindings"></a>[ListFindings](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListFindings.html) | List findings that are generated by the assessment runs that are specified by the ARNs of the assessment runs | List | 
| <a name="inspector-ListRulesPackages"></a>[ListRulesPackages](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListRulesPackages.html) | List all available Amazon Inspector rules packages | List | 
| <a name="inspector-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/inspector/latest/APIReference/API_ListTagsForResource.html) | List all tags associated with an assessment template | Read | 
| <a name="inspector-PreviewAgents"></a>[PreviewAgents](https://docs.aws.amazon.com/inspector/latest/APIReference/API_PreviewAgents.html) | Preview the agents installed on the EC2 instances that are part of the specified assessment target | Read |
