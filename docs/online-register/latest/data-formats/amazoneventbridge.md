# Data retrieval APIs for Amazon EventBridge

Amazon EventBridge provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                           | Description                                                            | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------ |
| [DescribeApiDestination](../../../eventbridge/latest/APIReference/API_DescribeApiDestination.md "../../../eventbridge/latest/APIReference/API_DescribeApiDestination.md")                         | Retrieve details about an api destination                              | Read         |
| [DescribeArchive](../../../eventbridge/latest/APIReference/API_DescribeArchive.md "../../../eventbridge/latest/APIReference/API_DescribeArchive.md")                                              | Retrieve details about an archive                                      | Read         |
| [DescribeConnection](../../../eventbridge/latest/APIReference/API_DescribeConnection.md "../../../eventbridge/latest/APIReference/API_DescribeConnection.md")                                     | Retrieve details about a conection                                     | Read         |
| [DescribeEndpoint](../../../eventbridge/latest/APIReference/API_DescribeEndpoint.md "../../../eventbridge/latest/APIReference/API_DescribeEndpoint.md")                                           | Retrieve details about an endpoint                                     | Read         |
| [DescribeEventBus](../../../eventbridge/latest/APIReference/API_DescribeEventBus.md "../../../eventbridge/latest/APIReference/API_DescribeEventBus.md")                                           | Retrieve details about event buses                                     | Read         |
| [DescribeEventSource](../../../eventbridge/latest/APIReference/API_DescribeEventSource.md "../../../eventbridge/latest/APIReference/API_DescribeEventSource.md")                                  | Retrieve details about event sources                                   | Read         |
| [DescribePartnerEventSource](../../../eventbridge/latest/APIReference/API_DescribePartnerEventSource.md "../../../eventbridge/latest/APIReference/API_DescribePartnerEventSource.md")             | Retrieve details about partner event sources                           | Read         |
| [DescribeReplay](../../../eventbridge/latest/APIReference/API_DescribeReplay.md "../../../eventbridge/latest/APIReference/API_DescribeReplay.md")                                                 | Retrieve the details of a replay                                       | Read         |
| [DescribeRule](../../../eventbridge/latest/APIReference/API_DescribeRule.md "../../../eventbridge/latest/APIReference/API_DescribeRule.md")                                                       | Retrieve details about rules                                           | Read         |
| [ListApiDestinations](../../../eventbridge/latest/APIReference/API_ListApiDestinations.md "../../../eventbridge/latest/APIReference/API_ListApiDestinations.md")                                  | Retrieve a list of api destinations                                    | List         |
| [ListArchives](../../../eventbridge/latest/APIReference/API_ListArchives.md "../../../eventbridge/latest/APIReference/API_ListArchives.md")                                                       | Retrieve a list of archives                                            | List         |
| [ListConnections](../../../eventbridge/latest/APIReference/API_ListConnections.md "../../../eventbridge/latest/APIReference/API_ListConnections.md")                                              | Retrieve a list of connections                                         | List         |
| [ListEndpoints](../../../eventbridge/latest/APIReference/API_ListEndpoints.md "../../../eventbridge/latest/APIReference/API_ListEndpoints.md")                                                    | Retrieve a list of endpoints                                           | List         |
| [ListEventBuses](../../../eventbridge/latest/APIReference/API_ListEventBuses.md "../../../eventbridge/latest/APIReference/API_ListEventBuses.md")                                                 | Retrieve a list of the event buses in your account                     | List         |
| [ListEventSources](../../../eventbridge/latest/APIReference/API_ListEventSources.md "../../../eventbridge/latest/APIReference/API_ListEventSources.md")                                           | To retrieve a list of event sources shared with this account           | List         |
| [ListPartnerEventSourceAccounts](../../../eventbridge/latest/APIReference/API_ListPartnerEventSourceAccounts.md "../../../eventbridge/latest/APIReference/API_ListPartnerEventSourceAccounts.md") | Retrieve a list of AWS account IDs associated with an event source     | List         |
| [ListPartnerEventSources](../../../eventbridge/latest/APIReference/API_ListPartnerEventSources.md "../../../eventbridge/latest/APIReference/API_ListPartnerEventSources.md")                      | Retrieve a list partner event sources                                  | List         |
| [ListReplays](../../../eventbridge/latest/APIReference/API_ListReplays.md "../../../eventbridge/latest/APIReference/API_ListReplays.md")                                                          | Retrieve a list of replays                                             | List         |
| [ListRuleNamesByTarget](../../../eventbridge/latest/APIReference/API_ListRuleNamesByTarget.md "../../../eventbridge/latest/APIReference/API_ListRuleNamesByTarget.md")                            | Retrieve a list of the names of the rules associated with a target     | List         |
| [ListRules](../../../eventbridge/latest/APIReference/API_ListRules.md "../../../eventbridge/latest/APIReference/API_ListRules.md")                                                                | Retrieve a list of the Amazon EventBridge rules in the account         | List         |
| [ListTagsForResource](../../../eventbridge/latest/APIReference/API_ListTagsForResource.md "../../../eventbridge/latest/APIReference/API_ListTagsForResource.md")                                  | Retrieve a list of tags associated with an Amazon EventBridge resource | List         |
| [ListTargetsByRule](../../../eventbridge/latest/APIReference/API_ListTargetsByRule.md "../../../eventbridge/latest/APIReference/API_ListTargetsByRule.md")                                        | Retrieve a list of targets defined for a rule                          | List         |
| [TestEventPattern](../../../eventbridge/latest/APIReference/API_TestEventPattern.md "../../../eventbridge/latest/APIReference/API_TestEventPattern.md")                                           | Test whether an event pattern matches the provided event               | Read         |
