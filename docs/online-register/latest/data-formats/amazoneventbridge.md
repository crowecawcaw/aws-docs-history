

# Data retrieval APIs for Amazon EventBridge
<a name="amazoneventbridge"></a>

Amazon EventBridge provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="events-DescribeApiDestination"></a>[DescribeApiDestination](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeApiDestination.html) | Retrieve details about an api destination | Read | 
| <a name="events-DescribeArchive"></a>[DescribeArchive](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeArchive.html) | Retrieve details about an archive | Read | 
| <a name="events-DescribeConnection"></a>[DescribeConnection](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeConnection.html) | Retrieve details about a conection | Read | 
| <a name="events-DescribeEndpoint"></a>[DescribeEndpoint](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeEndpoint.html) | Retrieve details about an endpoint | Read | 
| <a name="events-DescribeEventBus"></a>[DescribeEventBus](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeEventBus.html) | Retrieve details about event buses | Read | 
| <a name="events-DescribeEventSource"></a>[DescribeEventSource](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeEventSource.html) | Retrieve details about event sources | Read | 
| <a name="events-DescribePartnerEventSource"></a>[DescribePartnerEventSource](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribePartnerEventSource.html) | Retrieve details about partner event sources | Read | 
| <a name="events-DescribeReplay"></a>[DescribeReplay](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeReplay.html) | Retrieve the details of a replay | Read | 
| <a name="events-DescribeRule"></a>[DescribeRule](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_DescribeRule.html) | Retrieve details about rules | Read | 
| <a name="events-ListApiDestinations"></a>[ListApiDestinations](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListApiDestinations.html) | Retrieve a list of api destinations | List | 
| <a name="events-ListArchives"></a>[ListArchives](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListArchives.html) | Retrieve a list of archives | List | 
| <a name="events-ListConnections"></a>[ListConnections](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListConnections.html) | Retrieve a list of connections | List | 
| <a name="events-ListEndpoints"></a>[ListEndpoints](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListEndpoints.html) | Retrieve a list of endpoints | List | 
| <a name="events-ListEventBuses"></a>[ListEventBuses](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListEventBuses.html) | Retrieve a list of the event buses in your account | List | 
| <a name="events-ListEventSources"></a>[ListEventSources](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListEventSources.html) | To retrieve a list of event sources shared with this account | List | 
| <a name="events-ListPartnerEventSourceAccounts"></a>[ListPartnerEventSourceAccounts](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListPartnerEventSourceAccounts.html) | Retrieve a list of AWS account IDs associated with an event source | List | 
| <a name="events-ListPartnerEventSources"></a>[ListPartnerEventSources](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListPartnerEventSources.html) | Retrieve a list partner event sources | List | 
| <a name="events-ListReplays"></a>[ListReplays](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListReplays.html) | Retrieve a list of replays | List | 
| <a name="events-ListRuleNamesByTarget"></a>[ListRuleNamesByTarget](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListRuleNamesByTarget.html) | Retrieve a list of the names of the rules associated with a target | List | 
| <a name="events-ListRules"></a>[ListRules](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListRules.html) | Retrieve a list of the Amazon EventBridge rules in the account | List | 
| <a name="events-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListTagsForResource.html) | Retrieve a list of tags associated with an Amazon EventBridge resource | List | 
| <a name="events-ListTargetsByRule"></a>[ListTargetsByRule](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_ListTargetsByRule.html) | Retrieve a list of targets defined for a rule | List | 
| <a name="events-TestEventPattern"></a>[TestEventPattern](https://docs.aws.amazon.com/eventbridge/latest/APIReference/API_TestEventPattern.html) | Test whether an event pattern matches the provided event | Read |
