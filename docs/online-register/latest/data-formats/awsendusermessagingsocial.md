

# Data retrieval APIs for AWS End User Messaging Social
<a name="awsendusermessagingsocial"></a>

AWS End User Messaging Social provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="social-messaging-GetLinkedWhatsAppBusinessAccount"></a>[GetLinkedWhatsAppBusinessAccount](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_GetLinkedWhatsAppBusinessAccount.html) | View the details of a WhatsApp Business Account | Read | 
| <a name="social-messaging-GetLinkedWhatsAppBusinessAccountPhoneNumber"></a>[GetLinkedWhatsAppBusinessAccountPhoneNumber](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_GetLinkedWhatsAppBusinessAccountPhoneNumber.html) | View the details of a phone number | Read | 
| <a name="social-messaging-GetWhatsAppFlow"></a>[GetWhatsAppFlow](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_GetWhatsAppFlow.html) | Retrieve the metadata and status of a WhatsApp Flow | Read | 
| <a name="social-messaging-GetWhatsAppFlowPreview"></a>[GetWhatsAppFlowPreview](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_GetWhatsAppFlowPreview.html) | Generate a web preview URL for testing a WhatsApp Flow | Read | 
| <a name="social-messaging-GetWhatsAppMessageTemplate"></a>[GetWhatsAppMessageTemplate](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_GetWhatsAppMessageTemplate.html) | Get details of a WhatsApp message template | Read | 
| <a name="social-messaging-ListLinkedWhatsAppBusinessAccounts"></a>[ListLinkedWhatsAppBusinessAccounts](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListLinkedWhatsAppBusinessAccounts.html) | View all of your WhatsApp Business Accounts | List | 
| <a name="social-messaging-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read | 
| <a name="social-messaging-ListWhatsAppFlowAssets"></a>[ListWhatsAppFlowAssets](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListWhatsAppFlowAssets.html) | List the assets of a WhatsApp Flow | List | 
| <a name="social-messaging-ListWhatsAppFlows"></a>[ListWhatsAppFlows](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListWhatsAppFlows.html) | List all WhatsApp Flows for a WhatsApp Business Account | List | 
| <a name="social-messaging-ListWhatsAppMessageTemplates"></a>[ListWhatsAppMessageTemplates](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListWhatsAppMessageTemplates.html) | List WhatsApp message templates | List | 
| <a name="social-messaging-ListWhatsAppTemplateLibrary"></a>[ListWhatsAppTemplateLibrary](https://docs.aws.amazon.com/social-messaging/latest/APIReference/API_ListWhatsAppTemplateLibrary.html) | List available templates from Meta's template library | List |
