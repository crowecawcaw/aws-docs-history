# Data retrieval APIs for Amazon Neptune Analytics

Amazon Neptune Analytics provides the following APIs for data retrieval.

| Actions                                                                                                                                                                            | Description                                           | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------ |
| [GetEngineStatus](../../../neptune-analytics/latest/apiref.md#GetEngineStatus "../../../neptune-analytics/latest/apiref.md#GetEngineStatus")                                       | Get the engine status of the graph                    | Read         |
| [GetExportTask](../../../neptune-analytics/latest/apiref/API_GetExportTask.md "../../../neptune-analytics/latest/apiref/API_GetExportTask.md")                                     | Get details about an export task                      | Read         |
| [GetGraph](../../../neptune-analytics/latest/apiref/API_GetGraph.md "../../../neptune-analytics/latest/apiref/API_GetGraph.md")                                                    | Get details about a graph                             | Read         |
| [GetGraphSnapshot](../../../neptune-analytics/latest/apiref/API_GetGraphSnapshot.md "../../../neptune-analytics/latest/apiref/API_GetGraphSnapshot.md")                            | Get details about a snapshot                          | Read         |
| [GetGraphSummary](../../../neptune-analytics/latest/apiref/API_GetGraphSummary.md "../../../neptune-analytics/latest/apiref/API_GetGraphSummary.md")                               | Get the summary for the data in the graph             | Read         |
| [GetImportTask](../../../neptune-analytics/latest/apiref/API_GetImportTask.md "../../../neptune-analytics/latest/apiref/API_GetImportTask.md")                                     | Get details about an import task                      | Read         |
| [GetPrivateGraphEndpoint](../../../neptune-analytics/latest/apiref/API_GetPrivateGraphEndpoint.md "../../../neptune-analytics/latest/apiref/API_GetPrivateGraphEndpoint.md")       | Get details about a private graph endpoint of a graph | Read         |
| [GetQueryStatus](../../../neptune-analytics/latest/apiref/API_GetQuery.md "../../../neptune-analytics/latest/apiref/API_GetQuery.md")                                              | Check the status of a given query                     | Read         |
| [GetStatisticsStatus](../../../neptune-analytics/latest/apiref.md#GetStatisticsStatus "../../../neptune-analytics/latest/apiref.md#GetStatisticsStatus")                           | Get the statistics for the data in the graph          | Read         |
| [ListExportTasks](../../../neptune-analytics/latest/apiref/API_ListExportTasks.md "../../../neptune-analytics/latest/apiref/API_ListExportTasks.md")                               | List the export tasks in your account                 | Read         |
| [ListGraphSnapshots](../../../neptune-analytics/latest/apiref/API_ListGraphSnapshots.md "../../../neptune-analytics/latest/apiref/API_ListGraphSnapshots.md")                      | List the snapshots in your account                    | Read         |
| [ListGraphs](../../../neptune-analytics/latest/apiref/API_ListGraphs.md "../../../neptune-analytics/latest/apiref/API_ListGraphs.md")                                              | List the graphs in your account                       | Read         |
| [ListImportTasks](../../../neptune-analytics/latest/apiref/API_ListImportTasks.md "../../../neptune-analytics/latest/apiref/API_ListImportTasks.md")                               | List the import tasks in your account                 | Read         |
| [ListPrivateGraphEndpoints](../../../neptune-analytics/latest/apiref/API_ListPrivateGraphEndpoints.md "../../../neptune-analytics/latest/apiref/API_ListPrivateGraphEndpoints.md") | List the private graph endpoints for a given graph    | Read         |
| [ListQueries](../../../neptune-analytics/latest/apiref/API_ListQueries.md "../../../neptune-analytics/latest/apiref/API_ListQueries.md")                                           | Check the status of all active queries                | Read         |
| [ListTagsForResource](../../../neptune-analytics/latest/apiref/API_ListTagsForResource.md "../../../neptune-analytics/latest/apiref/API_ListTagsForResource.md")                   | Lists tag for a Neptune Analytics resource            | Read         |
| [ReadDataViaQuery](../../../neptune-analytics/latest/apiref/API_ExecuteQuery.md "../../../neptune-analytics/latest/apiref/API_ExecuteQuery.md")                                    | Read data via query APIs on the graph                 | Read         |
