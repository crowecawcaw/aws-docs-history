

# Data retrieval APIs for Amazon Neptune Analytics
<a name="amazonneptuneanalytics"></a>

Amazon Neptune Analytics provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="neptune-graph-GetEngineStatus"></a>[GetEngineStatus](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/#GetEngineStatus) | Get the engine status of the graph | Read | 
| <a name="neptune-graph-GetExportTask"></a>[GetExportTask](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetExportTask.html) | Get details about an export task | Read | 
| <a name="neptune-graph-GetGraph"></a>[GetGraph](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetGraph.html) | Get details about a graph | Read | 
| <a name="neptune-graph-GetGraphSnapshot"></a>[GetGraphSnapshot](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetGraphSnapshot.html) | Get details about a snapshot | Read | 
| <a name="neptune-graph-GetGraphSummary"></a>[GetGraphSummary](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetGraphSummary.html) | Get the summary for the data in the graph | Read | 
| <a name="neptune-graph-GetImportTask"></a>[GetImportTask](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetImportTask.html) | Get details about an import task | Read | 
| <a name="neptune-graph-GetPrivateGraphEndpoint"></a>[GetPrivateGraphEndpoint](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetPrivateGraphEndpoint.html) | Get details about a private graph endpoint of a graph | Read | 
| <a name="neptune-graph-GetQueryStatus"></a>[GetQueryStatus](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_GetQuery.html) | Check the status of a given query | Read | 
| <a name="neptune-graph-GetStatisticsStatus"></a>[GetStatisticsStatus](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/#GetStatisticsStatus) | Get the statistics for the data in the graph | Read | 
| <a name="neptune-graph-ListExportTasks"></a>[ListExportTasks](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListExportTasks.html) | List the export tasks in your account | Read | 
| <a name="neptune-graph-ListGraphSnapshots"></a>[ListGraphSnapshots](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListGraphSnapshots.html) | List the snapshots in your account | Read | 
| <a name="neptune-graph-ListGraphs"></a>[ListGraphs](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListGraphs.html) | List the graphs in your account | Read | 
| <a name="neptune-graph-ListImportTasks"></a>[ListImportTasks](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListImportTasks.html) | List the import tasks in your account | Read | 
| <a name="neptune-graph-ListPrivateGraphEndpoints"></a>[ListPrivateGraphEndpoints](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListPrivateGraphEndpoints.html) | List the private graph endpoints for a given graph | Read | 
| <a name="neptune-graph-ListQueries"></a>[ListQueries](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListQueries.html) | Check the status of all active queries | Read | 
| <a name="neptune-graph-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ListTagsForResource.html) | Lists tag for a Neptune Analytics resource | Read | 
| <a name="neptune-graph-ReadDataViaQuery"></a>[ReadDataViaQuery](https://docs.aws.amazon.com/neptune-analytics/latest/apiref/API_ExecuteQuery.html) | Read data via query APIs on the graph | Read |
