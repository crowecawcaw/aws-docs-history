# Data retrieval APIs for AWS Network Firewall

AWS Network Firewall provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                 | Description                                                                | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------ |
| [DescribeFirewall](../../../network-firewall/latest/APIReference/API_DescribeFirewall.md "../../../network-firewall/latest/APIReference/API_DescribeFirewall.md")                                                       | Retrieve the data objects that define a firewall                           | Read         |
| [DescribeFirewallMetadata](../../../network-firewall/latest/APIReference/API_DescribeFirewallMetadata.md "../../../network-firewall/latest/APIReference/API_DescribeFirewallMetadata.md")                               | Retrieve the high-level information about a firewall                       | Read         |
| [DescribeFirewallPolicy](../../../network-firewall/latest/APIReference/API_DescribeFirewallPolicy.md "../../../network-firewall/latest/APIReference/API_DescribeFirewallPolicy.md")                                     | Retrieve the data objects that define a firewall policy                    | Read         |
| [DescribeFlowOperation](../../../network-firewall/latest/APIReference/API_DescribeFlowOperation.md "../../../network-firewall/latest/APIReference/API_DescribeFlowOperation.md")                                        | Describe a flow operation performed on a firewall                          | Read         |
| [DescribeLoggingConfiguration](../../../network-firewall/latest/APIReference/API_DescribeLoggingConfiguration.md "../../../network-firewall/latest/APIReference/API_DescribeLoggingConfiguration.md")                   | Describe the logging configuration of a firewall                           | Read         |
| [DescribeResourcePolicy](../../../network-firewall/latest/APIReference/API_DescribeResourcePolicy.md "../../../network-firewall/latest/APIReference/API_DescribeResourcePolicy.md")                                     | Describe a resource policy for a firewall policy or rule group or firewall | Read         |
| [DescribeRuleGroup](../../../network-firewall/latest/APIReference/API_DescribeRuleGroup.md "../../../network-firewall/latest/APIReference/API_DescribeRuleGroup.md")                                                    | Retrieve the data objects that define a rule group                         | Read         |
| [DescribeRuleGroupMetadata](../../../network-firewall/latest/APIReference/API_DescribeRuleGroupMetadata.md "../../../network-firewall/latest/APIReference/API_DescribeRuleGroupMetadata.md")                            | Retrieve the high-level information about a rule group                     | Read         |
| [DescribeRuleGroupSummary](../../../network-firewall/latest/APIReference/API_DescribeRuleGroupSummary.md "../../../network-firewall/latest/APIReference/API_DescribeRuleGroupSummary.md")                               | Retrieve the summary information about a rule group                        | Read         |
| [DescribeTLSInspectionConfiguration](../../../network-firewall/latest/APIReference/API_DescribeTLSInspectionConfiguration.md "../../../network-firewall/latest/APIReference/API_DescribeTLSInspectionConfiguration.md") | Retrieve the data objects that define a tls inspection configuration       | Read         |
| [DescribeVpcEndpointAssociation](../../../network-firewall/latest/APIReference/API_DescribeVpcEndpointAssociation.md "../../../network-firewall/latest/APIReference/API_DescribeVpcEndpointAssociation.md")             | Retrieve the data objects that define a vpc endpoint association           | Read         |
| [GetAnalysisReportResults](../../../network-firewall/latest/APIReference/API_GetAnalysisReportResults.md "../../../network-firewall/latest/APIReference/API_GetAnalysisReportResults.md")                               | Retrieve analysis report results of a firewall                             | Read         |
| [ListAnalysisReports](../../../network-firewall/latest/APIReference/API_ListAnalysisReports.md "../../../network-firewall/latest/APIReference/API_ListAnalysisReports.md")                                              | List firewall analysis reports                                             | List         |
| [ListFirewallPolicies](../../../network-firewall/latest/APIReference/API_ListFirewallPolicies.md "../../../network-firewall/latest/APIReference/API_ListFirewallPolicies.md")                                           | Retrieve the metadata for firewall policies                                | List         |
| [ListFirewalls](../../../network-firewall/latest/APIReference/API_ListFirewalls.md "../../../network-firewall/latest/APIReference/API_ListFirewalls.md")                                                                | Retrieve the metadata for firewalls                                        | List         |
| [ListFlowOperationResults](../../../network-firewall/latest/APIReference/API_ListFlowOperationResults.md "../../../network-firewall/latest/APIReference/API_ListFlowOperationResults.md")                               | List results from a flow operation performed on a firewall                 | Read         |
| [ListFlowOperations](../../../network-firewall/latest/APIReference/API_ListFlowOperations.md "../../../network-firewall/latest/APIReference/API_ListFlowOperations.md")                                                 | List flow operations performed on a firewall                               | List         |
| [ListRuleGroups](../../../network-firewall/latest/APIReference/API_ListRuleGroups.md "../../../network-firewall/latest/APIReference/API_ListRuleGroups.md")                                                             | Retrieve the metadata for rule groups                                      | List         |
| [ListTLSInspectionConfigurations](../../../network-firewall/latest/APIReference/API_ListTLSInspectionConfigurations.md "../../../network-firewall/latest/APIReference/API_ListTLSInspectionConfigurations.md")          | Retrieve the metadata for tls inspection configurations                    | List         |
| [ListTagsForResource](../../../network-firewall/latest/APIReference/API_ListTagsForResource.md "../../../network-firewall/latest/APIReference/API_ListTagsForResource.md")                                              | Retrieve the tags for a resource                                           | List         |
| [ListVpcEndpointAssociations](../../../network-firewall/latest/APIReference/API_ListVpcEndpointAssociations.md "../../../network-firewall/latest/APIReference/API_ListVpcEndpointAssociations.md")                      | Retrieve the metadata for vpc endpoint associations                        | List         |
