

# Data retrieval APIs for AWS Network Firewall
<a name="awsnetworkfirewall"></a>

AWS Network Firewall provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="network-firewall-DescribeContainerAssociation"></a>[DescribeContainerAssociation](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeContainerAssociation.html) | Retrieve the data objects that define a container association | Read | 
| <a name="network-firewall-DescribeFirewall"></a>[DescribeFirewall](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeFirewall.html) | Retrieve the data objects that define a firewall | Read | 
| <a name="network-firewall-DescribeFirewallMetadata"></a>[DescribeFirewallMetadata](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeFirewallMetadata.html) | Retrieve the high-level information about a firewall | Read | 
| <a name="network-firewall-DescribeFirewallPolicy"></a>[DescribeFirewallPolicy](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeFirewallPolicy.html) | Retrieve the data objects that define a firewall policy | Read | 
| <a name="network-firewall-DescribeFlowOperation"></a>[DescribeFlowOperation](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeFlowOperation.html) | Describe a flow operation performed on a firewall | Read | 
| <a name="network-firewall-DescribeLoggingConfiguration"></a>[DescribeLoggingConfiguration](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeLoggingConfiguration.html) | Describe the logging configuration of a firewall | Read | 
| <a name="network-firewall-DescribeProxy"></a>[DescribeProxy](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeProxy.html) | Retrieve the data objects that define a proxy | Read | 
| <a name="network-firewall-DescribeProxyConfiguration"></a>[DescribeProxyConfiguration](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeProxyConfiguration.html) | Retrieve the data objects that define a proxy configuration | Read | 
| <a name="network-firewall-DescribeProxyRule"></a>[DescribeProxyRule](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeProxyRule.html) | Retrieve the data objects that define a proxy rule | Read | 
| <a name="network-firewall-DescribeProxyRuleGroup"></a>[DescribeProxyRuleGroup](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeProxyRuleGroup.html) | Retrieve the data objects that define a proxy rule group | Read | 
| <a name="network-firewall-DescribeResourcePolicy"></a>[DescribeResourcePolicy](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeResourcePolicy.html) | Describe a resource policy for a firewall policy or rule group or firewall | Read | 
| <a name="network-firewall-DescribeRuleGroup"></a>[DescribeRuleGroup](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeRuleGroup.html) | Retrieve the data objects that define a rule group | Read | 
| <a name="network-firewall-DescribeRuleGroupMetadata"></a>[DescribeRuleGroupMetadata](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeRuleGroupMetadata.html) | Retrieve the high-level information about a rule group | Read | 
| <a name="network-firewall-DescribeRuleGroupSummary"></a>[DescribeRuleGroupSummary](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeRuleGroupSummary.html) | Retrieve the summary information about a rule group | Read | 
| <a name="network-firewall-DescribeTLSInspectionConfiguration"></a>[DescribeTLSInspectionConfiguration](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeTLSInspectionConfiguration.html) | Retrieve the data objects that define a tls inspection configuration | Read | 
| <a name="network-firewall-DescribeVpcEndpointAssociation"></a>[DescribeVpcEndpointAssociation](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_DescribeVpcEndpointAssociation.html) | Retrieve the data objects that define a vpc endpoint association | Read | 
| <a name="network-firewall-GetAnalysisReportResults"></a>[GetAnalysisReportResults](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_GetAnalysisReportResults.html) | Retrieve analysis report results of a firewall | Read |

| <a name="network-firewall-ListFirewallPolicies"></a>[ListFirewallPolicies](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_ListFirewallPolicies.html) | Retrieve the metadata for firewall policies | List | 
| <a name="network-firewall-ListFirewalls"></a>[ListFirewalls](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_ListFirewalls.html) | Retrieve the metadata for firewalls | List | 
| <a name="network-firewall-ListFlowOperationResults"></a>[ListFlowOperationResults](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_ListFlowOperationResults.html) | List results from a flow operation performed on a firewall | Read | 
| <a name="network-firewall-ListFlowOperations"></a>[ListFlowOperations](https://docs.aws.amazon.com/network-firewall/latest/APIReference/API_ListFlowOperations.html) | List flow operations performed on a firewall | List |
