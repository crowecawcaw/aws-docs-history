

# Data retrieval APIs for Amazon Resource Group Tagging API
<a name="amazonresourcegrouptaggingapi"></a>

Amazon Resource Group Tagging API provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="tag-DescribeReportCreation"></a>[DescribeReportCreation](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_DescribeReportCreation.html) | Describe the status of the StartReportCreation operation | Read | 
| <a name="tag-GetComplianceSummary"></a>[GetComplianceSummary](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_GetComplianceSummary.html) | Retrieve a summary of how many resources are noncompliant with their effective tag policies | Read | 
| <a name="tag-GetResources"></a>[GetResources](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_GetResources.html) | Return tagged or previously tagged resources in the specified AWS Region for the calling account | Read | 
| <a name="tag-GetTagKeys"></a>[GetTagKeys](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_GetTagKeys.html) | Returns tag keys currently in use in the specified AWS Region for the calling account | Read | 
| <a name="tag-GetTagValues"></a>[GetTagValues](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_GetTagValues.html) | Return tag values for the specified key that are used in the specified AWS Region for the calling account | Read | 
| <a name="tag-ListRequiredTags"></a>[ListRequiredTags](https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/API_ListRequiredTags.html) | List required tags for supported resource types in the calling account | List |
