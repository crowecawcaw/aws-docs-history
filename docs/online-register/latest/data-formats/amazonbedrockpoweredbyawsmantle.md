# Data retrieval APIs for Amazon Bedrock Powered by AWS Mantle

Amazon Bedrock Powered by AWS Mantle provides the following APIs for data retrieval.

| Actions                                                                                                                              | Description                                      | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | ------------ |
| [CallWithBearerToken](#welcome "#welcome")                                                                                           | Make API calls using bearer token authentication | List         |
| [CountTokens](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                     | Count the tokens in an inference request         | Read         |
| [GetAccountDataRetention](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")         | Retrieve the account-wide data retention setting | Read         |
| [GetCustomizedModel](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")              | Get customized model                             | Read         |
| [GetFile](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                         | Retrieve information about a specific file       | Read         |
| [GetFineTuningJob](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                | Retrieve details of a specific fine tuning job   | Read         |
| [GetInference](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                    | Retrieve details of a specific inference request | Read         |
| [GetModel](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                        | Retrieve information about a specific model      | Read         |
| [GetProject](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                      | Retrieve details of a specific project           | Read         |
| [GetReservation](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                  | Get reservation                                  | Read         |
| [ListCustomizedModelAssociations](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome") | List project associations for a customized model | List         |
| [ListCustomizedModels](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")            | List customized models                           | List         |
| [ListFiles](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                       | List all available files in a project            | List         |
| [ListFineTuningJobs](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")              | List all available fine tuning jobs in a project | List         |
| [ListModels](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                      | List all available models in a project           | List         |
| [ListProjects](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                    | List projects                                    | List         |
| [ListReservations](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")                | List reservations                                | List         |
| [ListTagsForResource](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")             | List tags for a resource                         | Read         |
