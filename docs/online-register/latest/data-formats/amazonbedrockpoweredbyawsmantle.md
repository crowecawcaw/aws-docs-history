

# Data retrieval APIs for Amazon Bedrock Powered by AWS Mantle
<a name="amazonbedrockpoweredbyawsmantle"></a>

Amazon Bedrock Powered by AWS Mantle provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="bedrock-mantle-CallWithBearerToken"></a>[CallWithBearerToken](#welcome) | Make API calls using bearer token authentication | List | 
| <a name="bedrock-mantle-CountTokens"></a>[CountTokens](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Count the tokens in an inference request | Read | 
| <a name="bedrock-mantle-GetAccountDataRetention"></a>[GetAccountDataRetention](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve the account-wide data retention setting | Read | 
| <a name="bedrock-mantle-GetCustomizedModel"></a>[GetCustomizedModel](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Get customized model | Read | 
| <a name="bedrock-mantle-GetFile"></a>[GetFile](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve information about a specific file | Read | 
| <a name="bedrock-mantle-GetFineTuningJob"></a>[GetFineTuningJob](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific fine tuning job | Read | 
| <a name="bedrock-mantle-GetInference"></a>[GetInference](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific inference request | Read | 
| <a name="bedrock-mantle-GetModel"></a>[GetModel](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve information about a specific model | Read | 
| <a name="bedrock-mantle-GetProject"></a>[GetProject](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific project | Read | 
| <a name="bedrock-mantle-GetReservation"></a>[GetReservation](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Get reservation | Read | 
| <a name="bedrock-mantle-ListCustomizedModelAssociations"></a>[ListCustomizedModelAssociations](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List project associations for a customized model | List | 
| <a name="bedrock-mantle-ListCustomizedModels"></a>[ListCustomizedModels](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List customized models | List | 
| <a name="bedrock-mantle-ListFiles"></a>[ListFiles](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List all available files in a project | List | 
| <a name="bedrock-mantle-ListFineTuningJobs"></a>[ListFineTuningJobs](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List all available fine tuning jobs in a project | List | 
| <a name="bedrock-mantle-ListModels"></a>[ListModels](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List all available models in a project | List | 
| <a name="bedrock-mantle-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List projects | List | 
| <a name="bedrock-mantle-ListReservations"></a>[ListReservations](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List reservations | List | 
| <a name="bedrock-mantle-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List tags for a resource | Read |
