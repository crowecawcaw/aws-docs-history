# Data retrieval APIs for Amazon Bedrock Powered by AWS Mantle

Amazon Bedrock Powered by AWS Mantle provides the following APIs for data retrieval.

| Actions                                                                                                           | Description                                      | Access level |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------ |
| [CallWithBearerToken](#welcome "#welcome")                                                                        | Make API calls using bearer token authentication | List         |
| [GetInference](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome") | Retrieve details of a specific inference request | Read         |
| [GetModel](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")     | Retrieve information about a specific model      | Read         |
| [ListModels](../../../bedrock/latest/APIReference.md#welcome "../../../bedrock/latest/APIReference.md#welcome")   | List all available models in a project           | List         |
