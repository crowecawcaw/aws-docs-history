# Data retrieval APIs for AWS Serverless Application Repository

AWS Serverless Application Repository provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                              | Description                                                            | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------ |
| [GetApplication](../../../serverlessrepo/latest/devguide/applications-applicationid.md "../../../serverlessrepo/latest/devguide/applications-applicationid.md")                                                      | Get the specified application                                          | Read         |
| [GetApplicationPolicy](../../../serverlessrepo/latest/devguide/applications-applicationid-policy.md "../../../serverlessrepo/latest/devguide/applications-applicationid-policy.md")                                  | Get the policy for the specified application                           | Read         |
| [GetCloudFormationTemplate](../../../serverlessrepo/latest/devguide/applications-applicationid-templates-templateid.md "../../../serverlessrepo/latest/devguide/applications-applicationid-templates-templateid.md") | Get the specified AWS CloudFormation template                          | Read         |
| [ListApplicationDependencies](../../../serverlessrepo/latest/devguide/applications-applicationid-dependencies.md "../../../serverlessrepo/latest/devguide/applications-applicationid-dependencies.md")               | Retrieve the list of applications nested in the containing application | List         |
| [ListApplicationVersions](../../../serverlessrepo/latest/devguide/applications-applicationid-versions.md "../../../serverlessrepo/latest/devguide/applications-applicationid-versions.md")                           | List versions for the specified application owned by the requester     | List         |
| [ListApplications](../../../serverlessrepo/latest/devguide/applications.md "../../../serverlessrepo/latest/devguide/applications.md")                                                                                | List applications owned by the requester                               | List         |
| [SearchApplications](../../../serverlessrepo/latest/devguide/applications-applicationid.md "../../../serverlessrepo/latest/devguide/applications-applicationid.md")                                                  | Get all applications authorized for this user                          | Read         |
