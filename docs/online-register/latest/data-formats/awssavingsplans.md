

# Data retrieval APIs for AWS Savings Plans
<a name="awssavingsplans"></a>

AWS Savings Plans provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="savingsplans-DescribeSavingsPlanRates"></a>[DescribeSavingsPlanRates](https://docs.aws.amazon.com/savingsplans/latest/APIReference/API_DescribeSavingsPlanRates.html) | Describe the rates associated with customers savings plan | Read | 
| <a name="savingsplans-DescribeSavingsPlans"></a>[DescribeSavingsPlans](https://docs.aws.amazon.com/savingsplans/latest/APIReference/API_DescribeSavingsPlans.html) | Describe the savings plans associated with customers account | Read | 
| <a name="savingsplans-DescribeSavingsPlansOfferingRates"></a>[DescribeSavingsPlansOfferingRates](https://docs.aws.amazon.com/savingsplans/latest/APIReference/API_DescribeSavingsPlansOfferingRates.html) | Describe the rates assciated with savings plans offerings | Read | 
| <a name="savingsplans-DescribeSavingsPlansOfferings"></a>[DescribeSavingsPlansOfferings](https://docs.aws.amazon.com/savingsplans/latest/APIReference/API_DescribeSavingsPlansOfferings.html) | Describe the savings plans offerings that customer is eligible to purchase | Read | 
| <a name="savingsplans-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/savingsplans/latest/APIReference/API_ListTagsForResource.html) | List tags for a savings plan | List |
