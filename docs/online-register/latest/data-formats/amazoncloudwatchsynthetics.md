

# Data retrieval APIs for Amazon CloudWatch Synthetics
<a name="amazoncloudwatchsynthetics"></a>

Amazon CloudWatch Synthetics provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="synthetics-DescribeCanaries"></a>[DescribeCanaries](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_DescribeCanaries.html) | List information of all canaries | Read | 
| <a name="synthetics-DescribeCanariesLastRun"></a>[DescribeCanariesLastRun](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_DescribeCanariesLastRun.html) | List information about the last test run associated with all canaries | Read | 
| <a name="synthetics-DescribeRuntimeVersions"></a>[DescribeRuntimeVersions](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_DescribeRuntimeVersions.html) | List information about Synthetics canary runtime versions | Read | 
| <a name="synthetics-GetCanary"></a>[GetCanary](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_GetCanary.html) | View the details of a canary | Read | 
| <a name="synthetics-GetCanaryRuns"></a>[GetCanaryRuns](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_GetCanaryRuns.html) | List information about all the test runs associated with a canary | Read | 
| <a name="synthetics-GetGroup"></a>[GetGroup](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_GetGroup.html) | View the details of a group | Read | 
| <a name="synthetics-ListAssociatedGroups"></a>[ListAssociatedGroups](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_ListAssociatedGroups.html) | List information about the associated groups of a canary | List | 
| <a name="synthetics-ListGroupResources"></a>[ListGroupResources](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_ListGroupResources.html) | List information about canaries in a group | List | 
| <a name="synthetics-ListGroups"></a>[ListGroups](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_ListGroups.html) | List information of all groups | List | 
| <a name="synthetics-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/AmazonSynthetics/latest/APIReference/API_ListTagsForResource.html) | List all tags and values associated with a resource | Read |
