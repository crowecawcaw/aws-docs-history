# Data retrieval APIs for Amazon CloudWatch Synthetics

Amazon CloudWatch Synthetics provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                | Description                                                           | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------ |
| [DescribeCanaries](../../../AmazonSynthetics/latest/APIReference/API_DescribeCanaries.md "../../../AmazonSynthetics/latest/APIReference/API_DescribeCanaries.md")                      | List information of all canaries                                      | Read         |
| [DescribeCanariesLastRun](../../../AmazonSynthetics/latest/APIReference/API_DescribeCanariesLastRun.md "../../../AmazonSynthetics/latest/APIReference/API_DescribeCanariesLastRun.md") | List information about the last test run associated with all canaries | Read         |
| [DescribeRuntimeVersions](../../../AmazonSynthetics/latest/APIReference/API_DescribeRuntimeVersions.md "../../../AmazonSynthetics/latest/APIReference/API_DescribeRuntimeVersions.md") | List information about Synthetics canary runtime versions             | Read         |
| [GetCanary](../../../AmazonSynthetics/latest/APIReference/API_GetCanary.md "../../../AmazonSynthetics/latest/APIReference/API_GetCanary.md")                                           | View the details of a canary                                          | Read         |
| [GetCanaryRuns](../../../AmazonSynthetics/latest/APIReference/API_GetCanaryRuns.md "../../../AmazonSynthetics/latest/APIReference/API_GetCanaryRuns.md")                               | List information about all the test runs associated with a canary     | Read         |
| [GetGroup](../../../AmazonSynthetics/latest/APIReference/API_GetGroup.md "../../../AmazonSynthetics/latest/APIReference/API_GetGroup.md")                                              | View the details of a group                                           | Read         |
| [ListAssociatedGroups](../../../AmazonSynthetics/latest/APIReference/API_ListAssociatedGroups.md "../../../AmazonSynthetics/latest/APIReference/API_ListAssociatedGroups.md")          | List information about the associated groups of a canary              | List         |
| [ListGroupResources](../../../AmazonSynthetics/latest/APIReference/API_ListGroupResources.md "../../../AmazonSynthetics/latest/APIReference/API_ListGroupResources.md")                | List information about canaries in a group                            | List         |
| [ListGroups](../../../AmazonSynthetics/latest/APIReference/API_ListGroups.md "../../../AmazonSynthetics/latest/APIReference/API_ListGroups.md")                                        | List information of all groups                                        | List         |
| [ListTagsForResource](../../../AmazonSynthetics/latest/APIReference/API_ListTagsForResource.md "../../../AmazonSynthetics/latest/APIReference/API_ListTagsForResource.md")             | List all tags and values associated with a resource                   | Read         |
