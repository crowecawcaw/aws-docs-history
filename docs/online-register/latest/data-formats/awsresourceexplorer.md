# Data retrieval APIs for AWS Resource Explorer

AWS Resource Explorer provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                      | Description                                                                                                                 | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetView](../../../resource-explorer/latest/apireference/API_BatchGetView.md "../../../resource-explorer/latest/apireference/API_BatchGetView.md")                                                                      | Retrieve details about views that you specify by a list of ARNs                                                             | Read         |
| [GetAccountLevelServiceConfiguration](../../../resource-explorer/latest/apireference/API_GetAccountLevelServiceConfiguration.md "../../../resource-explorer/latest/apireference/API_GetAccountLevelServiceConfiguration.md") | Resource Explorer to access account level data within your AWS Organization                                                 | Read         |
| [GetDefaultView](../../../resource-explorer/latest/apireference/API_GetDefaultView.md "../../../resource-explorer/latest/apireference/API_GetDefaultView.md")                                                                | Retrieve the Amazon resource name (ARN) of the view that is the default for the AWS Region in which you call this operation | Read         |
| [GetIndex](../../../resource-explorer/latest/apireference/API_GetIndex.md "../../../resource-explorer/latest/apireference/API_GetIndex.md")                                                                                  | Retrieve information about the index in the AWS Region in which you call this operation                                     | Read         |
| [GetManagedView](../../../resource-explorer/latest/apireference/API_GetManagedView.md "../../../resource-explorer/latest/apireference/API_GetManagedView.md")                                                                | Get managed view                                                                                                            | Read         |
| GetResourceExplorerSetup                                                                                                                                                                                                     | Get resource explorer setup                                                                                                 | Read         |
| [GetResourcePolicy](../../../resource-explorer/latest/userguide/manage-views-share.md "../../../resource-explorer/latest/userguide/manage-views-share.md")                                                                   | Retrieve information about the specified view's resource policy                                                             | Read         |
| GetServiceIndex                                                                                                                                                                                                              | Get service index                                                                                                           | Read         |
| GetServiceView                                                                                                                                                                                                               | Get service view                                                                                                            | Read         |
| [GetView](../../../resource-explorer/latest/apireference/API_GetView.md "../../../resource-explorer/latest/apireference/API_GetView.md")                                                                                     | Retrieve information about the specified view                                                                               | Read         |
| [ListIndexes](../../../resource-explorer/latest/apireference/API_ListIndexes.md "../../../resource-explorer/latest/apireference/API_ListIndexes.md")                                                                         | List the indexes in all AWS Regions                                                                                         | List         |
| [ListIndexesForMembers](../../../resource-explorer/latest/apireference/API_ListIndexesForMembers.md "../../../resource-explorer/latest/apireference/API_ListIndexesForMembers.md")                                           | List the organization member account's indexes in all AWS Regions                                                           | List         |
| [ListManagedViews](../../../resource-explorer/latest/apireference/API_ListManagedViews.md "../../../resource-explorer/latest/apireference/API_ListManagedViews.md")                                                          | List managed views                                                                                                          | List         |
| ListServiceIndexes                                                                                                                                                                                                           | List service indexes in all AWS Regions                                                                                     | List         |
| ListServiceViews                                                                                                                                                                                                             | List service views in all AWS Regions                                                                                       | List         |
| ListStreamingAccessForServices                                                                                                                                                                                               | List streaming access for services                                                                                          | List         |
| [ListSupportedResourceTypes](../../../resource-explorer/latest/apireference/API_ListSupportedResourceTypes.md "../../../resource-explorer/latest/apireference/API_ListSupportedResourceTypes.md")                            | Retrieve a list of all resource types currently supported by Resource Explorer                                              | List         |
| [ListTagsForResource](../../../resource-explorer/latest/apireference/API_ListTagsForResource.md "../../../resource-explorer/latest/apireference/API_ListTagsForResource.md")                                                 | List the tags that are attached to the specified resource                                                                   | Read         |
| [ListViews](../../../resource-explorer/latest/apireference/API_ListViews.md "../../../resource-explorer/latest/apireference/API_ListViews.md")                                                                               | List the Amazon resource names (ARNs) of all of the views available in the AWS Region in which you call this operation      | List         |
| [Search](../../../resource-explorer/latest/apireference/API_Search.md "../../../resource-explorer/latest/apireference/API_Search.md")                                                                                        | Search for resources and display details about all resources that match the specified criteria                              | Read         |
