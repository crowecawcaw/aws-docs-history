# Data retrieval APIs for AWS User Notifications Contacts

AWS User Notifications Contacts provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                                        | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------ |
| [GetEmailContact](../../../notifications/latest/userguide/resource-level-permissions.md "../../../notifications/latest/userguide/resource-level-permissions.md")     | Get an email contact associated with the given ARN | Read         |
| [ListEmailContacts](../../../notifications/latest/userguide/resource-level-permissions.md "../../../notifications/latest/userguide/resource-level-permissions.md")   | List email contacts                                | List         |
| [ListTagsForResource](../../../notifications/latest/userguide/resource-level-permissions.md "../../../notifications/latest/userguide/resource-level-permissions.md") | Get tags for a resource                            | Read         |
