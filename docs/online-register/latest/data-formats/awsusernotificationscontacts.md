

# Data retrieval APIs for AWS User Notifications Contacts
<a name="awsusernotificationscontacts"></a>

AWS User Notifications Contacts provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="notifications-contacts-GetEmailContact"></a>[GetEmailContact](https://docs.aws.amazon.com/notifications/latest/userguide/resource-level-permissions.html) | Get an email contact associated with the given ARN | Read | 
| <a name="notifications-contacts-ListEmailContacts"></a>[ListEmailContacts](https://docs.aws.amazon.com/notifications/latest/userguide/resource-level-permissions.html) | List email contacts | List | 
| <a name="notifications-contacts-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/notifications/latest/userguide/resource-level-permissions.html) | Get tags for a resource | Read |
