# Data retrieval APIs for Amazon DocumentDB Elastic Clusters

Amazon DocumentDB Elastic Clusters provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                          | Description                                                                        | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------ |
| [GetCluster](../../../documentdb/latest/developerguide/API_elastic_GetCluster.md "../../../documentdb/latest/developerguide/API_elastic_GetCluster.md")                                                          | View details about a cluster                                                       | Read         |
| [GetClusterSnapshot](../../../documentdb/latest/developerguide/API_elastic_GetClusterSnapshot.md "../../../documentdb/latest/developerguide/API_elastic_GetClusterSnapshot.md")                                  | View details about a cluster snapshot                                              | Read         |
| [GetPendingMaintenanceAction](../../../documentdb/latest/developerguide/API_elastic_GetPendingMaintenanceAction.md "../../../documentdb/latest/developerguide/API_elastic_GetPendingMaintenanceAction.md")       | View details about pending maintenance actions on Amazon DocDB-Elastic cluster     | Read         |
| [ListClusterSnapshots](../../../documentdb/latest/developerguide/API_elastic_ListClusterSnapshots.md "../../../documentdb/latest/developerguide/API_elastic_ListClusterSnapshots.md")                            | List the cluster snapshots in your account                                         | List         |
| [ListClusters](../../../documentdb/latest/developerguide/API_elastic_ListClusters.md "../../../documentdb/latest/developerguide/API_elastic_ListClusters.md")                                                    | List the clusters in your account                                                  | List         |
| [ListPendingMaintenanceActions](../../../documentdb/latest/developerguide/API_elastic_ListPendingMaintenanceActions.md "../../../documentdb/latest/developerguide/API_elastic_ListPendingMaintenanceActions.md") | List details about pending maintenance actions on any Amazon DocDB-Elastic cluster | List         |
| [ListTagsForResource](../../../documentdb/latest/developerguide/API_elastic_ListTagsForResource.md "../../../documentdb/latest/developerguide/API_elastic_ListTagsForResource.md")                               | Lists tag for an DocumentDB Elastic resource                                       | List         |
