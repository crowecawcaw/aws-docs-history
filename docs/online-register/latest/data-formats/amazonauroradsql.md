# Data retrieval APIs for Amazon Aurora DSQL

Amazon Aurora DSQL provides the following APIs for data retrieval.

| Actions                                                                                                                                                                            | Description                                                     | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------ |
| [GetBackupJob](../../../aurora-dsql/latest/userguide/backup-aurora-dsql.md "../../../aurora-dsql/latest/userguide/backup-aurora-dsql.md")                                          | Get the status of an Aurora DSQL cluster backup job             | Read         |
| [GetCluster](../../../aurora-dsql/latest/APIReference/API_GetCluster.md "../../../aurora-dsql/latest/APIReference/API_GetCluster.md")                                              | Get information about a cluster                                 | Read         |
| [GetClusterPolicy](../../../aurora-dsql/latest/APIReference/rbp-api-operations.md "../../../aurora-dsql/latest/APIReference/rbp-api-operations.md")                                | Retrieve the inline resource-based policy attached to a cluster | Read         |
| [GetRestoreJob](../../../aurora-dsql/latest/userguide/backup-aurora-dsql.md "../../../aurora-dsql/latest/userguide/backup-aurora-dsql.md")                                         | Get the status of an Aurora DSQL cluster restore job            | Read         |
| [GetVpcEndpointServiceName](../../../aurora-dsql/latest/APIReference/API_GetVpcEndpointServiceName.md "../../../aurora-dsql/latest/APIReference/API_GetVpcEndpointServiceName.md") | Retrieve the VPC endpoint service name for a cluster            | Read         |
| [ListClusters](../../../aurora-dsql/latest/APIReference/API_ListClusters.md "../../../aurora-dsql/latest/APIReference/API_ListClusters.md")                                        | Retrieve a list of clusters                                     | List         |
| [ListTagsForResource](../../../aurora-dsql/latest/APIReference/API_ListTagsForResource.md "../../../aurora-dsql/latest/APIReference/API_ListTagsForResource.md")                   | List all tags on an Aurora DSQL resource                        | Read         |
