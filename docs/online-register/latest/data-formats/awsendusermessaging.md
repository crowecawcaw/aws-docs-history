

# Data retrieval APIs for AWS End User Messaging
<a name="awsendusermessaging"></a>

AWS End User Messaging provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="end-user-messaging-GetBrandProfile"></a>[GetBrandProfile](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_GetBrandProfile.html) | Get a brand profile | Read | 
| <a name="end-user-messaging-GetBrandProfileAttribute"></a>[GetBrandProfileAttribute](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_GetBrandProfileAttribute.html) | Get a brand profile attribute | Read | 
| <a name="end-user-messaging-GetJob"></a>[GetJob](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_GetJob.html) | Get the details of an asynchronous job | Read | 
| <a name="end-user-messaging-GetNotifyCodeConfiguration"></a>[GetNotifyCodeConfiguration](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_GetNotifyCodeConfiguration.html) | Get a notify code configuration | Read | 
| <a name="end-user-messaging-ListBrandProfileAttributes"></a>[ListBrandProfileAttributes](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListBrandProfileAttributes.html) | List the attributes for a brand profile | List | 
| <a name="end-user-messaging-ListBrandProfiles"></a>[ListBrandProfiles](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListBrandProfiles.html) | List brand profiles | List | 
| <a name="end-user-messaging-ListJobs"></a>[ListJobs](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListJobs.html) | List asynchronous jobs in your account | List | 
| <a name="end-user-messaging-ListNotifyCodeConfigurations"></a>[ListNotifyCodeConfigurations](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListNotifyCodeConfigurations.html) | List notify code configurations | List | 
| <a name="end-user-messaging-ListRegistrationsFromBrandProfile"></a>[ListRegistrationsFromBrandProfile](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListRegistrationsFromBrandProfile.html) | List the registrations created from a brand profile | List | 
| <a name="end-user-messaging-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/end-user-messaging/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
