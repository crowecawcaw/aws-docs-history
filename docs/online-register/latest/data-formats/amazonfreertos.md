# Data retrieval APIs for Amazon FreeRTOS

Amazon FreeRTOS provides the following APIs for data retrieval.

| Actions                                                                                                                                                                 | Description                                                                                                    | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeHardwarePlatform](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                     | Describe the hardware platform                                                                                 | Read         |
| [DescribeSoftwareConfiguration](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                | Describe the software configuration                                                                            | Read         |
| [DescribeSubscription](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md")         | Describes the subscription for FreeRTOS extended maintenance plan (EMP)                                        | Read         |
| [GetEmpPatchUrl](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md")               | Get URL for sotware patch-release, patch-diff and release notes under FreeRTOS extended maintenance plan (EMP) | Read         |
| [GetSoftwareURL](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                               | Get the URL for Amazon FreeRTOS software download                                                              | Read         |
| [GetSoftwareURLForConfiguration](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                               | Get the URL for Amazon FreeRTOS software download based on the configuration                                   | Read         |
| [GetSubscriptionBillingAmount](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md") | Fetch the subscription billing amount for FreeRTOS extended maintenance plan (EMP)                             | Read         |
| [ListFreeRTOSVersions](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                         | Lists versions of AmazonFreeRTOS                                                                               | List         |
| [ListHardwarePlatforms](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                        | List the hardware platforms                                                                                    | List         |
| [ListHardwareVendors](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                          | List the hardware vendors                                                                                      | List         |
| [ListSoftwareConfigurations](../../../freertos/latest/userguide/freertos-ocw.md "../../../freertos/latest/userguide/freertos-ocw.md")                                   | Lists the software configurations                                                                              | List         |
| [ListSoftwarePatches](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md")          | List software patches of subscription for FreeRTOS extended maintenance plan (EMP)                             | List         |
| [ListSubscriptionEmails](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md")       | List the subscription emails for FreeRTOS extended maintenance plan (EMP)                                      | List         |
| [ListSubscriptions](../../../freertos/latest/userguide/freertos-getting-started-emp.md "../../../freertos/latest/userguide/freertos-getting-started-emp.md")            | List the subscriptions for FreeRTOS extended maintenance plan (EMP)                                            | List         |
