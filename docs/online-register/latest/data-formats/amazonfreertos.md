

# Data retrieval APIs for Amazon FreeRTOS
<a name="amazonfreertos"></a>

Amazon FreeRTOS provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="freertos-DescribeHardwarePlatform"></a>[DescribeHardwarePlatform](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Describe the hardware platform | Read | 
| <a name="freertos-DescribeSoftwareConfiguration"></a>[DescribeSoftwareConfiguration](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Describe the software configuration | Read | 
| <a name="freertos-DescribeSubscription"></a>[DescribeSubscription](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | Describes the subscription for FreeRTOS extended maintenance plan (EMP) | Read | 
| <a name="freertos-GetEmpPatchUrl"></a>[GetEmpPatchUrl](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | Get URL for sotware patch-release, patch-diff and release notes under FreeRTOS extended maintenance plan (EMP) | Read | 
| <a name="freertos-GetSoftwareURL"></a>[GetSoftwareURL](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Get the URL for Amazon FreeRTOS software download | Read | 
| <a name="freertos-GetSoftwareURLForConfiguration"></a>[GetSoftwareURLForConfiguration](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Get the URL for Amazon FreeRTOS software download based on the configuration | Read | 
| <a name="freertos-GetSubscriptionBillingAmount"></a>[GetSubscriptionBillingAmount](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | Fetch the subscription billing amount for FreeRTOS extended maintenance plan (EMP) | Read | 
| <a name="freertos-ListFreeRTOSVersions"></a>[ListFreeRTOSVersions](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Lists versions of AmazonFreeRTOS | List | 
| <a name="freertos-ListHardwarePlatforms"></a>[ListHardwarePlatforms](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | List the hardware platforms | List | 
| <a name="freertos-ListHardwareVendors"></a>[ListHardwareVendors](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | List the hardware vendors | List | 
| <a name="freertos-ListSoftwareConfigurations"></a>[ListSoftwareConfigurations](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-ocw.html) | Lists the software configurations | List | 
| <a name="freertos-ListSoftwarePatches"></a>[ListSoftwarePatches](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | List software patches of subscription for FreeRTOS extended maintenance plan (EMP) | List | 
| <a name="freertos-ListSubscriptionEmails"></a>[ListSubscriptionEmails](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | List the subscription emails for FreeRTOS extended maintenance plan (EMP) | List | 
| <a name="freertos-ListSubscriptions"></a>[ListSubscriptions](https://docs.aws.amazon.com/freertos/latest/userguide/freertos-getting-started-emp.html) | List the subscriptions for FreeRTOS extended maintenance plan (EMP) | List |
