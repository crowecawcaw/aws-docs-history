

# Data retrieval APIs for AWS Migration Hub Refactor Spaces
<a name="awsmigrationhubrefactorspaces"></a>

AWS Migration Hub Refactor Spaces provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="refactor-spaces-GetApplication"></a>[GetApplication](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_GetApplication.html) | Get more information about an application | Read | 
| <a name="refactor-spaces-GetEnvironment"></a>[GetEnvironment](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_GetEnvironment.html) | Get more information for an environment | Read | 
| <a name="refactor-spaces-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_GetResourcePolicy.html) | Get the details about a resource policy | Read | 
| <a name="refactor-spaces-GetRoute"></a>[GetRoute](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_GetRoute.html) | Get more information about a route | Read | 
| <a name="refactor-spaces-GetService"></a>[GetService](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_GetService.html) | Get more information about a service | Read | 
| <a name="refactor-spaces-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListApplications.html) | List all the applications in an environment | Read | 
| <a name="refactor-spaces-ListEnvironmentVpcs"></a>[ListEnvironmentVpcs](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListEnvironmentVpcs.html) | List all the VPCs for the environment | Read | 
| <a name="refactor-spaces-ListEnvironments"></a>[ListEnvironments](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListEnvironments.html) | List all environments | Read | 
| <a name="refactor-spaces-ListRoutes"></a>[ListRoutes](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListRoutes.html) | List all the routes in an application | Read | 
| <a name="refactor-spaces-ListServices"></a>[ListServices](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListServices.html) | List all the services in an environment | Read | 
| <a name="refactor-spaces-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/migrationhub-refactor-spaces/latest/APIReference/API_ListTagsForResource.html) | List all the tags for a given resource | Read |
