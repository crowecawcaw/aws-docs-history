# Data retrieval APIs for AWS Elemental MediaStore

AWS Elemental MediaStore provides the following APIs for data retrieval.

| Actions                                                                                                                                                           | Description                                                           | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------ |
| [DescribeContainer](../../../mediastore/latest/apireference/API_DescribeContainer.md "../../../mediastore/latest/apireference/API_DescribeContainer.md")          | Retrieve details on a container                                       | List         |
| [DescribeObject](../../../mediastore/latest/apireference/API_objstore_DescribeObject.md "../../../mediastore/latest/apireference/API_objstore_DescribeObject.md") | Retrieve metadata for an object                                       | List         |
| [GetContainerPolicy](../../../mediastore/latest/apireference/API_GetContainerPolicy.md "../../../mediastore/latest/apireference/API_GetContainerPolicy.md")       | Retrieve the access policy of a container                             | Read         |
| [GetCorsPolicy](../../../mediastore/latest/apireference/API_GetCorsPolicy.md "../../../mediastore/latest/apireference/API_GetCorsPolicy.md")                      | Retrieve the CORS policy of a container                               | Read         |
| [GetLifecyclePolicy](../../../mediastore/latest/apireference/API_GetLifecyclePolicy.md "../../../mediastore/latest/apireference/API_GetLifecyclePolicy.md")       | Retrieve the lifecycle policy that is assigned to a container         | Read         |
| [GetMetricPolicy](../../../mediastore/latest/apireference/API_GetMetricPolicy.md "../../../mediastore/latest/apireference/API_GetMetricPolicy.md")                | Retrieve the metric policy that is assigned to a container            | Read         |
| [GetObject](../../../mediastore/latest/apireference/API_objstore_GetObject.md "../../../mediastore/latest/apireference/API_objstore_GetObject.md")                | Retrieve an object                                                    | Read         |
| [ListContainers](../../../mediastore/latest/apireference/API_ListContainers.md "../../../mediastore/latest/apireference/API_ListContainers.md")                   | Retrieve a list of containers in the current account                  | List         |
| [ListItems](../../../mediastore/latest/apireference/API_objstore_ListItems.md "../../../mediastore/latest/apireference/API_objstore_ListItems.md")                | Retrieve a list of objects and subfolders that are stored in a folder | List         |
| [ListTagsForResource](../../../mediastore/latest/apireference/API_ListTagsForResource.md "../../../mediastore/latest/apireference/API_ListTagsForResource.md")    | List tags on a container                                              | Read         |
