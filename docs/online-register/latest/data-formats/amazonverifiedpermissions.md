| Actions                                                                                                                                                                                | Description                                                                                                                                              | Access level |

| [GetPolicy](../../../verifiedpermissions/latest/apireference/API_GetPolicy.md "../../../verifiedpermissions/latest/apireference/API_GetPolicy.md")                                     | Retrieve information about the specified policy                                                                                                          | Read         |
| [GetPolicyStore](../../../verifiedpermissions/latest/apireference/API_GetPolicyStore.md "../../../verifiedpermissions/latest/apireference/API_GetPolicyStore.md")                      | Retrieve details about a policy store                                                                                                                    | Read         |
| [GetPolicyTemplate](../../../verifiedpermissions/latest/apireference/API_GetPolicyTemplate.md "../../../verifiedpermissions/latest/apireference/API_GetPolicyTemplate.md")             | Retrieve the details for the specified policy template in the specified policy store                                                                     | Read         |
| [GetSchema](../../../verifiedpermissions/latest/apireference/API_GetSchema.md "../../../verifiedpermissions/latest/apireference/API_GetSchema.md")                                     | Retrieve the details for the specified schema in the specified policy store                                                                              | Read         |
| [IsAuthorized](../../../verifiedpermissions/latest/apireference/API_IsAuthorized.md "../../../verifiedpermissions/latest/apireference/API_IsAuthorized.md")                            | Make an authorization decision about a service request described in the parameters                                                                       | Read         |

The principal in this request comes from an external identity source | Read         |

| [ListTagsForResource](../../../verifiedpermissions/latest/apireference/API_ListTagsForResource.md "../../../verifiedpermissions/latest/apireference/API_ListTagsForResource.md")       | View a list of resource tags for the specified policy store                                                                                              | Read         |
