

# Data retrieval APIs for Amazon Verified Permissions
<a name="amazonverifiedpermissions"></a>

Amazon Verified Permissions provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="verifiedpermissions-GetIdentitySource"></a>[GetIdentitySource](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetIdentitySource.html) | Retrieve the details about the specified identity source | Read | 
| <a name="verifiedpermissions-GetPolicy"></a>[GetPolicy](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetPolicy.html) | Retrieve information about the specified policy | Read | 
| <a name="verifiedpermissions-GetPolicyStore"></a>[GetPolicyStore](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetPolicyStore.html) | Retrieve details about a policy store | Read | 
| <a name="verifiedpermissions-GetPolicyStoreAlias"></a>[GetPolicyStoreAlias](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetPolicyStoreAlias.html) | Retrieve details about an alias for a policy store | Read | 
| <a name="verifiedpermissions-GetPolicyTemplate"></a>[GetPolicyTemplate](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetPolicyTemplate.html) | Retrieve the details for the specified policy template in the specified policy store | Read | 
| <a name="verifiedpermissions-GetSchema"></a>[GetSchema](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_GetSchema.html) | Retrieve the details for the specified schema in the specified policy store | Read | 
| <a name="verifiedpermissions-IsAuthorized"></a>[IsAuthorized](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_IsAuthorized.html) | Make an authorization decision about a service request described in the parameters | Read | 
| <a name="verifiedpermissions-IsAuthorizedWithToken"></a>[IsAuthorizedWithToken](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_IsAuthorizedWithToken.html) | Make an authorization decision about a service request described in the parameters. The principal in this request comes from an external identity source | Read | 
| <a name="verifiedpermissions-ListIdentitySources"></a>[ListIdentitySources](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListIdentitySources.html) | Return a paginated list of all of the identity sources defined in the specified policy store | List | 
| <a name="verifiedpermissions-ListPolicies"></a>[ListPolicies](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListPolicies.html) | Return a paginated list of all policies stored in the specified policy store | List | 
| <a name="verifiedpermissions-ListPolicyStoreAliases"></a>[ListPolicyStoreAliases](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListPolicyStoreAliases.html) | Return a paginated list of all policy store aliases | List | 
| <a name="verifiedpermissions-ListPolicyStores"></a>[ListPolicyStores](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListPolicyStores.html) | Return a paginated list of all policy stores in the calling Amazon Web Services account | List | 
| <a name="verifiedpermissions-ListPolicyTemplates"></a>[ListPolicyTemplates](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListPolicyTemplates.html) | Return a paginated list of all policy templates in the specified policy store | List | 
| <a name="verifiedpermissions-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/verifiedpermissions/latest/apireference/API_ListTagsForResource.html) | View a list of resource tags for the specified policy store | Read |
