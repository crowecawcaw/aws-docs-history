

# Data retrieval APIs for AWS OpsWorks
<a name="awsopsworks"></a>

AWS OpsWorks provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="opsworks-DescribeAgentVersions"></a>[DescribeAgentVersions](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeAgentVersions.html) | Describe the available AWS OpsWorks agent versions | List | 
| <a name="opsworks-DescribeApps"></a>[DescribeApps](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeApps.html) | Request a description of a specified set of apps | List | 
| <a name="opsworks-DescribeCommands"></a>[DescribeCommands](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeCommands.html) | Describe the results of specified commands | List | 
| <a name="opsworks-DescribeDeployments"></a>[DescribeDeployments](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeDeployments.html) | Request a description of a specified set of deployments | List | 
| <a name="opsworks-DescribeEcsClusters"></a>[DescribeEcsClusters](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeEcsClusters.html) | Describe Amazon ECS clusters that are registered with a stack | List | 
| <a name="opsworks-DescribeElasticIps"></a>[DescribeElasticIps](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeElasticIps.html) | Describe Elastic IP addresses | List | 
| <a name="opsworks-DescribeElasticLoadBalancers"></a>[DescribeElasticLoadBalancers](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeElasticLoadBalancers.html) | Describe a stack's Elastic Load Balancing instances | List | 
| <a name="opsworks-DescribeInstances"></a>[DescribeInstances](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeInstances.html) | Request a description of a set of instances | List | 
| <a name="opsworks-DescribeLayers"></a>[DescribeLayers](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeLayers.html) | Request a description of one or more layers in a specified stack | List | 
| <a name="opsworks-DescribeLoadBasedAutoScaling"></a>[DescribeLoadBasedAutoScaling](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeLoadBasedAutoScaling.html) | Describe load-based auto scaling configurations for specified layers | List | 
| <a name="opsworks-DescribeMyUserProfile"></a>[DescribeMyUserProfile](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeMyUserProfile.html) | Describe a user's SSH information | List | 
| <a name="opsworks-DescribeOperatingSystems"></a>[DescribeOperatingSystems](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeOperatingSystems.html) | Describe the operating systems that are supported by AWS OpsWorks Stacks | List | 
| <a name="opsworks-DescribePermissions"></a>[DescribePermissions](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribePermissions.html) | Describe the permissions for a specified stack | List | 
| <a name="opsworks-DescribeRaidArrays"></a>[DescribeRaidArrays](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeRaidArrays.html) | Describe an instance's RAID arrays | List | 
| <a name="opsworks-DescribeRdsDbInstances"></a>[DescribeRdsDbInstances](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeRdsDbInstances.html) | Describe Amazon RDS instances | List | 
| <a name="opsworks-DescribeServiceErrors"></a>[DescribeServiceErrors](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeServiceErrors.html) | Describe AWS OpsWorks service errors | List | 
| <a name="opsworks-DescribeStackProvisioningParameters"></a>[DescribeStackProvisioningParameters](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeStackProvisioningParameters.html) | Request a description of a stack's provisioning parameters | List | 
| <a name="opsworks-DescribeStackSummary"></a>[DescribeStackSummary](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeStackSummary.html) | Describe the number of layers and apps in a specified stack, and the number of instances in each state, such as running\_setup or online | List | 
| <a name="opsworks-DescribeStacks"></a>[DescribeStacks](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeStacks.html) | Request a description of one or more stacks | List | 
| <a name="opsworks-DescribeTimeBasedAutoScaling"></a>[DescribeTimeBasedAutoScaling](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeTimeBasedAutoScaling.html) | Describe time-based auto scaling configurations for specified instances | List | 
| <a name="opsworks-DescribeUserProfiles"></a>[DescribeUserProfiles](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeUserProfiles.html) | Describe specified users | List | 
| <a name="opsworks-DescribeVolumes"></a>[DescribeVolumes](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_DescribeVolumes.html) | Describe an instance's Amazon EBS volumes | List | 
| <a name="opsworks-GetHostnameSuggestion"></a>[GetHostnameSuggestion](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_GetHostnameSuggestion.html) | Get a generated host name for the specified layer, based on the current host name theme | Read | 
| <a name="opsworks-ListTags"></a>[ListTags](https://docs.aws.amazon.com/opsworks/latest/APIReference/API_ListTags.html) | Return a list of tags that are applied to the specified stack or layer | List |
