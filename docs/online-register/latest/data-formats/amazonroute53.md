

# Data retrieval APIs for Amazon Route 53
<a name="amazonroute53"></a>

Amazon Route 53 provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="route53-GetAccountLimit"></a>[GetAccountLimit](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetAccountLimit.html) | Get the specified limit for the current account, for example, the maximum number of health checks that you can create using the account | Read | 
| <a name="route53-GetChange"></a>[GetChange](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetChange.html) | Get the current status of a request to create, update, or delete one or more records | List | 
| <a name="route53-GetCheckerIpRanges"></a>[GetCheckerIpRanges](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetCheckerIpRanges.html) | Get a list of the IP ranges that are used by Route 53 health checkers to check the health of your resources | List | 
| <a name="route53-GetDNSSEC"></a>[GetDNSSEC](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetDNSSEC.html) | Get information about DNSSEC for a specific hosted zone, including the key-signing keys in the hosted zone | Read | 
| <a name="route53-GetGeoLocation"></a>[GetGeoLocation](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetGeoLocation.html) | Get information about whether a specified geographic location is supported for Route 53 geolocation records | List | 
| <a name="route53-GetHealthCheck"></a>[GetHealthCheck](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHealthCheck.html) | Get information about a specified health check | Read | 
| <a name="route53-GetHealthCheckCount"></a>[GetHealthCheckCount](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHealthCheckCount.html) | Get the number of health checks that are associated with the current AWS account | List | 
| <a name="route53-GetHealthCheckLastFailureReason"></a>[GetHealthCheckLastFailureReason](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHealthCheckLastFailureReason.html) | Get the reason that a specified health check failed most recently | List | 
| <a name="route53-GetHealthCheckStatus"></a>[GetHealthCheckStatus](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHealthCheckStatus.html) | Get the status of a specified health check | List | 
| <a name="route53-GetHostedZone"></a>[GetHostedZone](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHostedZone.html) | Get information about a specified hosted zone including the four name servers that Route 53 assigned to the hosted zone | List | 
| <a name="route53-GetHostedZoneCount"></a>[GetHostedZoneCount](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHostedZoneCount.html) | Get the number of hosted zones that are associated with the current AWS account | List | 
| <a name="route53-GetHostedZoneLimit"></a>[GetHostedZoneLimit](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetHostedZoneLimit.html) | Get the specified limit for a specified hosted zone | Read | 
| <a name="route53-GetQueryLoggingConfig"></a>[GetQueryLoggingConfig](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetQueryLoggingConfig.html) | Get information about a specified configuration for DNS query logging | Read | 
| <a name="route53-GetReusableDelegationSet"></a>[GetReusableDelegationSet](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetReusableDelegationSet.html) | Get information about a specified reusable delegation set, including the four name servers that are assigned to the delegation set | List | 
| <a name="route53-GetReusableDelegationSetLimit"></a>[GetReusableDelegationSetLimit](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetReusableDelegationSetLimit.html) | Get the maximum number of hosted zones that you can associate with the specified reusable delegation set | Read | 
| <a name="route53-GetTrafficPolicy"></a>[GetTrafficPolicy](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetTrafficPolicy.html) | Get information about a specified traffic policy version | Read | 
| <a name="route53-GetTrafficPolicyInstance"></a>[GetTrafficPolicyInstance](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetTrafficPolicyInstance.html) | Get information about a specified traffic policy instance | Read | 
| <a name="route53-GetTrafficPolicyInstanceCount"></a>[GetTrafficPolicyInstanceCount](https://docs.aws.amazon.com/Route53/latest/APIReference/API_GetTrafficPolicyInstanceCount.html) | Get the number of traffic policy instances that are associated with the current AWS account | Read | 
| <a name="route53-ListCidrBlocks"></a>[ListCidrBlocks](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListCidrBlocks.html) | Get a list of the CIDR blocks within a specified CIDR collection | List | 
| <a name="route53-ListCidrCollections"></a>[ListCidrCollections](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListCidrCollections.html) | Get a list of the CIDR collections that are associated with the current AWS account | List | 
| <a name="route53-ListCidrLocations"></a>[ListCidrLocations](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListCidrLocations.html) | Get a list of the CIDR locations that belong to a specified CIDR collection | List | 
| <a name="route53-ListGeoLocations"></a>[ListGeoLocations](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListGeoLocations.html) | Get a list of geographic locations that Route 53 supports for geolocation | Read | 
| <a name="route53-ListHealthChecks"></a>[ListHealthChecks](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListHealthChecks.html) | Get a list of the health checks that are associated with the current AWS account | Read | 
| <a name="route53-ListHostedZones"></a>[ListHostedZones](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListHostedZones.html) | Get a list of the public and private hosted zones that are associated with the current AWS account | List | 
| <a name="route53-ListHostedZonesByName"></a>[ListHostedZonesByName](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListHostedZonesByName.html) | Get a list of your hosted zones in lexicographic order. Hosted zones are sorted by name with the labels reversed, for example, com.example.www | List | 
| <a name="route53-ListHostedZonesByVPC"></a>[ListHostedZonesByVPC](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListHostedZonesByVPC.html) | Get a list of all the private hosted zones that a specified VPC is associated with | List | 
| <a name="route53-ListQueryLoggingConfigs"></a>[ListQueryLoggingConfigs](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListQueryLoggingConfigs.html) | List the configurations for DNS query logging that are associated with the current AWS account or the configuration that is associated with a specified hosted zone | List | 
| <a name="route53-ListResourceRecordSets"></a>[ListResourceRecordSets](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListResourceRecordSets.html) | List the records in a specified hosted zone | List | 
| <a name="route53-ListReusableDelegationSets"></a>[ListReusableDelegationSets](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListReusableDelegationSets.html) | List the reusable delegation sets that are associated with the current AWS account.  | Read | 
| <a name="route53-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTagsForResource.html) | List tags for one health check or hosted zone | Read | 
| <a name="route53-ListTagsForResources"></a>[ListTagsForResources](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTagsForResources.html) | List tags for up to 10 health checks or hosted zones | Read | 
| <a name="route53-ListTrafficPolicies"></a>[ListTrafficPolicies](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTrafficPolicies.html) | Get information about the latest version for every traffic policy that is associated with the current AWS account. Policies are listed in the order in which they were created | List | 
| <a name="route53-ListTrafficPolicyInstances"></a>[ListTrafficPolicyInstances](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTrafficPolicyInstances.html) | Get information about the traffic policy instances that you created by using the current AWS account | Read | 
| <a name="route53-ListTrafficPolicyInstancesByHostedZone"></a>[ListTrafficPolicyInstancesByHostedZone](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTrafficPolicyInstancesByHostedZone.html) | Get information about the traffic policy instances that you created in a specified hosted zone | List | 
| <a name="route53-ListTrafficPolicyInstancesByPolicy"></a>[ListTrafficPolicyInstancesByPolicy](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTrafficPolicyInstancesByPolicy.html) | Get information about the traffic policy instances that you created using a specified traffic policy version | List | 
| <a name="route53-ListTrafficPolicyVersions"></a>[ListTrafficPolicyVersions](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListTrafficPolicyVersions.html) | Get information about all the versions for a specified traffic policy | List | 
| <a name="route53-ListVPCAssociationAuthorizations"></a>[ListVPCAssociationAuthorizations](https://docs.aws.amazon.com/Route53/latest/APIReference/API_ListVPCAssociationAuthorizations.html) | Get a list of the VPCs that were created by other accounts and that can be associated with a specified hosted zone | List | 
| <a name="route53-TestDNSAnswer"></a>[TestDNSAnswer](https://docs.aws.amazon.com/Route53/latest/APIReference/API_TestDNSAnswer.html) | Get the value that Route 53 returns in response to a DNS query for a specified record name and type | Read |
