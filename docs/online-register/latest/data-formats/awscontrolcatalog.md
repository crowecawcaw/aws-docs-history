# Data retrieval APIs for AWS Control Catalog

AWS Control Catalog provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                                          | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------ |
| [GetControl](../../../controlcatalog/latest/APIReference/API_GetControl.md "../../../controlcatalog/latest/APIReference/API_GetControl.md")                            | Return details about a specific control                                              | Read         |
| [ListCommonControls](../../../controlcatalog/latest/APIReference/API_ListCommonControls.md "../../../controlcatalog/latest/APIReference/API_ListCommonControls.md")    | Return a paginated list of common controls from the AWS Control Catalog              | List         |
| [ListControlMappings](../../../controlcatalog/latest/APIReference/API_ListControlMappings.md "../../../controlcatalog/latest/APIReference/API_ListControlMappings.md") | Return a paginated list of control mappings from the AWS Control Catalog             | List         |
| [ListControls](../../../controlcatalog/latest/APIReference/API_ListControls.md "../../../controlcatalog/latest/APIReference/API_ListControls.md")                      | Return a paginated list of all available controls in the AWS Control Catalog library | List         |
| [ListDomains](../../../controlcatalog/latest/APIReference/API_ListDomains.md "../../../controlcatalog/latest/APIReference/API_ListDomains.md")                         | Return a paginated list of domains from the AWS Control Catalog                      | List         |
| [ListObjectives](../../../controlcatalog/latest/APIReference/API_ListObjectives.md "../../../controlcatalog/latest/APIReference/API_ListObjectives.md")                | Return a paginated list of objectives from the AWS Control Catalog                   | List         |
