# Data retrieval APIs for Amazon Elastic Kubernetes Service

Amazon Elastic Kubernetes Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                              | Description                                                                                                                                                                                                             | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [AccessKubernetesApi](../../../eks/latest/userguide/view-workloads.md "../../../eks/latest/userguide/view-workloads.md")                                                             | View Kubernetes objects via AWS EKS console                                                                                                                                                                             | Read         |
| [DescribeAccessEntry](../../../eks/latest/APIReference/API_DescribeAccessEntry.md "../../../eks/latest/APIReference/API_DescribeAccessEntry.md")                                     | Describe an Amazon EKS access entry                                                                                                                                                                                     | Read         |
| [DescribeAddon](../../../eks/latest/APIReference/API_DescribeAddon.md "../../../eks/latest/APIReference/API_DescribeAddon.md")                                                       | Retrieve descriptive information about an Amazon EKS add-on                                                                                                                                                             | Read         |
| [DescribeAddonConfiguration](../../../eks/latest/APIReference/API_DescribeAddonConfiguration.md "../../../eks/latest/APIReference/API_DescribeAddonConfiguration.md")                | List configuration options about an Amazon EKS add-on                                                                                                                                                                   | Read         |
| [DescribeAddonVersions](../../../eks/latest/APIReference/API_DescribeAddonVersions.md "../../../eks/latest/APIReference/API_DescribeAddonVersions.md")                               | Retrieve descriptive version information about the add-ons that Amazon EKS Add-ons supports                                                                                                                             | Read         |
| [DescribeCluster](../../../eks/latest/APIReference/API_DescribeCluster.md "../../../eks/latest/APIReference/API_DescribeCluster.md")                                                 | Retrieve descriptive information about an Amazon EKS cluster                                                                                                                                                            | Read         |
| [DescribeClusterVersions](../../../eks/latest/APIReference/API_DescribeClusterVersions.md "../../../eks/latest/APIReference/API_DescribeClusterVersions.md")                         | Retrieve descriptive information about Kubernetes versions that Amazon EKS clusters support                                                                                                                             | Read         |
| [DescribeEksAnywhereSubscription](../../../eks/latest/APIReference/API_DescribeEksAnywhereSubscription.md "../../../eks/latest/APIReference/API_DescribeEksAnywhereSubscription.md") | Describe an EKS Anywhere subscription                                                                                                                                                                                   | Read         |
| [DescribeFargateProfile](../../../eks/latest/APIReference/API_DescribeFargateProfile.md "../../../eks/latest/APIReference/API_DescribeFargateProfile.md")                            | Retrieve descriptive information about an AWS Fargate profile associated with a cluster                                                                                                                                 | Read         |
| [DescribeIdentityProviderConfig](../../../eks/latest/APIReference/API_DescribeIdentityProviderConfig.md "../../../eks/latest/APIReference/API_DescribeIdentityProviderConfig.md")    | Retrieve descriptive information about an Idp config associated with a cluster                                                                                                                                          | Read         |
| [DescribeInsight](../../../eks/latest/APIReference/API_DescribeInsight.md "../../../eks/latest/APIReference/API_DescribeInsight.md")                                                 | Retrieve descriptive information of a detected insight for a specified cluster                                                                                                                                          | Read         |
| [DescribeInsightsRefresh](../../../eks/latest/APIReference/API_DescribeInsightsRefresh.md "../../../eks/latest/APIReference/API_DescribeInsightsRefresh.md")                         | Retrieve the status of the latest on-demand cluster insights refresh operation                                                                                                                                          | Read         |
| [DescribeNodegroup](../../../eks/latest/APIReference/API_DescribeNodegroup.md "../../../eks/latest/APIReference/API_DescribeNodegroup.md")                                           | Retrieve descriptive information about an Amazon EKS nodegroup                                                                                                                                                          | Read         |
| [DescribePodIdentityAssociation](../../../eks/latest/APIReference/API_DescribePodIdentityAssociation.md "../../../eks/latest/APIReference/API_DescribePodIdentityAssociation.md")    | Describe an EKS Pod Identity association                                                                                                                                                                                | Read         |
| [DescribeUpdate](../../../eks/latest/APIReference/API_DescribeUpdate.md "../../../eks/latest/APIReference/API_DescribeUpdate.md")                                                    | Retrieve a given update for a given Amazon EKS cluster/nodegroup/add-on (in the specified or default region)                                                                                                            | Read         |
| [ListAccessEntries](../../../eks/latest/APIReference/API_ListAccessEntries.md "../../../eks/latest/APIReference/API_ListAccessEntries.md")                                           | List all Amazon EKS access entries                                                                                                                                                                                      | List         |
| [ListAccessPolicies](../../../eks/latest/APIReference/API_ListAccessPolicies.md "../../../eks/latest/APIReference/API_ListAccessPolicies.md")                                        | List Amazon EKS access policies                                                                                                                                                                                         | List         |
| [ListAddons](../../../eks/latest/APIReference/API_ListAddons.md "../../../eks/latest/APIReference/API_ListAddons.md")                                                                | List the Amazon EKS add-ons in your AWS account (in the specified or default region) for a given cluster                                                                                                                | List         |
| [ListAssociatedAccessPolicies](../../../eks/latest/APIReference/API_ListAssociatedAccessPolicies.md "../../../eks/latest/APIReference/API_ListAssociatedAccessPolicies.md")          | List associated access policy on and Amazon EKS access entry                                                                                                                                                            | List         |
| [ListClusters](../../../eks/latest/APIReference/API_ListClusters.md "../../../eks/latest/APIReference/API_ListClusters.md")                                                          | List the Amazon EKS clusters in your AWS account (in the specified or default region)                                                                                                                                   | List         |
| [ListDashboardData](../../../eks/latest/APIReference/API_ListDashboardData.md "../../../eks/latest/APIReference/API_ListDashboardData.md")                                           | List dashboard data. | [ListDashboardResources](../../../eks/latest/APIReference/API_ListDashboardResources.md "../../../eks/latest/APIReference/API_ListDashboardResources.md")                            | List dashboard resources. The dashboard includes information about EC2 Instances and EKS Cluster versions | Read         |
| [ListEksAnywhereSubscriptions](../../../eks/latest/APIReference/API_ListEksAnywhereSubscriptions.md "../../../eks/latest/APIReference/API_ListEksAnywhereSubscriptions.md")          | List EKS Anywhere subscriptions                                                                                                                                                                                         | List         |
| [ListFargateProfiles](../../../eks/latest/APIReference/API_ListFargateProfiles.md "../../../eks/latest/APIReference/API_ListFargateProfiles.md")                                     | List the AWS Fargate profiles in your AWS account (in the specified or default region) associated with a given cluster                                                                                                  | List         |
| [ListIdentityProviderConfigs](../../../eks/latest/APIReference/API_ListIdentityProviderConfigs.md "../../../eks/latest/APIReference/API_ListIdentityProviderConfigs.md")             | List the Idp configs in your AWS account (in the specified or default region) associated with a given cluster                                                                                                           | List         |
| [ListInsights](../../../eks/latest/APIReference/API_ListInsights.md "../../../eks/latest/APIReference/API_ListInsights.md")                                                          | List all detected insights for a specified cluster                                                                                                                                                                      | List         |
| [ListNodegroups](../../../eks/latest/APIReference/API_ListNodegroups.md "../../../eks/latest/APIReference/API_ListNodegroups.md")                                                    | List the Amazon EKS nodegroups in your AWS account (in the specified or default region) attached to given cluster                                                                                                       | List         |
| [ListPodIdentityAssociations](../../../eks/latest/APIReference/API_ListPodIdentityAssociations.md "../../../eks/latest/APIReference/API_ListPodIdentityAssociations.md")             | List EKS Pod Identity associations                                                                                                                                                                                      | List         |
| [ListTagsForResource](../../../eks/latest/APIReference/API_ListTagsForResource.md "../../../eks/latest/APIReference/API_ListTagsForResource.md")                                     | List tags for the specified resource                                                                                                                                                                                    | Read         |
| [ListUpdates](../../../eks/latest/APIReference/API_ListUpdates.md "../../../eks/latest/APIReference/API_ListUpdates.md")                                                             | List the updates for a given Amazon EKS cluster/nodegroup/add-on (in the specified or default region)                                                                                                                   | List         |
