# Data retrieval APIs for Amazon Kinesis Data Streams

Amazon Kinesis Data Streams provides the following APIs for data retrieval.

| Actions                                                                                                                                                           | Description                                                                                                                                     | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeLimits](../../../kinesis/latest/APIReference/API_DescribeLimits.md "../../../kinesis/latest/APIReference/API_DescribeLimits.md")                         | Describe the shard limits and usage for the account                                                                                             | Read         |
| [DescribeStream](../../../kinesis/latest/APIReference/API_DescribeStream.md "../../../kinesis/latest/APIReference/API_DescribeStream.md")                         | Describe the specified stream                                                                                                                   | Read         |
| [DescribeStreamConsumer](../../../kinesis/latest/APIReference/API_DescribeStreamConsumer.md "../../../kinesis/latest/APIReference/API_DescribeStreamConsumer.md") | Get the description of a registered stream consumer                                                                                             | Read         |
| [DescribeStreamSummary](../../../kinesis/latest/APIReference/API_DescribeStreamSummary.md "../../../kinesis/latest/APIReference/API_DescribeStreamSummary.md")    | Provide a summarized description of the specified Kinesis data stream without the shard list                                                    | Read         |
| [GetRecords](../../../kinesis/latest/APIReference/API_GetRecords.md "../../../kinesis/latest/APIReference/API_GetRecords.md")                                     | Get data records from a shard                                                                                                                   | Read         |
| [GetResourcePolicy](../../../kinesis/latest/APIReference/API_GetResourcePolicy.md "../../../kinesis/latest/APIReference/API_GetResourcePolicy.md")                | Get a resource policy associated with a specified stream or consumer                                                                            | Read         |
| [GetShardIterator](../../../kinesis/latest/APIReference/API_GetShardIterator.md "../../../kinesis/latest/APIReference/API_GetShardIterator.md")                   | Get a shard iterator. A shard iterator expires five minutes after it is returned to the requester                                               | Read         |
| [ListShards](../../../kinesis/latest/APIReference/API_ListShards.md "../../../kinesis/latest/APIReference/API_ListShards.md")                                     | List the shards in a stream and provides information about each shard                                                                           | List         |
| [ListStreamConsumers](../../../kinesis/latest/APIReference/API_ListStreamConsumers.md "../../../kinesis/latest/APIReference/API_ListStreamConsumers.md")          | List the stream consumers registered to receive data from a Kinesis stream using enhanced fan-out, and provides information about each consumer | List         |
| [ListStreams](../../../kinesis/latest/APIReference/API_ListStreams.md "../../../kinesis/latest/APIReference/API_ListStreams.md")                                  | List your streams                                                                                                                               | List         |
| [ListTagsForResource](../../../kinesis/latest/APIReference/API_ListTagsForResource.md "../../../kinesis/latest/APIReference/API_ListTagsForResource.md")          | List the tags for the specified Amazon Kinesis resource                                                                                         | Read         |
| [ListTagsForStream](../../../kinesis/latest/APIReference/API_ListTagsForStream.md "../../../kinesis/latest/APIReference/API_ListTagsForStream.md")                | List the tags for the specified Amazon Kinesis stream                                                                                           | Read         |
| [SubscribeToShard](../../../kinesis/latest/APIReference/API_SubscribeToShard.md "../../../kinesis/latest/APIReference/API_SubscribeToShard.md")                   | Listen to a specific shard with enhanced fan-out                                                                                                | Read         |
