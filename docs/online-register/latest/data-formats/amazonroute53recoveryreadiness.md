| Actions                                                                                                                                                                                                                                                              | Description                                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------ |

| [GetCell](../../../recovery-readiness/latest/api/cells-cellname.md "../../../recovery-readiness/latest/api/cells-cellname.md")                                                                                                                                       | Get information about a cell                             | Read         |
| [GetCellReadinessSummary](../../../recovery-readiness/latest/api/cellreadiness-cellname.md "../../../recovery-readiness/latest/api/cellreadiness-cellname.md")                                                                                                       | Get a readiness summary for a cell                       | Read         |
| [GetReadinessCheck](../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname.md "../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname.md")                                                                                     | Get information about a readiness check                  | Read         |
| [GetReadinessCheckResourceStatus](../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname-resource-resourceidentifier-status.md "../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname-resource-resourceidentifier-status.md") | Get the readiness status for an individual resource      | Read         |
| [GetReadinessCheckStatus](../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname-status.md "../../../recovery-readiness/latest/api/readinesschecks-readinesscheckname-status.md")                                                                 | Get the status of a readiness check (for a resource set) | Read         |
| [GetRecoveryGroup](../../../recovery-readiness/latest/api/recoverygroups-recoverygroupname.md "../../../recovery-readiness/latest/api/recoverygroups-recoverygroupname.md")                                                                                          | Get information about a recovery group                   | Read         |
| [GetRecoveryGroupReadinessSummary](../../../recovery-readiness/latest/api/recoverygroupreadiness-recoverygroupname.md "../../../recovery-readiness/latest/api/recoverygroupreadiness-recoverygroupname.md")                                                          | Get a readiness summary for a recovery group             | Read         |
| [GetResourceSet](../../../recovery-readiness/latest/api/resourcesets-resourcesetname.md "../../../recovery-readiness/latest/api/resourcesets-resourcesetname.md")                                                                                                    | Get information about a resource set                     | Read         |
| [ListCells](../../../recovery-readiness/latest/api/cells.md "../../../recovery-readiness/latest/api/cells.md")                                                                                                                                                       | List cells                                               | Read         |

| [ListResourceSets](../../../recovery-readiness/latest/api/resourcesets.md "../../../recovery-readiness/latest/api/resourcesets.md")                                                                                                                                  | List resource sets                                       | Read         |
