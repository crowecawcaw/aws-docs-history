# Data retrieval APIs for Amazon MQ

Amazon MQ provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                                          | Description                                                                 | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------ |
| [DescribeBroker](../../../amazon-mq/latest/api-reference/rest-api-broker.md#rest-api-broker-methods-get "../../../amazon-mq/latest/api-reference/rest-api-broker.md#rest-api-broker-methods-get")                                                                                | Return information about the specified broker                               | Read         |
| [DescribeBrokerEngineTypes](../../../amazon-mq/latest/api-reference/broker-engine-types.md#broker-engine-types-http-methods "../../../amazon-mq/latest/api-reference/broker-engine-types.md#broker-engine-types-http-methods")                                                   | Return information about broker engines                                     | Read         |
| [DescribeBrokerInstanceOptions](../../../amazon-mq/latest/api-reference/broker-instance-options.md#broker-engine-types-http-methods "../../../amazon-mq/latest/api-reference/broker-instance-options.md#broker-engine-types-http-methods")                                       | Return information about the broker instance options                        | Read         |
| [DescribeConfiguration](../../../amazon-mq/latest/api-reference/rest-api-configuration.md#rest-api-configuration-methods-get "../../../amazon-mq/latest/api-reference/rest-api-configuration.md#rest-api-configuration-methods-get")                                             | Return information about the specified configuration                        | Read         |
| [DescribeConfigurationRevision](../../../amazon-mq/latest/api-reference/rest-api-configuration-revision.md#rest-api-configuration-revision-methods-get "../../../amazon-mq/latest/api-reference/rest-api-configuration-revision.md#rest-api-configuration-revision-methods-get") | Return the specified configuration revision for the specified configuration | Read         |
| [DescribeUser](../../../amazon-mq/latest/api-reference/rest-api-username.md#rest-api-username-methods-get "../../../amazon-mq/latest/api-reference/rest-api-username.md#rest-api-username-methods-get")                                                                          | Return information about an ActiveMQ user                                   | Read         |
| [ListBrokers](../../../amazon-mq/latest/api-reference/rest-api-brokers.md#rest-api-brokers-methods-get "../../../amazon-mq/latest/api-reference/rest-api-brokers.md#rest-api-brokers-methods-get")                                                                               | Return a list of all brokers                                                | List         |
| [ListConfigurationRevisions](../../../amazon-mq/latest/api-reference/rest-api-revisions.md#rest-api-revisions-methods-get "../../../amazon-mq/latest/api-reference/rest-api-revisions.md#rest-api-revisions-methods-get")                                                        | Return a list of all existing revisions for the specified configuration     | List         |
| [ListConfigurations](../../../amazon-mq/latest/api-reference/rest-api-configurations.md#rest-api-configurations-methods-get "../../../amazon-mq/latest/api-reference/rest-api-configurations.md#rest-api-configurations-methods-get")                                            | Return a list of all configurations                                         | List         |
| [ListTags](../../../amazon-mq/latest/api-reference/rest-api-tags.md#rest-api-tags-methods-get "../../../amazon-mq/latest/api-reference/rest-api-tags.md#rest-api-tags-methods-get")                                                                                              | Return a list of tags                                                       | List         |
| [ListUsers](../../../amazon-mq/latest/api-reference/rest-api-users.md#rest-api-users-methods-get "../../../amazon-mq/latest/api-reference/rest-api-users.md#rest-api-users-methods-get")                                                                                         | Return a list of all ActiveMQ users                                         | List         |
