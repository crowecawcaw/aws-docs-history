

# Data retrieval APIs for Amazon MQ
<a name="amazonmq"></a>

Amazon MQ provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mq-DescribeBroker"></a>[DescribeBroker](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-broker.html#rest-api-broker-methods-get) | Return information about the specified broker | Read | 
| <a name="mq-DescribeBrokerEngineTypes"></a>[DescribeBrokerEngineTypes](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/broker-engine-types.html#broker-engine-types-http-methods) | Return information about broker engines | Read | 
| <a name="mq-DescribeBrokerInstanceOptions"></a>[DescribeBrokerInstanceOptions](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/broker-instance-options.html#broker-engine-types-http-methods) | Return information about the broker instance options | Read | 
| <a name="mq-DescribeConfiguration"></a>[DescribeConfiguration](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-configuration.html#rest-api-configuration-methods-get) | Return information about the specified configuration | Read | 
| <a name="mq-DescribeConfigurationRevision"></a>[DescribeConfigurationRevision](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-configuration-revision.html#rest-api-configuration-revision-methods-get) | Return the specified configuration revision for the specified configuration | Read | 
| <a name="mq-DescribeSharedResources"></a>[DescribeSharedResources](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/brokers-broker-id-shared-resources.html) | Return the resources shared to a broker | Read | 
| <a name="mq-DescribeUser"></a>[DescribeUser](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-username.html#rest-api-username-methods-get) | Return information about an ActiveMQ user | Read | 
| <a name="mq-ListBrokers"></a>[ListBrokers](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-brokers.html#rest-api-brokers-methods-get) | Return a list of all brokers | List | 
| <a name="mq-ListConfigurationRevisions"></a>[ListConfigurationRevisions](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-revisions.html#rest-api-revisions-methods-get) | Return a list of all existing revisions for the specified configuration | List | 
| <a name="mq-ListConfigurations"></a>[ListConfigurations](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-configurations.html#rest-api-configurations-methods-get) | Return a list of all configurations | List | 
| <a name="mq-ListTags"></a>[ListTags](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-tags.html#rest-api-tags-methods-get) | Return a list of tags | List | 
| <a name="mq-ListUsers"></a>[ListUsers](https://docs.aws.amazon.com/amazon-mq/latest/api-reference/rest-api-users.html#rest-api-users-methods-get) | Return a list of all ActiveMQ users | List |
