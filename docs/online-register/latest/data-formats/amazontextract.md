

# Data retrieval APIs for Amazon Textract
<a name="amazontextract"></a>

Amazon Textract provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="textract-AnalyzeDocument"></a>[AnalyzeDocument](https://docs.aws.amazon.com/textract/latest/dg/API_AnalyzeDocument.html) | Detect instances of real-world document entities within an image provided as input | Read | 
| <a name="textract-AnalyzeExpense"></a>[AnalyzeExpense](https://docs.aws.amazon.com/textract/latest/dg/API_AnalyzeExpense.html) | Detect instances of real-world document entities within an image provided as input | Read | 
| <a name="textract-AnalyzeID"></a>[AnalyzeID](https://docs.aws.amazon.com/textract/latest/dg/API_AnalyzeID.html) | Detect relevant information from identity documents provided as input | Read | 
| <a name="textract-DetectDocumentText"></a>[DetectDocumentText](https://docs.aws.amazon.com/textract/latest/dg/API_DetectDocumentText.html) | Detect text in document images | Read | 
| <a name="textract-GetAdapter"></a>[GetAdapter](https://docs.aws.amazon.com/textract/latest/dg/API_GetAdapter.html) | Get an Amazon Textract adapter | Read | 
| <a name="textract-GetAdapterVersion"></a>[GetAdapterVersion](https://docs.aws.amazon.com/textract/latest/dg/API_GetAdapterVersion.html) | Get an Amazon Textract adapter version | Read | 
| <a name="textract-GetDocumentAnalysis"></a>[GetDocumentAnalysis](https://docs.aws.amazon.com/textract/latest/dg/API_GetDocumentAnalysis.html) | Return information about a document analysis job | Read | 
| <a name="textract-GetDocumentTextDetection"></a>[GetDocumentTextDetection](https://docs.aws.amazon.com/textract/latest/dg/API_GetDocumentTextDetection.html) | Return information about a document text detection job | Read | 
| <a name="textract-GetExpenseAnalysis"></a>[GetExpenseAnalysis](https://docs.aws.amazon.com/textract/latest/dg/API_GetExpenseAnalysis.html) | Return information about an expense analysis job | Read | 
| <a name="textract-GetLendingAnalysis"></a>[GetLendingAnalysis](https://docs.aws.amazon.com/textract/latest/dg/API_GetLendingAnalysis.html) | Retrieve page-level information regarding a lending analysis job | Read | 
| <a name="textract-GetLendingAnalysisSummary"></a>[GetLendingAnalysisSummary](https://docs.aws.amazon.com/textract/latest/dg/API_GetLendingAnalysisSummary.html) | Retrieve summarized information regarding a lending analysis job | Read | 
| <a name="textract-ListAdapterVersions"></a>[ListAdapterVersions](https://docs.aws.amazon.com/textract/latest/dg/API_ListAdapterVersions.html) | List Amazon Textract adapter versions | Read | 
| <a name="textract-ListAdapters"></a>[ListAdapters](https://docs.aws.amazon.com/textract/latest/dg/API_ListAdapters.html) | List Amazon Textract adapters | Read | 
| <a name="textract-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/textract/latest/dg/API_ListTagsForResource.html) | Return a list of tags associated with a resource | Read |
