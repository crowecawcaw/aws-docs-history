# Data retrieval APIs for Amazon Textract

Amazon Textract provides the following APIs for data retrieval.

| Actions                                                                                                                                                  | Description                                                                        | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------ |
| [AnalyzeDocument](../../../textract/latest/dg/API_AnalyzeDocument.md "../../../textract/latest/dg/API_AnalyzeDocument.md")                               | Detect instances of real-world document entities within an image provided as input | Read         |
| [AnalyzeExpense](../../../textract/latest/dg/API_AnalyzeExpense.md "../../../textract/latest/dg/API_AnalyzeExpense.md")                                  | Detect instances of real-world document entities within an image provided as input | Read         |
| [AnalyzeID](../../../textract/latest/dg/API_AnalyzeID.md "../../../textract/latest/dg/API_AnalyzeID.md")                                                 | Detect relevant information from identity documents provided as input              | Read         |
| [DetectDocumentText](../../../textract/latest/dg/API_DetectDocumentText.md "../../../textract/latest/dg/API_DetectDocumentText.md")                      | Detect text in document images                                                     | Read         |
| [GetAdapter](../../../textract/latest/dg/API_GetAdapter.md "../../../textract/latest/dg/API_GetAdapter.md")                                              | Get an Amazon Textract adapter                                                     | Read         |
| [GetAdapterVersion](../../../textract/latest/dg/API_GetAdapterVersion.md "../../../textract/latest/dg/API_GetAdapterVersion.md")                         | Get an Amazon Textract adapter version                                             | Read         |
| [GetDocumentAnalysis](../../../textract/latest/dg/API_GetDocumentAnalysis.md "../../../textract/latest/dg/API_GetDocumentAnalysis.md")                   | Return information about a document analysis job                                   | Read         |
| [GetDocumentTextDetection](../../../textract/latest/dg/API_GetDocumentTextDetection.md "../../../textract/latest/dg/API_GetDocumentTextDetection.md")    | Return information about a document text detection job                             | Read         |
| [GetExpenseAnalysis](../../../textract/latest/dg/API_GetExpenseAnalysis.md "../../../textract/latest/dg/API_GetExpenseAnalysis.md")                      | Return information about an expense analysis job                                   | Read         |
| [GetLendingAnalysis](../../../textract/latest/dg/API_GetLendingAnalysis.md "../../../textract/latest/dg/API_GetLendingAnalysis.md")                      | Retrieve page-level information regarding a lending analysis job                   | Read         |
| [GetLendingAnalysisSummary](../../../textract/latest/dg/API_GetLendingAnalysisSummary.md "../../../textract/latest/dg/API_GetLendingAnalysisSummary.md") | Retrieve summarized information regarding a lending analysis job                   | Read         |
| [ListAdapterVersions](../../../textract/latest/dg/API_ListAdapterVersions.md "../../../textract/latest/dg/API_ListAdapterVersions.md")                   | List Amazon Textract adapter versions                                              | Read         |
| [ListAdapters](../../../textract/latest/dg/API_ListAdapters.md "../../../textract/latest/dg/API_ListAdapters.md")                                        | List Amazon Textract adapters                                                      | Read         |
| [ListTagsForResource](../../../textract/latest/dg/API_ListTagsForResource.md "../../../textract/latest/dg/API_ListTagsForResource.md")                   | Return a list of tags associated with a resource                                   | Read         |
