# Data retrieval APIs for AWS Certificate Manager

AWS Certificate Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                         | Description                                                         | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------ |
| [DescribeAcmeAccount](../../../acm/latest/APIReference/API_DescribeAcmeAccount.md "../../../acm/latest/APIReference/API_DescribeAcmeAccount.md")                                                                | Retrieve details of an ACME account                                 | Read         |
| [DescribeAcmeDomainValidation](../../../acm/latest/APIReference/API_DescribeAcmeDomainValidation.md "../../../acm/latest/APIReference/API_DescribeAcmeDomainValidation.md")                                     | Retrieve details of an ACME domain validation                       | Read         |
| [DescribeAcmeEndpoint](../../../acm/latest/APIReference/API_DescribeAcmeEndpoint.md "../../../acm/latest/APIReference/API_DescribeAcmeEndpoint.md")                                                             | Retrieve details of an ACME endpoint                                | Read         |
| [DescribeAcmeExternalAccountBinding](../../../acm/latest/APIReference/API_DescribeAcmeExternalAccountBinding.md "../../../acm/latest/APIReference/API_DescribeAcmeExternalAccountBinding.md")                   | Retrieve details of an ACME external account binding                | Read         |
| [DescribeCertificate](../../../acm/latest/APIReference/API_DescribeCertificate.md "../../../acm/latest/APIReference/API_DescribeCertificate.md")                                                                | Retreive a certificates and its metadata                            | Read         |
| [ExportCertificate](../../../acm/latest/APIReference/API_ExportCertificate.md "../../../acm/latest/APIReference/API_ExportCertificate.md")                                                                      | Export an exportable certificate for use anywhere                   | Read         |
| [GetAccountConfiguration](../../../acm/latest/APIReference/API_GetAccountConfiguration.md "../../../acm/latest/APIReference/API_GetAccountConfiguration.md")                                                    | Retrieve account level configuration from AWS Certificate Manager   | Read         |
| [GetAcmeExternalAccountBindingCredentials](../../../acm/latest/APIReference/API_GetAcmeExternalAccountBindingCredentials.md "../../../acm/latest/APIReference/API_GetAcmeExternalAccountBindingCredentials.md") | Retrieve credentials for an ACME external account binding           | Read         |
| [GetCertificate](../../../acm/latest/APIReference/API_GetCertificate.md "../../../acm/latest/APIReference/API_GetCertificate.md")                                                                               | Retrieve a certificate and certificate chain for a certificate ARN  | Read         |
| [ListAcmeAccounts](../../../acm/latest/APIReference/API_ListAcmeAccounts.md "../../../acm/latest/APIReference/API_ListAcmeAccounts.md")                                                                         | List ACME accounts                                                  | List         |
| [ListAcmeDomainValidations](../../../acm/latest/APIReference/API_ListAcmeDomainValidations.md "../../../acm/latest/APIReference/API_ListAcmeDomainValidations.md")                                              | List ACME domain validations                                        | List         |
| [ListAcmeEndpoints](../../../acm/latest/APIReference/API_ListAcmeEndpoints.md "../../../acm/latest/APIReference/API_ListAcmeEndpoints.md")                                                                      | List ACME endpoints                                                 | List         |
| [ListAcmeExternalAccountBindings](../../../acm/latest/APIReference/API_ListAcmeExternalAccountBindings.md "../../../acm/latest/APIReference/API_ListAcmeExternalAccountBindings.md")                            | List ACME external account bindings                                 | List         |
| [ListCertificateDomainValidations](../../../acm/latest/APIReference/API_ListCertificateDomainValidations.md "../../../acm/latest/APIReference/API_ListCertificateDomainValidations.md")                         | List domain validation methods for a certificate                    | List         |
| [ListCertificates](../../../acm/latest/APIReference/API_ListCertificates.md "../../../acm/latest/APIReference/API_ListCertificates.md")                                                                         | Retrieve a list of certificates for specific certificate parameters | List         |
| [ListTagsForCertificate](../../../acm/latest/APIReference/API_ListTagsForCertificate.md "../../../acm/latest/APIReference/API_ListTagsForCertificate.md")                                                       | Lists the tags that have been associated with a certificate         | Read         |
| [ListTagsForResource](../../../acm/latest/APIReference/API_ListTagsForResource.md "../../../acm/latest/APIReference/API_ListTagsForResource.md")                                                                | List tags for a resource                                            | Read         |
| [SearchCertificates](../../../acm/latest/APIReference/API_SearchCertificates.md "../../../acm/latest/APIReference/API_SearchCertificates.md")                                                                   | Retrieve a list of certificates matching search criteria            | List         |
