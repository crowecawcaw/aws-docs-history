# Data retrieval APIs for AWS Certificate Manager

AWS Certificate Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                                      | Description                                                              | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ | ------------ |
| [DescribeCertificate](../../../acm/latest/APIReference/API_DescribeCertificate.md "../../../acm/latest/APIReference/API_DescribeCertificate.md")             | Retreive a certificates and its metadata                                 | Read         |
| [ExportCertificate](../../../acm/latest/APIReference/API_ExportCertificate.md "../../../acm/latest/APIReference/API_ExportCertificate.md")                   | Export an exportable certificate for use anywhere                        | Read         |
| [GetAccountConfiguration](../../../acm/latest/APIReference/API_GetAccountConfiguration.md "../../../acm/latest/APIReference/API_GetAccountConfiguration.md") | Retrieve account level configuration from AWS Certificate Manager        | Read         |
| [GetCertificate](../../../acm/latest/APIReference/API_GetCertificate.md "../../../acm/latest/APIReference/API_GetCertificate.md")                            | Retrieve a certificate and certificate chain for a certificate ARN       | Read         |
| [ListCertificates](../../../acm/latest/APIReference/API_ListCertificates.md "../../../acm/latest/APIReference/API_ListCertificates.md")                      | Retrieve a list of the certificate ARNs and the domain name for each ARN | List         |
| [ListTagsForCertificate](../../../acm/latest/APIReference/API_ListTagsForCertificate.md "../../../acm/latest/APIReference/API_ListTagsForCertificate.md")    | Lists the tags that have been associated with a certificate              | Read         |
