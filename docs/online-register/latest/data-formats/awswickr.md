

# Data retrieval APIs for AWS Wickr
<a name="awswickr"></a>

AWS Wickr provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="wickr-BatchLookupUserUname"></a>[BatchLookupUserUname](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Batch lookup user unames in a Wickr network | Read | 
| <a name="wickr-GetBot"></a>[GetBot](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get bot information in a Wickr network | Read | 
| <a name="wickr-GetBotsCount"></a>[GetBotsCount](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get bot count for a Wickr network | Read | 
| <a name="wickr-GetDataRetentionBot"></a>[GetDataRetentionBot](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get data retention bot information in a Wickr network | Read | 
| <a name="wickr-GetGuestUserHistoryCount"></a>[GetGuestUserHistoryCount](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get guest user history count for a Wickr network | Read | 
| <a name="wickr-GetNetwork"></a>[GetNetwork](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get details of a Wickr network | Read | 
| <a name="wickr-GetNetworkSettings"></a>[GetNetworkSettings](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get network settings for a Wickr network | Read | 
| <a name="wickr-GetOidcInfo"></a>[GetOidcInfo](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get OIDC information for a Wickr network | Read | 
| <a name="wickr-GetOpentdfConfig"></a>[GetOpentdfConfig](https://docs.aws.amazon.com/wickr/latest/APIReference/API_GetOpentdfConfig.html) | Retrieve the OpenTDF integration configuration for a Wickr network | Read | 
| <a name="wickr-GetSecurityGroup"></a>[GetSecurityGroup](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get security group information in a Wickr network | Read | 
| <a name="wickr-GetUser"></a>[GetUser](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get information about a user in a Wickr network | Read | 
| <a name="wickr-GetUsersCount"></a>[GetUsersCount](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | Get user count for a Wickr network | Read | 
| <a name="wickr-ListBlockedGuestUsers"></a>[ListBlockedGuestUsers](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List blocked guest users in a Wickr network | Read | 
| <a name="wickr-ListBots"></a>[ListBots](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List bots in a Wickr network | Read | 
| <a name="wickr-ListDevicesForUser"></a>[ListDevicesForUser](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List devices for a user in a Wickr network | Read | 
| <a name="wickr-ListGuestUsers"></a>[ListGuestUsers](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List guest users in a Wickr network | Read | 
| <a name="wickr-ListNetworks"></a>[ListNetworks](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List Wickr networks | Read | 
| <a name="wickr-ListSecurityGroupUsers"></a>[ListSecurityGroupUsers](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List users in a security group in a Wickr network | Read | 
| <a name="wickr-ListSecurityGroups"></a>[ListSecurityGroups](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List security groups in a Wickr network | Read | 
| <a name="wickr-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List the tags applied to a Wickr resource | Read | 
| <a name="wickr-ListUsers"></a>[ListUsers](https://docs.aws.amazon.com/wickr/latest/adminguide/security-iam.html) | List users in a Wickr network | Read |
