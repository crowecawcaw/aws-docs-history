# Data retrieval APIs for AWS Wickr

AWS Wickr provides the following APIs for data retrieval.

| Actions                                                                                                                         | Description                                           | Access level |
| ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------ |
| [BatchLookupUserUname](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")     | Batch lookup user unames in a Wickr network           | Read         |
| [GetBot](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")                   | Get bot information in a Wickr network                | Read         |
| [GetBotsCount](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")             | Get bot count for a Wickr network                     | Read         |
| [GetDataRetentionBot](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")      | Get data retention bot information in a Wickr network | Read         |
| [GetGuestUserHistoryCount](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md") | Get guest user history count for a Wickr network      | Read         |
| [GetNetwork](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")               | Get details of a Wickr network                        | Read         |
| [GetNetworkSettings](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")       | Get network settings for a Wickr network              | Read         |
| [GetOidcInfo](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")              | Get OIDC information for a Wickr network              | Read         |
| [GetSecurityGroup](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")         | Get security group information in a Wickr network     | Read         |
| [GetUser](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")                  | Get information about a user in a Wickr network       | Read         |
| [GetUsersCount](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")            | Get user count for a Wickr network                    | Read         |
| [ListBlockedGuestUsers](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")    | List blocked guest users in a Wickr network           | Read         |
| [ListBots](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")                 | List bots in a Wickr network                          | Read         |
| [ListDevicesForUser](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")       | List devices for a user in a Wickr network            | Read         |
| [ListGuestUsers](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")           | List guest users in a Wickr network                   | Read         |
| [ListNetworks](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")             | List Wickr networks                                   | Read         |
| [ListSecurityGroupUsers](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")   | List users in a security group in a Wickr network     | Read         |
| [ListSecurityGroups](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")       | List security groups in a Wickr network               | Read         |
| [ListTagsForResource](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")      | List the tags applied to a Wickr resource             | Read         |
| [ListUsers](../../../wickr/latest/adminguide/security-iam.md "../../../wickr/latest/adminguide/security-iam.md")                | List users in a Wickr network                         | Read         |
