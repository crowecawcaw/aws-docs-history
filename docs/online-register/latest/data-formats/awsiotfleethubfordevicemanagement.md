# Data retrieval APIs for AWS IoT Fleet Hub for Device Management

AWS IoT Fleet Hub for Device Management provides the following APIs for data retrieval.

| Actions                                                                                                                                                                  | Description                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- | ------------ |
| [DescribeApplication](../../../iot/latest/apireference/API_iotfleethub_DescribeApplication.md "../../../iot/latest/apireference/API_iotfleethub_DescribeApplication.md") | Describe an application      | Read         |
| [ListApplications](../../../iot/latest/apireference/API_iotfleethub_ListApplications.md "../../../iot/latest/apireference/API_iotfleethub_ListApplications.md")          | List all applications        | List         |
| [ListTagsForResource](../../../iot/latest/apireference/API_iotfleethub_ListTagsForResource.md "../../../iot/latest/apireference/API_iotfleethub_ListTagsForResource.md") | List all tags for a resource | Read         |
