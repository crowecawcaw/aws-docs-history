

# Data retrieval APIs for AWS CloudShell
<a name="awscloudshell"></a>

AWS CloudShell provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="cloudshell-ApproveCommand"></a>[ApproveCommand](https://docs.aws.amazon.com/cloudshell/latest/userguide/sec-auth-with-identities.html#ApproveCommand) | Approve a command sent by another AWS service | Read | 
| <a name="cloudshell-DescribeEnvironments"></a>[DescribeEnvironments](https://docs.aws.amazon.com/cloudshell/latest/userguide/sec-auth-with-identities.html#DescribeEnvironments) | Return descriptions of existing user's environments | List | 
| <a name="cloudshell-GetEnvironmentStatus"></a>[GetEnvironmentStatus](https://docs.aws.amazon.com/cloudshell/latest/userguide/sec-auth-with-identities.html#GetEnvironmentStatus) | Read a CloudShell environment status | Read |
