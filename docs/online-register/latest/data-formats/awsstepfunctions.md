# Data retrieval APIs for AWS Step Functions

AWS Step Functions provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                       | Description                                                       | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------ |
| [DescribeActivity](../../../step-functions/latest/apireference/API_DescribeActivity.md "../../../step-functions/latest/apireference/API_DescribeActivity.md")                                                 | Describe an activity                                              | Read         |
| [DescribeExecution](../../../step-functions/latest/apireference/API_DescribeExecution.md "../../../step-functions/latest/apireference/API_DescribeExecution.md")                                              | Describe an execution                                             | Read         |
| [DescribeMapRun](../../../step-functions/latest/apireference/API_DescribeMapRun.md "../../../step-functions/latest/apireference/API_DescribeMapRun.md")                                                       | Describe a map run                                                | Read         |
| [DescribeStateMachine](../../../step-functions/latest/apireference/API_DescribeStateMachine.md "../../../step-functions/latest/apireference/API_DescribeStateMachine.md")                                     | Describe a state machine                                          | Read         |
| [DescribeStateMachineAlias](../../../step-functions/latest/apireference/API_DescribeStateMachineAlias.md "../../../step-functions/latest/apireference/API_DescribeStateMachineAlias.md")                      | Describe a state machine alias                                    | Read         |
| [DescribeStateMachineForExecution](../../../step-functions/latest/apireference/API_DescribeStateMachineForExecution.md "../../../step-functions/latest/apireference/API_DescribeStateMachineForExecution.md") | Describe the state machine for an execution                       | Read         |
| [GetExecutionHistory](../../../step-functions/latest/apireference/API_GetExecutionHistory.md "../../../step-functions/latest/apireference/API_GetExecutionHistory.md")                                        | Return the history of the specified execution as a list of events | Read         |
| [ListActivities](../../../step-functions/latest/apireference/API_ListActivities.md "../../../step-functions/latest/apireference/API_ListActivities.md")                                                       | List the existing activities                                      | List         |
| [ListExecutions](../../../step-functions/latest/apireference/API_ListExecutions.md "../../../step-functions/latest/apireference/API_ListExecutions.md")                                                       | List the executions of a state machine                            | List         |
| [ListMapRuns](../../../step-functions/latest/apireference/API_ListMapRuns.md "../../../step-functions/latest/apireference/API_ListMapRuns.md")                                                                | List the map runs of an execution                                 | List         |
| [ListStateMachineAliases](../../../step-functions/latest/apireference/API_ListStateMachineAliases.md "../../../step-functions/latest/apireference/API_ListStateMachineAliases.md")                            | List the aliases of a state machine                               | List         |
| [ListStateMachineVersions](../../../step-functions/latest/apireference/API_ListStateMachineVersions.md "../../../step-functions/latest/apireference/API_ListStateMachineVersions.md")                         | List the versions of a state machine                              | List         |
| [ListStateMachines](../../../step-functions/latest/apireference/API_ListStateMachines.md "../../../step-functions/latest/apireference/API_ListStateMachines.md")                                              | Lists the existing state machines                                 | List         |
| [ListTagsForResource](../../../step-functions/latest/apireference/API_ListTagsForResource.md "../../../step-functions/latest/apireference/API_ListTagsForResource.md")                                        | List tags for an AWS Step Functions resource                      | List         |
| [RevealSecrets](../../../step-functions/latest/dg/test-state-isolation.md "../../../step-functions/latest/dg/test-state-isolation.md")                                                                        | Reveal sensitive data from an execution                           | Read         |
| [ValidateStateMachineDefinition](../../../step-functions/latest/apireference/API_ValidateStateMachineDefinition.md "../../../step-functions/latest/apireference/API_ValidateStateMachineDefinition.md")       | Validate a state machine definition                               | Read         |
