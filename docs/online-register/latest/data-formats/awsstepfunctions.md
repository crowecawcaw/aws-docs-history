

# Data retrieval APIs for AWS Step Functions
<a name="awsstepfunctions"></a>

AWS Step Functions provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="states-DescribeActivity"></a>[DescribeActivity](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeActivity.html) | Describe an activity | Read | 
| <a name="states-DescribeExecution"></a>[DescribeExecution](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeExecution.html) | Describe an execution | Read | 
| <a name="states-DescribeMapRun"></a>[DescribeMapRun](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeMapRun.html) | Describe a map run | Read | 
| <a name="states-DescribeStateMachine"></a>[DescribeStateMachine](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeStateMachine.html) | Describe a state machine | Read | 
| <a name="states-DescribeStateMachineAlias"></a>[DescribeStateMachineAlias](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeStateMachineAlias.html) | Describe a state machine alias | Read | 
| <a name="states-DescribeStateMachineForExecution"></a>[DescribeStateMachineForExecution](https://docs.aws.amazon.com/step-functions/latest/apireference/API_DescribeStateMachineForExecution.html) | Describe the state machine for an execution | Read | 
| <a name="states-GetExecutionHistory"></a>[GetExecutionHistory](https://docs.aws.amazon.com/step-functions/latest/apireference/API_GetExecutionHistory.html) | Return the history of the specified execution as a list of events | Read | 
| <a name="states-ListActivities"></a>[ListActivities](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListActivities.html) | List the existing activities | List | 
| <a name="states-ListExecutions"></a>[ListExecutions](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListExecutions.html) | List the executions of a state machine | List | 
| <a name="states-ListMapRuns"></a>[ListMapRuns](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListMapRuns.html) | List the map runs of an execution | List | 
| <a name="states-ListStateMachineAliases"></a>[ListStateMachineAliases](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListStateMachineAliases.html) | List the aliases of a state machine | List | 
| <a name="states-ListStateMachineVersions"></a>[ListStateMachineVersions](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListStateMachineVersions.html) | List the versions of a state machine | List | 
| <a name="states-ListStateMachines"></a>[ListStateMachines](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListStateMachines.html) | Lists the existing state machines | List | 
| <a name="states-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ListTagsForResource.html) | List tags for an AWS Step Functions resource | List | 
| <a name="states-RevealSecrets"></a>[RevealSecrets](https://docs.aws.amazon.com/step-functions/latest/dg/test-state-isolation.html) | Reveal sensitive data from an execution | Read | 
| <a name="states-ValidateStateMachineDefinition"></a>[ValidateStateMachineDefinition](https://docs.aws.amazon.com/step-functions/latest/apireference/API_ValidateStateMachineDefinition.html) | Validate a state machine definition | Read |
