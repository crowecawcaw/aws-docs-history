# Data retrieval APIs for Amazon Braket

Amazon Braket provides the following APIs for data retrieval.

| Actions                                                                                                                                                | Description                                                                     | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- | ------------ |
| [GetDevice](../../../braket/latest/APIReference/API_GetDevice.md "../../../braket/latest/APIReference/API_GetDevice.md")                               | Retrieve information about the devices available in Amazon Braket               | Read         |
| [GetJob](../../../braket/latest/APIReference/API_GetJob.md "../../../braket/latest/APIReference/API_GetJob.md")                                        | Retrieve jobs                                                                   | Read         |
| [GetQuantumTask](../../../braket/latest/APIReference/API_GetQuantumTask.md "../../../braket/latest/APIReference/API_GetQuantumTask.md")                | Retrieve quantum tasks                                                          | Read         |
| [GetServiceLinkedRoleStatus](${UserGuideDocPage}.md "${UserGuideDocPage}.md")                                                                          | Check if the Amazon Braket service linked role has been created                 | Read         |
| [GetUserAgreementStatus](${UserGuideDocPage}.md "${UserGuideDocPage}.md")                                                                              | Check if the account has accepted the Amazon Braket user agreement              | Read         |
| [ListTagsForResource](../../../braket/latest/APIReference/API_ListTagsForResource.md "../../../braket/latest/APIReference/API_ListTagsForResource.md") | Listing the tags that have been applied to the quantum task resource or the job | Read         |
| [SearchDevices](../../../braket/latest/APIReference/API_SearchDevices.md "../../../braket/latest/APIReference/API_SearchDevices.md")                   | Search for devices available in Amazon Braket                                   | Read         |
| [SearchJobs](../../../braket/latest/APIReference/API_SearchJobs.md "../../../braket/latest/APIReference/API_SearchJobs.md")                            | Search for jobs                                                                 | Read         |
| [SearchQuantumTasks](../../../braket/latest/APIReference/API_SearchQuantumTasks.md "../../../braket/latest/APIReference/API_SearchQuantumTasks.md")    | Search for quantum tasks                                                        | Read         |
