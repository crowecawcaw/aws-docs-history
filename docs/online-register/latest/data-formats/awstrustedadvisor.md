

# Data retrieval APIs for AWS Trusted Advisor
<a name="awstrustedadvisor"></a>

AWS Trusted Advisor provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="trustedadvisor-DescribeAccount"></a>[DescribeAccount](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View the AWS Support plan and various AWS Trusted Advisor preferences | Read | 
| <a name="trustedadvisor-DescribeAccountAccess"></a>[DescribeAccountAccess](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View if the AWS account has enabled or disabled AWS Trusted Advisor | Read | 
| <a name="trustedadvisor-DescribeCheckItems"></a>[DescribeCheckItems](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View details for the check items | Read | 
| <a name="trustedadvisor-DescribeCheckRefreshStatuses"></a>[DescribeCheckRefreshStatuses](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View the refresh statuses for AWS Trusted Advisor checks | Read | 
| <a name="trustedadvisor-DescribeCheckStatusHistoryChanges"></a>[DescribeCheckStatusHistoryChanges](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View the results and changed statuses for checks in the last 30 days | Read | 
| <a name="trustedadvisor-DescribeCheckSummaries"></a>[DescribeCheckSummaries](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View AWS Trusted Advisor check summaries | Read | 
| <a name="trustedadvisor-DescribeChecks"></a>[DescribeChecks](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View details for AWS Trusted Advisor checks | Read | 
| <a name="trustedadvisor-DescribeNotificationConfigurations"></a>[DescribeNotificationConfigurations](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | Get your email notification preferences for Trusted Advisor Priority | Read | 
| <a name="trustedadvisor-DescribeNotificationPreferences"></a>[DescribeNotificationPreferences](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View the notification preferences for the AWS account | Read | 
| <a name="trustedadvisor-DescribeOrganization"></a>[DescribeOrganization](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View if the AWS account meets the requirements to enable the organizational view feature | Read | 
| <a name="trustedadvisor-DescribeOrganizationAccounts"></a>[DescribeOrganizationAccounts](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View the linked AWS accounts that are in the organization | Read | 
| <a name="trustedadvisor-DescribeReports"></a>[DescribeReports](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View details for organizational view reports, such as the report name, runtime, date created, status, and format | Read | 
| <a name="trustedadvisor-DescribeRisk"></a>[DescribeRisk](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View risk details in AWS Trusted Advisor Priority | Read | 
| <a name="trustedadvisor-DescribeRiskResources"></a>[DescribeRiskResources](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View affected resources for a risk in AWS Trusted Advisor Priority | Read | 
| <a name="trustedadvisor-DescribeRisks"></a>[DescribeRisks](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View risks in AWS Trusted Advisor Priority | Read | 
| <a name="trustedadvisor-DescribeServiceMetadata"></a>[DescribeServiceMetadata](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View information about organizational view reports, such as the AWS Regions, check categories, check names, and resource statuses | Read | 
| <a name="trustedadvisor-DownloadRisk"></a>[DownloadRisk](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | Download a file that contains details about the risk in AWS Trusted Advisor Priority | Read | 
| <a name="trustedadvisor-GetOrganizationRecommendation"></a>[GetOrganizationRecommendation](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | Get a specific recommendation within an AWS Organization's organization. This API supports only prioritized recommendations | Read | 
| <a name="trustedadvisor-GetRecommendation"></a>[GetRecommendation](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | Get a specific Recommendation | Read | 
| <a name="trustedadvisor-ListAccountsForParent"></a>[ListAccountsForParent](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View, in the Trusted Advisor console, all of the accounts in an AWS organization that are contained by a root or organizational unit (OU) | Read | 
| <a name="trustedadvisor-ListChecks"></a>[ListChecks](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List a filterable set of Checks | List | 
| <a name="trustedadvisor-ListOrganizationRecommendationAccounts"></a>[ListOrganizationRecommendationAccounts](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List the accounts that own the resources for an AWS Organization aggregate recommendation. This API only supports prioritized recommendations | List | 
| <a name="trustedadvisor-ListOrganizationRecommendationResources"></a>[ListOrganizationRecommendationResources](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List Resources of a Recommendation within an AWS Organization. This API only supports prioritized recommendations | List | 
| <a name="trustedadvisor-ListOrganizationRecommendations"></a>[ListOrganizationRecommendations](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List a filterable set of Recommendations within an AWS Organization. This API only supports prioritized recommendations | List | 
| <a name="trustedadvisor-ListOrganizationalUnitsForParent"></a>[ListOrganizationalUnitsForParent](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View, in the Trusted Advisor console, all of the organizational units (OUs) in a parent organizational unit or root | Read | 
| <a name="trustedadvisor-ListRecommendationResources"></a>[ListRecommendationResources](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List Resources of a Recommendation | List | 
| <a name="trustedadvisor-ListRecommendations"></a>[ListRecommendations](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List a filterable set of Recommendations | List | 
| <a name="trustedadvisor-ListRecommendationsForResource"></a>[ListRecommendationsForResource](https://docs.aws.amazon.com/awssupport/latest/user/get-started-with-aws-trusted-advisor-api.html) | List Recommendation of a Resource | List | 
| <a name="trustedadvisor-ListRoots"></a>[ListRoots](https://docs.aws.amazon.com/awssupport/latest/user/security-trusted-advisor.html#trusted-advisor-operations) | View, in the Trusted Advisor console, all of the roots that are defined in an AWS organization | Read |
