# Data retrieval APIs for AWS CodeArtifact

AWS CodeArtifact provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                             | Description                                                                      | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------ |
| [DescribeDomain](../../../codeartifact/latest/APIReference/API_DescribeDomain.md "../../../codeartifact/latest/APIReference/API_DescribeDomain.md")                                                 | Return information about a domain                                                | Read         |
| [DescribePackage](../../../codeartifact/latest/APIReference/API_DescribePackage.md "../../../codeartifact/latest/APIReference/API_DescribePackage.md")                                              | Retrieve information about a package                                             | Read         |
| [DescribePackageGroup](../../../codeartifact/latest/APIReference/API_DescribePackageGroup.md "../../../codeartifact/latest/APIReference/API_DescribePackageGroup.md")                               | Return detailed information about a package group                                | Read         |
| [DescribePackageVersion](../../../codeartifact/latest/APIReference/API_DescribePackageVersion.md "../../../codeartifact/latest/APIReference/API_DescribePackageVersion.md")                         | Return information about a package version                                       | Read         |
| [DescribeRepository](../../../codeartifact/latest/APIReference/API_DescribeRepository.md "../../../codeartifact/latest/APIReference/API_DescribeRepository.md")                                     | Return detailed information about a repository                                   | Read         |
| [GetAssociatedPackageGroup](../../../codeartifact/latest/APIReference/API_GetAssociatedPackageGroup.md "../../../codeartifact/latest/APIReference/API_GetAssociatedPackageGroup.md")                | Return a package's associated package group                                      | Read         |
| [GetAuthorizationToken](../../../codeartifact/latest/APIReference/API_GetAuthorizationToken.md "../../../codeartifact/latest/APIReference/API_GetAuthorizationToken.md")                            | Generate a temporary authentication token for accessing repositories in a domain | Read         |
| [GetDomainPermissionsPolicy](../../../codeartifact/latest/APIReference/API_GetDomainPermissionsPolicy.md "../../../codeartifact/latest/APIReference/API_GetDomainPermissionsPolicy.md")             | Return a domain's resource policy                                                | Read         |
| [GetPackageVersionAsset](../../../codeartifact/latest/APIReference/API_GetPackageVersionAsset.md "../../../codeartifact/latest/APIReference/API_GetPackageVersionAsset.md")                         | Return an asset (or file) that is part of a package version                      | Read         |
| [GetPackageVersionReadme](../../../codeartifact/latest/APIReference/API_GetPackageVersionReadme.md "../../../codeartifact/latest/APIReference/API_GetPackageVersionReadme.md")                      | Return a package version's readme file                                           | Read         |
| [GetRepositoryEndpoint](../../../codeartifact/latest/APIReference/API_GetRepositoryEndpoint.md "../../../codeartifact/latest/APIReference/API_GetRepositoryEndpoint.md")                            | Return an endpoint for a repository                                              | Read         |
| [GetRepositoryPermissionsPolicy](../../../codeartifact/latest/APIReference/API_GetRepositoryPermissionsPolicy.md "../../../codeartifact/latest/APIReference/API_GetRepositoryPermissionsPolicy.md") | Return a repository's resource policy                                            | Read         |
| [ListAllowedRepositoriesForGroup](../../../codeartifact/latest/APIReference/API_ListRepositoriesInDomain.md "../../../codeartifact/latest/APIReference/API_ListRepositoriesInDomain.md")            | List the allowed repositories for a package group                                | List         |
| [ListAssociatedPackages](../../../codeartifact/latest/APIReference/API_ListAssociatedPackages.md "../../../codeartifact/latest/APIReference/API_ListAssociatedPackages.md")                         | List the packages associated to a package group                                  | List         |
| [ListDomains](../../../codeartifact/latest/APIReference/API_ListDomains.md "../../../codeartifact/latest/APIReference/API_ListDomains.md")                                                          | List the domains in the current user's AWS account                               | List         |
| [ListPackageGroups](../../../codeartifact/latest/APIReference/API_ListPackageGroups.md "../../../codeartifact/latest/APIReference/API_ListPackageGroups.md")                                        | List the package groups in a domain                                              | List         |
| [ListPackageVersionAssets](../../../codeartifact/latest/APIReference/API_ListPackageVersionAssets.md "../../../codeartifact/latest/APIReference/API_ListPackageVersionAssets.md")                   | List a package version's assets                                                  | List         |
| [ListPackageVersionDependencies](../../../codeartifact/latest/APIReference/API_ListPackageVersionDependencies.md "../../../codeartifact/latest/APIReference/API_ListPackageVersionDependencies.md") | List the direct dependencies of a package version                                | List         |
| [ListPackageVersions](../../../codeartifact/latest/APIReference/API_ListPackageVersions.md "../../../codeartifact/latest/APIReference/API_ListPackageVersions.md")                                  | List a package's versions                                                        | List         |
| [ListPackages](../../../codeartifact/latest/APIReference/API_ListPackages.md "../../../codeartifact/latest/APIReference/API_ListPackages.md")                                                       | List the packages in a repository                                                | List         |
| [ListRepositories](../../../codeartifact/latest/APIReference/API_ListRepositories.md "../../../codeartifact/latest/APIReference/API_ListRepositories.md")                                           | List the repositories administered by the calling account                        | List         |
| [ListRepositoriesInDomain](../../../codeartifact/latest/APIReference/API_ListRepositoriesInDomain.md "../../../codeartifact/latest/APIReference/API_ListRepositoriesInDomain.md")                   | List the repositories in a domain                                                | List         |
| [ListSubPackageGroups](../../../codeartifact/latest/APIReference/API_ListSubPackageGroups.md "../../../codeartifact/latest/APIReference/API_ListSubPackageGroups.md")                               | List the sub package groups for a parent package group                           | List         |
| [ListTagsForResource](../../../codeartifact/latest/APIReference/API_ListTagsForResource.md "../../../codeartifact/latest/APIReference/API_ListTagsForResource.md")                                  | List tags for a CodeArtifact resource                                            | List         |
| [ReadFromRepository](../../../codeartifact/latest/ug/repo-policies.md "../../../codeartifact/latest/ug/repo-policies.md")                                                                           | Return package assets and metadata from a repository endpoint                    | Read         |
