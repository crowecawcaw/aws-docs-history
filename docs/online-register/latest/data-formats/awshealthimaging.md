

# Data retrieval APIs for AWS HealthImaging
<a name="awshealthimaging"></a>

AWS HealthImaging provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="medical-imaging-GetDICOMBulkdata"></a>[GetDICOMBulkdata](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_GetDICOMBulkdata.html) | Get dicom bulkdata in binary format | Read | 
| <a name="medical-imaging-GetDICOMImportJob"></a>[GetDICOMImportJob](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_GetDICOMImportJob.html) | Get an import job's properties | Read | 
| <a name="medical-imaging-GetDICOMInstance"></a>[GetDICOMInstance](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_GetDICOMInstance.html) | Get dicom instance in dcm format | Read | 
| <a name="medical-imaging-GetDICOMInstanceFrames"></a>[GetDICOMInstanceFrames](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceFrames.html) | Get dicom instance frames in format requested by the customer | Read | 
| <a name="medical-imaging-GetDICOMInstanceMetadata"></a>[GetDICOMInstanceMetadata](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceMetadata.html) | Get dicom instance metadata in DICOM JSON format | Read | 
| <a name="medical-imaging-GetDICOMSeriesMetadata"></a>[GetDICOMSeriesMetadata](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_GetDICOMSeriesMetadata.html) | Retrieve metadata for all DICOM instances belonging to a given DICOM series in DICOM JSON format | Read | 
| <a name="medical-imaging-GetDatastore"></a>[GetDatastore](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_GetDatastore.html) | Get data store properties | Read | 
| <a name="medical-imaging-GetImageFrame"></a>[GetImageFrame](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dataplane_GetImageFrame.html) | Get image frame properties | Read | 
| <a name="medical-imaging-GetImageSet"></a>[GetImageSet](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dataplane_GetImageSet.html) | Get image set properties | Read | 
| <a name="medical-imaging-GetImageSetMetadata"></a>[GetImageSetMetadata](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dataplane_GetImageSetMetadata.html) | Get image set metadata properties | Read | 
| <a name="medical-imaging-ListDICOMImportJobs"></a>[ListDICOMImportJobs](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_ListDICOMImportJobs.html) | List import jobs for a data store | List | 
| <a name="medical-imaging-ListDatastores"></a>[ListDatastores](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_ListDatastores.html) | List data stores | List | 
| <a name="medical-imaging-ListImageSetVersions"></a>[ListImageSetVersions](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dataplane_ListImageSetVersions.html) | List versions of an image set | List | 
| <a name="medical-imaging-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_ListTagsForResource.html) | List tags for a medical imaging resource | List | 
| <a name="medical-imaging-SearchDICOMInstances"></a>[SearchDICOMInstances](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_SearchDICOMInstances.html) | Search dicom instances that returns data in DICOM JSON format | Read | 
| <a name="medical-imaging-SearchDICOMSeries"></a>[SearchDICOMSeries](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_SearchDICOMSeries.html) | Search dicom series that returns data in DICOM JSON format | Read | 
| <a name="medical-imaging-SearchDICOMStudies"></a>[SearchDICOMStudies](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dicom_SearchDICOMStudies.html) | Search dicom studies that returns data in DICOM JSON format | Read | 
| <a name="medical-imaging-SearchImageSets"></a>[SearchImageSets](https://docs.aws.amazon.com/healthimaging/latest/APIReference/API_dataplane_SearchImageSets.html) | Search image sets | Read |
