# Data retrieval APIs for AWS HealthImaging

AWS HealthImaging provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                         | Description                                                                                      | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------ |
| [GetDICOMBulkdata](../../../healthimaging/latest/APIReference/API_dicom_GetDICOMBulkdata.md "../../../healthimaging/latest/APIReference/API_dicom_GetDICOMBulkdata.md")                         | Get dicom bulkdata in binary format                                                              | Read         |
| [GetDICOMImportJob](../../../healthimaging/latest/APIReference/API_GetDICOMImportJob.md "../../../healthimaging/latest/APIReference/API_GetDICOMImportJob.md")                                  | Get an import job's properties                                                                   | Read         |
| [GetDICOMInstance](../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstance.md "../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstance.md")                         | Get dicom instance in dcm format                                                                 | Read         |
| [GetDICOMInstanceFrames](../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceFrames.md "../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceFrames.md")       | Get dicom instance frames in format requested by the customer                                    | Read         |
| [GetDICOMInstanceMetadata](../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceMetadata.md "../../../healthimaging/latest/APIReference/API_dicom_GetDICOMInstanceMetadata.md") | Get dicom instance metadata in DICOM JSON format                                                 | Read         |
| [GetDICOMSeriesMetadata](../../../healthimaging/latest/APIReference/API_dicom_GetDICOMSeriesMetadata.md "../../../healthimaging/latest/APIReference/API_dicom_GetDICOMSeriesMetadata.md")       | Retrieve metadata for all DICOM instances belonging to a given DICOM series in DICOM JSON format | Read         |
| [GetDatastore](../../../healthimaging/latest/APIReference/API_GetDatastore.md "../../../healthimaging/latest/APIReference/API_GetDatastore.md")                                                 | Get data store properties                                                                        | Read         |
| [GetImageFrame](../../../healthimaging/latest/APIReference/API_dataplane_GetImageFrame.md "../../../healthimaging/latest/APIReference/API_dataplane_GetImageFrame.md")                          | Get image frame properties                                                                       | Read         |
| [GetImageSet](../../../healthimaging/latest/APIReference/API_dataplane_GetImageSet.md "../../../healthimaging/latest/APIReference/API_dataplane_GetImageSet.md")                                | Get image set properties                                                                         | Read         |
| [GetImageSetMetadata](../../../healthimaging/latest/APIReference/API_dataplane_GetImageSetMetadata.md "../../../healthimaging/latest/APIReference/API_dataplane_GetImageSetMetadata.md")        | Get image set metadata properties                                                                | Read         |
| [ListDICOMImportJobs](../../../healthimaging/latest/APIReference/API_ListDICOMImportJobs.md "../../../healthimaging/latest/APIReference/API_ListDICOMImportJobs.md")                            | List import jobs for a data store                                                                | List         |
| [ListDatastores](../../../healthimaging/latest/APIReference/API_ListDatastores.md "../../../healthimaging/latest/APIReference/API_ListDatastores.md")                                           | List data stores                                                                                 | List         |
| [ListImageSetVersions](../../../healthimaging/latest/APIReference/API_dataplane_ListImageSetVersions.md "../../../healthimaging/latest/APIReference/API_dataplane_ListImageSetVersions.md")     | List versions of an image set                                                                    | List         |
| [ListTagsForResource](../../../healthimaging/latest/APIReference/API_ListTagsForResource.md "../../../healthimaging/latest/APIReference/API_ListTagsForResource.md")                            | List tags for a medical imaging resource                                                         | List         |
| [SearchDICOMInstances](../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMInstances.md "../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMInstances.md")             | Search dicom instances that returns data in DICOM JSON format                                    | Read         |
| [SearchDICOMSeries](../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMSeries.md "../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMSeries.md")                      | Search dicom series that returns data in DICOM JSON format                                       | Read         |
| [SearchDICOMStudies](../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMStudies.md "../../../healthimaging/latest/APIReference/API_dicom_SearchDICOMStudies.md")                   | Search dicom studies that returns data in DICOM JSON format                                      | Read         |
| [SearchImageSets](../../../healthimaging/latest/APIReference/API_dataplane_SearchImageSets.md "../../../healthimaging/latest/APIReference/API_dataplane_SearchImageSets.md")                    | Search image sets                                                                                | Read         |
