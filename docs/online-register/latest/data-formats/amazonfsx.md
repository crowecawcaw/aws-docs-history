# Data retrieval APIs for Amazon FSx

Amazon FSx provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                       | Description                                                                                                                                 | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAssociatedFileGateways](../../../filegateway/latest/filefsxw/what-is-file-fsxw.md "../../../filegateway/latest/filefsxw/what-is-file-fsxw.md")                                       | Describe the File Gateway instances associated with an Amazon FSx for Windows File Server file system                                       | Read         |
| [DescribeBackups](../../../fsx/latest/APIReference/API_DescribeBackups.md "../../../fsx/latest/APIReference/API_DescribeBackups.md")                                                          | Return the descriptions of all backups owned by your AWS account in the AWS Region of the endpoint that you're calling                      | Read         |
| [DescribeDataRepositoryAssociations](../../../fsx/latest/APIReference/API_DescribeDataRepositoryAssociations.md "../../../fsx/latest/APIReference/API_DescribeDataRepositoryAssociations.md") | Return the descriptions of all data repository associations owned by your AWS account in the AWS Region of the endpoint that you're calling | Read         |
| [DescribeDataRepositoryTasks](../../../fsx/latest/APIReference/API_DescribeDataRepositoryTasks.md "../../../fsx/latest/APIReference/API_DescribeDataRepositoryTasks.md")                      | Return the descriptions of all data repository tasks owned by your AWS account in the AWS Region of the endpoint that you're calling        | Read         |
| [DescribeFileCaches](../../../fsx/latest/APIReference/API_DescribeFileCaches.md "../../../fsx/latest/APIReference/API_DescribeFileCaches.md")                                                 | Return the descriptions of all file caches owned by your AWS account in the AWS Region of the endpoint that you're calling                  | Read         |
| [DescribeFileSystemAliases](../../../fsx/latest/APIReference/API_DescribeFileSystemAliases.md "../../../fsx/latest/APIReference/API_DescribeFileSystemAliases.md")                            | Return the description of all DNS aliases owned by your Amazon FSx for Windows File Server file system                                      | Read         |
| [DescribeFileSystems](../../../fsx/latest/APIReference/API_DescribeFileSystems.md "../../../fsx/latest/APIReference/API_DescribeFileSystems.md")                                              | Return the descriptions of all file systems owned by your AWS account in the AWS Region of the endpoint that you're calling                 | Read         |
| [DescribeS3AccessPointAttachments](../../../fsx/latest/APIReference/API_DescribeS3AccessPointAttachments.md "../../../fsx/latest/APIReference/API_DescribeS3AccessPointAttachments.md")       | Return the descriptions of S3 Access Point Attachments                                                                                      | Read         |
| [DescribeSharedVpcConfiguration](../../../fsx/latest/APIReference/API_DescribeSharedVpcConfiguration.md "../../../fsx/latest/APIReference/API_DescribeSharedVpcConfiguration.md")             | Return the descriptions of whether FSx route table updates from participant accounts are allowed in your account                            | Read         |
| [DescribeSnapshots](../../../fsx/latest/APIReference/API_DescribeSnapshots.md "../../../fsx/latest/APIReference/API_DescribeSnapshots.md")                                                    | Return the descriptions of all snapshots owned by your AWS account in the AWS Region of the endpoint you're calling                         | Read         |
| [DescribeStorageVirtualMachines](../../../fsx/latest/APIReference/API_DescribeStorageVirtualMachines.md "../../../fsx/latest/APIReference/API_DescribeStorageVirtualMachines.md")             | Return the descriptions of all storage virtual machines owned by your AWS account in the AWS Region of the endpoint that you're calling     | Read         |
| [DescribeVolumes](../../../fsx/latest/APIReference/API_DescribeVolumes.md "../../../fsx/latest/APIReference/API_DescribeVolumes.md")                                                          | Return the descriptions of all volumes owned by your AWS account in the AWS Region of the endpoint that you're calling                      | Read         |
| [ListTagsForResource](../../../fsx/latest/APIReference/API_ListTagsForResource.md "../../../fsx/latest/APIReference/API_ListTagsForResource.md")                                              | List tags for an Amazon FSx resource                                                                                                        | Read         |
