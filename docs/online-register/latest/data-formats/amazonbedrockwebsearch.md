

# Data retrieval APIs for Amazon Bedrock Web Search
<a name="amazonbedrockwebsearch"></a>

Amazon Bedrock Web Search provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="bedrock-websearch-ExternalWebAccess"></a>[ExternalWebAccess](https://docs.aws.amazon.com/bedrock/latest/userguide/security-web-search.html#security-web-search-actions) | Retrieve content from external web sites outside the AWS boundary | Read | 
| <a name="bedrock-websearch-InvokeFetch"></a>[InvokeFetch](https://docs.aws.amazon.com/bedrock/latest/userguide/security-web-search.html#security-web-search-actions) | Invoke web fetch tools | Read | 
| <a name="bedrock-websearch-InvokeSearch"></a>[InvokeSearch](https://docs.aws.amazon.com/bedrock/latest/userguide/security-web-search.html#security-web-search-actions) | Invoke web search tools | Read |
