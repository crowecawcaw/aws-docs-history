# Data retrieval APIs for Amazon Bedrock Web Search

Amazon Bedrock Web Search provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                          | Description                                                       | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- | ------------ |
| [ExternalWebAccess](../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions "../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions") | Retrieve content from external web sites outside the AWS boundary | Read         |
| [InvokeFetch](../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions "../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions")       | Invoke web fetch tools                                            | Read         |
| [InvokeSearch](../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions "../../../bedrock/latest/userguide/security-web-search.md#security-web-search-actions")      | Invoke web search tools                                           | Read         |
