

# Data retrieval APIs for Amazon Q Business Q Apps
<a name="amazonqbusinessqapps"></a>

Amazon Q Business Q Apps provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="qapps-DescribeQAppPermissions"></a>[DescribeQAppPermissions](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_DescribeQAppPermissions.html) | Get Q App sharing permissions in the Q Business application environment | Read | 
| <a name="qapps-GetLibraryItem"></a>[GetLibraryItem](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_GetLibraryItem.html) | Get a library item in the Q Business application environment | Read | 
| <a name="qapps-GetQApp"></a>[GetQApp](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_GetQApp.html) | Get Q App in the Q Business application environment | Read | 
| <a name="qapps-GetQAppSession"></a>[GetQAppSession](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_GetQAppSession.html) | Get Q App session in the Q Business application environment | Read | 
| <a name="qapps-GetQAppSessionMetadata"></a>[GetQAppSessionMetadata](https://docs.aws.amazon.com/amazonq/latest/qbusiness-ug/purpose-built-qapps.html) | Get Q App session metadata in the Q Business application environment | Read | 
| <a name="qapps-ListCategories"></a>[ListCategories](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_ListCategories.html) | List categories in the Q Business application environment | List | 
| <a name="qapps-ListLibraryItems"></a>[ListLibraryItems](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_ListLibraryItems.html) | List library items in the Q Business application environment | List | 
| <a name="qapps-ListQAppSessionData"></a>[ListQAppSessionData](https://docs.aws.amazon.com/amazonq/latest/qbusiness-ug/purpose-built-qapps.html) | Get Q App session data in the Q Business application environment | Read | 
| <a name="qapps-ListQApps"></a>[ListQApps](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_qapps_ListQApps.html) | List Q Apps in the Q Business application environment | List | 
| <a name="qapps-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/amazonq/latest/api-reference/API_ListTagsForResource.html) | List tags for a resource | Read |
