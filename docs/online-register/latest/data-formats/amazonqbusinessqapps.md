| Actions                                                                                                                                                                            | Description                                                             | Access level |

| [GetLibraryItem](../../../amazonq/latest/api-reference/API_qapps_GetLibraryItem.md "../../../amazonq/latest/api-reference/API_qapps_GetLibraryItem.md")                            | Get a library item in the Q Business application environment            | Read         |
| [GetQApp](../../../amazonq/latest/api-reference/API_qapps_GetQApp.md "../../../amazonq/latest/api-reference/API_qapps_GetQApp.md")                                                 | Get Q App in the Q Business application environment                     | Read         |
| [GetQAppSession](../../../amazonq/latest/api-reference/API_qapps_GetQAppSession.md "../../../amazonq/latest/api-reference/API_qapps_GetQAppSession.md")                            | Get Q App session in the Q Business application environment             | Read         |
| [GetQAppSessionMetadata](../../../amazonq/latest/qbusiness-ug/purpose-built-qapps.md "../../../amazonq/latest/qbusiness-ug/purpose-built-qapps.md")                                | Get Q App session metadata in the Q Business application environment    | Read         |
| [ListCategories](../../../amazonq/latest/api-reference/API_qapps_ListCategories.md "../../../amazonq/latest/api-reference/API_qapps_ListCategories.md")                            | List categories in the Q Business application environment               | List         |
| [ListLibraryItems](../../../amazonq/latest/api-reference/API_qapps_ListLibraryItems.md "../../../amazonq/latest/api-reference/API_qapps_ListLibraryItems.md")                      | List library items in the Q Business application environment            | List         |
| [ListQAppSessionData](../../../amazonq/latest/qbusiness-ug/purpose-built-qapps.md "../../../amazonq/latest/qbusiness-ug/purpose-built-qapps.md")                                   | Get Q App session data in the Q Business application environment        | Read         |
| [ListQApps](../../../amazonq/latest/api-reference/API_qapps_ListQApps.md "../../../amazonq/latest/api-reference/API_qapps_ListQApps.md")                                           | List Q Apps in the Q Business application environment                   | List         |
| [ListTagsForResource](../../../amazonq/latest/api-reference/API_ListTagsForResource.md "../../../amazonq/latest/api-reference/API_ListTagsForResource.md")                         | List tags for a resource                                                | Read         |
