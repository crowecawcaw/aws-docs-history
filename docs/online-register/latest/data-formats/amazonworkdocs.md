# Data retrieval APIs for Amazon WorkDocs

Amazon WorkDocs provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                              | Description                                                                                                                          | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [CheckAlias](../../../workdocs/latest/adminguide/cloud_quick_start.md "../../../workdocs/latest/adminguide/cloud_quick_start.md")                                                                    | Check an alias                                                                                                                       | Read         |
| [DescribeActivities](../../../workdocs/latest/APIReference/API_DescribeActivities.md "../../../workdocs/latest/APIReference/API_DescribeActivities.md")                                              | Fetch user activities in a specified time period                                                                                     | List         |
| [DescribeAvailableDirectories](../../../workdocs/latest/adminguide/getting_started.md "../../../workdocs/latest/adminguide/getting_started.md")                                                      | Describe available directories                                                                                                       | List         |
| [DescribeComments](../../../workdocs/latest/APIReference/API_DescribeComments.md "../../../workdocs/latest/APIReference/API_DescribeComments.md")                                                    | List all the comments for the specified document version                                                                             | List         |
| [DescribeDocumentVersions](../../../workdocs/latest/APIReference/API_DescribeDocumentVersions.md "../../../workdocs/latest/APIReference/API_DescribeDocumentVersions.md")                            | Retrieve the document versions for the specified document                                                                            | List         |
| [DescribeFolderContents](../../../workdocs/latest/APIReference/API_DescribeFolderContents.md "../../../workdocs/latest/APIReference/API_DescribeFolderContents.md")                                  | Describe the contents of the specified folder, including its documents and sub-folders                                               | List         |
| [DescribeGroups](../../../workdocs/latest/APIReference/API_DescribeGroups.md "../../../workdocs/latest/APIReference/API_DescribeGroups.md")                                                          | Describe the user groups                                                                                                             | List         |
| [DescribeInstanceExports](../../../workdocs/latest/adminguide/migration-tool.md "../../../workdocs/latest/adminguide/migration-tool.md")                                                             | Describe the export history for an instance                                                                                          | List         |
| [DescribeInstances](../../../workdocs/latest/adminguide/getting_started.md "../../../workdocs/latest/adminguide/getting_started.md")                                                                 | Describe instances                                                                                                                   | List         |
| [DescribeNotificationPermissions](../../../workdocs/latest/adminguide/manage-notifications.md "../../../workdocs/latest/adminguide/manage-notifications.md")                                         | Describe principals that are allowed to call notification subscription APIs for a given WorkDocs site                                | List         |
| [DescribeNotificationSubscriptions](../../../workdocs/latest/APIReference/API_DescribeNotificationSubscriptions.md "../../../workdocs/latest/APIReference/API_DescribeNotificationSubscriptions.md") | List the specified notification subscriptions                                                                                        | List         |
| [DescribeResourcePermissions](../../../workdocs/latest/APIReference/API_DescribeResourcePermissions.md "../../../workdocs/latest/APIReference/API_DescribeResourcePermissions.md")                   | View a description of a specified resource's permissions                                                                             | List         |
| [DescribeRootFolders](../../../workdocs/latest/APIReference/API_DescribeRootFolders.md "../../../workdocs/latest/APIReference/API_DescribeRootFolders.md")                                           | Describe the root folders                                                                                                            | List         |
| [DescribeUsers](../../../workdocs/latest/APIReference/API_DescribeUsers.md "../../../workdocs/latest/APIReference/API_DescribeUsers.md")                                                             | View a description of the specified users. You can describe all users or filter the results (for example, by status or organization) | List         |
| [DownloadDocumentVersion](../../../workdocs/latest/APIReference/API_GetDocumentVersion.md "../../../workdocs/latest/APIReference/API_GetDocumentVersion.md")                                         | Download a specified document version                                                                                                | Read         |
| [GetCurrentUser](../../../workdocs/latest/APIReference/API_GetCurrentUser.md "../../../workdocs/latest/APIReference/API_GetCurrentUser.md")                                                          | Retrieve the details of the current user                                                                                             | Read         |
| [GetDocument](../../../workdocs/latest/APIReference/API_GetDocument.md "../../../workdocs/latest/APIReference/API_GetDocument.md")                                                                   | Retrieve the specified document object                                                                                               | Read         |
| [GetDocumentPath](../../../workdocs/latest/APIReference/API_GetDocumentPath.md "../../../workdocs/latest/APIReference/API_GetDocumentPath.md")                                                       | Retrieve the path information (the hierarchy from the root folder) for the requested document                                        | Read         |
| [GetDocumentVersion](../../../workdocs/latest/APIReference/API_GetDocumentVersion.md "../../../workdocs/latest/APIReference/API_GetDocumentVersion.md")                                              | Retrieve version metadata for the specified document                                                                                 | Read         |
| [GetFolder](../../../workdocs/latest/APIReference/API_GetFolder.md "../../../workdocs/latest/APIReference/API_GetFolder.md")                                                                         | Retrieve the metadata of the specified folder                                                                                        | Read         |
| [GetFolderPath](../../../workdocs/latest/APIReference/API_GetFolderPath.md "../../../workdocs/latest/APIReference/API_GetFolderPath.md")                                                             | Retrieve the path information (the hierarchy from the root folder) for the specified folder                                          | Read         |
| [GetGroup](../../../workdocs/latest/APIReference/API_Operations.md "../../../workdocs/latest/APIReference/API_Operations.md")                                                                        | Retrieve details for the specified group                                                                                             | Read         |
| [GetResources](../../../workdocs/latest/APIReference/API_GetResources.md "../../../workdocs/latest/APIReference/API_GetResources.md")                                                                | Get a collection of resources                                                                                                        | Read         |
| [SearchResources](../../../workdocs/latest/APIReference/API_SearchResources.md "../../../workdocs/latest/APIReference/API_SearchResources.md")                                                       | Search metadata and the content of resources                                                                                         | List         |
