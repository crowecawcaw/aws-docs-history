

# Data retrieval APIs for Amazon FinSpace
<a name="amazonfinspace"></a>

Amazon FinSpace provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- |

| <a name="finspace-GetKxChangeset"></a>[GetKxChangeset](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxChangeset.html) | Describe a changeset for a kdb database | Read | 
| <a name="finspace-GetKxCluster"></a>[GetKxCluster](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxCluster.html) | Describe a cluster in a managed kdb environment | Read | 
| <a name="finspace-GetKxConnectionString"></a>[GetKxConnectionString](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxConnectionString.html) | Retrieve a connection string for kdb clusters | Read | 
| <a name="finspace-GetKxDatabase"></a>[GetKxDatabase](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxDatabase.html) | Describe a kdb database | Read | 
| <a name="finspace-GetKxDataview"></a>[GetKxDataview](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxDataview.html) | Describe a databiew in a managed kdb environment | Read | 
| <a name="finspace-GetKxEnvironment"></a>[GetKxEnvironment](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxEnvironment.html) | Describe a managed kdb environment | Read | 
| <a name="finspace-GetKxScalingGroup"></a>[GetKxScalingGroup](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxScalingGroup.html) | Describe a scaling group in a managed kdb environment | Read | 
| <a name="finspace-GetKxUser"></a>[GetKxUser](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxUser.html) | Describe a kdb user | Read | 
| <a name="finspace-GetKxVolume"></a>[GetKxVolume](https://docs.aws.amazon.com/finspace/latest/management-api/API_GetKxVolume.html) | Describe a volume in a managed kdb environment | Read | 
| <a name="finspace-GetLoadSampleDataSetGroupIntoEnvironmentStatus"></a>[GetLoadSampleDataSetGroupIntoEnvironmentStatus](https://docs.aws.amazon.com/finspace/latest/userguide/finspace-what-is.html) | Request status of the loading of sample data bundle | Read | 
| <a name="finspace-GetUser"></a>[GetUser](https://docs.aws.amazon.com/finspace/latest/userguide/finspace-what-is.html) | Describe a FinSpace user | Read | 
| <a name="finspace-ListEnvironments"></a>[ListEnvironments](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListEnvironments.html) | List FinSpace environments in the AWS account | List | 
| <a name="finspace-ListKxChangesets"></a>[ListKxChangesets](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxChangesets.html) | List changesets for a kdb database | List | 
| <a name="finspace-ListKxClusterNodes"></a>[ListKxClusterNodes](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxClusterNodes.html) | List cluster nodes in a managed kdb environment | List | 
| <a name="finspace-ListKxClusters"></a>[ListKxClusters](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxClusters.html) | List clusters in a managed kdb environment | List | 
| <a name="finspace-ListKxDatabases"></a>[ListKxDatabases](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxDatabases.html) | List kdb databases in a managed kdb environment | List | 
| <a name="finspace-ListKxDataviews"></a>[ListKxDataviews](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxDataviews.html) | List dataviews in a database | List |

| <a name="finspace-ListKxScalingGroups"></a>[ListKxScalingGroups](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxScalingGroups.html) | List scaling groups in a managed kdb environment | List |

| <a name="finspace-ListKxVolumes"></a>[ListKxVolumes](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListKxVolumes.html) | List volumes in a managed kdb environment | List | 
| <a name="finspace-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/finspace/latest/management-api/API_ListTagsForResource.html) | Return a list of tags for a resource | List |
