| [GetKxCluster](../../../finspace/latest/management-api/API_GetKxCluster.md "../../../finspace/latest/management-api/API_GetKxCluster.md")                            | Describe a cluster in a managed kdb environment       | Read         |
| [GetKxConnectionString](../../../finspace/latest/management-api/API_GetKxConnectionString.md "../../../finspace/latest/management-api/API_GetKxConnectionString.md") | Retrieve a connection string for kdb clusters         | Read         |
| [GetKxDatabase](../../../finspace/latest/management-api/API_GetKxDatabase.md "../../../finspace/latest/management-api/API_GetKxDatabase.md")                         | Describe a kdb database                               | Read         |
| [GetKxDataview](../../../finspace/latest/management-api/API_GetKxDataview.md "../../../finspace/latest/management-api/API_GetKxDataview.md")                         | Describe a databiew in a managed kdb environment      | Read         |
| [GetKxEnvironment](../../../finspace/latest/management-api/API_GetKxEnvironment.md "../../../finspace/latest/management-api/API_GetKxEnvironment.md")                | Describe a managed kdb environment                    | Read         |
