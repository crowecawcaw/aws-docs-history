# Data retrieval APIs for Amazon OpenSearch Ingestion

Amazon OpenSearch Ingestion provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                      | Description                                                                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------ |
| [GetPipeline](../../../opensearch-service/latest/APIReference/API_osis_GetPipeline.md "../../../opensearch-service/latest/APIReference/API_osis_GetPipeline.md")                                                             | Retrieve configuration information for an OpenSearch Ingestion pipeline                           | Read         |
| [GetPipelineBlueprint](../../../opensearch-service/latest/APIReference/API_osis_GetPipelineBlueprint.md "../../../opensearch-service/latest/APIReference/API_osis_GetPipelineBlueprint.md")                                  | Get the contents of an OpenSearch Ingestion pipeline blueprint                                    | Read         |
| [GetPipelineChangeProgress](../../../opensearch-service/latest/APIReference/API_osis_GetPipelineChangeProgress.md "../../../opensearch-service/latest/APIReference/API_osis_GetPipelineChangeProgress.md")                   | Get granular information about the status of an OpenSearch Ingestion pipeline                     | Read         |
| [GetResourcePolicy](../../../opensearch-service/latest/APIReference/API_osis_GetResourcePolicy.md "../../../opensearch-service/latest/APIReference/API_osis_GetResourcePolicy.md")                                           | Get a resource policy for an OpenSearch Ingestion resource                                        | Read         |
| [ListPipelineBlueprints](../../../opensearch-service/latest/APIReference/API_osis_ListPipelineBlueprints.md "../../../opensearch-service/latest/APIReference/API_osis_ListPipelineBlueprints.md")                            | List the names of available blueprints for an OpenSearch Ingestion pipeline configuration         | List         |
| [ListPipelineEndpointConnections](../../../opensearch-service/latest/APIReference/API_osis_ListPipelineEndpointConnections.md "../../../opensearch-service/latest/APIReference/API_osis_ListPipelineEndpointConnections.md") | List OpenSearch Ingestion pipeline endpoint connections to pipelines in the current account       | List         |
| [ListPipelineEndpoints](../../../opensearch-service/latest/APIReference/API_osis_ListPipelineEndpoints.md "../../../opensearch-service/latest/APIReference/API_osis_ListPipelineEndpoints.md")                               | List OpenSearch Ingestion pipeline endpoints in the current account                               | List         |
| [ListPipelines](../../../opensearch-service/latest/APIReference/API_osis_ListPipelines.md "../../../opensearch-service/latest/APIReference/API_osis_ListPipelines.md")                                                       | List basic configuration for each OpenSearch Ingestion pipeline in the current account and Region | List         |
| [ListTagsForResource](../../../opensearch-service/latest/APIReference/API_osis_ListTagsForResource.md "../../../opensearch-service/latest/APIReference/API_osis_ListTagsForResource.md")                                     | List all resource tags associated with an OpenSearch Ingestion pipeline                           | Read         |
| [ValidatePipeline](../../../opensearch-service/latest/APIReference/API_osis_ValidatePipeline.md "../../../opensearch-service/latest/APIReference/API_osis_ValidatePipeline.md")                                              | Validate the configuration of an OpenSearch Ingestion pipeline                                    | Read         |
