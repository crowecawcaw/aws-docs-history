

# Data retrieval APIs for AWS Resource Access Manager (RAM)
<a name="awsresourceaccessmanagerram"></a>

AWS Resource Access Manager (RAM) provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="ram-GetPermission"></a>[GetPermission](https://docs.aws.amazon.com/ram/latest/APIReference/API_GetPermission.html) | Get the contents of an AWS RAM permission | Read | 
| <a name="ram-GetResourcePolicies"></a>[GetResourcePolicies](https://docs.aws.amazon.com/ram/latest/APIReference/API_GetResourcePolicies.html) | Get the policies for the specified resources that you own and have shared | Read | 
| <a name="ram-GetResourceShareAssociations"></a>[GetResourceShareAssociations](https://docs.aws.amazon.com/ram/latest/APIReference/API_GetResourceShareAssociations.html) | Get a set of resource share associations from a provided list or with a specified status of the specified type | Read | 
| <a name="ram-GetResourceShareInvitations"></a>[GetResourceShareInvitations](https://docs.aws.amazon.com/ram/latest/APIReference/API_GetResourceShareInvitations.html) | Get resource share invitations by the specified invitation arn or those for the resource share | Read | 
| <a name="ram-GetResourceShares"></a>[GetResourceShares](https://docs.aws.amazon.com/ram/latest/APIReference/API_GetResourceShares.html) | Get a set of resource shares from a provided list or with a specified status | Read | 
| <a name="ram-ListPendingInvitationResources"></a>[ListPendingInvitationResources](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListPendingInvitationResources.html) | List the resources in a resource share that is shared with you but that the invitation is still pending for | Read | 
| <a name="ram-ListPermissionAssociations"></a>[ListPermissionAssociations](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListPermissionAssociations.html) | List information about the permission and any associations | List | 
| <a name="ram-ListPermissionVersions"></a>[ListPermissionVersions](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListPermissionVersions.html) | List the versions of an AWS RAM permission | List | 
| <a name="ram-ListPermissions"></a>[ListPermissions](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListPermissions.html) | List the AWS RAM permissions | List | 
| <a name="ram-ListPrincipals"></a>[ListPrincipals](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListPrincipals.html) | List the principals that you have shared resources with or that have shared resources with you | List | 
| <a name="ram-ListReplacePermissionAssociationsWork"></a>[ListReplacePermissionAssociationsWork](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListReplacePermissionAssociationsWork.html) | Retrieve the status of the asynchronous permission replacement | List | 
| <a name="ram-ListResourceSharePermissions"></a>[ListResourceSharePermissions](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListResourceSharePermissions.html) | List the Permissions associated with a Resource Share | List | 
| <a name="ram-ListResourceTypes"></a>[ListResourceTypes](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListResourceTypes.html) | List the shareable resource types supported by AWS RAM | List | 
| <a name="ram-ListResources"></a>[ListResources](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListResources.html) | List the resources that you added to resource shares or the resources that are shared with you | List | 
| <a name="ram-ListSourceAssociations"></a>[ListSourceAssociations](https://docs.aws.amazon.com/ram/latest/APIReference/API_ListSourceAssociations.html) | List source associations for resource shares | List |
