# Data retrieval APIs for AWS Resource Access Manager (RAM)

AWS Resource Access Manager (RAM) provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                | Description                                                                                                    | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetPermission](../../../ram/latest/APIReference/API_GetPermission.md "../../../ram/latest/APIReference/API_GetPermission.md")                                                                         | Get the contents of an AWS RAM permission                                                                      | Read         |
| [GetResourcePolicies](../../../ram/latest/APIReference/API_GetResourcePolicies.md "../../../ram/latest/APIReference/API_GetResourcePolicies.md")                                                       | Get the policies for the specified resources that you own and have shared                                      | Read         |
| [GetResourceShareAssociations](../../../ram/latest/APIReference/API_GetResourceShareAssociations.md "../../../ram/latest/APIReference/API_GetResourceShareAssociations.md")                            | Get a set of resource share associations from a provided list or with a specified status of the specified type | Read         |
| [GetResourceShareInvitations](../../../ram/latest/APIReference/API_GetResourceShareInvitations.md "../../../ram/latest/APIReference/API_GetResourceShareInvitations.md")                               | Get resource share invitations by the specified invitation arn or those for the resource share                 | Read         |
| [GetResourceShares](../../../ram/latest/APIReference/API_GetResourceShares.md "../../../ram/latest/APIReference/API_GetResourceShares.md")                                                             | Get a set of resource shares from a provided list or with a specified status                                   | Read         |
| [ListPendingInvitationResources](../../../ram/latest/APIReference/API_ListPendingInvitationResources.md "../../../ram/latest/APIReference/API_ListPendingInvitationResources.md")                      | List the resources in a resource share that is shared with you but that the invitation is still pending for    | Read         |
| [ListPermissionAssociations](../../../ram/latest/APIReference/API_ListPermissionAssociations.md "../../../ram/latest/APIReference/API_ListPermissionAssociations.md")                                  | List information about the permission and any associations                                                     | List         |
| [ListPermissionVersions](../../../ram/latest/APIReference/API_ListPermissionVersions.md "../../../ram/latest/APIReference/API_ListPermissionVersions.md")                                              | List the versions of an AWS RAM permission                                                                     | List         |
| [ListPermissions](../../../ram/latest/APIReference/API_ListPermissions.md "../../../ram/latest/APIReference/API_ListPermissions.md")                                                                   | List the AWS RAM permissions                                                                                   | List         |
| [ListPrincipals](../../../ram/latest/APIReference/API_ListPrincipals.md "../../../ram/latest/APIReference/API_ListPrincipals.md")                                                                      | List the principals that you have shared resources with or that have shared resources with you                 | List         |
| [ListReplacePermissionAssociationsWork](../../../ram/latest/APIReference/API_ListReplacePermissionAssociationsWork.md "../../../ram/latest/APIReference/API_ListReplacePermissionAssociationsWork.md") | Retrieve the status of the asynchronous permission replacement                                                 | List         |
| [ListResourceSharePermissions](../../../ram/latest/APIReference/API_ListResourceSharePermissions.md "../../../ram/latest/APIReference/API_ListResourceSharePermissions.md")                            | List the Permissions associated with a Resource Share                                                          | List         |
| [ListResourceTypes](../../../ram/latest/APIReference/API_ListResourceTypes.md "../../../ram/latest/APIReference/API_ListResourceTypes.md")                                                             | List the shareable resource types supported by AWS RAM                                                         | List         |
| [ListResources](../../../ram/latest/APIReference/API_ListResources.md "../../../ram/latest/APIReference/API_ListResources.md")                                                                         | List the resources that you added to resource shares or the resources that are shared with you                 | List         |
