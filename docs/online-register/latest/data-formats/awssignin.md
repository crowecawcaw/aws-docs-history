# Data retrieval APIs for AWS Signin

AWS Signin provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                   | Description                                                                                                                                               | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [Authenticate](../../../signin/latest/APIReference/API_Authenticate.md "../../../signin/latest/APIReference/API_Authenticate.md")                                                                                                                         | Authenticate to the AWS Management Console                                                                                                                | Read         |
| [AuthorizeOAuth2Access](../../../signin/latest/APIReference/API_AuthorizeOAuth2Access.md "../../../signin/latest/APIReference/API_AuthorizeOAuth2Access.md")                                                                                              | Authenticate through a browser and obtain an OAuth 2.0 authorization code for credential exchange                                                         | Read         |
| [CreateOAuth2Token](../../../signin/latest/APIReference/API_CreateOAuth2Token.md "../../../signin/latest/APIReference/API_CreateOAuth2Token.md")                                                                                                          | Exchange an authorization code for OAuth 2.0 access token and refresh token that can be used to access AWS services from developer tools and applications | Read         |
| [GetConsoleAuthorizationConfiguration](../../../signin/latest/APIReference/API_GetConsoleAuthorizationConfiguration.md "../../../signin/latest/APIReference/API_GetConsoleAuthorizationConfiguration.md")                                                 | Retrieve console authorization configuration for an AWS account or organization                                                                           | Read         |
| [GetResourcePolicy](../../../signin/latest/APIReference/API_GetResourcePolicy.md "../../../signin/latest/APIReference/API_GetResourcePolicy.md")                                                                                                          | Retrieve SignIn Resource Based Policy document that is attached with your account                                                                         | Read         |
| [IntrospectOAuth2Token](../../../signin/latest/APIReference/API_IntrospectOAuth2Token.md "../../../signin/latest/APIReference/API_IntrospectOAuth2Token.md")                                                                                              | Inspect the metadata and active state of an OAuth 2.0 access token or refresh token                                                                       | Read         |
| [ListResourcePermissionStatements](../../../signin/latest/APIReference/API_ListResourcePermissionStatements.md "../../../signin/latest/APIReference/API_ListResourcePermissionStatements.md")                                                             | List the SignIn Resource Based Policy statements in your account                                                                                          | List         |
| [ListTrustedIdentityPropagationApplicationsForConsole](../../../signin/latest/APIReference/API_ListTrustedIdentityPropagationApplicationsForConsole.md "../../../signin/latest/APIReference/API_ListTrustedIdentityPropagationApplicationsForConsole.md") | List all Identity Center applications that represent the AWS Management Console                                                                           | List         |
