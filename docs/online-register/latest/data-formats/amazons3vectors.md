# Data retrieval APIs for Amazon S3 Vectors

Amazon S3 Vectors provides the following APIs for data retrieval.

| Actions                                                                                                                                                                        | Description                                                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ------------ |
| [GetIndex](../../../AmazonS3/latest/API/API_S3VectorBuckets_GetIndex.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_GetIndex.md")                                        | Get the attributes of a specified vector index                                                     | Read         |
| [GetVectorBucket](../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectorBucket.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectorBucket.md")                   | Get the attributes of a specified vector bucket                                                    | Read         |
| [GetVectorBucketPolicy](../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectorBucketPolicy.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectorBucketPolicy.md") | Get the IAM resource policy for a specific vector bucket                                           | Read         |
| [GetVectors](../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectors.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_GetVectors.md")                                  | Get a batch of vectors by their vector keys                                                        | Read         |
| [ListIndexes](../../../AmazonS3/latest/API/API_S3VectorBuckets_ListIndexes.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_ListIndexes.md")                               | Get a paginated list of all indexes in a specified vector bucket                                   | List         |
| [ListVectorBuckets](../../../AmazonS3/latest/API/API_S3VectorBuckets_ListVectorBuckets.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_ListVectorBuckets.md")             | Get a paginated list of all vector buckets in the account                                          | List         |
| [ListVectors](../../../AmazonS3/latest/API/API_S3VectorBuckets_ListVectors.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_ListVectors.md")                               | Get a paginated list of all vectors in a specified vector index                                    | List         |
| [QueryVectors](../../../AmazonS3/latest/API/API_S3VectorBuckets_QueryVectors.md "../../../AmazonS3/latest/API/API_S3VectorBuckets_QueryVectors.md")                            | Find approximate nearest neighbors within a specified search vector index for a given query vector | Read         |
