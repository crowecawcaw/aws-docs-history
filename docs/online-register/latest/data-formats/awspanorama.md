# Data retrieval APIs for AWS Panorama

AWS Panorama provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                     | Description                                                                | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------ |
| [DescribeApplicationInstance](../../../panorama/latest/api/API_DescribeApplicationInstance.md "../../../panorama/latest/api/API_DescribeApplicationInstance.md")                            | View details about an AWS Panorama application instance                    | Read         |
| [DescribeApplicationInstanceDetails](../../../panorama/latest/api/API_DescribeApplicationInstanceDetails.md "../../../panorama/latest/api/API_DescribeApplicationInstanceDetails.md")       | View details about an AWS Panorama application instance                    | Read         |
| [DescribeDevice](../../../panorama/latest/api/API_DescribeDevice.md "../../../panorama/latest/api/API_DescribeDevice.md")                                                                   | View details about an AWS Panorama Appliance                               | Read         |
| [DescribeDeviceJob](../../../panorama/latest/api/API_DescribeDeviceJob.md "../../../panorama/latest/api/API_DescribeDeviceJob.md")                                                          | View job details for an AWS Panorama Appliance                             | Read         |
| [DescribeNode](../../../panorama/latest/api/API_DescribeNode.md "../../../panorama/latest/api/API_DescribeNode.md")                                                                         | View details about an AWS Panorama application node                        | Read         |
| [DescribeNodeFromTemplateJob](../../../panorama/latest/api/API_DescribeNodeFromTemplateJob.md "../../../panorama/latest/api/API_DescribeNodeFromTemplateJob.md")                            | View details about AWS Panorama application node                           | Read         |
| [DescribePackage](../../../panorama/latest/api/API_DescribePackage.md "../../../panorama/latest/api/API_DescribePackage.md")                                                                | View details about an AWS Panorama package                                 | Read         |
| [DescribePackageImportJob](../../../panorama/latest/api/API_DescribePackageImportJob.md "../../../panorama/latest/api/API_DescribePackageImportJob.md")                                     | View details about an AWS Panorama package                                 | Read         |
| [DescribePackageVersion](../../../panorama/latest/api/API_DescribePackageVersion.md "../../../panorama/latest/api/API_DescribePackageVersion.md")                                           | View details about an AWS Panorama package version                         | Read         |
| [DescribeSoftware](../../../service-authorization/latest/reference/list_awspanorama.md "../../../service-authorization/latest/reference/list_awspanorama.md")                               | View details about a software version for the AWS Panorama Appliance       | Read         |
| [GetWebSocketURL](../../../service-authorization/latest/reference/list_awspanorama.md "../../../service-authorization/latest/reference/list_awspanorama.md")                                | Generate a WebSocket endpoint for communication with AWS Panorama          | Read         |
| [ListApplicationInstanceDependencies](../../../panorama/latest/api/API_ListApplicationInstanceDependencies.md "../../../panorama/latest/api/API_ListApplicationInstanceDependencies.md")    | Retrieve a list of application instance dependencies in AWS Panorama       | List         |
| [ListApplicationInstanceNodeInstances](../../../panorama/latest/api/API_ListApplicationInstanceNodeInstances.md "../../../panorama/latest/api/API_ListApplicationInstanceNodeInstances.md") | Retrieve a list of node instances of application instances in AWS Panorama | List         |
| [ListApplicationInstances](../../../panorama/latest/api/API_ListApplicationInstances.md "../../../panorama/latest/api/API_ListApplicationInstances.md")                                     | Retrieve a list of application instances in AWS Panorama                   | List         |
| [ListDevices](../../../panorama/latest/api/API_ListDevices.md "../../../panorama/latest/api/API_ListDevices.md")                                                                            | Retrieve a list of appliances in AWS Panorama                              | List         |
| [ListDevicesJobs](../../../panorama/latest/api/API_ListDevicesJobs.md "../../../panorama/latest/api/API_ListDevicesJobs.md")                                                                | Retrieve a list of jobs for an AWS Panorama Appliance                      | List         |
| [ListNodeFromTemplateJobs](../../../panorama/latest/api/API_ListNodeFromTemplateJobs.md "../../../panorama/latest/api/API_ListNodeFromTemplateJobs.md")                                     | Retrieve a list of Nodes for an AWS Panorama Appliance                     | List         |
| [ListNodes](../../../panorama/latest/api/API_ListNodes.md "../../../panorama/latest/api/API_ListNodes.md")                                                                                  | Retrieve a list of nodes in AWS Panorama                                   | List         |
| [ListPackageImportJobs](../../../panorama/latest/api/API_ListPackageImportJobs.md "../../../panorama/latest/api/API_ListPackageImportJobs.md")                                              | Retrieve a list of packages in AWS Panorama                                | List         |
| [ListPackages](../../../panorama/latest/api/API_ListPackages.md "../../../panorama/latest/api/API_ListPackages.md")                                                                         | Retrieve a list of packages in AWS Panorama                                | List         |
| [ListTagsForResource](../../../panorama/latest/api/API_ListTagsForResource.md "../../../panorama/latest/api/API_ListTagsForResource.md")                                                    | Retrieve a list of tags for a resource in AWS Panorama                     | Read         |
