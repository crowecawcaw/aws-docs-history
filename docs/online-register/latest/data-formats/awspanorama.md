

# Data retrieval APIs for AWS Panorama
<a name="awspanorama"></a>

AWS Panorama provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="panorama-DescribeApplicationInstance"></a>[DescribeApplicationInstance](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstance.html) | View details about an AWS Panorama application instance | Read | 
| <a name="panorama-DescribeApplicationInstanceDetails"></a>[DescribeApplicationInstanceDetails](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstanceDetails.html) | View details about an AWS Panorama application instance | Read | 
| <a name="panorama-DescribeDevice"></a>[DescribeDevice](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDevice.html) | View details about an AWS Panorama Appliance | Read | 
| <a name="panorama-DescribeDeviceJob"></a>[DescribeDeviceJob](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDeviceJob.html) | View job details for an AWS Panorama Appliance | Read | 
| <a name="panorama-DescribeNode"></a>[DescribeNode](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNode.html) | View details about an AWS Panorama application node | Read | 
| <a name="panorama-DescribeNodeFromTemplateJob"></a>[DescribeNodeFromTemplateJob](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNodeFromTemplateJob.html) | View details about AWS Panorama application node | Read | 
| <a name="panorama-DescribePackage"></a>[DescribePackage](https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackage.html) | View details about an AWS Panorama package | Read | 
| <a name="panorama-DescribePackageImportJob"></a>[DescribePackageImportJob](https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageImportJob.html) | View details about an AWS Panorama package | Read | 
| <a name="panorama-DescribePackageVersion"></a>[DescribePackageVersion](https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageVersion.html) | View details about an AWS Panorama package version | Read | 
| <a name="panorama-DescribeSoftware"></a>[DescribeSoftware](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awspanorama.html) | View details about a software version for the AWS Panorama Appliance | Read | 
| <a name="panorama-GetWebSocketURL"></a>[GetWebSocketURL](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awspanorama.html) | Generate a WebSocket endpoint for communication with AWS Panorama | Read | 
| <a name="panorama-ListApplicationInstanceDependencies"></a>[ListApplicationInstanceDependencies](https://docs.aws.amazon.com/panorama/latest/api/API_ListApplicationInstanceDependencies.html) | Retrieve a list of application instance dependencies in AWS Panorama | List | 
| <a name="panorama-ListApplicationInstanceNodeInstances"></a>[ListApplicationInstanceNodeInstances](https://docs.aws.amazon.com/panorama/latest/api/API_ListApplicationInstanceNodeInstances.html) | Retrieve a list of node instances of application instances in AWS Panorama | List | 
| <a name="panorama-ListApplicationInstances"></a>[ListApplicationInstances](https://docs.aws.amazon.com/panorama/latest/api/API_ListApplicationInstances.html) | Retrieve a list of application instances in AWS Panorama | List | 
| <a name="panorama-ListDevices"></a>[ListDevices](https://docs.aws.amazon.com/panorama/latest/api/API_ListDevices.html) | Retrieve a list of appliances in AWS Panorama | List | 
| <a name="panorama-ListDevicesJobs"></a>[ListDevicesJobs](https://docs.aws.amazon.com/panorama/latest/api/API_ListDevicesJobs.html) | Retrieve a list of jobs for an AWS Panorama Appliance | List | 
| <a name="panorama-ListNodeFromTemplateJobs"></a>[ListNodeFromTemplateJobs](https://docs.aws.amazon.com/panorama/latest/api/API_ListNodeFromTemplateJobs.html) | Retrieve a list of Nodes for an AWS Panorama Appliance | List | 
| <a name="panorama-ListNodes"></a>[ListNodes](https://docs.aws.amazon.com/panorama/latest/api/API_ListNodes.html) | Retrieve a list of nodes in AWS Panorama | List | 
| <a name="panorama-ListPackageImportJobs"></a>[ListPackageImportJobs](https://docs.aws.amazon.com/panorama/latest/api/API_ListPackageImportJobs.html) | Retrieve a list of packages in AWS Panorama | List | 
| <a name="panorama-ListPackages"></a>[ListPackages](https://docs.aws.amazon.com/panorama/latest/api/API_ListPackages.html) | Retrieve a list of packages in AWS Panorama | List | 
| <a name="panorama-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/panorama/latest/api/API_ListTagsForResource.html) | Retrieve a list of tags for a resource in AWS Panorama | Read |
