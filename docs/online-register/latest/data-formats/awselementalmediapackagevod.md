# Data retrieval APIs for AWS Elemental MediaPackage VOD

AWS Elemental MediaPackage VOD provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                     | Description                                                                  | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ------------ |
| [DescribeAsset](../../../mediapackage-vod/latest/apireference/assets-id.md#assets-idget "../../../mediapackage-vod/latest/apireference/assets-id.md#assets-idget")                                                                                          | View the details of an asset in AWS Elemental MediaPackage                   | Read         |
| [DescribePackagingConfiguration](../../../mediapackage-vod/latest/apireference/packaging_configurations-id.md#packaging_configurations-idget "../../../mediapackage-vod/latest/apireference/packaging_configurations-id.md#packaging_configurations-idget") | View the details of a packaging configuration in AWS Elemental MediaPackage  | Read         |
| [DescribePackagingGroup](../../../mediapackage-vod/latest/apireference/packaging_groups-id.md#packaging_groups-idget "../../../mediapackage-vod/latest/apireference/packaging_groups-id.md#packaging_groups-idget")                                         | View the details of a packaging group in AWS Elemental MediaPackage          | Read         |
| [ListAssets](../../../mediapackage-vod/latest/apireference/assets.md#assetsget "../../../mediapackage-vod/latest/apireference/assets.md#assetsget")                                                                                                         | View a list of assets in AWS Elemental MediaPackage                          | List         |
| [ListPackagingConfigurations](../../../mediapackage-vod/latest/apireference/packaging_configurations.md#packaging_configurationsget "../../../mediapackage-vod/latest/apireference/packaging_configurations.md#packaging_configurationsget")                | View a list of packaging configurations in AWS Elemental MediaPackage        | List         |
| [ListPackagingGroups](../../../mediapackage-vod/latest/apireference/packaging_groups.md#packaging_groupsget "../../../mediapackage-vod/latest/apireference/packaging_groups.md#packaging_groupsget")                                                        | View a list of packaging groups in AWS Elemental MediaPackage                | List         |
| [ListTagsForResource](../../../mediapackage-vod/latest/apireference/tags-resource-arn.md#tags-resource-arnget "../../../mediapackage-vod/latest/apireference/tags-resource-arn.md#tags-resource-arnget")                                                    | List the tags assigned to a PackagingGroup, PackagingConfiguration, or Asset | Read         |
