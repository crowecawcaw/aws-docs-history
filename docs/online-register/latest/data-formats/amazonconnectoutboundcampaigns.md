

# Data retrieval APIs for Amazon Connect Outbound Campaigns
<a name="amazonconnectoutboundcampaigns"></a>

Amazon Connect Outbound Campaigns provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="connect-campaigns-DescribeCampaign"></a>[DescribeCampaign](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Describe a specific campaign | Read | 
| <a name="connect-campaigns-GetCampaignState"></a>[GetCampaignState](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Get state of a campaign | Read | 
| <a name="connect-campaigns-GetCampaignStateBatch"></a>[GetCampaignStateBatch](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Get state of campaigns | Read | 
| <a name="connect-campaigns-GetConnectInstanceConfig"></a>[GetConnectInstanceConfig](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Get configuration information for an Amazon Connect instance | Read | 
| <a name="connect-campaigns-GetInstanceCommunicationLimits"></a>[GetInstanceCommunicationLimits](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Get the communication limits configuration of an Amazon Connect instance | Read | 
| <a name="connect-campaigns-GetInstanceOnboardingJobStatus"></a>[GetInstanceOnboardingJobStatus](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Get onboarding job status for an Amazon Connect instance | Read | 
| <a name="connect-campaigns-ListCampaigns"></a>[ListCampaigns](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Provide summary of all campaigns | List | 
| <a name="connect-campaigns-ListConnectInstanceIntegrations"></a>[ListConnectInstanceIntegrations](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | Provide summary of all integrations with an Amazon Connect instance | List | 
| <a name="connect-campaigns-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/connect/latest/adminguide/enable-outbound-campaigns.html) | List tags for a resource | Read |
