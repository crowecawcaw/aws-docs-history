# Data retrieval APIs for Amazon Connect Outbound Campaigns

Amazon Connect Outbound Campaigns provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                                                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------ |
| [DescribeCampaign](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")                | Describe a specific campaign                                             | Read         |
| [GetCampaignState](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")                | Get state of a campaign                                                  | Read         |
| [GetCampaignStateBatch](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")           | Get state of campaigns                                                   | Read         |
| [GetConnectInstanceConfig](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")        | Get configuration information for an Amazon Connect instance             | Read         |
| [GetInstanceCommunicationLimits](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")  | Get the communication limits configuration of an Amazon Connect instance | Read         |
| [GetInstanceOnboardingJobStatus](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")  | Get onboarding job status for an Amazon Connect instance                 | Read         |
| [ListCampaigns](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")                   | Provide summary of all campaigns                                         | List         |
| [ListConnectInstanceIntegrations](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md") | Provide summary of all integrations with an Amazon Connect instance      | List         |
| [ListTagsForResource](../../../connect/latest/adminguide/enable-outbound-campaigns.md "../../../connect/latest/adminguide/enable-outbound-campaigns.md")             | List tags for a resource                                                 | Read         |
