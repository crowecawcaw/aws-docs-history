

# Data retrieval APIs for AWS App Runner
<a name="awsapprunner"></a>

AWS App Runner provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="apprunner-DescribeAutoScalingConfiguration"></a>[DescribeAutoScalingConfiguration](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeAutoScalingConfiguration.html) | Retrieve the description of an AWS App Runner automatic scaling configuration resource | Read | 
| <a name="apprunner-DescribeCustomDomains"></a>[DescribeCustomDomains](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeCustomDomains.html) | Retrieve descriptions of custom domain names associated with an AWS App Runner service | Read | 
| <a name="apprunner-DescribeObservabilityConfiguration"></a>[DescribeObservabilityConfiguration](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeObservabilityConfiguration.html) | Retrieve the description of an AWS App Runner observability configuration resource | Read | 
| <a name="apprunner-DescribeOperation"></a>[DescribeOperation](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeOperation.html) | Retrieve the description of an operation that occurred on an AWS App Runner service | Read | 
| <a name="apprunner-DescribeService"></a>[DescribeService](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeService.html) | Retrieve the description of an AWS App Runner service resource | Read | 
| <a name="apprunner-DescribeVpcConnector"></a>[DescribeVpcConnector](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcConnector.html) | Retrieve the description of an AWS App Runner VPC connector resource | Read | 
| <a name="apprunner-DescribeVpcIngressConnection"></a>[DescribeVpcIngressConnection](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcIngressConnection.html) | Retrieve the description of an AWS App Runner VpcIngressConnection resource | Read | 
| <a name="apprunner-DescribeWebAclForService"></a>[DescribeWebAclForService](https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html) | Get the AWS WAF web ACL that is associated with an AWS App Runner service | Read | 
| <a name="apprunner-ListAssociatedServicesForWebAcl"></a>[ListAssociatedServicesForWebAcl](https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html) | List the services that are associated with an AWS WAF web ACL | List | 
| <a name="apprunner-ListAutoScalingConfigurations"></a>[ListAutoScalingConfigurations](https://docs.aws.amazon.com/apprunner/latest/api/API_ListAutoScalingConfigurations.html) | Retrieve a list of AWS App Runner automatic scaling configurations in your AWS account | List | 
| <a name="apprunner-ListConnections"></a>[ListConnections](https://docs.aws.amazon.com/apprunner/latest/api/API_ListConnections.html) | Retrieve a list of AWS App Runner connections in your AWS account | List | 
| <a name="apprunner-ListObservabilityConfigurations"></a>[ListObservabilityConfigurations](https://docs.aws.amazon.com/apprunner/latest/api/API_ListObservabilityConfigurations.html) | Retrieve a list of AWS App Runner observability configurations in your AWS account | List | 
| <a name="apprunner-ListOperations"></a>[ListOperations](https://docs.aws.amazon.com/apprunner/latest/api/API_ListOperations.html) | Retrieve a list of operations that occurred on an AWS App Runner service resource | List | 
| <a name="apprunner-ListServices"></a>[ListServices](https://docs.aws.amazon.com/apprunner/latest/api/API_ListServices.html) | Retrieve a list of running AWS App Runner services in your AWS account | List | 
| <a name="apprunner-ListServicesForAutoScalingConfiguration"></a>[ListServicesForAutoScalingConfiguration](https://docs.aws.amazon.com/apprunner/latest/api/API_ListServicesForAutoScalingConfiguration.html) | Retrieve a list of associated AppRunner services of an AWS App Runner automatic scaling configuration in your AWS account | List | 
| <a name="apprunner-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/apprunner/latest/api/API_ListTagsForResource.html) | List tags associated with an AWS App Runner resource | Read | 
| <a name="apprunner-ListVpcConnectors"></a>[ListVpcConnectors](https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnectors.html) | Retrieve a list of AWS App Runner VPC connectors in your AWS account | List | 
| <a name="apprunner-ListVpcIngressConnections"></a>[ListVpcIngressConnections](https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnections.html) | Retrieve a list of AWS App Runner VpcIngressConnections in your AWS account | List |
