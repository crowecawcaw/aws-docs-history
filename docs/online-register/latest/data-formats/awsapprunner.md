# Data retrieval APIs for AWS App Runner

AWS App Runner provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                | Description                                                                                                               | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAutoScalingConfiguration](../../../apprunner/latest/api/API_DescribeAutoScalingConfiguration.md "../../../apprunner/latest/api/API_DescribeAutoScalingConfiguration.md")                      | Retrieve the description of an AWS App Runner automatic scaling configuration resource                                    | Read         |
| [DescribeCustomDomains](../../../apprunner/latest/api/API_DescribeCustomDomains.md "../../../apprunner/latest/api/API_DescribeCustomDomains.md")                                                       | Retrieve descriptions of custom domain names associated with an AWS App Runner service                                    | Read         |
| [DescribeObservabilityConfiguration](../../../apprunner/latest/api/API_DescribeObservabilityConfiguration.md "../../../apprunner/latest/api/API_DescribeObservabilityConfiguration.md")                | Retrieve the description of an AWS App Runner observability configuration resource                                        | Read         |
| [DescribeOperation](../../../apprunner/latest/api/API_DescribeOperation.md "../../../apprunner/latest/api/API_DescribeOperation.md")                                                                   | Retrieve the description of an operation that occurred on an AWS App Runner service                                       | Read         |
| [DescribeService](../../../apprunner/latest/api/API_DescribeService.md "../../../apprunner/latest/api/API_DescribeService.md")                                                                         | Retrieve the description of an AWS App Runner service resource                                                            | Read         |
| [DescribeVpcConnector](../../../apprunner/latest/api/API_DescribeVpcConnector.md "../../../apprunner/latest/api/API_DescribeVpcConnector.md")                                                          | Retrieve the description of an AWS App Runner VPC connector resource                                                      | Read         |
| [DescribeVpcIngressConnection](../../../apprunner/latest/api/API_DescribeVpcIngressConnection.md "../../../apprunner/latest/api/API_DescribeVpcIngressConnection.md")                                  | Retrieve the description of an AWS App Runner VpcIngressConnection resource                                               | Read         |
| [DescribeWebAclForService](../../../apprunner/latest/dg/waf-manage.md "../../../apprunner/latest/dg/waf-manage.md")                                                                                    | Get the AWS WAF web ACL that is associated with an AWS App Runner service                                                 | Read         |
| [ListAssociatedServicesForWebAcl](../../../apprunner/latest/dg/waf-manage.md "../../../apprunner/latest/dg/waf-manage.md")                                                                             | List the services that are associated with an AWS WAF web ACL                                                             | List         |
| [ListAutoScalingConfigurations](../../../apprunner/latest/api/API_ListAutoScalingConfigurations.md "../../../apprunner/latest/api/API_ListAutoScalingConfigurations.md")                               | Retrieve a list of AWS App Runner automatic scaling configurations in your AWS account                                    | List         |
| [ListConnections](../../../apprunner/latest/api/API_ListConnections.md "../../../apprunner/latest/api/API_ListConnections.md")                                                                         | Retrieve a list of AWS App Runner connections in your AWS account                                                         | List         |
| [ListObservabilityConfigurations](../../../apprunner/latest/api/API_ListObservabilityConfigurations.md "../../../apprunner/latest/api/API_ListObservabilityConfigurations.md")                         | Retrieve a list of AWS App Runner observability configurations in your AWS account                                        | List         |
| [ListOperations](../../../apprunner/latest/api/API_ListOperations.md "../../../apprunner/latest/api/API_ListOperations.md")                                                                            | Retrieve a list of operations that occurred on an AWS App Runner service resource                                         | List         |
| [ListServices](../../../apprunner/latest/api/API_ListServices.md "../../../apprunner/latest/api/API_ListServices.md")                                                                                  | Retrieve a list of running AWS App Runner services in your AWS account                                                    | List         |
| [ListServicesForAutoScalingConfiguration](../../../apprunner/latest/api/API_ListServicesForAutoScalingConfiguration.md "../../../apprunner/latest/api/API_ListServicesForAutoScalingConfiguration.md") | Retrieve a list of associated AppRunner services of an AWS App Runner automatic scaling configuration in your AWS account | List         |
| [ListTagsForResource](../../../apprunner/latest/api/API_ListTagsForResource.md "../../../apprunner/latest/api/API_ListTagsForResource.md")                                                             | List tags associated with an AWS App Runner resource                                                                      | Read         |
| [ListVpcConnectors](../../../apprunner/latest/api/API_ListVpcConnectors.md "../../../apprunner/latest/api/API_ListVpcConnectors.md")                                                                   | Retrieve a list of AWS App Runner VPC connectors in your AWS account                                                      | List         |
| [ListVpcIngressConnections](../../../apprunner/latest/api/API_ListVpcConnections.md "../../../apprunner/latest/api/API_ListVpcConnections.md")                                                         | Retrieve a list of AWS App Runner VpcIngressConnections in your AWS account                                               | List         |
