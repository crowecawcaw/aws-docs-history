# Data retrieval APIs for AWS IoT Greengrass V2

AWS IoT Greengrass V2 provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                  | Description                                                                                                    | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeComponent](../../../greengrass/v2/APIReference/API_DescribeComponent.md "../../../greengrass/v2/APIReference/API_DescribeComponent.md")                                                                         | Retrieve metadata for a version of a component                                                                 | Read         |
| [GetComponent](../../../greengrass/v2/APIReference/API_GetComponent.md "../../../greengrass/v2/APIReference/API_GetComponent.md")                                                                                        | Get the recipe for a version of a component                                                                    | Read         |
| [GetComponentVersionArtifact](../../../greengrass/v2/APIReference/API_GetComponentVersionArtifact.md "../../../greengrass/v2/APIReference/API_GetComponentVersionArtifact.md")                                           | Get the pre-signed URL to download a public component artifact                                                 | Read         |
| [GetConnectivityInfo](../../../greengrass/v2/APIReference/API_GetConnectivityInfo.md "../../../greengrass/v2/APIReference/API_GetConnectivityInfo.md")                                                                   | Retrieve the connectivity information for a Greengrass core device                                             | Read         |
| [GetCoreDevice](../../../greengrass/v2/APIReference/API_GetCoreDevice.md "../../../greengrass/v2/APIReference/API_GetCoreDevice.md")                                                                                     | Retrieves metadata for a AWS IoT Greengrass core device                                                        | Read         |
| [GetDeployment](../../../greengrass/v2/APIReference/API_GetDeployment.md "../../../greengrass/v2/APIReference/API_GetDeployment.md")                                                                                     | Get a deployment                                                                                               | Read         |
| [GetServiceRoleForAccount](../../../greengrass/v2/APIReference/API_GetServiceRoleForAccount.md "../../../greengrass/v2/APIReference/API_GetServiceRoleForAccount.md")                                                    | Retrieve the service role that is attached to an account                                                       | Read         |
| [ListClientDevicesAssociatedWithCoreDevice](../../../greengrass/v2/APIReference/API_ListClientDevicesAssociatedWithCoreDevice.md "../../../greengrass/v2/APIReference/API_ListClientDevicesAssociatedWithCoreDevice.md") | Retrieve a paginated list of client devices associated to a AWS IoT Greengrass core device                     | List         |
| [ListComponentVersions](../../../greengrass/v2/APIReference/API_ListComponentVersions.md "../../../greengrass/v2/APIReference/API_ListComponentVersions.md")                                                             | Retrieve a paginated list of all versions for a component                                                      | List         |
| [ListComponents](../../../greengrass/v2/APIReference/API_ListComponents.md "../../../greengrass/v2/APIReference/API_ListComponents.md")                                                                                  | Retrieve a paginated list of component summaries                                                               | List         |
| [ListCoreDevices](../../../greengrass/v2/APIReference/API_ListCoreDevices.md "../../../greengrass/v2/APIReference/API_ListCoreDevices.md")                                                                               | Retrieve a paginated list of AWS IoT Greengrass core devices                                                   | List         |
| [ListDeployments](../../../greengrass/v2/APIReference/API_ListDeployments.md "../../../greengrass/v2/APIReference/API_ListDeployments.md")                                                                               | Retrieves a paginated list of deployments                                                                      | List         |
| [ListEffectiveDeployments](../../../greengrass/v2/APIReference/API_ListEffectiveDeployments.md "../../../greengrass/v2/APIReference/API_ListEffectiveDeployments.md")                                                    | Retrieves a paginated list of deployment jobs that AWS IoT Greengrass sends to AWS IoT Greengrass core devices | List         |
| [ListInstalledComponents](../../../greengrass/v2/APIReference/API_ListInstalledComponents.md "../../../greengrass/v2/APIReference/API_ListInstalledComponents.md")                                                       | Retrieve a paginated list of the components that a AWS IoT Greengrass core device runs                         | List         |
| [ListTagsForResource](../../../greengrass/v2/APIReference/API_ListTagsForResource.md "../../../greengrass/v2/APIReference/API_ListTagsForResource.md")                                                                   | List the tags for a resource                                                                                   | Read         |
| [ResolveComponentCandidates](../../../greengrass/v2/APIReference/API_ResolveComponentCandidates.md "../../../greengrass/v2/APIReference/API_ResolveComponentCandidates.md")                                              | List components that meet the component, version, and platform requirements of a deployment                    | List         |
