# Data retrieval APIs for Amazon Connect Voice ID

Amazon Connect Voice ID provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                         | Description                                   | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- | ------------ |
| [DescribeComplianceConsent](../../../connect/latest/adminguide/enable-voiceid.md#enable-voiceid-step1 "../../../connect/latest/adminguide/enable-voiceid.md#enable-voiceid-step1")              | Describe compliance consent                   | Read         |
| [DescribeDomain](../../../voiceid/latest/APIReference/API_DescribeDomain.md "../../../voiceid/latest/APIReference/API_DescribeDomain.md")                                                       | Describe a domain                             | Read         |
| [DescribeFraudster](../../../voiceid/latest/APIReference/API_DescribeFraudster.md "../../../voiceid/latest/APIReference/API_DescribeFraudster.md")                                              | Describe a fraudster                          | Read         |
| [DescribeFraudsterRegistrationJob](../../../voiceid/latest/APIReference/API_DescribeFraudsterRegistrationJob.md "../../../voiceid/latest/APIReference/API_DescribeFraudsterRegistrationJob.md") | Describe a fraudster registration job         | Read         |
| [DescribeSpeaker](../../../voiceid/latest/APIReference/API_DescribeSpeaker.md "../../../voiceid/latest/APIReference/API_DescribeSpeaker.md")                                                    | Describe a speaker                            | Read         |
| [DescribeSpeakerEnrollmentJob](../../../voiceid/latest/APIReference/API_DescribeSpeakerEnrollmentJob.md "../../../voiceid/latest/APIReference/API_DescribeSpeakerEnrollmentJob.md")             | Describe a speaker enrollment job             | Read         |
| [DescribeWatchlist](../../../voiceid/latest/APIReference/API_DescribeWatchlist.md "../../../voiceid/latest/APIReference/API_DescribeWatchlist.md")                                              | Describe a watchlist                          | Read         |
| [ListDomains](../../../voiceid/latest/APIReference/API_ListDomains.md "../../../voiceid/latest/APIReference/API_ListDomains.md")                                                                | List domains for an account                   | List         |
| [ListFraudsterRegistrationJobs](../../../voiceid/latest/APIReference/API_ListFraudsterRegistrationJobs.md "../../../voiceid/latest/APIReference/API_ListFraudsterRegistrationJobs.md")          | List fraudster registration jobs for a domain | List         |
| [ListFraudsters](../../../voiceid/latest/APIReference/API_ListFraudsters.md "../../../voiceid/latest/APIReference/API_ListFraudsters.md")                                                       | List fraudsters for a domain or watchlist     | List         |
| [ListSpeakerEnrollmentJobs](../../../voiceid/latest/APIReference/API_ListSpeakerEnrollmentJobs.md "../../../voiceid/latest/APIReference/API_ListSpeakerEnrollmentJobs.md")                      | List speaker enrollment jobs for a domain     | List         |
| [ListSpeakers](../../../voiceid/latest/APIReference/API_ListSpeakers.md "../../../voiceid/latest/APIReference/API_ListSpeakers.md")                                                             | List speakers for a domain                    | List         |
| [ListTagsForResource](../../../voiceid/latest/APIReference/API_ListTagsForResource.md "../../../voiceid/latest/APIReference/API_ListTagsForResource.md")                                        | List tags for a Voice ID resource             | Read         |
| [ListWatchlists](../../../voiceid/latest/APIReference/API_ListWatchlists.md "../../../voiceid/latest/APIReference/API_ListWatchlists.md")                                                       | List watchlists for a domain                  | List         |
