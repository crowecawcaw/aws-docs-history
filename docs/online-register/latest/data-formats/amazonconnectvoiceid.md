

# Data retrieval APIs for Amazon Connect Voice ID
<a name="amazonconnectvoiceid"></a>

Amazon Connect Voice ID provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="voiceid-DescribeComplianceConsent"></a>[DescribeComplianceConsent](https://docs.aws.amazon.com/connect/latest/adminguide/enable-voiceid.html#enable-voiceid-step1) | Describe compliance consent | Read | 
| <a name="voiceid-DescribeDomain"></a>[DescribeDomain](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeDomain.html) | Describe a domain | Read | 
| <a name="voiceid-DescribeFraudster"></a>[DescribeFraudster](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeFraudster.html) | Describe a fraudster | Read | 
| <a name="voiceid-DescribeFraudsterRegistrationJob"></a>[DescribeFraudsterRegistrationJob](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeFraudsterRegistrationJob.html) | Describe a fraudster registration job | Read | 
| <a name="voiceid-DescribeSpeaker"></a>[DescribeSpeaker](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeSpeaker.html) | Describe a speaker | Read | 
| <a name="voiceid-DescribeSpeakerEnrollmentJob"></a>[DescribeSpeakerEnrollmentJob](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeSpeakerEnrollmentJob.html) | Describe a speaker enrollment job | Read | 
| <a name="voiceid-DescribeWatchlist"></a>[DescribeWatchlist](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_DescribeWatchlist.html) | Describe a watchlist | Read | 
| <a name="voiceid-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListDomains.html) | List domains for an account | List | 
| <a name="voiceid-ListFraudsterRegistrationJobs"></a>[ListFraudsterRegistrationJobs](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListFraudsterRegistrationJobs.html) | List fraudster registration jobs for a domain | List | 
| <a name="voiceid-ListFraudsters"></a>[ListFraudsters](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListFraudsters.html) | List fraudsters for a domain or watchlist | List | 
| <a name="voiceid-ListSpeakerEnrollmentJobs"></a>[ListSpeakerEnrollmentJobs](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListSpeakerEnrollmentJobs.html) | List speaker enrollment jobs for a domain | List | 
| <a name="voiceid-ListSpeakers"></a>[ListSpeakers](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListSpeakers.html) | List speakers for a domain | List | 
| <a name="voiceid-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListTagsForResource.html) | List tags for a Voice ID resource | Read | 
| <a name="voiceid-ListWatchlists"></a>[ListWatchlists](https://docs.aws.amazon.com/voiceid/latest/APIReference/API_ListWatchlists.html) | List watchlists for a domain | List |
