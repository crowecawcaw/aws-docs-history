# Data retrieval APIs for AWS Private Certificate Authority

AWS Private Certificate Authority provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                  | Description                                                                                                                     | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeCertificateAuthority](../../../privateca/latest/APIReference/API_DescribeCertificateAuthority.md "../../../privateca/latest/APIReference/API_DescribeCertificateAuthority.md")                                  | Return a list of the configuration and status fields contained in the specified AWS Private CA                                  | Read         |
| [DescribeCertificateAuthorityAuditReport](../../../privateca/latest/APIReference/API_DescribeCertificateAuthorityAuditReport.md "../../../privateca/latest/APIReference/API_DescribeCertificateAuthorityAuditReport.md") | Return the status and information about an AWS Private CA audit report                                                          | Read         |
| [GetCertificate](../../../privateca/latest/APIReference/API_GetCertificate.md "../../../privateca/latest/APIReference/API_GetCertificate.md")                                                                            | Retrieve an AWS Private CA certificate and certificate chain for the certificate authority specified by an ARN                  | Read         |
| [GetCertificateAuthorityCertificate](../../../privateca/latest/APIReference/API_GetCertificateAuthorityCertificate.md "../../../privateca/latest/APIReference/API_GetCertificateAuthorityCertificate.md")                | Retrieve an AWS Private CA certificate and certificate chain for the certificate authority specified by an ARN                  | Read         |
| [GetCertificateAuthorityCsr](../../../privateca/latest/APIReference/API_GetCertificateAuthorityCsr.md "../../../privateca/latest/APIReference/API_GetCertificateAuthorityCsr.md")                                        | Retrieve an AWS Private CA certificate signing request (CSR) for the certificate-authority specified by an ARN                  | Read         |
| [GetPolicy](../../../privateca/latest/APIReference/API_GetPolicy.md "../../../privateca/latest/APIReference/API_GetPolicy.md")                                                                                           | Retrieve the policy on an AWS Private CA                                                                                        | Read         |
| [ListCertificateAuthorities](../../../privateca/latest/APIReference/API_ListCertificateAuthorities.md "../../../privateca/latest/APIReference/API_ListCertificateAuthorities.md")                                        | Retrieve a list of the AWS Private CA certificate authority ARNs, and a summary of the status of each CA in the calling account | List         |
| [ListPermissions](../../../privateca/latest/APIReference/API_ListPermissions.md "../../../privateca/latest/APIReference/API_ListPermissions.md")                                                                         | List the permissions that have been applied to the AWS Private CA certificate authority                                         | Read         |
| [ListTags](../../../privateca/latest/APIReference/API_ListTags.md "../../../privateca/latest/APIReference/API_ListTags.md")                                                                                              | List the tags that have been applied to the AWS Private CA certificate authority                                                | Read         |
