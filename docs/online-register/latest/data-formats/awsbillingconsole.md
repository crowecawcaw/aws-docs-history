

# Data retrieval APIs for AWS Billing Console
<a name="awsbillingconsole"></a>

AWS Billing Console provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aws-portal-GetConsoleActionSetEnforced"></a>[GetConsoleActionSetEnforced](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View whether existing or fine-grained IAM actions are being used to control authorization to Billing, Cost Management, and Account consoles | Read | 
| <a name="aws-portal-ViewAccount"></a>[ViewAccount](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Allow or deny IAM users permission to view account settings | Read | 
| <a name="aws-portal-ViewBilling"></a>[ViewBilling](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Allow or deny IAM users permission to view billing pages in the console | Read | 
| <a name="aws-portal-ViewPaymentMethods"></a>[ViewPaymentMethods](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Allow or deny IAM users permission to view payment methods | Read | 
| <a name="aws-portal-ViewUsage"></a>[ViewUsage](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Allow or deny IAM users permission to view AWS usage reports | Read |
