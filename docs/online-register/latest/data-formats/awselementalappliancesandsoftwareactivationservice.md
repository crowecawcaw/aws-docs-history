# Data retrieval APIs for AWS Elemental Appliances and Software Activation Service

AWS Elemental Appliances and Software Activation Service provides the following APIs for data retrieval.

| Actions                                                                                                                   | Description                                                                      | Access level |
| ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------ |
| [DownloadKickstart](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")                | Download the kickstart files for AWS Elemental Appliances and Software purchases | Read         |
| [DownloadSoftware](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")                 | Download the Software files for AWS Elemental Appliances and Software Purchases  | Read         |
| [GetArtifactGroupSoftwareVersions](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md") | Describe the software version of an artifact group                               | Read         |
| [GetAsset](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")                         | Describe an asset                                                                | Read         |
| [GetAssets](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")                        | Describe assets associated to the requesting account                             | Read         |
| [GetProductAdvisories](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")             | Get all product advisories                                                       | Read         |
| [GetSoftwareVersions](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")              | Describe available software versions                                             | Read         |
