

# Data retrieval APIs for AWS Elemental Appliances and Software Activation Service
<a name="awselementalappliancesandsoftwareactivationservice"></a>

AWS Elemental Appliances and Software Activation Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="elemental-activations-DownloadKickstart"></a>[DownloadKickstart](https://docs.aws.amazon.com/elemental-appliances-software/) | Download the kickstart files for AWS Elemental Appliances and Software purchases | Read | 
| <a name="elemental-activations-DownloadSoftware"></a>[DownloadSoftware](https://docs.aws.amazon.com/elemental-appliances-software/) | Download the Software files for AWS Elemental Appliances and Software Purchases | Read | 
| <a name="elemental-activations-GetArtifactGroupSoftwareVersions"></a>[GetArtifactGroupSoftwareVersions](https://docs.aws.amazon.com/elemental-appliances-software/) | Describe the software version of an artifact group | Read | 
| <a name="elemental-activations-GetAsset"></a>[GetAsset](https://docs.aws.amazon.com/elemental-appliances-software/) | Describe an asset | Read | 
| <a name="elemental-activations-GetAssets"></a>[GetAssets](https://docs.aws.amazon.com/elemental-appliances-software/) | Describe assets associated to the requesting account | Read | 
| <a name="elemental-activations-GetProductAdvisories"></a>[GetProductAdvisories](https://docs.aws.amazon.com/elemental-appliances-software/) | Get all product advisories | Read | 
| <a name="elemental-activations-GetSoftwareVersions"></a>[GetSoftwareVersions](https://docs.aws.amazon.com/elemental-appliances-software/) | Describe available software versions | Read |
