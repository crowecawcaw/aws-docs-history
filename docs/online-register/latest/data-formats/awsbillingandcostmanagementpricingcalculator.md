

# Data retrieval APIs for AWS Billing And Cost Management Pricing Calculator
<a name="awsbillingandcostmanagementpricingcalculator"></a>

AWS Billing And Cost Management Pricing Calculator provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="bcm-pricing-calculator-GetBillEstimate"></a>[GetBillEstimate](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_GetBillEstimate.html) | Retrieve details of a bill estimate including estimated cost | Read | 
| <a name="bcm-pricing-calculator-GetBillScenario"></a>[GetBillScenario](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_GetBillScenario.html) | Retrieve information associated with a bill scenario | Read | 
| <a name="bcm-pricing-calculator-GetPreferences"></a>[GetPreferences](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_GetPreferences.html) | Retrieve applicable rate type preferences for the account | Read | 
| <a name="bcm-pricing-calculator-GetWorkloadEstimate"></a>[GetWorkloadEstimate](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_GetWorkloadEstimate.html) | Retrieve information associated with a workload estimate | Read | 
| <a name="bcm-pricing-calculator-ListBillEstimateCommitments"></a>[ListBillEstimateCommitments](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillEstimateCommitments.html) | List commitments associated with the specified bill estimate | List | 
| <a name="bcm-pricing-calculator-ListBillEstimateInputCommitmentModifications"></a>[ListBillEstimateInputCommitmentModifications](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillEstimateInputCommitmentModifications.html) | List added or removed commitments for a specified bill estimate | List | 
| <a name="bcm-pricing-calculator-ListBillEstimateInputUsageModifications"></a>[ListBillEstimateInputUsageModifications](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillEstimateInputUsageModifications.html) | List added or modified usage for a specified bill estimate | List | 
| <a name="bcm-pricing-calculator-ListBillEstimateLineItems"></a>[ListBillEstimateLineItems](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillEstimateLineItems.html) | List result line items for a specified bill estimate | List | 
| <a name="bcm-pricing-calculator-ListBillEstimates"></a>[ListBillEstimates](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillEstimates.html) | List bill estimates | List | 
| <a name="bcm-pricing-calculator-ListBillScenarioCommitmentModifications"></a>[ListBillScenarioCommitmentModifications](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillScenarioCommitmentModifications.html) | List commitments included in a bill scenario | List | 
| <a name="bcm-pricing-calculator-ListBillScenarioUsageModifications"></a>[ListBillScenarioUsageModifications](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillScenarioUsageModifications.html) | List usage lines of a specified bill scenario | List | 
| <a name="bcm-pricing-calculator-ListBillScenarios"></a>[ListBillScenarios](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListBillScenarios.html) | List bill scenarios | List | 
| <a name="bcm-pricing-calculator-ListWorkloadEstimateUsage"></a>[ListWorkloadEstimateUsage](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListWorkloadEstimateUsage.html) | List usage lines for the specified workload estimate | List | 
| <a name="bcm-pricing-calculator-ListWorkloadEstimates"></a>[ListWorkloadEstimates](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_AWSBCMPricingCalculator_ListWorkloadEstimates.html) | List workload estimates | List |
