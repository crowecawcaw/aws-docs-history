# Data retrieval APIs for Amazon WorkSpaces

Amazon WorkSpaces provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                   | Description                                                                                                              | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeAccount](../../../workspaces/latest/api/API_DescribeAccount.md "../../../workspaces/latest/api/API_DescribeAccount.md")                                                          | Retrieve the configuration of Bring Your Own License (BYOL) for WorkSpaces accounts                                      | Read         |
| [DescribeAccountModifications](../../../workspaces/latest/api/API_DescribeAccountModifications.md "../../../workspaces/latest/api/API_DescribeAccountModifications.md")                   | Retrieve modifications to the configuration of Bring Your Own License (BYOL) for WorkSpaces accounts                     | Read         |
| [DescribeApplicationAssociations](../../../workspaces/latest/api/API_DescribeApplicationAssociations.md "../../../workspaces/latest/api/API_DescribeApplicationAssociations.md")          | Retrieve information about resources associated with a WorkSpace application                                             | List         |
| [DescribeApplications](../../../workspaces/latest/api/API_DescribeApplications.md "../../../workspaces/latest/api/API_DescribeApplications.md")                                           | Obtain information about WorkSpace applications                                                                          | List         |
| [DescribeBundleAssociations](../../../workspaces/latest/api/API_DescribeBundleAssociations.md "../../../workspaces/latest/api/API_DescribeBundleAssociations.md")                         | Retrieve information about resources associated with a WorkSpace bundle                                                  | List         |
| [DescribeClientBranding](../../../workspaces/latest/api/API_DescribeClientBranding.md "../../../workspaces/latest/api/API_DescribeClientBranding.md")                                     | Retrieve AWS WorkSpaces Client branding data within a directory                                                          | Read         |
| [DescribeClientProperties](../../../workspaces/latest/api/API_DescribeClientProperties.md "../../../workspaces/latest/api/API_DescribeClientProperties.md")                               | Retrieve information about WorkSpaces clients                                                                            | List         |
| [DescribeConnectClientAddIns](../../../workspaces/latest/api/API_DescribeConnectClientAddIns.md "../../../workspaces/latest/api/API_DescribeConnectClientAddIns.md")                      | Retrieve a list of Amazon Connect client add-ins that have been created                                                  | List         |
| [DescribeConnectionAliasPermissions](../../../workspaces/latest/api/API_DescribeConnectionAliasPermissions.md "../../../workspaces/latest/api/API_DescribeConnectionAliasPermissions.md") | Retrieve the permissions that the owners of connection aliases have granted to other AWS accounts for connection aliases | Read         |
| [DescribeConnectionAliases](../../../workspaces/latest/api/API_DescribeConnectionAliases.md "../../../workspaces/latest/api/API_DescribeConnectionAliases.md")                            | Retrieve a list that describes the connection aliases used for cross-Region redirection                                  | Read         |
| [DescribeConsent](../../../workspaces/latest/adminguide/wsp-console-permissions-ref.md "../../../workspaces/latest/adminguide/wsp-console-permissions-ref.md")                            | Retrieve information about consent agreement to BYOL minimum requirements                                                | Read         |
| [DescribeCustomWorkspaceImageImport](../../../workspaces/latest/api/API_DescribeCustomWorkspaceImageImport.md "../../../workspaces/latest/api/API_DescribeCustomWorkspaceImageImport.md") | Retrieve information about WorkSpace BYOL image import task                                                              | Read         |
| [DescribeImageAssociations](../../../workspaces/latest/api/API_DescribeImageAssociations.md "../../../workspaces/latest/api/API_DescribeImageAssociations.md")                            | Retrieve information about resources associated with a WorkSpace image                                                   | List         |
| [DescribeIpGroups](../../../workspaces/latest/api/API_DescribeIpGroups.md "../../../workspaces/latest/api/API_DescribeIpGroups.md")                                                       | Retrieve information about IP access control groups                                                                      | Read         |
| [DescribeTags](../../../workspaces/latest/api/API_DescribeTags.md "../../../workspaces/latest/api/API_DescribeTags.md")                                                                   | Describe the tags for WorkSpaces resources                                                                               | Read         |
| [DescribeWorkspaceAssociations](../../../workspaces/latest/api/API_DescribeWorkspaceAssociations.md "../../../workspaces/latest/api/API_DescribeWorkspaceAssociations.md")                | Retrieve information about resources associated with a WorkSpace                                                         | List         |
| [DescribeWorkspaceBundles](../../../workspaces/latest/api/API_DescribeWorkspaceBundles.md "../../../workspaces/latest/api/API_DescribeWorkspaceBundles.md")                               | Obtain information about WorkSpace bundles                                                                               | List         |
| [DescribeWorkspaceDirectories](../../../workspaces/latest/api/API_DescribeWorkspaceDirectories.md "../../../workspaces/latest/api/API_DescribeWorkspaceDirectories.md")                   | Retrieve information about directories that are registered with WorkSpaces                                               | Read         |
| [DescribeWorkspaceImagePermissions](../../../workspaces/latest/api/API_DescribeWorkspaceImagePermissions.md "../../../workspaces/latest/api/API_DescribeWorkspaceImagePermissions.md")    | Retrieve information about WorkSpace image permissions                                                                   | Read         |
| [DescribeWorkspaceImages](../../../workspaces/latest/api/API_DescribeWorkspaceImages.md "../../../workspaces/latest/api/API_DescribeWorkspaceImages.md")                                  | Retrieve information about WorkSpace images                                                                              | List         |
| [DescribeWorkspaceSnapshots](../../../workspaces/latest/api/API_DescribeWorkspaceSnapshots.md "../../../workspaces/latest/api/API_DescribeWorkspaceSnapshots.md")                         | Retrieve information about WorkSpace snapshots                                                                           | List         |
| [DescribeWorkspaces](../../../workspaces/latest/api/API_DescribeWorkspaces.md "../../../workspaces/latest/api/API_DescribeWorkspaces.md")                                                 | Obtain information about WorkSpaces                                                                                      | List         |
| [DescribeWorkspacesConnectionStatus](../../../workspaces/latest/api/API_DescribeWorkspacesConnectionStatus.md "../../../workspaces/latest/api/API_DescribeWorkspacesConnectionStatus.md") | Obtain the connection status of WorkSpaces                                                                               | Read         |
| [DescribeWorkspacesPoolSessions](../../../workspaces/latest/api/API_DescribeWorkspacesPoolSessions.md "../../../workspaces/latest/api/API_DescribeWorkspacesPoolSessions.md")             | Retrieve information about the sessions of a WorkSpaces Pool                                                             | List         |
| [DescribeWorkspacesPools](../../../workspaces/latest/api/API_DescribeWorkspacesPools.md "../../../workspaces/latest/api/API_DescribeWorkspacesPools.md")                                  | Retrieve information about WorkSpaces Pools                                                                              | List         |
| [DirectoryAccessManagement](../../../workspaces/latest/adminguide/wsp-console-permissions-ref.md "../../../workspaces/latest/adminguide/wsp-console-permissions-ref.md")                  | Directory management actions while managing and provisioning workspaces                                                  | List         |
| [GetAccountLink](../../../workspaces/latest/api/API_GetAccountLink.md "../../../workspaces/latest/api/API_GetAccountLink.md")                                                             | Retrieve a link with another AWS Account for sharing configuration for WorkSpaces BYOL                                   | Read         |
| [ListAccountLinks](../../../workspaces/latest/api/API_ListAccountLinks.md "../../../workspaces/latest/api/API_ListAccountLinks.md")                                                       | Retrieve links with the AWS Account(s) that share your configuration for WorkSpaces BYOL                                 | List         |
| [ListAvailableManagementCidrRanges](../../../workspaces/latest/api/API_ListAvailableManagementCidrRanges.md "../../../workspaces/latest/api/API_ListAvailableManagementCidrRanges.md")    | List the available CIDR ranges for enabling Bring Your Own License (BYOL) for WorkSpaces accounts                        | List         |
