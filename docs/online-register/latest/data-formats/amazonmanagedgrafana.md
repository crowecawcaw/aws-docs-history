# Data retrieval APIs for Amazon Managed Grafana

Amazon Managed Grafana provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                   | Description                                                                                                                     | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeWorkspace](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                                  | Describe a workspace                                                                                                            | Read         |
| [DescribeWorkspaceAuthentication](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                    | Describe authentication providers on a workspace                                                                                | Read         |
| [DescribeWorkspaceConfiguration](../../../grafana/latest/APIReference/API_DescribeWorkspaceConfiguration.md "../../../grafana/latest/APIReference/API_DescribeWorkspaceConfiguration.md") | Describe the current configuration string for the given workspace                                                               | Read         |
| [ListPermissions](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                                    | List the permissions on a wokspace                                                                                              | List         |
| [ListTagsForResource](../../../grafana/latest/APIReference/API_ListTagsForResource.md "../../../grafana/latest/APIReference/API_ListTagsForResource.md")                                  | List tags associated with a workspace                                                                                           | Read         |
| [ListVersions](../../../grafana/latest/APIReference/API_ListVersions.md "../../../grafana/latest/APIReference/API_ListVersions.md")                                                       | List all available supported Grafana versions. Optionally, include a workspace to list the versions to which it can be upgraded | List         |
| [ListWorkspaceServiceAccountTokens](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                  | List service account tokens for a workspace                                                                                     | Read         |
| [ListWorkspaceServiceAccounts](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                       | List service accounts for a workspace                                                                                           | Read         |
| [ListWorkspaces](../../../grafana/latest/userguide/AMG-and-IAM.md "../../../grafana/latest/userguide/AMG-and-IAM.md")                                                                     | List workspaces                                                                                                                 | Read         |
