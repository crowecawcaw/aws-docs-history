

# Data retrieval APIs for AWS Elastic Load Balancing V2
<a name="awselasticloadbalancingv2"></a>

AWS Elastic Load Balancing V2 provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="elasticloadbalancing-DescribeAccountLimits"></a>[DescribeAccountLimits](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeAccountLimits.html) | Describe the Elastic Load Balancing resource limits for the AWS account  | Read | 
| <a name="elasticloadbalancing-DescribeCapacityReservation"></a>[DescribeCapacityReservation](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeCapacityReservation.html) | Describe the capacity reservation for a load balancer  | Read | 
| <a name="elasticloadbalancing-DescribeListenerAttributes"></a>[DescribeListenerAttributes](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeListenerAttributes.html) | Describe the attributes for the specified listener | Read | 
| <a name="elasticloadbalancing-DescribeListenerCertificates"></a>[DescribeListenerCertificates](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeListenerCertificates.html) | Describe the certificates for the specified secure listener  | Read | 
| <a name="elasticloadbalancing-DescribeListeners"></a>[DescribeListeners](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeListeners.html) | Describe the specified listeners or the listeners for the specified Application Load Balancer  | Read | 
| <a name="elasticloadbalancing-DescribeLoadBalancerAttributes"></a>[DescribeLoadBalancerAttributes](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancerAttributes.html) | Describe the attributes for the specified load balancer | Read | 
| <a name="elasticloadbalancing-DescribeLoadBalancers"></a>[DescribeLoadBalancers](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancers.html) | Describe the specified the load balancers. If no load balancers are specified, the call describes all of your load balancers | List | 
| <a name="elasticloadbalancing-DescribeRules"></a>[DescribeRules](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeRules.html) | Describe the specified rules or the rules for the specified listener  | Read | 
| <a name="elasticloadbalancing-DescribeSSLPolicies"></a>[DescribeSSLPolicies](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeSSLPolicies.html) | Describe the specified policies or all policies used for SSL negotiation | Read | 
| <a name="elasticloadbalancing-DescribeTags"></a>[DescribeTags](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTags.html) | Describe the tags associated with the specified resource | Read | 
| <a name="elasticloadbalancing-DescribeTargetGroupAttributes"></a>[DescribeTargetGroupAttributes](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTargetGroupAttributes.html) | Describe the attributes for the specified target group | Read | 
| <a name="elasticloadbalancing-DescribeTargetGroups"></a>[DescribeTargetGroups](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTargetGroups.html) | Describe the specified target groups or all of your target groups  | Read | 
| <a name="elasticloadbalancing-DescribeTargetHealth"></a>[DescribeTargetHealth](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTargetHealth.html) | Describe the health of the specified targets or all of your targets | Read | 
| <a name="elasticloadbalancing-DescribeTrustStoreAssociations"></a>[DescribeTrustStoreAssociations](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreAssociations.html) | Describe the associations with a trust store | Read | 
| <a name="elasticloadbalancing-DescribeTrustStoreRevocations"></a>[DescribeTrustStoreRevocations](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreRevocations.html) | Describe the specified trust stores revocations or all of your revocations related to a trust store | Read | 
| <a name="elasticloadbalancing-DescribeTrustStores"></a>[DescribeTrustStores](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_DescribeTrustStores.html) | Describe the specified trust stores or all of your trust stores | Read | 
| <a name="elasticloadbalancing-DescribeWebACLAssociation"></a>[DescribeWebACLAssociation](https://docs.aws.amazon.com/waf/latest/developerguide/security_iam_service-with-iam.html#security_iam_action-AssociateWebACL) | Describe all load balancers associated to a WAF WebACL in your account | List | 
| <a name="elasticloadbalancing-GetLoadBalancerWebACL"></a>[GetLoadBalancerWebACL](https://docs.aws.amazon.com/waf/latest/developerguide/security_iam_service-with-iam.html#security_iam_action-AssociateWebACL) | Retrieve the WAF WebACL associated to the specified load balancer | Read | 
| <a name="elasticloadbalancing-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_GetResourcePolicy.html) | Retrieve the resource policy associated with the resource | Read | 
| <a name="elasticloadbalancing-GetTrustStoreCaCertificatesBundle"></a>[GetTrustStoreCaCertificatesBundle](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_GetTrustStoreCaCertificatesBundle.html) | Retrieve a trust store CA certificates bundle | Read | 
| <a name="elasticloadbalancing-GetTrustStoreRevocationContent"></a>[GetTrustStoreRevocationContent](https://docs.aws.amazon.com/elasticloadbalancing/latest/APIReference/API_GetTrustStoreRevocationContent.html) | Retrieve a trust store revocation content | Read |
