# Data retrieval APIs for AWS Elastic Load Balancing V2

AWS Elastic Load Balancing V2 provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                      | Description                                                                                                                  | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAccountLimits](../../../elasticloadbalancing/latest/APIReference/API_DescribeAccountLimits.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeAccountLimits.md")                                     | Describe the Elastic Load Balancing resource limits for the AWS account                                                      | Read         |
| [DescribeCapacityReservation](../../../elasticloadbalancing/latest/APIReference/API_DescribeCapacityReservation.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeCapacityReservation.md")                   | Describe the capacity reservation for a load balancer                                                                        | Read         |
| [DescribeListenerAttributes](../../../elasticloadbalancing/latest/APIReference/API_DescribeListenerAttributes.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeListenerAttributes.md")                      | Describe the attributes for the specified listener                                                                           | Read         |
| [DescribeListenerCertificates](../../../elasticloadbalancing/latest/APIReference/API_DescribeListenerCertificates.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeListenerCertificates.md")                | Describe the certificates for the specified secure listener                                                                  | Read         |
| [DescribeListeners](../../../elasticloadbalancing/latest/APIReference/API_DescribeListeners.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeListeners.md")                                                 | Describe the specified listeners or the listeners for the specified Application Load Balancer                                | Read         |
| [DescribeLoadBalancerAttributes](../../../elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancerAttributes.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancerAttributes.md")          | Describe the attributes for the specified load balancer                                                                      | Read         |
| [DescribeLoadBalancers](../../../elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancers.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeLoadBalancers.md")                                     | Describe the specified the load balancers. If no load balancers are specified, the call describes all of your load balancers | List         |
| [DescribeRules](../../../elasticloadbalancing/latest/APIReference/API_DescribeRules.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeRules.md")                                                             | Describe the specified rules or the rules for the specified listener                                                         | Read         |
| [DescribeSSLPolicies](../../../elasticloadbalancing/latest/APIReference/API_DescribeSSLPolicies.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeSSLPolicies.md")                                           | Describe the specified policies or all policies used for SSL negotiation                                                     | Read         |
| [DescribeTags](../../../elasticloadbalancing/latest/APIReference/API_DescribeTags.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTags.md")                                                                | Describe the tags associated with the specified resource                                                                     | Read         |
| [DescribeTargetGroupAttributes](../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetGroupAttributes.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetGroupAttributes.md")             | Describe the attributes for the specified target group                                                                       | Read         |
| [DescribeTargetGroups](../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetGroups.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetGroups.md")                                        | Describe the specified target groups or all of your target groups                                                            | Read         |
| [DescribeTargetHealth](../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetHealth.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTargetHealth.md")                                        | Describe the health of the specified targets or all of your targets                                                          | Read         |
| [DescribeTrustStoreAssociations](../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreAssociations.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreAssociations.md")          | Describe the associations with a trust store                                                                                 | Read         |
| [DescribeTrustStoreRevocations](../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreRevocations.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStoreRevocations.md")             | Describe the specified trust stores revocations or all of your revocations related to a trust store                          | Read         |
| [DescribeTrustStores](../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStores.md "../../../elasticloadbalancing/latest/APIReference/API_DescribeTrustStores.md")                                           | Describe the specified trust stores or all of your trust stores                                                              | Read         |
| [GetResourcePolicy](../../../elasticloadbalancing/latest/APIReference/API_GetResourcePolicy.md "../../../elasticloadbalancing/latest/APIReference/API_GetResourcePolicy.md")                                                 | Retrieve the resource policy associated with the resource                                                                    | Read         |
| [GetTrustStoreCaCertificatesBundle](../../../elasticloadbalancing/latest/APIReference/API_GetTrustStoreCaCertificatesBundle.md "../../../elasticloadbalancing/latest/APIReference/API_GetTrustStoreCaCertificatesBundle.md") | Retrieve a trust store CA certificates bundle                                                                                | Read         |
| [GetTrustStoreRevocationContent](../../../elasticloadbalancing/latest/APIReference/API_GetTrustStoreRevocationContent.md "../../../elasticloadbalancing/latest/APIReference/API_GetTrustStoreRevocationContent.md")          | Retrieve a trust store revocation content                                                                                    | Read         |
