

# Data retrieval APIs for AWS Support Authorization
<a name="awssupportauthorization"></a>

AWS Support Authorization provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="supportauthz-GetAction"></a>[GetAction](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetAction.html) | Retrieve details about a support action | Read | 
| <a name="supportauthz-GetSupportPermit"></a>[GetSupportPermit](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetSupportPermit.html) | Retrieve a support permit | Read | 
| <a name="supportauthz-ListActions"></a>[ListActions](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListActions.html) | List available support actions | List | 
| <a name="supportauthz-ListSupportPermitRequests"></a>[ListSupportPermitRequests](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermitRequests.html) | List support permit requests | List | 
| <a name="supportauthz-ListSupportPermits"></a>[ListSupportPermits](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermits.html) | List support permits | List | 
| <a name="supportauthz-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
