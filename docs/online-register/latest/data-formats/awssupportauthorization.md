# Data retrieval APIs for AWS Support Authorization

AWS Support Authorization provides the following APIs for data retrieval.

| Actions                                                                                                                                                                              | Description                             | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------- | ------------ |
| [GetAction](../../../supportauthz/latest/APIReference/API_GetAction.md "../../../supportauthz/latest/APIReference/API_GetAction.md")                                                 | Retrieve details about a support action | Read         |
| [GetSupportPermit](../../../supportauthz/latest/APIReference/API_GetSupportPermit.md "../../../supportauthz/latest/APIReference/API_GetSupportPermit.md")                            | Retrieve a support permit               | Read         |
| [ListActions](../../../supportauthz/latest/APIReference/API_ListActions.md "../../../supportauthz/latest/APIReference/API_ListActions.md")                                           | List available support actions          | List         |
| [ListSupportPermitRequests](../../../supportauthz/latest/APIReference/API_ListSupportPermitRequests.md "../../../supportauthz/latest/APIReference/API_ListSupportPermitRequests.md") | List support permit requests            | List         |
| [ListSupportPermits](../../../supportauthz/latest/APIReference/API_ListSupportPermits.md "../../../supportauthz/latest/APIReference/API_ListSupportPermits.md")                      | List support permits                    | List         |
| [ListTagsForResource](../../../supportauthz/latest/APIReference/API_ListTagsForResource.md "../../../supportauthz/latest/APIReference/API_ListTagsForResource.md")                   | List tags for a resource                | Read         |
