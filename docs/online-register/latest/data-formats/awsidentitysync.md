

# Data retrieval APIs for AWS Identity Sync
<a name="awsidentitysync"></a>

AWS Identity Sync provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="identity-sync-GetSyncProfile"></a>[GetSyncProfile](https://docs.aws.amazon.com/singlesignon/latest/userguide/provision-users-groups-AD.html) | Retrieve a sync profile by using a sync profile name | Read | 
| <a name="identity-sync-GetSyncTarget"></a>[GetSyncTarget](https://docs.aws.amazon.com/singlesignon/latest/userguide/provision-users-groups-AD.html) | Retrieve a sync target from the sync profile | Read | 
| <a name="identity-sync-ListSyncFilters"></a>[ListSyncFilters](https://docs.aws.amazon.com/singlesignon/latest/userguide/provision-users-groups-AD.html) | List the sync filters from the sync profile | List |
