# Data retrieval APIs for AWS Identity Sync

AWS Identity Sync provides the following APIs for data retrieval.

| Actions                                                                                                                                                      | Description                                          | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | ------------ |
| [GetSyncProfile](../../../singlesignon/latest/userguide/provision-users-groups-AD.md "../../../singlesignon/latest/userguide/provision-users-groups-AD.md")  | Retrieve a sync profile by using a sync profile name | Read         |
| [GetSyncTarget](../../../singlesignon/latest/userguide/provision-users-groups-AD.md "../../../singlesignon/latest/userguide/provision-users-groups-AD.md")   | Retrieve a sync target from the sync profile         | Read         |
| [ListSyncFilters](../../../singlesignon/latest/userguide/provision-users-groups-AD.md "../../../singlesignon/latest/userguide/provision-users-groups-AD.md") | List the sync filters from the sync profile          | List         |
