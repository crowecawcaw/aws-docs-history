# Data retrieval APIs for Amazon Fraud Detector

Amazon Fraud Detector provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetVariable](../../../frauddetector/latest/api/API_BatchGetVariable.md "../../../frauddetector/latest/api/API_BatchGetVariable.md")                                                                        | Get a batch of variables                                                                                                                                                                                                                                                                                                                                                                                                                                                   | List         |
| [DescribeDetector](../../../frauddetector/latest/api/API_DescribeDetector.md "../../../frauddetector/latest/api/API_DescribeDetector.md")                                                                        | Get all versions for a specified detector                                                                                                                                                                                                                                                                                                                                                                                                                                  | Read         |
| [DescribeModelVersions](../../../frauddetector/latest/api/API_DescribeModelVersions.md "../../../frauddetector/latest/api/API_DescribeModelVersions.md")                                                         | Get all of the model versions for the specified model type or for the specified model type and model ID. You can also get details for a single, specified model version                                                                                                                                                                                                                                                                                                    | Read         |
| [GetBatchImportJobValidationReport](../../../frauddetector/latest/ug/prepare-storage-event-data.md#smart-data-validation "../../../frauddetector/latest/ug/prepare-storage-event-data.md#smart-data-validation") | Get the data validation report of a specific batch import job                                                                                                                                                                                                                                                                                                                                                                                                              | Read         |
| [GetBatchImportJobs](../../../frauddetector/latest/api/API_GetBatchImportJobs.md "../../../frauddetector/latest/api/API_GetBatchImportJobs.md")                                                                  | Get all batch import jobs or a specific job if you specify a job ID                                                                                                                                                                                                                                                                                                                                                                                                        | List         |
| [GetBatchPredictionJobs](../../../frauddetector/latest/api/API_GetBatchPredictionJobs.md "../../../frauddetector/latest/api/API_GetBatchPredictionJobs.md")                                                      | Get all batch prediction jobs or a specific job if you specify a job ID. This is a paginated API. If you provide a null maxResults, this action retrieves a maximum of 50 records per page. If you provide a maxResults, the value must be between 1 and 50. To get the next page results, provide the pagination token from the GetBatchPredictionJobsResponse as part of your request. A null pagination token fetches the records from the beginning                    | List         |
| [GetDeleteEventsByEventTypeStatus](../../../frauddetector/latest/api/API_GetDeleteEventsByEventTypeStatus.md "../../../frauddetector/latest/api/API_GetDeleteEventsByEventTypeStatus.md")                        | Get a specific event type DeleteEventsByEventType API execution status                                                                                                                                                                                                                                                                                                                                                                                                     | Read         |
| [GetDetectorVersion](../../../frauddetector/latest/api/API_GetDetectorVersion.md "../../../frauddetector/latest/api/API_GetDetectorVersion.md")                                                                  | Get a particular detector version                                                                                                                                                                                                                                                                                                                                                                                                                                          | Read         |
| [GetDetectors](../../../frauddetector/latest/api/API_GetDetectors.md "../../../frauddetector/latest/api/API_GetDetectors.md")                                                                                    | Get all detectors or a single detector if a detectorId is specified. This is a paginated API. If you provide a null maxResults, this action retrieves a maximum of 10 records per page. If you provide a maxResults, the value must be between 5 and 10. To get the next page results, provide the pagination token from the GetDetectorsResponse as part of your request. A null pagination token fetches the records from the beginning                                  | List         |
| [GetEntityTypes](../../../frauddetector/latest/api/API_GetEntityTypes.md "../../../frauddetector/latest/api/API_GetEntityTypes.md")                                                                              | Get all entity types or a specific entity type if a name is specified. This is a paginated API. If you provide a null maxResults, this action retrieves a maximum of 10 records per page. If you provide a maxResults, the value must be between 5 and 10. To get the next page results, provide the pagination token from the GetEntityTypesResponse as part of your request. A null pagination token fetches the records from the beginning                              | List         |
| [GetEvent](../../../frauddetector/latest/api/API_GetEvent.md "../../../frauddetector/latest/api/API_GetEvent.md")                                                                                                | Get the details of the specified event                                                                                                                                                                                                                                                                                                                                                                                                                                     | Read         |
| [GetEventPrediction](../../../frauddetector/latest/api/API_GetEventPrediction.md "../../../frauddetector/latest/api/API_GetEventPrediction.md")                                                                  | Evaluate an event against a detector version. If a version ID is not provided, the detector's (ACTIVE) version is used                                                                                                                                                                                                                                                                                                                                                     | Read         |
| [GetEventPredictionMetadata](../../../frauddetector/latest/api/API_GetEventPredictionMetadata.md "../../../frauddetector/latest/api/API_GetEventPredictionMetadata.md")                                          | Get more details of a particular prediction                                                                                                                                                                                                                                                                                                                                                                                                                                | Read         |

This is a paginated API. If you provide a null maxResults, this action retrieves a maximum of 10 records per page. If you provide a maxResults, the value must be between 5 and 10. To get the next page results, provide the pagination token from the GetEventTypesResponse as part of your request. A null pagination token fetches the records from the beginning                                    | List         |
| [GetExternalModels](../../../frauddetector/latest/api/API_GetExternalModels.md "../../../frauddetector/latest/api/API_GetExternalModels.md")                                                                     | Get the details for one or more Amazon SageMaker models that have been imported into the service. To get the next page results, provide the pagination token from the GetExternalModelsResult as part of your request. A null pagination token fetches the records from the beginning | List         |

| [GetLabels](../../../frauddetector/latest/api/API_GetLabels.md "../../../frauddetector/latest/api/API_GetLabels.md")                                                                                             | Get all labels or a specific label if name is provided. This is a paginated API. If you provide a null maxResults, this action retrieves a maximum of 50 records per page. If you provide a maxResults, the value must be between 10 and 50. To get the next page results, provide the pagination token from the GetGetLabelsResponse as part of your request. A null pagination token fetches the records from the beginning                                              | List         |
| [GetListElements](../../../frauddetector/latest/api/API_GetListElements.md "../../../frauddetector/latest/api/API_GetListElements.md")                                                                           | Get elements of a list                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Read         |

Gets all models for the AWS account if no model type and no model id provided. Gets all models for the AWS account and model type, if the model type is specified but model id is not provided. Gets a specific model if (model type, model id) tuple is specified                                                                                                                                                                                 | List         |
