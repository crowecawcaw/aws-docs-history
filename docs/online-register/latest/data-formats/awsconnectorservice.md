

# Data retrieval APIs for AWS Connector Service
<a name="awsconnectorservice"></a>

AWS Connector Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="awsconnector-GetConnectorHealth"></a>[GetConnectorHealth](https://docs.aws.amazon.com/server-migration-service/latest/userguide/prereqs.html#connector-permissions) | Retrieves all health metrics that were published from the Server Migration Connector. | Read | 
| <a name="awsconnector-ValidateConnectorId"></a>[ValidateConnectorId](https://docs.aws.amazon.com/server-migration-service/latest/userguide/prereqs.html#connector-permissions) | Validates Server Migration Connector Id that was registered with AWS Connector Service. | Read |
