| [GetHost](../../../codestar-connections/latest/APIReference/API_GetHost.md "../../../codestar-connections/latest/APIReference/API_GetHost.md")                                                                                                 | Get details about a host resource                                                                                                                | Read         |

| [GetInstallationUrl](../../../dtconsole/latest/userguide/security-iam.md#permissions-reference-connections-handshake "../../../dtconsole/latest/userguide/security-iam.md#permissions-reference-connections-handshake")                        | Associate a third party, such as a Bitbucket App installation, with a Connection                                                                 | Read         |

| [GetSyncBlockerSummary](../../../codestar-connections/latest/APIReference/API_GetSyncBlockerSummary.md "../../../codestar-connections/latest/APIReference/API_GetSyncBlockerSummary.md")                                                       | Describe service sync blockers on a resource (cfn stack or other resources)                                                                      | Read         |
