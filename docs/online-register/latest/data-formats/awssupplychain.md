

# Data retrieval APIs for AWS Supply Chain
<a name="awssupplychain"></a>

AWS Supply Chain provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="scn-DescribeInstance"></a>[DescribeInstance](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | View details of an AWS Supply Chain instance | Read | 
| <a name="scn-GetBillOfMaterialsImportJob"></a>[GetBillOfMaterialsImportJob](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | View status and details of a BillOfMaterialsImportJob | Read | 
| <a name="scn-GetDataIntegrationEvent"></a>[GetDataIntegrationEvent](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | Get a DataIntegrationEvent | Read | 
| <a name="scn-GetDataIntegrationFlow"></a>[GetDataIntegrationFlow](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | Get the DataIntegrationFlow details | Read | 
| <a name="scn-GetDataIntegrationFlowExecution"></a>[GetDataIntegrationFlowExecution](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | Get a particular execution of one specified DataIntegrationFlow | Read | 
| <a name="scn-GetDataLakeDataset"></a>[GetDataLakeDataset](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | Get the dataset details | Read | 
| <a name="scn-GetDataLakeNamespace"></a>[GetDataLakeNamespace](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | Get the namespace details | Read | 
| <a name="scn-GetInstance"></a>[GetInstance](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | View details of an AWS Supply Chain instance | Read | 
| <a name="scn-ListAdminUsers"></a>[ListAdminUsers](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List AWS Supply Chain administrators of an instance | List | 
| <a name="scn-ListDataIntegrationEvents"></a>[ListDataIntegrationEvents](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List all DataIntegrationEvents under an instance | List | 
| <a name="scn-ListDataIntegrationFlowExecutions"></a>[ListDataIntegrationFlowExecutions](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List all executions of one specified DataIntegrationFlow | List | 
| <a name="scn-ListDataIntegrationFlows"></a>[ListDataIntegrationFlows](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List all the DataIntegrationFlows in a paginated way | List | 
| <a name="scn-ListDataLakeDatasets"></a>[ListDataLakeDatasets](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List the data lake datasets under specific instance or namespace | List | 
| <a name="scn-ListDataLakeNamespaces"></a>[ListDataLakeNamespaces](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List the data lake namespaces under specific instance | List | 
| <a name="scn-ListInstances"></a>[ListInstances](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | View the AWS Supply Chain instances associated with an AWS account | List | 
| <a name="scn-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html) | List tags for an AWS Supply Chain resource | List |
