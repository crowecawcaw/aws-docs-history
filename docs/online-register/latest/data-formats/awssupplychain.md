# Data retrieval APIs for AWS Supply Chain

AWS Supply Chain provides the following APIs for data retrieval.

| Actions                                                                                                                                                                              | Description                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ | ------------ |
| [DescribeInstance](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")                  | View details of an AWS Supply Chain instance                       | Read         |
| [GetBillOfMaterialsImportJob](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")       | View status and details of a BillOfMaterialsImportJob              | Read         |
| [GetDataIntegrationEvent](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")           | Get a DataIntegrationEvent                                         | Read         |
| [GetDataIntegrationFlow](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")            | Get the DataIntegrationFlow details                                | Read         |
| [GetDataIntegrationFlowExecution](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")   | Get a particular execution of one specified DataIntegrationFlow    | Read         |
| [GetDataLakeDataset](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")                | Get the dataset details                                            | Read         |
| [GetDataLakeNamespace](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")              | Get the namespace details                                          | Read         |
| [GetInstance](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")                       | View details of an AWS Supply Chain instance                       | Read         |
| [ListAdminUsers](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")                    | List AWS Supply Chain administrators of an instance                | List         |
| [ListDataIntegrationEvents](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")         | List all DataIntegrationEvents under an instance                   | List         |
| [ListDataIntegrationFlowExecutions](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md") | List all executions of one specified DataIntegrationFlow           | List         |
| [ListDataIntegrationFlows](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")          | List all the DataIntegrationFlows in a paginated way               | List         |
| [ListDataLakeDatasets](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")              | List the data lake datasets under specific instance or namespace   | List         |
| [ListDataLakeNamespaces](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")            | List the data lake namespaces under specific instance              | List         |
| [ListInstances](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")                     | View the AWS Supply Chain instances associated with an AWS account | List         |
| [ListTagsForResource](../../../service-authorization/latest/reference/list_awssupplychain.md "../../../service-authorization/latest/reference/list_awssupplychain.md")               | List tags for an AWS Supply Chain resource                         | List         |
