| [DescribeConversionConfiguration](../../../dms/latest/APIReference/API_DescribeConversionConfiguration.md "../../../dms/latest/APIReference/API_DescribeConversionConfiguration.md")                                        | Return information about DMS Schema Conversion project configuration                                                                                                                                                                               | Read         |
