# Data retrieval APIs for AWS Firewall Manager

AWS Firewall Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                           | Description                                                                                                                                                                     | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetAdminAccount](../../../fms/2018-01-01/APIReference/API_GetAdminAccount.md "../../../fms/2018-01-01/APIReference/API_GetAdminAccount.md")                                                                      | Return the AWS Organizations account that is associated with AWS Firewall Manager as the AWS Firewall Manager administrator                                                     | Read         |
| [GetAdminScope](../../../fms/2018-01-01/APIReference/API_GetAdminScope.md "../../../fms/2018-01-01/APIReference/API_GetAdminScope.md")                                                                            | Return information about the specified account's administrative scope                                                                                                           | Read         |
| [GetAppsList](../../../fms/2018-01-01/APIReference/API_GetAppsList.md "../../../fms/2018-01-01/APIReference/API_GetAppsList.md")                                                                                  | Return information about the specified AWS Firewall Manager applications list                                                                                                   | Read         |
| [GetComplianceDetail](../../../fms/2018-01-01/APIReference/API_GetComplianceDetail.md "../../../fms/2018-01-01/APIReference/API_GetComplianceDetail.md")                                                          | Retrieve detailed compliance information about the specified member account. Details include resources that are in and out of compliance with the specified policy              | Read         |
| [GetNotificationChannel](../../../fms/2018-01-01/APIReference/API_GetNotificationChannel.md "../../../fms/2018-01-01/APIReference/API_GetNotificationChannel.md")                                                 | Retrieve information about the Amazon Simple Notification Service (SNS) topic that is used to record AWS Firewall Manager SNS logs                                              | Read         |
| [GetPolicy](../../../fms/2018-01-01/APIReference/API_GetPolicy.md "../../../fms/2018-01-01/APIReference/API_GetPolicy.md")                                                                                        | Retrieve information about the specified AWS Firewall Manager policy                                                                                                            | Read         |
| [GetProtectionStatus](../../../fms/2018-01-01/APIReference/API_GetProtectionStatus.md "../../../fms/2018-01-01/APIReference/API_GetProtectionStatus.md")                                                          | Retrieve policy-level attack summary information in the event of a potential DDoS attack                                                                                        | Read         |
| [GetProtocolsList](../../../fms/2018-01-01/APIReference/API_GetProtocolsList.md "../../../fms/2018-01-01/APIReference/API_GetProtocolsList.md")                                                                   | Return information about the specified AWS Firewall Manager protocols list                                                                                                      | Read         |
| [GetResourceSet](../../../fms/2018-01-01/APIReference/API_GetResourceSet.md "../../../fms/2018-01-01/APIReference/API_GetResourceSet.md")                                                                         | Retrieve information about the specified AWS Firewall Manager resource set                                                                                                      | Read         |
| [GetThirdPartyFirewallAssociationStatus](../../../fms/2018-01-01/APIReference/API_GetThirdPartyFirewallAssociationStatus.md "../../../fms/2018-01-01/APIReference/API_GetThirdPartyFirewallAssociationStatus.md") | Retrieve the onboarding status of a Firewall Manager administrator account to third-party firewall vendor tenant                                                                | Read         |
| [GetViolationDetails](../../../fms/2018-01-01/APIReference/API_GetViolationDetails.md "../../../fms/2018-01-01/APIReference/API_GetViolationDetails.md")                                                          | Retrieve violations for a resource based on the specified AWS Firewall Manager policy and AWS account                                                                           | Read         |
| [ListAdminAccountsForOrganization](../../../fms/2018-01-01/APIReference/API_ListAdminAccountsForOrganization.md "../../../fms/2018-01-01/APIReference/API_ListAdminAccountsForOrganization.md")                   | Return a AdminAccounts object that lists the Firewall Manager administrators within the organization that are onboarded to Firewall Manager by AssociateAdminAccount            | List         |
| [ListAdminsManagingAccount](../../../fms/2018-01-01/APIReference/API_ListAdminsManagingAccount.md "../../../fms/2018-01-01/APIReference/API_ListAdminsManagingAccount.md")                                        | List the accounts that are managing the specified AWS Organizations member account                                                                                              | List         |
| [ListAppsLists](../../../fms/2018-01-01/APIReference/API_ListAppsLists.md "../../../fms/2018-01-01/APIReference/API_ListAppsLists.md")                                                                            | Return an array of AppsListDataSummary objects                                                                                                                                  | List         |
| [ListComplianceStatus](../../../fms/2018-01-01/APIReference/API_ListComplianceStatus.md "../../../fms/2018-01-01/APIReference/API_ListComplianceStatus.md")                                                       | Retrieve an array of PolicyComplianceStatus objects in the response. Use PolicyComplianceStatus to get a summary of which member accounts are protected by the specified policy | List         |
| [ListDiscoveredResources](../../../fms/2018-01-01/APIReference/API_ListDiscoveredResources.md "../../../fms/2018-01-01/APIReference/API_ListDiscoveredResources.md")                                              | Retrieve an array of resources in the organization's accounts that are available to be associated with a resource set                                                           | List         |
| [ListMemberAccounts](../../../fms/2018-01-01/APIReference/API_ListMemberAccounts.md "../../../fms/2018-01-01/APIReference/API_ListMemberAccounts.md")                                                             | Retrieve an array of member account ids if the caller is FMS admin account                                                                                                      | List         |
| [ListPolicies](../../../fms/2018-01-01/APIReference/API_ListPolicies.md "../../../fms/2018-01-01/APIReference/API_ListPolicies.md")                                                                               | Retrieve an array of PolicySummary objects in the response                                                                                                                      | List         |
| [ListProtocolsLists](../../../fms/2018-01-01/APIReference/API_ListProtocolsLists.md "../../../fms/2018-01-01/APIReference/API_ListProtocolsLists.md")                                                             | Return an array of ProtocolsListDataSummary objects                                                                                                                             | List         |
| [ListResourceSetResources](../../../fms/2018-01-01/APIReference/API_ListResourceSetResources.md "../../../fms/2018-01-01/APIReference/API_ListResourceSetResources.md")                                           | Retrieve an array of resources that are currently associated to a resource set                                                                                                  | List         |
| [ListResourceSets](../../../fms/2018-01-01/APIReference/API_ListResourceSets.md "../../../fms/2018-01-01/APIReference/API_ListResourceSets.md")                                                                   | Retrieve an array of ResourceSetSummary objects                                                                                                                                 | List         |
| [ListTagsForResource](../../../fms/2018-01-01/APIReference/API_ListTagsForResource.md "../../../fms/2018-01-01/APIReference/API_ListTagsForResource.md")                                                          | List Tags for a given resource                                                                                                                                                  | Read         |
| [ListThirdPartyFirewallFirewallPolicies](../../../fms/2018-01-01/APIReference/API_ListThirdPartyFirewallFirewallPolicies.md "../../../fms/2018-01-01/APIReference/API_ListThirdPartyFirewallFirewallPolicies.md") | Retrieve a list of all of the third-party firewall policies that are associated with the third-party firewall administrator's account                                           | List         |
