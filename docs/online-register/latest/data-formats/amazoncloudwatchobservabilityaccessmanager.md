# Data retrieval APIs for Amazon CloudWatch Observability Access Manager

Amazon CloudWatch Observability Access Manager provides the following APIs for data retrieval.

| Actions                                                                                                                                          | Description                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | ------------ |
| [GetLink](../../../OAM/latest/APIReference/API_GetLink.md "../../../OAM/latest/APIReference/API_GetLink.md")                                     | Retrieve complete information about one cross-account monitoring link        | Read         |
| [GetSink](../../../OAM/latest/APIReference/API_GetSink.md "../../../OAM/latest/APIReference/API_GetSink.md")                                     | Retrieve complete information about one cross-account monitoring sink        | Read         |
| [GetSinkPolicy](../../../OAM/latest/APIReference/API_GetSinkPolicy.md "../../../OAM/latest/APIReference/API_GetSinkPolicy.md")                   | Retrieve information for the IAM policy for a cross-account monitoring sink  | Read         |
| [ListAttachedLinks](../../../OAM/latest/APIReference/API_ListAttachedLinks.md "../../../OAM/latest/APIReference/API_ListAttachedLinks.md")       | Retrieve a list of links that are linked for a cross-account monitoring sink | Read         |
| [ListLinks](../../../OAM/latest/APIReference/API_ListLinks.md "../../../OAM/latest/APIReference/API_ListLinks.md")                               | Retrieve the ARNs of cross-account monitoring links in this account          | Read         |
| [ListSinks](../../../OAM/latest/APIReference/API_ListSinks.md "../../../OAM/latest/APIReference/API_ListSinks.md")                               | Retrieve the ARNs of cross-account monitoring sinks in this account          | Read         |
| [ListTagsForResource](../../../OAM/latest/APIReference/API_ListTagsForResource.md "../../../OAM/latest/APIReference/API_ListTagsForResource.md") | List the tags for a resource                                                 | Read         |
