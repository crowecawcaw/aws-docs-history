

# Data retrieval APIs for Amazon CloudWatch Observability Access Manager
<a name="amazoncloudwatchobservabilityaccessmanager"></a>

Amazon CloudWatch Observability Access Manager provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="oam-GetLink"></a>[GetLink](https://docs.aws.amazon.com/OAM/latest/APIReference/API_GetLink.html) | Retrieve complete information about one cross-account monitoring link | Read | 
| <a name="oam-GetSink"></a>[GetSink](https://docs.aws.amazon.com/OAM/latest/APIReference/API_GetSink.html) | Retrieve complete information about one cross-account monitoring sink | Read | 
| <a name="oam-GetSinkPolicy"></a>[GetSinkPolicy](https://docs.aws.amazon.com/OAM/latest/APIReference/API_GetSinkPolicy.html) | Retrieve information for the IAM policy for a cross-account monitoring sink | Read | 
| <a name="oam-ListAttachedLinks"></a>[ListAttachedLinks](https://docs.aws.amazon.com/OAM/latest/APIReference/API_ListAttachedLinks.html) | Retrieve a list of links that are linked for a cross-account monitoring sink | Read | 
| <a name="oam-ListLinks"></a>[ListLinks](https://docs.aws.amazon.com/OAM/latest/APIReference/API_ListLinks.html) | Retrieve the ARNs of cross-account monitoring links in this account | Read | 
| <a name="oam-ListSinks"></a>[ListSinks](https://docs.aws.amazon.com/OAM/latest/APIReference/API_ListSinks.html) | Retrieve the ARNs of cross-account monitoring sinks in this account | Read | 
| <a name="oam-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/OAM/latest/APIReference/API_ListTagsForResource.html) | List the tags for a resource | Read |
