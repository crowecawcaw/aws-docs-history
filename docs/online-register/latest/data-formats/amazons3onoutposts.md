# Data retrieval APIs for Amazon S3 on Outposts

Amazon S3 on Outposts provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                | Description                                                                | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------ |
| [GetAccessPoint](../../../AmazonS3/latest/API/API_control_GetAccessPoint.md "../../../AmazonS3/latest/API/API_control_GetAccessPoint.md")                                              | Return configuration information about the specified access point          | Read         |
| [GetAccessPointPolicy](../../../AmazonS3/latest/API/API_control_GetAccessPointPolicy.md "../../../AmazonS3/latest/API/API_control_GetAccessPointPolicy.md")                            | Returns the access point policy associated with the specified access point | Read         |
| [GetBucket](../../../AmazonS3/latest/API/API_control_GetBucket.md "../../../AmazonS3/latest/API/API_control_GetBucket.md")                                                             | Return the bucket configuration associated with an Amazon S3 bucket        | Read         |
| [GetBucketPolicy](../../../AmazonS3/latest/API/API_control_GetBucketPolicy.md "../../../AmazonS3/latest/API/API_control_GetBucketPolicy.md")                                           | Return the policy of the specified bucket                                  | Read         |
| [GetBucketTagging](../../../AmazonS3/latest/API/API_control_GetBucketTagging.md "../../../AmazonS3/latest/API/API_control_GetBucketTagging.md")                                        | Return the tag set associated with an Amazon S3 bucket                     | Read         |
| [GetBucketVersioning](../../../AmazonS3/latest/API/API_GetBucketVersioning.md "../../../AmazonS3/latest/API/API_GetBucketVersioning.md")                                               | Return the versioning state of an Amazon S3 bucket                         | Read         |
| [GetLifecycleConfiguration](../../../AmazonS3/latest/API/API_control_GetBucketLifecycleConfiguration.md "../../../AmazonS3/latest/API/API_control_GetBucketLifecycleConfiguration.md") | Return the lifecycle configuration information set on an Amazon S3 bucket  | Read         |
| [GetObject](../../../AmazonS3/latest/API/API_GetObject.md "../../../AmazonS3/latest/API/API_GetObject.md")                                                                             | Retrieve objects from Amazon S3                                            | Read         |
| [GetObjectTagging](../../../AmazonS3/latest/API/API_GetObjectTagging.md "../../../AmazonS3/latest/API/API_GetObjectTagging.md")                                                        | Return the tag set of an object                                            | Read         |
| [GetObjectVersion](../../../AmazonS3/latest/API/API_GetObject.md "../../../AmazonS3/latest/API/API_GetObject.md")                                                                      | Retrieve a specific version of an object                                   | Read         |
| [GetObjectVersionForReplication](../../../AmazonS3/latest/API/API_GetObject.md "../../../AmazonS3/latest/API/API_GetObject.md")                                                        | Replicate both unencrypted objects and objects encrypted with SSE-KMS      | Read         |
| [GetObjectVersionTagging](../../../AmazonS3/latest/API/API_GetObject.md "../../../AmazonS3/latest/API/API_GetObject.md")                                                               | Return the tag set for a specific version of the object                    | Read         |
| [GetReplicationConfiguration](../../../AmazonS3/latest/API/API_control_GetBucketReplication.md "../../../AmazonS3/latest/API/API_control_GetBucketReplication.md")                     | Get the replication configuration information set on an Amazon S3 bucket   | Read         |
| [ListAccessPoints](../../../AmazonS3/latest/API/API_control_ListAccessPoints.md "../../../AmazonS3/latest/API/API_control_ListAccessPoints.md")                                        | List access points                                                         | List         |
| [ListBucket](../../../AmazonS3/latest/API/API_ListObjectsV2.md "../../../AmazonS3/latest/API/API_ListObjectsV2.md")                                                                    | List some or all of the objects in an Amazon S3 bucket (up to 1000)        | List         |
| [ListBucketMultipartUploads](../../../AmazonS3/latest/API/API_ListMultipartUploads.md "../../../AmazonS3/latest/API/API_ListMultipartUploads.md")                                      | List in-progress multipart uploads                                         | List         |
| [ListBucketVersions](../../../AmazonS3/latest/API/API_ListObjectVersions.md "../../../AmazonS3/latest/API/API_ListObjectVersions.md")                                                  | List metadata about all the versions of objects in an Amazon S3 bucket     | List         |
| [ListEndpoints](../../../AmazonS3/latest/API/API_s3outposts_ListEndpoints.md "../../../AmazonS3/latest/API/API_s3outposts_ListEndpoints.md")                                           | List endpoints                                                             | List         |
| [ListMultipartUploadParts](../../../AmazonS3/latest/API/API_ListParts.md "../../../AmazonS3/latest/API/API_ListParts.md")                                                              | List the parts that have been uploaded for a specific multipart upload     | List         |
| [ListOutpostsWithS3](../../../AmazonS3/latest/API/API_s3outposts_ListOutpostsWithS3.md "../../../AmazonS3/latest/API/API_s3outposts_ListOutpostsWithS3.md")                            | List outposts with S3 capacity                                             | List         |
| [ListRegionalBuckets](../../../AmazonS3/latest/API/API_control_ListRegionalBuckets.md "../../../AmazonS3/latest/API/API_control_ListRegionalBuckets.md")                               | List all buckets owned by the authenticated sender of the request          | List         |
| [ListSharedEndpoints](../../../AmazonS3/latest/API/API_s3outposts_ListSharedEndpoints.md "../../../AmazonS3/latest/API/API_s3outposts_ListSharedEndpoints.md")                         | List shared endpoints                                                      | List         |
