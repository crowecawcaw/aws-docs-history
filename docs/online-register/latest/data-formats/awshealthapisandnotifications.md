# Data retrieval APIs for AWS Health APIs and Notifications

AWS Health APIs and Notifications provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                     | Description                                                                                              | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAffectedAccountsForOrganization](../../../health/latest/APIReference/API_DescribeAffectedAccountsForOrganization.md "../../../health/latest/APIReference/API_DescribeAffectedAccountsForOrganization.md")          | Retrieve a list of accounts that have been affected by the specified events in organization              | Read         |
| [DescribeAffectedEntities](../../../health/latest/APIReference/API_DescribeAffectedEntities.md "../../../health/latest/APIReference/API_DescribeAffectedEntities.md")                                                       | Retrieve a list of entities that have been affected by the specified events                              | Read         |
| [DescribeAffectedEntitiesForOrganization](../../../health/latest/APIReference/API_DescribeAffectedEntitiesForOrganization.md "../../../health/latest/APIReference/API_DescribeAffectedEntitiesForOrganization.md")          | Retrieve a list of entities that have been affected by the specified events and accounts in organization | Read         |
| [DescribeEntityAggregates](../../../health/latest/APIReference/API_DescribeEntityAggregates.md "../../../health/latest/APIReference/API_DescribeEntityAggregates.md")                                                       | Retrieve the number of entities that are affected by each of the specified events                        | Read         |
| [DescribeEntityAggregatesForOrganization](../../../health/latest/APIReference/API_DescribeEntityAggregatesForOrganization.md "../../../health/latest/APIReference/API_DescribeEntityAggregatesForOrganization.md")          | Retrieve the number of entities that are affected by each of the specified events in an organization     | Read         |
| [DescribeEventAggregates](../../../health/latest/APIReference/API_DescribeEventAggregates.md "../../../health/latest/APIReference/API_DescribeEventAggregates.md")                                                          | Retrieve the number of events of each event type (issue, scheduled change, and account notification)     | Read         |
| [DescribeEventDetails](../../../health/latest/APIReference/API_DescribeEventDetails.md "../../../health/latest/APIReference/API_DescribeEventDetails.md")                                                                   | Retrieve detailed information about one or more specified events                                         | Read         |
| [DescribeEventDetailsForOrganization](../../../health/latest/APIReference/API_DescribeEventDetailsForOrganization.md "../../../health/latest/APIReference/API_DescribeEventDetailsForOrganization.md")                      | Retrieve detailed information about one or more specified events for provided accounts in organization   | Read         |
| [DescribeEventTypes](../../../health/latest/APIReference/API_DescribeEventTypes.md "../../../health/latest/APIReference/API_DescribeEventTypes.md")                                                                         | Retrieve the event types that meet the specified filter criteria                                         | Read         |
| [DescribeEvents](../../../health/latest/APIReference/API_DescribeEvents.md "../../../health/latest/APIReference/API_DescribeEvents.md")                                                                                     | Retrieve information about events that meet the specified filter criteria                                | Read         |
| [DescribeEventsForOrganization](../../../health/latest/APIReference/API_DescribeEventsForOrganization.md "../../../health/latest/APIReference/API_DescribeEventsForOrganization.md")                                        | Retrieve information about events that meet the specified filter criteria in organization                | Read         |
| [DescribeHealthServiceStatusForOrganization](../../../health/latest/APIReference/API_DescribeHealthServiceStatusForOrganization.md "../../../health/latest/APIReference/API_DescribeHealthServiceStatusForOrganization.md") | Retrieve the status of enabling or disabling the Organizational View feature                             | Read         |
