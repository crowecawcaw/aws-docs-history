

# Data retrieval APIs for AWS Tax Settings
<a name="awstaxsettings"></a>

AWS Tax Settings provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="tax-GetDocument"></a>[GetDocument](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Retrieve documents such as withholding slips | Read | 
| <a name="tax-GetDocumentUploadUrl"></a>[GetDocumentUploadUrl](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Retrieve a generated URL to upload documents | Read | 
| <a name="tax-GetExemptions"></a>[GetExemptions](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax exemptions data | Read | 
| <a name="tax-GetTaxInfoReportingDocument"></a>[GetTaxInfoReportingDocument](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View/download tax documents/forms | Read | 
| <a name="tax-GetTaxInheritance"></a>[GetTaxInheritance](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax inheritance status | Read | 
| <a name="tax-GetTaxInterview"></a>[GetTaxInterview](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | Retrieve tax interview data | Read | 
| <a name="tax-GetTaxRegistration"></a>[GetTaxRegistration](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | View tax registrations data | Read | 
| <a name="tax-GetTaxRegistrationDocument"></a>[GetTaxRegistrationDocument](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Download tax registration documents | Read | 
| <a name="tax-ListDocuments"></a>[ListDocuments](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View documents such as withholding slips | Read | 
| <a name="tax-ListSupplementalTaxRegistrations"></a>[ListSupplementalTaxRegistrations](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | View supplemental tax registrations | Read | 
| <a name="tax-ListTaxRegistrations"></a>[ListTaxRegistrations](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax registrations | Read | 
| <a name="tax-ListWithholdingEligibleInvoices"></a>[ListWithholdingEligibleInvoices](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View eligible withholding invoices | Read |
