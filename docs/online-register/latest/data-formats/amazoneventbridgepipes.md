# Data retrieval APIs for Amazon EventBridge Pipes

Amazon EventBridge Pipes provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                    | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ------------ |
| [DescribePipe](../../../eventbridge/latest/pipes-reference/API_DescribePipe.md "../../../eventbridge/latest/pipes-reference/API_DescribePipe.md")                      | Describe a pipe                | Read         |
| [ListPipes](../../../eventbridge/latest/pipes-reference/API_ListPipes.md "../../../eventbridge/latest/pipes-reference/API_ListPipes.md")                               | List all pipes in your account | List         |
| [ListTagsForResource](../../../eventbridge/latest/pipes-reference/API_ListTagsForResource.md "../../../eventbridge/latest/pipes-reference/API_ListTagsForResource.md") | List the tags for a resource   | Read         |
