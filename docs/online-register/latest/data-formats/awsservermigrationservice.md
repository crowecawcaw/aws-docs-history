# Data retrieval APIs for AWS Server Migration Service

AWS Server Migration Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                     | Description                                                                   | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------ |
| [GetApp](../../../server-migration-service/latest/APIReference/API_GetApp.md "../../../server-migration-service/latest/APIReference/API_GetApp.md")                                                                         | Get the configuration and statuses for an existing application                | Read         |
| [GetAppLaunchConfiguration](../../../server-migration-service/latest/APIReference/API_GetAppLaunchConfiguration.md "../../../server-migration-service/latest/APIReference/API_GetAppLaunchConfiguration.md")                | Get launch configuration for an existing application                          | Read         |
| [GetAppReplicationConfiguration](../../../server-migration-service/latest/APIReference/API_GetAppReplicationConfiguration.md "../../../server-migration-service/latest/APIReference/API_GetAppReplicationConfiguration.md") | Get replication configuration for an existing application                     | Read         |
| [GetAppValidationConfiguration](../../../server-migration-service/latest/APIReference/API_GetAppValidationConfiguration.md "../../../server-migration-service/latest/APIReference/API_GetAppValidationConfiguration.md")    | Get validation configuration for an existing application                      | Read         |
| [GetAppValidationOutput](../../../server-migration-service/latest/APIReference/API_GetAppValidationOutput.md "../../../server-migration-service/latest/APIReference/API_GetAppValidationOutput.md")                         | Get notification sent from application validation script.                     | Read         |
| [GetConnectors](../../../server-migration-service/latest/APIReference/API_GetConnectors.md "../../../server-migration-service/latest/APIReference/API_GetConnectors.md")                                                    | Get all connectors that have been associated                                  | Read         |
| GetMessages                                                                                                                                                                                                                 | Gets messages from AWS Server Migration Service to Server Migration Connector | Read         |
| [GetReplicationJobs](../../../server-migration-service/latest/APIReference/API_GetReplicationJobs.md "../../../server-migration-service/latest/APIReference/API_GetReplicationJobs.md")                                     | Get all existing jobs to migrate on-premise servers onto AWS                  | Read         |
| [GetReplicationRuns](../../../server-migration-service/latest/APIReference/API_GetReplicationRuns.md "../../../server-migration-service/latest/APIReference/API_GetReplicationRuns.md")                                     | Get all runs for an existing job                                              | Read         |
| [GetServers](../../../server-migration-service/latest/APIReference/API_GetServers.md "../../../server-migration-service/latest/APIReference/API_GetServers.md")                                                             | Get all servers that have been imported                                       | Read         |
| [ListApps](../../../server-migration-service/latest/APIReference/API_ListAppss.md "../../../server-migration-service/latest/APIReference/API_ListAppss.md")                                                                 | Get a list of summaries for existing applications                             | List         |
