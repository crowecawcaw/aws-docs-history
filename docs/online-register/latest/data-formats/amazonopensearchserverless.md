

# Data retrieval APIs for Amazon OpenSearch Serverless
<a name="amazonopensearchserverless"></a>

Amazon OpenSearch Serverless provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aoss-BatchGetCollection"></a>[BatchGetCollection](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_BatchGetCollection.html) | Get attributes for one or more collections | Read | 
| <a name="aoss-BatchGetCollectionGroup"></a>[BatchGetCollectionGroup](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_BatchGetCollectionGroup.html) | Get attributes for one or more collection groups | Read | 
| <a name="aoss-BatchGetEffectiveLifecyclePolicy"></a>[BatchGetEffectiveLifecyclePolicy](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_BatchGetEffectiveLifecyclePolicy.html) | Get the information about a lifecycle policy applied to one or more AOSS resources | Read | 
| <a name="aoss-BatchGetLifecyclePolicy"></a>[BatchGetLifecyclePolicy](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_BatchGetLifecyclePolicy.html) | Get information about one or more lifecycle policies | Read | 
| <a name="aoss-BatchGetVpcEndpoint"></a>[BatchGetVpcEndpoint](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_BatchGetVpcEndpoint.html) | Get attributes for one or more VPC endpoints | Read | 
| <a name="aoss-GetAccessPolicy"></a>[GetAccessPolicy](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetAccessPolicy.html) | Get information about a data access policy | Read | 
| <a name="aoss-GetAccountSettings"></a>[GetAccountSettings](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetAccountSettings.html) | Get account settings, including capacity settings | Read | 
| <a name="aoss-GetIndex"></a>[GetIndex](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetIndex.html) | Get an opensearch index | Read | 
| <a name="aoss-GetPoliciesStats"></a>[GetPoliciesStats](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetPoliciesStats.html) | Get statistis about the security policies in your account | Read | 
| <a name="aoss-GetSecurityConfig"></a>[GetSecurityConfig](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetSecurityConfig.html) | Get information about a serverless security configuration | Read | 
| <a name="aoss-GetSecurityPolicy"></a>[GetSecurityPolicy](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_GetSecurityPolicy.html) | Get information about a security policy | Read | 
| <a name="aoss-ListAccessPolicies"></a>[ListAccessPolicies](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListAccessPolicies.html) | List data access policies | List | 
| <a name="aoss-ListCollectionGroups"></a>[ListCollectionGroups](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListCollectionGroups.html) | List collection groups | List | 
| <a name="aoss-ListCollections"></a>[ListCollections](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListCollections.html) | List collections | List | 
| <a name="aoss-ListLifecyclePolicies"></a>[ListLifecyclePolicies](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListLifecyclePolicies.html) | List lifecycle policies | List | 
| <a name="aoss-ListSecurityConfigs"></a>[ListSecurityConfigs](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListSecurityConfigs.html) | List security configurations | List | 
| <a name="aoss-ListSecurityPolicies"></a>[ListSecurityPolicies](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListSecurityPolicies.html) | List security policies | List | 
| <a name="aoss-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListTagsForResource.html) | List tags for a collection | List | 
| <a name="aoss-ListVpcEndpoints"></a>[ListVpcEndpoints](https://docs.aws.amazon.com/opensearch-service/latest/ServerlessAPIReference/API_ListVpcEndpoints.html) | List OpenSearch Serverless-managed VPC endpoints | List |
