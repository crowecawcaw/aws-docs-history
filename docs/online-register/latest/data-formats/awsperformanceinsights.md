# Data retrieval APIs for AWS Performance Insights

AWS Performance Insights provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                | Description                                                                                                                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeDimensionKeys](../../../performance-insights/latest/APIReference/API_DescribeDimensionKeys.md "../../../performance-insights/latest/APIReference/API_DescribeDimensionKeys.md")                               | Call DescribeDimensionKeys API to retrieve the top N dimension keys for a metric for a specific time period                                       | Read         |
| [GetDimensionKeyDetails](../../../performance-insights/latest/APIReference/API_GetDimensionKeyDetails.md "../../../performance-insights/latest/APIReference/API_GetDimensionKeyDetails.md")                            | Call GetDimensionKeyDetails API to retrieve the attributes of the specified dimension group                                                       | Read         |
| [GetPerformanceAnalysisReport](../../../performance-insights/latest/APIReference/API_GetPerformanceAnalysisReport.md "../../../performance-insights/latest/APIReference/API_GetPerformanceAnalysisReport.md")          | Call GetPerformanceAnalysisReport API to retrieve a Performance Analysis Report for a specified DB instance                                       | Read         |
| [GetResourceMetadata](../../../performance-insights/latest/APIReference/API_GetResourceMetadata.md "../../../performance-insights/latest/APIReference/API_GetResourceMetadata.md")                                     | Call GetResourceMetadata API to retrieve the metadata for different features                                                                      | Read         |
| [GetResourceMetrics](../../../performance-insights/latest/APIReference/API_GetResourceMetrics.md "../../../performance-insights/latest/APIReference/API_GetResourceMetrics.md")                                        | Call GetResourceMetrics API to retrieve PI metrics for a set of data sources, over a time period                                                  | Read         |
| [ListAvailableResourceDimensions](../../../performance-insights/latest/APIReference/API_ListAvailableResourceDimensions.md "../../../performance-insights/latest/APIReference/API_ListAvailableResourceDimensions.md") | Call ListAvailableResourceDimensions API to retrieve the dimensions that can be queried for each specified metric type on a specified DB instance | Read         |
| [ListAvailableResourceMetrics](../../../performance-insights/latest/APIReference/API_ListAvailableResourceMetrics.md "../../../performance-insights/latest/APIReference/API_ListAvailableResourceMetrics.md")          | Call ListAvailableResourceMetrics API to retrieve metrics of the specified types that can be queried for a specified DB instance                  | Read         |
| [ListPerformanceAnalysisReports](../../../performance-insights/latest/APIReference/API_ListPerformanceAnalysisReports.md "../../../performance-insights/latest/APIReference/API_ListPerformanceAnalysisReports.md")    | Call ListPerformanceAnalysisReports API to list Performance Analysis Reports for a specified DB instance                                          | List         |
| [ListTagsForResource](../../../performance-insights/latest/APIReference/API_ListTagsForResource.md "../../../performance-insights/latest/APIReference/API_ListTagsForResource.md")                                     | Call ListTagsForResource API to list tags for a resource                                                                                          | List         |
