

# Data retrieval APIs for AWS Performance Insights
<a name="awsperformanceinsights"></a>

AWS Performance Insights provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="pi-DescribeDimensionKeys"></a>[DescribeDimensionKeys](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_DescribeDimensionKeys.html) | Call DescribeDimensionKeys API to retrieve the top N dimension keys for a metric for a specific time period | Read | 
| <a name="pi-GetDimensionKeyDetails"></a>[GetDimensionKeyDetails](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_GetDimensionKeyDetails.html) | Call GetDimensionKeyDetails API to retrieve the attributes of the specified dimension group | Read | 
| <a name="pi-GetPerformanceAnalysisReport"></a>[GetPerformanceAnalysisReport](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_GetPerformanceAnalysisReport.html) | Call GetPerformanceAnalysisReport API to retrieve a Performance Analysis Report for a specified DB instance | Read | 
| <a name="pi-GetResourceMetadata"></a>[GetResourceMetadata](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_GetResourceMetadata.html) | Call GetResourceMetadata API to retrieve the metadata for different features | Read | 
| <a name="pi-GetResourceMetrics"></a>[GetResourceMetrics](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_GetResourceMetrics.html) | Call GetResourceMetrics API to retrieve PI metrics for a set of data sources, over a time period | Read | 
| <a name="pi-ListAvailableResourceDimensions"></a>[ListAvailableResourceDimensions](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_ListAvailableResourceDimensions.html) | Call ListAvailableResourceDimensions API to retrieve the dimensions that can be queried for each specified metric type on a specified DB instance | Read | 
| <a name="pi-ListAvailableResourceMetrics"></a>[ListAvailableResourceMetrics](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_ListAvailableResourceMetrics.html) | Call ListAvailableResourceMetrics API to retrieve metrics of the specified types that can be queried for a specified DB instance | Read | 
| <a name="pi-ListPerformanceAnalysisReportRecommendations"></a>[ListPerformanceAnalysisReportRecommendations](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_ListPerformanceAnalysisReportRecommendations.html) | Call ListPerformanceAnalysisReportRecommendations API to retrieve a Performance Analysis Report Recommendations for a specified DB instance | List | 
| <a name="pi-ListPerformanceAnalysisReports"></a>[ListPerformanceAnalysisReports](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_ListPerformanceAnalysisReports.html) | Call ListPerformanceAnalysisReports API to list Performance Analysis Reports for a specified DB instance | List | 
| <a name="pi-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/performance-insights/latest/APIReference/API_ListTagsForResource.html) | Call ListTagsForResource API to list tags for a resource | List |
