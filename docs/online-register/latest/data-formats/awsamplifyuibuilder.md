# Data retrieval APIs for AWS Amplify UI Builder

AWS Amplify UI Builder provides the following APIs for data retrieval.

| Actions                                                                                                                                                                    | Description                                          | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ------------ |
| [ExportComponents](../../../amplifyuibuilder/latest/APIReference/API_ExportComponents.md "../../../amplifyuibuilder/latest/APIReference/API_ExportComponents.md")          | Export components                                    | Read         |
| [ExportForms](../../../amplifyuibuilder/latest/APIReference/API_ExportForms.md "../../../amplifyuibuilder/latest/APIReference/API_ExportForms.md")                         | Export forms                                         | Read         |
| [ExportThemes](../../../amplifyuibuilder/latest/APIReference/API_ExportThemes.md "../../../amplifyuibuilder/latest/APIReference/API_ExportThemes.md")                      | Export themes                                        | Read         |
| [GetCodegenJob](../../../amplifyuibuilder/latest/APIReference/API_GetCodegenJob.md "../../../amplifyuibuilder/latest/APIReference/API_GetCodegenJob.md")                   | Get an existing codegen job                          | Read         |
| [GetComponent](../../../amplifyuibuilder/latest/APIReference/API_GetComponent.md "../../../amplifyuibuilder/latest/APIReference/API_GetComponent.md")                      | Get an existing component                            | Read         |
| [GetForm](../../../amplifyuibuilder/latest/APIReference/API_GetForm.md "../../../amplifyuibuilder/latest/APIReference/API_GetForm.md")                                     | Get an existing form                                 | Read         |
| [GetMetadata](../../../amplifyuibuilder/latest/APIReference/API_GetMetadata.md "../../../amplifyuibuilder/latest/APIReference/API_GetMetadata.md")                         | Get an existing metadata                             | Read         |
| [GetTheme](../../../amplifyuibuilder/latest/APIReference/API_GetTheme.md "../../../amplifyuibuilder/latest/APIReference/API_GetTheme.md")                                  | Get an existing theme                                | Read         |
| [ListCodegenJobs](../../../amplifyuibuilder/latest/APIReference/API_ListCodegenJobs.md "../../../amplifyuibuilder/latest/APIReference/API_ListCodegenJobs.md")             | List codegen jobs                                    | List         |
| [ListComponents](../../../amplifyuibuilder/latest/APIReference/API_ListComponents.md "../../../amplifyuibuilder/latest/APIReference/API_ListComponents.md")                | List components                                      | List         |
| [ListForms](../../../amplifyuibuilder/latest/APIReference/API_ListForms.md "../../../amplifyuibuilder/latest/APIReference/API_ListForms.md")                               | List forms                                           | List         |
| [ListTagsForResource](../../../amplifyuibuilder/latest/APIReference/API_ListTagsForResource.md "../../../amplifyuibuilder/latest/APIReference/API_ListTagsForResource.md") | List tags for a specified Amazon Resource Name (ARN) | List         |
| [ListThemes](../../../amplifyuibuilder/latest/APIReference/API_ListThemes.md "../../../amplifyuibuilder/latest/APIReference/API_ListThemes.md")                            | List themes                                          | List         |
