

# Data retrieval APIs for AWS Amplify UI Builder
<a name="awsamplifyuibuilder"></a>

AWS Amplify UI Builder provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="amplifyuibuilder-ExportComponents"></a>[ExportComponents](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ExportComponents.html) | Export components | Read | 
| <a name="amplifyuibuilder-ExportForms"></a>[ExportForms](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ExportForms.html) | Export forms | Read | 
| <a name="amplifyuibuilder-ExportThemes"></a>[ExportThemes](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ExportThemes.html) | Export themes | Read | 
| <a name="amplifyuibuilder-GetCodegenJob"></a>[GetCodegenJob](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_GetCodegenJob.html) | Get an existing codegen job | Read | 
| <a name="amplifyuibuilder-GetComponent"></a>[GetComponent](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_GetComponent.html) | Get an existing component | Read | 
| <a name="amplifyuibuilder-GetForm"></a>[GetForm](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_GetForm.html) | Get an existing form | Read | 
| <a name="amplifyuibuilder-GetMetadata"></a>[GetMetadata](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_GetMetadata.html) | Get an existing metadata | Read | 
| <a name="amplifyuibuilder-GetTheme"></a>[GetTheme](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_GetTheme.html) | Get an existing theme | Read | 
| <a name="amplifyuibuilder-ListCodegenJobs"></a>[ListCodegenJobs](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ListCodegenJobs.html) | List codegen jobs | List | 
| <a name="amplifyuibuilder-ListComponents"></a>[ListComponents](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ListComponents.html) | List components | List | 
| <a name="amplifyuibuilder-ListForms"></a>[ListForms](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ListForms.html) | List forms | List | 
| <a name="amplifyuibuilder-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ListTagsForResource.html) | List tags for a specified Amazon Resource Name (ARN) | List | 
| <a name="amplifyuibuilder-ListThemes"></a>[ListThemes](https://docs.aws.amazon.com/amplifyuibuilder/latest/APIReference/API_ListThemes.html) | List themes | List |
