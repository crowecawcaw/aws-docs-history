# Data retrieval APIs for AWS Recycle Bin

AWS Recycle Bin provides the following APIs for data retrieval.

| Actions                                                                                                                                                        | Description                                                 | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | ------------ |
| [GetRule](../../../recyclebin/latest/APIReference/API_GetRule.md "../../../recyclebin/latest/APIReference/API_GetRule.md")                                     | Get detailed information about a Recycle Bin retention rule | Read         |
| [ListRules](../../../recyclebin/latest/APIReference/API_ListRules.md "../../../recyclebin/latest/APIReference/API_ListRules.md")                               | List the Recycle Bin retention rules in the Region          | Read         |
| [ListTagsForResource](../../../recyclebin/latest/APIReference/API_ListTagsForResource.md "../../../recyclebin/latest/APIReference/API_ListTagsForResource.md") | List the tags associated with a resource                    | Read         |
