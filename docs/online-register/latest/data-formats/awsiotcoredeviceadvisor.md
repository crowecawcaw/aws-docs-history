

# Data retrieval APIs for AWS IoT Core Device Advisor
<a name="awsiotcoredeviceadvisor"></a>

AWS IoT Core Device Advisor provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="iotdeviceadvisor-GetEndpoint"></a>[GetEndpoint](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_GetEndpoint.html) | Get a Device Advisor endpoint | Read | 
| <a name="iotdeviceadvisor-GetSuiteDefinition"></a>[GetSuiteDefinition](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_GetSuiteDefinition.html) | Get a suite definition | Read | 
| <a name="iotdeviceadvisor-GetSuiteRun"></a>[GetSuiteRun](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRun.html) | Get a suite run | Read | 
| <a name="iotdeviceadvisor-GetSuiteRunReport"></a>[GetSuiteRunReport](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRunReport.html) | Get the qualification report for a suite run | Read | 
| <a name="iotdeviceadvisor-ListSuiteDefinitions"></a>[ListSuiteDefinitions](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_ListSuiteDefinitions.html) | List suite definitions | List | 
| <a name="iotdeviceadvisor-ListSuiteRuns"></a>[ListSuiteRuns](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_ListSuiteRuns.html) | List suite runs | List | 
| <a name="iotdeviceadvisor-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/iot/latest/apireference/API_iotdeviceadvisor_ListTagsForResource.html) | List the tags (metadata) assigned to a resource | Read |
