# Data retrieval APIs for AWS IoT Core Device Advisor

AWS IoT Core Device Advisor provides the following APIs for data retrieval.

| Actions                                                                                                                                                                               | Description                                     | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ------------ |
| [GetEndpoint](../../../iot/latest/apireference/API_iotdeviceadvisor_GetEndpoint.md "../../../iot/latest/apireference/API_iotdeviceadvisor_GetEndpoint.md")                            | Get a Device Advisor endpoint                   | Read         |
| [GetSuiteDefinition](../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteDefinition.md "../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteDefinition.md")       | Get a suite definition                          | Read         |
| [GetSuiteRun](../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRun.md "../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRun.md")                            | Get a suite run                                 | Read         |
| [GetSuiteRunReport](../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRunReport.md "../../../iot/latest/apireference/API_iotdeviceadvisor_GetSuiteRunReport.md")          | Get the qualification report for a suite run    | Read         |
| [ListSuiteDefinitions](../../../iot/latest/apireference/API_iotdeviceadvisor_ListSuiteDefinitions.md "../../../iot/latest/apireference/API_iotdeviceadvisor_ListSuiteDefinitions.md") | List suite definitions                          | List         |
| [ListSuiteRuns](../../../iot/latest/apireference/API_iotdeviceadvisor_ListSuiteRuns.md "../../../iot/latest/apireference/API_iotdeviceadvisor_ListSuiteRuns.md")                      | List suite runs                                 | List         |
| [ListTagsForResource](../../../iot/latest/apireference/API_iotdeviceadvisor_ListTagsForResource.md "../../../iot/latest/apireference/API_iotdeviceadvisor_ListTagsForResource.md")    | List the tags (metadata) assigned to a resource | Read         |
