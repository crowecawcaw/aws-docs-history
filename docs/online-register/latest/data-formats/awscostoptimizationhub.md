

# Data retrieval APIs for AWS Cost Optimization Hub
<a name="awscostoptimizationhub"></a>

AWS Cost Optimization Hub provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="cost-optimization-hub-GetPreferences"></a>[GetPreferences](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_GetPreferences.html) | Get preferences | Read | 
| <a name="cost-optimization-hub-GetRecommendation"></a>[GetRecommendation](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_GetRecommendation.html) | Get resource configuration and estimated cost impact for a recommendation | Read | 
| <a name="cost-optimization-hub-ListEfficiencyMetrics"></a>[ListEfficiencyMetrics](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_ListEfficiencyMetrics.html) | List efficiency metric scores by group | List | 
| <a name="cost-optimization-hub-ListEnrollmentStatuses"></a>[ListEnrollmentStatuses](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_ListEnrollmentStatuses.html) | List enrollment statuses for the specified account or all members under a management account | List | 
| <a name="cost-optimization-hub-ListRecommendationSummaries"></a>[ListRecommendationSummaries](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_ListRecommendationSummaries.html) | List recommendation summaries by group | List | 
| <a name="cost-optimization-hub-ListRecommendations"></a>[ListRecommendations](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_CostOptimizationHub_ListRecommendations.html) | List summary view of recommendations | List |
