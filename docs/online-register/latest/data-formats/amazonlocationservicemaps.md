# Data retrieval APIs for Amazon Location Service Maps

Amazon Location Service Maps provides the following APIs for data retrieval.

| Actions                                                                                                                                               | Description             | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------ |
| [GetStaticMap](../../../location/latest/APIReference/API_geomaps_GetStaticMap.md "../../../location/latest/APIReference/API_geomaps_GetStaticMap.md") | Retrieve the static map | Read         |
| [GetTile](../../../location/latest/APIReference/API_geomaps_GetTile.md "../../../location/latest/APIReference/API_geomaps_GetTile.md")                | Retrieve the map tile   | Read         |
