# Data retrieval APIs for AWS Diagnostic tools

AWS Diagnostic tools provides the following APIs for data retrieval.

| Actions                                                                                                                                                                    | Description                                                             | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------ |
| [GetExecution](../../../diagnostic-tools/latest/APIReference/API_GetExecution.md "../../../diagnostic-tools/latest/APIReference/API_GetExecution.md")                      | Get details about specific execution within AWS Diagnostic tools        | Read         |
| [GetExecutionOutput](../../../diagnostic-tools/latest/APIReference/API_GetExecutionOutput.md "../../../diagnostic-tools/latest/APIReference/API_GetExecutionOutput.md")    | Get details about specific execution output within AWS Diagnostic tools | Read         |
| [GetTool](../../../diagnostic-tools/latest/APIReference/API_GetTool.md "../../../diagnostic-tools/latest/APIReference/API_GetTool.md")                                     | Get details about specific tool within AWS Diagnostic tools             | Read         |
| [ListExecutions](../../../diagnostic-tools/latest/APIReference/API_ListExecutions.md "../../../diagnostic-tools/latest/APIReference/API_ListExecutions.md")                | List all available execution within AWS Diagnostic tools                | List         |
| [ListTagsForResource](../../../diagnostic-tools/latest/APIReference/API_ListTagsForResource.md "../../../diagnostic-tools/latest/APIReference/API_ListTagsForResource.md") | List the tags for an AWS Diagnostic tools resource                      | Read         |
| [ListTools](../../../diagnostic-tools/latest/APIReference/API_ListTools.md "../../../diagnostic-tools/latest/APIReference/API_ListTools.md")                               | List all available tools within AWS Diagnostic tools                    | List         |
