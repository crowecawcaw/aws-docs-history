# Data retrieval APIs for AWS Elastic Beanstalk

AWS Elastic Beanstalk provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                              | Description                                                                                          | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------ |
| [CheckDNSAvailability](../../../elasticbeanstalk/latest/api/API_CheckDNSAvailability.md "../../../elasticbeanstalk/latest/api/API_CheckDNSAvailability.md")                                                          | Check CNAME availability                                                                             | Read         |
| [DescribeAccountAttributes](../../../elasticbeanstalk/latest/api/API_DescribeAccountAttributes.md "../../../elasticbeanstalk/latest/api/API_DescribeAccountAttributes.md")                                           | Retrieve a list of account attributes, including resource quotas                                     | Read         |
| [DescribeApplicationVersions](../../../elasticbeanstalk/latest/api/API_DescribeApplicationVersions.md "../../../elasticbeanstalk/latest/api/API_DescribeApplicationVersions.md")                                     | Retrieve a list of application versions stored in an AWS Elastic Beanstalk storage bucket            | List         |
| [DescribeApplications](../../../elasticbeanstalk/latest/api/API_DescribeApplications.md "../../../elasticbeanstalk/latest/api/API_DescribeApplications.md")                                                          | Retrieve the descriptions of existing applications                                                   | List         |
| [DescribeConfigurationOptions](../../../elasticbeanstalk/latest/api/API_DescribeConfigurationOptions.md "../../../elasticbeanstalk/latest/api/API_DescribeConfigurationOptions.md")                                  | Retrieve descriptions of environment configuration options                                           | Read         |
| [DescribeConfigurationSettings](../../../elasticbeanstalk/latest/api/API_DescribeConfigurationSettings.md "../../../elasticbeanstalk/latest/api/API_DescribeConfigurationSettings.md")                               | Retrieve a description of the settings for a configuration set                                       | Read         |
| [DescribeEnvironmentHealth](../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentHealth.md "../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentHealth.md")                                           | Retrieve information about the overall health of an environment                                      | Read         |
| [DescribeEnvironmentManagedActionHistory](../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentManagedActionHistory.md "../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentManagedActionHistory.md") | Retrieve a list of an environment's completed and failed managed actions                             | Read         |
| [DescribeEnvironmentManagedActions](../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentManagedActions.md "../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentManagedActions.md")                   | Retrieve a list of an environment's upcoming and in-progress managed actions                         | Read         |
| [DescribeEnvironmentResources](../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentResources.md "../../../elasticbeanstalk/latest/api/API_DescribeEnvironmentResources.md")                                  | Retrieve a list of AWS resources for an environment                                                  | Read         |
| [DescribeEnvironments](../../../elasticbeanstalk/latest/api/API_DescribeEnvironments.md "../../../elasticbeanstalk/latest/api/API_DescribeEnvironments.md")                                                          | Retrieve descriptions for existing environments                                                      | List         |
| [DescribeEvents](../../../elasticbeanstalk/latest/api/API_DescribeEvents.md "../../../elasticbeanstalk/latest/api/API_DescribeEvents.md")                                                                            | Retrieve a list of event descriptions matching a set of criteria                                     | Read         |
| [DescribeInstancesHealth](../../../elasticbeanstalk/latest/api/API_DescribeInstancesHealth.md "../../../elasticbeanstalk/latest/api/API_DescribeInstancesHealth.md")                                                 | Retrieve more detailed information about the health of environment instances                         | Read         |
| [DescribePlatformVersion](../../../elasticbeanstalk/latest/api/API_DescribePlatformVersion.md "../../../elasticbeanstalk/latest/api/API_DescribePlatformVersion.md")                                                 | Retrieve a description of a managed platform version                                                 | Read         |
| [ListAvailableSolutionStacks](../../../elasticbeanstalk/latest/api/API_ListAvailableSolutionStacks.md "../../../elasticbeanstalk/latest/api/API_ListAvailableSolutionStacks.md")                                     | Retrieve a list of the available solution stack names                                                | List         |
| [ListPlatformBranches](../../../elasticbeanstalk/latest/api/API_ListPlatformBranches.md "../../../elasticbeanstalk/latest/api/API_ListPlatformBranches.md")                                                          | Retrieve a list of the available platform branches                                                   | List         |
| [ListPlatformVersions](../../../elasticbeanstalk/latest/api/API_ListPlatformVersions.md "../../../elasticbeanstalk/latest/api/API_ListPlatformVersions.md")                                                          | Retrieve a list of the available platforms                                                           | List         |
| [ListTagsForResource](../../../elasticbeanstalk/latest/api/API_ListTagsForResource.md "../../../elasticbeanstalk/latest/api/API_ListTagsForResource.md")                                                             | Retrieve a list of tags of an Elastic Beanstalk resource                                             | Read         |
| [RequestEnvironmentInfo](../../../elasticbeanstalk/latest/api/API_RequestEnvironmentInfo.md "../../../elasticbeanstalk/latest/api/API_RequestEnvironmentInfo.md")                                                    | Initiate a request to compile information of the deployed environment                                | Read         |
| [RetrieveEnvironmentInfo](../../../elasticbeanstalk/latest/api/API_RetrieveEnvironmentInfo.md "../../../elasticbeanstalk/latest/api/API_RetrieveEnvironmentInfo.md")                                                 | Retrieve the compiled information from a RequestEnvironmentInfo request                              | Read         |
| [ValidateConfigurationSettings](../../../elasticbeanstalk/latest/api/API_ValidateConfigurationSettings.md "../../../elasticbeanstalk/latest/api/API_ValidateConfigurationSettings.md")                               | Check the validity of a set of configuration settings for a configuration template or an environment | Read         |
