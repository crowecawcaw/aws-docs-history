# Data retrieval APIs for Amazon Transcribe

Amazon Transcribe provides the following APIs for data retrieval.

| Actions                                                                                                                                                                 | Description                                                                                                                                    | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeLanguageModel](../../../transcribe/latest/dg/API_DescribeLanguageModel.md "../../../transcribe/latest/dg/API_DescribeLanguageModel.md")                        | Return information about a custom language model                                                                                               | Read         |
| [GetCallAnalyticsCategory](../../../transcribe/latest/dg/API_GetCallAnalyticsCategory.md "../../../transcribe/latest/dg/API_GetCallAnalyticsCategory.md")               | Retrieve information about a call analytics category                                                                                           | Read         |
| [GetCallAnalyticsJob](../../../transcribe/latest/dg/API_GetCallAnalyticsJob.md "../../../transcribe/latest/dg/API_GetCallAnalyticsJob.md")                              | Return information about a call analytics job                                                                                                  | Read         |
| [GetMedicalScribeJob](../../../transcribe/latest/dg/API_GetMedicalScribeJob.md "../../../transcribe/latest/dg/API_GetMedicalScribeJob.md")                              | Return information about a Medical Scribe job                                                                                                  | Read         |
| [GetMedicalScribeStream](../../../transcribe/latest/dg/API_streaming_GetMedicalScribeStream.md "../../../transcribe/latest/dg/API_streaming_GetMedicalScribeStream.md") | Get information about the specified AWS HealthScribe streaming session                                                                         | Read         |
| [GetMedicalTranscriptionJob](../../../transcribe/latest/dg/API_GetMedicalTranscriptionJob.md "../../../transcribe/latest/dg/API_GetMedicalTranscriptionJob.md")         | Return information about a medical transcription job                                                                                           | Read         |
| [GetMedicalVocabulary](../../../transcribe/latest/dg/API_GetMedicalVocabulary.md "../../../transcribe/latest/dg/API_GetMedicalVocabulary.md")                           | Get information about a medical vocabulary                                                                                                     | Read         |
| [GetTranscriptionJob](../../../transcribe/latest/dg/API_GetTranscriptionJob.md "../../../transcribe/latest/dg/API_GetTranscriptionJob.md")                              | Return information about a transcription job                                                                                                   | Read         |
| [GetVocabulary](../../../transcribe/latest/dg/API_GetVocabulary.md "../../../transcribe/latest/dg/API_GetVocabulary.md")                                                | To get information about a vocabulary                                                                                                          | Read         |
| [GetVocabularyFilter](../../../transcribe/latest/dg/API_GetVocabularyFilter.md "../../../transcribe/latest/dg/API_GetVocabularyFilter.md")                              | Get information about a vocabulary filter                                                                                                      | Read         |
| [ListCallAnalyticsCategories](../../../transcribe/latest/dg/API_ListCallAnalyticsCategories.md "../../../transcribe/latest/dg/API_ListCallAnalyticsCategories.md")      | List call analytics categories that has been created                                                                                           | List         |
| [ListCallAnalyticsJobs](../../../transcribe/latest/dg/API_ListCallAnalyticsJobs.md "../../../transcribe/latest/dg/API_ListCallAnalyticsJobs.md")                        | List call analytics jobs with the specified status                                                                                             | List         |
| [ListLanguageModels](../../../transcribe/latest/dg/API_ListLanguageModels.md "../../../transcribe/latest/dg/API_ListLanguageModels.md")                                 | List custom language models                                                                                                                    | List         |
| [ListMedicalScribeJobs](../../../transcribe/latest/dg/API_ListMedicalScribeJobs.md "../../../transcribe/latest/dg/API_ListMedicalScribeJobs.md")                        | List Medical Scribe jobs with the specified status                                                                                             | List         |
| [ListMedicalTranscriptionJobs](../../../transcribe/latest/dg/API_ListMedicalTranscriptionJobs.md "../../../transcribe/latest/dg/API_ListMedicalTranscriptionJobs.md")   | List medical transcription jobs with the specified status                                                                                      | List         |
| [ListMedicalVocabularies](../../../transcribe/latest/dg/API_ListMedicalVocabularies.md "../../../transcribe/latest/dg/API_ListMedicalVocabularies.md")                  | Return a list of medical vocabularies that match the specified criteria. If no criteria are specified, returns the entire list of vocabularies | List         |
| [ListTagsForResource](../../../transcribe/latest/dg/API_ListTagsForResource.md "../../../transcribe/latest/dg/API_ListTagsForResource.md")                              | List tags for a resource                                                                                                                       | Read         |
| [ListTranscriptionJobs](../../../transcribe/latest/dg/API_ListTranscriptionJobs.md "../../../transcribe/latest/dg/API_ListTranscriptionJobs.md")                        | List transcription jobs with the specified status                                                                                              | List         |
| [ListVocabularies](../../../transcribe/latest/dg/API_ListVocabularies.md "../../../transcribe/latest/dg/API_ListVocabularies.md")                                       | Return a list of vocabularies that match the specified criteria. If no criteria are specified, returns the entire list of vocabularies         | List         |
| [ListVocabularyFilters](../../../transcribe/latest/dg/API_ListVocabularyFilters.md "../../../transcribe/latest/dg/API_ListVocabularyFilters.md")                        | Return a list of vocabulary filters that match the specified criteria. If no criteria are specified, returns the at most 5 vocabulary filters  | List         |
