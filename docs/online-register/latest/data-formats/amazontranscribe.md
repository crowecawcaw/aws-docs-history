

# Data retrieval APIs for Amazon Transcribe
<a name="amazontranscribe"></a>

Amazon Transcribe provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="transcribe-DescribeLanguageModel"></a>[DescribeLanguageModel](https://docs.aws.amazon.com/transcribe/latest/dg/API_DescribeLanguageModel.html) | Return information about a custom language model | Read | 
| <a name="transcribe-GetCallAnalyticsCategory"></a>[GetCallAnalyticsCategory](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetCallAnalyticsCategory.html) | Retrieve information about a call analytics category | Read | 
| <a name="transcribe-GetCallAnalyticsJob"></a>[GetCallAnalyticsJob](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetCallAnalyticsJob.html) | Return information about a call analytics job | Read | 
| <a name="transcribe-GetMedicalScribeJob"></a>[GetMedicalScribeJob](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetMedicalScribeJob.html) | Return information about a Medical Scribe job | Read | 
| <a name="transcribe-GetMedicalScribeStream"></a>[GetMedicalScribeStream](https://docs.aws.amazon.com/transcribe/latest/dg/API_streaming_GetMedicalScribeStream.html) | Get information about the specified AWS HealthScribe streaming session | Read | 
| <a name="transcribe-GetMedicalTranscriptionJob"></a>[GetMedicalTranscriptionJob](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetMedicalTranscriptionJob.html) | Return information about a medical transcription job | Read | 
| <a name="transcribe-GetMedicalVocabulary"></a>[GetMedicalVocabulary](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetMedicalVocabulary.html) | Get information about a medical vocabulary | Read | 
| <a name="transcribe-GetTranscriptionJob"></a>[GetTranscriptionJob](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetTranscriptionJob.html) | Return information about a transcription job | Read | 
| <a name="transcribe-GetVocabulary"></a>[GetVocabulary](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetVocabulary.html) | To get information about a vocabulary | Read | 
| <a name="transcribe-GetVocabularyFilter"></a>[GetVocabularyFilter](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetVocabularyFilter.html) | Get information about a vocabulary filter | Read | 
| <a name="transcribe-ListCallAnalyticsCategories"></a>[ListCallAnalyticsCategories](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListCallAnalyticsCategories.html) | List call analytics categories that has been created | List | 
| <a name="transcribe-ListCallAnalyticsJobs"></a>[ListCallAnalyticsJobs](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListCallAnalyticsJobs.html) | List call analytics jobs with the specified status | List | 
| <a name="transcribe-ListLanguageModels"></a>[ListLanguageModels](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListLanguageModels.html) | List custom language models | List | 
| <a name="transcribe-ListMedicalScribeJobs"></a>[ListMedicalScribeJobs](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListMedicalScribeJobs.html) | List Medical Scribe jobs with the specified status | List | 
| <a name="transcribe-ListMedicalTranscriptionJobs"></a>[ListMedicalTranscriptionJobs](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListMedicalTranscriptionJobs.html) | List medical transcription jobs with the specified status | List | 
| <a name="transcribe-ListMedicalVocabularies"></a>[ListMedicalVocabularies](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListMedicalVocabularies.html) | Return a list of medical vocabularies that match the specified criteria. If no criteria are specified, returns the entire list of vocabularies | List | 
| <a name="transcribe-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListTagsForResource.html) | List tags for a resource | Read | 
| <a name="transcribe-ListTranscriptionJobs"></a>[ListTranscriptionJobs](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListTranscriptionJobs.html) | List transcription jobs with the specified status | List | 
| <a name="transcribe-ListVocabularies"></a>[ListVocabularies](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListVocabularies.html) | Return a list of vocabularies that match the specified criteria. If no criteria are specified, returns the entire list of vocabularies | List | 
| <a name="transcribe-ListVocabularyFilters"></a>[ListVocabularyFilters](https://docs.aws.amazon.com/transcribe/latest/dg/API_ListVocabularyFilters.html) | Return a list of vocabulary filters that match the specified criteria. If no criteria are specified, returns the at most 5 vocabulary filters | List |
