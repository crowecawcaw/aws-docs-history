# Data retrieval APIs for AWS Marketplace Entitlement Service

AWS Marketplace Entitlement Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                    | Description                                                                                                                     | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetEntitlements](../../../marketplaceentitlement/latest/APIReference/API_GetEntitlements.md "../../../marketplaceentitlement/latest/APIReference/API_GetEntitlements.md") | Retrieve entitlement values for a given product. The results can be filtered based on customer identifier or product dimensions | Read         |
