# Data retrieval APIs for Amazon Lookout for Vision

Amazon Lookout for Vision provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                          | Description                                                      | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- | ------------ |
| [DescribeDataset](../../../lookout-for-vision/latest/APIReference/API_DescribeDataset.md "../../../lookout-for-vision/latest/APIReference/API_DescribeDataset.md")                               | Show detailed information about dataset manifest                 | Read         |
| [DescribeModel](../../../lookout-for-vision/latest/APIReference/API_DescribeModel.md "../../../lookout-for-vision/latest/APIReference/API_DescribeModel.md")                                     | Show detailed information about a model                          | Read         |
| [DescribeModelPackagingJob](../../../lookout-for-vision/latest/APIReference/API_DescribeModelPackagingJob.md "../../../lookout-for-vision/latest/APIReference/API_DescribeModelPackagingJob.md") | Show detailed information about a model packaging job            | Read         |
| [DescribeProject](../../../lookout-for-vision/latest/APIReference/API_DescribeProject.md "../../../lookout-for-vision/latest/APIReference/API_DescribeProject.md")                               | Show detailed information about a project                        | Read         |
| [DescribeTrialDetection](../../../lookout-for-vision/latest/developer-guide/trial-detection.md "../../../lookout-for-vision/latest/developer-guide/trial-detection.md")                          | Provides state information about a running anomaly detection job | Read         |
| [ListDatasetEntries](../../../lookout-for-vision/latest/APIReference/API_ListDatasetEntries.md "../../../lookout-for-vision/latest/APIReference/API_ListDatasetEntries.md")                      | List the contents of dataset manifest                            | Read         |
| [ListModelPackagingJobs](../../../lookout-for-vision/latest/APIReference/API_ListModelPackagingJobs.md "../../../lookout-for-vision/latest/APIReference/API_ListModelPackagingJobs.md")          | List all model packaging jobs associated with a project          | List         |
| [ListModels](../../../lookout-for-vision/latest/APIReference/API_ListModels.md "../../../lookout-for-vision/latest/APIReference/API_ListModels.md")                                              | List all models associated with a project                        | List         |
| [ListProjects](../../../lookout-for-vision/latest/APIReference/API_ListProjects.md "../../../lookout-for-vision/latest/APIReference/API_ListProjects.md")                                        | List all projects                                                | List         |
| [ListTagsForResource](../../../lookout-for-vision/latest/APIReference/API_ListTagsForResource.md "../../../lookout-for-vision/latest/APIReference/API_ListTagsForResource.md")                   | List tags for a resource                                         | Read         |
| [ListTrialDetections](../../../lookout-for-vision/latest/developer-guide/trial-detection.md "../../../lookout-for-vision/latest/developer-guide/trial-detection.md")                             | List all anomaly detection jobs                                  | List         |
