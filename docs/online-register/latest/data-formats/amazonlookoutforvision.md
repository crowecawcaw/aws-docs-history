

# Data retrieval APIs for Amazon Lookout for Vision
<a name="amazonlookoutforvision"></a>

Amazon Lookout for Vision provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="lookoutvision-DescribeDataset"></a>[DescribeDataset](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_DescribeDataset.html) | Show detailed information about dataset manifest | Read | 
| <a name="lookoutvision-DescribeModel"></a>[DescribeModel](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_DescribeModel.html) | Show detailed information about a model | Read | 
| <a name="lookoutvision-DescribeModelPackagingJob"></a>[DescribeModelPackagingJob](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_DescribeModelPackagingJob.html) | Show detailed information about a model packaging job | Read | 
| <a name="lookoutvision-DescribeProject"></a>[DescribeProject](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_DescribeProject.html) | Show detailed information about a project | Read | 
| <a name="lookoutvision-DescribeTrialDetection"></a>[DescribeTrialDetection](https://docs.aws.amazon.com/lookout-for-vision/latest/developer-guide/trial-detection.html) | Provides state information about a running anomaly detection job | Read | 
| <a name="lookoutvision-ListDatasetEntries"></a>[ListDatasetEntries](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_ListDatasetEntries.html) | List the contents of dataset manifest | Read | 
| <a name="lookoutvision-ListModelPackagingJobs"></a>[ListModelPackagingJobs](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_ListModelPackagingJobs.html) | List all model packaging jobs associated with a project | List | 
| <a name="lookoutvision-ListModels"></a>[ListModels](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_ListModels.html) | List all models associated with a project | List | 
| <a name="lookoutvision-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_ListProjects.html) | List all projects | List | 
| <a name="lookoutvision-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/lookout-for-vision/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read | 
| <a name="lookoutvision-ListTrialDetections"></a>[ListTrialDetections](https://docs.aws.amazon.com/lookout-for-vision/latest/developer-guide/trial-detection.html) | List all anomaly detection jobs | List |
