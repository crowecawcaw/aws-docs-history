# Data retrieval APIs for AWS rePost Private

AWS rePost Private provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                                                          | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ |
| [GetChannel](../../../repostprivate/latest/APIReference/API_GetChannel.md "../../../repostprivate/latest/APIReference/API_GetChannel.md")                            | Get the description for a channel in private re:Post in your account | Read         |
| [GetSpace](../../../repostprivate/latest/APIReference/API_GetSpace.md "../../../repostprivate/latest/APIReference/API_GetSpace.md")                                  | Get the description for a private re:Post in your account            | Read         |
| [ListChannels](../../../repostprivate/latest/APIReference/API_ListChannels.md "../../../repostprivate/latest/APIReference/API_ListChannels.md")                      | List all channels in a private re:Post in your account               | Read         |
| [ListSpaces](API_ListSpaces.md "API_ListSpaces.md")                                                                                                                  | List all private re:Posts in your account                            | Read         |
| [ListTagsForResource](../../../repostprivate/latest/APIReference/API_ListTagsForResource.md "../../../repostprivate/latest/APIReference/API_ListTagsForResource.md") | List the tags associated with a resource                             | Read         |
