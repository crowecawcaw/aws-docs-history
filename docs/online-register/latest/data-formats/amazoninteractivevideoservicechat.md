# Data retrieval APIs for Amazon Interactive Video Service Chat

Amazon Interactive Video Service Chat provides the following APIs for data retrieval.

| Actions                                                                                                                                                                    | Description                                                             | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------ |
| [GetLoggingConfiguration](../../../ivs/latest/ChatAPIReference/API_GetLoggingConfiguration.md "../../../ivs/latest/ChatAPIReference/API_GetLoggingConfiguration.md")       | Get the logging configuration for a specified logging configuration ARN | Read         |
| [GetRoom](../../../ivs/latest/ChatAPIReference/API_GetRoom.md "../../../ivs/latest/ChatAPIReference/API_GetRoom.md")                                                       | Get the room configuration for a specified room ARN                     | Read         |
| [ListLoggingConfigurations](../../../ivs/latest/ChatAPIReference/API_ListLoggingConfigurations.md "../../../ivs/latest/ChatAPIReference/API_ListLoggingConfigurations.md") | Get summary information about logging configurations                    | List         |
| [ListRooms](../../../ivs/latest/ChatAPIReference/API_ListRooms.md "../../../ivs/latest/ChatAPIReference/API_ListRooms.md")                                                 | Get summary information about rooms                                     | List         |
| [ListTagsForResource](../../../ivs/latest/ChatAPIReference/API_ListTagsForResource.md "../../../ivs/latest/ChatAPIReference/API_ListTagsForResource.md")                   | Get information about the tags for a specified ARN                      | Read         |
