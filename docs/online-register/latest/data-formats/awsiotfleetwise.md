AWS IoT FleetWise provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                 | Description                                                           | Access level |

| [GetDecoderManifest](../../../iot-fleetwise/latest/APIReference/API_GetDecoderManifest.md "../../../iot-fleetwise/latest/APIReference/API_GetDecoderManifest.md")                                                       | Get summary information for a given decoder manifest definition       | Read         |
| [GetEncryptionConfiguration](../../../iot-fleetwise/latest/APIReference/API_GetEncryptionConfiguration.md "../../../iot-fleetwise/latest/APIReference/API_GetEncryptionConfiguration.md")                               | Get KMS-based encryption status for the AWS account                   | Read         |
| [GetFleet](../../../iot-fleetwise/latest/APIReference/API_GetFleet.md "../../../iot-fleetwise/latest/APIReference/API_GetFleet.md")                                                                                     | Get summary information for a fleet                                   | Read         |
| [GetLoggingOptions](../../../iot-fleetwise/latest/APIReference/API_GetLoggingOptions.md "../../../iot-fleetwise/latest/APIReference/API_GetLoggingOptions.md")                                                          | Get the logging options for the AWS account                           | Read         |
| [GetModelManifest](../../../iot-fleetwise/latest/APIReference/API_GetModelManifest.md "../../../iot-fleetwise/latest/APIReference/API_GetModelManifest.md")                                                             | Get summary information for a given model manifest definition         | Read         |
| [GetRegisterAccountStatus](../../../iot-fleetwise/latest/APIReference/API_GetRegisterAccountStatus.md "../../../iot-fleetwise/latest/APIReference/API_GetRegisterAccountStatus.md")                                     | Get the account registration status with IoT FleetWise                | Read         |
| [GetSignalCatalog](../../../iot-fleetwise/latest/APIReference/API_GetSignalCatalog.md "../../../iot-fleetwise/latest/APIReference/API_GetSignalCatalog.md")                                                             | Get summary information for a specific signal catalog                 | Read         |
| [GetStateTemplate](../../../iot-fleetwise/latest/APIReference/API_GetStateTemplate.md "../../../iot-fleetwise/latest/APIReference/API_GetStateTemplate.md")                                                             | Get summary information for a given state template                    | Read         |
| [GetVehicle](../../../iot-fleetwise/latest/APIReference/API_GetVehicle.md "../../../iot-fleetwise/latest/APIReference/API_GetVehicle.md")                                                                               | Get summary information for a vehicle                                 | Read         |
| [GetVehicleStatus](../../../iot-fleetwise/latest/APIReference/API_GetVehicleStatus.md "../../../iot-fleetwise/latest/APIReference/API_GetVehicleStatus.md")                                                             | Get the status of the campaigns running on a specific vehicle         | Read         |
