# Data retrieval APIs for AWS Directory Service

AWS Directory Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                               | Description                                                                                                                                                                                                                                                                                        | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [CheckAlias](../../../directoryservice/latest/admin-guide/UsingWithDS_IAM_ResourcePermissions.md "../../../directoryservice/latest/admin-guide/UsingWithDS_IAM_ResourcePermissions.md")                               | Verify that the alias is available for use                                                                                                                                                                                                                                                         | Read         |
| [DescribeADAssessment](../../../directoryservice/latest/devguide/API_DescribeADAssessment.md "../../../directoryservice/latest/devguide/API_DescribeADAssessment.md")                                                 | Describe a directory assessment                                                                                                                                                                                                                                                                    | Read         |

| [DescribeCertificate](../../../directoryservice/latest/devguide/API_DescribeCertificate.md "../../../directoryservice/latest/devguide/API_DescribeCertificate.md")                                                    | Display information about the certificate registered for a secured LDAP connection                                                                                                                                                                                                                 | Read         |
| [DescribeClientAuthenticationSettings](../../../directoryservice/latest/devguide/API_DescribeClientAuthenticationSettings.md "../../../directoryservice/latest/devguide/API_DescribeClientAuthenticationSettings.md") | Retrieve information about the type of client authentication for the specified directory, if the type is specified. If no type is specified, information about all client authentication types that are supported for the specified directory is retrieved. Currently, only SmartCard is supported | Read         |
| [DescribeConditionalForwarders](../../../directoryservice/latest/devguide/API_DescribeConditionalForwarders.md "../../../directoryservice/latest/devguide/API_DescribeConditionalForwarders.md")                      | Obtain information about the conditional forwarders for this account                                                                                                                                                                                                                               | Read         |
| [DescribeDirectories](../../../directoryservice/latest/devguide/API_DescribeDirectories.md "../../../directoryservice/latest/devguide/API_DescribeDirectories.md")                                                    | Obtain information about the directories that belong to this account                                                                                                                                                                                                                               | List         |

| [DescribeDomainControllers](../../../directoryservice/latest/devguide/API_DescribeDomainControllers.md "../../../directoryservice/latest/devguide/API_DescribeDomainControllers.md")                                  | Provide information about any domain controllers in your directory                                                                                                                                                                                                                                 | Read         |

| [DescribeRegions](../../../directoryservice/latest/devguide/API_DescribeRegions.md "../../../directoryservice/latest/devguide/API_DescribeRegions.md")                                                                | Provide information about the Regions that are configured for multi-Region replication                                                                                                                                                                                                             | Read         |
