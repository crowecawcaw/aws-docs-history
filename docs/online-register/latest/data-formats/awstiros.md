# Data retrieval APIs for AWS Tiros

AWS Tiros provides the following APIs for data retrieval.

| Actions                                                                                                                                                                            | Description                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ------------ |
| [GetQueryAnswer](../../../vpc/latest/reachability/security_iam_required-API-permissions.md "../../../vpc/latest/reachability/security_iam_required-API-permissions.md")            | Get VPC reachability query answers                | Read         |
| [GetQueryExplanation](../../../vpc/latest/reachability/security_iam_required-API-permissions.md "../../../vpc/latest/reachability/security_iam_required-API-permissions.md")       | Get VPC reachability query explanations           | Read         |
| [GetQueryExtensionAccounts](../../../vpc/latest/reachability/security_iam_required-API-permissions.md "../../../vpc/latest/reachability/security_iam_required-API-permissions.md") | List accounts that might be useful in a new query | Read         |
