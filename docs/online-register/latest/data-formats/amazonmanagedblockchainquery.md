

# Data retrieval APIs for Amazon Managed Blockchain Query
<a name="amazonmanagedblockchainquery"></a>

Amazon Managed Blockchain Query provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="managedblockchain-query-BatchGetTokenBalance"></a>[BatchGetTokenBalance](${APIReferenceDocPage}API_BatchGetTokenBalance.html) | Batch calls for GetTokenBalance API | Read | 
| <a name="managedblockchain-query-GetAssetContract"></a>[GetAssetContract](${APIReferenceDocPage}API_GetAssetContract.html) | Fetch information about a contract on the blockchain | Read | 
| <a name="managedblockchain-query-GetTokenBalance"></a>[GetTokenBalance](${APIReferenceDocPage}API_GetTokenBalance.html) | Retrieve balance of a token for an address on the blockchain | Read | 
| <a name="managedblockchain-query-GetTransaction"></a>[GetTransaction](${APIReferenceDocPage}API_GetTransaction.html) | Retrieve a transaction on the blockchain | Read | 
| <a name="managedblockchain-query-ListAssetContracts"></a>[ListAssetContracts](${APIReferenceDocPage}API_ListAssetContracts.html) | Fetch multiple contracts on the blockchain | List | 
| <a name="managedblockchain-query-ListFilteredTransactionEvents"></a>[ListFilteredTransactionEvents](${APIReferenceDocPage}API_ListFilteredTransactionEvents.html) | Retrieve events on the blockchain with additional filters | List | 
| <a name="managedblockchain-query-ListTokenBalances"></a>[ListTokenBalances](${APIReferenceDocPage}API_ListTokenBalances.html) | Retrieve multiple balances on the blockchain | List | 
| <a name="managedblockchain-query-ListTransactionEvents"></a>[ListTransactionEvents](${APIReferenceDocPage}API_ListTransactionEvents.html) | Retrieve events in a transaction on the blockchain | List | 
| <a name="managedblockchain-query-ListTransactions"></a>[ListTransactions](${APIReferenceDocPage}API_ListTransactions.html) | Retrieve a multiple transactions on a blockchain | List |
