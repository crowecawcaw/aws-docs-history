

# Data retrieval APIs for AWS Continuum
<a name="awscontinuum"></a>

AWS Continuum provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="continuum-GetCodeFinding"></a>[GetCodeFinding](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCodeFinding.html) | Get a code finding | Read | 
| <a name="continuum-GetCodeIssue"></a>[GetCodeIssue](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCodeIssue.html) | Get a code issue | Read | 
| <a name="continuum-GetCodeIssueArtifact"></a>[GetCodeIssueArtifact](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCodeIssueArtifact.html) | Get an artifact of a code issue | Read | 
| <a name="continuum-GetCodeScan"></a>[GetCodeScan](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCodeScan.html) | Get a code scan | Read | 
| <a name="continuum-GetCollector"></a>[GetCollector](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCollector.html) | Get a collector | Read | 
| <a name="continuum-GetCollectorDataAccessAuthorization"></a>[GetCollectorDataAccessAuthorization](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetCollectorDataAccessAuthorization.html) | Access the data of a collector from an environment | Read | 
| <a name="continuum-GetEnvironment"></a>[GetEnvironment](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetEnvironment.html) | Get an environment | Read | 
| <a name="continuum-GetIntegration"></a>[GetIntegration](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetIntegration.html) | Get an integration | Read | 
| <a name="continuum-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/continuum/latest/APIReference/API_GetResourcePolicy.html) | Get the resource policy attached to a resource | Read | 
| <a name="continuum-ListAssociatedCollectors"></a>[ListAssociatedCollectors](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListAssociatedCollectors.html) | List the collectors associated with an environment | List | 
| <a name="continuum-ListAssociatedEnvironments"></a>[ListAssociatedEnvironments](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListAssociatedEnvironments.html) | List the environments associated with a collector | List | 
| <a name="continuum-ListCodeFindings"></a>[ListCodeFindings](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListCodeFindings.html) | List the code findings in an environment | List | 
| <a name="continuum-ListCodeIssueArtifacts"></a>[ListCodeIssueArtifacts](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListCodeIssueArtifacts.html) | List the artifacts of a code issue | List | 
| <a name="continuum-ListCodeIssues"></a>[ListCodeIssues](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListCodeIssues.html) | List the code issues in an environment | List | 
| <a name="continuum-ListCodeScans"></a>[ListCodeScans](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListCodeScans.html) | List the code scans of an environment | List | 
| <a name="continuum-ListCollectors"></a>[ListCollectors](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListCollectors.html) | List collectors | List | 
| <a name="continuum-ListEnvironments"></a>[ListEnvironments](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListEnvironments.html) | List environments | List | 
| <a name="continuum-ListIntegrations"></a>[ListIntegrations](https://docs.aws.amazon.com/continuum/latest/APIReference/API_ListIntegrations.html) | List integrations | List |
