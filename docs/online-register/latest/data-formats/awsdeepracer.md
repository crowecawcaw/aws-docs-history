# Data retrieval APIs for AWS DeepRacer

AWS DeepRacer provides the following APIs for data retrieval.

| [AdminGetAccountConfig](../../../deepracer/latest/developerguide/deepracer-admin-set-account-config.md "../../../deepracer/latest/developerguide/deepracer-admin-set-account-config.md")                      | Get current admin multiuser configuration for this account                                                | Read         |
| [AdminListAssociatedResources](../../../deepracer/latest/developerguide/deepracer-admin-list-associated-resources.md "../../../deepracer/latest/developerguide/deepracer-admin-list-associated-resources.md") | List all deepracer users with their associated resources created under this account                       | Read         |
| [AdminListAssociatedUsers](../../../deepracer/latest/developerguide/deepracer-admin-list-associated-users.md "../../../deepracer/latest/developerguide/deepracer-admin-list-associated-users.md")             | List user data for all users associated with this account                                                 | Read         |
| [GetAccountConfig](../../../deepracer/latest/developerguide/deepracer-admin-set-account-config.md "../../../deepracer/latest/developerguide/deepracer-admin-set-account-config.md")                           | Get current multiuser configuration for this account                                                      | Read         |

| [GetCar](../../../deepracer/latest/developerguide/deepracer-choose-race-type.md "../../../deepracer/latest/developerguide/deepracer-choose-race-type.md")                                                     | Retrieve a specific DeepRacer car from your garage                                                        | Read         |
