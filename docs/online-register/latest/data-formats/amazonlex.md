# Data retrieval APIs for Amazon Lex

Amazon Lex provides the following APIs for data retrieval.

| Actions                                                                                                                                        | Description                                                                                                                                            | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [GetBot](../../../lex/latest/dg/API_GetBot.md "../../../lex/latest/dg/API_GetBot.md")                                                          | Returns information for a specific bot. In addition to the bot name, the bot version or alias is required                                              | Read         |
| [GetBotAlias](../../../lex/latest/dg/API_GetBotAlias.md "../../../lex/latest/dg/API_GetBotAlias.md")                                           | Returns information about a Amazon Lex bot alias                                                                                                       | Read         |
| [GetBotAliases](../../../lex/latest/dg/API_GetBotAliases.md "../../../lex/latest/dg/API_GetBotAliases.md")                                     | Returns a list of aliases for a given Amazon Lex bot                                                                                                   | List         |
| [GetBotChannelAssociation](../../../lex/latest/dg/API_GetBotChannelAssociation.md "../../../lex/latest/dg/API_GetBotChannelAssociation.md")    | Returns information about the association between a Amazon Lex bot and a messaging platform                                                            | Read         |
| [GetBotChannelAssociations](../../../lex/latest/dg/API_GetBotChannelAssociations.md "../../../lex/latest/dg/API_GetBotChannelAssociations.md") | Returns a list of all of the channels associated with a single bot                                                                                     | List         |
| [GetBotVersions](../../../lex/latest/dg/API_GetBotVersions.md "../../../lex/latest/dg/API_GetBotVersions.md")                                  | Returns information for all versions of a specific bot                                                                                                 | List         |
| [GetBots](../../../lex/latest/dg/API_GetBots.md "../../../lex/latest/dg/API_GetBots.md")                                                       | Returns information for the $LATEST version of all bots, subject to filters provided by the client                                                     | List         |
| [GetBuiltinIntent](../../../lex/latest/dg/API_GetBuiltinIntent.md "../../../lex/latest/dg/API_GetBuiltinIntent.md")                            | Returns information about a built-in intent                                                                                                            | Read         |
| [GetBuiltinIntents](../../../lex/latest/dg/API_GetBuiltinIntents.md "../../../lex/latest/dg/API_GetBuiltinIntents.md")                         | Gets a list of built-in intents that meet the specified criteria                                                                                       | Read         |
| [GetBuiltinSlotTypes](../../../lex/latest/dg/API_GetBuiltinSlotTypes.md "../../../lex/latest/dg/API_GetBuiltinSlotTypes.md")                   | Gets a list of built-in slot types that meet the specified criteria                                                                                    | Read         |
| [GetExport](../../../lex/latest/dg/API_GetExport.md "../../../lex/latest/dg/API_GetExport.md")                                                 | Exports Amazon Lex Resource in a requested format                                                                                                      | Read         |
| [GetImport](../../../lex/latest/dg/API_GetImport.md "../../../lex/latest/dg/API_GetImport.md")                                                 | Gets information about an import job started with StartImport                                                                                          | Read         |
| [GetIntent](../../../lex/latest/dg/API_GetIntent.md "../../../lex/latest/dg/API_GetIntent.md")                                                 | Returns information for a specific intent. In addition to the intent name, you must also specify the intent version                                    | Read         |
| [GetIntentVersions](../../../lex/latest/dg/API_GetIntentVersions.md "../../../lex/latest/dg/API_GetIntentVersions.md")                         | Returns information for all versions of a specific intent                                                                                              | List         |
| [GetIntents](../../../lex/latest/dg/API_GetIntents.md "../../../lex/latest/dg/API_GetIntents.md")                                              | Returns information for the $LATEST version of all intents, subject to filters provided by the client                                                  | List         |
| [GetMigration](../../../lex/latest/dg/API_GetMigration.md "../../../lex/latest/dg/API_GetMigration.md")                                        | View an ongoing or completed migration                                                                                                                 | Read         |
| [GetMigrations](../../../lex/latest/dg/API_GetMigrations.md "../../../lex/latest/dg/API_GetMigrations.md")                                     | View list of migrations from Amazon Lex v1 to Amazon Lex v2                                                                                            | List         |
| [GetSession](../../../lex/latest/dg/API_runtime_GetSession.md "../../../lex/latest/dg/API_runtime_GetSession.md")                              | Returns session information for a specified bot, alias, and user ID                                                                                    | Read         |
| [GetSlotType](../../../lex/latest/dg/API_GetSlotType.md "../../../lex/latest/dg/API_GetSlotType.md")                                           | Returns information about a specific version of a slot type. In addition to specifying the slot type name, you must also specify the slot type version | Read         |
| [GetSlotTypeVersions](../../../lex/latest/dg/API_GetSlotTypeVersions.md "../../../lex/latest/dg/API_GetSlotTypeVersions.md")                   | Returns information for all versions of a specific slot type                                                                                           | List         |
| [GetSlotTypes](../../../lex/latest/dg/API_GetSlotTypes.md "../../../lex/latest/dg/API_GetSlotTypes.md")                                        | Returns information for the $LATEST version of all slot types, subject to filters provided by the client                                               | List         |
| [GetUtterancesView](../../../lex/latest/dg/API_GetUtterancesView.md "../../../lex/latest/dg/API_GetUtterancesView.md")                         | Returns a view of aggregate utterance data for versions of a bot for a recent time period                                                              | List         |
| [ListTagsForResource](../../../lex/latest/dg/API_ListTagsForResource.md "../../../lex/latest/dg/API_ListTagsForResource.md")                   | Lists tags for a Lex resource                                                                                                                          | Read         |
