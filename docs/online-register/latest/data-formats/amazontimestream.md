

# Data retrieval APIs for Amazon Timestream
<a name="amazontimestream"></a>

Amazon Timestream provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="timestream-DescribeAccountSettings"></a>[DescribeAccountSettings](https://docs.aws.amazon.com/timestream/latest/developerguide/API_query_DescribeAccountSettings.html) | Describe your account settings | Read | 
| <a name="timestream-DescribeBatchLoadTask"></a>[DescribeBatchLoadTask](https://docs.aws.amazon.com/timestream/latest/developerguide/API_DescribeBatchLoadTask.html) | Describe a batch load task in your account | Read | 
| <a name="timestream-DescribeDatabase"></a>[DescribeDatabase](https://docs.aws.amazon.com/timestream/latest/developerguide/API_DescribeDatabase.html) | Describe a database in your account | Read | 
| <a name="timestream-DescribeEndpoints"></a>[DescribeEndpoints](https://docs.aws.amazon.com/timestream/latest/developerguide/API_DescribeEndpoints.html) | Describe timestream endpoints | List | 
| <a name="timestream-DescribeScheduledQuery"></a>[DescribeScheduledQuery](https://docs.aws.amazon.com/timestream/latest/developerguide/API_DescribeScheduledQuery.html) | Describe a scheduled query in your account | Read | 
| <a name="timestream-DescribeTable"></a>[DescribeTable](https://docs.aws.amazon.com/timestream/latest/developerguide/API_DescribeTable.html) | Describe a table in your account | Read | 
| <a name="timestream-GetAwsBackupStatus"></a>[GetAwsBackupStatus](https://docs.aws.amazon.com/timestream/latest/developerguide/backups.html) | Get Status of a Timestream Table Backup | Read | 
| <a name="timestream-GetAwsRestoreStatus"></a>[GetAwsRestoreStatus](https://docs.aws.amazon.com/timestream/latest/developerguide/backups.html) | Get Status of a Timestream Table Restore | Read | 
| <a name="timestream-ListBatchLoadTasks"></a>[ListBatchLoadTasks](https://docs.aws.amazon.com/timestream/latest/developerguide/API_ListBatchLoadTasks.html) | List batch load tasks in your account | List | 
| <a name="timestream-ListDatabases"></a>[ListDatabases](https://docs.aws.amazon.com/timestream/latest/developerguide/API_ListDatabases.html) | List databases in your account | List | 
| <a name="timestream-ListMeasures"></a>[ListMeasures](https://docs.aws.amazon.com/timestream/latest/developerguide/API_query_Query.html) | List measures of a table in your account | List | 
| <a name="timestream-ListScheduledQueries"></a>[ListScheduledQueries](https://docs.aws.amazon.com/timestream/latest/developerguide/API_ListScheduledQueries.html) | List scheduled queries in your account | List | 
| <a name="timestream-ListTables"></a>[ListTables](https://docs.aws.amazon.com/timestream/latest/developerguide/API_ListTables.html) | List tables in your account | List | 
| <a name="timestream-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/timestream/latest/developerguide/API_ListTagsForResource.html) | List tags of a resource in your account | Read | 
| <a name="timestream-PrepareQuery"></a>[PrepareQuery](https://docs.aws.amazon.com/timestream/latest/developerguide/API_query_PrepareQuery.html) | Issue prepare queries | Read | 
| <a name="timestream-Select"></a>[Select](https://docs.aws.amazon.com/timestream/latest/developerguide/API_query_Query.html) | Issue 'select from table' queries | Read | 
| <a name="timestream-SelectValues"></a>[SelectValues](https://docs.aws.amazon.com/timestream/latest/developerguide/API_query_Query.html) | Issue 'select 1' queries | Read |
