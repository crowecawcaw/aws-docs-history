# Data retrieval APIs for Amazon DynamoDB

Amazon DynamoDB provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                              | Description                                                                                                                                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetItem](../../../amazondynamodb/latest/APIReference/API_BatchGetItem.md "../../../amazondynamodb/latest/APIReference/API_BatchGetItem.md")                                                                                    | Return the attributes of one or more items from one or more tables                                                                                                                 | Read         |
| [ConditionCheckItem](../../../amazondynamodb/latest/APIReference/API_ConditionCheck.md "../../../amazondynamodb/latest/APIReference/API_ConditionCheck.md")                                                                          | The ConditionCheckItem operation checks the existence of a set of attributes for the item with the given primary key                                                               | Read         |
| [DescribeBackup](../../../amazondynamodb/latest/APIReference/API_DescribeBackup.md "../../../amazondynamodb/latest/APIReference/API_DescribeBackup.md")                                                                              | Describe an existing backup of a table                                                                                                                                             | Read         |
| [DescribeContinuousBackups](../../../amazondynamodb/latest/APIReference/API_DescribeContinuousBackups.md "../../../amazondynamodb/latest/APIReference/API_DescribeContinuousBackups.md")                                             | Check the status of the backup restore settings on the specified table                                                                                                             | Read         |
| [DescribeContributorInsights](../../../amazondynamodb/latest/APIReference/API_DescribeContributorInsights.md "../../../amazondynamodb/latest/APIReference/API_DescribeContributorInsights.md")                                       | Describe the contributor insights status and related details for a given table or global secondary index                                                                           | Read         |
| [DescribeEndpoints](../../../amazondynamodb/latest/APIReference/API_DescribeEndpoints.md "../../../amazondynamodb/latest/APIReference/API_DescribeEndpoints.md")                                                                     | Return the regional endpoint information                                                                                                                                           | Read         |
| [DescribeExport](../../../amazondynamodb/latest/APIReference/API_DescribeExport.md "../../../amazondynamodb/latest/APIReference/API_DescribeExport.md")                                                                              | Describe an existing Export of a table                                                                                                                                             | Read         |
| [DescribeGlobalTable](../../../amazondynamodb/latest/APIReference/API_DescribeGlobalTable.md "../../../amazondynamodb/latest/APIReference/API_DescribeGlobalTable.md")                                                               | Return information about the specified global table                                                                                                                                | Read         |
| [DescribeGlobalTableSettings](../../../amazondynamodb/latest/APIReference/API_DescribeGlobalTableSettings.md "../../../amazondynamodb/latest/APIReference/API_DescribeGlobalTableSettings.md")                                       | Return settings information about the specified global table                                                                                                                       | Read         |
| [DescribeImport](../../../amazondynamodb/latest/APIReference/API_DescribeImport.md "../../../amazondynamodb/latest/APIReference/API_DescribeImport.md")                                                                              | Describe an existing import                                                                                                                                                        | Read         |
| [DescribeKinesisStreamingDestination](../../../amazondynamodb/latest/APIReference/API_DescribeKinesisStreamingDestination.md "../../../amazondynamodb/latest/APIReference/API_DescribeKinesisStreamingDestination.md")               | Grant permission to describe the status of Kinesis streaming and related details for a given table                                                                                 | Read         |
| [DescribeLimits](../../../amazondynamodb/latest/APIReference/API_DescribeLimits.md "../../../amazondynamodb/latest/APIReference/API_DescribeLimits.md")                                                                              | Return the current provisioned-capacity limits for your AWS account in a region, both for the region as a whole and for any one DynamoDB table that you create there               | Read         |
| [DescribeReservedCapacity](../../../amazondynamodb/latest/developerguide/iam-policy-prevent-purchase-reserved-capacity.md "../../../amazondynamodb/latest/developerguide/iam-policy-prevent-purchase-reserved-capacity.md")          | Describe one or more of the Reserved Capacity purchased                                                                                                                            | Read         |
| [DescribeReservedCapacityOfferings](../../../amazondynamodb/latest/developerguide/iam-policy-prevent-purchase-reserved-capacity.md "../../../amazondynamodb/latest/developerguide/iam-policy-prevent-purchase-reserved-capacity.md") | Describe Reserved Capacity offerings that are available for purchase                                                                                                               | Read         |
| [DescribeStream](../../../amazondynamodb/latest/APIReference/API_streams_DescribeStream.md "../../../amazondynamodb/latest/APIReference/API_streams_DescribeStream.md")                                                              | Return information about a stream, including the current status of the stream, its Amazon Resource Name (ARN), the composition of its shards, and its corresponding DynamoDB table | Read         |
| [DescribeTable](../../../amazondynamodb/latest/APIReference/API_DescribeTable.md "../../../amazondynamodb/latest/APIReference/API_DescribeTable.md")                                                                                 | Return information about the table                                                                                                                                                 | Read         |
| [DescribeTableReplicaAutoScaling](../../../amazondynamodb/latest/APIReference/API_DescribeTableReplicaAutoScaling.md "../../../amazondynamodb/latest/APIReference/API_DescribeTableReplicaAutoScaling.md")                           | Describe the auto scaling settings across all replicas of the global table                                                                                                         | Read         |
| [DescribeTimeToLive](../../../amazondynamodb/latest/APIReference/API_DescribeTimeToLive.md "../../../amazondynamodb/latest/APIReference/API_DescribeTimeToLive.md")                                                                  | Give a description of the Time to Live (TTL) status on the specified table                                                                                                         | Read         |
| [GetAbacStatus](../../../amazondynamodb/latest/developerguide/abac-enable-ddb.md "../../../amazondynamodb/latest/developerguide/abac-enable-ddb.md")                                                                                 | View the status of Attribute Based Access Control for the account                                                                                                                  | Read         |
| [GetItem](../../../amazondynamodb/latest/APIReference/API_GetItem.md "../../../amazondynamodb/latest/APIReference/API_GetItem.md")                                                                                                   | The GetItem operation that returns a set of attributes for the item with the given primary key                                                                                     | Read         |
| [GetRecords](../../../amazondynamodb/latest/APIReference/API_streams_GetRecords.md "../../../amazondynamodb/latest/APIReference/API_streams_GetRecords.md")                                                                          | Retrieve the stream records from a given shard                                                                                                                                     | Read         |
| [GetResourcePolicy](../../../amazondynamodb/latest/APIReference/API_GetResourcePolicy.md "../../../amazondynamodb/latest/APIReference/API_GetResourcePolicy.md")                                                                     | View a resource-based policy for a resource                                                                                                                                        | Read         |
| [GetShardIterator](../../../amazondynamodb/latest/APIReference/API_streams_GetShardIterator.md "../../../amazondynamodb/latest/APIReference/API_streams_GetShardIterator.md")                                                        | Return a shard iterator                                                                                                                                                            | Read         |
| [ListBackups](../../../amazondynamodb/latest/APIReference/API_ListBackups.md "../../../amazondynamodb/latest/APIReference/API_ListBackups.md")                                                                                       | List backups associated with the account and endpoint                                                                                                                              | List         |
| [ListContributorInsights](../../../amazondynamodb/latest/APIReference/API_ListContributorInsights.md "../../../amazondynamodb/latest/APIReference/API_ListContributorInsights.md")                                                   | List the ContributorInsightsSummary for all tables and global secondary indexes associated with the current account and endpoint                                                   | List         |
| [ListExports](../../../amazondynamodb/latest/APIReference/API_ListExports.md "../../../amazondynamodb/latest/APIReference/API_ListExports.md")                                                                                       | List exports associated with the account and endpoint                                                                                                                              | List         |
| [ListGlobalTables](../../../amazondynamodb/latest/APIReference/API_ListGlobalTables.md "../../../amazondynamodb/latest/APIReference/API_ListGlobalTables.md")                                                                        | List all global tables that have a replica in the specified region                                                                                                                 | List         |
| [ListImports](../../../amazondynamodb/latest/APIReference/API_ListImports.md "../../../amazondynamodb/latest/APIReference/API_ListImports.md")                                                                                       | List imports associated with the account and endpoint                                                                                                                              | List         |
| [ListStreams](../../../amazondynamodb/latest/APIReference/API_streams_ListStreams.md "../../../amazondynamodb/latest/APIReference/API_streams_ListStreams.md")                                                                       | Return an array of stream ARNs associated with the current account and endpoint                                                                                                    | Read         |
| [ListTables](../../../amazondynamodb/latest/APIReference/API_ListTables.md "../../../amazondynamodb/latest/APIReference/API_ListTables.md")                                                                                          | Return an array of table names associated with the current account and endpoint                                                                                                    | List         |
| [ListTagsOfResource](../../../amazondynamodb/latest/APIReference/API_ListTagsOfResource.md "../../../amazondynamodb/latest/APIReference/API_ListTagsOfResource.md")                                                                  | List all tags on an Amazon DynamoDB resource                                                                                                                                       | Read         |
| [PartiQLSelect](../../../amazondynamodb/latest/APIReference/API_ExecuteStatement.md "../../../amazondynamodb/latest/APIReference/API_ExecuteStatement.md")                                                                           | Read a set of attributes for items from a table or index                                                                                                                           | Read         |
| [Query](../../../amazondynamodb/latest/APIReference/API_Query.md "../../../amazondynamodb/latest/APIReference/API_Query.md")                                                                                                         | Use the primary key of a table or a secondary index to directly access items from that table or index                                                                              | Read         |
| [ReadDataForReplication](../../../amazondynamodb/latest/developerguide/globaltables_MA_security.md "../../../amazondynamodb/latest/developerguide/globaltables_MA_security.md")                                                      | Read data from a multi account global table replica                                                                                                                                | Read         |
| [Scan](../../../amazondynamodb/latest/APIReference/API_Scan.md "../../../amazondynamodb/latest/APIReference/API_Scan.md")                                                                                                            | Return one or more items and item attributes by accessing every item in a table or a secondary index                                                                               | Read         |
