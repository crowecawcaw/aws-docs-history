

# Data retrieval APIs for Amazon Comprehend Medical
<a name="amazoncomprehendmedical"></a>

Amazon Comprehend Medical provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- |

| <a name="comprehendmedical-DescribeICD10CMInferenceJob"></a>[DescribeICD10CMInferenceJob](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DescribeICD10CMInferenceJob.html) | Describe the properties of an ICD-10-CM linking job that you have submitted | Read | 
| <a name="comprehendmedical-DescribePHIDetectionJob"></a>[DescribePHIDetectionJob](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DescribePHIDetectionJob.html) | Describe the properties of a PHI entity detection job that you have submitted | Read | 
| <a name="comprehendmedical-DescribeRxNormInferenceJob"></a>[DescribeRxNormInferenceJob](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DescribeRxNormInferenceJob.html) | Describe the properties of an RxNorm linking job that you have submitted | Read | 
| <a name="comprehendmedical-DescribeSNOMEDCTInferenceJob"></a>[DescribeSNOMEDCTInferenceJob](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DescribeSNOMEDCTInferenceJob.html) | Describe the properties of a SNOMED-CT linking job that you have submitted | Read | 
| <a name="comprehendmedical-DetectEntitiesV2"></a>[DetectEntitiesV2](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DetectEntitiesV2.html) | Detect the named medical entities, and their relationships and traits within the given text document | Read | 
| <a name="comprehendmedical-DetectPHI"></a>[DetectPHI](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_DetectPHI.html) | Detect the protected health information (PHI) entities within the given text document | Read |

| <a name="comprehendmedical-InferRxNorm"></a>[InferRxNorm](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_InferRxNorm.html) | Detect the medication entities within the given text document and link them to RxCUI concept identifiers from the National Library of Medicine RxNorm database | Read | 
| <a name="comprehendmedical-InferSNOMEDCT"></a>[InferSNOMEDCT](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_InferSNOMEDCT.html) | Detect the medical condition, anatomy, and test, treatment, and procedure entities within the given text document and link them to SNOMED-CT codes | Read | 
| <a name="comprehendmedical-ListEntitiesDetectionV2Jobs"></a>[ListEntitiesDetectionV2Jobs](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_ListEntitiesDetectionV2Jobs.html) | List the medical entity detection jobs that you have submitted | Read | 
| <a name="comprehendmedical-ListICD10CMInferenceJobs"></a>[ListICD10CMInferenceJobs](https://docs.aws.amazon.com/comprehend-medical/latest/api/API_ListICD10CMInferenceJobs.html) | List the ICD-10-CM linking jobs that you have submitted | Read |
