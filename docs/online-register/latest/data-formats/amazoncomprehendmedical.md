| Actions                                                                                                                                                                                       | Description                                                                                                                                                    | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |

| [DescribeICD10CMInferenceJob](../../../comprehend-medical/latest/api/API_DescribeICD10CMInferenceJob.md "../../../comprehend-medical/latest/api/API_DescribeICD10CMInferenceJob.md")          | Describe the properties of an ICD-10-CM linking job that you have submitted                                                                                    | Read         |
| [DescribePHIDetectionJob](../../../comprehend-medical/latest/api/API_DescribePHIDetectionJob.md "../../../comprehend-medical/latest/api/API_DescribePHIDetectionJob.md")                      | Describe the properties of a PHI entity detection job that you have submitted                                                                                  | Read         |
| [DescribeRxNormInferenceJob](../../../comprehend-medical/latest/api/API_DescribeRxNormInferenceJob.md "../../../comprehend-medical/latest/api/API_DescribeRxNormInferenceJob.md")             | Describe the properties of an RxNorm linking job that you have submitted                                                                                       | Read         |
| [DescribeSNOMEDCTInferenceJob](../../../comprehend-medical/latest/api/API_DescribeSNOMEDCTInferenceJob.md "../../../comprehend-medical/latest/api/API_DescribeSNOMEDCTInferenceJob.md")       | Describe the properties of a SNOMED-CT linking job that you have submitted                                                                                     | Read         |
| [DetectEntitiesV2](../../../comprehend-medical/latest/api/API_DetectEntitiesV2.md "../../../comprehend-medical/latest/api/API_DetectEntitiesV2.md")                                           | Detect the named medical entities, and their relationships and traits within the given text document                                                           | Read         |
| [DetectPHI](../../../comprehend-medical/latest/api/API_DetectPHI.md "../../../comprehend-medical/latest/api/API_DetectPHI.md")                                                                | Detect the protected health information (PHI) entities within the given text document                                                                          | Read         |
| [InferICD10CM](../../../comprehend-medical/latest/api/API_InferICD10CM.md "../../../comprehend-medical/latest/api/API_InferICD10CM.md")                                                       | Detect the medical condition entities within the given text document and link them to ICD-10-CM codes                                                          | Read         |
| [InferRxNorm](../../../comprehend-medical/latest/api/API_InferRxNorm.md "../../../comprehend-medical/latest/api/API_InferRxNorm.md")                                                          | Detect the medication entities within the given text document and link them to RxCUI concept identifiers from the National Library of Medicine RxNorm database | Read         |
| [InferSNOMEDCT](../../../comprehend-medical/latest/api/API_InferSNOMEDCT.md "../../../comprehend-medical/latest/api/API_InferSNOMEDCT.md")                                                    | Detect the medical condition, anatomy, and test, treatment, and procedure entities within the given text document and link them to SNOMED-CT codes             | Read         |
| [ListEntitiesDetectionV2Jobs](../../../comprehend-medical/latest/api/API_ListEntitiesDetectionV2Jobs.md "../../../comprehend-medical/latest/api/API_ListEntitiesDetectionV2Jobs.md")          | List the medical entity detection jobs that you have submitted                                                                                                 | Read         |
| [ListICD10CMInferenceJobs](../../../comprehend-medical/latest/api/API_ListICD10CMInferenceJobs.md "../../../comprehend-medical/latest/api/API_ListICD10CMInferenceJobs.md")                   | List the ICD-10-CM linking jobs that you have submitted                                                                                                        | Read         |
| [ListPHIDetectionJobs](../../../comprehend-medical/latest/api/API_ListPHIDetectionJobs.md "../../../comprehend-medical/latest/api/API_ListPHIDetectionJobs.md")                               | List the PHI entity detection jobs that you have submitted                                                                                                     | Read         |
| [ListRxNormInferenceJobs](../../../comprehend-medical/latest/api/API_ListRxNormInferenceJobs.md "../../../comprehend-medical/latest/api/API_ListRxNormInferenceJobs.md")                      | List the RxNorm linking jobs that you have submitted                                                                                                           | Read         |
| [ListSNOMEDCTInferenceJobs](../../../comprehend-medical/latest/api/API_ListSNOMEDCTInferenceJobs.md "../../../comprehend-medical/latest/api/API_ListSNOMEDCTInferenceJobs.md")                | List the SNOMED-CT linking jobs that you have submitted                                                                                                        | Read         |
