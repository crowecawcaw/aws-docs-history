

# Data retrieval APIs for AWS Marketplace
<a name="awsmarketplace"></a>

AWS Marketplace provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aws-marketplace-DescribeAgreement"></a>[DescribeAgreement](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | Describe the metadata about the agreement | Read | 
| <a name="aws-marketplace-GetAgreementApprovalRequest"></a>[GetAgreementApprovalRequest](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View the details of incoming subscription requests (for providers who provide products that require subscription verification) | Read | 
| <a name="aws-marketplace-GetAgreementCancellationRequest"></a>[GetAgreementCancellationRequest](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View the details of an agreement cancellation request | Read | 
| <a name="aws-marketplace-GetAgreementEntitlements"></a>[GetAgreementEntitlements](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | Get the entitlements associated with an agreement | Read | 
| <a name="aws-marketplace-GetAgreementPaymentRequest"></a>[GetAgreementPaymentRequest](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View details for a payment request | Read | 
| <a name="aws-marketplace-GetAgreementRequest"></a>[GetAgreementRequest](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View the details of subscription requests for data products that require subscription verification | Read | 
| <a name="aws-marketplace-GetAgreementTerms"></a>[GetAgreementTerms](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | Get a list of terms for an agreement | List | 
| <a name="aws-marketplace-GetBillingAdjustmentRequest"></a>[GetBillingAdjustmentRequest](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View the details of a billing adjustment request | Read | 
| <a name="aws-marketplace-ListAgreementApprovalRequests"></a>[ListAgreementApprovalRequests](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List incoming subscription requests (for providers who provide products that require subscription verification) | List | 
| <a name="aws-marketplace-ListAgreementCancellationRequests"></a>[ListAgreementCancellationRequests](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List agreement cancellation requests | List | 
| <a name="aws-marketplace-ListAgreementCharges"></a>[ListAgreementCharges](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List charges associated with an agreement | List | 
| <a name="aws-marketplace-ListAgreementInvoiceLineItems"></a>[ListAgreementInvoiceLineItems](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List invoice line items for an agreement | List | 
| <a name="aws-marketplace-ListAgreementPaymentRequests"></a>[ListAgreementPaymentRequests](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List payment requests for an agreement | List | 
| <a name="aws-marketplace-ListAgreementRequests"></a>[ListAgreementRequests](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List subscription requests for products that require subscription verification | List | 
| <a name="aws-marketplace-ListBillingAdjustmentRequests"></a>[ListBillingAdjustmentRequests](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List billing adjustment requests | List | 
| <a name="aws-marketplace-ListEntitlementDetails"></a>[ListEntitlementDetails](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | List details of the entitlements associated with an agreement. Note that this action is not applicable to Marketplace purchases | Read | 
| <a name="aws-marketplace-SearchAgreements"></a>[SearchAgreements](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | Search agreements | List | 
| <a name="aws-marketplace-ViewSubscriptions"></a>[ViewSubscriptions](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-iam-users-groups-policies.html) | View account's subscriptions | List |
