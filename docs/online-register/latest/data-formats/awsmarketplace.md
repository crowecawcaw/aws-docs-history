| Actions                                                                                                                                                                                    | Description                                                                                                                                   | Access level |

| [GetAgreementCancellationRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")   | Users to view the details of an agreement cancellation request                                                                                | Read         |
| [GetAgreementEntitlements](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")          | Users to view the entitlements associated with an agreement                                                                                   | Read         |
| [GetAgreementPaymentRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")        | Users to view details for a payment request                                                                                                   | Read         |
| [GetAgreementRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")               | Users to view the details of their subscription requests for data products that require subscription verification                             | Read         |

| [GetBillingAdjustmentRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")       | Users to view the details of a billing adjustment request                                                                                     | Read         |
| [ListAgreementApprovalRequests](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")     | Users to list their incoming subscription requests (for providers who provide products that require subscription verification)                | List         |
| [ListAgreementCancellationRequests](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md") | Users to list agreement cancellation requests                                                                                                 | List         |
| [ListAgreementCharges](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")              | Users to view charges associated with their agreements                                                                                        | List         |
| [ListAgreementInvoiceLineItems](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")     | Users to list invoice line items for an agreement                                                                                             | List         |
| [ListAgreementPaymentRequests](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")      | Users to list payment requests for an agreement                                                                                               | List         |

Note that this action is not applicable to Marketplace purchases      | Read         |

| [ViewSubscriptions](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")                 | Users to see their account's subscriptions                                                                                                    | List         |
