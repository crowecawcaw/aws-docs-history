# Data retrieval APIs for AWS Marketplace

AWS Marketplace provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                | Description                                                                                                                                   | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAgreement](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")             | Users to describe the metadata about the agreement                                                                                            | Read         |
| [GetAgreementApprovalRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")   | Users to view the details of their incoming subscription requests (for providers who provide products that require subscription verification) | Read         |
| [GetAgreementEntitlements](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")      | Users to view the entitlements associated with an agreement                                                                                   | Read         |
| [GetAgreementRequest](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")           | Users to view the details of their subscription requests for data products that require subscription verification                             | Read         |
| [GetAgreementTerms](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")             | Users to get a list of terms for an agreement                                                                                                 | List         |
| [ListAgreementApprovalRequests](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md") | Users to list their incoming subscription requests (for providers who provide products that require subscription verification)                | List         |
| [ListAgreementCharges](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")          | Users to view charges associated with their agreements                                                                                        | List         |
| [ListAgreementRequests](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")         | Users to list their subscription requests for products that require subscription verification                                                 | List         |
| [ListEntitlementDetails](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")        | Users to view details of the entitlements associated with an agreement. Note that this action is not applicable to Marketplace purchases      | Read         |
| [SearchAgreements](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")              | Users to search their agreements                                                                                                              | List         |
| [ViewSubscriptions](../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md "../../../marketplace/latest/buyerguide/buyer-iam-users-groups-policies.md")             | Users to see their account's subscriptions                                                                                                    | List         |
