# Data retrieval APIs for AWS License Manager User Subscriptions

AWS License Manager User Subscriptions provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                             | Description                                                                     | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------ |
| [ListIdentityProviders](../../../license-manager-user-subscriptions/latest/APIReference/API_ListIdentityProviders.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListIdentityProviders.md")                | List all the identity providers on license manager user subscriptions           | List         |
| [ListInstances](../../../license-manager-user-subscriptions/latest/APIReference/API_ListInstances.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListInstances.md")                                        | List all the instances launched with license manager user subscription products | List         |
| [ListLicenseServerEndpoints](../../../license-manager-user-subscriptions/latest/APIReference/API_ListLicenseServerEndpoints.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListLicenseServerEndpoints.md") | List license server endpoints                                                   | List         |
| [ListProductSubscriptions](../../../license-manager-user-subscriptions/latest/APIReference/API_ListProductSubscriptions.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListProductSubscriptions.md")       | Lists all the product subscriptions for a product and identity provider         | List         |
| [ListTagsForResource](../../../license-manager-user-subscriptions/latest/APIReference/API_ListTagsForResource.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListTagsForResource.md")                      | List tags for a selected resource                                               | Read         |
| [ListUserAssociations](../../../license-manager-user-subscriptions/latest/APIReference/API_ListUserAssociations.md "../../../license-manager-user-subscriptions/latest/APIReference/API_ListUserAssociations.md")                   | List all the users associated to an instance launched for a product             | List         |
