

# Data retrieval APIs for AWS License Manager User Subscriptions
<a name="awslicensemanagerusersubscriptions"></a>

AWS License Manager User Subscriptions provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="license-manager-user-subscriptions-ListIdentityProviders"></a>[ListIdentityProviders](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListIdentityProviders.html) | List all the identity providers on license manager user subscriptions | List | 
| <a name="license-manager-user-subscriptions-ListInstances"></a>[ListInstances](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListInstances.html) | List all the instances launched with license manager user subscription products | List | 
| <a name="license-manager-user-subscriptions-ListLicenseServerEndpoints"></a>[ListLicenseServerEndpoints](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListLicenseServerEndpoints.html) | List license server endpoints | List | 
| <a name="license-manager-user-subscriptions-ListProductSubscriptions"></a>[ListProductSubscriptions](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListProductSubscriptions.html) | Lists all the product subscriptions for a product and identity provider | List | 
| <a name="license-manager-user-subscriptions-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListTagsForResource.html) | List tags for a selected resource | Read | 
| <a name="license-manager-user-subscriptions-ListUserAssociations"></a>[ListUserAssociations](https://docs.aws.amazon.com/license-manager-user-subscriptions/latest/APIReference/API_ListUserAssociations.html) | List all the users associated to an instance launched for a product | List |
