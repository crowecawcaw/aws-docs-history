# Data retrieval APIs for Amazon Nova Act

Amazon Nova Act provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                                                                                | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetWorkflowDefinition](../../../nova-act/latest/APIReference/API_GetWorkflowDefinition.md "../../../nova-act/latest/APIReference/API_GetWorkflowDefinition.md")       | Retrieve details and configuration of a specific workflow definition                                                       | Read         |
| [GetWorkflowRun](../../../nova-act/latest/APIReference/API_GetWorkflowRun.md "../../../nova-act/latest/APIReference/API_GetWorkflowRun.md")                            | Retrieve the current state, configuration, and execution details of a workflow run                                         | Read         |
| [ListActs](../../../nova-act/latest/APIReference/API_ListActs.md "../../../nova-act/latest/APIReference/API_ListActs.md")                                              | List all acts within a specific session with their current status and execution details                                    | Read         |
| [ListModels](../../../nova-act/latest/APIReference/API_ListModels.md "../../../nova-act/latest/APIReference/API_ListModels.md")                                        | List all available AI models that can be used for workflow execution, including their status and compatibility information | Read         |
| [ListSessions](../../../nova-act/latest/APIReference/API_ListSessions.md "../../../nova-act/latest/APIReference/API_ListSessions.md")                                  | List all sessions within a specific workflow run                                                                           | Read         |
| [ListWorkflowDefinitions](../../../nova-act/latest/APIReference/API_ListWorkflowDefinitions.md "../../../nova-act/latest/APIReference/API_ListWorkflowDefinitions.md") | List all workflow definitions in your account with optional filtering and pagination                                       | List         |
| [ListWorkflowRuns](../../../nova-act/latest/APIReference/API_ListWorkflowRuns.md "../../../nova-act/latest/APIReference/API_ListWorkflowRuns.md")                      | List all workflow runs for a specific workflow definition with optional filtering and pagination                           | List         |
