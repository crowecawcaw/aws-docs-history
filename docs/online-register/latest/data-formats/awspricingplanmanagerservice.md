# Data retrieval APIs for AWS PricingPlanManager Service

AWS PricingPlanManager Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                            | Description                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------- | ------------ |
| [GetSubscription](../../../PricingPlanManager/latest/UserGuide/security-pricing-plan.md "../../../PricingPlanManager/latest/UserGuide/security-pricing-plan.md")   | Get the details for a subscription | Read         |
| [ListSubscriptions](../../../PricingPlanManager/latest/UserGuide/security-pricing-plan.md "../../../PricingPlanManager/latest/UserGuide/security-pricing-plan.md") | List subscriptions in your account | Read         |
