# Data retrieval APIs for AWS CodeStar Notifications

AWS CodeStar Notifications provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                               | Description                                                | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------ |
| [DescribeNotificationRule](../../../codestar-notifications/latest/APIReference/API_DescribeNotificationRule.md "../../../codestar-notifications/latest/APIReference/API_DescribeNotificationRule.md") | Get information about a notification rule                  | Read         |
| [ListEventTypes](../../../codestar-notifications/latest/APIReference/API_ListEventTypes.md "../../../codestar-notifications/latest/APIReference/API_ListEventTypes.md")                               | List notifications event types                             | List         |
| [ListNotificationRules](../../../codestar-notifications/latest/APIReference/API_ListNotificationRules.md "../../../codestar-notifications/latest/APIReference/API_ListNotificationRules.md")          | List notification rules in an AWS account                  | List         |
| [ListTagsForResource](../../../codestar-notifications/latest/APIReference/API_ListTagsForResource.md "../../../codestar-notifications/latest/APIReference/API_ListTagsForResource.md")                | List the tags attached to a notification rule resource ARN | List         |
| [ListTargets](../../../codestar-notifications/latest/APIReference/API_ListTargets.md "../../../codestar-notifications/latest/APIReference/API_ListTargets.md")                                        | List the notification rule targets for an AWS account      | List         |
