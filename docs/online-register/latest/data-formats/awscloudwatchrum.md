# Data retrieval APIs for AWS CloudWatch RUM

AWS CloudWatch RUM provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                         | Description                                           | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ------------ |
| [BatchGetRumMetricDefinitions](../../../cloudwatchrum/latest/APIReference/API_BatchGetRumMetricDefinitions.md "../../../cloudwatchrum/latest/APIReference/API_BatchGetRumMetricDefinitions.md") | Get rum metric definitions                            | Read         |
| [GetAppMonitor](../../../cloudwatchrum/latest/APIReference/API_GetAppMonitor.md "../../../cloudwatchrum/latest/APIReference/API_GetAppMonitor.md")                                              | Get appMonitor metadata                               | Read         |
| [GetAppMonitorData](../../../cloudwatchrum/latest/APIReference/API_GetAppMonitorData.md "../../../cloudwatchrum/latest/APIReference/API_GetAppMonitorData.md")                                  | Get appMonitor data                                   | Read         |
| [GetResourcePolicy](../../../cloudwatchrum/latest/APIReference/API_GetResourcePolicy.md "../../../cloudwatchrum/latest/APIReference/API_GetResourcePolicy.md")                                  | Retrieve a resource policy attached to an app monitor | Read         |
| [ListAppMonitors](../../../cloudwatchrum/latest/APIReference/API_ListAppMonitors.md "../../../cloudwatchrum/latest/APIReference/API_ListAppMonitors.md")                                        | List appMonitors metadata                             | List         |
| [ListRumMetricsDestinations](../../../cloudwatchrum/latest/APIReference/API_ListRumMetricsDestinations.md "../../../cloudwatchrum/latest/APIReference/API_ListRumMetricsDestinations.md")       | List rum metrics destinations                         | Read         |
| [ListTagsForResource](../../../cloudwatchrum/latest/APIReference/API_ListTagsForResource.md "../../../cloudwatchrum/latest/APIReference/API_ListTagsForResource.md")                            | List tags for resources                               | Read         |
