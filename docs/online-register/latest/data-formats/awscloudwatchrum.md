

# Data retrieval APIs for AWS CloudWatch RUM
<a name="awscloudwatchrum"></a>

AWS CloudWatch RUM provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="rum-BatchGetRumMetricDefinitions"></a>[BatchGetRumMetricDefinitions](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_BatchGetRumMetricDefinitions.html) | Get rum metric definitions | Read | 
| <a name="rum-GetAppMonitor"></a>[GetAppMonitor](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_GetAppMonitor.html) | Get appMonitor metadata | Read | 
| <a name="rum-GetAppMonitorData"></a>[GetAppMonitorData](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_GetAppMonitorData.html) | Get appMonitor data | Read | 
| <a name="rum-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_GetResourcePolicy.html) | Retrieve a resource policy attached to an app monitor | Read | 
| <a name="rum-ListAppMonitors"></a>[ListAppMonitors](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_ListAppMonitors.html) | List appMonitors metadata | List | 
| <a name="rum-ListRumMetricsDestinations"></a>[ListRumMetricsDestinations](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_ListRumMetricsDestinations.html) | List rum metrics destinations | Read | 
| <a name="rum-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/cloudwatchrum/latest/APIReference/API_ListTagsForResource.html) | List tags for resources | Read |
