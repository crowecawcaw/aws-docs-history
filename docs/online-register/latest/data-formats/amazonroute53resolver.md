

# Data retrieval APIs for Amazon Route 53 Resolver

Amazon Route 53 Resolver provides the following APIs for data retrieval.

| <a name="route53resolver-GetFirewallRuleGroupPolicy"></a>[GetFirewallRuleGroupPolicy](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_GetFirewallRuleGroupPolicy.html) | Get information about a specified Firewall rule group policy, which specifies the Firewall rule group operations and resources that you want to allow another AWS account to use | Read | 
| <a name="route53resolver-GetOutpostResolver"></a>[GetOutpostResolver](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_GetOutpostResolver.html) | Get information about a specified Route 53 Resolver on Outposts | Read |

| <a name="route53resolver-GetResolverEndpoint"></a>[GetResolverEndpoint](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_GetResolverEndpoint.html) | Get information about a specified Resolver endpoint, such as whether it's an inbound or an outbound endpoint, and the IP addresses in your VPC that DNS queries are forwarded to on the way into or out of your VPC | Read |

When you associate a VPC with a query logging configuration, Resolver logs DNS queries that originate in that VPC | Read |

| <a name="route53resolver-GetResolverRule"></a>[GetResolverRule](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_GetResolverRule.html) | Get information about a specified Resolver rule, such as the domain name that the rule forwards DNS queries for and the IP address that queries are forwarded to | Read | 
| <a name="route53resolver-GetResolverRuleAssociation"></a>[GetResolverRuleAssociation](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_GetResolverRuleAssociation.html) | Get information about an association between a specified Resolver rule and a VPC | Read |

| <a name="route53resolver-ListFirewallConfigs"></a>[ListFirewallConfigs](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_ListFirewallConfigs.html) | List all the Firewall config that current AWS account is able to check | List | 
| <a name="route53resolver-ListFirewallDomainLists"></a>[ListFirewallDomainLists](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_ListFirewallDomainLists.html) | List all the Firewall domain list that current AWS account is able to use | List |

| <a name="route53resolver-ListFirewallRules"></a>[ListFirewallRules](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_ListFirewallRules.html) | List all the Firewall rule under a specified Firewall rule group | List |

| <a name="route53resolver-ListResolverDnssecConfigs"></a>[ListResolverDnssecConfigs](https://docs.aws.amazon.com/Route53/latest/APIReference/API_route53resolver_ListResolverDnssecConfigs.html) | List the DNSSEC validation support status for DNS queries | List |
