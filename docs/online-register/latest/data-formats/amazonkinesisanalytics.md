

# Data retrieval APIs for Amazon Kinesis Analytics
<a name="amazonkinesisanalytics"></a>

Amazon Kinesis Analytics provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="kinesisanalytics-DescribeApplication"></a>[DescribeApplication](https://docs.aws.amazon.com/kinesisanalytics/latest/dev/API_DescribeApplication.html) | Describe the specified application | Read | 
| <a name="kinesisanalytics-DiscoverInputSchema"></a>[DiscoverInputSchema](https://docs.aws.amazon.com/kinesisanalytics/latest/dev/API_DiscoverInputSchema.html) | Discover the input schema for the application | Read | 
| <a name="kinesisanalytics-GetApplicationState"></a>[GetApplicationState](https://docs.aws.amazon.com/kinesisanalytics/latest/dev/api-permissions-reference.html#api-permissions-reference-gas) | Kinesis Data Analytics console to display stream results for Kinesis Data Analytics SQL runtime applications | Read | 
| <a name="kinesisanalytics-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/kinesisanalytics/latest/dev/API_ListApplications.html) | List applications for the account | List | 
| <a name="kinesisanalytics-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/kinesisanalytics/latest/dev/API_ListTagsForResource.html) | Fetch the tags associated with the application | Read |
