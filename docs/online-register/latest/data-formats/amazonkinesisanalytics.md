# Data retrieval APIs for Amazon Kinesis Analytics

Amazon Kinesis Analytics provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                  | Description                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeApplication](../../../kinesisanalytics/latest/dev/API_DescribeApplication.md "../../../kinesisanalytics/latest/dev/API_DescribeApplication.md")                                                                 | Describe the specified application                                                                           | Read         |
| [DiscoverInputSchema](../../../kinesisanalytics/latest/dev/API_DiscoverInputSchema.md "../../../kinesisanalytics/latest/dev/API_DiscoverInputSchema.md")                                                                 | Discover the input schema for the application                                                                | Read         |
| [GetApplicationState](../../../kinesisanalytics/latest/dev/api-permissions-reference.md#api-permissions-reference-gas "../../../kinesisanalytics/latest/dev/api-permissions-reference.md#api-permissions-reference-gas") | Kinesis Data Analytics console to display stream results for Kinesis Data Analytics SQL runtime applications | Read         |
| [ListApplications](../../../kinesisanalytics/latest/dev/API_ListApplications.md "../../../kinesisanalytics/latest/dev/API_ListApplications.md")                                                                          | List applications for the account                                                                            | List         |
| [ListTagsForResource](../../../kinesisanalytics/latest/dev/API_ListTagsForResource.md "../../../kinesisanalytics/latest/dev/API_ListTagsForResource.md")                                                                 | Fetch the tags associated with the application                                                               | Read         |
