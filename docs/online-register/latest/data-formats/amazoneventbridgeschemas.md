# Data retrieval APIs for Amazon EventBridge Schemas

Amazon EventBridge Schemas provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                                                                                               | Description                                                                            | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------ |
| [DescribeCodeBinding](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language.md#DescribeCodeBinding "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language.md#DescribeCodeBinding")                  | Retrieve metadata for generated code for specific schema in your account               | Read         |
| [DescribeDiscoverer](../../../eventbridge/latest/schema-reference/v1-discoverers-id-discovererid.md#DescribeDiscoverer "../../../eventbridge/latest/schema-reference/v1-discoverers-id-discovererid.md#DescribeDiscoverer")                                                                                                           | Retrieve discoverer metadata in your account                                           | Read         |
| [DescribeRegistry](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname.md#DescribeRegistry "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname.md#DescribeRegistry")                                                                                                               | Describe an existing registry metadata in your account                                 | Read         |
| [DescribeSchema](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname.md#DescribeSchema "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname.md#DescribeSchema")                                                                     | Retrieve an existing schema in your account                                            | Read         |
| [ExportSchema](../../../eventbridge/latest/schema-reference/v1-policy.md#ExportSchema "../../../eventbridge/latest/schema-reference/v1-policy.md#ExportSchema")                                                                                                                                                                       | Export the AWS registry or discovered schemas in OpenAPI 3 format to JSONSchema format | Read         |
| [GetCodeBindingSource](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language-source.md#GetCodeBindingSource "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language-source.md#GetCodeBindingSource") | Retrieve metadata for generated code for specific schema in your account               | Read         |
| [GetDiscoveredSchema](../../../eventbridge/latest/schema-reference/v1-discover.md#GetDiscoveredSchema "../../../eventbridge/latest/schema-reference/v1-discover.md#GetDiscoveredSchema")                                                                                                                                              | Retrieve a schema for the provided list of sample events                               | Read         |
| [GetResourcePolicy](../../../eventbridge/latest/schema-reference/v1-policy.md#GetResourcePolicy "../../../eventbridge/latest/schema-reference/v1-policy.md#GetResourcePolicy")                                                                                                                                                        | Retrieve the resource-based policy attached to a given registry                        | Read         |
| [ListDiscoverers](../../../eventbridge/latest/schema-reference/v1-discoverers.md#ListDiscoverers "../../../eventbridge/latest/schema-reference/v1-discoverers.md#ListDiscoverers")                                                                                                                                                    | List all discoverers in your account                                                   | List         |
| [ListRegistries](../../../eventbridge/latest/schema-reference/v1-registries.md#ListRegistries "../../../eventbridge/latest/schema-reference/v1-registries.md#ListRegistries")                                                                                                                                                         | List all registries in your account                                                    | List         |
| [ListSchemaVersions](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-versions.md#ListSchemaVersions "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-versions.md#ListSchemaVersions")                                       | List all versions of a schema                                                          | List         |
| [ListSchemas](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas.md#ListSchemas "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas.md#ListSchemas")                                                                                                              | List all schemas                                                                       | List         |
| [ListTagsForResource](../../../eventbridge/latest/schema-reference/tags-resource-arn.md#ListTagsForResource "../../../eventbridge/latest/schema-reference/tags-resource-arn.md#ListTagsForResource")                                                                                                                                  | Lists tags for a resource                                                              | Read         |
| [SearchSchemas](../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-search.md#SearchSchemas "../../../eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-search.md#SearchSchemas")                                                                                          | Search schemas based on specified keywords in your account                             | List         |
