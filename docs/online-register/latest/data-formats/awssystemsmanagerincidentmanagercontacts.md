AWS Systems Manager Incident Manager Contacts provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                              | Description                                                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------ |

| [DescribePage](../../../incident-manager/latest/APIReference/API_SSMContacts_DescribePage.md "../../../incident-manager/latest/APIReference/API_SSMContacts_DescribePage.md")                                        | Describe a page                                                          | Read         |
| [GetContact](../../../incident-manager/latest/APIReference/API_SSMContacts_GetContact.md "../../../incident-manager/latest/APIReference/API_SSMContacts_GetContact.md")                                              | Get a contact                                                            | Read         |
| [GetContactChannel](../../../incident-manager/latest/APIReference/API_SSMContacts_GetContactChannel.md "../../../incident-manager/latest/APIReference/API_SSMContacts_GetContactChannel.md")                         | Get a contact's contact channel                                          | Read         |
| [GetContactPolicy](../../../incident-manager/latest/APIReference/API_SSMContacts_GetContactPolicy.md "../../../incident-manager/latest/APIReference/API_SSMContacts_GetContactPolicy.md")                            | Get a contact's resource policy                                          | Read         |
| [GetRotation](../../../incident-manager/latest/APIReference/API_SSMContacts_GetRotation.md "../../../incident-manager/latest/APIReference/API_SSMContacts_GetRotation.md")                                           | Retrieve information about an on-call rotation                           | Read         |
| [GetRotationOverride](../../../incident-manager/latest/APIReference/API_SSMContacts_GetRotationOverride.md "../../../incident-manager/latest/APIReference/API_SSMContacts_GetRotationOverride.md")                   | Retrieve information about an override in an on-call rotation            | Read         |
| [ListContactChannels](../../../incident-manager/latest/APIReference/API_SSMContacts_ListContactChannels.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListContactChannels.md")                   | List all of a contact's contact channels                                 | List         |
| [ListContacts](../../../incident-manager/latest/APIReference/API_SSMContacts_ListContacts.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListContacts.md")                                        | List all contacts                                                        | List         |
| [ListEngagements](../../../incident-manager/latest/APIReference/API_SSMContacts_ListEngagements.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListEngagements.md")                               | List all engagements                                                     | List         |
| [ListPageReceipts](../../../incident-manager/latest/APIReference/API_SSMContacts_ListPageReceipts.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListPageReceipts.md")                            | List all receipts of a page                                              | List         |
| [ListPageResolutions](../../../incident-manager/latest/APIReference/API_SSMContacts_ListPageResolutions.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListPageResolutions.md")                   | List the resolution path of an engagement                                | List         |

| [ListTagsForResource](../../../incident-manager/latest/APIReference/API_SSMContacts_ListTagsForResource.md "../../../incident-manager/latest/APIReference/API_SSMContacts_ListTagsForResource.md")                   | View a list of resource tags for a specified resource                    | Read         |
