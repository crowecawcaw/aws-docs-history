

# Data retrieval APIs for AWS Systems Manager Incident Manager Contacts
<a name="awssystemsmanagerincidentmanagercontacts"></a>

AWS Systems Manager Incident Manager Contacts provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="ssm-contacts-DescribeEngagement"></a>[DescribeEngagement](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_DescribeEngagement.html) | Describe an engagement | Read | 
| <a name="ssm-contacts-DescribePage"></a>[DescribePage](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_DescribePage.html) | Describe a page | Read | 
| <a name="ssm-contacts-GetContact"></a>[GetContact](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_GetContact.html) | Get a contact | Read | 
| <a name="ssm-contacts-GetContactChannel"></a>[GetContactChannel](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_GetContactChannel.html) | Get a contact's contact channel | Read | 
| <a name="ssm-contacts-GetContactPolicy"></a>[GetContactPolicy](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_GetContactPolicy.html) | Get a contact's resource policy | Read | 
| <a name="ssm-contacts-GetRotation"></a>[GetRotation](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_GetRotation.html) | Retrieve information about an on-call rotation | Read | 
| <a name="ssm-contacts-GetRotationOverride"></a>[GetRotationOverride](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_GetRotationOverride.html) | Retrieve information about an override in an on-call rotation | Read | 
| <a name="ssm-contacts-ListContactChannels"></a>[ListContactChannels](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListContactChannels.html) | List all of a contact's contact channels | List | 
| <a name="ssm-contacts-ListContacts"></a>[ListContacts](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListContacts.html) | List all contacts | List | 
| <a name="ssm-contacts-ListEngagements"></a>[ListEngagements](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListEngagements.html) | List all engagements | List | 
| <a name="ssm-contacts-ListPageReceipts"></a>[ListPageReceipts](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListPageReceipts.html) | List all receipts of a page | List | 
| <a name="ssm-contacts-ListPageResolutions"></a>[ListPageResolutions](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListPageResolutions.html) | List the resolution path of an engagement | List | 
| <a name="ssm-contacts-ListPagesByContact"></a>[ListPagesByContact](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListPagesByContact.html) | List all pages sent to a contact | List | 
| <a name="ssm-contacts-ListPagesByEngagement"></a>[ListPagesByEngagement](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListPagesByEngagement.html) | List all pages created in an engagement | List | 
| <a name="ssm-contacts-ListPreviewRotationShifts"></a>[ListPreviewRotationShifts](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListPreviewRotationShifts.html) | Retrieve a list of shifts based on rotation configuration parameters | List | 
| <a name="ssm-contacts-ListRotationOverrides"></a>[ListRotationOverrides](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListRotationOverrides.html) | Retrieve a list of overrides currently specified for an on-call rotation | List | 
| <a name="ssm-contacts-ListRotationShifts"></a>[ListRotationShifts](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListRotationShifts.html) | Retrieve a list of rotation shifts in an on-call schedule | List | 
| <a name="ssm-contacts-ListRotations"></a>[ListRotations](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListRotations.html) | Retrieve a list of on-call rotations | List | 
| <a name="ssm-contacts-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_SSMContacts_ListTagsForResource.html) | View a list of resource tags for a specified resource | Read |
