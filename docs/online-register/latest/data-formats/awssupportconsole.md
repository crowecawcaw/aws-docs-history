

# Data retrieval APIs for AWS Support Console
<a name="awssupportconsole"></a>

AWS Support Console provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="support-console-CheckSubscription"></a>[CheckSubscription](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Check whether the account has access to given product | Read | 
| <a name="support-console-DescribeDynamicHelp"></a>[DescribeDynamicHelp](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get dynamic help resources for given service and category | Read | 
| <a name="support-console-GetAccountGovCloudEnabled"></a>[GetAccountGovCloudEnabled](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Determines whether the calling account is GovCloud enabled | Read | 
| <a name="support-console-GetAccountState"></a>[GetAccountState](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get the state of the calling account | Read | 
| <a name="support-console-GetBanner"></a>[GetBanner](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get the support banner information | Read | 
| <a name="support-console-GetCaseDraft"></a>[GetCaseDraft](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get a case draft for given case type | Read | 
| <a name="support-console-GetIssueClassificationPredictions"></a>[GetIssueClassificationPredictions](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get classification predictions of an issue | Read | 
| <a name="support-console-GetIssueTextSummary"></a>[GetIssueTextSummary](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get a generated text summary of an issue | Read | 
| <a name="support-console-GetQuestionnaire"></a>[GetQuestionnaire](https://docs.aws.amazon.com/awssupport/latest/user/support-console-access-control.html) | Get a feedback questionnaire | Read |
