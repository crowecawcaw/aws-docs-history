# Data retrieval APIs for AWS Support Console

AWS Support Console provides the following APIs for data retrieval.

| Actions                                                              | Description                                                | Access level |
| -------------------------------------------------------------------- | ---------------------------------------------------------- | ------------ |
| [CheckSubscription](${AuthZDocPage}.md "${AuthZDocPage}.md")         | Check whether the account has access to given product      | Read         |
| [DescribeDynamicHelp](${AuthZDocPage}.md "${AuthZDocPage}.md")       | Get dynamic help resources for given service and category  | Read         |
| [GetAccountGovCloudEnabled](${AuthZDocPage}.md "${AuthZDocPage}.md") | Determines whether the calling account is GovCloud enabled | Read         |
| [GetAccountState](${AuthZDocPage}.md "${AuthZDocPage}.md")           | Get the state of the calling account                       | Read         |
| [GetBanner](${AuthZDocPage}.md "${AuthZDocPage}.md")                 | Get the support banner information                         | Read         |
| [GetCaseDraft](${AuthZDocPage}.md "${AuthZDocPage}.md")              | Get a case draft for given case type                       | Read         |
| [GetQuestionnaire](${AuthZDocPage}.md "${AuthZDocPage}.md")          | Get a feedback questionnaire                               | Read         |
