

# Data retrieval APIs for Amazon AppStream 2.0
<a name="amazonappstream2.0"></a>

Amazon AppStream 2.0 provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="appstream-DescribeAppBlockBuilderAppBlockAssociations"></a>[DescribeAppBlockBuilderAppBlockAssociations](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeAppBlockBuilderAppBlockAssociations.html) | Retrieve the associations that are associated with the specified app block builder or app block | List | 
| <a name="appstream-DescribeAppBlockBuilders"></a>[DescribeAppBlockBuilders](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeAppBlockBuilders.html) | Retrieve a list that describes one or more specified app block builders, if the app block builder names are provided. Otherwise, all app block builders in the account are described | List | 
| <a name="appstream-DescribeAppBlocks"></a>[DescribeAppBlocks](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeAppBlocks.html) | Retrieve a list that describes one or more specified app blocks, if the app block arns are provided. Otherwise, all app blocks in the account are described | List | 
| <a name="appstream-DescribeAppLicenseUsage"></a>[DescribeAppLicenseUsage](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeAppLicenseUsage.html) | Retrieve license included application usage information | List | 
| <a name="appstream-DescribeApplicationFleetAssociations"></a>[DescribeApplicationFleetAssociations](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeApplicationFleetAssociations.html) | Retrieve the associations that are associated with the specified application or fleet | List | 
| <a name="appstream-DescribeApplications"></a>[DescribeApplications](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeApplications.html) | Retrieve a list that describes one or more specified applications, if the application arns are provided. Otherwise, all applications in the account are described | List | 
| <a name="appstream-DescribeDirectoryConfigs"></a>[DescribeDirectoryConfigs](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeDirectoryConfigs.html) | Retrieve a list that describes one or more specified Directory Config objects for AppStream 2.0, if the names for these objects are provided. Otherwise, all Directory Config objects in the account are described. This object includes the configuration information required to join fleets and image builders to Microsoft Active Directory domains | List | 
| <a name="appstream-DescribeEntitlements"></a>[DescribeEntitlements](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeEntitlements.html) | Retrieve one or all entitlements for the specified stack | List | 
| <a name="appstream-DescribeFleets"></a>[DescribeFleets](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeFleets.html) | Retrieve a list that describes one or more specified fleets, if the fleet names are provided. Otherwise, all fleets in the account are described | List | 
| <a name="appstream-DescribeImageBuilders"></a>[DescribeImageBuilders](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeImageBuilders.html) | Retrieve a list that describes one or more specified image builders, if the image builder names are provided. Otherwise, all image builders in the account are described | List | 
| <a name="appstream-DescribeImagePermissions"></a>[DescribeImagePermissions](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeImagePermissions.html) | Retrieve a list that describes the permissions for shared AWS account IDs on a private image that you own | Read | 
| <a name="appstream-DescribeImages"></a>[DescribeImages](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeImages.html) | Retrieve a list that describes one or more specified images, if the image names or image ARNs are provided. Otherwise, all images in the account are described | List | 
| <a name="appstream-DescribeSessions"></a>[DescribeSessions](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeSessions.html) | Retrieve a list that describes the streaming sessions for the specified stack and fleet. If a user ID is provided for the stack and fleet, only the streaming sessions for that user are described | List | 
| <a name="appstream-DescribeSoftwareAssociations"></a>[DescribeSoftwareAssociations](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeSoftwareAssociations.html) | Retrieve license included application associations for a specified resource | List | 
| <a name="appstream-DescribeStacks"></a>[DescribeStacks](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeStacks.html) | Retrieve a list that describes one or more specified stacks, if the stack names are provided. Otherwise, all stacks in the account are described | List | 
| <a name="appstream-DescribeThemeForStack"></a>[DescribeThemeForStack](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeThemeForStack.html) | Get the custom branding theme information, which might includes a custom logo, website links, and other branding to display to your users | Read | 
| <a name="appstream-DescribeUsageReportSubscriptions"></a>[DescribeUsageReportSubscriptions](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeUsageReportSubscriptions.html) | Retrieve a list that describes one or more usage report subscriptions | List | 
| <a name="appstream-DescribeUserStackAssociations"></a>[DescribeUserStackAssociations](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeUserStackAssociations.html) | Retrieve a list that describes the UserStackAssociation objects | List | 
| <a name="appstream-DescribeUsers"></a>[DescribeUsers](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_DescribeUsers.html) | Retrieve a list that describes users in the user pool | List | 
| <a name="appstream-GetExportImageTask"></a>[GetExportImageTask](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_GetExportImageTask.html) | Retrieve details of a specific export image task | Read | 
| <a name="appstream-ListAssociatedFleets"></a>[ListAssociatedFleets](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_ListAssociatedFleets.html) | Retrieve the name of the fleet that is associated with the specified stack | Read | 
| <a name="appstream-ListAssociatedStacks"></a>[ListAssociatedStacks](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_ListAssociatedStacks.html) | Retrieve the name of the stack with which the specified fleet is associated | Read | 
| <a name="appstream-ListEntitledApplications"></a>[ListEntitledApplications](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_ListEntitledApplications.html) | Retrieve the applications that are associated with the specified entitlement | List | 
| <a name="appstream-ListExportImageTasks"></a>[ListExportImageTasks](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_ListExportImageTasks.html) | List export image tasks | List | 
| <a name="appstream-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/appstream2/latest/APIReference/API_ListTagsForResource.html) | Retrieve a list of all tags for the specified AppStream 2.0 resource. The following resources can be tagged: Image builders, images, fleets, and stacks | Read |
