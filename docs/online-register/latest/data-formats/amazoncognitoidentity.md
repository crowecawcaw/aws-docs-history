# Data retrieval APIs for Amazon Cognito Identity

Amazon Cognito Identity provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                               | Description                                                                                                                                                      | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeIdentity](../../../cognitoidentity/latest/APIReference/API_DescribeIdentity.md "../../../cognitoidentity/latest/APIReference/API_DescribeIdentity.md")                                                       | Return metadata related to the given identity, including when the identity was created and any associated linked logins                                          | Read         |
| [DescribeIdentityPool](../../../cognitoidentity/latest/APIReference/API_DescribeIdentityPool.md "../../../cognitoidentity/latest/APIReference/API_DescribeIdentityPool.md")                                           | Get details about a particular identity pool, including the pool name, ID description, creation date, and current number of users                                | Read         |
| [GetCredentialsForIdentity](../../../cognitoidentity/latest/APIReference/API_GetCredentialsForIdentity.md "../../../cognitoidentity/latest/APIReference/API_GetCredentialsForIdentity.md")                            | Return credentials for the provided identity ID                                                                                                                  | Read         |
| [GetIdentityPoolAnalytics](../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolAnalytics.md "../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolAnalytics.md")                               | Get analytics data about the total current identity count for all identity pool identity provider (IdPs)                                                         | Read         |
| [GetIdentityPoolDailyAnalytics](../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolDailyAnalytics.md "../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolDailyAnalytics.md")                | Get analytics data about the number of new identities and total identities for all identity pool identity providers (IdPs)                                       | Read         |
| [GetIdentityPoolRoles](../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolRoles.md "../../../cognitoidentity/latest/APIReference/API_GetIdentityPoolRoles.md")                                           | Get the roles for an identity pool                                                                                                                               | Read         |
| [GetIdentityProviderDailyAnalytics](../../../cognitoidentity/latest/APIReference/API_GetIdentityProviderDailyAnalytics.md "../../../cognitoidentity/latest/APIReference/API_GetIdentityProviderDailyAnalytics.md")    | Get analytics data about the number of new identities and total identities for one identity pool identity provider (IdPs)                                        | Read         |
| [GetOpenIdToken](../../../cognitoidentity/latest/APIReference/API_GetOpenIdToken.md "../../../cognitoidentity/latest/APIReference/API_GetOpenIdToken.md")                                                             | Get an OpenID token, using a known Cognito ID                                                                                                                    | Read         |
| [GetOpenIdTokenForDeveloperIdentity](../../../cognitoidentity/latest/APIReference/API_GetOpenIdTokenForDeveloperIdentity.md "../../../cognitoidentity/latest/APIReference/API_GetOpenIdTokenForDeveloperIdentity.md") | Register (or retrieve) a Cognito IdentityId and an OpenID Connect token for a user authenticated by your backend authentication process                          | Read         |
| [GetPrincipalTagAttributeMap](../../../cognitoidentity/latest/APIReference/API_GetPrincipalTagAttributeMap.md "../../../cognitoidentity/latest/APIReference/API_GetPrincipalTagAttributeMap.md")                      | Get the principal tags for an identity pool and provider                                                                                                         | Read         |
| [ListIdentities](../../../cognitoidentity/latest/APIReference/API_ListIdentities.md "../../../cognitoidentity/latest/APIReference/API_ListIdentities.md")                                                             | List the identities in an identity pool                                                                                                                          | List         |
| [ListIdentityPools](../../../cognitoidentity/latest/APIReference/API_ListIdentityPools.md "../../../cognitoidentity/latest/APIReference/API_ListIdentityPools.md")                                                    | List all of the Cognito identity pools registered for your account                                                                                               | List         |
| [ListTagsForResource](../../../cognitoidentity/latest/APIReference/API_ListTagsForResource.md "../../../cognitoidentity/latest/APIReference/API_ListTagsForResource.md")                                              | List the tags that are assigned to an Amazon Cognito identity pool                                                                                               | Read         |
| [LookupDeveloperIdentity](../../../cognitoidentity/latest/APIReference/API_LookupDeveloperIdentity.md "../../../cognitoidentity/latest/APIReference/API_LookupDeveloperIdentity.md")                                  | Retrieve the IdentityId associated with a DeveloperUserIdentifier or the list of DeveloperUserIdentifiers associated with an IdentityId for an existing identity | Read         |
