

# Data retrieval APIs for Amazon Honeycode
<a name="amazonhoneycode"></a>

Amazon Honeycode provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="honeycode-DescribeTableDataImportJob"></a>[DescribeTableDataImportJob](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_DescribeTableDataImportJob.html) | Get details about a table data import job | Read | 
| <a name="honeycode-DescribeTeam"></a>[DescribeTeam](https://docs.aws.amazon.com/honeycode/latest/UserGuide/team.html#describe-team) | Get details about Amazon Honeycode teams for your AWS Account | Read | 
| <a name="honeycode-GetScreenData"></a>[GetScreenData](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_GetScreenData.html) | Load the data from a screen | Read | 
| <a name="honeycode-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/honeycode/latest/UserGuide/domain.html#list-domains) | List all Amazon Honeycode domains and their verification status for your AWS Account | List | 
| <a name="honeycode-ListGroups"></a>[ListGroups](https://docs.aws.amazon.com/honeycode/latest/UserGuide/group.html#list-groups) | List all groups in an Amazon Honeycode team for your AWS Account | List | 
| <a name="honeycode-ListTableColumns"></a>[ListTableColumns](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_ListTableColumns.html) | List the columns in a table | List | 
| <a name="honeycode-ListTableRows"></a>[ListTableRows](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_ListTableRows.html) | List the rows in a table | List | 
| <a name="honeycode-ListTables"></a>[ListTables](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_ListTables.html) | List the tables in a workbook | List | 
| <a name="honeycode-ListTeamAssociations"></a>[ListTeamAssociations](https://docs.aws.amazon.com/honeycode/latest/UserGuide/team-association.html#list-team-associations) | List all pending and approved team associations with your AWS Account | List | 
| <a name="honeycode-ListTenants"></a>[ListTenants](https://docs.aws.amazon.com/honeycode/latest/UserGuide/tenant.html#list-tenants) | List all tenants of Amazon Honeycode for your AWS Account | List | 
| <a name="honeycode-QueryTableRows"></a>[QueryTableRows](https://docs.aws.amazon.com/honeycode/latest/UserGuide/API_QueryTableRows.html) | Query the rows of a table using a filter | Read |
