# Data retrieval APIs for AWS Identity Store

AWS Identity Store provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                    | Description                                                                                 | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------ |
| [DescribeGroup](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroup.md")                                                 | Retrieve information about a group in the specified IdentityStore                           | Read         |
| [DescribeGroupMembership](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroupMembership.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeGroupMembership.md")                   | Retrieve information about a member that is part of a group in the specified IdentityStore  | Read         |
| [DescribeRegion](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                    | Retrieve configuration details for a specific IdentityStore region                          | Read         |
| [DescribeUser](../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_DescribeUser.md")                                                    | Retrieve information about user in the specified IdentityStore                              | Read         |
| [GetGroupId](../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupId.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupId.md")                                                          | Retrieve ID information about group in the specified IdentityStore                          | Read         |
| [GetGroupMembershipId](../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupMembershipId.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_GetGroupMembershipId.md")                            | Retrieve ID information of a member which is part of a group in the specified IdentityStore | Read         |
| [GetUserId](../../../singlesignon/latest/IdentityStoreAPIReference/API_GetUserId.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_GetUserId.md")                                                             | Retrieves ID information about user in the specified IdentityStore                          | Read         |
| [IsMemberInGroups](../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_IsMemberInGroups.md")                                        | Check if a member is a part of groups in the specified IdentityStore                        | Read         |
| [ListGroupMemberships](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMemberships.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMemberships.md")                            | Retrieve all members that are part of a group in the specified IdentityStore                | List         |
| [ListGroupMembershipsForMember](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroupMembershipsForMember.md") | List groups of the target member in the specified IdentityStore                             | List         |
| [ListGroups](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroups.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListGroups.md")                                                          | Search for groups within the specified IdentityStore                                        | List         |
| [ListRegions](../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample "../../../singlesignon/latest/userguide/iam-auth-access-using-id-policies.md#policyexample")                       | List all regions configured for an IdentityStore                                            | List         |
| [ListUsers](../../../singlesignon/latest/IdentityStoreAPIReference/API_ListUsers.md "../../../singlesignon/latest/IdentityStoreAPIReference/API_ListUsers.md")                                                             | Search for users in the specified IdentityStore                                             | List         |
