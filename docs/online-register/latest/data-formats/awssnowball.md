# Data retrieval APIs for AWS Snowball

AWS Snowball provides the following APIs for data retrieval.

| Actions                                                                                                                                                                              | Description                                                                                                                                                | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAddress](../../../snowball/latest/api-reference/API_DescribeAddress.md "../../../snowball/latest/api-reference/API_DescribeAddress.md")                                     | Get specific details about that address in the form of an Address object                                                                                   | Read         |
| [DescribeAddresses](../../../snowball/latest/api-reference/API_DescribeAddresses.md "../../../snowball/latest/api-reference/API_DescribeAddresses.md")                               | Describe a specified number of ADDRESS objects                                                                                                             | List         |
| [DescribeCluster](../../../snowball/latest/api-reference/API_DescribeCluster.md "../../../snowball/latest/api-reference/API_DescribeCluster.md")                                     | Describe information about a specific cluster including shipping information, cluster status, and other important metadata                                 | Read         |
| [DescribeJob](../../../snowball/latest/api-reference/API_DescribeJob.md "../../../snowball/latest/api-reference/API_DescribeJob.md")                                                 | Describe information about a specific job including shipping information, job status, and other important metadata                                         | Read         |
| [DescribeReturnShippingLabel](../../../snowball/latest/api-reference/API_DescribeReturnShippingLabel.md "../../../snowball/latest/api-reference/API_DescribeReturnShippingLabel.md") | Describe information on the shipping label of a Snow device that is being returned to AWS                                                                  | Read         |
| [GetJobManifest](../../../snowball/latest/api-reference/API_GetJobManifest.md "../../../snowball/latest/api-reference/API_GetJobManifest.md")                                        | Get a link to an Amazon S3 presigned URL for the manifest file associated with the specified JobId value                                                   | Read         |
| [GetJobUnlockCode](../../../snowball/latest/api-reference/API_GetJobUnlockCode.md "../../../snowball/latest/api-reference/API_GetJobUnlockCode.md")                                  | Get the UnlockCode code value for the specified job                                                                                                        | Read         |
| [GetSnowballUsage](../../../snowball/latest/api-reference/API_GetSnowballUsage.md "../../../snowball/latest/api-reference/API_GetSnowballUsage.md")                                  | Get information about the Snowball service limit for your account, and also the number of Snowballs your account has in use                                | Read         |
| [GetSoftwareUpdates](../../../snowball/latest/api-reference/API_GetSoftwareUpdates.md "../../../snowball/latest/api-reference/API_GetSoftwareUpdates.md")                            | Return an Amazon S3 presigned URL for an update file associated with a specified JobId                                                                     | Read         |
| [ListClusterJobs](../../../snowball/latest/api-reference/API_ListClusterJobs.md "../../../snowball/latest/api-reference/API_ListClusterJobs.md")                                     | List JobListEntry objects of the specified length                                                                                                          | List         |
| [ListClusters](../../../snowball/latest/api-reference/API_ListClusters.md "../../../snowball/latest/api-reference/API_ListClusters.md")                                              | List ClusterListEntry objects of the specified length                                                                                                      | List         |
| [ListCompatibleImages](../../../snowball/latest/api-reference/API_ListCompatibleImages.md "../../../snowball/latest/api-reference/API_ListCompatibleImages.md")                      | Return a list of the different Amazon EC2 Amazon Machine Images (AMIs) that are owned by your AWS account that would be supported for use on a Snow device | List         |
| [ListJobs](../../../snowball/latest/api-reference/API_ListJobs.md "../../../snowball/latest/api-reference/API_ListJobs.md")                                                          | List JobListEntry objects of the specified length                                                                                                          | List         |
| [ListLongTermPricing](../../../snowball/latest/api-reference/API_ListLongTermPricing.md "../../../snowball/latest/api-reference/API_ListLongTermPricing.md")                         | List LongTermPricingListEntry objects for the account making the request                                                                                   | Read         |
| [ListPickupLocations](../../../snowball/latest/api-reference/API_ListPickupLocations.md "../../../snowball/latest/api-reference/API_ListPickupLocations.md")                         | List Address objects where pickup is available, of the specified length                                                                                    | List         |
| [ListServiceVersions](../../../snowball/latest/api-reference/API_ListServiceVersions.md "../../../snowball/latest/api-reference/API_ListServiceVersions.md")                         | List all supported versions for Snow on-device services                                                                                                    | List         |
