# Data retrieval APIs for AWS Elemental Appliances and Software

AWS Elemental Appliances and Software provides the following APIs for data retrieval.

| Actions                                                                                                         | Description                                    | Access level |
| --------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | ------------ |
| [GetAvsCorrectAddress](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")   | Validate an address                            | Read         |
| [GetBillingAddresses](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")    | List the billing addresses in the AWS Account  | Read         |
| [GetDeliveryAddressesV2](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md") | List the delivery addresses in the AWS Account | Read         |
| [GetOrder](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")               | Describe an order                              | Read         |
| [GetOrdersV2](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")            | List the orders in the AWS Account             | Read         |
| [GetQuote](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")               | Describe a quote                               | Read         |
| [GetTaxes](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")               | Calculate taxes for an order                   | Read         |
| [ListQuotes](../../../elemental-appliances-software.md "../../../elemental-appliances-software.md")             | List the quotes in the AWS Account             | List         |
