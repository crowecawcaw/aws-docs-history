

# Data retrieval APIs for AWS Elemental Appliances and Software
<a name="awselementalappliancesandsoftware"></a>

AWS Elemental Appliances and Software provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="elemental-appliances-software-GetAvsCorrectAddress"></a>[GetAvsCorrectAddress](https://docs.aws.amazon.com/elemental-appliances-software) | Validate an address | Read | 
| <a name="elemental-appliances-software-GetBillingAddresses"></a>[GetBillingAddresses](https://docs.aws.amazon.com/elemental-appliances-software) | List the billing addresses in the AWS Account | Read | 
| <a name="elemental-appliances-software-GetDeliveryAddressesV2"></a>[GetDeliveryAddressesV2](https://docs.aws.amazon.com/elemental-appliances-software) | List the delivery addresses in the AWS Account | Read | 
| <a name="elemental-appliances-software-GetOrder"></a>[GetOrder](https://docs.aws.amazon.com/elemental-appliances-software) | Describe an order | Read | 
| <a name="elemental-appliances-software-GetOrdersV2"></a>[GetOrdersV2](https://docs.aws.amazon.com/elemental-appliances-software) | List the orders in the AWS Account | Read | 
| <a name="elemental-appliances-software-GetQuote"></a>[GetQuote](https://docs.aws.amazon.com/elemental-appliances-software) | Describe a quote | Read | 
| <a name="elemental-appliances-software-GetTaxes"></a>[GetTaxes](https://docs.aws.amazon.com/elemental-appliances-software) | Calculate taxes for an order | Read | 
| <a name="elemental-appliances-software-ListQuotes"></a>[ListQuotes](https://docs.aws.amazon.com/elemental-appliances-software) | List the quotes in the AWS Account | List |
