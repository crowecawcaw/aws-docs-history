

# Data retrieval APIs for AWS Telco Network Builder
<a name="awstelconetworkbuilder"></a>

AWS Telco Network Builder provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="tnb-GetSolFunctionInstance"></a>[GetSolFunctionInstance](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolFunctionInstance.html) | Get a function instance | Read | 
| <a name="tnb-GetSolFunctionPackage"></a>[GetSolFunctionPackage](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolFunctionPackage.html) | Get a function package | Read | 
| <a name="tnb-GetSolFunctionPackageContent"></a>[GetSolFunctionPackageContent](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolFunctionPackageContent.html) | Get a function package contents | Read | 
| <a name="tnb-GetSolFunctionPackageDescriptor"></a>[GetSolFunctionPackageDescriptor](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolFunctionPackageDescriptor.html) | Get a function package descriptor | Read | 
| <a name="tnb-GetSolNetworkInstance"></a>[GetSolNetworkInstance](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolNetworkInstance.html) | Get a network instance | Read | 
| <a name="tnb-GetSolNetworkOperation"></a>[GetSolNetworkOperation](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolNetworkOperation.html) | Get a network operation | Read | 
| <a name="tnb-GetSolNetworkPackage"></a>[GetSolNetworkPackage](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolNetworkPackage.html) | Get a network package | Read | 
| <a name="tnb-GetSolNetworkPackageContent"></a>[GetSolNetworkPackageContent](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolNetworkPackageContent.html) | Get a network package contents | Read | 
| <a name="tnb-GetSolNetworkPackageDescriptor"></a>[GetSolNetworkPackageDescriptor](https://docs.aws.amazon.com/tnb/latest/APIReference/API_GetSolNetworkPackageDescriptor.html) | Get a network package descriptor | Read | 
| <a name="tnb-ListSolFunctionInstances"></a>[ListSolFunctionInstances](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListSolFunctionInstances.html) | List function instances | List | 
| <a name="tnb-ListSolFunctionPackages"></a>[ListSolFunctionPackages](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListSolFunctionPackages.html) | List function packages | List | 
| <a name="tnb-ListSolNetworkInstances"></a>[ListSolNetworkInstances](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListSolNetworkInstances.html) | List network instances | List | 
| <a name="tnb-ListSolNetworkOperations"></a>[ListSolNetworkOperations](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListSolNetworkOperations.html) | List network operations | List | 
| <a name="tnb-ListSolNetworkPackages"></a>[ListSolNetworkPackages](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListSolNetworkPackages.html) | List network packages | List | 
| <a name="tnb-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/tnb/latest/APIReference/API_ListTagsForResource.html) | Return a list of tags for a resource | List |
