# Data retrieval APIs for AWS Telco Network Builder

AWS Telco Network Builder provides the following APIs for data retrieval.

| Actions                                                                                                                                                                              | Description                          | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ | ------------ |
| [GetSolFunctionInstance](../../../tnb/latest/APIReference/API_GetSolFunctionInstance.md "../../../tnb/latest/APIReference/API_GetSolFunctionInstance.md")                            | Get a function instance              | Read         |
| [GetSolFunctionPackage](../../../tnb/latest/APIReference/API_GetSolFunctionPackage.md "../../../tnb/latest/APIReference/API_GetSolFunctionPackage.md")                               | Get a function package               | Read         |
| [GetSolFunctionPackageContent](../../../tnb/latest/APIReference/API_GetSolFunctionPackageContent.md "../../../tnb/latest/APIReference/API_GetSolFunctionPackageContent.md")          | Get a function package contents      | Read         |
| [GetSolFunctionPackageDescriptor](../../../tnb/latest/APIReference/API_GetSolFunctionPackageDescriptor.md "../../../tnb/latest/APIReference/API_GetSolFunctionPackageDescriptor.md") | Get a function package descriptor    | Read         |
| [GetSolNetworkInstance](../../../tnb/latest/APIReference/API_GetSolNetworkInstance.md "../../../tnb/latest/APIReference/API_GetSolNetworkInstance.md")                               | Get a network instance               | Read         |
| [GetSolNetworkOperation](../../../tnb/latest/APIReference/API_GetSolNetworkOperation.md "../../../tnb/latest/APIReference/API_GetSolNetworkOperation.md")                            | Get a network operation              | Read         |
| [GetSolNetworkPackage](../../../tnb/latest/APIReference/API_GetSolNetworkPackage.md "../../../tnb/latest/APIReference/API_GetSolNetworkPackage.md")                                  | Get a network package                | Read         |
| [GetSolNetworkPackageContent](../../../tnb/latest/APIReference/API_GetSolNetworkPackageContent.md "../../../tnb/latest/APIReference/API_GetSolNetworkPackageContent.md")             | Get a network package contents       | Read         |
| [GetSolNetworkPackageDescriptor](../../../tnb/latest/APIReference/API_GetSolNetworkPackageDescriptor.md "../../../tnb/latest/APIReference/API_GetSolNetworkPackageDescriptor.md")    | Get a network package descriptor     | Read         |
| [ListSolFunctionInstances](../../../tnb/latest/APIReference/API_ListSolFunctionInstances.md "../../../tnb/latest/APIReference/API_ListSolFunctionInstances.md")                      | List function instances              | List         |
| [ListSolFunctionPackages](../../../tnb/latest/APIReference/API_ListSolFunctionPackages.md "../../../tnb/latest/APIReference/API_ListSolFunctionPackages.md")                         | List function packages               | List         |
| [ListSolNetworkInstances](../../../tnb/latest/APIReference/API_ListSolNetworkInstances.md "../../../tnb/latest/APIReference/API_ListSolNetworkInstances.md")                         | List network instances               | List         |
| [ListSolNetworkOperations](../../../tnb/latest/APIReference/API_ListSolNetworkOperations.md "../../../tnb/latest/APIReference/API_ListSolNetworkOperations.md")                      | List network operations              | List         |
| [ListSolNetworkPackages](../../../tnb/latest/APIReference/API_ListSolNetworkPackages.md "../../../tnb/latest/APIReference/API_ListSolNetworkPackages.md")                            | List network packages                | List         |
| [ListTagsForResource](../../../tnb/latest/APIReference/API_ListTagsForResource.md "../../../tnb/latest/APIReference/API_ListTagsForResource.md")                                     | Return a list of tags for a resource | List         |
