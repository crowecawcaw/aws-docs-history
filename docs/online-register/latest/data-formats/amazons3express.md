# Data retrieval APIs for Amazon S3 Express

Amazon S3 Express provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                  | Description                                                                 | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------ |
| [GetAccessPoint](../../../AmazonS3/latest/API/API_control_GetAccessPoint.md "../../../AmazonS3/latest/API/API_control_GetAccessPoint.md")                                                                | Return configuration information about the specified access point           | Read         |
| [GetAccessPointPolicy](../../../AmazonS3/latest/API/API_control_GetAccessPointPolicy.md "../../../AmazonS3/latest/API/API_control_GetAccessPointPolicy.md")                                              | Return the access point policy associated with the specified access point   | Read         |
| [GetAccessPointScope](../../../AmazonS3/latest/API/API_control_GetAccessPointScope.md "../../../AmazonS3/latest/API/API_control_GetAccessPointScope.md")                                                 | Return the scope configuration associated with the specified access point   | Read         |
| [GetBucketPolicy](../../../AmazonS3/latest/API/API_GetBucketPolicy.md "../../../AmazonS3/latest/API/API_GetBucketPolicy.md")                                                                             | Return the policy of the specified bucket                                   | Read         |
| [GetEncryptionConfiguration](../../../AmazonS3/latest/API/API_GetBucketEncryption.md "../../../AmazonS3/latest/API/API_GetBucketEncryption.md")                                                          | Return the default encryption configuration for a directory bucket          | Read         |
| [GetLifecycleConfiguration](../../../AmazonS3/latest/API/API_GetBucketLifecycleConfiguration.md "../../../AmazonS3/latest/API/API_GetBucketLifecycleConfiguration.md")                                   | Return the lifecycle configuration information set on a directory bucket    | Read         |
| [ListAccessPointsForDirectoryBuckets](../../../AmazonS3/latest/API/API_control_ListAccessPointsForDirectoryBuckets.md "../../../AmazonS3/latest/API/API_control_ListAccessPointsForDirectoryBuckets.md") | List access points                                                          | List         |
| [ListAllMyDirectoryBuckets](../../../AmazonS3/latest/API/API_ListDirectoryBuckets.md "../../../AmazonS3/latest/API/API_ListDirectoryBuckets.md")                                                         | List all directory buckets owned by the authenticated sender of the request | List         |
| [ListTagsForResource](../../../AmazonS3/latest/API/API_control_ListTagsForResource.md "../../../AmazonS3/latest/API/API_control_ListTagsForResource.md")                                                 | Lists all of the tags for a specified resource                              | List         |
