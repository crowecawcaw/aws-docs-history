# Data retrieval APIs for Amazon ARC Region switch

Amazon ARC Region switch provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------ |
| [GetPlan](../../../arc-region-switch/latest/api/API_GetPlan.md "../../../arc-region-switch/latest/api/API_GetPlan.md")                                                 | Get information about plans in all AWS Regions using a control plane                              | Read         |
| [GetPlanEvaluationStatus](../../../arc-region-switch/latest/api/API_GetPlanEvaluationStatus.md "../../../arc-region-switch/latest/api/API_GetPlanEvaluationStatus.md") | Get a plan's evaluation status                                                                    | Read         |
| [GetPlanExecution](../../../arc-region-switch/latest/api/API_GetPlanExecution.md "../../../arc-region-switch/latest/api/API_GetPlanExecution.md")                      | Get plan execution details and setup information                                                  | Read         |
| [GetPlanInRegion](../../../arc-region-switch/latest/api/API_GetPlanInRegion.md "../../../arc-region-switch/latest/api/API_GetPlanInRegion.md")                         | Get information about a plan in a specific AWS Region using the Region switch Regional data plane | Read         |
| [ListPlanExecutionEvents](../../../arc-region-switch/latest/api/API_ListPlanExecutionEvents.md "../../../arc-region-switch/latest/api/API_ListPlanExecutionEvents.md") | List plan execution events                                                                        | List         |
| [ListPlanExecutions](../../../arc-region-switch/latest/api/API_ListPlanExecutions.md "../../../arc-region-switch/latest/api/API_ListPlanExecutions.md")                | List plan executions                                                                              | List         |
| [ListPlans](../../../arc-region-switch/latest/api/API_ListPlans.md "../../../arc-region-switch/latest/api/API_ListPlans.md")                                           | List plans in all AWS Regions using a control plane                                               | List         |
| [ListPlansInRegion](../../../arc-region-switch/latest/api/API_ListPlansInRegion.md "../../../arc-region-switch/latest/api/API_ListPlansInRegion.md")                   | List plans in a specific AWS Region using the Region switch Regional data plane                   | List         |
| [ListRoute53HealthChecks](../../../arc-region-switch/latest/api/API_ListRoute53HealthChecks.md "../../../arc-region-switch/latest/api/API_ListRoute53HealthChecks.md") | List Route 53 health checks                                                                       | List         |
| [ListTagsForResource](../../../arc-region-switch/latest/api/API_ListTagsForResource.md "../../../arc-region-switch/latest/api/API_ListTagsForResource.md")             | List tags for a resource                                                                          | Read         |
