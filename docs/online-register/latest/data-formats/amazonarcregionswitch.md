

# Data retrieval APIs for Amazon ARC Region switch
<a name="amazonarcregionswitch"></a>

Amazon ARC Region switch provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="arc-region-switch-GetPlan"></a>[GetPlan](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_GetPlan.html) | Get information about plans in all AWS Regions using a control plane | Read | 
| <a name="arc-region-switch-GetPlanEvaluationStatus"></a>[GetPlanEvaluationStatus](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_GetPlanEvaluationStatus.html) | Get a plan's evaluation status | Read | 
| <a name="arc-region-switch-GetPlanExecution"></a>[GetPlanExecution](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_GetPlanExecution.html) | Get plan execution details and setup information | Read | 
| <a name="arc-region-switch-GetPlanInRegion"></a>[GetPlanInRegion](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_GetPlanInRegion.html) | Get information about a plan in a specific AWS Region using the Region switch Regional data plane | Read | 
| <a name="arc-region-switch-ListPlanExecutionEvents"></a>[ListPlanExecutionEvents](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListPlanExecutionEvents.html) | List plan execution events | List | 
| <a name="arc-region-switch-ListPlanExecutions"></a>[ListPlanExecutions](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListPlanExecutions.html) | List plan executions | List | 
| <a name="arc-region-switch-ListPlans"></a>[ListPlans](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListPlans.html) | List plans in all AWS Regions using a control plane | List | 
| <a name="arc-region-switch-ListPlansInRegion"></a>[ListPlansInRegion](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListPlansInRegion.html) | List plans in a specific AWS Region using the Region switch Regional data plane | List | 
| <a name="arc-region-switch-ListRoute53HealthChecks"></a>[ListRoute53HealthChecks](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListRoute53HealthChecks.html) | List Route 53 health checks | List | 
| <a name="arc-region-switch-ListRoute53HealthChecksInRegion"></a>[ListRoute53HealthChecksInRegion](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListRoute53HealthChecksInRegion.html) | List Route 53 health checks in a specific AWS Region using the Region switch Regional data plane | List | 
| <a name="arc-region-switch-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/arc-region-switch/latest/api/API_ListTagsForResource.html) | List tags for a resource | Read |
