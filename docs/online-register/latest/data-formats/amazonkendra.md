

# Data retrieval APIs for Amazon Kendra
<a name="amazonkendra"></a>

Amazon Kendra provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="kendra-BatchGetDocumentStatus"></a>[BatchGetDocumentStatus](https://docs.aws.amazon.com/kendra/latest/dg/API_BatchGetDocumentStatus.html) | Do batch get document status | Read | 
| <a name="kendra-DescribeAccessControlConfiguration"></a>[DescribeAccessControlConfiguration](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeAccessControlConfiguration.html) | Describe an access control configuration | Read | 
| <a name="kendra-DescribeDataSource"></a>[DescribeDataSource](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeDataSource.html) | Describe a data source | Read | 
| <a name="kendra-DescribeExperience"></a>[DescribeExperience](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeExperience.html) | Gets information about your Amazon Kendra experience such as a search application | Read | 
| <a name="kendra-DescribeFaq"></a>[DescribeFaq](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeFaq.html) | Describe an Faq | Read | 
| <a name="kendra-DescribeFeaturedResultsSet"></a>[DescribeFeaturedResultsSet](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeThesaurus.html) | Describe a featured results set | Read | 
| <a name="kendra-DescribeIndex"></a>[DescribeIndex](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeIndex.html) | Describe an Index | Read | 
| <a name="kendra-DescribePrincipalMapping"></a>[DescribePrincipalMapping](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribePrincipalMapping.html) | Describe principal mapping from index | Read | 
| <a name="kendra-DescribeQuerySuggestionsBlockList"></a>[DescribeQuerySuggestionsBlockList](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeQuerySuggestionsBlockList.html) | Describe a QuerySuggestions BlockList | Read | 
| <a name="kendra-DescribeQuerySuggestionsConfig"></a>[DescribeQuerySuggestionsConfig](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeQuerySuggestionsConfig.html) | Describe the query suggestions configuration for an index | Read | 
| <a name="kendra-DescribeThesaurus"></a>[DescribeThesaurus](https://docs.aws.amazon.com/kendra/latest/dg/API_DescribeThesaurus.html) | Describe a Thesaurus | Read | 
| <a name="kendra-GetQuerySuggestions"></a>[GetQuerySuggestions](https://docs.aws.amazon.com/kendra/latest/dg/API_GetQuerySuggestions.html) | Get suggestions for a query prefix | Read | 
| <a name="kendra-GetSnapshots"></a>[GetSnapshots](https://docs.aws.amazon.com/kendra/latest/dg/API_GetSnapshots.html) | Retrieves search metrics data | Read | 
| <a name="kendra-ListAccessControlConfigurations"></a>[ListAccessControlConfigurations](https://docs.aws.amazon.com/kendra/latest/dg/API_ListAccessControlConfigurations.html) | List the access control configurations | List | 
| <a name="kendra-ListDataSourceSyncJobs"></a>[ListDataSourceSyncJobs](https://docs.aws.amazon.com/kendra/latest/dg/API_ListDataSourceSyncJobs.html) | Get Data Source sync job history | List | 
| <a name="kendra-ListDataSources"></a>[ListDataSources](https://docs.aws.amazon.com/kendra/latest/dg/API_ListDataSources.html) | List the data sources | List | 
| <a name="kendra-ListEntityPersonas"></a>[ListEntityPersonas](https://docs.aws.amazon.com/kendra/latest/dg/API_ListEntityPersonas.html) | Lists specific permissions of users and groups with access to your Amazon Kendra experience | List | 
| <a name="kendra-ListExperienceEntities"></a>[ListExperienceEntities](https://docs.aws.amazon.com/kendra/latest/dg/API_ListExperienceEntities.html) | Lists users or groups in your AWS SSO identity source that are granted access to your Amazon Kendra experience | List | 
| <a name="kendra-ListExperiences"></a>[ListExperiences](https://docs.aws.amazon.com/kendra/latest/dg/API_ListExperiences.html) | Lists one or more Amazon Kendra experiences. You can create an Amazon Kendra experience such as a search application | List | 
| <a name="kendra-ListFaqs"></a>[ListFaqs](https://docs.aws.amazon.com/kendra/latest/dg/API_ListFaqs.html) | List the Faqs | List | 
| <a name="kendra-ListFeaturedResultsSets"></a>[ListFeaturedResultsSets](https://docs.aws.amazon.com/kendra/latest/dg/API_ListFeaturedResults.html) | List the featured results sets | List | 
| <a name="kendra-ListGroupsOlderThanOrderingId"></a>[ListGroupsOlderThanOrderingId](https://docs.aws.amazon.com/kendra/latest/dg/API_ListGroupsOlderThanOrderingId.html) | List groups that are older than an ordering id | List | 
| <a name="kendra-ListIndices"></a>[ListIndices](https://docs.aws.amazon.com/kendra/latest/dg/API_ListIndices.html) | List the indexes | List | 
| <a name="kendra-ListQuerySuggestionsBlockLists"></a>[ListQuerySuggestionsBlockLists](https://docs.aws.amazon.com/kendra/latest/dg/API_ListQuerySuggestionsBlockLists.html) | List the QuerySuggestions BlockLists | List | 
| <a name="kendra-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/kendra/latest/dg/API_ListTagsForResource.html) | List tags for a resource | Read | 
| <a name="kendra-ListThesauri"></a>[ListThesauri](https://docs.aws.amazon.com/kendra/latest/dg/API_ListThesauri.html) | List the Thesauri | List | 
| <a name="kendra-Query"></a>[Query](https://docs.aws.amazon.com/kendra/latest/dg/API_Query.html) | Query documents and faqs | Read | 
| <a name="kendra-Retrieve"></a>[Retrieve](https://docs.aws.amazon.com/kendra/latest/dg/API_Retrieve.html) | Retrieve relevant content from an index | Read |
