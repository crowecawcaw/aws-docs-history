# Data retrieval APIs for Claude Platform on AWS

Claude Platform on AWS provides the following APIs for data retrieval.

| Actions                                                                                                                                                            | Description                                                              | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ | ------------ |
| [CallWithBearerToken](../../../claude-platform/latest/userguide/iam-actions.md "../../../claude-platform/latest/userguide/iam-actions.md")                         | Make API calls using bearer token authentication                         | List         |
| [GetAccountStatus](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")    | Retrieve the status of account setup and AWS Marketplace registration    | Read         |
| [GetAgent](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")            | Retrieve details or versions of a managed agent                          | Read         |
| [GetBatchInference](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")   | Retrieve details of a batch inference request                            | Read         |
| [GetEnvironment](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")      | Retrieve details of a managed agent environment                          | Read         |
| [GetFile](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")             | Retrieve a file or its content from a workspace                          | Read         |
| [GetMemoryStore](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")      | Retrieve details of a memory store, its memories, or its memory versions | Read         |
| [GetModel](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")            | Retrieve information about a specific model                              | Read         |
| [GetSession](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | Retrieve details, events, or resources of a managed agent session        | Read         |
| [GetSkill](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")            | Retrieve details of a skill or its versions                              | Read         |
| [GetUserProfile](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")      | Retrieve details of a user profile                                       | Read         |
| [GetVault](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")            | Retrieve details of a credential vault or its credentials                | Read         |
| [GetWebhook](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | Retrieve details of a webhook                                            | Read         |
| [GetWorkspace](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")        | Retrieve details of a workspace                                          | Read         |
| [ListAgents](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | List managed agents in a workspace                                       | List         |
| [ListBatchInferences](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions") | List batch inference requests in a workspace                             | List         |
| [ListEnvironments](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")    | List managed agent environments in a workspace                           | List         |
| [ListFiles](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")           | List files in a workspace                                                | List         |
| [ListMemoryStores](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")    | List managed agent memory stores in a workspace                          | List         |
| [ListModels](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | List available models in a workspace                                     | List         |
| [ListSessions](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")        | List managed agent sessions in a workspace                               | List         |
| [ListSkills](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | List skills in a workspace                                               | List         |
| [ListTagsForResource](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions") | List tags for a resource                                                 | Read         |
| [ListUserProfiles](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")    | List user profiles in a workspace                                        | List         |
| [ListVaults](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")          | List managed agent credential vaults in a workspace                      | List         |
| [ListWebhooks](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")        | List webhooks in a workspace                                             | List         |
| [ListWorkspaces](../../../claude-platform/latest/userguide/iam-actions.md#iam-actions "../../../claude-platform/latest/userguide/iam-actions.md#iam-actions")      | List workspaces in an organization                                       | List         |
