# Data retrieval APIs for Claude Platform on AWS

Claude Platform on AWS provides the following APIs for data retrieval.

| Actions                                                                      | Description                                                           | Access level |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------ |
| [CallWithBearerToken](../../../index.md "../../../index.md")                 | Make API calls using bearer token authentication                      | List         |
| [GetAccountStatus](../../../index.md#welcome "../../../index.md#welcome")    | Retrieve the status of account setup and AWS Marketplace registration | Read         |
| [GetBatchInference](../../../index.md#welcome "../../../index.md#welcome")   | Retrieve details of a batch inference request                         | Read         |
| [GetFile](../../../index.md#welcome "../../../index.md#welcome")             | Retrieve a file or its content from a workspace                       | Read         |
| [GetModel](../../../index.md#welcome "../../../index.md#welcome")            | Retrieve information about a specific model                           | Read         |
| [GetSkill](../../../index.md#welcome "../../../index.md#welcome")            | Retrieve details of a skill or its versions                           | Read         |
| [GetUserProfile](../../../index.md#welcome "../../../index.md#welcome")      | Retrieve details of a user profile                                    | Read         |
| [GetWorkspace](../../../index.md#welcome "../../../index.md#welcome")        | Retrieve details of a workspace                                       | Read         |
| [ListBatchInferences](../../../index.md#welcome "../../../index.md#welcome") | List batch inference requests in a workspace                          | List         |
| [ListFiles](../../../index.md#welcome "../../../index.md#welcome")           | List files in a workspace                                             | List         |
| [ListModels](../../../index.md#welcome "../../../index.md#welcome")          | List available models in a workspace                                  | List         |
| [ListSkills](../../../index.md#welcome "../../../index.md#welcome")          | List skills in a workspace                                            | List         |
| [ListUserProfiles](../../../index.md#welcome "../../../index.md#welcome")    | List user profiles in a workspace                                     | List         |
| [ListWorkspaces](../../../index.md#welcome "../../../index.md#welcome")      | List workspaces in an organization                                    | List         |
