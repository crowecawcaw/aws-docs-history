

# Data retrieval APIs for AWS Batch
<a name="awsbatch"></a>

AWS Batch provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="batch-DescribeComputeEnvironments"></a>[DescribeComputeEnvironments](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeComputeEnvironments.html) | Describe one or more AWS Batch compute environments in your account | Read | 
| <a name="batch-DescribeConsumableResource"></a>[DescribeConsumableResource](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeConsumableResource.html) | Describe one or more AWS Batch consumable resource in your account | Read | 
| <a name="batch-DescribeJobDefinitions"></a>[DescribeJobDefinitions](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeJobDefinitions.html) | Describe one or more AWS Batch job definitions in your account | Read | 
| <a name="batch-DescribeJobQueues"></a>[DescribeJobQueues](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeJobQueues.html) | Describe one or more AWS Batch job queues in your account | Read | 
| <a name="batch-DescribeJobs"></a>[DescribeJobs](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeJobs.html) | Describe a list of AWS Batch jobs in your account | Read | 
| <a name="batch-DescribeQuotaShare"></a>[DescribeQuotaShare](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeQuotaShare.html) | Describe an AWS Batch quota share in your account | Read | 
| <a name="batch-DescribeSchedulingPolicies"></a>[DescribeSchedulingPolicies](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeSchedulingPolicies.html) | Describe one or more AWS Batch scheduling policies in your account | Read | 
| <a name="batch-DescribeServiceEnvironments"></a>[DescribeServiceEnvironments](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeServiceEnvironments.html) | Describe one or more AWS Batch service environments in your account | Read | 
| <a name="batch-DescribeServiceJob"></a>[DescribeServiceJob](https://docs.aws.amazon.com/batch/latest/APIReference/API_DescribeServiceJob.html) | Describe a AWS Batch service job in your account | Read | 
| <a name="batch-GetJobQueueSnapshot"></a>[GetJobQueueSnapshot](https://docs.aws.amazon.com/batch/latest/APIReference/API_GetJobQueueSnapshot.html) | Get a snapshot of an AWS Batch job queue in your account | Read | 
| <a name="batch-ListConsumableResources"></a>[ListConsumableResources](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListConsumableResources.html) | List AWS Batch consumable resources in your account | List | 
| <a name="batch-ListJobs"></a>[ListJobs](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListJobs.html) | List jobs for a specified AWS Batch job queue in your account | List | 
| <a name="batch-ListJobsByConsumableResource"></a>[ListJobsByConsumableResource](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListJobsByConsumableResource.html) | List AWS Batch jobs that require a specific consumable resource in your account | List | 
| <a name="batch-ListQuotaShares"></a>[ListQuotaShares](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListQuotaShares.html) | List AWS Batch quota shares in your account | List | 
| <a name="batch-ListSchedulingPolicies"></a>[ListSchedulingPolicies](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListSchedulingPolicies.html) | List AWS Batch scheduling policies in your account | Read | 
| <a name="batch-ListServiceJobs"></a>[ListServiceJobs](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListServiceJobs.html) | List service jobs for a specified AWS Batch job queue in your account | List | 
| <a name="batch-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/batch/latest/APIReference/API_ListTagsForResource.html) | List tags for an AWS Batch resource in your account | Read |
