# Data retrieval APIs for AWS Batch

AWS Batch provides the following APIs for data retrieval.

| Actions                                                                                                                                                                         | Description                                                                     | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------ |
| [DescribeComputeEnvironments](../../../batch/latest/APIReference/API_DescribeComputeEnvironments.md "../../../batch/latest/APIReference/API_DescribeComputeEnvironments.md")    | Describe one or more AWS Batch compute environments in your account             | Read         |
| [DescribeConsumableResource](../../../batch/latest/APIReference/API_DescribeConsumableResource.md "../../../batch/latest/APIReference/API_DescribeConsumableResource.md")       | Describe one or more AWS Batch consumable resource in your account              | Read         |
| [DescribeJobDefinitions](../../../batch/latest/APIReference/API_DescribeJobDefinitions.md "../../../batch/latest/APIReference/API_DescribeJobDefinitions.md")                   | Describe one or more AWS Batch job definitions in your account                  | Read         |
| [DescribeJobQueues](../../../batch/latest/APIReference/API_DescribeJobQueues.md "../../../batch/latest/APIReference/API_DescribeJobQueues.md")                                  | Describe one or more AWS Batch job queues in your account                       | Read         |
| [DescribeJobs](../../../batch/latest/APIReference/API_DescribeJobs.md "../../../batch/latest/APIReference/API_DescribeJobs.md")                                                 | Describe a list of AWS Batch jobs in your account                               | Read         |
| [DescribeSchedulingPolicies](../../../batch/latest/APIReference/API_DescribeSchedulingPolicies.md "../../../batch/latest/APIReference/API_DescribeSchedulingPolicies.md")       | Describe one or more AWS Batch scheduling policies in your account              | Read         |
| [DescribeServiceEnvironments](../../../batch/latest/APIReference/API_DescribeServiceEnvironments.md "../../../batch/latest/APIReference/API_DescribeServiceEnvironments.md")    | Describe one or more AWS Batch service environments in your account             | Read         |
| [DescribeServiceJob](../../../batch/latest/APIReference/API_DescribeServiceJob.md "../../../batch/latest/APIReference/API_DescribeServiceJob.md")                               | Describe a AWS Batch service job in your account                                | Read         |
| [GetJobQueueSnapshot](../../../batch/latest/APIReference/API_GetJobQueueSnapshot.md "../../../batch/latest/APIReference/API_GetJobQueueSnapshot.md")                            | Get a snapshot of an AWS Batch job queue in your account                        | Read         |
| [ListConsumableResources](../../../batch/latest/APIReference/API_ListConsumableResources.md "../../../batch/latest/APIReference/API_ListConsumableResources.md")                | List AWS Batch consumable resources in your account                             | List         |
| [ListJobs](../../../batch/latest/APIReference/API_ListJobs.md "../../../batch/latest/APIReference/API_ListJobs.md")                                                             | List jobs for a specified AWS Batch job queue in your account                   | List         |
| [ListJobsByConsumableResource](../../../batch/latest/APIReference/API_ListJobsByConsumableResource.md "../../../batch/latest/APIReference/API_ListJobsByConsumableResource.md") | List AWS Batch jobs that require a specific consumable resource in your account | List         |
| [ListSchedulingPolicies](../../../batch/latest/APIReference/API_ListSchedulingPolicies.md "../../../batch/latest/APIReference/API_ListSchedulingPolicies.md")                   | List AWS Batch scheduling policies in your account                              | Read         |
| [ListServiceJobs](../../../batch/latest/APIReference/API_ListServiceJobs.md "../../../batch/latest/APIReference/API_ListServiceJobs.md")                                        | List service jobs for a specified AWS Batch job queue in your account           | List         |
| [ListTagsForResource](../../../batch/latest/APIReference/API_ListTagsForResource.md "../../../batch/latest/APIReference/API_ListTagsForResource.md")                            | List tags for an AWS Batch resource in your account                             | Read         |
