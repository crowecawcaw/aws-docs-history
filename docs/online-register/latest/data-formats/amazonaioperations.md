# Data retrieval APIs for Amazon AI Operations

Amazon AI Operations provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                       | Description                                                                 | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------ |
| [GetEphemeralInvestigationResults](../../../AmazonCloudWatch/latest/monitoring/API_GetEphemeralInvestigationResults.md "../../../AmazonCloudWatch/latest/monitoring/API_GetEphemeralInvestigationResults.md") | Run and retrieve ephemeral investigation results                            | List         |
| [GetFact](../../../AmazonCloudWatch/latest/monitoring/API_GetFact.md "../../../AmazonCloudWatch/latest/monitoring/API_GetFact.md")                                                                            | Retrieve a fact in the specified investigation report                       | Read         |
| [GetFactVersions](../../../AmazonCloudWatch/latest/monitoring/API_GetFactVersions.md "../../../AmazonCloudWatch/latest/monitoring/API_GetFactVersions.md")                                                    | Retrieve all versions of a fact token in the specified investigation report | Read         |
| [GetInvestigation](../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigation.md "../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigation.md")                                                 | Retrieve an investigation in the specified investigation group              | Read         |
| [GetInvestigationEvent](../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationEvent.md "../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationEvent.md")                                  | Retrieve an investigation event in the specified investigation group        | Read         |
| [GetInvestigationGroup](../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroup.md "../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroup.md")                                  | Retrieve the specified investigation group                                  | Read         |
| [GetInvestigationGroupPolicy](../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroupPolicy.md "../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroupPolicy.md")                | Retrieve the investigation group policy attached to an investigation group  | Read         |
| [GetInvestigationResource](../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationResource.md "../../../AmazonCloudWatch/latest/monitoring/API_GetInvestigationResource.md")                         | Retrieve an investigation resource in the specified investigation group     | Read         |
| [GetReport](../../../AmazonCloudWatch/latest/monitoring/API_GetReport.md "../../../AmazonCloudWatch/latest/monitoring/API_GetReport.md")                                                                      | Retrieve a report in the specified investigation                            | Read         |
| [ListFacts](../../../AmazonCloudWatch/latest/monitoring/API_ListFacts.md "../../../AmazonCloudWatch/latest/monitoring/API_ListFacts.md")                                                                      | List all facts in the specified investigation report                        | List         |
| [ListInvestigationEvents](../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigationEvents.md "../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigationEvents.md")                            | List all investigation events in the specified investigation group          | List         |
| [ListInvestigationGroups](../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigationGroups.md "../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigationGroups.md")                            | List all investigation groups in the AWS account making the request         | List         |
| [ListInvestigations](../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigations.md "../../../AmazonCloudWatch/latest/monitoring/API_ListInvestigations.md")                                           | List all investigations that are in the specified investigation group       | List         |
| [ListReports](../../../AmazonCloudWatch/latest/monitoring/API_ListReports.md "../../../AmazonCloudWatch/latest/monitoring/API_ListReports.md")                                                                | List all reports in the specified investigation                             | List         |
| [ListTagsForResource](../../../AmazonCloudWatch/latest/monitoring/API_ListTagsForResource.md "../../../AmazonCloudWatch/latest/monitoring/API_ListTagsForResource.md")                                        | List the tags for the specified resource                                    | List         |
| [ValidateInvestigationGroup](../../../AmazonCloudWatch/latest/monitoring/API_ValidateInvestigationGroup.md "../../../AmazonCloudWatch/latest/monitoring/API_ValidateInvestigationGroup.md")                   | Validate the specified investigation group                                  | Read         |
