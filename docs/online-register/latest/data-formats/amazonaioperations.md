

# Data retrieval APIs for Amazon AI Operations
<a name="amazonaioperations"></a>

Amazon AI Operations provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aiops-GetEphemeralInvestigationResults"></a>[GetEphemeralInvestigationResults](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetEphemeralInvestigationResults.html) | Run and retrieve ephemeral investigation results | List | 
| <a name="aiops-GetFact"></a>[GetFact](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFact.html) | Retrieve a fact in the specified investigation report | Read | 
| <a name="aiops-GetFactVersions"></a>[GetFactVersions](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFactVersions.html) | Retrieve all versions of a fact token in the specified investigation report | Read | 
| <a name="aiops-GetInvestigation"></a>[GetInvestigation](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigation.html) | Retrieve an investigation in the specified investigation group | Read | 
| <a name="aiops-GetInvestigationEvent"></a>[GetInvestigationEvent](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationEvent.html) | Retrieve an investigation event in the specified investigation group | Read | 
| <a name="aiops-GetInvestigationGroup"></a>[GetInvestigationGroup](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroup.html) | Retrieve the specified investigation group | Read | 
| <a name="aiops-GetInvestigationGroupPolicy"></a>[GetInvestigationGroupPolicy](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroupPolicy.html) | Retrieve the investigation group policy attached to an investigation group | Read | 
| <a name="aiops-GetInvestigationResource"></a>[GetInvestigationResource](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationResource.html) | Retrieve an investigation resource in the specified investigation group | Read | 
| <a name="aiops-GetReport"></a>[GetReport](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetReport.html) | Retrieve a report in the specified investigation | Read | 
| <a name="aiops-ListFacts"></a>[ListFacts](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListFacts.html) | List all facts in the specified investigation report | List | 
| <a name="aiops-ListInvestigationEvents"></a>[ListInvestigationEvents](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationEvents.html) | List all investigation events in the specified investigation group | List | 
| <a name="aiops-ListInvestigationGroups"></a>[ListInvestigationGroups](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationGroups.html) | List all investigation groups in the AWS account making the request | List | 
| <a name="aiops-ListInvestigations"></a>[ListInvestigations](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigations.html) | List all investigations that are in the specified investigation group | List | 
| <a name="aiops-ListReports"></a>[ListReports](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListReports.html) | List all reports in the specified investigation | List | 
| <a name="aiops-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListTagsForResource.html) | List the tags for the specified resource | List | 
| <a name="aiops-ValidateInvestigationGroup"></a>[ValidateInvestigationGroup](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ValidateInvestigationGroup.html) | Validate the specified investigation group | Read |
