

# Data retrieval APIs for AWS Fault Injection Service
<a name="awsfaultinjectionservice"></a>

AWS Fault Injection Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="fis-GetAction"></a>[GetAction](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetAction.html) | Retrieve an AWS FIS action | Read | 
| <a name="fis-GetExperiment"></a>[GetExperiment](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetExperiment.html) | Retrieve an AWS FIS experiment | Read | 
| <a name="fis-GetExperimentTargetAccountConfiguration"></a>[GetExperimentTargetAccountConfiguration](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetExperimentTargetAccountConfiguration.html) | Retrieve an AWS FIS target account configuration for an AWS FIS experiment | Read | 
| <a name="fis-GetExperimentTemplate"></a>[GetExperimentTemplate](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetExperimentTemplate.html) | Retrieve an AWS FIS Experiment Template | Read | 
| <a name="fis-GetSafetyLever"></a>[GetSafetyLever](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetSafetyLever.html) | Get information about the safety lever | Read | 
| <a name="fis-GetTargetAccountConfiguration"></a>[GetTargetAccountConfiguration](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetTargetAccountConfiguration.html) | Retrieve an AWS FIS target account configuration for an AWS FIS experiment template | Read | 
| <a name="fis-GetTargetResourceType"></a>[GetTargetResourceType](https://docs.aws.amazon.com/fis/latest/APIReference/API_GetTargetResourceType.html) | Get information about the specified resource type | Read | 
| <a name="fis-ListActions"></a>[ListActions](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListActions.html) | List all available AWS FIS actions | List | 
| <a name="fis-ListExperimentResolvedTargets"></a>[ListExperimentResolvedTargets](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListExperimentResolvedTargets.html) | List resolved targets for AWS FIS experiments | List | 
| <a name="fis-ListExperimentTargetAccountConfigurations"></a>[ListExperimentTargetAccountConfigurations](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListExperimentTargetAccountConfigurations.html) | List target account configurations for AWS FIS experiments | List | 
| <a name="fis-ListExperimentTemplates"></a>[ListExperimentTemplates](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListExperimentTemplates.html) | List all available AWS FIS experiment templates | List | 
| <a name="fis-ListExperiments"></a>[ListExperiments](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListExperiments.html) | List all available AWS FIS experiments | List | 
| <a name="fis-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListTagsForResource.html) | List the tags for an AWS FIS resource | Read | 
| <a name="fis-ListTargetAccountConfigurations"></a>[ListTargetAccountConfigurations](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListTargetAccountConfigurations.html) | List target account configurations for AWS FIS experiment templates | List | 
| <a name="fis-ListTargetResourceTypes"></a>[ListTargetResourceTypes](https://docs.aws.amazon.com/fis/latest/APIReference/API_ListTargetResourceTypes.html) | List the resource types | List |
