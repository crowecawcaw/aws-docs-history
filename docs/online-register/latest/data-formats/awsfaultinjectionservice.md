# Data retrieval APIs for AWS Fault Injection Service

AWS Fault Injection Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                            | Description                                                                         | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- | ------------ |
| [GetAction](../../../fis/latest/APIReference/API_GetAction.md "../../../fis/latest/APIReference/API_GetAction.md")                                                                                                 | Retrieve an AWS FIS action                                                          | Read         |
| [GetExperiment](../../../fis/latest/APIReference/API_GetExperiment.md "../../../fis/latest/APIReference/API_GetExperiment.md")                                                                                     | Retrieve an AWS FIS experiment                                                      | Read         |
| [GetExperimentTargetAccountConfiguration](../../../fis/latest/APIReference/API_GetExperimentTargetAccountConfiguration.md "../../../fis/latest/APIReference/API_GetExperimentTargetAccountConfiguration.md")       | Retrieve an AWS FIS target account configuration for an AWS FIS experiment          | Read         |
| [GetExperimentTemplate](../../../fis/latest/APIReference/API_GetExperimentTemplate.md "../../../fis/latest/APIReference/API_GetExperimentTemplate.md")                                                             | Retrieve an AWS FIS Experiment Template                                             | Read         |
| [GetSafetyLever](../../../fis/latest/APIReference/API_GetSafetyLever.md "../../../fis/latest/APIReference/API_GetSafetyLever.md")                                                                                  | Get information about the safety lever                                              | Read         |
| [GetTargetAccountConfiguration](../../../fis/latest/APIReference/API_GetTargetAccountConfiguration.md "../../../fis/latest/APIReference/API_GetTargetAccountConfiguration.md")                                     | Retrieve an AWS FIS target account configuration for an AWS FIS experiment template | Read         |
| [GetTargetResourceType](../../../fis/latest/APIReference/API_GetTargetResourceType.md "../../../fis/latest/APIReference/API_GetTargetResourceType.md")                                                             | Get information about the specified resource type                                   | Read         |
| [ListActions](../../../fis/latest/APIReference/API_ListActions.md "../../../fis/latest/APIReference/API_ListActions.md")                                                                                           | List all available AWS FIS actions                                                  | List         |
| [ListExperimentResolvedTargets](../../../fis/latest/APIReference/API_ListExperimentResolvedTargets.md "../../../fis/latest/APIReference/API_ListExperimentResolvedTargets.md")                                     | List resolved targets for AWS FIS experiments                                       | List         |
| [ListExperimentTargetAccountConfigurations](../../../fis/latest/APIReference/API_ListExperimentTargetAccountConfigurations.md "../../../fis/latest/APIReference/API_ListExperimentTargetAccountConfigurations.md") | List target account configurations for AWS FIS experiments                          | List         |
| [ListExperimentTemplates](../../../fis/latest/APIReference/API_ListExperimentTemplates.md "../../../fis/latest/APIReference/API_ListExperimentTemplates.md")                                                       | List all available AWS FIS experiment templates                                     | List         |
| [ListExperiments](../../../fis/latest/APIReference/API_ListExperiments.md "../../../fis/latest/APIReference/API_ListExperiments.md")                                                                               | List all available AWS FIS experiments                                              | List         |
| [ListTagsForResource](../../../fis/latest/APIReference/API_ListTagsForResource.md "../../../fis/latest/APIReference/API_ListTagsForResource.md")                                                                   | List the tags for an AWS FIS resource                                               | Read         |
| [ListTargetAccountConfigurations](../../../fis/latest/APIReference/API_ListTargetAccountConfigurations.md "../../../fis/latest/APIReference/API_ListTargetAccountConfigurations.md")                               | List target account configurations for AWS FIS experiment templates                 | List         |
| [ListTargetResourceTypes](../../../fis/latest/APIReference/API_ListTargetResourceTypes.md "../../../fis/latest/APIReference/API_ListTargetResourceTypes.md")                                                       | List the resource types                                                             | List         |
