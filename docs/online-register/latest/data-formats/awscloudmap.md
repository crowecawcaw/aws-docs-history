# Data retrieval APIs for AWS Cloud Map

AWS Cloud Map provides the following APIs for data retrieval.

| Actions                                                                                                                                                      | Description                                                                               | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | ------------ |
| [DiscoverInstances](../../../cloud-map/latest/api/API_DiscoverInstances.md "../../../cloud-map/latest/api/API_DiscoverInstances.md")                         | Discover registered instances for a specified namespace and service                       | Read         |
| [DiscoverInstancesRevision](../../../cloud-map/latest/api/API_DiscoverInstancesRevision.md "../../../cloud-map/latest/api/API_DiscoverInstancesRevision.md") | Discover the revision of the instances for a specified namespace and service              | Read         |
| [GetInstance](../../../cloud-map/latest/api/API_GetInstance.md "../../../cloud-map/latest/api/API_GetInstance.md")                                           | Get information about a specified instance                                                | Read         |
| [GetInstancesHealthStatus](../../../cloud-map/latest/api/API_GetInstancesHealthStatus.md "../../../cloud-map/latest/api/API_GetInstancesHealthStatus.md")    | Get the current health status (Healthy, Unhealthy, or Unknown) of one or more instances   | Read         |
| [GetNamespace](../../../cloud-map/latest/api/API_GetNamespace.md "../../../cloud-map/latest/api/API_GetNamespace.md")                                        | Get information about a namespace                                                         | Read         |
| [GetOperation](../../../cloud-map/latest/api/API_GetOperation.md "../../../cloud-map/latest/api/API_GetOperation.md")                                        | Get information about a specific operation                                                | Read         |
| [GetResourcePolicy](../../../cloud-map/latest/dg/sharing-namespaces.md "../../../cloud-map/latest/dg/sharing-namespaces.md")                                 | Read the RAM access control policy for a namespace                                        | Read         |
| [GetService](../../../cloud-map/latest/api/API_GetService.md "../../../cloud-map/latest/api/API_GetService.md")                                              | Get the settings for a specified service                                                  | Read         |
| [GetServiceAttributes](../../../cloud-map/latest/api/API_GetServiceAttributes.md "../../../cloud-map/latest/api/API_GetServiceAttributes.md")                | Get the attributes for a specified service                                                | Read         |
| [ListInstances](../../../cloud-map/latest/api/API_ListInstances.md "../../../cloud-map/latest/api/API_ListInstances.md")                                     | Get summary information about the instances that were registered with a specified service | Read         |
| [ListNamespaces](../../../cloud-map/latest/api/API_ListNamespaces.md "../../../cloud-map/latest/api/API_ListNamespaces.md")                                  | Get information about the namespaces                                                      | Read         |
| [ListOperations](../../../cloud-map/latest/api/API_ListOperations.md "../../../cloud-map/latest/api/API_ListOperations.md")                                  | List operations that match the criteria that you specify                                  | List         |
| [ListServices](../../../cloud-map/latest/api/API_ListServices.md "../../../cloud-map/latest/api/API_ListServices.md")                                        | Get settings for all the services that match specified filters                            | Read         |
| [ListTagsForResource](../../../cloud-map/latest/api/API_ListTagsForResource.md "../../../cloud-map/latest/api/API_ListTagsForResource.md")                   | Lists tags for the specified resource                                                     | Read         |
