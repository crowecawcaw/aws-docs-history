# Data retrieval APIs for AWS CloudHSM

AWS CloudHSM provides the following APIs for data retrieval.

| Actions                                                                                                                                              | Description                                                          | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ |
| [DescribeBackups](../../../cloudhsm/latest/APIReference/API_DescribeBackups.md "../../../cloudhsm/latest/APIReference/API_DescribeBackups.md")       | Get information about backups of AWS CloudHSM clusters               | Read         |
| [DescribeClusters](../../../cloudhsm/latest/APIReference/API_DescribeClusters.md "../../../cloudhsm/latest/APIReference/API_DescribeClusters.md")    | Get information about AWS CloudHSM clusters                          | Read         |
| [GetResourcePolicy](../../../cloudhsm/latest/APIReference/API_GetResourcePolicy.md "../../../cloudhsm/latest/APIReference/API_GetResourcePolicy.md") | Get information about the policy attached to a AWS CloudHSM resource | Read         |
| [ListTags](../../../cloudhsm/latest/APIReference/API_ListTags.md "../../../cloudhsm/latest/APIReference/API_ListTags.md")                            | Get a list of tags for the specified AWS CloudHSM cluster            | Read         |
