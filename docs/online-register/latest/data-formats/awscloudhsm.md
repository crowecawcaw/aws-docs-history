

# Data retrieval APIs for AWS CloudHSM
<a name="awscloudhsm"></a>

AWS CloudHSM provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="cloudhsm-DescribeBackups"></a>[DescribeBackups](https://docs.aws.amazon.com/cloudhsm/latest/APIReference/API_DescribeBackups.html) | Get information about backups of AWS CloudHSM clusters | Read | 
| <a name="cloudhsm-DescribeClusters"></a>[DescribeClusters](https://docs.aws.amazon.com/cloudhsm/latest/APIReference/API_DescribeClusters.html) | Get information about AWS CloudHSM clusters | Read | 
| <a name="cloudhsm-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/cloudhsm/latest/APIReference/API_GetResourcePolicy.html) | Get information about the policy attached to a AWS CloudHSM resource | Read | 
| <a name="cloudhsm-ListTags"></a>[ListTags](https://docs.aws.amazon.com/cloudhsm/latest/APIReference/API_ListTags.html) | Get a list of tags for the specified AWS CloudHSM cluster | Read |
