# Data retrieval APIs for Apache Kafka APIs for Amazon MSK clusters

Apache Kafka APIs for Amazon MSK clusters provides the following APIs for data retrieval.

| Actions                                                                                                                                                                    | Description                                                                                                        | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------ |
| [DescribeCluster](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")                     | Describe various aspects of the cluster, equivalent to Apache Kafka's DESCRIBE CLUSTER ACL                         | List         |
| [DescribeClusterDynamicConfiguration](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions") | Describe the dynamic configuration of a cluster, equivalent to Apache Kafka's DESCRIBE_CONFIGS CLUSTER ACL         | List         |
| [DescribeGroup](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")                       | Describe groups on a cluster, equivalent to Apache Kafka's DESCRIBE GROUP ACL                                      | List         |
| [DescribeTopic](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")                       | Describe topics on a cluster, equivalent to Apache Kafka's DESCRIBE TOPIC ACL                                      | List         |
| [DescribeTopicDynamicConfiguration](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")   | Describe the dynamic configuration of topics on a cluster, equivalent to Apache Kafka's DESCRIBE_CONFIGS TOPIC ACL | List         |
| [DescribeTransactionalId](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")             | Describe transactional IDs on a cluster, equivalent to Apache Kafka's DESCRIBE TRANSACTIONAL_ID ACL                | List         |
| [ReadData](../../../msk/latest/developerguide/iam-access-control.md#actions "../../../msk/latest/developerguide/iam-access-control.md#actions")                            | Read data from topics on a cluster, equivalent to Apache Kafka's READ TOPIC ACL                                    | Read         |
