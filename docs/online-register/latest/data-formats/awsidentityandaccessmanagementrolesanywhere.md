# Data retrieval APIs for AWS Identity and Access Management Roles Anywhere

AWS Identity and Access Management Roles Anywhere provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------ |
| [GetCrl](../../../rolesanywhere/latest/APIReference/API_GetCrl.md "../../../rolesanywhere/latest/APIReference/API_GetCrl.md")                                        | Get a certificate revocation list (crl)  | Read         |
| [GetProfile](../../../rolesanywhere/latest/APIReference/API_GetProfile.md "../../../rolesanywhere/latest/APIReference/API_GetProfile.md")                            | Get a profile                            | Read         |
| [GetSubject](../../../rolesanywhere/latest/APIReference/API_GetSubject.md "../../../rolesanywhere/latest/APIReference/API_GetSubject.md")                            | Get a subject                            | Read         |
| [GetTrustAnchor](../../../rolesanywhere/latest/APIReference/API_GetTrustAnchor.md "../../../rolesanywhere/latest/APIReference/API_GetTrustAnchor.md")                | Get a trust anchor                       | Read         |
| [ListCrls](../../../rolesanywhere/latest/APIReference/API_ListCrls.md "../../../rolesanywhere/latest/APIReference/API_ListCrls.md")                                  | List certificate revocation lists (crls) | List         |
| [ListProfiles](../../../rolesanywhere/latest/APIReference/API_ListProfiles.md "../../../rolesanywhere/latest/APIReference/API_ListProfiles.md")                      | List profiles                            | List         |
| [ListSubjects](../../../rolesanywhere/latest/APIReference/API_ListSubjects.md "../../../rolesanywhere/latest/APIReference/API_ListSubjects.md")                      | List subjects                            | List         |
| [ListTagsForResource](../../../rolesanywhere/latest/APIReference/API_ListTagsForResource.md "../../../rolesanywhere/latest/APIReference/API_ListTagsForResource.md") | List tags for a resource                 | List         |
| [ListTrustAnchors](../../../rolesanywhere/latest/APIReference/API_ListTrustAnchors.md "../../../rolesanywhere/latest/APIReference/API_ListTrustAnchors.md")          | List trust anchors                       | List         |
