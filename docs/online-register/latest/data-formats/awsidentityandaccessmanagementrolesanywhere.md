

# Data retrieval APIs for AWS Identity and Access Management Roles Anywhere
<a name="awsidentityandaccessmanagementrolesanywhere"></a>

AWS Identity and Access Management Roles Anywhere provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="rolesanywhere-GetCrl"></a>[GetCrl](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetCrl.html) | Get a certificate revocation list (crl) | Read | 
| <a name="rolesanywhere-GetProfile"></a>[GetProfile](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetProfile.html) | Get a profile | Read | 
| <a name="rolesanywhere-GetSubject"></a>[GetSubject](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetSubject.html) | Get a subject | Read | 
| <a name="rolesanywhere-GetTrustAnchor"></a>[GetTrustAnchor](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetTrustAnchor.html) | Get a trust anchor | Read | 
| <a name="rolesanywhere-ListCrls"></a>[ListCrls](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListCrls.html) | List certificate revocation lists (crls) | List | 
| <a name="rolesanywhere-ListProfiles"></a>[ListProfiles](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListProfiles.html) | List profiles | List | 
| <a name="rolesanywhere-ListSubjects"></a>[ListSubjects](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListSubjects.html) | List subjects | List | 
| <a name="rolesanywhere-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | List | 
| <a name="rolesanywhere-ListTrustAnchors"></a>[ListTrustAnchors](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTrustAnchors.html) | List trust anchors | List |
