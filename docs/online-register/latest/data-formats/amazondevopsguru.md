

# Data retrieval APIs for Amazon DevOps Guru
<a name="amazondevopsguru"></a>

Amazon DevOps Guru provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="devops-guru-DescribeAccountHealth"></a>[DescribeAccountHealth](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeAccountHealth.html) | View the health of operations in your AWS account | Read | 
| <a name="devops-guru-DescribeAccountOverview"></a>[DescribeAccountOverview](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeAccountOverview.html) | View the health of operations within a time range in your AWS account | Read | 
| <a name="devops-guru-DescribeAnomaly"></a>[DescribeAnomaly](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeAnomaly.html) | List the details of a specified anomaly | Read | 
| <a name="devops-guru-DescribeEventSourcesConfig"></a>[DescribeEventSourcesConfig](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeEventSourcesConfig.html) | Retrieve details about event sources for DevOps Guru | Read | 
| <a name="devops-guru-DescribeFeedback"></a>[DescribeFeedback](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeFeedback.html) | View the feedback details of a specified insight | Read | 
| <a name="devops-guru-DescribeInsight"></a>[DescribeInsight](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeInsight.html) | List the details of a specified insight | Read | 
| <a name="devops-guru-DescribeOrganizationHealth"></a>[DescribeOrganizationHealth](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeOrganizationHealth.html) | View the health of operations in your organization | Read | 
| <a name="devops-guru-DescribeOrganizationOverview"></a>[DescribeOrganizationOverview](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeOrganizationOverview.html) | View the health of operations within a time range in your organization | Read | 
| <a name="devops-guru-DescribeOrganizationResourceCollectionHealth"></a>[DescribeOrganizationResourceCollectionHealth](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeOrganizationResourceCollectionHealth.html) | View the health of operations for each AWS CloudFormation stack or AWS Services or accounts specified in DevOps Guru in your organization | Read | 
| <a name="devops-guru-DescribeResourceCollectionHealth"></a>[DescribeResourceCollectionHealth](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeResourceCollectionHealth.html) | View the health of operations for each AWS CloudFormation stack specified in DevOps Guru | Read | 
| <a name="devops-guru-DescribeServiceIntegration"></a>[DescribeServiceIntegration](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_DescribeServiceIntegration.html) | View the integration status of services that can be integrated with DevOps Guru | Read | 
| <a name="devops-guru-GetCostEstimation"></a>[GetCostEstimation](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_GetCostEstimation.html) | List service resource cost estimates | Read | 
| <a name="devops-guru-GetResourceCollection"></a>[GetResourceCollection](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_GetResourceCollection.html) | List AWS CloudFormation stacks that DevOps Guru is configured to use | Read | 
| <a name="devops-guru-ListAnomaliesForInsight"></a>[ListAnomaliesForInsight](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListAnomaliesForInsight.html) | List anomalies of a given insight in your account | List | 
| <a name="devops-guru-ListAnomalousLogGroups"></a>[ListAnomalousLogGroups](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListAnomalousLogGroups.html) | List log anomalies of a given insight in your account | List | 
| <a name="devops-guru-ListEvents"></a>[ListEvents](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListEvents.html) | List resource events that are evaluated by DevOps Guru | List | 
| <a name="devops-guru-ListInsights"></a>[ListInsights](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListInsights.html) | List insights in your account | List | 
| <a name="devops-guru-ListMonitoredResources"></a>[ListMonitoredResources](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListMonitoredResources.html) | List resource monitored by DevOps Guru in your account | List | 
| <a name="devops-guru-ListNotificationChannels"></a>[ListNotificationChannels](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListNotificationChannels.html) | List notification channels configured for DevOps Guru in your account | List | 
| <a name="devops-guru-ListOrganizationInsights"></a>[ListOrganizationInsights](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListOrganizationInsights.html) | List insights in your organization | List | 
| <a name="devops-guru-ListRecommendations"></a>[ListRecommendations](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_ListRecommendations.html) | List a specified insight's recommendations | List | 
| <a name="devops-guru-SearchInsights"></a>[SearchInsights](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_SearchInsights.html) | Search insights in your account | List | 
| <a name="devops-guru-SearchOrganizationInsights"></a>[SearchOrganizationInsights](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_SearchOrganizationInsights.html) | Search insights in your organization | List | 
| <a name="devops-guru-StartCostEstimation"></a>[StartCostEstimation](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_StartCostEstimation.html) | Start the creation of an estimate of the monthly cost | Read |
