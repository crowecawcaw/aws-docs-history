| Actions                                                                                                                                                                                                                                     | Description                                                                                                                               | Access level |

| [DescribeAccountHealth](../../../devops-guru/latest/APIReference/API_DescribeAccountHealth.md "../../../devops-guru/latest/APIReference/API_DescribeAccountHealth.md")                                                                      | View the health of operations in your AWS account                                                                                         | Read         |
| [DescribeAccountOverview](../../../devops-guru/latest/APIReference/API_DescribeAccountOverview.md "../../../devops-guru/latest/APIReference/API_DescribeAccountOverview.md")                                                                | View the health of operations within a time range in your AWS account                                                                     | Read         |
| [DescribeAnomaly](../../../devops-guru/latest/APIReference/API_DescribeAnomaly.md "../../../devops-guru/latest/APIReference/API_DescribeAnomaly.md")                                                                                        | List the details of a specified anomaly                                                                                                   | Read         |
| [DescribeEventSourcesConfig](../../../devops-guru/latest/APIReference/API_DescribeEventSourcesConfig.md "../../../devops-guru/latest/APIReference/API_DescribeEventSourcesConfig.md")                                                       | Retrieve details about event sources for DevOps Guru                                                                                      | Read         |
| [DescribeFeedback](../../../devops-guru/latest/APIReference/API_DescribeFeedback.md "../../../devops-guru/latest/APIReference/API_DescribeFeedback.md")                                                                                     | View the feedback details of a specified insight                                                                                          | Read         |
| [DescribeInsight](../../../devops-guru/latest/APIReference/API_DescribeInsight.md "../../../devops-guru/latest/APIReference/API_DescribeInsight.md")                                                                                        | List the details of a specified insight                                                                                                   | Read         |

| [DescribeOrganizationOverview](../../../devops-guru/latest/APIReference/API_DescribeOrganizationOverview.md "../../../devops-guru/latest/APIReference/API_DescribeOrganizationOverview.md")                                                 | View the health of operations within a time range in your organization                                                                    | Read         |
| [DescribeOrganizationResourceCollectionHealth](../../../devops-guru/latest/APIReference/API_DescribeOrganizationResourceCollectionHealth.md "../../../devops-guru/latest/APIReference/API_DescribeOrganizationResourceCollectionHealth.md") | View the health of operations for each AWS CloudFormation stack or AWS Services or accounts specified in DevOps Guru in your organization | Read         |
| [DescribeResourceCollectionHealth](../../../devops-guru/latest/APIReference/API_DescribeResourceCollectionHealth.md "../../../devops-guru/latest/APIReference/API_DescribeResourceCollectionHealth.md")                                     | View the health of operations for each AWS CloudFormation stack specified in DevOps Guru                                                  | Read         |
