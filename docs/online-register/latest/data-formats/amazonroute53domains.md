# Data retrieval APIs for Amazon Route 53 Domains

Amazon Route 53 Domains provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                             | Description                                                                                                                                                                                              | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [CheckDomainAvailability](../../../Route53/latest/APIReference/API_domains_CheckDomainAvailability.md "../../../Route53/latest/APIReference/API_domains_CheckDomainAvailability.md")                | Check the availability of one domain name                                                                                                                                                                | Read         |
| [CheckDomainTransferability](../../../Route53/latest/APIReference/API_domains_CheckDomainTransferability.md "../../../Route53/latest/APIReference/API_domains_CheckDomainTransferability.md")       | Check whether a domain name can be transferred to Amazon Route 53                                                                                                                                        | Read         |
| [GetContactReachabilityStatus](../../../Route53/latest/APIReference/API_domains_GetContactReachabilityStatus.md "../../../Route53/latest/APIReference/API_domains_GetContactReachabilityStatus.md") | Get information about whether the registrant contact has responded for operations that require confirmation that the email address for the registrant contact is valid, such as registering a new domain | Read         |
| [GetDomainDetail](../../../Route53/latest/APIReference/API_domains_GetDomainDetail.md "../../../Route53/latest/APIReference/API_domains_GetDomainDetail.md")                                        | Get detailed information about a domain                                                                                                                                                                  | Read         |
| [GetDomainSuggestions](../../../Route53/latest/APIReference/API_domains_GetDomainSuggestions.md "../../../Route53/latest/APIReference/API_domains_GetDomainSuggestions.md")                         | Get a list of suggested domain names given a string, which can either be a domain name or simply a word or phrase (without spaces)                                                                       | Read         |
| [GetOperationDetail](../../../Route53/latest/APIReference/API_domains_GetOperationDetail.md "../../../Route53/latest/APIReference/API_domains_GetOperationDetail.md")                               | Get the current status of an operation that is not completed                                                                                                                                             | Read         |
| [ListDomains](../../../Route53/latest/APIReference/API_domains_ListDomains.md "../../../Route53/latest/APIReference/API_domains_ListDomains.md")                                                    | List all the domain names registered with Amazon Route 53 for the current AWS account                                                                                                                    | List         |
| [ListOperations](../../../Route53/latest/APIReference/API_domains_ListOperations.md "../../../Route53/latest/APIReference/API_domains_ListOperations.md")                                           | List the operation IDs of operations that are not yet complete                                                                                                                                           | List         |
| [ListPrices](../../../Route53/latest/APIReference/API_domains_ListPrices.md "../../../Route53/latest/APIReference/API_domains_ListPrices.md")                                                       | List the prices of operations for TLDs                                                                                                                                                                   | List         |
| [ListTagsForDomain](../../../Route53/latest/APIReference/API_domains_ListTagsForDomain.md "../../../Route53/latest/APIReference/API_domains_ListTagsForDomain.md")                                  | List all the tags that are associated with the specified domain                                                                                                                                          | Read         |
| [ViewBilling](../../../Route53/latest/APIReference/API_domains_ViewBilling.md "../../../Route53/latest/APIReference/API_domains_ViewBilling.md")                                                    | Get all the domain-related billing records for the current AWS account for a specified period                                                                                                            | Read         |
