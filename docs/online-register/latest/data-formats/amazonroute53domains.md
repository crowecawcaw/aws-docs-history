

# Data retrieval APIs for Amazon Route 53 Domains
<a name="amazonroute53domains"></a>

Amazon Route 53 Domains provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="route53domains-CheckDomainAvailability"></a>[CheckDomainAvailability](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_CheckDomainAvailability.html) | Check the availability of one domain name | Read | 
| <a name="route53domains-CheckDomainTransferability"></a>[CheckDomainTransferability](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_CheckDomainTransferability.html) | Check whether a domain name can be transferred to Amazon Route 53 | Read | 
| <a name="route53domains-GetContactReachabilityStatus"></a>[GetContactReachabilityStatus](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_GetContactReachabilityStatus.html) | Get information about whether the registrant contact has responded for operations that require confirmation that the email address for the registrant contact is valid, such as registering a new domain | Read | 
| <a name="route53domains-GetDomainDetail"></a>[GetDomainDetail](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_GetDomainDetail.html) | Get detailed information about a domain | Read | 
| <a name="route53domains-GetDomainSuggestions"></a>[GetDomainSuggestions](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_GetDomainSuggestions.html) | Get a list of suggested domain names given a string, which can either be a domain name or simply a word or phrase (without spaces) | Read | 
| <a name="route53domains-GetOperationDetail"></a>[GetOperationDetail](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_GetOperationDetail.html) | Get the current status of an operation that is not completed | Read | 
| <a name="route53domains-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_ListDomains.html) | List all the domain names registered with Amazon Route 53 for the current AWS account | List | 
| <a name="route53domains-ListOperations"></a>[ListOperations](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_ListOperations.html) | List the operation IDs of operations that are not yet complete | List | 
| <a name="route53domains-ListPrices"></a>[ListPrices](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_ListPrices.html) | List the prices of operations for TLDs | List | 
| <a name="route53domains-ListTagsForDomain"></a>[ListTagsForDomain](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_ListTagsForDomain.html) | List all the tags that are associated with the specified domain | Read | 
| <a name="route53domains-ViewBilling"></a>[ViewBilling](https://docs.aws.amazon.com/Route53/latest/APIReference/API_domains_ViewBilling.html) | Get all the domain-related billing records for the current AWS account for a specified period | Read |
