

# Data retrieval APIs for Amazon CodeGuru Reviewer
<a name="amazoncodegurureviewer"></a>

Amazon CodeGuru Reviewer provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="codeguru-reviewer-CreateConnectionToken"></a>[CreateConnectionToken](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/Welcome.html) | Perform webbased oauth handshake for 3rd party providers | Read | 
| <a name="codeguru-reviewer-DescribeCodeReview"></a>[DescribeCodeReview](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_DescribeCodeReview.html) | Describe a code review | Read | 
| <a name="codeguru-reviewer-DescribeRecommendationFeedback"></a>[DescribeRecommendationFeedback](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_DescribeRecommendationFeedback.html) | Describe a recommendation feedback on a code review | Read | 
| <a name="codeguru-reviewer-DescribeRepositoryAssociation"></a>[DescribeRepositoryAssociation](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_DescribeRepositoryAssociation.html) | Describe a repository association | Read | 
| <a name="codeguru-reviewer-GetMetricsData"></a>[GetMetricsData](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/Welcome.html) | View pull request metrics in console | Read | 
| <a name="codeguru-reviewer-ListCodeReviews"></a>[ListCodeReviews](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_ListCodeReviews.html) | List summary of code reviews | List | 
| <a name="codeguru-reviewer-ListRecommendationFeedback"></a>[ListRecommendationFeedback](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_ListRecommendationFeedback.html) | List summary of recommendation feedback on a code review | List | 
| <a name="codeguru-reviewer-ListRecommendations"></a>[ListRecommendations](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_ListRecommendations.html) | List summary of recommendations on a code review | List | 
| <a name="codeguru-reviewer-ListRepositoryAssociations"></a>[ListRepositoryAssociations](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_ListRepositoryAssociations.html) | List summary of repository associations | List | 
| <a name="codeguru-reviewer-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/API_ListTagsForResource.html) | List the resource attached to a associated repository ARN | List | 
| <a name="codeguru-reviewer-ListThirdPartyRepositories"></a>[ListThirdPartyRepositories](https://docs.aws.amazon.com/codeguru/latest/reviewer-api/Welcome.html) | List 3rd party providers repositories in console | Read |
