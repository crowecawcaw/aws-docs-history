# Data retrieval APIs for Amazon CodeGuru Reviewer

Amazon CodeGuru Reviewer provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                     | Description                                               | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- | ------------ |
| [CreateConnectionToken](../../../codeguru/latest/reviewer-api/Welcome.md "../../../codeguru/latest/reviewer-api/Welcome.md")                                                                | Perform webbased oauth handshake for 3rd party providers  | Read         |
| [DescribeCodeReview](../../../codeguru/latest/reviewer-api/API_DescribeCodeReview.md "../../../codeguru/latest/reviewer-api/API_DescribeCodeReview.md")                                     | Describe a code review                                    | Read         |
| [DescribeRecommendationFeedback](../../../codeguru/latest/reviewer-api/API_DescribeRecommendationFeedback.md "../../../codeguru/latest/reviewer-api/API_DescribeRecommendationFeedback.md") | Describe a recommendation feedback on a code review       | Read         |
| [DescribeRepositoryAssociation](../../../codeguru/latest/reviewer-api/API_DescribeRepositoryAssociation.md "../../../codeguru/latest/reviewer-api/API_DescribeRepositoryAssociation.md")    | Describe a repository association                         | Read         |
| [GetMetricsData](../../../codeguru/latest/reviewer-api/Welcome.md "../../../codeguru/latest/reviewer-api/Welcome.md")                                                                       | View pull request metrics in console                      | Read         |
| [ListCodeReviews](../../../codeguru/latest/reviewer-api/API_ListCodeReviews.md "../../../codeguru/latest/reviewer-api/API_ListCodeReviews.md")                                              | List summary of code reviews                              | List         |
| [ListRecommendationFeedback](../../../codeguru/latest/reviewer-api/API_ListRecommendationFeedback.md "../../../codeguru/latest/reviewer-api/API_ListRecommendationFeedback.md")             | List summary of recommendation feedback on a code review  | List         |
| [ListRecommendations](../../../codeguru/latest/reviewer-api/API_ListRecommendations.md "../../../codeguru/latest/reviewer-api/API_ListRecommendations.md")                                  | List summary of recommendations on a code review          | List         |
| [ListRepositoryAssociations](../../../codeguru/latest/reviewer-api/API_ListRepositoryAssociations.md "../../../codeguru/latest/reviewer-api/API_ListRepositoryAssociations.md")             | List summary of repository associations                   | List         |
| [ListTagsForResource](../../../codeguru/latest/reviewer-api/API_ListTagsForResource.md "../../../codeguru/latest/reviewer-api/API_ListTagsForResource.md")                                  | List the resource attached to a associated repository ARN | List         |
| [ListThirdPartyRepositories](../../../codeguru/latest/reviewer-api/Welcome.md "../../../codeguru/latest/reviewer-api/Welcome.md")                                                           | List 3rd party providers repositories in console          | Read         |
