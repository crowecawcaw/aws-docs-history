# Data retrieval APIs for Amazon CodeGuru Security

Amazon CodeGuru Security provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                              | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------ |
| [BatchGetFindings](../../../codeguru/latest/security-api/API_BatchGetFindings.md "../../../codeguru/latest/security-api/API_BatchGetFindings.md")                      | Batch retrieve specific findings generated by CodeGuru Security          | Read         |
| [GetAccountConfiguration](../../../codeguru/latest/security-api/API_GetAccountConfiguration.md "../../../codeguru/latest/security-api/API_GetAccountConfiguration.md") | Retrieve the account level configurations                                | Read         |
| [GetFindings](../../../codeguru/latest/security-api/API_GetFindings.md "../../../codeguru/latest/security-api/API_GetFindings.md")                                     | Retrieve findings for a scan generated by CodeGuru Security              | List         |
| [GetMetricsSummary](../../../codeguru/latest/security-api/API_GetMetricsSummary.md "../../../codeguru/latest/security-api/API_GetMetricsSummary.md")                   | Retrieve AWS accout level metrics summary generated by CodeGuru Security | Read         |
| [GetScan](../../../codeguru/latest/security-api/API_GetScan.md "../../../codeguru/latest/security-api/API_GetScan.md")                                                 | Retrieve CodeGuru Security scan metadata                                 | Read         |
| [ListFindings](${AuthZDocPage}.md "${AuthZDocPage}.md")                                                                                                                | Retrieve findings generated by CodeGuru Security                         | List         |
| [ListFindingsMetrics](../../../codeguru/latest/security-api/API_ListFindingsMetrics.md "../../../codeguru/latest/security-api/API_ListFindingsMetrics.md")             | Retrieve a list of account level findings metrics within a date range    | List         |
| [ListScans](../../../codeguru/latest/security-api/API_ListScans.md "../../../codeguru/latest/security-api/API_ListScans.md")                                           | Retrieve list of CodeGuru Security scan metadata                         | List         |
| [ListTagsForResource](../../../codeguru/latest/security-api/API_ListTagsForResource.md "../../../codeguru/latest/security-api/API_ListTagsForResource.md")             | Retrieve a list of tags for a scan name ARN                              | Read         |
