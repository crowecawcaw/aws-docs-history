# Data retrieval APIs for Amazon CodeCatalyst

Amazon CodeCatalyst provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                         | Description                                                                   | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------ |
| [GetBillingAuthorization](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                  | Describe the billing authorization for a connection                           | Read         |
| [GetConnection](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                            | Get a connection                                                              | Read         |
| [GetIdentityCenterApplication](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications")           | Get information about an IAM Identity Center application                      | Read         |
| [GetPendingConnection](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                     | Get a pending request to connect this account to an Amazon CodeCatalyst space | Read         |
| [ListConnections](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                          | List connections that are not pending                                         | List         |
| [ListIamRolesForConnection](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                | List IAM roles associated with a connection                                   | List         |
| [ListIdentityCenterApplications](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications")         | View a list of all IAM Identity Center applications in the account            | List         |
| [ListIdentityCenterApplicationsForSpace](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications") | View a list of IAM Identity Center applications by Amazon CodeCatalyst space  | List         |
| [ListSpacesForIdentityCenterApplication](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-applications") | View a list of Amazon CodeCatalyst spaces by IAM Identity Center application  | List         |
| [ListTagsForResource](../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections "../../../codecatalyst/latest/userguide/security-iam.md#permissions-reference-connections")                      | List tags for an Amazon CodeCatalyst resource                                 | Read         |
