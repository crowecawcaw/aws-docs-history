

# Data retrieval APIs for Amazon AppFlow
<a name="amazonappflow"></a>

Amazon AppFlow provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="appflow-DescribeConnector"></a>[DescribeConnector](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeConnector.html) | Describe a connector registered in Amazon AppFlow | Read | 
| <a name="appflow-DescribeConnectorEntity"></a>[DescribeConnectorEntity](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeConnectorEntity.html) | Describe all fields for an object in a login profile configured in Amazon AppFlow | Read | 
| <a name="appflow-DescribeConnectorFields"></a>[DescribeConnectorFields](https://docs.aws.amazon.com/appflow/latest/userguide/identity-access-management.html#appflow-api-actions) | Describe all fields for an object in a login profile configured in Amazon AppFlow (Console Only) | Read | 
| <a name="appflow-DescribeConnectorProfiles"></a>[DescribeConnectorProfiles](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeConnectorProfiles.html) | Describe all login profiles configured in Amazon AppFlow | Read | 
| <a name="appflow-DescribeConnectors"></a>[DescribeConnectors](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeConnectors.html ) | Describe all connectors supported by Amazon AppFlow | Read | 
| <a name="appflow-DescribeFlow"></a>[DescribeFlow](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeFlow.html) | Describe a specific flow configured in Amazon AppFlow | Read | 
| <a name="appflow-DescribeFlowExecution"></a>[DescribeFlowExecution](https://docs.aws.amazon.com/appflow/latest/userguide/identity-access-management.html#appflow-api-actions) | Describe all flow executions for a flow configured in Amazon AppFlow (Console Only) | Read | 
| <a name="appflow-DescribeFlowExecutionRecords"></a>[DescribeFlowExecutionRecords](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_DescribeFlowExecutionRecords.html) | Describe all flow executions for a flow configured in Amazon AppFlow | Read | 
| <a name="appflow-DescribeFlows"></a>[DescribeFlows](https://docs.aws.amazon.com/appflow/latest/userguide/identity-access-management.html#appflow-api-actions) | Describe all flows configured in Amazon AppFlow (Console Only) | Read | 
| <a name="appflow-ListConnectorEntities"></a>[ListConnectorEntities](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_ListConnectorEntities.html) | List all objects for a login profile configured in Amazon AppFlow | List | 
| <a name="appflow-ListConnectorFields"></a>[ListConnectorFields](https://docs.aws.amazon.com/appflow/latest/userguide/identity-access-management.html#appflow-api-actions) | List all objects for a login profile configured in Amazon AppFlow (Console Only) | Read | 
| <a name="appflow-ListConnectors"></a>[ListConnectors](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_ListConnectors.html) | List all connectors supported in Amazon AppFlow | List | 
| <a name="appflow-ListFlows"></a>[ListFlows](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_ListFlows.html) | List all flows configured in Amazon AppFlow | List | 
| <a name="appflow-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/appflow/1.0/APIReference/API_ListTagsForResource.html) | List tags for a flow | Read |
