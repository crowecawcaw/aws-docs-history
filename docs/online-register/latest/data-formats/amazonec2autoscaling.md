# Data retrieval APIs for Amazon EC2 Auto Scaling

Amazon EC2 Auto Scaling provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                             | Description                                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAccountLimits](../../../AutoScaling/latest/APIReference/API_DescribeAccountLimits.md "../../../AutoScaling/latest/APIReference/API_DescribeAccountLimits.md")                                              | Describe the current Auto Scaling resource limits for your AWS account                                                       | List         |
| [DescribeAdjustmentTypes](../../../AutoScaling/latest/APIReference/API_DescribeAdjustmentTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeAdjustmentTypes.md")                                        | Describe the policy adjustment types for use with PutScalingPolicy                                                           | List         |
| [DescribeAutoScalingGroups](../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingGroups.md "../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingGroups.md")                                  | Describe one or more Auto Scaling groups. If a list of names is not provided, the call describes all Auto Scaling groups     | List         |
| [DescribeAutoScalingInstances](../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingInstances.md "../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingInstances.md")                         | Describe one or more Auto Scaling instances. If a list is not provided, the call describes all instances                     | List         |
| [DescribeAutoScalingNotificationTypes](../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingNotificationTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeAutoScalingNotificationTypes.md") | Describe the notification types that are supported by Auto Scaling                                                           | List         |
| [DescribeInstanceRefreshes](../../../AutoScaling/latest/APIReference/API_DescribeInstanceRefreshes.md "../../../AutoScaling/latest/APIReference/API_DescribeInstanceRefreshes.md")                                  | Describe one or more instance refreshes for an Auto Scaling group                                                            | List         |
| [DescribeLaunchConfigurations](../../../AutoScaling/latest/APIReference/API_DescribeLaunchConfigurations.md "../../../AutoScaling/latest/APIReference/API_DescribeLaunchConfigurations.md")                         | Describe one or more launch configurations. If you omit the list of names, then the call describes all launch configurations | List         |
| [DescribeLifecycleHookTypes](../../../AutoScaling/latest/APIReference/API_DescribeLifecycleHookTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeLifecycleHookTypes.md")                               | Describe the available types of lifecycle hooks                                                                              | List         |
| [DescribeLifecycleHooks](../../../AutoScaling/latest/APIReference/API_DescribeLifecycleHooks.md "../../../AutoScaling/latest/APIReference/API_DescribeLifecycleHooks.md")                                           | Describe the lifecycle hooks for the specified Auto Scaling group                                                            | List         |
| [DescribeLoadBalancerTargetGroups](../../../AutoScaling/latest/APIReference/API_DescribeLoadBalancerTargetGroups.md "../../../AutoScaling/latest/APIReference/API_DescribeLoadBalancerTargetGroups.md")             | Describe the target groups for the specified Auto Scaling group                                                              | List         |
| [DescribeLoadBalancers](../../../AutoScaling/latest/APIReference/API_DescribeLoadBalancers.md "../../../AutoScaling/latest/APIReference/API_DescribeLoadBalancers.md")                                              | Describe the load balancers for the specified Auto Scaling group                                                             | List         |
| [DescribeMetricCollectionTypes](../../../AutoScaling/latest/APIReference/API_DescribeMetricCollectionTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeMetricCollectionTypes.md")                      | Describe the available CloudWatch metrics for Auto Scaling                                                                   | List         |
| [DescribeNotificationConfigurations](../../../AutoScaling/latest/APIReference/API_DescribeNotificationConfigurations.md "../../../AutoScaling/latest/APIReference/API_DescribeNotificationConfigurations.md")       | Describe the notification actions associated with the specified Auto Scaling group                                           | List         |
| [DescribePolicies](../../../AutoScaling/latest/APIReference/API_DescribePolicies.md "../../../AutoScaling/latest/APIReference/API_DescribePolicies.md")                                                             | Describe the policies for the specified Auto Scaling group                                                                   | List         |
| [DescribeScalingActivities](../../../AutoScaling/latest/APIReference/API_DescribeScalingActivities.md "../../../AutoScaling/latest/APIReference/API_DescribeScalingActivities.md")                                  | Describe one or more scaling activities for the specified Auto Scaling group                                                 | List         |
| [DescribeScalingProcessTypes](../../../AutoScaling/latest/APIReference/API_DescribeScalingProcessTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeScalingProcessTypes.md")                            | Describe the scaling process types for use with ResumeProcesses and SuspendProcesses                                         | List         |
| [DescribeScheduledActions](../../../AutoScaling/latest/APIReference/API_DescribeScheduledActions.md "../../../AutoScaling/latest/APIReference/API_DescribeScheduledActions.md")                                     | Describe the actions scheduled for your Auto Scaling group that haven't run                                                  | List         |
| [DescribeTags](../../../AutoScaling/latest/APIReference/API_DescribeTags.md "../../../AutoScaling/latest/APIReference/API_DescribeTags.md")                                                                         | Describe the specified tags                                                                                                  | Read         |
| [DescribeTerminationPolicyTypes](../../../AutoScaling/latest/APIReference/API_DescribeTerminationPolicyTypes.md "../../../AutoScaling/latest/APIReference/API_DescribeTerminationPolicyTypes.md")                   | Describe the termination policies supported by Auto Scaling                                                                  | List         |
| [DescribeTrafficSources](../../../AutoScaling/latest/APIReference/API_DescribeTrafficSources.md "../../../AutoScaling/latest/APIReference/API_DescribeTrafficSources.md")                                           | Describe the target groups for the specified Auto Scaling group                                                              | List         |
| [DescribeWarmPool](../../../AutoScaling/latest/APIReference/API_DescribeWarmPool.md "../../../AutoScaling/latest/APIReference/API_DescribeWarmPool.md")                                                             | Describe the warm pool associated with the Auto Scaling group                                                                | List         |
| [GetPredictiveScalingForecast](../../../AutoScaling/latest/APIReference/API_GetPredictiveScalingForecast.md "../../../AutoScaling/latest/APIReference/API_GetPredictiveScalingForecast.md")                         | Retrieve the forecast data for a predictive scaling policy                                                                   | List         |
