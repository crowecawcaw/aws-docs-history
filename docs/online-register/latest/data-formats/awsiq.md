# Data retrieval APIs for AWS IQ

AWS IQ provides the following APIs for data retrieval.

| Actions                                                                           | Description                                                  | Access level |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------ |
| [DownloadAttachment](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")     | Download existing attachment                                 | Read         |
| [GetBuyer](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")               | Read buyer information                                       | Read         |
| [GetCall](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")                | Read details of a voice/video call                           | Read         |
| [GetChatInfo](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")            | Read the chat environment details about a conversation       | Read         |
| [GetChatMessages](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")        | Read chat messages in a conversation                         | Read         |
| [GetChatToken](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")           | Request a websocket token for the conversation notifications | Read         |
| [GetCompanyChatMessages](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/") | Read chat messages in a company conversation                 | Read         |
| [GetCompanyProfile](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")      | Read a company profile                                       | Read         |
| [GetConversation](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")        | Read details of a conversation                               | Read         |
| [GetExpert](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")              | Read expert information                                      | Read         |
| [GetListing](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")             | Read a listing                                               | Read         |
| [GetMarketplaceSeller](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")   | Read a seller profile information                            | Read         |
| [GetPaymentRequest](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")      | Read a payment request                                       | Read         |
| [GetProposal](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")            | Read a proposal                                              | Read         |
| [GetRequest](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")             | Get a created request                                        | Read         |
| [GetReview](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")              | Read a review for an expert                                  | Read         |
| [ListAttachments](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")        | List existing attachments                                    | List         |
| [ListConversations](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")      | List existing conversations                                  | Read         |
| [ListExpertAccessLogs](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")   | List access logs of expert activity                          | Read         |
| [ListListings](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")           | List listings                                                | Read         |
| [ListPaymentRequests](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")    | List payment requests                                        | Read         |
| [ListProposals](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")          | List proposals                                               | Read         |
| [ListRequests](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")           | List requests that are created                               | Read         |
| [ListReviews](https://aws.amazon.com/iq/ "https://aws.amazon.com/iq/")            | List reviews for an expert                                   | Read         |
