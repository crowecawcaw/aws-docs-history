

# Data retrieval APIs for AWS IQ
<a name="awsiq"></a>

AWS IQ provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="iq-DownloadAttachment"></a>[DownloadAttachment](https://aws.amazon.com/iq/) | Download existing attachment | Read | 
| <a name="iq-GetBuyer"></a>[GetBuyer](https://aws.amazon.com/iq/) | Read buyer information | Read | 
| <a name="iq-GetCall"></a>[GetCall](https://aws.amazon.com/iq/) | Read details of a voice/video call | Read | 
| <a name="iq-GetChatInfo"></a>[GetChatInfo](https://aws.amazon.com/iq/) | Read the chat environment details about a conversation | Read | 
| <a name="iq-GetChatMessages"></a>[GetChatMessages](https://aws.amazon.com/iq/) | Read chat messages in a conversation | Read | 
| <a name="iq-GetChatToken"></a>[GetChatToken](https://aws.amazon.com/iq/) | Request a websocket token for the conversation notifications | Read | 
| <a name="iq-GetCompanyChatMessages"></a>[GetCompanyChatMessages](https://aws.amazon.com/iq/) | Read chat messages in a company conversation | Read | 
| <a name="iq-GetCompanyProfile"></a>[GetCompanyProfile](https://aws.amazon.com/iq/) | Read a company profile | Read | 
| <a name="iq-GetConversation"></a>[GetConversation](https://aws.amazon.com/iq/) | Read details of a conversation | Read | 
| <a name="iq-GetExpert"></a>[GetExpert](https://aws.amazon.com/iq/) | Read expert information | Read | 
| <a name="iq-GetListing"></a>[GetListing](https://aws.amazon.com/iq/) | Read a listing | Read | 
| <a name="iq-GetMarketplaceSeller"></a>[GetMarketplaceSeller](https://aws.amazon.com/iq/) | Read a seller profile information | Read | 
| <a name="iq-GetPaymentRequest"></a>[GetPaymentRequest](https://aws.amazon.com/iq/) | Read a payment request | Read | 
| <a name="iq-GetProposal"></a>[GetProposal](https://aws.amazon.com/iq/) | Read a proposal | Read | 
| <a name="iq-GetRequest"></a>[GetRequest](https://aws.amazon.com/iq/) | Get a created request | Read | 
| <a name="iq-GetReview"></a>[GetReview](https://aws.amazon.com/iq/) | Read a review for an expert | Read | 
| <a name="iq-ListAttachments"></a>[ListAttachments](https://aws.amazon.com/iq/) | List existing attachments | List | 
| <a name="iq-ListConversations"></a>[ListConversations](https://aws.amazon.com/iq/) | List existing conversations | Read | 
| <a name="iq-ListExpertAccessLogs"></a>[ListExpertAccessLogs](https://aws.amazon.com/iq/) | List access logs of expert activity | Read | 
| <a name="iq-ListListings"></a>[ListListings](https://aws.amazon.com/iq/) | List listings | Read | 
| <a name="iq-ListPaymentRequests"></a>[ListPaymentRequests](https://aws.amazon.com/iq/) | List payment requests | Read | 
| <a name="iq-ListProposals"></a>[ListProposals](https://aws.amazon.com/iq/) | List proposals | Read | 
| <a name="iq-ListRequests"></a>[ListRequests](https://aws.amazon.com/iq/) | List requests that are created | Read | 
| <a name="iq-ListReviews"></a>[ListReviews](https://aws.amazon.com/iq/) | List reviews for an expert | Read |
