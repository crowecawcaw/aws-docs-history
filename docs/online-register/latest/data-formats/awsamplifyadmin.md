# Data retrieval APIs for AWS Amplify Admin

AWS Amplify Admin provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                                                  | Description                                                                                                     | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetBackend](../../../amplify-admin-ui/latest/APIReference/backend-appid-details.md#GetBackend "../../../amplify-admin-ui/latest/APIReference/backend-appid-details.md#GetBackend")                                                                                      | Retrieve an existing Amplify Admin backend environment by appId and backendEnvironmentName                      | Read         |
| [GetBackendAPI](../../../amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-details.md#GetBackendAPI "../../../amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-details.md#GetBackendAPI")                       | Retrieve an API of an existing Amplify Admin backend environment by appId and backendEnvironmentName            | Read         |
| [GetBackendAPIModels](../../../amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-getmodels.md#GetBackendAPIModels "../../../amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-getmodels.md#GetBackendAPIModels") | Retrieve models for an API of an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read         |
| [GetBackendAuth](../../../amplify-admin-ui/latest/APIReference/backend-appid-auth-backendenvironmentname-details.md#GetBackendAuth "../../../amplify-admin-ui/latest/APIReference/backend-appid-auth-backendenvironmentname-details.md#GetBackendAuth")                  | Retrieve an auth resource of an existing Amplify Admin backend environment by appId and backendEnvironmentName  | Read         |
| [GetBackendJob](../../../amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname-jobid.md#GetBackendJob "../../../amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname-jobid.md#GetBackendJob")                           | Retrieve a job of an existing Amplify Admin backend environment by appId and backendEnvironmentName             | Read         |
| [GetBackendStorage](../../../amplify-admin-ui/latest/APIReference/backend-appid-storage.md#GetBackendStorage "../../../amplify-admin-ui/latest/APIReference/backend-appid-storage.md#GetBackendStorage")                                                                 | Retrieve an existing backend storage resource                                                                   | Read         |
| [GetToken](../../../amplify-admin-ui/latest/APIReference/backend-appid-challenge-sessionid.md#GetToken "../../../amplify-admin-ui/latest/APIReference/backend-appid-challenge-sessionid.md#GetToken")                                                                    | Retrieve an Amplify Admin challenge token by appId                                                              | Read         |
| [ListBackendJobs](../../../amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname.md#ListBackendJobs "../../../amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname.md#ListBackendJobs")                                 | Retrieve the jobs of an existing Amplify Admin backend environment by appId and backendEnvironmentName          | List         |
| [ListS3Buckets](../../../amplify-admin-ui/latest/APIReference/backend-appid-storage.md#ListS3Buckets "../../../amplify-admin-ui/latest/APIReference/backend-appid-storage.md#ListS3Buckets")                                                                             | Retrieve s3 buckets                                                                                             | List         |
