

# Data retrieval APIs for AWS Amplify Admin
<a name="awsamplifyadmin"></a>

AWS Amplify Admin provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="amplifybackend-GetBackend"></a>[GetBackend](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-details.html#GetBackend) | Retrieve an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read | 
| <a name="amplifybackend-GetBackendAPI"></a>[GetBackendAPI](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-details.html#GetBackendAPI) | Retrieve an API of an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read | 
| <a name="amplifybackend-GetBackendAPIModels"></a>[GetBackendAPIModels](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-api-backendenvironmentname-getmodels.html#GetBackendAPIModels) | Retrieve models for an API of an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read | 
| <a name="amplifybackend-GetBackendAuth"></a>[GetBackendAuth](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-auth-backendenvironmentname-details.html#GetBackendAuth) | Retrieve an auth resource of an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read | 
| <a name="amplifybackend-GetBackendJob"></a>[GetBackendJob](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname-jobid.html#GetBackendJob) | Retrieve a job of an existing Amplify Admin backend environment by appId and backendEnvironmentName | Read | 
| <a name="amplifybackend-GetBackendStorage"></a>[GetBackendStorage](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-storage.html#GetBackendStorage) | Retrieve an existing backend storage resource | Read | 
| <a name="amplifybackend-GetToken"></a>[GetToken](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-challenge-sessionid.html#GetToken) | Retrieve an Amplify Admin challenge token by appId | Read | 
| <a name="amplifybackend-ListBackendJobs"></a>[ListBackendJobs](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-job-backendenvironmentname.html#ListBackendJobs) | Retrieve the jobs of an existing Amplify Admin backend environment by appId and backendEnvironmentName | List | 
| <a name="amplifybackend-ListS3Buckets"></a>[ListS3Buckets](https://docs.aws.amazon.com/amplify-admin-ui/latest/APIReference/backend-appid-storage.html#ListS3Buckets) | Retrieve s3 buckets | List |
