

# Data retrieval APIs for AWS CodeCommit
<a name="awscodecommit"></a>

AWS CodeCommit provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="codecommit-BatchDescribeMergeConflicts"></a>[BatchDescribeMergeConflicts](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_BatchDescribeMergeConflicts.html) | Get information about multiple merge conflicts when attempting to merge two commits using either the three-way merge or the squash merge option | Read | 
| <a name="codecommit-BatchGetCommits"></a>[BatchGetCommits](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_BatchGetCommits.html) | Return information about one or more commits in an AWS CodeCommit repository | Read | 
| <a name="codecommit-BatchGetPullRequests"></a>[BatchGetPullRequests](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-pr) | Return information about one or more pull requests in an AWS CodeCommit repository | Read | 
| <a name="codecommit-BatchGetRepositories"></a>[BatchGetRepositories](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_BatchGetRepositories.html) | Get information about multiple repositories | Read | 
| <a name="codecommit-CancelUploadArchive"></a>[CancelUploadArchive](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-acp) | Cancel the uploading of an archive to a pipeline in AWS CodePipeline | Read | 
| <a name="codecommit-DescribeMergeConflicts"></a>[DescribeMergeConflicts](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_DescribeMergeConflicts.html) | Get information about specific merge conflicts when attempting to merge two commits using either the three-way or the squash merge option | Read | 
| <a name="codecommit-DescribePullRequestEvents"></a>[DescribePullRequestEvents](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_DescribePullRequestEvents.html) | Return information about one or more pull request events | Read | 
| <a name="codecommit-EvaluatePullRequestApprovalRules"></a>[EvaluatePullRequestApprovalRules](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_EvaluatePullRequestApprovalRules.html) | Evaluate whether a pull request is mergable based on its current approval state and approval rule requirements | Read | 
| <a name="codecommit-GetApprovalRuleTemplate"></a>[GetApprovalRuleTemplate](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetApprovalRuleTemplate.html) | Return information about an approval rule template | Read | 
| <a name="codecommit-GetBlob"></a>[GetBlob](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetBlob.html) | View the encoded content of an individual file in an AWS CodeCommit repository from the AWS CodeCommit console | Read | 
| <a name="codecommit-GetBlobDifferences"></a>[GetBlobDifferences](API_GetBlobDifferences.html) | Compute a structured, line-level diff between two blob versions in an AWS CodeCommit repository | Read | 
| <a name="codecommit-GetBranch"></a>[GetBranch](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetBranch.html) | Get details about a branch in an AWS CodeCommit repository with this API; does not control Git branch actions | Read | 
| <a name="codecommit-GetComment"></a>[GetComment](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetComment.html) | Get the content of a comment made on a change, file, or commit in a repository | Read | 
| <a name="codecommit-GetCommentReactions"></a>[GetCommentReactions](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetCommentReactions.html) | Get the reactions on a comment | Read | 
| <a name="codecommit-GetCommentsForComparedCommit"></a>[GetCommentsForComparedCommit](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetCommentsForComparedCommit.html) | Get information about comments made on the comparison between two commits | Read | 
| <a name="codecommit-GetCommentsForPullRequest"></a>[GetCommentsForPullRequest](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetCommentsForPullRequest.html) | Get comments made on a pull request | Read | 
| <a name="codecommit-GetCommit"></a>[GetCommit](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetCommit.html) | Return information about a commit, including commit message and committer information, with this API; does not control Git log actions | Read | 
| <a name="codecommit-GetCommitHistory"></a>[GetCommitHistory](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-code) | Get information about the history of commits in a repository | Read | 
| <a name="codecommit-GetCommitsFromMergeBase"></a>[GetCommitsFromMergeBase](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-pr) | Get information about the difference between commits in the context of a potential merge | Read | 
| <a name="codecommit-GetDifferences"></a>[GetDifferences](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetDifferences.html) | View information about the differences between valid commit specifiers such as a branch, tag, HEAD, commit ID, or other fully qualified reference | Read | 
| <a name="codecommit-GetFile"></a>[GetFile](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetFile.html) | Return the base-64 encoded contents of a specified file and its metadata | Read | 
| <a name="codecommit-GetFolder"></a>[GetFolder](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetFolder.html) | Return the contents of a specified folder in a repository | Read | 
| <a name="codecommit-GetMergeCommit"></a>[GetMergeCommit](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetMergeCommit.html) | Get information about a merge commit created by one of the merge options for pull requests that creates merge commits. Not all merge options create merge commits. This permission does not control Git merge actions | Read | 
| <a name="codecommit-GetMergeConflicts"></a>[GetMergeConflicts](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetMergeConflicts.html) | Get information about merge conflicts between the before and after commit IDs for a pull request in a repository | Read | 
| <a name="codecommit-GetMergeOptions"></a>[GetMergeOptions](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetMergeOptions.html) | Get information about merge options for pull requests that can be used to merge two commits; does not control Git merge actions | Read | 
| <a name="codecommit-GetObjectIdentifier"></a>[GetObjectIdentifier](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-code) | Resolve blobs, trees, and commits to their identifier | Read | 
| <a name="codecommit-GetPullRequest"></a>[GetPullRequest](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetPullRequest.html) | Get information about a pull request in a specified repository | Read | 
| <a name="codecommit-GetPullRequestApprovalStates"></a>[GetPullRequestApprovalStates](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetPullRequestApprovalStates.html) | Retrieve the current approvals on an inputted pull request | Read | 
| <a name="codecommit-GetPullRequestOverrideState"></a>[GetPullRequestOverrideState](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetPullRequestOverrideState.html) | Retrieve the current override state of a given pull request | Read | 
| <a name="codecommit-GetReferences"></a>[GetReferences](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-code) | Get details about references in an AWS CodeCommit repository; does not control Git reference actions | Read | 
| <a name="codecommit-GetRepository"></a>[GetRepository](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetRepository.html) | Get information about an AWS CodeCommit repository | Read | 
| <a name="codecommit-GetRepositoryTriggers"></a>[GetRepositoryTriggers](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_GetRepositoryTriggers.html) | Get information about triggers configured for a repository | Read | 
| <a name="codecommit-GetTree"></a>[GetTree](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-code) | View the contents of a specified tree in an AWS CodeCommit repository from the AWS CodeCommit console | Read | 
| <a name="codecommit-GetUploadArchiveStatus"></a>[GetUploadArchiveStatus](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-acp) | Get status information about an archive upload to a pipeline in AWS CodePipeline | Read | 
| <a name="codecommit-GitPull"></a>[GitPull](https://docs.aws.amazon.com/codecommit/latest/userguide/auth-and-access-control-permissions-reference.html#aa-git) | Pull information from an AWS CodeCommit repository to a local repo | Read | 
| <a name="codecommit-ListApprovalRuleTemplates"></a>[ListApprovalRuleTemplates](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListApprovalRuleTemplates.html) | List all approval rule templates in an AWS Region for the AWS account | List | 
| <a name="codecommit-ListAssociatedApprovalRuleTemplatesForRepository"></a>[ListAssociatedApprovalRuleTemplatesForRepository](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListAssociatedApprovalRuleTemplatesForRepository.html) | List approval rule templates that are associated with a repository | List | 
| <a name="codecommit-ListBranches"></a>[ListBranches](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListBranches.html) | List branches for an AWS CodeCommit repository with this API; does not control Git branch actions | List | 
| <a name="codecommit-ListFileCommitHistory"></a>[ListFileCommitHistory](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListFileCommitHistory.html) | List commits and changes to a specified file | List | 
| <a name="codecommit-ListPullRequests"></a>[ListPullRequests](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListPullRequests.html) | List pull requests for a specified repository | List | 
| <a name="codecommit-ListRepositories"></a>[ListRepositories](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListRepositories.html) | List information about AWS CodeCommit repositories in the current Region for your AWS account | List | 
| <a name="codecommit-ListRepositoriesForApprovalRuleTemplate"></a>[ListRepositoriesForApprovalRuleTemplate](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListRepositoriesForApprovalRuleTemplate.html) | List repositories that are associated with an approval rule template | List | 
| <a name="codecommit-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/codecommit/latest/APIReference/API_ListTagsForResource.html) | List the resource attached to a CodeCommit resource ARN | List |
