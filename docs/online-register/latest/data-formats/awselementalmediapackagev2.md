

# Data retrieval APIs for AWS Elemental MediaPackage V2
<a name="awselementalmediapackagev2"></a>

AWS Elemental MediaPackage V2 provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mediapackagev2-GetChannel"></a>[GetChannel](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetChannel.html) | Retrieve details of a channel in a channel group | Read | 
| <a name="mediapackagev2-GetChannelGroup"></a>[GetChannelGroup](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetChannelGroup.html) | Retrieve details of a channel group | Read | 
| <a name="mediapackagev2-GetChannelPolicy"></a>[GetChannelPolicy](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetChannelPolicy.html) | Retrieve a resource policy for a channel | Read | 
| <a name="mediapackagev2-GetHarvestJob"></a>[GetHarvestJob](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetHarvestJob.html) | Retrieve details of an harvest job | Read | 
| <a name="mediapackagev2-GetHeadObject"></a>[GetHeadObject](https://docs.aws.amazon.com/mediapackage/latest/userguide/dataplane-apis.html) | Make GetHeadObject requests to MediaPackage | Read | 
| <a name="mediapackagev2-GetObject"></a>[GetObject](https://docs.aws.amazon.com/mediapackage/latest/userguide/dataplane-apis.html) | Make GetObject requests to MediaPackage | Read | 
| <a name="mediapackagev2-GetOriginEndpoint"></a>[GetOriginEndpoint](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetOriginEndpoint.html) | Retrieve details of an origin endpoint | Read | 
| <a name="mediapackagev2-GetOriginEndpointPolicy"></a>[GetOriginEndpointPolicy](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_GetOriginEndpointPolicy.html) | Retrieve details of a resource policy for an origin endpoint | Read | 
| <a name="mediapackagev2-HarvestObject"></a>[HarvestObject](https://docs.aws.amazon.com/mediapackage/latest/userguide/dataplane-apis.html) | Make HarvestObject requests to MediaPackage | Read | 
| <a name="mediapackagev2-ListChannelGroups"></a>[ListChannelGroups](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_ListChannelGroups.html) | List all channel groups for an aws account | List | 
| <a name="mediapackagev2-ListChannels"></a>[ListChannels](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_ListChannels.html) | List all channels in a channel group | List | 
| <a name="mediapackagev2-ListHarvestJobs"></a>[ListHarvestJobs](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_ListHarvestJobs.html) | List all harvest jobs in a channel group, channel, origin endpoint | List | 
| <a name="mediapackagev2-ListOriginEndpoints"></a>[ListOriginEndpoints](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_ListOriginEndpoints.html) | List all origin endpoints of a channel | List | 
| <a name="mediapackagev2-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/mediapackage/latest/APIReference/API_ListTagsForResource.html) | List tags for the specified resource | Read |
