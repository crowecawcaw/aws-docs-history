# Data retrieval APIs for AWS Elemental MediaPackage V2

AWS Elemental MediaPackage V2 provides the following APIs for data retrieval.

| Actions                                                                                                                                                                        | Description                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ | ------------ |
| [GetChannel](../../../mediapackage/latest/APIReference/API_GetChannel.md "../../../mediapackage/latest/APIReference/API_GetChannel.md")                                        | Retrieve details of a channel in a channel group                   | Read         |
| [GetChannelGroup](../../../mediapackage/latest/APIReference/API_GetChannelGroup.md "../../../mediapackage/latest/APIReference/API_GetChannelGroup.md")                         | Retrieve details of a channel group                                | Read         |
| [GetChannelPolicy](../../../mediapackage/latest/APIReference/API_GetChannelPolicy.md "../../../mediapackage/latest/APIReference/API_GetChannelPolicy.md")                      | Retrieve a resource policy for a channel                           | Read         |
| [GetHarvestJob](../../../mediapackage/latest/APIReference/API_GetHarvestJob.md "../../../mediapackage/latest/APIReference/API_GetHarvestJob.md")                               | Retrieve details of an harvest job                                 | Read         |
| [GetHeadObject](../../../mediapackage/latest/userguide/dataplane-apis.md "../../../mediapackage/latest/userguide/dataplane-apis.md")                                           | Make GetHeadObject requests to MediaPackage                        | Read         |
| [GetObject](../../../mediapackage/latest/userguide/dataplane-apis.md "../../../mediapackage/latest/userguide/dataplane-apis.md")                                               | Make GetObject requests to MediaPackage                            | Read         |
| [GetOriginEndpoint](../../../mediapackage/latest/APIReference/API_GetOriginEndpoint.md "../../../mediapackage/latest/APIReference/API_GetOriginEndpoint.md")                   | Retrieve details of an origin endpoint                             | Read         |
| [GetOriginEndpointPolicy](../../../mediapackage/latest/APIReference/API_GetOriginEndpointPolicy.md "../../../mediapackage/latest/APIReference/API_GetOriginEndpointPolicy.md") | Retrieve details of a resource policy for an origin endpoint       | Read         |
| [HarvestObject](../../../mediapackage/latest/userguide/dataplane-apis.md "../../../mediapackage/latest/userguide/dataplane-apis.md")                                           | Make HarvestObject requests to MediaPackage                        | Read         |
| [ListChannelGroups](../../../mediapackage/latest/APIReference/API_ListChannelGroups.md "../../../mediapackage/latest/APIReference/API_ListChannelGroups.md")                   | List all channel groups for an aws account                         | List         |
| [ListChannels](../../../mediapackage/latest/APIReference/API_ListChannels.md "../../../mediapackage/latest/APIReference/API_ListChannels.md")                                  | List all channels in a channel group                               | List         |
| [ListHarvestJobs](../../../mediapackage/latest/APIReference/API_ListHarvestJobs.md "../../../mediapackage/latest/APIReference/API_ListHarvestJobs.md")                         | List all harvest jobs in a channel group, channel, origin endpoint | List         |
| [ListOriginEndpoints](../../../mediapackage/latest/APIReference/API_ListOriginEndpoints.md "../../../mediapackage/latest/APIReference/API_ListOriginEndpoints.md")             | List all origin endpoints of a channel                             | List         |
| [ListTagsForResource](../../../mediapackage/latest/APIReference/API_ListTagsForResource.md "../../../mediapackage/latest/APIReference/API_ListTagsForResource.md")             | List tags for the specified resource                               | Read         |
