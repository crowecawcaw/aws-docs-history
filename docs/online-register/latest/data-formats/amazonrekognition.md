

# Data retrieval APIs for Amazon Rekognition
<a name="amazonrekognition"></a>

Amazon Rekognition provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="rekognition-CompareFaces"></a>[CompareFaces](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_CompareFaces.html) | Compare faces in the source input image with each face detected in the target input image | Read | 
| <a name="rekognition-DescribeCollection"></a>[DescribeCollection](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DescribeCollection.html) | Read details about a collection | Read | 
| <a name="rekognition-DescribeDataset"></a>[DescribeDataset](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DescribeDataset.html) | Describe an Amazon Rekognition Custom Labels dataset | Read | 
| <a name="rekognition-DescribeProjectVersions"></a>[DescribeProjectVersions](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DescribeProjectVersions.html) | List the versions of a model in an Amazon Rekognition Custom Labels project | Read | 
| <a name="rekognition-DescribeProjects"></a>[DescribeProjects](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DescribeProjects.html) | List Amazon Rekognition Custom Labels projects | Read | 
| <a name="rekognition-DescribeStreamProcessor"></a>[DescribeStreamProcessor](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DescribeStreamProcessor.html) | Get information about the specified stream processor | Read | 
| <a name="rekognition-DetectCustomLabels"></a>[DetectCustomLabels](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectCustomLabels.html) | Detect custom labels in a supplied image | Read | 
| <a name="rekognition-DetectFaces"></a>[DetectFaces](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectFaces.html) | Detect human faces within an image provided as input | Read | 
| <a name="rekognition-DetectLabels"></a>[DetectLabels](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectLabels.html) | Detect instances of real-world labels within an image provided as input | Read | 
| <a name="rekognition-DetectModerationLabels"></a>[DetectModerationLabels](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectModerationLabels.html) | Detect moderation labels within the input image | Read | 
| <a name="rekognition-DetectProtectiveEquipment"></a>[DetectProtectiveEquipment](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectProtectiveEquipment.html) | Detect Personal Protective Equipment in the input image | Read | 
| <a name="rekognition-DetectText"></a>[DetectText](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_DetectText.html) | Detect text in the input image and convert it into machine-readable text | Read | 
| <a name="rekognition-GetCelebrityInfo"></a>[GetCelebrityInfo](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetCelebrityInfo.html) | Read the name, and additional information, of a celebrity | Read | 
| <a name="rekognition-GetCelebrityRecognition"></a>[GetCelebrityRecognition](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetCelebrityRecognition.html) | Read the celebrity recognition results found in a stored video by an asynchronous celebrity recognition job | Read | 
| <a name="rekognition-GetContentModeration"></a>[GetContentModeration](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetContentModeration.html) | Read the content moderation analysis results found in a stored video by an asynchronous content moderation job | Read | 
| <a name="rekognition-GetFaceDetection"></a>[GetFaceDetection](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetFaceDetection.html) | Read the faces detection results found in a stored video by an asynchronous face detection job | Read | 
| <a name="rekognition-GetFaceLivenessSessionResults"></a>[GetFaceLivenessSessionResults](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetFaceLivenessSessionResults.html) | Get results of a face liveness session | Read | 
| <a name="rekognition-GetFaceSearch"></a>[GetFaceSearch](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetFaceSearch.html) | Read the matching collection faces found in a stored video by an asynchronous face search job | Read | 
| <a name="rekognition-GetLabelDetection"></a>[GetLabelDetection](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetLabelDetection.html) | Read the label detected resuls found in a stored video by an asynchronous label detection job | Read | 
| <a name="rekognition-GetMediaAnalysisJob"></a>[GetMediaAnalysisJob](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetMediaAnalysisJob.html) | Read the reference to job results in S3 and additional information about a media analysis job | Read | 
| <a name="rekognition-GetPersonTracking"></a>[GetPersonTracking](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetPersonTracking.html) | Read the list of persons detected in a stored video by an asynchronous person tracking job | Read | 
| <a name="rekognition-GetSegmentDetection"></a>[GetSegmentDetection](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetSegmentDetection.html) | Get the vdeo segments found in a stored video by an asynchronous segment detection job | Read | 
| <a name="rekognition-GetTextDetection"></a>[GetTextDetection](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_GetTextDetection.html) | Get the text found in a stored video by an asynchronous text detection job | Read | 
| <a name="rekognition-ListCollections"></a>[ListCollections](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListCollections.html) | Read the collection Id's in your account | Read | 
| <a name="rekognition-ListDatasetEntries"></a>[ListDatasetEntries](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListDatasetEntries.html) | List the dataset entries in an existing Amazon Rekognition Custom Labels dataset | Read | 
| <a name="rekognition-ListDatasetLabels"></a>[ListDatasetLabels](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListDatasetLabels.html) | List the labels in a dataset | Read | 
| <a name="rekognition-ListFaces"></a>[ListFaces](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListFaces.html) | Read metadata for faces in the specificed collection | Read | 
| <a name="rekognition-ListMediaAnalysisJobs"></a>[ListMediaAnalysisJobs](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListMediaAnalysisJobs.html) | Read the list of media analysis jobs | Read | 
| <a name="rekognition-ListProjectPolicies"></a>[ListProjectPolicies](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListProjectPolicies.html) | List the resource policies attached to a project | Read | 
| <a name="rekognition-ListStreamProcessors"></a>[ListStreamProcessors](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListStreamProcessors.html) | Get a list of your stream processors | List | 
| <a name="rekognition-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListTagsForResource.html) | Return a list of tags associated with a resource | Read | 
| <a name="rekognition-ListUsers"></a>[ListUsers](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_ListUsers.html) | List UserIds and the UserStatus | Read | 
| <a name="rekognition-RecognizeCelebrities"></a>[RecognizeCelebrities](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_RecognizeCelebrities.html) | Detect celebrities in the input image | Read | 
| <a name="rekognition-SearchFaces"></a>[SearchFaces](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_SearchFaces.html) | Search the specificed collection for the supplied face ID | Read | 
| <a name="rekognition-SearchFacesByImage"></a>[SearchFacesByImage](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_SearchFacesByImage.html) | Search the specificed collection for the largest face in the input image | Read | 
| <a name="rekognition-SearchUsers"></a>[SearchUsers](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_SearchUsers.html) | Search the specificed collection for user match result with given either face ID or user ID | Read | 
| <a name="rekognition-SearchUsersByImage"></a>[SearchUsersByImage](https://docs.aws.amazon.com/rekognition/latest/APIReference/API_SearchUsersByImage.html) | Search the specificed collection for user match result by using the largest face in the input image | Read |
