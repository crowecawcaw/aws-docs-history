

# Data retrieval APIs for AWS Cost Explorer Service
<a name="awscostexplorerservice"></a>

AWS Cost Explorer Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="ce-DescribeCostCategoryDefinition"></a>[DescribeCostCategoryDefinition](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_DescribeCostCategoryDefinition.html) | Retrieve descriptions such as the name, ARN, rules, definition, and effective dates of a Cost Category | Read | 
| <a name="ce-DescribeNotificationSubscription"></a>[DescribeNotificationSubscription](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View Reservation expiration alerts | Read | 
| <a name="ce-DescribeReport"></a>[DescribeReport](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View Cost Explorer Reports page | Read | 
| <a name="ce-GetAnomalies"></a>[GetAnomalies](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetAnomalies.html) | Retrieve anomalies | Read | 
| <a name="ce-GetAnomalyMonitors"></a>[GetAnomalyMonitors](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetAnomalyMonitors.html) | Query Anomaly Monitors | Read | 
| <a name="ce-GetAnomalySubscriptions"></a>[GetAnomalySubscriptions](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetAnomalySubscriptions.html) | Query Anomaly Subscriptions | Read | 
| <a name="ce-GetApproximateUsageRecords"></a>[GetApproximateUsageRecords](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Retrieve approximate usage record count for the chosen resource, level, and hourly granularity preferences, derived from the past month's usage | Read | 
| <a name="ce-GetCommitmentPurchaseAnalysis"></a>[GetCommitmentPurchaseAnalysis](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCommitmentPurchaseAnalysis.html) | Retrieve the commitment purchase analysis for your account | Read | 
| <a name="ce-GetConsoleActionSetEnforced"></a>[GetConsoleActionSetEnforced](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View whether existing or fine-grained IAM actions are being used to control authorization to Billing, Cost Management, and Account consoles | Read | 
| <a name="ce-GetCostAndUsage"></a>[GetCostAndUsage](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostAndUsage.html) | Retrieve the cost and usage metrics for your account | Read | 
| <a name="ce-GetCostAndUsageComparisons"></a>[GetCostAndUsageComparisons](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostAndUsageComparisons.html) | Retrieve the cost and usage comparisons for your account | Read | 
| <a name="ce-GetCostAndUsageWithResources"></a>[GetCostAndUsageWithResources](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostAndUsageWithResources.html) | Retrieve the cost and usage metrics with resources for your account | Read | 
| <a name="ce-GetCostCategories"></a>[GetCostCategories](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostCategories.html) | Query Cost Catagory names and values for a specified time period | Read | 
| <a name="ce-GetCostComparisonDrivers"></a>[GetCostComparisonDrivers](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostComparisonDrivers.html) | Retrieve the cost drivers for your account | Read | 
| <a name="ce-GetCostForecast"></a>[GetCostForecast](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetCostForecast.html) | Retrieve a cost forecast for a forecast time period | Read | 
| <a name="ce-GetDimensionValues"></a>[GetDimensionValues](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetDimensionValues.html) | Retrieve all available filter values for a filter for a period of time | Read | 
| <a name="ce-GetPreferences"></a>[GetPreferences](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View Cost Explorer Preferences page | Read | 
| <a name="ce-GetReservationCoverage"></a>[GetReservationCoverage](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetReservationCoverage.html) | Retrieve the reservation coverage for your account | Read | 
| <a name="ce-GetReservationPurchaseRecommendation"></a>[GetReservationPurchaseRecommendation](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetReservationPurchaseRecommendation.html) | Retrieve the reservation recommendations for your account | Read | 
| <a name="ce-GetReservationUtilization"></a>[GetReservationUtilization](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetReservationUtilization.html) | Retrieve the reservation utilization for your account | Read | 
| <a name="ce-GetRightsizingRecommendation"></a>[GetRightsizingRecommendation](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetRightsizingRecommendation.html) | Retrieve the rightsizing recommendations for your account | Read | 
| <a name="ce-GetSavingsPlanPurchaseRecommendationDetails"></a>[GetSavingsPlanPurchaseRecommendationDetails](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetSavingsPlanPurchaseRecommendationDetails.html) | Retrieve the Savings Plan recommendation details for your account | Read | 
| <a name="ce-GetSavingsPlansCoverage"></a>[GetSavingsPlansCoverage](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetSavingsPlansCoverage.html) | Retrieve the Savings Plans coverage for your account | Read | 
| <a name="ce-GetSavingsPlansPurchaseRecommendation"></a>[GetSavingsPlansPurchaseRecommendation](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetSavingsPlansPurchaseRecommendation.html) | Retrieve the Savings Plans recommendations for your account | Read | 
| <a name="ce-GetSavingsPlansUtilization"></a>[GetSavingsPlansUtilization](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetSavingsPlansUtilization.html) | Retrieve the Savings Plans utilization for your account | Read | 
| <a name="ce-GetSavingsPlansUtilizationDetails"></a>[GetSavingsPlansUtilizationDetails](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetSavingsPlansUtilizationDetails.html) | Retrieve the Savings Plans utilization details for your account | Read | 
| <a name="ce-GetTags"></a>[GetTags](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetTags.html) | Query tags for a specified time period | Read | 
| <a name="ce-GetUsageForecast"></a>[GetUsageForecast](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_GetUsageForecast.html) | Retrieve a usage forecast for a forecast time period | Read | 
| <a name="ce-ListCommitmentPurchaseAnalyses"></a>[ListCommitmentPurchaseAnalyses](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_ListCommitmentPurchaseAnalyses.html) | Retrieve a list of your historical commitment purchase analyses | List | 
| <a name="ce-ListCostAllocationTagBackfillHistory"></a>[ListCostAllocationTagBackfillHistory](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_ListCostAllocationTagBackfillHistory.html) | List Cost Allocation Tag backfill history | List | 
| <a name="ce-ListCostAllocationTags"></a>[ListCostAllocationTags](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_ListCostAllocationTags.html) | List Cost Allocation Tags | List |
