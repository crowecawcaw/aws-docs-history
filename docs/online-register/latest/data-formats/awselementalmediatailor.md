# Data retrieval APIs for AWS Elemental MediaTailor

AWS Elemental MediaTailor provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                 | Description                                                                                                                 | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeChannel](../../../mediatailor/latest/apireference/channel-channelname.md "../../../mediatailor/latest/apireference/channel-channelname.md")                                                                                    | Retrieve the channel with the specified channel name                                                                        | Read         |
| [DescribeLiveSource](../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-livesource-livesourcename.md "../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-livesource-livesourcename.md") | Retrieve the live source with the specified live source name on the source location with the specified source location name | Read         |
| [DescribeProgram](../../../mediatailor/latest/apireference/channel-channelname-program-programname.md "../../../mediatailor/latest/apireference/channel-channelname-program-programname.md")                                            | Retrieve the program with the specified program name on the channel with the specified channel name                         | Read         |
| [DescribeSourceLocation](../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname.md "../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname.md")                                                 | Retrieve the source location with the specified source location name                                                        | Read         |
| [DescribeVodSource](../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-vodsource-vodsourcename.md "../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-vodsource-vodsourcename.md")      | Retrieve the VOD source with the specified VOD source name on the source location with the specified source location name   | Read         |
| [GetChannelPolicy](../../../mediatailor/latest/apireference/channel-channelname-policy.md "../../../mediatailor/latest/apireference/channel-channelname-policy.md")                                                                     | Read the IAM policy on the channel with the specified channel name                                                          | Read         |
| [GetChannelSchedule](../../../mediatailor/latest/apireference/channel-channelname-schedule.md "../../../mediatailor/latest/apireference/channel-channelname-schedule.md")                                                               | Retrieve the schedule of programs on the channel with the specified channel name                                            | Read         |
| [GetPlaybackConfiguration](../../../mediatailor/latest/apireference/playbackconfiguration-name.md "../../../mediatailor/latest/apireference/playbackconfiguration-name.md")                                                             | Retrieve the configuration for the specified name                                                                           | Read         |
| [GetPrefetchSchedule](../../../mediatailor/latest/apireference/prefetchschedule-playbackconfigurationname-name.md "../../../mediatailor/latest/apireference/prefetchschedule-playbackconfigurationname-name.md")                        | Retrieve prefetch schedule for a playback configuration with the specified prefetch schedule name                           | Read         |
| [ListAlerts](../../../mediatailor/latest/apireference/alerts.md "../../../mediatailor/latest/apireference/alerts.md")                                                                                                                   | Retrieve the list of alerts on a resource                                                                                   | Read         |
| [ListChannels](../../../mediatailor/latest/apireference/channels.md "../../../mediatailor/latest/apireference/channels.md")                                                                                                             | Retrieve the list of existing channels                                                                                      | Read         |
| [ListLiveSources](../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-livesources.md "../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-livesources.md")                                | Retrieve the list of existing live sources on the source location with the specified source location name                   | Read         |
| [ListPlaybackConfigurations](../../../mediatailor/latest/apireference/playbackconfigurations.md "../../../mediatailor/latest/apireference/playbackconfigurations.md")                                                                   | Retrieve the list of available configurations                                                                               | List         |
| [ListPrefetchSchedules](../../../mediatailor/latest/apireference/prefetchschedule-playbackconfigurationname.md "../../../mediatailor/latest/apireference/prefetchschedule-playbackconfigurationname.md")                                | Retrieve the list of prefetch schedules for a playback configuration                                                        | List         |
| [ListSourceLocations](../../../mediatailor/latest/apireference/sourcelocations.md "../../../mediatailor/latest/apireference/sourcelocations.md")                                                                                        | Retrieve the list of existing source locations                                                                              | Read         |
| [ListTagsForResource](../../../mediatailor/latest/apireference/tags-resourcearn.md "../../../mediatailor/latest/apireference/tags-resourcearn.md")                                                                                      | List the tags assigned to the specified playback configuration resource                                                     | Read         |
| [ListVodSources](../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-vodsources.md "../../../mediatailor/latest/apireference/sourcelocation-sourcelocationname-vodsources.md")                                   | Retrieve the list of existing VOD sources on the source location with the specified source location name                    | Read         |
