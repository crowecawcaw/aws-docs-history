

# Data retrieval APIs for Amazon CloudWatch Internet Monitor
<a name="amazoncloudwatchinternetmonitor"></a>

Amazon CloudWatch Internet Monitor provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="internetmonitor-GetHealthEvent"></a>[GetHealthEvent](https://docs.aws.amazon.com/internet-monitor/latest/api/API_GetHealthEvent.html) | Get information about a health event for a specified monitor | Read | 
| <a name="internetmonitor-GetInternetEvent"></a>[GetInternetEvent](https://docs.aws.amazon.com/internet-monitor/latest/api/API_GetInternetEvent.html) | Get information about a specified internet event | Read | 
| <a name="internetmonitor-GetMonitor"></a>[GetMonitor](https://docs.aws.amazon.com/internet-monitor/latest/api/API_GetMonitor.html) | Get information about a monitor | Read | 
| <a name="internetmonitor-GetQueryResults"></a>[GetQueryResults](https://docs.aws.amazon.com/internet-monitor/latest/api/API_GetQueryResults.html) | Get results for a data query for a monitor | Read | 
| <a name="internetmonitor-GetQueryStatus"></a>[GetQueryStatus](https://docs.aws.amazon.com/internet-monitor/latest/api/API_GetQueryStatus.html) | Get status for a data query for a monitor | Read | 
| <a name="internetmonitor-ListHealthEvents"></a>[ListHealthEvents](https://docs.aws.amazon.com/internet-monitor/latest/api/API_ListHealthEvents.html) | List all health events for a monitor | List | 
| <a name="internetmonitor-ListInternetEvents"></a>[ListInternetEvents](https://docs.aws.amazon.com/internet-monitor/latest/api/API_ListInternetEvents.html) | List all internet events | List | 
| <a name="internetmonitor-ListMonitors"></a>[ListMonitors](https://docs.aws.amazon.com/internet-monitor/latest/api/API_ListMonitors.html) | List all monitors in an account and their statuses | List | 
| <a name="internetmonitor-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/internet-monitor/latest/api/API_ListTagsForResource.html) | List the tags for a resource | Read | 
| <a name="internetmonitor-StartQuery"></a>[StartQuery](https://docs.aws.amazon.com/internet-monitor/latest/api/API_StartQuery.html) | Start a data query for a monitor | Read | 
| <a name="internetmonitor-StopQuery"></a>[StopQuery](https://docs.aws.amazon.com/internet-monitor/latest/api/API_StopQuery.html) | Stop a data query for a monitor | Read |
