# Data retrieval APIs for Amazon CloudWatch Internet Monitor

Amazon CloudWatch Internet Monitor provides the following APIs for data retrieval.

| Actions                                                                                                                                                  | Description                                                  | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------ |
| [GetHealthEvent](../../../internet-monitor/latest/api/API_GetHealthEvent.md "../../../internet-monitor/latest/api/API_GetHealthEvent.md")                | Get information about a health event for a specified monitor | Read         |
| [GetInternetEvent](../../../internet-monitor/latest/api/API_GetInternetEvent.md "../../../internet-monitor/latest/api/API_GetInternetEvent.md")          | Get information about a specified internet event             | Read         |
| [GetMonitor](../../../internet-monitor/latest/api/API_GetMonitor.md "../../../internet-monitor/latest/api/API_GetMonitor.md")                            | Get information about a monitor                              | Read         |
| [GetQueryResults](../../../internet-monitor/latest/api/API_GetQueryResults.md "../../../internet-monitor/latest/api/API_GetQueryResults.md")             | Get results for a data query for a monitor                   | Read         |
| [GetQueryStatus](../../../internet-monitor/latest/api/API_GetQueryStatus.md "../../../internet-monitor/latest/api/API_GetQueryStatus.md")                | Get status for a data query for a monitor                    | Read         |
| [ListHealthEvents](../../../internet-monitor/latest/api/API_ListHealthEvents.md "../../../internet-monitor/latest/api/API_ListHealthEvents.md")          | List all health events for a monitor                         | List         |
| [ListInternetEvents](../../../internet-monitor/latest/api/API_ListInternetEvents.md "../../../internet-monitor/latest/api/API_ListInternetEvents.md")    | List all internet events                                     | List         |
| [ListMonitors](../../../internet-monitor/latest/api/API_ListMonitors.md "../../../internet-monitor/latest/api/API_ListMonitors.md")                      | List all monitors in an account and their statuses           | List         |
| [ListTagsForResource](../../../internet-monitor/latest/api/API_ListTagsForResource.md "../../../internet-monitor/latest/api/API_ListTagsForResource.md") | List the tags for a resource                                 | Read         |
| [StartQuery](../../../internet-monitor/latest/api/API_StartQuery.md "../../../internet-monitor/latest/api/API_StartQuery.md")                            | Start a data query for a monitor                             | Read         |
| [StopQuery](../../../internet-monitor/latest/api/API_StopQuery.md "../../../internet-monitor/latest/api/API_StopQuery.md")                               | Stop a data query for a monitor                              | Read         |
