| [ListConnectors](../../../transform/latest/userguide/security_iam_permissions.md "../../../transform/latest/userguide/security_iam_permissions.md")      | Invoke ListConnectors on AWS Transform      | List         |
| [ListProfiles](../../../transform/latest/userguide/security_iam_permissions.md "../../../transform/latest/userguide/security_iam_permissions.md")        | Invoke ListProfiles on AWS Transform        | List         |
