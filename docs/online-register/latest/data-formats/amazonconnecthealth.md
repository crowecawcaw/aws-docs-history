# Data retrieval APIs for Amazon Connect Health

Amazon Connect Health provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                     | Description                                                                             | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------ |
| [GetAgent](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                                 | Retrieve an agent configuration, defaulting to the most recent version if not specified | Read         |
| [GetCareTeamProvider](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                      | Retrieve the care team provider of a patient                                            | Read         |
| [GetDomain](../../../connecthealth/latest/APIReference/API_GetDomain.md "../../../connecthealth/latest/APIReference/API_GetDomain.md")                                                                      | Retrieve information about a domain                                                     | Read         |
| [GetDomainAnalytics](../../../connecthealth/latest/APIReference/API_GetDomainAnalytics.md "../../../connecthealth/latest/APIReference/API_GetDomainAnalytics.md")                                           | Retrieve aggregated analytics for a domain                                              | Read         |
| [GetIntegration](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                           | Get an existing integration                                                             | Read         |
| [GetMedicalScribeListeningSession](../../../connecthealth/latest/APIReference/API_GetMedicalScribeListeningSession.md "../../../connecthealth/latest/APIReference/API_GetMedicalScribeListeningSession.md") | Retrieve details about an existing Medical Scribe listening session                     | Read         |
| [GetPatient](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                               | Retrieve patient information                                                            | Read         |
| [GetPatientInsightsJob](../../../connecthealth/latest/APIReference/API_GetPatientInsightsJob.md "../../../connecthealth/latest/APIReference/API_GetPatientInsightsJob.md")                                  | Get details of a started patient insights job                                           | Read         |
| [GetPractitioner](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                          | Retrieve practitioner information                                                       | Read         |
| [GetSessionContext](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                        | Retrieve structured session context including attributes and collected data             | Read         |
| [GetSubscription](../../../connecthealth/latest/APIReference/API_GetSubscription.md "../../../connecthealth/latest/APIReference/API_GetSubscription.md")                                                    | Retrieve information about a subscription                                               | Read         |
| [ListAgents](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                               | List all agents in a domain                                                             | List         |
| [ListAppointmentSlots](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                     | List available appointment slots                                                        | Read         |
| [ListDomains](../../../connecthealth/latest/APIReference/API_ListDomains.md "../../../connecthealth/latest/APIReference/API_ListDomains.md")                                                                | List domains for a given account                                                        | List         |
| [ListIntegrations](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                         | List integrations for a domain                                                          | List         |
| [ListPatientAppointments](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                  | List patient appointments                                                               | Read         |
| [ListPatientInsuranceCoverages](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                            | List patient insurance coverages                                                        | Read         |
| [ListPatientMedications](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                   | List patient medications                                                                | Read         |
| [ListProviders](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                            | Retrieve active providers available for scheduling appointments with a patient          | Read         |
| [ListSessionRecords](../../../connecthealth/latest/APIReference/API_ListSessionRecords.md "../../../connecthealth/latest/APIReference/API_ListSessionRecords.md")                                           | List session records for a domain                                                       | List         |
| [ListSubscriptions](../../../connecthealth/latest/APIReference/API_ListSubscriptions.md "../../../connecthealth/latest/APIReference/API_ListSubscriptions.md")                                              | List all subscriptions within a domain                                                  | List         |
| [ListTagsForResource](../../../connecthealth/latest/APIReference/API_ListTagsForResource.md "../../../connecthealth/latest/APIReference/API_ListTagsForResource.md")                                        | List the tags for the specified resource                                                | List         |
| [MatchPatient](../../../connecthealth/latest/userguide/patient-engagement-overview.md "../../../connecthealth/latest/userguide/patient-engagement-overview.md")                                             | Match a patient                                                                         | Read         |
