# Data retrieval APIs for Amazon Connect Health

Amazon Connect Health provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                   | Description                                                                             | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------ |
| [GetAgent](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                       | Retrieve an agent configuration, defaulting to the most recent version if not specified | Read         |
| [GetCareTeamProvider](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                            | Retrieve the care team provider of a patient                                            | Read         |
| [GetDomain](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                      | Retrieve information about a domain                                                     | Read         |
| [GetIntegration](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                 | Get an existing integration                                                             | Read         |
| [GetMedicalScribeListeningSession](../../../connecthealth/latest/api/API_GetMedicalScribeListeningSession.md "../../../connecthealth/latest/api/API_GetMedicalScribeListeningSession.md") | Retrieve details about an existing Medical Scribe listening session                     | Read         |
| [GetPatient](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                     | Retrieve patient information                                                            | Read         |
| [GetPatientInsightsJob](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                          | Get details of a started patient insights job                                           | Read         |
| [GetPractitioner](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                | Retrieve practitioner information                                                       | Read         |
| [GetSessionContext](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                              | Retrieve structured session context including attributes and collected data             | Read         |
| [GetSubscription](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                | Retrieve information about a subscription                                               | Read         |
| [ListAgents](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                     | List all agents in a domain                                                             | List         |
| [ListAppointmentSlots](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                           | List available appointment slots                                                        | Read         |
| [ListDomains](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                    | List domains for a given account                                                        | List         |
| [ListIntegrations](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                               | List integrations for a domain                                                          | List         |
| [ListPatientAppointments](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                        | List patient appointments                                                               | Read         |
| [ListPatientInsuranceCoverages](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                  | List patient insurance coverages                                                        | Read         |
| [ListProviders](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                  | Retrieve active providers available for scheduling appointments with a patient          | Read         |
| [ListSubscriptions](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                              | List all subscriptions within a domain                                                  | List         |
| [ListTagsForResource](../../../connecthealth/latest/api/API_ListTagsForResource.md "../../../connecthealth/latest/api/API_ListTagsForResource.md")                                        | List the tags for the specified resource                                                | List         |
| [MatchPatient](../../../connecthealth/latest/userguide.md "../../../connecthealth/latest/userguide.md")                                                                                   | Match a patient                                                                         | Read         |
