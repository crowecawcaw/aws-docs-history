

# Data retrieval APIs for Amazon Connect Health
<a name="amazonconnecthealth"></a>

Amazon Connect Health provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="health-agent-GetAgent"></a>[GetAgent](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve an agent configuration, defaulting to the most recent version if not specified | Read | 
| <a name="health-agent-GetCareTeamProvider"></a>[GetCareTeamProvider](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve the care team provider of a patient | Read | 
| <a name="health-agent-GetDomain"></a>[GetDomain](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_GetDomain.html) | Retrieve information about a domain | Read | 
| <a name="health-agent-GetDomainAnalytics"></a>[GetDomainAnalytics](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_GetDomainAnalytics.html) | Retrieve aggregated analytics for a domain | Read | 
| <a name="health-agent-GetIntegration"></a>[GetIntegration](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Get an existing integration | Read | 
| <a name="health-agent-GetMedicalScribeListeningSession"></a>[GetMedicalScribeListeningSession](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_GetMedicalScribeListeningSession.html) | Retrieve details about an existing Medical Scribe listening session | Read | 
| <a name="health-agent-GetPatient"></a>[GetPatient](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve patient information | Read | 
| <a name="health-agent-GetPatientInsightsJob"></a>[GetPatientInsightsJob](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_GetPatientInsightsJob.html) | Get details of a started patient insights job | Read | 
| <a name="health-agent-GetPractitioner"></a>[GetPractitioner](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve practitioner information | Read | 
| <a name="health-agent-GetSessionContext"></a>[GetSessionContext](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve structured session context including attributes and collected data | Read | 
| <a name="health-agent-GetSubscription"></a>[GetSubscription](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_GetSubscription.html) | Retrieve information about a subscription | Read | 
| <a name="health-agent-ListAgents"></a>[ListAgents](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List all agents in a domain | List | 
| <a name="health-agent-ListAppointmentSlots"></a>[ListAppointmentSlots](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List available appointment slots | Read | 
| <a name="health-agent-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_ListDomains.html) | List domains for a given account | List | 
| <a name="health-agent-ListIntegrations"></a>[ListIntegrations](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List integrations for a domain | List | 
| <a name="health-agent-ListPatientAppointments"></a>[ListPatientAppointments](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List patient appointments | Read | 
| <a name="health-agent-ListPatientInsuranceCoverages"></a>[ListPatientInsuranceCoverages](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List patient insurance coverages | Read | 
| <a name="health-agent-ListPatientMedications"></a>[ListPatientMedications](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | List patient medications | Read | 
| <a name="health-agent-ListProviders"></a>[ListProviders](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Retrieve active providers available for scheduling appointments with a patient | Read | 
| <a name="health-agent-ListSessionRecords"></a>[ListSessionRecords](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_ListSessionRecords.html) | List session records for a domain | List | 
| <a name="health-agent-ListSubscriptions"></a>[ListSubscriptions](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_ListSubscriptions.html) | List all subscriptions within a domain | List | 
| <a name="health-agent-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/connecthealth/latest/APIReference/API_ListTagsForResource.html) | List the tags for the specified resource | List | 
| <a name="health-agent-MatchPatient"></a>[MatchPatient](https://docs.aws.amazon.com/connecthealth/latest/userguide/patient-engagement-overview.html) | Match a patient | Read |
