

# Data retrieval APIs for AWS Storage Gateway
<a name="awsstoragegateway"></a>

AWS Storage Gateway provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="storagegateway-DescribeAvailabilityMonitorTest"></a>[DescribeAvailabilityMonitorTest](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeAvailabilityMonitorTest.html) | Get the information about the most recent high availability monitoring test that was performed on the gateway | Read | 
| <a name="storagegateway-DescribeBandwidthRateLimit"></a>[DescribeBandwidthRateLimit](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeBandwidthRateLimit.html) | Get the bandwidth rate limits of a gateway | Read | 
| <a name="storagegateway-DescribeBandwidthRateLimitSchedule"></a>[DescribeBandwidthRateLimitSchedule](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeBandwidthRateLimitSchedule.html) | Get the bandwidth rate limit schedule of a gateway | Read | 
| <a name="storagegateway-DescribeCache"></a>[DescribeCache](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeCache.html) | Get information about the cache of a gateway. This operation is supported only for the gateway-cached volume architecture | Read | 
| <a name="storagegateway-DescribeCacheReport"></a>[DescribeCacheReport](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeCacheReport.html) | Get a description of a cache report | Read | 
| <a name="storagegateway-DescribeCachediSCSIVolumes"></a>[DescribeCachediSCSIVolumes](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeCachediSCSIVolumes.html) | Get a description of the gateway volumes specified in the request. This operation is supported only for the gateway-cached volume architecture | Read | 
| <a name="storagegateway-DescribeChapCredentials"></a>[DescribeChapCredentials](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeChapCredentials.html) | Get an array of Challenge-Handshake Authentication Protocol (CHAP) credentials information for a specified iSCSI target, one for each target-initiator pair | Read | 
| <a name="storagegateway-DescribeFileSystemAssociations"></a>[DescribeFileSystemAssociations](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeFileSystemAssociations.html) | Get a description for one or more file system associations | Read | 
| <a name="storagegateway-DescribeGatewayInformation"></a>[DescribeGatewayInformation](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeGatewayInformation.html) | Get metadata about a gateway such as its name, network interfaces, configured time zone, and the state (whether the gateway is running or not) | Read | 
| <a name="storagegateway-DescribeMaintenanceStartTime"></a>[DescribeMaintenanceStartTime](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeMaintenanceStartTime.html) | Get your gateway's weekly maintenance start time including the day and time of the week | Read | 
| <a name="storagegateway-DescribeNFSFileShares"></a>[DescribeNFSFileShares](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeNFSFileShares.html) | Get a description for one or more file shares from a file gateway | Read | 
| <a name="storagegateway-DescribeSMBFileShares"></a>[DescribeSMBFileShares](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeSMBFileShares.html) | Get a description for one or more file shares from a file gateway | Read | 
| <a name="storagegateway-DescribeSMBSettings"></a>[DescribeSMBSettings](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeSMBSettings.html) | Get a description of a Server Message Block (SMB) file share settings from a file gateway | Read | 
| <a name="storagegateway-DescribeSnapshotSchedule"></a>[DescribeSnapshotSchedule](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeSnapshotSchedule.html) | Describe the snapshot schedule for the specified gateway volume | Read | 
| <a name="storagegateway-DescribeStorediSCSIVolumes"></a>[DescribeStorediSCSIVolumes](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeStorediSCSIVolumes.html) | Get the description of the gateway volumes specified in the request | Read | 
| <a name="storagegateway-DescribeTapeArchives"></a>[DescribeTapeArchives](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeTapeArchives.html) | Get a description of specified virtual tapes in the virtual tape shelf (VTS) | Read | 
| <a name="storagegateway-DescribeTapeRecoveryPoints"></a>[DescribeTapeRecoveryPoints](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeTapeRecoveryPoints.html) | Get a list of virtual tape recovery points that are available for the specified gateway-VTL | Read | 
| <a name="storagegateway-DescribeTapes"></a>[DescribeTapes](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeTapes.html) | Get a description of the specified Amazon Resource Name (ARN) of virtual tapes | Read | 
| <a name="storagegateway-DescribeUploadBuffer"></a>[DescribeUploadBuffer](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeUploadBuffer.html) | Get information about the upload buffer of a gateway | Read | 
| <a name="storagegateway-DescribeVTLDevices"></a>[DescribeVTLDevices](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeVTLDevices.html) | Get a description of virtual tape library (VTL) devices for the specified gateway | Read | 
| <a name="storagegateway-DescribeWorkingStorage"></a>[DescribeWorkingStorage](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_DescribeWorkingStorage.html) | Get information about the working storage of a gateway | Read | 
| <a name="storagegateway-ListAutomaticTapeCreationPolicies"></a>[ListAutomaticTapeCreationPolicies](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListAutomaticTapeCreationPolicies.html) | List the automatic tape creation policies configured on the specified gateway-VTL or all gateway-VTLs owned by your AWS account | List | 
| <a name="storagegateway-ListCacheReports"></a>[ListCacheReports](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListCacheReports.html) | Get a list of the cache reports owned by your AWS account | List | 
| <a name="storagegateway-ListFileShares"></a>[ListFileShares](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListFileShares.html) | Get a list of the file shares for a specific file gateway, or the list of file shares owned by your AWS account | List | 
| <a name="storagegateway-ListFileSystemAssociations"></a>[ListFileSystemAssociations](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListFileSystemAssociations.html) | Get a list of the file system associations for the specified gateway | List | 
| <a name="storagegateway-ListGateways"></a>[ListGateways](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListGateways.html) | List gateways owned by an AWS account in a region specified in the request. The returned list is ordered by gateway Amazon Resource Name (ARN) | List | 
| <a name="storagegateway-ListLocalDisks"></a>[ListLocalDisks](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListLocalDisks.html) | Get a list of the gateway's local disks | List | 
| <a name="storagegateway-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListTagsForResource.html) | Get the tags that have been added to the specified resource | List | 
| <a name="storagegateway-ListTapePools"></a>[ListTapePools](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListTapePools.html) | List tape pools owned by your AWS account | List | 
| <a name="storagegateway-ListTapes"></a>[ListTapes](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListTapes.html) | List virtual tapes in your virtual tape library (VTL) and your virtual tape shelf (VTS) | List | 
| <a name="storagegateway-ListVolumeInitiators"></a>[ListVolumeInitiators](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListVolumeInitiators.html) | List iSCSI initiators that are connected to a volume | List | 
| <a name="storagegateway-ListVolumeRecoveryPoints"></a>[ListVolumeRecoveryPoints](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListVolumeRecoveryPoints.html) | List the recovery points for a specified gateway | List | 
| <a name="storagegateway-ListVolumes"></a>[ListVolumes](https://docs.aws.amazon.com/storagegateway/latest/APIReference/API_ListVolumes.html) | List the iSCSI stored volumes of a gateway | List |
