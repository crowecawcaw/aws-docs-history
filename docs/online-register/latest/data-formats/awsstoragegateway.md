# Data retrieval APIs for AWS Storage Gateway

AWS Storage Gateway provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                             | Description                                                                                                                                                 | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAvailabilityMonitorTest](../../../storagegateway/latest/APIReference/API_DescribeAvailabilityMonitorTest.md "../../../storagegateway/latest/APIReference/API_DescribeAvailabilityMonitorTest.md")          | Get the information about the most recent high availability monitoring test that was performed on the gateway                                               | Read         |
| [DescribeBandwidthRateLimit](../../../storagegateway/latest/APIReference/API_DescribeBandwidthRateLimit.md "../../../storagegateway/latest/APIReference/API_DescribeBandwidthRateLimit.md")                         | Get the bandwidth rate limits of a gateway                                                                                                                  | Read         |
| [DescribeBandwidthRateLimitSchedule](../../../storagegateway/latest/APIReference/API_DescribeBandwidthRateLimitSchedule.md "../../../storagegateway/latest/APIReference/API_DescribeBandwidthRateLimitSchedule.md") | Get the bandwidth rate limit schedule of a gateway                                                                                                          | Read         |
| [DescribeCache](../../../storagegateway/latest/APIReference/API_DescribeCache.md "../../../storagegateway/latest/APIReference/API_DescribeCache.md")                                                                | Get information about the cache of a gateway. This operation is supported only for the gateway-cached volume architecture                                   | Read         |
| [DescribeCacheReport](../../../storagegateway/latest/APIReference/API_DescribeCacheReport.md "../../../storagegateway/latest/APIReference/API_DescribeCacheReport.md")                                              | Get a description of a cache report                                                                                                                         | Read         |
| [DescribeCachediSCSIVolumes](../../../storagegateway/latest/APIReference/API_DescribeCachediSCSIVolumes.md "../../../storagegateway/latest/APIReference/API_DescribeCachediSCSIVolumes.md")                         | Get a description of the gateway volumes specified in the request. This operation is supported only for the gateway-cached volume architecture              | Read         |
| [DescribeChapCredentials](../../../storagegateway/latest/APIReference/API_DescribeChapCredentials.md "../../../storagegateway/latest/APIReference/API_DescribeChapCredentials.md")                                  | Get an array of Challenge-Handshake Authentication Protocol (CHAP) credentials information for a specified iSCSI target, one for each target-initiator pair | Read         |
| [DescribeFileSystemAssociations](../../../storagegateway/latest/APIReference/API_DescribeFileSystemAssociations.md "../../../storagegateway/latest/APIReference/API_DescribeFileSystemAssociations.md")             | Get a description for one or more file system associations                                                                                                  | Read         |
| [DescribeGatewayInformation](../../../storagegateway/latest/APIReference/API_DescribeGatewayInformation.md "../../../storagegateway/latest/APIReference/API_DescribeGatewayInformation.md")                         | Get metadata about a gateway such as its name, network interfaces, configured time zone, and the state (whether the gateway is running or not)              | Read         |
| [DescribeMaintenanceStartTime](../../../storagegateway/latest/APIReference/API_DescribeMaintenanceStartTime.md "../../../storagegateway/latest/APIReference/API_DescribeMaintenanceStartTime.md")                   | Get your gateway's weekly maintenance start time including the day and time of the week                                                                     | Read         |
| [DescribeNFSFileShares](../../../storagegateway/latest/APIReference/API_DescribeNFSFileShares.md "../../../storagegateway/latest/APIReference/API_DescribeNFSFileShares.md")                                        | Get a description for one or more file shares from a file gateway                                                                                           | Read         |
| [DescribeSMBFileShares](../../../storagegateway/latest/APIReference/API_DescribeSMBFileShares.md "../../../storagegateway/latest/APIReference/API_DescribeSMBFileShares.md")                                        | Get a description for one or more file shares from a file gateway                                                                                           | Read         |
| [DescribeSMBSettings](../../../storagegateway/latest/APIReference/API_DescribeSMBSettings.md "../../../storagegateway/latest/APIReference/API_DescribeSMBSettings.md")                                              | Get a description of a Server Message Block (SMB) file share settings from a file gateway                                                                   | Read         |
| [DescribeSnapshotSchedule](../../../storagegateway/latest/APIReference/API_DescribeSnapshotSchedule.md "../../../storagegateway/latest/APIReference/API_DescribeSnapshotSchedule.md")                               | Describe the snapshot schedule for the specified gateway volume                                                                                             | Read         |
| [DescribeStorediSCSIVolumes](../../../storagegateway/latest/APIReference/API_DescribeStorediSCSIVolumes.md "../../../storagegateway/latest/APIReference/API_DescribeStorediSCSIVolumes.md")                         | Get the description of the gateway volumes specified in the request                                                                                         | Read         |
| [DescribeTapeArchives](../../../storagegateway/latest/APIReference/API_DescribeTapeArchives.md "../../../storagegateway/latest/APIReference/API_DescribeTapeArchives.md")                                           | Get a description of specified virtual tapes in the virtual tape shelf (VTS)                                                                                | Read         |
| [DescribeTapeRecoveryPoints](../../../storagegateway/latest/APIReference/API_DescribeTapeRecoveryPoints.md "../../../storagegateway/latest/APIReference/API_DescribeTapeRecoveryPoints.md")                         | Get a list of virtual tape recovery points that are available for the specified gateway-VTL                                                                 | Read         |
| [DescribeTapes](../../../storagegateway/latest/APIReference/API_DescribeTapes.md "../../../storagegateway/latest/APIReference/API_DescribeTapes.md")                                                                | Get a description of the specified Amazon Resource Name (ARN) of virtual tapes                                                                              | Read         |
| [DescribeUploadBuffer](../../../storagegateway/latest/APIReference/API_DescribeUploadBuffer.md "../../../storagegateway/latest/APIReference/API_DescribeUploadBuffer.md")                                           | Get information about the upload buffer of a gateway                                                                                                        | Read         |
| [DescribeVTLDevices](../../../storagegateway/latest/APIReference/API_DescribeVTLDevices.md "../../../storagegateway/latest/APIReference/API_DescribeVTLDevices.md")                                                 | Get a description of virtual tape library (VTL) devices for the specified gateway                                                                           | Read         |
| [DescribeWorkingStorage](../../../storagegateway/latest/APIReference/API_DescribeWorkingStorage.md "../../../storagegateway/latest/APIReference/API_DescribeWorkingStorage.md")                                     | Get information about the working storage of a gateway                                                                                                      | Read         |
| [ListAutomaticTapeCreationPolicies](../../../storagegateway/latest/APIReference/API_ListAutomaticTapeCreationPolicies.md "../../../storagegateway/latest/APIReference/API_ListAutomaticTapeCreationPolicies.md")    | List the automatic tape creation policies configured on the specified gateway-VTL or all gateway-VTLs owned by your AWS account                             | List         |
| [ListCacheReports](../../../storagegateway/latest/APIReference/API_ListCacheReports.md "../../../storagegateway/latest/APIReference/API_ListCacheReports.md")                                                       | Get a list of the cache reports owned by your AWS account                                                                                                   | List         |
| [ListFileShares](../../../storagegateway/latest/APIReference/API_ListFileShares.md "../../../storagegateway/latest/APIReference/API_ListFileShares.md")                                                             | Get a list of the file shares for a specific file gateway, or the list of file shares owned by your AWS account                                             | List         |
| [ListFileSystemAssociations](../../../storagegateway/latest/APIReference/API_ListFileSystemAssociations.md "../../../storagegateway/latest/APIReference/API_ListFileSystemAssociations.md")                         | Get a list of the file system associations for the specified gateway                                                                                        | List         |
| [ListGateways](../../../storagegateway/latest/APIReference/API_ListGateways.md "../../../storagegateway/latest/APIReference/API_ListGateways.md")                                                                   | List gateways owned by an AWS account in a region specified in the request. The returned list is ordered by gateway Amazon Resource Name (ARN)              | List         |
| [ListLocalDisks](../../../storagegateway/latest/APIReference/API_ListLocalDisks.md "../../../storagegateway/latest/APIReference/API_ListLocalDisks.md")                                                             | Get a list of the gateway's local disks                                                                                                                     | List         |
| [ListTagsForResource](../../../storagegateway/latest/APIReference/API_ListTagsForResource.md "../../../storagegateway/latest/APIReference/API_ListTagsForResource.md")                                              | Get the tags that have been added to the specified resource                                                                                                 | List         |
| [ListTapePools](../../../storagegateway/latest/APIReference/API_ListTapePools.md "../../../storagegateway/latest/APIReference/API_ListTapePools.md")                                                                | List tape pools owned by your AWS account                                                                                                                   | List         |
| [ListTapes](../../../storagegateway/latest/APIReference/API_ListTapes.md "../../../storagegateway/latest/APIReference/API_ListTapes.md")                                                                            | List virtual tapes in your virtual tape library (VTL) and your virtual tape shelf (VTS)                                                                     | List         |
| [ListVolumeInitiators](../../../storagegateway/latest/APIReference/API_ListVolumeInitiators.md "../../../storagegateway/latest/APIReference/API_ListVolumeInitiators.md")                                           | List iSCSI initiators that are connected to a volume                                                                                                        | List         |
| [ListVolumeRecoveryPoints](../../../storagegateway/latest/APIReference/API_ListVolumeRecoveryPoints.md "../../../storagegateway/latest/APIReference/API_ListVolumeRecoveryPoints.md")                               | List the recovery points for a specified gateway                                                                                                            | List         |
| [ListVolumes](../../../storagegateway/latest/APIReference/API_ListVolumes.md "../../../storagegateway/latest/APIReference/API_ListVolumes.md")                                                                      | List the iSCSI stored volumes of a gateway                                                                                                                  | List         |
