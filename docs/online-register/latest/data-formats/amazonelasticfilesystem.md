# Data retrieval APIs for Amazon Elastic File System

Amazon Elastic File System provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                                                                                                                                                                                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [ClientMount](../../../efs/latest/ug/efs-client-authorization.md "../../../efs/latest/ug/efs-client-authorization.md")                                                 | Allow an NFS client read-access to a file system                                                                                                                                                                                                  | Read         |
| [DescribeAccessPoints](../../../efs/latest/ug/API_DescribeAccessPoints.md "../../../efs/latest/ug/API_DescribeAccessPoints.md")                                        | View the descriptions of Amazon EFS access points                                                                                                                                                                                                 | List         |
| [DescribeAccountPreferences](../../../efs/latest/ug/API_DescribeAccountPreferences.md "../../../efs/latest/ug/API_DescribeAccountPreferences.md")                      | View the account preferences in effect for an account                                                                                                                                                                                             | List         |
| [DescribeBackupPolicy](../../../efs/latest/ug/API_DescribeBackupPolicy.md "../../../efs/latest/ug/API_DescribeBackupPolicy.md")                                        | View the BackupPolicy object for an Amazon EFS file system                                                                                                                                                                                        | Read         |
| [DescribeFileSystemPolicy](../../../efs/latest/ug/API_DescribeFileSystemPolicy.md "../../../efs/latest/ug/API_DescribeFileSystemPolicy.md")                            | View the resource-level policy for an Amazon EFS file system                                                                                                                                                                                      | Read         |
| [DescribeFileSystems](../../../efs/latest/ug/API_DescribeFileSystems.md "../../../efs/latest/ug/API_DescribeFileSystems.md")                                           | View the description of an Amazon EFS file system specified by file system CreationToken or FileSystemId; or to view the description of all file systems owned by the caller's AWS account in the AWS region of the endpoint that is being called | List         |
| [DescribeLifecycleConfiguration](../../../efs/latest/ug/API_DescribeLifecycleConfiguration.md "../../../efs/latest/ug/API_DescribeLifecycleConfiguration.md")          | View the LifecycleConfiguration object for an Amazon EFS file system                                                                                                                                                                              | Read         |
| [DescribeMountTargetSecurityGroups](../../../efs/latest/ug/API_DescribeMountTargetSecurityGroups.md "../../../efs/latest/ug/API_DescribeMountTargetSecurityGroups.md") | View the security groups in effect for a mount target                                                                                                                                                                                             | Read         |
| [DescribeMountTargets](../../../efs/latest/ug/API_DescribeMountTargets.md "../../../efs/latest/ug/API_DescribeMountTargets.md")                                        | View the descriptions of all mount targets, or a specific mount target, for a file system                                                                                                                                                         | Read         |
| [DescribeReplicationConfigurations](../../../efs/latest/ug/API_DescribeReplicationConfigurations.md "../../../efs/latest/ug/API_DescribeReplicationConfigurations.md") | View the description of an Amazon EFS replication configuration specified by FileSystemId; or to view the description of all replication configurations owned by the caller's AWS account in the AWS region of the endpoint that is being called  | List         |
| [DescribeTags](../../../efs/latest/ug/API_DescribeTags.md "../../../efs/latest/ug/API_DescribeTags.md")                                                                | View the tags associated with a file system                                                                                                                                                                                                       | Read         |
| [ListTagsForResource](../../../efs/latest/ug/API_ListTagsForResource.md "../../../efs/latest/ug/API_ListTagsForResource.md")                                           | View the tags associated with the specified Amazon EFS resource                                                                                                                                                                                   | Read         |
| [ReplicationRead](../../../efs/latest/ug/efs-replication.md "../../../efs/latest/ug/efs-replication.md")                                                               | Read file system data for replication                                                                                                                                                                                                             | Read         |
