# Data retrieval APIs for AWS Security Agent

AWS Security Agent provides the following APIs for data retrieval.

| Actions                                                                                                                                                                      | Description                                                                                       | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------ |

| [BatchGetArtifactMetadata](../../../securityagent/API_BatchGetArtifactMetadata.md "../../../securityagent/API_BatchGetArtifactMetadata.md")                                  | Retrieve one or more Artifact Metadata records for the given Agent Instance                       | Read         |
| [BatchGetFindings](../../../securityagent/API_BatchGetFindings.md "../../../securityagent/API_BatchGetFindings.md")                                                          | Retrieve multiple security testing findings in a single request                                   | Read         |
| [BatchGetPentestJobTasks](../../../securityagent/API_BatchGetPentestJobTasks.md "../../../securityagent/API_BatchGetPentestJobTasks.md")                                     | Retrieve multiple pentest job tasks in a single request                                           | Read         |
| [BatchGetPentestJobs](../../../securityagent/API_BatchGetPentestJobs.md "../../../securityagent/API_BatchGetPentestJobs.md")                                                 | Retrieve multiple security testing jobs in a single request                                       | Read         |
| [BatchGetPentests](../../../securityagent/API_BatchGetPentests.md "../../../securityagent/API_BatchGetPentests.md")                                                          | Retrieve multiple penetration tests in a single request                                           | Read         |
| [BatchGetSecurityTestContentMetadata](../../../securityagent/API_BatchGetSecurityTestContentMetadata.md "../../../securityagent/API_BatchGetSecurityTestContentMetadata.md") | Retrieve multiple security testing contents metadata in a single request                          | Read         |

| [DescribeFindings](../../../securityagent/API_DescribeFindings.md "../../../securityagent/API_DescribeFindings.md")                                                          | Retrieve security findings for a penetration test or security testing tasks in a penetration test | Read         |
| [GetApplication](../../../securityagent/API_GetApplication.md "../../../securityagent/API_GetApplication.md")                                                                | Get application details by application ID                                                         | Read         |
| [GetArtifact](../../../securityagent/API_GetArtifact.md "../../../securityagent/API_GetArtifact.md")                                                                         | Retrieve an Artifact for the given Agent Instance                                                 | Read         |
| [GetCodeReviewTask](../../../securityagent/API_GetCodeReviewTask.md "../../../securityagent/API_GetCodeReviewTask.md")                                                       | Retrieve a Code Review Task                                                                       | Read         |
| [GetControl](../../../securityagent/API_GetControl.md "../../../securityagent/API_GetControl.md")                                                                            | Retrieve a Control                                                                                | Read         |
