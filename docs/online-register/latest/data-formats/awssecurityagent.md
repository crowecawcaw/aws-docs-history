# Data retrieval APIs for AWS Security Agent

AWS Security Agent provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                                                | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------ |
| [BatchGetAgentSpaces](../../../securityagent/API_BatchGetAgentSpaces.md "../../../securityagent/API_BatchGetAgentSpaces.md")                                           | Retrieve multiple agent spaces in a single request                                         | Read         |
| [BatchGetArtifactMetadata](../../../securityagent/API_BatchGetArtifactMetadata.md "../../../securityagent/API_BatchGetArtifactMetadata.md")                            | Retrieve one or more Artifact Metadata records for the given Agent Space                   | Read         |
| [BatchGetFindings](../../../securityagent/API_BatchGetFindings.md "../../../securityagent/API_BatchGetFindings.md")                                                    | Retrieve multiple security testing findings in a single request                            | Read         |
| [BatchGetPentestJobContentMetadata](../../../securityagent/API_BatchGetPentestJobContentMetadata.md "../../../securityagent/API_BatchGetPentestJobContentMetadata.md") | Retrieve multiple pentest job contents metadata in a single request                        | Read         |
| [BatchGetPentestJobTasks](../../../securityagent/API_BatchGetPentestJobTasks.md "../../../securityagent/API_BatchGetPentestJobTasks.md")                               | Retrieve multiple pentest job tasks in a single request                                    | Read         |
| [BatchGetPentestJobs](../../../securityagent/API_BatchGetPentestJobs.md "../../../securityagent/API_BatchGetPentestJobs.md")                                           | Retrieve multiple security testing jobs in a single request                                | Read         |
| [BatchGetPentests](../../../securityagent/API_BatchGetPentests.md "../../../securityagent/API_BatchGetPentests.md")                                                    | Retrieve multiple penetration tests in a single request                                    | Read         |
| [BatchGetTargetDomains](../../../securityagent/API_BatchGetTargetDomains.md "../../../securityagent/API_BatchGetTargetDomains.md")                                     | Retrieve multiple target domains in a single request                                       | Read         |
| [GetApplication](../../../securityagent/API_GetApplication.md "../../../securityagent/API_GetApplication.md")                                                          | Get application details by application ID                                                  | Read         |
| [GetArtifact](../../../securityagent/API_GetArtifact.md "../../../securityagent/API_GetArtifact.md")                                                                   | Retrieve an Artifact for the given Agent Space                                             | Read         |
| [GetDesignReview](../../../securityagent/API_GetDesignReview.md "../../../securityagent/API_GetDesignReview.md")                                                       | Get the status of the associated agent space design review                                 | Read         |
| [GetDesignReviewArtifact](../../../securityagent/API_GetDesignReviewArtifact.md "../../../securityagent/API_GetDesignReviewArtifact.md")                               | Get design review artifact for a specific document                                         | Read         |
| [GetDesignReviewFeedback](../../../securityagent/API_GetDesignReviewFeedback.md "../../../securityagent/API_GetDesignReviewFeedback.md")                               | Get feedback for a design review comment                                                   | Read         |
| [GetIntegration](../../../securityagent/API_GetIntegration.md "../../../securityagent/API_GetIntegration.md")                                                          | Get the integration metadata by ID                                                         | Read         |
| [GetSecurityRequirement](../../../securityagent/API_GetSecurityRequirement.md "../../../securityagent/API_GetSecurityRequirement.md")                                  | Retrieve a Security Requirement                                                            | Read         |
| [ListAgentSpaces](../../../securityagent/API_ListAgentSpaces.md "../../../securityagent/API_ListAgentSpaces.md")                                                       | List agent spaces                                                                          | List         |
| [ListApplications](../../../securityagent/API_ListApplications.md "../../../securityagent/API_ListApplications.md")                                                    | List all applications in the account                                                       | List         |
| [ListArtifacts](../../../securityagent/API_ListArtifacts.md "../../../securityagent/API_ListArtifacts.md")                                                             | List all artifacts for the given agent space                                               | List         |
| [ListDesignReviewComments](../../../securityagent/API_ListDesignReviewComments.md "../../../securityagent/API_ListDesignReviewComments.md")                            | List design review comments                                                                | List         |
| [ListDesignReviews](../../../securityagent/API_ListDesignReviews.md "../../../securityagent/API_ListDesignReviews.md")                                                 | List all design reviews for the given agent space                                          | List         |
| [ListDiscoveredEndpoints](../../../securityagent/API_ListDiscoveredEndpoints.md "../../../securityagent/API_ListDiscoveredEndpoints.md")                               | List discovered endpoints associated with a pentest job with optional URI prefix filtering | List         |
| [ListFindings](../../../securityagent/API_ListFindings.md "../../../securityagent/API_ListFindings.md")                                                                | List findings with filtering and pagination support                                        | List         |
| [ListIntegratedResources](../../../securityagent/API_ListIntegratedResources.md "../../../securityagent/API_ListIntegratedResources.md")                               | List integrated resources for an agent space                                               | List         |
| [ListIntegrations](../../../securityagent/API_ListIntegrations.md "../../../securityagent/API_ListIntegrations.md")                                                    | Get the integrations owned by the caller's AWS account                                     | List         |
| [ListMemberships](../../../securityagent/API_ListMemberships.md "../../../securityagent/API_ListMemberships.md")                                                       | List all members associated to an agent space with pagination support                      | List         |
| [ListPentestJobTasks](../../../securityagent/API_ListPentestJobTasks.md "../../../securityagent/API_ListPentestJobTasks.md")                                           | List pentest job tasks associated with a pentest job                                       | List         |
| [ListPentestJobsForPentest](../../../securityagent/API_ListPentestJobsForPentest.md "../../../securityagent/API_ListPentestJobsForPentest.md")                         | List penetration test jobs associated with a penetration test                              | List         |
| [ListPentests](../../../securityagent/API_ListPentests.md "../../../securityagent/API_ListPentests.md")                                                                | List penetration tests with optional filtering by status                                   | List         |
| [ListResourcesFromIntegration](../../../securityagent/API_ListResourcesFromIntegration.md "../../../securityagent/API_ListResourcesFromIntegration.md")                | List resources from Integration                                                            | List         |
| [ListSecurityRequirements](../../../securityagent/API_ListSecurityRequirements.md "../../../securityagent/API_ListSecurityRequirements.md")                            | List all Security Requirements                                                             | List         |
| [ListTagsForResource](../../../securityagent/API_ListTagsForResource.md "../../../securityagent/API_ListTagsForResource.md")                                           | List the tags for a resource                                                               | Read         |
| [ListTargetDomains](../../../securityagent/API_ListTargetDomains.md "../../../securityagent/API_ListTargetDomains.md")                                                 | List target domains                                                                        | List         |
