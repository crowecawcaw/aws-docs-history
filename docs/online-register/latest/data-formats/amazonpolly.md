# Data retrieval APIs for Amazon Polly

Amazon Polly provides the following APIs for data retrieval.

| Actions                                                                                                                                         | Description                                                                             | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------ |
| [DescribeVoices](../../../polly/latest/dg/API_DescribeVoices.md "../../../polly/latest/dg/API_DescribeVoices.md")                               | Describe the list of voices that are available for use when requesting speech synthesis | List         |
| [GetLexicon](../../../polly/latest/dg/API_GetLexicon.md "../../../polly/latest/dg/API_GetLexicon.md")                                           | Retrieve the content of the specified pronunciation lexicon stored in an AWS Region     | Read         |
| [GetSpeechSynthesisTask](../../../polly/latest/dg/API_GetSpeechSynthesisTask.md "../../../polly/latest/dg/API_GetSpeechSynthesisTask.md")       | Get information about specific speech synthesis task                                    | Read         |
| [ListLexicons](../../../polly/latest/dg/API_ListLexicons.md "../../../polly/latest/dg/API_ListLexicons.md")                                     | List the pronunciation lexicons stored in an AWS Region                                 | List         |
| [ListSpeechSynthesisTasks](../../../polly/latest/dg/API_ListSpeechSynthesisTasks.md "../../../polly/latest/dg/API_ListSpeechSynthesisTasks.md") | List requested speech synthesis tasks                                                   | List         |
| [SynthesizeSpeech](../../../polly/latest/dg/API_SynthesizeSpeech.md "../../../polly/latest/dg/API_SynthesizeSpeech.md")                         | Synthesize speech                                                                       | Read         |
