# Data retrieval APIs for AWS CloudTrail

AWS CloudTrail provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                    | Description                                                                                                                              | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeQuery](../../../awscloudtrail/latest/APIReference/API_DescribeQuery.md "../../../awscloudtrail/latest/APIReference/API_DescribeQuery.md")                                                                         | List details for the query                                                                                                               | Read         |
| [DescribeTrails](../../../awscloudtrail/latest/APIReference/API_DescribeTrails.md "../../../awscloudtrail/latest/APIReference/API_DescribeTrails.md")                                                                      | List settings for the trails associated with the current region for your account                                                         | Read         |
| [GenerateQueryResultsSummary](../../../awscloudtrail/latest/userguide/query-results-summary.md "../../../awscloudtrail/latest/userguide/query-results-summary.md")                                                         | Generate a results summary for specified queries using the CloudTrail natural language generator                                         | Read         |
| [GetChannel](../../../awscloudtrail/latest/APIReference/API_GetChannel.md "../../../awscloudtrail/latest/APIReference/API_GetChannel.md")                                                                                  | Return information about a specific channel                                                                                              | Read         |
| [GetDashboard](../../../awscloudtrail/latest/APIReference/API_GetDashboard.md "../../../awscloudtrail/latest/APIReference/API_GetDashboard.md")                                                                            | List settings for the dashboard                                                                                                          | Read         |
| [GetEventConfiguration](../../../awscloudtrail/latest/APIReference/API_GetEventConfiguration.md "../../../awscloudtrail/latest/APIReference/API_GetEventConfiguration.md")                                                 | List event configurations that are configured for an event data store                                                                    | Read         |
| [GetEventDataStore](../../../awscloudtrail/latest/APIReference/API_GetEventDataStore.md "../../../awscloudtrail/latest/APIReference/API_GetEventDataStore.md")                                                             | List settings for the event data store                                                                                                   | Read         |
| [GetEventDataStoreData](../../../awscloudtrail/latest/userguide/query-federation.md#query-federation-permissions "../../../awscloudtrail/latest/userguide/query-federation.md#query-federation-permissions")               | Get data from an event data store by using the AWS Glue Data Catalog                                                                     | Read         |
| [GetEventSelectors](../../../awscloudtrail/latest/APIReference/API_GetEventSelectors.md "../../../awscloudtrail/latest/APIReference/API_GetEventSelectors.md")                                                             | List settings for event selectors configured for a trail                                                                                 | Read         |
| [GetImport](../../../awscloudtrail/latest/APIReference/API_GetImport.md "../../../awscloudtrail/latest/APIReference/API_GetImport.md")                                                                                     | Return information about a specific import                                                                                               | Read         |
| [GetInsightSelectors](../../../awscloudtrail/latest/APIReference/API_GetInsightSelectors.md "../../../awscloudtrail/latest/APIReference/API_GetInsightSelectors.md")                                                       | List CloudTrail Insights selectors that are configured for a trail or event data store                                                   | Read         |
| [GetQueryResults](../../../awscloudtrail/latest/APIReference/API_GetQueryResults.md "../../../awscloudtrail/latest/APIReference/API_GetQueryResults.md")                                                                   | Fetch results of a complete query                                                                                                        | Read         |
| [GetResourcePolicy](../../../awscloudtrail/latest/APIReference/API_GetResourcePolicy.md "../../../awscloudtrail/latest/APIReference/API_GetResourcePolicy.md")                                                             | Get the resource policy attached to the provided resource                                                                                | Read         |
| [GetServiceLinkedChannel](../../../awscloudtrail/latest/userguide/viewing-service-linked-channels.md#slc-service-events "../../../awscloudtrail/latest/userguide/viewing-service-linked-channels.md#slc-service-events")   | List settings for the service-linked channel                                                                                             | Read         |
| [GetTrail](../../../awscloudtrail/latest/APIReference/API_GetTrail.md "../../../awscloudtrail/latest/APIReference/API_GetTrail.md")                                                                                        | List settings for the trail                                                                                                              | Read         |
| [GetTrailStatus](../../../awscloudtrail/latest/APIReference/API_GetTrailStatus.md "../../../awscloudtrail/latest/APIReference/API_GetTrailStatus.md")                                                                      | Retrieve a JSON-formatted list of information about the specified trail                                                                  | Read         |
| [ListChannels](../../../awscloudtrail/latest/APIReference/API_ListChannels.md "../../../awscloudtrail/latest/APIReference/API_ListChannels.md")                                                                            | List the channels in the current account, and their source names                                                                         | List         |
| [ListDashboards](../../../awscloudtrail/latest/APIReference/API_ListDashboards.md "../../../awscloudtrail/latest/APIReference/API_ListDashboards.md")                                                                      | List dashboards associated with the current region for your account                                                                      | List         |
| [ListEventDataStores](../../../awscloudtrail/latest/APIReference/API_ListEventDataStores.md "../../../awscloudtrail/latest/APIReference/API_ListEventDataStores.md")                                                       | List event data stores associated with the current region for your account                                                               | List         |
| [ListImportFailures](../../../awscloudtrail/latest/APIReference/API_ListImportFailures.md "../../../awscloudtrail/latest/APIReference/API_ListImportFailures.md")                                                          | Return a list of failures for the specified import                                                                                       | Read         |
| [ListImports](../../../awscloudtrail/latest/APIReference/API_ListImports.md "../../../awscloudtrail/latest/APIReference/API_ListImports.md")                                                                               | Return information on all imports, or a select set of imports by ImportStatus or Destination                                             | List         |
| [ListPublicKeys](../../../awscloudtrail/latest/APIReference/API_ListPublicKeys.md "../../../awscloudtrail/latest/APIReference/API_ListPublicKeys.md")                                                                      | List the public keys whose private keys were used to sign trail digest files within a specified time range                               | Read         |
| [ListQueries](../../../awscloudtrail/latest/APIReference/API_ListQueries.md "../../../awscloudtrail/latest/APIReference/API_ListQueries.md")                                                                               | List queries associated with an event data store                                                                                         | List         |
| [ListServiceLinkedChannels](../../../awscloudtrail/latest/userguide/viewing-service-linked-channels.md#slc-service-events "../../../awscloudtrail/latest/userguide/viewing-service-linked-channels.md#slc-service-events") | List service-linked channels associated with the current region for a specified account                                                  | List         |
| [ListTags](../../../awscloudtrail/latest/APIReference/API_ListTags.md "../../../awscloudtrail/latest/APIReference/API_ListTags.md")                                                                                        | List the tags for trails, event data stores, channels or dashboards in the current region                                                | Read         |
| [ListTrails](../../../awscloudtrail/latest/APIReference/API_ListTrails.md "../../../awscloudtrail/latest/APIReference/API_ListTrails.md")                                                                                  | List trails associated with the current region for your account                                                                          | List         |
| [LookupEvents](../../../awscloudtrail/latest/APIReference/API_LookupEvents.md "../../../awscloudtrail/latest/APIReference/API_LookupEvents.md")                                                                            | Look up and retrieve metric data for API activity events captured by CloudTrail that create, update, or delete resources in your account | Read         |
| [SearchSampleQueries](../../../awscloudtrail/latest/userguide/lake-console-queries.md "../../../awscloudtrail/latest/userguide/lake-console-queries.md")                                                                   | Perform semantic search for CloudTrail Lake sample queries                                                                               | Read         |
