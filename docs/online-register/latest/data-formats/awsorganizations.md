# Data retrieval APIs for AWS Organizations

AWS Organizations provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                       | Description                                                                                             | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAccount](../../../organizations/latest/APIReference/API_DescribeAccount.md "../../../organizations/latest/APIReference/API_DescribeAccount.md")                                                                      | Retrieve Organizations-related details about the specified account                                      | Read         |
| [DescribeCreateAccountStatus](../../../organizations/latest/APIReference/API_DescribeCreateAccountStatus.md "../../../organizations/latest/APIReference/API_DescribeCreateAccountStatus.md")                                  | Retrieve the current status of an asynchronous request to create an account                             | Read         |
| [DescribeEffectivePolicy](../../../organizations/latest/APIReference/API_DescribeEffectivePolicy.md "../../../organizations/latest/APIReference/API_DescribeEffectivePolicy.md")                                              | Retrieve the effective policy for an account                                                            | Read         |
| [DescribeHandshake](../../../organizations/latest/APIReference/API_DescribeHandshake.md "../../../organizations/latest/APIReference/API_DescribeHandshake.md")                                                                | Retrieve details about a previously requested handshake                                                 | Read         |
| [DescribeOrganization](../../../organizations/latest/APIReference/API_DescribeOrganization.md "../../../organizations/latest/APIReference/API_DescribeOrganization.md")                                                       | Retrieve details about the organization that the calling credentials belong to                          | Read         |
| [DescribeOrganizationalUnit](../../../organizations/latest/APIReference/API_DescribeOrganizationalUnit.md "../../../organizations/latest/APIReference/API_DescribeOrganizationalUnit.md")                                     | Retrieve details about an organizational unit (OU)                                                      | Read         |
| [DescribePolicy](../../../organizations/latest/APIReference/API_DescribePolicy.md "../../../organizations/latest/APIReference/API_DescribePolicy.md")                                                                         | Retrieve details about a policy                                                                         | Read         |
| [DescribeResourcePolicy](../../../organizations/latest/APIReference/API_DescribeResourcePolicy.md "../../../organizations/latest/APIReference/API_DescribeResourcePolicy.md")                                                 | Retrieve information about a resource policy                                                            | Read         |
| [DescribeResponsibilityTransfer](../../../organizations/latest/APIReference/API_DescribeResponsibilityTransfer.md "../../../organizations/latest/APIReference/API_DescribeResponsibilityTransfer.md")                         | Retrieve details about a previously responsibility transfer                                             | Read         |
| [ListAWSServiceAccessForOrganization](../../../organizations/latest/APIReference/API_ListAWSServiceAccessForOrganization.md "../../../organizations/latest/APIReference/API_ListAWSServiceAccessForOrganization.md")          | Retrieve the list of the AWS services for which you enabled integration with your organization          | List         |
| [ListAccounts](../../../organizations/latest/APIReference/API_ListAccounts.md "../../../organizations/latest/APIReference/API_ListAccounts.md")                                                                               | List all of the accounts in the organization                                                            | List         |
| [ListAccountsForParent](../../../organizations/latest/APIReference/API_ListAccountsForParent.md "../../../organizations/latest/APIReference/API_ListAccountsForParent.md")                                                    | List the accounts in an organization that are contained by a root or organizational unit (OU)           | List         |
| [ListAccountsWithInvalidEffectivePolicy](../../../organizations/latest/APIReference/API_ListAccountsWithInvalidEffectivePolicy.md "../../../organizations/latest/APIReference/API_ListAccountsWithInvalidEffectivePolicy.md") | List accounts that have invalid effective policies for a specified policy type                          | List         |
| [ListChildren](../../../organizations/latest/APIReference/API_ListChildren.md "../../../organizations/latest/APIReference/API_ListChildren.md")                                                                               | List all of the OUs or accounts that are contained in a parent OU or root                               | List         |
| [ListCreateAccountStatus](../../../organizations/latest/APIReference/API_ListCreateAccountStatus.md "../../../organizations/latest/APIReference/API_ListCreateAccountStatus.md")                                              | List the asynchronous account creation requests that are currently being tracked for the organization   | List         |
| [ListDelegatedAdministrators](../../../organizations/latest/APIReference/API_ListDelegatedAdministrators.md "../../../organizations/latest/APIReference/API_ListDelegatedAdministrators.md")                                  | List the AWS accounts that are designated as delegated administrators in this organization              | List         |
| [ListDelegatedServicesForAccount](../../../organizations/latest/APIReference/API_ListDelegatedServicesForAccount.md "../../../organizations/latest/APIReference/API_ListDelegatedServicesForAccount.md")                      | List the AWS services for which the specified account is a delegated administrator in this organization | List         |
| [ListEffectivePolicyValidationErrors](../../../organizations/latest/APIReference/API_ListEffectivePolicyValidationErrors.md "../../../organizations/latest/APIReference/API_ListEffectivePolicyValidationErrors.md")          | List validation errors found in the effective policy for a specific account and policy type             | List         |
| [ListHandshakesForAccount](../../../organizations/latest/APIReference/API_ListHandshakesForAccount.md "../../../organizations/latest/APIReference/API_ListHandshakesForAccount.md")                                           | List all of the handshakes that are associated with an account                                          | List         |
| [ListHandshakesForOrganization](../../../organizations/latest/APIReference/API_ListHandshakesForOrganization.md "../../../organizations/latest/APIReference/API_ListHandshakesForOrganization.md")                            | List the handshakes that are associated with the organization                                           | List         |
| [ListInboundResponsibilityTransfers](../../../organizations/latest/APIReference/API_ListInboundResponsibilityTransfers.md "../../../organizations/latest/APIReference/API_ListInboundResponsibilityTransfers.md")             | List all responsibilities of a particular type transfered to your organization                          | List         |
| [ListOrganizationalUnitsForParent](../../../organizations/latest/APIReference/API_ListOrganizationalUnitsForParent.md "../../../organizations/latest/APIReference/API_ListOrganizationalUnitsForParent.md")                   | List all of the organizational units (OUs) in a parent organizational unit or root                      | List         |
| [ListOutboundResponsibilityTransfers](../../../organizations/latest/APIReference/API_ListOutboundResponsibilityTransfers.md "../../../organizations/latest/APIReference/API_ListOutboundResponsibilityTransfers.md")          | List all responsibilities of a particular type transfered to another organization                       | List         |
| [ListParents](../../../organizations/latest/APIReference/API_ListParents.md "../../../organizations/latest/APIReference/API_ListParents.md")                                                                                  | List the root or organizational units (OUs) that serve as the immediate parent of a child OU or account | List         |
| [ListPolicies](../../../organizations/latest/APIReference/API_ListPolicies.md "../../../organizations/latest/APIReference/API_ListPolicies.md")                                                                               | List all of the policies in an organization                                                             | List         |
| [ListPoliciesForTarget](../../../organizations/latest/APIReference/API_ListPoliciesForTarget.md "../../../organizations/latest/APIReference/API_ListPoliciesForTarget.md")                                                    | List all of the policies that are directly attached to a root, organizational unit (OU), or account     | List         |
| [ListRoots](../../../organizations/latest/APIReference/API_ListRoots.md "../../../organizations/latest/APIReference/API_ListRoots.md")                                                                                        | List all of the roots that are defined in the organization                                              | List         |
| [ListTagsForResource](../../../organizations/latest/APIReference/API_ListTagsForResource.md "../../../organizations/latest/APIReference/API_ListTagsForResource.md")                                                          | List all tags for the specified resource                                                                | List         |
| [ListTargetsForPolicy](../../../organizations/latest/APIReference/API_ListTargetsForPolicy.md "../../../organizations/latest/APIReference/API_ListTargetsForPolicy.md")                                                       | List all the roots, OUs, and accounts to which a policy is attached                                     | List         |
