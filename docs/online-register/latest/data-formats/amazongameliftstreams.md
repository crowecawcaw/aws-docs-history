

# Data retrieval APIs for Amazon GameLift Streams

| Actions | Description | Access level |

| <a name="gameliftstreams-GetStreamGroup"></a>[GetStreamGroup](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_GetStreamGroup.html) | Grants `permission` to get a StreamGroup | Read | 
| <a name="gameliftstreams-GetStreamSession"></a>[GetStreamSession](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_GetStreamSession.html) | Get a stream session | Read | 
| <a name="gameliftstreams-GetStreamUrl"></a>[GetStreamUrl](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_GetStreamUrl.html) | Get a stream URL | Read | 
| <a name="gameliftstreams-ListApplicationShaderCaches"></a>[ListApplicationShaderCaches](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_ListApplicationShaderCaches.html) | List application shader caches | List | 
| <a name="gameliftstreams-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_ListApplications.html) | List applications | List |

| <a name="gameliftstreams-ListStreamUrls"></a>[ListStreamUrls](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_ListStreamUrls.html) | List stream URLs | List | 
| <a name="gameliftstreams-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/gameliftstreams/latest/apireference/API_ListTagsForResource.html) | List tags for a resource | Read |
