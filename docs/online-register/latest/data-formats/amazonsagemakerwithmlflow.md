# Data retrieval APIs for Amazon SageMaker with MLflow

Amazon SageMaker with MLflow provides the following APIs for data retrieval.

| Actions                                                                                         | Description                                                        | Access level |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------ |
| [AccessUI](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                               | Access the MLflow UI                                               | Read         |
| [GetDownloadURIForModelVersionArtifacts](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md") | Get a URI to download model artifacts for a specific model version | Read         |
| [GetExperiment](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                          | Get metadata for an MLflow experiment                              | Read         |
| [GetExperimentByName](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                    | Get metadata for an MLflow experiment by name                      | Read         |
| [GetLatestModelVersions](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                 | Get the latest model versions                                      | List         |
| [GetLoggedModel](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                         | Get a logged model in MLflow                                       | Read         |
| [GetMetricHistory](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                       | Get a list of all values for the specified metric for a given run  | Read         |
| [GetModelVersion](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                        | Get a model version by model name and version                      | Read         |
| [GetModelVersionByAlias](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                 | Get model version by alias in MLflow                               | Read         |
| [GetRegisteredModel](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                     | Get a registered model                                             | Read         |
| [GetRun](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                                 | Get metadata, metrics, parameters, and tags for a run              | Read         |
| [GetTraceInfo](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                           | Get information about a trace in MLflow                            | Read         |
| [ListArtifacts](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                          | List artifacts for a run                                           | List         |
| [ListLoggedModelArtifacts](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")               | List artifacts for a logged model in MLflow                        | List         |
| [SearchExperiments](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                      | Search for MLflow experiments                                      | Read         |
| [SearchLoggedModels](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                     | Search for logged models in MLflow                                 | Read         |
| [SearchModelVersions](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                    | Search for a model version                                         | Read         |
| [SearchRegisteredModels](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                 | Search for registered models in MLflow                             | Read         |
| [SearchRuns](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                             | Search for runs that satisfy expressions                           | Read         |
| [SearchTraces](${APIReferenceDocPage}.md "${APIReferenceDocPage}.md")                           | Search for traces in MLflow                                        | Read         |
