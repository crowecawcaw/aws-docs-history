

# Data retrieval APIs for Amazon SageMaker with MLflow
<a name="amazonsagemakerwithmlflow"></a>

Amazon SageMaker with MLflow provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="sagemaker-mlflow-AccessUI"></a>[AccessUI](${APIReferenceDocPage}) | Access the MLflow UI | Read | 
| <a name="sagemaker-mlflow-GetDownloadURIForModelVersionArtifacts"></a>[GetDownloadURIForModelVersionArtifacts](${APIReferenceDocPage}) | Get a URI to download model artifacts for a specific model version | Read | 
| <a name="sagemaker-mlflow-GetExperiment"></a>[GetExperiment](${APIReferenceDocPage}) | Get metadata for an MLflow experiment | Read | 
| <a name="sagemaker-mlflow-GetExperimentByName"></a>[GetExperimentByName](${APIReferenceDocPage}) | Get metadata for an MLflow experiment by name | Read | 
| <a name="sagemaker-mlflow-GetLatestModelVersions"></a>[GetLatestModelVersions](${APIReferenceDocPage}) | Get the latest model versions | List | 
| <a name="sagemaker-mlflow-GetLoggedModel"></a>[GetLoggedModel](${APIReferenceDocPage}) | Get a logged model in MLflow | Read | 
| <a name="sagemaker-mlflow-GetMetricHistory"></a>[GetMetricHistory](${APIReferenceDocPage}) | Get a list of all values for the specified metric for a given run | Read | 
| <a name="sagemaker-mlflow-GetModelVersion"></a>[GetModelVersion](${APIReferenceDocPage}) | Get a model version by model name and version | Read | 
| <a name="sagemaker-mlflow-GetModelVersionByAlias"></a>[GetModelVersionByAlias](${APIReferenceDocPage}) | Get model version by alias in MLflow | Read | 
| <a name="sagemaker-mlflow-GetRegisteredModel"></a>[GetRegisteredModel](${APIReferenceDocPage}) | Get a registered model | Read | 
| <a name="sagemaker-mlflow-GetRun"></a>[GetRun](${APIReferenceDocPage}) | Get metadata, metrics, parameters, and tags for a run | Read | 
| <a name="sagemaker-mlflow-GetTraceInfo"></a>[GetTraceInfo](${APIReferenceDocPage}) | Get information about a trace in MLflow | Read | 
| <a name="sagemaker-mlflow-ListArtifacts"></a>[ListArtifacts](${APIReferenceDocPage}) | List artifacts for a run | List | 
| <a name="sagemaker-mlflow-ListLoggedModelArtifacts"></a>[ListLoggedModelArtifacts](${APIReferenceDocPage}) | List artifacts for a logged model in MLflow | List | 
| <a name="sagemaker-mlflow-SearchExperiments"></a>[SearchExperiments](${APIReferenceDocPage}) | Search for MLflow experiments | Read | 
| <a name="sagemaker-mlflow-SearchLoggedModels"></a>[SearchLoggedModels](${APIReferenceDocPage}) | Search for logged models in MLflow | Read | 
| <a name="sagemaker-mlflow-SearchModelVersions"></a>[SearchModelVersions](${APIReferenceDocPage}) | Search for a model version | Read | 
| <a name="sagemaker-mlflow-SearchRegisteredModels"></a>[SearchRegisteredModels](${APIReferenceDocPage}) | Search for registered models in MLflow | Read | 
| <a name="sagemaker-mlflow-SearchRuns"></a>[SearchRuns](${APIReferenceDocPage}) | Search for runs that satisfy expressions | Read | 
| <a name="sagemaker-mlflow-SearchTraces"></a>[SearchTraces](${APIReferenceDocPage}) | Search for traces in MLflow | Read |
