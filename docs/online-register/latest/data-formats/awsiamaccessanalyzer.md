# Data retrieval APIs for AWS IAM Access Analyzer

AWS IAM Access Analyzer provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                              | Description                                                             | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------ |
| [CheckAccessNotGranted](../../../access-analyzer/latest/APIReference/API_CheckAccessNotGranted.md "../../../access-analyzer/latest/APIReference/API_CheckAccessNotGranted.md")                                       | Check that specified access is not allowed by a policy                  | Read         |
| [CheckNoNewAccess](../../../access-analyzer/latest/APIReference/API_CheckNoNewAccess.md "../../../access-analyzer/latest/APIReference/API_CheckNoNewAccess.md")                                                      | Check that no new access is allowed when compared to an existing policy | Read         |
| [CheckNoPublicAccess](../../../access-analyzer/latest/APIReference/API_CheckNoPublicAccess.md "../../../access-analyzer/latest/APIReference/API_CheckNoPublicAccess.md")                                             | Check that public access is not allowed by a resource policy            | Read         |
| [GetAccessPreview](../../../access-analyzer/latest/APIReference/API_GetAccessPreview.md "../../../access-analyzer/latest/APIReference/API_GetAccessPreview.md")                                                      | Retrieve information about an access preview                            | Read         |
| [GetAnalyzedResource](../../../access-analyzer/latest/APIReference/API_GetAnalyzedResource.md "../../../access-analyzer/latest/APIReference/API_GetAnalyzedResource.md")                                             | Retrieve information about an analyzed resource                         | Read         |
| [GetAnalyzer](../../../access-analyzer/latest/APIReference/API_GetAnalyzer.md "../../../access-analyzer/latest/APIReference/API_GetAnalyzer.md")                                                                     | Retrieve information about analyzers                                    | Read         |
| [GetArchiveRule](../../../access-analyzer/latest/APIReference/API_GetArchiveRule.md "../../../access-analyzer/latest/APIReference/API_GetArchiveRule.md")                                                            | Retrieve information about archive rules for the specified analyzer     | Read         |
| [GetFinding](../../../access-analyzer/latest/APIReference/API_GetFindingV2.md "../../../access-analyzer/latest/APIReference/API_GetFindingV2.md")                                                                    | Retrieve findings                                                       | Read         |
| [GetFindingRecommendation](../../../access-analyzer/latest/APIReference/API_GetFindingRecommendation.md "../../../access-analyzer/latest/APIReference/API_GetFindingRecommendation.md")                              | Retrieve recommendation steps to resolve a finding                      | Read         |
| [GetFindingsStatistics](../../../IAM/latest/UserGuide/access-analyzer-getting-started.md#access-analyzer-permissions "../../../IAM/latest/UserGuide/access-analyzer-getting-started.md#access-analyzer-permissions") | Retrieve statistics for findings                                        | Read         |
| [GetGeneratedPolicy](../../../access-analyzer/latest/APIReference/API_GetGeneratedPolicy.md "../../../access-analyzer/latest/APIReference/API_GetGeneratedPolicy.md")                                                | Retrieve a policy that was generated using StartPolicyGeneration        | Read         |
| [ListAccessPreviewFindings](../../../access-analyzer/latest/APIReference/API_ListAccessPreviewFindings.md "../../../access-analyzer/latest/APIReference/API_ListAccessPreviewFindings.md")                           | Retrieve a list of findings from an access preview                      | Read         |
| [ListAccessPreviews](../../../access-analyzer/latest/APIReference/API_ListAccessPreviews.md "../../../access-analyzer/latest/APIReference/API_ListAccessPreviews.md")                                                | Retrieve a list of access previews                                      | List         |
| [ListAnalyzedResources](../../../access-analyzer/latest/APIReference/API_ListAnalyzedResources.md "../../../access-analyzer/latest/APIReference/API_ListAnalyzedResources.md")                                       | Retrieve a list of resources that have been analyzed                    | Read         |
| [ListAnalyzers](../../../access-analyzer/latest/APIReference/API_ListAnalyzers.md "../../../access-analyzer/latest/APIReference/API_ListAnalyzers.md")                                                               | Retrieves a list of analyzers                                           | List         |
| [ListArchiveRules](../../../access-analyzer/latest/APIReference/API_ListArchiveRules.md "../../../access-analyzer/latest/APIReference/API_ListArchiveRules.md")                                                      | Retrieve a list of archive rules from an analyzer                       | List         |
| [ListFindings](../../../access-analyzer/latest/APIReference/API_ListFindingsV2.md "../../../access-analyzer/latest/APIReference/API_ListFindingsV2.md")                                                              | Retrieve a list of findings from an analyzer                            | Read         |
| [ListPolicyGenerations](../../../access-analyzer/latest/APIReference/API_ListPolicyGenerations.md "../../../access-analyzer/latest/APIReference/API_ListPolicyGenerations.md")                                       | List all the recently started policy generations                        | Read         |
| [ListTagsForResource](../../../access-analyzer/latest/APIReference/API_ListTagsForResource.md "../../../access-analyzer/latest/APIReference/API_ListTagsForResource.md")                                             | Retrieve a list of tags applied to a resource                           | Read         |
| [ValidatePolicy](../../../access-analyzer/latest/APIReference/API_ValidatePolicy.md "../../../access-analyzer/latest/APIReference/API_ValidatePolicy.md")                                                            | Validate a policy                                                       | Read         |
