

# Data retrieval APIs for AWS Glue DataBrew
<a name="awsgluedatabrew"></a>

AWS Glue DataBrew provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="databrew-DescribeDataset"></a>[DescribeDataset](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeDataset.html) | View details about a dataset | Read | 
| <a name="databrew-DescribeJob"></a>[DescribeJob](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeJob.html) | View details about a job | Read | 
| <a name="databrew-DescribeJobRun"></a>[DescribeJobRun](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeJobRun.html) | View details about job run for a given job | Read | 
| <a name="databrew-DescribeProject"></a>[DescribeProject](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeProject.html) | View details about a project | Read | 
| <a name="databrew-DescribeRecipe"></a>[DescribeRecipe](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeRecipe.html) | View details about a recipe | Read | 
| <a name="databrew-DescribeRuleset"></a>[DescribeRuleset](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeRuleset.html) | View details about a ruleset | Read | 
| <a name="databrew-DescribeSchedule"></a>[DescribeSchedule](https://docs.aws.amazon.com/databrew/latest/dg/API_DescribeSchedule.html) | View details about a schedule | Read | 
| <a name="databrew-ListDatasets"></a>[ListDatasets](https://docs.aws.amazon.com/databrew/latest/dg/API_ListDatasets.html) | List datasets in your account | Read | 
| <a name="databrew-ListJobRuns"></a>[ListJobRuns](https://docs.aws.amazon.com/databrew/latest/dg/API_ListJobRuns.html) | List job runs for a given job | Read | 
| <a name="databrew-ListJobs"></a>[ListJobs](https://docs.aws.amazon.com/databrew/latest/dg/API_ListJobs.html) | List jobs in your account | Read | 
| <a name="databrew-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/databrew/latest/dg/API_ListProjects.html) | List projects in your account | Read | 
| <a name="databrew-ListRecipeVersions"></a>[ListRecipeVersions](https://docs.aws.amazon.com/databrew/latest/dg/API_ListRecipeVersions.html) | List versions in your recipe | Read | 
| <a name="databrew-ListRecipes"></a>[ListRecipes](https://docs.aws.amazon.com/databrew/latest/dg/API_ListRecipes.html) | List recipes in your account | Read | 
| <a name="databrew-ListRulesets"></a>[ListRulesets](https://docs.aws.amazon.com/databrew/latest/dg/API_ListRulesets.html) | List rulesets in your account | Read | 
| <a name="databrew-ListSchedules"></a>[ListSchedules](https://docs.aws.amazon.com/databrew/latest/dg/API_ListSchedules.html) | List schedules in your account | Read | 
| <a name="databrew-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/databrew/latest/dg/API_ListTagsForResource.html) | Retrieve tags associated with a resource | Read |
