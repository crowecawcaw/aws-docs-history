# Data retrieval APIs for AWS Glue DataBrew

AWS Glue DataBrew provides the following APIs for data retrieval.

| Actions                                                                                                                                | Description                                | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | ------------ |
| [DescribeDataset](../../../databrew/latest/dg/API_DescribeDataset.md "../../../databrew/latest/dg/API_DescribeDataset.md")             | View details about a dataset               | Read         |
| [DescribeJob](../../../databrew/latest/dg/API_DescribeJob.md "../../../databrew/latest/dg/API_DescribeJob.md")                         | View details about a job                   | Read         |
| [DescribeJobRun](../../../databrew/latest/dg/API_DescribeJobRun.md "../../../databrew/latest/dg/API_DescribeJobRun.md")                | View details about job run for a given job | Read         |
| [DescribeProject](../../../databrew/latest/dg/API_DescribeProject.md "../../../databrew/latest/dg/API_DescribeProject.md")             | View details about a project               | Read         |
| [DescribeRecipe](../../../databrew/latest/dg/API_DescribeRecipe.md "../../../databrew/latest/dg/API_DescribeRecipe.md")                | View details about a recipe                | Read         |
| [DescribeRuleset](../../../databrew/latest/dg/API_DescribeRuleset.md "../../../databrew/latest/dg/API_DescribeRuleset.md")             | View details about a ruleset               | Read         |
| [DescribeSchedule](../../../databrew/latest/dg/API_DescribeSchedule.md "../../../databrew/latest/dg/API_DescribeSchedule.md")          | View details about a schedule              | Read         |
| [ListDatasets](../../../databrew/latest/dg/API_ListDatasets.md "../../../databrew/latest/dg/API_ListDatasets.md")                      | List datasets in your account              | Read         |
| [ListJobRuns](../../../databrew/latest/dg/API_ListJobRuns.md "../../../databrew/latest/dg/API_ListJobRuns.md")                         | List job runs for a given job              | Read         |
| [ListJobs](../../../databrew/latest/dg/API_ListJobs.md "../../../databrew/latest/dg/API_ListJobs.md")                                  | List jobs in your account                  | Read         |
| [ListProjects](../../../databrew/latest/dg/API_ListProjects.md "../../../databrew/latest/dg/API_ListProjects.md")                      | List projects in your account              | Read         |
| [ListRecipeVersions](../../../databrew/latest/dg/API_ListRecipeVersions.md "../../../databrew/latest/dg/API_ListRecipeVersions.md")    | List versions in your recipe               | Read         |
| [ListRecipes](../../../databrew/latest/dg/API_ListRecipes.md "../../../databrew/latest/dg/API_ListRecipes.md")                         | List recipes in your account               | Read         |
| [ListRulesets](../../../databrew/latest/dg/API_ListRulesets.md "../../../databrew/latest/dg/API_ListRulesets.md")                      | List rulesets in your account              | Read         |
| [ListSchedules](../../../databrew/latest/dg/API_ListSchedules.md "../../../databrew/latest/dg/API_ListSchedules.md")                   | List schedules in your account             | Read         |
| [ListTagsForResource](../../../databrew/latest/dg/API_ListTagsForResource.md "../../../databrew/latest/dg/API_ListTagsForResource.md") | Retrieve tags associated with a resource   | Read         |
