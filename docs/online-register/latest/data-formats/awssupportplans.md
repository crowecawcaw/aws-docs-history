# Data retrieval APIs for AWS Support Plans

AWS Support Plans provides the following APIs for data retrieval.

| Actions                                                                                                                                             | Description                                                          | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------ |
| [GetSupportPlan](../../../awssupport/latest/user/security-support-plans.md "../../../awssupport/latest/user/security-support-plans.md")             | View details about the current support plan for this AWS account     | Read         |
| [GetSupportPlanUpdateStatus](../../../awssupport/latest/user/security-support-plans.md "../../../awssupport/latest/user/security-support-plans.md") | View details about the status for a request to update a support plan | Read         |
| [ListSupportPlanModifiers](../../../awssupport/latest/user/security-support-plans.md "../../../awssupport/latest/user/security-support-plans.md")   | View a list of all support plan modifiers for this AWS account       | List         |
