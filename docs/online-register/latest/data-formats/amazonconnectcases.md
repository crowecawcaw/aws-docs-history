# Data retrieval APIs for Amazon Connect Cases

Amazon Connect Cases provides the following APIs for data retrieval.

| Actions                                                                                                                                                                | Description                                                               | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------ |
| [BatchGetCaseRule](../../../cases/latest/APIReference/API_BatchGetCaseRule.md "../../../cases/latest/APIReference/API_BatchGetCaseRule.md")                            | Retrieve information about the case rules in the case domain              | Read         |
| [BatchGetField](../../../cases/latest/APIReference/API_BatchGetField.md "../../../cases/latest/APIReference/API_BatchGetField.md")                                     | Retrieve information about the fields in the case domain                  | Read         |
| [GetCase](../../../cases/latest/APIReference/API_GetCase.md "../../../cases/latest/APIReference/API_GetCase.md")                                                       | Retrieve information about a case in the case domain                      | Read         |
| [GetCaseAuditEvents](../../../cases/latest/APIReference/API_GetCaseAuditEvents.md "../../../cases/latest/APIReference/API_GetCaseAuditEvents.md")                      | View audit history of a case                                              | Read         |
| [GetCaseEventConfiguration](../../../cases/latest/APIReference/API_GetCaseEventConfiguration.md "../../../cases/latest/APIReference/API_GetCaseEventConfiguration.md") | Retrieve information about the case event configuraton in the case domain | Read         |
| [GetDomain](../../../cases/latest/APIReference/API_GetDomain.md "../../../cases/latest/APIReference/API_GetDomain.md")                                                 | Retrieve information about the case domain                                | Read         |
| [GetLayout](../../../cases/latest/APIReference/API_GetLayout.md "../../../cases/latest/APIReference/API_GetLayout.md")                                                 | Retrieve information about the layout in the case domain                  | Read         |
| [GetTemplate](../../../cases/latest/APIReference/API_GetTemplate.md "../../../cases/latest/APIReference/API_GetTemplate.md")                                           | Retrieve information about the template in the case domain                | Read         |
| [ListCaseRules](../../../cases/latest/APIReference/API_ListCaseRules.md "../../../cases/latest/APIReference/API_ListCaseRules.md")                                     | List case rules in the case domain                                        | List         |
| [ListCasesForContact](../../../cases/latest/APIReference/API_ListCasesForContact.md "../../../cases/latest/APIReference/API_ListCasesForContact.md")                   | List cases for a specific contact in the case domain                      | List         |
| [ListDomains](../../../cases/latest/APIReference/API_ListDomains.md "../../../cases/latest/APIReference/API_ListDomains.md")                                           | List all domains in the aws account                                       | List         |
| [ListFieldOptions](../../../cases/latest/APIReference/API_ListFieldOptions.md "../../../cases/latest/APIReference/API_ListFieldOptions.md")                            | List field options for a single select field in the case domain           | List         |
| [ListFields](../../../cases/latest/APIReference/API_ListFields.md "../../../cases/latest/APIReference/API_ListFields.md")                                              | List fields in the case domain                                            | List         |
| [ListLayouts](../../../cases/latest/APIReference/API_ListLayouts.md "../../../cases/latest/APIReference/API_ListLayouts.md")                                           | List layouts in the case domain                                           | List         |
| [ListTagsForResource](../../../cases/latest/APIReference/API_ListTagsForResource.md "../../../cases/latest/APIReference/API_ListTagsForResource.md")                   | List the tags for the specified resource                                  | Read         |
| [ListTemplates](../../../cases/latest/APIReference/API_ListTemplates.md "../../../cases/latest/APIReference/API_ListTemplates.md")                                     | List templates in the case domain                                         | List         |
| [SearchCases](../../../cases/latest/APIReference/API_SearchCases.md "../../../cases/latest/APIReference/API_SearchCases.md")                                           | Search for cases in the case domain                                       | Read         |
| [SearchRelatedItems](../../../cases/latest/APIReference/API_SearchRelatedItems.md "../../../cases/latest/APIReference/API_SearchRelatedItems.md")                      | Search for related items associated to the case in the case domain        | Read         |
