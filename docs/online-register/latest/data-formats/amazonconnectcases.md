

# Data retrieval APIs for Amazon Connect Cases
<a name="amazonconnectcases"></a>

Amazon Connect Cases provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="cases-BatchGetCaseRule"></a>[BatchGetCaseRule](https://docs.aws.amazon.com/cases/latest/APIReference/API_BatchGetCaseRule.html) | Retrieve information about the case rules in the case domain | Read | 
| <a name="cases-BatchGetField"></a>[BatchGetField](https://docs.aws.amazon.com/cases/latest/APIReference/API_BatchGetField.html) | Retrieve information about the fields in the case domain | Read | 
| <a name="cases-GetCase"></a>[GetCase](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCase.html) | Retrieve information about a case in the case domain | Read | 
| <a name="cases-GetCaseAuditEvents"></a>[GetCaseAuditEvents](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseAuditEvents.html) | View audit history of a case | Read | 
| <a name="cases-GetCaseEventConfiguration"></a>[GetCaseEventConfiguration](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseEventConfiguration.html) | Retrieve information about the case event configuraton in the case domain | Read | 
| <a name="cases-GetDomain"></a>[GetDomain](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetDomain.html) | Retrieve information about the case domain | Read | 
| <a name="cases-GetLayout"></a>[GetLayout](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetLayout.html) | Retrieve information about the layout in the case domain | Read | 
| <a name="cases-GetTemplate"></a>[GetTemplate](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetTemplate.html) | Retrieve information about the template in the case domain | Read | 
| <a name="cases-ListCaseRules"></a>[ListCaseRules](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListCaseRules.html) | List case rules in the case domain | List | 
| <a name="cases-ListCasesForContact"></a>[ListCasesForContact](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListCasesForContact.html) | List cases for a specific contact in the case domain | List | 
| <a name="cases-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListDomains.html) | List all domains in the aws account | List | 
| <a name="cases-ListFieldOptions"></a>[ListFieldOptions](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListFieldOptions.html) | List field options for a single select field in the case domain | List | 
| <a name="cases-ListFields"></a>[ListFields](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListFields.html) | List fields in the case domain | List | 
| <a name="cases-ListLayouts"></a>[ListLayouts](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListLayouts.html) | List layouts in the case domain | List | 
| <a name="cases-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListTagsForResource.html) | List the tags for the specified resource | Read | 
| <a name="cases-ListTemplates"></a>[ListTemplates](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListTemplates.html) | List templates in the case domain | List | 
| <a name="cases-SearchAllRelatedItems"></a>[SearchAllRelatedItems](https://docs.aws.amazon.com/cases/latest/APIReference/API_SearchAllRelatedItems.html) | Search for related items in the case domain | Read | 
| <a name="cases-SearchCases"></a>[SearchCases](https://docs.aws.amazon.com/cases/latest/APIReference/API_SearchCases.html) | Search for cases in the case domain | Read | 
| <a name="cases-SearchRelatedItems"></a>[SearchRelatedItems](https://docs.aws.amazon.com/cases/latest/APIReference/API_SearchRelatedItems.html) | Search for related items associated to the case in the case domain | Read |
