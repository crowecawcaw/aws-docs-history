# Data retrieval APIs for AWS Payment Cryptography

AWS Payment Cryptography provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                        | Description                                                                          | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------ |
| [GetAlias](../../../payment-cryptography/latest/APIReference/API_GetAlias.md "../../../payment-cryptography/latest/APIReference/API_GetAlias.md")                                              | Return the keyArn associated with an aliasName                                       | Read         |
| [GetKey](../../../payment-cryptography/latest/APIReference/API_GetKey.md "../../../payment-cryptography/latest/APIReference/API_GetKey.md")                                                    | Return the detailed information about the specified key                              | Read         |
| [GetParametersForExport](../../../payment-cryptography/latest/APIReference/API_GetParametersForExport.md "../../../payment-cryptography/latest/APIReference/API_GetParametersForExport.md")    | Get the export token and the signing key certificate to initiate a TR-34 key export  | Read         |
| [GetParametersForImport](../../../payment-cryptography/latest/APIReference/API_GetParametersForImport.md "../../../payment-cryptography/latest/APIReference/API_GetParametersForImport.md")    | Get the import token and the wrapping key certificate to initiate a TR-34 key import | Read         |
| [GetPublicKeyCertificate](../../../payment-cryptography/latest/APIReference/API_GetPublicKeyCertificate.md "../../../payment-cryptography/latest/APIReference/API_GetPublicKeyCertificate.md") | Return the public key from a key of class PUBLIC_KEY                                 | Read         |
| [ListAliases](../../../payment-cryptography/latest/APIReference/API_ListAliases.md "../../../payment-cryptography/latest/APIReference/API_ListAliases.md")                                     | Return a list of aliases created for all keys in the caller's AWS account and Region | List         |
| [ListKeys](../../../payment-cryptography/latest/APIReference/API_ListKeys.md "../../../payment-cryptography/latest/APIReference/API_ListKeys.md")                                              | Return a list of keys created in the caller's AWS account and Region                 | List         |
| [ListTagsForResource](../../../payment-cryptography/latest/APIReference/API_ListTagsForResource.md "../../../payment-cryptography/latest/APIReference/API_ListTagsForResource.md")             | Return a list of tags created in the caller's AWS account and Region                 | Read         |
