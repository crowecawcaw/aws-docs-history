# Data retrieval APIs for AWS Management Console Mobile App

AWS Management Console Mobile App provides the following APIs for data retrieval.

| Actions                                                                                                                                                         | Description                                                  | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------ |
| [GetDeviceIdentity](../../../consolemobileapp/latest/userguide/permissions-policies.md "../../../consolemobileapp/latest/userguide/permissions-policies.md")    | Retrieve the device identity for a Console Mobile App device | Read         |
| [ListDeviceIdentities](../../../consolemobileapp/latest/userguide/permissions-policies.md "../../../consolemobileapp/latest/userguide/permissions-policies.md") | Retrieve a list of device identities                         | List         |
