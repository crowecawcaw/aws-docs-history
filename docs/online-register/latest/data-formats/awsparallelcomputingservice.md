# Data retrieval APIs for AWS Parallel Computing Service

AWS Parallel Computing Service provides the following APIs for data retrieval.

| Actions                                                                                                                                                | Description                       | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------- | ------------ |
| [GetCluster](../../../pcs/latest/APIReference/API_GetCluster.md "../../../pcs/latest/APIReference/API_GetCluster.md")                                  | Get cluster properties            | Read         |
| [GetComputeNodeGroup](../../../pcs/latest/APIReference/API_GetComputeNodeGroup.md "../../../pcs/latest/APIReference/API_GetComputeNodeGroup.md")       | Get compute node group properties | Read         |
| [GetQueue](../../../pcs/latest/APIReference/API_GetQueue.md "../../../pcs/latest/APIReference/API_GetQueue.md")                                        | Get queue properties              | Read         |
| [ListClusters](../../../pcs/latest/APIReference/API_ListClusters.md "../../../pcs/latest/APIReference/API_ListClusters.md")                            | List clusters                     | List         |
| [ListComputeNodeGroups](../../../pcs/latest/APIReference/API_ListComputeNodeGroups.md "../../../pcs/latest/APIReference/API_ListComputeNodeGroups.md") | List compute node groups          | List         |
| [ListQueues](../../../pcs/latest/APIReference/API_ListQueues.md "../../../pcs/latest/APIReference/API_ListQueues.md")                                  | List queues                       | List         |
| [ListTagsForResource](../../../pcs/latest/APIReference/API_ListTagsForResource.md "../../../pcs/latest/APIReference/API_ListTagsForResource.md")       | List the tags for a resource      | Read         |
