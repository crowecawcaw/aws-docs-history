# Data retrieval APIs for Amazon Route 53 Profiles

Amazon Route 53 Profiles provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                      | Description                                                                                                                                            | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [GetProfile](../../../Route53/latest/APIReference/API_route53profiles_GetProfile.md "../../../Route53/latest/APIReference/API_route53profiles_GetProfile.md")                                                                | Get a Profile                                                                                                                                          | Read         |
| [GetProfileAssociation](../../../Route53/latest/APIReference/API_route53profiles_GetProfileAssociation.md "../../../Route53/latest/APIReference/API_route53profiles_GetProfileAssociation.md")                               | Get a Profile to a VPC association specified by the Profile association ID                                                                             | Read         |
| [GetProfilePolicy](../../../Route53/latest/DeveloperGuide/sharing-profiles.md "../../../Route53/latest/DeveloperGuide/sharing-profiles.md")                                                                                  | Read the RAM access control policy for a Profile                                                                                                       | Read         |
| [GetProfileResourceAssociation](../../../Route53/latest/APIReference/API_route53profiles_GetProfileResourceAssociation.md "../../../Route53/latest/APIReference/API_route53profiles_GetProfileResourceAssociation.md")       | Get a Profile resource association based on the ProfileResourceAssociationId                                                                           | Read         |
| [ListProfileAssociations](../../../Route53/latest/APIReference/API_route53profiles_ListProfileAssociations.md "../../../Route53/latest/APIReference/API_route53profiles_ListProfileAssociations.md")                         | List all VPCs the specified Profile is associated to                                                                                                   | List         |
| [ListProfileResourceAssociations](../../../Route53/latest/APIReference/API_route53profiles_ListProfileResourceAssociations.md "../../../Route53/latest/APIReference/API_route53profiles_ListProfileResourceAssociations.md") | List all the associations between the resources, such as DNS Firewall rule groups, private hosted zones, resolver rules, etc. for the given Profile ID | List         |
| [ListProfiles](../../../Route53/latest/APIReference/API_route53profiles_ListProfiles.md "../../../Route53/latest/APIReference/API_route53profiles_ListProfiles.md")                                                          | List all the Profiles created by, and shared to the customer                                                                                           | List         |
| [ListTagsForResource](../../../Route53/latest/APIReference/API_route53profiles_ListTagsForResource.md "../../../Route53/latest/APIReference/API_route53profiles_ListTagsForResource.md")                                     | List all tags associated with the resource                                                                                                             | List         |
