# Data retrieval APIs for AWS Elastic Load Balancing

AWS Elastic Load Balancing provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                        | Description                                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeInstanceHealth](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeInstanceHealth.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeInstanceHealth.md")                            | Describe the state of the specified instances with respect to the specified load balancer                                    | Read         |
| [DescribeLoadBalancerAttributes](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerAttributes.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerAttributes.md")    | Describe the attributes for the specified load balancer                                                                      | Read         |
| [DescribeLoadBalancerPolicies](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicies.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicies.md")          | Describe the specified policies                                                                                              | Read         |
| [DescribeLoadBalancerPolicyTypes](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicyTypes.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicyTypes.md") | Describe the specified load balancer policy types                                                                            | Read         |
| [DescribeLoadBalancers](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancers.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancers.md")                               | Describe the specified the load balancers. If no load balancers are specified, the call describes all of your load balancers | List         |
| [DescribeTags](../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeTags.md "../../../elasticloadbalancing/2012-06-01/APIReference/API_DescribeTags.md")                                                          | Describe the tags associated with the specified load balancers                                                               | Read         |
