

# Data retrieval APIs for AWS Compute Optimizer Automation
<a name="awscomputeoptimizerautomation"></a>

AWS Compute Optimizer Automation provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aco-automation-GetAutomationEvent"></a>[GetAutomationEvent](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_GetAutomationEvent.html) | Get automation event details | Read | 
| <a name="aco-automation-GetAutomationRule"></a>[GetAutomationRule](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_GetAutomationRule.html) | Get automation rule | Read | 
| <a name="aco-automation-GetEnrollmentConfiguration"></a>[GetEnrollmentConfiguration](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_GetEnrollmentConfiguration.html) | Get enrollment configuration | Read | 
| <a name="aco-automation-ListAccounts"></a>[ListAccounts](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAccounts.html) | List the accounts in your organization that are enrolled in Compute Optimizer and whether they have enabled the Automation feature | List | 
| <a name="aco-automation-ListAutomationEventSteps"></a>[ListAutomationEventSteps](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationEventSteps.html) | List automation event steps | List | 
| <a name="aco-automation-ListAutomationEventSummaries"></a>[ListAutomationEventSummaries](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationEventSummaries.html) | List automation event summaries | List | 
| <a name="aco-automation-ListAutomationEvents"></a>[ListAutomationEvents](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationEvents.html) | List automation events | List | 
| <a name="aco-automation-ListAutomationRulePreview"></a>[ListAutomationRulePreview](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationRulePreview.html) | List automation rule preview results | List | 
| <a name="aco-automation-ListAutomationRulePreviewSummaries"></a>[ListAutomationRulePreviewSummaries](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationRulePreviewSummaries.html) | List automation rule preview summaries | List | 
| <a name="aco-automation-ListAutomationRules"></a>[ListAutomationRules](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListAutomationRules.html) | List automation rules | List | 
| <a name="aco-automation-ListRecommendedActionSummaries"></a>[ListRecommendedActionSummaries](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListRecommendedActionSummaries.html) | List recommended action summaries | List | 
| <a name="aco-automation-ListRecommendedActions"></a>[ListRecommendedActions](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListRecommendedActions.html) | List recommended actions | List | 
| <a name="aco-automation-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_automation_ListTagsForResource.html) | List tags for automation rule | List |
