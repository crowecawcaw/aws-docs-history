

# Data retrieval APIs for Amazon Neptune
<a name="amazonneptune"></a>

Amazon Neptune provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="neptune-db-GetEngineStatus"></a>[GetEngineStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getenginestatus) | Check the status of the Neptune engine | Read | 
| <a name="neptune-db-GetGraphSummary"></a>[GetGraphSummary](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getgraphsummary) | Get the graph summary from the database | Read | 
| <a name="neptune-db-GetLoaderJobStatus"></a>[GetLoaderJobStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getloaderjobstatus) | Check the status of a loader job | Read | 
| <a name="neptune-db-GetMLDataProcessingJobStatus"></a>[GetMLDataProcessingJobStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getmldataprocessingjobstatus) | Check the status of an ML data processing job | Read | 
| <a name="neptune-db-GetMLEndpointStatus"></a>[GetMLEndpointStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getmlendpointstatus) | Check the status of an ML endpoint | Read | 
| <a name="neptune-db-GetMLModelTrainingJobStatus"></a>[GetMLModelTrainingJobStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getmlmodeltrainingjobstatus) | Check the status of an ML model training job | Read | 
| <a name="neptune-db-GetMLModelTransformJobStatus"></a>[GetMLModelTransformJobStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getmlmodeltransformjobstatus) | Check the status of an ML model transform job | Read | 
| <a name="neptune-db-GetQueryStatus"></a>[GetQueryStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getquerystatus) | Check the status of all active queries | Read | 
| <a name="neptune-db-GetStatisticsStatus"></a>[GetStatisticsStatus](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getstatisticsstatus) | Check the status of statistics of the database | Read | 
| <a name="neptune-db-GetStreamRecords"></a>[GetStreamRecords](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#getstreamrecords) | Fetch stream records from Neptune | Read | 
| <a name="neptune-db-ListLoaderJobs"></a>[ListLoaderJobs](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#listloaderjobs) | List all the loader jobs | List | 
| <a name="neptune-db-ListMLDataProcessingJobs"></a>[ListMLDataProcessingJobs](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#listmldataprocessingjobs) | List all the ML data processing jobs | List | 
| <a name="neptune-db-ListMLEndpoints"></a>[ListMLEndpoints](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#listmlendpoints) | List all the ML endpoints | List | 
| <a name="neptune-db-ListMLModelTrainingJobs"></a>[ListMLModelTrainingJobs](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#listmlmodeltrainingjobs) | List all the ML model training jobs | List | 
| <a name="neptune-db-ListMLModelTransformJobs"></a>[ListMLModelTransformJobs](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#listmlmodeltransformjobs) | List all the ML model transform jobs | List | 
| <a name="neptune-db-ReadDataViaQuery"></a>[ReadDataViaQuery](https://docs.aws.amazon.com/neptune/latest/userguide/iam-dp-actions.html#readdataviaquery) | Run read data via query APIs on database | Read |
