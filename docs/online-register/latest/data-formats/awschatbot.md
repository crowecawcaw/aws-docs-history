

# Data retrieval APIs for AWS Chatbot
<a name="awschatbot"></a>

AWS Chatbot provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="chatbot-DescribeChimeWebhookConfigurations"></a>[DescribeChimeWebhookConfigurations](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeChimeWebhookConfigurations.html) | List all AWS Chatbot Chime Webhook Configurations in an AWS Account | Read | 
| <a name="chatbot-DescribeSlackChannelConfigurations"></a>[DescribeSlackChannelConfigurations](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeSlackChannelConfigurations.html) | List all AWS Chatbot Slack Channel Configurations in an AWS account | Read | 
| <a name="chatbot-DescribeSlackChannels"></a>[DescribeSlackChannels](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_Operations.html) | List all public Slack channels in the Slack workspace connected to the AWS Account onboarded with AWS Chatbot service | Read | 
| <a name="chatbot-DescribeSlackUserIdentities"></a>[DescribeSlackUserIdentities](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeSlackUserIdentities.html) | Describe AWS Chatbot Slack User Identities | Read | 
| <a name="chatbot-DescribeSlackWorkspaces"></a>[DescribeSlackWorkspaces](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeSlackWorkspaces.html) | List all authorized Slack workspaces connected to the AWS Account onboarded with AWS Chatbot service | Read | 
| <a name="chatbot-GetAccountPreferences"></a>[GetAccountPreferences](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetAccountPreferences.html) | Retrieve AWS Chatbot account preferences | Read | 
| <a name="chatbot-GetCustomAction"></a>[GetCustomAction](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetCustomAction.html) | Get a custom action | Read | 
| <a name="chatbot-GetMicrosoftTeamsChannelConfiguration"></a>[GetMicrosoftTeamsChannelConfiguration](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetMicrosoftTeamsChannelConfiguration.html) | Get a single AWS Chatbot Microsoft Teams Channel Configurations in an AWS account | Read | 
| <a name="chatbot-GetMicrosoftTeamsOauthParameters"></a>[GetMicrosoftTeamsOauthParameters](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_Operations.html) | Generate OAuth parameters to request Microsoft Teams OAuth code to be used by the AWS Chatbot service | Read | 
| <a name="chatbot-GetSlackOauthParameters"></a>[GetSlackOauthParameters](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_Operations.html) | Generate OAuth parameters to request Slack OAuth code to be used by the AWS Chatbot service | Read | 
| <a name="chatbot-ListAssociations"></a>[ListAssociations](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListAssociations.html) | List resources associated with a configuration | Read | 
| <a name="chatbot-ListCustomActions"></a>[ListCustomActions](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListCustomActions.html) | List custom actions | List | 
| <a name="chatbot-ListMicrosoftTeamsChannelConfigurations"></a>[ListMicrosoftTeamsChannelConfigurations](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListMicrosoftTeamsChannelConfigurations.html) | List all AWS Chatbot Microsoft Teams Channel Configurations in an AWS account | Read | 
| <a name="chatbot-ListMicrosoftTeamsConfiguredTeams"></a>[ListMicrosoftTeamsConfiguredTeams](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListMicrosoftTeamsConfiguredTeams.html) | List all Microsoft Teams connected to the AWS Account onboarded with AWS Chatbot service | Read | 
| <a name="chatbot-ListMicrosoftTeamsUserIdentities"></a>[ListMicrosoftTeamsUserIdentities](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListMicrosoftTeamsUserIdentities.html) | Describe AWS Chatbot Microsoft Teams User Identities | Read | 
| <a name="chatbot-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_ListTagsForResource.html) | List all tags associated with the AWS Chatbot Channel Configuration | Read |
