# Data retrieval APIs for AWS Chatbot

AWS Chatbot provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                              | Description                                                                                                           | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeChimeWebhookConfigurations](../../../chatbot/latest/APIReference/API_DescribeChimeWebhookConfigurations.md "../../../chatbot/latest/APIReference/API_DescribeChimeWebhookConfigurations.md")                | List all AWS Chatbot Chime Webhook Configurations in an AWS Account                                                   | Read         |
| [DescribeSlackChannelConfigurations](../../../chatbot/latest/APIReference/API_DescribeSlackChannelConfigurations.md "../../../chatbot/latest/APIReference/API_DescribeSlackChannelConfigurations.md")                | List all AWS Chatbot Slack Channel Configurations in an AWS account                                                   | Read         |
| [DescribeSlackChannels](../../../chatbot/latest/APIReference/API_Operations.md "../../../chatbot/latest/APIReference/API_Operations.md")                                                                             | List all public Slack channels in the Slack workspace connected to the AWS Account onboarded with AWS Chatbot service | Read         |
| [DescribeSlackUserIdentities](../../../chatbot/latest/APIReference/API_DescribeSlackUserIdentities.md "../../../chatbot/latest/APIReference/API_DescribeSlackUserIdentities.md")                                     | Describe AWS Chatbot Slack User Identities                                                                            | Read         |
| [DescribeSlackWorkspaces](../../../chatbot/latest/APIReference/API_DescribeSlackWorkspaces.md "../../../chatbot/latest/APIReference/API_DescribeSlackWorkspaces.md")                                                 | List all authorized Slack workspaces connected to the AWS Account onboarded with AWS Chatbot service                  | Read         |
| [GetAccountPreferences](../../../chatbot/latest/APIReference/API_GetAccountPreferences.md "../../../chatbot/latest/APIReference/API_GetAccountPreferences.md")                                                       | Retrieve AWS Chatbot account preferences                                                                              | Read         |
| [GetCustomAction](../../../chatbot/latest/APIReference/API_GetCustomAction.md "../../../chatbot/latest/APIReference/API_GetCustomAction.md")                                                                         | Get a custom action                                                                                                   | Read         |
| [GetMicrosoftTeamsChannelConfiguration](../../../chatbot/latest/APIReference/API_GetMicrosoftTeamsChannelConfiguration.md "../../../chatbot/latest/APIReference/API_GetMicrosoftTeamsChannelConfiguration.md")       | Get a single AWS Chatbot Microsoft Teams Channel Configurations in an AWS account                                     | Read         |
| [GetMicrosoftTeamsOauthParameters](../../../chatbot/latest/APIReference/API_Operations.md "../../../chatbot/latest/APIReference/API_Operations.md")                                                                  | Generate OAuth parameters to request Microsoft Teams OAuth code to be used by the AWS Chatbot service                 | Read         |
| [GetSlackOauthParameters](../../../chatbot/latest/APIReference/API_Operations.md "../../../chatbot/latest/APIReference/API_Operations.md")                                                                           | Generate OAuth parameters to request Slack OAuth code to be used by the AWS Chatbot service                           | Read         |
| [ListAssociations](../../../chatbot/latest/APIReference/API_ListAssociations.md "../../../chatbot/latest/APIReference/API_ListAssociations.md")                                                                      | List resources associated with a configuration                                                                        | Read         |
| [ListCustomActions](../../../chatbot/latest/APIReference/API_ListCustomActions.md "../../../chatbot/latest/APIReference/API_ListCustomActions.md")                                                                   | List custom actions                                                                                                   | List         |
| [ListMicrosoftTeamsChannelConfigurations](../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsChannelConfigurations.md "../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsChannelConfigurations.md") | List all AWS Chatbot Microsoft Teams Channel Configurations in an AWS account                                         | Read         |
| [ListMicrosoftTeamsConfiguredTeams](../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsConfiguredTeams.md "../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsConfiguredTeams.md")                   | List all Microsoft Teams connected to the AWS Account onboarded with AWS Chatbot service                              | Read         |
| [ListMicrosoftTeamsUserIdentities](../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsUserIdentities.md "../../../chatbot/latest/APIReference/API_ListMicrosoftTeamsUserIdentities.md")                      | Describe AWS Chatbot Microsoft Teams User Identities                                                                  | Read         |
| [ListTagsForResource](../../../chatbot/latest/APIReference/API_ListTagsForResource.md "../../../chatbot/latest/APIReference/API_ListTagsForResource.md")                                                             | List all tags associated with the AWS Chatbot Channel Configuration                                                   | Read         |
