

# Data retrieval APIs for AWS RTB Fabric
<a name="awsrtbfabric"></a>

AWS RTB Fabric provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="rtbfabric-GetCertificateAssociation"></a>[GetCertificateAssociation](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetCertificateAssociation.html) | Retrieve details of a certificate association with a responder gateway | Read | 
| <a name="rtbfabric-GetInboundExternalLink"></a>[GetInboundExternalLink](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetInboundExternalLink.html) | Retrieve information about an inbound external link | Read | 
| <a name="rtbfabric-GetLink"></a>[GetLink](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetLink.html) | Retrieve information about a link between RTB applications | Read | 
| <a name="rtbfabric-GetLinkRoutingRule"></a>[GetLinkRoutingRule](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetLinkRoutingRule.html) | Retrieve information about a routing rule for a link | Read | 
| <a name="rtbfabric-GetOutboundExternalLink"></a>[GetOutboundExternalLink](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetOutboundExternalLink.html) | Retrieve information about an outbound external link | Read | 
| <a name="rtbfabric-GetRequesterGateway"></a>[GetRequesterGateway](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetRequesterGateway.html) | Retrieve information about a requester gateway | Read | 
| <a name="rtbfabric-GetResponderGateway"></a>[GetResponderGateway](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_GetResponderGateway.html) | Retrieve information about a responder gateway | Read | 
| <a name="rtbfabric-ListCertificateAssociations"></a>[ListCertificateAssociations](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListCertificateAssociations.html) | List certificate associations for a responder gateway | List | 
| <a name="rtbfabric-ListLinkRoutingRules"></a>[ListLinkRoutingRules](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListLinkRoutingRules.html) | List routing rules for a link | List | 
| <a name="rtbfabric-ListLinks"></a>[ListLinks](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListLinks.html) | List links associated with an RTB application | List | 
| <a name="rtbfabric-ListRequesterGateways"></a>[ListRequesterGateways](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListRequesterGateways.html) | List requester gateways with optional filtering and pagination | List | 
| <a name="rtbfabric-ListResponderGateways"></a>[ListResponderGateways](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListResponderGateways.html) | List responder gateways with optional filtering and pagination | List | 
| <a name="rtbfabric-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_ListTagsForResource.html) | List tags for a resource | Read |
