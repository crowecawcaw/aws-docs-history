# Data retrieval APIs for AWS RTB Fabric

AWS RTB Fabric provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                                                            | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------ |
| [GetCertificateAssociation](../../../rtb-fabric/latest/api/API_GetCertificateAssociation.md "../../../rtb-fabric/latest/api/API_GetCertificateAssociation.md")       | Retrieve details of a certificate association with a responder gateway | Read         |
| [GetInboundExternalLink](../../../rtb-fabric/latest/api/API_GetInboundExternalLink.md "../../../rtb-fabric/latest/api/API_GetInboundExternalLink.md")                | Retrieve information about an inbound external link                    | Read         |
| [GetLink](../../../rtb-fabric/latest/api/API_GetLink.md "../../../rtb-fabric/latest/api/API_GetLink.md")                                                             | Retrieve information about a link between RTB applications             | Read         |
| [GetLinkRoutingRule](../../../rtb-fabric/latest/api/API_GetLinkRoutingRule.md "../../../rtb-fabric/latest/api/API_GetLinkRoutingRule.md")                            | Retrieve information about a routing rule for a link                   | Read         |
| [GetOutboundExternalLink](../../../rtb-fabric/latest/api/API_GetOutboundExternalLink.md "../../../rtb-fabric/latest/api/API_GetOutboundExternalLink.md")             | Retrieve information about an outbound external link                   | Read         |
| [GetRequesterGateway](../../../rtb-fabric/latest/api/API_GetRequesterGateway.md "../../../rtb-fabric/latest/api/API_GetRequesterGateway.md")                         | Retrieve information about a requester gateway                         | Read         |
| [GetResponderGateway](../../../rtb-fabric/latest/api/API_GetResponderGateway.md "../../../rtb-fabric/latest/api/API_GetResponderGateway.md")                         | Retrieve information about a responder gateway                         | Read         |
| [ListCertificateAssociations](../../../rtb-fabric/latest/api/API_ListCertificateAssociations.md "../../../rtb-fabric/latest/api/API_ListCertificateAssociations.md") | List certificate associations for a responder gateway                  | List         |
| [ListLinkRoutingRules](../../../rtb-fabric/latest/api/API_ListLinkRoutingRules.md "../../../rtb-fabric/latest/api/API_ListLinkRoutingRules.md")                      | List routing rules for a link                                          | List         |
| [ListLinks](../../../rtb-fabric/latest/api/API_ListLinks.md "../../../rtb-fabric/latest/api/API_ListLinks.md")                                                       | List links associated with an RTB application                          | List         |
| [ListRequesterGateways](../../../rtb-fabric/latest/api/API_ListRequesterGateways.md "../../../rtb-fabric/latest/api/API_ListRequesterGateways.md")                   | List requester gateways with optional filtering and pagination         | List         |
| [ListResponderGateways](../../../rtb-fabric/latest/api/API_ListResponderGateways.md "../../../rtb-fabric/latest/api/API_ListResponderGateways.md")                   | List responder gateways with optional filtering and pagination         | List         |
| [ListTagsForResource](../../../rtb-fabric/latest/api/API_ListTagsForResource.md "../../../rtb-fabric/latest/api/API_ListTagsForResource.md")                         | List tags for a resource                                               | Read         |
