

# Data retrieval APIs for AWS Billing
<a name="awsbilling"></a>

AWS Billing provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="billing-GetBillingData"></a>[GetBillingData](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Perform queries on billing information | Read | 
| <a name="billing-GetBillingDetails"></a>[GetBillingDetails](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View detailed line item billing information | Read | 
| <a name="billing-GetBillingNotifications"></a>[GetBillingNotifications](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View notifications sent by AWS related to your accounts billing information | Read | 
| <a name="billing-GetBillingPreferences"></a>[GetBillingPreferences](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View billing preferences such as reserved instance, savings plans and credits sharing | Read | 
| <a name="billing-GetBillingView"></a>[GetBillingView](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_billing_GetBillingView.html) | Get the metadata for a specified billing view | Read | 
| <a name="billing-GetBillingViewData"></a>[GetBillingViewData](https://docs.aws.amazon.com/) | Get cost and usage data for a specified billng view | Read | 
| <a name="billing-GetContractInformation"></a>[GetContractInformation](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View the account's contract information including the contract number, end-user organization names, PO numbers and if the account is used to service public-sector customers | Read | 
| <a name="billing-GetCreditAllocationHistory"></a>[GetCreditAllocationHistory](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View a credit allocation history | Read | 
| <a name="billing-GetCredits"></a>[GetCredits](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View credits that have been redeemed | Read | 
| <a name="billing-GetEnterpriseSupportChargeSummary"></a>[GetEnterpriseSupportChargeSummary](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View Enterprise Support charge summary data | Read | 
| <a name="billing-GetEnterpriseSupportContractDetails"></a>[GetEnterpriseSupportContractDetails](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View Enterprise Support contract details | Read | 
| <a name="billing-GetIAMAccessPreference"></a>[GetIAMAccessPreference](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Retrieve the state of the Allow IAM Access billing preference | Read | 
| <a name="billing-GetSellerOfRecord"></a>[GetSellerOfRecord](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Retrieve the account's default Seller of Record | Read | 
| <a name="billing-ListBillingViews"></a>[ListBillingViews](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_billing_ListBillingViews.html) | Get a list of all your available billing views | Read | 
| <a name="billing-ListEnterpriseSupportLinkedAccountCharges"></a>[ListEnterpriseSupportLinkedAccountCharges](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | View Enterprise Support charges broken down by linked account | List | 
| <a name="billing-ListSourceViewsForBillingView"></a>[ListSourceViewsForBillingView](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_billing_ListSourceViewsForBillingView.html) | Get the list of source views for a specified billing view | List | 
| <a name="billing-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_billing_ListTagsForResource.html) | Get the list of tags for a specified billing view | Read | 
| <a name="billing-UseSourceView"></a>[UseSourceView](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Use a billing view as a data source for other billing views | Read |
