# Data retrieval APIs for AWS Billing

AWS Billing provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                        | Description                                                                                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetBillingData](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                                | Perform queries on billing information                                                                                                                                       | Read         |
| [GetBillingDetails](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                             | View detailed line item billing information                                                                                                                                  | Read         |
| [GetBillingNotifications](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                       | View notifications sent by AWS related to your accounts billing information                                                                                                  | Read         |
| [GetBillingPreferences](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                         | View billing preferences such as reserved instance, savings plans and credits sharing                                                                                        | Read         |
| [GetBillingView](../../../aws-cost-management/latest/APIReference/API_billing_GetBillingView.md "../../../aws-cost-management/latest/APIReference/API_billing_GetBillingView.md")                                              | Get the metadata for a specified billing view                                                                                                                                | Read         |
| [GetBillingViewData](../../../index.md "../../../index.md")                                                                                                                                                                    | Get cost and usage data for a specified billng view                                                                                                                          | Read         |
| [GetContractInformation](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                        | View the account's contract information including the contract number, end-user organization names, PO numbers and if the account is used to service public-sector customers | Read         |
| [GetCredits](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                                    | View credits that have been redeemed                                                                                                                                         | Read         |
| [GetIAMAccessPreference](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                        | Retrieve the state of the Allow IAM Access billing preference                                                                                                                | Read         |
| [GetSellerOfRecord](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                             | Retrieve the account's default Seller of Record                                                                                                                              | Read         |
| [ListBillingViews](../../../aws-cost-management/latest/APIReference/API_billing_ListBillingViews.md "../../../aws-cost-management/latest/APIReference/API_billing_ListBillingViews.md")                                        | Get a list of all your available billing views                                                                                                                               | Read         |
| [ListSourceViewsForBillingView](../../../aws-cost-management/latest/APIReference/API_billing_ListSourceViewsForBillingView.md "../../../aws-cost-management/latest/APIReference/API_billing_ListSourceViewsForBillingView.md") | Get the list of source views for a specified billing view                                                                                                                    | List         |
| [ListTagsForResource](../../../aws-cost-management/latest/APIReference/API_billing_ListTagsForResource.md "../../../aws-cost-management/latest/APIReference/API_billing_ListTagsForResource.md")                               | Get the list of tags for a specified billing view                                                                                                                            | Read         |
| [UseSourceView](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md#user-permissions")                                 | Use a billing view as a data source for other billing views                                                                                                                  | Read         |
