# Data retrieval APIs for AWS Consolidated Billing

AWS Consolidated Billing provides the following APIs for data retrieval.

| Actions                                                                                                                                                              | Description                               | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- | ------------ |
| [GetAccountBillingRole](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md") | Get account role (Payer, Linked, Regular) | Read         |
| [ListLinkedAccounts](../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md "../../../awsaccountbilling/latest/aboutv2/billing-permissions-ref.md")    | Get list of member/linked accounts        | List         |
