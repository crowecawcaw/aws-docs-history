# Data retrieval APIs for AWS Lambda

AWS Lambda provides the following APIs for data retrieval.

| Actions                                                                                                                                                                      | Description                                                                                                     | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetAccountSettings](../../../lambda/latest/dg/API_GetAccountSettings.md "../../../lambda/latest/dg/API_GetAccountSettings.md")                                              | View details about an account's limits and usage in an AWS Region                                               | Read         |
| [GetAlias](../../../lambda/latest/dg/API_GetAlias.md "../../../lambda/latest/dg/API_GetAlias.md")                                                                            | View details about an AWS Lambda function alias                                                                 | Read         |
| [GetCodeSigningConfig](../../../lambda/latest/dg/API_GetCodeSigningConfig.md "../../../lambda/latest/dg/API_GetCodeSigningConfig.md")                                        | View details about an AWS Lambda code signing config                                                            | Read         |
| [GetEventSourceMapping](../../../lambda/latest/dg/API_GetEventSourceMapping.md "../../../lambda/latest/dg/API_GetEventSourceMapping.md")                                     | View details about an AWS Lambda event source mapping                                                           | Read         |
| [GetFunction](../../../lambda/latest/dg/API_GetFunction.md "../../../lambda/latest/dg/API_GetFunction.md")                                                                   | View details about an AWS Lambda function                                                                       | Read         |
| [GetFunctionCodeSigningConfig](../../../lambda/latest/dg/API_GetFunctionCodeSigningConfig.md "../../../lambda/latest/dg/API_GetFunctionCodeSigningConfig.md")                | View the code signing config arn attached to an AWS Lambda function                                             | Read         |
| [GetFunctionConcurrency](../../../lambda/latest/dg/API_GetFunctionConcurrency.md "../../../lambda/latest/dg/API_GetFunctionConcurrency.md")                                  | View details about the reserved concurrency configuration for a function                                        | Read         |
| [GetFunctionConfiguration](../../../lambda/latest/dg/API_GetFunctionConfiguration.md "../../../lambda/latest/dg/API_GetFunctionConfiguration.md")                            | View details about the version-specific settings of an AWS Lambda function or version                           | Read         |
| [GetFunctionEventInvokeConfig](../../../lambda/latest/dg/API_GetFunctionEventInvokeConfig.md "../../../lambda/latest/dg/API_GetFunctionEventInvokeConfig.md")                | View the configuration for asynchronous invocation for a function, version, or alias                            | Read         |
| [GetFunctionRecursionConfig](../../../lambda/latest/dg/API_GetFunctionRecursionConfig.md "../../../lambda/latest/dg/API_GetFunctionRecursionConfig.md")                      | View the recursion configuration of an AWS Lambda function                                                      | Read         |
| [GetFunctionUrlConfig](../../../lambda/latest/dg/API_GetFunctionUrlConfig.md "../../../lambda/latest/dg/API_GetFunctionUrlConfig.md")                                        | Read function url configuration for a Lambda function                                                           | Read         |
| [GetLayerVersion](../../../lambda/latest/dg/API_GetLayerVersion.md "../../../lambda/latest/dg/API_GetLayerVersion.md")                                                       | View details about a version of an AWS Lambda layer. Note this action also supports GetLayerVersionByArn API    | Read         |
| [GetLayerVersionPolicy](../../../lambda/latest/dg/API_GetLayerVersionPolicy.md "../../../lambda/latest/dg/API_GetLayerVersionPolicy.md")                                     | View the resource-based policy for a version of an AWS Lambda layer                                             | Read         |
| [GetPolicy](../../../lambda/latest/dg/API_GetPolicy.md "../../../lambda/latest/dg/API_GetPolicy.md")                                                                         | View the resource-based policy for an AWS Lambda function, version, or alias                                    | Read         |
| [GetProvisionedConcurrencyConfig](../../../lambda/latest/dg/API_GetProvisionedConcurrencyConfig.md "../../../lambda/latest/dg/API_GetProvisionedConcurrencyConfig.md")       | View the provisioned concurrency configuration for an AWS Lambda function's alias or version                    | Read         |
| [GetRuntimeManagementConfig](../../../lambda/latest/dg/API_GetRuntimeManagementConfig.md "../../../lambda/latest/dg/API_GetRuntimeManagementConfig.md")                      | View the runtime management configuration of an AWS Lambda function                                             | Read         |
| [ListAliases](../../../lambda/latest/dg/API_ListAliases.md "../../../lambda/latest/dg/API_ListAliases.md")                                                                   | Retrieve a list of aliases for an AWS Lambda function                                                           | List         |
| [ListCodeSigningConfigs](../../../lambda/latest/dg/API_ListCodeSigningConfigs.md "../../../lambda/latest/dg/API_ListCodeSigningConfigs.md")                                  | Retrieve a list of AWS Lambda code signing configs                                                              | List         |
| [ListEventSourceMappings](../../../lambda/latest/dg/API_ListEventSourceMappings.md "../../../lambda/latest/dg/API_ListEventSourceMappings.md")                               | Retrieve a list of AWS Lambda event source mappings                                                             | List         |
| [ListFunctionEventInvokeConfigs](../../../lambda/latest/dg/API_ListFunctionEventInvokeConfigs.md "../../../lambda/latest/dg/API_ListFunctionEventInvokeConfigs.md")          | Retrieve a list of configurations for asynchronous invocation for a function                                    | List         |
| [ListFunctionUrlConfigs](../../../lambda/latest/dg/API_ListFunctionUrlConfigs.md "../../../lambda/latest/dg/API_ListFunctionUrlConfigs.md")                                  | Read function url configurations for a function                                                                 | List         |
| [ListFunctions](../../../lambda/latest/dg/API_ListFunctions.md "../../../lambda/latest/dg/API_ListFunctions.md")                                                             | Retrieve a list of AWS Lambda functions, with the version-specific configuration of each function               | List         |
| [ListFunctionsByCodeSigningConfig](../../../lambda/latest/dg/API_ListFunctionsByCodeSigningConfig.md "../../../lambda/latest/dg/API_ListFunctionsByCodeSigningConfig.md")    | Retrieve a list of AWS Lambda functions by the code signing config assigned                                     | List         |
| [ListLayerVersions](../../../lambda/latest/dg/API_ListLayerVersions.md "../../../lambda/latest/dg/API_ListLayerVersions.md")                                                 | Retrieve a list of versions of an AWS Lambda layer                                                              | List         |
| [ListLayers](../../../lambda/latest/dg/API_ListLayers.md "../../../lambda/latest/dg/API_ListLayers.md")                                                                      | Retrieve a list of AWS Lambda layers, with details about the latest version of each layer                       | List         |
| [ListProvisionedConcurrencyConfigs](../../../lambda/latest/dg/API_ListProvisionedConcurrencyConfigs.md "../../../lambda/latest/dg/API_ListProvisionedConcurrencyConfigs.md") | Retrieve a list of provisioned concurrency configurations for an AWS Lambda function                            | List         |
| [ListTags](../../../lambda/latest/dg/API_ListTags.md "../../../lambda/latest/dg/API_ListTags.md")                                                                            | Retrieve a list of tags for an AWS Lambda function, event source mapping or code signing configuration resource | Read         |
| [ListVersionsByFunction](../../../lambda/latest/dg/API_ListVersionsByFunction.md "../../../lambda/latest/dg/API_ListVersionsByFunction.md")                                  | Retrieve a list of versions for an AWS Lambda function                                                          | List         |
