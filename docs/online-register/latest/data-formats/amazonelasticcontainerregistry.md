# Data retrieval APIs for Amazon Elastic Container Registry

Amazon Elastic Container Registry provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                  | Description                                                                                             | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchCheckLayerAvailability](../../../AmazonECR/latest/APIReference/API_BatchCheckLayerAvailability.md "../../../AmazonECR/latest/APIReference/API_BatchCheckLayerAvailability.md")                                     | Check the availability of multiple image layers in a specified registry and repository                  | Read         |
| [BatchGetImage](../../../AmazonECR/latest/APIReference/API_BatchGetImage.md "../../../AmazonECR/latest/APIReference/API_BatchGetImage.md")                                                                               | Get detailed information for specified images within a specified repository                             | Read         |
| [BatchGetRepositoryScanningConfiguration](../../../AmazonECR/latest/APIReference/API_BatchGetRepositoryScanningConfiguration.md "../../../AmazonECR/latest/APIReference/API_BatchGetRepositoryScanningConfiguration.md") | Retrieve repository scanning configuration for a list of repositories                                   | Read         |
| [DescribeImageReplicationStatus](../../../AmazonECR/latest/APIReference/API_DescribeImageReplicationStatus.md "../../../AmazonECR/latest/APIReference/API_DescribeImageReplicationStatus.md")                            | Retrieve replication status about an image in a registry, including failure reason if replication fails | Read         |
| [DescribeImageScanFindings](../../../AmazonECR/latest/APIReference/API_DescribeImageScanFindings.md "../../../AmazonECR/latest/APIReference/API_DescribeImageScanFindings.md")                                           | Describe the image scan findings for the specified image                                                | Read         |
| [DescribeImageSigningStatus](../../../AmazonECR/latest/APIReference/API_DescribeImageSigningStatus.md "../../../AmazonECR/latest/APIReference/API_DescribeImageSigningStatus.md")                                        | Retrieve signing status about an image in a specified registry                                          | Read         |
| [DescribeImages](../../../AmazonECR/latest/APIReference/API_DescribeImages.md "../../../AmazonECR/latest/APIReference/API_DescribeImages.md")                                                                            | Get metadata about the images in a repository, including image size, image tags, and creation date      | List         |
| [DescribePullThroughCacheRules](../../../AmazonECR/latest/APIReference/API_DescribePullThroughCacheRules.md "../../../AmazonECR/latest/APIReference/API_DescribePullThroughCacheRules.md")                               | Describe the pull-through cache rules                                                                   | List         |
| [DescribeRegistry](../../../AmazonECR/latest/APIReference/API_DescribeRegistry.md "../../../AmazonECR/latest/APIReference/API_DescribeRegistry.md")                                                                      | Describe the registry settings                                                                          | Read         |
| [DescribeRepositories](../../../AmazonECR/latest/APIReference/API_DescribeRepositories.md "../../../AmazonECR/latest/APIReference/API_DescribeRepositories.md")                                                          | Describe image repositories in a registry                                                               | Read         |
| [DescribeRepositoryCreationTemplates](../../../AmazonECR/latest/APIReference/API_DescribeRepositoryCreationTemplates.md "../../../AmazonECR/latest/APIReference/API_DescribeRepositoryCreationTemplates.md")             | Describe the repository creation template                                                               | Read         |
| [GetAccountSetting](../../../AmazonECR/latest/APIReference/API_GetAccountSetting.md "../../../AmazonECR/latest/APIReference/API_GetAccountSetting.md")                                                                   | Retrieve account settings                                                                               | Read         |
| [GetAuthorizationToken](../../../AmazonECR/latest/APIReference/API_GetAuthorizationToken.md "../../../AmazonECR/latest/APIReference/API_GetAuthorizationToken.md")                                                       | Retrieve a token that is valid for a specified registry for 12 hours                                    | Read         |
| [GetDownloadUrlForLayer](../../../AmazonECR/latest/APIReference/API_GetDownloadUrlForLayer.md "../../../AmazonECR/latest/APIReference/API_GetDownloadUrlForLayer.md")                                                    | Retrieve the download URL corresponding to an image layer                                               | Read         |
| [GetImageCopyStatus](../../../AmazonECR/latest/userguide/pull-through-cache.md "../../../AmazonECR/latest/userguide/pull-through-cache.md")                                                                              | Retrieve the status about an image copy                                                                 | Read         |
| [GetLifecyclePolicy](../../../AmazonECR/latest/APIReference/API_GetLifecyclePolicy.md "../../../AmazonECR/latest/APIReference/API_GetLifecyclePolicy.md")                                                                | Retrieve the specified lifecycle policy                                                                 | Read         |
| [GetLifecyclePolicyPreview](../../../AmazonECR/latest/APIReference/API_GetLifecyclePolicyPreview.md "../../../AmazonECR/latest/APIReference/API_GetLifecyclePolicyPreview.md")                                           | Retrieve the results of the specified lifecycle policy preview request                                  | Read         |
| [GetRegistryPolicy](../../../AmazonECR/latest/APIReference/API_GetRegistryPolicy.md "../../../AmazonECR/latest/APIReference/API_GetRegistryPolicy.md")                                                                   | Retrieve the registry policy                                                                            | Read         |
| [GetRegistryScanningConfiguration](../../../AmazonECR/latest/APIReference/API_GetRegistryScanningConfiguration.md "../../../AmazonECR/latest/APIReference/API_GetRegistryScanningConfiguration.md")                      | Retrieve registry scanning configuration                                                                | Read         |
| [GetRepositoryPolicy](../../../AmazonECR/latest/APIReference/API_GetRepositoryPolicy.md "../../../AmazonECR/latest/APIReference/API_GetRepositoryPolicy.md")                                                             | Retrieve the repository policy for a specified repository                                               | Read         |
| [GetSigningConfiguration](../../../AmazonECR/latest/APIReference/API_GetSigningConfiguration.md "../../../AmazonECR/latest/APIReference/API_GetSigningConfiguration.md")                                                 | Retrieve the signing configuration for the registry                                                     | Read         |
| [ListImages](../../../AmazonECR/latest/APIReference/API_ListImages.md "../../../AmazonECR/latest/APIReference/API_ListImages.md")                                                                                        | List all the image IDs for a given repository                                                           | List         |
| [ListPullTimeUpdateExclusions](../../../AmazonECR/latest/APIReference/API_ListPullTimeUpdateExclusions.md "../../../AmazonECR/latest/APIReference/API_ListPullTimeUpdateExclusions.md")                                  | List pull time update exclusions for the registry                                                       | List         |
| [ListTagsForResource](../../../AmazonECR/latest/APIReference/API_ListTagsForResource.md "../../../AmazonECR/latest/APIReference/API_ListTagsForResource.md")                                                             | List the tags for an Amazon ECR resource                                                                | Read         |
| [ValidatePullThroughCacheRule](../../../AmazonECR/latest/APIReference/API_ValidatePullThroughCacheRule.md "../../../AmazonECR/latest/APIReference/API_ValidatePullThroughCacheRule.md")                                  | Validate the pull-through cache rule                                                                    | Read         |
