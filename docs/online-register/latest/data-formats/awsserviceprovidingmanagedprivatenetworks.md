

# Data retrieval APIs for AWS service providing managed private networks
<a name="awsserviceprovidingmanagedprivatenetworks"></a>

AWS service providing managed private networks provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="private-networks-GetDeviceIdentifier"></a>[GetDeviceIdentifier](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_GetDeviceIdentifier.html) | Get a device identifier | Read | 
| <a name="private-networks-GetNetwork"></a>[GetNetwork](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_GetNetwork.html) | Get a network | Read | 
| <a name="private-networks-GetNetworkResource"></a>[GetNetworkResource](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_GetNetworkResource.html) | Get a network resource | Read | 
| <a name="private-networks-GetNetworkSite"></a>[GetNetworkSite](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_GetNetworkSite.html) | Get a network site | Read | 
| <a name="private-networks-GetOrder"></a>[GetOrder](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_GetOrder.html) | Get a network order | Read | 
| <a name="private-networks-ListDeviceIdentifiers"></a>[ListDeviceIdentifiers](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListDeviceIdentifiers.html) | List device identifiers | List | 
| <a name="private-networks-ListNetworkResources"></a>[ListNetworkResources](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListNetworkResources.html) | List network resources | List | 
| <a name="private-networks-ListNetworkSites"></a>[ListNetworkSites](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListNetworkSites.html) | List network sites | List | 
| <a name="private-networks-ListNetworks"></a>[ListNetworks](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListNetworks.html) | List networks | List | 
| <a name="private-networks-ListOrders"></a>[ListOrders](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListOrders.html) | List network orders | List | 
| <a name="private-networks-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_ListTagsForResource.html) | Return a list of tags for a resource | List | 
| <a name="private-networks-Ping"></a>[Ping](https://docs.aws.amazon.com/private-networks/latest/APIReference/API_Ping.html) | Check the health of the service | Read |
