# Data retrieval APIs for AWS service providing managed private networks

AWS service providing managed private networks provides the following APIs for data retrieval.

| Actions                                                                                                                                                                          | Description                          | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ | ------------ |
| [GetDeviceIdentifier](../../../private-networks/latest/APIReference/API_GetDeviceIdentifier.md "../../../private-networks/latest/APIReference/API_GetDeviceIdentifier.md")       | Get a device identifier              | Read         |
| [GetNetwork](../../../private-networks/latest/APIReference/API_GetNetwork.md "../../../private-networks/latest/APIReference/API_GetNetwork.md")                                  | Get a network                        | Read         |
| [GetNetworkResource](../../../private-networks/latest/APIReference/API_GetNetworkResource.md "../../../private-networks/latest/APIReference/API_GetNetworkResource.md")          | Get a network resource               | Read         |
| [GetNetworkSite](../../../private-networks/latest/APIReference/API_GetNetworkSite.md "../../../private-networks/latest/APIReference/API_GetNetworkSite.md")                      | Get a network site                   | Read         |
| [GetOrder](../../../private-networks/latest/APIReference/API_GetOrder.md "../../../private-networks/latest/APIReference/API_GetOrder.md")                                        | Get a network order                  | Read         |
| [ListDeviceIdentifiers](../../../private-networks/latest/APIReference/API_ListDeviceIdentifiers.md "../../../private-networks/latest/APIReference/API_ListDeviceIdentifiers.md") | List device identifiers              | List         |
| [ListNetworkResources](../../../private-networks/latest/APIReference/API_ListNetworkResources.md "../../../private-networks/latest/APIReference/API_ListNetworkResources.md")    | List network resources               | List         |
| [ListNetworkSites](../../../private-networks/latest/APIReference/API_ListNetworkSites.md "../../../private-networks/latest/APIReference/API_ListNetworkSites.md")                | List network sites                   | List         |
| [ListNetworks](../../../private-networks/latest/APIReference/API_ListNetworks.md "../../../private-networks/latest/APIReference/API_ListNetworks.md")                            | List networks                        | List         |
| [ListOrders](../../../private-networks/latest/APIReference/API_ListOrders.md "../../../private-networks/latest/APIReference/API_ListOrders.md")                                  | List network orders                  | List         |
| [ListTagsForResource](../../../private-networks/latest/APIReference/API_ListTagsForResource.md "../../../private-networks/latest/APIReference/API_ListTagsForResource.md")       | Return a list of tags for a resource | List         |
| [Ping](../../../private-networks/latest/APIReference/API_Ping.md "../../../private-networks/latest/APIReference/API_Ping.md")                                                    | Check the health of the service      | Read         |
