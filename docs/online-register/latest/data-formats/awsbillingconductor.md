# Data retrieval APIs for AWS Billing Conductor

AWS Billing Conductor provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                      | Description                                                                                                                                     | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetBillingGroupCostReport](../../../billingconductor/latest/APIReference/API_GetBillingGroupCostReport.md "../../../billingconductor/latest/APIReference/API_GetBillingGroupCostReport.md")                                                 | View the billing group cost report for the specified billing group                                                                              | Read         |
| [ListAccountAssociations](../../../billingconductor/latest/APIReference/API_ListAccountAssociations.md "../../../billingconductor/latest/APIReference/API_ListAccountAssociations.md")                                                       | List the linked accounts of the payer account for the given billing period while also providing the billing group the linked accounts belong to | List         |
| [ListBillingGroupCostReports](../../../billingconductor/latest/APIReference/API_ListBillingGroupCostReports.md "../../../billingconductor/latest/APIReference/API_ListBillingGroupCostReports.md")                                           | View the billing group cost report                                                                                                              | Read         |
| [ListBillingGroups](../../../billingconductor/latest/APIReference/API_ListBillingGroups.md "../../../billingconductor/latest/APIReference/API_ListBillingGroups.md")                                                                         | View the details of billing groups                                                                                                              | Read         |
| [ListCustomLineItemVersions](../../../billingconductor/latest/APIReference/API_ListCustomLineItemVersions.md "../../../billingconductor/latest/APIReference/API_ListCustomLineItemVersions.md")                                              | View custom line item versions                                                                                                                  | Read         |
| [ListCustomLineItems](../../../billingconductor/latest/APIReference/API_ListCustomLineItems.md "../../../billingconductor/latest/APIReference/API_ListCustomLineItems.md")                                                                   | View custom line item details                                                                                                                   | Read         |
| [ListPricingPlans](../../../billingconductor/latest/APIReference/API_ListPricingPlans.md "../../../billingconductor/latest/APIReference/API_ListPricingPlans.md")                                                                            | View the pricing plans details                                                                                                                  | Read         |
| [ListPricingPlansAssociatedWithPricingRule](../../../billingconductor/latest/APIReference/API_ListPricingPlansAssociatedWithPricingRule.md "../../../billingconductor/latest/APIReference/API_ListPricingPlansAssociatedWithPricingRule.md") | List pricing plans associated with a pricing rule                                                                                               | List         |
| [ListPricingRules](../../../billingconductor/latest/APIReference/API_ListPricingRules.md "../../../billingconductor/latest/APIReference/API_ListPricingRules.md")                                                                            | View pricing rules details                                                                                                                      | Read         |
| [ListPricingRulesAssociatedToPricingPlan](../../../billingconductor/latest/APIReference/API_ListPricingRulesAssociatedToPricingPlan.md "../../../billingconductor/latest/APIReference/API_ListPricingRulesAssociatedToPricingPlan.md")       | List pricing rules associated to a pricing plan                                                                                                 | List         |
| [ListResourcesAssociatedToCustomLineItem](../../../billingconductor/latest/APIReference/API_ListResourcesAssociatedToCustomLineItem.md "../../../billingconductor/latest/APIReference/API_ListResourcesAssociatedToCustomLineItem.md")       | List resources associated to a percentage custom line item                                                                                      | List         |
| [ListTagsForResource](../../../billingconductor/latest/APIReference/API_ListTagsForResource.md "../../../billingconductor/latest/APIReference/API_ListTagsForResource.md")                                                                   | List tags of a resource                                                                                                                         | Read         |
