

# Data retrieval APIs for AWS Global Accelerator
<a name="awsglobalaccelerator"></a>

AWS Global Accelerator provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="globalaccelerator-DescribeAccelerator"></a>[DescribeAccelerator](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeAccelerator.html) | Grants permissions to describe a standard accelerator | Read | 
| <a name="globalaccelerator-DescribeAcceleratorAttributes"></a>[DescribeAcceleratorAttributes](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeAcceleratorAttributes.html) | Describe a standard accelerator attributes | Read | 
| <a name="globalaccelerator-DescribeCrossAccountAttachment"></a>[DescribeCrossAccountAttachment](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeCrossAccountAttachment.html) | Grants permissions to describe a CrossAccountAttachment | Read | 
| <a name="globalaccelerator-DescribeCustomRoutingAccelerator"></a>[DescribeCustomRoutingAccelerator](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeCustomRoutingAccelerator.html) | Describe a custom routing accelerator | Read | 
| <a name="globalaccelerator-DescribeCustomRoutingAcceleratorAttributes"></a>[DescribeCustomRoutingAcceleratorAttributes](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeCustomRoutingAcceleratorAttributes.html) | Describe the attributes of a custom routing accelerator | Read | 
| <a name="globalaccelerator-DescribeCustomRoutingEndpointGroup"></a>[DescribeCustomRoutingEndpointGroup](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeCustomRoutingEndpointGroup.html) | Describe an endpoint group for a custom routing accelerator | Read | 
| <a name="globalaccelerator-DescribeCustomRoutingListener"></a>[DescribeCustomRoutingListener](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeCustomRoutingListener.html) | Describe a listener for a custom routing accelerator | Read | 
| <a name="globalaccelerator-DescribeEndpointGroup"></a>[DescribeEndpointGroup](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeEndpointGroup.html) | Describe a standard accelerator endpoint group | Read | 
| <a name="globalaccelerator-DescribeListener"></a>[DescribeListener](https://docs.aws.amazon.com/global-accelerator/latest/api/API_DescribeListener.html) | Describe a standard accelerator listener | Read | 
| <a name="globalaccelerator-ListAccelerators"></a>[ListAccelerators](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListAccelerators.html) | List all standard accelerators | List | 
| <a name="globalaccelerator-ListByoipCidrs"></a>[ListByoipCidrs](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListByoipCidrs.html) | List the BYOIP cidrs | List | 
| <a name="globalaccelerator-ListCrossAccountAttachments"></a>[ListCrossAccountAttachments](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCrossAccountAttachments.html) | List all CrossAccountAttachments | List | 
| <a name="globalaccelerator-ListCrossAccountResourceAccounts"></a>[ListCrossAccountResourceAccounts](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCrossAccountResourceAccounts.html) | List accounts with CrossAccountAttachments listing caller as a principal | List | 
| <a name="globalaccelerator-ListCrossAccountResources"></a>[ListCrossAccountResources](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCrossAccountResources.html) | List all CrossAccountAttachment resources usable by caller | List | 
| <a name="globalaccelerator-ListCustomRoutingAccelerators"></a>[ListCustomRoutingAccelerators](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCustomRoutingAccelerators.html) | List the custom routing accelerators for an AWS account | List | 
| <a name="globalaccelerator-ListCustomRoutingEndpointGroups"></a>[ListCustomRoutingEndpointGroups](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCustomRoutingEndpointGroups.html) | List the endpoint groups that are associated with a listener for a custom routing accelerator | List | 
| <a name="globalaccelerator-ListCustomRoutingListeners"></a>[ListCustomRoutingListeners](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCustomRoutingListeners.html) | List the listeners for a custom routing accelerator | List | 
| <a name="globalaccelerator-ListCustomRoutingPortMappings"></a>[ListCustomRoutingPortMappings](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCustomRoutingPortMappings.html) | List the port mappings for a custom routing accelerator | List | 
| <a name="globalaccelerator-ListCustomRoutingPortMappingsByDestination"></a>[ListCustomRoutingPortMappingsByDestination](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListCustomRoutingPortMappingsByDestination.html) | List the port mappings for a specific endpoint IP address (a destination address) in a subnet | List | 
| <a name="globalaccelerator-ListEndpointGroups"></a>[ListEndpointGroups](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListEndpointGroups.html) | List all endpoint groups associated with a standard accelerator listener | List | 
| <a name="globalaccelerator-ListListeners"></a>[ListListeners](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListListeners.html) | List all listeners associated with a standard accelerator | List | 
| <a name="globalaccelerator-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/global-accelerator/latest/api/API_ListTagsForResource.html) | List tags for a globalaccelerator resource | Read |
