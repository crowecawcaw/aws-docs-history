# Data retrieval APIs for AWS Marketplace Catalog

AWS Marketplace Catalog provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                      | Description                                                                                                                                                             | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [DescribeAssessment](../../../marketplace-catalog/latest/api-reference/API_DescribeAssessment.md "../../../marketplace-catalog/latest/api-reference/API_DescribeAssessment.md")              | Return the details of an existing assessment                                                                                                                            | Read         |
| [DescribeChangeSet](../../../marketplace-catalog/latest/api-reference/API_DescribeChangeSet.md "../../../marketplace-catalog/latest/api-reference/API_DescribeChangeSet.md")                 | Return the details of an existing change set                                                                                                                            | Read         |
| [DescribeEntity](../../../marketplace-catalog/latest/api-reference/API_DescribeEntity.md "../../../marketplace-catalog/latest/api-reference/API_DescribeEntity.md")                          | Return the details of an existing entity                                                                                                                                | Read         |
| [GetInvoiceSubmissionTask](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")            | Retrieve details of an existing invoice submission task                                                                                                                 | Read         |
| [GetIssuedTaxInvoice](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")                 | Retrieve details of a specific tax invoice issued by AWS on behalf of a seller                                                                                          | Read         |
| [GetResourcePolicy](../../../marketplace-catalog/latest/api-reference/API_GetResourcePolicy.md "../../../marketplace-catalog/latest/api-reference/API_GetResourcePolicy.md")                 | Get the resource policy of an existing entity                                                                                                                           | Read         |
| [GetTaxComplianceProfile](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")             | Retrieve details of a tax compliance profile including artifacts with download URLs                                                                                     | Read         |
| [GetVerification](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")                     | Retrieve the detailed status of a specific verification process, including PSP validation results                                                                       | Read         |
| [GetVerificationEvidence](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")             | Retrieve the complete content of a specific verification evidence resource                                                                                              | Read         |
| [ListAssessments](../../../marketplace-catalog/latest/api-reference/API_ListAssessments.md "../../../marketplace-catalog/latest/api-reference/API_ListAssessments.md")                       | List existing assessments                                                                                                                                               | List         |
| [ListChangeSets](../../../marketplace-catalog/latest/api-reference/API_ListChangeSets.md "../../../marketplace-catalog/latest/api-reference/API_ListChangeSets.md")                          | List existing change sets                                                                                                                                               | List         |
| [ListEntities](../../../marketplace-catalog/latest/api-reference/API_ListEntities.md "../../../marketplace-catalog/latest/api-reference/API_ListEntities.md")                                | List existing entities                                                                                                                                                  | List         |
| [ListInvoiceSubmissionTasks](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")          | List existing invoice submission tasks                                                                                                                                  | List         |
| [ListIssuedTaxInvoices](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")               | List tax invoices issued by AWS on behalf of a seller                                                                                                                   | List         |
| [ListPayables](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")                        | List payables of the specified payable provenance                                                                                                                       | List         |
| [ListTagsForResource](../../../marketplace-catalog/latest/api-reference/API_ListTagsForResource.md "../../../marketplace-catalog/latest/api-reference/API_ListTagsForResource.md")           | List tags on an existing entity, change set, invoice submission task, issued tax invoice, VerificationEvidence, TaxComplianceProfile, or TaxComplianceProfileChangeTask | Read         |
| [ListTaxComplianceProfileChangeTasks](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md") | List tax compliance profile change tasks with optional filters                                                                                                          | List         |
| [ListTaxComplianceProfiles](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")           | List tax compliance profiles with optional filters                                                                                                                      | List         |
| [ListVerificationEvidence](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")            | List verification evidence resources with summary metadata                                                                                                              | List         |
| [ListVerifications](../../../marketplace/latest/APIReference/compliance-api-access-control.md "../../../marketplace/latest/APIReference/compliance-api-access-control.md")                   | List all verification statuses across jurisdictions and verification types                                                                                              | List         |
