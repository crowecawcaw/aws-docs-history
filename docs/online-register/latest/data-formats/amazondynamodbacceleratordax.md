# Data retrieval APIs for Amazon DynamoDB Accelerator (DAX)

Amazon DynamoDB Accelerator (DAX) provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                          | Description                                                                                                               | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetItem](../../../amazondynamodb/latest/APIReference/API_BatchGetItem.md "../../../amazondynamodb/latest/APIReference/API_BatchGetItem.md")                                                | Return the attributes of one or more items from one or more tables                                                        | Read         |
| [ConditionCheckItem](../../../amazondynamodb/latest/APIReference/API_ConditionCheckItem.md "../../../amazondynamodb/latest/APIReference/API_ConditionCheckItem.md")                              | The ConditionCheckItem operation that checks the existence of a set of attributes for the item with the given primary key | Read         |
| [DescribeClusters](../../../amazondynamodb/latest/APIReference/API_dax_DescribeClusters.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeClusters.md")                            | Return information about all provisioned DAX clusters                                                                     | List         |
| [DescribeDefaultParameters](../../../amazondynamodb/latest/APIReference/API_dax_DescribeDefaultParameters.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeDefaultParameters.md") | Return the default system parameter information for DAX                                                                   | List         |
| [DescribeEvents](../../../amazondynamodb/latest/APIReference/API_dax_DescribeEvents.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeEvents.md")                                  | Return events related to DAX clusters and parameter groups                                                                | List         |
| [DescribeParameterGroups](../../../amazondynamodb/latest/APIReference/API_dax_DescribeParameterGroups.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeParameterGroups.md")       | Return a list of parameter group descriptions                                                                             | List         |
| [DescribeParameters](../../../amazondynamodb/latest/APIReference/API_dax_DescribeParameters.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeParameters.md")                      | Return the detailed parameter list for a particular parameter group                                                       | Read         |
| [DescribeSubnetGroups](../../../amazondynamodb/latest/APIReference/API_dax_DescribeSubnetGroups.md "../../../amazondynamodb/latest/APIReference/API_dax_DescribeSubnetGroups.md")                | Return a list of subnet group descriptions                                                                                | List         |
| [GetItem](../../../amazondynamodb/latest/APIReference/API_GetItem.md "../../../amazondynamodb/latest/APIReference/API_GetItem.md")                                                               | The GetItem operation that returns a set of attributes for the item with the given primary key                            | Read         |
| [ListTags](../../../amazondynamodb/latest/APIReference/API_dax_ListTags.md "../../../amazondynamodb/latest/APIReference/API_dax_ListTags.md")                                                    | Return a list all of the tags for a DAX cluster                                                                           | Read         |
| [Query](../../../amazondynamodb/latest/APIReference/API_Query.md "../../../amazondynamodb/latest/APIReference/API_Query.md")                                                                     | Use the primary key of a table or a secondary index to directly access items from that table or index                     | Read         |
| [Scan](../../../amazondynamodb/latest/APIReference/API_Scan.md "../../../amazondynamodb/latest/APIReference/API_Scan.md")                                                                        | Return one or more items and item attributes by accessing every item in a table or a secondary index                      | Read         |
