# Data retrieval APIs for Amazon Location

Amazon Location provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                     | Description                                                                                             | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchGetDevicePosition](../../../location/latest/APIReference/API_BatchGetDevicePosition.md "../../../location/latest/APIReference/API_BatchGetDevicePosition.md")                         | Send a batch request to retrieve device positions                                                       | Read         |
| [CalculateRoute](../../../location/latest/APIReference/API_CalculateRoute.md "../../../location/latest/APIReference/API_CalculateRoute.md")                                                 | Calculate routes using a given route calculator resource                                                | Read         |
| [CalculateRouteMatrix](../../../location/latest/APIReference/API_CalculateRouteMatrix.md "../../../location/latest/APIReference/API_CalculateRouteMatrix.md")                               | Calculate a route matrix using a given route calculator resource                                        | Read         |
| [DescribeGeofenceCollection](../../../location/latest/APIReference/API_DescribeGeofenceCollection.md "../../../location/latest/APIReference/API_DescribeGeofenceCollection.md")             | Retrieve geofence collection details                                                                    | Read         |
| [DescribeKey](../../../location/latest/APIReference/API_DescribeKey.md "../../../location/latest/APIReference/API_DescribeKey.md")                                                          | Retrieve API key resource details and secret                                                            | Read         |
| [DescribeMap](../../../location/latest/APIReference/API_DescribeMap.md "../../../location/latest/APIReference/API_DescribeMap.md")                                                          | Retrieve map resource details                                                                           | Read         |
| [DescribePlaceIndex](../../../location/latest/APIReference/API_DescribePlaceIndex.md "../../../location/latest/APIReference/API_DescribePlaceIndex.md")                                     | Retrieve place-index resource details                                                                   | Read         |
| [DescribeRouteCalculator](../../../location/latest/APIReference/API_DescribeRouteCalculator.md "../../../location/latest/APIReference/API_DescribeRouteCalculator.md")                      | Retrieve route calculator resource details                                                              | Read         |
| [DescribeTracker](../../../location/latest/APIReference/API_DescribeTracker.md "../../../location/latest/APIReference/API_DescribeTracker.md")                                              | Retrieve a tracker resource details                                                                     | Read         |
| [ForecastGeofenceEvents](../../../location/latest/APIReference/API_ForecastGeofenceEvents.md "../../../location/latest/APIReference/API_ForecastGeofenceEvents.md")                         | Forecast events for geofences stored in a given geofence collection                                     | Read         |
| [GetDevicePosition](../../../location/latest/APIReference/API_GetDevicePosition.md "../../../location/latest/APIReference/API_GetDevicePosition.md")                                        | Retrieve the latest device position                                                                     | Read         |
| [GetDevicePositionHistory](../../../location/latest/APIReference/API_GetDevicePositionHistory.md "../../../location/latest/APIReference/API_GetDevicePositionHistory.md")                   | Retrieve the device position history                                                                    | Read         |
| [GetGeofence](../../../location/latest/APIReference/API_GetGeofence.md "../../../location/latest/APIReference/API_GetGeofence.md")                                                          | Retrieve the geofence details from a geofence-collection                                                | Read         |
| [GetMapGlyphs](../../../location/latest/APIReference/API_GetMapGlyphs.md "../../../location/latest/APIReference/API_GetMapGlyphs.md")                                                       | Retrieve the glyph file for a map resource                                                              | Read         |
| [GetMapSprites](../../../location/latest/APIReference/API_GetMapSprites.md "../../../location/latest/APIReference/API_GetMapSprites.md")                                                    | Retrieve the sprite file for a map resource                                                             | Read         |
| [GetMapStyleDescriptor](../../../location/latest/APIReference/API_GetMapStyleDescriptor.md "../../../location/latest/APIReference/API_GetMapStyleDescriptor.md")                            | Retrieve the map style descriptor from a map resource                                                   | Read         |
| [GetMapTile](../../../location/latest/APIReference/API_GetMapTile.md "../../../location/latest/APIReference/API_GetMapTile.md")                                                             | Retrieve the map tile from the map resource                                                             | Read         |
| [GetPlace](../../../location/latest/APIReference/API_GetPlace.md "../../../location/latest/APIReference/API_GetPlace.md")                                                                   | Find a place by its unique ID                                                                           | Read         |
| [ListDevicePositions](../../../location/latest/APIReference/API_ListDevicePositions.md "../../../location/latest/APIReference/API_ListDevicePositions.md")                                  | Retrieve a list of devices and their latest positions from the given tracker resource                   | Read         |
| [ListGeofenceCollections](../../../location/latest/APIReference/API_ListGeofenceCollections.md "../../../location/latest/APIReference/API_ListGeofenceCollections.md")                      | Lists geofence-collections                                                                              | List         |
| [ListGeofences](../../../location/latest/APIReference/API_ListGeofences.md "../../../location/latest/APIReference/API_ListGeofences.md")                                                    | List geofences stored in a given geofence collection                                                    | Read         |
| [ListKeys](../../../location/latest/APIReference/API_ListKeys.md "../../../location/latest/APIReference/API_ListKeys.md")                                                                   | List API key resources                                                                                  | List         |
| [ListMaps](../../../location/latest/APIReference/API_ListMaps.md "../../../location/latest/APIReference/API_ListMaps.md")                                                                   | List map resources                                                                                      | List         |
| [ListPlaceIndexes](../../../location/latest/APIReference/API_ListPlaceIndexes.md "../../../location/latest/APIReference/API_ListPlaceIndexes.md")                                           | Return a list of place index resources                                                                  | List         |
| [ListRouteCalculators](../../../location/latest/APIReference/API_ListRouteCalculators.md "../../../location/latest/APIReference/API_ListRouteCalculators.md")                               | Return a list of route calculator resources                                                             | List         |
| [ListTagsForResource](../../../location/latest/APIReference/API_ListTagsForResource.md "../../../location/latest/APIReference/API_ListTagsForResource.md")                                  | List the tags (metadata) which you have assigned to the resource                                        | Read         |
| [ListTrackerConsumers](../../../location/latest/APIReference/API_ListTrackerConsumers.md "../../../location/latest/APIReference/API_ListTrackerConsumers.md")                               | Retrieve a list of geofence collections currently associated to the given tracker resource              | Read         |
| [ListTrackers](../../../location/latest/APIReference/API_ListTrackers.md "../../../location/latest/APIReference/API_ListTrackers.md")                                                       | Return a list of tracker resources                                                                      | List         |
| [SearchPlaceIndexForPosition](../../../location/latest/APIReference/API_SearchPlaceIndexForPosition.md "../../../location/latest/APIReference/API_SearchPlaceIndexForPosition.md")          | Reverse geocodes a given coordinate                                                                     | Read         |
| [SearchPlaceIndexForSuggestions](../../../location/latest/APIReference/API_SearchPlaceIndexForSuggestions.md "../../../location/latest/APIReference/API_SearchPlaceIndexForSuggestions.md") | Generate suggestions for addresses and points of interest based on partial or misspelled free-form text | Read         |
| [SearchPlaceIndexForText](../../../location/latest/APIReference/API_SearchPlaceIndexForText.md "../../../location/latest/APIReference/API_SearchPlaceIndexForText.md")                      | Geocode free-form text, such as an address, name, city or region                                        | Read         |
| [VerifyDevicePosition](../../../location/latest/APIReference/API_VerifyDevicePosition.md "../../../location/latest/APIReference/API_VerifyDevicePosition.md")                               | Verify a device position                                                                                | Read         |
