# Data retrieval APIs for Amazon Mechanical Turk

Amazon Mechanical Turk provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                   | Description                                                                                                                                                                   | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [GetAccountBalance](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetAccountBalanceOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetAccountBalanceOperation.md")                                              | The GetAccountBalance operation retrieves the amount of money in your Amazon Mechanical Turk account                                                                          | Read         |
| [GetAssignment](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetAssignmentOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetAssignmentOperation.md")                                                          | The GetAssignment retrieves an assignment with an AssignmentStatus value of Submitted, Approved, or Rejected, using the assignment's ID                                       | Read         |
| [GetFileUploadURL](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetFileUploadURLOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetFileUploadURLOperation.md")                                                 | The GetFileUploadURL operation generates and returns a temporary URL                                                                                                          | Read         |
| [GetHIT](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetHITOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetHITOperation.md")                                                                               | The GetHIT operation retrieves the details of the specified HIT                                                                                                               | Read         |
| [GetQualificationScore](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetQualificationScoreOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetQualificationScoreOperation.md")                                  | The GetQualificationScore operation returns the value of a Worker's Qualification for a given Qualification type                                                              | Read         |
| [GetQualificationType](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetQualificationTypeOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_GetQualificationTypeOperation.md")                                     | The GetQualificationType operation retrieves information about a Qualification type using its ID                                                                              | Read         |
| [ListAssignmentsForHIT](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListAssignmentsForHITOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListAssignmentsForHITOperation.md")                                  | The ListAssignmentsForHIT operation retrieves completed assignments for a HIT                                                                                                 | List         |
| [ListBonusPayments](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListBonusPaymentsOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListBonusPaymentsOperation.md")                                              | The ListBonusPayments operation retrieves the amounts of bonuses you have paid to Workers for a given HIT or assignment                                                       | List         |
| [ListHITs](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListHITsOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListHITsOperation.md")                                                                         | The ListHITs operation returns all of a Requester's HITs                                                                                                                      | List         |
| [ListHITsForQualificationType](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListHITsForQualificationTypeOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListHITsForQualificationTypeOperation.md")             | The ListHITsForQualificationType operation returns the HITs that use the given QualififcationType for a QualificationRequirement                                              | List         |
| [ListQualificationRequests](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListQualificationRequestsOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListQualificationRequestsOperation.md")                      | The ListQualificationRequests operation retrieves requests for Qualifications of a particular Qualification type                                                              | List         |
| [ListQualificationTypes](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListQualificationTypesOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListQualificationTypesOperation.md")                               | The ListQualificationTypes operation searches for Qualification types using the specified search query, and returns a list of Qualification types                             | List         |
| [ListReviewPolicyResultsForHIT](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListReviewPolicyResultsForHITOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListReviewPolicyResultsForHITOperation.md")          | The ListReviewPolicyResultsForHIT operation retrieves the computed results and the actions taken in the course of executing your Review Policies during a CreateHIT operation | List         |
| [ListReviewableHITs](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListReviewableHITsOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListReviewableHITsOperation.md")                                           | The ListReviewableHITs operation returns all of a Requester's HITs that have not been approved or rejected                                                                    | List         |
| [ListWorkerBlocks](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListWorkerBlocksOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListWorkerBlocksOperation.md")                                                 | The ListWorkersBlocks operation retrieves a list of Workers who are blocked from working on your HITs                                                                         | List         |
| [ListWorkersWithQualificationType](../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListWorkersWithQualificationTypeOperation.md "../../../AWSMechTurk/latest/AWSMturkAPI/ApiReference_ListWorkersWithQualificationTypeOperation.md") | The ListWorkersWithQualificationType operation returns all of the Workers with a given Qualification type                                                                     | List         |
