

# Data retrieval APIs for AWS Mainframe Modernization Service
<a name="awsmainframemodernizationservice"></a>

AWS Mainframe Modernization Service provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="m2-GetApplication"></a>[GetApplication](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetApplication.html) | Retrieve an application | Read | 
| <a name="m2-GetApplicationVersion"></a>[GetApplicationVersion](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetApplicationVersion.html) | Retrieve an application version | Read | 
| <a name="m2-GetBatchJobExecution"></a>[GetBatchJobExecution](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetBatchJobExecution.html) | Retrieve a batch job execution | Read | 
| <a name="m2-GetDataSetDetails"></a>[GetDataSetDetails](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetDataSetDetails.html) | Retrieve data set details | Read | 
| <a name="m2-GetDataSetExportTask"></a>[GetDataSetExportTask](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetDataSetExportTask.html) | Export a data set at the specified S3 location | Read | 
| <a name="m2-GetDataSetImportTask"></a>[GetDataSetImportTask](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetDataSetImportTask.html) | Retrieve a data set import task | Read | 
| <a name="m2-GetDeployment"></a>[GetDeployment](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetDeployment.html) | Retrieve a deployment | Read | 
| <a name="m2-GetEnvironment"></a>[GetEnvironment](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetEnvironment.html) | Retrieve a runtime environment | Read | 
| <a name="m2-GetSignedBluinsightsUrl"></a>[GetSignedBluinsightsUrl](https://docs.aws.amazon.com/m2/latest/APIReference/API_GetSignedBluinsightsUrl.html) | Create a signed Bluinsights url | Read | 
| <a name="m2-ListApplicationVersions"></a>[ListApplicationVersions](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListApplicationVersions.html) | List the versions of an application | Read | 
| <a name="m2-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListApplications.html) | List applications | List | 
| <a name="m2-ListBatchJobDefinitions"></a>[ListBatchJobDefinitions](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListBatchJobDefinitions.html) | List batch job definitions | Read | 
| <a name="m2-ListBatchJobExecutions"></a>[ListBatchJobExecutions](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListBatchJobExecutions.html) | List executions for a batch job | Read | 
| <a name="m2-ListBatchJobRestartPoints"></a>[ListBatchJobRestartPoints](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListBatchJobRestartPoints.html) | Retrieve a batch job execution | Read | 
| <a name="m2-ListDataSetExportHistory"></a>[ListDataSetExportHistory](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListDataSetExportHistory.html) | List data set export history | Read | 
| <a name="m2-ListDataSetImportHistory"></a>[ListDataSetImportHistory](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListDataSetImportHistory.html) | List data set import history | Read | 
| <a name="m2-ListDataSets"></a>[ListDataSets](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListDataSets.html) | List data sets | Read | 
| <a name="m2-ListDeployments"></a>[ListDeployments](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListDeployments.html) | List deployments | Read | 
| <a name="m2-ListEngineVersions"></a>[ListEngineVersions](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListEngineVersions.html) | List engine versions | Read | 
| <a name="m2-ListEnvironments"></a>[ListEnvironments](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListEnvironments.html) | List runtime environments | List | 
| <a name="m2-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/m2/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
