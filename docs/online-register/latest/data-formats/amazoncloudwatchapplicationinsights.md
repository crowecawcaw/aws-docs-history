# Data retrieval APIs for Amazon CloudWatch Application Insights

Amazon CloudWatch Application Insights provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                                   | Description                                                  | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------ |
| [DescribeApplication](../../../cloudwatch/latest/APIReference/API_DescribeApplication.md "../../../cloudwatch/latest/APIReference/API_DescribeApplication.md")                                                                            | Describe an application                                      | Read         |
| [DescribeComponent](../../../cloudwatch/latest/APIReference/API_DescribeComponent.md "../../../cloudwatch/latest/APIReference/API_DescribeComponent.md")                                                                                  | Describe a component                                         | Read         |
| [DescribeComponentConfiguration](../../../cloudwatch/latest/APIReference/API_DescribeComponentConfiguration.md "../../../cloudwatch/latest/APIReference/API_DescribeComponentConfiguration.md")                                           | Describe a component's configuration                         | Read         |
| [DescribeComponentConfigurationRecommendation](../../../cloudwatch/latest/APIReference/API_DescribeComponentConfigurationRecommendation.md "../../../cloudwatch/latest/APIReference/API_DescribeComponentConfigurationRecommendation.md") | Describe the recommended application component configuration | Read         |
| [DescribeLogPattern](../../../cloudwatch/latest/APIReference/API_DescribeLogPattern.md "../../../cloudwatch/latest/APIReference/API_DescribeLogPattern.md")                                                                               | Describe a log pattern                                       | Read         |
| [DescribeObservation](../../../cloudwatch/latest/APIReference/API_DescribeObservation.md "../../../cloudwatch/latest/APIReference/API_DescribeObservation.md")                                                                            | Describe an observation                                      | Read         |
| [DescribeProblem](../../../cloudwatch/latest/APIReference/API_DescribeProblem.md "../../../cloudwatch/latest/APIReference/API_DescribeProblem.md")                                                                                        | Describe a problem                                           | Read         |
| [DescribeProblemObservations](../../../cloudwatch/latest/APIReference/API_DescribeProblemObservations.md "../../../cloudwatch/latest/APIReference/API_DescribeProblemObservations.md")                                                    | Describe the observation in a problem                        | Read         |
| [DescribeWorkload](../../../cloudwatch/latest/APIReference/API_DescribeWorkload.md "../../../cloudwatch/latest/APIReference/API_DescribeWorkload.md")                                                                                     | Describe a workload                                          | Read         |
| [ListApplications](../../../cloudwatch/latest/APIReference/API_ListApplications.md "../../../cloudwatch/latest/APIReference/API_ListApplications.md")                                                                                     | List all applications                                        | List         |
| [ListComponents](../../../cloudwatch/latest/APIReference/API_ListComponents.md "../../../cloudwatch/latest/APIReference/API_ListComponents.md")                                                                                           | List an application's components                             | List         |
| [ListConfigurationHistory](../../../cloudwatch/latest/APIReference/API_ListConfigurationHistory.md "../../../cloudwatch/latest/APIReference/API_ListConfigurationHistory.md")                                                             | List configuration history                                   | List         |
| [ListLogPatternSets](../../../cloudwatch/latest/APIReference/API_ListLogPatternSets.md "../../../cloudwatch/latest/APIReference/API_ListLogPatternSets.md")                                                                               | List log pattern sets for an application                     | List         |
| [ListLogPatterns](../../../cloudwatch/latest/APIReference/API_ListLogPatterns.md "../../../cloudwatch/latest/APIReference/API_ListLogPatterns.md")                                                                                        | List log patterns                                            | List         |
| [ListProblems](../../../cloudwatch/latest/APIReference/API_ListProblems.md "../../../cloudwatch/latest/APIReference/API_ListProblems.md")                                                                                                 | List the problems in an application                          | List         |
| [ListTagsForResource](../../../cloudwatch/latest/APIReference/API_ListTagsForResource.md "../../../cloudwatch/latest/APIReference/API_ListTagsForResource.md")                                                                            | List tags for the resource                                   | Read         |
| [ListWorkloads](../../../cloudwatch/latest/APIReference/API_ListWorkloads.md "../../../cloudwatch/latest/APIReference/API_ListWorkloads.md")                                                                                              | List workloads                                               | List         |
