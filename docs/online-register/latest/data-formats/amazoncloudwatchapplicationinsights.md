

# Data retrieval APIs for Amazon CloudWatch Application Insights
<a name="amazoncloudwatchapplicationinsights"></a>

Amazon CloudWatch Application Insights provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="applicationinsights-DescribeApplication"></a>[DescribeApplication](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeApplication.html) | Describe an application | Read | 
| <a name="applicationinsights-DescribeComponent"></a>[DescribeComponent](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeComponent.html) | Describe a component | Read | 
| <a name="applicationinsights-DescribeComponentConfiguration"></a>[DescribeComponentConfiguration](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeComponentConfiguration.html) | Describe a component's configuration | Read | 
| <a name="applicationinsights-DescribeComponentConfigurationRecommendation"></a>[DescribeComponentConfigurationRecommendation](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeComponentConfigurationRecommendation.html) | Describe the recommended application component configuration | Read | 
| <a name="applicationinsights-DescribeLogPattern"></a>[DescribeLogPattern](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeLogPattern.html) | Describe a log pattern | Read | 
| <a name="applicationinsights-DescribeObservation"></a>[DescribeObservation](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeObservation.html) | Describe an observation | Read | 
| <a name="applicationinsights-DescribeProblem"></a>[DescribeProblem](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeProblem.html) | Describe a problem | Read | 
| <a name="applicationinsights-DescribeProblemObservations"></a>[DescribeProblemObservations](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeProblemObservations.html) | Describe the observation in a problem | Read | 
| <a name="applicationinsights-DescribeWorkload"></a>[DescribeWorkload](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_DescribeWorkload.html) | Describe a workload | Read | 
| <a name="applicationinsights-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListApplications.html) | List all applications | List | 
| <a name="applicationinsights-ListComponents"></a>[ListComponents](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListComponents.html) | List an application's components | List | 
| <a name="applicationinsights-ListConfigurationHistory"></a>[ListConfigurationHistory](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListConfigurationHistory.html) | List configuration history | List | 
| <a name="applicationinsights-ListLogPatternSets"></a>[ListLogPatternSets](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListLogPatternSets.html) | List log pattern sets for an application | List | 
| <a name="applicationinsights-ListLogPatterns"></a>[ListLogPatterns](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListLogPatterns.html) | List log patterns | List | 
| <a name="applicationinsights-ListProblems"></a>[ListProblems](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListProblems.html) | List the problems in an application | List | 
| <a name="applicationinsights-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListTagsForResource.html) | List tags for the resource | Read | 
| <a name="applicationinsights-ListWorkloads"></a>[ListWorkloads](https://docs.aws.amazon.com/cloudwatch/latest/APIReference/API_ListWorkloads.html) | List workloads | List |
