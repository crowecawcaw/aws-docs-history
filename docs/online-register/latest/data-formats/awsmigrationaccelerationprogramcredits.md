

# Data retrieval APIs for AWS Migration Acceleration Program Credits
<a name="awsmigrationaccelerationprogramcredits"></a>

AWS Migration Acceleration Program Credits provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mapcredits-ListAssociatedPrograms"></a>[ListAssociatedPrograms](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View the user's associated Migration Acceleration Program agreements | List | 
| <a name="mapcredits-ListQuarterCredits"></a>[ListQuarterCredits](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View Migration Acceleration Program agreements credits associated with the user's payer account | List | 
| <a name="mapcredits-ListQuarterSpend"></a>[ListQuarterSpend](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View Migration Acceleration Program agreements eligible spend associated with the user's payer account | List |
