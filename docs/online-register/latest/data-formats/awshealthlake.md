| Actions                                                                                                                                                                                  | Description                                                                                                                                                                                    | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |

| [DescribeFHIRDatastore](../../../healthlake/latest/APIReference/API_DescribeFHIRDatastore.md "../../../healthlake/latest/APIReference/API_DescribeFHIRDatastore.md")                     | Get the properties associated with the FHIR datastore, including the datastore ID, datastore ARN, datastore name, datastore status, created at, datastore type version, and datastore endpoint | Read         |
| [DescribeFHIRExportJob](../../../healthlake/latest/APIReference/API_DescribeFHIRExportJob.md "../../../healthlake/latest/APIReference/API_DescribeFHIRExportJob.md")                     | Display the properties of a FHIR export job, including the ID, ARN, name, and the status of the datastore                                                                                      | Read         |
| [DescribeFHIRExportJobWithGet](../../../healthlake/latest/devguide/export-datastore-rest.md "../../../healthlake/latest/devguide/export-datastore-rest.md")                              | Display the properties of a FHIR export job, including the ID, ARN, name, and the status of the datastore with Get                                                                             | Read         |
| [DescribeFHIRImportJob](../../../healthlake/latest/APIReference/API_DescribeFHIRImportJob.md "../../../healthlake/latest/APIReference/API_DescribeFHIRImportJob.md")                     | Display the properties of a FHIR import job, including the ID, ARN, name, and the status of the datastore                                                                                      | Read         |
| [ExpandValueSetWithGet](../../../healthlake/latest/devguide/reference-fhir-operations-expand.md "../../../healthlake/latest/devguide/reference-fhir-operations-expand.md")               | Search and expand ValueSet resource                                                                                                                                                            | Read         |
| [ExpandValueSetWithPost](../../../healthlake/latest/devguide/reference-fhir-operations-expand.md "../../../healthlake/latest/devguide/reference-fhir-operations-expand.md")              | Search and expand ValueSet resource                                                                                                                                                            | Read         |
| [GetCapabilities](../../../healthlake/latest/devguide/crud-healthlake.md "../../../healthlake/latest/devguide/crud-healthlake.md")                                                       | Get the capabilities of a FHIR datastore                                                                                                                                                       | Read         |
| [GetExportedFile](../../../healthlake/latest/devguide/export-datastore-rest.md "../../../healthlake/latest/devguide/export-datastore-rest.md")                                           | Access exported files from a FHIR Export job initiated with Get                                                                                                                                | Read         |
| [GetHistoryByResourceId](../../../healthlake/latest/devguide/crud-healthlake.md "../../../healthlake/latest/devguide/crud-healthlake.md")                                                | Read resource history                                                                                                                                                                          | Read         |

| [ListFHIRExportJobs](../../../healthlake/latest/APIReference/API_ListFHIRExportJobs.md "../../../healthlake/latest/APIReference/API_ListFHIRExportJobs.md")                              | Get a list of export jobs for the specified datastore                                                                                                                                          | List         |
| [ListFHIRImportJobs](../../../healthlake/latest/APIReference/API_ListFHIRImportJobs.md "../../../healthlake/latest/APIReference/API_ListFHIRImportJobs.md")                              | Get a list of import jobs for the specified datastore                                                                                                                                          | List         |
| [ListTagsForResource](../../../healthlake/latest/APIReference/API_ListTagsForResource.md "../../../healthlake/latest/APIReference/API_ListTagsForResource.md")                           | Get a list of tags for the specified datastore                                                                                                                                                 | List         |
| [LookupCodeSystemWithGet](../../../healthlake/latest/devguide/reference-fhir-operations-lookup.md "../../../healthlake/latest/devguide/reference-fhir-operations-lookup.md")             | Retrieve Codes for a CodeSystem resource                                                                                                                                                       | Read         |

| [ReadResource](../../../healthlake/latest/devguide/crud-healthlake.md "../../../healthlake/latest/devguide/crud-healthlake.md")                                                          | Read resource                                                                                                                                                                                  | Read         |
