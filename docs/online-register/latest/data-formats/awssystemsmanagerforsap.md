# Data retrieval APIs for AWS Systems Manager for SAP

AWS Systems Manager for SAP provides the following APIs for data retrieval.

| Actions                                                                                                    | Description                                                                                                                    | Access level |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------ |
| [GetApplication](../../../systems-manager/index.md "../../../systems-manager/index.md")                    | Access information about an application registered with SSM for SAP by providing the application ID or application ARN         | Read         |
| [GetComponent](../../../systems-manager/index.md "../../../systems-manager/index.md")                      | Access information about a component registered with SSM for SAP by providing the application ID and component ID              | Read         |
| [GetConfigurationCheckOperation](../../../systems-manager/index.md "../../../systems-manager/index.md")    | Get the details of a configuration check operation by specifying the operation ID                                              | Read         |
| [GetDatabase](../../../systems-manager/index.md "../../../systems-manager/index.md")                       | Access information about a database registered with SSM for SAP by providing the application ID, component ID, and database ID | Read         |
| [GetOperation](../../../systems-manager/index.md "../../../systems-manager/index.md")                      | Access information about an operation by providing its operation ID                                                            | Read         |
| [ListApplications](../../../systems-manager/index.md "../../../systems-manager/index.md")                  | Retrieve a list of all applications registered with SSM for SAP under the customer AWS account                                 | List         |
| [ListComponents](../../../systems-manager/index.md "../../../systems-manager/index.md")                    | Retrieve a list of all components in the account of customer, or a specific application                                        | List         |
| [ListConfigurationCheckDefinitions](../../../systems-manager/index.md "../../../systems-manager/index.md") | List all configuration check types supported by AWS Systems Manager for SAP                                                    | List         |
| [ListConfigurationCheckOperations](../../../systems-manager/index.md "../../../systems-manager/index.md")  | List past configuration check operations                                                                                       | List         |
| [ListDatabases](../../../systems-manager/index.md "../../../systems-manager/index.md")                     | Retrieve a list of all databases in the account of customer, or a specific application                                         | List         |
| [ListOperationEvents](../../../systems-manager/index.md "../../../systems-manager/index.md")               | Retrieve a list of all operation events in a specified operation                                                               | List         |
| [ListOperations](../../../systems-manager/index.md "../../../systems-manager/index.md")                    | Retrieve a list of all operations in the account of customer, additional filters can be applied                                | List         |
| [ListSubCheckResults](../../../systems-manager/index.md "../../../systems-manager/index.md")               | List the sub-check results of a specified configuration check operation                                                        | List         |
| [ListSubCheckRuleResults](../../../systems-manager/index.md "../../../systems-manager/index.md")           | List the rules of a specified sub-check belonging to a configuration check operation                                           | List         |
| [ListTagsForResource](../../../systems-manager/index.md "../../../systems-manager/index.md")               | List the tags on a specified resource ARN                                                                                      | Read         |
