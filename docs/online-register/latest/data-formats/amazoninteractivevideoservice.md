| [GetChannel](../../../ivs/latest/LowLatencyAPIReference/API_GetChannel.md "../../../ivs/latest/LowLatencyAPIReference/API_GetChannel.md")                                                                | Get the channel configuration for a specified channel ARN                       | Read         |
| [GetComposition](../../../ivs/latest/RealTimeAPIReference/API_GetComposition.md "../../../ivs/latest/RealTimeAPIReference/API_GetComposition.md")                                                        | Get the composition for the specified ARN                                       | Read         |
| [GetEncoderConfiguration](../../../ivs/latest/RealTimeAPIReference/API_GetEncoderConfiguration.md "../../../ivs/latest/RealTimeAPIReference/API_GetEncoderConfiguration.md")                             | Get the encoder configuration for the specified ARN                             | Read         |
| [GetIngestConfiguration](../../../ivs/latest/RealTimeAPIReference/API_GetIngestConfiguration.md "../../../ivs/latest/RealTimeAPIReference/API_GetIngestConfiguration.md")                                | Get the ingest configuration for the specified ARN                              | Read         |
