

# Data retrieval APIs for AWS Compute Optimizer
<a name="awscomputeoptimizer"></a>

AWS Compute Optimizer provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="compute-optimizer-DescribeRecommendationExportJobs"></a>[DescribeRecommendationExportJobs](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_DescribeRecommendationExportJobs.html) | View the status of recommendation export jobs | List | 
| <a name="compute-optimizer-GetAutoScalingGroupRecommendations"></a>[GetAutoScalingGroupRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetAutoScalingGroupRecommendations.html) | Get recommendations for the provided AutoScaling groups | List | 
| <a name="compute-optimizer-GetEBSVolumeRecommendations"></a>[GetEBSVolumeRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEBSVolumeRecommendations.html) | Get recommendations for the provided EBS volumes | List | 
| <a name="compute-optimizer-GetEC2InstanceRecommendations"></a>[GetEC2InstanceRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEC2InstanceRecommendations.html) | Get recommendations for the provided EC2 instances | List | 
| <a name="compute-optimizer-GetEC2RecommendationProjectedMetrics"></a>[GetEC2RecommendationProjectedMetrics](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEC2RecommendationProjectedMetrics.html) | Get the recommendation projected metrics of the specified instance | List | 
| <a name="compute-optimizer-GetECSServiceRecommendationProjectedMetrics"></a>[GetECSServiceRecommendationProjectedMetrics](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetECSServiceRecommendationProjectedMetrics.html) | Get the recommendation projected metrics of the specified ECS service | List | 
| <a name="compute-optimizer-GetECSServiceRecommendations"></a>[GetECSServiceRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetECSServiceRecommendations.html) | Get recommendations for the provided ECS services | List | 
| <a name="compute-optimizer-GetEffectiveRecommendationPreferences"></a>[GetEffectiveRecommendationPreferences](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEffectiveRecommendationPreferences.html) | Get recommendation preferences that are in effect | Read | 
| <a name="compute-optimizer-GetEnrollmentStatus"></a>[GetEnrollmentStatus](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEnrollmentStatus.html) | Get the enrollment status for the specified account | List | 
| <a name="compute-optimizer-GetEnrollmentStatusesForOrganization"></a>[GetEnrollmentStatusesForOrganization](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetEnrollmentStatusesForOrganization.html) | Get the enrollment statuses for member accounts of the organization | List | 
| <a name="compute-optimizer-GetIdleRecommendations"></a>[GetIdleRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetIdleRecommendations.html) | Get idle recommendations for the specified account(s) | List | 
| <a name="compute-optimizer-GetLambdaFunctionRecommendations"></a>[GetLambdaFunctionRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetLambdaFunctionRecommendations.html) | Get recommendations for the provided Lambda functions | List | 
| <a name="compute-optimizer-GetLicenseRecommendations"></a>[GetLicenseRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetLicenseRecommendations.html) | Get license recommendations for the specified account(s) | List | 
| <a name="compute-optimizer-GetRDSDatabaseRecommendationProjectedMetrics"></a>[GetRDSDatabaseRecommendationProjectedMetrics](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetRDSDatabaseRecommendationProjectedMetrics.html) | Get the recommendation projected metrics of the specified instance | List | 
| <a name="compute-optimizer-GetRDSDatabaseRecommendations"></a>[GetRDSDatabaseRecommendations](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetRDSDatabaseRecommendations.html) | Get rds recommendations for the specified account(s) | List | 
| <a name="compute-optimizer-GetRecommendationPreferences"></a>[GetRecommendationPreferences](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetRecommendationPreferences.html) | Get recommendation preferences | Read | 
| <a name="compute-optimizer-GetRecommendationSummaries"></a>[GetRecommendationSummaries](https://docs.aws.amazon.com/compute-optimizer/latest/APIReference/API_GetRecommendationSummaries.html) | Get the recommendation summaries for the specified account(s) | List |
