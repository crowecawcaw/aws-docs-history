# Data retrieval APIs for AWS Mainframe Modernization Application Testing

AWS Mainframe Modernization Application Testing provides the following APIs for data retrieval.

| Actions                                                                                                                                                           | Description                    | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ | ------------ |
| [GetTestCase](../../../apptest/latest/APIReference/API_GetTestCase.md "../../../apptest/latest/APIReference/API_GetTestCase.md")                                  | Get a test case                | Read         |
| [GetTestConfiguration](../../../apptest/latest/APIReference/API_GetTestConfiguration.md "../../../apptest/latest/APIReference/API_GetTestConfiguration.md")       | Get a test configuration       | Read         |
| [GetTestRunStep](../../../apptest/latest/APIReference/API_GetTestRunStep.md "../../../apptest/latest/APIReference/API_GetTestRunStep.md")                         | Get test run step              | Read         |
| [GetTestSuite](../../../apptest/latest/APIReference/API_GetTestSuite.md "../../../apptest/latest/APIReference/API_GetTestSuite.md")                               | Get a test suite               | Read         |
| [ListTagsForResource](../../../apptest/latest/APIReference/API_ListTagsForResource.md "../../../apptest/latest/APIReference/API_ListTagsForResource.md")          | List tags for a resource       | Read         |
| [ListTestCases](../../../apptest/latest/APIReference/API_ListTestCases.md "../../../apptest/latest/APIReference/API_ListTestCases.md")                            | List test cases                | List         |
| [ListTestConfigurations](../../../apptest/latest/APIReference/API_ListTestConfigurations.md "../../../apptest/latest/APIReference/API_ListTestConfigurations.md") | List test configurations       | List         |
| [ListTestRunSteps](../../../apptest/latest/APIReference/API_ListTestRunSteps.md "../../../apptest/latest/APIReference/API_ListTestRunSteps.md")                   | List steps for a test run      | Read         |
| [ListTestRunTestCases](../../../apptest/latest/APIReference/API_ListTestRunTestCases.md "../../../apptest/latest/APIReference/API_ListTestRunTestCases.md")       | List test cases for a test run | Read         |
| [ListTestRuns](../../../apptest/latest/APIReference/API_ListTestRuns.md "../../../apptest/latest/APIReference/API_ListTestRuns.md")                               | List test runs                 | List         |
| [ListTestSuites](../../../apptest/latest/APIReference/API_ListTestSuites.md "../../../apptest/latest/APIReference/API_ListTestSuites.md")                         | List test suites               | List         |
