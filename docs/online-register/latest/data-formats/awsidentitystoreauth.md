# Data retrieval APIs for AWS Identity Store Auth

AWS Identity Store Auth provides the following APIs for data retrieval.

| Actions                                                                                                                                        | Description                                                 | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | ------------ |
| [BatchGetSession](../../../singlesignon/latest/userguide/manage-app-session.md "../../../singlesignon/latest/userguide/manage-app-session.md") | Return session attributes for a batch of specified sessions | Read         |
| [ListSessions](../../../singlesignon/latest/userguide/manage-app-session.md "../../../singlesignon/latest/userguide/manage-app-session.md")    | Retrieve a list of active sessions for the specified user   | List         |
