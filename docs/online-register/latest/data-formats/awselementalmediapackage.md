

# Data retrieval APIs for AWS Elemental MediaPackage
<a name="awselementalmediapackage"></a>

AWS Elemental MediaPackage provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="mediapackage-DescribeChannel"></a>[DescribeChannel](https://docs.aws.amazon.com/mediapackage/latest/apireference/channels-id.html#channels-idget) | View the details of a channel in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-DescribeHarvestJob"></a>[DescribeHarvestJob](https://docs.aws.amazon.com/mediapackage/latest/apireference/harvest_jobs-id.html#harvest_jobs-idget) | View the details of a harvest job in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-DescribeOriginEndpoint"></a>[DescribeOriginEndpoint](https://docs.aws.amazon.com/mediapackage/latest/apireference/origin_endpoints-id.html#origin_endpoints-idget) | View the details of an endpoint in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-ListChannels"></a>[ListChannels](https://docs.aws.amazon.com/mediapackage/latest/apireference/channels.html#channelsget) | View a list of channels in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-ListHarvestJobs"></a>[ListHarvestJobs](https://docs.aws.amazon.com/mediapackage/latest/apireference/harvest_jobs.html#harvest_jobsget) | View a list of harvest jobs in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-ListOriginEndpoints"></a>[ListOriginEndpoints](https://docs.aws.amazon.com/mediapackage/latest/apireference/origin_endpoints.html#origin_endpointsget) | View a list of endpoints in AWS Elemental MediaPackage | Read | 
| <a name="mediapackage-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/mediapackage/latest/apireference/tags-resource-arn.html#tags-resource-arnget) | List the tags assigned to a Channel or OriginEndpoint | Read |
