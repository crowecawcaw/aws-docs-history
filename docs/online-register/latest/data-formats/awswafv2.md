# Data retrieval APIs for AWS WAF V2

AWS WAF V2 provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                | Description                                                                                                  | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------------ |
| [CheckCapacity](../../../waf/latest/APIReference/API_CheckCapacity.md "../../../waf/latest/APIReference/API_CheckCapacity.md")                                                                         | Calculate web ACL capacity unit (WCU) requirements for a specified scope and set of rules                    | Read         |
| [DescribeAllManagedProducts](../../../waf/latest/APIReference/API_DescribeAllManagedProducts.md "../../../waf/latest/APIReference/API_DescribeAllManagedProducts.md")                                  | Retrieve product information for a managed rule group                                                        | Read         |
| [DescribeManagedProductsByVendor](../../../waf/latest/APIReference/API_DescribeManagedProductsByVendor.md "../../../waf/latest/APIReference/API_DescribeManagedProductsByVendor.md")                   | Retrieve product information for a managed rule group by a given vendor                                      | Read         |
| [DescribeManagedRuleGroup](../../../waf/latest/APIReference/API_DescribeManagedRuleGroup.md "../../../waf/latest/APIReference/API_DescribeManagedRuleGroup.md")                                        | Retrieve high-level information for a managed rule group                                                     | Read         |
| [GenerateMobileSdkReleaseUrl](../../../waf/latest/APIReference/API_GenerateMobileSdkReleaseUrl.md "../../../waf/latest/APIReference/API_GenerateMobileSdkReleaseUrl.md")                               | Generate a presigned download URL for the specified release of the mobile SDK                                | Read         |
| [GetDecryptedAPIKey](../../../waf/latest/APIReference/API_GetDecryptedAPIKey.md "../../../waf/latest/APIReference/API_GetDecryptedAPIKey.md")                                                          | Return your API key in decrypted form. Use this to check the token domains that you have defined for the key | Read         |
| [GetIPSet](../../../waf/latest/APIReference/API_GetIPSet.md "../../../waf/latest/APIReference/API_GetIPSet.md")                                                                                        | Retrieve details about an IPSet                                                                              | Read         |
| [GetLoggingConfiguration](../../../waf/latest/APIReference/API_GetLoggingConfiguration.md "../../../waf/latest/APIReference/API_GetLoggingConfiguration.md")                                           | Retrieve LoggingConfiguration for a WebACL                                                                   | Read         |
| [GetManagedRuleSet](../../../waf/latest/APIReference/API_GetManagedRuleSet.md "../../../waf/latest/APIReference/API_GetManagedRuleSet.md")                                                             | Retrieve details about a ManagedRuleSet                                                                      | Read         |
| [GetMobileSdkRelease](../../../waf/latest/APIReference/API_GetMobileSdkRelease.md "../../../waf/latest/APIReference/API_GetMobileSdkRelease.md")                                                       | Retrieve information for the specified mobile SDK release, including release notes and tags                  | Read         |
| [GetPermissionPolicy](../../../waf/latest/APIReference/API_GetPermissionPolicy.md "../../../waf/latest/APIReference/API_GetPermissionPolicy.md")                                                       | Retrieve a PermissionPolicy for a RuleGroup                                                                  | Read         |
| [GetRateBasedStatementManagedKeys](../../../waf/latest/APIReference/API_GetRateBasedStatementManagedKeys.md "../../../waf/latest/APIReference/API_GetRateBasedStatementManagedKeys.md")                | Retrieve the keys that are currently blocked by a rate-based rule                                            | Read         |
| [GetRegexPatternSet](../../../waf/latest/APIReference/API_GetRegexPatternSet.md "../../../waf/latest/APIReference/API_GetRegexPatternSet.md")                                                          | Retrieve details about a RegexPatternSet                                                                     | Read         |
| [GetRuleGroup](../../../waf/latest/APIReference/API_GetRuleGroup.md "../../../waf/latest/APIReference/API_GetRuleGroup.md")                                                                            | Retrieve details about a RuleGroup                                                                           | Read         |
| [GetSampledRequests](../../../waf/latest/APIReference/API_GetSampledRequests.md "../../../waf/latest/APIReference/API_GetSampledRequests.md")                                                          | Retrieve detailed information about a sampling of web requests                                               | Read         |
| [GetWebACL](../../../waf/latest/APIReference/API_GetWebACL.md "../../../waf/latest/APIReference/API_GetWebACL.md")                                                                                     | Retrieve details about a WebACL                                                                              | Read         |
| [GetWebACLForResource](../../../waf/latest/APIReference/API_GetWebACLForResource.md "../../../waf/latest/APIReference/API_GetWebACLForResource.md")                                                    | Retrieve the WebACL that's associated with a resource                                                        | Read         |
| [ListAPIKeys](../../../waf/latest/APIReference/API_ListAPIKeys.md "../../../waf/latest/APIReference/API_ListAPIKeys.md")                                                                               | Retrieve a list of the API keys that you've defined for the specified scope                                  | List         |
| [ListAvailableManagedRuleGroupVersions](../../../waf/latest/APIReference/API_ListAvailableManagedRuleGroupVersions.md "../../../waf/latest/APIReference/API_ListAvailableManagedRuleGroupVersions.md") | Retrieve an array of managed rule group versions that are available for you to use                           | List         |
| [ListAvailableManagedRuleGroups](../../../waf/latest/APIReference/API_ListAvailableManagedRuleGroups.md "../../../waf/latest/APIReference/API_ListAvailableManagedRuleGroups.md")                      | Retrieve an array of managed rule groups that are available for you to use                                   | List         |
| [ListIPSets](../../../waf/latest/APIReference/API_ListIPSets.md "../../../waf/latest/APIReference/API_ListIPSets.md")                                                                                  | Retrieve an array of IPSetSummary objects for the IP sets that you manage                                    | List         |
| [ListLoggingConfigurations](../../../waf/latest/APIReference/API_ListLoggingConfigurations.md "../../../waf/latest/APIReference/API_ListLoggingConfigurations.md")                                     | Retrieve an array of your LoggingConfiguration objects                                                       | List         |
| [ListManagedRuleSets](../../../waf/latest/APIReference/API_ListManagedRuleSets.md "../../../waf/latest/APIReference/API_ListManagedRuleSets.md")                                                       | Retrieve an array of your ManagedRuleSet objects                                                             | List         |
| [ListMobileSdkReleases](../../../waf/latest/APIReference/API_ListMobileSdkReleases.md "../../../waf/latest/APIReference/API_ListMobileSdkReleases.md")                                                 | Retrieve a list of the available releases for the mobile SDK and the specified device platform               | List         |
| [ListRegexPatternSets](../../../waf/latest/APIReference/API_ListRegexPatternSets.md "../../../waf/latest/APIReference/API_ListRegexPatternSets.md")                                                    | Retrieve an array of RegexPatternSetSummary objects for the regex pattern sets that you manage               | List         |
| [ListResourcesForWebACL](../../../waf/latest/APIReference/API_ListResourcesForWebACL.md "../../../waf/latest/APIReference/API_ListResourcesForWebACL.md")                                              | Retrieve an array of the Amazon Resource Names (ARNs) for the resources that are associated with a web ACL   | List         |
| [ListRuleGroups](../../../waf/latest/APIReference/API_ListRuleGroups.md "../../../waf/latest/APIReference/API_ListRuleGroups.md")                                                                      | Retrieve an array of RuleGroupSummary objects for the rule groups that you manage                            | List         |
| [ListTagsForResource](../../../waf/latest/APIReference/API_ListTagsForResource.md "../../../waf/latest/APIReference/API_ListTagsForResource.md")                                                       | List tags for a resource                                                                                     | Read         |
| [ListWebACLs](../../../waf/latest/APIReference/API_ListWebACLs.md "../../../waf/latest/APIReference/API_ListWebACLs.md")                                                                               | Retrieve an array of WebACLSummary objects for the web ACLs that you manage                                  | List         |
