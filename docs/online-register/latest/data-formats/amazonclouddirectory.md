# Data retrieval APIs for Amazon Cloud Directory

Amazon Cloud Directory provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                               | Description                                                                                                                                                            | Access level |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [BatchRead](../../../directoryservice/latest/APIReference/API_BatchRead.md "../../../directoryservice/latest/APIReference/API_BatchRead.md")                                                          | Perform all the read operations in a batch. Each individual operation inside BatchRead needs to be granted permissions explicitly                                      | Read         |
| [GetAppliedSchemaVersion](../../../directoryservice/latest/APIReference/API_GetAppliedSchemaVersion.md "../../../directoryservice/latest/APIReference/API_GetAppliedSchemaVersion.md")                | Return current applied schema version ARN, including the minor version in use                                                                                          | Read         |
| [GetDirectory](../../../directoryservice/latest/APIReference/API_GetDirectory.md "../../../directoryservice/latest/APIReference/API_GetDirectory.md")                                                 | Retrieve metadata about a directory                                                                                                                                    | Read         |
| [GetFacet](../../../directoryservice/latest/APIReference/API_GetFacet.md "../../../directoryservice/latest/APIReference/API_GetFacet.md")                                                             | Get details of the Facet, such as Facet Name, Attributes, Rules, or ObjectType                                                                                         | Read         |
| [GetLinkAttributes](../../../directoryservice/latest/APIReference/API_GetLinkAttributes.md "../../../directoryservice/latest/APIReference/API_GetLinkAttributes.md")                                  | Retrieve attributes that are associated with a typed link                                                                                                              | Read         |
| [GetObjectAttributes](../../../directoryservice/latest/APIReference/API_GetObjectAttributes.md "../../../directoryservice/latest/APIReference/API_GetObjectAttributes.md")                            | Retrieve attributes within a facet that are associated with an object                                                                                                  | Read         |
| [GetObjectInformation](../../../directoryservice/latest/APIReference/API_GetObjectInformation.md "../../../directoryservice/latest/APIReference/API_GetObjectInformation.md")                         | Retrieve metadata about an object                                                                                                                                      | Read         |
| [GetSchemaAsJson](../../../directoryservice/latest/APIReference/API_GetSchemaAsJson.md "../../../directoryservice/latest/APIReference/API_GetSchemaAsJson.md")                                        | Retrieve a JSON representation of the schema                                                                                                                           | Read         |
| [GetTypedLinkFacetInformation](../../../directoryservice/latest/APIReference/API_GetTypedLinkFacetInformation.md "../../../directoryservice/latest/APIReference/API_GetTypedLinkFacetInformation.md") | Return identity attributes order information associated with a given typed link facet                                                                                  | Read         |
| [ListAppliedSchemaArns](../../../directoryservice/latest/APIReference/API_ListAppliedSchemaArns.md "../../../directoryservice/latest/APIReference/API_ListAppliedSchemaArns.md")                      | List schemas applied to a directory                                                                                                                                    | List         |
| [ListAttachedIndices](../../../directoryservice/latest/APIReference/API_ListAttachedIndices.md "../../../directoryservice/latest/APIReference/API_ListAttachedIndices.md")                            | List indices attached to an object                                                                                                                                     | Read         |
| [ListDevelopmentSchemaArns](../../../directoryservice/latest/APIReference/API_ListDevelopmentSchemaArns.md "../../../directoryservice/latest/APIReference/API_ListDevelopmentSchemaArns.md")          | Retrieve the ARNs of schemas in the development state                                                                                                                  | List         |
| [ListDirectories](../../../directoryservice/latest/APIReference/API_ListDirectories.md "../../../directoryservice/latest/APIReference/API_ListDirectories.md")                                        | List directories created within an account                                                                                                                             | List         |
| [ListFacetAttributes](../../../directoryservice/latest/APIReference/API_ListFacetAttributes.md "../../../directoryservice/latest/APIReference/API_ListFacetAttributes.md")                            | Retrieve attributes attached to the facet                                                                                                                              | Read         |
| [ListFacetNames](../../../directoryservice/latest/APIReference/API_ListFacetNames.md "../../../directoryservice/latest/APIReference/API_ListFacetNames.md")                                           | Retrieve the names of facets that exist in a schema                                                                                                                    | Read         |
| [ListIncomingTypedLinks](../../../directoryservice/latest/APIReference/API_ListIncomingTypedLinks.md "../../../directoryservice/latest/APIReference/API_ListIncomingTypedLinks.md")                   | Return a paginated list of all incoming TypedLinks for a given object                                                                                                  | Read         |
| [ListIndex](../../../directoryservice/latest/APIReference/API_ListIndex.md "../../../directoryservice/latest/APIReference/API_ListIndex.md")                                                          | List objects attached to the specified index                                                                                                                           | Read         |
| [ListManagedSchemaArns](../../../directoryservice/latest/APIReference/API_ListManagedSchemaArns.md "../../../directoryservice/latest/APIReference/API_ListManagedSchemaArns.md")                      | List the major version families of each managed schema. If a major version ARN is provided as SchemaArn, the minor version revisions in that family are listed instead | List         |
| [ListObjectAttributes](../../../directoryservice/latest/APIReference/API_ListObjectAttributes.md "../../../directoryservice/latest/APIReference/API_ListObjectAttributes.md")                         | List all attributes associated with an object                                                                                                                          | Read         |
| [ListObjectChildren](../../../directoryservice/latest/APIReference/API_ListObjectChildren.md "../../../directoryservice/latest/APIReference/API_ListObjectChildren.md")                               | Return a paginated list of child objects associated with a given object                                                                                                | Read         |
| [ListObjectParentPaths](../../../directoryservice/latest/APIReference/API_ListObjectParentPaths.md "../../../directoryservice/latest/APIReference/API_ListObjectParentPaths.md")                      | Retrieve all available parent paths for any object type such as node, leaf node, policy node, and index node objects                                                   | Read         |
| [ListObjectParents](../../../directoryservice/latest/APIReference/API_ListObjectParents.md "../../../directoryservice/latest/APIReference/API_ListObjectParents.md")                                  | List parent objects associated with a given object in pagination fashion                                                                                               | Read         |
| [ListObjectPolicies](../../../directoryservice/latest/APIReference/API_ListObjectPolicies.md "../../../directoryservice/latest/APIReference/API_ListObjectPolicies.md")                               | Return policies attached to an object in pagination fashion                                                                                                            | Read         |
| [ListOutgoingTypedLinks](../../../directoryservice/latest/APIReference/API_ListOutgoingTypedLinks.md "../../../directoryservice/latest/APIReference/API_ListOutgoingTypedLinks.md")                   | Return a paginated list of all outgoing TypedLinks for a given object                                                                                                  | Read         |
| [ListPolicyAttachments](../../../directoryservice/latest/APIReference/API_ListPolicyAttachments.md "../../../directoryservice/latest/APIReference/API_ListPolicyAttachments.md")                      | Return all of the ObjectIdentifiers to which a given policy is attached                                                                                                | Read         |
| [ListPublishedSchemaArns](../../../directoryservice/latest/APIReference/API_ListPublishedSchemaArns.md "../../../directoryservice/latest/APIReference/API_ListPublishedSchemaArns.md")                | Retrieve published schema ARNs                                                                                                                                         | List         |
| [ListTagsForResource](../../../directoryservice/latest/APIReference/API_ListTagsForResource.md "../../../directoryservice/latest/APIReference/API_ListTagsForResource.md")                            | Return tags for a resource                                                                                                                                             | Read         |
| [ListTypedLinkFacetAttributes](../../../directoryservice/latest/APIReference/API_ListTypedLinkFacetAttributes.md "../../../directoryservice/latest/APIReference/API_ListTypedLinkFacetAttributes.md") | Return a paginated list of attributes associated with typed link facet                                                                                                 | Read         |
| [ListTypedLinkFacetNames](../../../directoryservice/latest/APIReference/API_ListTypedLinkFacetNames.md "../../../directoryservice/latest/APIReference/API_ListTypedLinkFacetNames.md")                | Return a paginated list of typed link facet names that exist in a schema                                                                                               | Read         |
| [LookupPolicy](../../../directoryservice/latest/APIReference/API_LookupPolicy.md "../../../directoryservice/latest/APIReference/API_LookupPolicy.md")                                                 | List all policies from the root of the Directory to the object specified                                                                                               | Read         |
