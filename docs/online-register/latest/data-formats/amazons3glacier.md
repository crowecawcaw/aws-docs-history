# Data retrieval APIs for Amazon S3 Glacier

Amazon S3 Glacier provides the following APIs for data retrieval.

| Actions                                                                                                                                                        | Description                                                                         | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------ |
| [DescribeJob](../../../amazonglacier/latest/dev/api-describe-job-get.md "../../../amazonglacier/latest/dev/api-describe-job-get.md")                           | Get information about a job previously initiated                                    | Read         |
| [DescribeVault](../../../amazonglacier/latest/dev/api-vault-get.md "../../../amazonglacier/latest/dev/api-vault-get.md")                                       | Get information about a vault                                                       | Read         |
| [GetDataRetrievalPolicy](../../../amazonglacier/latest/dev/api-GetDataRetrievalPolicy.md "../../../amazonglacier/latest/dev/api-GetDataRetrievalPolicy.md")    | Get the data retrieval policy                                                       | Read         |
| [GetJobOutput](../../../amazonglacier/latest/dev/api-job-output-get.md "../../../amazonglacier/latest/dev/api-job-output-get.md")                              | Download the output of the job specified                                            | Read         |
| [GetVaultAccessPolicy](../../../amazonglacier/latest/dev/api-GetVaultAccessPolicy.md "../../../amazonglacier/latest/dev/api-GetVaultAccessPolicy.md")          | Retrieve the access-policy subresource set on the vault                             | Read         |
| [GetVaultLock](../../../amazonglacier/latest/dev/api-GetVaultLock.md "../../../amazonglacier/latest/dev/api-GetVaultLock.md")                                  | Retrieve attributes from the lock-policy subresource set on the specified vault     | Read         |
| [GetVaultNotifications](../../../amazonglacier/latest/dev/api-vault-notifications-get.md "../../../amazonglacier/latest/dev/api-vault-notifications-get.md")   | Retrieve the notification-configuration subresource set on the vault                | Read         |
| [ListJobs](../../../amazonglacier/latest/dev/api-jobs-get.md "../../../amazonglacier/latest/dev/api-jobs-get.md")                                              | List jobs for a vault that are in-progress and jobs that have recently finished     | List         |
| [ListMultipartUploads](../../../amazonglacier/latest/dev/api-multipart-list-uploads.md "../../../amazonglacier/latest/dev/api-multipart-list-uploads.md")      | List in-progress multipart uploads for the specified vault                          | List         |
| [ListParts](../../../amazonglacier/latest/dev/api-multipart-list-parts.md "../../../amazonglacier/latest/dev/api-multipart-list-parts.md")                     | List the parts of an archive that have been uploaded in a specific multipart upload | List         |
| [ListProvisionedCapacity](../../../amazonglacier/latest/dev/api-ListProvisionedCapacity.md "../../../amazonglacier/latest/dev/api-ListProvisionedCapacity.md") | List the provisioned capacity for the specified AWS account                         | List         |
| [ListTagsForVault](../../../amazonglacier/latest/dev/api-ListTagsForVault.md "../../../amazonglacier/latest/dev/api-ListTagsForVault.md")                      | List all the tags attached to a vault                                               | List         |
| [ListVaults](../../../amazonglacier/latest/dev/api-vaults-get.md "../../../amazonglacier/latest/dev/api-vaults-get.md")                                        | List all vaults                                                                     | List         |
