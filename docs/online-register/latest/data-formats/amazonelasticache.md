

# Data retrieval APIs for Amazon ElastiCache
<a name="amazonelasticache"></a>

Amazon ElastiCache provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="elasticache-DescribeCacheClusters"></a>[DescribeCacheClusters](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheClusters.html) | List information about provisioned cache clusters | List | 
| <a name="elasticache-DescribeCacheEngineVersions"></a>[DescribeCacheEngineVersions](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheEngineVersions.html) | List available cache engines and their versions | List | 
| <a name="elasticache-DescribeCacheParameterGroups"></a>[DescribeCacheParameterGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheParameterGroups.html) | List cache parameter group descriptions | List | 
| <a name="elasticache-DescribeCacheParameters"></a>[DescribeCacheParameters](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheParameters.html) | Retrieve the detailed parameter list for a particular cache parameter group | List | 
| <a name="elasticache-DescribeCacheSecurityGroups"></a>[DescribeCacheSecurityGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheSecurityGroups.html) | List cache security group descriptions | List | 
| <a name="elasticache-DescribeCacheSubnetGroups"></a>[DescribeCacheSubnetGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeCacheSubnetGroups.html) | List cache subnet group descriptions | List | 
| <a name="elasticache-DescribeEngineDefaultParameters"></a>[DescribeEngineDefaultParameters](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeEngineDefaultParameters.html) | Retrieve the default engine and system parameter information for the specified cache engine | List | 
| <a name="elasticache-DescribeEvents"></a>[DescribeEvents](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeEvents.html) | List events related to clusters, cache security groups, and cache parameter groups | List | 
| <a name="elasticache-DescribeGlobalReplicationGroups"></a>[DescribeGlobalReplicationGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeGlobalReplicationGroups.html) | List information about global replication groups | List | 
| <a name="elasticache-DescribeReplicationGroups"></a>[DescribeReplicationGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeReplicationGroups.html) | List information about provisioned replication groups | List | 
| <a name="elasticache-DescribeReservedCacheNodes"></a>[DescribeReservedCacheNodes](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeReservedCacheNodes.html) | List information about purchased reserved cache nodes | List | 
| <a name="elasticache-DescribeReservedCacheNodesOfferings"></a>[DescribeReservedCacheNodesOfferings](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeReservedCacheNodesOfferings.html) | List available reserved cache node offerings | List | 
| <a name="elasticache-DescribeServerlessCacheSnapshots"></a>[DescribeServerlessCacheSnapshots](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeServerlessCacheSnapshots.html) | List information about serverless cache snapshots | List | 
| <a name="elasticache-DescribeServerlessCaches"></a>[DescribeServerlessCaches](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeServerlessCaches.html) | List serverless caches | List | 
| <a name="elasticache-DescribeServiceUpdates"></a>[DescribeServiceUpdates](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeServiceUpdates.html) | List details of the service updates | List | 
| <a name="elasticache-DescribeSnapshots"></a>[DescribeSnapshots](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeSnapshots.html) | List information about cluster or replication group snapshots | List | 
| <a name="elasticache-DescribeUpdateActions"></a>[DescribeUpdateActions](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeUpdateActions.html) | List details of the update actions for a set of clusters or replication groups | List | 
| <a name="elasticache-DescribeUserGroups"></a>[DescribeUserGroups](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeUserGroups.html) | List information about Redis user groups | List | 
| <a name="elasticache-DescribeUsers"></a>[DescribeUsers](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_DescribeUsers.html) | List information about Redis users | List | 
| <a name="elasticache-ListAllowedNodeTypeModifications"></a>[ListAllowedNodeTypeModifications](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_ListAllowedNodeTypeModifications.html) | List available node type that can be used to scale a particular Redis cluster or replication group | List | 
| <a name="elasticache-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/AmazonElastiCache/latest/APIReference/API_ListTagsForResource.html) | List tags for an ElastiCache resource | Read |
