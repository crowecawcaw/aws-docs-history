# Data retrieval APIs for Amazon Timestream InfluxDB

Amazon Timestream InfluxDB provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                  | Description                                                                     | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------ |
| [GetDbCluster](../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbCluster.md "../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbCluster.md")                                        | Get information about a Timestream InfluxDB Cluster                             | Read         |
| [GetDbInstance](../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbInstance.md "../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbInstance.md")                                     | Get information about a Timestream InfluxDB instance                            | Read         |
| [GetDbParameterGroup](../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbParameterGroup.md "../../../ts-influxdb/latest/ts-influxdb-api/API_GetDbParameterGroup.md")                   | Get information about a Timestream InfluxDB parameter group                     | Read         |
| [ListDbClusters](../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbClusters.md "../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbClusters.md")                                  | List information about all Timestream InfluxDB clusters in the account          | List         |
| [ListDbInstances](../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbInstances.md "../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbInstances.md")                               | List information about all Timestream InfluxDB instances in the account         | List         |
| [ListDbInstancesForCluster](../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbInstancesForCluster.md "../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbInstancesForCluster.md") | List information about all Timestream InfluxDB Instances belonging to a cluster | Read         |
| [ListDbParameterGroups](../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbParameterGroups.md "../../../ts-influxdb/latest/ts-influxdb-api/API_ListDbParameterGroups.md")             | List information about all Timestream InfluxDB parameter groups                 | List         |
| [ListTagsForResource](../../../ts-influxdb/latest/ts-influxdb-api/API_ListTagsForResource.md "../../../ts-influxdb/latest/ts-influxdb-api/API_ListTagsForResource.md")                   | List tags for a Timestream InfluxDB resource                                    | Read         |
