

# Data retrieval APIs for AWS Private CA Connector for Active Directory
<a name="awsprivatecaconnectorforactivedirectory"></a>

AWS Private CA Connector for Active Directory provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="pca-connector-ad-GetConnector"></a>[GetConnector](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_GetConnector.html) | Get a Connector in your account | Read | 
| <a name="pca-connector-ad-GetDirectoryRegistration"></a>[GetDirectoryRegistration](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_GetDirectoryRegistration.html) | Get a DirectoryRegistration in your account | Read | 
| <a name="pca-connector-ad-GetServicePrincipalName"></a>[GetServicePrincipalName](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_GetServicePrincipalName.html) | Get a ServicePrincipalName for a DirectoryRegistration | Read | 
| <a name="pca-connector-ad-GetTemplate"></a>[GetTemplate](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_GetTemplate.html) | Get a Template for a Connector | Read | 
| <a name="pca-connector-ad-GetTemplateGroupAccessControlEntry"></a>[GetTemplateGroupAccessControlEntry](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_GetTemplateGroupAccessControlEntry.html) | Get a TemplateGroupAccessControlEntry for a Template | Read | 
| <a name="pca-connector-ad-ListConnectors"></a>[ListConnectors](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListConnectors.html) | List the Connectors in your account | List | 
| <a name="pca-connector-ad-ListDirectoryRegistrations"></a>[ListDirectoryRegistrations](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListDirectoryRegistrations.html) | List the DirectoryRegistrations in your account | List | 
| <a name="pca-connector-ad-ListServicePrincipalNames"></a>[ListServicePrincipalNames](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListServicePrincipalNames.html) | List the ServicePrincipalNames for a DirectoryRegistration | List | 
| <a name="pca-connector-ad-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListTagsForResource.html) | List the tags for a pca-connector-ad resource in your account | Read | 
| <a name="pca-connector-ad-ListTemplateGroupAccessControlEntries"></a>[ListTemplateGroupAccessControlEntries](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListTemplateGroupAccessControlEntries.html) | List the TemplateGroupAccessControlEntries for a Template | List | 
| <a name="pca-connector-ad-ListTemplates"></a>[ListTemplates](https://docs.aws.amazon.com/pca-connector-ad/latest/APIReference/API_ListTemplates.html) | List the Templates for a Connector | List |
