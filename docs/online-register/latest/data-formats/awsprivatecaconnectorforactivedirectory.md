# Data retrieval APIs for AWS Private CA Connector for Active Directory

AWS Private CA Connector for Active Directory provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                                                          | Description                                                   | Access level |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------ |
| [GetConnector](../../../pca-connector-ad/latest/APIReference/API_GetConnector.md "../../../pca-connector-ad/latest/APIReference/API_GetConnector.md")                                                                            | Get a Connector in your account                               | Read         |
| [GetDirectoryRegistration](../../../pca-connector-ad/latest/APIReference/API_GetDirectoryRegistration.md "../../../pca-connector-ad/latest/APIReference/API_GetDirectoryRegistration.md")                                        | Get a DirectoryRegistration in your account                   | Read         |
| [GetServicePrincipalName](../../../pca-connector-ad/latest/APIReference/API_GetServicePrincipalName.md "../../../pca-connector-ad/latest/APIReference/API_GetServicePrincipalName.md")                                           | Get a ServicePrincipalName for a DirectoryRegistration        | Read         |
| [GetTemplate](../../../pca-connector-ad/latest/APIReference/API_GetTemplate.md "../../../pca-connector-ad/latest/APIReference/API_GetTemplate.md")                                                                               | Get a Template for a Connector                                | Read         |
| [GetTemplateGroupAccessControlEntry](../../../pca-connector-ad/latest/APIReference/API_GetTemplateGroupAccessControlEntry.md "../../../pca-connector-ad/latest/APIReference/API_GetTemplateGroupAccessControlEntry.md")          | Get a TemplateGroupAccessControlEntry for a Template          | Read         |
| [ListConnectors](../../../pca-connector-ad/latest/APIReference/API_ListConnectors.md "../../../pca-connector-ad/latest/APIReference/API_ListConnectors.md")                                                                      | List the Connectors in your account                           | List         |
| [ListDirectoryRegistrations](../../../pca-connector-ad/latest/APIReference/API_ListDirectoryRegistrations.md "../../../pca-connector-ad/latest/APIReference/API_ListDirectoryRegistrations.md")                                  | List the DirectoryRegistrations in your account               | List         |
| [ListServicePrincipalNames](../../../pca-connector-ad/latest/APIReference/API_ListServicePrincipalNames.md "../../../pca-connector-ad/latest/APIReference/API_ListServicePrincipalNames.md")                                     | List the ServicePrincipalNames for a DirectoryRegistration    | List         |
| [ListTagsForResource](../../../pca-connector-ad/latest/APIReference/API_ListTagsForResource.md "../../../pca-connector-ad/latest/APIReference/API_ListTagsForResource.md")                                                       | List the tags for a pca-connector-ad resource in your account | Read         |
| [ListTemplateGroupAccessControlEntries](../../../pca-connector-ad/latest/APIReference/API_ListTemplateGroupAccessControlEntries.md "../../../pca-connector-ad/latest/APIReference/API_ListTemplateGroupAccessControlEntries.md") | List the TemplateGroupAccessControlEntries for a Template     | List         |
| [ListTemplates](../../../pca-connector-ad/latest/APIReference/API_ListTemplates.md "../../../pca-connector-ad/latest/APIReference/API_ListTemplates.md")                                                                         | List the Templates for a Connector                            | List         |
