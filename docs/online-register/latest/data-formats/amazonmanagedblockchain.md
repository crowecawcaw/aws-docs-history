

# Data retrieval APIs for Amazon Managed Blockchain
<a name="amazonmanagedblockchain"></a>

Amazon Managed Blockchain provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="managedblockchain-GetAccessor"></a>[GetAccessor](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetAccessor.html) | Return detailed information about an Amazon Managed Blockchain accessor | Read | 
| <a name="managedblockchain-GetMember"></a>[GetMember](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetMember.html) | Return detailed information about a member of an Amazon Managed Blockchain network | Read | 
| <a name="managedblockchain-GetNetwork"></a>[GetNetwork](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetNetwork.html) | Return detailed information about an Amazon Managed Blockchain network | Read | 
| <a name="managedblockchain-GetNode"></a>[GetNode](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetNode.html) | Return detailed information about a node within a member of an Amazon Managed Blockchain network | Read | 
| <a name="managedblockchain-GetProposal"></a>[GetProposal](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetProposal.html) | Return detailed information about a proposal of an Amazon Managed Blockchain network | Read | 
| <a name="managedblockchain-InvokeRpcBitcoinMainnet"></a>[InvokeRpcBitcoinMainnet](https://docs.aws.amazon.com/managed-blockchain/latest/ambbtc-dg/security_iam_id-based-policy-examples.html#security_iam_id-based-policy-examples-access-bitcoin-networks) | Invoke the Bitcoin Mainnet RPCs | Read | 
| <a name="managedblockchain-InvokeRpcBitcoinTestnet"></a>[InvokeRpcBitcoinTestnet](https://docs.aws.amazon.com/managed-blockchain/latest/ambbtc-dg/security_iam_id-based-policy-examples.html#security_iam_id-based-policy-examples-access-bitcoin-networks) | Invoke the Bitcoin Testnet RPCs | Read | 
| <a name="managedblockchain-InvokeRpcPolygonMainnet"></a>[InvokeRpcPolygonMainnet](https://docs.aws.amazon.com/managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.html#security_iam_id-based-policy-examples-access-polygon-networks) | Invoke the Polygon Mainnet RPCs | Read | 
| <a name="managedblockchain-InvokeRpcPolygonMumbaiTestnet"></a>[InvokeRpcPolygonMumbaiTestnet](https://docs.aws.amazon.com/managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.html#security_iam_id-based-policy-examples-access-polygon-networks) | Invoke the Polygon Mumbai Testnet RPCs | Read | 
| <a name="managedblockchain-ListAccessors"></a>[ListAccessors](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListAccessors.html) | List the Amazon Managed Blockchain accessors owned by the current AWS account | List | 
| <a name="managedblockchain-ListInvitations"></a>[ListInvitations](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListInvitations.html) | List the invitations extended to the active AWS account from any Managed Blockchain network | List | 
| <a name="managedblockchain-ListMembers"></a>[ListMembers](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListMembers.html) | List the members of an Amazon Managed Blockchain network and the properties of their memberships | List | 
| <a name="managedblockchain-ListNetworks"></a>[ListNetworks](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListNetworks.html) | List the Amazon Managed Blockchain networks in which the current AWS account participates | List | 
| <a name="managedblockchain-ListNodes"></a>[ListNodes](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListNodes.html) | List the nodes within a member of an Amazon Managed Blockchain network | List | 
| <a name="managedblockchain-ListProposalVotes"></a>[ListProposalVotes](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListProposalVotes.html) | List all votes for a proposal, including the value of the vote and the unique identifier of the member that cast the vote for the given Amazon Managed Blockchain network | Read | 
| <a name="managedblockchain-ListProposals"></a>[ListProposals](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListProposals.html) | List proposals for the given Amazon Managed Blockchain network | List | 
| <a name="managedblockchain-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_ListTagsForResource.html) | View tags associated with an Amazon Managed Blockchain resource | Read |
