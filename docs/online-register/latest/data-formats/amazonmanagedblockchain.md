| Actions                                                                                                                                                                                                                                                                                                                                | Description                                                                                                                                                               | Access level |

| [GetMember](../../../managed-blockchain/latest/APIReference/API_GetMember.md "../../../managed-blockchain/latest/APIReference/API_GetMember.md")                                                                                                                                                                                       | Return detailed information about a member of an Amazon Managed Blockchain network                                                                                        | Read         |
| [GetNetwork](../../../managed-blockchain/latest/APIReference/API_GetNetwork.md "../../../managed-blockchain/latest/APIReference/API_GetNetwork.md")                                                                                                                                                                                    | Return detailed information about an Amazon Managed Blockchain network                                                                                                    | Read         |
| [GetNode](../../../managed-blockchain/latest/APIReference/API_GetNode.md "../../../managed-blockchain/latest/APIReference/API_GetNode.md")                                                                                                                                                                                             | Return detailed information about a node within a member of an Amazon Managed Blockchain network                                                                          | Read         |
| [GetProposal](../../../managed-blockchain/latest/APIReference/API_GetProposal.md "../../../managed-blockchain/latest/APIReference/API_GetProposal.md")                                                                                                                                                                                 | Return detailed information about a proposal of an Amazon Managed Blockchain network                                                                                      | Read         |

| [InvokeRpcPolygonMainnet](../../../managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-access-polygon-networks "../../../managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-access-polygon-networks")       | Invoke the Polygon Mainnet RPCs                                                                                                                                           | Read         |
| [InvokeRpcPolygonMumbaiTestnet](../../../managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-access-polygon-networks "../../../managed-blockchain/latest/ambp-dg/security_iam_id-based-policy-examples.md#security_iam_id-based-policy-examples-access-polygon-networks") | Invoke the Polygon Mumbai Testnet RPCs                                                                                                                                    | Read         |
| [ListAccessors](../../../managed-blockchain/latest/APIReference/API_ListAccessors.md "../../../managed-blockchain/latest/APIReference/API_ListAccessors.md")                                                                                                                                                                           | List the Amazon Managed Blockchain accessors owned by the current AWS account                                                                                             | List         |
| [ListInvitations](../../../managed-blockchain/latest/APIReference/API_ListInvitations.md "../../../managed-blockchain/latest/APIReference/API_ListInvitations.md")                                                                                                                                                                     | List the invitations extended to the active AWS account from any Managed Blockchain network                                                                               | List         |
