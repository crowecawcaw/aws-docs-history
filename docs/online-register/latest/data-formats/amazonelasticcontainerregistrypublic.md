# Data retrieval APIs for Amazon Elastic Container Registry Public

Amazon Elastic Container Registry Public provides the following APIs for data retrieval.

| Actions                                                                                                                                                                                          | Description                                                                                        | Access level |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ------------ |
| [BatchCheckLayerAvailability](../../../AmazonECRPublic/latest/APIReference/API_BatchCheckLayerAvailability.md "../../../AmazonECRPublic/latest/APIReference/API_BatchCheckLayerAvailability.md") | Check the availability of multiple image layers in a specified registry and repository             | Read         |
| [DescribeImageTags](../../../AmazonECRPublic/latest/APIReference/API_DescribeImageTags.md "../../../AmazonECRPublic/latest/APIReference/API_DescribeImageTags.md")                               | Describe all the image tags for a given repository                                                 | List         |
| [DescribeImages](../../../AmazonECRPublic/latest/APIReference/API_DescribeImages.md "../../../AmazonECRPublic/latest/APIReference/API_DescribeImages.md")                                        | Get metadata about the images in a repository, including image size, image tags, and creation date | Read         |
| [DescribeRegistries](../../../AmazonECRPublic/latest/APIReference/API_DescribeRegistries.md "../../../AmazonECRPublic/latest/APIReference/API_DescribeRegistries.md")                            | Retrieve the catalog data associated with a registry                                               | List         |
| [DescribeRepositories](../../../AmazonECRPublic/latest/APIReference/API_DescribeRepositories.md "../../../AmazonECRPublic/latest/APIReference/API_DescribeRepositories.md")                      | Describe image repositories in a registry                                                          | List         |
| [GetAuthorizationToken](../../../AmazonECRPublic/latest/APIReference/API_GetAuthorizationToken.md "../../../AmazonECRPublic/latest/APIReference/API_GetAuthorizationToken.md")                   | Retrieve a token that is valid for a specified registry for 12 hours                               | Read         |
| [GetRegistryCatalogData](../../../AmazonECRPublic/latest/APIReference/API_GetRegistryCatalogData.md "../../../AmazonECRPublic/latest/APIReference/API_GetRegistryCatalogData.md")                | Retrieve the catalog data associated with a registry                                               | Read         |
| [GetRepositoryCatalogData](../../../AmazonECRPublic/latest/APIReference/API_GetRepositoryCatalogData.md "../../../AmazonECRPublic/latest/APIReference/API_GetRepositoryCatalogData.md")          | Retrieve the catalog data associated with a repository                                             | Read         |
| [GetRepositoryPolicy](../../../AmazonECRPublic/latest/APIReference/API_GetRepositoryPolicy.md "../../../AmazonECRPublic/latest/APIReference/API_GetRepositoryPolicy.md")                         | Retrieve the repository policy for a specified repository                                          | Read         |
| [ListTagsForResource](../../../AmazonECRPublic/latest/APIReference/API_ListTagsForResource.md "../../../AmazonECRPublic/latest/APIReference/API_ListTagsForResource.md")                         | List the tags for an Amazon ECR resource                                                           | Read         |
