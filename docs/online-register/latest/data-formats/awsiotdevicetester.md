# Data retrieval APIs for AWS IoT Device Tester

AWS IoT Device Tester provides the following APIs for data retrieval.

| Actions                                                                                                                                  | Description                                                                                               | Access level |
| ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------ |
| [CheckVersion](../../../freertos/latest/userguide/dev-tester-prereqs.md "../../../freertos/latest/userguide/dev-tester-prereqs.md")      | IoT Device Tester to check if a given set of product, test suite and device tester version are compatible | Read         |
| [DownloadTestSuite](../../../freertos/latest/userguide/dev-tester-prereqs.md "../../../freertos/latest/userguide/dev-tester-prereqs.md") | IoT Device Tester to download compatible test suite versions                                              | Read         |
| [LatestIdt](../../../freertos/latest/userguide/dev-tester-prereqs.md "../../../freertos/latest/userguide/dev-tester-prereqs.md")         | IoT Device Tester to get information on latest version of device tester available                         | Read         |
| [SupportedVersion](../../../freertos/latest/userguide/dev-tester-prereqs.md "../../../freertos/latest/userguide/dev-tester-prereqs.md")  | IoT Device Tester to get list of supported products and test suite versions                               | Read         |
