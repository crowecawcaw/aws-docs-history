# Data retrieval APIs for AWS Backup Search

AWS Backup Search provides the following APIs for data retrieval.

| Actions                                                                                                                                                                     | Description                               | Access level |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- | ------------ |
| [GetSearchJob](../../../aws-backup/latest/devguide/API_GetSearchJob.md "../../../aws-backup/latest/devguide/API_GetSearchJob.md")                                           | Get details of a search job               | Read         |
| [GetSearchResultExportJob](../../../aws-backup/latest/devguide/API_GetSearchResultExportJob.md "../../../aws-backup/latest/devguide/API_GetSearchResultExportJob.md")       | Get details of a search result export job | Read         |
| [ListSearchJobBackups](../../../aws-backup/latest/devguide/API_ListSearchJobBackups.md "../../../aws-backup/latest/devguide/API_ListSearchJobBackups.md")                   | List backups in scope of a search job     | Read         |
| [ListSearchJobResults](../../../aws-backup/latest/devguide/API_ListSearchJobResults.md "../../../aws-backup/latest/devguide/API_ListSearchJobResults.md")                   | List results of a search job              | Read         |
| [ListSearchJobs](../../../aws-backup/latest/devguide/API_ListSearchJobs.md "../../../aws-backup/latest/devguide/API_ListSearchJobs.md")                                     | List search jobs                          | List         |
| [ListSearchResultExportJobs](../../../aws-backup/latest/devguide/API_ListSearchResultExportJobs.md "../../../aws-backup/latest/devguide/API_ListSearchResultExportJobs.md") | List search result export jobs            | List         |
| [ListTagsForResource](../../../aws-backup/latest/devguide/API_ListTagsForResource.md "../../../aws-backup/latest/devguide/API_ListTagsForResource.md")                      | List tags for a resource                  | Read         |
