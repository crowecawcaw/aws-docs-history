

# Data retrieval APIs for AWS Marketplace Management Portal
<a name="awsmarketplacemanagementportal"></a>

AWS Marketplace Management Portal provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="aws-marketplace-management-GetAdditionalSellerNotificationRecipients"></a>[GetAdditionalSellerNotificationRecipients](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | View additional seller notification recipients | Read | 
| <a name="aws-marketplace-management-GetBankAccountVerificationDetails"></a>[GetBankAccountVerificationDetails](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | View bank account verification status | Read | 
| <a name="aws-marketplace-management-GetSecondaryUserVerificationDetails"></a>[GetSecondaryUserVerificationDetails](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | View secondary user account verification status | Read | 
| <a name="aws-marketplace-management-GetSellerVerificationDetails"></a>[GetSellerVerificationDetails](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | View account verification status | Read | 
| <a name="aws-marketplace-management-viewMarketing"></a>[viewMarketing](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | Allows access to the Marketing page inside the AWS Marketplace Management Portal | List | 
| <a name="aws-marketplace-management-viewReports"></a>[viewReports](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | Allows access to the Reports page inside the AWS Marketplace Management Portal | List | 
| <a name="aws-marketplace-management-viewSettings"></a>[viewSettings](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | Allows access to the Settings page inside the AWS Marketplace Management Portal | List | 
| <a name="aws-marketplace-management-viewSupport"></a>[viewSupport](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html#seller-ammp-permissions) | Allows access to the Customer Support Eligibility page inside the AWS Marketplace Management Portal | List |
