

# Data retrieval APIs for Amazon Macie
<a name="amazonmacie"></a>

Amazon Macie provides the following APIs for data retrieval.



| Actions | Description | Access level | 
| --- | --- | --- | 
| <a name="macie2-BatchGetCustomDataIdentifiers"></a>[BatchGetCustomDataIdentifiers](https://docs.aws.amazon.com/macie/latest/APIReference/custom-data-identifiers-get.html) | Retrieve information about one or more custom data identifiers | Read | 
| <a name="macie2-DescribeBuckets"></a>[DescribeBuckets](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) | Retrieve statistical data and other information about S3 buckets that Amazon Macie monitors and analyzes | Read | 
| <a name="macie2-DescribeClassificationJob"></a>[DescribeClassificationJob](https://docs.aws.amazon.com/macie/latest/APIReference/jobs-jobid.html) | Retrieve information about the status and settings for a sensitive data discovery job | Read | 
| <a name="macie2-DescribeOrganizationConfiguration"></a>[DescribeOrganizationConfiguration](https://docs.aws.amazon.com/macie/latest/APIReference/admin-configuration.html) | Retrieve information about the Amazon Macie configuration settings for an AWS organization | Read | 
| <a name="macie2-GetAdministratorAccount"></a>[GetAdministratorAccount](https://docs.aws.amazon.com/macie/latest/APIReference/administrator.html) | Retrieve information about the Amazon Macie administrator account for an account | Read | 
| <a name="macie2-GetAllowList"></a>[GetAllowList](https://docs.aws.amazon.com/macie/latest/APIReference/allow-lists-id.html) | Retrieve the settings and status of an allow list | Read | 
| <a name="macie2-GetAutomatedDiscoveryConfiguration"></a>[GetAutomatedDiscoveryConfiguration](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-configuration.html) | Retrieve the configuration settings and status of automated sensitive data discovery for an Amazon Macie administrator account, organization, or standalone account | Read | 
| <a name="macie2-GetBucketStatistics"></a>[GetBucketStatistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) | Retrieve aggregated statistical data for all the S3 buckets that Amazon Macie monitors and analyzes | Read | 
| <a name="macie2-GetClassificationExportConfiguration"></a>[GetClassificationExportConfiguration](https://docs.aws.amazon.com/macie/latest/APIReference/classification-export-configuration.html) | Retrieve the settings for exporting sensitive data discovery results | Read | 
| <a name="macie2-GetClassificationScope"></a>[GetClassificationScope](https://docs.aws.amazon.com/macie/latest/APIReference/classification-scopes-id.html) | Retrieve the classification scope settings for an account | Read | 
| <a name="macie2-GetCustomDataIdentifier"></a>[GetCustomDataIdentifier](https://docs.aws.amazon.com/macie/latest/APIReference/custom-data-identifiers-id.html) | Retrieve information about the settings for a custom data identifier | Read | 
| <a name="macie2-GetFindingStatistics"></a>[GetFindingStatistics](https://docs.aws.amazon.com/macie/latest/APIReference/findings-statistics.html) | Retrieve aggregated statistical data about findings | Read | 
| <a name="macie2-GetFindings"></a>[GetFindings](https://docs.aws.amazon.com/macie/latest/APIReference/findings-describe.html) | Retrieve the details of one or more findings | Read |

| <a name="macie2-GetFindingsPublicationConfiguration"></a>[GetFindingsPublicationConfiguration](https://docs.aws.amazon.com/macie/latest/APIReference/findings-publication-configuration.html) | Retrieve the configuration settings for publishing findings to AWS Security Hub | Read | 
| <a name="macie2-GetInvitationsCount"></a>[GetInvitationsCount](https://docs.aws.amazon.com/macie/latest/APIReference/invitations-count.html) | Retrieve the count of Amazon Macie membership invitations that were received by an account | Read | 
| <a name="macie2-GetMacieSession"></a>[GetMacieSession](https://docs.aws.amazon.com/macie/latest/APIReference/macie.html) | Retrieve information about the status and configuration settings for an Amazon Macie account | Read | 
| <a name="macie2-GetMasterAccount"></a>[GetMasterAccount](https://docs.aws.amazon.com/macie/latest/APIReference/master.html) | Retrieve information about the Amazon Macie administrator account for an account | Read | 
| <a name="macie2-GetMember"></a>[GetMember](https://docs.aws.amazon.com/macie/latest/APIReference/members-id.html) | Retrieve information about an account that's associated with an Amazon Macie administrator account | Read | 
| <a name="macie2-GetResourceProfile"></a>[GetResourceProfile](https://docs.aws.amazon.com/macie/latest/APIReference/resource-profiles.html) | Retrieve sensitive data discovery statistics and the sensitivity score for an S3 bucket | Read | 
| <a name="macie2-GetRevealConfiguration"></a>[GetRevealConfiguration](https://docs.aws.amazon.com/macie/latest/APIReference/reveal-configuration.html) | Retrieve the status and configuration settings for retrieving occurrences of sensitive data reported by findings | Read | 
| <a name="macie2-GetSensitiveDataOccurrences"></a>[GetSensitiveDataOccurrences](https://docs.aws.amazon.com/macie/latest/APIReference/findings-findingid-reveal.html) | Retrieve occurrences of sensitive data reported by a finding | Read | 
| <a name="macie2-GetSensitiveDataOccurrencesAvailability"></a>[GetSensitiveDataOccurrencesAvailability](https://docs.aws.amazon.com/macie/latest/APIReference/findings-findingid-reveal-availability.html) | Check whether occurrences of sensitive data can be retrieved for a finding | Read | 
| <a name="macie2-GetSensitivityInspectionTemplate"></a>[GetSensitivityInspectionTemplate](https://docs.aws.amazon.com/macie/latest/APIReference/templates-sensitivity-inspections-id.html) | Retrieve the sensitivity inspection template settings for an account | Read | 
| <a name="macie2-GetUsageStatistics"></a>[GetUsageStatistics](https://docs.aws.amazon.com/macie/latest/APIReference/usage-statistics.html) | Retrieve quotas and aggregated usage data for one or more accounts | Read | 
| <a name="macie2-GetUsageTotals"></a>[GetUsageTotals](https://docs.aws.amazon.com/macie/latest/APIReference/usage.html) | Retrieve aggregated usage data for an account | Read | 
| <a name="macie2-ListAllowLists"></a>[ListAllowLists](https://docs.aws.amazon.com/macie/latest/APIReference/allow-lists.html) | Retrieve a subset of information about all the allow lists for an account | List | 
| <a name="macie2-ListAutomatedDiscoveryAccounts"></a>[ListAutomatedDiscoveryAccounts](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-accounts.html) | Retrieve the status of automated sensitive data discovery for an account | List | 
| <a name="macie2-ListClassificationJobs"></a>[ListClassificationJobs](https://docs.aws.amazon.com/macie/latest/APIReference/jobs-list.html) | Retrieve a subset of information about the status and settings for one or more sensitive data discovery jobs | List | 
| <a name="macie2-ListClassificationScopes"></a>[ListClassificationScopes](https://docs.aws.amazon.com/macie/latest/APIReference/classification-scopes.html) | Retrieve a subset of information about the classification scope for an account | List | 
| <a name="macie2-ListCustomDataIdentifiers"></a>[ListCustomDataIdentifiers](https://docs.aws.amazon.com/macie/latest/APIReference/custom-data-identifiers-list.html) | Retrieve information about all custom data identifiers | List |

| <a name="macie2-ListInvitations"></a>[ListInvitations](https://docs.aws.amazon.com/macie/latest/APIReference/invitations.html) | Retrieve information about all the Amazon Macie membership invitations that were received by an account | List | 
| <a name="macie2-ListManagedDataIdentifiers"></a>[ListManagedDataIdentifiers](https://docs.aws.amazon.com/macie/latest/APIReference/managed-data-identifiers-list.html) | Retrieve information about managed data identifiers | List |

| <a name="macie2-ListResourceProfileDetections"></a>[ListResourceProfileDetections](https://docs.aws.amazon.com/macie/latest/APIReference/resource-profiles-detections.html) | Retrieve information about the types and amount of sensitive data that Amazon Macie found in an S3 bucket | List | 
| <a name="macie2-ListSensitivityInspectionTemplates"></a>[ListSensitivityInspectionTemplates](https://docs.aws.amazon.com/macie/latest/APIReference/templates-sensitivity-inspections.html) | Retrieve a subset of information about the sensitivity inspection template for an account | List | 
| <a name="macie2-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/macie/latest/APIReference/tags-resourcearn.html) | Retrieve the tags for an Amazon Macie resource | Read | 
| <a name="macie2-SearchResources"></a>[SearchResources](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-search-resources.html) | Retrieve statistical data and other information about AWS resources that Amazon Macie monitors and analyzes | Read |
