| [DescribeBuckets](../../../macie/latest/APIReference/datasources-s3.md "../../../macie/latest/APIReference/datasources-s3.md")                                                                         | Retrieve statistical data and other information about S3 buckets that Amazon Macie monitors and analyzes                                                            | Read         |
| [DescribeClassificationJob](../../../macie/latest/APIReference/jobs-jobid.md "../../../macie/latest/APIReference/jobs-jobid.md")                                                                       | Retrieve information about the status and settings for a sensitive data discovery job                                                                               | Read         |
| [DescribeOrganizationConfiguration](../../../macie/latest/APIReference/admin-configuration.md "../../../macie/latest/APIReference/admin-configuration.md")                                             | Retrieve information about the Amazon Macie configuration settings for an AWS organization                                                                          | Read         |
| [GetAdministratorAccount](../../../macie/latest/APIReference/administrator.md "../../../macie/latest/APIReference/administrator.md")                                                                   | Retrieve information about the Amazon Macie administrator account for an account                                                                                    | Read         |

| [GetClassificationExportConfiguration](../../../macie/latest/APIReference/classification-export-configuration.md "../../../macie/latest/APIReference/classification-export-configuration.md")          | Retrieve the settings for exporting sensitive data discovery results                                                                                                | Read         |
