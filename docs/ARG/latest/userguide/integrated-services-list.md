# AWS services that work with AWS Resource Groups

You can use the following AWS services with AWS Resource Groups.

| AWS service                                                                                                                                                                                                                                                                                                                                                                                               | Using with Resource Groups                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS CloudFormation](../../../AWSCloudFormation/latest/UserGuide.md "../../../AWSCloudFormation/latest/UserGuide.md")<br>– Create resource groups in CloudFormation by using a stack<br>template.                                                                                                                                                                                                         | Provision and organize AWS resources at the same time. Organize<br>resources by tags. Organize resources from another stack. Gather<br>insights on your AWS resources in resource groups using Amazon CloudWatch or<br>take operational actions using AWS Systems Manager.<br>For more information, see [ResourceGroups<br>resource type reference](../../../AWSCloudFormation/latest/UserGuide/AWS_ResourceGroups.md "../../../AWSCloudFormation/latest/UserGuide/AWS_ResourceGroups.md") in the _AWS CloudFormation User Guide_.                                                                                                                                                                                                                                                                                                |
| [CloudTrail](../../../awscloudtrail/latest/userguide.md "../../../awscloudtrail/latest/userguide.md")<br>– Capture all resource group actions using AWS CloudTrail.                                                                                                                                                                                                                                       | Capture information about actions performed on your resource groups<br>including details like who performed the action (IAM principal, such<br>as a role, user, or an AWS service), when the action was performed,<br>where the action occurred (the source IP address) and more. These<br>records can then be used for analysis or to trigger follow-up<br>actions.<br>For more information, see [Viewing events with<br>CloudTrail Event history](../../../awscloudtrail/latest/userguide/view-cloudtrail-events.md "../../../awscloudtrail/latest/userguide/view-cloudtrail-events.md").                                                                                                                                                                                                                                       |
| [Amazon CloudWatch](../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md "../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md") – Enable real-time monitoring of your AWS<br>resources and the applications you run on AWS.                                                                                                                                                        | Focus your view to display metrics and alarms from a single resource<br>group.<br>For more information, see [Focus on metrics and alarms in a resource group](../../../AmazonCloudWatch/latest/monitoring/CloudWatch_Automatic_Dashboards_Resource_Group.md "../../../AmazonCloudWatch/latest/monitoring/CloudWatch_Automatic_Dashboards_Resource_Group.md") in the<br>_Amazon CloudWatch User Guide._                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [Amazon CloudWatch application<br>insights](../../../AmazonCloudWatch/latest/monitoring/appinsights-what-is.md "../../../AmazonCloudWatch/latest/monitoring/appinsights-what-is.md") – Detect common problems with your .NET and<br>SQL Server-based applications.                                                                                                                                        | Monitor your .NET and SQL Server application resources that belong to<br>a resource group.<br>For more information, see [Supported application components](../../../AmazonCloudWatch/latest/monitoring/appinsights-what-is.md#appinsights-components "../../../AmazonCloudWatch/latest/monitoring/appinsights-what-is.md#appinsights-components") in the<br>_Amazon CloudWatch User Guide_.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [Amazon DynamoDB table groups](../../../amazondynamodb/latest/developerguide/Introduction.md "../../../amazondynamodb/latest/developerguide/Introduction.md") – Organize your DynamoDB tables<br>into logical groupings so you can more easily manage your resources.                                                                                                                                     | Create, edit, and delete groups of DynamoDB tables from the DynamoDB<br>\*_Action_<br>• menu.<br>For more information, see the [_Amazon DynamoDB Developer Guide._](../../../amazondynamodb/latest/developerguide/Introduction.md "../../../amazondynamodb/latest/developerguide/Introduction.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| [Amazon EC2 dedicated<br>hosts](../../../AWSEC2/latest/UserGuide/dedicated-hosts-overview.md "../../../AWSEC2/latest/UserGuide/dedicated-hosts-overview.md") – Use your existing per-socket, per-core, or<br>per-VM software licenses, including Windows Server, Microsoft SQL<br>Server, SUSE, and Linux Enterprise Server.                                                                              | Launch Amazon EC2 instances into host resource groups to help maximize your<br>utilization of Dedicated Hosts.<br>For more information, see [Working with<br>dedicated hosts](../../../AWSEC2/latest/UserGuide/how-dedicated-hosts-work.md "../../../AWSEC2/latest/UserGuide/how-dedicated-hosts-work.md") in the<br>_Amazon EC2 User Guide._                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| [Amazon EC2 capacity<br>reservations](../../../AWSEC2/latest/UserGuide/ec2-capacity-reservations.md "../../../AWSEC2/latest/UserGuide/ec2-capacity-reservations.md") – Reserve capacity for your Amazon EC2 instances<br>to be used when you need it. You can specify attributes for the capacity<br>reservation so that it only works with Amazon EC2 instances that launch with<br>matching attributes. | Launch your Amazon EC2 instances into resource groups that contain one or<br>more capacity reservations. If the group doesn't have a capacity<br>reservation with matching attributes and available capacity for a<br>requested instance, the instance runs as an on-demand instance. If you<br>later add a matching capacity reservation to the targeted group, the<br>instance is automatically matched with and moved into the reserved<br>capacity.<br>For more information, see [Work with Capacity Reservation groups](../../../AWSEC2/latest/UserGuide/capacity-reservations-using.md#create-cr-group "../../../AWSEC2/latest/UserGuide/capacity-reservations-using.md#create-cr-group") in the<br>_Amazon EC2 User Guide._                                                                                                |
| [AWS License Manager](../../../license-manager/latest/userguide/license-manager.md "../../../license-manager/latest/userguide/license-manager.md") – Streamline the process of bringing<br>software vendor licenses to the cloud.                                                                                                                                                                         | Configure a host resource group to enable License Manager to manage your<br>Dedicated Hosts.<br>For more information, see [Host Resource Groups<br>in License Manager](../../../license-manager/latest/userguide/host-resource-groups.md "../../../license-manager/latest/userguide/host-resource-groups.md") in the<br>_License Manager User Guide._                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| [AWS Resilience Hub](../../../resilience-hub/latest/userguide.md "../../../resilience-hub/latest/userguide.md") – Prepare and protect your applications<br>from disruptions.                                                                                                                                                                                                                              | Discover your applications that are defined using Resource<br>Groups.<br>For more information, see [Measure and Improve Your Application Resilience with<br>AWS Resilience Hub](https://aws.amazon.com/blogs/aws/monitor-and-improve-your-application-resiliency-with-resilience-hub/ "https://aws.amazon.com/blogs/aws/monitor-and-improve-your-application-resiliency-with-resilience-hub/") in the _AWS News Blog_.                                                                                                                                                                                                                                                                                                                                                                                                            |
| [AWS Resource Access Manager](../../../ram/latest/userguide.md "../../../ram/latest/userguide.md")<br>– Share specified AWS resources that you own with other<br>accounts.                                                                                                                                                                                                                                | Share host resource groups using AWS RAM.<br>For more information, see [Shareable<br>resources](../../../ram/latest/userguide/shareable.md#shareable-arg "../../../ram/latest/userguide/shareable.md#shareable-arg") in the _AWS RAM User Guide._                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [AWS Service Catalog AppRegistry](../../../servicecatalog/latest/adminguide/appregistry.md "../../../servicecatalog/latest/adminguide/appregistry.md") – Define and manage your applications and<br>their metadata.                                                                                                                                                                                       | When you create an application in AppRegistry, that service automatically<br>creates an resource group for that application. The application resource<br>group is a collection of all of the resources in your application. The<br>service also creates a CloudFormation stack-based resource group for every stack<br>associated with the application.<br>For more information, see [Using<br>AppRegistry](../../../servicecatalog/latest/adminguide/appregistry.md "../../../servicecatalog/latest/adminguide/appregistry.md") in the _AWS Service Catalog<br>Administrator Guide_.                                                                                                                                                                                                                                             |
| [AWS Systems Manager](../../../systems-manager/latest/userguide/what-is-systems-manager.md "../../../systems-manager/latest/userguide/what-is-systems-manager.md")<br>– Enable visibility and control of your AWS resources.                                                                                                                                                                              | Gather operational insights and take bulk actions on your applications<br>that are based on resource groups. In the AWS Systems Manager console, the<br>Application Manager \*_Custom applications_<br>• page<br>automatically imports and displays operations data for applications that<br>are based on resource groups. You can use the information in Application<br>Manager to help you determine which resources in an application are<br>compliant and working correctly and which resources require<br>action.<br>For more information, see [Working with applications in Application Manager](../../../systems-manager/latest/userguide/application-manager-working-applications.md "../../../systems-manager/latest/userguide/application-manager-working-applications.md") in the<br>_AWS Systems Manager User Guide_. |
| [Amazon VPC Network Access Analyzer](../../../vpc/latest/network-access-analyzer.md "../../../vpc/latest/network-access-analyzer.md") – Identify unwanted<br>network access to your resources on AWS.                                                                                                                                                                                                     | You can specify the sources and destinations for your network access<br>requirements by using AWS Resource Groups. This lets you govern network access<br>across your AWS environment, independent of how you configure your<br>network.<br>For more information, see [Use<br>Resource Groups with Network Access Scopes](../../../vpc/latest/network-access-analyzer/working-with-network-access-scopes.md "../../../vpc/latest/network-access-analyzer/working-with-network-access-scopes.md") in the<br>_Amazon Virtual Private Cloud User Guide_.                                                                                                                                                                                                                                                                             |
