# Life cycle operations of a network instance

AWS TNB allows you to easily manage your network using standardized management
operations inline with ETSI SOL003 and SOL005. You can perform the following life-cycle
operations:

- Create the network
- Instantiate the network
- Update the network function
- Update the network instance
- View network details and status
- Terminate the network
