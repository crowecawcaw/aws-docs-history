# Getting started with AWS Lake Formation-managed

datashares

With Amazon Redshift, you can access and share live data across AWS accounts and Amazon Redshift
clusters through AWS Lake Formation-managed datashares. AWS Lake Formation datashares enable data
providers to securely share live data from their Amazon S3 data lake with any consumer,
including other AWS accounts and Amazon Redshift clusters.
