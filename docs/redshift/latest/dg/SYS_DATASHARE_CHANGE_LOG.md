# SYS_DATASHARE_CHANGE_LOG

Records the consolidated view for tracking changes to datashares on both producer and
consumer clusters.

SYS_DATASHARE_CHANGE_LOG is visible to all users. Superusers can see all rows; regular users can see only their own data. For more information, see [Visibility of data in system tables and
views](cm_chap_system-tables.md#c_visibility-of-data "cm_chap_system-tables.md#c_visibility-of-data").
