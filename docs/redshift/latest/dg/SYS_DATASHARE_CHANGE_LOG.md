# SYS\_DATASHARE\_CHANGE\_LOG

Records the consolidated view for tracking changes to datashares on both producer and
consumer clusters.

SYS\_DATASHARE\_CHANGE\_LOG is visible to all users. Superusers can see all rows; regular users can see only their own data. For more information, see [Visibility of data in system tables and views](cm_chap_system-tables.md#c_visibility-of-data "cm_chap_system-tables.md#c_visibility-of-data").

## Sample queries

The following example shows a SYS\_DATASHARE\_CHANGE\_LOG view.

```
SELECT DISTINCT action
FROM sys_datashare_change_log
WHERE share_object_name LIKE 'tickit%';

         action
 -----------------------
  "ALTER DATASHARE ADD"
```
