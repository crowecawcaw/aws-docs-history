# Machine learning functions

By using Amazon Redshift machine learning (ML), you can train ML models using SQL statements
and invoke them in SQL queries for prediction. Amazon Redshift model explainability includes
feature-importance values to help you understand how each attribute in your training data
contributes to the predicted result.

Following, you can find descriptions for the machine learning functions for SQL that
Amazon Redshift supports.
