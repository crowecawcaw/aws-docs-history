# Rotating encryption keys

You can use the following procedure to rotate encryption keys by using the
Amazon Redshift console.

###### To rotate the encryption keys for a cluster

1. Sign in to the AWS Management Console and open the Amazon Redshift console at
   [https://console.aws.amazon.com/redshiftv2/](https://console.aws.amazon.com/redshiftv2/ "https://console.aws.amazon.com/redshiftv2/").
2. On the navigation menu, choose **Clusters**, then choose the
   cluster that you want to update encryption keys.
3. For **Actions**, choose **Rotate
   encryption** to display the **Rotate encryption
   keys** page.
4. On the **Rotate encryption keys** page, choose
   **Rotate encryption keys**.
