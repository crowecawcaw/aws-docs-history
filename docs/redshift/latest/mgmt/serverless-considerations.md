Amazon Redshift will no longer support the creation of new Python UDFs starting November 1, 2025.
If you would like to use Python UDFs, create the UDFs prior to that date.
Existing Python UDFs will continue to function as normal. For more information, see the
[blog post](https://aws.amazon.com/blogs/big-data/amazon-redshift-python-user-defined-functions-will-reach-end-of-support-after-june-30-2026/ "https://aws.amazon.com/blogs/big-data/amazon-redshift-python-user-defined-functions-will-reach-end-of-support-after-june-30-2026/") .

# Amazon Redshift Serverless feature overview

Most of the features supported by an Amazon Redshift provisioned data warehouse are also
supported by Amazon Redshift Serverless. The following are some of its key capabilities.

| Feature                               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Snapshots**                         | You can restore a snapshot of Amazon Redshift Serverless or a<br>provisioned data warehouse to Amazon Redshift Serverless. For more<br>information, see [Snapshots and recovery points](serverless-snapshots-recovery-points.md "serverless-snapshots-recovery-points.md").                                                                                                                                                                                                                                                                                                                                                        |
| **Recovery points**                   | Amazon Redshift Serverless automatically creates a point of recovery<br>every 30 minutes. These recovery points are kept for 24 hours. You<br>can use them to restore after accidental writes or deletes. When you<br>restore from a recovery point, all the data in your<br>Amazon Redshift Serverless database is restored to an earlier point in time.<br>You can also create a snapshot from a recovery point if you need to<br>keep a point of recovery for a longer period. For more information,<br>see [Snapshots and recovery points](serverless-snapshots-recovery-points.md "serverless-snapshots-recovery-points.md"). |
| **Base RPU<br>capacity**              | You can set a base capacity in Redshift Processing Units<br>(RPUs). One RPU provides 16 GB of memory. This setting gives you the<br>ability to control the balance between resources in use and cost for<br>your workload. You can increase this value to grow resources<br>available and improve query performance, or lower the value to limit<br>your spending. The default is 128 RPUs. You can also set usage<br>limits, such as RPUs used per day, to control costs. For more<br>information, see [Billing for Amazon Redshift Serverless](serverless-billing.md "serverless-billing.md").                                   |
| **Usage limits of data<br>sharing**   | You can limit the amount of data transferred from a producer<br>Region to a consumer Region using the console or the API. These data<br>transfer costs differ by AWS Region, and are measured in<br>terabytes. For more information about data sharing, see [Getting<br>started data sharing using the console](../dg/getting-started-datashare-console.md "../dg/getting-started-datashare-console.md") in the<br>_Amazon Redshift Database Developer<br>Guide_.                                                                                                                                                                  |
| **User-defined functions<br>(UDFs)**  | You can run user-defined functions (UDFs) in Amazon Redshift Serverless.<br>For more information, see [Creating<br>user-defined functions](../dg/user-defined-functions.md "../dg/user-defined-functions.md") in the<br>_Amazon Redshift Database Developer Guide_.                                                                                                                                                                                                                                                                                                                                                                |
