# Deleting a manual snapshot

You can delete manual snapshots by selecting one or more snapshots in the snapshot
list.

###### To delete a manual snapshot

1. Sign in to the AWS Management Console and open the Amazon Redshift console at
   [https://console.aws.amazon.com/redshiftv2/](https://console.aws.amazon.com/redshiftv2/ "https://console.aws.amazon.com/redshiftv2/").
2. On the navigation menu, choose **Clusters**,
   **Snapshots**, then choose the snapshot to delete.
3. For **Actions**, choose **Delete snapshot** to
   delete the snapshot.
4. Confirm the deletion of the listed snapshots, then choose
   **Delete**.
