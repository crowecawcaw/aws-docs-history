# Amazon EventBridge tutorials

EventBridge integrates with a number of AWS services and SaaS partners. These tutorials are designed to help you get familiar with the basics of EventBridge
and how it can be part of your serverless architecture.

**Getting started**

The following tutorials help you explore the features of EventBridge and how to use them.

- [Archive and replay events](eb-tutorial-archive-replay.md "eb-tutorial-archive-replay.md")
- [Create a sample application](eb-tutorial-get-started.md "eb-tutorial-get-started.md")
- [Download code bindings](eb-schema-download-binding-tutorial.md "eb-schema-download-binding-tutorial.md")
- [Use input transformer](eb-input-transformer-tutorial.md "eb-input-transformer-tutorial.md")

- [Log Auto Scaling group states](eb-log-as-group-state.md "eb-log-as-group-state.md")
- [Create rule for AWS API calls via CloudTrail](eb-log-api-call.md "eb-log-api-call.md")
- [Log Amazon EC2 instance states](eb-log-ec2-instance-state.md "eb-log-ec2-instance-state.md")
- [Log Amazon S3 object operations](eb-log-s3-data-events.md "eb-log-s3-data-events.md")
- [Send events using schemas](eb-relay-events-kinesis-stream.md "eb-relay-events-kinesis-stream.md")
- [Schedule automated Amazon EBS snapshots](eb-scheduled-snapshot.md "eb-scheduled-snapshot.md")
- [Send an email when events happen](eb-s3-object-created-tutorial.md "eb-s3-object-created-tutorial.md")
- [Schedule a Lambda function](eb-run-lambda-schedule.md "eb-run-lambda-schedule.md")
