# AWS services and tools integrations with Amazon EventBridge

Amazon EventBridge works with other AWS services and tools to process [events](eb-events.md "eb-events.md") or invoke a resource as the [target](eb-targets.md "eb-targets.md") of a
[rule](eb-rules.md "eb-rules.md"). For more information about EventBridge integrations with
other AWS services and tools, see the following:

- [Interface VPC Endpoints](eb-related-service-vpc.md "eb-related-service-vpc.md")
