

# Amazon EventBridge feature availability by AWS Region
<a name="feature-availability"></a>

The following table shows the availability of Amazon EventBridge features by AWS Region. A check mark (✓) indicates that the feature is available in the corresponding Region; a blank cell indicates that it is not. For [API destinations](eb-api-destinations.md), the cell shows which variants are available ([Private API destinations](connection-private.md) require Public API destinations). Features shown include [Event buses](eb-event-bus.md), [Scheduler](using-eventbridge-scheduler.md), [Pipes](eb-pipes.md), [Archive and replay](eb-archive.md), the [Schema registry](eb-schema-registry.md) and [Schema discovery](eb-schemas-infer-from-json.md), and [Global endpoints](eb-global-endpoints.md).
