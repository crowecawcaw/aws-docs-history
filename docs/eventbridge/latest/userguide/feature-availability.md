

# Amazon EventBridge feature availability by AWS Region
<a name="feature-availability"></a>

The following table shows which Amazon EventBridge features are available in each AWS Region. *Yes* means that the feature is available in that Region. *No* means that it is not.

For [API destinations](eb-api-destinations.md), the cell shows each variant. [Private API destinations](connection-private.md) require Public API destinations.

The table covers these features:
+ [Event buses](eb-event-bus.md)
+ [Custom Event Bus](eb-custom-bus-what-is.md)
+ [Scheduler](using-eventbridge-scheduler.md)
+ [Pipes](eb-pipes.md)
+ [Archive and replay](eb-archive.md)
+ [Schema registry](eb-schema-registry.md)
+ [Schema discovery](eb-schemas-infer-from-json.md)
+ [Global endpoints](eb-global-endpoints.md)
