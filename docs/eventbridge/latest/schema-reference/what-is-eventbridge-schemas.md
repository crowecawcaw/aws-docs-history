# Welcome

Welcome to the _Amazon EventBridge Schema Registry API Reference_.

The Amazon EventBridge Schema Registry allows you to discover, create, and manage OpenAPI schemas for
events on EventBridge. Using these API actions you can find schemas for existing AWS services, create and
upload custom schemas, or generate a schema based on messages on an event bus. You can download
code bindings for popular languages for all schemas in EventBridge to quickly build applications that use
those events.

###### Note

Inactive schemas will be deleted after two years.

For more information on Amazon EventBridge, and managing schemas in the EventBridge console, see the
following.

- [Amazon EventBridge Schema Registry](../userguide/eventbridge-schemas.md "../userguide/eventbridge-schemas.md")
- [Tutorial:
  Download code bindings for events using the EventBridge schema registry](../userguide/eb-schema-download-binding-tutorial.md "../userguide/eb-schema-download-binding-tutorial.md")
