# PipeTargetSageMakerPipelineParameters

The parameters for using a SageMaker AI pipeline as a target.

## Contents

**PipelineParameterList**

List of Parameter names and values for SageMaker AI Model Building Pipeline
execution.

Type: Array of [SageMakerPipelineParameter](API_SageMakerPipelineParameter.md "API_SageMakerPipelineParameter.md") objects

Array Members: Minimum number of 0 items. Maximum number of 200 items.

Required: No
