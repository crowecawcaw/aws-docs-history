# Filter

Filter events using an event pattern. For more information, see [Events and Event
Patterns](../userguide/eventbridge-and-event-patterns.md "../userguide/eventbridge-and-event-patterns.md") in the _Amazon EventBridge User Guide_.

## Contents

**Pattern**

The event pattern.

Type: String

Length Constraints: Minimum length of 0. Maximum length of 4096.

Required: No
