# BatchJobDependency

An object that represents an AWS Batch job dependency.

## Contents

**JobId**

The job ID of the AWS Batch job that's associated with this
dependency.

Type: String

Required: No

**Type**

The type of the job dependency.

Type: String

Valid Values: `N_TO_N | SEQUENTIAL`

Required: No
