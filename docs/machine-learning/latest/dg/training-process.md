# Training Process

To train an ML model, you need to specify the following:

- Input training datasource
- Name of the data attribute that contains the target to be
  predicted
- Required data transformation instructions
- Training parameters to control the learning algorithm

During the training process, Amazon ML automatically selects the
correct learning algorithm for you, based on the type of target
that you specified in the training datasource.
