# Get started with AWS Signer

Before you can begin signing code and binaries with AWS Signer, you need to set up an AWS
account, create administrative and root users, apply security policies using AWS Identity and Access Management
(IAM), and create a signing profile that contains the configuration for your signing
tasks.

- [Create a Signer signing profile](signing-profiles.md "signing-profiles.md")
- [Set up cross-account signing for Signer](signing-profile-cross-account.md "signing-profile-cross-account.md")
