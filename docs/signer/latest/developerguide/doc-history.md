

# Document History for Developer Guide
<a name="doc-history"></a>

**Latest documentation update**: November 19, 2018

The following table describes the documentation release history of AWS Signer.

| Change | Description | Date | 
| --- |--- |--- |
| [Signer open source library now available](image-signing-prerequisites.md) | Adds a link to the Signer open source library. You now have the option of using the Signer binary or the open source library. | July 24, 2024 | 
| [Added caveat about image verification in AWS GovCloud (US) Region](image-verification.md) | To verify images signed using a signing profile created in an AWS GovCloud (US) Region, you must set `signingAuthority` to `aws-us-gov-signer-ts` in your trust policy. | March 13, 2024 | 
| [Added support for container image signing.](#doc-history) | Introduced code signing for container images stored in an Open Container Initiative (OCI) compliant container registry such as Amazon ECR. | June 22, 2023 | 
| [Added configuration steps using the console.](#doc-history) | Introduced AWS Code Signer Console for Lambda applications. | May 8, 2020 | 
| [Added new content](#doc-history) | Integrated AWS Signer with AWS IoT Device Management. | November 8, 2018 | 
| [Launched AWS Signer](#doc-history) | This release introduces AWS Signer. | December 20, 2017 |
