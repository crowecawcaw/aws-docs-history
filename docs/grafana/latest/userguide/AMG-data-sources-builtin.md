# Connect to built-in data sources

The following data sources are supported in every Amazon Managed Grafana workspace.

For workspaces that support version 9 and newer, some of these data sources might not
be installed by default. The core data sources are available on all installations, but
the data sources that are not part of the core set might need the correct Grafana plugin
to be installed. You can install plugins for additional data sources that aren't listed
here. For more information about managing plugins, see [Extend your workspace with plugins](grafana-plugins.md "grafana-plugins.md").
