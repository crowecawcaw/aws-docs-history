# Inspect Variables

The variables page lets you easily identify whether a variable is being
referenced (or used) in other variables or dashboard.

Any variable that is referenced or used has a green check mark next to it,
while unreferenced variables have an orange caution icon next to them. In
addition, all referenced variables have a dependency icon next to the green
check mark. You can select the icon to view the dependency map. The dependency
map can be moved. You can zoom in or out with the mouse wheel or
equivalent.
