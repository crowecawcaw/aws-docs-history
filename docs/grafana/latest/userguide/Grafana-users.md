# Users

In Amazon Managed Grafana, you don't add users in the Grafana workspace. Instead, you use IAM Identity Center or
and identity provider to authenticate users, and then grant users access to Amazon Managed Grafana
workspaces from within the Amazon Managed Grafana console. For more information, see [Manage user and group access to
Amazon Managed Grafana workspaces](AMG-manage-users-and-groups-AMG.md "AMG-manage-users-and-groups-AMG.md").
