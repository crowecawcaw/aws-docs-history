# Manually adding the Prometheus data

source

###### To manually add the Prometheus data source

1. In the Grafana console side menu, pause on the **Administration** menu item (or the **Configuration** (gear) icon in Grafana v8), then choose
   **Data Sources**.
2. Choose **Add data source**.
3. Choose the **Prometheus** data source. If necessary,
   you can start typing `Prometheus` in the search box
   to help you find it.
