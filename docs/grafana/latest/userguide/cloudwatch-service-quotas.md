# Service quotas

AWS defines quotas, or limits, for resources, operations, and items in your
AWS account. Depending on the number of queries in your dashboard and the
number of users accessing the dashboard, you might reach the usage limits for
various CloudWatch and CloudWatch Logs resources. Note that quotas are defined per account and
per AWS Region. If you’re using multiple Regions or you have set up more than
one CloudWatch data source to query against multiple accounts, you must request a
quota increase for each account and each Region in which you reach the limit.

For more information, see [CloudWatch
service quotas](../../../AmazonCloudWatch/latest/monitoring/cloudwatch_limits.md "../../../AmazonCloudWatch/latest/monitoring/cloudwatch_limits.md").
