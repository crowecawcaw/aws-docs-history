

# Manually adding the Timestream data source
<a name="timestream-add-the-data-source"></a>

**To manually add the Timestream data source**

1.  In the Grafana console side menu, pause on the **Configuration** (gear) icon, then choose **Data Sources**.

1. Choose **Add data source**.

1. Choose the **Amazon Timestream** data source. If necessary, you can start typing **Timestream** in the search box to help you find it.
