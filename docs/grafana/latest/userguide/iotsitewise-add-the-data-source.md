# Manually adding the AWS IoT SiteWise

data source

###### To manually add the AWS IoT SiteWise data source

1. In the Grafana console side menu, pause on the **Configuration** (gear) icon, then choose **Data Sources**.
2. Choose **Add data source**.
3. Choose the **AWS IoT SiteWise** data source. If
   necessary, you can start typing `SiteWise` in the
   search box to help you find it.
