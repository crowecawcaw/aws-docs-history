# Manually adding the X-Ray data

source

###### To manually add the X-Ray data source

1. In the Grafana console side menu, pause on the **Configuration** (gear) icon, then choose **Data Sources**.
2. Choose **Add data source**.
3. Choose the **X-Ray** data source. If necessary, you
   can start typing `X-Ray` in the search box to help
   you find it.
