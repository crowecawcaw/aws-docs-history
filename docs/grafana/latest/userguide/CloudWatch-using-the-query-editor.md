# Using the query

editor

The CloudWatch data source in Amazon Managed Grafana provides a powerful query editor that allows
you to retrieve and analyze metrics and logs from various AWS services that
send data to CloudWatch. The query editor supports two distinct query modes: Metric
Search and CloudWatch Logs.

The query editor mode for metrics uses the CloudWatch API to find metrics uploaded
to CloudWatch. The mode for logs uses the CloudWatch Logs APIs to find log records. Each mode
has its own specialized query editor. You select which API you want to query
with by using the query mode switch at the top of the editor.
