# Using Grafana HTTP APIs

You can use Grafana HTTP APIs with Amazon Managed Grafana workspaces. The following sections
describe how to use the APIs, and then list which Grafana APIs are supported.

###### Note

Amazon Managed Grafana also provides AWS APIs for creating and managing workspaces. For more
information about the AWS APIs, see the [Amazon Managed Grafana API Reference](../APIReference/Welcome.md "../APIReference/Welcome.md").
