# How to compose in AWS Infrastructure Composer

This section covers the basics of using Infrastructure Composer from the [Infrastructure Composer console](using-composer-console.md "using-composer-console.md"),
[CloudFormation console mode](using-composer-console-cfn-mode.md "using-composer-console-cfn-mode.md"), and the [AWS Toolkit for Visual Studio Code](using-composer-ide.md "using-composer-ide.md").
More specifically, the topics in this section provide key details on how to compose an application with Infrastructure Composer, and includes details on additional features and shortcuts. There are a few variations in functionality between console and VS Code experiences,
and the topics in this section identifies and describes these variations where they occur.

After composing your application, you will be ready
to review [Deploy your Infrastructure Composer serverless application to the AWS Cloud](other-services-cfn.md "other-services-cfn.md") for information on deploying your application.
