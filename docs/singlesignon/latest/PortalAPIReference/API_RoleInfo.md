# RoleInfo

Provides information about the role that is assigned to the user.


## Contents





**accountId** 


The identifier of the AWS account assigned to the user.


Type: String


Required: No




**roleName** 


The friendly name of the role that is assigned to the user.


Type: String


Required: No
