tasks to control user access and session duration.

| Administrators can customize the landing page users see after<br>successfully authenticating through IAM Identity Center.  | [Set relay state for quick access to the<br>AWS Management Console](howtopermrelaystate.md "howtopermrelaystate.md")                  |
| Ensure users no longer have access to AWS resources when their<br>permissions are revoked.                                 | [Use a Deny policy to revoke<br>active user permissions](prereqs-revoking-user-permissions.md "prereqs-revoking-user-permissions.md") |
