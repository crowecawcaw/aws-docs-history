# IAM Identity Center console and API authorization

Existing IAM Identity Center console APIs support dual authorization, which allows you to maintain use of existing API operations when newer APIs are available. If you have existing instances of IAM Identity Center
that were created prior to November 15, 2023 and October 15th, 2020, you can use the following tables to
determine which API operations now map to newer API operations that were released after those
dates.

###### Topics

- [API actions after November 2023](#api-console-mapping-2023 "#api-console-mapping-2023")
- [API actions after October 2020](#api-console-mapping-2020 "#api-console-mapping-2020")

## API actions after November 2023

Instances of IAM Identity Center that were created before November 15, 2023 honor both old and new API
actions as long as there is no explicit deny on any of the actions. Instances created
after November 15, 2023 use [newer API
actions](../APIReference/API_Operations.md "../APIReference/API_Operations.md") for authorization in the IAM Identity Center console.
