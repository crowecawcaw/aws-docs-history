# AWS Migration Hub Automation

###### Note

The AWS Migration Hub Automation feature is in preview release. It is available in
US East (N. Virginia). To use this feature, you must set your AWS Region to US East (N. Virginia).
You must also set the AWS Migration Hub home Region to US East (N. Virginia). For instructions on how to
set the AWS Migration Hub home Region, see [Managing your AWS Migration Hub home Region](home-region.md "home-region.md").

This is pre-release documentation. Both the AWS Migration Hub Automation feature and the
documentation are subject to change.

AWS Migration Hub makes it possible to automate migration tasks. The core concept in this feature is
the automation unit, which is a discrete set of actions that run automatically when you run the
unit. Migration Hub provides a set of automation units, which are referred to as managed automation
units. In addition to those managed units, you can create your own custom automation units. The
topics in this section describe each of the managed automation units, as well as how to create
custom units, and how to run any kind of automation unit.
