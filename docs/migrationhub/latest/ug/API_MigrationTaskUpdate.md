# MigrationTaskUpdate

A migration-task progress update.

## Contents

**MigrationTaskState**

Task object encapsulating task information.

Type: [Task](API_Task.md "API_Task.md") object

Required: No

**UpdateDateTime**

The timestamp for the update.

Type: Timestamp

Required: No

**UpdateType**

The type of the update.

Type: String

Valid Values: `MIGRATION_TASK_STATE_UPDATED`

Required: No
