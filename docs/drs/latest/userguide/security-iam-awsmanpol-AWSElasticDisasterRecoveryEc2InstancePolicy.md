# AWS

managed policy: AWSElasticDisasterRecoveryEc2InstancePolicy

This policy allows installing and using the AWS Replication Agent, which is
used by AWS Elastic Disaster Recovery (AWS DRS) to recover source servers that run on EC2
(cross-Region, cross-AZ or cross-Account). An IAM role with this policy should be attached (as
an EC2 Instance Profile) to the EC2 Instances.

**Permissions details**

To view the policy permission details see [AWSElasticDisasterRecoveryEc2InstancePolicy](../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryEc2InstancePolicy.md "../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryEc2InstancePolicy.md") in the AWS Managed Policy Reference Guide.
