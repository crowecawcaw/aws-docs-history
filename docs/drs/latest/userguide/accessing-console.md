# Accessing the AWS Elastic Disaster Recovery Console

You can access AWS Elastic Disaster Recovery directly through the AWS Console or through the following links:

- Commercial AWS Regions: [https://console.aws.amazon.com/drs/home](https://console.aws.amazon.com/drs/home "https://console.aws.amazon.com/drs/home")
- AWS GovCloud Regions: [https://console.amazonaws-us-gov.com/drs/home](https://console.amazonaws-us-gov.com/drs/home "https://console.amazonaws-us-gov.com/drs/home")
