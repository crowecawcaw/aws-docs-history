# Amazon CloudWatch Metrics for DRS

The following are CloudWatch metrics for DRS:

- **TotalSourceServerCount**

* number of source
  servers

- **LagDuration**

* the age of the latest consistent
  snapshot, in seconds

- **Backlog**

* the amount of data yet to be synced, in
  bytes.

- **DurationSinceLastSuccessfulRecoveryLaunch**

* the
  amount of time that has passed since the last Drill or Recovery instance launch in
  seconds.

- **ElapsedReplicationDuration**

* the cumulative amount
  of time this server has been replicating for in seconds.
