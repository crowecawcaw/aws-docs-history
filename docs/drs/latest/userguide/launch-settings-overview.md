# AWS DRS launch settings

The launch settings are a set of instructions that determine how drill or recovery
instances are launched in AWS. They include two sections: general launch settings and
the EC2 launch template. These settings are created automatically every time you add a
source server to AWS Elastic Disaster Recovery. The launch settings can be modified at any time, even before
a specific source server has completed its initial sync.
