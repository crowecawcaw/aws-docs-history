# AWS managed policy:

AWSElasticDisasterRecoveryFailbackInstallationPolicy

You can attach the AWSElasticDisasterRecoveryFailbackInstallationPolicy policy to
your IAM identities.

This policy allows installing the AWS Elastic Disaster Recovery Failback Client, which is used to
failback Recovery Instances back to your original source infrastructure. Attach
this policy to your users or roles whose credentials you provide when running
the AWS Elastic Disaster Recovery Failback Client.

**Permissions details**

To view the policy permission details see [AWSElasticDisasterRecoveryFailbackInstallationPolicy](../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryFailbackInstallationPolicy.md "../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryFailbackInstallationPolicy.md") in the AWS Managed Policy Reference Guide.
