# Failback Client Version History

The following table describes the released versions of the AWS Elastic Disaster Recovery Failback Client. The latest version
of the Failback Client can be downloaded by following
[the failback instructions](failback-performing.md#failback-performing-performing "failback-performing.md#failback-performing-performing").

[What's in a Release?](drs-client-release-notes.md#client-release-notes-definition "drs-client-release-notes.md#client-release-notes-definition")
