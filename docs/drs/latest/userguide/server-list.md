# AWS DRS source servers page

The **Source servers** page lists all of the source servers
that were added to AWS Elastic Disaster Recovery. It allows you to manage your source servers and perform commands
for one or more servers, such as controlling replication and launching Initiate recovery job
instances. You are likely to interact with AWS Elastic Disaster Recovery predominantly through this page.
