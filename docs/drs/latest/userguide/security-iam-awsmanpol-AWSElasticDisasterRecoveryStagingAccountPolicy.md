# AWS

managed policy: AWSElasticDisasterRecoveryStagingAccountPolicy

This policy allows read-only access to AWS Elastic Disaster Recovery (AWS DRS) resources such as
source servers and jobs. It also allows creating a converted snapshot and
sharing that EBS snapshot with a specified account.

**Permissions details**

To view the policy permission details see [AWSElasticDisasterRecoveryStagingAccountPolicy](../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryStagingAccountPolicy.md "../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryStagingAccountPolicy.md") in the AWS Managed Policy Reference Guide.
