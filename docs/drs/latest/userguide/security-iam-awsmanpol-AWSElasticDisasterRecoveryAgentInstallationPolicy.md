# AWS managed policy:

AWSElasticDisasterRecoveryAgentInstallationPolicy

This policy allows installing the AWS Replication Agent, which is used with
AWS Elastic Disaster Recovery (AWS DRS) to recover external servers to AWS. Attach this policy to
your users or roles whose credentials you provide during the installation step
of the AWS Replication Agent.

**Permissions details**

To view the policy permission details see [AWSElasticDisasterRecoveryAgentInstallationPolicy](../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryAgentInstallationPolicy.md "../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryAgentInstallationPolicy.md") in the AWS Managed Policy Reference Guide.
