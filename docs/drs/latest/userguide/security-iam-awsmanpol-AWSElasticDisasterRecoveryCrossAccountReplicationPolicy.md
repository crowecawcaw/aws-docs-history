# AWS

managed policy: AWSElasticDisasterRecoveryCrossAccountReplicationPolicy

This policy allows AWS Elastic Disaster Recovery (DRS) to support cross-account replication and
cross-account failback.

**Permissions details**

To view the policy permission details see [AWSElasticDisasterRecoveryCrossAccountReplicationPolicy](../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryCrossAccountReplicationPolicy.md "../../../aws-managed-policy/latest/reference/AWSElasticDisasterRecoveryCrossAccountReplicationPolicy.md") in the AWS Managed Policy Reference Guide.
