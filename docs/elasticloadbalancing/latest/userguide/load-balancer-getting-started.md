# Getting started with ELB

ELB supports multiple load balancer types. You can select the type of load balancer
that best suits your needs.
For more information, see [ELB features](https://aws.amazon.com/elasticloadbalancing/features/ "https://aws.amazon.com/elasticloadbalancing/features/").

###### Load balancers

- [Create an Application Load Balancer](../application/create-application-load-balancer.md "../application/create-application-load-balancer.md")
- [Create a Network Load Balancer](../network/create-network-load-balancer.md "../network/create-network-load-balancer.md")
- [Create a Gateway Load Balancer](../gateway/create-load-balancer.md "../gateway/create-load-balancer.md")
  For demos of common load balancer configurations, see [ELB demos](https://exampleloadbalancer.com/ "https://exampleloadbalancer.com/").

If you have an existing Classic Load Balancer, you can migrate to an Application Load Balancer or a Network Load Balancer. For more information, see
[Migrate your Classic Load Balancer](migrate-classic-load-balancer.md "migrate-classic-load-balancer.md").
