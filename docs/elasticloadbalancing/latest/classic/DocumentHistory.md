# Document history for Classic Load Balancers

The following table describes the releases for Classic Load Balancers.

| Change                                                                                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Date               |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Bucket policies for access logs and connection logs                                       | Prior to this release, the bucket policy that you used depended on whether<br>the Region was available before or after August 2022. With this release,<br>the newer bucket policy is supported in all Regions. Note that the legacy<br>bucket policy is still supported.                                                                                                                                                                                                                                                                                                                                                                       | September 10, 2025 |
| Desync mitigation mode                                                                    | Added support for desync mitigation mode. For more information,<br>see [Configure desync mitigation mode for your Classic Load Balancer](config-desync-mitigation-mode.md "config-desync-mitigation-mode.md").                                                                                                                                                                                                                                                                                                                                                                                                                                 | August 17, 2020    |
| Classic Load Balancers                                                                    | With the introduction of Application Load Balancers and Network Load Balancers, load balancers created with<br>the 2016-06-01 API are now known as _Classic Load Balancers_. For more<br>information about the differences between these types of load balancers,<br>see [ELB features](https://aws.amazon.com/elasticloadbalancing/features/ "https://aws.amazon.com/elasticloadbalancing/features/") .                                                                                                                                                                                                                                       | August 11, 2016    |
| Support for AWS Certificate Manager (ACM)                                                 | You can request an SSL/TLS certificate from ACM and deploy it to your<br>load balancer. For information about the updated predefined SSL negotiation<br>configurations, see [SSL negotiation configurations for Classic Load Balancers](elb-ssl-security-policy.md "elb-ssl-security-policy.md").<br>For information about updating your current SSL negotiation configuration, see<br>[Update the SSL negotiation configuration of your Classic Load Balancer](ssl-config-update.md "ssl-config-update.md"). | February 19, 2014  |
