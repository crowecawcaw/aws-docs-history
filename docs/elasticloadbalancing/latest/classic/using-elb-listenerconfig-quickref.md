# Listener configurations for Classic Load Balancers

The following table describes possible configurations for HTTP and HTTPS listeners for a Classic Load Balancer.

| Use case                                                             | Front-end protocol | Front-end options                                                             | Back-end protocol | Back-end options        | Notes                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------- | ------------------ | ----------------------------------------------------------------------------- | ----------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Basic HTTP load balancer                                             | HTTP               | NA                                                                            | HTTP              | NA                      | • Supports the [X-Forwarded<br>headers](x-forwarded-headers.md#x-forwarded-for "x-forwarded-headers.md#x-forwarded-for")                                                                                                                                            |
| Secure website or application using ELB to offload SSL<br>decryption | HTTPS              | [SSL<br>negotiation](elb-ssl-security-policy.md "elb-ssl-security-policy.md") | HTTP              | NA                      | • Supports the [X-Forwarded<br>headers](x-forwarded-headers.md#x-forwarded-for "x-forwarded-headers.md#x-forwarded-for")<br>• Requires an [SSL<br>certificate](ssl-server-cert.md "ssl-server-cert.md") deployed on the load balancer                               |
| Secure website or application using end-to-end encryption            | HTTPS              | [SSL<br>negotiation](elb-ssl-security-policy.md "elb-ssl-security-policy.md") | HTTPS             | Back-end authentication | • Supports the [X-Forwarded<br>headers](x-forwarded-headers.md#x-forwarded-for "x-forwarded-headers.md#x-forwarded-for")<br>• Requires [SSL<br>certificates](ssl-server-cert.md "ssl-server-cert.md") deployed on the load balancer and<br>the registered instances |

The following table describes possible configurations for TCP and SSL listeners for a Classic Load Balancer.

| Use case                                                              | Front-end protocol | Front-end options                                                             | Back-end protocol | Back-end options        | Notes                                                                                                                                                                                                                                                   |
| --------------------------------------------------------------------- | ------------------ | ----------------------------------------------------------------------------- | ----------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Basic TCP load balancer                                               | TCP                | NA                                                                            | TCP               | NA                      | • Supports the [proxy<br>protocol header](enable-proxy-protocol.md "enable-proxy-protocol.md")                                                                                                                                                          |
| Secure website or application using ELB to offload SSL<br>decryption  | SSL                | [SSL<br>negotiation](elb-ssl-security-policy.md "elb-ssl-security-policy.md") | TCP               | NA                      | • Requires an [SSL<br>certificate](ssl-server-cert.md "ssl-server-cert.md") deployed on the load balancer<br>• Supports the [proxy<br>protocol header](enable-proxy-protocol.md "enable-proxy-protocol.md")                                             |
| Secure website or application using end-to-end encryption with<br>ELB | SSL                | [SSL<br>negotiation](elb-ssl-security-policy.md "elb-ssl-security-policy.md") | SSL               | Back-end authentication | • Requires [SSL<br>certificates](ssl-server-cert.md "ssl-server-cert.md") deployed on the load balancer and<br>the registered instances<br>• Does not insert SNI headers on back-end SSL<br>connections<br>• Does not support the proxy protocol header |
