

# Policy references
<a name="policies"></a>

 Reserving a session through the AWS Events API is subject to the same AWS event policies as any other reservation channel. The [AWS Event Terms and Conditions](https://aws.amazon.com/events/terms/) and the [AWS Code of Conduct](https://aws.amazon.com/codeofconduct/) govern your registration for and participation at an AWS event. For more information about reserved seating, see the [AWS re:Invent FAQ](https://aws.amazon.com/events/reinvent/faqs/).
