# Choosing a DLAMI

We offer a range of DLAMI options as mentioned in the [GPU DLAMI release notes](appendix-ami-release-notes.md#appendix-ami-release-notes-gpu "appendix-ami-release-notes.md#appendix-ami-release-notes-gpu"). To help you select the correct DLAMI for your use case,
we group images by the hardware type or functionality for which they were developed. Our
top level groupings are:

- **DLAMI Type:** Base, Single-Framework, Multi-Framework (Conda DLAMI)
- **Compute Architecture:** x86-based, Arm64-based [AWS Graviton](https://aws.amazon.com/ec2/graviton/ "https://aws.amazon.com/ec2/graviton/")
- **Processor Type:** [GPU](gpu.md "gpu.md"), [CPU](cpu.md "cpu.md"), [Inferentia](inferentia.md "inferentia.md"), [Trainium](trainium.md "trainium.md")
- **SDK:** [CUDA](https://developer.nvidia.com/cuda-toolkit "https://developer.nvidia.com/cuda-toolkit"), [AWS Neuron](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/neuron-intro/get-started.html "https://awsdocs-neuron.readthedocs-hosted.com/en/latest/neuron-intro/get-started.html")
- **OS:** Amazon Linux, Ubuntu
  The rest of the topics in this guide help further inform you and go into more details.
