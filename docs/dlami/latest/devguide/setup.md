# Setting up a DLAMI instance

After you [choose a DLAMI](choose-dlami.md "choose-dlami.md") and [choose an Amazon Elastic Compute Cloud (Amazon EC2) instance
type](instance-select.md "instance-select.md") that you want to use, then you're ready to set up your new DLAMI
instance.

If you haven't yet chosen a DLAMI and EC2 instance type, then see [Getting started with DLAMI](getting-started.md "getting-started.md").
