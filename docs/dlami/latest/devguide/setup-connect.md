# Connecting to a DLAMI instance

After you [launch a DLAMI instance](launch.md "launch.md") and the instance is
running, you can connect to it from a client (Windows, macOS, or Linux) using SSH. For
instructions, see [Connect to your Linux instance
using SSH](../../../AWSEC2/latest/UserGuide/AccessingInstances.md "../../../AWSEC2/latest/UserGuide/AccessingInstances.md") in the _Amazon EC2 User Guide_.

Keep a copy of the SSH login command handy in case you want to set up a Jupyter Notebook
server after you log in. To connect to the Jupyter webpage, you use a variation of that
command.
