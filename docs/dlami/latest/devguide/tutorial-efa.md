# Distributed training using Elastic Fabric Adapter

An [Elastic Fabric Adapter](https://aws.amazon.com/hpc/efa/ "https://aws.amazon.com/hpc/efa/") (EFA) is a network device that you can attach to your DLAMI
instance to accelerate High Performance Computing (HPC) applications. EFA enables you to achieve
the application performance of an on-premises HPC cluster, with the scalability, flexibility,
and elasticity provided by the AWS Cloud.

The following topics show you how to get started using EFA with the DLAMI.
