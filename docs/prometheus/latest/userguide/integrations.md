# Integrating with other AWS services

Amazon Managed Service for Prometheus integrates with other AWS services. This section describes integrating with
Amazon Elastic Kubernetes Service (Amazon EKS) cost monitoring (with Kubecost), and how to ingest metrics from CloudWatch
using Amazon Data Firehose. It also describes setting up and managing Amazon Managed Service for Prometheus with AWS Observability
Accelerator Terraform modules, or by using AWS Controllers for Kubernetes.
