# emr-spark-8.0.0-latest

Release label
Use `emr-spark-8.0.0-latest` as the `--release-label`
value in the [StartJobRun](../../../emr-on-eks/latest/APIReference/API_StartJobRun.md "../../../emr-on-eks/latest/APIReference/API_StartJobRun.md") API.

Release notes
`emr-spark-8.0.0-latest` currently points to
`emr-spark-8.0.0-20260421`.

Amazon EMR on EKS. For more information, see [Amazon EMR on EKS
service endpoints](service-quotas.md#service-endpoints "service-quotas.md#service-endpoints").
