The following error may occur when a job cannot start and the job waits in the SUBMITTED
state for 15 minutes. This can be caused by a lack of cluster resources.

| Error Message   | Error Condition                                                 | Recommended Next Step                                                                                                 |
| --------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| cluster timeout | The job has been in the SUBMITTED state for 15 minutes or more. | You can override the default setting of 15 minutes for this parameter with the<br>configuration override shown below. |

Use the following configuration to change the cluster timeout setting to 30 minutes.
Notice that you provide the new `job-start-timeout` value in seconds:

```
{
"configurationOverrides": {
  "applicationConfiguration": [{
      "classification": "emr-containers-defaults",
      "properties": {
          "job-start-timeout":"1800"
      }
  }]
}
```
