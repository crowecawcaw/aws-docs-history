# Run Amazon EMR Studio Workspace Workspace notebooks

programmatically

###### Note

Programmatic execution of notebooks isn't supported with Amazon EMR Serverless interactive
applications.

You can run your Amazon EMR Studio Workspace notebooks programmatically with a script
or on the AWS CLI. To learn how to run your notebook programmatically, see [Sample programmatic commands for EMR Notebooks](emr-managed-notebooks-headless.md "emr-managed-notebooks-headless.md").
