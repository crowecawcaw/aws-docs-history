# Configure trusted identity propagation with EMR on EC2

The prerequisites show you how to configure using either the AWS Console or the AWS CLI to create an IAM Identity Center instance and create users with the goal of setting up trusted identity propagation. Then you set up AWS Lake Formation to manage
permissions for your AWS Glue Data Catalog objects and Amazon Simple Storage Service data locations. Each section goes into detail, including showing how to register Amazon Simple Storage Service locations for
use with EMR and IAM Identity Center.
