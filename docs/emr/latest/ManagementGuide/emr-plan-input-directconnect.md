# Connect to data with

AWS Direct Connect from Amazon EMR

Direct Connect is a service you can use to establish a private dedicated network
connection to Amazon Web Services from your data center, office, or colocation
environment. If you have large amounts of input data, using Direct Connect may reduce your
network costs, increase bandwidth throughput, and provide a more consistent network
experience than Internet-based connections. For more information see the
[Direct Connect User Guide](../../../directconnect/latest/UserGuide.md "../../../directconnect/latest/UserGuide.md").
