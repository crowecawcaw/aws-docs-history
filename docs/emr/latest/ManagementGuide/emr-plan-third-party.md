# Drivers and third-party application integration on Amazon EMR

You can run several popular big-data applications on Amazon EMR with utility pricing. This
means you pay a nominal additional hourly fee for the third-party application while your
cluster is running. It allows you to use the application without having to purchase an
annual license. The following sections describe some of the tools you can use with
EMR.
