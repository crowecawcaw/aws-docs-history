

# Data handling for the Apache Spark agents

## How AWS uses your content
<a name="spark-agents-content-usage"></a>

AWS does not use any customer content for service improvement or model training. Customer content, including prompts, Spark logs, and generated responses, is used solely to provide the Apache Spark agents service.

## Service metadata stored for usage tracking and debugging
<a name="spark-agents-service-metadata"></a>

AWS stores the following service metadata for tracking service usage and debugging purposes:
+ Error stack traces
+ Spark logs and metrics
+ Analysis results and recommendations generated by the agents

All personally identifiable information (PII) is removed from this service metadata before storing.
