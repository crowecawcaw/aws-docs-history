

# AWS runtime for Apache Spark
<a name="emr-release-spark_8x"></a>

This section contains application versions, release notes, component versions, and configuration classifications available in each Amazon EMR Spark 8.x release version.

When you launch a cluster or application, you can choose from multiple releases of AWS runtime for Apache Spark. You specify the release number with the *release label*. Release labels are in the form `emr-spark-{{x.y.z}}`. For example, `emr-spark-8.0.0`.

For a comprehensive table of application versions in every Amazon EMR Spark 8.x release, see [Application versions in AWS runtime for Apache Spark releases](emr-release-app-versions-spark_8.x.md).
