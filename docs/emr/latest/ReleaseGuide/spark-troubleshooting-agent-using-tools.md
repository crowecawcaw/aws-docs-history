# Using Spark Troubleshooting Tools

## Available Troubleshooting Tools

The MCP service provides different tools for the Spark Troubleshooting Agent. The major tools are the following:

| Tool Name                 | Tool Category           | Description                                                         |
| ------------------------- | ----------------------- | ------------------------------------------------------------------- |
| analyze_spark_workload    | Root Cause Analysis     | Provides detailed troubleshooting for failed Apache Spark workloads |
| spark_code_recommendation | Code Fix Recommendation | Provides Apache Spark code recommendations for failed jobs          |
