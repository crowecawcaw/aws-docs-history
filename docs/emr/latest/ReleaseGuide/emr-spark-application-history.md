# View Spark application history

You can view Spark, YARN application, and Tez UI details using the
**Application user interfaces** tab of a cluster's detail page in
the console. Amazon EMR application user interfaces (UI) make it easier for you to
troubleshoot and analyze active jobs and job history.

For more information, see [View application
history](../ManagementGuide/emr-cluster-application-history.md "../ManagementGuide/emr-cluster-application-history.md") in the _Amazon EMR Management Guide_.
