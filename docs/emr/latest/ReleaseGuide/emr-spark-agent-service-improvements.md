# Data handling for Upgrade Agent

## How AWS uses your content

AWS does not use any customer content for service improvement or model training. Customer content, including prompts, code, and generated responses, is used solely to provide the Apache Spark Upgrade Agent service.

## Service metadata stored for usage tracking and debugging

AWS stores the following service metadata for tracking service usage and debugging purposes:

- Tool calls
- Error stack traces
- Code snippets processed by the Spark Upgrade Agent

All personally identifiable information (PII) is removed from this service metadata before storing.
