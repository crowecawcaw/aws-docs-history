# Migrating your Elastic Beanstalk Linux application to Amazon Linux 2023 or Amazon Linux 2

This section describes how to migrate your application using one of the following migration paths.

- Migrate from an _Amazon Linux 2_ platform branch to an _Amazon Linux 2023_ platform branch.
- Migrate from an _Amazon Linux AMI (AL1)_ platform branch to either an _Amazon Linux 2023_ (recommended) or an
  _Amazon Linux 2_ platform branch.
