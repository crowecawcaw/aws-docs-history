# Using the Elastic Beanstalk Docker platform branch

This section describes how to prepare your Docker image for launch with the either of the Elastic Beanstalk platform branches
_Docker running AL2 or AL2023_.

Follow the steps in [QuickStart for Docker](docker-quickstart.md "docker-quickstart.md") to create a Docker "Hello World" application and deploy it to an
Elastic Beanstalk environment using the EB CLI.
