# Node.js tools and resources

There are several places you can go to get additional help when developing your Node.js
applications:

| Resource                                                                                                                  | Description                                                                       |
| ------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| [GitHub](https://github.com/aws/aws-sdk-js "https://github.com/aws/aws-sdk-js")                                           | Install the AWS SDK for Node.js using GitHub.                                     |
| [AWS SDK for Node.js (Developer<br>Preview)](https://aws.amazon.com/sdkfornodejs/ "https://aws.amazon.com/sdkfornodejs/") | One-stop shop for sample code, documentation, tools, and additional<br>resources. |
