# **eb open**

## Description

Opens the public URL of your website in the default browser.

## Syntax

**eb open**

**eb open `environment-name`**

## Options

| Name                                                      | Description |
| --------------------------------------------------------- | ----------- |
| [Common options](eb3-cmd-options.md "eb3-cmd-options.md") |             |

## Output

The command **eb open** does not have output. Instead, it opens the application
in a browser window.
