# Configuring access logs

You can use [configuration files](ebextensions.md "ebextensions.md") to configure your environment's load balancer to upload access logs to an Amazon S3
bucket. See the following example configuration files on GitHub for instructions:

- `loadbalancer-accesslogs-existingbucket.config` – Configure the load balancer to upload access logs to an existing Amazon S3
  bucket.
- `loadbalancer-accesslogs-newbucket.config` – Configure the load balancer to upload access logs to a new bucket.
