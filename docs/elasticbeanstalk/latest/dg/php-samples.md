# Advanced examples for PHP in Elastic Beanstalk

To get started with PHP applications on AWS Elastic Beanstalk, you need an application [source bundle](applications-sourcebundle.md "applications-sourcebundle.md") to upload as your first application
version to deploy to an environment.

We recommend the [QuickStart for PHP](php-quickstart.md "php-quickstart.md") to get started with a simple PHP application deployed with the EB CLI.
