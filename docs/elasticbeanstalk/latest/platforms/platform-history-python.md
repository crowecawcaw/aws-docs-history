# Python platform history

This page lists the current and previous versions of AWS Elastic Beanstalk's Python platform branches and the dates that each version was current.
Previous platform versions remain accessible to accounts with active or terminated environments using them at the time they were superseded by a new version.

See the [Supported platforms](platforms-supported.md "platforms-supported.md") page for information on the latest version of each platform
supported by Elastic Beanstalk. Detailed release notes are available for recent releases at [AWS Elastic Beanstalk Release Notes](../relnotes.md "../relnotes.md").
