# Multicontainer Docker platform history

###### Note

On [July 18, 2022](../relnotes/release-2022-07-18-linux-al1-retire.md "../relnotes/release-2022-07-18-linux-al1-retire.md") Elastic Beanstalk set the
status of all platform branches based on Amazon Linux AMI (AL1) to **retired**.
For more information, see
[AL1 platform retirement FAQ](../dg/using-features.migration-al.md "../dg/using-features.migration-al.md") in the _AWS Elastic Beanstalk Developer Guide_.

This page lists previous versions of AWS Elastic Beanstalk's Multicontainer Docker platform branches and the dates that each version was current.
This platform
branch was marked as **retired** on July 18, 2022, along with all other platform branches based on Amazon Linux AMI (AL1).
Previous platform versions remain accessible to accounts with active or terminated environments using them at the time they were superseded by a new version.

For Multicontainer Docker platform versions that were current earlier than September 25, 2017, see [Docker platform earlier history](platform-history-docker-legacy.md "platform-history-docker-legacy.md").

See the [Supported platforms](platforms-supported.md "platforms-supported.md") page for information on the latest version of each platform
supported by Elastic Beanstalk. Detailed release notes are available for recent releases at [AWS Elastic Beanstalk Release Notes](../relnotes.md "../relnotes.md").
