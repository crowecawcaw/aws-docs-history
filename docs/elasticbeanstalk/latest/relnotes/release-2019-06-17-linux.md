# Release: Elastic Beanstalk Linux-based platform updates on June 17, 2019

This release provides new Linux-based platform versions for AWS Elastic Beanstalk. The release includes security updates.
It also includes Multicontainer Docker and PHP updates.

**Release date:** June 17, 2019
