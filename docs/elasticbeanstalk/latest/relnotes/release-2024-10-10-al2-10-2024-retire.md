# Release: Elastic Beanstalk Node.js 14 and 16, Ruby 2.7 and 3.0, PHP 8.0, Tomcat 8.5, and Python 3.7 Amazon Linux 2 platform branches retired on

October 10, 2024

This release announces the retirement of the following AL2 platform branches: Node.js 14, Node.js 16, Ruby 2.7, Ruby 3.0, PHP
8.0, Corretto 8 with Tomcat 8.5, Corretto 11 with Tomcat 8.5, and Python 3.7.

**Release date:** October 10, 2024

## Changes

Today we're announcing the retirement of the following AL2 platform branches:

- Corretto 8 with Tomcat 8.5 AL2
- Corretto 11 with Tomcat 8.5 AL2
- Node.js 14 AL2
- Node.js 16 AL2
- PHP 8.0 AL2
- Python 3.7 AL2
- Ruby 2.7 AL2
- Ruby 3.0 AL2

Elastic Beanstalk is retiring these platforms branches due to end of support by the maintainers of their language runtime components.

Elastic Beanstalk does not provide new maintenance updates for retired platform branches. If you currently use one of these retired platform branches, we strongly
recommend that you migrate to a current, fully supported version. For more information, see [Updating your Elastic Beanstalk environment's platform version](../dg/using-features.platform.md "../dg/using-features.platform.md") in the _AWS Elastic Beanstalk Developer Guide_.

For more information about platform retirement, see [Elastic Beanstalk platform support policy](../dg/platforms-support-policy.md "../dg/platforms-support-policy.md") in
the _AWS Elastic Beanstalk Developer Guide_.
