

# Release: Elastic Beanstalk Amazon Linux 2023 platform updates on October 8, 2026
<a name="release-2026-10-08-al2023"></a>

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2023. The release includes security updates. It also includes AMI, nginx, CloudWatch Agent, Docker, ECS based Docker, Corretto, Node.js, PHP, Python, and Ruby updates.

**Release date:** October 8, 2026

## Changes

**Note**  
Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that Elastic Beanstalk supports. It might take a few hours for the release to complete.
