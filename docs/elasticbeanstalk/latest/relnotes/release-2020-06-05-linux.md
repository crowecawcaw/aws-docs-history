# Release: Elastic Beanstalk Amazon Linux AMI platform updates on June 5, 2020

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux AMI. The release includes security updates.
It also includes Apache, Go, Java, PHP, and Python updates.

**Release date:** June 5, 2020

## Changes

The following table lists the changes included in this release.

###### Note

Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
Elastic Beanstalk supports. It might take a few hours for the release to complete.
