

# Release: Elastic Beanstalk Amazon Linux 2 platform updates on January 29, 2021
<a name="release-2021-01-29-al2"></a>

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2. The release includes security updates. It also includes AMI, Docker, Go, Corretto, Tomcat, .NET Core, Node.js, and Ruby updates.

**Release date:** January 29, 2021

**Note**
