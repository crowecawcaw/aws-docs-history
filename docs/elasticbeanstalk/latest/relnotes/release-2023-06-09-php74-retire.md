# Release: Elastic Beanstalk Amazon Linux 2 platform branch PHP 7.4 retired on

June 09, 2023

This release announces the retirement of the PHP 7.4 platform branch based on Amazon Linux 2.

**Release date:** June 09, 2023

## Changes

Today Elastic Beanstalk is announcing the retirement of the PHP 7.4 platform branch based on Amazon Linux 2, due to end of support by the owners of their language runtime
components.

Elastic Beanstalk does not provide new maintenance updates for retired platform branches. If you currently use this retired platform branch, we strongly
recommend that you migrate to a current, fully supported version. For more information, see [Updating your Elastic Beanstalk environment's platform version](../dg/using-features.platform.md "../dg/using-features.platform.md") in the _AWS Elastic Beanstalk Developer Guide_.

_The PHP 7.4 platform branch is now retired_. To reference this information along with other lists of retired components, see
[Retired platform branch
history](../dg/platforms-support-policy.md#platforms-support-policy.retired "../dg/platforms-support-policy.md#platforms-support-policy.retired") in the _AWS Elastic Beanstalk Developer Guide_.

For more information about platform retirement, see [Elastic Beanstalk platform support policy](../dg/platforms-support-policy.md "../dg/platforms-support-policy.md") in
the _AWS Elastic Beanstalk Developer Guide_.
