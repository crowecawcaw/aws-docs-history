# About AWS Elastic Beanstalk release notes

The Elastic Beanstalk release notes provide details about Elastic Beanstalk releases—new features, updates, and fixes related to the service, platform, console, and EB
CLI. Whenever we release any update, we publish release notes describing the content of the release.

Elastic Beanstalk has several types of regular releases:

- _Feature launches_—New functionality or updates to existing features.
- _Service updates_—Updates to the [Elastic Beanstalk API](../api.md "../api.md").
- _Platform updates_—Updates to [Elastic Beanstalk platforms](../dg/concepts-all-platforms.md "../dg/concepts-all-platforms.md"), which might update
  existing configurations or add new ones.
- _Client updates_—Updates to the [Elastic Beanstalk console](https://console.aws.amazon.com/elasticbeanstalk "https://console.aws.amazon.com/elasticbeanstalk") or the [EB CLI](../dg/eb-cli3.md "../dg/eb-cli3.md").
  For the list of release notes, see [AWS Elastic Beanstalk release notes](relnotes.md "relnotes.md").

For release notes predating this document, which were published elsewhere on the Amazon Web Services website, see [AWS Elastic Beanstalk Release Notes](https://aws.amazon.com/releasenotes/AWS-Elastic-Beanstalk/ "https://aws.amazon.com/releasenotes/AWS-Elastic-Beanstalk/") .
