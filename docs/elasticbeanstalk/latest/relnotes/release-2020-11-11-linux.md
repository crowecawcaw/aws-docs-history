# Release: Elastic Beanstalk Amazon Linux AMI platform updates on November 11, 2020

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux AMI. The release includes security updates.
It also includes Apache HTTP Server, Multicontainer Docker, Preconfigured Docker, Go, Tomcat, Node.js, PHP, Python, and Ruby updates.
Several language runtime, web server, and application server versions are reaching end of life with this release.

**Release date:** November 11, 2020

## Changes

As noted in the [Elastic Beanstalk platform support policy](../dg/health-enhanced.md "../dg/health-enhanced.md"), several language runtime, web server, and
application server versions have reached their end of life, as announced by their suppliers, and are therefore being retired with this release. We're
discontinuing some platform branches that were previously marked as retiring in the Preconfigured Docker, Tomcat, PHP, Python, and Ruby platforms. We're
also retiring the Apache HTTP Server version 2.2 in two current Tomcat platform branches, and older Node.js versions in the Amazon Linux AMI Node.js platform
branch. See the release tables for specific retired versions.

The following table lists the changes included in this release.

###### Note

Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
Elastic Beanstalk supports. It might take a few hours for the release to complete.
