

# Release: Elastic Beanstalk Windows Server 2016 platform branches retired on October 8, 2026
<a name="release-2026-10-08-windows-10-2026-retire"></a>

This release announces the retirement of the Windows Server 2016 with IIS 10.0 and Windows Server Core 2016 with IIS 10.0 platform branches.

**Release date:** October 8, 2026

## Changes
<a name="release-2026-10-08-windows-10-2026-retire.changes"></a>

Today we're announcing the retirement of the following Windows Server platform branches:
+ Windows Server 2016 with IIS 10.0
+ Windows Server Core 2016 with IIS 10.0

Elastic Beanstalk does not provide new maintenance updates for retired platform branches. If you currently use one of these retired platform branches, we strongly recommend that you migrate to a current, fully supported Windows Server platform branch. For a list of supported platform branches, see [.NET on Windows Server](https://docs.aws.amazon.com/elasticbeanstalk/latest/platforms/platforms-supported.html#platforms-supported.net) in the *AWS Elastic Beanstalk Platforms*.

For more information about platform retirement, see [Elastic Beanstalk platform support policy](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/platforms-support-policy.html) in the *AWS Elastic Beanstalk Developer Guide*.
