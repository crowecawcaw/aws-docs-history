# Release: Elastic Beanstalk Linux-based platform updates on February 21, 2019

This release provides new Linux-based platform versions for AWS Elastic Beanstalk. The release includes security updates.
It also includes Go, Node.js, and Ruby updates, and support for additional Amazon EC2 instance types in one AWS Region.

**Release date:** February 21, 2019
