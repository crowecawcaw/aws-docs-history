

# Release: Elastic Beanstalk Amazon Linux 2 platform updates on June 11, 2021
<a name="release-2021-06-11-al2"></a>

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2. The release includes security updates. It also includes AMI and Go updates.

**Release date:** June 11, 2021

## Changes
<a name="release-2021-06-11-al2.changes"></a>

The following table lists the changes included in this release.

**Note**  
Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that Elastic Beanstalk supports. It might take a few hours for the release to complete.
