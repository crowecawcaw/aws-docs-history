

# Release: Elastic Beanstalk Amazon Linux 2023 platform updates on May 19, 2026
<a name="release-2026-05-19-al2023"></a>

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2023. The release includes security updates. It also includes AMI, Docker, ECS based Docker, Go, Corretto, .NET, Node.js, PHP, Python, Ruby, and Tomcat updates.

**Release date:** May 19, 2026

## Changes
<a name="release-2026-05-19-al2023.changes"></a>

The following table lists the changes included in this release.

**Note**  
Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that Elastic Beanstalk supports. It might take a few hours for the release to complete.
