# Release: Elastic Beanstalk general availability of several Amazon Linux 2 platforms on April 8, 2020

AWS Elastic Beanstalk releases supported Amazon Linux 2 platform versions for the Docker, Amazon Corretto, and Python platforms.

**Release date:** April 8, 2020

## Changes

On November 25, 2019 we started a public beta program for Elastic Beanstalk platforms based on the Amazon Linux 2 operating system. Since then we've released beta Amazon Linux 2
platform versions for seven different platforms.

Today we released the first generally available, supported Amazon Linux 2 platform versions. We released versions of four new Amazon Linux 2 platform branches: one for
Docker, two for Amazon Corretto, and one for Python. We intend to release more supported Amazon Linux 2 platforms in the near future.

###### Note

Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
Elastic Beanstalk supports. It might take a few hours for the release to complete.
