# Release: Elastic Beanstalk introduces Tomcat on Amazon Linux 2 on June 3, 2020

This release introduces AWS Elastic Beanstalk Tomcat Amazon Linux 2 platform branches and
provides new versions for platforms based on Amazon Linux 2. The release includes security updates.
It also includes Go, Node.js, PHP, and Ruby updates, and brings back support for static files.

**Release date:** June 3, 2020

## Changes

The following table lists the changes included in this release.

###### Notes

- Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
  Elastic Beanstalk supports. It might take a few hours for the release to complete.
- _[June 4, 2020]_ We now added an updated Docker version. It was missing when we released this update on
  June 3, 2020.

The new Docker platform version has security updates published on or before June 3, 2020.
