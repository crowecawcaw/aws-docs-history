# Release: Elastic Beanstalk Amazon Linux 2 platform branches retired on August 6, 2026

This release announces the retirement of all remaining Amazon Linux 2 platform branches: Docker, ECS based Docker, Go 1, Corretto 8, Corretto 11, Corretto 17, Corretto 8 with Tomcat 9, Corretto 11 with Tomcat 9, and .NET Core.

**Release date:** August 6, 2026

## Changes

Today we're announcing the retirement of all remaining Amazon Linux 2 platform branches:

- .NET Core on AL2
- Corretto 8 AL2
- Corretto 8 with Tomcat 9 AL2
- Corretto 11 AL2
- Corretto 11 with Tomcat 9 AL2
- Corretto 17 AL2
- Docker AL2
- ECS AL2
- Go 1 AL2

Elastic Beanstalk is retiring these platform branches because Amazon Linux 2 has reached its End of Life (EOL) on June 30, 2026.

Elastic Beanstalk does not provide new maintenance updates for retired platform branches. If you currently use one of these retired platform branches, we strongly
recommend that you migrate to a current, fully supported AL2023 platform branch. For more information, see [Migrating your Elastic Beanstalk Linux application from Amazon Linux 2 to AL2023](../dg/using-features.migration-al.generic.from-al2.md "../dg/using-features.migration-al.generic.from-al2.md") in the
_AWS Elastic Beanstalk Developer Guide_.

For more information about platform retirement, see [Elastic Beanstalk platform support policy](../dg/platforms-support-policy.md "../dg/platforms-support-policy.md") in
the _AWS Elastic Beanstalk Developer Guide_.
