# Release: EB CLI 3.14.7 on December 5, 2018

The AWS Elastic Beanstalk Command Line Interface (EB CLI) has a new version with bug fixes and new functionality.

**Release date:** December 5, 2018

## Changes

Here is a list of the key changes in this release.

| **Change**                               | **Affected commands**                       | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Application Load Balancer by default** | **eb create**                               | When you create a load-balanced environment by using **eb create\*<br>• and don't specify the **--single*<br>• option, the EB<br>CLI now creates an Application Load Balancer by default. Previously, the default was a Classic Load Balancer.<br>In the interactive flow, the EB CLI now shows \*\*application*<br>• (option 2) as the default load balancer type. In the<br>non-interactive flow, the EB CLI defaults to Application Load Balancer unless you explicitly select a type by specifying the `--elb-type` option. For<br>more information, see [**eb create**](../dg/eb3-create.md "../dg/eb3-create.md") in the _AWS Elastic Beanstalk Developer<br>Guide_.<br>ImportantIf you have scripts that use the EB CLI to create an environment, the environment's source bundle might include configuration files that<br>assume a Classic Load Balancer. To keep using a Classic Load Balancer, be sure to add **--elb-type classic\*<br>• to the **eb create\*\*<br>command. |
| **Private IP address for SSH**           | **eb ssh**                                  | When a public IP address for your instance isn't found, the \*_eb ssh_<br>• command now uses a private IP address to connect to<br>the instance. Previously, a private DNS name was used in the same case. DNS resolution isn't always available (for example, when accessing<br>instances in VPCs in multiple AWS Regions through a single VPN). Using a private IP address should succeed more reliably.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Various bug fixes**                    | **eb create**<br>**eb init**<br>**eb tags** | Fixed several minor bugs that affected the correct behavior of some commands.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
