# Release: Elastic Beanstalk adds support for AWS Israel (Tel Aviv) Region on

August 4, 2023

AWS Elastic Beanstalk now supports the AWS Israel (Tel Aviv) Region

**Release date:** August 4, 2023

## Changes

Starting today, you can deploy and run applications orchestrated by AWS Elastic Beanstalk in the AWS
Israel (Tel Aviv) Region.

There is no additional charge for Elastic Beanstalk, as customers pay only for the AWS resources
needed to run their applications. Customers also retain full control over the AWS resources
powering their application. For more information, see [AWS Elastic Beanstalk Pricing.](https://aws.amazon.com/elasticbeanstalk/pricing "https://aws.amazon.com/elasticbeanstalk/pricing")

For more information about all of the Regions supported by Elastic Beanstalk, see [AWS Elastic Beanstalk endpoints and quotas](../../../general/latest/gr/elasticbeanstalk.md "../../../general/latest/gr/elasticbeanstalk.md") in the
_AWS General Reference_ guide.

For more general information about AWS Regions and services, see [AWS Service by
Region.](https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services "https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services")
