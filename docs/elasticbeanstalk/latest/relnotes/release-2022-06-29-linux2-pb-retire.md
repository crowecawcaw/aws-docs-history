

# Release: Elastic Beanstalk Amazon Linux 2 platform branches retired on June 29, 2022
<a name="release-2022-06-29-linux2-pb-retire"></a>

This release announces the retirement of several platform branches based on Amazon Linux 2.

**Release date:** June 29, 2022

## Changes
<a name="release-2022-06-29-linux2-pb-retire.changes"></a>

Today Elastic Beanstalk is announcing the retirement of several platform branches based on Amazon Linux 2, due to end of support by the owners of their language runtime components.

Elastic Beanstalk does not provide new maintenance updates for retired platform branches. If you currently use any of these retired platforms, we strongly recommend that you migrate from each one of them to a current, fully supported version. For more information, see [Updating your Elastic Beanstalk environment's platform version](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/using-features.platform.upgrade.html) in the *AWS Elastic Beanstalk Developer Guide*.

*The following platform branches are now retired*. To reference this information along with other lists of retired components, see [Retired platform branch history](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/platforms-support-policy.html#platforms-support-policy.retired) in the *AWS Elastic Beanstalk Developer Guide*.
+ Tomcat 7 with Corretto 11
+ Tomcat 7 with Corretto 8
+ Node.js 10
+ PHP 7.3
+ PHP 7.2
+ Ruby 2.5

For more information about platform retirement, see [Elastic Beanstalk platform support policy](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/platforms-support-policy.html) in the *AWS Elastic Beanstalk Developer Guide*.
