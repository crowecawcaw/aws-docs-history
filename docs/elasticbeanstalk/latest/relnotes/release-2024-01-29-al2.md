# Release: Elastic Beanstalk Amazon Linux 2 new platform release and updates on January 29, 2024

Elastic Beanstalk releases a new Amazon Linux 2 platform branch for the Tomcat platform.
This release includes updates for

Docker,
ECS based Docker,
Go,
Corretto,
Tomcat,
.NET Core,

Python,
and Ruby AL2 platforms.
This release also provides Puma updates, AMI updates, and security updates.

**Release date:** January 29, 2024

## Changes

The following table lists the changes included in this release.

###### Notes

- These release notes focus on changes to currently supported platform branches. For full version information of Elastic Beanstalk retiring (deprecated)
  platform branches, see [Elastic Beanstalk platform versions scheduled for retirement](../platforms/platforms-retiring.md "../platforms/platforms-retiring.md") in the
  _AWS Elastic Beanstalk Platforms_ guide.
- Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
  Elastic Beanstalk supports. It might take a few hours for the release to complete.

The configuration results in the use of Docker’s built-in log rotation mechanism to prevent issues and redundancies with the logs. <br>• This update causes a behavior change with the log publication to S3 functionality that's controlled by the `LogPublicationControl` option of the [`aws:elasticbeanstalk:hostmanager`](../dg/command-options-general.md#command-options-general-elasticbeanstalkhostmanager "../dg/command-options-general.md#command-options-general-elasticbeanstalkhostmanager") namespace. With the update introduced in this release, the rotated log files in the `/var/lib/docker/containers` directory will no longer be published to S3 buckets; however, rotated log files in the /`var/log/eb-docker/containers/eb-current-app` directory will continue to be published. |
