

# Release: Elastic Beanstalk API updates on August 5, 2024
<a name="release-2024-08-05-al2023"></a>

This release provides a bug fix for the AWS Elastic Beanstalk API.

**Release date:** August 5, 2024

## Changes
<a name="release-2024-08-05-al2023.changes"></a>

Here is a list of the key changes in this release.


| **Change** | **Affected API** | **Description** | 
| --- | --- | --- | 
| **Bug fix** |  [ApplicationVersionLifecycleConfig](https://docs.aws.amazon.com/elasticbeanstalk/latest/api/API_ApplicationVersionLifecycleConfig.html) data type  | *Bug:* The [MaxAgeRule](https://docs.aws.amazon.com/elasticbeanstalk/latest/api/API_MaxAgeRule.html) parameter was incorrectly determining that some application versions were ineligible for deletion.<br />*Fix:* The issue has been fixed and `MaxAgeRule` now functions as documented. |
