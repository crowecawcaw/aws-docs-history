# Release: Elastic Beanstalk API updates on August 5, 2024

This release provides a bug fix for the AWS Elastic Beanstalk API.

**Release date:** August 5, 2024

## Changes

Here is a list of the key changes in this release.

| **Change**  | **Affected API**                                                                                                                                 | **Description**                                                                                                                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Bug fix** | [ApplicationVersionLifecycleConfig](../api/API_ApplicationVersionLifecycleConfig.md "../api/API_ApplicationVersionLifecycleConfig.md") data type | *Bug:<br>• The [MaxAgeRule](../api/API_MaxAgeRule.md "../api/API_MaxAgeRule.md") parameter was incorrectly determining that some application versions were ineligible for deletion.<br>*Fix:<br>• The issue has been fixed and `MaxAgeRule` now functions as documented. |
