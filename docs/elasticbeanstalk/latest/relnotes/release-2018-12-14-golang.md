# Release: AWS Elastic Beanstalk Go platform update on December 14, 2018

This release applies security updates to the Go platform for AWS Elastic Beanstalk, and updates platform configuration.
The release also includes a Go runtime update, bug fixes, and, for certain AWS Regions, support for additional Amazon EC2 instance types.

**Release date:** December 14, 2018
