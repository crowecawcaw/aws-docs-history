# Release: Elastic Beanstalk Amazon Linux AMI platforms are retired on

July 18, 2022

This release announces the retirement of all Elastic Beanstalk platforms based on Amazon Linux AMI (AL1).

**Release date:** July 18, 2022

## Changes

Today Elastic Beanstalk is announcing the retirement of all our platform branches based on Amazon Linux AMI
(AL1).

Now that all AL1 based platform branches are retired, Elastic Beanstalk will stop providing new
maintenance updates for them. In order for customers to continue to benefit from the latest
security and features going forward, it's critical to migrate to our Amazon Linux 2 based platforms.
For more information, see [Migrating your Elastic Beanstalk Linux
application to Amazon Linux 2](../dg/using-features.md "../dg/using-features.md") in the _AWS Elastic Beanstalk Developer Guide_.

The following list provides all of the platform branches based on Amazon Linux AMI (AL1). _All of these platform branches are now retired_.
To reference this information along with lists of other retired components, see [Retired platform branch history](../dg/platforms-support-policy.md#platforms-support-policy.retired "../dg/platforms-support-policy.md#platforms-support-policy.retired") in the
_AWS Elastic Beanstalk Developer Guide_.

- Multicontainer Docker
- Preconfigured Docker - GlassFish 5.0 with Java 8
