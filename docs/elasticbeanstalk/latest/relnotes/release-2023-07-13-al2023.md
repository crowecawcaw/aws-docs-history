# Release: Elastic Beanstalk launches Amazon Linux 2023 Tomcat platform on

July 13, 2023

Elastic Beanstalk releases a new Corretto 17 Tomcat platform branch based on Amazon Linux 2023 (AL2023).

**Release date:** July 13, 2023

## Changes

Today we’re releasing another new Elastic Beanstalk platform based on Amazon Linux 2023. This release adds
a new Tomcat platform branch that runs on AL2023. We're also working on releasing support
for AL2023 to more platforms.

For more information, see [Elastic Beanstalk Linux platforms](../dg/platforms-linux.md "../dg/platforms-linux.md") in the
_AWS Elastic Beanstalk Developer Guide_.

For more information about Amazon Linux 2023, see [Comparing Amazon Linux 2 and Amazon Linux
2023](../../../linux/al2023/ug/compare-with-al2.md "../../../linux/al2023/ug/compare-with-al2.md") in the _Amazon Linux 2023 User Guide_.
