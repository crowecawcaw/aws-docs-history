# Release: Elastic Beanstalk Linux-based platform updates on September 6, 2019

This release provides new Linux-based platform versions for AWS Elastic Beanstalk. The release includes security updates.
It also includes Multicontainer Docker, Go, Java, Node.js, and Ruby updates.

**Release date:** September 6, 2019
