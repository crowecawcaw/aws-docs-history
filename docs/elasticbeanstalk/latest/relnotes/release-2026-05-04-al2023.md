# Release: Elastic Beanstalk Amazon Linux 2023 platform updates on May 4, 2026

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2023. The release includes security updates. It also includes AMI, Docker, ECS based Docker, Go, Corretto, .NET, Node.js, PHP, Python, Ruby, and Tomcat updates. AI-powered log analysis now uses Amazon Nova as a fallback model for improved reliability.

**Release date:** May 4, 2026

## Changes

The following table lists the changes included in this release.

###### Note

Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that
Elastic Beanstalk supports. It might take a few hours for the release to complete.
