# Release: Elastic Beanstalk Linux-based platform updates on August 8, 2019

This release provides new Linux-based platform versions for AWS Elastic Beanstalk. The release includes security updates.
It also includes Go and Java 8 updates and an AWS X-Ray update.

**Release date:** August 8, 2019
