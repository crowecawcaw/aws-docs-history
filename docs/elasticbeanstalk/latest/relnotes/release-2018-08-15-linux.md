# Release: Elastic Beanstalk platform updates for Linux-based platforms on August 15, 2018

This release applies security updates to Linux-based platforms for AWS Elastic Beanstalk, and updates platform configurations.
The release also adds a new PHP configuration and, for certain AWS Regions, support for additional Amazon EC2 instance types.

**Release date:** August 15, 2018
