

# Release: EB CLI becomes open source on January 15, 2020
<a name="release-2020-01-15-ebcli-opensource"></a>

The AWS Elastic Beanstalk Command Line Interface (EB CLI) is now an open-source project hosted on GitHub.

**Release date:** January 15, 2020

## Changes
<a name="release-2020-01-15-ebcli-opensource.changes"></a>

Today we published the source code for the EB CLI on GitHub, making the CLI an open-source project. You're welcome to participate by reporting issues, making suggestions, and submitting pull requests. We value your contributions\! You can find the EB CLI source code in the `[aws/aws-elastic-beanstalk-cli](https://github.com/aws/aws-elastic-beanstalk-cli)` GitHub repository.

For more information about the EB CLI, see [Using the Elastic Beanstalk Command Line Interface (EB CLI)](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/eb-cli3.html) in the *AWS Elastic Beanstalk Developer Guide*.
