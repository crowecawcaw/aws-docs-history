# AWS IoT Analytics end of support

After careful consideration, we decided to end support for AWS IoT Analytics, effective December 15, 2025. AWS IoT Analytics will
no longer accept new customers beginning July 24, 2024. As an existing customer with an account signed up for the service before July 23, 2024, you can continue
to use AWS IoT Analytics features. After December 15, 2025, you will no longer be able to use AWS IoT Analytics.

As AWS IoT Analytics approaches end-of-service on December 15, 2025, it's important for customers to understand their migration options.
This page provides an overview of the key features of AWS IoT Analytics and maps them to alternative AWS services that are used
to replicate the functionality. By understanding the capabilities of these alternate services,
customers can plan and execute a smooth migration, ensuring their AWS IoT data analytics workflows continue uninterrupted.
