On December 15, 2025, AWS will end support for AWS IoT Analytics. After December 15, 2025, you will no longer

For more information, see
[AWS IoT Analytics end of support](iotanalytics-end-of-support.md "iotanalytics-end-of-support.md").

# AWS IoT Analytics quotas

The _AWS General Reference Guide_ provides the default quotas for AWS IoT Analytics for an AWS account. Unless
specified, each quota is per AWS Region. For more information,
see [AWS IoT Analytics endpoints and quotas](../../../general/latest/gr/iot-analytics.md "../../../general/latest/gr/iot-analytics.md")
and [AWS service quotas](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md")
in the _AWS General Reference Guide_.

To request a service quota increase, submit a support case in the [Support center](https://console.aws.amazon.com/support/cases#/create?issueType=service-limit-increase&limitType=service-code-iot "https://console.aws.amazon.com/support/cases#/create?issueType=service-limit-increase&limitType=service-code-iot") console. For more information, see [Requesting a quota increase](../../../servicequotas/latest/userguide/request-quota-increase.md "../../../servicequotas/latest/userguide/request-quota-increase.md") in
the _Service Quotas User Guide_.
