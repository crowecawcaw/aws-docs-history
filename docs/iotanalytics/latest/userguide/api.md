# AWS IoT Analytics commands

Read this topic to learn about the API operations for AWS IoT Analytics, including sample requests,
responses, and errors for the supported web services protocols.

## AWS IoT Analytics actions

You can use AWS IoT Analytics API commands to collect, process, store, and analyze your IoT data. For more information,
see the [actions](../APIReference/API_Operations.md "../APIReference/API_Operations.md") that are supported
by AWS IoT Analytics in the _AWS IoT Analytics API Reference_.

The [AWS IoT Analytics sections](../../../cli/latest/reference/iotanalytics/index.md "../../../cli/latest/reference/iotanalytics/index.md") in the _AWS CLI Command Reference_
include the AWS CLI commands that you can use to administer and manipulate AWS IoT Analytics.

## AWS IoT Analytics data

You can use the AWS IoT Analytics Data API commands to perform advanced activities with AWS IoT Analytics `channel`,
`pipeline`, `datastore`, and `dataset`. For more information, see the [data
types](../../../iotevents/latest/apireference/API_Types.md "../../../iotevents/latest/apireference/API_Types.md") that are supported by AWS IoT Analytics Data in the _AWS IoT Analytics API
Reference_.
