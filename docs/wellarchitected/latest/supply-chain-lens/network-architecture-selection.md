# Network architecture selection

| SCPERF04: How do you select your network<br>architecture for supply chain application? |
| -------------------------------------------------------------------------------------- |
|                                                                                        |

Proximity to data sources, both internal and external, and the
distance between components can be a key factor for supply chain
workloads, like high-frequency supplier networking and
manufacturing systems from factory floors, so make use of AWS
services to sit your solution as close as possible to
dependencies.
