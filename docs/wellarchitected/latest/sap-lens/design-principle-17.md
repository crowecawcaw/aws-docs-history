# 17 – Evaluate SAP architecture patterns for cost

efficiency

**How do you incorporate cost considerations into the evaluation of SAP
architecture patterns?** Ensure that when there is a decision to be made on
architecture, that the cost implications are fully understood as part of design
considerations.

| ID        | Priority           | Best Practice                                                                            |
| --------- | ------------------ | ---------------------------------------------------------------------------------------- |
| ☐ BP 17.1 | Required           | Evaluate your use of SAP managed service offerings                                       |
| ☐ BP 17.2 | Required           | Evaluate the cost characteristics of your SAP application architecture pattern           |
| ☐ BP 17.3 | Required           | Understand business requirements to make cost optimized design decisions per environment |
| ☐ BP 17.4 | Highly Recommended | Review the size, granularity, and latest available EC2 instances for SAP components      |
| ☐ BP 17.5 | Highly Recommended | Consider using on-demand capacity to improve cost efficiency                             |
| ☐ BP 17.6 | Recommended        | Evaluate cost benefits and impact of shared services and solutions                       |
| ☐ BP 17.7 | Recommended        | Evaluate the cost benefits of automation                                                 |
