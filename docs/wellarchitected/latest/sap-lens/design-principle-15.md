# 15 – Evaluate tuning options for the operating system,

database, and SAP application

**How do you understand and weigh the effects of different tuning
options on your SAP system performance?** The great variance in performance
recommendations for different combinations of SAP software offerings, supported operating
systems and databases, and versions prohibit an exhaustive list of recommendations for
performance excellence in a single document. With that in mind, the following guidance
should be applicable to the majority of SAP use cases, and we will call out specific focus
areas where applicable.

| ID        | Priority           | Best Practice                                                        |
| --------- | ------------------ | -------------------------------------------------------------------- |

| ☐ BP 15.3 | Highly Recommended | Modify SAP parameters to align with hardware<br>selection            |
| ☐ BP 15.4 | Recommended        | Consider performance tuning for recovery and availability<br>options |
