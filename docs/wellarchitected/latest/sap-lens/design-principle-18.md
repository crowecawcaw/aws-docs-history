# 18 – Evaluate SAP compute resources for cost

efficiency

**How do you assess compute and storage options for your SAP
workloads?** When implementing or migrating SAP to AWS, you should select
cost-effective EC2 instances and storage solutions for the SAP workload to meet your cost
targets.

| ID        | Priority           | Best Practice                                                                     |
| --------- | ------------------ | --------------------------------------------------------------------------------- |
| ☐ BP 18.1 | Required           | Understand the payment and commitment options available for Amazon EC2            |
| ☐ BP 18.2 | Required           | Use cost as a key consideration for EC2 instance selection                        |
| ☐ BP 18.3 | Highly Recommended | Evaluate licensing impact and optimization options                                |
| ☐ BP 18.4 | Highly Recommended | Evaluate the cost impact of storage options based on the required characteristics |
