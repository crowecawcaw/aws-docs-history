# Definitions

| Term                                                              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Examples (if applicable)                                                  |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| SAP workload                                                      | A workload is a collection of SAP resources that delivers business value. In the<br>SAP context, this includes customer-facing components of SAP applications as well as SAP<br>backend processes. A workload might consist of a subset of resources in a single AWS<br>account or be a collection of resources spanning multiple AWS accounts.                                                                                                                                                                          |                                                                           |
| SAP product                                                       | A product of SAP, the enterprise software company that provides solutions for<br>business processes across all industries. Sometimes referred to as _SAP<br>solutions_.                                                                                                                                                                                                                                                                                                                                                  | SAP S/4HANA On-premise edition, Concur, Qualtrics                         |
| SAP system                                                        | A logical grouping of architecture (a set of things that work together as part of a<br>greater mechanism) that is typically characterized by an SAP System Identifier<br>(SID).                                                                                                                                                                                                                                                                                                                                          | Production ERP system                                                     |
| SAP System Identifier (SAP SID / DB SID)                          | A combination of letters and numbers used to uniquely identify an SAP<br>system.                                                                                                                                                                                                                                                                                                                                                                                                                                         | PRD, HDB, PR1                                                             |
| SAP environment                                                   | Integrated grouping of one or more SAP products or technology components. Are<br>linked to form a _path to production._                                                                                                                                                                                                                                                                                                                                                                                                  | Sandbox, Development, QA, Training, Test, Pre-Production, and Production. |
| SAP instance or host                                              | An instance is a copy of an Amazon Machine Image (AMI) running as a virtual server<br>in the AWS Cloud. In the SAP context, usually a compute instance in Amazon EC2<br>service.                                                                                                                                                                                                                                                                                                                                         |                                                                           |
| SAP technical component                                           | Administrative units that group together components of an SAP system running on an<br>instance or host. These are technical architecture building blocks of SAP<br>applications.                                                                                                                                                                                                                                                                                                                                         | Application Server (PAS or AAS), SAP HANA Database, Web Dispatcher        |
| Services (AWS services)                                           | Over 200 cloud services that are used in combinations tailored to business or<br>organizational needs. For information about many AWS services, see the<br>[Overview<br>of Amazon Web Services whitepaper](../../../whitepapers/latest/aws-overview/introduction.md "../../../whitepapers/latest/aws-overview/introduction.md").                                                                                                                                                                                         | Amazon EC2, Amazon S3, Amazon EFS                                         |
| SAP deployment / Deployment pattern                               | Used to described how SAP is deployed in reference to the options in SAP<br>Provisioning Tools (SUM, SWPM).                                                                                                                                                                                                                                                                                                                                                                                                              | Highly Available (HA), Distributed, Standalone                            |
| SAPS rating (referred to as \*SAPS<br>• in multiple<br>locations) | SAP Application Performance Standard (SAPS) – is a hardware-independent unit of<br>measurement that describes the performance of a system configuration in the SAP<br>environment. It is derived from the Sales and Distribution (SD) benchmark, where 100<br>SAPS is defined as 2,000 fully business processed order line items per hour. For<br>more information, see [SAP Standard Application Benchmarks](https://www.sap.com/about/benchmark/measuring.html "https://www.sap.com/about/benchmark/measuring.html") . | _The Amazon EC2 instance type `c5.large` provides 3,650 SAPS._            |
