# Select the correct resource type, size, and number

By selecting the best resource type, size, and number of
resources, you meet the technical requirements with the lowest
cost resource. Right-sizing activities takes into account all of
the resources of a workload, all of the attributes of each
individual resource, and the effort involved in the right-sizing
operation. Right-sizing can be an iterative process, initiated by
changes in usage patterns and external factors, such as AWS price
drops or new AWS resource types. Right-sizing can also be one-off
if the cost of the effort to right-size, outweighs the potential
savings over the life of the workload.
