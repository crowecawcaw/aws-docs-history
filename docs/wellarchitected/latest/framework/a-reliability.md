# Reliability

The Reliability pillar encompasses the ability of a workload to perform its intended
function correctly and consistently when it’s expected to. You can find prescriptive guidance on
implementation in the [Reliability Pillar whitepaper](../reliability-pillar/welcome.md "../reliability-pillar/welcome.md").
