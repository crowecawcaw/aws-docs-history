

# Release notes

 This page describes changes to the AWS Well-Architected Framework. For notification about updates to this documentation, you can subscribe to the RSS feed. 

## Framework update (11-16-2026)
<a name="fw-11-16-2026-update"></a>

For a detailed overview of the exact changes in each pillar, see [Announcing updates to the AWS Well-Architected Framework](https://aws.amazon.com/blogs/architecture/announcing-updates-to-the-aws-well-architected-framework-3/).

### Content consolidation
<a name="release-notes-consolidation"></a>

 The six individual pillar whitepapers have been consolidated into a single unified AWS Well-Architected Framework document. All pillar guidance is now accessible from one location, reducing navigation overhead and making cross-pillar relationships easier to identify. 

### Best practice overhaul
<a name="release-notes-best-practices"></a>

 We've updated nearly all best practices to a new standardized format and template. Most of our best practices have received new and up to date content, and all best practices have been refreshed or tweaked. 

### Cloud Foundations
<a name="release-notes-foundations"></a>

 Added [Cloud Foundations](cloud-foundations.md), which provides guidance on establishing the foundational capabilities needed before applying pillar-specific best practices. 

### Cloud Workloads
<a name="release-notes-workloads"></a>

 All workload-specific content has been consolidated under [Cloud Workloads](workloads.md), which provides guidance on best practices that can be continually evaluated and tracked in your AWS workloads. 

### Updated framework content
<a name="release-notes-architecture"></a>

 Updated the base framework content, including architecture definitions and foundational concepts. Added a new concepts section that introduces key terminology and mental models used throughout the framework.
