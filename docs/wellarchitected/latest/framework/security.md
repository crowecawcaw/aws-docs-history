# Security

The Security pillar encompasses the ability to protect data, systems, and assets to take
advantage of cloud technologies to improve your security.

The security pillar provides an overview of design principles, best practices, and
questions. You can find prescriptive guidance on implementation in the [Security Pillar whitepaper](../security-pillar/welcome.md "../security-pillar/welcome.md").
