# REL 8. How do you implement change?

Controlled changes are necessary to deploy new functionality, and to verify that the workloads and the operating
environment are running known software and can be patched or replaced in a predictable manner. If these changes are uncontrolled,
then it makes it difficult to predict the effect of these changes, or to address issues that arise because of them.
