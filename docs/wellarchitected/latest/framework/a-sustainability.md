# Sustainability

The Sustainability pillar includes understanding the impacts of the services used,
quantifying impacts through the entire workload lifecycle, and applying design principles and best
practices to reduce these impacts when building cloud workloads. You can
find prescriptive guidance on implementation in the [Sustainability Pillar whitepaper](../sustainability-pillar/sustainability-pillar.md "../sustainability-pillar/sustainability-pillar.md").
