

# Cloud Workloads

 Creating a software system is a lot like constructing a building. If the foundation is not solid, structural problems can undermine the integrity and function of the building. The same holds for the workloads you run in the cloud. If you neglect the six pillars of operational excellence, security, reliability, performance efficiency, cost optimization, and sustainability, it becomes hard to build a system that meets your expectations and requirements. Building these pillars into your architecture helps you produce stable, efficient systems, so you can focus on functional requirements. 

 The Well-Architected Framework is organized into two areas. [Cloud Foundations](cloud-foundations.md) (WA Cloud Foundations) covers the account- and organization-level decisions you make once, so that every workload inherits consistent security, cost governance, and observability. **Well-Architected Cloud Workloads** (WA Cloud Workloads) focuses on how you design, build, and operate each individual workload after your foundations are established. 

 Each pillar is organized into capabilities, or groupings of related best practices that share a common objective. *Capabilities* are the level at which you assess a workload, which gives you a practical way to find gaps and prioritize improvements. 


|  Pillar  |  Description  | 
| --- | --- | 
|  [Operational excellence](operational-excellence.md)  |  Run and evolve workloads, gain insight into how they behave, and continuously improve the processes and procedures that support them.  | 
|  [Security](security.md)  |  Protect data, systems, and assets, control who can access which resources under what conditions, and detect and respond to security events.  | 
|  [Reliability](reliability.md)  |  Make a workload perform its intended function correctly and consistently, and recover from failures with minimal impact.  | 
|  [Performance efficiency](performance-efficiency.md)  |  Use computing resources efficiently to meet requirements, and sustain that efficiency as demand changes and technologies evolve.  | 
|  [Cost optimization](cost-optimization.md)  |  Deliver business value at the lowest price point, and avoid or remove cost that no longer earns its place.  | 
|  [Sustainability](sustainability.md)  |  Reduce the energy and resources a workload consumes, and the downstream impact of running it.  |
