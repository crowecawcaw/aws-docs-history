# COST 5. How do you evaluate cost when you select services?

Amazon EC2, Amazon EBS, and Amazon S3 are building-block AWS services. Managed
services, such as Amazon RDS and Amazon DynamoDB, are higher level, or application level, AWS services. By
selecting the appropriate building blocks and managed services, you can optimize this
workload for cost. For example, using managed services, you can reduce or remove
much of your administrative and operational overhead, freeing you to work on
applications and business-related activities.
