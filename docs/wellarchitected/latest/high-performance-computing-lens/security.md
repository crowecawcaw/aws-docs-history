

# Security
<a name="security"></a>

 The security pillar encompasses the ability to protect data, systems, and assets by taking advantage of cloud technologies. The [AWS Well Architected Security Pillar](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/welcome.html) provides guidance to help you apply best practices, current recommendations in the design, delivery, and maintenance of secure AWS workloads. All of the Security Pillar best practices apply to HPC workloads with the following extensions.
