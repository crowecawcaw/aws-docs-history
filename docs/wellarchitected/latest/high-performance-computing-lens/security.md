# Security

The security pillar encompasses the ability to protect data,
systems, and assets by taking advantage of cloud technologies. The
[AWS Well Architected Security Pillar](../security-pillar/welcome.md "../security-pillar/welcome.md") provides guidance to help
you apply best practices, current recommendations in the design,
delivery, and maintenance of secure AWS workloads. All of the
Security Pillar best practices apply to HPC workloads with the
following extensions.
