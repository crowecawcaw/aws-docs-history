# Change management

| EUCREL07: How do you track changes and implement<br>reversible deployments in your change management process? |
| ------------------------------------------------------------------------------------------------------------- |
|                                                                                                               |

Maintain thorough documentation for changes in your Amazon WorkSpaces and WorkSpaces Applications environments.

| EUCREL08: How do you test andd verify changes in your<br>EUC environment before pushing to end users? |
| ----------------------------------------------------------------------------------------------------- |
|                                                                                                       |

Evaluate changes in a controlled environment before deploying
them in the production environment for Amazon WorkSpaces and
WorkSpaces Applications.

| EUCREL09: How do you test rollback plans in your EUC<br>change management process? |
| ---------------------------------------------------------------------------------- |
|                                                                                    |

Create rollback plans for changes in Amazon WorkSpaces and
WorkSpaces Applications, and test these procedures to maintain
continuous operations and facilitate timely recovery from
issues or failures.

| EUCREL10: How do you communicate and coordinate<br>changes with EUC environment stakeholders? |
| --------------------------------------------------------------------------------------------- |
|                                                                                               |

Notify stakeholders about changes, and coordinate with other
teams to support continuous operations for users in your EUC
environments.

| EUCREL11: How do you perform post-change assessments<br>in your EUC environment? |
| -------------------------------------------------------------------------------- |
|                                                                                  |

When you perform post-change evaluations in Amazon WorkSpaces
and WorkSpaces Applications, use metrics and user feedback to inform
future change management.
