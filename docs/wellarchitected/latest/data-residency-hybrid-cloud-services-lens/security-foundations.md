# Security foundations

| DRHCSEC01: Have you updated and validated<br>your control objectives to address data residency compliance<br>requirements? |
| -------------------------------------------------------------------------------------------------------------------------- |
|                                                                                                                            |

Based on your requirements and risks identified from your data
residency compliance requirements, update and validate the control
objectives and controls that apply to the workload. Ongoing
validation of control objectives and controls help you measure the
effectiveness of risk mitigation.

| DRHCSEC02: Does your account management<br>strategy separate workloads that have different data residency<br>requirements? |
| -------------------------------------------------------------------------------------------------------------------------- |
|                                                                                                                            |

Separating workloads at the AWS account level is recommended, as
it provides a strong separation boundary and simplifies the
implementation of preventative controls, such as Identity and
Access Management (IAM) policies and service control policies
(SCPs), as well as detective controls.
