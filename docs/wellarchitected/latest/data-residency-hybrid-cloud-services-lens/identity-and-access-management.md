# Identity and access management

| DRHCSEC03: Have you implemented controls<br>designed to enhance your digital sovereignty governance<br>posture? |
| --------------------------------------------------------------------------------------------------------------- |
|                                                                                                                 |

Digital sovereignty means control over digital assets. Data
residency is control over the location of your data.

| DRHCSEC04: How do you control access to<br>support data residency requirements? |
| ------------------------------------------------------------------------------- |
|                                                                                 |

While some least privilege review processes focus decisions on
access to actions and data, even more scrutiny is needed on
actions that can move data. This helps you reduce the risk of
non-compliance with data residency by restricting access using
the resources of policies.
