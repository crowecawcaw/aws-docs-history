# Compute selection

| GAMEPERF05: How do you select the appropriate compute<br>solution for your game? |
| -------------------------------------------------------------------------------- |
|                                                                                  |

Compute performance varies across instance sizes and families.
It is beneficial to use multiple compute options that are from
separate capacity pools. Develop a fleet composition strategy
that gives preference to performance but includes enough
diversity to avoid insufficient capacity errors.
