# Health monitoring

| GAMEOPS04: How do you monitor the health of the game? |
| ----------------------------------------------------- |
|                                                       |

Monitor game health by implementing comprehensive instrumentation
to detect and track player-impacting issues, including client-side
activity logging, backend service monitoring, and error reporting.
Use a combination of AWS tools like Amazon CloudWatch and AWS X-Ray, as well as third-party solutions, to help quickly identify
and resolve problems.
