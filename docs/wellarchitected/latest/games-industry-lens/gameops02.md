# Account structure

| GAMEOPS02: How do you structure your AWS accounts for<br>hosting your game environments? |
| ---------------------------------------------------------------------------------------- |
|                                                                                          |

Implement a multi-account strategy to isolate different game
environments and enhance security, operational efficiency, and
scalability. Use AWS Organizations to manage account
hierarchies, apply guardrails to accounts, and enforce tag
policies and tagging on deployed resources.
