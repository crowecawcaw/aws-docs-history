# Data management

| GAMEPERF06: How do you efficiently manage and analyze game<br>server logs and store different types of game data for<br>optimal performance? |
| -------------------------------------------------------------------------------------------------------------------------------------------- |
|                                                                                                                                              |

Games can have player data, game logs and server logs which should
be decoupled from each other where possible. Centralizing log
ingestion and lifecycle management can benefit your game teams by
providing insights into what's happening in game and on the
server.
