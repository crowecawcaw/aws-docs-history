# Load testing

| GAMEOPS05: What should you consider when load testing a<br>game? |
| ---------------------------------------------------------------- |
|                                                                  |

When load testing a game, consider the appropriate testing
stage, load-generating architecture, and testing framework to
effectively evaluate system performance and scalability. Choose
the right combination of timing (early development, sprints,
pre-production, or post-deployment), infrastructure (EC2, EKS,
Fargate, or Lambda), and testing tool (JMeter, Locust, Grafana
K6, or Gatling) to align with your game's unique characteristics
and development goals.
