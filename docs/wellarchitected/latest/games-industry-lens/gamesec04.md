# Access control

| GAMESEC04: How do you block unauthorized access to game content? |
| ---------------------------------------------------------------- |
|                                                                  |

Modern games include a significant amount of content, such as downloadable content (DLC),
which is an important aspect of player engagement and game monetization. Players expect an
ongoing stream of new characters, levels, and challenges, requiring game developers to keep up
with a constant demand for fresh content to retain players. The variety and the size of the
content can vary greatly depending on the type of the game and the device on which the game is
played. Regardless of a game's system, protect the game's content from unauthorized access.
