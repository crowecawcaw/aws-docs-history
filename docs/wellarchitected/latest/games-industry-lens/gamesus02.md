# Hardware and services

| GAMESUS02: How do you manage the use of compute resources<br>in your games backend? |
| ----------------------------------------------------------------------------------- |
|                                                                                     |

Studios should develop a compute strategy that uses a mix of
different compute types, managed services, and savings plan to
optimize your usage. You should also optimize how game servers and
backend services are packed on to compute instances to reduce the
number of unneeded resources.
