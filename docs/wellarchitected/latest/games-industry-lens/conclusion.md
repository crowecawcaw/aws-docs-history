# Conclusion

Games are designed to deliver entertainment experiences to a global
audience of players and have usage characteristics that are
typically unpredictable and variable. The Games Industry Lens
describes the common types of scenarios that typically comprise a
game architecture and provides a set of questions and best practices
to consider when you are building and operating games in the cloud.
By applying this framework to your game architecture, you can build
reliable, secure, efficient, and cost-effective games in the cloud.
