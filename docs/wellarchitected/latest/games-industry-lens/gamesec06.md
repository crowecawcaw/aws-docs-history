# Infrastructure protection

Refer to the Well-Architected Framework whitepaper for best practices in [infrastructure
protection](../security-pillar/infrastructure-protection.md "../security-pillar/infrastructure-protection.md") for security that apply to games workloads.

| GAMESEC06: How do you monitor and respond to infrastructure threats? |
| -------------------------------------------------------------------- |
|                                                                      |

Monitoring and responding to infrastructure threats is critical for game studios because
their infrastructure represents the backbone that supports millions of concurrent players,
processes real-money transactions, and stores valuable player data and proprietary game
content. It is essential for game studios to implement monitoring systems and incident
response processes that can preserve the integrity of both player experiences and business
operations.
