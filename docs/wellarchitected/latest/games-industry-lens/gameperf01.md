# Architecture selection

| GAMEPERF01: How do you select the appropriate hosting<br>option for your game servers? |
| -------------------------------------------------------------------------------------- |
|                                                                                        |

Selection of the appropriate hosting option for your game servers
is foundational to game server performance. Deciding to use EC2
instances, a container solution, or a fully managed service is one
of the first decisions to make when architecting for production.
Each hosting option will have varying capabilities and
considerations for performance tuning, scaling, operations and
integration.
