# Indicators for code review

Embed a lightweight, frictionless change review
process into the development lifecycle. This capability
enables separation of duties to be performed to ensure
multiple perspectives are involved in approving changes.

- [[DL.CR.1] Standardize coding practices](dl.cr.md "dl.cr.md")
- [[DL.CR.2] Perform peer review for code changes](dl.cr.md "dl.cr.md")
- [[DL.CR.3] Establish clear completion criteria for code tasks](dl.cr.md "dl.cr.md")
- [[DL.CR.4] Comprehensive code reviews with an emphasis on business logic](dl.cr.md "dl.cr.md")
- [[DL.CR.5] Foster a constructive and inclusive review culture](dl.cr.md "dl.cr.md")
- [[DL.CR.6] Initiate code reviews using pull requests](dl.cr.md "dl.cr.md")
