# Continuous delivery

Continuous delivery (CD) takes place after continuous integration (CI), where code
changes that pass the build validation are automatically deployed to other environments,
including production, with minimal human intervention. CD strives to ensure that new features,
fixes, and improvements are deployed in a fast and reliable manner, reducing lead times and
improving overall efficiency of the deployment process. By automating the delivery process
using CD, teams can focus on developing and refining code, while the system handles the
time-consuming and error-prone process of deploying changes to various environments.
