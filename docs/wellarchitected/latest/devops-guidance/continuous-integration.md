# Continuous integration

Continuous integration (CI) is a software development practice
where developers make regular, small alterations to the code and
integrate them into a releasable branch of the code
repository. The newly integrated code is autonomously built,
tested, and validated in a consistent and repeatable manner. CI
allows developers to receive feedback swiftly, identify
potential issues in the early stages of the development
lifecycle, and address them before they escalate in complexity
and cost.
