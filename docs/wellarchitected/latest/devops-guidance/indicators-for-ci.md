# Indicators for continuous integration

Regularly integrate small code changes
into a releasable branch, ensuring fast feedback and early
problem detection. Streamline builds and tests using automated
pipelines to reduce downstream problems and increasing code
quality.

- [[DL.CI.1] Integrate code changes regularly and frequently](dl.ci.md "dl.ci.md")
