# Cryptographic signing

Cryptographic signing in the development lifecycle authenticates
the origins and verifies the integrity of software components.
Through the use of digital signatures, it safeguards software
builds and deployments against unauthorized changes and
potential threats from malicious actors. By leveraging
cryptographic signing, you can establish a secure software
supply chain, improve transparency in the build and delivery
process, and reliably distribute verifiable software components
at scale.
