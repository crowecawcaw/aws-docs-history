# Local development

Local development concentrates on establishing development environments that mirror the
production setup as closely as possible, either on a local machine or in the cloud. The
primary goal is to allow developers to receive feedback as fast as possible in the development
lifecycle without impacting other team members or systems. Using development environments aids
in early error detection and the swift rectification of issues before they are introduced into
other environments. By adopting this capability, development teams can improve productivity,
reduce the time it takes to develop new features, and deliver higher-quality software.
