

# Event preparedness
<a name="smops03"></a>

Large-scale events involve sudden spikes in viewership that stress every component. Preparation before the event determines whether it delivers without degradation.

## Capability intent
<a name="smops03-intent"></a>
+ Capacity planning accounts for peak viewership across all workflow components.
+ Infrastructure is validated under peak load before the event through load testing.
+ Incident response procedures and war room operations are established before the event begins.
+ Specialized support is engaged for business-critical events.

## Common issues to watch for
<a name="smops03-issues"></a>
+ Capacity planned for the average case rather than the peak, with no headroom for spikes.
+ No pre-event load testing, so the first real test is the live audience.
+ War room procedures defined during the incident rather than before.
+ No engagement with specialized media support for high-value events.
