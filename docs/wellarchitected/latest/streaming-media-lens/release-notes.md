

# Release notes
<a name="release-notes"></a>

## Large-scale revamp (09-11-2026)
<a name="update-2026-09-11"></a>

This update includes a large-scale modernization of the Streaming Media Lens, including:
+  **Every best practice now has its own page:** All 57 best practices moved from inline sections to individual pages, each with substantially expanded content. 
+  **Every pillar now has its own page:** Pillar content moved out of the lens document into six per-pillar hub pages, each linking to the capabilities and best practices it owns. 
+  **New capability template applied to all 34 capabilities:** Every capability now includes Capability intent, Common issues to watch for, and Maturity levels. 
+  **Maturity model introduced:** Each capability is scored against a five-level rubric (Initial, Emerging, Defined, Proactive, Optimized) with concrete descriptions of what each level looks like, giving customers a way to self-assess and plan improvement. 
+  **Standardized best practice structure:** Every best practice follows the same template as our modern lenses. 
+  **Sustainability pillar fully fleshed out:** All ten sustainability best practices, previously short outlines, now have full best practice guidance. 
+  **Performance efficiency guidance rewritten:** All 13 performance efficiency best practices were restructured to the authoring directive, with deeper coverage of content-aware and per-title encoding, quality-defined variable bit rate trade-offs, packaging strategy against demand, and cache-hit-ratio economics for personalized manifests. 
+  **Cost optimization guidance enriched:** All seven cost optimization best practices were aligned to the guidance template with clearer trade-off framing and more prescriptive implementation steps.
