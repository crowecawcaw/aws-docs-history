

# Security
<a name="security"></a>

The security pillar covers protecting data, systems, and content in streaming media workloads. Streaming media often carries high-value licensed content delivered to large audiences or commercially sensitive material in enterprise settings. Security for these workloads includes identity and access management, detection, infrastructure protection, data protection, and incident response. You can find additional guidance in the [Security Pillar](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/welcome.html) whitepaper.
