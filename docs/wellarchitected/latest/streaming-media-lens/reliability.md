

# Reliability
<a name="reliability"></a>

The reliability pillar covers the ability of a streaming workflow to perform its intended function correctly and consistently. This includes operating, managing, and testing the workflow from content ingest through delivery to viewers. The probability of failure increases with the number of components, so streaming architectures are built to maintain the viewing experience when individual components fail or degrade.
