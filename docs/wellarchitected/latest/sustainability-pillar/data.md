# Data management

Implement data management practices to reduce the provisioned
storage required to support your workload, and the resources
required to use it. Understand your data, and use storage
technologies and configurations that best support the business
value of the data and how it’s used. Lifecycle data to more
efficient, less performant storage when requirements decrease, and
delete data that’s no longer required.
