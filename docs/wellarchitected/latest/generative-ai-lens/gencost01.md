# Model selection and cost optimization

| GENCOST01: How do you select the appropriate model to optimize costs? |
| --------------------------------------------------------------------- |
|                                                                       |

Foundation model costs vary greatly across the various foundation
model providers, model families and sizes, and model hosting
paradigms. It may be advantageous to evaluate cost as a factor
when selecting models. This question describes best practices to
achieving cost-aware model selection.
