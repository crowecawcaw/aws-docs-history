# MLREL-04: Use a data pipeline

Automate the processing, movement, and transformation of data
between different compute and storage services. This automation
enables data processing that is fault tolerant, repeatable, and
highly available.

## Implementation plan

- **Use Amazon SageMaker AI Data Wrangler** -
  [SageMaker AI
  Data Wrangler](https://aws.amazon.com/sagemaker/data-wrangler/ "https://aws.amazon.com/sagemaker/data-wrangler/") simplifies the preparation of machine
  learning data. It enables data selection, cleansing,
  exploration, and visualization using a single visual
  interface. After you’ve created a workflow, export it to a data pipeline to automate model deployment and management. Data
  pipelines provide an automated way to move and transform
  data in your ML workload. Manually moving and transforming
  data can lead to errors and inconsistencies.
