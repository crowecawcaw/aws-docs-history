# 2G

2G network deployments are still a source of connectivity for
global IoT deployments and are used widely in some legacy
device deployments. Many new LPWA radio modules still support
2G along with LTE-M and Narrowband-IoT to offer as close to
global coverage as possible, offering a single SKU solution
that is a more sustainable choice than building multiple SKUs.
Only choose 2G as a primary technology if there is no other
coverage type in the deployment area; otherwise leverage the
newer technologies for better power optimization features.
