# Conclusion

The AWS Well-Architected Framework provides architectural best
practices across the pillars for designing and operating reliable,
secure, efficient, and cost-effective systems for IoT applications.
The framework provides a set of questions that you can use to review
an existing or proposed IoT architecture, and also a set of AWS best
practices for each pillar. Using the framework in your architecture
helps you produce stable and efficient systems, which allows you to
focus on your functional requirements.
