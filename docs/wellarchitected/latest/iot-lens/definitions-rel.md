# Definitions

Reliability encompasses four focus areas:

1. [Foundations](foundations.md "foundations.md")
2. [Workload architecture](workload-architecture.md "workload-architecture.md")
3. [Change management](change-management.md "change-management.md")
4. [Failure management](failure-management.md "failure-management.md")

To achieve reliability, a system must have a well-planned
foundation and monitoring in place, with mechanisms for handling
changes in demand, requirements, and protecting your system from
high volumes of requests whether intentional or not. The system
should be designed to detect the failure and automatically
recover.
