# Key AWS services

The key AWS feature supporting cost optimization is cost
allocation tags, which help you to understand the costs of a
system. The following services and features are important in the
three areas of cost optimization:

- **Cost-effective resources**:
  [Amazon Kinesis](https://aws.amazon.com/kinesis/ "https://aws.amazon.com/kinesis/") and

[Amazon S3](https://aws.amazon.com/s3/ "https://aws.amazon.com/s3/")
are AWS services that enable you to process multiple IoT
messages in a single request in order to improve the cost
effectiveness of compute resources.

- **Managing demand and supplying
  resources**:
  [AWS IoT Core](https://aws.amazon.com/iot-core/ "https://aws.amazon.com/iot-core/") is a managed IoT service for managing
  connectivity, device security to the cloud, messaging routing,
  and device state.
- **Optimize over time**: The AWS IoT Blog section on the AWS website is a resource for learning
  about what is newly launched as part of AWS IoT.
