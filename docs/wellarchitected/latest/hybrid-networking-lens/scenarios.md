# Scenarios

In the digital world of today, most customers are establishing global presence. There is a
need to deploy resources within the cloud and connect to data centers or branch locations across
geographies. The following are common scenarios that influence the design and architecture of
your hybrid networking workloads using AWS services as examples with common scenarios. Each
scenario includes the common drivers for the design and a reference architecture.
