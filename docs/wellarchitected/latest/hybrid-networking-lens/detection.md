# Detection

Detection or detective controls can be used to identify a potential security threat or
incident. You can get detailed insights into your hybrid network performance and use that
information to detect misconfiguration or potential malicious activities and further optimize
your deployment.

| HNSEC03: How do you monitor and detect threats in a hybrid network<br>environment? |
| ---------------------------------------------------------------------------------- |
|                                                                                    |

Capturing and analyzing metrics in a hybrid networking environment is important to get
detailed insights into network performance and to detect misconfigurations or potential
malicious activity so issues can be addressed promptly. Analyzing metrics also aids further
optimization of the deployment.
