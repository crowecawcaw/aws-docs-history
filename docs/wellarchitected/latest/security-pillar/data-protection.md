# Data protection

Before architecting any workload, foundational practices that influence security should be
in place. For example, data classification provides a way to categorize data based on levels of
sensitivity, and encryption protects data by way of rendering it unintelligible to unauthorized
access. These methods are important because they support objectives such as preventing
mishandling or complying with regulatory obligations.

In AWS, there are a number of different approaches you can use when addressing data
protection. The following section describes how to use these approaches.
