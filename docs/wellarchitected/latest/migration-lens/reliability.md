# Reliability

The reliability pillar encompasses the ability of a workload to
perform its intended function correctly and consistently when it's
expected to. This includes the ability to operate and test the
workload through its total lifecycle. The reliability pillar
provides guidance to help you apply best practices, current
recommendations in the design, delivery, and maintenance for
implementing reliable workloads on AWS. This paper provides an
overview of best practices and questions. You can find prescriptive
guidance on implementation in the
[reliability
pillar whitepaper](../reliability-pillar/reliability.md "../reliability-pillar/reliability.md").

A reliable cloud migration strategy involves planning, risk
assessment and contingency measures to address potential
disruptions. Factors like data integrity, network stability, and
application availability play crucial roles in determining the
reliability of the migration process. Plan to migrate your workload
to AWS based on existing reliability requirements, during the
migration activities, and after the migration cut-over.
