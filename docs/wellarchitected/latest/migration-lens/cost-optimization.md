# Cost optimization

The cost optimization pillar includes the continual process of
refinement and improvement of a system over its entire lifecycle to
optimize cost. As part of their migration journey into the AWS Cloud, successful companies undergoing large scale migration and
modernization initiatives incorporate Cloud Financial Management
(CFM) principles to optimize cost. The AWS Migration Acceleration
Program (MAP) is a comprehensive and proven cloud migration program
that can help you accelerate your cloud migration and modernization
journey with an outcome-driven methodology.
