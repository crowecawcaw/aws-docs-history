# Compute and hardware

| TELCOPERF02: How do you select the appropriate compute solution for your telco<br>workloads? |
| -------------------------------------------------------------------------------------------- |
|                                                                                              |

The selection of compute resources must account for specific telecommunications needs
such as deterministic performance, ultra-low latency, hardware acceleration capabilities, and
support for specialized telecom protocols. This includes consideration of bare metal,
virtualized, and containerized environments, as well as specific instance types optimized for
telecom workloads like Network Function Virtualization (NFV) and Radio Access Network (RAN)
processing.
