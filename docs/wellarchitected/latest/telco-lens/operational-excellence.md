# Operational excellence

This section describes the operational excellence pillar for the AWS Well-Architected
Telco Lens. It provides AWS customers with a set of best practices and guidance on how
telecommunications service providers can achieve operational excellence in their AWS cloud
environments.

Operational excellence is a commitment to build software correctly while consistently
delivering a great customer experience. The operational excellence pillar contains best
practices for organizing your team, designing your workload, operating it at scale, and evolving
it over time.
