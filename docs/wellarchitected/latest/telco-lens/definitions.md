

# Definitions
<a name="definitions"></a>

 The following are common definitions used throughout the Telco Lens: 
+  **5G network:** The fifth generation of cellular network technology that provides significantly faster data speeds, lower latency, and higher capacity compared to previous 4G networks. 5G enables new use cases around the Internet of Things (IoT), augmented and virtual reality, autonomous vehicles, and more. 
+  **Network functions virtualization (NFV):** The concept of virtualizing network functions previously implemented in proprietary hardware, such as firewalls, load balancers, and routers. NFV allows these network functions to run on commercial off-the-shelf (COTS) hardware. 
+  **Software-defined networking (SDN):** The practice of decoupling the network control plane from the data forwarding plane, enabling dynamic, programmatic control of network behavior. SDN provides flexibility and agility in network management and service provisioning. 
+  **Edge computing:** The practice of processing data closer to the source of data generation, rather than in a centralized data center. Edge computing enables low-latency, high-bandwidth applications by reducing the distance data must travel. 
+  **Intelligent routing:** The use of advanced algorithms and real-time analytics to dynamically route network traffic based on factors like congestion, latency, security, and cost optimization. 
+  **Customer experience (CX) applications:** Telco applications and solutions that enable an exceptional customer experience, such as self-service portals, chatbots, service assurance dashboards, and customer engagement tools. 
+  **Cloud network function (CNF):** A network function designed and implemented to run within containers, using cloud technologies and microservices architecture. 
+  **Network function (NF):** A functional building block within a network infrastructure, which has well-defined external interfaces and well-defined functional behavior. 
+  **Virtual network function (VNF):** Software implementation of network functions that can be deployed on virtual machines. 
+  **Control plane:** The part of a network that carries signaling traffic and is responsible for routing. 
+  **User plane or data plane:** The part of a network that carries user traffic. 
+  **Stream Control Transmission Protocol (SCTP):** A transport layer protocol that provides message-oriented communication with features for telecommunications signaling. 
+  **Communication service providers (CSPs):** The network operators that build the networks according to the regulatory requirements and deliver telecommunication services to the users. 
+  **User equipment (UE):** The end-user device, such as a smartphone or IoT module, that connects to the mobile network. 
+  **Access and Mobility Management Function (AMF):** The 5G core network function that handles registration, connection, reachability, and mobility management for user equipment. 
+  **Session Management Function (SMF):** The 5G core network function that manages PDU sessions, including IP address allocation for user equipment, and controls the user plane function. 
+  **User Plane Function (UPF):** The 5G core network function that forwards and routes subscriber data traffic between the radio network and external data networks. 
+  **Protocol Data Unit (PDU) session:** A logical connection between user equipment and a data network that carries subscriber traffic through the 5G core. 
+  **Operations Support Systems (OSS) and Business Support Systems (BSS):** The systems operators use to run the network (OSS: provisioning, fault, and performance management) and the business (BSS: billing, charging, customer management). 
+  **IP Multimedia Subsystem (IMS):** A standardized framework for delivering IP-based multimedia and voice services, such as Voice over LTE, across telecommunications networks. 
+  **IP Address Management (IPAM):** The practice and tooling used to plan, track, and manage the IP address space used across a network. 
+  **Container Network Interface (CNI):** A specification and set of plugins for configuring network interfaces for containers, used by Kubernetes to attach pods to networks. 
+  **Operations, Administration, and Maintenance (OAM):** The processes and interfaces used to operate, monitor, and maintain network functions. 
+  **GPRS Tunneling Protocol (GTP):** A protocol used in mobile core networks, with a control-plane variant (GTP-C) for signaling and a user-plane variant (GTP-U) for carrying subscriber data. 
+  **Non-Access Stratum (NAS):** The protocol layer between user equipment and the core network that handles signaling such as registration and session management, independent of the radio access. 
+  **International Mobile Subscriber Identity (IMSI):** A unique identifier assigned to a subscriber on a mobile network. 
+  **Mobile Application Part (MAP):** An SS7-based signaling protocol used for mobility, roaming, and short-message services between mobile network elements. 
+  **Independent software vendor (ISV):** A company that develops and sells software, such as the network function software that operators deploy on cloud infrastructure. 
+  **Interactive Voice Response (IVR):** An automated telephony system that interacts with callers through voice and keypad input to route or service calls. 
+  **On-Demand Capacity Reservation (ODCR):** An AWS capability that reserves compute capacity for specific instance types in a specific Availability Zone, so capacity is available when a workload needs to scale. 
+  **Availability Zone (AZ):** One or more discrete data centers within an AWS Region, each with redundant power, networking, and connectivity, isolated from failures in other Availability Zones.
