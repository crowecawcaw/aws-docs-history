

# Performance baselining


|  TELCOOPS09: How do you verify accurate performance baseline measurements for capacity planning?  | 
| --- | 
| [TELCOOPS09-BP01 Implement Prometheus-based observability with Nitro network metrics for telco workload performance baselining](telcoops09-bp01.md) | 

 In cloud environments, particularly those with shared underlying infrastructure, accurately measuring performance baselines for telecommunication workloads can be challenging. The lack of visibility into resource utilization at the hardware level and potential variations in performance because of multi-tenancy can lead to inaccurate capacity planning. This question explores strategies for establishing reliable performance baselines in cloud environments to support effective capacity planning for telecommunication workloads.
