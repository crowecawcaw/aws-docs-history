# Infrastructure protection

| TELCOSEC02: How do you implement holistic security within your telco network to<br>avoid risks and provide integrity? |
| --------------------------------------------------------------------------------------------------------------------- |
|                                                                                                                       |

Telecom networks face diverse security threats, making it crucial for operators to
implement comprehensive end-to-end security measures to block unauthorized access, malicious
attacks, and data breaches while providing for confidentiality, integrity, and availability of
your network services and subscriber information.

- [TELCOSEC02-BP01 Use secure control plane protocols between the
  network functions (NF)](telcosec02-bp01.md "telcosec02-bp01.md")

  spoofed subscriber identities for signaling over the interfaces with access network](telcosec02-bp02.md "telcosec02-bp02.md")
- [TELCOSEC02-BP03 Segment and isolate telco network domains and
  slices](telcosec02-bp03.md "telcosec02-bp03.md")
