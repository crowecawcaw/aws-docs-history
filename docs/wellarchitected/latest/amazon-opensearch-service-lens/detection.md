# Detection

| AOSSEC02: How do you track and audit user and API access to your OpenSearch Service domains? |
| -------------------------------------------------------------------------------------------- |
|                                                                                              |

To protect the security and integrity of your data, it's essential to monitor and control access to your OpenSearch Service domains. This includes tracking and auditing access to prevent unauthorized changes or data breaches. Implement robust access controls and monitor usage patterns to quickly detect and respond to potential threats, securing your search infrastructure and sensitive data.
