# Foundations

| AOSREL01: How do you keep your OpenSearch<br>version up to date? |
| ---------------------------------------------------------------- |
|                                                                  |

OpenSearch Service consistently adds support for
community-maintained OpenSearch versions. It is recommended to
always upgrade to the latest available OpenSearch versions to
benefit from performance improvements, security upgrades, and bug
fixes.

  strategy](aosrel01-bp01.md "aosrel01-bp01.md")
