# Conclusion

The [AWS Well-Architected Framework](../framework/welcome.md "../framework/welcome.md") provides best practices across the six pillars for
designing and operating reliable, secure, efficient, and cost-effective systems in the cloud.
The framework provides a set of questions that allows you to review an existing or proposed
architecture. It also provides a set of AWS best practices for each pillar. Using the
framework in your architecture will help you produce stable and efficient systems, which allow
you to focus on your functional requirements.
