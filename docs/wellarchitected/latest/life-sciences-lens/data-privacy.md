# Data privacy

| LSSEC02: How do you determine and enforce data privacy requirements? |
| -------------------------------------------------------------------- |
|                                                                      |

Data privacy requirements vary across the globe. For example, in the US, the handling of
protected health information (PHI) is governed by [HIPAA](https://www.hhs.gov/hipaa/for-professionals/privacy/laws-regulations/index.html "https://www.hhs.gov/hipaa/for-professionals/privacy/laws-regulations/index.html"). In the EU, [GDPR](https://gdpr.eu/ "https://gdpr.eu/"), [Clinical Trial Regulations](https://www.ema.europa.eu/en/human-regulatory/research-development/clinical-trials/clinical-trials-regulation "https://www.ema.europa.eu/en/human-regulatory/research-development/clinical-trials/clinical-trials-regulation"), and others may apply.
