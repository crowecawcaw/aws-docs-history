# Conclusion

The Life Sciences Lens provides architectural best practices across the six pillars of the
AWS Well-Architected Framework for designing and operating reliable, secure, efficient, and
cost-effective systems in the cloud. The Framework provides a set of questions that allows you
to review an existing or proposed architecture. It also provides a set of AWS best practices
for each pillar. Using the Framework in your life sciences workloads assists you in producing
stable and efficient systems, which allows you to focus on your functional requirements.
