# System evaluation

| RAIER01: How will you evaluate the AI system against your release criteria? |
| --------------------------------------------------------------------------- |
|                                                                             |

Test system performance against the release criteria to determine
if benefits and risks are addressed. Consider double checking your
evaluations with evaluations by experts outside your team.
Identify steps to address each criterion that is not met,
modifying transparency solutions as appropriate. To reach a
release decision, establish a methodology for combining the
results for each release criterion.

- [RAIER01-BP01 Validate that release criteria still align with
