# Guiding

| RAIGT01: How will downstream stakeholders learn how to responsibly use the AI system (guiding)? |
| ----------------------------------------------------------------------------------------------- |
|                                                                                                 |

Provide downstream stakeholders with tailored documentation that
outlines potential benefits and risks of an AI system by
discussing its intended uses, limitations, and failure modes,
distributed via appropriate channels for each stakeholder group.
