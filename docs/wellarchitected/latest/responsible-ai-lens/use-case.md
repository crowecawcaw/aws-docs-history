# Use case

The AI use case is the problem you are solving with an AI system.
This focus area assists you to produce a high-level use case
description and a minimal description of the AI solution, including
system inputs, system outputs, and the type of AI solution
(traditional, generative, or agentic AI). Deeper dives into benefits
and risks come in the Benefits and Risk focus area. If you want to
design a system to handle multiple related use cases (for example,
to recognize faces of missing children or locate frames in a video
containing a specific actor), then you should consider applying this
framework to each use case independently. If you want to design a
general-purpose system (for example, to chat with anyone about
anything), then this framework is not appropriate.
