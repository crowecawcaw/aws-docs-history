# Dataset access and versioning

| RAIDP04: How will you manage dataset access and versioning? |
| ----------------------------------------------------------- |
|                                                             |

Reduce the risk of data manipulation by checking for data integrity and by providing the
minimal access necessary. Implement a taxonomy (for example, classified, confidential,
proprietary, and public) to classify data that interacts with your AI system. Align access
rights to the classification of each data source.
