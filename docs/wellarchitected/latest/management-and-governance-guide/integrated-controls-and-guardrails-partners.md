# Integrated controls partners

The M&G Guide recommends you consider the following questions
when choosing an AWS Partner solution for controls:

- Does it integrate with lifecycle events for AWS Control Tower?
- If controls are provided, are they updated on a regular basis?
- Does it support multiple AWS Regions?
- Can it be provisioned from an infrastructure as code template
  that is distributed from a service catalog?
- Does it integrate with an observability solution?
- Can changes be tracked automatically, or integrated to your
  service management tool?
