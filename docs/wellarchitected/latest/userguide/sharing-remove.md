# Delete shared access in

AWS Well-Architected Tool

You can delete a workload invitation. Deleting a workload invitation removes
shared access to the workload.

###### To delete shared access to a workload

1. Sign in to the AWS Management Console and open the AWS Well-Architected Tool console at [https://console.aws.amazon.com/wellarchitected/](https://console.aws.amazon.com/wellarchitected/ "https://console.aws.amazon.com/wellarchitected/").
2. In the left navigation pane, choose **Workloads**.
3. Select the workload in one of the following ways:
   - Choose the name of the workload.
   - Select the workload and choose **View
     details**.

4. Choose **Shares**.
5. Select the workload invitation to delete and choose
   **Delete**.
6. Choose **Delete** to confirm.
   If a user and the user's AWS account have workload invitations, you must delete
   both workload invitations to remove the user's permission to the workload.
