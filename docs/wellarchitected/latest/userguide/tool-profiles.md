# Tool profiles
<a name="tool-profiles"></a>

You can create profiles to provide your business context, and identify goals you'd like to accomplish when performing a Well-Architected review. AWS Well-Architected Tool uses the information gathered from your profile to help you focus on a prioritized list of questions that are relevant to your business during the workload review. Attaching a profile to your workload also helps you see which risks are prioritized for you to address with your improvement plan. 

**Note**  
AWS Well-Architected Agent also has a feature named profiles. AWS WA Agent profiles define the scope and optimization targets for AI-powered infrastructure analysis, and are unrelated to AWS WA Tool profiles. For information about AWS WA Agent profiles, see [AWS Well-Architected Agent Concepts and terminology](agent-concepts.md).

You can [create a profile](tool-creating-a-profile.md) from the **Profiles** page and associate it to a new workload, or you can [add a profile to an existing workload](tool-adding-profiles-to-workloads.md).
