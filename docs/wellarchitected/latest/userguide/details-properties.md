# The AWS Well-Architected Tool Properties tab

To display the properties of your workload, choose the
**Properties** tab. Initially, these properties are the values
that were specified when the workload was defined. Choose **Edit**
to make changes. Only the owner of the workload can make changes.

For descriptions of the properties, see [Defining a workload in AWS WA Tool](define-workload.md "define-workload.md").
