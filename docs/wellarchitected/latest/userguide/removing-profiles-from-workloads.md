# Removing a profile from a

workload in AWS WA Tool

Removing a profile from the workload reverts the workload to the version prior to when
the profile was associated with it, and workload review questions and risks are no
longer prioritized.

###### To remove a profile from a workload

1. From the **Profiles** section of the workload, choose
   **Remove**.
2. To confirm removal, enter the name of the profile in the text input field.
3. Choose **Remove**.
   A notification that the profile has been successfully removed from the workload is
   displayed. Removing a profile reverts the workload to the version prior to when the
   profile was associated with it, and workload review questions and risks are no longer
   prioritized.
