# Upgrading a lens in AWS WA Tool

Lenses can be upgraded for workloads and review templates.

###### Note

You can't undo a lens upgrade. After a workload or review template has been
upgraded to the latest lens version, you can't go back to the previous version
of the lens.

###### Upgrading a lens for a workload

1. On the **Notifications** page, select a workload to upgrade, and choose **Upgrade lens version**. Information about what changed in each
   pillar is displayed.

###### Note

You can also choose **View available upgrades** from the workload **Overview** tab. 2. Before upgrading a lens for a workload, a milestone is created to save the state
of your existing workload for future reference. Enter a unique name for the
milestone in the **Milestone name** field. 3. Select the **Confirmation** box next to **I understand and accept
these changes** and choose **Save**.
Once the lens is upgraded, you can view the previous version of the lens from the
**Milestones** tab.
