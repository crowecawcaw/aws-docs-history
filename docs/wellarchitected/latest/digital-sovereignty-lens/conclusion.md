

# Conclusion
<a name="conclusion"></a>

 The AWS Digital Sovereignty Lens provides architectural best practices across four of the six pillars of Well-Architected Framework. The Framework provides a set of questions for reviewing an existing or proposed architecture. It also provides a set of AWS best practices for each pillar. Using the Framework in your sovereign workloads assists you when building compliance-aligned, secure, and reliable systems and helps you focus on your functional requirements.
