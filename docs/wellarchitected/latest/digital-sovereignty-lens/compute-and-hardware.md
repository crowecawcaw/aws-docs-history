# Compute and hardware

| DSPERF02: How do you choose optimal compute solutions<br>without compromising on sovereignty? |
| --------------------------------------------------------------------------------------------- |
|                                                                                               |

Customers must balance between using modern computing
capabilities and adhering to regulatory requirements. This
includes data protection laws and national security
policies. Choosing optimal compute solutions improves
adherence while maintaining performance and operational
efficiency.
