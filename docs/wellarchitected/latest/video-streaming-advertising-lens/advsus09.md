# Ad intelligence, measurement, and security

| ADVSUS09: How are you implementing sustainable practices<br>for ad intelligence, measurement, and security? |
| ----------------------------------------------------------------------------------------------------------- |
|                                                                                                             |

For security, ad fraud detection and prevention systems require
continuous monitoring and analysis of advertising traffic, which
can be computationally intensive. Implementing sustainable
practices while maintaining effective fraud prevention requires
careful optimization of detection mechanisms and resource usage,
especially for real-time bidding and campaign monitoring
systems.
