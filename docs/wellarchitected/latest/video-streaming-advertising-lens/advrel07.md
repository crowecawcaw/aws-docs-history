# Failure and recovery

| ADVREL07: How do you handle component<br>failures and disaster recovery? |
| ------------------------------------------------------------------------ |
|                                                                          |

Handle component failures and disaster recovery by designing
fault-tolerant systems using cell-based architectures and
distributed resources. Implement backup strategies aligned with
RTO/RPO objectives. Manage data backup across multiple
locations, and comply with required regulations.

###### Best practices

- [ADVREL07-BP01 Design your workloads to withstand failures of individual components, such as compute instances, queues, databases, and caches](advrel07-bp01.md "advrel07-bp01.md")
- [ADVREL07-BP02 Implement a backup strategy which would meet RTO and RPO objectives](advrel07-bp02.md "advrel07-bp02.md")
- [ADVREL07-BP03 Back up data in multiple locations with consideration for your regulatory or legal requirements](advrel07-bp03.md "advrel07-bp03.md")
