# Infrastructure protection

| MIDASEC04: How do you enable network segmentation and access controls for<br>industrial data? |
| --------------------------------------------------------------------------------------------- |
|                                                                                               |

Implement clear network segmentation between OT and IT systems in manufacturing
environments. Use firewalls, perimeter networks, and dedicated network zones to manage and
secure traffic flows between cloud, IT, and OT systems, while verifying that you have proper
isolation and controlled data exchange to help protect critical manufacturing operations
from potential security threats.
