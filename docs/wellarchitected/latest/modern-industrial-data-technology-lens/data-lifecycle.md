# Data lifecycle

| MIDACOST02: How does your organization manage the full lifecycle of manufacturing data<br>resources? |
| ---------------------------------------------------------------------------------------------------- |
|                                                                                                      |

Effective management of industrial data resources throughout their lifecycle is crucial
for cost optimization. This includes tracking resource usage, implementing proper
decommissioning processes, and improving compliance with data retention policies.

MIDACOST02-BP04, BP05, and BP06 are closely related and focus on different aspects
of managing manufacturing data and resources: retention policies, cloud resource policies,
and cost controls. When implemented together, they provide a comprehensive approach to
managing your manufacturing data lifecycle while optimizing costs.
