# The pillars of the Well-Architected Framework

This section describes each of the pillars, and includes
definitions, best practices, questions, considerations, and key AWS
services that are relevant when architecting solutions for
serverless applications.

For brevity, we have only selected the questions from the
Well-Architected Framework that are specific to serverless
workloads. Questions that have not been included in this document
should still be considered when designing your architecture. We
recommend that you read
the [AWS Well-Architected Framework whitepaper](../framework/welcome.md "../framework/welcome.md").
