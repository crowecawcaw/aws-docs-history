# Data protection

Microsoft workloads often handle sensitive enterprise data that requires protection
through encryption, access controls, and secure data handling practices. This focus area
explores how to implement comprehensive data protection strategies that secure data at rest,
in transit, and in use, while using both Microsoft and AWS security capabilities.

| MSFTSEC03: How do you protect your Microsoft workload data? |
| ----------------------------------------------------------- |
|                                                             |

Whether using Microsoft SQL Server or other solutions, it's best practice to encrypt data
both at rest and in transit, employing multiple encryption mechanisms to meet internal and
external security requirements.
