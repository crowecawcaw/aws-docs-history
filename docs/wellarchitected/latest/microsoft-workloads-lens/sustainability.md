# Sustainability

The sustainability pillar focuses on designing and operating Microsoft workloads on AWS
in an environmentally responsible manner. It emphasizes minimizing environmental impact through
efficient resource utilization while maintaining business effectiveness. This pillar addresses
three key areas: aligning business requirements with sustainable architecture designs,
optimizing Microsoft ecosystems for sustainability, and implementing effective monitoring of
sustainability performance metrics
