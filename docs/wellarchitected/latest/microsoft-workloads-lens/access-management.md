# Access management

Controlling access to Microsoft workloads involves implementing proper authentication,
authorization, and auditing mechanisms that integrate with both Microsoft and AWS identity
services. This focus area addresses how to establish centralized identity management,
implement least privilege principles, and maintain comprehensive access monitoring across your
Microsoft environment.

| MSFTSEC02: How do you manage and regulate user access to your Microsoft workload<br>environment? |
| ------------------------------------------------------------------------------------------------ |
|                                                                                                  |

To control access to your Microsoft workload, utilize the authentication and
authorization tools provided by AWS, Microsoft, and trusted third-party vendors. Implement a
least-privilege approach, verifying that users and systems have only the permissions necessary
for their roles.
