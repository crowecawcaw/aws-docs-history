# Conclusion

The AWS Well-Architected Framework provides architectural best
practices across the pillars for designing and operating reliable,
secure, efficient, and cost-effective healthcare workloads in the
cloud. The Framework provides a set of questions that allows you to
review an existing or proposed architecture, and also a set of AWS
best practices for each pillar. Using the Framework in your
architecture will help you produce stable and efficient systems,
which allows you to focus on your functional requirements.
