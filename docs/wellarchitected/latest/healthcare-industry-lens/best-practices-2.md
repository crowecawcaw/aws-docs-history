## Definition
<a name="definition-2"></a>

 To achieve reliability, a system must have a well-planned [foundation](https://docs.aws.amazon.com/wellarchitected/latest/reliability-pillar/foundations.html) in place, with mechanisms for handling changes in demand or requirements. The system should be designed to detect failure and automatically repair itself.
