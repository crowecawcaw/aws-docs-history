# Reliability

The reliability pillar encompasses the ability of a workload to
perform its intended function correctly and consistently when
it’s expected to. This includes the ability to operate and test
the workload through its total lifecycle. This reliability pillar
provides in-depth, best practice guidance for implementing
reliable analytics workloads on AWS.
