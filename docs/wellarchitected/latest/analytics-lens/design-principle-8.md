# 8 – Choose the best-performing

compute solution

## How do you select the best-performing options for your analytics workload?

The definition of best-performing will mean different things
to different stakeholders, so gathering all stakeholders’
input in the decision process is key. Define performance and
cost goals by balancing business and application
requirements. Then evaluate the overall efficiency of the
compute solution against those goals using metrics emitted
from the solution.
