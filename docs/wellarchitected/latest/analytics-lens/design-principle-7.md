# 7 – Govern data and metadata changes

**How do you govern data and metadata
changes?** Controlled changes are not only necessary
for infrastructure, but also required for data quality
assurance. If the data changes are uncontrolled, it becomes
difficult to anticipate the impact of these changes. It also
makes downstream systems harder to manage data quality issues
of their own.

| **ID**   | **Priority** | **Best practice**                                                         |
| -------- | ------------ | ------------------------------------------------------------------------- |
| ☐ BP 7.1 | Required     | Build a central Data Catalog to store, share, and track metadata changes. |
| ☐ BP 7.2 | Required     | Monitor for data quality anomalies.                                       |
| ☐ BP 7.3 | Required     | Trace data lineage.                                                       |
