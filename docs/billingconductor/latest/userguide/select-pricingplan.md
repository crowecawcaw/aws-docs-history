# Select an AWS managed pricing plan

Use the following steps to select an AWS managed pricing plan.

###### To select a AWS managed pricing plan

1. Open AWS Billing Conductor at
   [https://console.aws.amazon.com/billingconductor/](https://console.aws.amazon.com/billingconductor/ "https://console.aws.amazon.com/billingconductor/").
2. In the navigation pane, choose **Billing groups**.
3. When creating or editing a billing group, for pricing plan, select a pricing plan in the AWS Managed Pricing Plan category from the drop down menu.
