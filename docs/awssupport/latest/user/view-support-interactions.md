

# View support interactions
<a name="view-support-interactions"></a>

Past interactions with AWS Support are saved for 10 years. To view past interactions, open the Support Dashboard. In the **Support interactions** section, the **History** table shows the following information for each interaction:
+ **Interaction**: The name of the interaction. Choose the name to view the interaction.
+ **Support request (case) ID**: The ID of the support case that you created from the interaction, if any. Choose the ID to view the case.
+ **Status**: The status of the interaction or case, such as **Resolved** or **Reopened**.
+ **Opened**: The date that the interaction started.
+ **Last response**: When the interaction or case last received a response.

Support interactions and the support cases that you create from them appear together in the **History** table.

You can add additional details to the interaction to generate a new response. Or, you can choose to create a Support case from the interaction by choosing **Create a case** on the AWS Support interaction details screen.
