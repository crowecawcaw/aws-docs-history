# Managing attachments

You can attach files to a support case when you create a case or when you reply to an existing case. You can attach up to 10 files, with each file up to 150 MB. Supported attachments include error logs, screenshots, configuration files, and other documents relevant to your issue.

The attachments table in the Support Center Console displays the following information for each file:

- **File name** – The name of the attached file.
- **Size** – The file size.
- **Status** – The current upload status of the file.
- **Action** – Available actions for the file, such as **Cancel**, **Retry**, or **Remove**.

###### Note

Files that are removed or not submitted with a case are automatically deleted after 24 hours.
