# Using AWS DevOps Agent with your AWS Support plan

AWS DevOps Agent is an AI-powered operations teammate that investigates incidents,
recommends preventive improvements, and handles on-demand SRE tasks across your
AWS account. If your account is on an eligible Support plan, you can enable AWS DevOps Agent
directly from the Support Center Console. For an overview of what the agent does, see
[About
AWS DevOps Agent](../../../devopsagent/latest/userguide/about-aws-devops-agent.md "../../../devopsagent/latest/userguide/about-aws-devops-agent.md") in the _AWS DevOps Agent User Guide_.
