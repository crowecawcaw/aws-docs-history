# Resources created for AWS DevOps Agent activated from AWS Support

Activation from the Support Center Console creates the following resources in
`us-east-1`. Replace `ACCOUNT_ID` with your
12-digit AWS account ID. The `WebappAdmin` role suffix is a
12-character identifier derived from the agent space.

| Resources created when you enable AWS DevOps Agent from the Support Center Console | AWS service             | Resource type                                       | Resource name                                                                                                                                                                              | Trust scope                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Permissions granted |
| ---------------------------------------------------------------------------------- | ----------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------- |
| AWS DevOps Agent                                                                   | Agent space             | `DevOpsAgentSpace`                                  | Not applicable                                                                                                                                                                             | Container for the account association, operator web app<br>configuration, and data the agent generates while it operates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| AWS Identity and Access Management (IAM)                                           | Role                    | `DevOpsAgentRole-AgentSpace-`ACCOUNT_ID``           | Trusted by `aidevops.amazonaws.com` with<br>`aws:SourceAccount` and `aws:SourceArn`<br>conditions that scope the role to agent spaces in your own account<br>(confused-deputy protection). | Grants the agent the read-only investigation permissions<br>across AWS services that it needs to investigate resources in your<br>account. Permissions come from the AWS-managed<br>`AIDevOpsAgentAccessPolicy` attached at activation time.<br>For the full list, see [`AIDevOpsAgentAccessPolicy`](../../../devopsagent/latest/userguide/aws-devops-agent-security-devops-agent-iam-permissions.md#AIDevOpsAgentAccessPolicy "../../../devopsagent/latest/userguide/aws-devops-agent-security-devops-agent-iam-permissions.md#AIDevOpsAgentAccessPolicy") in the<br>_AWS DevOps Agent User Guide_. The customer-managed<br>`AIDevOpsAllowAwsSupportActionsPolicy-`ACCOUNT_ID``<br>policy is also attached. |
| AWS Identity and Access Management (IAM)                                           | Role                    | `DevOpsAgentRole-WebappAdmin-`suffix``              | Trust policy scoped to a specific agent space, so only that<br>agent space's operator web app can assume it.                                                                               | Grants the operator web app the permissions it needs for<br>chat, journal, recommendations, and Support integration. Permissions<br>come from the AWS-managed<br>`AIDevOpsOperatorAppAccessPolicy`. For the full list,<br>see [`AIDevOpsOperatorAppAccessPolicy`](../../../devopsagent/latest/userguide/aws-devops-agent-security-devops-agent-iam-permissions.md#AIDevOpsOperatorAppAccessPolicy "../../../devopsagent/latest/userguide/aws-devops-agent-security-devops-agent-iam-permissions.md#AIDevOpsOperatorAppAccessPolicy") in the<br>_AWS DevOps Agent User Guide_.                                                                                                                                |
| AWS Identity and Access Management (IAM)                                           | Customer-managed policy | `AIDevOpsAllowAwsSupportActionsPolicy-`ACCOUNT_ID`` | Attached to the<br>`DevOpsAgentRole-AgentSpace-`ACCOUNT_ID``<br>role.                                                                                                                      | Grants `iam:CreateServiceLinkedRole`, scoped to<br>the AWS Resource Explorer service-linked role ARN<br>(`arn:aws:iam::`ACCOUNT_ID`:role/aws-service-role/resource-explorer-2.amazonaws.com/AWSServiceRoleForResourceExplorer`).<br>This permission allows the agent to create the AWS Resource Explorer<br>service-linked role on your behalf if it doesn't already exist, so<br>the agent can use AWS Resource Explorer for topology<br>discovery.                                                                                                                                                                                                                                                         |

The Support Center Console activation doesn't create resources in any other
AWS Region.
