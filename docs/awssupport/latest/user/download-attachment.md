# Downloading an attachment

After a case is submitted, you can download attachments from the case correspondence.

###### To download an attachment

1. Navigate to the **Case details** page for the support case.
2. In the **Correspondence** section, locate the attachment link.
3. Choose the filename link. The file downloads directly to your device.

###### Note

You must have the required IAM permissions to download attachments. If you don't have the correct permissions, an **Access denied** error appears when you choose the attachment link.
