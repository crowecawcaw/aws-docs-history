

# API Access

In addition to managing Revenue Attribution IDs or the Marketplace Revenue Share through AWS Partner Central, you can manage them programmatically through the AWS Revenue Measurement APIs and the Marketplace Revenue Share APIs.

## AWS Revenue Measurement APIs
<a name="raid-prm-apis"></a>

Use the [AWS Revenue Measurement APIs](https://docs.aws.amazon.com/partner-central/latest/APIReference/API_Operations_Partner_Central_Revenue_Measurement_API.html) to create, retrieve, list, and update Revenue Attribution IDs and their monthly cost allocation percentages for associated AWS Marketplace offers and/or ACE opportunities. The API surface includes the following operations:

**Revenue Attribution**


| Operation | Description | 
| --- | --- | 
| CreateRevenueAttribution | Creates a new Revenue Attribution ID. | 
| GetRevenueAttribution | Retrieves the details of a Revenue Attribution ID by identifier. | 
| ListRevenueAttributions | Returns a paginated list of Revenue Attribution IDs. | 
| UpdateRevenueAttribution | Updates the description and context of an existing Revenue Attribution ID. | 

**Revenue Attribution Allocations**


| Operation | Description | 
| --- | --- | 
| StartRevenueAttributionAllocationsTask | Submits a batch of up to 250 monthly cost allocation changes for asynchronous processing. | 
| GetRevenueAttributionAllocationsTask | Retrieves the status of an allocations task and per-record results. | 
| ListRevenueAttributionAllocations | Returns a paginated list of monthly cost allocation entries for a given Revenue Attribution ID. | 
| GetRevenueAttributionAllocation | Retrieves a single monthly cost allocation entry. | 

## Marketplace Revenue Share APIs
<a name="raid-mrs-apis"></a>

Use the [Marketplace Revenue Share APIs](https://docs.aws.amazon.com/partner-central/latest/APIReference/API_Operations_Partner_Central_Revenue_Measurement_API.html) to specify what portion of their product sales are generated by AWS Marketplace for a specific duration (month, quarter, or year).

**Marketplace Revenue Share**


| Operation | Description | 
| --- | --- | 
| CreateMarketplaceRevenueShare | Creates a Marketplace Revenue share for one AWS Marketplace product or a group of products that share infrastructure. | 
| GetMarketplaceRevenueShare | Retrieves a Marketplace Revenue Share by its share ID or ARN. | 
| ListMarketplaceRevenueShares | Returns a paginated list of Marketplace Revenue Shares. | 
| UpdateMarketplaceRevenueShare | Replaces the AWS Marketplace products in a marketplace revenue share. The request must include the complete set of AWS Marketplace products, which should be products that run on the same backend AWS infrastructure, and their typed AWS account lists. Any AWS Marketplace product not included is removed, along with its AWS account lists. An empty Products list closes the marketplace revenue share. A closed marketplace revenue share cannot be reopened. | 

**Marketplace Revenue Share Allocations**


| Operation | Description | 
| --- | --- | 
| CreateMarketplaceRevenueShareAllocation | Creates an allocation that sets the monthly revenue share percentage. | 
| GetMarketplaceRevenueShareAllocation | Retrieves a single Marketplace Revenue Share allocation. | 
| UpdateMarketplaceRevenueShareAllocation | Updates the revenue share percentage or status of an allocation. Finalized months can't be changed. | 
| ListMarketplaceRevenueShareAllocations | Returns a paginated list of allocations for a given Marketplace Revenue Share. | 

Standard AWS tagging operations (TagResource, UntagResource, ListTagsForResource) are supported on Marketplace Revenue Shares and Revenue Attribution IDs. Allocations do not support tags.
