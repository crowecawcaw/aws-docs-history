

# Account Tagging for SaaS products

Account Tagging for SaaS products enables partners to associate all AWS consumption within partner-owned accounts to a specific product listing. Instead of tagging individual resources, partners tag the AWS account itself using AWS Organizations. All usage within the tagged account is attributed to the partner's product.

This method is designed for partners who dedicate one or more AWS accounts to deliver a single product. If multiple products share the same AWS account, use Resource Tagging or User Agent String instead.
