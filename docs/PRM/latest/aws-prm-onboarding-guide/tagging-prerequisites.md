# Method-Specific Requirements

In addition to the general [prerequisites](resource-tagging-prerequisites.md "resource-tagging-prerequisites.md"), ensure you meet the following requirements for resource tagging:

- Ability to tag AWS resources in your own account or in customer's account
- Product that uses one or more of the [supported AWS services for resource tagging](resource-tagging-included-services.md "resource-tagging-included-services.md")
