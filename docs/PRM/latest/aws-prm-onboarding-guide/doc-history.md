

# Document history for the AWS Revenue Measurement User Guide

The following table describes the documentation releases for AWS Revenue Measurement.

| Change | Description | Date | 
| --- |--- |--- |
| [Added AWS Revenue Measurement Advisor chapter](doc-history.md) | Added a chapter that describes how to use the AWS Revenue Measurement Advisor in AWS Partner Central console or through the MCP server, including readiness checks, product code retrieval, implementation method recommendations, tag verification, compliance status checks, and attributed revenue reporting. Updated the Getting started tip to point to the advisor. | November 19, 2026 | 
| [Expanded implementation methods, enhanced Revenue Attribution ID, expanded Amazon Bedrock coverage, and renamed to AWS Revenue Measurement](doc-history.md) | This release includes the following updates:+ Added Account Tagging for SaaS products as an implementation method.<br />+ Added Identity Tagging as an implementation method.<br />+ Enhanced Revenue Attribution ID with the Marketplace Revenue Share for automated attribution across AWS Marketplace SaaS offers.<br />+ Expanded Amazon Bedrock coverage to Amazon and closed-source models, and added an Amazon Bedrock supported foundation models reference table.<br />+ Renamed the service from Partner Revenue Measurement to AWS Revenue Measurement. | November 18, 2026 | 
| [Expanded Resource Tagging included services](doc-history.md) | Added four AWS services to the Resource Tagging included services list: Amazon GameLift Streams, AWS RTB Fabric, Amazon Simple Email Service (SES), and Amazon Connect Decisions. Revenue attribution for these services is available from September 1, 2026. Updated the downloadable Resource Tagging Included Services CSV. | September 30, 2026 | 
| [Added multi-partner attribution support for Resource Tagging](doc-history.md) | Introduced the account-suffixed tag key format (`aws-apn-id-{{partner-central-aws-account-id}}`) that enables multiple partners to independently tag the same AWS resource. Updated all Resource Tagging examples, best practices (Bedrock, EKS), automated tagging, troubleshooting, and FAQs. The simple `aws-apn-id` tag key remains fully backward compatible. | September 30, 2026 | 
| [Expanded User Agent included services](doc-history.md) | Expanded the User Agent included services list from 24 to 119 AWS services. Updated the downloadable API actions CSV with supported actions and Regions for each service. Clarified that User Agent strings apply to management or control-plane API calls and that data plane operations are not supported. Spend on services not listed is aggregated as Misc. | August 31, 2026 | 
| [Restructured FAQs by audience; added Customer FAQ](doc-history.md) | Restructured the FAQs chapter into audience-specific pages: Partner FAQ and Customer FAQ. Added a new Customer FAQ covering the purpose of AWS Revenue Measurement, customer benefits, environment and billing impact, data collected, tagging strategy considerations, tag lifecycle, account access, data sharing, and supported regions. | August 19, 2026 | 
| [Added Revenue Attribution ID service user guide](doc-history.md) | Added new Partner Revenue Attribution ID service user guide for AWS Revenue Measurement. | June 30, 2026 | 
| [Added Demo and AWS Samples sections; updated Resource Tagging included services](doc-history.md) | Added Demo section with click-through walkthroughs and AWS Samples section with CloudFormation automation examples. Added Amazon DynamoDB Accelerator (DAX), Amazon Elastic VMware Service (Amazon EVS), Amazon WorkSpaces Core Managed Instances, and AWS End User Messaging to Resource Tagging included services. Updated Amazon Bedrock notes to clarify supported model types. | May 18, 2026 | 
| [Added best practices chapter and additional FAQs; updated Terraform User Agent guidance](doc-history.md) | Added best practices chapter covering Bedrock and EKS integration. Added additional FAQs section. | April 13, 2026 | 
| [Updated Terraform User Agent implementation guidance](doc-history.md) | Updated Terraform section to use `provider_meta` with the `user_agent` argument (AWS provider >= 6.27.0). | April 8, 2026 | 
| [Added User Agent String and AWS Marketplace Metering implementation methods; restructured documentation](doc-history.md) | Added User Agent String and AWS Marketplace Metering as new implementation methods. Restructured documentation to organize content by implementation method: AWS Marketplace Metering, Resource Tagging, and User Agent String. Updated Automation and Included AWS Services as hub pages linking to method-specific content. | April 2, 2026 | 
| [Initial release of AWS Revenue Measurement with ResourceTagging capability](doc-history.md) | Initial release of the AWS Revenue Measurement User Guide | January 29, 2026 |
