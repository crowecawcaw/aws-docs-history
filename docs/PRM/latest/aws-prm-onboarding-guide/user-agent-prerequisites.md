# Method-Specific Requirements

In addition to the general [prerequisites](resource-tagging-prerequisites.md "resource-tagging-prerequisites.md"), ensure you meet the following requirements for User Agent string implementation:

- Product listing on AWS Marketplace. See the
  [AWS Marketplace Seller Guide](../../../marketplace/latest/userguide/user-guide-for-sellers.md "../../../marketplace/latest/userguide/user-guide-for-sellers.md")
  for general information. For product-specific listing guide instructions:

| Product Type               | Listing Guide                                                                                                                                                                                               |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Amazon Machine Image (AMI) | [AMI Product Listing Guide](../../../marketplace/latest/userguide/ami-single-ami-products.md#ami-create-product "../../../marketplace/latest/userguide/ami-single-ami-products.md#ami-create-product")      |
| SaaS                       | [SaaS Product Listing Guide](../../../marketplace/latest/userguide/saas-create-product.md "../../../marketplace/latest/userguide/saas-create-product.md")                                                   |
| ML                         | [ML Product Listing Guide](../../../marketplace/latest/userguide/ml-publishing-your-product-in-aws-marketplace.md "../../../marketplace/latest/userguide/ml-publishing-your-product-in-aws-marketplace.md") |
| Professional Services      | [Professional Services Listing Guide](../../../marketplace/latest/userguide/proserv-getting-started.md#proserv-create "../../../marketplace/latest/userguide/proserv-getting-started.md#proserv-create")    |

- Product that uses one or more of the [supported AWS services for User Agent string](user-agent-included-services.md "user-agent-included-services.md")
- Direct regular AWS API/CLI access from your application
