

# Get AWS Revenue Measurement Advisor help via AWS Partner Central agent

AWS Partner Central provides an AI-powered agent that helps you with Partner Central tasks, including AWS Revenue Measurement (formerly Partner Revenue Measurement). You can use the agent in the AWS Partner Central console or from your own AI tools through the Partner Central Agent MCP Server. When you ask about AWS Revenue Measurement, the agent passes your question to a specialized AI agent for Revenue Measurement. This specialist reviews your AWS Marketplace listings, account connections, compliance status, and attributed revenue, and answers with prescriptive guidance for your situation.

## Prerequisites
<a name="aws-revenue-measurement-advisor-prerequisites"></a>

Before you use AWS Partner Central agents for AWS Revenue Measurement, complete the following:
+ Sign in with the AWS account that is linked to Partner Central. The agent reads listings, account connections, compliance status, and attributed revenue for the account that you sign in with.
+ Grant your IAM user or role the following read-only permissions. The agent uses them to read your AWS Marketplace listings and product codes, your account connections, and your compliance status and attributed revenue.

  ```json
  {
    "Version": "2012-10-17", 		 	 	 
    "Statement": [
      {
        "Effect": "Allow",
        "Action": [
          "aws-marketplace:ListEntities",
          "aws-marketplace:DescribeEntity",
          "partnercentral:ListConnections",
          "partnercentral:GetConnection",
          "partnercentral:GetPartnerReportingData"
        ],
        "Resource": "*"
      }
    ]
  }
  ```

**Note**  
If a permission is missing, the agent tells you which action was denied and continues with the checks that it can complete. After the permission is granted, ask the agent to check again.

## Access the agent
<a name="aws-revenue-measurement-advisor-access"></a>

You can use AWS Partner Central agents in two ways. Both ways provide the same AWS Revenue Measurement capabilities.

### Option 1: Use the AWS Partner Central console
<a name="aws-revenue-measurement-advisor-access-console"></a>

1. Sign in to the AWS Partner Central console.

1. On your Partner Central dashboard, find the **Explore AWS Revenue Measurement requirements** card, and then choose **Explore**.

1. The **AWS assistant** panel opens and sends the prompt *Help me get started with AWS Revenue Measurement*.

1. Review the response, and then ask follow-up questions in the same panel. For example prompts, see [What the agent can help with](#aws-revenue-measurement-advisor-capabilities).

**Note**  
Conversations in the AWS Partner Central console are temporary and aren't saved.

For more information, see [How to access the agent](https://docs.aws.amazon.com/partner-central/latest/getting-started/partner-onboarding-agent.html#onboarding-agent-access) in the AWS Partner Central Getting Started Guide.

### Option 2: Use the Partner Central Agent MCP Server
<a name="aws-revenue-measurement-advisor-access-mcp"></a>

1. Connect an MCP-compatible client, such as Claude Code, Kiro, Claude Desktop, or AWS Quick, to the Partner Central Agent MCP Server. For setup instructions, see [Getting Started with the Partner Central Agent MCP Server](https://docs.aws.amazon.com/partner-central/latest/developer-guide/mcp-getting-started.html).

1. Ask your AWS Revenue Measurement question in your client. For example:

   ```
   Help me get started with AWS Revenue Measurement
   ```

For more information, see [Partner Central Agent MCP Server](https://docs.aws.amazon.com/partner-central/latest/developer-guide/partner-central-mcp-server.html) in the AWS Partner Central Developer Guide.

## What the agent doesn't do
<a name="aws-revenue-measurement-advisor-limitations"></a>

The agent provides guidance and reads your account information. It doesn't make changes to your resources. The agent doesn't do the following:
+ Apply tags to your AWS resources. The agent provides guidance only.
+ Read, generate, or edit infrastructure as code, such as AWS CloudFormation, AWS CDK, or Terraform templates. The agent provides the tag format for you to apply.
+ Create or change subsidiary account connections. The agent routes these requests to the agent that helps with account connections.
+ Create AWS Marketplace listings. The agent routes these requests to the agent that helps with listings.
+ Show charts of your attributed revenue, report revenue for an individual AWS Marketplace listing, or separate your own account's revenue from your subsidiary accounts' revenue. For charts and more detail, use the Attributed Revenue Dashboard. For more information, see [Attributed Revenue guide](https://docs.aws.amazon.com/partner-central/latest/getting-started/partner-analytics-attributed-revenue.html).
+ Estimate revenue or explain why revenue is missing for a period. The agent reports only the data that AWS returns. If you expected revenue, ask the agent to check your compliance status.
+ Decide whether you are compliant based on the setup steps that you describe. The agent reports only the compliance status that AWS has determined for your account.
+ Answer questions outside AWS Revenue Measurement. The agent routes questions about other topics, such as partner profile setup or seller configuration, to the appropriate agent.
