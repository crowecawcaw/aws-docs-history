# VPC Tutorials

Amazon Virtual Private Cloud (VPC) is the foundation of your network infrastructure in
AWS. While the AWS Management Console provides a user-friendly interface, the AWS Command
Line Interface (CLI) offers greater flexibility and automation capabilities for creating and
managing your VPC resources.

This guide presents two essential VPC deployment scenarios:

- A basic VPC setup with a public subnet, ideal for simple web
  applications
- An advanced VPC configuration with both private and public subnets using NAT
  gateways, suitable for multi-tier applications
  By following these tutorials, you'll learn how to:

- Create VPCs with different subnet configurations
- Set up internet and NAT gateways
- Configure route tables and security groups
- Use AWS CLI commands to manage your network infrastructure
- Implement AWS networking best practices
  Let's start building your AWS network infrastructure using the command line.
