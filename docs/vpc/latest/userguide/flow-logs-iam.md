# Identity and access management in VPC Flow Logs

AWS uses security credentials to identify you and to grant you access to your AWS
resources. You can use features of AWS Identity and Access Management (IAM) to allow other users, services, and
applications to use your AWS resources fully or in a limited way, without sharing your
security credentials.

This section describes the AWS service-linked roles that are created specifically
for VPC Flow Logs and the managed policies attached to the VPC Flow Logs service-linked roles. For more information about
AWS IAM roles and policies, see [Roles terms and concepts](../../../IAM/latest/UserGuide/id_roles.md#id_roles_terms-and-concepts "../../../IAM/latest/UserGuide/id_roles.md#id_roles_terms-and-concepts") in the _IAM User Guide_.

For more information about identity and access management for VPC, see [Identity and access management for Amazon VPC](security-iam.md "security-iam.md")
in the _Amazon VPC User Guide_.
