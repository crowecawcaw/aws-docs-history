# Filter DNS traffic using Route 53 Resolver DNS Firewall

With DNS Firewall, you define domain name filtering rules in rule groups that you
associate with your VPCs. You can specify lists of domain names to allow or block, and you
can customize the responses for the DNS queries that you block. For more information, see
the [Route 53 Resolver DNS Firewall Documentation](../../../Route53/latest/DeveloperGuide/resolver-dns-firewall.md "../../../Route53/latest/DeveloperGuide/resolver-dns-firewall.md").

You implement DNS Firewall with the following AWS resources.

| DNS Firewall resource   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DNS Firewall rule group | A DNS Firewall rule group is a named, reusable<br>collection of DNS Firewall rules for filtering DNS<br>queries. You populate the rule group with the filtering rules, then<br>associate the rule group with one or more VPCs from Amazon VPC. When you<br>associate a rule group with a VPC, you enable<br>DNS Firewall filtering for the VPC. Then, when Resolver<br>receives a DNS query for a VPC that has a rule group associated with it,<br>Resolver passes the query to DNS Firewall for filtering.Each rule<br>within the rule group specifies one domain list and an action to take on<br>DNS queries whose domains match the domain specifications in the list.<br>You can allow, block, or alert on matching queries. You can also define<br>custom responses for blocked queries.<br>For more information, see [Rule groups and rules in<br>Route 53 Resolver DNS Firewall](../../../Route53/latest/DeveloperGuide/resolver-dns-firewall-rule-groups.md "../../../Route53/latest/DeveloperGuide/resolver-dns-firewall-rule-groups.md"). |
| Domain list             | A domain list is a reusable set of domain specifications that you use in<br>a DNS Firewall rule, inside a rule group.For more information, see<br>[Domain lists in<br>Route 53 Resolver DNS Firewall](../../../Route53/latest/DeveloperGuide/resolver-dns-firewall-domain-lists.md "../../../Route53/latest/DeveloperGuide/resolver-dns-firewall-domain-lists.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

You can also use AWS Firewall Manager to centrally configure and manage
DNS Firewall resources across your accounts and organizations in
AWS Organizations. You can manage firewalls for multiple accounts using a single account in Firewall Manager.
For more information, see [AWS Firewall Manager](../../../waf/latest/developerguide/fms-chapter.md "../../../waf/latest/developerguide/fms-chapter.md") in the
_AWS WAF, AWS Firewall Manager, and AWS Shield Advanced Developer Guide_.
