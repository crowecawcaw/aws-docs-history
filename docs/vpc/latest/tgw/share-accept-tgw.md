# Accept an AWS Transit Gateway resource share using the

AWS Resource Access Manager console

If you were added to a resource share, you receive an invitation to join the resource
share. You must accept the resource share through the AWS Resource Access Manager (AWS RAM) console
before you can access the shared resources.

###### To accept a resource share

1. Open the AWS RAM console at [https://console.aws.amazon.com/ram/](https://console.aws.amazon.com/ram/ "https://console.aws.amazon.com/ram/").
2. In the navigation pane, choose **Shared with me**,
   **Resource shares**.
3. Select the resource share.
4. Choose **Accept resource share**.
5. To view the shared transit gateway, open the **Transit Gateways**
   page in the Amazon VPC console.
