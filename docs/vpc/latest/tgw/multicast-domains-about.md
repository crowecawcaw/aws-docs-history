# Multicast domains in AWS Transit Gateway

A multicast domain allows segmentation of a multicast network into different domains. To
begin using multicast with a transit gateway, create a multicast domain, and then associate
subnets with the domain.

## Multicast domain attributes

The following table details the multicast domain attributes. You cannot enable both attributes
at the same time.

| Attribute                                                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Igmpv2Support` (AWS CLI)<br>\*_IGMPv2 support_<br>• (console)                | This attribute determines how group members join or leave a multicast group.<br>When this attribute is disabled, you must add the group members to the domain<br>manually.<br>Enable this attribute if at least one member uses the IGMP protocol. Members join<br>the multicast group in one of the following ways:<br>• Members that support IGMP use the `JOIN` and `LEAVE`<br>messages.<br>• Members that do not support IGMP must be added or removed from the group using<br>the Amazon VPC console or the AWS CLI.<br>If you register multicast group members, you must deregister them, too. The<br>transit gateway ignores an IGMP `LEAVE` message sent by a manually added group<br>member.                 |
| `StaticSourcesSupport` (AWS CLI)<br>\*_Static sources support_<br>• (console) | This attribute determines whether there are static multicast sources for the<br>group.<br>When this attribute is enabled, you must add sources for a multicast domain using<br>[register-transit-gateway-multicast-group-sources](../../../cli/latest/reference/ec2/register-transit-gateway-multicast-group-sources.md "../../../cli/latest/reference/ec2/register-transit-gateway-multicast-group-sources.md") . Only multicast sources<br>can send multicast traffic.<br>When this attribute is disabled, there are no designated multicast sources. Any<br>instances that are in subnets associated with the multicast domain can send multicast<br>traffic, and the group members receive the multicast traffic. |
