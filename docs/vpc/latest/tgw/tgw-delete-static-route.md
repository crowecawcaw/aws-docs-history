# Delete a static route in AWS Transit Gateway

Delete static routes from a transit gateway route table.

###### To delete a static route using the console

1. Open the Amazon VPC console at
   [https://console.aws.amazon.com/vpc/](https://console.aws.amazon.com/vpc/ "https://console.aws.amazon.com/vpc/").
2. On the navigation pane, choose **Transit Gateway Route
   Tables**.
3. Select the route table for which to delete the route, and choose
   **Routes**.
4. Choose the route to delete.
5. Choose **Delete static route**.
6. In the confirmation box, choose **Delete static route**.

###### To delete a static route using the AWS CLI

Use the [delete-transit-gateway-route](../../../cli/latest/reference/ec2/delete-transit-gateway-route.md "../../../cli/latest/reference/ec2/delete-transit-gateway-route.md") command.
