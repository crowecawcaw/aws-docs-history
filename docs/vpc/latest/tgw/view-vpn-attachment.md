# View a VPN attachment in AWS Transit Gateway

###### To view your VPN attachments using the console

1. Open the Amazon VPC console at
   [https://console.aws.amazon.com/vpc/](https://console.aws.amazon.com/vpc/ "https://console.aws.amazon.com/vpc/").
2. On the navigation pane, choose **Transit Gateway
   Attachments**.
3. In the **Resource type** column, look for
   **VPN**. These are the VPN attachments.
4. Choose an attachment to view its details or to add tags.

###### To view your VPN attachments using the AWS CLI

Use the [describe-transit-gateway-attachments](../../../cli/latest/reference/ec2/describe-transit-gateway-attachments.md "../../../cli/latest/reference/ec2/describe-transit-gateway-attachments.md") command.
