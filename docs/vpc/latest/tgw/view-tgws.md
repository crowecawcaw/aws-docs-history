# View transit gateway information in AWS Transit Gateway

View any of your transit gateways.

###### To view a transit gateway using the console

1. Open the Amazon VPC console at
   [https://console.aws.amazon.com/vpc/](https://console.aws.amazon.com/vpc/ "https://console.aws.amazon.com/vpc/").
2. On the navigation pane, choose **Transit Gateways**. Details
   for the transit gateway are displayed below the list of gateways on the page.

###### To view a transit gateway using the AWS CLI

Use the [describe-transit-gateways](../../../cli/latest/reference/ec2/describe-transit-gateways.md "../../../cli/latest/reference/ec2/describe-transit-gateways.md") command.
