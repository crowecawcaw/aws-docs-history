# Quotas for your IPAM

This section lists the quotas related to IPAM. The Service Quotas console also provides
information about IPAM quotas. You can use the Service Quotas console to view default quotas and
[request quota increases](https://console.aws.amazon.com/servicequotas/home/services/ec2-ipam/quotas "https://console.aws.amazon.com/servicequotas/home/services/ec2-ipam/quotas") for
adjustable quotas. For more information, see [Requesting a quota
increase](../../../servicequotas/latest/userguide/request-quota-increase.md "../../../servicequotas/latest/userguide/request-quota-increase.md") in the _Service Quotas User Guide_.
