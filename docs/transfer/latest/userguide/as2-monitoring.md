# Monitoring AS2 usage

You can monitor AS2 activity using Amazon CloudWatch and AWS CloudTrail. To view other Transfer Family server
metrics, see [Amazon CloudWatch logging for AWS Transfer Family servers](structured-logging.md "structured-logging.md")
