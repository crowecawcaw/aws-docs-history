

# Supported SOP classes
<a name="supported-sop-classes"></a>

With AWS HealthImaging, you can import DICOM P10 Service-Object Pair (SOP) instances encoded with any SOP class UID, including [retired](https://dicom.nema.org/medical/dicom/current/output/chtml/part05/sect_7.7.html) and [private](https://dicom.nema.org/dicom/2013/output/chtml/part05/sect_7.8.html). All private *attributes* are preserved, as well.
