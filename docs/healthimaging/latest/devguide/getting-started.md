# Getting started with AWS HealthImaging

To start using AWS HealthImaging, set up an AWS account and create an AWS Identity and Access Management user. To use the
[AWS CLI](../../../cli/latest/userguide/getting-started-install.md "../../../cli/latest/userguide/getting-started-install.md")
or the [AWS SDKs](https://aws.amazon.com/developer/tools/ "https://aws.amazon.com/developer/tools/"), you must install and
configure them.

After learning about HealthImaging concepts and setting up, a short tutorial with code examples is
available to help get you started.
