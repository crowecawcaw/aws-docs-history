# Migrating Active Directory users to AWS Managed Microsoft AD

You can use the Active Directory Migration Toolkit (ADMT) along with the Password Export
Service (PES) to migrate users from your self-managed Active Directory to your AWS Managed Microsoft AD directory. This
enables you to migrate Active Directory objects and encrypted passwords for your users more easily.

For detailed instructions, see [How to migrate your on-premises domain to AWS Managed Microsoft AD using ADMT](https://aws.amazon.com/blogs/security/how-to-migrate-your-on-premises-domain-to-aws-managed-microsoft-ad-using-admt/ "https://aws.amazon.com/blogs/security/how-to-migrate-your-on-premises-domain-to-aws-managed-microsoft-ad-using-admt/") on the _AWS Security Blog_.
