# Directory Assessment Error Messages

To create a hybrid directory, you need to a passed directory assessment. Directory assessments can fail for various
reasons.

The following table shows directory assessment error messages and how to resolve them.

| Directory Assessment Error Messages & Resolutions                                                                                                                                                                                                                                                     | Directory Assessment Error Message                                                                                                                                                                                                                                                                                                                                         | Resolution |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| This assessment failed multiple tests on both managed instances.<br>Investigate the failed tests by selecting each managed instance and<br>resolving them in your on-premises directory. Then, create a new<br>assessment.                                                                            | One or more of the directory assessment tests failed for your self-managed AD.<br>Review the [Assessment Test error messages](assessment_test_error-msgs.md "assessment_test_error-msgs.md") for more<br>information on specific test failures and their resolutions.                                                                                                      |
| This assessment failed due to Internal Service Exception. Please<br>retry by creating a new assessment or contact service for<br>troubleshooting.                                                                                                                                                     | Try to create a new directory assessment. If you continue to experience this<br>error, contact [Support](https://aws.amazon.com/premiumsupport/ "https://aws.amazon.com/premiumsupport/").                                                                                                                                                                                 |
| This assessment failed due to missing permission to perform an<br>action like `ec2:CreateSecurityGroup`,<br>`ec2:DeleteSecurityGroup`,<br>`ec2:CreateNetworkInterface`,<br>`ec2:DeleteNetworkInterface`,<br>`ec2:DescribeSubnets`, and<br>`ec2:DescribeNetworkInterface`.                             | To create a directory assessment, your AWS account needs the necessary [AWS account permissions](create_hybrid_directory_prereqs.md#hybrid-dir-prereq-perms "create_hybrid_directory_prereqs.md#hybrid-dir-prereq-perms").                                                                                                                                                 |
| This assessment failed due to missing permission to perform an<br>action like `ssm:GetConnectionStatus`,<br>`ssm:GetCommandInvocation`,<br>`ssm:ListCommands`,<br>`ssm:SendCommand`.                                                                                                                  | To create a directory assessment, you will need two Systems Manager nodes with the necessary<br>[AWS account permissions](create_hybrid_directory_prereqs.md#hybrid-dir-prereq-perms "create_hybrid_directory_prereqs.md#hybrid-dir-prereq-perms").                                                                                                                        |
| This assessment failed as you've reached the limit on the number<br>of network interfaces that you can create. For more information, see<br>[Amazon VPC<br>quotas](../../../vpc/latest/userguide/amazon-vpc-limits.md "../../../vpc/latest/userguide/amazon-vpc-limits.md").                          | To create a directory assessment, you must create a network interface and security<br>groups. There are limits to the number of VPC resources you can<br>create however you can adjust some of these limits. For more<br>information, see [Amazon VPC<br>quotas](../../../vpc/latest/userguide/amazon-vpc-limits.md "../../../vpc/latest/userguide/amazon-vpc-limits.md"). |
| This assessment failed as you have reached the limit on the number<br>of security groups that you can create, or assign to an instance.<br>For more information, see [Amazon VPC<br>quotas](../../../vpc/latest/userguide/amazon-vpc-limits.md "../../../vpc/latest/userguide/amazon-vpc-limits.md"). | To create a directory assessment, you must create a network interface and security<br>groups. There are limits to the number of VPC resources you can<br>create however you can adjust some of these limits. For more<br>information, see [Amazon VPC<br>quotas](../../../vpc/latest/userguide/amazon-vpc-limits.md "../../../vpc/latest/userguide/amazon-vpc-limits.md"). |
| This assessment failed. Unable to connect to customer instances<br>from AWS Systems Manager.                                                                                                                                                                                                          | To create a directory assessment, you will need two AWS Systems Manager nodes that have a<br>connected status. See [Troubleshooting SSM Agent](../../../systems-manager/latest/userguide/troubleshooting-ssm-agent.md "../../../systems-manager/latest/userguide/troubleshooting-ssm-agent.md").                                                                           |
| This assessment failed multiple critical tests. Investigate the<br>failed tests by selecting each managed instance and resolve them in<br>your on-premises directory.
