# Deleting directory assessments

You can delete customer-created directory assessments in the AWS Management Console. You can't delete
system-initiated assessments that AWS creates automatically.

###### To delete a customer directory assessment

1. Open the AWS Directory Service console at [https://console.aws.amazon.com/directoryservicev2/](https://console.aws.amazon.com/directoryservicev2/ "https://console.aws.amazon.com/directoryservicev2/").
2. On the **Directories** page, under the
   **Directory assessments** section, choose the customer assessment you want
   to delete. Alternatively, you can choose the checkbox beside the directory assessments you want
   to delete and then from the **Actions** menu, choose
   **Delete**.
3. You're directed to the **Assessments** details page. Choose
   **Actions** and then choose **Delete
   Assessment**. A **Delete directory assessment** dialog box
   appears. Choose **Delete**.
