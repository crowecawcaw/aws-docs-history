# Service level agreement for Directory Service

Directory Service is a highly available service, and is built on AWS-managed infrastructure. It is
backed by a service level (SLA) agreement that defines our service availability policy.

- The SLA applies to AWS Managed Microsoft AD, AD Connector, and Simple AD.
- The SLA discusses service credits, SLA exclusions, and defines terms like "Covered
  Directory", "Monthly Uptime Percentage", and "Requests".
- For more information, see [Service
  level agreement for Directory Service](https://aws.amazon.com/directoryservice/sla/ "https://aws.amazon.com/directoryservice/sla/").
