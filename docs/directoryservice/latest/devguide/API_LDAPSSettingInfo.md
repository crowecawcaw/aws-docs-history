

# LDAPSSettingInfo
<a name="API_LDAPSSettingInfo"></a>

Contains general information about the LDAPS settings.

## Contents
<a name="API_LDAPSSettingInfo_Contents"></a>

 ** LastUpdatedDateTime **   <a name="DirectoryService-Type-LDAPSSettingInfo-LastUpdatedDateTime"></a>
The date and time when the LDAPS settings were last updated.  
Type: Timestamp  
Required: No

 ** LDAPSStatus **   <a name="DirectoryService-Type-LDAPSSettingInfo-LDAPSStatus"></a>
The state of the LDAPS settings.  
Type: String  
Valid Values: `Enabling | Enabled | EnableFailed | Disabled`   
Required: No

 ** LDAPSStatusReason **   <a name="DirectoryService-Type-LDAPSSettingInfo-LDAPSStatusReason"></a>
Describes a state change for LDAPS.  
Type: String  
Required: No
