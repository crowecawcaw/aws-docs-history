# CloudTrail Lake integrations event

schema

The following table describes the required and optional schema elements that match
those in CloudTrail event records. The contents of `eventData` are provided by
your events; other fields are provided by CloudTrail after ingestion.

CloudTrail event record contents are described in more detail in [CloudTrail record contents for management, data, and network activity events](cloudtrail-event-reference-record-contents.md "cloudtrail-event-reference-record-contents.md").

- [Fields that are provided by CloudTrail after
  ingestion](#fields-cloudtrail "#fields-cloudtrail")
- [Fields that are provided by your
  events](#fields-event "#fields-event")
  The following fields are provided by CloudTrail after ingestion:

| Field name                | Input type  | Requirement | Description                                                                                                                                                                                           |
| ------------------------- | ----------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| eventVersion              | string      | Required    | The event version.                                                                                                                                                                                    |
| eventCategory             | string      | Required    | The event category. For non-AWS events, the value is `ActivityAuditLog`.                                                                                                                              |
| eventType                 | string      | Required    | The event type. For non-AWS events, the valid value is `ActivityLog`.                                                                                                                                 |
| eventID                   | string      | Required    | A unique ID for an event.                                                                                                                                                                             |
| eventTime                 | string      | Required    | Event timestamp, in `yyyy-MM-DDTHH:mm:ss` format, in Universal Coordinated Time (UTC).                                                                                                                |
| awsRegion                 | string      | Required    | The AWS Region where the `PutAuditEvents` call was made.                                                                                                                                              |
| recipientAccountId        | string      | Required    | Represents the account ID that received this event. CloudTrail populates this field by calculating it from event payload.                                                                             |
| addendum                  | -           | Optional    | Shows information about why event processing was delayed. If information was missing from an existing event, the addendum block includes the missing information and a reason for why it was missing. |
| <br>• reason              | string      | Optional    | The reason that the event or some of its contents were missing.                                                                                                                                       |
| <br>• updatedFields       | string      | Optional    | The event record fields that are updated by the addendum. This is only provided if the reason is `UPDATED_DATA`.                                                                                      |
| <br>• originalUID         | string      | Optional    | The original event UID from the source. This is only provided if the reason is `UPDATED_DATA`.                                                                                                        |
| <br>• originalEventID     | string      | Optional    | The original event ID. This is only provided if the reason is `UPDATED_DATA`.                                                                                                                         |
| metadata                  | -           | Required    | Information about the channel that the event used.                                                                                                                                                    |
| <br>• ingestionTime       | string      | Required    | The timestamp when the event was processed, in `yyyy-MM-DDTHH:mm:ss` format, in Universal Coordinated Time (UTC).                                                                                     |
| <br>• channelARN          | string      | Required    | The ARN of the channel that the event used.                                                                                                                                                           | The following fields are provided by customer events:                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Field name                | Input type  | Requirement | Description                                                                                                                                                                                           |
| ---                       | ---         | ---         | ---                                                                                                                                                                                                   |
| eventData                 | -           | Required    | The audit data sent to CloudTrail in a `PutAuditEvents` call.                                                                                                                                         |
| <br>• version             | string      | Required    | The version of the event from its source. Length constraints: Maximum length of 256.                                                                                                                  |
| <br>• userIdentity        | -           | Required    | Information about the user who made a request.                                                                                                                                                        |
| <br>• + type              | string      | Required    | The type of user identity. Length constraints: Maximum length of 128.                                                                                                                                 |
| <br>• + principalId       | string      | Required    | A unique identifier for the actor of the event. Length constraints: Maximum length of 1024.                                                                                                           |
| <br>• + details           | JSON object | Optional    | Additional information about the identity.                                                                                                                                                            |
| <br>• userAgent           | string      | Optional    | The agent through which the request was made. Length constraints: Maximum length of 1024.                                                                                                             |
| <br>• eventSource         | string      | Required    | This is the partner event source, or the custom application about which events are logged. Length constraints: Maximum length of 1024.                                                                |
| <br>• eventName           | string      | Required    | The requested action, one of the actions in the API for the source service or application. Length constraints: Maximum length of 1024.                                                                |
| <br>• eventTime           | string      | Required    | Event timestamp, in `yyyy-MM-DDTHH:mm:ss` format, in Universal Coordinated Time (UTC).                                                                                                                |
| <br>• UID                 | string      | Required    | The UID value that identifies the request. The service or application that is called generates this value. Length constraints: Maximum length of 1024.                                                |
| <br>• requestParameters   | JSON object | Optional    | The parameters, if any, that were sent with the request. This field has a maximum size of 100 kB, and content exceeding the limit is rejected.                                                        |
| <br>• responseElements    | JSON object | Optional    | The response element for actions that make changes (create, update, or delete actions). This field has a maximum size of 100 kB, and content exceeding the limit is rejected.                         |
| <br>• errorCode           | string      | Optional    | A string representing an error for the event. Length constraints: Maximum length of 256.                                                                                                              |
| <br>• errorMessage        | string      | Optional    | The description of the error. Length constraints: Maximum length of 256.                                                                                                                              |
| <br>• sourceIPAddress     | string      | Optional    | The IP address from which the request was made. Both IPv4 and IPv6 addresses are accepted.                                                                                                            |
| <br>• recipientAccountId  | string      | Required    | Represents the account ID that received this event. The account ID must be the same as the AWS account ID that owns the channel.                                                                      |
| <br>• additionalEventData | JSON object | Optional    | Additional data about the event that was not part of the request or response.
