# TrailInfo

Information about a CloudTrail trail, including the trail's name, home Region,
 and Amazon Resource Name (ARN).


## Contents





**HomeRegion** 


The AWS Region in which a trail was created.


Type: String


Required: No




**Name** 


The name of a trail.


Type: String


Required: No




**TrailARN** 


The ARN of a trail.


Type: String


Required: No
