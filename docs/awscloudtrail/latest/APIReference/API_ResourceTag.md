# ResourceTag

A resource tag.


## Contents





**ResourceId** 


Specifies the ARN of the resource.


Type: String


Required: No




**TagsList** 


A list of tags.


Type: Array of [Tag](API_Tag.md "API_Tag.md") objects


Array Members: Maximum number of 200 items.


Required: No
