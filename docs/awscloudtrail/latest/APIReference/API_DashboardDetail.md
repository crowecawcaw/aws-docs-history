# DashboardDetail


Provides information about a CloudTrail Lake dashboard.



## Contents





**DashboardArn** 



The ARN for the dashboard.



Type: String


Pattern: `^[a-zA-Z0-9._/\-:]+$`



Required: No




**Type** 



The type of dashboard.



Type: String


Valid Values: `MANAGED | CUSTOM`



Required: No
