# About this Guide

This guide describes how to install AWS Elemental Statmux software for the first time. These
are the reference documents for each installation type.

| Installation type                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Node-locked licenses on AWS Elemental appliances | You received AWS Elemental Appliance edition hardware, which comes with<br>the appropriate licenses already installed. To complete setup of each node,<br>see the getting started guide that came in your product box or [Cabling Setup](../../../elemental-onprem/latest/pdf/DOC-1991.md "../../../elemental-onprem/latest/pdf/DOC-1991.md"). If you're using AWS Elemental Conductor Live 3 to<br>control your Statmux nodes, see [AWS Elemental Conductor Live 3 Installation Guide](../../../elemental-cl3/latest/installguide.md "../../../elemental-cl3/latest/installguide.md") as well. |
| Node-locked licenses on hardware                 | You're installing unique licenses for each piece of physical, qualified<br>hardware that's running AWS Elemental software. See [Installing AWS Elemental Statmux Node-locked Licenses on Qualified Hardware](install-sm-ig.md "install-sm-ig.md").If you're using AWS Elemental Conductor Live 3 to control your Statmux<br>nodes, see [AWS Elemental Conductor Live 3 Installation Guide](../../../elemental-cl3/latest/installguide.md "../../../elemental-cl3/latest/installguide.md") as well.                                                                                              |

All of these scenarios get you through phase 1 of the installation process: the
preconfigured operating system is installed, the software is installed, eth0 is configured,
and licenses are installed. Phase 2 is configuration of the software and is addressed in
[AWS Elemental Statmux Configuration Guide](../configguide.md "../configguide.md").
