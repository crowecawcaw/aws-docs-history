# Configure DNS and NTP Servers
<a name="config-wrkr-sm-cg-servers"></a>

You can add Domain Name System (DNS) name servers and Network Time Protocol (NTP) servers for the node to use.

**To configure servers**

1. On the AWS Elemental Statmux web interface, go to the **Settings** page and choose **Network**.

1. On the **Network** page, choose **Hostname, DNS & NTP**.

1. As needed, add one server at a time to the **DNS Name Servers** and **NTP Servers** fields and choose **Save**.
