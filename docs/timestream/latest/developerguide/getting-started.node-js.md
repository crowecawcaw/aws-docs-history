# Node.js

To get started with the [Node.js SDK](https://aws.amazon.com/sdk-for-node-js/ "https://aws.amazon.com/sdk-for-node-js/") and Amazon Timestream,

## Prerequisites

Before you get started with Node.js, you must do the
following:

1. [Install Node.js](https://nodejs.org/en/ "https://nodejs.org/en/").
2. [Install the AWS SDK for JavaScript](https://aws.amazon.com/sdk-for-node-js/ "https://aws.amazon.com/sdk-for-node-js/").
