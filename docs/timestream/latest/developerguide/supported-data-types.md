# Supported data types

Timestream for LiveAnalytics's query language supports the following data types.

###### Note

Data types supported for writes are described in [Data types](writes.md#writes.data-types "writes.md#writes.data-types").

| Data type                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `int`                                 | Represents a 32-bit integer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `bigint`                              | Represents a 64-bit signed integer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `boolean`                             | One of the two truth values of logic, `True` and `False`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `double`                              | Represents a 64-bit variable-precision data type. Implements [IEEE Standard 754 for Binary<br>Floating-Point Arithmetic](https://standards.ieee.org/standard/754-2019.html "https://standards.ieee.org/standard/754-2019.html").<br>NoteThe query language is for reading data. There are functions for `Infinity`<br>and `NaN` double values which can be used in queries. But you cannot write those<br>values to Timestream.                                                                                                                                                                                                                                                                                                            |
| `varchar`                             | Variable length character data with a maximum size of 2KB.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `array[`T`,...]`                      | Contains one or more elements of a specified data type `T`,<br>where `T` can be any of the data types supported in<br>Timestream.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `row(`T`,...)`                        | Contains one or more named fields of data type `T`. The fields<br>may be of any data type supported by Timestream, and are accessed with the dot field<br>reference operator:<br>`<br>.<br>`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `date`                                | Represents a date in the form<br>``YYYY`-`MM`-`DD``.<br>where `YYYY` is the year, `MM` is the<br>month, and `DD` is the day, respectively. The supported range is<br>from `1970-01-01` to `2262-04-11`.<br>_Example:_<br>`<br>1971-02-03<br>`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `time`                                | Represents the time of day in [UTC](https://en.wikipedia.org/wiki/Coordinated_Universal_Time "https://en.wikipedia.org/wiki/Coordinated_Universal_Time"). The<br>`time` datatype is represented in the form<br>``HH`.`MM`.`SS`.`sssssssss`.`<br>Supports nanosecond precision.<br>_Example:_<br>`<br>17:02:07.496000000<br>`                                                                                                                                                                                                                                                                                                                                                                                                               |
| `timestamp`                           | Represents an instance in time using nanosecond precision time in UTC.<br>``YYYY`-`MM`-`DD`<br>`hh`:`mm`:`ss`.`sssssssss``<br>Query supports timestamps in the range `1677-09-21 00:12:44.000000000` to<br>`2262-04-11 23:47:16.854775807`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `interval`                            | Represents an interval of time as a string literal<br>`Xt`, composed of two parts,<br>`X` and `t`.<br>`X` is an numeric value greater than or equal to `0`, and<br>`t` is a unit of time like second or hour. The unit is not<br>pluralized. The unit of time `t` is must be one of the following<br>string literals:<br>• `nanosecond`<br>• `microsecond`<br>• `millisecond`<br>• `second`<br>• `minute`<br>• `hour`<br>• `day`<br>• `ns` (same as `nanosecond`)<br>• `us` (same as `microsecond`)<br>• `ms` (same as `millisecond`)<br>• `s` (same as `second`)<br>• `m` (same as `minute`)<br>• `h` (same as `hour`)<br>• `d` (same as `day`)<br>_Examples:_<br>`<br>17s<br>`<br>`<br>12second<br>`<br>`<br>21hour<br>`<br>`<br>2d<br>` |
| `timeseries[row(timestamp, `T`,...)]` | Represents the values of a measure recorded over a time interval as an<br>`array` composed of `row` objects. Each `row` contains a<br>`timestamp` and one or more measure values of data type<br>`T`, where `T` can be any one of<br>`bigint`, `boolean`, `double`, or `varchar`.<br>Rows are assorted in ascending order by `timestamp`. The<br>\*timeseries<br>• datatype represents the values of a measure over<br>time.                                                                                                                                                                                                                                                                                                               |
| `unknown`                             | Represents null data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
