# Aggregate functions

Timestream for LiveAnalytics supports the following aggregate functions.

| Function                                      | Output data type      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| arbitrary(x)                                  | [same as input]       | Returns an arbitrary non-null value of x, if one exists.<br>`<br>SELECT arbitrary(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| array_agg(x)                                  | array<[same as input] | Returns an array created from the input x elements.<br>`<br>SELECT array_agg(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `[ 1,2,3,4 ]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| avg(x)                                        | double                | Returns the average (arithmetic mean) of all input values.<br>`<br>SELECT avg(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `2.5`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| bool_and(boolean) every(boolean)              | boolean               | Returns TRUE if every input value is TRUE, otherwise FALSE.<br>`<br>SELECT bool_and(t.c) FROM (VALUES true, true, false, true) AS t(c)<br>`<br>Example result: `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| bool_or(boolean)                              | boolean               | Returns TRUE if any input value is TRUE, otherwise FALSE.<br>`<br>SELECT bool_or(t.c) FROM (VALUES true, true, false, true) AS t(c)<br>`<br>Example result: `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| count(\*) count(x)                            | bigint                | count(\*) returns the number of input rows.<br>count(x) returns the number of non-null input values.<br>`<br>SELECT count(t.c) FROM (VALUES true, true, false, true) AS t(c)<br>`<br>Example result: `4`                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| count_if(x)                                   | bigint                | Returns the number of TRUE input values.<br>`<br>SELECT count_if(t.c) FROM (VALUES true, true, false, true) AS t(c)<br>`<br>Example result: `3`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| geometric_mean(x)                             | double                | Returns the geometric mean of all input values.<br>`<br>SELECT geometric_mean(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `2.213363839400643`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| max_by(x, y)                                  | [same as x]           | Returns the value of x associated with the maximum value of y over all input<br>values.<br>`<br>SELECT max_by(t.c1, t.c2) FROM (VALUES (('a', 1)), (('b', 2)), (('c', 3)), (('d', 4))) AS t(c1, c2)<br>`<br>Example result: `d`                                                                                                                                                                                                                                                                                                                                                                                                                               |
| max_by(x, y, n)                               | array<[same as x]>    | Returns n values of x associated with the n largest of all input values of y<br>in descending order of y.<br>`<br>SELECT max_by(t.c1, t.c2, 2) FROM (VALUES (('a', 1)), (('b', 2)), (('c', 3)), (('d', 4))) AS t(c1, c2)<br>`<br>Example result: `[ d,c ]`                                                                                                                                                                                                                                                                                                                                                                                                    |
| min_by(x, y)                                  | [same as x]           | Returns the value of x associated with the minimum value of y over all input<br>values.<br>`<br>SELECT min_by(t.c1, t.c2) FROM (VALUES (('a', 1)), (('b', 2)), (('c', 3)), (('d', 4))) AS t(c1, c2)<br>`<br>Example result: `a`                                                                                                                                                                                                                                                                                                                                                                                                                               |
| min_by(x, y, n)                               | array<[same as x]>    | Returns n values of x associated with the n smallest of all input values of<br>y in ascending order of y.<br>`<br>SELECT min_by(t.c1, t.c2, 2) FROM (VALUES (('a', 1)), (('b', 2)), (('c', 3)), (('d', 4))) AS t(c1, c2)<br>`<br>Example result: `[ a,b ]`                                                                                                                                                                                                                                                                                                                                                                                                    |
| max(x)                                        | [same as input]       | Returns the maximum value of all input values.<br>`<br>SELECT max(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `4`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| max(x, n)                                     | array<[same as x]>    | Returns n largest values of all input values of x.<br>`<br>SELECT max(t.c, 2) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `[ 4,3 ]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| min(x)                                        | [same as input]       | Returns the minimum value of all input values.<br>`<br>SELECT min(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| min(x, n)                                     | array<[same as x]>    | Returns n smallest values of all input values of x.<br>`<br>SELECT min(t.c, 2) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `[ 1,2 ]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| sum(x)                                        | [same as input]       | Returns the sum of all input values.<br>`<br>SELECT sum(t.c) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `10`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| bitwise_and_agg(x)                            | bigint                | Returns the bitwise AND of all input values in 2’s complement<br>representation.<br>`<br>SELECT bitwise_and_agg(t.c) FROM (VALUES 1, -3) AS t(c)<br>`<br>Example result: `1`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| bitwise_or_agg(x)                             | bigint                | Returns the bitwise OR of all input values in 2’s complement<br>representation.<br>`<br>SELECT bitwise_or_agg(t.c) FROM (VALUES 1, -3) AS t(c)<br>`<br>Example result: `-3`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| approx_distinct(x)                            | bigint                | Returns the approximate number of distinct input values. This function<br>provides an approximation of count(DISTINCT x). Zero is returned if all input<br>values are null. This function should produce a standard error of 2.3%, which<br>is the standard deviation of the (approximately normal) error distribution over<br>all possible sets. It does not guarantee an upper bound on the error for any<br>specific input set.<br>`<br>SELECT approx_distinct(t.c) FROM (VALUES 1, 2, 3, 4, 8) AS t(c)<br>`<br>Example result: `5`                                                                                                                        |
| approx_distinct(x, e)                         | bigint                | Returns the approximate number of distinct input values. This function<br>provides an approximation of count(DISTINCT x). Zero is returned if all input<br>values are null. This function should produce a standard error of no more than<br>e, which is the standard deviation of the (approximately normal) error<br>distribution over all possible sets. It does not guarantee an upper bound on<br>the error for any specific input set. The current implementation of this<br>function requires that e be in the range of [0.0040625, 0.26000].<br>`<br>SELECT approx_distinct(t.c, 0.2) FROM (VALUES 1, 2, 3, 4, 8) AS t(c)<br>`<br>Example result: `5` |
| approx_percentile(x, percentage)              | [same as x]           | Returns the approximate percentile for all input values of x at the given<br>percentage. The value of percentage must be between zero and one and must be<br>constant for all input rows.<br>`<br>SELECT approx_percentile(t.c, 0.4) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `2`                                                                                                                                                                                                                                                                                                                                                             |
| approx_percentile(x, percentages)             | array<[same as x]>    | Returns the approximate percentile for all input values of x at each of the<br>specified percentages. Each element of the percentages array must be between<br>zero and one, and the array must be constant for all input rows.<br>`<br>SELECT approx_percentile(t.c, ARRAY[0.1, 0.8, 0.8]) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `[ 1,4,4 ]`                                                                                                                                                                                                                                                                                              |
| approx_percentile(x, w, percentage)           | [same as x]           | Returns the approximate weighed percentile for all input values of x using<br>the per-item weight w at the percentage p. The weight must be an integer value<br>of at least one. It is effectively a replication count for the value x in the<br>percentile set. The value of p must be between zero and one and must be<br>constant for all input rows.<br>`<br>SELECT approx_percentile(t.c, 1, 0.1) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `1`                                                                                                                                                                                           |
| approx_percentile(x, w, percentages)          | array<[same as x]>    | Returns the approximate weighed percentile for all input values of x using<br>the per-item weight w at each of the given percentages specified in the array.<br>The weight must be an integer value of at least one. It is effectively a<br>replication count for the value x in the percentile set. Each element of the<br>array must be between zero and one, and the array must be constant for all<br>input rows.<br>`<br>SELECT approx_percentile(t.c, 1, ARRAY[0.1, 0.8, 0.8]) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `[ 1,4,4 ]`                                                                                                     |
| approx_percentile(x, w, percentage, accuracy) | [same as x]           | Returns the approximate weighed percentile for all input values of x using<br>the per-item weight w at the percentage p, with a maximum rank error of<br>accuracy. The weight must be an integer value of at least one. It is<br>effectively a replication count for the value x in the percentile set. The<br>value of p must be between zero and one and must be constant for all input<br>rows. The accuracy must be a value greater than zero and less than one, and it must<br>be constant for all input rows.<br>`<br>SELECT approx_percentile(t.c, 1, 0.1, 0.5) FROM (VALUES 1, 2, 3, 4) AS t(c)<br>`<br>Example result: `1`                           |
| corr(y, x)                                    | double                | Returns correlation coefficient of input values.<br>`<br>SELECT corr(t.c1, t.c2) FROM (VALUES ((1, 1)), ((2, 2)), ((3, 3)), ((4, 4))) AS t(c1, c2)<br>`<br>Example result: `1.0`                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| covar_pop(y, x)                               | double                | Returns the population covariance of input values.<br>`<br>SELECT covar_pop(t.c1, t.c2) FROM (VALUES ((1, 1)), ((2, 2)), ((3, 3)), ((4, 4))) AS t(c1, c2)<br>`<br>Example result: `1.25`                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| covar_samp(y, x)                              | double                | Returns the sample covariance of input values.<br>`<br>SELECT covar_samp(t.c1, t.c2) FROM (VALUES ((1, 1)), ((2, 2)), ((3, 3)), ((4, 4))) AS t(c1, c2)<br>`<br>Example result: `1.6666666666666667`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| regr_intercept(y, x)                          | double                | Returns linear regression intercept of input values. y is the dependent<br>value. x is the independent value.<br>`<br>SELECT regr_intercept(t.c1, t.c2) FROM (VALUES ((1, 1)), ((2, 2)), ((3, 3)), ((4, 4))) AS t(c1, c2)<br>`<br>Example result: `0.0`                                                                                                                                                                                                                                                                                                                                                                                                       |
| regr_slope(y, x)                              | double                | Returns linear regression slope of input values. y is the dependent value. x<br>is the independent value.<br>`<br>SELECT regr_slope(t.c1, t.c2) FROM (VALUES ((1, 1)), ((2, 2)), ((3, 3)), ((4, 4))) AS t(c1, c2)<br>`<br>Example result: `1.0`                                                                                                                                                                                                                                                                                                                                                                                                               |
| skewness(x)                                   | double                | Returns the skewness of all input values.<br>`<br>SELECT skewness(t.c1) FROM (VALUES 1, 2, 3, 4, 8) AS t(c1)<br>`<br>Example result: `0.8978957037987335`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| stddev_pop(x)                                 | double                | Returns the population standard deviation of all input values.<br>`<br>SELECT stddev_pop(t.c1) FROM (VALUES 1, 2, 3, 4, 8) AS t(c1)<br>`<br>Example result: `2.4166091947189146`                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| stddev_samp(x) stddev(x)                      | double                | Returns the sample standard deviation of all input values.<br>`<br>SELECT stddev_samp(t.c1) FROM (VALUES 1, 2, 3, 4, 8) AS t(c1)<br>`<br>Example result: `2.701851217221259`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| var_pop(x)                                    | double                | Returns the population variance of all input values.<br>`<br>SELECT var_pop(t.c1) FROM (VALUES 1, 2, 3, 4, 8) AS t(c1)<br>`<br>Example result: `5.840000000000001`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| var_samp(x) variance(x)                       | double                | Returns the sample variance of all input values.<br>`<br>SELECT var_samp(t.c1) FROM (VALUES 1, 2, 3, 4, 8) AS t(c1)<br>`<br>Example result: `7.300000000000001`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
