# Using the AWS SDKs

You can access Amazon Timestream using the AWS SDKs.
Timestream supports two SDKs per language;
namely, the Write SDK and the Query SDK.
The Write SDK is used to perform CRUD operations and to insert your time series data into Timestream.
The Query SDK is used to query your existing time series data stored in Timestream.

Once you've completed the necessary prerequisites for your SDK of choice, you can get started with the [Code samples](code-samples.md "code-samples.md").
