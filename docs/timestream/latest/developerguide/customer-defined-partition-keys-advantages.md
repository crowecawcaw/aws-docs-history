# Advantages of

customer-defined partition keys

**Enhanced query performance:** Customer-defined
partition keys enable you to optimize your query execution and improve overall query
performance. By defining partition keys that align with your query patterns, you can
minimize data scanning and optimize data pruning, resulting in lower query
latency.

**Better long term performance predictability:** Customer-defined partition keys allow customers to distribute data evenly
across partitions, improving the efficiency of data management. This will ensure that
your query performance remains stable as your data stored scales over time.
