# Endpoint

Represents an available endpoint against which to make API calls against, as well as the TTL for that
endpoint.

## Contents

**Address**

An endpoint address.

Type: String

Required: Yes

**CachePeriodInMinutes**

The TTL for the endpoint, in minutes.

Type: Long

Required: Yes
