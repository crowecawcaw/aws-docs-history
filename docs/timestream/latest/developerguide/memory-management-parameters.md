# Category 2: Memory Management
<a name="memory-management-parameters"></a>

These parameters control how memory is allocated across query execution, caching, and data management. Proper memory tuning is critical — InfluxDB 3 is memory-intensive, and misconfiguration can lead to out-of-memory conditions or underutilization.
