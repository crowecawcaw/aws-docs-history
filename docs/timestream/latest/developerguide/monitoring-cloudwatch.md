# Monitoring with Amazon CloudWatch

You can monitor Timestream for LiveAnalytics using Amazon CloudWatch, which collects and processes raw data from Timestream for LiveAnalytics
into readable, near-real-time metrics. It records these statistics for two weeks so that you
can access historical information and gain a better perspective on how your web application or
service is performing. By default, Timestream for LiveAnalytics metric data is automatically sent to CloudWatch in 1-minute
or 15-minute periods. For more information, see [What Is Amazon CloudWatch?](../../../AmazonCloudWatch/latest/DeveloperGuide/WhatIsCloudWatch.md "../../../AmazonCloudWatch/latest/DeveloperGuide/WhatIsCloudWatch.md")
in the _Amazon CloudWatch User Guide_.
