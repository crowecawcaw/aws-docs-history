# .NET

To get started with the [.NET SDK](https://aws.amazon.com/sdk-for-net/ "https://aws.amazon.com/sdk-for-net/") and Amazon Timestream,
complete the prerequisites, described below.

Once you've completed the necessary prerequisites for the .NET SDK, you can get started with the [Code samples](code-samples.md "code-samples.md").

## Prerequisites

Before you get started with .NET, install the required NuGet packages and ensure that AWSSDK.Core version is 3.3.107 or newer by running the following commands:

```
dotnet add package AWSSDK.Core
dotnet add package AWSSDK.TimestreamWrite
dotnet add package AWSSDK.TimestreamQuery
```
