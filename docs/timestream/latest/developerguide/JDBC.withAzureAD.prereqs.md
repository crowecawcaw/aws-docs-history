Ensure that you have met the following prerequisites before using the Timestream for LiveAnalytics
JDBC single sign-on authentication with Microsoft Azure AD:

- [Admin permissions in AWS to create the
  identity provider and the roles](security-iam.md "security-iam.md").
- An Azure Active Directory account (Go to [https://azure.microsoft.com/en-ca/services/active-directory/](https://azure.microsoft.com/en-ca/services/active-directory/ "https://azure.microsoft.com/en-ca/services/active-directory/") to
  create an account)
