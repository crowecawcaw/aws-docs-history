# Logging and Monitoring in Amazon Forecast

Monitoring is an important part of maintaining the reliability, availability, and
performance of your Amazon Forecast applications. To monitor Amazon Forecast API calls, you can use
AWS CloudTrail. To monitor the status of your Forecast assets and processes, use Amazon CloudWatch.
