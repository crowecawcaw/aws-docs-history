# Model

Amazon Fraud Detector uses machine learning models for generating fraud predictions. Each model is trained
using a
_model type_. The model type specifies the
algorithms and transformations used for training the model. Model training is the process of
using a dataset that you provide to create a model that can predict fraudulent events.

To create a model, you must first choose a model type and then prepare and provide data that will be used to train the model.
