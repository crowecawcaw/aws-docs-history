# Tutorial: Get started using the Amazon Fraud Detector

console

This tutorial consists of two parts. The first part describes how to build, train, and deploy a
fraud detection model. The second part covers how to use the model to generate fraud predictions in real time. The model
is trained using the example data file that you upload to an S3 bucket. By the end of this tutorial, you complete the following actions:

- Build and train an Amazon Fraud Detector model
- Generate real-time fraud predictions

###### Important

Before you proceed, make sure that you have followed instructions to [Get and upload example dataset](step-1-get-s3-data.md "step-1-get-s3-data.md")
