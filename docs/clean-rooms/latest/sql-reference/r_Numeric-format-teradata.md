# Teradata-style formatting

characters for numeric data

This topic shows you how the TEXT_TO_INT_ALT and TEXT_TO_NUMERIC_ALT functions interpret
the characters in the input _expression_ string. In the following table,
you can also find a list of the characters that you can specify in the
_format_ phrase. In addition, you can find a description of the
differences between Teradata-style formatting and AWS Clean Rooms for the _format_
option.

| Format             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G                  | Not supported as a group separator in the input<br>*expression<br>• string. You can't specify this<br>character in the *format<br>• phrase.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D                  | Radix symbol. You can specify this character in the<br>*format<br>• phrase. This character is equivalent to the .<br>(period).<br>The radix symbol can't appear in a *format\*<br>phrase that contains any of the following characters:<br>• . (period)<br>• S (uppercase 's')<br>• V (uppercase 'v')                                                                                                                                                                                                                                                                                                                                                       |
| / , : %            | Insertion characters / (forward slash), comma (,), : (colon), and %<br>(percent sign).<br>You can't include these characters in the<br>*format<br>• phrase.<br>AWS Clean Rooms ignores these characters in the input<br>*expression<br>• string.                                                                                                                                                                                                                                                                                                                                                                                                            |
| .                  | Period as a radix character, that is, a decimal point.<br>This character can't appear in a \*format<br>• phrase<br>that contains any of the following characters:<br>• D (uppercase 'd')<br>• S (uppercase 's')<br>• V (uppercase 'v')                                                                                                                                                                                                                                                                                                                                                                                                                      |
| B                  | You can't include the blank space character (B) in the<br>*format<br>• phrase. | V                  | Decimal point position indicator.<br>This character can't appear in a \*format<br>• phrase<br>that contains any of the following characters:<br>• D (uppercase 'd')<br>• . | Z                  | Zero-suppressed decimal digit. AWS Clean Rooms trims leading zeros. The Z character<br>can't follow a 9 character. | 9                  | Decimal digit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

| -                  | Hyphen (-) character.<br>You can't include this character in the _format_<br>phrase.<br>AWS Clean Rooms ignores this character in the input _expression_<br>string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| S                  | Signed zoned decimal. The S character must follow the last decimal digit<br>in the *format<br>• phrase. | U                  | Dual ISO currency symbol. You can't specify this character in the<br>\*format<br>• phrase.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| A                  | Full dual currency name. You can't specify this character in the<br>\*format<br>• phrase.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## Data formatting characters for

signed zoned decimal, Teradata–style numeric data formatting

TEXT_TO_INT_ALT and TEXT_TO_NUMERIC_ALT functions for a signed zoned decimal value.
