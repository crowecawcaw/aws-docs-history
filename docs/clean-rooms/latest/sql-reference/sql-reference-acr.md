# AWS Clean Rooms SQL

###### Note

AWS Clean Rooms will end support for the legacy Clean Rooms SQL analytics engine on December 17th, 2025. Before July 16, 2025, you must request a limit increase via AWS Customer Support to
create any new Clean Rooms SQL engine-based collaborations. Starting July 17, 2025, the
creation of new Clean Rooms SQL engine-based collaborations will no longer be
available.

AWS Clean Rooms SQL enforces rules regarding the use of data types, expressions, and
literals.

For more information about AWS Clean Rooms, see the [AWS Clean Rooms User Guide](../userguide/what-is.md "../userguide/what-is.md") and the [AWS Clean Rooms API
Reference](../apireference/Welcome.md "../apireference/Welcome.md").
