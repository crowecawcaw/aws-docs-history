# PI function

The PI function returns the value of pi to 14 decimal places.

## Syntax

```
PI()
```

## Return type

`DOUBLE PRECISION`

## Examples

To return the value of pi, use the following example.

```
`SELECT PI();`

`+-------------------+
| pi |
+-------------------+
| 3.141592653589793 |
+-------------------+`
```
