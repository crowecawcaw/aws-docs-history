# Integer types

Use the following data types to store whole numbers of various ranges. You can't
store values outside of the allowed range for each type.

| Name           | Storage | Range                                       |
| -------------- | ------- | ------------------------------------------- |
| SMALLINT       | 2 bytes | -32768 to +32767                            |
| INTEGER or INT | 4 bytes | -2147483648 to +2147483647                  |
| BIGINT         | 8 bytes | -9223372036854775808 to 9223372036854775807 |
