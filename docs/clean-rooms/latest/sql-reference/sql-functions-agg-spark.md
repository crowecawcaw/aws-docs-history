# Aggregate functions

Aggregate functions in AWS Clean Rooms Spark SQL are used to perform calculations or operations on a
group of rows and return a single value. They are essential for data analysis and summarization
tasks.

AWS Clean Rooms Spark SQL supports the following aggregate functions:
