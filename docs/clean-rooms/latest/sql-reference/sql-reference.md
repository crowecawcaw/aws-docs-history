# Overview of SQL in AWS Clean Rooms

Welcome to the _AWS Clean Rooms SQL Reference._

AWS Clean Rooms is built around industry-standard Structured Query Language (SQL), a query language
that consists of commands and functions that you use to work with databases and database
objects. SQL also enforces rules regarding the use of data types, expressions, and
literals.

The following topics provide general information about the conventions and naming rules
used in this SQL Reference.
