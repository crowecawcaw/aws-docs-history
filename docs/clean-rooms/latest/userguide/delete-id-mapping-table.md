# Deleting an ID mapping table

As a collaboration member, you can delete an ID mapping table that you have created. This
action prevents the member who can query from querying the table.

###### Warning

Deleting a mapping table permanently removes any populated data.

###### To delete an ID mapping table

1. Sign in to the AWS Management Console and open the [AWS Clean Rooms console](https://console.aws.amazon.com/cleanrooms/home "https://console.aws.amazon.com/cleanrooms/home") with your AWS account (if you haven't yet done so).
2. In the left navigation pane, choose **Collaborations**.
3. Choose the collaboration.
4. Choose the **Entity resolution** tab.
5. For ID mapping tables, choose a table.
6. On the ID mapping table details page, scroll down to view the **ID mapping
   tables**.
7. Choose and ID mapping table, and then choose **Delete**.
8. If you’re certain that you want to delete the ID mapping table, choose
   **Delete**.
