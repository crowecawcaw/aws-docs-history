

# Document history for the AWS Clean Rooms User Guide

For notification about updates to this documentation, you can subscribe to the RSS feed. To subscribe to RSS updates, you must have an RSS plug-in enabled for the browser you are using.

| [Added guidance for CSV headers in split inference requests](#doc-history) | Added guidance about CSV header behavior in split inference requests. When an input CSV file is larger than the configured `maxPayloadInMB` value, SageMaker AI sends the CSV header row only in the first request. Your inference container must accept requests with or without a header row. For more information, see [Model authoring guidelines for the inference container](https://docs.aws.amazon.com/clean-rooms/latest/userguide/inference-model-guidelines.html). | August 20, 2026 | 
| [Support for minimum aggregation thresholds and comparison controls in custom analysis rules](#doc-history) | You can now configure minimum aggregation thresholds and comparison controls in a custom analysis rule. A minimum aggregation threshold requires each result row to represent at least a minimum number of distinct data subjects. With comparison controls, you specify which columns a query can compare against a literal value and which columns it can compare against another column. For more information, see [Minimum aggregation thresholds](https://docs.aws.amazon.com/clean-rooms/latest/userguide/custom-min-agg-thresholds.html) and [Comparison controls](https://docs.aws.amazon.com/clean-rooms/latest/userguide/custom-comparison-controls.html). | August 13, 2026 | 
| [Export query analysis logs](#doc-history) | You can now export redacted Spark logs for a completed SQL query to your own Amazon S3 bucket to troubleshoot failures and analyze query performance.
