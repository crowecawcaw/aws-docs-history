

# Editing an ID mapping table
<a name="edit-id-mapping-table"></a>

As a collaboration member, you can edit the ID mapping table that you have created.

**To edit an ID mapping table**

1. Sign in to the AWS Management Console and open the [AWS Clean Rooms console](https://console.aws.amazon.com/cleanrooms/home) with your AWS account (if you haven't yet done so).

1. In the left navigation pane, choose **Collaborations**.

1. Choose the collaboration.

1. Choose the **Entity resolution** tab.

1. For **ID mapping tables**, choose a table.

1. On the ID mapping table details page, scroll down to view the **ID mapping table details**.

1. Choose **Edit**.

1. On the **Edit ID mapping table** page, update the **Description** or the **Service access information**.

1. Choose **Save changes**.
