# Mapping Amazon RDS personas to this guide

This guide is structured around common Amazon RDS user roles to provide targeted, actionable
guidance based on your responsibilities and objectives. The following table helps you identify
the sections most relevant to your needs, whether you’re a data professional optimizing database
performance, a developer connecting applications, or a security professional ensuring
compliance.

By aligning each chapter with specific challenges and goals, this guide offers a tailored
approach to getting started with Amazon RDS.

| Persona                  | Where to start                                                                                                                  | Why start here?                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cloud implementer        | [Creating your first DB instance](creating.md "creating.md")                                                                    | This chapter guides you through the process of creating a DB instance, including<br>selecting the appropriate engine and configuring instance settings.<br>**Your goals**:<br>• Deploy and manage RDS resources effectively.<br>• Ensure efficient integration into development and deployment workflows.<br>• Master ongoing operational tasks to ensure database availability and<br>performance. |
| Security professional    | [Securing your DB instance](security.md "security.md")                                                                          | This chapter focuses on setting up critical security configurations, including IAM<br>roles, encryption, and networking best practices.<br>**Your goals**:<br>• Ensure regulatory compliance.<br>• Protect data from unauthorized access.<br>• Set up secure networking.                                                                                                                            |
| Developer                | [Connecting to your DB instance](connecting.md "connecting.md")                                                                 | This chapter guides developers through connecting to RDS, including using CLI commands<br>with practical examples.<br>**Your goals**:<br>• Successfully connect to the database.<br>• Troubleshoot connectivity issues.<br>• Automate database connections with Infrastructure as Code (IaC).                                                                                                       |
| Data engineer or manager | [Managing your DB instance](managing.md "managing.md") and [Optimizing and scaling your DB instance](advanced.md "advanced.md") | These chapters provide guidance on monitoring, diagnosing, and optimizing your RDS<br>database to ensure reliable performance and operational efficiency.<br>**Your goals**:<br>• Diagnose and resolve performance issues efficiently.<br>• Monitor database health and ensure uptime.<br>• Implement effective logging and alerting systems.                                                       |
