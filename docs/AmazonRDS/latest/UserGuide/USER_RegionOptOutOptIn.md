# Region opt-out and opt-in behavior for Amazon RDS resources

AWS allows you to enable and disable certain AWS Regions for your account. When you
disable (opt out of) a Region, you can no longer access resources in that Region. When you
enable (opt in to) a Region, you can use it again. This topic explains how opting out of and
opting in to a Region affects your Amazon RDS resources.

For general information about AWS Regions and how to enable or disable them, see [Managing AWS
Regions](../../../accounts/latest/reference/manage-acct-regions.md "../../../accounts/latest/reference/manage-acct-regions.md") in the _AWS Account Management Reference
Guide_. For information about which Regions are available For
Amazon RDS, see [Regions, Availability Zones, and Local Zones](Concepts.RegionsAndAvailabilityZones.md "Concepts.RegionsAndAvailabilityZones.md").
