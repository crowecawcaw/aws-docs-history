# Troubleshooting connections to your Oracle DB

instance

The following are issues you might encounter when you try to connect to your Oracle DB instance.

| Issue                                                                                                        | Troubleshooting suggestions                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unable to connect to your DB instance.                                                                       | For a newly created DB instance, the DB instance has a status of<br>**creating\*<br>• until it is ready to use. When the state changes to<br>**available\*\*, you can connect to the DB instance. Depending on the DB<br>instance class and the amount of storage, it can take up to 20 minutes before the new DB<br>instance is available.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Unable to connect to your DB instance.                                                                       | If you can't send or receive communications over the port that you specified when you<br>created the DB instance, you can't connect to the DB instance. Check with your network<br>administrator to verify that the port you specified for your DB instance allows inbound and<br>outbound communication.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Unable to connect to your DB instance.                                                                       | The access rules enforced by your local firewall and the IP addresses you authorized to<br>access your DB instance in the security group for the DB instance might not match. The<br>problem is most likely the inbound or outbound rules on your firewall.<br>You can add or edit an inbound rule in the security group. For **Source**,<br>choose **My IP**. This allows access to the DB instance from the IP address<br>detected in your browser. For more information, see [Amazon VPC and Amazon RDS](USER_VPC.md "USER_VPC.md").<br>For more information about security groups, see [Controlling access with security<br>groups](Overview.md "Overview.md").<br>To walk through the process of setting up rules for your security group, see [Tutorial: Create a VPC for use with a<br>DB instance (IPv4 only)](CHAP_Tutorials.WebServerDB.md "CHAP_Tutorials.WebServerDB.md"). |
| **Connect failed because target host or object does not exist – Oracle,<br>Error: ORA-12545**                | Make sure that you specified the server name and port number correctly. For<br>**Server name**, enter the DNS name from the console.<br>For information about finding the DNS name and port number for a DB instance, see [Finding the endpoint of your RDS for Oracle DB instance](USER_Endpoint.md "USER_Endpoint.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Invalid username/password; logon denied – Oracle, Error:<br>ORA-01017**                                    | You were able to reach the DB instance, but the connection was refused. This is usually<br>caused by providing an incorrect user name or password. Verify the user name and password,<br>and then retry.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **TNS:listener does not currently know of SID given in connect descriptor<br>• Oracle,<br>ERROR: ORA-12505** | Ensure the correct SID is entered. The SID is the same as your DB<br>name. Find the DB name in the **Configuration\*<br>• tab<br>of the **Databases*<br>• page for your instance. You<br>can also find the DB name using the AWS CLI:<br>```<br>aws rds describe-db-instances --query 'DBInstances[*].[DBInstanceIdentifier,DBName]' --output text<br>```                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

For more information on connection issues, see [Can't connect to Amazon RDS DB instance](CHAP_Troubleshooting.md#CHAP_Troubleshooting.Connecting "CHAP_Troubleshooting.md#CHAP_Troubleshooting.Connecting").
