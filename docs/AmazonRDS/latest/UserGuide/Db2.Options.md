

# Options for Amazon RDS for Db2 DB instances
<a name="Db2.Options"></a>

The following shows the options, or additional features, that are available for Amazon RDS instances running the Db2 DB engine. To enable these options, you can add them to a custom option group, and then associate the option group with your DB instance. For more information about working with option groups, see [Working with option groups](USER_WorkingWithOptionGroups.md).

Amazon RDS supports the following options for Db2:


| Option | Option ID | 
| --- | --- | 
| [Db2 audit logging](Db2.Options.Audit.md) | `DB2_AUDIT` |
