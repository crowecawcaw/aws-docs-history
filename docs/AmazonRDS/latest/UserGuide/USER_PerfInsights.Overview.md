

# Overview of Database Insights on Amazon RDS
<a name="USER_PerfInsights.Overview"></a>

By default, RDS enables Database Insights in Advanced mode, which includes lock diagnostics, execution plan capture, and fleet-level monitoring.

**Important**  
The following topics describe using Database Insights with non-Aurora DB engines. For information about using Database Insights with Amazon Aurora, see [Using Database Insights](https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/USER_PerfInsights.html) in the *Amazon Aurora User Guide*.
