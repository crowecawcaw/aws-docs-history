# Overview of Database Insights on Amazon RDS

By default, RDS enables Database Insights in Advanced mode, which includes lock diagnostics, execution plan capture, and fleet-level monitoring.

###### Important

The following topics describe using Database Insights with non-Aurora DB engines.
For information about using Database Insights with Amazon Aurora, see [Using Database Insights](../AuroraUserGuide/USER_PerfInsights.md "../AuroraUserGuide/USER_PerfInsights.md") in the _Amazon Aurora User Guide_.
