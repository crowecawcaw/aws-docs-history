# Migrating to Amazon RDS for Db2 with AWS Database Migration Service (AWS DMS)

You can use AWS DMS for one-time migrations and then synchronize from Db2 on Linux,
Unix (such as AIX), and Windows to Amazon RDS for Db2. For more information, see [What is
AWS Database Migration Service?](../../../dms/latest/userguide/Welcome.md "../../../dms/latest/userguide/Welcome.md").
