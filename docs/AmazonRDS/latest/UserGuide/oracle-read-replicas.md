read replicas, see [Overview of Amazon RDS read replicas](USER_ReadRepl.md#USER_ReadRepl.Overview "USER_ReadRepl.md#USER_ReadRepl.Overview"). For a summary of
the differences between Oracle replicas and other DB engines, see [Differences between read replicas for DB engines](USER_ReadRepl.Overview.md "USER_ReadRepl.Overview.md").
