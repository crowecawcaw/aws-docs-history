# Managed kdb Insights

environments

The Managed kdb Insights environment provides a logical container where you can launch
and run clusters, and store data from kdb that can be used by the clusters.

All resources in the Managed kdb environment run in AWS managed accounts and not in
the customer account. The Managed kdb environment dedicated account is not shared with the
existing FinSpace dataset browser environment.
