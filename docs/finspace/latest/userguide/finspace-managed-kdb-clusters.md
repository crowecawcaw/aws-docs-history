# Managed kdb Insights clusters

A FinSpace Managed kdb Insights cluster is a set of compute resources that run kdb processes
in a FinSpace Managed kdb environment. By using FinSpace Managed kdb clusters, you can easily set
up your own private managed data processing and analytics hub for capital markets data.
This provides access to real-time and historical data along with high-performance
analytics.
