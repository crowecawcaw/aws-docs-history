# Running code on a Managed kdb

Insights cluster

Q is the programming system for working with kdb+. This corresponds to SQL for
traditional databases, but unlike SQL, q is a powerful interpreted programming
language in its own right. Q expressions can be entered and run in the q console, or
loaded from a q script, which is a text file with extension `*.q*`. For more information, see the [q documentation](https://code.kx.com/q/learn/startingkdb/language/ "https://code.kx.com/q/learn/startingkdb/language/").
You can run your own kdb code on a Managed kdb cluster to perform analytics or query
data in a database.
