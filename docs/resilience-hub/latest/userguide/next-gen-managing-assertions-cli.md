

# Managing assertions (AWS CLI)
<a name="next-gen-managing-assertions-cli"></a>

The following examples use a service ARN in `us-east-1`. Replace the service ARN and assertion ID with your own values.

**To create an assertion**

```
aws resiliencehubv2 create-assertion \
  --service-arn "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123" \
  --text "Steady-state traffic is about 500 requests per second, with predictable spikes to 5,000 requests per second during weekday business hours."
```

The response returns the new assertion, including its generated `assertionId`:

```
{
    "assertion": {
        "serviceArn": "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123",
        "assertionId": "1b4e28ba-2fa1-4d3b-9c6e-0f2a7d9e5c11",
        "text": "Steady-state traffic is about 500 requests per second, with predictable spikes to 5,000 requests per second during weekday business hours.",
        "source": "USER",
        "createdAt": "2026-09-11T14:32:10.000000+00:00",
        "updatedAt": "2026-09-11T14:32:10.000000+00:00"
    }
}
```

You can optionally pass `--client-token` to make the request idempotent.

**To list assertions**

```
aws resiliencehubv2 list-assertions \
  --service-arn "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123"
```

To list only the assertions generated by the assessment engine, filter by source:

```
aws resiliencehubv2 list-assertions \
  --service-arn "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123" \
  --source AI_GENERATED
```

**To update an assertion**

```
aws resiliencehubv2 update-assertion \
  --service-arn "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123" \
  --assertion-id "1b4e28ba-2fa1-4d3b-9c6e-0f2a7d9e5c11" \
  --text "Steady-state traffic is about 800 requests per second, with predictable spikes to 8,000 requests per second during weekday business hours."
```

If the assertion was AI-generated, the response shows its source changed to `USER`.

**To delete an assertion**

```
aws resiliencehubv2 delete-assertion \
  --service-arn "arn:aws:resiliencehub:us-east-1:123456789012:service/checkout:abc123" \
  --assertion-id "1b4e28ba-2fa1-4d3b-9c6e-0f2a7d9e5c11"
```

For the full request and response syntax, see [CreateAssertion](https://docs.aws.amazon.com/resilience-hub/v2/APIReference/API_CreateAssertion.html), [ListAssertions](https://docs.aws.amazon.com/resilience-hub/v2/APIReference/API_ListAssertions.html), [UpdateAssertion](https://docs.aws.amazon.com/resilience-hub/v2/APIReference/API_UpdateAssertion.html), and [DeleteAssertion](https://docs.aws.amazon.com/resilience-hub/v2/APIReference/API_DeleteAssertion.html) in the *Next generation Resilience Hub API Reference*.
