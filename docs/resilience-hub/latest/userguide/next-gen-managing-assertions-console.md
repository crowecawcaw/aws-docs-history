

# Managing assertions (console)
<a name="next-gen-managing-assertions-console"></a>

**To manage assertions (console)**

1. Open the Next generation Resilience Hub console and navigate to your service.

1. Choose the **Assessments** tab.

1. Choose **Failure mode guidance**. The assertions list shows each assertion's text, whether it was generated by the assessment engine or added by you, and when it was created and last updated.

1. Do one of the following:
   + To add an assertion, choose **Add assertion**, enter the assertion text, and save.
   + To edit an assertion, select it and edit the text inline. Editing an AI-generated assertion changes its source to user-created.
   + To remove an assertion, select it and choose **Delete**.

Changes take effect on the next failure mode assessment you run.
