# Failure mode assessments

| Action                       | Method | Description                                                                                                           |
| ---------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------- |
| `StartFailureModeAssessment` | POST   | Trigger an asynchronous AI-powered assessment that creates topology, service<br>functions, and failure mode findings. |
| `ListFailureModeAssessments` | GET    | List assessments with status, resilience score, and report info.                                                      |
