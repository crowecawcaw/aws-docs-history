# Viewing service topology

The Next generation Resilience Hub console provides a visual canvas view showing your service
hierarchy, including resource topology and service functions.

###### To view service topology

1. Open the Next generation Resilience Hub console and navigate to your service.
2. Choose **Service topology**.
3. The topology view shows how your discovered resources connect to each other. Resources
   are grouped by service function and show edges representing dependencies.
4. Choose a resource node to view its details, including resource type, ARN, Region, and
   account.
