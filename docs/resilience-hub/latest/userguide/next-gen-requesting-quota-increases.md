# Requesting quota increases

You can request an increase for adjustable quotas using the Service Quotas console or by
contacting AWS Support.

**To request a quota increase using Service Quotas:**

1. Open the
   [Service Quotas
   console](https://console.aws.amazon.com/servicequotas/ "https://console.aws.amazon.com/servicequotas/").
2. In the navigation pane, choose **AWS services**.
3. Choose **AWS Resilience Hub**.
4. Choose the quota that you want to increase.
5. Choose **Request quota increase**.
6. Enter the new quota value and choose **Request**.
   **To request a quota increase through AWS Support:**

7. Open the
   [AWS Support
   Center](https://console.aws.amazon.com/support/home "https://console.aws.amazon.com/support/home").
8. Choose **Create case**.
9. Choose **Service limit increase**.
10. Select **Resilience Hub** as the service.
11. Fill in the required information and submit your request.
    Quota increase requests are typically processed within a few business days.
