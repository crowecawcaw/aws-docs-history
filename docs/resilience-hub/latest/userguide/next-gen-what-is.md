# What is Next generation Resilience Hub?

Next generation Resilience Hub is a resilience management service that helps you define resilience
goals, model your applications, discover dependencies, test resilience, and assess your resilience posture against
those goals. Next generation Resilience Hub uses GenAI-powered failure mode assessments based on the AWS
Well-Architected Framework to identify potential weaknesses and provide actionable
recommendations. AWS recommended resilience tests validate how your services respond to and recover from specific failure scenarios aligned to fault boundaries and dependencies.
