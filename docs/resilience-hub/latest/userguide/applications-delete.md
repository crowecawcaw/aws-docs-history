# Deleting an AWS Resilience Hub application

After you've reached the maximum limit of 50 applications, you must delete one or more
applications before you can add more.

###### To delete an application

1. In the navigation pane, choose **Applications**.
2. On the **Applications** page, select the application that you
   want to delete.
3. Choose **Actions**, and then choose **Delete
   application**.
4. To confirm the deletion, enter **Delete** in the
   **Delete** box, and choose
   **Delete**.
