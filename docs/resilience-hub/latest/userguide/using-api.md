# Using AWS Resilience Hub APIs to describe and manage application

As an alternative for describing and managing application using AWS Resilience Hub console,
AWS Resilience Hub allows you to describe and manage applications using AWS Resilience Hub APIs. This chapter
explains how to create an application using AWS Resilience Hub APIs. It also defines the sequence in
which you need to execute the APIs and the parameter values you must provide with
appropriate examples. For more information, see the following topics:

- [Preparing the application](prepare-app-using-api.md "prepare-app-using-api.md")
- [Running and managing AWS Resilience Hub
  resiliency assessments](running-app-using-api.md "running-app-using-api.md")
- [Modifying your
  application](modify-application-using-api.md "modify-application-using-api.md")
