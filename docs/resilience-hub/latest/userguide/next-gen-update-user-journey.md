

# Update a user journey
<a name="next-gen-update-user-journey"></a>

**To update a user journey (console)**

1. Open the Next generation Resilience Hub console and navigate to your system.

1. Choose the **User journeys** tab.

1. Choose the user journey you want to update.

1. Choose **Edit**.

1. Modify the name, description, or associated services as needed.

1. Choose **Save changes**.
