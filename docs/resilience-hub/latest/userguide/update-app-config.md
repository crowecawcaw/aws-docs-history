# Updating application configuration

parameters

This section allows you to update the configuration parameters of your AWS Elastic Disaster Recovery and
publish the application to include the updated parameters for resiliency
assessments.

###### To update application configuration parameters

1. In the navigation pane, choose **Applications**.
2. On the **Applications** page, choose the application name
   that you want to edit.
3. Choose the **Application configuration parameters**
   tab.
4. Choose **Update**.
5. Enter the failover account ID in the **Account ID**
   box.
6. Select a failover Region from the **Region** dropdown
   list.

###### Note

If you want to disable this feature, select
"**–**" from the dropdown list. 7. Choose **Update and publish**.
