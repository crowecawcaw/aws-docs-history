

# Service design files
<a name="next-gen-service-design-files"></a>

You can attach architecture design documents stored in Amazon S3 to your service as input sources. The assessment engine reads these documents to understand your intended architecture and to identify gaps between the design and what is deployed. Supported formats include PDF, Markdown, and plain text. For more information, see [Import design documents](next-gen-import-design-docs.md).
