# Input sources

| Action              | Method | Description                                                                                                                                               |
| ------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CreateInputSource` | POST   | Configure a resource discovery source (resource tags, CloudFormation stack, Terraform state<br>file, EKS cluster, design file, or CloudWatch monitoring). |
| `ListInputSources`  | GET    | List input sources for a service.                                                                                                                         |
| `DeleteInputSource` | POST   | Delete an input source.                                                                                                                                   |
