# Add tags

Assign a tag or label to an AWS resource to search and filter your resources, or track
your AWS costs.

(Optional) To add tags to your application, choose **Add new tag** if you
want to associate one or more tags with the application. For more information about tags, see
[Tagging resources](../../../general/latest/gr/aws_tagging.md "../../../general/latest/gr/aws_tagging.md")
in the _AWS General Reference_.

Choose **Add application** to create your application.
