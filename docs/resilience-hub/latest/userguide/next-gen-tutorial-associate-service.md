

# Associate service with system
<a name="next-gen-tutorial-associate-service"></a>

After creating your system and service, associate the service with the system by creating a user journey.

**Console:**

1. Choose **Systems** and select your system name.

1. Choose **Create user journey**.

1. Enter a name for the user journey (for example, `checkout process`).

1. Select the service you created to associate it with this user journey.

1. Choose **Create user journey**.
