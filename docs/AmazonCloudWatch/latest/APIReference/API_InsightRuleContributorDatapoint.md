# InsightRuleContributorDatapoint

One data point related to one contributor.

For more information, see [GetInsightRuleReport](API_GetInsightRuleReport.md "API_GetInsightRuleReport.md") and [InsightRuleContributor](API_InsightRuleContributor.md "API_InsightRuleContributor.md").


## Contents





**ApproximateValue** 


The approximate value that this contributor added during this timestamp.


Type: Double


Required: Yes




**Timestamp** 


The timestamp of the data point.


Type: Timestamp


Required: Yes
