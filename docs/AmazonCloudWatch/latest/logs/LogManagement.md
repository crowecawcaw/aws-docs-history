# Log management

CloudWatch Logs provides advanced log management capabilities that help you organize, transform, and
analyze your log data more effectively. These features include [cross-account and cross-region data
centralization](CloudWatchLogs_Centralization.md "CloudWatchLogs_Centralization.md"), [automatic data
discovery and schema management,](data-source-discovery-management.md "data-source-discovery-management.md")
[log transformation during ingestions](CloudWatch-Logs-Transformation.md "CloudWatch-Logs-Transformation.md"),
and [enhanced analytics with facets for interactive log
exploration](CloudWatchLogs-Facets.md "CloudWatchLogs-Facets.md").
