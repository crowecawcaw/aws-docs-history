

# HashiCorp Vault integration configuration
<a name="hashicorp-vault-setup"></a>

HashiCorp Vault is the industry-leading secrets management and encryption-as-a-service platform that enables organizations to centrally store, access, and distribute digital secrets. CloudWatch Pipelines allow ingestion of HashiCorp Vault audit log and operational log data into CloudWatch Logs.
