

# Akamai DataStream 2 integration configuration
<a name="akamai-datastream2-setup"></a>

Akamai DataStream 2 is a near real-time log streaming service that delivers detailed performance and security metrics from the Akamai edge platform to various third-party destinations. It enables proactive monitoring, troubleshooting, and, through its support for [DataStream 2.1](https://techdocs.akamai.com/datastream2/v3/docs/welcome-datastream2), includes Edge DNS, Global Traffic Management (GTM), and EdgeWorkers log data.
