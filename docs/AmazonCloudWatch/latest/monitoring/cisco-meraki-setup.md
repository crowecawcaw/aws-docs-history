

# Cisco Meraki integration configuration
<a name="cisco-meraki-setup"></a>

Cisco Meraki is a cloud-managed IT platform by Cisco that provides centralized management of enterprise networking infrastructure — including security appliances (MX), wireless access points (MR), switches (MS), cameras (MV), sensors (MT), and mobile device management (SM) — through a single dashboard. CloudWatch pipelines uses the Meraki Dashboard REST API v1 to retrieve security events, configuration changes, assurance alerts, and network events from your Meraki organization.
