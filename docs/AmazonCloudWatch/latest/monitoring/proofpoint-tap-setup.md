

# Proofpoint TAP integration configuration
<a name="proofpoint-tap-setup"></a>

Proofpoint TAP is an advanced email security solution that detects, analyzes, and blocks advanced threats before they reach users' inboxes. CloudWatch pipelines use the Proofpoint TAP SIEM API, Campaign API, and Forensics API to retrieve security event data including message and click events, threat campaign information, and sandbox analysis results.
