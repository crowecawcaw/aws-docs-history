# (Optional) Set up Amazon EKS control plane logging

If you're using Amazon EKS, you can optionally enable Amazon EKS control plane logging, to
provide audit and diagnostic logs directly from the Amazon EKS control plane to CloudWatch Logs. For
more information, see [Amazon EKS Control
Plane Logging](../../../eks/latest/userguide/control-plane-logs.md "../../../eks/latest/userguide/control-plane-logs.md").
