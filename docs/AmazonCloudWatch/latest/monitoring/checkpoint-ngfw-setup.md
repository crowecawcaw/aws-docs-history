

# Check Point NGFW integration configuration
<a name="checkpoint-ngfw-setup"></a>

Check Point Next-Generation Firewall (NGFW), also known as Check Point Quantum, is an advanced on-premises firewall that combines traditional filtering with modern threat-prevention technologies such as intrusion prevention, antivirus, and application control. CloudWatch pipelines allow ingestion of Check Point NGFW log data into CloudWatch Logs, providing scalable collection, processing, normalization, and integration with downstream AWS security and monitoring services.
