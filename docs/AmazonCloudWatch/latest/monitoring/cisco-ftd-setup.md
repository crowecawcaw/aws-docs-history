

# Cisco FTD integration configuration
<a name="cisco-ftd-setup"></a>

Cisco Firepower Threat Defense (FTD) is a next-generation firewall platform that provides advanced threat protection, intrusion prevention, and deep visibility into network traffic. It generates security logs including connection events, intrusion detections, file and malware activity, and system events, which can be exported for centralized monitoring and analysis.
