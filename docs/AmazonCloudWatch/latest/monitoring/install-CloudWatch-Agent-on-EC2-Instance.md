# Installing the CloudWatch agent

You can install the CloudWatch agent on your Amazon EC2 instances and on-premises servers to collect
 metrics and logs. The agent supports both Linux and Windows operating systems. There are
 several ways to install the agent, including using Systems Manager, installing from the command line, or
 installing using a configuration file. Before installing, make sure you have the required
 IAM permissions and network access configured.

###### Note

To install and configure the CloudWatch agent on a group of Amazon EC2's or to quickly get started,
 see [Install and configure the CloudWatch Logs using the Amazon EC2 console to add additional metrics](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/install-and-configure-cloudwatch-agent-using-ec2-console.html "https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/install-and-configure-cloudwatch-agent-using-ec2-console.html") .
