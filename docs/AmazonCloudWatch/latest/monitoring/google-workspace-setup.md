

# Google Workspace integration configuration
<a name="google-workspace-setup"></a>

Google Workspace, formerly G Suite, is Google's cloud-native productivity and collaboration suite. It includes Gmail, Drive, Docs, Sheets, Slides, Calendar, Meet, and Chat, along with identity and security services. CloudWatch pipelines use the Google Workspace Admin SDK Reports API and Alert Center API. These APIs retrieve audit logs, authentication activity, account and access changes, drive operations, and security alerts. The data comes from your Google Workspace environment. Both APIs expose REST endpoints that fetch time-filtered event data for security monitoring and analysis.
