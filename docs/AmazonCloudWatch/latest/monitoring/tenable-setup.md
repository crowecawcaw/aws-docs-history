

# Tenable Vulnerability Management integration configuration
<a name="tenable-setup"></a>

Tenable Vulnerability Management is a cloud-based vulnerability management platform that provides continuous visibility into assets, vulnerabilities, compliance posture, and security findings. CloudWatch pipelines use the Tenable REST API to retrieve asset inventories, vulnerability findings, compliance data, scan results, audit logs, and plugin metadata from your Tenable environment.
