

# F5 BIG-IP integration configuration
<a name="f5-bigip-setup"></a>

F5 Telemetry Streaming is a real-time log streaming solution that delivers detailed traffic and security logs from F5 BIG-IP to external destinations such as Amazon S3 and CloudWatch. It enables monitoring, troubleshooting, and analysis of logs generated by modules like AFM, LTM, APM, ASM, and Advanced WAF.
