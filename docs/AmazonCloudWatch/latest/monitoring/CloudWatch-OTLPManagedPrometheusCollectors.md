# Managed Prometheus collectors

Amazon CloudWatch managed Prometheus collectors provide a fully managed, agentless way to
collect Prometheus-compatible metrics from your AWS resources and
deliver them to the CloudWatch OTLP endpoint. You don't install, patch, or scale any
collection infrastructure yourself, and you query the collected metrics with PromQL.

For more information, including how to integrate Amazon MSK, Amazon EKS, Amazon
OpenSearch Service, and other VPC-based sources, see [Amazon CloudWatch managed Prometheus collectors](managed-prometheus-collectors.md "managed-prometheus-collectors.md").
