

# Ping Identity PingAccess integration configuration
<a name="pingidentity-pingaccess-setup"></a>

Ping Identity PingAccess is an enterprise-grade access management solution that serves as a centralized policy enforcement point for web applications and APIs. It provides fine-grained authorization, URL-level access control, and web session management across enterprise resources. CloudWatch pipelines allow ingestion of Ping Identity PingAccess audit log data into CloudWatch Logs.
