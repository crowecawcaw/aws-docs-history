

# Monitor the AWS backbone with Infrastructure Performance

Performance Monitor includes Infrastructure Performance at no additional charge, providing near real-time and historical health and latency data across AWS Regions and Availability Zones. Infrastructure Performance is for network operators and application developers who want visibility into AWS network health that could affect their workloads. You can also use it to assess Regions in which to deploy new resources. Evaluate whether AWS backbone network performance between Regions and Availability Zones might be affecting your applications. Choose a path to view health and latency metrics. These metrics don't incorporate performance for paths through Amazon VPC networking resources. By default, the source is set to your currently selected Region.
