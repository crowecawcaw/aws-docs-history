

# Security in CloudWatch Omni
<a name="omni-security-in-cloudwatch-omni"></a>

Cloud security at AWS is the highest priority. As an AWS customer, you benefit from a data center and network architecture that is built to meet the requirements of the most security-sensitive organizations.

Security is a shared responsibility between AWS and you. The [shared responsibility model](https://aws.amazon.com/compliance/shared-responsibility-model/) describes this as security of the cloud and security in the cloud:
+ **Security of the cloud** – AWS is responsible for protecting the infrastructure that runs AWS services in the AWS Cloud. AWS also provides you with services that you can use securely. Third-party auditors regularly test and verify the effectiveness of our security as part of the [AWS Compliance Programs](https://aws.amazon.com/compliance/programs/). For the compliance programs that apply to CloudWatch Omni, see [Compliance validation for CloudWatch Omni](omni-compliance-validation-for-cloudwatch-omni.md).
+ **Security in the cloud** – Your responsibility is determined by the AWS service that you use. You are also responsible for other factors including the sensitivity of your data, your company's requirements, and applicable laws and regulations.

This documentation helps you understand how to apply the shared responsibility model when you use CloudWatch Omni. For a space, your share covers who can read your telemetry and which key encrypts what CloudWatch Omni stores. The following topics show you how to configure both, and how to use other AWS services that help you secure a space. To control what content reaches your telemetry before CloudWatch Omni stores it, see [Protect sensitive data](omni-data-protection.md).
