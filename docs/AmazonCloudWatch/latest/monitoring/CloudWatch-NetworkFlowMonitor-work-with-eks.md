# Work with EKS

Using Network Flow Monitor, you can collect performance metrics for your workloads that use Amazon Elastic Kubernetes Service.
This chapter provides step-by-step agent installation instructions, as well as
information about the different EKS scenarios that you can gather information for. Detailed
descriptions are included of the metadata that is provided for EKS in the Network Flow Monitor console
to help you understand network performance.

To gain the benefits of Network Flow Monitor performance monitoring, you must first install the AWS Network Flow Monitor Agent add-on
for Amazon EKS. For more information, see the first section in this chapter, [Install the EKS AWS Network Flow Monitor Agent add-on](CloudWatch-NetworkFlowMonitor-agents-kubernetes-eks.md "CloudWatch-NetworkFlowMonitor-agents-kubernetes-eks.md"). To see a list of the
Linux distributions that are supported for agents, see [Linux versions supported for Network Flow Monitor agents](CloudWatch-NetworkFlowMonitor-agents-versions.md "CloudWatch-NetworkFlowMonitor-agents-versions.md").
