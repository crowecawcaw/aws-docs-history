# Evidently quotas in CloudWatch

###### Important

End of support notice: On October 16, 2025, AWS 
 will discontinue support for CloudWatch Evidently. After October 16, 2025, you will 
 no longer be able to access the Evidently console or Evidently resources. 
 

CloudWatch Evidently has the following quotas.



| Resource | Default quota |
| --- | --- |
| Projects | 50 per Region per account You can request a quota increase. |
| Segments | 500 per Region per account You can request a quota increase. |
| Quotas per project | <br>• 100 total features <br>• 500 total launches <br>• 50 running launches <br>• 500 total experiments <br>• 50 running experiments You can request a quota increase for all of these quotas. |
| API quotas (all quotas are per Region) | <br>• PutProjectEvents: 1000 transactions per second (TPS) in US East (N. Virginia), US West (Oregon), and Europe (Ireland). 200 TPS in all other Regions. <br>• EvaluateFeature: 1000 TPS in US East (N. Virginia), US West (Oregon), and Europe (Ireland). 200 TPS in all other Regions. <br>• BatchEvaluateFeature: 50 TPS <br>• Create, Read, Update, Delete (CRUD) APIs: 10 TPS combined across all CRUD APIs You can request a quota increase for all of these quotas. |
