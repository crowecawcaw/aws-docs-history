

# Performance Monitor API operations

Performance Monitor API operations are part of the Network Flow Monitor API. Scope operations are shared with Network Flow Monitor. The following table lists the Performance Monitor API operations, with links to the reference documentation.


| Action | API operation | 
| --- | --- | 
| Create a monitor. | See [CreatePerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_CreatePerformanceMonitor.html) | 
| Get details about a monitor. | See [GetPerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_GetPerformanceMonitor.html) | 
| Add or remove VPCs for a monitor. | See [UpdatePerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_UpdatePerformanceMonitor.html) | 
| Delete a monitor. | See [DeletePerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_DeletePerformanceMonitor.html) | 
| List the monitors in an account. | See [ListPerformanceMonitors](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_ListPerformanceMonitors.html) | 
| Start a query for top network paths. | See [StartQueryPerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_StartQueryPerformanceMonitor.html) | 
| Get the status of a query. | See [GetQueryStatusPerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_GetQueryStatusPerformanceMonitor.html) | 
| Get the results of a query. | See [GetQueryResultsPerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_GetQueryResultsPerformanceMonitor.html) | 
| Stop a running query. | See [StopQueryPerformanceMonitor](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_StopQueryPerformanceMonitor.html) | 
| Add or remove account-Region pairs in the scope. | See [UpdateScope](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_UpdateScope.html) | 
| Delete the scope. | See [DeleteScope](https://docs.aws.amazon.com/networkflowmonitor/2.0/APIReference/API_DeleteScope.html) |
