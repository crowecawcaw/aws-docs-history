

# SailPoint ISC integration configuration
<a name="sailpoint-isc-setup"></a>

SailPoint Identity Security Cloud (ISC) is a cloud-based identity governance and administration platform. It provides identity security capabilities such as access certifications (periodic reviews of who has access to what), provisioning (granting and removing access), password management, and single sign-on. The platform generates audit events covering authentication, user management, provisioning, access requests, certifications, and system configuration changes. CloudWatch pipelines integrate with SailPoint ISC through its Search API to continuously collect identity governance audit events for centralized security monitoring and analysis.
