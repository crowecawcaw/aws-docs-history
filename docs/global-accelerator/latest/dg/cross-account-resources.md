#

Work with cross-account resources in Global Accelerator

If your account, or an accelerator that you have permission to access, is specified as a principal in a
cross-account attachment in AWS Global Accelerator, you can use resources that have been shared with you from another
account.

For example, you can select bring your own IP (BYOIP) addresses as static IP addresses
when you create an accelerator, or you can add endpoints to accelerator endpoint groups for an accelerator.
The resources that you can add must also be specified in the attachment.

The following sections include the steps to add or remove cross-account attachments in Global Accelerator.
