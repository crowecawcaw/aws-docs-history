# Remove a standard listener

This section provides the steps to remove a standard listener on the AWS Global Accelerator console. To complete
this task by using an API operation instead of the console, see [`DeleteListener`](../api/API_DeleteListener.md "../api/API_DeleteListener.md") in the _AWS Global Accelerator API Reference_.

# To remove a listener

1. Open the Global Accelerator console at [https://us-west-2.console.aws.amazon.com/globalaccelerator/home#GlobalAcceleratorHome:](https://us-west-2.console.aws.amazon.com/globalaccelerator/home#GlobalAcceleratorHome: "https://us-west-2.console.aws.amazon.com/globalaccelerator/home#GlobalAcceleratorHome:").
2. On the **accelerators** page, choose an accelerator.
3. Choose a listener, and then choose **Remove**.
4. In the confirmation dialog box, choose **Remove**.
