# Getting started with AWS Global Accelerator

To help you get started with AWS Global Accelerator, this chapter provides tutorials for setting up a standard accelerator
and a custom routing accelerator.

To learn more about the two types of accelerators that you can create in Global Accelerator, see
[Working with standard accelerators in AWS Global Accelerator](work-with-standard-accelerators.md "work-with-standard-accelerators.md") and
[Working with custom routing accelerators in AWS Global Accelerator](work-with-custom-routing-accelerators.md "work-with-custom-routing-accelerators.md").

The tutorials provide steps that primarily use AWS Management Console. Note that when you set up a custom routing accelerator, you must
use the API for certain configuration steps.

You can also use Global Accelerator API operations with the AWS Command Line Interface (AWS CLI) or AWS SDKs to create and customize your accelerators.
The following are resources for working with the Global Accelerator APIs.

- For a list of API operations,
  see [Common API actions for AWS Global Accelerator](global-accelerator-actions.md "global-accelerator-actions.md").
- For detailed information
  about working with AWS Global Accelerator API operations, see the [AWS Global Accelerator API Reference](../api/Welcome.md "../api/Welcome.md").
  Global Accelerator is a global service that supports endpoints in multiple AWS Regions. Supported Regions are listed
  in the [AWS
  Region Table](https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/ "https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/").
