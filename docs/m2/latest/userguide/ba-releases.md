# AWS Blu Age releases

AWS Blu Age engine has multiple versions that you can choose from. This page is
an overview of the way AWS Blu Age versioning works, what changes each version releases have,
upgrading instructions for versions, how updates to AWS Blu Age are communicated with customers,
and the lifecycle of these versions.

The [AWS Blu Age versioning](ba-versioning.md "ba-versioning.md") page details information about releases and how each
release can be identified by major and minor versions. The [AWS Blu Age release notes](ba-release-notes.md "ba-release-notes.md") page has in-depth release notes for each major and minor version. [AWS Blu Age security vulnerabilities](ba-security-cve.md "ba-security-cve.md") page mentions how AWS Blu Age handles Common Vulnerabilities and
Exposures (CVE). [Upgrading instructions for AWS Blu Age](ba-migration-notes.md "ba-migration-notes.md") details upgrading instructions for
AWS Blu Age versions. And [AWS Blu Age lifecycle](ba-lifecycle.md "ba-lifecycle.md") includes all details about end of life
(EOL) dates for the AWS Blu Age Runtime major versions.
