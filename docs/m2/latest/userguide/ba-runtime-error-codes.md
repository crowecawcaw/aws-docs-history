# AWS Transform for mainframe Runtime Error Codes
<a name="ba-runtime-error-codes"></a>

During the lifecyle of an application using the AWS Transform for mainframe Runtime, errors may arise for various reasons such as misconfiguration or networking issues. Error codes managed by the AWS Transform for mainframe Runtime are documented here with the cause and actions to solve them. The error codes handled by AWS Transform for mainframe Runtime follow this convention: `BA-X1234`, where X is a letter and 1234 are four digits. In this documentation, errors are classified by first letter, then digits.
