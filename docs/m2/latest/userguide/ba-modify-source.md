# Modify the source code with AWS Transform for mainframe Developer IDE
<a name="ba-modify-source"></a>

If you are using the AWS-managed AWS Transform for mainframe runtime engine, you can use AWS Transform for mainframe Developer to modify the generated source code. You might want to do this if you need to update the modernized code for some reason, or if a portion of the legacy source code couldn't be modernized. You access AWS Transform for mainframe Developer through Amazon WorkSpaces Applications. This section describes how to set up AWS Transform for mainframe Developer on WorkSpaces Applications. It also explains how to use AWS Transform for mainframe Developer to update source code, using the sample application PlanetsDemo.
