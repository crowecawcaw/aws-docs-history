# Prerequisites for setting up Rocket Software (formerly Micro Focus) (on

Amazon EC2)

When you set up Rocket Software (on Amazon EC2), make sure you meet the following prerequisites.

- Administrator access to the account where the Amazon EC2 instances will be created.
- Identify the AWS Region where the Amazon EC2 instances will be created and verify the AWS Mainframe Modernization service is available.
  See [AWS Services by Region](https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/ "https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/").
  Make sure to choose a Region where the service is available.
- Identify the Amazon Virtual Private Cloud (Amazon VPC) where the Amazon EC2 instances will be created.
