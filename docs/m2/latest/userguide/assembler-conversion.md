# AWS Mainframe Modernization Code Conversion with mLogica

AWS Mainframe Modernization Code Conversion with mLogica (Code conversion), is an
AWS Mainframe Modernization feature that automatically converts z/OS mainframe Assembler code to COBOL.
You can use Code conversion to pull an assembler image using the AWS CodeBuild service for
your intended code conversion with your AWS account.
