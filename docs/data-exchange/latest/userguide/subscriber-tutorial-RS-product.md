# Worldwide Event

Attendance (Test Product) on AWS Data Exchange

Worldwide Event Attendance (Test Product) is a free product that helps subscribers
understand how to subscribe to and interact with an AWS Data Exchange product containing Amazon Redshift data sets.
You can use this product for testing purposes and to learn how to query, analyze, and build
applications within minutes.

Worldwide Event Attendance (Test Product) contains an Amazon Redshift data set named
**Worldwide Event Data (Test Data)** that is in the US East (N. Virginia)
AWS Region.

You use the AWS Data Exchange console to find and subscribe to Worldwide Event Attendance (Test
Product). Then, you can use either the Amazon Redshift console or SQL commands to query the
datashare.
