# Publishing a new product in AWS Data Exchange

You can publish products on AWS Data Exchange using multiple AWS tools and consoles.

In the [AWS Marketplace Management Portal](https://console.aws.amazon.com/marketplace "https://console.aws.amazon.com/marketplace") or programmatically through the AWS Marketplace Catalog API, you can:

- Create and manage products.
- Create and manage offers.
- Verify subscription requests.
  In the [AWS Data Exchange console](https://console.aws.amazon.com/dataexchange "https://console.aws.amazon.com/dataexchange"), you can create and manage data sets.

The following topics describe the process of publishing a new product on AWS Data Exchange by using
the AWS Data Exchange console.
