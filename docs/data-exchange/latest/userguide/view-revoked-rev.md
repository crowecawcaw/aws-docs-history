# Viewing revoked revisions as a subscriber

(console)

As a subscriber to AWS Data Exchange data products, you can use the AWS Data Exchange console to view the reason
for revocation of access to a revision using the following instructions.

###### To view a revoked revision as a subscriber (console)

1. Open your web browser and sign in to the [AWS Data Exchange console](https://console.aws.amazon.com/dataexchange "https://console.aws.amazon.com/dataexchange").
2. From the left navigation pane, under **My subscriptions**, choose
   **Entitled data**.
3. Under **Products**, choose a product, and then expand the data set
   under the product to see a list of revisions.
4. On the data set page, under the **Revisions** tab, view the
   **Status** of the revision (**Published** or
   **Revoked**).
5. Choose a revision.
6. View the revision reason on the top of the revision detail page.
