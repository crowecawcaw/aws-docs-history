# Editing an AWS Data Exchange asset revocation reason as a provider

(console)

As a provider of AWS Data Exchange data products, you can use the AWS Data Exchange console to edit the reason
for the revocation using the following instructions.

###### To edit a revocation revision as a provider (console)

1. Open your web browser and sign in to the [AWS Data Exchange console](https://console.aws.amazon.com/dataexchange "https://console.aws.amazon.com/dataexchange").
2. In the left side navigation pane, for **Publish data products**,
   choose **Owned data sets**.
3. In **Owned data sets**, choose the data set that has the revision
   you revoked.
4. On the **Revisions** tab, choose the revoked revision.
5. On the revision page, choose **Edit revocation reason**.
6. In the **Edit revocation revision** dialog box, enter a short
   description of your reason for revoking the revision.
7. Choose **Save**.

The **Status** of the revision is set to
**Revoked**.

The updated revocation reason is displayed on the revision page.
