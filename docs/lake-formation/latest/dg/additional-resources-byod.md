# Additional resources

You can use [Amazon SageMaker Lakehouse](../../../sagemaker-unified-studio/latest/userguide/lakehouse.md "../../../sagemaker-unified-studio/latest/userguide/lakehouse.md") to achieve unified access to data in
both data warehouses and data lakes. Through SageMaker Lakehouse, you can use preferred
analytics, machine learning, and business intelligence engines through an open, Apache
Iceberg REST API to help ensure secure access to data with consistent, fine-grained access
controls.
