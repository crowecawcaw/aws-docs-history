# Roles and responsibilities in Lake Formation application

integration

The following are the roles and their associated responsibilities for enabling third-party application integration with AWS Lake Formation.

| Role                 | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The customer         | <br>• Enable Lake Formation application integration setting (see [Registering a third-party query engine](register-query-engine.md "register-query-engine.md")). <br>• Explicitly registers approved third parties with Lake Formation (see [Registering a third-party query engine](register-query-engine.md "register-query-engine.md")). <br>• Tests and validates third-party solutions with Lake Formation permissions. <br>• Monitors and audits third-party usage of Lake Formation credential vending API operations.                                                 |
| The third-party      | <br>• Publicly documents the supported capability for every software revision and provides instructions to enable it correctly. <br>• Accurately advertises the supported capabilities when calling Lake Formation credential vending API operations (according to the documentation). <br>• Securely stores and handles vended credentials to avoid credential leaks and privilege escalation. <br>• Enforces permissions based on supported capabilities and returns only filtered data to users <br>• Fails the query when unable to properly enforce required permissions |
| `AWS Lake Formation` | <br>• Correctly derives and returns effective permissions for a given principal. <br>• Validates third-party supported capabilities on an API operation call-by-call basis. <br>• Returns scoped-down IAM credentials only when the engine’s advertised capabilities match those defined on the catalog resources, otherwise returns an error.                                                                                                                                                                                                                                |
