# Using AWS Lake Formation with AWS CloudTrail Lake

AWS CloudTrail Lake supports exploring event data stores using Amazon Athena with
fine-grained permissions in AWS Lake Formation.

###### Note

CloudTrail Lake can only be queried through Amazon Athena.

To register your CloudTrail Lake event data store with Lake Formation, see [Federate an
event data store](../../../awscloudtrail/latest/userguide/query-federation.md "../../../awscloudtrail/latest/userguide/query-federation.md").
