# Additional resources

The following blog post contains detailed instructions to set up Lake Formation permissions on a
Hive metastore database and tables, and query them using Athena. We also illustrate a
cross-account sharing use case, where a Lake Formation principal in producer account A shares a
federated Hive database and tables using LF-Tag to consumer account B.

- [Query your Apache Hive metastore with AWS Lake Formation permissions](https://aws.amazon.com/blogs/big-data/query-your-apache-hive-metastore-with-aws-lake-formation-permissions/ "https://aws.amazon.com/blogs/big-data/query-your-apache-hive-metastore-with-aws-lake-formation-permissions/")
