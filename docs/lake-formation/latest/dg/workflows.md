# Importing data using workflows in Lake Formation

With AWS Lake Formation, you can import your data using _workflows_. A workflow
defines the data source and schedule to import data into your data lake. It is a container for
AWS Glue crawlers, jobs, and triggers that are used to orchestrate the processes to load and update
the data lake.
