# Rename a CodeDeploy application

You can use the AWS CLI or the CodeDeploy APIs to change the name of an application.

To view a list of application names, use the AWS CLI to call the
[list-applications](../../../cli/latest/reference/deploy/list-applications.md "../../../cli/latest/reference/deploy/list-applications.md") command.

For information about using the AWS CLI to change an application name, see
[update-application](../../../cli/latest/reference/deploy/update-application.md "../../../cli/latest/reference/deploy/update-application.md").

For information about using the CodeDeploy APIs to change an application name, see [API_UpdateApplication](../APIReference/API_UpdateApplication.md "../APIReference/API_UpdateApplication.md").
