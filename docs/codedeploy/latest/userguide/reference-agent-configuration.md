# CodeDeploy agent configuration reference

When the CodeDeploy agent is installed, a configuration file is placed on the instance. This
configuration file specifies directory paths and other settings for CodeDeploy to use as it
interacts with the instance. You can change some of the configuration options in the
file.

For Amazon Linux, Ubuntu Server, and Red Hat Enterprise Linux (RHEL) instances, the configuration file is named
`codedeployagent.yml`. It is placed in the
`/etc/codedeploy-agent/conf` directory.

For Windows Server instances, the configuration file is named
`conf.yml`. It is placed in the
`C:\ProgramData\Amazon\CodeDeploy` directory.

The configuration settings include:

|                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **:log_aws_wire:**            | Set to `true` for the CodeDeploy agent to capture wire logs from<br>Amazon S3 and write them to a file named `codedeploy-agent.wire.log` in<br>the location pointed to by the **:log_dir:\*<br>• setting.<br>WarningYou should set **:log_aws_wire:\*<br>• to<br>`true` only for the amount of time required to<br>capture wire logs. The `codedeploy-agent.wire.log` file<br>can grow to a very large size quickly. The wire log output in this<br>file might contain sensitive information, including the plain-text<br>contents of files transferred into, or out of, Amazon S3 while this<br>setting was set to `true`. The wire logs contain<br>information about all Amazon S3 activity associated with the AWS<br>account while this setting was set to `true`, not just<br>activity related to CodeDeploy deployments.<br>The default setting is `false`.<br>This setting applies to all instance types. You must add this<br>configuration setting to Windows Server instances to be able to use it. |
| **:log_dir:**                 | The folder on the instance where log files related to CodeDeploy agent<br>operations are stored.<br>The default setting is `'/var/log/aws/codedeploy-agent'` for Amazon Linux,<br>Ubuntu Server, and RHEL instances and<br>`C:\ProgramData\Amazon\CodeDeploy\log` for Windows Server<br>instances.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **:pid_dir:**                 | The folder where `codedeploy-agent.pid` is<br>stored.<br>This file contains the process ID (PID) of the CodeDeploy agent. The<br>default setting is `'/opt/codedeploy-agent/state/.pid'`.<br>This setting applies to Amazon Linux, Ubuntu Server, and RHEL instances<br>only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **:program_name:**            | The CodeDeploy agent program name.<br>The default setting is<br>`codedeploy-agent`.This setting<br>applies to Amazon Linux, Ubuntu Server, and RHEL instances only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:root_dir:**                | The folder where related revisions, deployment history, and<br>deployment scripts on the instance are stored.<br>The default setting is `/opt/codedeploy-agent/deployment-root` for<br>Amazon Linux, Ubuntu Server, and RHEL instances and<br>`C:\ProgramData\Amazon\CodeDeploy` for Windows Server<br>instances.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **:verbose:**                 | Set to `true` for the CodeDeploy agent to print debug<br>messages log files on the instance.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **:wait_between_runs:**       | The interval, in seconds, between CodeDeploy agent polling of CodeDeploy for<br>pending deployments.<br>The default setting is `1`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:on_premises_config_file:** | For on-premises instances, the path to an alternate location for<br>the configuration file named<br>`codedeploy.onpremises.yml` (for Ubuntu Server<br>and RHEL) or<br>`conf.onpremises.yml` (for<br>Windows Server). By default, these files are stored in<br>`/etc/codedeploy-agent/conf`/`codedeploy.onpremises.yml`<br>for Ubuntu Server and RHEL and<br>`C:\ProgramData\Amazon\CodeDeploy`\`conf.onpremises.yml`<br>for Windows Server.<br>Available in version 1.0.1.686 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **:proxy_uri:**               | (Optional) The HTTP proxy through which you want the CodeDeploy agent to<br>connect to AWS for your CodeDeploy operations. Use a format similar to<br>`https://user:password@my.proxy:443/path?query`.<br>Available in version 1.0.1.824 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **:max_revisions:**           | (Optional) The number of application revisions for a deployment group<br>that you want the CodeDeploy agent to archive. Any revisions that exceed the<br>number specified are deleted.<br>Enter any positive integer. If no value is specified, CodeDeploy will<br>retain the five most recent revisions in addition to the currently<br>deployed revision.<br>Supported in version 1.0.1.966 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **:enable_auth_policy:**      | (Optional) Set to `true` if you want to use [IAM authorization](../../../IAM/latest/UserGuide/intro-structure.md#intro-structure-authorization "../../../IAM/latest/UserGuide/intro-structure.md#intro-structure-authorization") to configure access control and limit<br>permission of the IAM role or user that the CodeDeploy Agent is using. To<br>[Use CodeDeploy with Amazon Virtual Private Cloud](vpc-endpoints.md "vpc-endpoints.md"), this<br>value must be `true`.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **:disable_imds_v1:**         | This setting is available with CodeDeploy agent 1.7.0 and later.<br>Set to `true` to disable the fallback to IMDSv1 when IMDSv2<br>errors occur. Defaults to `false` (enable the<br>fallback).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
