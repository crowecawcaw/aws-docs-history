# CodeDeploy agent configuration reference

When the CodeDeploy agent is installed, a configuration file is placed on the instance. This
configuration file specifies directory paths and other settings for CodeDeploy to use as it
interacts with the instance. You can change some of the configuration options in the
file.

For Amazon Linux, Ubuntu Server, and Red Hat Enterprise Linux (RHEL) instances, the configuration file is named
`codedeployagent.yml`. It is placed in the
`/etc/codedeploy-agent/conf` directory.

For Windows Server instances, the configuration file is named
`conf.yml`. It is placed in the
`C:\ProgramData\Amazon\CodeDeploy` directory.

The configuration settings include:

| **:log\_aws\_wire:**                          | Set to `true` for the CodeDeploy agent to capture wire logs from<br>Amazon S3 and write them to a log file in the location pointed to by the<br>**:log\_dir:_<br>• setting.<br>For version 2.0.x and later, the filename is<br>`codedeploy-agent.aws_wire.log` (created with 0640<br>permissions).<br>For version 1.8.x and earlier, the filename is<br>`codedeploy-agent.wire.log`.<br>WarningYou should set \**:log\_aws\_wire:_<br>• to<br>`true` only for the amount of time required to<br>capture wire logs. The wire log file<br>can grow to a very large size quickly. The wire log output<br>might contain sensitive information, including the plain-text<br>contents of files transferred into, or out of, Amazon S3 while this<br>setting was set to `true`. The wire logs contain<br>information about all Amazon S3 activity associated with the AWS<br>account while this setting was set to `true`, not just<br>activity related to CodeDeploy deployments.<br>The default setting is `false`.<br>This setting applies to all instance types. You must add this<br>configuration setting to Windows Server instances to be able to use it. |

| **:pid\_dir:**                                | The folder where `codedeploy-agent.pid` is<br>stored.<br>This file contains the process ID (PID) of the CodeDeploy agent. The<br>default setting is `'/opt/codedeploy-agent/state/.pid'`.<br>This setting applies to Amazon Linux, Ubuntu Server, and RHEL instances<br>only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **:program\_name:**                           | The CodeDeploy agent program name.<br>The default setting is<br>`codedeploy-agent`.This setting<br>applies to Amazon Linux, Ubuntu Server, and RHEL instances only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **:root\_dir:**                               | The folder where related revisions, deployment history, and<br>deployment scripts on the instance are stored.<br>The default setting is `/opt/codedeploy-agent/deployment-root` for<br>Amazon Linux, Ubuntu Server, and RHEL instances and<br>`C:\ProgramData\Amazon\CodeDeploy` for Windows Server<br>instances.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **:verbose:**                                 | Set to `true` for the CodeDeploy agent to print debug<br>messages log files on the instance.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **:wait\_between\_runs:**                     | The interval, in seconds, between CodeDeploy agent polling of CodeDeploy for<br>pending deployments.<br>For version 2.0.x and later, the default setting is<br>`30`.<br>For version 1.8.x and earlier, the default setting is<br>`1`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **:on\_premises\_config\_file:**              | For on-premises instances, the path to an alternate location for<br>the configuration file named<br>`codedeploy.onpremises.yml` (for Ubuntu Server<br>and RHEL) or<br>`conf.onpremises.yml` (for<br>Windows Server). By default, these files are stored in<br>`/etc/codedeploy-agent/conf`/`codedeploy.onpremises.yml`<br>for Ubuntu Server and RHEL and<br>`C:\ProgramData\Amazon\CodeDeploy`\`conf.onpremises.yml`<br>for Windows Server.<br>Available in version 1.0.1.686 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **:proxy\_uri:**                              | (Optional) The HTTP proxy through which you want the CodeDeploy agent to<br>connect to AWS for your CodeDeploy operations. Use a format similar to<br>`https://user:password@my.proxy:443/path?query`.<br>Available in version 1.0.1.824 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **:max\_revisions:**                          | (Optional) The number of application revisions for a deployment group<br>that you want the CodeDeploy agent to archive. Any revisions that exceed the<br>number specified are deleted.<br>Enter any positive integer. If no value is specified, CodeDeploy will<br>retain the five most recent revisions in addition to the currently<br>deployed revision.<br>Supported in version 1.0.1.966 and later versions of the CodeDeploy<br>agent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **:enable\_auth\_policy:**                    | (Optional) Set to `true` if you want to use [IAM authorization](../../../IAM/latest/UserGuide/intro-structure.md#intro-structure-authorization "../../../IAM/latest/UserGuide/intro-structure.md#intro-structure-authorization") to configure access control and limit<br>permission of the IAM role or user that the CodeDeploy Agent is using. To<br>[Use CodeDeploy with Amazon Virtual Private Cloud](vpc-endpoints.md "vpc-endpoints.md"), this<br>value must be `true`.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:disable\_imds\_v1:**                       | This setting is available with CodeDeploy agent 1.7.0 and later.<br>Set to `true` to disable the fallback to IMDSv1 when IMDSv2<br>errors occur. Defaults to `false` (enable the<br>fallback).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **:disable\_core\_dumps:**                    | For version 2.0.x and later.<br>Set to `true` to suppress core dumps. Set to<br>`false` for crash investigation.<br>The default setting is `true`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **:enable\_command\_port:**                   | For version 2.0.x and later.<br>Set to `true` to enable the loopback-only (127.0.0.1) local<br>management interface for querying agent status and injecting commands<br>locally.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **:reject\_symlinks\_in\_bundle:**            | For version 2.0.x and later.<br>Set to `true` to reject bundles that contain symlinks or<br>hardlinks.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **:reject\_path\_traversal\_in\_bundle:**     | For version 2.0.x and later.<br>Set to `true` to reject archive entries that contain<br>`../` path traversal or absolute paths, and AppSpec source<br>fields that escape the bundle root.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **:reject\_unsafe\_permissions\_in\_bundle:** | For version 2.0.x and later.<br>Set to `true` to reject bundles that contain SUID/SGID<br>files or AppSpec permission modes that set SUID/SGID.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **:reject\_unconfined\_selinux\_in\_bundle:** | For version 2.0.x and later.<br>Set to `true` to reject bundles that contain files with<br>MAC-disabling SELinux types.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **:reject\_symlink\_permission\_targets:**    | For version 2.0.x and later.<br>Set to `true` to reject an AppSpec file<br>`permissions` entry whose target is a symbolic link. By<br>default, the agent follows the link when it applies ownership, mode,<br>ACL, and SELinux changes.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **:ignore\_ownership\_in\_bundle:**           | For version 2.0.x and later.<br>Set to `true` to reset the ownership of files extracted<br>from `tar` and `tgz` bundles to<br>`root` instead of applying the user ID and group ID recorded<br>in the archive. Files in `zip` bundles are owned by<br>`root` regardless of this setting.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **:restrict\_agent\_dir\_permissions:**       | For version 2.0.x and later. Linux instances only.<br>Set to `true` to restrict the directories and files under<br>the agent installation root to root-only access instead of the<br>world-readable modes used by default.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **:restrict\_log\_dir\_permissions:**         | For version 2.0.x and later. Linux instances only.<br>Set to `true` to restrict the agent log directory, which<br>contains the agent log and the updater log, to root-only access instead<br>of the world-readable modes used by default.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **:restrict\_hook\_env\_to\_allowlist:**      | For version 2.0.x and later.<br>Set to `true` to run lifecycle event hooks with a minimal<br>environment that contains only basic shell variables and the CodeDeploy<br>deployment variables. By default, hooks inherit the full environment of<br>the agent process.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **:strip\_loader\_env\_in\_hooks:**           | For version 2.0.x and later. Linux instances only.<br>Set to `true` to remove the `LD_PRELOAD`,<br>`LD_LIBRARY_PATH`, and `LD_AUDIT` variables<br>from the environment of lifecycle event hooks.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **:disable\_powershell\_profile\_in\_hooks:** | For version 2.0.x and later. Windows Server instances only.<br>Set to `true` to run `.ps1` lifecycle<br>event hooks with the `-NoProfile` and<br>`-NonInteractive` options. By default, these hooks load<br>the PowerShell profile of the user that the agent runs as.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **:archive\_max\_extraction\_size:**          | For version 2.0.x and later.<br>Sets a cap on the declared uncompressed bundle size. If the extracted<br>content exceeds this value, the deployment fails.<br>The default is no cap (unlimited).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:wait\_after\_error:**                      | The number of seconds the agent waits after encountering an error<br>before resuming normal operation.<br>The default setting is `30`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **:http\_read\_timeout:**                     | The HTTP read timeout in seconds for service API calls.<br>The default setting is `80`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **:kill\_agent\_max\_wait\_time\_seconds:**   | The maximum number of seconds the agent waits for a graceful shutdown<br>before force-terminating. For version 2.0.x and later, this value is<br>capped at 24 hours (86400 seconds).<br>The default setting is `7200` (2 hours).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:enable\_deployments\_log:**                | Set to `true` to write the aggregated deployments log<br>(`codedeploy-agent-deployments.log`).<br>The default setting is `true`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:use\_fips\_mode:**                         | Set to `true` to use FIPS-compliant endpoints. Applies to<br>US Regions only.<br>The default setting is `false`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **:deploy\_control\_endpoint:**               | (Optional) A custom control-plane endpoint URL for the CodeDeploy service.<br>The default is no override (the agent resolves the endpoint from the<br>Region).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **:s3\_endpoint\_override:**                  | (Optional) A custom Amazon S3 endpoint URL for bundle downloads.<br>The default is no override (the agent resolves the Amazon S3 endpoint from<br>the Region).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **:ongoing\_deployment\_tracking:**           | The name of the subdirectory used for deployment tracking state.<br>The default setting is `ongoing-deployment`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
