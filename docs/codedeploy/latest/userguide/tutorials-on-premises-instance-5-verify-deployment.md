# Step 5: Verify your

deployment

To verify the deployment was successful, follow the instructions in [View CodeDeploy deployment details](deployments-view-details.md "deployments-view-details.md") , and
then return to this page.

If the deployment was successful, you'll find four text files in the
`c:\temp\CodeDeployExample` folder (for
Windows Server) or `/tmp/CodeDeployExample` (for
Ubuntu Server and RHEL).

If the deployment failed, follow the troubleshooting steps in [View Instance Details](instances-view-details.md "instances-view-details.md") and [Troubleshoot instance issues](troubleshooting-ec2-instances.md "troubleshooting-ec2-instances.md"). Make any required fixes, rebundle
and upload your application revision, and then try the deployment again.
