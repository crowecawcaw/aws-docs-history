# Integration with partner products and

services

CodeDeploy has built-in integration for the following partner products and services:

|                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Ansible**                             | If you already have a set of [Ansible](http://www.ansible.com "http://www.ansible.com") playbooks, but just need somewhere to run them, the<br>template for Ansible and CodeDeploy demonstrates how a couple of simple<br>deployment hooks can ensure Ansible is available on the local deployment<br>instance and runs the playbooks. If you already have a process for building<br>and maintaining your inventory, there's also an Ansible module you can use<br>to install and run the CodeDeploy agent.<br>Learn more:<br>• [Ansible and CodeDeploy](https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/ansible/ "https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/ansible/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Atlassian – Bamboo and<br>Bitbucket** | The CodeDeploy task for [Bamboo](https://www.atlassian.com/software/bamboo/ "https://www.atlassian.com/software/bamboo/")<br>compresses the directory that contains an AppSpec file into a .zip file,<br>uploads the file to Amazon S3, and then starts the deployment according to the<br>configuration provided in the CodeDeploy application.<br>Atlassian Bitbucket support for CodeDeploy enables you to push code to Amazon EC2<br>instances directly from the Bitbucket UI, on demand, to any of your<br>deployment groups. This means that after you update code in your Bitbucket<br>repository, you do not have to sign in to your continuous integration (CI)<br>platform or Amazon EC2 instances to run a manual deployment process.<br>Learn more:<br>• [Using the CodeDeploy task for Bamboo](https://confluence.atlassian.com/bamboo059/using-the-aws-codedeploy-task-800858098.html "https://confluence.atlassian.com/bamboo059/using-the-aws-codedeploy-task-800858098.html")<br>• [Announcing Atlassian Bitbucket support for CodeDeploy](https://aws.amazon.com/blogs/apn/announcing-atlassian-bitbucket-support-for-aws-codedeploy/ "https://aws.amazon.com/blogs/apn/announcing-atlassian-bitbucket-support-for-aws-codedeploy/") |
| **Chef**                                | AWS provides two template samples for integrating [Chef](https://www.chef.io/ "https://www.chef.io/") and CodeDeploy. The first is a Chef<br>cookbook that installs and starts the CodeDeploy agent. This allows you to<br>continue managing your host infrastructure with Chef while using CodeDeploy. The<br>second sample template demonstrates how to use CodeDeploy to orchestrate the<br>running of cookbooks and recipes with chef-solo on each node.<br>Learn more:<br>• [Chef and CodeDeploy](https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/chef/ "https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/chef/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **CircleCI**                            | [CircleCI](https://circleci.com/ "https://circleci.com/") provides an automated<br>testing and continuous integration and deployment toolset. After you create<br>an IAM role in AWS to use with CircleCI and configure your deployment<br>parameters in your circle.yml file, you can use CircleCI with CodeDeploy to<br>create application revisions, upload them to an Amazon S3 bucket, and then<br>initiate and monitor your deployments.<br>Learn more:<br>• [Using a CircleCI Orb to deploy applications to<br>AWS CodeDeploy](https://github.com/CircleCI-Public/aws-code-deploy-orb "https://github.com/CircleCI-Public/aws-code-deploy-orb")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **CloudBees**                           | You can use the CodeDeploy Jenkins plugin, available on [CloudBees](https://www.cloudbees.com/ "https://www.cloudbees.com/") DEV@cloud, as a<br>post-build action. For example, at the end of a continuous delivery<br>pipeline, you can use it to deploy an application revision to your fleet of<br>servers.<br>Learn more:<br>• [CodeDeploy Jenkins plugin now available on DEV@cloud](http://developer-blog.cloudbees.com/2015/01/amazon-aws-codedeploy-jenkins-plugin.html "http://developer-blog.cloudbees.com/2015/01/amazon-aws-codedeploy-jenkins-plugin.html")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Codeship**                            | You can use [Codeship](https://codeship.com/ "https://codeship.com/") to deploy<br>application revisions through CodeDeploy. You can use the Codeship UI to add<br>CodeDeploy to a deployment pipeline for a branch.<br>Learn more:<br>• [Deploy to CodeDeploy](https://documentation.codeship.com/basic/continuous-deployment/deployment-to-aws-codedeploy/ "https://documentation.codeship.com/basic/continuous-deployment/deployment-to-aws-codedeploy/")<br>• [CodeDeploy integration on Codeship](http://blog.codeship.com/aws-codedeploy-codeship/ "http://blog.codeship.com/aws-codedeploy-codeship/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **GitHub**                              | You can use CodeDeploy to deploy application revisions from [GitHub](http://www.github.com "http://www.github.com") repositories. You can also<br>trigger a deployment from a GitHub repository whenever the source code in<br>that repository is changed.<br>Learn more:<br>• [Integrating CodeDeploy with GitHub](integrations-partners-github.md "integrations-partners-github.md")<br>• [Tutorial: Use CodeDeploy to deploy an application from<br>GitHub](tutorials-github.md "tutorials-github.md")<br>• [Automatically deploy from GitHub using CodeDeploy](https://aws.amazon.com/blogs/devops/automatically-deploy-from-github-using-aws-codedeploy/ "https://aws.amazon.com/blogs/devops/automatically-deploy-from-github-using-aws-codedeploy/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **HashiCorp Consul**                    | You can use the open-source HashiCorp Consul tool to help ensure the<br>health and stability of your application environment when you deploy<br>applications in CodeDeploy. You can use Consul to register applications to be<br>discovered during deployment, put applications and nodes in maintenance mode<br>to omit them from deployments, and stop deployments if target instances<br>become unhealthy.<br>Learn more:<br>• [CodeDeploy deployments with HashiCorp Consul](https://aws.amazon.com/blogs/apn/aws-codedeploy-deployments-with-hashicorp-consul/ "https://aws.amazon.com/blogs/apn/aws-codedeploy-deployments-with-hashicorp-consul/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Jenkins**                             | The CodeDeploy [Jenkins](http://jenkins-ci.org/ "http://jenkins-ci.org/") plugin<br>provides a post-build step for your Jenkins project. Upon a successful<br>build, it zips the workspace, uploads to Amazon S3, and starts a new<br>deployment.<br>Learn more:<br>• [CodeDeploy<br>Jenkins plugin](https://github.com/awslabs/aws-codedeploy-plugin "https://github.com/awslabs/aws-codedeploy-plugin")<br>• [Setting up the Jenkins plugin for CodeDeploy](https://aws.amazon.com/blogs/devops/setting-up-the-jenkins-plugin-for-aws-codedeploy/ "https://aws.amazon.com/blogs/devops/setting-up-the-jenkins-plugin-for-aws-codedeploy/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Puppet Labs**                         | AWS provides sample templates for [Puppet](https://puppetlabs.com/ "https://puppetlabs.com/") and CodeDeploy. The first is a Puppet module that installs and<br>starts the CodeDeploy agent. This allows you to continue managing your host<br>infrastructure with Puppet while using CodeDeploy. The second sample template<br>demonstrates how to use CodeDeploy to orchestrate the running of modules and<br>manifests with a masterless puppet on each node.<br>Learn more:<br>• [Puppet and CodeDeploy](https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/puppet/ "https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/puppet/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **SaltStack**                           | You can integrate [SaltStack](https://saltproject.io/index.html "https://saltproject.io/index.html")<br>infrastructure with CodeDeploy. You can use the CodeDeploy module to install and run<br>the CodeDeploy agent on your minions or, with a couple of simple deployment<br>hooks, you can use CodeDeploy to orchestrate the running of your Salt<br>States.<br>Learn more:<br>• [SaltStack and CodeDeploy](https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/salt/ "https://github.com/awslabs/aws-codedeploy-samples/tree/master/conf-mgmt/salt/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **TeamCity**                            | You can use the CodeDeploy Runner plugin to deploy applications directly from<br>TeamCity. The plugin adds a TeamCity build step that prepares and uploads an<br>application revision to an Amazon S3 bucket, registers the revision in a CodeDeploy<br>application, creates a CodeDeploy deployment and, if you choose, waits for the<br>deployment to be completed.<br>Learn more:<br>• [CodeDeploy Runner (Download)](https://github.com/JetBrains/teamcity-aws-codedeploy-plugin?tab=readme-ov-file "https://github.com/JetBrains/teamcity-aws-codedeploy-plugin?tab=readme-ov-file")<br>• [CodeDeploy Runner plugin (Documentation)](https://blog.jetbrains.com/teamcity/2016/04/aws-codedeploy-runner-plugin/ "https://blog.jetbrains.com/teamcity/2016/04/aws-codedeploy-runner-plugin/")                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Travis CI**                           | You can configure [Travis CI](https://travis-ci.com/ "https://travis-ci.com/")<br>to trigger a deployment in CodeDeploy after a successful build.<br>Learn more:<br>• [Travis CI and CodeDeploy deployments](http://docs.travis-ci.com/user/deployment/codedeploy/ "http://docs.travis-ci.com/user/deployment/codedeploy/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
