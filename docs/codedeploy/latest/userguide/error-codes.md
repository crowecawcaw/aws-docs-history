# Error codes for AWS CodeDeploy

This topic provides reference information about CodeDeploy errors.

| Error Code                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `AGENT_ISSUE`                       | The deployment failed because of a problem with the CodeDeploy agent. Make<br>sure the agent is installed and running on all instances in this<br>deployment group.<br>Learn more:<br>• [Verify the CodeDeploy agent is running](codedeploy-agent-operations-verify.md "codedeploy-agent-operations-verify.md")<br>• [Install the CodeDeploy agent](codedeploy-agent-operations-install.md "codedeploy-agent-operations-install.md")<br>• [Working with the CodeDeploy agent](codedeploy-agent.md "codedeploy-agent.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `AUTO_SCALING_IAM_ROLE_PERMISSIONS` | The service role associated with your deployment group does not have<br>the permission required to perform operations in the following AWS<br>service.<br>Learn more:<br>• [Step 2: Create a service role for<br>CodeDeploy](getting-started-create-service-role.md "getting-started-create-service-role.md")<br>• [Creating a Role to Delegate Permissions to an AWS<br>Service](../../../IAM/latest/UserGuide/id_roles_create_for-service.md "../../../IAM/latest/UserGuide/id_roles_create_for-service.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `HEALTH_CONSTRAINTS`                | The overall deployment failed because too many individual instances<br>failed deployment, too few healthy instances are available for<br>deployment, or some instances in your deployment group are experiencing<br>problems.<br>Learn more:<br>• [Instance Health](instances-health.md "instances-health.md")<br>• [Troubleshoot instance issues](troubleshooting-ec2-instances.md "troubleshooting-ec2-instances.md")<br>• [Troubleshoot EC2/On-Premises<br>deployment issues](troubleshooting-deployments.md "troubleshooting-deployments.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `HEALTH_CONSTRAINTS_INVALID`        | The deployment can’t start because the minimum number of healthy<br>instances, as defined by your deployment configuration, are not<br>available. You can reduce the required number of healthy instances by<br>updating your deployment configuration or increase the number of<br>instances in this deployment group.<br>Learn more:<br>• [Instance Health](instances-health.md "instances-health.md")<br>• [Working with instances for CodeDeploy](instances.md "instances.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `IAM_ROLE_MISSING`                  | The deployment failed because no service role exists with the service<br>role name specified for the deployment group. Make sure you are using<br>the correct service role name.<br>Learn more:<br>• [Step 2: Create a service role for<br>CodeDeploy](getting-started-create-service-role.md "getting-started-create-service-role.md")<br>• [Change deployment group settings with CodeDeploy](deployment-groups-edit.md "deployment-groups-edit.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `IAM_ROLE_PERMISSIONS`              | CodeDeploy does not have the permissions required to assume a role, or the<br>IAM role you're using does't give you permission to perform operations<br>in an AWS service.<br>Learn more:<br>• [Step 1: Setting up](getting-started-setting-up.md "getting-started-setting-up.md")<br>• [Step 2: Create a service role for<br>CodeDeploy](getting-started-create-service-role.md "getting-started-create-service-role.md")<br>• [Step 4: Create an IAM instance<br>profile for your Amazon EC2 instances](getting-started-create-iam-instance-profile.md "getting-started-create-iam-instance-profile.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `NO_INSTANCES`                      | This might be caused by one of the following.<br>• For an EC2/On-Premises blue/green deployment, if<br>you use Amazon EC2 tags they might not be configured properly. In<br>your CodeDeploy deployment group, make sure they are included in your<br>blue instances and your green instances. You can confirm your<br>instances are tagged properly using the Amazon EC2 console.<br>• If you use an Amazon EC2 Auto Scaling group, your Auto Scaling group might not<br>have enough capacity. Make sure your Auto Scaling group has enough<br>capacity for your deployment. You can view the capacity of your<br>Amazon EC2 Auto Scaling group by looking at its number of healthy instances<br>using the Amazon EC2 console.<br>• For an EC2/On-Premises blue/green deployment, the<br>blue and green fleets might not be the same size. Make sure both<br>fleets are the same size.<br>Learn more:<br>• [Tagging Instances for Deployments](instances-tagging.md "instances-tagging.md")<br>• [Tutorial: Use CodeDeploy to deploy an application<br>to an Auto Scaling group](tutorials-auto-scaling-group.md "tutorials-auto-scaling-group.md")<br>• [Create an application for a blue/green<br>deployment (console)](applications-create-blue-green.md "applications-create-blue-green.md") |
| `OVER_MAX_INSTANCES`                | The deployment failed because more instances are targeted for<br>deployment than are allowed for your account. To reduce the number of<br>instances targeted for this deployment, update the tag settings for this<br>deployment group or delete some of the targeted instances.<br>Alternatively, you can contact AWS Support to request a limit<br>increase.<br>Learn more:<br>• [Change deployment group settings with CodeDeploy](deployment-groups-edit.md "deployment-groups-edit.md")<br>• [CodeDeploy quotas](limits.md "limits.md")<br>• [Request a Limit Increase](https://console.aws.amazon.com/support/home#/case/create%3FissueType=service-limit-increase "https://console.aws.amazon.com/support/home#/case/create%3FissueType=service-limit-increase")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `THROTTLED`                         | The deployment failed because more requests were made than are<br>permitted for AWS CodeDeploy by an IAM role. Try reducing the number of<br>requests.<br>Learn more:<br>• [Query API Request Rate](../../../AWSEC2/latest/APIReference/query-api-troubleshooting.md#api-request-rate "../../../AWSEC2/latest/APIReference/query-api-troubleshooting.md#api-request-rate")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `UNABLE_TO_SEND_ASG`                | The deployment failed because the deployment group isn’t configured<br>correctly with its Amazon EC2 Auto Scaling group. In the CodeDeploy console, delete the<br>Amazon EC2 Auto Scaling group from the deployment group, and then add it again.<br>Learn more:<br>• [Under the Hood: CodeDeploy and Auto Scaling Integration](https://aws.amazon.com/blogs/devops/under-the-hood-aws-codedeploy-and-auto-scaling-integration/ "https://aws.amazon.com/blogs/devops/under-the-hood-aws-codedeploy-and-auto-scaling-integration/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
