# Integration with other AWS services

CodeDeploy is integrated with the following AWS services:

|                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Amazon CloudWatch**                | [Amazon CloudWatch](../../../AmazonCloudWatch/latest/DeveloperGuide.md "../../../AmazonCloudWatch/latest/DeveloperGuide.md") is a monitoring service for<br>AWS cloud resources and the applications you run on AWS. You can use<br>Amazon CloudWatch to collect and track metrics, collect and monitor log files, and<br>set alarms. CodeDeploy supports the following CloudWatch tools:<br>• **CloudWatch alarms** for monitoring your<br>deployments and stopping them when your specified monitoring metrics<br>exceed or fall below the thresholds you specify in a CloudWatch alarm rule.<br>To use alarm monitoring, you first set up an alarm in CloudWatch, and then<br>add it in CodeDeploy to the application or deployment group where<br>deployments should stop when the alarm is activated.<br>Learn more:<br>+ [Creating<br>CloudWatch Logs alarms](../../../AmazonCloudWatch/latest/DeveloperGuide/AlarmThatSendsEmail.md "../../../AmazonCloudWatch/latest/DeveloperGuide/AlarmThatSendsEmail.md")<br>• **Amazon CloudWatch Events** for detecting and<br>reacting to changes in the state of an instance or a deployment in<br>your CodeDeploy operations. Then, based on rules you create, CloudWatch Events invokes<br>one or more target actions when a deployment or instance enters the<br>state you specify in a rule.<br>Learn more:<br>+ [Monitoring deployments with Amazon CloudWatch Events](monitoring-cloudwatch-events.md "monitoring-cloudwatch-events.md")<br>• **Amazon CloudWatch Logs** for monitoring the three<br>types of logs created by the CodeDeploy agent without having to sign in to<br>instances one at a time.<br>Learn more:<br>+ [View CodeDeploy logs in CloudWatch Logs console](https://aws.amazon.com/blogs/devops/view-aws-codedeploy-logs-in-amazon-cloudwatch-console/ "https://aws.amazon.com/blogs/devops/view-aws-codedeploy-logs-in-amazon-cloudwatch-console/")                                   |
| **Amazon EC2 Auto Scaling**          | CodeDeploy supports [Amazon EC2 Auto Scaling](https://aws.amazon.com/autoscaling "https://aws.amazon.com/autoscaling").<br>This AWS service can automatically launch Amazon EC2 instances based on<br>criteria you specify, for example:<br>• Limits exceeded for specified CPU utilization.<br>• Disk reads or writes.<br>• Inbound or outbound network traffic over a specified time<br>interval.<br>You can scale out a group of Amazon EC2 instances whenever you need them and<br>then use CodeDeploy to deploy application revisions to them automatically.<br>Amazon EC2 Auto Scaling terminates those Amazon EC2 instances when they are no longer<br>needed.<br>Learn more:<br>• [Integrating CodeDeploy with Amazon EC2 Auto Scaling](integrations-aws-auto-scaling.md "integrations-aws-auto-scaling.md")<br>• [Tutorial: Use CodeDeploy to deploy an application<br>to an Auto Scaling group](tutorials-auto-scaling-group.md "tutorials-auto-scaling-group.md")<br>• [Under the hood: CodeDeploy and Auto Scaling integration](https://aws.amazon.com/blogs/devops/under-the-hood-aws-codedeploy-and-auto-scaling-integration/ "https://aws.amazon.com/blogs/devops/under-the-hood-aws-codedeploy-and-auto-scaling-integration/")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Amazon Elastic Container Service** | You can use CodeDeploy to deploy an Amazon ECS containerized application as a task<br>set. CodeDeploy performs a blue/green deployment by installing an updated version<br>of the application as a new replacement task set. CodeDeploy reroutes production<br>traffic from the original application task set to the replacement task set.<br>The original task set is terminated after a successful deployment. For more<br>information about Amazon ECS, see [Amazon<br>Elastic Container Service](https://aws.amazon.com/ecs/ "https://aws.amazon.com/ecs/").<br>You can manage the way in which traffic is shifted to the updated task<br>set during a deployment by choosing a canary, linear, or all-at-once<br>configuration. For more information about Amazon ECS deployments, see [Deployments on an Amazon ECS compute platform](../../../en_us/codedeploy/latest/userguide/deployment-steps-ecs.md "../../../en_us/codedeploy/latest/userguide/deployment-steps-ecs.md").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **AWS CloudTrail**                   | CodeDeploy is integrated with [AWS CloudTrail](../../../awscloudtrail/latest/userguide.md "../../../awscloudtrail/latest/userguide.md").<br>This service captures API calls made by or on behalf of CodeDeploy in your AWS<br>account and delivers the log files to an Amazon S3 bucket you specify. CloudTrail<br>captures API calls from the CodeDeploy console, from CodeDeploy commands through the<br>AWS CLI, or from the CodeDeploy APIs directly. Using the information collected by<br>CloudTrail, you can determine:<br>• Which request was made to CodeDeploy.<br>• The source IP address from which the request was made.<br>• Who made the request.<br>• When it was made.<br>Learn more:<br>• [Monitoring Deployments](monitoring-cloudtrail.md "monitoring-cloudtrail.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **AWS Cloud9**                       | [AWS Cloud9](../../../cloud9/latest/user-guide.md "../../../cloud9/latest/user-guide.md") is an online, cloud-based<br>integrated development environment (IDE) you can use to write, run, debug,<br>and deploy code using just a browser from an internet-connected machine.<br>AWS Cloud9 includes a code editor, debugger, terminal, and essential tools, such<br>as the AWS CLI and Git.<br>• You can use the AWS Cloud9 IDE to run, debug, and build code that is<br>in a GitHub repository. You can view, change, and save the code using<br>its IDE \*_Environment_<br>• window and editor tabs. When<br>you're ready, you can use Git in the AWS Cloud9 terminal session to<br>push code changes to your GitHub repository, and then use AWS CodeDeploy to<br>deploy your updates. For more information about using AWS Cloud9 with<br>GitHub, see [GitHub sample<br>for AWS Cloud9](../../../cloud9/latest/user-guide/sample-github.md "../../../cloud9/latest/user-guide/sample-github.md").<br>• You can use the AWS Cloud9 IDE to update an AWS Lambda function. You<br>can then use AWS CodeDeploy to create a deployment that shifts traffic to<br>the new version of your AWS Lambda function. For more information, see<br>[Working with<br>AWS Lambda functions in the AWS Cloud9 Integrated Development Environment<br>(IDE)](../../../cloud9/latest/user-guide/lambda-functions.md "../../../cloud9/latest/user-guide/lambda-functions.md").<br>For more information about AWS Cloud9, see [What Is AWS Cloud9](../../../cloud9/latest/user-guide/welcom.md "../../../cloud9/latest/user-guide/welcom.md") and [Getting started with<br>AWS Cloud9](../../../cloud9/latest/user-guide/get-started.md "../../../cloud9/latest/user-guide/get-started.md").                                                                                                                                                                                      |
| **AWS CodePipeline**                 | [AWS CodePipeline](../../../codepipeline/latest/userguide.md "../../../codepipeline/latest/userguide.md") is a continuous delivery<br>service you can use to model, visualize, and automate the steps required to<br>release your software in a continuous delivery process. You can use<br>AWS CodePipeline to define your own release process so that the service builds,<br>tests, and deploys your code every time there is a code change. For example,<br>you might have three deployment groups for an application: Beta, Gamma, and<br>Prod. You can set up a pipeline so that each time there is a change in your<br>source code, the updates are deployed to each deployment group, one by<br>one.<br>You can configure AWS CodePipeline to use CodeDeploy to deploy:<br>• Code to Amazon EC2 instances, on-premises instances, or both.<br>• Serverless AWS Lambda function versions.<br>You can create the CodeDeploy application, deployment, and deployment group to<br>use in a deploy action in a stage either before you create the pipeline or<br>in the \*_Create Pipeline_<br>• wizard.<br>Learn more:<br>• [AWS<br>for DevOps getting started guide](../../../devops/latest/gsg/welcome.md "../../../devops/latest/gsg/welcome.md") — Learn how to use<br>CodePipeline with CodeDeploy to continuously deliver and deploy source code in<br>CodeCommit repositories to Amazon EC2 instances.<br>• [Simple pipeline<br>walkthrough (Amazon S3 Bucket)](../../../codepipeline/latest/userguide/getting-started-w.md "../../../codepipeline/latest/userguide/getting-started-w.md")<br>• [Simple pipeline<br>walkthrough (CodeCommit Repository)](../../../codepipeline/latest/userguide/getting-started-cc.md "../../../codepipeline/latest/userguide/getting-started-cc.md")<br>• [Four-stage<br>pipeline tutorial](../../../codepipeline/latest/userguide/getting-started-4.md "../../../codepipeline/latest/userguide/getting-started-4.md") |
| **AWS Serverless Application Model** | AWS Serverless Application Model (AWS SAM) is a model to define serverless applications.<br>It extends AWS CloudFormation to provide a simplified way of defining AWS Lambda<br>functions, Amazon API Gateway APIs, and Amazon DynamoDB tables required by a serverless<br>application. If you already use AWS SAM, you can add deployment<br>preferences to start using CodeDeploy to manage the way in which traffic is<br>shifted during an AWS Lambda application deployment.<br>For more information, see the [AWS Serverless Application Model](https://github.com/awslabs/serverless-application-model "https://github.com/awslabs/serverless-application-model").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Elastic Load Balancing**           | CodeDeploy supports [Elastic Load Balancing](../../../ElasticLoadBalancing/latest/DeveloperGuide/elastic-load-balancing.md "../../../ElasticLoadBalancing/latest/DeveloperGuide/elastic-load-balancing.md"), a service that distributes incoming application<br>traffic across multiple Amazon EC2 instances.<br>For CodeDeploy deployments, load balancers also prevent traffic from being<br>routed to instances when they are not ready, are currently being deployed<br>to, or are no longer needed as part of an environment.<br>Learn more:<br>• [Integrating CodeDeploy with Elastic Load Balancing](integrations-aws-elastic-load-balancing.md "integrations-aws-elastic-load-balancing.md")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
