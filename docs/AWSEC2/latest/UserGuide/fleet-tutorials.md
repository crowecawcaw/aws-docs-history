# Tutorials for EC2 Fleet

There are different ways to configure an EC2 Fleet. The configuration you choose depends on
your specific use case.

The following tutorials cover some of the possible use cases and provide the tasks required
to implement them.

| Use case                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Link to tutorial                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use instance weighting to manage the availability and performance<br>of your EC2 Fleet.**<br>With instance weighting, you assign a weight to each instance type in your EC2 Fleet to<br>represent their compute capacity and performance relative to each other.<br>Based on the weights, the fleet can use any combination of the specified<br>instance types, as long as it can fulfil the desired target<br>capacity.                                                                                                                          | [Tutorial: Configure EC2 Fleet to use<br>instance weighting](ec2-fleet-instance-weighting-walkthrough.md "ec2-fleet-instance-weighting-walkthrough.md")                                                                                                                                 |
| **Use On-Demand capacity to ensure availability during peak periods,<br>but benefit from additional Spot capacity at a lower<br>cost.**<br>Configure your EC2 Fleet to use On-Demand Instances as the primary capacity to ensure available capacity<br>during peak periods. In addition, allocate some capacity to Spot Instances to<br>benefit from discounted pricing, while keeping in mind that Spot Instances can be<br>interrupted if Amazon EC2 needs the capacity back.                                                                     | [Tutorial: Configure EC2 Fleet to use On-Demand Instances<br>as the primary capacity](ec2-fleet-on-demand-walkthrough.md "ec2-fleet-on-demand-walkthrough.md")                                                                                                                          |
| **Use Capacity Reservations to reserve compute capacity for your<br>On-Demand Instances.**<br>Configure your EC2 Fleet to use `targeted` Capacity Reservations first when launching On-Demand Instances. If<br>you have strict capacity requirements, and are running business-critical<br>workloads that require a certain level of long or short-term capacity<br>assurance, we recommend that you create a Capacity Reservation to ensure that you<br>always have access to Amazon EC2 capacity when you need it, for as long<br>as you need it. | [Tutorial: Configure EC2 Fleet to launch On-Demand Instances using targeted Capacity Reservations](ec2-fleet-launch-on-demand-instances-using-targeted-capacity-reservations-walkthrough.md "ec2-fleet-launch-on-demand-instances-using-targeted-capacity-reservations-walkthrough.md") |
| **Use Capacity Blocks to reserve highly sought-after GPU instances for<br>your ML workloads.**<br>Configure your EC2 Fleet to launch instances into Capacity Blocks.                                                                                                                                                                                                                                                                                                                                                                                | [Tutorial:<br>Configure your EC2 Fleet to launch instances into Capacity Blocks](ec2-fleet-launch-instances-capacity-blocks-walkthrough.md "ec2-fleet-launch-instances-capacity-blocks-walkthrough.md")                                                                                 |
