

# Relationship to Spot placement score
<a name="capacity-manager-sps"></a>

For Spot capacity, get-capacity-manager-supportability-scores is built on Spot placement score (SPS), so you can check both On-Demand and Spot supportability through a single interface. SPS scores your flexibility as a whole rather than scoring individual instance type and Availability Zone combinations, and the Spot aggregate score gives you equivalent guidance. If you already use SPS directly, read the aggregate as your Spot signal.
