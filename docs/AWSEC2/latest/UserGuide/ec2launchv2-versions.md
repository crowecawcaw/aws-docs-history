## EC2Launch v2 version history

To ensure that you have the latest launch agent installed, see [Install the latest version of
EC2Launch v2](ec2launch-v2-install.md "ec2launch-v2-install.md"). You can
receive notifications when new versions of the EC2Launch v2 agent are released.
For more information, see [Subscribe to EC2 Windows launch agent notifications](launch-agents-subscribe-notifications.md "launch-agents-subscribe-notifications.md").
