# Enabling EC2 Capacity Manager

Capacity Manager can be enabled at two different levels depending on your requirements. You can enable it for a single AWS account to monitor resources
within that account only, or integrate it with AWS Organizations for centralized visibility across all member accounts in your organization.

- **Organization-level:** View and analyze capacity data across all member accounts in your organization from a single dashboard.
- **Account-level:** Monitor capacity usage within a single AWS account.
