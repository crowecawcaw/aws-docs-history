# Tutorials for launching EC2

instances

There are different ways to launch and configure an Amazon EC2 instance. The method and
configuration you use depends on your specific use case.

The following tutorials can help you learn how to launch EC2 instances. If you're new to
Amazon EC2, we recommend that you start with the first
tutorial. The tutorials start by introducing you to the basics, and help you
build on the basics by introducing more configuration options.

| Objective                                                                                                                                                                                                                                                                                                                                                                                          | Link to tutorial                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Launch my very first EC2<br>instance**<br>Learn how to quickly launch an Amazon EC2 instance by using the default<br>settings in the Amazon EC2 launch instance wizard. Also learn how to review<br>the instance configuration fields and terminate the instance.<br>Duration: 10 minutes                                                                                                        | [Tutorial 1: Launch my very first<br>Amazon EC2 instance](tutorial-launch-my-first-ec2-instance.md "tutorial-launch-my-first-ec2-instance.md") |
| **Launch a test EC2 instance and connect to<br>it**<br>Learn how to launch an Amazon EC2 instance that you can use for testing<br>purposes. This instance will have no advanced configuration and won't<br>store sensitive information. You will also learn about the essential<br>instance configuration settings, how to connect to the instance, and how<br>to stop it.<br>Duration: 30 minutes | [Tutorial 2: Launch a test EC2<br>instance and connect to it](tutorial-launch-a-test-ec2-instance.md "tutorial-launch-a-test-ec2-instance.md") |
