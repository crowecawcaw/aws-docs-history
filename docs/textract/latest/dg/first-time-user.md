

# First-time Amazon Textract Core users

If this is your first time using Amazon Textract Core, read the following sections in order:

1. **[Identifying your Amazon Textract Core use case](how-it-works.md)** – This section introduces the Amazon Textract Core components and how they work together for an end-to-end experience.

1. **[Getting started with Amazon Textract Core](getting-started.md)** – In this section, you set up your account and test the Amazon Textract Core API.

If you want to split, classify, and extract data from documents in a single asynchronous request using generative AI, use Amazon Textract Insights. To get started, see [Getting started with Amazon Textract Insights](insights-getting-started.md).
