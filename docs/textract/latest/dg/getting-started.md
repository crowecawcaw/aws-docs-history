

# Getting started with Amazon Textract Core

This section provides topics to get you started using Amazon Textract Core. It covers the prerequisites of creating and configuring your AWS account and the AWS software development kits (SDKs) you will use to invoke the Amazon Textract Core APIs. If you're new to Amazon Textract Core, first review the concepts and terminology in [Identifying your Amazon Textract Core use case](how-it-works.md). 

You can try the API by using the demonstration in the [Amazon Textract console](https://console.aws.amazon.com/textract/).

You can also process documents by asking your AI coding agent in natural language. See [Amazon Textract document processing skill](textract-document-processing-skill.md).
