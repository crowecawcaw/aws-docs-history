# Getting Started with Amazon Textract

This section provides topics to get you started using Amazon Textract. It covers the
prerequisites of creating and configuring your AWS account and the AWS SDKs you will use to
invoke the Amazon Textract APIs. If you're new to Amazon Textract, we recommend that you first
review the concepts and terminology in [Identifying Your Amazon Textract Use Case](how-it-works.md "how-it-works.md").

You can try the API by using the demonstration in the Amazon Textract console. For more information, see
[https://console.aws.amazon.com/textract/](https://console.aws.amazon.com/textract/ "https://console.aws.amazon.com/textract/").
