# Set Quotas in Amazon Textract

The following is a list of set quotas in Amazon Textract, which cannot be changed. For
information about limitations in default quotas you can change, see the section [Default
Quotas in Amazon Textract.](limits-quotas-explained.md "limits-quotas-explained.md")

| Limit                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Accepted File Formats            | Operations support JPEG, PNG, PDF, and TIFF files. (JPEG<br>2000-encoded images within PDFs are supported). Textract<br>does not support XFA based PDFs.                                                                                                                                                                                                                                                                           |
| File Size and Page Count Limits  | For synchronous operations, JPEG, PNG, PDF, and TIFF files have a<br>limit of 10 MB in memory. PDF and TIFF files also have a limit of 1<br>page. For asynchronous operations, JPEG and PNG files have a limit<br>of 10 MB in memory. PDF and TIFF files have a limit of 500 MB in<br>memory and a limit of 3,000 pages.                                                                                                           |
| PDF Specific Limits              | The maximum height and width<br>is 40 inches and 9000 points. PDFs cannot be password protected.<br>PDFs can contain JPEG 2000 formatted images.                                                                                                                                                                                                                                                                                   |
| Document Rotation and Image Size | Amazon Textract supports all in-plane document rotations, for example<br>45-degree in-plane rotation.<br>Amazon Textract supports images with a resolution less than or equal to<br>10000 pixels on all sides.                                                                                                                                                                                                                     |
| Query Specific Limits            | Amazon Textract supports up to 15 queries per page for synchronous operations and up to 30 queries per page<br>for asynchronous operations.                                                                                                                                                                                                                                                                                        |
| Text Alignment                   | Text can be text aligned horizontally within the document.<br>Horizontally arrayed text can be read regardless of the degree of<br>rotation of a document. Amazon Textract does not support vertical text<br>(text written vertically, as is common in languages like Japanese<br>and Chinese) alignment within the document.                                                                                                      |
| Languages                        | Amazon Textract supports English, French, German, Italian, Portuguese,<br>and Spanish text detection. Amazon Textract will not return the language<br>detected in its output. Query detection is only available in English<br>document detection.                                                                                                                                                                                  |
| Character Size                   | The minimum height for text to be detected is 15 pixels.<br>At 150 DPI, this would be the same as 8 point font.                                                                                                                                                                                                                                                                                                                    |
| Character Type                   | Amazon Textract supports both handwritten and printed character recognition. Handwritten character<br>recognition is only supported in English.                                                                                                                                                                                                                                                                                    |
