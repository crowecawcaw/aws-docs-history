# LendingDocument

Holds the structured data returned by AnalyzeDocument for lending documents.

## Contents

**LendingFields**

An array of LendingField objects.

Type: Array of [LendingField](API_LendingField.md "API_LendingField.md") objects

Required: No

**SignatureDetections**

A list of signatures detected in a lending document.

Type: Array of [SignatureDetection](API_SignatureDetection.md "API_SignatureDetection.md") objects

Required: No
