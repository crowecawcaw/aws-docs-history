

# Extraction

This section describes extraction, the capability that turns a document's text, layout elements, tables, and reading order into structured output. Every project includes extraction, and every job that uses a project produces extraction results. The topics explain the structure of the extraction results and how granularity controls which sections they contain. They also cover the plain text, Markdown, HTML, and CSV formats you can pass straight to a large language model (LLM) or a retrieval-augmented generation (RAG) pipeline, and the AI-generated document summaries and figure captions you can add.
