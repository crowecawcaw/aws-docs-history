# EvaluationMetric

The evaluation metrics (F1 score, Precision, and Recall) for an adapter version.

## Contents

**F1Score**

The F1 score for an adapter version.

Type: Float

Required: No

**Precision**

The Precision score for an adapter version.

Type: Float

Required: No

**Recall**

The Recall score for an adapter version.

Type: Float

Required: No
