

# Security and operations

This section covers protecting your data and running Amazon Textract Insights reliably at scale. These topics explain default encryption and how to use your own AWS KMS key. They describe how cross-Region inference routes processing to other AWS Regions within your geography, and how tags on projects, blueprints, and jobs help you organize resources and control access to them. They also cover the quotas and fixed limits on jobs, documents, and resources, what affects job latency and how to reduce it, and how to troubleshoot common errors and configuration issues.
