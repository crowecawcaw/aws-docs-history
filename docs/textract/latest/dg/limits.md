

# Quotas in Amazon Textract Core

The following sections provide information about quotas, formerly referred to as limits, when using Amazon Textract Core. There are two kinds of quotas. *Set quotas*, which can be viewed in the section [Set quotas in Amazon Textract Core](limits-document.md), cannot be changed. *Default quotas*, discussed in the section [Default Quotas](limits-quotas-explained.md), can be viewed or changed via the [Service quotas console](https://console.aws.amazon.com/servicequotas). You can also view the current Amazon Textract Core default quotas on the [Amazon Textract endpoints and service quotas](https://docs.aws.amazon.com/general/latest/gr/textract.html).
