# Managing message templates

The **Message templates** page on the Amazon Pinpoint console provides a single
location for you to create, view, and manage all the message templates for your Amazon Pinpoint account in
the current AWS Region. By using this page, you can manage your message templates as a single
collection. This can help you design consistent messages and reuse content more easily and
effectively. You can use this page to perform management tasks such as viewing and editing
templates, and copying, deleting, and creating templates.
