# Disable Automatic Database Backups

Follow these steps to disable automatic backups.

1. On the AWS Elemental Server web interface, go to the **Settings** page and
   choose **General**.
2. In the **Cluster Tasks** section, change the value in
   **Minutes between management database backups** to
   `0`.
3. Choose **Save**.
