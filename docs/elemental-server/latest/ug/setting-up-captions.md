# Setting Up Captions with AWS Elemental Server

To include captions in your job, follow these steps in the order listed:

1. [Set the timecode source
   settings.](set-the-timecode-source-settings.md "set-the-timecode-source-settings.md")
2. [Gather required captions
   information.](gather-required-captions-information.md "gather-required-captions-information.md")
3. [Choose a supported output
   captions format.](choose-a-supported-output-captions-format.md "choose-a-supported-output-captions-format.md")
4. [Create input captions
   selectors.](create-input-caption-selectors.md "create-input-caption-selectors.md")
5. [Set up captions in outputs.](including-captions-in-outputs.md "including-captions-in-outputs.md")
   For information about the files AWS Elemental Server generates from jobs that have captions
   in the outputs, see [About Captions Handling in Outputs](caption-handling.md "caption-handling.md").
