# (Font Styles for DVB-Sub)

You can specify the look of the captions if the output captions are DVB-Sub.

###### Note

If you choose the same **Caption Selector** in the **Caption
Source** field in more than one output, then you must set up the font style
information identically in each output. If you do not, you will get an error when you save the
job.

| Name               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Font               | Click \*_Browse_<br>• to find a font file to use. The file must be on a<br>server mounted to the node and must have the extension TTF or TTE. Do not specify a font<br>file if the caption source is embedded or teletext.                                                                                                                                                                                                                                            |
| Font Size          | Specify “auto” or enter a number. When set to auto, **font_size**<br>will scale depending on the size of the output. Giving a positive integer specifies the<br>exact font size in points.                                                                                                                                                                                                                                                                            |
| Font Resolution    | Font resolution in DPI (dots per inch). Range: 96 to 600. Default is 96 dpi.                                                                                                                                                                                                                                                                                                                                                                                          |
| Text Justify       | • Centered: If X Position and Y Position are both empty, positions the captions at<br>the bottom center of the video frame.<br>If X Position and Y Position are specified, the captions are offset and then<br>centered across the video frame.<br>• Left: If X Position and Y Position are both empty, positions captions at the bottom<br>left of the video frame.<br>If X Position and Y Position are specified, the captions are offset and then<br>left-aligned. |
| X Position         | Specifies the offset for the left edge of the caption relative to the horizontal<br>axis of the video frame, in pixels. 0 is the left edge of the video frame. 10 pixels means<br>_offset 10 pixels to the right._<br>Empty means _0 offset_.                                                                                                                                                                                                                         |
| Y Position         | Offset of the top edge of the caption relative to the vertical axis of the video<br>frame, in pixels. 0 is the top edge of the video frame. 10 pixels means _offset 10 pixels from the top._<br>Empty means _position the captions towards the bottom of the<br>output._                                                                                                                                                                                              |

| Font Color         | The font color. | Font Opacity       | The opacity for the font color. | Background Color   | The color for the background rectangle.                                                                                                                                                                                                                                                                                                                                                                                                                               |

| Shadow Opacity     | The opacity of the shadow, in pixels. Range 0 (transparent) to 255 (opaque). Empty<br>means 0.                                                                                                                                                                                                                                                                                                                                                                        |

| Shadow Y Offset    | The vertical offset of the shadow, in pixels. A value of -2 results in a shadow<br>offset 2 pixels above the text.
