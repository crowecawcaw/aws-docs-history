# Font Styles for Burn-in

You can specify the look of the captions if the output captions are Burn-in by changing
the font styles.

###### Note

If you choose the same **Caption Selector** in the **Caption
Source** field in more than one output, then you must set up the font style
information identically in each output. If you do not, you will get an error when you save the
job.

| Name               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Font               | Click \*_Browse_<br>• to find a font file to use. The file must be on a<br>server mounted to the node and must have the extension TTF or TTE. Do not specify a font<br>file if the caption source is embedded or teletext.                                                                                                                                                                                                                                                      |
| Font Size          | Specify “auto” or enter a number. When set to auto, **font_size**<br>scales depending on the size of the output. Giving a positive integer specifies the exact<br>font size in points.                                                                                                                                                                                                                                                                                          |
| Font Resolution    | Specify the font resolution in DPI (dots per inch). Range: 96 to 600. Default is 96<br>dpi.                                                                                                                                                                                                                                                                                                                                                                                     |
| Text Justify       | • Centered: If the X Position and Y Position are both empty, positions the captions<br>at the bottom center of the video frame. If the X Position and Y Position are specified,<br>the captions are offset and then centered across the video frame.<br>• Left: If the X Position and Y Position are both empty, positions captions at the<br>bottom left of the video frame. If the X Position and Y Position are specified, the<br>captions are offset and then left-aligned. |
| X Position         | Specify the offset for the left edge of the caption relative to the horizontal axis<br>of the video frame, in pixels. 0 is the left edge of the video frame. 10 pixels means<br>_offset 10 pixels to the right_.<br>Empty means _0 offset_.                                                                                                                                                                                                                                     |
| Y Position         | Specify the offset of the top edge of the caption relative to the vertical axis of<br>the video frame, in pixels. 0 is the top edge of the video frame. 10 pixels means<br>_offset 10 pixels from the top._<br>Empty means _position the captions towards the bottom of the<br>output_.                                                                                                                                                                                         |
