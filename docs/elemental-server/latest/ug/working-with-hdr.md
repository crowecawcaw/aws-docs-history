# Creating HDR Outputs with AWS Elemental Server

## Supported HDR Formats

AWS Elemental Server
can ingest and output video in the following formats and color
spaces:

- HDR10
- HLG, rec. 2020
- SDR, rec. 709
- SDR, rec. 609
