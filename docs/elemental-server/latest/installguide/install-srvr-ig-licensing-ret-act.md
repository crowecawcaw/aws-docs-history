# Step a: Retrieve Activation

Code

You should have received an email containing an activation code. If you're installing software for more than one node, you will have received a separate code for each one.

If you didn't receive this email or have lost it, contact AWS Elemental Support through your company’s Private Space in [AWS Elemental Support Center](https://console.aws.amazon.com/elemental-appliances-software/home?region=us-east-1#/supportcenter "https://console.aws.amazon.com/elemental-appliances-software/home?region=us-east-1#/supportcenter").
