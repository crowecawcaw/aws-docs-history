

# Working with DevOps Agent

AWS DevOps Agent works alongside your team across the full software delivery lifecycle — from validating code changes through to operating services in production.

## Code Change Risk Analysis (preview)
<a name="code-change-risk-analysis-preview"></a>

Code Change Risk Analysis helps you find production risks in code changes before they are deployed. AWS DevOps Agent reviews changes for risks to dependencies, adherence to your standards and best practices, and risks to your production environments. It can also build, run, and test your changes in a verification environment.

Code Change Risk Analysis is available in your IDE during code generation, in pull requests and merge requests, and on demand through AWS DevOps Agent chat, custom agents, and webhooks. For more information, see [Code Change Risk Analysis](working-with-devops-agent-code-change-risk-analysis-index.md).

## Production operations
<a name="production-operations"></a>

Production operations capabilities help you detect, respond to, and prevent incidents once your code is running in production. DevOps Agent autonomously investigates issues the moment they occur, analyzes patterns across your incident history to prevent future problems, and provides a conversational interface for querying your infrastructure and guiding investigations. For more information, see [Production operations](working-with-devops-agent-production-operations-index.md).

## Custom Agents
<a name="custom-agents"></a>

Custom agents let you define your own AI agents tailored to your infrastructure and workflows. You configure a system prompt, select which MCP tools the agent can use, and assign skills that provide domain knowledge. Custom agents run on demand or on a schedule to automate recurring operational work such as generating reports, auditing configurations, and analyzing trends. For more information, see [Custom Agents](working-with-devops-agent-custom-agents-index.md).

## Reviewing investigations
<a name="reviewing-investigations"></a>

After an investigation completes, you can launch a Review to get an on-demand quality assessment of that investigation. For more information about launching and interpreting Reviews, see [Reviewing investigations](working-with-devops-agent-reviewing-investigations.md).

## Accessing DevOps Agent
<a name="accessing-devops-agent"></a>

AWS DevOps Agent supports multiple access methods including the web app console, MCP integration for IDEs, Agent Client Protocol (ACP), webhooks for event-driven automation, and direct API access. For more information, see [Accessing DevOps Agent](working-with-devops-agent-accessing-devops-agent-index.md).
