You can create storage<br>volumes up to 32 TiB in size and mount them as iSCSI devices from<br>your on-premises application servers. Data written to your cached<br>volumes is stored in Amazon Simple Storage Service (Amazon S3), with only a cache of recently<br>written and recently read data stored locally on your on-premises<br>storage hardware.
