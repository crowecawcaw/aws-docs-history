

# Support and Resources

## Getting Help
<a name="getting-help"></a>

For questions or issues with flat-rate plans:
+ Open a support case in the [AWS Support Center](https://console.aws.amazon.com/support/) under the Billing category
+ Visit [AWS re:Post](https://repost.aws/) for community discussions
