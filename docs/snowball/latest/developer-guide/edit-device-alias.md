# Editing the device alias with AWS OpsHub

Use these steps to edit your device alias using AWS OpsHub.

###### To edit your device's alias

1. On the AWS OpsHub dashboard, find your device under **Devices**. Choose the device
   to open the device details page.
2. Choose the **Edit device alias** tab.

![Device details page showing Edit device alias tab at top right.](images/opshub-edit-device-alias-button-console.png) 3. For **Device alias**, enter a new name, and choose **Save
alias**.

![Edit device alias window showing Save alias button at lower right.](images/opshub-edit-device-alias-window-console.png)
