# Getting started with Amazon Nova

###### Note

This documentation is for Amazon Nova Version 1. Amazon Nova 2 is now available with new models and enhanced capabilities. For information about getting started with Amazon Nova 2, visit [Getting started with Amazon Nova 2](../nova2-userguide/getting-started-nova-2.md "../nova2-userguide/getting-started-nova-2.md").

Amazon Nova models can be invoked either through an API using the Amazon Bedrock [InvokeModel](../../../bedrock/latest/APIReference/API_runtime_InvokeModel.md "../../../bedrock/latest/APIReference/API_runtime_InvokeModel.md") or [Converse](../../../bedrock/latest/APIReference/API_runtime_Converse.md "../../../bedrock/latest/APIReference/API_runtime_Converse.md") API operations or
they can be utilized through the [Amazon Bedrock Chat and Text playgrounds](../../../bedrock/latest/userguide/playgrounds.md "../../../bedrock/latest/userguide/playgrounds.md").

###### Important

If you're new to AWS or to Amazon Bedrock, you must first set up Amazon Bedrock by following the steps at [Getting started with Amazon Bedrock](../../../bedrock/latest/userguide/getting-started.md "../../../bedrock/latest/userguide/getting-started.md").

Alternately, you can try the Amazon Nova models without entering Amazon Bedrock on [https://nova.amazon.com](https://nova.amazon.com/chat "https://nova.amazon.com/chat").

Select a topic to get started on using Amazon Nova with that method.
