

# Getting started with Amazon Nova
<a name="getting-started"></a>

**Note**  
This documentation is for Amazon Nova Version 1. Amazon Nova 2 is now available with new models and enhanced capabilities. For information about getting started with Amazon Nova 2, visit [Getting started with Amazon Nova 2](https://docs.aws.amazon.com/nova/latest/nova2-userguide/getting-started-nova-2.html).

Amazon Nova models can be invoked either through an API using the Amazon Bedrock [InvokeModel](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_InvokeModel.html) or [Converse](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html) API operations or they can be utilized through the [Amazon Bedrock Chat and Text playgrounds](https://docs.aws.amazon.com/bedrock/latest/userguide/playgrounds.html).

**Important**  
If you're new to AWS or to Amazon Bedrock, you must first set up Amazon Bedrock by following the steps at [Getting started with Amazon Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html).

Alternately, you can try the Amazon Nova models without entering Amazon Bedrock on [https://nova.amazon.com](https://nova.amazon.com/chat).

Select a topic to get started on using Amazon Nova with that method.
