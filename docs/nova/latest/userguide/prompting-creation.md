# Prompting best practices for Amazon Nova content creation

models

###### Note

This documentation is for Amazon Nova Version 1. Amazon Nova 2 is now available with new models and enhanced capabilities. New features and documentation updates are published in the Amazon Nova 2 User Guide. For information on prompt engineering for Amazon Nova 2, visit [Prompt engineering guide](../nova2-userguide/prompt-engineering-guide.md "../nova2-userguide/prompt-engineering-guide.md").

Amazon Nova consists of two creative content generation models, Amazon Nova Canvas and Amazon Nova Reel. The following guidance addresses the image and video generation models.
For guidance on multimodal understanding models, [Prompting best practices for Amazon Nova understanding models](prompting.md "prompting.md").
