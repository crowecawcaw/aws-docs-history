# With Amazon Bedrock

Model customization is the process of providing training data to a model in order to improve its performance for specific use-cases. You can customize Amazon Nova in Amazon Bedrock to improve its performance and create a better customer experience. For specific information about customizing Amazon Nova models, see the following sections. For general information about customizing models in Amazon Bedrock, see [Customize your model to improve its performance for your use case](../../../bedrock/latest/userguide/custom-models.md "../../../bedrock/latest/userguide/custom-models.md") in the Amazon Bedrock user guide.
