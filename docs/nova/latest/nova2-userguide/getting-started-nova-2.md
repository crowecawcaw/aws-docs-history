

# Getting started with Amazon Nova 2
<a name="getting-started-nova-2"></a>

You can invoke Amazon Nova 2 models through the following methods:
+ Amazon Bedrock [InvokeModel](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_InvokeModel.html) or [Converse](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html) API operations
+ Amazon Bedrock [Chat and Text playgrounds](https://docs.aws.amazon.com/bedrock/latest/userguide/playgrounds.html) for Nova 2 Lite, Nova 2 Sonic

**Important**  
If you're new to AWS or to Amazon Bedrock, you must first set up Amazon Bedrock by following the steps at [Getting started with Amazon Bedrock](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html). Alternatively, you can try the Amazon Nova models without entering Amazon Bedrock at [nova.amazon.com](https://nova.amazon.com) or start building for free at [nova.amazon.com/dev](https://nova.amazon.com/dev).

Select a topic to get started on using Amazon Nova with that method.
