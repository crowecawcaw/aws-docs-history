# Getting started with Amazon Nova 2

You can invoke Amazon Nova 2 models through the following methods:

- Amazon Bedrock [InvokeModel](../../../bedrock/latest/APIReference/API_runtime_InvokeModel.md "../../../bedrock/latest/APIReference/API_runtime_InvokeModel.md") or [Converse](../../../bedrock/latest/APIReference/API_runtime_Converse.md "../../../bedrock/latest/APIReference/API_runtime_Converse.md") API operations
- Amazon Bedrock [Chat
  and Text playgrounds](../../../bedrock/latest/userguide/playgrounds.md "../../../bedrock/latest/userguide/playgrounds.md") for Nova 2 Lite,
  Nova 2 Sonic

###### Important

If you're new to AWS or to Amazon Bedrock, you must first set up Amazon Bedrock by following the steps
at [Getting started with Amazon Bedrock](../../../bedrock/latest/userguide/getting-started.md "../../../bedrock/latest/userguide/getting-started.md"). Alternatively, you can try the Amazon Nova models
without entering Amazon Bedrock at [nova.amazon.com](https://nova.amazon.com "https://nova.amazon.com") or
start building for free at [nova.amazon.com/dev](https://nova.amazon.com/dev "https://nova.amazon.com/dev").

Select a topic to get started on using Amazon Nova with that method.
