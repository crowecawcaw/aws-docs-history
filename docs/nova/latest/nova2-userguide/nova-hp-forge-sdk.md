

# SageMaker Python SDK
<a name="nova-hp-forge-sdk"></a>

The SageMaker Python SDK v3 provides a modern, modular API for training, fine-tuning, and managing Amazon Nova models on SageMaker HyperPod. Use trainer classes (CPTTrainer, SFTTrainer, DPOTrainer, RLVRTrainer) with HyperPodCompute configuration to run distributed customization jobs on your HyperPod cluster.

For more information, see [Customizing with SageMaker Python SDK](nova-forge-sdk.md).
