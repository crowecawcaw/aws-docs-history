

# Data Types

The AWS Lambda Core API contains several data types that various actions use. This section describes each data type in detail.

**Note**  
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Compatibility](API_Compatibility.md) 
+  [ElasticIpConfiguration](API_ElasticIpConfiguration.md) 
+  [NetworkConnectorConfiguration](API_NetworkConnectorConfiguration.md) 
+  [NetworkConnectorSummary](API_NetworkConnectorSummary.md) 
+  [NetworkConnectorVersionSummary](API_NetworkConnectorVersionSummary.md) 
+  [NetworkConnectorVpcEgressConfiguration](API_NetworkConnectorVpcEgressConfiguration.md) 
+  [Platform](API_Platform.md) 
+  [RuntimeAliasInfo](API_RuntimeAliasInfo.md) 
+  [RuntimeInfo](API_RuntimeInfo.md) 
+  [RuntimeReleaseLifecycle](API_RuntimeReleaseLifecycle.md) 
+  [RuntimeVersionInfo](API_RuntimeVersionInfo.md)
