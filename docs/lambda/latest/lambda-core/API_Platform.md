

# Platform

Describes a single OCI platform (CPU architecture and operating system) available for a runtime version.

## Contents
<a name="API_Platform_Contents"></a>

 ** Architecture **   <a name="lambdacore-Type-Platform-Architecture"></a>
The CPU architecture of the platform, for example x86\_64 or arm64.  
Type: String  
Required: Yes

 ** Digest **   <a name="lambdacore-Type-Platform-Digest"></a>
The content digest of the platform-specific image.  
Type: String  
Required: Yes

 ** Os **   <a name="lambdacore-Type-Platform-Os"></a>
The operating system of the platform.  
Type: String  
Required: Yes
