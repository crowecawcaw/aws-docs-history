

# RuntimeConfig
<a name="API_RuntimeConfig"></a>

The runtime configuration for a web function revision.

## Contents
<a name="API_RuntimeConfig_Contents"></a>

 ** runtime **   <a name="lambdaweb-Type-RuntimeConfig-runtime"></a>
The runtime identifier for the web function (for example, a Node.js runtime identifier).  
Type: String  
Length Constraints: Minimum length of 1. Maximum length of 30.  
Pattern: `[a-z][a-z0-9]*(\.[a-z0-9]+)*`   
Required: Yes
