

# BuildConfig
<a name="API_BuildConfig"></a>

The build configuration for a web function revision, including code location and runtime settings.

## Contents
<a name="API_BuildConfig_Contents"></a>

 ** codeConfig **   <a name="lambdaweb-Type-BuildConfig-codeConfig"></a>
The code configuration specifying where the deployment artifact is stored.  
Type: [CodeConfig](API_CodeConfig.md) object  
Required: Yes

 ** runtimeConfig **   <a name="lambdaweb-Type-BuildConfig-runtimeConfig"></a>
The runtime configuration for the revision.  
Type: [RuntimeConfig](API_RuntimeConfig.md) object  
Required: Yes
