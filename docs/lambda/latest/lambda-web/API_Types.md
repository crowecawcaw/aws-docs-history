

# Data Types
<a name="API_Types"></a>

The Lambda Web API contains several data types that various actions use. This section describes each data type in detail.

**Note**  
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountQuotas](API_AccountQuotas.md) 
+  [AccountUsage](API_AccountUsage.md) 
+  [BuildConfig](API_BuildConfig.md) 
+  [CodeConfig](API_CodeConfig.md) 
+  [EndpointConfig](API_EndpointConfig.md) 
+  [Filter](API_Filter.md) 
+  [FunctionEndpointSummary](API_FunctionEndpointSummary.md) 
+  [FunctionRevisionSummary](API_FunctionRevisionSummary.md) 
+  [FunctionSummary](API_FunctionSummary.md) 
+  [LoggingConfig](API_LoggingConfig.md) 
+  [RegionalEndpoint](API_RegionalEndpoint.md) 
+  [RevisionConfig](API_RevisionConfig.md) 
+  [RevisionError](API_RevisionError.md) 
+  [RevisionWeight](API_RevisionWeight.md) 
+  [RuntimeConfig](API_RuntimeConfig.md) 
+  [S3Object](API_S3Object.md) 
+  [ScalingConfig](API_ScalingConfig.md) 
+  [ServiceConfig](API_ServiceConfig.md) 
+  [TelemetryConfig](API_TelemetryConfig.md) 
+  [ThrottleConfig](API_ThrottleConfig.md)
