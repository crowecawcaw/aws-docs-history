

# Regional Availability
<a name="region-availability"></a>

## AWS Interconnect – last mile
<a name="last-mile-availability"></a>

 AWS Interconnect – last mile is available with the following partners and Regions. Additional partners and Regions will be added over time.

### Lumen
<a name="lumen"></a>

Available in us-east-1 (N. Virginia) through the New York City (NYC) metro. You can also connect from anywhere in the continental United States through the Lumen connectivity fabric.

### AT&T (Gated Preview)
<a name="att-gated-preview"></a>

Available in us-west-2 (Oregon) through the Seattle metro.

### Megaport (Preview)
<a name="megaport-preview"></a>

Available in us-west-1 (N. California) and us-east-1 (N. Virginia) through the San Jose and Northern Virginia metros.

## AWS Interconnect – multicloud
<a name="multicloud-availability"></a>

Interconnect - multicloud is supported with the following AWS Regions and cloud services providers:

### Google Cloud
<a name="google-cloud"></a>
+  AWS US East (N. Virginia) us-east-1 – Google Cloud N. Virginia (us-east4)
+  AWS US West (N. California) us-west-1 – Google Cloud Los Angeles (us-west2)
+  AWS US West (Oregon) us-west-2 – Google Cloud Oregon (us-west1)
+  AWS Europe (London) eu-west-2 – Google Cloud London (europe-west2)
+  AWS Europe (Frankfurt) eu-central-1 – Google Cloud Frankfurt (europe-west3)
+  AWS Europe (Stockholm) eu-north-1 – Google Cloud Stockholm (europe-north2)
+  AWS Asia Pacific (Singapore) ap-southeast-1 – Google Cloud Singapore (asia-southeast1)
+  AWS Asia Pacific (Sydney) ap-southeast-2 – Google Cloud Sydney (australia-southeast1)

### Microsoft Azure (Preview)
<a name="microsoft-azure-preview"></a>
+  AWS US East (N. Virginia) us-east-1 – Azure US East (eastus)
+  AWS US West (N. California) us-west-1 – Azure West US (westus)
+  AWS Europe (Frankfurt) eu-central-1 – Azure Germany West Central (germanywestcentral)
+  AWS Asia Pacific (Sydney) ap-southeast-2 – Azure Australia East (australiaeast)

### Oracle Cloud Infrastructure
<a name="oracle-cloud-infrastructure"></a>
+  AWS US East (N. Virginia) us-east-1 – OCI US East (Ashburn): us-ashburn-1
