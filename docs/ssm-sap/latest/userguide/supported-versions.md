# Supported versions for SAP deployments

The following section provides information about the versions of operating systems, databases, and applications supported by AWS Systems Manager for SAP.

###### Topics

- [Operating systems](#supported-versions-operating-systems "#supported-versions-operating-systems")
- [Databases](#supported-versions-databases "#supported-versions-databases")

## Operating systems

The following table provides details of the operating systems supported by AWS Systems Manager for SAP.

| Operating system                                  | Versions                                                               |
| ------------------------------------------------- | ---------------------------------------------------------------------- |
| Red Hat Enterprise Linux                          | 9.2, 9.0, 8.8, 8.6, 8.4, 8.2, 8.1, 7.9, and 7.7                        |
| SUSE Linux Enterprise Server for SAP Applications | 15, 15 SP1, 15 SP2, 15 SP3, 15 SP4, 15 SP5, 15 SP6, 12 SP4, and 12 SP5 |
| SUSE Linux Enterprise Server                      | 15, 15 SP1, 15 SP2, 15 SP3, 15 SP4, 15 SP5, 15 SP6, 12 SP4, and 12 SP5 |
