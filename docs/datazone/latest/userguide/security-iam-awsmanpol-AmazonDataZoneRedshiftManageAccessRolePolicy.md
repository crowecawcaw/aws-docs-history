# AWS managed policy:

AmazonDataZoneRedshiftManageAccessRolePolicy

This policy gives Amazon DataZone permissions to publish Amazon Redshift data to the
catalog. It also gives Amazon DataZone permissions to grant access or revoke access to
Amazon Redshift or Amazon Redshift Serverless published assets in the
catalog.

To view the permissions for this policy, see [AmazonDataZoneRedshiftManageAccessRolePolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneRedshiftManageAccessRolePolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneRedshiftManageAccessRolePolicy.md") in the _AWS Managed Policy Reference_.
