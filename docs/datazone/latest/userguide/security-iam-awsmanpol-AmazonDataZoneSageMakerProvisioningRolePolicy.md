# AWS managed policy:

AmazonDataZoneSageMakerProvisioningRolePolicy

The AmazonDataZoneSageMakerProvisioningRolePolicy policy grants Amazon DataZone the
permissions required to interoperate with Amazon SageMaker.

To view the permissions for this policy, see [AmazonDataZoneSageMakerProvisioningRolePolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneSageMakerProvisioningRolePolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneSageMakerProvisioningRolePolicy.md") in the _AWS Managed Policy Reference_.
