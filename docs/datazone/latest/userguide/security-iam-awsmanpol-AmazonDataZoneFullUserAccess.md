# AWS managed

policy: AmazonDataZoneFullUserAccess

This policy grants full access to Amazon DataZone, but it doesn't allow the management
of domains, users, or associated accounts.

**Permissions details**

To view the permissions for this policy, see [AmazonDataZoneFullUserAccess](../../../aws-managed-policy/latest/reference/AmazonDataZoneFullUserAccess.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneFullUserAccess.md") in the _AWS
Managed Policy Reference_.
