# AWS managed policy:

AmazonDataZoneRedshiftGlueProvisioningPolicy

The AmazonDataZoneRedshiftGlueProvisioningPolicy policy grants
Amazon DataZone the permissions required to interoperate with AWS Glue and Amazon
Redshift.

To view the permissions for this policy, see [AmazonDataZoneRedshiftGlueProvisioningPolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneRedshiftGlueProvisioningPolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneRedshiftGlueProvisioningPolicy.md") in the _AWS Managed Policy Reference_.
