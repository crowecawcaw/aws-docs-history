# AWS managed policy:

AmazonDataZoneGlueManageAccessRolePolicy

This policy gives Amazon DataZone permissions to publish AWS Glue data to the
catalog. It also gives Amazon DataZone permissions to grant access or revoke access to
AWS Glue published assets in the catalog.

To view the permissions for this policy, see [AmazonDataZoneGlueManageAccessRolePolicy](../../../aws-managed-policy/latest/reference/AmazonDataZoneGlueManageAccessRolePolicy.md "../../../aws-managed-policy/latest/reference/AmazonDataZoneGlueManageAccessRolePolicy.md") in the _AWS Managed Policy Reference_.
