# Creating a catalog

You can create a catalog for your Redshift Managed Storage (RMS) objects.

###### To create a catalog

1. On the **Data** explorer in the middle of the project page, choose
   **+** on the top. This opens **Add data source** on
   the right.
2. On **Add data source**, choose **Create catalog**.
   Enter a name for your catalog.
3. Choose **Create**.
