# Uploading data

You can upload data to the lakehouse architecture.

###### To upload data

1. On the **Data** section in the middle of the project page, choose
   **+** on the top. This opens **Add data source** on
   the right.
2. On **Add data source**, choose **Upload data**.
3. Choose **Click to upload** or drag and drop a CSV or JSON file.
   Complete the information in the form.
4. Choose **Upload data**.
