# AWS CloudFormation support

Use AWS CloudFormation templates to provision Amplify resources, enabling repeatable
and reliable web app deployments. AWS CloudFormation provides a common language for you to describe
and provision all the infrastructure resources in your cloud environment and simplifies the roll
out across multiple AWS accounts and/or regions with just a couple of clicks.

For Amplify Hosting, see the [Amplify CloudFormation
documentation](../../../AWSCloudFormation/latest/UserGuide/AWS_Amplify.md "../../../AWSCloudFormation/latest/UserGuide/AWS_Amplify.md"). For Amplify Studio, see the [Amplify UI Builder CloudFormation documentation](../../../AWSCloudFormation/latest/UserGuide/AWS_AmplifyUIBuilder.md "../../../AWSCloudFormation/latest/UserGuide/AWS_AmplifyUIBuilder.md").
