## Announcements
<a name="announcements-20261027"></a>

**Note**  
 Amazon Linux 2 (AL2) reached end of life on June 30, 2026. For more information, see [Amazon Linux 2 FAQs](https://aws.amazon.com/amazon-linux-2/faqs/#topic-0). 
 We strongly recommend that customers migrate to [Amazon Linux 2023](https://aws.amazon.com/linux/amazon-linux-2023/) as soon as possible. 

## Release Summary
<a name="release-summary-20261027"></a>

This release of Amazon Linux 2 includes the latest security updates. 

**Security updates**
