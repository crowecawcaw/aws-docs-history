# AWS Systems Manager Incident Manager

###### Incident Manager availability change

AWS Systems Manager Incident Manager will no longer be open to new customers starting November 7, 2025. If
you would like to use Incident Manager, sign up prior to that date. Existing customers can
continue to use the service as normal. For more information, see [AWS Systems Manager Incident Manager availability change](../../../incident-manager/latest/userguide/incident-manager-availability-change.md "../../../incident-manager/latest/userguide/incident-manager-availability-change.md").

Use Incident Manager, a tool in AWS Systems Manager, to manage incidents occurring in your AWS hosted
applications. Incident Manager combines user engagements, escalation, runbooks, response plans,
chat channels, and post-incident analysis to help your team triage incidents faster and
return your applications to normal. To learn more about Incident Manager, see the [Incident Manager User
Guide](../../../incident-manager/latest/userguide/what-is-incident-manager.md "../../../incident-manager/latest/userguide/what-is-incident-manager.md").
