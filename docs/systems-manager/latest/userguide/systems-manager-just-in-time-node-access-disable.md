# Disabling just-in-time

access with Systems Manager

The following procedure describes how to disable just-in-time node access. After
disabling just-in-time node access, users in your organization might be unable to
connect to your nodes unless you've already implemented other connection methods.

###### To disable just-in-time node access

1. Log in to the Systems Manager delegated administrator account for your
   organization.
2. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
3. Select **Settings** in the navigation pane.
4. In the **Just-in-time node access** tab, select
   **Disable**.
