# Session Manager plugin on GitHub

The source code for Session Manager plugin is available on [GitHub](https://github.com/aws/session-manager-plugin "https://github.com/aws/session-manager-plugin")
so that you can adapt the plugin to meet your needs. We encourage you to submit
[pull requests](https://github.com/aws/session-manager-plugin/blob/mainline/CONTRIBUTING.md "https://github.com/aws/session-manager-plugin/blob/mainline/CONTRIBUTING.md") for changes that you would like to have included.
However, Amazon Web Services doesn't provide support for running
modified copies of this software.
