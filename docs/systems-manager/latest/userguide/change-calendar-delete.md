# Deleting a change calendar

You can delete a calendar in Change Calendar, a tool in AWS Systems Manager, by using either the
Systems Manager console or the AWS Command Line Interface (AWS CLI). Deleting a change calendar deletes all
associated events.

###### To delete a change calendar

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Change Calendar**.
3. In the list of calendars, choose the name of the calendar that you want to
   delete.
4. On the calendar's details page, choose **Actions,
   Delete**. When you're prompted to confirm that you want to
   delete the calendar, choose **Delete**.
