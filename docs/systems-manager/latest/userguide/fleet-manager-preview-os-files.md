# Previewing OS files using

Fleet Manager

You can use Fleet Manager to preview text files on an OS.

###### To view text previews of files using Fleet Manager

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Fleet Manager**.
3. Select the link of the managed node with the files you want to
   preview.
4. Choose **Tools, File system**.
5. Select the **File name** of the directory that
   contains the file you want to preview.
6. Choose the button next to the file whose content you want to
   preview.
7. Choose **Actions, Preview as text**.
