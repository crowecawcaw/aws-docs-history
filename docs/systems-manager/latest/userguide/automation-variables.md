# Automation system variables

AWS Systems Manager Automation runbooks use the following variables. For an example of how these
variables are used, view the JSON source of the `AWS-UpdateWindowsAmi`
runbook.

###### To view the JSON source of the `AWS-UpdateWindowsAmi` runbook

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Documents**.
3. In the document list, use either the Search bar or the numbers to the right of
   the Search bar to choose the runbook
   `**AWS-UpdateWindowsAmi**`.
4. Choose the **Content** tab.

###### System variables

Automation runbooks support the following system variables.

| Variable               | Details                                                                                                                                                                                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `global:ACCOUNT_ID`    | The AWS account ID of the user or role in which Automation<br>runs.                                                                                                                                                                                                               |
| `global:DATE`          | The date (at run time) in the format yyyy-MM-dd.                                                                                                                                                                                                                                  |
| `global:DATE_TIME`     | The date and time (at run time) in the format<br>yyyy-MM-dd_HH.mm.ss.                                                                                                                                                                                                             |
| `global:AWS_PARTITION` | The partition that the resource is in. For standard AWS Regions,<br>the partition is `aws`. For resources in other<br>partitions, the partition is<br>`aws-`partitionname``.<br>For example, the partition for resources in the<br>AWS GovCloud (US-West) Region is `aws-us-gov`. |
| `global:REGION`        | The Region that the runbook is run in. For example,<br>us-east-2.                                                                                                                                                                                                                 |

###### Automation variables

Automation runbooks support the following automation variables.

| Variable                  | Details                                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `automation:EXECUTION_ID` | The unique identifier assigned to the current automation. For<br>example,<br>`1a2b3c-1a2b3c-1a2b3c-1a2b3c1a2b3c1a2b3c`. |

## Terminology

The following terms describe how variables and parameters are resolved.

| Term                      | Definition                                                                                                                                                                     | Example                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Constant ARN              | A valid Amazon Resource Name (ARN) without variables.                                                                                                                          | `arn:aws:iam::123456789012:role/roleName`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Runbook parameter         | A parameter defined at the runbook level (for example,<br>`instanceId`). The parameter is used in a basic<br>string replace. Its value is supplied at Start Execution<br>time. | ``<br>{<br>"description": "Create Image Demo",<br>"version": "0.3",<br>"assumeRole": "`Your_Automation_Assume_Role_ARN`",<br>"parameters":{<br>**"instanceId": {**<br>**"type": "String",**<br>**"description": "Instance to create image from"**<br>}<br>}<br>``                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| System variable           | A general variable substituted into the runbook when any part<br>of the runbook is evaluated.                                                                                  | `<br>"activities": [<br>{<br>"id": "copyImage",<br>"activityType": "AWS-CopyImage",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"ImageName": "{{imageName}}",<br>"SourceImageId": "{{sourceImageId}}",<br>"SourceRegion": "{{sourceRegion}}",<br>"Encrypted": true,<br>"ImageDescription": "Test CopyImage Description created on **{{global:DATE}}**"<br>}<br>}<br>]<br>`                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Automation variable       | A variable relating to the automation substituted into the<br>runbook when any part of the runbook is evaluated.                                                               | `<br>{<br>"name": "runFixedCmds",<br>"action": "aws:runCommand",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"DocumentName": "AWS-RunPowerShellScript",<br>"InstanceIds": [<br>"{{LaunchInstance.InstanceIds}}"<br>],<br>"Parameters": {<br>"commands": [<br>"dir",<br>"date",<br>"“{{outputFormat}}” -f “left”,”right”,”{{global:DATE}}”,”**{{automation:EXECUTION\_ID}}**”<br>]<br>}<br>}<br>}<br>`                                                                                                                                                                                                                                                                                                                                                                                                       |
| Systems Manager Parameter | A variable defined within AWS Systems Manager Parameter Store. It can't be<br>directly referenced in step input. Permissions might be required<br>to access the parameter.     | `<br>description: Launch new Windows test instance<br>schemaVersion: '0.3'<br>assumeRole: '{{AutomationAssumeRole}}'<br>parameters:<br>AutomationAssumeRole:<br>type: String<br>default: ''<br>description: >-<br>(Required) The ARN of the role that allows Automation to perform the<br>actions on your behalf. If no role is specified, Systems Manager<br>Automation uses your IAM permissions to run this runbook.<br>LatestAmi:<br>type: String<br>default: >-<br>{{ssm:/aws/service/ami-windows-latest/Windows_Server-2016-English-Full-Base}}<br>description: The latest Windows Server 2016 AMI queried from the public parameter.<br>mainSteps:<br>• name: launchInstance<br>action: 'aws:runInstances'<br>maxAttempts: 3<br>timeoutSeconds: 1200<br>onFailure: Abort<br>inputs:<br>ImageId: '{{LatestAmi}}'<br>...<br>` |

## Supported scenarios

| Scenario                                                                       | Comments                                                                                                                                                                                                                                                                                                                                                                                                                        | Example                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Constant ARN `assumeRole` at creation.                                         | An authorization check is performed to verify that the calling<br>user is permitted to pass the given<br>`assumeRole`.                                                                                                                                                                                                                                                                                                          | `<br>{<br>"description": "Test all Automation resolvable parameters",<br>"schemaVersion": "0.3",<br>"assumeRole": **``"arn:aws:iam::123456789012:role/roleName"``**,<br>"parameters": {<br>...<br>`                                                                                                                                                                                                                                                                                                      |
| Runbook parameter supplied for `AssumeRole` when<br>the automation is started. | Must be defined in the parameter list of the runbook.                                                                                                                                                                                                                                                                                                                                                                           | `<br>{<br>"description": "Test all Automation resolvable parameters",<br>"schemaVersion": "0.3",<br>"assumeRole": **"{{dynamicARN}}"**,<br>"parameters": {<br>...<br>`                                                                                                                                                                                                                                                                                                                                   |
| Value supplied for runbook parameter at start.                                 | Customer supplies the value to use for a parameter. Any inputs<br>supplied at start time need to be defined in the parameter list<br>of the runbook.                                                                                                                                                                                                                                                                            | ``<br>...<br>"parameters": {<br>"amiId": {<br>"type": "String",<br>"default": "`ami-12345678`",<br>"description": "list of commands to run as part of first step"<br>},<br>...<br>``<br>Inputs to Start Automation Execution include : `{"amiId"<br>: ["`ami-12345678`"]<br>}`                                                                                                                                                                                                                           |
| Systems Manager Parameter referenced within runbook content.                   | The variable exists within the customer's account, or is a<br>publicly accessibly parameter, and the `AssumeRole`<br>for the runbook has access to the variable. A check is performed<br>at create time to confirm the `AssumeRole` has<br>access. The parameter can't be directly referenced in step<br>input.                                                                                                                 | `<br>...<br>parameters:<br>LatestAmi:<br>type: String<br>default: >-<br>{{ssm:/aws/service/ami-windows-latest/Windows_Server-2016-English-Full-Base}}<br>description: The latest Windows Server 2016 AMI queried from the public parameter.<br>mainSteps:<br>• name: launchInstance<br>action: 'aws:runInstances'<br>maxAttempts: 3<br>timeoutSeconds: 1200<br>onFailure: Abort<br>inputs:<br>ImageId: '{{LatestAmi}}'<br>...<br>`                                                                       |
| System variable referenced within step definition                              | A system variable is substituted into the runbook when the<br>automation is started. The value injected into the runbook is<br>relative to when the substitution occurs. That is, the value of<br>a time variable injected at step 1 is different from the value<br>injected at step 3 because of the time it takes to run the steps<br>between. System variables don't need to be set in the parameter<br>list of the runbook. | `<br>...<br>"mainSteps": [<br>{<br>"name": "RunSomeCommands",<br>"action": "aws:runCommand",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"DocumentName": "AWS:RunPowerShell",<br>"InstanceIds": ["{{LaunchInstance.InstanceIds}}"],<br>"Parameters": {<br>"commands" : [<br>"echo {The time is now {{global:DATE_TIME}}}"<br>]<br>}<br>}<br>}, ...<br>`                                                                                                                           |
| Automation variable referenced within step definition.                         | Automation variables don't need to be set in the parameter<br>list of the runbook. The only supported Automation variable is<br>**automation:EXECUTION_ID**.                                                                                                                                                                                                                                                                    | `<br>...<br>"mainSteps": [<br>{<br>"name": "invokeLambdaFunction",<br>"action": "aws:invokeLambdaFunction",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"FunctionName": "Hello-World-LambdaFunction",<br>"Payload" : "{ "executionId" : "{{automation:EXECUTION_ID}}" }"<br>}<br>}<br>...<br>`                                                                                                                                                                                    |
| Refer to output from previous step within next step<br>definition.             | This is parameter redirection. The output of a previous step<br>is referenced using the syntax<br>`{{stepName.OutputName}}`. This syntax can't be<br>used by the customer for runbook parameters. This is resolved<br>when the referring step runs. The parameter isn't listed in the<br>parameters of the runbook.                                                                                                             | `<br>...<br>"mainSteps": [<br>{<br>"name": "LaunchInstance",<br>"action": "aws:runInstances",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"ImageId": "{{amiId}}",<br>"MinInstanceCount": 1,<br>"MaxInstanceCount": 2<br>}<br>},<br>{<br>"name":"changeState",<br>"action": "aws:changeInstanceState",<br>"maxAttempts": 1,<br>"onFailure": "Continue",<br>"inputs": {<br>"InstanceIds": ["{{LaunchInstance.InstanceIds}}"],<br>"DesiredState": "terminated"<br>}<br>}<br>...<br>` |

| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
