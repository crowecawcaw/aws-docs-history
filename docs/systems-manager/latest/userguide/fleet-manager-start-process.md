# Starting an OS process on a

managed node using Fleet Manager

You can use Fleet Manager to start a process on a managed node.

###### To start a process with Fleet Manager

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Fleet Manager**.
3. Select the link of the managed node you want to start a process
   on.
4. Choose **Tools, Processes**.
5. Select **Start new process**.
6. For **Process name or full path**, enter the name of
   the process or the full path to the executable.
7. (Optional) For **Working directory**, enter the
   directory path where you want the process to run.
