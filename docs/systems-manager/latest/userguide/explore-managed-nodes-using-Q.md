

# Exploring managed nodes using AWS assistant

Systems Manager integration with the AWS assistant lets you ask questions about managed nodes in your fleet. You can access this feature from anywhere in the AWS Management Console where the AWS assistant interface is available.

For more information about interacting with the AWS assistant, see [Using AWS assistant](https://docs.aws.amazon.com/assistant/latest/userguide/using-assistant.html) in the *AWS assistant User Guide*.

**To explore managed nodes using AWS assistant**

1. From anywhere in the AWS Management Console, choose the AWS assistant icon (![The AWS assistant icon](https://docs.aws.amazon.com/systems-manager/latest/userguide/images/q-icon-white.png)).

1. In the prompt field at the bottom of the AWS assistant pane, ask a question about managed nodes in your account or organization.
**Tip**  
For tips on creating effective prompts, review the information in [Learning to craft effective prompts to ask AWS assistant about your fleet](view-aggregated-node-details-Q-prompts.md) .

1. Examine information about specific nodes, or choose **Open AWS Systems Manager console** to continue exploring.
