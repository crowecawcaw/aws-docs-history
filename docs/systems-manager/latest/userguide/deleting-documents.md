# Deleting custom SSM documents

If you no longer want to use a custom SSM document, you can delete it using the
AWS Systems Manager console.

###### To delete an SSM document

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Documents**.
3. Select the document you want to delete.
4. Select **Delete**. When prompted to delete the document,
   select **Delete**.
   For examples using command line tools or SDKs to delete SSM documents, see [Use DeleteDocument with an AWS SDK or CLI](example_ssm_DeleteDocument_section.md "example_ssm_DeleteDocument_section.md").
