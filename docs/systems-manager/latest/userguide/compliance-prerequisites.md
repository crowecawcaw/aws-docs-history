# Getting started with Compliance

To get started with Compliance, a tool in AWS Systems Manager, complete the following
tasks.

| Task                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | For more information                                                                                                                                           |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Compliance works with patch data in Patch Manager and associations in<br>State Manager. (Patch Manager and State Manager are also both tools in AWS Systems Manager.)<br>Compliance also works with custom compliance types on managed nodes<br>that are managed using Systems Manager. Verify that you have completed the<br>setup requirements for your Amazon Elastic Compute Cloud (Amazon EC2) instances and non-EC2<br>machines in a [hybrid and multicloud](operating-systems-and-machine-types.md#supported-machine-types "operating-systems-and-machine-types.md#supported-machine-types") environment. | [Setting up Systems Manager unified console<br>for an organization](systems-manager-setting-up-organizations.md "systems-manager-setting-up-organizations.md") |
| Update the AWS Identity and Access Management (IAM) role used by your managed nodes to<br>restrict Compliance permissions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | [Configuring permissions for Compliance](compliance-permissions.md "compliance-permissions.md")                                                                |
| If you plan to monitor patch compliance, verify that you've<br>configured Patch Manager. You must perform patching operations by using<br>Patch Manager before Compliance can display patch compliance data.                                                                                                                                                                                                                                                                                                                                                                                                     | [AWS Systems Manager Patch Manager](patch-manager.md "patch-manager.md")                                                                                       |
| If you plan to monitor association compliance, verify that you've<br>created State Manager associations. You must create associations before<br>Compliance can display association compliance data.                                                                                                                                                                                                                                                                                                                                                                                                              | [AWS Systems Manager State Manager](systems-manager-state.md "systems-manager-state.md")                                                                       |
| (Optional) Configure the system to view compliance history and<br>change tracking.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | [Viewing compliance configuration history and<br>change tracking](compliance-about.md#compliance-history "compliance-about.md#compliance-history")             |
| (Optional) Create custom compliance types.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | [Assign custom compliance metadata using<br>the AWS CLI](compliance-custom-metadata-cli.md "compliance-custom-metadata-cli.md")                                |
| (Optional) Create a resource data sync to aggregate all compliance<br>data in a target Amazon Simple Storage Service (Amazon S3) bucket.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | [Creating a resource data sync for<br>Compliance](compliance-datasync-create.md "compliance-datasync-create.md")                                               |
