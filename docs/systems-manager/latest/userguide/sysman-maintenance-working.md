# Create and manage maintenance windows using

the console

This section describes how to create, configure, update, and delete maintenance
windows using the AWS Systems Manager console. This section also provides information about
managing the targets and tasks of a maintenance window.

###### Important

We recommend that you initially create and configure maintenance windows in a test
environment.

###### Before you begin

Before you create a maintenance window, you must configure access to Maintenance Windows, a
tool in AWS Systems Manager. For more information, see [Setting up Maintenance Windows](setting-up-maintenance-windows.md "setting-up-maintenance-windows.md").
