# AWS Systems Manager operations tools

Operations tools are a suite of capabilities that help you manage your AWS
resources.

- [Amazon CloudWatch dashboards hosted by Systems Manager](systems-manager-cloudwatch-dashboards.md "systems-manager-cloudwatch-dashboards.md") are customizable home pages in the
  CloudWatch console that you can use to monitor your resources across AWS Regions in a
  single view.
- [Explorer](Explorer.md "Explorer.md") is a customizable operations dashboard that reports
  information about your AWS resources. Explorer displays an aggregated view of
  operations data (OpsData) for your AWS accounts and across AWS Regions.
- [Incident Manager](../../../incident-manager/latest/userguide/what-is-incident-manager.md "../../../incident-manager/latest/userguide/what-is-incident-manager.md") helps you mitigate and recover from incidents affecting
  your applications hosted on AWS.
- [OpsCenter](OpsCenter.md "OpsCenter.md") provides a central location where operations engineers and IT
  professionals can view, investigate, and resolve operational work items (OpsItems)
  related to AWS resources.
