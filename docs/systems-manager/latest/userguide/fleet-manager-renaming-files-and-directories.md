# Renaming OS files

and directories using Fleet Manager

You can use Fleet Manager to rename files and directories on a managed node in your
account.

###### To rename files or directories with Fleet Manager

1. Open the AWS Systems Manager console at [https://console.aws.amazon.com/systems-manager/](https://console.aws.amazon.com/systems-manager/ "https://console.aws.amazon.com/systems-manager/").
2. In the navigation pane, choose **Fleet Manager**.
3. Select the link of the managed node with the files or directories you
   want to rename.
4. Choose **Tools, File system**.
5. To rename a file, select the **File name** of the
   directory that contains the file you want to rename. To rename a
   directory, choose the button next to the directory that you want to
   rename and then proceed to step 8.
6. Choose the button next to the file whose content you want to
   rename.
7. Choose **Actions, Rename**.
8. For **File name**, enter the new name for the file
   and select **Rename**.
