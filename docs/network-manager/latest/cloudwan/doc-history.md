# Document history for AWS Cloud WAN

The following table describes the releases for AWS Cloud WAN:



| Change | Description | Date |
| --- | --- | --- |
| Removed the table of supported Regions for Direct Connect Gateway attachments | Direct Connect Gateway attachments are now supported in all Cloud WAN Regions listed here [Region Availability](what-is-cloudwan.md#cloudwan-available-regions "what-is-cloudwan.md#cloudwan-available-regions"). | June 24, 2025 |
| [DNS and security group referencing support](cloudwan-vpc-attachment.md#cloudwan-dns-support "cloudwan-vpc-attachment.md#cloudwan-dns-support") | Cloud WAN now supports DNS and security group referencing | June 11, 2025 |
| Support for dual-stack IPv6 endpoints | AWS Cloud WAN now supports dual-stack IPv6 endpoints | March 25, 2025 |
| [PrivateLink support](what-is-cloudwan.md#cloudwan-privatelink "what-is-cloudwan.md#cloudwan-privatelink") | PrivateLink support in the us-west-2 and us-gov-west-1 Regions | March 25, 2025 |
| Updated supported regions | AWS Cloud WAN now supports the `ap-southeast-5` Region | March 13, 2025 |
| Updated supported attachments | AWS Cloud WAN now supports Direct Connect attachment types | November 25, 2024 |
| Updated supported regions. | AWS Cloud WAN now supports additional Regions | October 3, 2024 |
| Added a new feature, Cloud WAN service insertion | AWS Cloud WAN now supports Service Insertion, a feature allowing you to route traffic to security appliances | June 11, 2024 |
| Added a new available Region | ap-southeast-3 Asia Pacific (Jakarta) Region is now an available Region for AWS Cloud WAN | March 26, 2024 |
| Support added for appliance mode | VPC attachments now support appliance mode in AWS Cloud WAN | December 14, 2022 |
| Official launch date | The official launch of AWS Cloud WAN | July 12, 2022 |
