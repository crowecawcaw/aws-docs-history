

# Document history for AWS Cloud WAN
<a name="doc-history"></a>

The following table describes the releases for AWS Cloud WAN:

| Change | Description | Date | 
| --- |--- |--- |
| [Removed the table of supported Regions for Direct Connect Gateway attachments](#doc-history) | Direct Connect Gateway attachments are now supported in all Cloud WAN Regions listed here [Region Availability](https://docs.aws.amazon.com/network-manager/latest/cloudwan/what-is-cloudwan.html#cloudwan-available-regions). | June 24, 2025 | 
| [DNS and security group referencing support](https://docs.aws.amazon.com/network-manager/latest/cloudwan/cloudwan-vpc-attachment.html#cloudwan-dns-support) | Cloud WAN now supports DNS and security group referencing | June 11, 2025 | 
| [Support for dual-stack IPv6 endpoints](#doc-history) | AWS Cloud WAN now supports dual-stack IPv6 endpoints | March 25, 2025 | 
| [PrivateLink support](https://docs.aws.amazon.com/network-manager/latest/cloudwan/what-is-cloudwan.html#cloudwan-privatelink) | PrivateLink support in the us-west-2 and us-gov-west-1 Regions | March 25, 2025 | 
| [Updated supported regions](#doc-history) | AWS Cloud WAN now supports the `ap-southeast-5` Region | March 13, 2025 | 
| [Updated supported attachments](#doc-history) | AWS Cloud WAN now supports Direct Connect attachment types | November 25, 2024 | 
| [Updated supported regions.](#doc-history) | AWS Cloud WAN now supports additional Regions | October 3, 2024 | 
| [Added a new feature, Cloud WAN service insertion](#doc-history) | AWS Cloud WAN now supports Service Insertion, a feature allowing you to route traffic to security appliances | June 11, 2024 | 
| [Added a new available Region](#doc-history) | ap-southeast-3 Asia Pacific (Jakarta) Region is now an available Region for AWS Cloud WAN | March 26, 2024 | 
| [Support added for appliance mode](#doc-history) | VPC attachments now support appliance mode in AWS Cloud WAN | December 14, 2022 | 
| [Official launch date](#doc-history) | The official launch of AWS Cloud WAN | July 12, 2022 |
