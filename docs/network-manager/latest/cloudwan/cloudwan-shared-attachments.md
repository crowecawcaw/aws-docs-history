# Shared attachments in AWS Cloud WAN

You can share attachments on any of your shared core networks. For more information on sharing core networks, see [Shared AWS Cloud WAN core network](cloudwan-share-network.md "cloudwan-share-network.md").

 When a core network owner shares their core network with your account, you are then able
 to create new VPC, transit gateway route table, or Direct Connect gateway attachments for
 the shared core network. You can also view the current attachments or delete an attachment
 from the shared core network.

###### Note

A shared core network currently supports only VPC, transit gateway route table, and Direct
 Connect gateway attachments.
