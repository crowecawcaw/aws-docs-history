# Delete a shared peering from an AWS Cloud WAN global network

Delete a transit gateway peering.

###### To delete a shared peering

1. Access the Network Manager console at [https://console.aws.amazon.com/networkmanager/home/](https://console.aws.amazon.com/networkmanager/home "https://console.aws.amazon.com/networkmanager/home").
2. Under **Connectivity**, choose **Global Networks**.
3. On the **Global networks** page, choose the global network ID.
4. In the navigation pane, under **Shared by me**, choose
 **Peerings**.
5. Choose the **Peering ID** of the peer that you want to
 delete.
6. Choose **Delete**.
7. In the confirmation box, choose **Delete**.


The **Peering** page displays a confirmation that you deleted
 the transit gateway peering.
