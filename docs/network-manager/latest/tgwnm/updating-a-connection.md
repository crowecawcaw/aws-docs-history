# Update a connection using AWS Network Manager

You can update the information for an existing connection.

###### To update a connection

1. Access the Network Manager console at [https://console.aws.amazon.com/networkmanager/home/](https://console.aws.amazon.com/networkmanager/home "https://console.aws.amazon.com/networkmanager/home").
2. Under **Connectivity**, choose **Global Networks**.
3. On the **Global networks** page, choose the global network ID.
4. In the navigation pane, choose **Devices**, and select
   the device.
5. Choose **Connections**, and select the connection.
6. Choose **Edit**.
7. Update the connection details as needed, and then choose **Edit
   connection**.

###### To update a connection using the AWS CLI

Use the [update-connection](../../../cli/latest/reference/networkmanager/update-connection.md "../../../cli/latest/reference/networkmanager/update-connection.md") command.
