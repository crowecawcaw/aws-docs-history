

# AWS Global Networks for Transit Gateways Quotas
<a name="nm-quotas"></a>

Your AWS account has the quotas shown in the following table for AWS Global Networks for Transit Gateways.

The Service Quotas console also provides information about global networks quotas. You can use the Service Quotas console to view default quotas and [request quota increases](https://console.aws.amazon.com/servicequotas/home?) for adjustable quotas. For more information, see [Requesting a quota increase](https://docs.aws.amazon.com/servicequotas/latest/userguide/request-quota-increase.html) in the *Service Quotas User Guide*.
