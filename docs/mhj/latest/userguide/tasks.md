# Migration Hub Journeys tasks and subtasks

A migration journey consists of phases. Phases consist of modules, which in turn consist
of tasks and subtasks.

For information about phases, see [Phases](phases.md "phases.md").

For information about modules, see [Modules](modules.md "modules.md").

For information about how to attach files to a task or a subtask, see [Attached files](attached-files.md "attached-files.md").
