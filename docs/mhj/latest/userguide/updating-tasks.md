# Updating Migration Hub Journeys tasks

###### To edit the details of a task

The details of a task include its title, status, due date, estimated effort,
effort spent, and assignee. Only members of the task's journey appear in the list of
assignees. For information about membership, see [Individuals and teams](individuals-and-teams.md "individuals-and-teams.md").

1. Open the Migration Hub Journeys console. For information about how to access the console, see [Accessing AWS Migration Hub Journeys](setup.md "setup.md").
2. In the left navigation pane, choose **Migration
   journeys**.
3. In the list of migration journeys, choose the name of the journey that
   contains the task.
4. Choose the **Tasks** tab.
5. Choose the tile that represents the task whose details you want to edit. A
   right pane appears and shows the properties of the task, some of which are
   editable in that pane. To edit the rest of the properties of the task, choose
   the external link icon that appears in the top-right corner of this task details
   pane.
