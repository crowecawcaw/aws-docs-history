# Migration templates

A migration template is a declaration of phases, modules, and tasks that make up a
migration journey. Migration Hub Journeys provides a set of templates that represent common migration
scenarios. You can use one of these templates to create a journey. After you create a
journey from a template, you can customize the journey to better fit your scenario.
Alternatively, you can create a custom journey where you define phases, modules, and
tasks.
