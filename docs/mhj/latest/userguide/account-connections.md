# AWS account connections in AWS Migration Hub Journeys

###### Note

The account-connection feature is in preview release. It is available in
US East (N. Virginia).

This is pre-release documentation. Both the account-connection feature and this
documentation are subject to change.

To access Migration Hub Journeys, you need an AWS Builder ID, as described in [Accessing AWS Migration Hub Journeys](setup.md "setup.md"). However, some migration tasks require access to an AWS account for creating and
updating AWS resources. To make it possible to perform such tasks, you can create
connections to one or more AWS accounts. This section explains how to create and use such
account connections inside migration journeys.
