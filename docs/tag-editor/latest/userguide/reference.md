# Service quotas

The following table provides information about the service quotas for Tag Editor.

These quotas are currently not adjustable using the [Service Quotas console](https://console.aws.amazon.com/servicequotas/home/services/resource-groups/quotas "https://console.aws.amazon.com/servicequotas/home/services/resource-groups/quotas").
Contact [Support](https://console.aws.amazon.com/support/home#/ "https://console.aws.amazon.com/support/home#/").
