# Tagging categories

Companies that are most effective in their use of tags typically create
business-relevant tag groupings to organize their resources along technical, business,
and security dimensions. Companies that use automated processes to manage their
infrastructure also include additional, automation-specific tags.

| Technical tags                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Tags for automation                                                                                                                                                                                                                                                                                                                                                                                                                    | Business tags                                                                                                                                                                                                                                                                                                                                                                      | Security tags                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <br>• **Name –** Identify individual resources <br>• **Application ID –** Identify resources that are related to a specific application <br>• **Application Role –** Describe the function of a particular resource (such as web server, message broker, database) <br>• **Cluster –** Identify resource farms that share a common configuration and perform a specific function for an application <br>• **Environment –** Distinguish between development, test, and production resources <br>• **Version –** Help distinguish between versions of resources or applications | <br>• **Date/Time –** Identify the date or time a resource should be started, stopped, deleted, or rotated <br>• **Opt in/Opt out –** Indicate whether a resource should be included in an automated activity such as starting, stopping, or resizing instances <br>• **Security –** Determine requirements, such as encryption or enabling of Amazon VPC flow logs; identify route tables or security groups that need extra scrutiny | <br>• **Project –** Identify projects that the resource supports <br>• **Owner –** Identify who is responsible for the resource <br>• **Cost Center/Business Unit –** Identify the cost center or business unit associated with a resource, typically for cost allocation and tracking <br>• **Customer –** Identify a specific client that a particular group of resources serves | <br>• **Confidentiality –** An identifier for the specific data confidentiality level a resource supports <br>• **Compliance –** An identifier for workloads that must adhere to specific compliance requirements |
