# Tagging categories

Companies that are most effective in their use of tags typically create
business-relevant tag groupings to organize their resources along technical, business,
and security dimensions. Companies that use automated processes to manage their
infrastructure also include additional, automation-specific tags.

| Technical tags                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Tags for automation                                                                                                                                                                                                                                                                                                                                                                                                                                      | Business tags                                                                                                                                                                                                                                                                                                                                                                                           | Security tags                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| • **Name –** Identify<br>individual resources<br>• **Application ID –** Identify<br>resources that are related to a specific application<br>• **Application Role –**<br>Describe the function of a particular resource (such as web<br>server, message broker, database)<br>• **Cluster –** Identify<br>resource farms that share a common configuration and perform<br>a specific function for an application<br>• **Environment –** Distinguish<br>between development, test, and production resources<br>• **Version –** Help<br>distinguish between versions of resources or<br>applications | • **Date/Time –** Identify the<br>date or time a resource should be started, stopped, deleted,<br>or rotated<br>• **Opt in/Opt out –** Indicate<br>whether a resource should be included in an automated<br>activity such as starting, stopping, or resizing<br>instances<br>• **Security –** Determine<br>requirements, such as encryption or enabling of Amazon VPC flow<br>logs; identify route tables or security groups that need<br>extra scrutiny | • **Project –** Identify<br>projects that the resource supports<br>• **Owner –** Identify who is<br>responsible for the resource<br>• **Cost Center/Business Unit<br>–\*<br>• Identify the cost center or business unit<br>associated with a resource, typically for cost allocation<br>and tracking<br>• **Customer –\*\* Identify a<br>specific client that a particular group of resources<br>serves | • **Confidentiality –** An<br>identifier for the specific data confidentiality level a<br>resource supports<br>• **Compliance –** An<br>identifier for workloads that must adhere to specific<br>compliance requirements |
