# Template Strings to

Create Specific Output Timestamps

| `'yyyy-MM-dd hh:mm:ss'` | `'2009-09-16 03:15:24'`                                                                              | `'2009-09-16 03:15:24'`                            |
| `'yyyy-mm'`             | `'2011-02-08 07:23:19'`                                                                              | `'2011-01-01 00:02:00'`                            | The template above specifies only year first and minutes second, so the second<br>element in the input string ("02") is used as minutes. Default values are used for<br>Month and Day ("01") and for hours and seconds ("00").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `'MMM dd, yyyy'`        | `'March 7, 2010'`                                                                                    | `'2010-03-07 00:00:00'`                            | MMM in the template above matches "March"; the template's 'comma space'<br>matches the input string.<br>If the template lacks the comma, so must the input string, or there is no<br>output;<br>If the input string lacks the comma, so must the template.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `'MMM dd,'`             | `'March 7, 2010'`                                                                                    | `'1970-03-07 00:00:00'`                            | Note that the template above doesn't use a year specifier, causing the output<br>TIMESTAMP to use the earliest year in this epoch, 1970.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `'MMM dd,y'`            | `'March 7, 2010'`                                                                                    | `'2010-03-07 00:00:00'`                            | Using the template above, if the input string were 'March 7, 10', the output<br>TIMESTAMP would be '0010-03-07 00:00:00'.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `'M-d'`                 | `'2-8'`                                                                                              | `'1970-02-08 00:00:00'`                            | Absent a yyyy specifier in the template, as above, the earliest year in this<br>epoch (1970) is used.<br>An input string of '2–8−2011' would give the same result; using '2011–2−8' would<br>give no result because 2011 is not a valid month.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `'MM-dd-yyyy'`          | `'06-23-2011 10:11:12'`                                                                              | `'2011-06-23 00:00:00'`                            | Dashes as delimiters (as above) are fine, if template and input both use them<br>in the same positions. Since the template omits hours, minutes, and seconds, zeroes<br>are used in the output TIMESTAMP.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `'dd-MM-yy hh:mm:ss'`   | `'23-06-11 10:11:12'`                                                                                | `'2011-06-23 10:11:12'`                            | You can have the specifiers in any order as long as that order matches the<br>meaning of the input string you supply. The template and input string of the next<br>example below have the same meaning (and the same output TIMESTAMP) as this example,<br>but they specify months before days and seconds before hours.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `'MM-dd-yy ss:hh:mm'`   | `'06-23-11 12:10:11'`                                                                                | `'2011-06-23 10:11:12'`                            | In the template used above, the order of the month and day specifiers is<br>reversed from the example just above, and the specifier for seconds is before hours<br>instead of after minutes; but because the input string also puts months before days<br>and seconds before hours, the meaning (and the output TIMESTAMP) is the same as the<br>example ABOVE.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `'yy-dd-MM ss:hh:mm'`   | `'06-23-11 12:10:11'`                                                                                | `'2006-11-23 10:11:12'`                            | The template used above reverses (compared to the prior example above) the<br>years and months specifiers, while the input string remains the same. In this case,<br>the output TIMESTAMP uses the first element of the input string as the years, the<br>second as the days, and the third as the months.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `'dd-MM-yy hh:mm'`      | `'23-06-11 10:11:12'`                                                                                | `'2011-06-23 10:11:00'`                            | With seconds omitted in the template, as above, the output TIMESTAMP uses 00<br>seconds. Any number of y specifiers produces the same result; but if the input string<br>inadvertently uses a 1 instead of 11 for the year, as in '23-06-1 10:11:12', then the<br>output TIMESTAMP becomes '0001-06-23 10:11:00'.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `'MM/dd/yy hh:mm:ss'`   | `'12/19/11 10:11:12'`<br>`'12/19/11 12:11:12'`                                                       | `'2011-12-19 10:11:12'`<br>`'12/19/11 00:11:12'`   | Slashes as delimiters are fine, if template and input both use them in the<br>same positions, as above. Using specifier hh, input times of 12:11:10 and 00:11:10<br>have the same meaning as a time in the morning.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `'MM/dd/yy HH:mm:ss'`   | `'12/19/11 12:59:59'`<br>`'12/19/11 21:08:07'`<br>`'2011-12-19 00:11:12'`<br>`'2011-12-19 12:11:12'` | `'2011-12-19 12:59:59'`<br>`'2011-12-19 21:08:07'` | The input-string values `'2011-12-19 00:11:12'` or `'2011-12-19<br>12:11:12'` would fail with this template because `'2011'` is not a<br>month, as required/expected by the template-string `'MM/dd/yy<br>HH:mm:ss'`.<br>However, changing the template gives useful output:<br>`<br>values(cast(CHAR_TO_TIMESTAMP('y/MM/dd HH:mm:ss', '2011/12/19 00:11:12') as<br>varchar(19)));<br>'EXPR$0'<br>'2011-12-19 00:11:12'<br>`<br>1 row selected<br>`'12/19/11 00:11:12'` would fail with the above template<br>(`'y/MM/dd'`), since 19 is not a valid month; supplying '`12/11/19<br>00:11:12'` works.<br>`'2011-12-19 12:11:12'` would fail as input because dashes don't match<br>the slashes in the template, `'2011/12/19 12:11:12'` works.<br>Note that for times after 12 noon (that is, for afternoon and evening times), the<br>hours specifier must be HH instead of hh, and the input string must specify the<br>afternoon or evening hour in 24-hour clock time, hours running from 00 to 23.<br>Using specifier HH, input times of 12:11:10 and 00:11:10 have different meanings,<br>the first as a time in the afternoon and the second as a time in the morning.<br>Using the specifier hh, the times from 12:00 through 11:59:59 are morning<br>times:<br>• Given the specifiers hh:mm:ss, the output TIMESTAMP will include<br>`'00:09:08'` in the morning for both input string '12:09:08' and<br>input string `'00:09:08'`; whereas,<br>• Given the specifiers HH:mm:ss, the output TIMESTAMP for input string<br>`'00:09:08'` in the morning will include<br>`'00:09:08'`<br>and the output TIMESTAMP for input string `'12:09:08'` in the<br>afternoon will include `'12:09:08'`. |
