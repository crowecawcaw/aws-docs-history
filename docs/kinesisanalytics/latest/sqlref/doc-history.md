release of the Amazon Kinesis Data Analytics SQL Reference.

- **API version: 2015-08-14**

| Change                                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Date              |

| New `HOTSPOTS` function                           | Locate and return information about relatively dense regions in your data. | Stream-to-stream JOIN examples                    | Examples for JOIN clause queries. | New `RANDOM_CUT_FOREST_WITH_EXPLANATION` function | Get an explanation of what fields contribute to an anomaly score in a data stream.
