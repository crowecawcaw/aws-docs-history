# INITCAP

```
INITCAP ( <character-expression> )

```

Returns a converted version of the input string such that the first character of each
space-delimited word is upper-cased, and all other characters are lower-cased.

## Examples

| Function                                    | Result                           |
| ------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| INITCAP('Each FIRST lEtTeR is cAPITALIZED') | Each First Letter Is Capitalized | ## ###### Note The INITCAP function is not part of the SQL:2008 standard. It is an Amazon Kinesis Data Analytics extension. |
