# LN

```
LN ( <number-expression> )

```

Returns the natural log (that is, the log with respect to base e) of the input argument. If
the argument is negative or 0, an exception is raised. Returns null if the input argument is
null.

For more information, see [LOG10](sql-reference-log10.md "sql-reference-log10.md") and [EXP](sql-reference-exp.md "sql-reference-exp.md").

## Examples

| Function | Result             |
| -------- | ------------------ |
| LN(1)    | 0.0                |
| LN(10)   | 2.302585092994046  |
| LN(2.5)  | 0.9162907318741551 |
