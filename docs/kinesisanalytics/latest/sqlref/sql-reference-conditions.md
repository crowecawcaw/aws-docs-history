- DELETE
  A condition is any value expression of type BOOLEAN, such as the following examples:

- 2<4
- TRUE
- FALSE
- expr_17 IS NULL
- NOT expr_19 IS NULL AND expr_23 < expr>29
- expr_17 IS NULL OR ( NOT expr_19 IS NULL AND expr_23 < expr>29 )
