# CURRENT\_TIME

Returns the current Amazon Kinesis Data Analytics system time when the query executes. Time is in UTC, not the
local time zone.

For more information, see [CURRENT\_TIMESTAMP](sql-reference-current-timestamp.md "sql-reference-current-timestamp.md"), [LOCALTIMESTAMP](sql-reference-local-timestamp.md "sql-reference-local-timestamp.md"),
[LOCALTIME](sql-reference-localtime.md "sql-reference-localtime.md"), [CURRENT\_ROW\_TIMESTAMP](sql-reference-current-row-timestamp.md "sql-reference-current-row-timestamp.md"), and [CURRENT\_DATE](sql-reference-current-date.md "sql-reference-current-date.md").

## Example

```

+---------------+
| CURRENT_TIME  |
+---------------+
| 20:52:05      |
```
