# Patient engagement agents

Amazon Connect Health provides two AI agents for patient engagement: the Patient verification agent and the Appointment management agent. These agents handle routine patient interactions through voice calls via Amazon Connect, integrating with Epic EHR systems in real time through FHIR R4 APIs. Both agents support intelligent escalation to human agents with full context preservation.

## Communication channels

Amazon Connect Health patient engagement agents currently support the voice channel only through Amazon Connect. Web chat, SMS, and other digital channels are not supported in the current release.
