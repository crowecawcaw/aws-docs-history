# Setting up the Windows 11 Mail app for Amazon WorkMail

If you have the Mail app for Microsoft Windows 11, you can add your Amazon WorkMail
account.

###### Note

If you are using the Mail app for Microsoft Windows 11, you may receive
incompatibility reports that require a fix when connecting your Amazon WorkMail account to
the app. Until a fix is released by Microsoft, you will not be able to connect the
Mail app to WorkMail. To ensure that you can resolve the issue as soon as a fix is
released, make sure that you install Windows 11 updates as they become
available.

###### To connect your Amazon WorkMail account to your Mail app

1. In Windows 11, open the Mail app, and then choose
   **Accounts**.
2. Choose **Add Account**, and then choose **Advanced
   Setup**.
3. Choose **Internet email**, and then provide the following
   information:

| Required Information                     | Description                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Email address**                        | Email address associated with your Amazon WorkMail account                                                                                                                                                                                                                                                                                                                |
| **Password**                             | Your password                                                                                                                                                                                                                                                                                                                                                             |
| **User name**                            | Email address associated with your Amazon WorkMail account                                                                                                                                                                                                                                                                                                                |
| **Account name**                         | Your account name                                                                                                                                                                                                                                                                                                                                                         |
| **Send your message using this<br>name** | Your account name                                                                                                                                                                                                                                                                                                                                                         |
| **Incoming email server**                | The endpoint matching the AWS Region in which your<br>mailbox is located:<br>• US West (Oregon)<br>imap.mail.us-west-2.awsapps.com<br>• US East (N. Virginia)<br>imap.mail.us-east-1.awsapps.com<br>• Europe (Ireland)<br>imap.mail.eu-west-1.awsapps.com<br>NoteIf you don't know the AWS Region where your<br>mailbox is located, contact your system<br>administrator. |
| **Account type**                         | IMAP4                                                                                                                                                                                                                                                                                                                                                                     |
| **Outgoing (SMTP) email server**         | The endpoint matching the AWS Region where your mailbox<br>is located:<br>• US West (Oregon)<br>smtp.mail.us-west-2.awsapps.com<br>• US East (N. Virginia)<br>smtp.mail.us-east-1.awsapps.com<br>• Europe (Ireland)<br>smtp.mail.eu-west-1.awsapps.com<br>NoteIf you don't know the AWS Region where your<br>mailbox is located, contact your system<br>administrator.    |

4. Choose **Sign in**.
