# Monitoring Amazon WorkMail with

CloudWatch metrics

You can monitor Amazon WorkMail using CloudWatch, which collects raw data and processes it into
readable, near real-time metrics. The no charge metrics are stored for 15 months so that
you can access historical information to see how your web application or service is
performing. You can also set alarms that watch for certain thresholds, and send
notifications or take actions when those thresholds are met. For more information, see
the [Amazon CloudWatch User Guide](../../../AmazonCloudWatch/latest/monitoring.md "../../../AmazonCloudWatch/latest/monitoring.md").

## CloudWatch metrics for Amazon WorkMail

Amazon WorkMail
sends the following metrics and dimension information to CloudWatch.

The `AWS/WorkMail` namespace includes the following
metrics.

| Metric                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OrganizationEmailReceived`   | The number of emails received by your Amazon WorkMail organization. If<br>one email is addressed to 10 recipients in your organization,<br>the `OrganizationEmailReceived` count is one.<br>Units: Count                                                                                                                                                                                                                                                                           |
| `MailboxEmailDelivered`       | The number of emails delivered to individual mailboxes in your<br>Amazon WorkMail organization. If one email is successfully delivered to 10<br>recipients in your organization, the<br>`MailboxEmailDelivered` count is 10.<br>Units: Count                                                                                                                                                                                                                                       |
| `IncomingEmailBounced`        | The number of incoming emails that bounced due to full<br>mailboxes. This metric is counted for each intended recipient.<br>For example, if one email is sent to 10 recipients in your<br>organization, and two of the recipients have full mailboxes<br>resulting in a bounce response, the<br>`IncomingEmailBounced` count is two.<br>Units: Count                                                                                                                               |
| `OutgoingEmailBounced`        | The number of outgoing emails that couldn't be delivered. This<br>metric is counted for each intended recipient. For example, if<br>one email is sent to 10 recipients, and two emails could not be<br>delivered, the `OutgoingEmailBounced` count is<br>2.<br>Units: Count                                                                                                                                                                                                        |
| `OutgoingEmailSent`           | The number of emails successfully sent from your Amazon WorkMail<br>organization. This metric is counted for each recipient of a<br>successfully sent email. For example, if 1 email is sent to 10<br>recipients, and the email was successfully delivered to 8 of the<br>recipients, the `OutgoingEmailSent` count is<br>8.<br>Units: Count                                                                                                                                       |
| `AuthenticationFailure`       | This metric counts the number of authentication attempts. When<br>authentication is successful, the count is 0 and when<br>authentication is unsuccessful, the count is 1. Use the<br>`Sum` statistic to monitor the amount of failed<br>authentication attempts. Use the `Sample count`<br>statistic to monitor the total number of authentication events.<br>Use the `Average` statistic to monitor the ratio of<br>failed and successful authentication events.<br>Units: Count |
| `AccessDenied`                | This metric counts the number of access control evaluations.<br>When action is denied by access control, the count is 1 and when<br>action is granted, the count is 0. Use the `Sum`<br>statistic to monitor the volume of denied actions, the<br>`Sample count` statistic to monitor the total<br>number of attempted actions, and the `Average`<br>statistic to monitor the ratio of allowed and denied<br>actions.<br>Units: Count                                              |
| `ActionDenied`                | This metric is counted when there's action on mailbox data.<br>When action is denied, the count is 1 and if action is granted,<br>the count is 0. Use the `Sum` statistic to monitor<br>the volume of denied mailbox actions, the `Sample<br>count` statistic to monitor the total number of<br>attempted mailbox actions, and the `Average`<br>statistic to monitor the ratio of allowed and denied<br>actions.<br>Units: Count                                                   |
| `AvailabilityProviderFailure` | This metric is counted for every \*availability provider<br>• request that Amazon WorkMail executes<br>to retrieve calendar availability from an external source. For<br>more information about Availability Providers, see the Amazon WorkMail<br>Administrator Guide.                                                                                                                                                                                                            |
