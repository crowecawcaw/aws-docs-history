# Migrating to the Amazon Pinpoint Console

After April 30, 2018, the Mobile Analytics console will automatically redirect to the [Amazon Pinpoint](https://console.aws.amazon.com/pinpoint "https://console.aws.amazon.com/pinpoint") console. After
this date, the Amazon Pinpoint console will also show all data from apps that report events using the
Mobile Analytics client in the AWS Mobile SDKs. In addition to analytics reports, the Amazon Pinpoint console
offers functionality to create user segments and set up targeted messaging campaigns. Your
campaigns can message your audience through channels for email, mobile push, and SMS. After
you launch a campaign, you can monitor its performance through campaign analytics.
