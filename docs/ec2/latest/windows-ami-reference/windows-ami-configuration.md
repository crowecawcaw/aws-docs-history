# Updates applied for AWS Windows AMIs

To help ensure a smooth and consistent launch experience, AWS Windows AMIs
include the following updates for initialization, installation, and configuration.

###### Note

When you launch an instance from an Amazon managed AWS Windows AMI, the root device for the
Windows instance is an Amazon Elastic Block Store (Amazon EBS) volume. AWS Windows AMIs don't support
instance store for the root device.
