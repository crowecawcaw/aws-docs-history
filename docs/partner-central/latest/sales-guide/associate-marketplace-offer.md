

# Associating an AWS Marketplace private offer

You can associate an AWS Marketplace private offer with an approved opportunity. You can start from the Opportunities page or from the opportunity details.

## Associate an offer from the Opportunities page
<a name="associate-offer-opportunities-page"></a>

1. On the Opportunities page, find the opportunity. In the **Actions** column, choose the actions menu (three dots).

1. Choose one of the following options:
   + **Choose product and offer**. Choose the product type for the AWS Marketplace listing, the product listing, and then the offer.
   + **Enter an AWS Marketplace offer ID**. Enter the offer ID in the dialog.
   + **Enter an AWS Marketplace offer set ID**. Enter the offer set ID in the dialog.
   + **Enter an AWS Marketplace offer/offer set ARN**. Enter the offer or offer set ARN in the dialog.

1. Choose **Associate offer**.

**Note**  
These options are available only for approved opportunities.

## Associate an offer from the opportunity details
<a name="associate-offer-opportunity-details"></a>

1. Choose the ID of the opportunity that you want to update.

1. Go to the **AWS Marketplace transactions** section, and associate your offers there.

## Launch an opportunity with an offer
<a name="associate-offer-launch"></a>

To launch an opportunity that has an associated offer, the opportunity must also have an associated agreement. To check, open the opportunity details, and review the **AWS Marketplace transactions** section.

If the private offer expired and there's no agreement, you can only mark the opportunity Closed Lost.
