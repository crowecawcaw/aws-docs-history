

# Search and filter opportunities

On the Opportunities page, you can narrow the list of opportunities with a filter set, a date range, and property filters. You can use them together.

**Note**  
We upgrade existing AWS Partners to the new opportunities experience automatically. You don't need to change any configuration or take any action.

## Filter sets
<a name="search-filter-sets"></a>

A filter set shows a predefined group of opportunities. To choose one, open the **Filter sets** list. The default filter set is **All open opportunities**. You can't create or save your own filter sets.
+ **All open opportunities**
+ **All opportunities**
+ **Draft opportunities**
+ **Opportunities in review**
+ **Validated opportunities**
+ **Committed opportunities**
+ **Closing this month**
+ **Partner referred opportunities**
+ **AWS referred opportunities**
+ **Date of last provided update exceeds 2 weeks**
+ **Draft opportunities in the last 14 days**
+ **Launched opportunities**
+ **Closed lost opportunities**

## Date range
<a name="search-filter-date-range"></a>

The date range limits the list by when opportunities were updated or when they're expected to close. The default range is **Updated in the last 6 months**. The preset ranges are the following:
+ **Updated in the last 6 months**
+ **Updated in the last 12 months**
+ **Target closing in next 6 months**
+ **Target closing in next 3 months**

1. Choose **Filter date range**.

1. Choose a range in one of the following ways:
   + On the **Preset range** tab, choose a preset range.
   + On the **Custom date range** tab, enter your own start and end dates.

1. Choose **Apply**. To return to the default range, choose **Reset**.

## Property filters
<a name="search-filter-properties"></a>

To find opportunities by a specific value, choose the **Find opportunities** box. Choose a property, and then enter or choose a value. To narrow the list further, add more property filters.

You can filter by the following properties:
+ **Opportunity ID**
+ **Stage**
+ **Status**
+ **Customer company name**
+ **Last updated date**
+ **Target close date**
+ **Date created**
+ **Country**
+ **Partner project title**
+ **Next step**
+ **Tags**
+ **Opportunity Type**
+ **Opportunity Owner**
+ **Partner CRM identifier**
+ **Industry**
+ **AWS account ID**
+ **APN programs**
+ **Co-sell motion**
+ **Estimated AWS MRR amount**
+ **Offer ID**
+ **Offer set ID**

## Columns
<a name="search-filter-columns"></a>

To choose which columns appear in the list, choose the settings (gear) icon, and then select the columns you want to display. The Leads page has the same search bar and column picker.

## Export opportunities
<a name="export-opportunities"></a>

To export opportunities to a CSV file, on the Opportunities page, choose **Export as CSV** above the opportunities table.

## Search opportunities from your CRM
<a name="search-filter-api"></a>

To search opportunities from your CRM or other tools, use the SearchOpportunities operation in the Partner Central Selling API. The operation accepts a keyword, structured filters, and sort options. For details, see [SearchOpportunities](https://docs.aws.amazon.com/partner-central/latest/APIReference/API_SearchOpportunities.html) in the AWS Partner Central API Reference.
