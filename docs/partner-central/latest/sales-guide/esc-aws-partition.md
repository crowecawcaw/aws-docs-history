

# Tagging AWS partition for opportunities
<a name="esc-aws-partition"></a>

Partners can now specify AWS partition details when creating or managing opportunities in AWS Partner Central in the console.

**Create new opportunity**

1. Navigate to **Create opportunity**.

1. In the second step **Add project details**, locate the AWS partition details section.

1. Select the AWS partition from the dropdown menu.

1. Continue with opportunity creation.

**Edit existing opportunity**

1. Open the opportunity you want to update.

1. Navigate to **Project details**.

1. Locate the AWS partition field.

1. Select **Edit** and choose the appropriate partition value.

1. Save your changes.

**AWS updates**

1. AWS updates will provide suggested values based on what your AWS contact suggests.

1. The system will show suggested values when the AWS input is different from your input.

1. Partners can simply locate the record with Property being AWS partition, select and click **Apply**.

1. The suggested value will be saved on the opportunity.
