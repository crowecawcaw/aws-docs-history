

# Remove a solution from AWS Partner Solution Finder
<a name="removing-solution-from-finder"></a>

To remove a solution from your AWS Partner Solution Finder listing, mark it restricted in AWS Partner Central. In AWS Partner Central you can do this on the Solution details page.

**To remove a solution from AWS Partner Solution Finder**

1. Log in to [AWS Partner Central](https://partnercentral.awspartner.com/APNLogin).

1. From the Navigation bar, select **Build** then **solutions**.

1. Select the solution you would like to remove and navigate to solution detail page.

1. Click **Update Visibility** on the top right section.

1. Set the solution's status to **Restricted**.

The solution in Restricted status won't be able to discoverable in Partner Solution Finder, AWS Marketplace and ACE opportunity.
