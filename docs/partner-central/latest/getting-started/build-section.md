

# Build
<a name="build-section"></a>
+ **Solutions:** Native in the AWS Console. [Create](https://docs.aws.amazon.com/partner-central/latest/builder-guide/creating-a-solution.html) and manage solutions. More information in the [AWS Partner Central Builder Guide](https://docs.aws.amazon.com/partner-central/latest/builder-guide/what-is-a-solution.html).
+ **AI agents & tools:** Redirects to AMMP. Manage your AI agents and tools listings on the AWS Marketplace. For more information, see [AI agent products](https://docs.aws.amazon.com/marketplace/latest/userguide/ai-agents-tools.html).
+ **SaaS products:** Redirects to AMMP. Manage your SaaS product listings on the AWS Marketplace. For more information, see [SaaS-based products in AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/userguide/saas-products.html).
+ **Server products:** Redirects to AMMP. Manage your server product listings on the AWS Marketplace.
+ **Machine learning products:** Redirects to AMMP. Manage machine learning (NL) algorithms and models that buyers can deploy in AWS. For more information, see [Machine learning products in AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/userguide/machine-learning-products.html).
+ **Amazon Machine Image:** Redirects to AMMP. Deliver products to buyers with Amazon Machine Images (AMIs). For more information, see [AMI-based products in AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/userguide/ami-products.html).
+ **Data products:** Redirects to AMMP. Manage your data product listings on the AWS Marketplace. For more information, see [Data products](https://docs.aws.amazon.com/marketplace/latest/userguide/data-products.html).
+ **Professional services:** Redirects to AMMP. Manage your professional services listings on the AWS Marketplace. For more information, see [Professional services products in AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/userguide/proserv-products.html).
+ **Requests:** Redirects to AMMP. Displays a list of change requests made on products (AMI, Container, SaaS and Professional Services), offers, and other AWS Marketplace entities from AWS Marketplace Management Portal, or from AWS Marketplace Catalog API.
+ **File upload:** Redirects to AMMP. Upload product load forms (PLFs) to request a new product or updates to an existing product in AWS Marketplace.
+ **Device listings:** Redirects to the legacy Partner Central experience. Relevant for partners on the Hardware Path.
