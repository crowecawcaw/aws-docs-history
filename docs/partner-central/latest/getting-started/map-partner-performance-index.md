

# Performance Indicators
<a name="map-partner-performance-index"></a>

The topics in this section explain how to understand and use the Performance Indicators dashboard within Partner Analytics. Performance Indicators helps you track your organization's effectiveness in delivering Migration Acceleration Program (MAP) projects and provides insights to improve your migration practice. We will continue to evolve Performance Indicators to include additional programs beyond MAP in early 2027.
