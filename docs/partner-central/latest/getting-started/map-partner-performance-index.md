# MAP Partner Performance Index

The MAP Partner Performance Index (PPI) is a comprehensive measurement system that evaluates partner effectiveness in delivering successful AWS migration projects. PPI provides transparent, data-driven insights into your migration practice performance and helps identify opportunities for improvement.

###### Note

Only alliance leads can access the Partner Performance Index dashboard.
