# Co-selling with AWS

Partners participating in the APN Customer Engagements Program (ACE) can create, share and receive [opportunities](../sales-guide/opportunities.md "../sales-guide/opportunities.md") for collaboration with AWS. For more information on how to manage shared customer engagements with AWS, see the [AWS Partner Central Sales Guide](../sales-guide/what-is-ace-pipeline-manager.md "../sales-guide/what-is-ace-pipeline-manager.md").
