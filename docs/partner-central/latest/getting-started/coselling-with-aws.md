

# Co-selling with AWS
<a name="coselling-with-aws"></a>

Partners participating in the APN Customer Engagements Program (ACE) can create, share and receive [opportunities](https://docs.aws.amazon.com/partner-central/latest/sales-guide/opportunities.html) for collaboration with AWS. For more information on how to manage shared customer engagements with AWS, see the [AWS Partner Central Sales Guide](https://docs.aws.amazon.com/partner-central/latest/sales-guide/what-is-ace-pipeline-manager.html).
