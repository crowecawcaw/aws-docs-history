

# Personalized support from the AWS Partner Assistant extension in AWS assistant
<a name="partner-assistant"></a>

The AWS assistant is an AI-powered chat assistant available to all AWS customers in the AWS Management Console. When accessed from AWS Partner Central, the AWS assistant will connect to Partner Assistant, an exclusive extension for AWS Partners that provides access to partner-specific content, including AWS Partner program documentation and guides not available to general AWS customers.

## Personalization capabilities
<a name="personalization-capabilities"></a>

Partner Assistant extension in the AWS assistant also supports personalization capabilities. Users can receive guidance based on your specific partner profile, including your current Tier, Path or other account activity such as opportunities, solutions, benefits and [AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/userguide/user-guide-for-sellers.html) listings.

**Important**  
Use the AWS assistant in AWS Partner Central to quickly find partner-specific information using natural language queries. Unlike the AWS Console's [unified search tool](https://docs.aws.amazon.com/awsconsolehelpdocs/latest/gsg/using-search.html), the AWS assistant can provide summary based on partner-exclusive documentation to deliver answers and recommendations from Partner Central and Marketplace resources. Users can read source documentation by choosing the Source link below each chat response.

## Language support
<a name="language-support"></a>

Partners can ask questions in non-English languages and receive responses in the same language. Supported non-English languages include:
+ Mandarin
+ French
+ German
+ Italian
+ Japanese
+ Spanish
+ Korean
+ Hindi
+ Portuguese

## Accessing AWS assistant for AWS Partner Central
<a name="accessing-amazon-q"></a>

1. From any page in the AWS Console, locate the AWS assistant logo from the top navigation

1. Click the AWS assistant logo to open the chat window

or

1. Type your question in natural language in search bar at the top of the AWS Management Console

1. Click Ask AWS assistant to open the chat window with your question filled in
