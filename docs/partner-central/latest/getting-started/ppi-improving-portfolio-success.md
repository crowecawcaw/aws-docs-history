

# Improving your Portfolio Success
<a name="ppi-improving-portfolio-success"></a>

**Setting realistic expectations:**
+ Base ARR estimates on detailed discovery and data analysis
+ Include conservative assumptions for unknown factors
+ Document assumptions clearly in funding requests
+ Provide realistic estimates that reflect expected outcomes
+ Review estimates with AWS technical teams before submission

**Maintaining momentum:**
+ Keep customers engaged after initial migrations complete
+ Plan for optimization and additional workload migrations
+ Monitor tagged spend monthly and address discrepancies
+ Address technical debt that might limit AWS consumption
+ Help customers expand their AWS usage over time

**Tracking and reporting:**
+ Implement robust workload tagging strategies
+ Review revenue actuals monthly against expectations
+ Update project status and completion dates promptly
+ Provide explanations for material variances
+ Work with AWS to correct any data discrepancies
