# Managed policy mappings

The following table shows the managed policies that must be associated with IAM identities (users/roles) for each scenario.

| Scenario                                                             | User role                                            | Required managed policies                                                                                                        | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Full access to all AWS Partner Central and AWS Marketplace features  | Alliance Lead + Marketplace                          | 1. `AWSPartnerCentralFullAccess`<br>2. `AWSMarketplaceSellerFullAccess`                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Access parity to Partner Central 2.0 Alliance Lead and Alliance Team | Alliance Lead                                        | 1. `AWSPartnerCentralFullAccess`<br>2. `AWSMarketplaceSellerProductsFullAccess`                                                  | `AWSMarketplaceSellerProductsFullAccess` gives access to solution management which is moved to [AWS Marketplace](../../../marketplace/latest/userguide/user-guide-for-sellers.md "../../../marketplace/latest/userguide/user-guide-for-sellers.md")                                                                                                                                                                                         |
| Access parity to Partner Central 2.0 ACE user and ACE manager        | ACE manager                                          | `AWSPartnerCentralOpportunityManagement`                                                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Access parity to Partner Central 2.0 Marketing staff                 | Marketing staff                                      | `AWSPartnerCentralMarketingManagement`                                                                                           |                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Access parity to Partner Central 2.0 Channel user                    | Channel user                                         | There are 2 options here:<br>1. `AWSPartnerCentralChannelManagement`<br>2. `AWSPartnerCentralChannelHandshakeApprovalManagement` | `AWSPartnerCentralChannelManagement`<br>• for full access. `AWSPartnerCentralChannelHandshakeApprovalManagement`<br>• for channel handshake approvals (subset of full access, ideally should be used by recipient AWS account that receives [Channel handshake](channel-management.md "channel-management.md"))                                                                                                                             |
| Technical staff                                                      | Access parity to Partner Central 2.0 Technical staff | `AWSMarketplaceSellerProductsFullAccess`                                                                                         |                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Full access to all AWS Partner Central features                      |                                                      | `AWSPartnerCentralFullAccess`                                                                                                    | As solution have moved to [AWS Marketplace](../../../marketplace/latest/userguide/user-guide-for-sellers.md "../../../marketplace/latest/userguide/user-guide-for-sellers.md"), solution management is not part of this access                                                                                                                                                                                                              |
| Access parity to Partner Central 2.0 Cloud admin                     |                                                      | Not applicable                                                                                                                   | Depending on which access control service is used by partners, they should use managed policies from [IAM](../../../IAM/latest/UserGuide/security-iam-awsmanpol.md "../../../IAM/latest/UserGuide/security-iam-awsmanpol.md"), [Identity Center](../../../singlesignon/latest/userguide/security-iam-awsmanpol.md "../../../singlesignon/latest/userguide/security-iam-awsmanpol.md"), or other mechanisms from external identity providers |
| Access parity to Partner Central 2.0 Standard user                   |                                                      | Not applicable                                                                                                                   | Standard user did not grant access to Partner Central 2.0 features.                                                                                                                                                                                                                                                                                                                                                                         |

For more information about IAM managed policies, see [Managing IAM policies](../../../IAM/latest/UserGuide/access_policies_managed-using.md "../../../IAM/latest/UserGuide/access_policies_managed-using.md"). For information about attaching policies to users and groups, see [Attaching a policy to an IAM user group](../../../IAM/latest/UserGuide/id_groups_manage_attach-policy.md "../../../IAM/latest/UserGuide/id_groups_manage_attach-policy.md").
