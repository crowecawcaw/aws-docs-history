

# Understanding your Performance Indicators score
<a name="ppi-scoring"></a>

Your Performance Indicators score is a single percentage that reflects your overall effectiveness across four key performance areas. The score ranges from 33% to 100%, with higher scores indicating stronger performance.

## How scoring works
<a name="ppi-scoring-mechanism"></a>

Performance Indicators evaluates your performance using four key metrics:
+ [Migration Win Rate](#ppi-metric-assess-conversion) – Your ability to convert funded assessments into migration projects
+ [Speed to Value](#ppi-metric-speed-value) – How quickly you help customers realize value after the migration starts
+ [Portfolio Success](#ppi-metric-portfolio-success) – Overall revenue achievement across all completed projects
+ [Project Success](#ppi-metric-project-success) – Individual project performance and consistency

For each metric, you receive a score of 1, 2, or 3 points based on your performance. For more information about performance tracks, see [Performance levels and benefits](ppi-tiers-benefits.md).


| Score | Performance track | Description | 
| --- | --- | --- | 
| 3 points | High Performance Track | Exceeds expectations; demonstrates excellence | 
| 2 points | Core Program Track | Meets expectations; solid execution | 
| 1 point | Turnaround Track | Below expectations; improvement needed | 

**Note**  
Partners must have a score for each metric in order to receive a Performance Indicators score. Partners without 3 completed migrations or 3 assess claims will receive a Trending Performance Indicators score until they meet the minimum activity required.

### Calculating your score
<a name="ppi-scoring-calculation"></a>

**Performance Indicators Score** = The average of all four metric scores, with a maximum of 3. A partner must have a score for all four metrics to receive a Performance Indicators score.

**Performance Indicators Score %** = The Performance Indicators average score divided by 3 (maximum possible score), expressed as a percentage.

For example, if you score 2 points on two metrics and 3 points on two metrics:
+ Performance Indicators Score: (2 \+ 2 \+ 3 \+ 3) / 4 = 2.5
+ Performance Indicators Score %: 2.5 / 3 = 83%

## Four key performance metrics
<a name="ppi-key-metrics"></a>

This section provides detailed information about each of the four metrics used to calculate your Performance Indicators score.

### Metric 1: Assess conversion rate
<a name="ppi-metric-assess-conversion"></a>

This metric measures your ability to convert AWS-funded Assess projects into signed migration commitments. High conversion rates indicate that you:
+ Effectively qualify opportunities before requesting funding
+ Align assessment findings with customer priorities
+ Make efficient use of AWS funding resources
+ Build strong customer commitment early in the process

#### Calculating this metric
<a name="ppi-metric-assess-conversion-calculating"></a>

**Win Rate** = (Number of Assess-funded Won migrations) / (Number of Assess-funded Won \+ Lost migrations) in the past 24 months

The following table shows the thresholds for each performance level.


| Performance level | Win rate | 
| --- | --- | 
| High Performance Track (3 points) | 75% or higher | 
| Core Program Track (2 points) | 40% to less than 75% | 
| Turnaround Track (1 point) | Below 40% | 

For example, if you've received Assess funding for 100 projects and 85 of them converted to signed migrations while 15 were lost, your win rate is 85/100 = 85%, earning you 3 points (High Performance Track).

#### Improving this metric
<a name="ppi-metric-assess-conversion-improving"></a>

To improve this metric, follow these best practices:
+ Strengthen your opportunity qualification process
+ Ensure thorough customer discovery before submitting funding requests
+ Align assessment outcomes with specific customer business drivers
+ Maintain regular communication with customers throughout the assessment phase
+ Partner closely with AWS account teams during the sales cycle

For more information about improving your score, see [Improving your Performance Indicators score](ppi-improvement-strategies.md).

### Metric 2: Migration delivery velocity health
<a name="ppi-metric-speed-value"></a>

This metric measures how quickly your migration projects begin generating meaningful AWS revenue after the project reached $1K in tagged spend. Fast starts demonstrate that you:
+ Improve Partner Cash Flow by ensuring faster payment of the Mobilize funding
+ Effectively plan and execute migration strategies
+ Prioritize high-value workloads early
+ Remove blockers and accelerate customer adoption
+ Help customers realize business value quickly

#### Calculating this metric
<a name="ppi-metric-speed-value-calculating"></a>

**Speed to Value** = Percentage of projects reaching $50K within 90 days from $1K date in the past 24 months

The following table shows the thresholds for each performance level.


| Performance level | Projects hitting target | 
| --- | --- | 
| High Performance Track (3 points) | 75% or higher of projects | 
| Core Program Track (2 points) | 40% to less than 75% of projects | 
| Turnaround Track (1 point) | Below 40% of projects | 

For example, if you have 50 projects that are at least 6 months past their start date, and 44 of them reached $50K within 90 days from the day of $1K, your speed to value is 44/50 = 88%, earning you 3 points (High Performance Track).

#### Improving this metric
<a name="ppi-metric-speed-value-improving"></a>

To improve this metric, follow these best practices:
+ Develop detailed migration wave planning during Mobilize
+ Prioritize workloads that generate immediate business value
+ Implement automated migration tools and processes
+ Establish clear project governance and escalation paths
+ Ensure adequate customer resources are committed to the project
+ Use AWS migration best practices and frameworks
+ Monitor progress weekly and address blockers immediately

For more information about improving your score, see [Improving your Performance Indicators score](ppi-improvement-strategies.md).

### Metric 3: Final migration revenue realization on completed projects at portfolio level
<a name="ppi-metric-portfolio-success"></a>

This metric measures your overall effectiveness in delivering expected revenue outcomes across all completed migration projects. Strong portfolio performance shows that you:
+ Accurately estimate project scope and potential
+ Consistently deliver on commitments
+ Have effective project management processes
+ Maintain customer engagement through project completion
+ Solve obstacles/challenges to ensure migration completion

#### Calculating this metric
<a name="ppi-metric-portfolio-success-calculating"></a>

**Portfolio Success** = Sum of tagged spend (monthly recurring revenue, or MRR) from completed Migrations / Sum of expected terminal annual recurring revenue (ARR) from completed migrations in the past 36 months

The following table shows the thresholds for each performance level.


| Performance level | Revenue achievement | 
| --- | --- | 
| High Performance Track (3 points) | 75% or higher | 
| Core Program Track (2 points) | 40% to less than 75% | 
| Turnaround Track (1 point) | Below 40% | 

For example, if your completed projects had a combined expected terminal ARR of $10M and you achieved $9.2M in actual map tagged spend, your portfolio success rate is 9.2/10 = 92%, earning you 3 points (High Performance Track).

#### Improving this metric
<a name="ppi-metric-portfolio-success-improving"></a>

To improve this metric, follow these best practices:
+ Provide the most accurate and up to date information as the migration progresses
+ Provide realistic, well-justified ARR estimates in funding requests
+ Maintain active customer engagement throughout the migration lifecycle
+ Implement robust workload tagging and tracking processes
+ Conduct regular project health checks and business reviews
+ Address project challenges proactively before they impact outcomes
+ Ensure all migrated workloads are properly tagged for revenue tracking

For more information about improving your score, see [Improving your Performance Indicators score](ppi-improvement-strategies.md).

### Metric 4: Final migration revenue realization on completed projects at individual deal level
<a name="ppi-metric-project-success"></a>

This metric measures the consistency of your project delivery by examining individual project outcomes. It prevents a few exceptional projects from masking multiple underperforming ones. Consistent project delivery demonstrates that you:
+ Execute with quality across your entire portfolio
+ Manage and mitigate risk effectively
+ Use reliable processes that work for various project types
+ Satisfy customers at the individual project level

#### Calculating this metric
<a name="ppi-metric-project-success-calculating"></a>

**Project Success** = Percentage of completed projects that achieved at least 50% of expected ARR in the past 36 months

The following table shows the thresholds for each performance level.


| Performance level | Projects over 50% ARR | 
| --- | --- | 
| High Performance Track (3 points) | 75% or higher | 
| Core Program Track (2 points) | 40% to less than 75% | 
| Turnaround Track (1 point) | below 40% | 

For example, if you've completed 30 projects and 26 of them achieved over 50% of their expected ARR, then 26/30 = 87% of your projects met the threshold, earning you 3 points (High Performance Track).

#### Improving this metric
<a name="ppi-metric-project-success-improving"></a>

To improve this metric, follow these best practices:
+ Implement consistent project delivery methodologies
+ Identify and replicate success patterns from your best projects
+ Intervene early when projects show signs of underperformance
+ Conduct post-project reviews to identify improvement opportunities
+ Ensure adequate staffing and expertise for each project
+ Maintain detailed project documentation and lessons learned

For more information about improving your score, see [Improving your Performance Indicators score](ppi-improvement-strategies.md).
