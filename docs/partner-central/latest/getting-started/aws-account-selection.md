

# AWS account selection
<a name="aws-account-selection"></a>

To use AWS Partner Central, you need an AWS account. Whether you are migrating to AWS Partner Central or registering for the first time, review the following requirements before you choose which account to use.

## Account selection criteria
<a name="account-selection-criteria"></a>

The AWS account you choose must meet the following requirements:
+ **Use a paid AWS account plan and maintain good standing** – The account must use a paid account plan (not the AWS Free Tier) and maintain good standing with AWS and APN. Sign in to the [AWS Billing console](https://console.aws.amazon.com/billing/home?#/freetier/upgrade) and choose **Upgrade plan**.
+ **Be owned by your company** – Your company must own the account, not a distributor or another organization.
+ **Support onboarding of future Partner Central users** – Anyone who needs to create opportunities, solutions, and fund requests must have access to this account.

Do not choose the following types of accounts:
+ **Developer or test accounts** – An account where developers write code or perform proof-of-concept work.
+ **Personal accounts** – An account used by individuals for learning, experimenting, or personal projects.

We do not recommend using the following types of accounts:
+ **Management account (payer account)** – The account that manages billing and metadata for all AWS accounts in your organization.
+ **AWS Marketplace buyer account** – An account used to procure products from AWS Marketplace.

## Selecting an account
<a name="selecting-an-account"></a>

The process for selecting an account depends on whether you have existing AWS Marketplace Seller accounts.

### If you do not have any existing AWS Marketplace Seller accounts
<a name="no-marketplace-seller-accounts"></a>

1. Review the account selection criteria in the preceding section against your existing AWS accounts.

1. If no existing account meets all criteria, create a new AWS account that does.

### If you have one existing AWS Marketplace Seller account
<a name="one-marketplace-seller-account"></a>

1. Evaluate the AWS Marketplace account against the account selection criteria.

1. If it meets all criteria, we recommend using this account.

1. If it does not meet all criteria, create a new AWS account that does.

### If you have multiple existing AWS Marketplace Seller accounts
<a name="multiple-marketplace-seller-accounts"></a>

For example, you might have separate accounts in multiple countries.

1. Determine whether one of your existing AWS Marketplace Seller accounts can represent your global business. Evaluate it against the checklist in the preceding section. If it meets all criteria, we recommend using this account.

1. If none of your existing AWS Marketplace Seller accounts can represent your global business, evaluate your other AWS accounts. Use the criteria in the preceding section as your guide.

   1. If an existing account meets all criteria, we recommend using that account.

   1. If no existing account meets all criteria, create a new AWS account that does.

**Note**  
If you have more than one AWS Marketplace Seller account, you can either designate one as the primary account for Partner Central engagements or use a non-AWS Marketplace Seller account instead. You can then connect your AWS Marketplace Seller accounts to your Partner Central account. For more information, see [Subsidiary Account Connections](https://docs.aws.amazon.com/partner-central/latest/getting-started/manage-subsidiary.html).

**Important**  
Register only one AWS account for AWS Partner Central, regardless of how many AWS or AWS Marketplace accounts your organization maintains. Do not register additional AWS Partner Central accounts from other AWS accounts.
