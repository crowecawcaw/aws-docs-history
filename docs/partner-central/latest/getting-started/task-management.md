# Task management

Alliance leads can manage task assignments for users in their AWS Partner organization.

###### To assign or reassign a task

1. Sign in to [AWS Partner Central](https://partnercentral.awspartner.com/APNLogin "https://partnercentral.awspartner.com/APNLogin") as a user with the alliance lead role.
2. In the **Tasks** section of the home page, choose **View tasks**.
3. On the **Tasks** page, choose the **Account tasks**, **Solution tasks**, or **Program tasks** tab.
4. In the tasks table, select the check box of the task you want to assign.
5. Choose **Change assignee**.
6. On the **Assign task** dialog box, choose a user. You can search for a user by entering a name.
7. Choose **Confirm**.
