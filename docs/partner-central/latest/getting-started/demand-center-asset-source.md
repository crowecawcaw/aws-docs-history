

# Choosing a source for an AI asset

Each AI asset has a source step. AI drafts the asset from the source that you give it, so the more specific the source, the better the draft. For a case study, give the customer's challenge, the solution, and measurable results.

You can choose from the following sources:
+ **Generate with AI** – AI drafts from a reference that you provide: a description in your own words, a public link, or a file. For a file, choose a PDF, DOCX, TXT, or MD file.
+ **Build from an opportunity** – For case studies, AI drafts from a won ACE opportunity, so the story uses real deal details.
+ **I already have this content** – Uses content that you provide, so review it for accuracy and brand compliance first.

1. On the asset's source step, select a source.

1. Provide the source. For **Generate with AI**, enter a description, paste a link, or upload a PDF, DOCX, TXT, or MD file. For **Build from an opportunity**, select a won opportunity.

1. Choose the draft button for the asset, such as **Draft case study**, **Draft white paper**, or **Draft solution brief**.

1. Review the drafted fields, and edit any that need changes.

1. Choose **Save and next**.

For more information about the rest of the create campaign wizard, see [Creating a campaign in Demand Center](demand-center-create-campaign.md).
