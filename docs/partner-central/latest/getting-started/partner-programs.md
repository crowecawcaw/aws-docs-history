

# Applying to AWS Partner programs
<a name="partner-programs"></a>

AWS Partner programs provide resources through AWS Partner Central, including technical training, marketing funds, and solution architect support to help partners grow their business on AWS. You can apply to [AWS Partner programs](https://aws.amazon.com/partners/programs/) in AWS Partner Central.

Program Navigator is the experience for discovering and applying to AWS Partner programs. From Program Navigator, you can browse available programs and designations, review requirements and benefits, and submit applications through a guided workflow.

To access Program Navigator, sign in to [AWS Partner Central](https://partnercentral.awspartner.com/APNLogin), and then, in the left navigation panel, choose **Go to Market**, and then choose **Program Navigator**.

**Note**  
For programs that are not yet available in Program Navigator, choose **Apply in legacy experience** in the banner at the top of the Program Navigator page. This redirects you to the legacy application experience for those programs.

## Prerequisites
<a name="partner-programs-prerequisites"></a>

To apply for programs, you must have one of the following AWS managed policies assigned:
+ `AWSPartnerCentralFullAccess`
+ `PartnerCentralIncentiveBenefitManagement`

## Applying for a program
<a name="partner-programs-applying"></a>

**To apply for a program**

1. In the left navigation panel, choose **Go to Market**, and then choose **Program Navigator**.

1. Choose the **All programs** tab to find the program you want to apply for.

1. Choose the program to view the program detail page. Review the program requirements and benefits.

1. Choose **Create application**.

1. Complete the application steps. Depending on the program, the application might include a self-assessment, case studies, a validated solution, and training or certification achievements.

1. Choose **Submit** to send your application for review, or choose **Save as draft** to return to the application later.

To view applications you have already submitted, choose the **Applications** tab.

After you submit the application, the status changes to In review. We review the application and provide feedback throughout the process. If the Competency is automated, then the results appear within minutes on the application page. If you need to address open items, the status changes to Action required. Review the feedback, make the required changes, and resubmit. You can withdraw a submitted application at any time while the application is in review.

## Application statuses
<a name="partner-programs-statuses"></a>

The following table describes the statuses for program applications in Program Navigator.


| Status | Description | 
| --- | --- | 
| Draft | You are building the application. The application has not been submitted. You can also see this status after withdrawing a submitted application. | 
| In review | The application has been submitted and is being reviewed by AWS. No action is required from you. You can't edit the application while it is in review. | 
| Action required | AWS has identified items that need your attention. Review the feedback on the application detail page, or an AWS team member will contact you and share details by email. Address the open items and resubmit. | 
| Approved | The application has been approved. | 
| Canceled | The application has been canceled. |
