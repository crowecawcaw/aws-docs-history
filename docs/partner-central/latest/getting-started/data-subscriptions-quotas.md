

# Data subscription quotas

Data subscriptions have the following limits. The limits are the same for every account and can't be increased.
+ You can have up to 100 active subscriptions for each dataset in your account.
+ You can't create a second subscription for the same dataset to the same bucket. Create the second subscription against a different bucket instead.
+ A subscription can have up to 50 tags. Tag keys can be up to 128 characters, tag values up to 256. Keys that begin with `aws:` are reserved.
