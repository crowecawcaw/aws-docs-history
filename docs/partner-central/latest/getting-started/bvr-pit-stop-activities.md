

# Pit stop activities
<a name="bvr-pit-stop-activities"></a>

Each pit stop contains activities that you complete to demonstrate progress. Activities are categorized as **Required** (must complete to advance) or **Optional** (support adoption but don't block progression).

## Activity statuses
<a name="bvr-activity-statuses"></a>


| Status | Description | 
| --- | --- | 
| Not submitted | The activity hasn't been started. Choose Submit to begin. | 
| Under review | Submitted and awaiting PSS review. No action needed from you. | 
| Complete | Approved and finalized. | 
| Action required | Your PSS requested changes. Review feedback and resubmit. | 

## Submitting an activity
<a name="bvr-submitting-activity"></a>

Each activity tells you what type of submission is required (for example, a file upload, a KPI value entry, or a confirmation). Follow the instructions in the submission form and choose **Submit** when ready.

Some activities provide downloadable templates. If a template is available, it appears in the submission form.

## Responding to feedback
<a name="bvr-responding-to-feedback"></a>

When your PSS requests changes, the activity moves to **Action required** and a notification banner appears on the initiative detail page.

1. Choose **Review feedback** on the notification banner, or choose **View** on the activity.

1. Review the PSS feedback in the activity history.

1. Make the requested changes and resubmit.

## Viewing completed activities
<a name="bvr-viewing-completed"></a>

To see what was submitted for a completed activity, find it in the activities list and choose **View**. The detail shows the full submission history including timestamps and notes.
