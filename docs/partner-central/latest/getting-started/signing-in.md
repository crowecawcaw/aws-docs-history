

# Accessing AWS Partner Central
<a name="signing-in"></a>

Users can sign in to AWS Partner Central from a browser. For the best experience, we recommend using a desktop computer.

**To sign in to AWS Partner Central**

1. Log into the AWS Management Console for the AWS account associated with their AWS Partner Central account.

   Depending on how users are managed in the account, this process will vary. Users using [AWS IAM Identity Center](https://docs.aws.amazon.com/singlesignon/latest/userguide/what-is.html) will log in using Single Sign-On. Users with an [external Identity Provider](https://docs.aws.amazon.com/singlesignon/latest/userguide/manage-your-identity-source-idp.html) may log in through the IdP console and select the AWS account to log in.

1. Once logged into the AWS Management Console, users can get to the AWS Partner Central service page through:
   + [Direct link](https://us-east-1.console.aws.amazon.com/partnercentral))
   + Services menu
   + [Global search](https://docs.aws.amazon.com/awsconsolehelpdocs/latest/gsg/using-search.html)

1. Choose **Launch AWS AWS Partner Central** on the service page.
