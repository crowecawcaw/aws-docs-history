

# Adoption report
<a name="bvr-adoption-report"></a>

The adoption report provides a weekly summary of your customer's AWS service usage, feature adoption, and engagement signals. It's available during the adoption-focused pit stops of your initiative.

## What the report shows
<a name="bvr-report-contents"></a>

The adoption report includes:
+ **Key metrics** — Weekly active users, feature utilization, and champion engagement with week-over-week trend indicators.
+ **AI-generated insights** — Highlights of what's working, risks that need attention, and recommended next actions with links to enablement resources.
+ **Charts** — Visualizations of user engagement, feature adoption trends, and service utilization over time.

Reports are generated weekly from account telemetry. The report period and last updated date are displayed in the summary.

## Requesting changes
<a name="bvr-report-changes"></a>

If you identify inaccuracies or want to provide feedback on the report, submit a **Request changes to adoption report** activity in the current pit stop. Add your feedback in the activity notes describing what needs correction or additional context.
