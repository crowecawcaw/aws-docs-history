

# Getting help and support
<a name="ppi-support"></a>

AWS provides several ways to get help with Performance Indicators. Use the following resources to open support cases, submit data correction requests, attend enablement sessions, and work with your Partner Development Manager (PDM).

## Accessing AWS Partner Central resources
<a name="ppi-support-resources"></a>

**To open a support case in AWS Partner Central**

1. Sign in to AWS Partner Central.

1. Choose **Support**, and then choose **Contact Support**.

1. For **What type of support case would you like to open?**, choose **APN Funding**.

1. For **Type of request**, choose **Migration Acceleration Program (MAP)**.

## Submitting data correction requests
<a name="ppi-support-data-corrections"></a>

Work with your PDM to submit corrections for:
+ Project attribution errors
+ Incorrect project dates
+ ARR estimate updates
+ Project status discrepancies

## Attending enablement sessions
<a name="ppi-support-enablement"></a>

AWS hosts regular enablement sessions on:
+ Migration best practices
+ Performance Indicators optimization strategies
+ New program features
+ Top performer insights

Check the AWS Partner Central events calendar for upcoming sessions.

## Contacting your PDM
<a name="ppi-support-pdm"></a>

Your PDM is your primary point of contact for all Performance Indicators–related questions and support. They can:
+ Help you understand your Performance Indicators score and metrics
+ Provide improvement recommendations
+ Assist with data corrections and validation
+ Connect you with technical resources
+ Answer questions about program policies
