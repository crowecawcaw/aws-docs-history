

# Performance levels and benefits
<a name="ppi-tiers-benefits"></a>

Performance Indicators recognizes different levels of partner capability and provides appropriate support and benefits for each level.

Your Performance Indicators score classifies you into one of three performance levels.


| Level | Score range | Description | 
| --- | --- | --- | 
| High Performance Track | 83%–100% (10–12 total points) | Partners delivering the strongest results across metrics | 
| Core Program Track | 50%–82% (6–9 total points) | Partners within core expectations with growth potential | 
| Turnaround Track | 0%–49% (5 or fewer total points) | Partners who need support to meet performance standards | 

## High Performance Track
<a name="ppi-tier-high-performance"></a>

### Who qualifies
<a name="ppi-tier-high-performance-qualifies"></a>

Partners delivering exceptional results across all four metrics, or strong performance in most areas.

### Benefits
<a name="ppi-tier-high-performance-benefits"></a>

AWS will announce benefits for High Performing Partners in December 2026.

### Support
<a name="ppi-tier-high-performance-support"></a>

This track includes the following support:
+ Regular business reviews with AWS Partner Development Managers
+ Standard AWS Partner support channels
+ Access to migration best practices and playbooks
+ Partner community forums and knowledge base
+ Quarterly performance reviews

## Core Program Track
<a name="ppi-tier-core-program"></a>

### Who qualifies
<a name="ppi-tier-core-program-qualifies"></a>

Partners meeting core expectations with solid execution and clear growth potential.

### Support
<a name="ppi-tier-core-program-support"></a>

This track includes the following support:
+ Standard AWS Partner support channels
+ Access to migration best practices and playbooks
+ Partner community forums and knowledge base
+ Quarterly performance reviews

## Turnaround Track
<a name="ppi-tier-turnaround"></a>

### Who qualifies
<a name="ppi-tier-turnaround-qualifies"></a>

Partners who need focused support to meet performance standards. This tier is designed to help you succeed through targeted resources and guidance.

### Support benefits
<a name="ppi-tier-turnaround-support"></a>

This track includes the following support benefits:
+ Standard AWS Partner support channels
+ Access to migration best practices and playbooks
+ Partner community forums and knowledge base
+ Quarterly performance reviews

### What AWS asks
<a name="ppi-tier-turnaround-asks"></a>

AWS asks for the following:
+ Commitment to improve performance
+ Regular participation in performance reviews
+ Cooperation in maintaining data accuracy and timely project updates
+ Implementation of recommended best practices
