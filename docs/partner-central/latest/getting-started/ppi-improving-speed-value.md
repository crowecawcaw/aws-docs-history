

# Improving your Speed to Value
<a name="ppi-improving-speed-value"></a>

**During Mobilize:**
+ Develop detailed wave planning that prioritizes high-value workloads
+ Identify and migrate "quick wins" in the first 90 days
+ Ensure customer resources are allocated and available
+ Remove organizational and technical blockers early
+ Set clear milestones with customer accountability

**During execution:**
+ Use automated migration tools (AWS MGN, AWS DMS, etc.)
+ Implement parallel workload migration streams where possible
+ Monitor progress weekly with detailed metrics
+ Conduct daily standups during active migration sprints
+ Have escalation paths ready for quick issue resolution

**Project governance:**
+ Establish a clear RACI matrix (Responsible, Accountable, Consulted, Informed)
+ Hold regular steering committee meetings
+ Maintain risk registers and mitigation plans
+ Celebrate early wins to maintain momentum
