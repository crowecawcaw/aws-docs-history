# CRM connector tabs and permission sets

When you use the CRM connector app in Salesforce, a set of tabs appears. The tabs you see vary, depending on your permission settings.
The following table lists the tabs provided by the connector app, and the permission sets allowed to use each tab.

| **Connector app tab**             | **Permission sets**                                                                                                                                        |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AWS Guided Setup**              | APN Business Administrator<br>APN Integration User<br>APN Business User ?<br>AWS Marketplace Administrator                                                 |
| **Reports**                       | APN Business User<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner User                                                                |
| **ACE Mappings**                  | APN Business Administrator<br>APN Business User ?                                                                                                          |
| **Schedules**                     | APN Business Administrator<br>APN Integration User<br>AWS Marketplace User (AWS Marketplace ISV)                                                           |
| **ACE Sync Logs**                 | APN Business Administrator<br>APN Integration User<br>APN Business User                                                                                    |
| **ACE Leads**                     | APN Business Administrator ? -> Available<br>APN Integration User ?<br>APN Business User                                                                   |
| **ACE Opportunities**             | APN Business Administrator ? -> Available<br>APN Integration User ?<br>APN Business User                                                                   |
| **Solution Offerings**            | APN Business Administrator<br>APN Business User                                                                                                            |
| **AWS Accounts**                  | AWS Marketplace Administrator<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner User                                                    |
| **Products**                      | AWS Marketplace Administrator<br>AWS Marketplace User (AWS Marketplace ISV)                                                                                |
| **Private Offers**                | AWS Marketplace Administrator ? -> Available<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner User                                     |
| **Resale Authorizations**         | AWS Marketplace Administrator ? -> Available<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner user                                     |
| **Shared Resale Authorizations**  | AWS Marketplace Administrator ? -> Available<br>AWS Channel Partner user                                                                                   |
| **Marketplace sync logs**         | AWS Marketplace Administrator<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner User                                                    |

| **AWS Marketplace Notifications** | APN Business Administrator<br>APN Business User<br>AWS Marketplace Administrator<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner user |
| **Field Mappings**                | APN Business Administrator ?<br>APN Integration User ?                                                                                                     |
| **Offer Dimensions**              | AWS Marketplace Administrator ?<br>AWS Marketplace User (AWS Marketplace ISV)<br>AWS Channel Partner User                                                  |
