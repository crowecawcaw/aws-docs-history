# Using an earlier CRM with Amazon S3 integration

###### Important

AWS Partner Central stopped accepting new requests for this type of integration in 2024.
This section only applies to partners using Amazon S3.

To upgrade from S3 integration to new API CRM integration, refer to
[upgrade from S3 to API](upgrade-crm-api.md "upgrade-crm-api.md").
