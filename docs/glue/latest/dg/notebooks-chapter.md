# Authoring code with AWS Glue Studio notebooks

Data engineers can author AWS Glue jobs faster and more easily than before using the interactive notebook
interface in AWS Glue Studio or interactive sessions in AWS Glue.

##

Limitations

- AWS Glue Studio notebooks do not support Scala.
