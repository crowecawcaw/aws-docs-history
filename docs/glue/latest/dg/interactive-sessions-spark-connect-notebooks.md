

# Getting started with Spark Connect using Notebooks in SageMaker Unified Studio
<a name="interactive-sessions-spark-connect-notebooks"></a>

In Amazon SageMaker Unified Studio, you can select AWS Glue as the Spark Connect runtime in the notebook side panel. The notebook manages the session connection automatically, so you don't need to handle endpoint retrieval or token refresh.

For detailed instructions on setting up and using AWS Glue Spark Connect in Notebooks in Amazon SageMaker Unified Studio, see [Spark Compute](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/userguide/notebooks-spark-connect.html) in the *Amazon SageMaker Unified Studio User Guide*.
