# Getting started with Spark Connect using Notebooks in SageMaker Unified Studio

In Amazon SageMaker Unified Studio, you can select AWS Glue as the Spark Connect runtime
in the notebook side panel. The notebook manages the session connection automatically,
so you don't need to handle endpoint retrieval or token refresh.

For detailed instructions on setting up and using AWS Glue Spark Connect in Notebooks
in Amazon SageMaker Unified Studio, see
[Spark Compute](../../../sagemaker-unified-studio/latest/userguide/notebooks-spark-connect.md "../../../sagemaker-unified-studio/latest/userguide/notebooks-spark-connect.md")
in the _Amazon SageMaker Unified Studio User Guide_.
