#

Connecting to Amazon Redshift in AWS Glue Studio

###### Note

You can use AWS Glue for Spark to read from and write to tables in Amazon Redshift databases outside of
AWS Glue Studio. To configure Amazon Redshift with AWS Glue jobs programatically, see
[Redshift connections](aws-glue-programming-etl-connect-redshift-home.md "aws-glue-programming-etl-connect-redshift-home.md").

AWS Glue provides built-in support for Amazon Redshift. AWS Glue Studio provides a visual interface to
connect to Amazon Redshift, author data integration jobs, and run them on AWS Glue Studio serverless Spark runtime.
