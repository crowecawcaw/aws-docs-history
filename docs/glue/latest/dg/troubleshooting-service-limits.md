# AWS Glue quotas

You can contact AWS Support to
[request a quota increase](../../../general/latest/gr/aws_service_limits.md "../../../general/latest/gr/aws_service_limits.md") for the service quotas listed
in the _AWS General Reference_. Unless otherwise noted, each quota is
Region-specific. For more information, see [AWS Glue Endpoints
and Quotas](../../../general/latest/gr/glue.md "../../../general/latest/gr/glue.md").
