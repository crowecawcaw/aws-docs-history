# Configuring Adobe Analytics

Before you can use AWS Glue to transfer from Adobe Analytics, you must meet the following
requirements:

## Minimum requirements

- You have an Adobe Analytics account with email and password. For more
  information about creating an account, see [Creating a Adobe Analytics
  account](adobeanalytics-create-account.md "adobeanalytics-create-account.md").
- Your Adobe Analytics account is enabled for API access. API access is enabled by default for the Select, Prime, and Ultimate editions.

If you meet these requirements, you’re ready to connect AWS Glue to your Adobe
Analytics account. For typical connections, you don't need do anything else in Adobe
Analytics.
