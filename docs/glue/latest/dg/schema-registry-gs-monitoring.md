# Accessing Amazon CloudWatch metrics

Amazon CloudWatch metrics are available as part of CloudWatch’s free tier. You can access these metrics
in the CloudWatch console. API-Level metrics include CreateSchema (Success and Latency),
GetSchemaByDefinition, (Success and Latency), GetSchemaVersion (Success and
Latency), RegisterSchemaVersion (Success and Latency), PutSchemaVersionMetadata
(Success and Latency). Resource-level metrics include Registry.ThrottledByLimit,
SchemaVersion.ThrottledByLimit, SchemaVersion.Size.
