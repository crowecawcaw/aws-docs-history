# Configuring a crawler

A crawler accesses your data store, identifies metadata, and creates table definitions in
the AWS Glue Data Catalog. The **Crawlers** pane in the AWS Glue console lists all
the crawlers that you create. The list displays status and metrics from the last run of your
crawler.

This topic contains the step-by-step process of configuring a crawler,
covering essential aspects such as setting up the crawler's parameters, defining the data sources to crawl, setting up security, and managing the crawled data.
