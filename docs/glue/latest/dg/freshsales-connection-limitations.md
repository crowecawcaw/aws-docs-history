# Freshsales limitations

The following are limitations or notes for Freshsales:

- In Freshsales, the API Rate limit is 1000 API requests per hour per account (see [Errors](https://developer.freshsales.io/api/#error "https://developer.freshsales.io/api/#error"). But this limit is extendable with the Enterprise subscription plan (see the [plan comparison](https://www.freshworks.com/crm/pricing-compare/ "https://www.freshworks.com/crm/pricing-compare/")).
