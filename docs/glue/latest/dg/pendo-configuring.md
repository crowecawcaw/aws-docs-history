# Configuring Pendo

Before you can use AWS Glue to transfer from Pendo, you must meet the following
requirements:

## Minimum requirements

- You have a Pendo account with an `apiKey` with `write
access` enabled.
- Your Pendo account has API access with a valid license.

If you meet these requirements, you’re ready to connect AWS Glue to your Pendo
account. For typical connections, you don't need do anything else in Pendo.
