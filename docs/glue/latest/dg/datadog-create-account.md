# Creating a Datadog account

1. Go to [https://www.datadoghq.com/](https://api.datadoghq.com "https://api.datadoghq.com").
2. Choose **GET STARTED FREE**.
3. Enter the required information and sign up.
4. Install the **Datadog Agent Installer** as suggested.
5. Ensure that the account gets registered with a valid organization (from the list
   available) that has an active Datadog subscription.
6. After logging in to your Datadog account, hover over your username in the top-right
   corner to view the **Keys** details:
   1. To get your API key, choose **API Keys**.
   2. To get your application key, choose **Application Keys**.
