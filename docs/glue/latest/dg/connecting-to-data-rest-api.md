# Connecting to a REST API

AWS Glue allows you to configure an AWS Glue ConnectionType that can be used to connect AWS Glue
to any REST API-based data source. This can be used as a data source in your ETL Jobs. You can run these jobs to
transfer data between the REST API-based data source and AWS services or other supported applications.
