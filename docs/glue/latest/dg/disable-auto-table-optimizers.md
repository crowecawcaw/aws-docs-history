# Disabling catalog-level table optimization

You can disable table optimization for new tables using
the AWS Lake Formation console, the `glue:UpdateCatalog` API.

###### To disable the table optimizations at the catalog level

1. Open the Lake Formation console at [https://console.aws.amazon.com/lakeformation/](https://console.aws.amazon.com/lakeformation/ "https://console.aws.amazon.com/lakeformation/").
2. On the left navigation bar, choose **Catalogs**.
3. On the **Catalog summary** page, choose **Edit** under **Table optimizations**.
4. On the **Edit optimization** page,
   unselect the **Optimization options**.
5. Choose **Save**.
