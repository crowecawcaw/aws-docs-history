# Creating integrations using the APIs

You can use the following APIs to create and manage Zero-ETL integrations in AWS Glue:

- CreateIntegration
- CreateIntegrationTableProperties
- CreateIntegrationResourceProperty
- UpdateIntegrationTableProperties
- UpdateIntegrationResourceProperty
- ModifyingIntegration
- DeleteIntegration
- DeleteIntegrationTableProperties
- DescribeIntegrations
- DescribeInboundIntegrations
- GetIntegrationTableProperties
- GetIntegrationResourceProperty
  For more information, see [Integration APIs in AWS Glue](aws-glue-api-integrations.md "aws-glue-api-integrations.md").
