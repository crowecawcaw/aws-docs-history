# Connecting to Salesforce Commerce Cloud

The B2C Commerce API is a collection of RESTful APIs for interacting with B2C Commerce instances. It goes by a
few different names: Salesforce Commerce API, the acronym SCAPI, or just Commerce API.

The API enables developers to build a wide range of applications: from full storefronts to custom merchant tools to
augment Business Manager. For all B2C Commerce customers, the API is available at no extra cost.

The API is broken into two main groups of APIs: Shopper APIs and Admin APIs. And within each group, they're divided into
API families and into smaller groups focused on related functionality.
