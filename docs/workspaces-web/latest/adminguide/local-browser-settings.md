# Selecting languages in user browser settings

To set a user's local browser settings, follow the appropriate steps.

- In Chrome, choose **Settings**, choose **Languages**,
  and then order the languages based on preference.
- In Firefox, choose **Settings**, **General**,
  **Language**, and select the language from the drop-down menu.
- In Edge, choose **Settings**, choose **Languages**, and
  then order the languages based on preference.
