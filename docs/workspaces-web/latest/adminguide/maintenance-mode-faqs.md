

Amazon WorkSpaces Secure Browser will no longer be open to new customers starting October 29, 2026. If you would like to use Amazon WorkSpaces Secure Browser, sign up prior to that date. Existing customers can continue to use the service as normal. For more information, see [Amazon WorkSpaces Secure Browser availability change](https://docs.aws.amazon.com/workspaces-web/latest/adminguide/workspaces-secure-browser-maintenance-mode.html). 

# FAQs
<a name="maintenance-mode-faqs"></a>

The following are answers to common questions about WorkSpaces Secure Browser maintenance mode.

What does maintenance mode mean for my existing WorkSpaces Secure Browser deployment?  
Your WorkSpaces Secure Browser portals continue to operate as they do today. You can still add or remove users, create new portals in new AWS Regions, and manage your configuration. We continue to patch Chrome images, fix security vulnerabilities, and provide the same support as before.

Will there be a sunset date for WorkSpaces Secure Browser?  
There is no sunset date at this time. In maintenance mode, the service remains fully operational for you. If we decide to discontinue the service in the future, we will give at least 12 months' notice so that you can plan and complete your migration.

Can I still create new WorkSpaces Secure Browser portals in my existing account?  
Yes. You can continue to create new portals, including in new AWS Regions, and add or remove users without restriction.

Will my pricing change?  
No. Your WorkSpaces Secure Browser pricing remains unchanged during maintenance mode.

Do I need to migrate immediately?  
No. You are not required to migrate immediately. The service remains fully operational for you. If you are evaluating alternatives, we recommend Amazon WorkSpaces Applications or a third-party enterprise secure browser.

What will no longer be available during maintenance mode?  
We will not release new features for WorkSpaces Secure Browser, and we will not expand the service to new AWS Regions. Security patches and Chrome browser updates continue.

Do the recommended alternatives offer full feature parity with WorkSpaces Secure Browser?  
Amazon WorkSpaces Applications with a self-managed Chrome image covers most WorkSpaces Secure Browser capabilities, including clipboard and download controls and URL filtering. However, inline data redaction and SSO passthrough to downstream applications require additional configuration. For details, see the Alternative solutions section. Enterprise secure browsers provide full feature parity with WorkSpaces Secure Browser.
