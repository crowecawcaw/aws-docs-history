# Example of URLs
<a name="example-urls"></a>

The following types of URLs can be provided in the AllowedUrls or BlockedUrls



| Type | Example | 
| --- | --- | 
| Domain | example.com | 
| Subdomain | login.example.com | 
| Path | example.com/myvideos | 
| Query parameter | example.com/?parameter=123 |
