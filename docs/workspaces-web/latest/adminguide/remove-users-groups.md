# Viewing or removing users and groups for your web portal

To view or remove users and groups for your web portal, use the actions available
in the **Assigned users** table. For more information, see
[Manage access to applications](../../../singlesignon/latest/userguide/manage-your-applications.md "../../../singlesignon/latest/userguide/manage-your-applications.md")

###### Note

You can't view or remove users and groups from the edit page of the WorkSpaces Secure Browserportal.
You must do this from the edit page of your IAM Identity Center console.
