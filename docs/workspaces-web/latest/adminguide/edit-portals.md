# Editing a web portal in Amazon WorkSpaces Secure Browser

To edit a web portal, follow these steps.

1. Open the WorkSpaces Secure Browser console at [https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/](https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/ "https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/").
2. Choose **WorkSpaces Secure Browser**, **Web portals**, choose your
   web portal, and then choose **Edit**.

###### Note

Changes to networking settings or timeout settings immediately end any active portal
sessions. Users are disconnected and must reconnect to begin a new session. Changes to
**Clipboard permissions**, **File transfer permissions**,
or **Print to local device** apply beginning with the first new session.
Currently active sessions aren't disconnected. Users connected to active sessions aren't
affected by the changes until they disconnect and connect to a new session.
