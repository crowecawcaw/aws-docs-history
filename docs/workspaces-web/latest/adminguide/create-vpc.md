# Creating a new VPC for Amazon WorkSpaces Secure Browser

This section describes how to use the VPC wizard to quickly create a VPC with public and private subnets. The wizard automatically creates an internet gateway, NAT gateway, and configures route tables for your subnets.

For more information about this configuration, see [VPC with public and private subnets
(NAT)](../../../vpc/latest/userguide/VPC_Scenario2.md "../../../vpc/latest/userguide/VPC_Scenario2.md").
