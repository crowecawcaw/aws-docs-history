# Web portal access for Amazon WorkSpaces Secure Browser

Your administrator can provide access to your web portal with the following options:

- You can select a link from an email or website, and then sign in with your SAML
  identity credentials.
- You can sign into your SAML identity provider (such as Okta, Ping, or Azure), and
  launch a session with one click from your SAML provider’s application home page (such as
  the Okta End User Dashboard or the Azure Myapps portal) .
