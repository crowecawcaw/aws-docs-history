# Delete data protection settings in Amazon WorkSpaces Secure Browser

You can delete data protection settings in WorkSpaces Secure Browser.

###### To delete data protection settings

1. If you have a portal associated with a data protection setting, you must first remove the
   association before deleting the data protection setting.
2. Open the WorkSpaces Secure Browser console at [https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/](https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/ "https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/").
3. Choose **data protections settings** and the data protection setting you
   want to delete from the list view.
4. Choose **Delete**.
