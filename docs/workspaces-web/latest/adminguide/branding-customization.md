# Branding customization in Amazon WorkSpaces Secure Browser

You can customize the sign-in and loading screens that appear to your end users by modifying visual elements, text content, and terms of service. Branding customization helps create a consistent experience that aligns with your organization's identity.

**Overview**

Branding customization allows you to personalize the following aspects of the user experience:

- **Visual elements** - Upload logo, favicon, and wallpaper, and select color themes to match your brand identity.
- **Text content** - Customize welcome messages, browser tab title and other optional text fields to maintain your brand voice throughout the sign-in flow. If you don't specify custom text for certain fields, default text will be used. For details, see [Customization guidelines](customization-guideline.md "customization-guideline.md").
- **Terms of service (optional)** - Add your organization's terms of service that users must acknowledge before starting a session.

###### Note

You can also customize the domain name for your portal. For details, see [Configuring custom domain for your portal](custom-domains.md "custom-domains.md").
