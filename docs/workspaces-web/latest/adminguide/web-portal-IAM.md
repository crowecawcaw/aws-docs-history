# Creating a web portal with IAM Identity Center

To create a web portal with IAM Identity Center, follow these steps.

###### To create a web portal with IAM Identity Center

1. During portal creation at **Step 4: Configure identity
   provider**, choose **AWS IAM Identity Center**.
2. Choose **Continue with IAM Identity Center**.
3. On the **Assign users and groups** page, choose the
   **Users** and/or **Groups** tab.
4. Check the box next to the user(s) or group(s) that you want to add to the
   portal.
5. After you create your portal, the users that you associated can sign into WorkSpaces Secure Browser with
   their IAM Identity Center user name and password.
