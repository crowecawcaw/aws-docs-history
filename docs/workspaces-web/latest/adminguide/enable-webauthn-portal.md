# Enabling WebAuthn redirection in portal settings

To enable WebAuthn redirection for websites accessed within the remote browser session, follow these steps.

1. Open the WorkSpaces Secure Browser console at [https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/](https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/ "https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/").
2. Choose **WorkSpaces Secure Browser**, **Web portals**, choose your
   web portal, and then choose **Edit**.
3. Navigate to the **User settings** section.
4. Under **User permissions**, set **Allow users to use local authentication in their portal session** to **Allowed**.
5. Choose **Save** to apply the configuration.
