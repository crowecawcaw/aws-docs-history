# Browser and device compatibility for Amazon WorkSpaces Secure Browser

Amazon WorkSpaces Secure Browser is powered by the Amazon DCV web browser client, which runs inside a web browser, so
no installation is required. The web browser client is supported by common web browsers, such
as Chrome and Firefox, and by major desktop operating systems, such as Windows, macOS, and
Linux.

For the most up-to-date details on web browser client support, see [Web browser
client](../../../dcv/latest/userguide/client-web.md "../../../dcv/latest/userguide/client-web.md").

###### Note

Support for webcam is currently only available in Chromium-based browsers, such as
Google Chrome and Microsoft Edge. Currently, Apple Safari and Mozilla FireFox do not support
webcam.
