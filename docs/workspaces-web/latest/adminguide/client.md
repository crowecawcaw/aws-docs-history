# Enabling user connections for Amazon WorkSpaces Secure Browser
<a name="client"></a>

WorkSpaces Secure Browser is configured to route streaming connections over the public internet. Internet connectivity is required to authenticate users and deliver the web assets that WorkSpaces Secure Browser requires to function. To allow this traffic, you must allow the domains listed in [Allowed domains for Amazon WorkSpaces Secure Browser](allowed.md).
