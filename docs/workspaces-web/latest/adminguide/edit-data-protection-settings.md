# Edit data protection settings in Amazon WorkSpaces Secure Browser

You can edit data protection settings in WorkSpaces Secure Browser.

###### To edit data protection settings

1. Open the WorkSpaces Secure Browser console at [https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/](https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/ "https://console.aws.amazon.com/workspaces-web/home?region=us-east-1#/").
2. Choose **data protections settings** and the data protection setting you
   want to edit from the list view.
3. You can update the name, description, default settings, data types (supported or custom),
   and apply confidence level or domain overrides.
4. Choose **Save**.
