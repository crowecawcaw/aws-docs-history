# Setting up URL filtering in Amazon WorkSpaces Secure Browser

You can use Chrome Policy to filter which URLs users can access from their remote browser.
Chrome Policy provides two mechanisms to filter URLs: URLAllowlist and URLBlocklist. You can use
the WorkSpaces Secure Browser console interface to configure URL filtering as a portal setting, or you can add it as
part of your custom JSON statement (either in the inline editor, or as a JSON file
upload).
