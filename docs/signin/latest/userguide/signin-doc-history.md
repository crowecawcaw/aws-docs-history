

# Document history
<a name="signin-doc-history"></a>

The following table describes important additions to the AWS Sign-In documentation. We also update the documentation frequently to address the feedback that you send us.
+ **Latest major documentation update: **August 17, 2026

| Change | Description | Date | 
| --- |--- |--- |
| [AWS Builder ID now supports multi-factor authentication for social logins](https://docs.aws.amazon.com/signin/latest/userguide/mfa-builder-id.html) | You can now register multi-factor authentication (MFA) devices for your AWS Builder ID even when you sign in with a social login. Supported social logins include Google, Apple, GitHub, and Amazon. Previously, if you used a social login, you could add a second verification factor only through your identity provider. With MFA, you get an additional layer of security when you sign in. This helps protect your AWS Builder ID even if your social login credentials are compromised. This feature is available in all AWS Regions where AWS Builder ID is available. | August 31, 2026 | 
| [Sign in with a login you already own](https://docs.aws.amazon.com/signin/latest/userguide/sign-in-project.html) | Started the release of our new AWS sign in experience. You might not be able to access this experience yet. | August 17, 2026 | 
| [Account recovery for AWS Builder ID](https://docs.aws.amazon.com/signin/latest/userguide/recover-builder-id.html) | Added [Recover access to your AWS Builder ID](https://docs.aws.amazon.com/signin/latest/userguide/recover-builder-id.html), describing self-service recovery for a forgotten password, a lost MFA device, and a social login you can no longer access. Added a recovery email that you can set up from the **Security** page. | August 17, 2026 |
