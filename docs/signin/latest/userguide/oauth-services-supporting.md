

# Services supporting OAuth
<a name="oauth-services-supporting"></a>

AWS Sign-In OAuth is available for AWS services that support OAuth authorization. The following AWS services currently support OAuth through AWS Sign-In.
+ **AWS MCP Server** – Connect AI agents and developer tools to AWS using OAuth authorization. See [AWS MCP Server](aws-mcp-server.md).
+ **AWS Glue Iceberg REST Catalog** – Allow external integration partners and third-party query engines to access your Apache Iceberg tables in the AWS Glue Data Catalog using OAuth authorization. See [AWS Glue Iceberg REST Catalog](configure-oauth-glue-iceberg-rest.md).
+ **AWS Partner Central MCP Server** – Connect AI agents and developer tools to AWS Partner Central using OAuth authorization. See [AWS Partner Central MCP Server](https://docs.aws.amazon.com/partner-central/latest/developer-guide/mcp-getting-started.html).
