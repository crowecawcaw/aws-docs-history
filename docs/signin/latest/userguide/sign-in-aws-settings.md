

# Sign in to AWS Settings
<a name="sign-in-aws-settings"></a>

**Note**  
Our new AWS experience lets you build using AWS accounts created with preconfigured defaults. If you have regulated workloads, want complete control over where your content is stored, or require advanced features right away, such as networking and security services, [sign up for AWS (advanced)](https://docs.aws.amazon.com/accounts/latest/reference/getting-started.html). [Compare sign-up options](https://docs.aws.amazon.com/accounts/latest/reference/sign-up-for-aws.html#compare-sign-up-options).

If you sign up for AWS using our new AWS experience, you can access AWS Settings. This portal lets you access all the projects you own, and projects shared with you. You can also use AWS Settings to modify your billing settings and invite team members.

## To sign in to AWS Settings
<a name="sign-in-aws-settings-tutorial"></a>

You can sign in to AWS Settings while you are already signed in to another identity in the AWS Management Console. For details, see [Signing in to multiple accounts](https://docs.aws.amazon.com/awsconsolehelpdocs/latest/gsg/multisession.html) in the *AWS Management Console Getting Started Guide*.

1. Open AWS Settings at [https://settings.aws.com](https://settings.aws.com).

1. The main sign-in page appears. Choose a login type to use.

1. You'll be redirected to the login for the provider you chose.

1. If MFA is enabled, AWS requires you to confirm your identity with an authenticator. For more information, see [Using multi-factor authentication (MFA) in AWS](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_mfa.html).

After authentication, AWS Settings opens. Choose **Project accounts** to view and access your projects.
