# Sign in to AWS Settings

###### Warning

We're currently releasing our new experience to a limited number of customers. You might not be able to access this experience yet.

If you sign up for AWS using our new AWS experience, you can access AWS Settings.
This portal lets you access all the projects you own, and projects shared
with you. You can also use AWS Settings to modify your billing settings and invite team
members.

## To sign in to AWS Settings

You can sign in to AWS Settings while you are already signed in to another identity
in the AWS Management Console. For details, see [Signing in to multiple
accounts](../../../awsconsolehelpdocs/latest/gsg/multisession.md "../../../awsconsolehelpdocs/latest/gsg/multisession.md") in the _AWS Management Console Getting Started Guide_.

1. Open AWS Settings at [https://settings.aws.com](https://settings.aws.com "https://settings.aws.com").
2. The main sign-in page appears. Choose a login type to use.
3. You'll be redirected to the login for the provider you chose.
4. If MFA is enabled, AWS requires you to confirm your identity with an authenticator.
   For more information, see [Using multi-factor authentication
   (MFA) in AWS](../../../IAM/latest/UserGuide/id_credentials_mfa.md "../../../IAM/latest/UserGuide/id_credentials_mfa.md").

After authentication, AWS Settings opens. Choose **Project
accounts** to view and access your projects.
