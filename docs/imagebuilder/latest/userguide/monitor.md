# Monitor events and logs in Image Builder

To maintain the reliability, availability, and performance of your EC2 Image Builder
pipelines, it's important to monitor events and logs. Events and logs help you
see the big picture and dive down into the details when an API call fails. Image Builder
integrate with services that can send alerts and kick off automated responses
when events match the criteria that you've configured.

The following topics describe monitoring techniques you can use through services
that integrate with Image Builder.

- [Log Image Builder API calls using CloudTrail](log-cloudtrail.md "log-cloudtrail.md")
