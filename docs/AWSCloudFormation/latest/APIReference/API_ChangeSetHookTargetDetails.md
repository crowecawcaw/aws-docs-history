# ChangeSetHookTargetDetails

Specifies target details for an activated Hook.


## Contents





**ResourceTargetDetails** 


Required if `TargetType` is `RESOURCE`.


Type: [ChangeSetHookResourceTargetDetails](API_ChangeSetHookResourceTargetDetails.md "API_ChangeSetHookResourceTargetDetails.md") object


Required: No




**TargetType** 


The name of the type.


Type: String


Valid Values: `RESOURCE`



Required: No
