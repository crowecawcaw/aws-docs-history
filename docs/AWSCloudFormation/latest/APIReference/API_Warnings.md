# Warnings

Contains any warnings returned by the `GetTemplateSummary` API action.


## Contents





**UnrecognizedResourceTypes.member.N** 


A list of all of the unrecognized resource types. This is only returned if the
 `TemplateSummaryConfig` parameter has the
 `TreatUnrecognizedResourceTypesAsWarning` configuration set to
 `True`.


Type: Array of strings


Length Constraints: Minimum length of 1. Maximum length of 256.


Required: No
