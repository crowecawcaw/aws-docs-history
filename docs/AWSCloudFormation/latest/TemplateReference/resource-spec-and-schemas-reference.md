# Resource spec and schemas reference
<a name="resource-spec-and-schemas-reference"></a>

The following topics contain compressed files (zip files) that include resource specifications and schemas for each resource type. They also contain a combined JSON "resource spec" file containing resource specifications for all resource types that CloudFormation supports. The resource spec is a machine-readable specification that you can use to build tools for creating CloudFormation templates.
