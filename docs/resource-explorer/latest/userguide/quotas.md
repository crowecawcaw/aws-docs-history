

# Quotas for Resource Explorer
<a name="quotas"></a>

Your AWS account has default quotas for each AWS service. Unless otherwise noted, quotas are Region-specific. You cannot increase the quotas for AWS Resource Explorer.

To view the quotas for AWS Resource Explorer, open the [Service Quotas console](https://console.aws.amazon.com/servicequotas/home). In the navigation pane, choose **AWS services** and select **Resource Explorer**.

The following quotas are the defaults and maximums for Resource Explorer.


| Maximum value quotas | Default value | Maximum value | 
| --- | --- | --- | 
| Number of views in an AWS Region | 10 | 10 | 


| Rate limits for operations | Default value | Maximum value | 
| --- | --- | --- | 
| Maximum Search operations per second | 5 | 5 | 
| Maximum non-Search operations per second | 3 | 3 |
