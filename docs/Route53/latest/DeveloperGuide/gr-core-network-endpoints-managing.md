

# Managing core network endpoints

You can create a core network endpoint, view its details, list the endpoints for a global resolver, update an endpoint, and delete an endpoint. You can manage core network endpoints with the AWS Management Console, the AWS CLI, or the Route 53 Global Resolver API.

**Create**  
Create a core network endpoint to connect a global resolver to a Cloud WAN core network. After you create the endpoint, the core network's segments can be used as access sources.

**Get**  
Get a core network endpoint to view its details, such as the connected core network and the endpoint's current status.

**List**  
List the core network endpoints to see every core network that a global resolver connects to.

**Update**  
Update a core network endpoint to change its configuration.

**Delete**  
Delete a core network endpoint to disconnect the global resolver from the core network. After you delete the endpoint, the core network's segments are no longer available as access sources.
