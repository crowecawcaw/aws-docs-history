# View managed rules from Palo Alto Networks

You can view the available PANW managed rule groups and their current state using the
console, API, or CLI.

###### To view managed rules using the console

Use the following procedure to view rules.

1. Open the Amazon Virtual Private Cloud console.
2. In the navigation pane, choose **DNS Firewall**, then
   choose **Rule groups**.
3. Select a rule group that contains PANW rules.
4. In the **Rules** tab, view rules with the following
   columns: Name, Action, Priority, Rule type, Resource value, Query type,
   Domain redirection setting, and Status.
