# ActionableInsights

|                                                                                    |
| ---------------------------------------------------------------------------------- |
| The AWS AppFabric for productivity feature is in preview and is subject to change. |

Contains a summary of important and suitable actions for a user based on emails,
calendar invites, messages, and tasks from their app portfolio. Users can see
proactive insights from across their applications to help them best orient their
day. These insights provide justification on why a user should care about the
insight summary along with references, such as embedded links, to individual apps
and artifacts that generated the insight.

| Parameter          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------- |
| **insightId**      | The unique id for the generated insight.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **insightContent** | This returns a summary of the insight and embedded links to<br>artifacts used to generate the insight.<br>This would be an HTML content containing embedded links<br>(`<a>` tags).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **insightTitle**   | The title of the generated insight.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **createdAt**      | When the insight was generated.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **actions**        | A list of actions recommend for the generated insight.<br>The action object contains the following parameters:<br>• `actionId` — The unique id for the<br>generated action.<br>• `actionIconUrl` — The icon URL for<br>the app that the action is suggested to be executed<br>in.<br>• `actionTitle` — The title of the<br>generated action.<br>• `actionUrl` — The unique URL for the<br>end user to view and execute the action in AppFabric’s<br>user portal.<br>For executing actions, ISV apps will re-direct users<br>to AppFabric user portal (pop up screen) using this<br>URL.<br>• `actionExecutionStatus` — An enum<br>indicating the status of the action.<br>The possible values are: `EXECUTED | <br>NOT_EXECUTED` |
