# Languages in Amazon Polly

The following languages are supported by Amazon Polly and can be used to synthesize speech. Each language has
a unique language code. These language codes are
[W3C language identification tags](https://www.w3.org/TR/ltli/#language-terminology "https://www.w3.org/TR/ltli/#language-terminology")
(`ISO 639-3` for the language name and `ISO 3166` for the country code).

Select a language from the following table for details on the phonemes and visemes that Amazon Polly provides.
