# Amazon Polly voice engines

Amazon Polly has four voice engines that convert input text into life-like speech. These
include: **Generative**,
**Long-form**, **Neural**, and **Standard**. To use an Amazon Polly voice, select an engine and a speech synthesis API
operation. Then provide input text for the engine to synthesize, and select an audio output
format. Given these inputs, Amazon Polly synthesizes the provided text into a high-quality speech
audio stream.
