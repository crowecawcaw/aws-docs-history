# Hindi (hi-IN)

The following table lists the International Phonetic Alphabet (IPA) phonemes, the
Extended Speech Assessment Methods Phonetic Alphabet (X-SAMPA) symbols, and the
phoneme's sound type for the Hindi voices that are supported by Amazon Polly.

For additional phonemes used in conjunction with Hindi, see [English (Indian) (en-IN)](ph-table-english-in.md "ph-table-english-in.md").
