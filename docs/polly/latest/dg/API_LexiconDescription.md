# LexiconDescription

Describes the content of the lexicon.

## Contents

**Attributes**

Provides lexicon metadata.

Type: [LexiconAttributes](API_LexiconAttributes.md "API_LexiconAttributes.md") object

Required: No

**Name**

Name of the lexicon.

Type: String

Pattern: `[0-9A-Za-z]{1,20}`

Required: No
