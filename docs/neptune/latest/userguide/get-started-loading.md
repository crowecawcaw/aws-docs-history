# Loading Data into an Amazon Neptune cluster

Amazon Neptune provides a process for loading data from external files directly into a
Neptune DB instance. You can use this process instead of executing a large number of
`INSERT` statements, `addV` and `addE` steps, or
other API calls.

The following are links to additional loading information.

- **Methods for loading data** – [Loading data into Amazon Neptune](load-data.md "load-data.md")
- **Data formats supported by the bulk loader** – [Load Data Formats](bulk-load-tutorial-format.md "bulk-load-tutorial-format.md")
- **Loading example** – [Example: Loading Data into a Neptune DB Instance](bulk-load-data.md "bulk-load-data.md")
