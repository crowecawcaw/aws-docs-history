

# Linkurious
<a name="visualization-Linkurious"></a>

[Linkurious](https://linkurious.com/decision-intelligence-platform-overview/) provides technical and non-technical users with a next-generation, enterprise-ready contextual decision intelligence platform powered by native graph technology.

Used by public sector agencies, Global 2000 companies, and non-profit organizations, Linkurious helps data-driven researchers, analysts, and investigators detect hidden patterns in complex connected data – and make faster, context-based decisions.

For Neptune users, Linkurious offers several advanced graph analytics and visualization software solutions enabling organizations to visualize, explore, and analyze connected data stored in Neptune database.

## Linkurious Enterprise
<a name="visualization-Linkurious-enterprise"></a>

Linkurious Enterprise is a standalone module of the Linkurious Decision Intelligence Platform. It is an off-the-shelf graph visualization and analytics software that helps users visually and intuitively harness data stored in Neptune. With its user-friendly interface, advanced analytics capabilities, and enterprise-grade security features, Linkurious Enterprise enables teams to detect complex patterns, uncover hidden connections, and accelerate decisions based on Neptune graph data.
+ **Visualize Neptune data:** Seamlessly connect to Neptune and access a 360° view of your graph data for dynamic, interactive exploration.
+ **Accelerate data analysis:** Filter results, explore timelines, switch to geo-mode, or use the no-code query builder and preset specific queries for all users to uncover meaningful insights quickly.
+ **Detect complex patterns automatically:** Use graph-based, multi-model alerts and alert deduplication to automatically surface patterns of interest in the graph and reduce triage effort.
+ **Collaborate efficiently:** Share graph views and investigation results across teams or at the organization level to support consistent, data-driven decision-making.
+ **Secure enterprise deployment:** Ensure compliance with role-based access control, LDAP/SSO integration, and audit logging.

For technical information, check out [Linkurious Enterprise documentation](https://doc.linkurious.com/admin-manual/latest/feature-map/).

## Ogma
<a name="visualization-Linkurious-ogma"></a>

[Ogma](https://doc.linkurious.com/ogma/latest/) is a commercial JavaScript library developed by Linkurious, designed for developers building powerful, large-scale interactive graph visualizations within applications leveraging Neptune data.

Key features include:
+ **High-performance rendering:** Utilize WebGL and proprietary algorithms to visualize tens of thousands of nodes almost instantly while preserving precision and quality, even with a 5-year-old GPU, ensuring smooth user experiences.
+ **Customization:** Tailor visualizations with a variety of layouts, styles, and interactive features. Enrich visualizations with embedded graph algorithms or external machine learning classifiers. Add visual overlays and in-picture annotations for human insights and collaboration.
+ **Integration:** Start quickly with extensive documentation, [tutorials](https://doc.linkurious.com/ogma/latest/tutorials/neptune-gremlin/), and a code playground. Load and transform data in minutes, integrate Ogma into your framework, and access advanced developer support.

For more detailed information and tutorials on integrating Ogma with Neptune, visit [Ogma documentation](https://doc.linkurious.com/ogma/latest/).
