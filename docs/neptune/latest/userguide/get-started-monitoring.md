# Monitoring an Amazon Neptune cluster

Amazon Neptune supports the following monitoring methods.

- **Amazon CloudWatch** – Amazon Neptune automatically sends
  metrics to CloudWatch and also supports CloudWatch Alarms. For more information, see [Monitoring Neptune Using Amazon CloudWatch](cloudwatch.md "cloudwatch.md").
- **AWS CloudTrail** – Amazon Neptune supports API logging
  using CloudTrail. For more information, see [Logging Amazon Neptune API Calls with AWS CloudTrail](cloudtrail.md "cloudtrail.md").
- **Tagging** – Use tags to add metadata to your
  Neptune resources and track usage based on tags. For more information, see [Tagging Amazon Neptune resources](tagging.md "tagging.md").
- **Audit log files** – View, download, or watch
  database log files using the Neptune console. For more information, see [Using Audit Logs with Amazon Neptune Clusters](auditing.md "auditing.md").
- **Instance status** – Check the health of a
  Neptune instance's graph database engine, find out what version of the engine is installed,
  and obtain other engine status information using the [instance
  status API](access-graph-status.md "access-graph-status.md").
