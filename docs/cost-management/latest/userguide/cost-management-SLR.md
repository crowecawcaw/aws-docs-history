# Using service-linked roles

A service-linked role is a type of service role that is linked to an AWS service.
The service can assume the role to perform an action on your behalf. Service-linked
roles appear in your AWS account and are owned by the service. An IAM administrator
can view, but not edit the permissions for service-linked roles.
