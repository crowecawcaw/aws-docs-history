# Exporting your recommendations

Use the following procedure to export your recommendations and their estimated
savings.

The exported CSV file reflects any filters that you applied on the
**Savings opportunities** page.

###### Note

The CSV download supports a maximum file size of 350 MB. If your recommendations data
exceeds this limit, use Data Exports to export your data. For more information, see [Creating a standard data export](../../../cur/latest/userguide/dataexports-create-standard.md "../../../cur/latest/userguide/dataexports-create-standard.md").

1. On the **Savings opportunities** page, choose **Download as
   CSV**.
2. This opens a new browser tab and begins the download.
3. Keep the tab open until the download is complete.
