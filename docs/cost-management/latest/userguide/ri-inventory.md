

# Viewing your Reserved Instances inventory

The Reserved Instances **Inventory** page shows a detailed overview of the Reserved Instances that you own.

If you're a user in a linked account of AWS Organizations, you can view the Reserved Instances owned by your linked account. If you're a user in the payer account of an organization, you can view Reserved Instances owned only by the payer account or Reserved Instances owned by all accounts in the organization. To change views, choose **Account inventory** or **Organization inventory**.<a name="view-ri-inventory-howto"></a>

**To view your Reserved Instances inventory**

1. Open the Billing and Cost Management console at [https://console.aws.amazon.com/costmanagement/](https://console.aws.amazon.com/costmanagement/).

1. In the navigation pane, under **Reservations**, choose **Inventory**.

The Reserved Instances table includes the following columns:
+ **Subscription ID**
+ **Reservation ID**
+ **Owning account**
+ **Account name**
+ **Status** – Active, Retired, or Pending.
+ **Service**
+ **Instance type**
+ **Platform**
+ **Quantity**
+ **Region**
+ **Scope**
+ **Offering class**
+ **Size flexibility**
+ **Term**
+ **Payment option**
+ **Effective hourly rate**
+ **Net savings (last 30 days)**
+ **Start date (UTC)**
+ **Expiration date (UTC)**
+ **Cancellation date (UTC)**
+ **Sharing preference** – The mode of the Reserved Instance's level sharing preference (Prioritized or Restricted), or `--` when it has none.

You can use a property filter to filter by the table columns. In the table preferences, you can show 25, 50, or 100 results per page, wrap lines, use striped rows, use compact mode, and select columns. You can also download the table as a CSV file.

Choose a Reserved Instance to open the **Reserved Instance details** page.

**Note**  
Reserved Instances data can take up to 48 hours to become available.
