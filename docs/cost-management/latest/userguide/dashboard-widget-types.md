# Understanding widget types

Dashboards help you monitor and analyze your AWS costs, usage, and resource commitments.
Two types of widgets are available: custom widgets that you configure from scratch to track
costs, usage, and commitment metrics, and predefined widgets that come with preset cost
breakdowns over time.

| Widget type                     | Widget name                                                                                                     | Widget description                                                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Custom                          | Cost                                                                                                            | Visualizes your aggregate costs across all AWS services, including breakdown by<br>service, Region, or custom tags. |
| Usage                           | Visualizes your aggregate usage across all AWS services, helping you track<br>resource consumption patterns.    |
| Savings Plans utilization       | Shows how well you're using your Savings Plans commitments, including unused and<br>partially used commitments. |
| Savings Plans coverage          | Shows what percentage of your usage is covered by Savings Plans.                                                |
| Reservation utilization         | Shows how well you're using your Reserved Instances.                                                            |
| Reservation coverage            | Shows what percentage of your usage is covered by Reserved Instances.                                           |
| Predefined                      | Monthly costs by service                                                                                        | Visualizes your aggregate monthly costs across all AWS services for the last<br>six months.                         |
| Monthly costs by linked account | Visualizes your aggregate monthly costs across all AWS linked accounts for the<br>last six months.              |
| Monthly EC2 running hour costs  | Visualizes your monthly EC2 running hour costs for the last six months.                                         |
| Daily costs                     | Visualizes your daily AWS costs for the last six months.                                                        |
| AWS Marketplace costs           | Visualizes your AWS Marketplace costs for the last six months.                                                  |

Each of these widgets can be customized to show the data most relevant to your needs,
allowing you to create comprehensive and insightful dashboards.
