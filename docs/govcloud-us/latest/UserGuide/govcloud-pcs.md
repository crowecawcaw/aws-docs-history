# AWS Parallel Computing Service (AWS PCS) in AWS GovCloud (US)

AWS Parallel Computing Service (AWS PCS) is a managed service that makes it easier to run and scale high
performance computing (HPC) workloads, and build scientific and engineering models on AWS using
Slurm. Use AWS PCS to build compute clusters that integrate best in class AWS compute,
storage, networking, and visualization. Run simulations or build scientific and engineering
models. Streamline and simplify your cluster operations using built-in management and
observability capabilities. Empower your users to focus on research and innovation by enabling
them to run their applications and jobs in a familiar environment.

## How AWS PCS differs for

AWS GovCloud (US)

- Accounting isn't supported.
- Amazon EC2 Capacity Blocks for ML aren't supported.
