# AWS Verified Access in AWS GovCloud (US)

AWS Verified Access provides secure access to corporate applications without a VPN
connection. It evaluates each request in real time and determines whether the user has
access to the application.

## How AWS Verified Access differs for

AWS GovCloud (US)

- Use SSL (HTTPS) when you make calls to the service in the AWS GovCloud (US) Region. In other AWS Regions, you can use HTTP or HTTPS.
