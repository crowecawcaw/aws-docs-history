# VMware Cloud on AWS in AWS GovCloud (US)

VMware Cloud on AWS brings VMware’s enterprise-class Software-Defined Data Center software to the AWS Cloud, and enables customers to run production applications in a managed service from VMware and AWS. For more information, see [VMware Cloud on AWS](https://aws.amazon.com/vmware "https://aws.amazon.com/vmware").
