# AWS Cloud Map in AWS GovCloud (US)

AWS Cloud Map is a fully managed service that you can use to create and maintain a map of the
backend services and resources that your applications depend on.

## How AWS Cloud Map differs for AWS GovCloud (US)

- Public DNS namespaces are not supported in the AWS GovCloud (US) Regions.
- Sharing namespaces using AWS Resource Access Manager (AWS RAM) is not supported.
