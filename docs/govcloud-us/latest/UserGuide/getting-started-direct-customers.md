# Onboarding to AWS GovCloud (US) (Direct

Customers)

AWS Direct Customers can follow the steps outlined in [**Configuring Your Account**](../../../en_us/govcloud-us/latest/UserGuide/configure-account.md "../../../en_us/govcloud-us/latest/UserGuide/configure-account.md") to set up their
GovCloud accounts and ensure CloudTrail is enabled.

We automatically enable AWS CloudTrail for AWS GovCloud (US) accounts, but you should also
verify that CloudTrail is enabled to store logs.
