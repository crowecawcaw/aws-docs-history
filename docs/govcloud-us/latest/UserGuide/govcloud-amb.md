# Amazon Managed Blockchain in AWS GovCloud (US)

Amazon Managed Blockchain is a fully managed service for creating and managing blockchain
networks and network resources using open-source frameworks. Blockchain allows you to build
applications where multiple parties can securely and transparently run transactions and share
data without the need for a trusted, central authority.

You can use Managed Blockchain to create scalable blockchain resources and networks quickly and
efficiently using the AWS Management Console, the AWS CLI, or the Managed Blockchain SDK.

###### Note

Only the Hyperledger Fabric framework on Amazon Managed Blockchain is currently supported
in the AWS GovCloud (US-West) Region.

## How Hyperledger Fabric on Amazon Managed Blockchain differs

for AWS GovCloud (US)
