# Set individual desktop schedules
<a name="schedule-individual-desktops"></a>

1. Choose **Actions**.   
![Virtual desktops](https://docs.aws.amazon.com/res/latest/ug/images/res-virtualdesktops.png)

1. Choose **Schedule**. 

1. Set your schedule for each day.

1. Choose **Save**.   
![Schedule desktop sessions](https://docs.aws.amazon.com/res/latest/ug/images/res-sessionschedule.jpg)
