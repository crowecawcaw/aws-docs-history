# Delete a project

To delete a project:

1. Select a project in the project list.
2. From the **Actions** menu, choose **Delete Project**.

![Projects page showing actions dropdown options](images/res-delete-project1.png) 3. A confirmation pop-up appears. Enter the name of the project, then choose
**Yes** to delete it.

![Delete projects confirmation pop-up](images/res-delete-project-confirm.png) 4. If a project is deleted, all VDI sessions associated with that project are terminated.

![Projects page under environment management with banner showing successful project deletion](images/res-delete-project3.png)
