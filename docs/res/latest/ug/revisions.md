| June 2026      | • Release version 2026.06<br>Security fixes<br>+ Fixed a security vulnerability where an authenticated user could exploit symlink handling in the File System API on the cluster manager host to read arbitrary files.<br>Enhancements<br>+ Replaced DCV broker infrastructure host with serverless Lambda-based session management, reducing infrastructure overhead and improving scalability.<br>+ Included QUIC, default schedule, and other cluster settings in snapshot restore functionality.<br>Changes<br>+ Continued migration of VDC-related APIs from the VDC infra host to the backend Lambda.<br>Bug fixes<br>+ Fixed "Create Software Stack from Session" workflow failing due to stale AD credentials, missing IAM permissions, and incompatible EC2Launch version on Windows.<br>+ Fixed Ubuntu VDI login failure caused by SSSD configuration parsing error with special characters in home directory paths.<br>+ Fixed list project owners and members in the user drop-down when sharing a Virtual Desktop.<br>+ Fixed VDI login failures on RHEL8, RHEL9, Ubuntu 22.04, and Ubuntu 24.04 caused by amazon-efs-utils build incompatibility preventing EFS /home directory mounting.<br>+ Fixed IAM policies not appearing in "add policies" dropdown when account has more than 1000 policies.<br>+ Updated default AMIs across all supported OS types and regions, resolving Linux kernel local privilege escalation vulnerability.                                                                                                                                                                                                                                                                                    |
| March 2026     | • Release version 2026.03<br>Security fixes<br>+ Fixed a privilege escalation vulnerability in the FileBrowser component.<br>+ Fixed a cross-user remote code execution vulnerability via session name injection.<br>+ Fixed an issue where an external instance profile ARN could be used when creating a session.<br>Enhancements<br>+ Support for multiple volumes from a single ONTAP filesystem.<br>+ Allow users to reset their session schedule to the system default.<br>+ Allow administrators to restart errored VDIs from the Sessions page.<br>+ Allow administrators to set instance type/family when registering a software stack.<br>+ Allow administrators to configure DCV token expiration time via the RES portal.<br>+ Allow administrators to add custom links to the web portal login page.<br>+ Added configurable DCV session validation thresholds to support environments with longer bootstrap times.<br>Changes<br>+ Continued migration of VDC-related APIs from the VDC EC2 host to the backend Lambda.<br>+ Upgraded Python to 3.12+ on infrastructure and VDI hosts.<br>+ Removed AL2 and RHEL8 from default software stacks. Existing AL2 and RHEL8 software stacks in deployed environments are unaffected but will no longer be included as defaults for new environments.<br>+ Removed unnecessary RES_Interface shortcut from VDI desktops.<br>Bug fixes<br>+ Fixed Sessions filter field.<br>+ Fixed Ubuntu 24.04 bootstrap failure caused by systemd service restart.<br>+ Fixed project deletion/creation when deploying with IAM resource prefix.<br>+ Fixed failure to mount Lustre file system on RHEL9/Rocky9 VDIs.<br>+ Fixed date range filter for list_sessions and list_shared_permissions. |
