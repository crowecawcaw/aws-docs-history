# Desktop sharing profiles

Administrators can create new profiles and customize them. These profiles can be
accessed by all users and are used when sharing a session with others. The maximum
permissions granted within these profiles cannot exceed the desktop permissions allowed
globally.

**Create Profile**

Administrators can choose **Create profile** to create a new profile.
Then they can enter a **Profile name**, a **Profile
Description**, set the desired permissions, and **Save**
their changes.

**Edit Profile**

###### To edit a profile:

1. Select the desired profile.
2. Choose **Actions**, then select **Edit**
   to modify the profile.
3. Adjust the permissions as needed.
4. Choose **Save changes**.
   Any changes made to the profile will be immediately applied to the current open
   sessions.
