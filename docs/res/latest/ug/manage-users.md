# Identity management

Research and Engineering Studio can use any SAML 2.0 compliant identity provider. To use Amazon Cognito as a native user
directory which allows users to login in to the Web portal and Linux based VDIs with Cognito
user identities, see [Setting up Amazon Cognito users](setting-up-cognito-users.md "setting-up-cognito-users.md").
If you deployed RES using the external resources or plan to use IAM Identity
center, see [Setting up single sign-on (SSO) with IAM Identity Center](sso-idc.md "sso-idc.md"). If you have your own SAML 2.0
compliant identity provider, see [Configuring your identity provider for single sign-on
(SSO)](configure-id-federation.md "configure-id-federation.md").
