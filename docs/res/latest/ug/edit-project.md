

# Edit a project
<a name="edit-project"></a>

1. Choose a project in the project list.

1. From the **Actions** menu, choose **Edit Project**.

1. Enter your updates.

   If you intend to enable budgets, see [Cost monitoring and control](cost-management.md) for more information. When you choose a budget for the project, there could be a few seconds delay for the budget dropdown options to load— if you do not see the budget you just created, choose the refresh button next to the dropdown.

   For information on **Advanced Options**, see [Add a launch template](project-launch-template.md).

1. Choose **Submit**.
