

# File Systems
<a name="file-system"></a>

![File systems](http://docs.aws.amazon.com/res/latest/ug/images/home-file-systems.png)


From the File Systems page, you can:

1. Search for file systems.

1. When a file system is selected, use the **Actions** menu to:

   1. Add the file system to a project.

   1. Remove the file system from a project

1. Onboard a new file system.

1. When a file system is selected, you can expand the pane at the bottom of the screen to view file system details.
