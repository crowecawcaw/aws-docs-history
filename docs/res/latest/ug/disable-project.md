# Disable a project
<a name="disable-project"></a>

To disable a project:

1. Choose a project in the project list.

1. From the **Actions** menu, choose **Disable Project**.  
![Projects page showing actions menu dropdown options](https://docs.aws.amazon.com/res/latest/ug/images/res-disable-project1.png)

1. If a project is disabled, all VDI sessions associated with that project are stopped. Those sessions cannot be restarted while the project is disabled.   
![Projects page showing successful disable project banner](https://docs.aws.amazon.com/res/latest/ug/images/res-disable-project2.png)
