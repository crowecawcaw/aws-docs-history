# Disable a project

To disable a project:

1. Select a project in the project list.
2. From the **Actions** menu, choose **Disable Project**.

![Projects page showing actions menu dropdown options](images/res-disable-project1.png) 3. If a project is disabled, all VDI sessions associated with that project are stopped.
Those sessions cannot be restarted while the project is disabled.

![Projects page showing successful disable project banner](images/res-disable-project2.png)
