# Dashboard
<a name="dashboard"></a>

![Session management dashboard](https://docs.aws.amazon.com/res/latest/ug/images/virtualdesktopdashboard.jpg)


The Session Management Dashboard provides administrators with a quick view into:

1. Instance types

1. Session states

1. Base OS

1. Projects

1. Availability zones

1. Software stacks

Additionally, administrators can: 

1.  Refresh the dashboard to update information.

1. Choose **View Sessions** to navigate to Sessions.
