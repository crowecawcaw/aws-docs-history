# Project management

permissions

**Update project membership**

This permission allows non-admin users who have been granted it
to add and remove users or groups from a project. It also allows
them to set the permission profile and decide the access level for
all other users and groups for that project.

![Team configurations pop-out window](images/res-update-project-membership.png)

**Update project status**

This permission allows non-admin users who have been granted it to
enable or disable a project using the **Actions**
button on the **Projects** page.

![Admin console projects window under environment management](images/res-update-project-status.png)
