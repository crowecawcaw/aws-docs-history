## ActiveMQ destination (queue and topic) metrics

###### Important

The following metrics include per-minute counts for the CloudWatch polling
period.

- `EnqueueCount`
- `ExpiredCount`
- `DequeueCount`
- `DispatchCount`
- `InFlightCount`
  For example, in a five-minute [CloudWatch period](../../../AmazonCloudWatch/latest/monitoring/cloudwatch_concepts.md#CloudWatchPeriods "../../../AmazonCloudWatch/latest/monitoring/cloudwatch_concepts.md#CloudWatchPeriods"), `EnqueueCount` has five count values, each
  for a one-minute portion of the period. The `Minimum` and
  `Maximum` statistics provide the lowest and highest per-minute
  value during the specified period.

| Metric              | Unit                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ConsumerCount`     | Count               | The number of consumers subscribed to the destination.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `EnqueueCount`      | Count               | The number of messages sent to the destination, per<br>minute.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `EnqueueTime`       | Time (milliseconds) | The end-to-end latency from when a message arrives at a broker<br>until it is delivered to a consumer.Note<br>`EnqueueTime` does not measure the end-to-end latency from when a message is sent by a producer until<br>it reaches the broker, nor the latency from when a message is received by a broker until it is acknowledged<br>by the broker. Rather, `EnqueueTime` is the number of milliseconds from the moment a message is received by the broker<br>until it is successfully delivered to a consumer. |
| `ExpiredCount`      | Count               | The number of messages that couldn't be delivered because<br>they expired, per minute.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `DispatchCount`     | Count               | The number of messages sent to consumers, per minute.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `DequeueCount`      | Count               | The number of messages acknowledged by consumers, per<br>minute.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `InFlightCount`     | Count               | The number of messages sent to consumers that have not been<br>acknowledged.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `ReceiveCount`      | Count               | The number of messages that have been received from the remote<br>broker for a duplex network connector.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `MemoryUsage`       | Percent             | The percentage of the memory limit that the destination currently<br>uses.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `ProducerCount`     | Count               | The number of producers for the destination.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `QueueSize`         | Count               | The number of messages in the queue.ImportantThis metric applies only to queues.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `TotalEnqueueCount` | Count               | The total number of messages that have been sent to the<br>broker.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `TotalDequeueCount` | Count               | The total number of messages that have been consumed by<br>clients.                                                                                                                                                                                                                                                                                                                                                                                                                                               |

###### Note

`TotalEnqueueCount` and `TotalDequeueCount` metrics
include messages for advisory topics. For more information about advisory topic
messages, see the [ActiveMQ documentation](https://activemq.apache.org/advisory-message.html "https://activemq.apache.org/advisory-message.html").

### Dimensions for ActiveMQ destination (queue and topic) metrics

| Dimension          | Description                                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Broker`           | The name of the broker.<br>NoteA single-instance broker has the suffix<br>`-1`. An active/standby broker for high<br>availability has the suffixes `-1` and<br>`-2` for its redundant pair. |
| `Topic` or `Queue` | The name of the topic or queue.                                                                                                                                                             |
| `NetworkConnector` | The name of the network connector.                                                                                                                                                          |
