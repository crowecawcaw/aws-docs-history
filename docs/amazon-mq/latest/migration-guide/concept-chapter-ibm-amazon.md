# Migrating from IBM MQ queue manager to Amazon MQ

You can migrate you IBM MQ system to Amazon MQ while keeping the same configuration.

## Terminologies

The following table is a list of common IBM MQ concepts, and how they
relate to Amazon MQ.

| **IBM MQ**                  | **Amazon MQ**                                                                                                                                                                                                                                                                                                                                              |                                    |                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Component**               | **Description**                                                                                                                                                                                                                                                                                                                                            | **Component**                      | **Description**                                                                                                                                                                                                                                                                                                                                                                                                      |
| Standard Queue Manager      | Standard Queue Manager is similar to a broker but one<br>server can have multiple IBM MQ Queue Managers                                                                                                                                                                                                                                                    | Broker                             | Broker in Amazon MQ is equivalent to IBM MQ Queue<br>Manager.                                                                                                                                                                                                                                                                                                                                                        |
| Gateway Queue Manager       | A gateway Queue Manager is used to balance the workload.<br>by routing traffic across multiple IBM MQ<br>Queue Managers.                                                                                                                                                                                                                                   | Network of Brokers                 | Amazon MQ provides [Network of Brokers](../developer-guide/network-of-brokers.md "../developer-guide/network-of-brokers.md") to route<br>traffic to multiple brokers.                                                                                                                                                                                                                                                |
| Local Queues                | A local queue is a definition of both a queue and the<br>set of messages that are associated with a queue. The<br>hosting IBM MQ Queue Manager receives<br>messages in its local queues. Local queues support<br>several IBM MQ specific properties like `put`, `get`,<br>`inhibits`, etc.                                                                 | Queues                             | This is equivalent to queues in Amazon MQ.                                                                                                                                                                                                                                                                                                                                                                           |
| Remote Queues               | Remote queues are used to refer to a queue which<br>physically exists on a different IBM MQ Queue Manager,<br>but connectivity is established using channels (Sender<br>Channel and Receiver Channel)                                                                                                                                                      | Network of Brokers                 | This is achieved using a [Network of Brokers](../developer-guide/network-of-brokers.md "../developer-guide/network-of-brokers.md"). Networks<br>of Brokers connect to one another on a Network<br>Connector. With a Netowork of Brokers, you can create connections<br>across different Regions and Availability Zones.                                                                                              |
| Alias Queues                | Alias queues are used to give a different name to a<br>different physical queue. It allows setting different<br>security settings to the same physical queue.                                                                                                                                                                                              | Composite and Virtual Destinations | Composite Destinations and Virtual destinations provide<br>the same functionality in the Amazon MQ world. You can<br>achieve this by making a minor change in a broker<br>configuration file.                                                                                                                                                                                                                        |
| Model Queues                | Acts as a template for a queue definition.                                                                                                                                                                                                                                                                                                                 | Destination Policy                 | This can be achieved using Destination Policies in the<br>broker configuration file                                                                                                                                                                                                                                                                                                                                  |
| Transmission Queues         | Used for remote queue connectivity                                                                                                                                                                                                                                                                                                                         | Network of Brokers                 | A network of Brokers provides equivalent configuration<br>using Network Connector                                                                                                                                                                                                                                                                                                                                    |
| Topics                      | Pub-Sub destination                                                                                                                                                                                                                                                                                                                                        | Topics                             | Topics in Amazon MQ                                                                                                                                                                                                                                                                                                                                                                                                  |
| Server connection channel   | Basic construct through which direct connectivity<br>from a remote application client to an MQ<br>server is established. Admins can create multiple connection channels<br>to enforce different policies. A default server<br>connection channel is created for each IBM MQ Queue<br>Manager. Allows for monitoring of connections<br>from remote clients. | Transport Connector                | Provides the details for the<br>connection point for producers and consumers to connect<br>to a broker.                                                                                                                                                                                                                                                                                                              |
| Client Connection Channel   | Client connection channel in IBM MQ allows a connection<br>mode where a config file (client connection<br>definition table, or CCDT) is kept on the client<br>application side which specifies options around<br>connecting to an IBM MQ Queue Manager. Usually, legacy<br>applications prior to JMS were written using this<br>mechanism.                 | Transport Connector                | Transport Connector provides the details for the<br>connection point for producers and consumers to connect<br>to a broker.                                                                                                                                                                                                                                                                                          |
| Channel level Firewall      | Channel level Firewall is used to blacklist/whitelist IP<br>address, protocols                                                                                                                                                                                                                                                                             | Security Group                     | With Amazon MQ, use the Security Group at the broker<br>level and use NACL at the subnet level to create a<br>firewall.                                                                                                                                                                                                                                                                                              |
| Error Logs                  | Each IBM MQ Queue Manager has a configuration around<br>transaction logs. It's similar to database logs. It has<br>a size and policy (circular/linear). Any time there is a<br>shared JMS transaction, the state is written in a log<br>file for rollback or commit.                                                                                       | Amazon CloudWatch                  | CloudWatch logs are fully integrated with Amazon MQ.<br>For more information, see [Monitoring Amazon MQ Brokers Using Amazon CloudWatch](../developer-guide/security-logging-monitoring-cloudwatch.md "../developer-guide/security-logging-monitoring-cloudwatch.md").                                                                                                                                               |
| Listener                    | A listener is an IBM MQ process that listens for<br>connections to the IBM MQ Queue Manager.                                                                                                                                                                                                                                                               | Broker Instance                    | Amazon MQ is a managed broker and acts as a listener by<br>itself.                                                                                                                                                                                                                                                                                                                                                   |
| LDAP Authentication         | IBM MQ provides out of box connectivity to LDAP and<br>group-based access to QM, queues, topics, etc. It also<br>supports fine-grained access control at queue and topic<br>levels.                                                                                                                                                                        | IAM and LDAP Authentication        | Simple authentication is available with Amazon MQ.<br>Fine-grained access is only available at the broker user<br>level. Fine-Grained Access Control at queue and topic<br>level with access options to `Get`, `Put`.<br>To learn more, see [Messaging Authentication and Authorization](../developer-guide/security-authentication-authorization.md "../developer-guide/security-authentication-authorization.md"). |
| Message channel agent (MCA) | MCA is used to enforce an alternate level of security.<br>The default configuration is at the server connection channel level.                                                                                                                                                                                                                             | Not Applicable                     | Not Applicable                                                                                                                                                                                                                                                                                                                                                                                                       |
| Channel exit programs       | Channel exit programs are programs that are called at<br>defined places in the processing sequence of a Message<br>channel agent (MCA). Users and vendors can write their<br>own channel exit programs. Some are supplied by IBM.                                                                                                                          | Plugins                            | Limited plugins supported. To learn more, see [Supported plugins for Amazon MQ for ActiveMQ](amazon-mq-supported-plugins.md "amazon-mq-supported-plugins.md")                                                                                                                                                                                                                                                        |
| Queue Manager Group         | Queue Manager Group is used to support a cluster of IBM<br>MQ Queue Managers. It is based on providing a high<br>availability but providing a set of IBM MQ Queue Manager<br>for connectivity.                                                                                                                                                             | Network of Brokers                 | Using Network of Brokers and each broker with<br>Active-Standby configuration                                                                                                                                                                                                                                                                                                                                        |
| Sender / Receiver Channels  | A message channel, a unidirectional<br>communications link between two IBM MQ Queue Managers.<br>WebSphere MQ uses message channels to transfer messages<br>between the IBM MQ Queue Managers. To send messages in<br>both directions, you must define a channel for each<br>direction.                                                                    | Network Connector                  | A duplex communication channel between 2 brokers.                                                                                                                                                                                                                                                                                                                                                                    |
