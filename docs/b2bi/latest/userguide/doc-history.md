# Document history for the AWS B2B Data Interchange User Guide

The following table describes the documentation releases for AWS B2B Data Interchange.

| Change                                                     | Description                                                                                                                                                                                                                                                                           | Date              |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- |
| Added Custom EDI Validation                                | Added the ability to customize EDI validation rules to support<br>partner-specific EDI formats. For details, see [EDI Validation](edi-validation.md "edi-validation.md").                                                                                                             | August 25, 2025   |
| EventBridge split event updates                            | Updated the EventBridge split event documentation to replace the<br>`original-is-valid` field with a new<br>`validation-status` field that provides more detailed<br>validation status information.                                                                                   | July 22, 2025     |
| Added EDI splitting feature                                | Added the ability to split large EDI files into smaller, manageable<br>pieces by transaction.                                                                                                                                                                                         | June 30, 2025     |
| Enhanced Partnership Configuration Options                 | Added new configuration options for partnerships, including<br>acknowledgment generation, time formats, line wrapping, and control<br>numbers.                                                                                                                                        | June 9, 2025      |
| Added troubleshooting section                              | Added a comprehensive troubleshooting section with solutions for common<br>issues. For details, see [Troubleshooting AWS B2B Data Interchange](troubleshooting.md "troubleshooting.md").                                                                                              | June 4, 2025      |
| Add the ability to use generative AI-assisted EDI mapping. | The AWS B2B Data Interchange generative AI-assisted EDI mapping capabilities expedite the process of<br>writing and testing bidirectional mapping code. for details, see [Generative AI-assisted EDI mapping](generative-ai-assisted-mapping.md "generative-ai-assisted-mapping.md"). | November 15, 2024 |
| Add the ability to generate X12 EDI documents              | Add the ability to generate X12 EDI documents for purposes of sending<br>transactional data to your partners. For details see [Outbound EDI](transform-outbound-variations.md "transform-outbound-variations.md").                                                                    | October 3, 2024   |
| Add the ability to return acknowledgements                 | AWS B2B Data Interchange now automatically creates return acknowledgements for all<br>inbound EDI files. For details, see [EDI acknowledgements](edi-ack.md "edi-ack.md")                                                                                                             | April 30, 2024    |
| Integrate with Amazon EventBridge                          | AWS B2B Data Interchange now automatically publishes event to Amazon EventBridge for transformation<br>operations. For details, see [Managing AWS B2B Data Interchange events using Amazon EventBridge](eventbridge.md "eventbridge.md").                                             | March 22, 2024    |
| First version of AWS B2B Data Interchange released         | This initial release includes the ability to set up and exchange<br>electronic data interchange (EDI) transactions in AWS B2B Data Interchange                                                                                                                                        | November 27, 2023 |
