

# Personas and Tenancy
<a name="personas-and-tenancy"></a>

AVX is designed from the start for multi-tenant, multi-persona operation. A single AVX deployment handles calls from a fleet operator’s drivers, an OEM’s vehicle owners, and a rental company’s customers — each in a correctly framed, correctly grounded session — with complete data isolation between tenants. At the same time, each session is shaped by a persona that determines the agent’s role framing, grounding surface, and tool access. Both dimensions — tenancy and persona — are resolved at session start from verifiable identity signals, not from client-supplied inputs.
