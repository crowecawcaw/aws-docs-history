

# Extend and Customize
<a name="extend-and-customize"></a>

AVX is designed for extensibility. New personas, specialist tools, and tenant configurations can be added without modifying the core supervisor agent, following the sub-agent-as-tool pattern described in [Agentic Architecture](agentic-architecture.md) and the STAR booking contract described later in this chapter. This chapter is a developer guide — it prescribes the extension points and shows the pattern for each.
