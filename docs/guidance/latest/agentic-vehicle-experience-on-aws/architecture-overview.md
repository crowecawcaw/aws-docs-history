

# Architecture Overview
<a name="architecture-overview"></a>

The Agentic Vehicle Experience (AVX) is a composition layer that does not store or manage vehicle data itself. AVX orchestrates three foundation platforms — Connected Mobility (CMS), the Automotive Data Platform (ADP), and Amazon Connect — into a unified AI-powered channel. A Bedrock AgentCore runtime hosts the supervisor agent and tools that translate every incoming customer interaction into structured reads and writes against those foundations.

This chapter describes the four architectural dimensions of AVX: the composition-layer model and the three foundations it integrates, the AI agent layer, the high-level request and data flow, and the deployment topology. Subsequent chapters elaborate each dimension: [Agentic Architecture](agentic-architecture.md) covers the supervisor and sub-agent mesh in depth; [Building on CMS and ADP](building-on-cms-and-adp.md) covers the cross-account data grounding pattern; [Contact Center Integration](contact-center-integration.md) covers Amazon Connect channels and the human handoff.
