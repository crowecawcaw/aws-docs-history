

# Guidance Overview
<a name="guidance-overview"></a>

Publication date: *July 2026* 

The Guidance for Agentic Vehicle Experience on AWS (AVX) is an AI-powered customer-engagement layer that composes on top of the Connected Mobility (CMS) and Automotive Data Platform (ADP) guidance accelerators to deliver multi-channel vehicle lifecycle experiences — from finding a vehicle, through ownership and service, to the end of the vehicle lifecycle.

Agentic Vehicle Experience (AVX) exposes live vehicle data from CMS and governed analytical data products from ADP through an agentic layer built on Amazon Bedrock and Amazon Connect. The result is a voice- and text-capable assistant that can triage a check-engine warning, quote a repair, book a service appointment, and hand off to a human agent — all in a single conversation.

**Note**  
AVX includes fleet-driver, consumer, retail advisor, vehicle owner, service advisor, technician, and fleet manager personas — each with its own tool catalog — together with Amazon Connect escalation capability, multi-stage booking with STAR-JSON ticket creation, and core vehicle triage workflows.
