# Products

Nutanix offers multiple integrated products to help customers move workloads into Nutanix
Cloud Clusters (NC2) on AWS. Below is a mapping of notable VMware products along with
Nutanix products that possess corresponding functionality:

| **VMWare**
| **Corresponding Nutanix product**
|
| --- | --- |
| VMWare Cloud Foundation | [Nutanix Cloud Platform™ (NCP)](https://www.nutanix.com/products/cloud-platform "https://www.nutanix.com/products/cloud-platform") |
| vSphere/ESXi | [Nutanix AHV](https://www.nutanix.com/products/ahv "https://www.nutanix.com/products/ahv") |
| vSAN | [Nutanix AOS Storage](https://www.nutanix.com/products/nutanix-cloud-infrastructure/distributed-storage "https://www.nutanix.com/products/nutanix-cloud-infrastructure/distributed-storage") |
| VMware NSX | [Flow Network Security](https://www.nutanix.com/products/flow "https://www.nutanix.com/products/flow") and [Flow Virtual Networking](https://www.nutanix.com/products/flow/networking "https://www.nutanix.com/products/flow/networking") |
| VMware vCenter | [Nutanix Prism Central](https://www.nutanix.com/products/prism "https://www.nutanix.com/products/prism") |
| VMware Aria Suite | [Nutanix Cloud Manager (NCM)](https://www.nutanix.com/products/cloud-manager "https://www.nutanix.com/products/cloud-manager") |
| VMware Aria Operations | [NCM Intelligent Operations](https://www.nutanix.com/products/cloud-manager/intelligent-operations "https://www.nutanix.com/products/cloud-manager/intelligent-operations") |
| VMware Aria Automation | [NCM Self-Service](https://www.nutanix.com/products/cloud-manager/self-service "https://www.nutanix.com/products/cloud-manager/self-service") |
| VMware Aria Operations for Networks | [Nutanix Security Central](https://www.nutanix.com/products/cloud-manager/security-central "https://www.nutanix.com/products/cloud-manager/security-central") |
