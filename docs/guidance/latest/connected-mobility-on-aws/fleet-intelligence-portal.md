

# Fleet Intelligence portal
<a name="fleet-intelligence-portal"></a>

The Fleet Intelligence portal is the fleet operator’s web application. It tracks vehicles, trips, drivers, and safety and maintenance events in real time, sends remote commands, and turns fleet data into cost, utilization, recall, and warranty decisions. This chapter covers what the portal can do, how its processing works, and the architecture that runs it, followed by its fleet intelligence features: fleet cost intelligence, dynamic fleet rebalancing, and recall and warranty management.
