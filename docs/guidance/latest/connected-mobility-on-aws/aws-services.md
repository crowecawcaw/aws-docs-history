# AWS services in this Guidance

| AWS service                                                                                                                      | Description                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS IoT Core](https://aws.amazon.com/iot-core/ "https://aws.amazon.com/iot-core/")                                              | Core. Provides secure device connectivity, authentication using X.509 certificates, and message routing for vehicle telemetry ingestion. Supports fleet provisioning and device lifecycle management. |
| [Amazon MSK](https://aws.amazon.com/msk/ "https://aws.amazon.com/msk/")                                                          | Core. Managed Kafka service for high-throughput telemetry data streaming with SCRAM authentication and multi-AZ deployment. Provides durable, ordered message delivery at automotive scale.           |
| [Amazon Kinesis Data Analytics](https://aws.amazon.com/kinesis/data-analytics/ "https://aws.amazon.com/kinesis/data-analytics/") | Core. Runs Apache Flink applications for real-time stream processing, data transformation, and routing. Supports stateful computations and exactly-once processing semantics.                         |
| [Amazon DynamoDB](https://aws.amazon.com/dynamodb/ "https://aws.amazon.com/dynamodb/")                                           | Core. NoSQL database optimized for high-throughput vehicle data storage with single-digit millisecond latency. Provides automatic scaling and point-in-time recovery.                                 |
| [Amazon Cognito](https://aws.amazon.com/cognito/ "https://aws.amazon.com/cognito/")                                              | Supporting. Provides user authentication and authorization for the fleet management web application. Supports MFA and integration with external identity providers.                                   |
| [Amazon CloudFront](https://aws.amazon.com/cloudfront/ "https://aws.amazon.com/cloudfront/")                                     | Supporting. Content delivery network for the React-based fleet management dashboard. Provides global low-latency access with edge caching.                                                            |
| [Amazon S3](https://aws.amazon.com/s3/ "https://aws.amazon.com/s3/")                                                             | Supporting. Object storage for web application assets, Flink JAR files, and data archival. Supports lifecycle policies for cost optimization.                                                         |
| [AWS Secrets Manager](https://aws.amazon.com/secrets-manager/ "https://aws.amazon.com/secrets-manager/")                         | Supporting. Securely stores and manages SCRAM credentials for MSK authentication with automatic rotation capabilities.                                                                                |
| [Amazon CloudWatch](https://aws.amazon.com/cloudwatch/ "https://aws.amazon.com/cloudwatch/")                                     | Supporting. Monitoring and observability for telemetry pipeline performance and system health. Provides metrics, logs, and alarms.                                                                    |
| [AWS Lambda](https://aws.amazon.com/lambda/ "https://aws.amazon.com/lambda/")                                                    | Supporting. Serverless compute for API endpoints, data processing, and integration functions. Enables event-driven architectures.                                                                     |
| [Amazon VPC](https://aws.amazon.com/vpc/ "https://aws.amazon.com/vpc/")                                                          | Supporting. Isolated network environment for MSK cluster and Flink applications. Provides network security with security groups and NACLs.                                                            |
