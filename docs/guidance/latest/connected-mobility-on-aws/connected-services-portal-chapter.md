

# Connected Services portal
<a name="connected-services-portal-chapter"></a>

The Connected Services portal is the vehicle maker’s web application for connected services: connectivity, the vehicle data model, software and data collection campaigns, diagnostics quality signals, manufacturing events, and the sale of vehicle data to subscribers. This chapter covers what the portal can do, how vehicle data collection works, and the architecture that runs it. Data products and third-party delivery each have their own chapter: see [Data products](data-products.md) and [Third-party data delivery](third-party-data-delivery.md).
