# Event Catalog

This section documents all safety and maintenance events generated by the simulator and detected by Flink processors.

## Safety Events

### Imminent Collision Event

| Property           | Value                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| Event Type         | IMMINENT_COLLISION                                                                               |
| Severity           | CRITICAL                                                                                         |
| Response Time      | < 5 seconds                                                                                      |
| Trigger Conditions | aeb_act == 1 AND harsh_brk > 0.4                                                                 |
| Actions            | Dispatch emergency services, alert nearby vehicles, notify fleet manager, activate hazard lights |
| Example Scenario   | Delivery truck AEB activates to avoid pedestrian                                                 |

### Rollover Risk Event

| Property           | Value                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------- |
| Event Type         | ROLLOVER_RISK                                                                               |
| Severity           | CRITICAL                                                                                    |
| Response Time      | < 5 seconds                                                                                 |
| Trigger Conditions | harsh_turn > 45 AND spd > 50 AND cargo_wt > 3000                                            |
| Actions            | Immediate speed reduction alert, stability control activation, driver coaching intervention |
| Example Scenario   | Loaded delivery van taking highway exit too fast                                            |

### Tire Blowout Event

| Property           | Value                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| Event Type         | TIRE_BLOWOUT                                                                                            |
| Severity           | HIGH                                                                                                    |
| Response Time      | < 5 seconds                                                                                             |
| Trigger Conditions | tire_fl < 20 OR tire_pressure_drop_rate > 5 PSI/min                                                     |
| Actions            | Immediate pull-over instruction, hazard light activation, roadside assistance dispatch, traffic warning |
| Example Scenario   | Front tire blowout on highway at 65mph                                                                  |

### Engine Overheat Event
