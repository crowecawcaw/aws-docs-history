# Reference

## Configuration parameters

| Parameter           | Description                        | Default   |
| ------------------- | ---------------------------------- | --------- |
| DEPLOYMENT_STAGE    | Deployment environment identifier  | dev       |
| AWS_REGION          | Target AWS region                  | us-east-1 |
| FLEET_SIZE          | Expected number of vehicles        | 100       |
| TELEMETRY_FREQUENCY | Message frequency per vehicle (Hz) | 1         |
