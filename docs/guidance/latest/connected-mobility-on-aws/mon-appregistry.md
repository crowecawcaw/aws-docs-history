

# Service Catalog AppRegistry
<a name="mon-appregistry"></a>

The Guidance registers with AWS Service Catalog AppRegistry, which groups every deployed resource under one application for centralized management, tags resources with application metadata for cost tracking, and provides resource health and cost views across the deployment.

To access it:

1. Open AWS Service Catalog in the AWS Management Console.

1. Choose **AppRegistry** in the navigation pane.

1. Select the Connected Mobility application.

1. Review resource groups, costs and operational insights.

AppRegistry answers questions about the deployment as an inventory — what exists, what it costs, how it is tagged. It does not answer whether telemetry is flowing. For that, use the alarms and log groups above.
