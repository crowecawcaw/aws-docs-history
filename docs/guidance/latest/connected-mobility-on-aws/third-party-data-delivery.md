

# Third-party data delivery
<a name="third-party-data-delivery"></a>

This chapter defines a delivery pattern for streaming vehicle and telemetry data to third-party consumers from the guidance’s Amazon MSK layer. It covers the four delivery patterns and when each fits, where cost lands, how performance and isolation are achieved, and the reliability and governance practices that make third-party delivery safe on a platform that also carries safety- and command-critical traffic. The Connected Services subscription plane described later in this chapter is the concrete implementation of this pattern that ships with this guidance today.
