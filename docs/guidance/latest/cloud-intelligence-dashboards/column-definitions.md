# Column Definitions

## summary\_view

[summary\_view](https://github.com/aws-solutions-library-samples/cloud-intelligence-dashboards-framework/blob/main/cid/builtin/core/data/queries/cid/summary_view.sql "https://github.com/aws-solutions-library-samples/cloud-intelligence-dashboards-framework/blob/main/cid/builtin/core/data/queries/cid/summary_view.sql")
is a view in Amazon Athena, created on top of Cost and Usage Report
[CUR](../../../cur/latest/userguide/what-is-cur.md "../../../cur/latest/userguide/what-is-cur.md"),
it allows users to have a concise overview of their AWS spend. It
provides aggregated insights into costs and usage across various
services and accounts.

| Column                      | Data Type   | Description                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **year**                    | string      | Year of the billing period that is covered by report.                                                                                                                                                                                                                                                                                                                                                                              |
| **month**                   | string      | Month of the billing period that is covered by report.                                                                                                                                                                                                                                                                                                                                                                             |
| **billing\_period**         | timestamp   | The start date of the billing period that<br>is covered by this report, in UTC. The format is<br>`YYYY-MM-DDTHH:mm:ssZ`.                                                                                                                                                                                                                                                                                                           |
| **usage\_date**             | timestamp   | If Start date is older than 3 months then it<br>converts into first date of month, else actual date.The start date for<br>the line item in UTC, inclusive. The format is `YYYY-MM-DDTHH:mm:ssZ`.                                                                                                                                                                                                                                   |
| **payer\_account\_id**      | string      | The account ID of the paying account. For<br>an organization in AWS Organizations, this is the account ID of the<br>management account.                                                                                                                                                                                                                                                                                            |
| **linked\_account\_id**     | string      | The account ID of the account that used<br>this line item. For organizations, this can be either the management<br>account or a member account. You can use this field to track costs or<br>usage by account.                                                                                                                                                                                                                      |
| **invoice\_id**             | string      | The ID associated with a specific line item.<br>Until the report is final, the InvoiceId is blank, generally after the<br>6th or 7th of the month (example: June data available after July 6 or<br>7).                                                                                                                                                                                                                             |
| **charge\_type**            | string      | The type of charge covered by this line item.<br>Some possible types are the following: Credit, Discount, Fee & Refund.<br>For more charge type please refer this<br>[Link](../../../cur/latest/userguide/Lineitem-columns.md#Lineitem-details-L-LineItemType "../../../cur/latest/userguide/Lineitem-columns.md#Lineitem-details-L-LineItemType").                                                                                |
| **charge\_category**        | varchar(13) | Describes charge category as<br>"running\_usage" or "non\_usage".In case of Charge type<br>"DiscountedUsage","SavingsPlanCoveredUsage" & "Usage" it converts<br>into "running\_usage" else "non\_usage".                                                                                                                                                                                                                           |
| **purchase\_option**        | varchar(11) | Describes the available purchasing<br>models for an AWS service. For example: AWS provides four main Amazon<br>EC2 instance purchasing options: On-Demand, Reserved Instances & Spot<br>Instances.                                                                                                                                                                                                                                 |
| **ri\_sp\_arn**             | string      | Provides Savings Plan and RI arn, if resource not<br>covered by SP or RI, it returns blank.                                                                                                                                                                                                                                                                                                                                        |
| **product\_code**           | string      | The code of the product measured. For example:<br>Amazon EC2 is the product code for Amazon Elastic Compute Cloud.                                                                                                                                                                                                                                                                                                                 |
| **product\_name**           | string      | Describes the full name of the AWS service. Use<br>this column to filter AWS usage by AWS service. Sample values: AWS<br>Backup, AWS Config, Amazon Registrar, Amazon Elastic File System &<br>Amazon Elastic Compute Cloud.                                                                                                                                                                                                       |
| **service**                 | string      | This identifies the specific AWS service to the<br>customer as a unique short abbreviation including Marketplace. Sample<br>values: Amazon EC2 , AWS KMS, AWS Budgets, AWS Backup & AWS Certificate<br>Manager.                                                                                                                                                                                                                    |
| **product\_family**         | string      | This describes category for the type of<br>product. Sample values: Alarm, AWS Budgets, Stopped Instance, Storage<br>Snapshot & Compute.                                                                                                                                                                                                                                                                                            |
| **usage\_type**             | string      | The usage details of the line item. For example:<br>`USW2-BoxUsage:m2.2xlarge` describes an `m2` High Memory Double<br>Extra Large instance in the US West (Oregon) Region.                                                                                                                                                                                                                                                        |
| **operation**               | string      | The specific AWS operation covered by this line<br>item. This describes the specific usage of the line item. For example: a<br>value of RunInstances indicates the operation of an Amazon EC2 instance.                                                                                                                                                                                                                            |
| **item\_description**       | string      | The description of the line item type.For<br>example: The description of a usage line item summarizes what type of<br>usage you incurred during a specific time period. For size-flexible RIs,<br>the description corresponds to the RI the benefit was applied to. If a<br>line item corresponds to a t2.micro and a t2.small RI was applied to the<br>usage, the lineItem/LineItemDescription displays t2.small.                 |
| **availability\_zone**      | string      | The Availability Zone that hosts this line<br>item. For example: us-east-1a or us-east-1b.                                                                                                                                                                                                                                                                                                                                         |
| **region**                  | string      | This describes geographical area that hosts your AWS<br>services. Use this field to analyze spend across a particular Region.<br>Sample values: eu-west-3, us-west-1, us-east-1, ap-northeast-2 &<br>sa-east-1.                                                                                                                                                                                                                    |
| **instance\_type\_family**  | string      | This describes the instance family that<br>is associated with the given usage. Sample values: t2, m4 & m3.                                                                                                                                                                                                                                                                                                                         |
| **instance\_type**          | string      | Describes the instance type, size, and family,<br>which define the CPU, networking, and storage capacity of your instance.<br>Sample values: t2.small, m4.xlarge, t2.micro, m4.large & t2.large                                                                                                                                                                                                                                    |
| **platform**                | string      | Describes the operating system of your Amazon EC2<br>instance. Sample values: Amazon Linux, Ubuntu, Windows Server, Oracle<br>Linux & FreeBSD.                                                                                                                                                                                                                                                                                     |
| **tenancy**                 | string      | Describes the type of tenancy allowed on the Amazon<br>EC2 instance. Sample values: Dedicated, Reserved, Shared, NA & Host.                                                                                                                                                                                                                                                                                                        |
| **processor**               | string      | Describes the processor on your Amazon EC2<br>instance. Sample values: High Frequency Intel Xeon E7-8880 v3 (Haswell)<br>& Intel Xeon E5-2670 & AMD EPYC 7571.                                                                                                                                                                                                                                                                     |
| **processor\_features**     | string      | Describes the processor features of your<br>instances. Sample values: Intel AVX, Intel AVX2, Intel AVX512 & Intel<br>Turbo.                                                                                                                                                                                                                                                                                                        |
| **database\_engine**        | string      | Describes which database engine is being<br>used. Sample Values: Aurora MySQL, Aurora PostgreSQL, Oracle & MySQL.                                                                                                                                                                                                                                                                                                                  |
| **product\_group**          | string      | A construct of several products that are<br>similar by definition, or grouped together. For example: the Amazon EC2<br>team can categorize their products into shared instances, dedicated<br>host, and dedicated usage.                                                                                                                                                                                                           |
| **product\_from\_location** | string      | Describes the location where the usage<br>originated from. Sample values: External, US East (N. Virginia) &<br>Global.                                                                                                                                                                                                                                                                                                             |
| **product\_to\_location**   | string      | Describes the location usage<br>destination. Sample values: External & US East (N. Virginia).                                                                                                                                                                                                                                                                                                                                      |
| **current\_generation**     | string      | Describes the instance’s generation is<br>current or not, if it is current generation instance, the record will<br>show "Yes" if not it will show "No".                                                                                                                                                                                                                                                                            |
| **legal\_entity**           | string      | The Seller of Record of a specific product or<br>service. In most cases, the invoicing entity and legal entity are the<br>same. The values might differ for third-party AWS Marketplace<br>transactions. Possible values include: Amazon Web Services, Inc. -<br>• The<br>entity that sells AWS services Amazon Web Services India Private Limited — The local Indian entity that acts as a reseller for AWS services in<br>India. |
| **billing\_entity**         | string      | Helps you identify whether your invoices or<br>transactions are for AWS Marketplace or for purchases of other AWS<br>services. Possible values include: AWS — Identifies a transaction for<br>AWS services other than in AWS Marketplace. AWS Marketplace — Identifies<br>a purchase in AWS Marketplace.                                                                                                                           |
| **pricing\_unit**           | string      | The smallest billing unit for an AWS service.<br>For example: 0.01c per API call.                                                                                                                                                                                                                                                                                                                                                  |
| **resource\_id\_count**     | bigint      | Count of Distinct ResourceIDs, whereas a<br>ResourceID is an ID of individual resource that you provisioned. For<br>example: an Amazon S3 storage bucket, an Amazon EC2 compute instance, or<br>an Amazon RDS database can each have a resource ID.                                                                                                                                                                                |
| **usage\_quantity**         | double      | Sum of the amount of usage that you incurred<br>during the specified time period. It specifically covers usage covered<br>by Savings plan and on-demand usage.                                                                                                                                                                                                                                                                     |
| **unblended\_cost**         | double      | Sum of the unblended cost, whereas the<br>UnblendedCost is the UnblendedRate multiplied by the UsageAmount.                                                                                                                                                                                                                                                                                                                        |
| **amortized\_cost**         | double      | Sum of amortized cost, the costs are<br>amortized over the billing period. This means that the costs are broken<br>out into the effective daily rate. AWS estimates your amortized costs by<br>combining your unblended costs with the amortized portion of your<br>upfront and recurring reservation fees.                                                                                                                        |
| **ri\_sp\_trueup**          | double      | In case of No Upfront or Partial Upfront<br>Savings Plans, it shows the amount of upfront fee a Savings Plan<br>subscription is costing you for the billing period in negative. The<br>initial upfront payment for All Upfront Savings Plan and Partial Upfront<br>Savings Plan amortized over the current month.                                                                                                                  |
| **ri\_sp\_upfront\_fees**   | double      | Describes upfront payment of Savings plan<br>and Reserved Instances.                                                                                                                                                                                                                                                                                                                                                               |
| **public\_cost**            | double      | Sum of the total cost for the line item based on<br>public On-Demand Instance rates. If you have SKUs with multiple<br>On-Demand public costs, the equivalent cost for the highest tier is<br>displayed. For example: services offering free-tiers or tiered pricing.                                                                                                                                                              |
