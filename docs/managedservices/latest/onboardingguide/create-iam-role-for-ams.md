# Create an IAM role for AMS to access your account

Now that you've successfully created your new AWS account, the next step in the process is to allow AMS access to
the new account to create and configure your AMS environment, and for ongoing change and provisioning requests to be fulfilled. For details,
see [Delegate Access Across AWS Accounts Using IAM Roles](../../../IAM/latest/UserGuide/tutorial_cross-account-with-roles.md "../../../IAM/latest/UserGuide/tutorial_cross-account-with-roles.md").

AWS Identity and Access Management (IAM) is a web service that helps you securely control access to AWS resources
for your users. You use IAM to control who can use your AWS resources (authentication) and what resources they can use and in what ways
(authorization).
