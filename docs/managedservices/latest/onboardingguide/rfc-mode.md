# RFC mode

RFC mode is the default mode for AMS Advanced operations plan customers. It includes a change management system with
requests for change or RFCs and a catalog of change types to use to request the addition or change that you need to your
accounts. This change management system provides a level of security in limiting who can make changes to your accounts.

For details on AMS Advanced change types, see
[What Are AMS Change Types?](../ctref/index.md "../ctref/index.md").

For details about onboarding to AMS Advanced, see
[AWS Managed Services Onboarding Introduction](index.md "index.md").

For change type example walkthroughs, see the "Additional Information" section for the relevant change type in the _AMS Advanced Change Type Reference_
[Change Types by Classification](../ctref/classifications.md "../ctref/classifications.md") section.

###### Note

RFC mode was previously called "Change Management mode" or "Standard CM mode."
