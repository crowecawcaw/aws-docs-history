# Verify API Access

AMS uses the AWS API, with some AMS-specific operations that you can read about in
the [AMS API Reference](../ApiReference-cm/index.md "../ApiReference-cm/index.md").

AWS provides several SDKs that you can access at [Tools for Amazon Web Services](https://aws.amazon.com/tools/ "https://aws.amazon.com/tools/"). If you don't
want to use an SDK, you can make direct API calls. For information on authentication, see
[Signing AWS API Requests.](../../../general/latest/gr/signing_aws_api_requests.md "../../../general/latest/gr/signing_aws_api_requests.md"). If you are not using an SDK, or making direct HTTP API
requests, you can use the AMS CLIs for Change Management (CM) and SKMS.
