# SALZ: Create a new AWS account for AMS

The five steps to creating a new AWS account for AWS Managed Services (AMS) are:

1. [Create an AWS account](create-account.md "create-account.md")
2. [Set up consolidated billing–link new account to Payer account](set-up-consolidated-billing.md "set-up-consolidated-billing.md")
3. [Configure your AWS account for AMS access](configure-aws-account-for-sent.md "configure-aws-account-for-sent.md")
4. [Secure the new account with multi-factor authentication (MFA) for the root user in AMS](sog-secure-new-account-with-mfa.md "sog-secure-new-account-with-mfa.md")
5. [Subscribe to AWS Marketplace for EPS](subscribe-to-marketplace-for-eps.md "subscribe-to-marketplace-for-eps.md")
   Please contact your customer service delivery manager (CSDM) if you have any questions.
