# Understand RFC change type classifications

The change types that you use when submitting an RFC are divided into two broad
categories:

- **Deployment**: This classification is for creating resources.
- **Management**: This classification is for updating or deleting resources. The
  **Management** category also contains change types for
  accessing instances, encrypting or sharing AMIs, and starting,stopping,rebooting, or deleting stacks.
