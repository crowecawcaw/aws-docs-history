# Tutorials

The following tutorials detail the steps to creating a two-tier stack with the High Availability (advanced) CT (ct-06mjngx5flwto), using the CLI and
using the Console. A tutorial is given for deploying a Linux Auto Scaling group (ASG) and for deploying a Windows ASG.

Descriptions for all CT options, including ChangeTypeId can be found in the [AMS Change Type Reference](../ctref/index.md "../ctref/index.md").
