# What are change types?

Change type refers to the action that an AWS Managed Services (AMS) request for change (RFC) performs and encompasses the change action itself,
and the type of change – manual vs automated. AMS has a large collection of change types not used by other Amazon web services.
You use these change types when submitting a request for change (RFC) to deploy, or manage, or gain access to, resources.
