# Incident management in AMS Developer mode

No change to incident response times. Incident resolution is a best effort for
resources provisioned outside the change management process, or resources provisioned
through change management and then altered by an account using Developer mode permissions.

###### Note

AMS service level agreement (SLA) does not apply for resources created or updated outside of the AMS change management system (requests for
change or RFCs), Developer mode included; therefore, resources updated or created in Developer mode are automatically degraded to a P3 and AMS support
is best effort.
