# RFC state change notifications

AMS offers notifications for RFC state changes by email and CloudWatch Events:

- Emails by way of the AMS Console: There is an option on the second page of the Create RFC
  wizard, where you can add up to five email addresses to be notified when
  that RFC state changes.
- CloudWatch Events: You can configure different rules and targets for CloudWatch Events to receive
  notifications for every RFC state change.
