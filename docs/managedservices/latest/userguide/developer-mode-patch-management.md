# Patch management in AMS Developer mode

Patch management is not available for resources provisioned outside of the AMS Advanced
change management process, or for resources provisioned through change management and
then altered by an account using Developer mode permissions. Patching times:

- For a critical security update: Within 10 business days of release by the vendor
  for resources provisioned through change management and then altered by an account using Developer mode permissions.
- For an important update: Within 2 months of release by the vendor for
  resources provisioned through change management and then altered by an account using Developer mode permissions.
