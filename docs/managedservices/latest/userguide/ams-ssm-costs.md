# Systems Manager pricing in AMS
<a name="ams-ssm-costs"></a>

There is no cost associated with AMS Advanced SSM document access. Runtime cost varies based on the type of SSM document, its steps, and runtime duration. For more information, refer to [AWS Systems Manager pricing](https://aws.amazon.com/systems-manager/pricing/).
