## Patch Instance Details Summary report

The Patch Instance Details Summary report provides instance details
gathered for instances that are onboarded to reporting. This is an informational report that helps
identify all the instances onboarded, account status, instance details, maintenance window coverage, maintenance
window execution time, stack details, and platform type. This report provides the following:

1. Data on the production and non-production instances of an account. Note: Production and
   non-production stage is derived from the Account Name and not from the Instance Tags.
2. Data on the distribution of instances by platform type. Note: 'N/A' platform type is when AWS Systems Manager
   can't retrieve the platform information.
3. Data on the distribution of state of instances, and the number of instances running, stopped, or terminating.
