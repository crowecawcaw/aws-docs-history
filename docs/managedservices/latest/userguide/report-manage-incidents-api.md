# Managing incidents with the AWS Support API

The [AWS Support API](../../../awssupport/latest/user/Welcome.md "../../../awssupport/latest/user/Welcome.md")
enables you to create incidents and add correspondence to them
throughout investigations of your issues and interactions with AWS Support staff. The
AWS Support API models much of the behavior of the [AWS Support Center](https://console.aws.amazon.com/support/home#/ "https://console.aws.amazon.com/support/home#/"). For more details about how you can use this AWS
support service, see [Programming an AWS Support Case](../../../awssupport/latest/user/Case_Life_Cycle.md#crebopbatecase "../../../awssupport/latest/user/Case_Life_Cycle.md#crebopbatecase").

###### Note

When using the AWS Support API, or SAPI, for AMS Advanced incidents, use this service code:
`sentinel-report-incident`.
