# Security event logging and monitoring in Accelerate

Accounts enrolled in AMS Accelerate are configured with a baseline deployment of CloudWatch
[Events](../../../AmazonCloudWatch/latest/events/WhatIsCloudWatchEvents.md "../../../AmazonCloudWatch/latest/events/WhatIsCloudWatchEvents.md") and
[Alarms](../../../AmazonCloudWatch/latest/monitoring/AlarmThatSendsEmail.md "../../../AmazonCloudWatch/latest/monitoring/AlarmThatSendsEmail.md") that have been optimized to reduce
noise and to identify indications of a true incident. AMS Accelerate also employs GuardDuty for account monitoring. For more information, see
[Monitor with GuardDuty](acc-sec-data-protect.md#acc-sec-data-protect-gd "acc-sec-data-protect.md#acc-sec-data-protect-gd").
