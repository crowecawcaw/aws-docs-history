

# Alerts from baseline monitoring in AMS
<a name="monitoring-default-metrics"></a>

Learn about AMS Accelerate monitoring defaults. For more information, see [Monitoring and event management in AMS Accelerate](acc-mon-event-mgmt.md).

The following table shows what is monitored and the default alerting thresholds. You can change the alerting thresholds with a custom configuration document, or submit a service request. For instructions on changing your custom alarm configuration, see [Changing the Accelerate alarm configuration](acc-mem-change-am.md). To receive notifications when alarms cross their threshold, in addition to AMS's standard alerting process, you can overwrite alarm configurations. For instructions, see [Accelerate Alarm Manager](acc-mem-tag-alarms.md).

Amazon CloudWatch provides extended retention of metrics. For more information, see [CloudWatch Limits](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/cloudwatch_limits.html).

**Note**  
AMS Accelerate calibrates its baseline monitoring on a periodic basis. New accounts are always onboarded with the latest baseline monitoring and the table describes the baseline monitoring for an account that is newly onboarded. AMS Accelerate updates the baseline monitoring in existing accounts on a periodic basis and you may experience a delay before the updates are in place.
