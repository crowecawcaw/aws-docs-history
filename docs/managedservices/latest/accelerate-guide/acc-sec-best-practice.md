# Security best practices in Accelerate

AMS Accelerate uses conformance packs, which provide a general-purpose compliance framework
designed to enable you to create security, operational, or cost-optimization governance checks using managed
or custom AWS Config Rules and AWS Config remediation actions. For information on how to best configure these conformance packs, see AWS Config's
[Operational Best Practices for NIST CSF](../../../config/latest/developerguide/operational-best-practices-for-nist-csf.md "../../../config/latest/developerguide/operational-best-practices-for-nist-csf.md") and
[Operational Best Practices for CIS Top 20](../../../config/latest/developerguide/operational-best-practices-for-cis_top_20.md "../../../config/latest/developerguide/operational-best-practices-for-cis_top_20.md").
