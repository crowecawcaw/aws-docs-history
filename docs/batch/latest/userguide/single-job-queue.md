

# How to add the Single job queue widget to the AWS Batch dashboard
<a name="single-job-queue"></a>

The Single job queue widget displays detailed information about a single job queue. 

To add this widget, follow these steps.

1. Open the [AWS Batch console](https://console.aws.amazon.com/batch).

1. From the navigation bar, choose the AWS Region that you want.

1. In the navigation pane, choose **Dashboard**.

1. Choose **Add widgets**.

1. For **Single job queue**, choose **Add widget**.

1. For **Job queue,** select the job queue that you want.

1. For **Job status**, choose the job statuses that you want to display.

1. (Optional) Turn off **Show connected compute environments** if you don't want to display the properties for compute environments.

1. For **Compute environment properties**, select the properties that you want.

1. Choose **Add**.
