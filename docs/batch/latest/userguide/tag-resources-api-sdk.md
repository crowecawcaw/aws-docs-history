# Manage tags using the CLI or API

Use the following AWS CLI commands or AWS Batch API operations to add, update, list, and delete the tags for your
resources.

| Tag support for AWS Batch resources | Task                                                                                                                          | API action                                                                                                                                                          | AWS CLI                                                                                                                                                                                 | AWS Tools for Windows PowerShell                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Add or overwrite one or more tags.  | [TagResource](../APIReference/API_TagResource.md "../APIReference/API_TagResource.md")                                        | [tag-resource](../../../cli/latest/reference/batch/tag-resource.md "../../../cli/latest/reference/batch/tag-resource.md")                                           | [Add-BATResourceTag](../../../powershell/latest/reference/items/Add-BATResourceTag.md "../../../powershell/latest/reference/items/Add-BATResourceTag.md")                               |
| Delete one or more tags.            | [UntagResource](../APIReference/API_UntagResource.md "../APIReference/API_UntagResource.md")                                  | [untag-resource](../../../cli/latest/reference/batch/untag-resource.md "../../../cli/latest/reference/batch/untag-resource.md")                                     | [Remove-BATResourceTag](../../../powershell/latest/reference/items/Remove-BATResourceTag.md "../../../powershell/latest/reference/items/Remove-BATResourceTag.md")                      |
| List tags for a resource            | [ListTagsForResource](../APIReference/API_ListTagsForResource.md "../APIReference/API_ListTagsForResource.md")                | [list-tags-for-resource](../../../cli/latest/reference/batch/list-tags-for-resource.md "../../../cli/latest/reference/batch/list-tags-for-resource.md")             | [Get-BATResourceTag](../../../powershell/latest/reference/items/Get-BATResourceTag.md "../../../powershell/latest/reference/items/Get-BATResourceTag.md")                               | The following examples show how to tag or untag resources using the AWS CLI. ###### Example 1: Tag an existing resource The following command tags an existing resource. ``` `aws batch tag-resource --resource-arn `resource_ARN` --tags `team`=`devs`` ``` ###### Example 2: Untag an existing resource The following command deletes a tag from an existing resource. ``` `aws batch untag-resource --resource-arn `resource_ARN` --tag-keys `tag_key`` ``` ###### Example 3: List tags for a resource The following command lists the tags associated with an existing resource. ``` `aws batch list-tags-for-resource --resource-arn `resource_ARN`` ``` Some resource-creating actions enable you to specify tags when you create the resource. The following actions support tagging on creation. |
