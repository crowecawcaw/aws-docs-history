# How to add the Job logs widget to the AWS Batch dashboard

This widget displays different logs from your jobs in one convenient location. For more
information about job logs, see [View AWS Batch job logs in CloudWatch Logs](review-job-logs.md "review-job-logs.md").

To add this widget, follow these steps.

1. Open the [AWS Batch console](https://console.aws.amazon.com/batch "https://console.aws.amazon.com/batch").
2. From the navigation bar, choose the AWS Region that you want.
3. In the navigation pane, choose **Dashboard**.
4. Choose **Add widgets**.
5. For **Job logs**, choose **Add
   widget**.
6. For **Job id**, enter the job ID for the job that you
   want.
7. Choose **Add**.
