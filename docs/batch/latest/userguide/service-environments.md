# Service environments for AWS Batch

Service environments enable AWS Batch to integrate with SageMaker AI. A service environment contains
the SageMaker AI specific configuration parameters required for AWS Batch to submit and manage SageMaker
Training jobs while providing AWS Batch's queuing, scheduling, and priority management
capabilities.

With service environments, data scientists and ML engineers can submit SageMaker Training
jobs with priorities to service job queues. This integration eliminates the need for manual
coordination of ML workloads, prevents accidental overspending, and improves resource
utilization across your organization's machine learning workflows.
