# IVS Broadcast SDK: Web Guide | Real-Time Streaming

The IVS real-time streaming Web broadcast SDK gives developers the tools to
build interactive, real-time experiences on the web. This SDK is for developers who are
building web applications with Amazon IVS.

The Web broadcast SDK enables participants to send and receive video. The SDK
supports the following operations:

- Join a stage
- Publish media to other participants in the stage
- Subscribe to media from other participants in the stage
- Manage and monitor video and audio published to the stage
- Get WebRTC statistics for each peer connection
- All operations from the IVS low-latency streaming Web broadcast SDK
  **Latest version of Web broadcast SDK:** 1.29.0 ([Release
  Notes](release-notes.md#oct02-25-broadcast-web-rt "release-notes.md#oct02-25-broadcast-web-rt"))
