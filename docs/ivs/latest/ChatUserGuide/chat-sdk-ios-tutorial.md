# IVS Chat Client Messaging SDK: iOS

Tutorial

The Amazon Interactive Video (IVS) Chat Client Messaging iOS SDK provides interfaces to
allow you to incorporate our [IVS Chat Messaging API](../chatmsgapireference/welcome.md "../chatmsgapireference/welcome.md") on
platforms using Apple’s [Swift programming
language](https://developer.apple.com/swift/ "https://developer.apple.com/swift/").

For a Chat iOS SDK tutorial, see [https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/latest/tutorials/table-of-contents/](https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/latest/tutorials/table-of-contents/ "https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/latest/tutorials/table-of-contents/").
