

# Managed Policies for IVS Chat
<a name="security-managed-policies"></a>

An AWS managed policy is a standalone policy that is created and administered by AWS. See [ Managed Policies for Amazon IVS](https://docs.aws.amazon.com/ivs/latest/LowLatencyUserGuide/security-iam-awsmanpol.html) in the *IVS Low-Latency Streaming User Guide*.
