

# IVS Chat Document History
<a name="doc-history"></a>

The following tables describe the important changes to the documentation for Amazon IVS Chat. We update the documentation frequently, for new releases and to address the feedback that you send us.

## Chat User Guide Changes
<a name="history-chat-user-guide"></a>

| Change | Description | Date | 
| --- |--- |--- |
| [iOS integration](#history-chat-user-guide) | CocoaPods is no longer used. Related documentation changes were made in [IVS Chat Client Messaging SDK: iOS Guide](https://docs.aws.amazon.com/ivs/latest/ChatUserGuide/chat-ios-getting-started.html) (in "Getting Started"). | February 13, 2026 | 
| [Chat Client Messaging SDK: iOS 1.0.1](#history-chat-user-guide) | Updated version number and artifact links in the Chat SDK guide: [iOS](https://docs.aws.amazon.com/ivs/latest/ChatUserGuide/chat-sdk-ios.html). Also see the [Release Notes](https://docs.aws.amazon.com/ivs/latest/ChatUserGuide/release-notes.html#aug08-25). | August 8, 2025 | 
| [Split out a Chat UG](#history-chat-user-guide) | Major documentation changes accompany this release. We moved chat information from the IVS Low-Latency Streaming User Guide to a new IVS Chat User Guide, located in the existing IVS Chat section of the [IVS documentation landing page](https://docs.aws.amazon.com/ivs/). <br />For other documentation changes, see [Document History (Low-Latency Streaming)](https://docs.aws.amazon.com/ivs/latest/LowLatencyUserGuide/doc-history.html). | December 28, 2023 | 
| [IVS Glossary](ivs-glossary.md) | Extended the glossary, covering IVS real-time, low-latency, and chat terms. | December 20, 2023 | 

## IVS Chat API Reference Changes

| API Change | Description | Date |

Prior history entries for those Chat API References are in [Document History (Low-Latency Streaming)](https://docs.aws.amazon.com/ivs/latest/LowLatencyUserGuide/doc-history.html). | December 28, 2023 |
