# IVS Chat Client Messaging SDK: iOS Guide

The Amazon Interactive Video (IVS) Chat Client Messaging iOS SDK provides interfaces that
allow you to incorporate our [IVS Chat Messaging API](../chatmsgapireference/welcome.md "../chatmsgapireference/welcome.md") on
platforms using Apple’s [Swift programming
language](https://developer.apple.com/swift/ "https://developer.apple.com/swift/").

**Latest version of IVS Chat Client Messaging iOS SDK:**
1.0.1 ([Release Notes](release-notes.md#aug08-25 "release-notes.md#aug08-25"))

**Reference documentation and tutorials:** For information on
the most important methods available in the Amazon IVS Chat Client Messaging iOS SDK, see
the reference documentation at: [https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/1.0.1/](https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/1.0.1/ "https://aws.github.io/amazon-ivs-chat-messaging-sdk-ios/1.0.1/"). This repository also contains various articles and tutorials.

**Sample code:** See the iOS sample repository on GitHub:
[https://github.com/aws-samples/amazon-ivs-chat-for-ios-demo](https://github.com/aws-samples/amazon-ivs-chat-for-ios-demo "https://github.com/aws-samples/amazon-ivs-chat-for-ios-demo").

**Platform requirements:** iOS 13.0 or greater is required
for development.
