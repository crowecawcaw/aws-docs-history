# What is Amazon IVS Chat?

Amazon IVS Chat is a managed, live-chat feature to go alongside live video streams.
Documentation is accessible from the [Amazon IVS
documentation landing page](../../../ivs.md "../../../ivs.md"), in the Amazon IVS Chat section:

- Chat User Guide — This document, along with all the other User Guide pages listed on the navigation pane.
- [Chat API Reference](../ChatAPIReference/Welcome.md "../ChatAPIReference/Welcome.md") — Control-plane API (HTTPS).
- [Chat Messaging API Reference](../chatmsgapireference/welcome.md "../chatmsgapireference/welcome.md") — Data-plane API (WebSocket).
- SDK References for chat clients: Android, iOS, and JavaScript.
