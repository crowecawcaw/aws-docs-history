

# Switch between projects
<a name="switch-projects"></a>

**Note**  
Our new AWS experience lets you build using AWS accounts created with preconfigured defaults. If you have regulated workloads, want complete control over where your content is stored, or require advanced features right away, such as networking and security services, [sign up for AWS (advanced)](https://docs.aws.amazon.com/accounts/latest/reference/getting-started.html). [Compare sign-up options](https://docs.aws.amazon.com/accounts/latest/reference/sign-up-for-aws.html#compare-sign-up-options).

You can only manage AWS resources for one project at a time. You can always tell which project you are in based on the name in the upper right of the AWS console.

## Switch between projects for active sessions from the AWS Management Console
<a name="switch-projects-active-sessions"></a>

**To switch between projects for active sessions from the AWS Management Console**

1. Open the [AWS Management Console](https://console.aws.amazon.com/).

1. Choose your project name on the upper right of the AWS Management Console.

1. Choose **Switch project**.

1. Under **Active sessions**, choose an active session. An active session is a session that's been signed in for up to 12 hours. The active session time can't be changed.

1. You'll be redirected to the AWS console home page for your new project.

## Switch between projects in AWS Settings
<a name="switch-projects-portal"></a>

**To switch between projects in AWS Settings**

1. Open AWS Settings at [https://settings.aws.com](https://settings.aws.com).

1. In the main navigation pane, choose the project you want to access.

1. In the navigation bar on the upper right, choose **Create and manage cloud infrastructure**.

   You'll be redirected back to the AWS Management Console for your new project.

## Switch between projects from the AWS Management Console
<a name="switch-projects-console"></a>

**To switch between projects from the AWS Management Console**

1. Open the [AWS Management Console](https://console.aws.amazon.com/).

1. Choose **Manage projects**.

1. In AWS Settings, choose the project you want to access.

1. In the navigation bar on the upper right, choose **Create and manage cloud infrastructure**.

   You'll be redirected back to the AWS Management Console for your new project.
