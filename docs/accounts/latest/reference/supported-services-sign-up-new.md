

# Supported AWS services for Sign up for AWS (new)
<a name="supported-services-sign-up-new"></a>

**Warning**  
We're currently releasing our new experience to a limited number of customers. You might not be able to access this experience yet.

When you use Sign up for AWS (new), you get access to the Free Tier. Free Tier provides access to select AWS services. You can upgrade your account to a Paid Plan to access additional AWS services and features. To learn how to upgrade your account, see [Upgrade your account in AWS Settings](upgrade-account.md).

Not every AWS service is available for Sign up for AWS (new). If a service is not listed in either of the following lists or has an unsupported feature, you must create an account by using [Sign up for AWS (advanced)](getting-started.md) or [Activate advanced AWS features](activate-advanced-features.md).
