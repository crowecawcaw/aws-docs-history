

# Earn additional credits

**Note**  
Our new AWS experience lets you build using AWS accounts created with preconfigured defaults. If you have regulated workloads, want complete control over where your content is stored, or require advanced features right away, such as networking and security services, [sign up for AWS (advanced)](https://docs.aws.amazon.com/accounts/latest/reference/getting-started.html). [Compare sign-up options](https://docs.aws.amazon.com/accounts/latest/reference/sign-up-for-aws.html#compare-sign-up-options).

If you are a new AWS customer on the Free account plan or the Paid account plan, you can earn credits by completing activities. Each activity earns USD $20 in credits, and you can choose the activities that best fit your use case. The maximum you can earn from activities is USD $100. You can still complete all of the activities to explore and learn AWS services, but you don't receive credits after you reach USD $100. You can find the activities in the **Explore AWS** widget on your AWS Console Home dashboard. These activities incur AWS service charges that are deducted from your AWS Free Tier credits.

**Activities to complete**
+ [Launch an instance using Amazon EC2](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/tutorial-launch-my-first-ec2-instance.html)
+ [Use a foundational model in the Amazon Bedrock playground](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html)
+ [Create a budget](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-create.html)
+ [Create a web app using Lambda](https://docs.aws.amazon.com/lambda/latest/dg/getting-started.html)
+ [Create an Amazon RDS database](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_GettingStarted.CreatingConnecting.MariaDB.html)
+ [Create a table using Amazon DynamoDB](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/getting-started-step-1.html)
