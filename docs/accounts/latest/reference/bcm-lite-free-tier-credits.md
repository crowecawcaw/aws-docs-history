# Earn additional credits

###### Warning

We're currently releasing our new experience to a limited number of customers. You might not be able to access this experience yet.

If you are a new AWS customer, you can earn an additional USD $100 in credits
 regardless of your account plan by completing activities. These activities assist your
 learning of AWS services. You can find the activities in the Explore AWS widget on your
 AWS Console Home dashboard. All of these activities will incur AWS service charges that
 are deducted from your AWS Free Tier credits, however when you complete each activity,
 you receive USD $20 in credits.

###### Activities to complete

- [Launch an instance using Amazon EC2](../../../AWSEC2/latest/UserGuide/tutorial-launch-my-first-ec2-instance.md "../../../AWSEC2/latest/UserGuide/tutorial-launch-my-first-ec2-instance.md")
- [Use a foundational model in the Amazon Bedrock playground](../../../bedrock/latest/userguide/getting-started.md "../../../bedrock/latest/userguide/getting-started.md")
- [Create a budget](../../../cost-management/latest/userguide/budgets-create.md "../../../cost-management/latest/userguide/budgets-create.md")
- [Create a web app using Lambda](../../../lambda/latest/dg/getting-started.md "../../../lambda/latest/dg/getting-started.md")
- [Create an Amazon RDS database](../../../AmazonRDS/latest/UserGuide/CHAP_GettingStarted.CreatingConnecting.MariaDB.md "../../../AmazonRDS/latest/UserGuide/CHAP_GettingStarted.CreatingConnecting.MariaDB.md")
