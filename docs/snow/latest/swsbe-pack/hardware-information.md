# Snow Family device hardware description

The Snowball Edge is a single unit with a built‐in rugged box. On the outside of the box is an LCD display that can be used to manage network connections and get service status information. Network and power connections are built in to the box. The device can be used to physically transport and analyze data without using the internet.

The Snowball Edge encrypts data on the device at rest and in transit. This protects your data at rest during physical transit and during network transmission. You can write Python-language Lambda functions and associate them with Amazon S3 buckets when you create an AWS Snow device job. Each function triggers when a local Amazon S3 PUT object action is run on the associated bucket on the device.

Five to ten devices can be clustered for local compute jobs, data durability, and to locally grow or shrink storage on demand.
