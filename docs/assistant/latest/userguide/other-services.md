

# Working with other AWS services
<a name="other-services"></a>

The AWS assistant works with the following AWS services. Each entry links to the topic in this guide that describes the integration.

**AWS Identity and Access Management (IAM)**  
Control who can use the AWS assistant and which actions it performs on your behalf. For more information, see [Identity and access management](security.md#security-iam) and [Identity-based policy examples for the AWS assistant](security-iam-examples.md).

**AWS Command Line Interface (AWS CLI)**  
Ask the AWS assistant to generate short AWS CLI scripts and code snippets for the AWS SDKs. For example prompts, see [Use the prompt library](using-assistant.md#prompt-library).

**AWS CloudTrail**  
Record the AWS assistant API calls as events. For more information, see [Logging and incident response](security.md#incident-response).

**Amazon CloudWatch**  
Analyze telemetry, alarms, and application health. For more information, see [Chatting about telemetry and operations](service-insights.md#operations-insights).

**AWS Cost Explorer and cost management services**  
Analyze costs, forecasts, and optimization opportunities. For more information, see [Chatting about your AWS costs](costs.md).

**AWS Key Management Service (AWS KMS)**  
Encrypt console chat and console error diagnosis data with a customer managed key. For more information, see [Key management](data-protection.md#key-management).

**AWS Organizations**  
Use service control policies and artificial intelligence services opt-out policies. For more information, see [Service control policies](security-iam-examples.md#iam-examples-scps) and [Service improvement for the AWS assistant](service-improvement.md).

**AWS Support**  
Create a support case and contact a support agent. For more information, see [Contacting AWS Support with the AWS assistant](support.md).
