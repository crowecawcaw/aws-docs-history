

# Quotas for the AWS assistant
<a name="quotas"></a>

Your use of the AWS assistant is subject to the following quotas.

## Conversation quotas
<a name="quotas-conversations"></a>


| Name | Default | Adjustable | Description | 
| --- | --- | --- | --- | 
| Saved conversations | 80 | No | The maximum number of conversations that you can save in the AWS Management Console. | 
| Inactive conversation retention | 90 days | No | The AWS assistant deletes a conversation when you don't ask a new question in it for 90 days. | 
| Message retention | 90 days | No | The AWS assistant deletes messages older than 90 days, even in an active conversation. | 

For information about conversations, see [Manage console conversations](using-assistant.md#manage-conversations).

## Usage quotas
<a name="quotas-usage"></a>


| Name | Default | Adjustable | Description | 
| --- | --- | --- | --- | 
| Free tier usage | 1,000 queries per month | No | The maximum number of queries that you can make each month at the Free tier. For pricing, see [Amazon Q Developer pricing](https://aws.amazon.com/q/developer/pricing/). | 

For information about tiers, see [[Optional] Step 3: Review Pro tier access](getting-started.md#subscription-access).
