# Regions and endpoints

This topic includes tables that show endpoints for Amazon Inspector and Amazon Inspector Scan.
It also includes tables that show which AWS Regions support Amazon Inspector features.
To view the AWS Regions where Amazon Inspector is available, see [Amazon Inspector endpoint and quotas](../../../general/latest/gr/inspector2.md "../../../general/latest/gr/inspector2.md") in the _Amazon Web Services General Reference_.
