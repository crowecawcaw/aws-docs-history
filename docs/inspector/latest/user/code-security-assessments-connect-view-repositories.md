# Viewing code repositories

The topic describes how to view code repositories in the Amazon Inspector console.

###### To view code repositories in the Amazon Inspector console

1. Sign in using your credentials, and then open the Amazon Inspector console at [https://console.aws.amazon.com/inspector/v2/home](https://console.aws.amazon.com/inspector/v2/home "https://console.aws.amazon.com/inspector/v2/home").
2. From the navigation pane, choose **Code Security**.
3. Choose **Code repositories**.
   From this tab, you can review all of your code repositories, which are listed as projects, and review basic information about them.
   This information includes the name and scan status for each project.
   You can also review the configurations associated with your projects and when your projects were last scanned.
   You can even filter your projects in the search bar.
