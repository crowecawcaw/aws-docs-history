

# Amazon Inspector Code Security

 Amazon Inspector is a vulnerability management service that automatically discovers workloads and continually scans them for software vulnerabilities and unintended network exposure. With Code Security, Amazon Inspector scans first-party application source code, third-party application dependencies, and Infrastructure as Code for vulnerabilities. With Code Security, you can also automatically create pull requests to fix Static Application Security Testing (SAST) findings that meet a minimum severity threshold you define. For more information about creating a scan configuration, see [Creating a scan configuration](code-security-assessments-create-configuration.md). You can activate Code Security in the Amazon Inspector console or with the Amazon Inspector API. Once you activate Code Security, you can create and apply a scan configuration to your code repository to determine how often and when it will be scanned. You can view, edit, and delete your scan configuration at any time. For information about the AWS Regions where Code Security is available, see [Regions and endpoints](https://docs.aws.amazon.com/inspector/latest/user/inspector_regions.html#ins-regional-feature-availability). For information about pricing, see [Amazon Inspector pricing](https://aws.amazon.com/inspector/pricing/?nc=sn&loc=3&refid=0d873978-11ec-4d4f-9e53-b563bf029726). 

 Code Security supports both public and private network connectivity for enterprise customers. For organizations with self-managed GitHub Enterprise Server or GitLab Self-Managed instances hosted in private networks, you can establish secure connections using VPC configurations or AWS CodeConnections. This allows you to scan your code repositories without opening your firewalls to the entire AWS IP address range, providing enhanced security for your enterprise infrastructure. For more information, see [Creating an integration between Amazon Inspector and GitHub Enterprise Server](code-security-assessments-connect-github-enterprise-server.md) and [Creating an integration between Amazon Inspector and GitLab Self-Managed](code-security-assessments-connect-gitlab.md).
