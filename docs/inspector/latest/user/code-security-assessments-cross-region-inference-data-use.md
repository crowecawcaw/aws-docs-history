

# Data use for service improvement

 Amazon Inspector does not use your content to develop or improve its services or to train any foundation models. Your content is used only to provide Code Security analysis to you. Amazon Inspector processes this content through Amazon Bedrock, which also does not use your inputs or outputs to train models or improve the service, and does not share them with third-party model providers. Amazon Inspector Code Security opts you out of using your content for service improvement at the service level, so you are opted out by default and do not need to take any action.
