

# Get help from AWS Support and Broadcom

Contact AWS Support or Broadcom when the troubleshooting pages in this chapter don’t resolve your problem.

## Broadcom and AWS Support guidance
<a name="broadcom-aws-support-guidance"></a>

 AWS provides support for Amazon Elastic VMware Service and its associated infrastructure services, including VMware Cloud Foundation (VCF). For VCF configuration guidance, or for issues with other VMware products such as VCF Operations, HCX or NSX, you can also contact Broadcom with your Broadcom support entitlement. For more information, see the [Broadcom Support Portal](https://support.broadcom.com/).

Amazon EVS requires an AWS Business, AWS Enterprise On-Ramp, or AWS Enterprise Support plan. For more information, see [Compare AWS Support Plans](https://aws.amazon.com/premiumsupport/plans).

## Who to contact by problem and mode
<a name="get-help-by-problem"></a>

The following table shows who to contact for each type of problem. The columns show the problem area, the contact for Self-deployed environments that run VCF 9.x and the contact for EVS-deployed environments (VCF 5.2.x).


| Problem area | VCF 9.x (Self-deployed) | VCF 5.2.x (EVS-deployed) | 
| --- | --- | --- | 
| Amazon EVS environments, hosts, connectors, entitlements, the Amazon EVS API and console, VLAN subnets, VPC networking, Amazon VPC Route Server, and the bare metal EC2 hosts |  AWS Support |  AWS Support | 
| VCF installation | You install VCF, and Amazon EVS doesn’t manage the installation. Contact AWS Support for any Amazon EVS issue. For VCF-specific requests, you can also contact Broadcom with your Broadcom support entitlement. | Amazon EVS does the initial VCF installation. Contact AWS Support. | 
| VCF configuration, and VMware products such as VCF Operations, HCX, or NSX |  AWS Support. You can also contact Broadcom with your Broadcom support entitlement. |  AWS Support. You can also contact Broadcom with your Broadcom support entitlement. | 
| VCF subscriptions and license keys | Broadcom, through the Broadcom Support Portal. | Broadcom, through the Broadcom Support Portal. | 

For the division of responsibilities between you and AWS in each mode, see [Shared responsibility and support](plan-shared-responsibility.md).

## Open a case with AWS Support
<a name="get-help-open-case"></a>

Open the case in the AWS Support Center. For the steps, see [Creating support cases and case management](https://docs.aws.amazon.com/awssupport/latest/user/case-management.html) in the * AWS Support User Guide*.

**Important**  
Don’t include passwords, secret values, or other credentials in a case.

Include the following information, so that AWS Support can find your resources:
+ The AWS Region and the environment ID
+ The host name and host ID, for a problem with a host
+ The connector ID, for a problem with a connector
+ The VM ID and the error details of the entitlement, for a problem with a Windows Server entitlement
+ The deployment mode and the VCF version of the environment
+ The command or console action that failed, the full error message, and the time when the problem started
+ The troubleshooting steps that you have already tried

## Open a case with Broadcom
<a name="get-help-broadcom-case"></a>

To open a case with Broadcom, sign in to the [Broadcom Support Portal](https://support.broadcom.com/) with the account that holds your Broadcom support entitlement. For the information that Broadcom needs, see the Broadcom Support Portal.
