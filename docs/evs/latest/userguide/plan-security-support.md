

# Plan security, support, and recovery

Amazon Elastic VMware Service is a self-managed service, so you operate the VMware software and many of the safeguards around it. Make these decisions before you deploy, in the following order.

1.  [Shared responsibility and support](plan-shared-responsibility.md). Learn what AWS manages and what you manage in each deployment mode, and where to get help.

1.  [Account permissions and guardrails](plan-account-guardrails.md). Prepare the AWS Identity and Access Management (IAM) permissions and check the account policies that can block a deployment.

1.  [Plan for resilience and recovery](plan-resilience.md). Design for availability in one Availability Zone, and plan backup and disaster recovery.

For the security controls of a running environment, see [Security in Amazon Elastic VMware Service](security.md).
