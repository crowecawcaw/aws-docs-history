

# Reference

The Plan, Deploy, and Operate chapters link to these lookup tables instead of repeating their rows. Start with [Supported VCF versions and instance types](versions-provided.md) and [VCF feature support on Amazon EVS](vcf-feature-support.md), because most design choices depend on them.

The procedures in [Deploy in Self-deployed mode](getting-started-self-deployed.md) deploy VCF 9.x. Pages in [Deploy in EVS-deployed mode](evs-deployed-overview.md) cover VCF 5.2.x. A page with no line and outside those sections covers both.

Use the following pages to look up each topic.
+  [Supported VCF versions and instance types](versions-provided.md) lists the VCF versions, ESX builds, and Amazon EC2 instance types that Amazon EVS supports.
+  [VCF feature support on Amazon EVS](vcf-feature-support.md) shows whether Amazon EVS supports a VCF feature, and under which conditions.
+  [Service quotas for Amazon EVS](service-quotas-evs.md) gives the Amazon EVS quota values and the Amazon EC2 quotas to check before you add hosts.
+  [AWS Regions for Amazon EVS](regions-reference.md) lists the AWS Regions where Amazon EVS is available.
+  [VLAN subnets, VLAN IDs, and IP addresses](vlan-subnet-reference.md) describes the VLAN subnets that Amazon EVS creates, with their size rules and MTU values.
+  [VCF Installer settings for Amazon EVS](vcf-installer-settings.md) collects the Amazon EVS settings that you enter in the VCF Installer for VCF 9.x.
+  [Use the AWS CLI, SDKs, and API with Amazon EVS](evs-api-cli-reference.md) links the AWS CLI Command Reference, the API Reference, and the AWS CloudFormation resource types.
