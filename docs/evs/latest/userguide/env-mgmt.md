# Managing Amazon EVS environments

This chapter includes the following topics to help you manage your environment.

- [VCF subscriptions](vcf-license-mgmt.md "vcf-license-mgmt.md") - Describes how VCF subscriptions works with Amazon EVS and customer responsibilities for VCF subscription management.
- [VCF versions and EC2 instance types provided by Amazon EVS](versions-provided.md "versions-provided.md") - Describes supported VCF and ESX versions and how to check version availability in Amazon EVS.
- [Amazon EVS environment lifecycle management](evs-lifecycle-mgmt.md "evs-lifecycle-mgmt.md") - Describes lifecycle management responsibilities within an Amazon EVS environment, including the underlying infrastructure management, VCF upgrade management, the ESX host lifecyle management.
- [Performing maintenance on your environment](evs-env-maintenance.md "evs-env-maintenance.md") - Describes how to perform common maintenance tasks for your Amazon EVS environment, including networking configuration, ESX host maintenance, checking environment status, and managing secret rotation schedules for your VCF credentials.
- [Create an Amazon EVS host](evs-env-create-host.md "evs-env-create-host.md") - Describes how to create an Amazon EVS host after the environment deploys and add the host to the cluster.
- [Delete an Amazon EVS host](evs-env-delete-host.md "evs-env-delete-host.md") - Describes how to delete an Amazon EVS host and remove it from the cluster.
