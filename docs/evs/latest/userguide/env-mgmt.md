

# Managing Amazon EVS environments
<a name="env-mgmt"></a>

This chapter includes the following topics to help you manage your environment.
+  [VCF subscriptions](vcf-license-mgmt.md) - Describes how VCF subscriptions works with Amazon EVS and customer responsibilities for VCF subscription management.
+  [VCF versions and EC2 instance types provided by Amazon EVS](versions-provided.md) - Describes supported VCF and ESX versions and how to check version availability in Amazon EVS.
+  [Amazon EVS environment lifecycle management](evs-lifecycle-mgmt.md) - Describes lifecycle management responsibilities within an Amazon EVS environment, including the underlying infrastructure management, VCF upgrade management, the ESX host lifecyle management.
+  [Performing maintenance on your environment](evs-env-maintenance.md) - Describes how to perform common maintenance tasks for your Amazon EVS environment, including networking configuration, ESX host maintenance, checking environment status, and managing secret rotation schedules for your VCF credentials.
+  [Create an Amazon EVS host](evs-env-create-host.md) - Describes how to create an Amazon EVS host after the environment deploys and add the host to the cluster.
+  [Delete an Amazon EVS host](evs-env-delete-host.md) - Describes how to delete an Amazon EVS host and remove it from the cluster.
+  [Create an Amazon EVS environment connector](evs-env-create-connector.md) - Describes how to create an Amazon EVS environment connector to establish a persistent connection between Amazon EVS and a VCF appliance.
+  [Update an Amazon EVS environment connector](evs-env-update-connector.md) - Describes how to update an Amazon EVS environment connector to change the appliance FQDN or Secrets Manager secret.
+  [Delete an Amazon EVS environment connector](evs-env-delete-connector.md) - Describes how to delete an Amazon EVS environment connector.
+  [Create an Amazon EVS entitlement](evs-env-create-entitlement.md) - Describes how to create an Amazon EVS entitlement to enable AWS offered Windows licensing coverage for VMs.
+  [Delete an Amazon EVS entitlement](evs-env-delete-entitlement.md) - Describes how to delete an Amazon EVS entitlement to remove AWS offered Windows licensing coverage from VMs.
+  [Configure Windows Server Activation](evs-activate-windows-server.md) - Describes how to configure Windows Server activation on VMs that have Windows Server entitlements.
+  [Access the Amazon EVS Custom Addon depot](addon-depot.md) - Describes how to access the Amazon EVS Custom Addon depot and configure it as a download source in vLCM.
