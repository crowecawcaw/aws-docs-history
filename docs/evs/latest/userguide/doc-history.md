

# Document history for the Amazon Elastic VMware Service User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Amazon Elastic VMware Service.

| Change | Description | Date | 
| --- |--- |--- |
| [Added support for instance type](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html) | Amazon EVS now supports the i7i.metal-48xl instance type for use with VMware Cloud Foundation (VCF) environments.<br />This bare-metal instance type is available across all VMware Cloud Foundation (VCF) versions. | August 27, 2026 | 
| [Added Amazon EVS Custom Addon depot topic](https://docs.aws.amazon.com/evs/latest/userguide/addon-depot.html) | Added documentation for accessing the Amazon EVS Custom Addon depot. You can use the `GetDepotUrl` API action to retrieve a depot URL and configure it as a download source in vSphere Lifecycle Manager (vLCM) to sync and install the Amazon EVS Custom Addon. | May 21, 2026 | 
| [Added support for 32 hosts per EVS environment](https://docs.aws.amazon.com/evs/latest/userguide/evs-env-create-host.html) | Amazon EVS now supports up to 32 hosts per EVS environment. | May 18, 2026 | 
| [Updated Setting up guide for Self-deployed mode](https://docs.aws.amazon.com/evs/latest/userguide/setting-up.html) | Updated the Setting up guide and the deployment prerequisite checklist to identify which setup tasks apply only when Amazon EVS installs VCF (VCF 5.2.x). In Self-deployed mode, VCF license keys and VCF management appliance DNS records are not required at environment creation time. | May 6, 2026 | 
| [Updated Getting started guide for Self-deployed mode](https://docs.aws.amazon.com/evs/latest/userguide/getting-started.html) | Updated the Getting started guide to clarify that it covers environment creation with VCF 5.2.x (where Amazon EVS installs VCF), and to reference the new Self-deployed mode guide. | May 6, 2026 | 
| [Added Self-deployed mode getting started guide](https://docs.aws.amazon.com/evs/latest/userguide/getting-started-self-deployed.html) | Amazon EVS now supports Self-deployed mode, in which Amazon EVS provisions the AWS infrastructure for your environment and you install VCF yourself. Self-deployed mode enables VCF 9.0.x and 9.1.x deployments and gives you direct control over VCF installation.<br />The new Getting started with Self-deployed mode guide covers prerequisites, environment creation with `vcfVersion=SELF_DEPLOYED`, adding hosts, installing VCF, and creating Operations Manager and SDDC Manager connectors. | May 6, 2026 | 
| [Added support for instance type](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html) | Amazon EVS now supports the i7i.metal-24xl instance type for use with VMware Cloud Foundation (VCF) environments.<br />This bare-metal instance type is available across all VMware Cloud Foundation (VCF) versions. | April 27, 2026 | 
| [Added environment connector and entitlement user guides](https://docs.aws.amazon.com/evs/latest/userguide/evs-env-create-connector.html) | Added user guides for managing Amazon EVS environment connectors and entitlements. Connectors establish a persistent connection between Amazon EVS and a VCF appliance, enabling features such as Windows License Included. Entitlements allow you to enable or remove Windows Server license coverage for virtual machines in your Amazon EVS environment. | April 20, 2026 | 
| [Updated AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Amazon EVS has updated the managed policy `AmazonEVSServiceRolePolicy` to allow the service to retrieve vCenter credentials from AWS Secrets Manager and decrypting secrets encrypted with customer-managed KMS keys. | March 23, 2026 | 
| [Release support for VCF-5.2.2](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html#current-vcf-versions) | Amazon EVS now supports VCF-5.2.2 allowing the ability to specify supported combinations of VMware Cloud Foundation (VCF) and ESX software versions when setting up your EVS environments and hosts. | January 20, 2026 | 
| [Amazon EVS released in multiple AWS Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the US West (N. California), Asia Pacific (Hyderabad), Asia Pacific (Malaysia), Canada West (Calgary), Europe (Milan), Mexico (Central), and South America (São Paulo) Regions. | December 15, 2025 | 
| [Amazon EVS released in multiple AWS Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Asia Pacific (Mumbai), Asia Pacific (Sydney), Canada (Central) and Europe (Paris) Regions. | November 6, 2025 | 
| [Amazon EVS released in Asia Pacific (Singapore) and Europe (London) Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Asia Pacific (Singapore) and Europe (London) Regions. | September 30, 2025 | 
| [Amazon EVS supports HCX migration over the public internet](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS now allows you to securely migrate and stretch your layer 2 networks from your on-premises data centers to Amazon EVS environments over the public internet. | September 18, 2025 | 
| [Updated AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Amazon EVS has updated the managed policy `AmazonEVSServiceRolePolicy` to add comprehensive resource management capabilities including EC2 instance management, EBS volume operations, and AWS Secrets Manager integration. For information, see [Amazon EVS updates to AWS managed policies](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-account-updates). | August 14, 2025 | 
| [Updated AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Updated the AWS managed policy AmazonEVSServiceRolePolicy. | August 4, 2025 | 
| [Released the environment count per AWS account quota](https://docs.aws.amazon.com/evs/latest/userguide/service-quotas-evs.html) | Amazon EVS released environment count per AWS account quota.<br />The environment count per AWS account quota represents the maximum number of Amazon EVS environments that can be created in a given account and Region. | July 8, 2025 | 
| [Amazon EVS released in the Europe (Ireland) Region](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Europe (Ireland) Region. | June 18, 2025 | 
| [Released AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | The AWS managed policy AmazonEVSServiceRolePolicy was released. | June 9, 2025 | 
| [Initial User Guide release](https://docs.aws.amazon.com/evs/latest/userguide) | The Amazon Elastic VMware Service User Guide was released.<br />The Amazon EVS User Guide describes all Amazon EVS concepts and provides instructions on using the various features with both the console and the command line interface. | June 9, 2025 |
