

# Document history for the Amazon Elastic VMware Service User Guide

The following table describes the documentation releases for Amazon Elastic VMware Service.

| Change | Description | Date | 
| --- |--- |--- |
| [EVS Deployment Orchestrator supports r7i instance types and VCF 9.1.1](https://docs.aws.amazon.com/evs/latest/userguide/deploy-with-edo.html) | The EVS Deployment Orchestrator (EDO) now deploys the `r7i.metal-24xl` and `r7i.metal-48xl` instance types, using Amazon FSx for NetApp ONTAP as the principal storage, and supports VCF 9.1.1 on every instance type. | November 16, 2026 | 
| [Combined the supported configurations into one table](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html) | Combined the supported VCF versions, ESX builds, and Amazon EC2 instance types for both deployment modes into a single table. Each row is an instance type, with one column for VCF 5.2.x in EVS-deployed mode and one column for each VCF 9.x release in Self-deployed mode. | November 4, 2026 | 
| [Added the diskless host deployment path for Self-deployed mode](https://docs.aws.amazon.com/evs/latest/userguide/getting-started-diskless.html) | Added steps to deploy VCF 9.x in Self-deployed mode on diskless hosts, such as the `r7i.metal-24xl` and `r7i.metal-48xl` instance types. The steps cover external principal storage with Amazon FSx for OpenZFS, the VCF Installer, and the deployment specification. Diskless hosts are available only in Self-deployed mode with VCF 9.x. | November 4, 2026 | 
| [Added the Troubleshooting chapter](https://docs.aws.amazon.com/evs/latest/userguide/troubleshooting.html) | Added a Troubleshooting chapter that lists common problems by area and symptom and links to the page that covers each one. It includes pages for Self-deployed deployments, environment status checks, hosts, networking, and Windows Server entitlements. | November 4, 2026 | 
| [Added the Reference chapter](https://docs.aws.amazon.com/evs/latest/userguide/reference-overview.html) | Added a Reference chapter that holds the lookup tables that the other chapters share. It covers supported VMware Cloud Foundation (VCF) versions and instance types, VCF feature support, service quotas, AWS Regions, VLAN subnets, and VCF Installer settings. | November 4, 2026 | 
| [vSAN capacity warnings in AWS Health](https://docs.aws.amazon.com/evs/latest/userguide/troubleshoot-hosts.html#troubleshoot-vsan-capacity) | You now receive an AWS Health notification when a vSAN cluster in your environment reaches the utilization warning threshold of 70%. This notification alerts you when a cluster runs low on the free capacity that vSAN needs to rebuild data. If vSAN can’t rebuild data in a timely manner, you run the risk of cascading VM failures. You also receive a notification when Amazon EVS can’t determine the vSAN capacity of a cluster. | November 2, 2026 | 
| [Restructured the Windows Server entitlements documentation](https://docs.aws.amazon.com/evs/latest/userguide/entitlements.html) | Restructured the Windows Server entitlements documentation into a dedicated section with expanded topics covering setup, maintenance, and troubleshooting. | September 11, 2026 | 
| [Added support for the `i7i.metal-48xl` instance type](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html) | Amazon EVS now supports the `i7i.metal-48xl` instance type for use with VCF environments.<br />This bare-metal instance type is available across all VCF versions. | August 27, 2026 | 
| [Added the Amazon EVS custom add-on depot topic](https://docs.aws.amazon.com/evs/latest/userguide/addon-depot.html) | Added documentation for accessing the Amazon EVS custom add-on depot. Call the `GetDepotUrl` API action to get the URL of the Amazon EVS custom add-on depot. Add the URL to vSphere Lifecycle Manager (vLCM) as a download source, and then sync and install the Amazon EVS add-on. | May 21, 2026 | 
| [Added support for 32 hosts in each environment](https://docs.aws.amazon.com/evs/latest/userguide/evs-env-create-host.html) | Amazon EVS now supports up to 32 hosts in each Amazon EVS environment. | May 18, 2026 | 
| [Updated Setting up guide for Self-deployed mode](https://docs.aws.amazon.com/evs/latest/userguide/setting-up.html) | Updated the Setting up guide and the deployment prerequisite checklist to identify which setup tasks apply only when Amazon EVS installs VCF (VCF 5.2.x). In Self-deployed mode, VCF license keys and VCF management appliance DNS records are not required at environment creation time. | May 6, 2026 | 
| [Updated Getting started guide for Self-deployed mode](https://docs.aws.amazon.com/evs/latest/userguide/getting-started.html) | Updated the Getting started guide to clarify that it covers environment creation with VCF 5.2.x (where Amazon EVS installs VCF), and to reference the new Self-deployed mode guide. | May 6, 2026 | 
| [Added Self-deployed mode getting started guide](https://docs.aws.amazon.com/evs/latest/userguide/getting-started-self-deployed.html) | Amazon EVS now supports Self-deployed mode, in which Amazon EVS provisions the AWS infrastructure for your environment and you install VCF yourself. Self-deployed mode supports VCF 9.0 and 9.1 and gives you direct control over VCF installation.<br />The new Self-deployed mode guide covers prerequisites, environment creation with `vcfVersion=SELF_DEPLOYED`, adding hosts, installing VCF, and creating Operations Manager and SDDC Manager connectors. | May 6, 2026 | 
| [Added support for the `i7i.metal-24xl` instance type](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html) | Amazon EVS now supports the `i7i.metal-24xl` instance type for use with VCF environments.<br />This bare-metal instance type is available across all VCF versions. | April 27, 2026 | 
| [Added environment connector and entitlement user guides](https://docs.aws.amazon.com/evs/latest/userguide/evs-env-create-connector.html) | Added user guides for managing Amazon EVS environment connectors and entitlements. Connectors establish a persistent connection between Amazon EVS and a VCF appliance, enabling features such as Windows License Included. With entitlements, you can enable or remove Windows Server license coverage for virtual machines in your Amazon EVS environment. | April 20, 2026 | 
| [Updated AmazonEVSServiceRolePolicy to retrieve vCenter credentials](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Amazon EVS has updated the managed policy `AmazonEVSServiceRolePolicy` to allow the service to retrieve vCenter credentials from AWS Secrets Manager and decrypt secrets encrypted with customer-managed KMS keys. | March 23, 2026 | 
| [Release support for VCF-5.2.2](https://docs.aws.amazon.com/evs/latest/userguide/versions-provided.html#current-vcf-versions) | Amazon EVS now supports VCF 5.2.2. You can specify supported combinations of VCF and ESX software versions when you create environments and add hosts. | January 20, 2026 | 
| [Amazon EVS released in seven more AWS Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the US West (N. California), Asia Pacific (Hyderabad), Asia Pacific (Malaysia), Canada West (Calgary), Europe (Milan), Mexico (Central), and South America (São Paulo) Regions. | December 15, 2025 | 
| [Amazon EVS released in four more AWS Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Asia Pacific (Mumbai), Asia Pacific (Sydney), Canada (Central), and Europe (Paris) Regions. | November 6, 2025 | 
| [Amazon EVS released in Asia Pacific (Singapore) and Europe (London) Regions](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Asia Pacific (Singapore) and Europe (London) Regions. | September 30, 2025 | 
| [Amazon EVS supports HCX migration over the public internet](https://docs.aws.amazon.com/general/latest/gr/evs.html) | You can now securely migrate and stretch your layer 2 networks from your on-premises data centers to Amazon EVS environments over the public internet. | September 18, 2025 | 
| [Updated AmazonEVSServiceRolePolicy to add resource management permissions](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Amazon EVS has updated the managed policy `AmazonEVSServiceRolePolicy` to add permissions for managing Amazon EC2 instances and Amazon EBS volumes, and for using AWS Secrets Manager. For more information, see [Amazon EVS updates to AWS managed policies](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-account-updates). | August 14, 2025 | 
| [Updated AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Updated the AWS managed policy `AmazonEVSServiceRolePolicy`. | August 4, 2025 | 
| [Released the environment count per AWS account quota](https://docs.aws.amazon.com/evs/latest/userguide/service-quotas-evs.html) | Amazon EVS added a quota for the number of environments in each account and Region.<br />The environment count per AWS account quota represents the maximum number of Amazon EVS environments that can be created in a given account and Region. | July 8, 2025 | 
| [Amazon EVS released in the Europe (Ireland) Region](https://docs.aws.amazon.com/general/latest/gr/evs.html) | Amazon EVS was released in the Europe (Ireland) Region. | June 18, 2025 | 
| [Released AmazonEVSServiceRolePolicy](https://docs.aws.amazon.com/evs/latest/userguide/security-iam-awsmanpol.html#security-iam-awsmanpol-amazonevsservicerolepolicy) | Amazon EVS released the AWS managed policy `AmazonEVSServiceRolePolicy`. | June 9, 2025 | 
| [Initial User Guide release](https://docs.aws.amazon.com/evs/latest/userguide) | The Amazon Elastic VMware Service User Guide was released.<br />The Amazon EVS User Guide describes Amazon EVS concepts and explains how to use the features in the console and with the AWS CLI. | June 9, 2025 |
