

# Use the AWS CLI, SDKs, and API with Amazon EVS

The AWS CLI, API, and AWS CloudFormation references for Amazon Elastic VMware Service give the exact command, operation, or resource property that a procedure in this guide uses.

The following table lists the references. The columns show the reference, what it documents, and where to find it.


| Reference | What it documents | Link | 
| --- | --- | --- | 
|  AWS CLI Command Reference | The `aws evs` commands, with their options and example output. |  [evs commands in the AWS CLI Command Reference](https://docs.aws.amazon.com/cli/latest/reference/evs/index.html)  | 
| Amazon EVS API Reference | The API operations, data types, parameters, and errors. The AWS SDKs use the same operations. |  [Amazon EVS API Reference](https://docs.aws.amazon.com/evs/latest/APIReference/Welcome.html)  | 
|  AWS SDKs | The language-specific SDKs that call the Amazon EVS API, and the settings that they share. |  [AWS SDKs and Tools Reference Guide](https://docs.aws.amazon.com/sdkref/latest/guide/overview.html)  | 
|  AWS CloudFormation resource types | The `AWS::EVS::Environment` resource type, with its properties and template examples. |  [Amazon Elastic VMware Service resource type reference in the AWS CloudFormation Template Reference](https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/AWS_EVS.html)  | 
| Service endpoints and quotas | The Regional endpoints, including FIPS and dual-stack endpoints, and the default quotas. |  [Amazon Elastic VMware Service endpoints and quotas in the AWS General Reference](https://docs.aws.amazon.com/general/latest/gr/evs.html)  | 

## Set up the AWS CLI
<a name="api-cli-setup"></a>

To run the `aws evs` commands in this guide, install and configure the AWS CLI. For more information, see [Set up the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-quickstart.html) in the * AWS Command Line Interface User Guide*.
