

# Windows Server entitlements
<a name="entitlements"></a>

If you have eligible Windows Server licenses with portability rights, you can bring those licenses directly to the Windows VMs running in your Amazon EVS environment. EVS Windows Server Entitlements is not needed for those VMs.

For VMs without portability rights, use Windows Server entitlements to consume Windows Server licenses directly through AWS on a pay-as-you-go basis, paying only for what you use per vCPU-hour. This section describes how Windows Server entitlements work and how to create, maintain, and delete them for your Windows VMs running in EVS. For an overview of the resources and setup workflow, see [How Windows Server entitlements work](entitlements-concepts.md).
