# Get your data in bulk

You have three options to access your data in bulk.

1. Download your data in csv format. See [CSV reports](csv-reports.md "csv-reports.md") for details.
2. Access your data via API. See the [AWS Sustainability API Reference](../APIReference.md "../APIReference.md") for details.
3. For carbon emissions, you can also create a data export to S3 via Data Exports, a product in the Billing and Cost Management console. See [What is AWS Data Exports?](../../../cur/latest/userguide/what-is-data-exports.md "../../../cur/latest/userguide/what-is-data-exports.md") for details.
