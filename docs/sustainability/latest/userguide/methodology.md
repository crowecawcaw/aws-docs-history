# Calculation methodology

The AWS Sustainability service quantifies estimated environmental impact (carbon, water) associated with the use of AWS cloud services and covers the full range of said services.

The methodologies used to calculate the impact estimates are based on industry standards and have been verified by an independent third-party.
The methodologies are updated over time based on evolving data, climate science, and more.
To see the full methodology documents for the current version of the methodologies and the third-party verification letters see [Reports](https://sustainability.aboutamazon.com/reports "https://sustainability.aboutamazon.com/reports") on the _Amazon Sustainability_ page.
When AWS releases a new version of the methodology, historical data is recalculated using the updated version to ensure accurate comparisons over time.
