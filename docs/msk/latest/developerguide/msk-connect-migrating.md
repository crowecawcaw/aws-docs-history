# Migrate to Amazon MSK Connect

This section describes how to migrate your Apache Kafka connector application to
Amazon Managed Streaming for Apache Kafka Connect (Amazon MSK Connect). To know more about the
benefits of migrating to Amazon MSK Connect, see [Benefits of using Amazon MSK Connect](msk-connect.md#msk-connect-benefits "msk-connect.md#msk-connect-benefits").

This section also describes the state management topics used by Kafka Connect and
Amazon MSK Connect and covers procedures for migrating source and sink connectors.
