# Apache Kafka versions

When you create an Amazon MSK cluster, you specify which Apache Kafka version you want
to have on it. You can also update the Apache Kafka version of an existing cluster. The topics in the chapter help you understand timelines for Kafka version support and suggestions for best practices.
