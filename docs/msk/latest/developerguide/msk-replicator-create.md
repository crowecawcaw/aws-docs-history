# Tutorial: Create an Amazon MSK Replicator

After you set up the source and target clusters, you can use those clusters to create
an Amazon MSK Replicator. Before you create the Amazon MSK Replicator, make sure you have
[IAM
permissions required to create an MSK Replicator](msk-replicator-requirements.md#replicator-role-permissions-successful "msk-replicator-requirements.md#replicator-role-permissions-successful").
