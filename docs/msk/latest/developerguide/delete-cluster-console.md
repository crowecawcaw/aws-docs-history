# Delete an Amazon MSK Provisioned cluster using the AWS Management Console

This process describes how to delete an Amazon MSK Provisioned cluster using the AWS Management Console. Before you delete a
MSK cluster, ensure that you have a backup of any important data stored in
the cluster and that there aren't any scheduled tasks dependant on the cluster. You
can't undo a MSK cluster deletion.

1. Sign in to the AWS Management Console, and open the Amazon MSK console at [https://console.aws.amazon.com/msk/home?region=us-east-1#/home/](https://console.aws.amazon.com/msk/home?region=us-east-1#/home/ "https://console.aws.amazon.com/msk/home?region=us-east-1#/home/").
2. Choose the MSK cluster that you want to delete by selecting the check box next to
   it.
3. Choose **Delete**, and then confirm deletion.
