# Create an MSK Provisioned cluster using the Amazon MSK

API

The Amazon MSK API allows you to programmatically create and manage your MSK
Provisioned cluster as part of automated infrastructure provisioning or deployment
scripts.

To create an MSK Provisioned cluster using the API, see [CreateCluster](../../1.0/apireference/clusters.md#CreateCluster "../../1.0/apireference/clusters.md#CreateCluster").
