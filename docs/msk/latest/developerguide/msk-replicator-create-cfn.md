# Create a replicator using CloudFormation or Terraform

###### AWS CloudFormation

Use the `AWS::MSK::Replicator` resource type. For the full resource reference, see [AWS::MSK::Replicator](../../../AWSCloudFormation/latest/UserGuide/aws-resource-msk-replicator.md "../../../AWSCloudFormation/latest/UserGuide/aws-resource-msk-replicator.md") in the AWS CloudFormation User Guide.

###### Terraform

Use the `aws_msk_replicator` resource. For the full resource reference, see [aws\_msk\_replicator](https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/msk_replicator "https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/msk_replicator") in the Terraform Registry.
