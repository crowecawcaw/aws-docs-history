

# Manage Channels
<a name="msk-data-delivery-iceberg-manage"></a>

**Resource states:** `CREATING`, `ACTIVE`, `UPDATING`, `DELETING`, `FAILED`, `SUSPENDING`, `SUSPENDED`. A Channel is suspended by the service when it runs into an unrecoverable error.

You can create and manage Channels in the [https://console.aws.amazon.com/msk/home?region=us-east-1\#/home/](https://console.aws.amazon.com/msk/home?region=us-east-1#/home/) or with the Amazon MSK API. For the API operations and their parameters, see the [Amazon MSK API Reference](https://docs.aws.amazon.com/MSK/2.0/APIReference/resources.html).
