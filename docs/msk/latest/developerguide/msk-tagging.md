# Tag an Amazon MSK cluster

You can assign your own metadata in the form of _tags_ to an Amazon MSK resource, such as an MSK cluster.
A tag is a key-value pair that you define for the resource. Using
tags is a simple yet powerful way to manage AWS resources and organize data, including
billing data.
