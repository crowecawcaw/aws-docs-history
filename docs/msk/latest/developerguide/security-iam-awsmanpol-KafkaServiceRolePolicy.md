# AWS managed policy:

KafkaServiceRolePolicy

You can't attach KafkaServiceRolePolicy to your IAM entities. This policy is attached
to a service-linked role that allows Amazon MSK to perform actions such as managing VPC
endpoints (connectors) on MSK clusters, managing network interfaces, and managing
cluster credentials with AWS Secrets Manager. For more information, see [Service-linked roles for
Amazon MSK](using-service-linked-roles.md "using-service-linked-roles.md").
