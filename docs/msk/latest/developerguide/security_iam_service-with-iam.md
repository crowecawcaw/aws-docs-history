# How Amazon MSK works with IAM

Before you use IAM to manage access to Amazon MSK, you should understand what
IAM features are available to use with Amazon MSK. To get a high-level view of
how Amazon MSK and other AWS services work with IAM, see [AWS Services
That Work with IAM](../../../IAM/latest/UserGuide/reference_aws-services-that-work-with-iam.md "../../../IAM/latest/UserGuide/reference_aws-services-that-work-with-iam.md") in the _IAM User Guide_.
