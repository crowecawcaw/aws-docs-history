# Step D: Deploy the VM and Install

AWS Elemental Server

After you've installed the AWS Elemental Conductor File nodes, perform these steps on each
individual blade that you're adding to the cluster in order to deploy a VM and install
the AWS Elemental Server worker software.

1. Start the VMware vSphere client and choose the option that lets you run
   the OVF Deploy wizard.

| Screen and Field                                     | Action                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Select source**                                    | Do one of these:<br>• Choose **URL** and enter the<br>network share where you placed the OVA.<br>• Choose **Local file** and browse<br>to the download directory on your workstation, then<br>select the OVA.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Review details**                                   | Make sure the value for \*_Size on disk_<br>• is<br>as expected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Accept EULAs**                                     | Accept the EULA.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Destination > Select name and folder**             | • Assign a name to the guest (the VM that you are building on<br>the physical blade).<br>• Select a folder: Select the physical blade where the guest<br>will be created.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Destination > Select storage**                     | Complete this screen as desired.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Destination > Setup networks**                     | Complete this screen as desired.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Destination > Customize template > General**       | Do the following:<br>• **Hostname**: Create a hostname<br>for this guest. For example, “conductor-file01” or<br>“conductor-file-chicago-01”. The hostname must be<br>unique among all of your AWS Elemental products.<br>• **Shut down VM after<br>installation**: Make sure you set this to<br>your preference.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Destination > Customize template > Installer**     | • Location field: enter the path and filename of the<br>AWS Elemental Server installer (.run) file. The path is to the<br>network share where you placed the installer after<br>downloading it.<br>• Installer options: enter this string<br>``<br>-s -e 2790@`<IP address of primary Conductor File node>`:2790@`<IP address of secondary Conductor File node>`<br>``<br>For example, `-s -e<br>2790@10.24.34.2:2790@10.24.34.0`<br>Where:<br>+ The `-s` option instructs the<br>installer to start the service (elemental_se)<br>automatically.<br>+ The `-e` option (and its<br>parameters) configures the worker node with the IP<br>address and port of each Conductor File node. This<br>address is used to obtain a pooled license when<br>required.<br>• License file: leave empty. |
| **Destination > Customize template ><br>Networking** | • DNS servers field: Leave blank; you will configure<br>DNS servers in the next phase of<br>configuration.<br>• eth0 field: Complete if you are using static IP<br>addresses. Leave blank if you are using DHCP.<br>• eth1 and eth2 fields: Leave blank; you will<br>configure more Ethernet devices in the next phase of<br>configuration.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Ready to complete**                                | **Power on after deployment**: Select this<br>field.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

2. Choose **Finish**. The OVA is installed, the
   guest is created, and AWS Elemental Conductor File is installed on that guest with the eth0
   configured as specified.
3. Before proceeding, take a snapshot of the VM, as described in the VMware
   vSphere help text.
4. When you've finished installing, enter the hostname of the worker node into a
   web browser and make sure that the web interface appears.
5. Repeat these steps for each worker node.
