# Gateway response types for API Gateway

API Gateway exposes the following gateway responses for customization by API developers.

| Gateway response type            | Default status code | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ACCESS_DENIED`                  | `403`               | The gateway response for authorization failure—for example, when access is denied by a<br>custom or Amazon Cognito authorizer. If the response type is unspecified,<br>this response defaults to the `DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                     |
| `API_CONFIGURATION_ERROR`        | `500`               | The gateway response for an invalid API configuration—including when an invalid<br>endpoint address is submitted, when base64 decoding fails on binary<br>data when binary support is enacted, or when integration response<br>mapping can't match any template and no default template is<br>configured. If the response type is unspecified, this response<br>defaults to the `DEFAULT_5XX` type.                                                                                                                                                                                          |
| `AUTHORIZER_CONFIGURATION_ERROR` | `500`               | The gateway response for failing to connect to a custom or<br>Amazon Cognito authorizer. If the response type is unspecified, this response<br>defaults to the `DEFAULT_5XX` type.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `AUTHORIZER_FAILURE`             | `500`               | The gateway response when a custom or Amazon Cognito authorizer failed<br>to authenticate the caller. If the response type is unspecified,<br>this response defaults to the `DEFAULT_5XX`<br>type.                                                                                                                                                                                                                                                                                                                                                                                           |
| `BAD_REQUEST_PARAMETERS`         | `400`               | The gateway response when the request parameter cannot be<br>validated according to an enabled request validator. If the response<br>type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                               |
| `BAD_REQUEST_BODY`               | `400`               | The gateway response when the request body cannot be validated<br>according to an enabled request validator. If the response type is<br>unspecified, this response defaults to the `DEFAULT_4XX`<br>type.                                                                                                                                                                                                                                                                                                                                                                                    |
| `DEFAULT_4XX`                    | Null                | The default gateway response for an unspecified response type<br>with the status code of `4XX`. Changing the status code<br>of this fallback gateway response changes the status codes of all<br>other `4XX` responses to the new value. Resetting this<br>status code to null reverts the status codes of all other<br>`4XX` responses to their original<br>values.<br>Note[AWS WAF custom responses](../../../waf/latest/developerguide/waf-custom-request-response.md "../../../waf/latest/developerguide/waf-custom-request-response.md") take precedence over custom gateway responses. |
| `DEFAULT_5XX`                    | Null                | The default gateway response for an unspecified response type<br>with a status code of `5XX`. Changing the status code of<br>this fallback gateway response changes the status codes of all other<br>`5XX` responses to the new value. Resetting this<br>status code to null reverts the status codes of all other<br>`5XX` responses to their original<br>values.                                                                                                                                                                                                                           |
| `EXPIRED_TOKEN`                  | `403`               | The gateway response for an AWS authentication token expired<br>error. If the response type is unspecified, this response defaults<br>to the `DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `INTEGRATION_FAILURE`            | `504`               | The gateway response for an integration failed error. If the<br>response type is unspecified, this response defaults to the<br>`DEFAULT_5XX` type.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `INTEGRATION_TIMEOUT`            | `504`               | The gateway response for an integration timed out error. If the<br>response type is unspecified, this response defaults to the<br>`DEFAULT_5XX` type.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `INVALID_API_KEY`                | `403`               | The gateway response for an invalid API key submitted for a<br>method requiring an API key. If the response type is unspecified,<br>this response defaults to the `DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `INVALID_SIGNATURE`              | `403`               | The gateway response for an invalid AWS signature error. If<br>the response type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `MISSING_AUTHENTICATION_TOKEN`   | `403`               | The gateway response for a missing authentication token error,<br>including the cases when the client attempts to invoke an<br>unsupported API method or resource. If the response type is<br>unspecified, this response defaults to the `DEFAULT_4XX`<br>type.                                                                                                                                                                                                                                                                                                                              |
| `QUOTA_EXCEEDED`                 | `429`               | The gateway response for the usage plan quota exceeded error.<br>If the response type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `REQUEST_TOO_LARGE`              | `413`               | The gateway response for the request too large error. If the<br>response type is unspecified, this<br>response defaults to: `HTTP content length exceeded 10485760 bytes`.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `RESOURCE_NOT_FOUND`             | `404`               | The gateway response when API Gateway cannot find the specified<br>resource after an API request passes authentication and<br>authorization, except for API key authentication and authorization.<br>If the response type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                               |
| `THROTTLED`                      | `429`               | The gateway response when usage plan-, method-, stage-, or<br>account-level throttling limits exceeded. If the response type is<br>unspecified, this response defaults to the `DEFAULT_4XX`<br>type.                                                                                                                                                                                                                                                                                                                                                                                         |
| `UNAUTHORIZED`                   | `401`               | The gateway response when the custom or Amazon Cognito authorizer failed<br>to authenticate the caller.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `UNSUPPORTED_MEDIA_TYPE`         | `415`               | The gateway response when a payload is of an unsupported media<br>type, if strict passthrough behavior is enabled. If the response<br>type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.                                                                                                                                                                                                                                                                                                                                                                              |
| `WAF_FILTERED`                   | `403`               | The gateway response when a request is blocked by AWS WAF. If the<br>response type is unspecified, this response defaults to the<br>`DEFAULT_4XX` type.<br>Note[AWS WAF custom responses](../../../waf/latest/developerguide/waf-custom-request-response.md "../../../waf/latest/developerguide/waf-custom-request-response.md") take precedence over custom gateway responses.                                                                                                                                                                                                              |
