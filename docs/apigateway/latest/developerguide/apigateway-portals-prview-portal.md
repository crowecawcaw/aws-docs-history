# Preview a portal in API Gateway

You can preview your portal before you publish it. API Gateway creates a short-lived URL that you can use to preview
the version of your portal that customers will see once your portal is published.

## Considerations

The following considerations might impact how you preview a portal:

- Try it is not enabled for your preview portal. For more information, see [Enable try it for an API Gateway product REST endpoint in your portal](apigateway-portals-try-it.md "apigateway-portals-try-it.md").

## Preview a portal

The following procedure shows how to preview a portal.

###### To preview a portal

1. Sign in to the API Gateway console at [https://console.aws.amazon.com/apigateway](https://console.aws.amazon.com/apigateway "https://console.aws.amazon.com/apigateway").
2. In the main navigation pane, choose
   **Portals**.
3. Choose a portal.
4. Choose **Generate portal preview**.

Do not refresh your page. 5. After API Gateway generates your preview, choose **Open portal preview**.

Your portal preview
will open in a new tab.
