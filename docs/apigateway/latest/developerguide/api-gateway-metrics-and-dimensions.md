# Amazon API Gateway dimensions and

metrics

The metrics and dimensions that API Gateway sends to Amazon CloudWatch are listed below. For more
information, see [Monitor REST API execution with Amazon CloudWatch metrics](monitoring-cloudwatch.md "monitoring-cloudwatch.md").

## API Gateway metrics

Amazon API Gateway sends metric data to CloudWatch every minute.

The `AWS/ApiGateway` namespace includes the following metrics.

| Metric             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4XXError           | The number of client-side errors captured in a given<br>period.<br>API Gateway counts modified gateway response status codes as 4XXError errors.<br>The `Sum` statistic represents this metric, namely, the<br>total count of the 4XXError errors in the given<br>period. The `Average` statistic represents the<br>4XXError error rate, namely, the total count of<br>the 4XXError errors divided by the total number of<br>requests during the period. The denominator corresponds to the<br>Count metric (below).<br>Unit: Count |
| 5XXError           | The number of server-side errors captured in a given<br>period.<br>The `Sum` statistic represents this metric, namely, the<br>total count of the 5XXError errors in the given<br>period. The `Average` statistic represents the<br>5XXError error rate, namely, the total count of<br>the 5XXError errors divided by the total number of<br>requests during the period. The denominator corresponds to the<br>Count metric (below).<br>Unit: Count                                                                                  |
| CacheHitCount      | The number of requests served from the API cache in a given<br>period.<br>The `Sum` statistic represents this metric, namely, the<br>total count of the cache hits in the given period. The<br>`Average` statistic represents the cache hit rate,<br>namely, the total count of the cache hits divided by the total<br>number of requests during the period. The denominator corresponds to<br>the Count metric (below).<br>Unit: Count                                                                                             |
| CacheMissCount     | The number of requests served from the backend in a given period,<br>when API caching is enabled.<br>The `Sum` statistic represents this metric, namely, the<br>total count of the cache misses in the given period. The<br>`Average` statistic represents the cache miss rate,<br>namely, the total count of the cache misses divided by the total<br>number of requests during the period. The denominator corresponds to<br>the Count metric (below).<br>Unit: Count                                                             |
| Count              | The total number API requests in a given period.<br>The `SampleCount` statistic represents this<br>metric.<br>Unit: Count                                                                                                                                                                                                                                                                                                                                                                                                           |
| IntegrationLatency | The time between when API Gateway relays a request to the backend and<br>when it receives a response from the backend.<br>Unit: Millisecond                                                                                                                                                                                                                                                                                                                                                                                         |
| Latency            | The time between when API Gateway receives a request from a client and<br>when it returns a response to the client. The latency includes the<br>integration latency and other API Gateway overhead.<br>Unit: Millisecond                                                                                                                                                                                                                                                                                                            |

## Dimensions for metrics

You can use the dimensions in the following table to filter API Gateway metrics.

###### Note

API Gateway removes non-ASCII characters from the ApiName dimension
before sending metrics to CloudWatch. If the APIName contains no ASCII
characters, the API ID is used as the ApiName.

| Dimension                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ApiName                          | Filters API Gateway metrics for the REST API with the specified API<br>name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ApiName, Method, Resource, Stage | Filters API Gateway metrics for the API method with the specified API<br>name, stage, resource, and method.<br>API Gateway will not send these metrics unless you have explicitly enabled detailed CloudWatch metrics. In the<br>console, choose a stage, and then for **Logs and tracing**, select<br>**Edit**. Select **Detailed metrics**, and then choose<br>**Save changes**. Alternatively, you can call the [update-stage](../../../cli/latest/reference/apigateway/update-stage.md "../../../cli/latest/reference/apigateway/update-stage.md") AWS CLI<br>command to update the `metricsEnabled` property to `true`.<br>Enabling these metrics will incur additional charges to your<br>account. For pricing information, see [Amazon CloudWatch<br>Pricing](https://aws.amazon.com/cloudwatch/pricing/ "https://aws.amazon.com/cloudwatch/pricing/"). |
| ApiName, Stage                   | Filters API Gateway metrics for the API stage resource with the<br>specified API name and stage.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
