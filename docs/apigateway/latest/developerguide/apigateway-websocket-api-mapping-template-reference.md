# WebSocket API mapping template reference for API Gateway

This section summarizes the set of variables that are currently supported for WebSocket
APIs in API Gateway.

| Parameter                                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `$context.connectionId`                           | A unique ID for the connection that can be used to make a callback to<br>the client.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `$context.connectedAt`                            | The [Epoch](https://en.wikipedia.org/wiki/Unix_time "https://en.wikipedia.org/wiki/Unix_time")-formatted connection time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `$context.domainName`                             | A domain name for the WebSocket API. This can be used to make a<br>callback to the client (instead of a hard-coded value).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `$context.eventType`                              | The event type: `CONNECT`, `MESSAGE`, or<br>`DISCONNECT`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `$context.messageId`                              | A unique server-side ID for a message. Available only when the<br>`$context.eventType` is `MESSAGE`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `$context.routeKey`                               | The selected route key.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `$context.requestId`                              | Same as `$context.extendedRequestId`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `$context.extendedRequestId`                      | An automatically generated ID for the API call, which contains more<br>useful information for debugging/troubleshooting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$context.apiId`                                  | The identifier API Gateway assigns to your API.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `$context.authorizer.principalId`                 | The principal user identification associated with the token sent by<br>the client and returned from an API Gateway Lambda authorizer (formerly known<br>as a custom authorizer) Lambda function.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `$context.authorizer.`property``                  | The stringified value of the specified key-value pair of the `context` map returned from an API Gateway Lambda<br>authorizer function. For example, if the authorizer returns the<br>following `context` map:<br>`<br>"context" : {<br>"key": "value",<br>"numKey": 1,<br>"boolKey": true<br>}<br>`<br>calling `$context.authorizer.key` returns the<br>`"value"` string, calling<br>`$context.authorizer.numKey` returns the `"1"`<br>string, and calling `$context.authorizer.boolKey` returns the<br>`"true"` string.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$context.error.messageString`                    | The quoted value of `$context.error.message`, namely<br>`"$context.error.message"`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `$context.error.validationErrorString`            | A string containing a detailed validation error message.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$context.identity.accountId`                     | The AWS account ID associated with the request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `$context.identity.apiKey`                        | The API owner key associated with key-enabled API request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `$context.identity.apiKeyId`                      | The API key ID associated with the key-enabled API request                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `$context.identity.caller`                        | The principal identifier of the caller making the request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `$context.identity.cognitoAuthenticationProvider` | A comma-separated list of all the Amazon Cognito authentication providers used by the caller making the<br>request. Available only if the request was signed with Amazon Cognito credentials.<br>For example, for an identity from an Amazon Cognito user pool, `cognito-idp.<br>`region`.amazonaws.com/`user_pool_id`,cognito-idp.`region`.amazonaws.com/`user_pool_id`:CognitoSignIn:`token<br>subject claim``<br>For information about the available Amazon Cognito authentication providers, see [Using Federated<br>Identities](../../../cognito/latest/developerguide/cognito-identity.md "../../../cognito/latest/developerguide/cognito-identity.md") in the _Amazon Cognito Developer Guide_.                                                                                                                                                                                                                                                             |
| `$context.identity.cognitoAuthenticationType`     | The Amazon Cognito authentication type of the caller making the request. Available only if the request<br>was signed with Amazon Cognito credentials. Possible values include `authenticated` for authenticated<br>identities and `unauthenticated` for unauthenticated identities.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `$context.identity.cognitoIdentityId`             | The Amazon Cognito identity ID of the caller making the request.<br>Available only if the request was signed with Amazon Cognito<br>credentials.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `$context.identity.cognitoIdentityPoolId`         | The Amazon Cognito identity pool ID of the caller making the request.<br>Available only if the request was signed with Amazon Cognito<br>credentials.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `$context.identity.sourceIp`                      | The source IP address of the immediate TCP connection making the request to API Gateway endpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `$context.identity.user`                          | The principal identifier of the user making the request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$context.identity.userAgent`                     | The User Agent of the API caller.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `$context.identity.userArn`                       | The Amazon Resource Name (ARN) of the effective user identified after<br>authentication.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$context.requestTime`                            | The [CLF](https://httpd.apache.org/docs/current/logs.html#common "https://httpd.apache.org/docs/current/logs.html#common")-formatted request time (`dd/MMM/yyyy:HH:mm:ss<br>+-hhmm`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `$context.requestTimeEpoch`                       | The [Epoch](https://en.wikipedia.org/wiki/Unix_time "https://en.wikipedia.org/wiki/Unix_time")-formatted request time, in milliseconds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `$context.stage`                                  | The deployment stage of the API call (for example, Beta or<br>Prod).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `$context.status`                                 | The response status.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `$input.body`                                     | Returns the raw payload as a string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `$input.json(x)`                                  | This function evaluates a JSONPath expression and returns the<br>results as a JSON string.<br>For example, `$input.json('$.pets')` will return a JSON<br>string representing the pets structure.<br>For more information about JSONPath, see [JSONPath](https://goessner.net/articles/JsonPath/ "https://goessner.net/articles/JsonPath/") or<br>[JSONPath for<br>Java](https://github.com/json-path/JsonPath "https://github.com/json-path/JsonPath").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `$input.path(x)`                                  | Takes a JSONPath expression string (`x`) and returns<br>a JSON object representation of the result. This allows you to<br>access and manipulate elements of the payload natively in [Apache Velocity Template Language (VTL)](https://velocity.apache.org/engine/devel/vtl-reference.html "https://velocity.apache.org/engine/devel/vtl-reference.html").<br>For example, if the expression `$input.path('$.pets')`<br>returns an object like this:<br>`<br>[<br>{<br>"id": 1,<br>"type": "dog",<br>"price": 249.99<br>},<br>{<br>"id": 2,<br>"type": "cat",<br>"price": 124.99<br>},<br>{<br>"id": 3,<br>"type": "fish",<br>"price": 0.99<br>}<br>]<br>`<br>`$input.path('$.pets').count()` would return<br>`"3"`.<br>For more information about JSONPath, see [JSONPath](http://goessner.net/articles/JsonPath/ "http://goessner.net/articles/JsonPath/") or<br>[JSONPath for<br>Java](https://github.com/jayway/JsonPath "https://github.com/jayway/JsonPath"). |
| `$stageVariables.`<variable_name>``               | `<variable_name>` represents a stage<br>variable name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `$stageVariables['`<variable_name>`']`            | `<variable_name>` represents any stage<br>variable name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `${stageVariables['`<variable_name>`']}`          | `<variable_name>` represents any stage<br>variable name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `$util.escapeJavaScript()`                        | Escapes the characters in a string using JavaScript string<br>rules.<br>NoteThis function will turn any regular single quotes (`'`)<br>into escaped ones (`\'`). However, the escaped single<br>quotes are not valid in JSON. Thus, when the output from this<br>function is used in a JSON property, you must turn any escaped<br>single quotes (`\'`) back to regular single quotes<br>(`'`). This is shown in the following example:<br>``<br>$util.escapeJavaScript(`data`).replaceAll("\\'","'")<br>``                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `$util.parseJson()`                               | Takes "stringified" JSON and returns an object representation of the<br>result. You can use the result from this function to access and<br>manipulate elements of the payload natively in Apache Velocity Template<br>Language (VTL). For example, if you have the following payload:<br>`<br>{"errorMessage":"{\"key1\":\"var1\",\"key2\":{\"arr\":[1,2,3]}}"}<br>`<br>and use the following mapping template<br>`<br>#set ($errorMessageObj = $util.parseJson($input.path('$.errorMessage')))<br>{<br>"errorMessageObjKey2ArrVal" : $errorMessageObj.key2.arr[0]<br>}<br>`<br>You will get the following output:<br>`<br>{<br>"errorMessageObjKey2ArrVal" : 1<br>}<br>`                                                                                                                                                                                                                                                                                          |
| `$util.urlEncode()`                               | Converts a string into "application/x-www-form-urlencoded"<br>format.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `$util.urlDecode()`                               | Decodes an "application/x-www-form-urlencoded"<br>string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `$util.base64Encode()`                            | Encodes the data into a base64-encoded string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `$util.base64Decode()`                            | Decodes the data from a base64-encoded string.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
