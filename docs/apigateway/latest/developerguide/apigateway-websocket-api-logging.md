# Monitor WebSocket API execution with CloudWatch metrics

You can use [Amazon CloudWatch](../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md "../../../AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.md") metrics to
monitor WebSocket APIs. The configuration is similar to that used for REST APIs. For more
information, see [Monitor REST API execution with Amazon CloudWatch metrics](monitoring-cloudwatch.md "monitoring-cloudwatch.md").

The following metrics are supported for WebSocket APIs:

| Metric             | Description                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ConnectCount       | The number of messages sent to the `$connect` route<br>integration.                                                                                                                               |
| MessageCount       | The number of messages sent to the WebSocket API, either from or to the<br>client.                                                                                                                |
| IntegrationError   | The number of requests that return a 4XX/5XX response from the<br>integration.                                                                                                                    |
| ClientError        | The number of requests that have a 4XX response returned by API Gateway before<br>the integration is invoked.                                                                                     |
| ExecutionError     | Errors that occurred when calling the integration.                                                                                                                                                |
| IntegrationLatency | The time difference between API Gateway sending the request to the integration<br>and API Gateway receiving the response from the integration. Suppressed for<br>callbacks and mock integrations. |

You can use the dimensions in the following table to filter API Gateway metrics.

| Dimension                      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ApiId                          | Filters API Gateway metrics for an API with the specified API ID.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ApiId, Stage                   | Filters API Gateway metrics for an API stage with the specified API ID and<br>stage ID.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ApiId, Method, Resource, Stage | Filters API Gateway metrics for an API method with the specified API ID,<br>stage ID, resource path, and route ID.<br>API Gateway will not send these metrics unless you have explicitly enabled<br>detailed CloudWatch metrics. You can do this by calling the [UpdateStage](../../../apigatewayv2/latest/api-reference/apis-apiid-stages-stagename.md "../../../apigatewayv2/latest/api-reference/apis-apiid-stages-stagename.md") action<br>of the API Gateway V2 REST API to update the `detailedMetricsEnabled` property to<br>`true`. Alternatively, you can call<br>the [update-stage](../../../cli/latest/reference/apigatewayv2/update-stage.md "../../../cli/latest/reference/apigatewayv2/update-stage.md") AWS CLI command to update the `DetailedMetricsEnabled` property to<br>`true`. Enabling such metrics will incur additional charges to your<br>account. For pricing information, see [Amazon CloudWatch<br>Pricing](https://aws.amazon.com/cloudwatch/pricing/ "https://aws.amazon.com/cloudwatch/pricing/"). |
