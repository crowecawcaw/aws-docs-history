# Database services

The following table describes how Amazon SNS integrates with AWS database
services such as AWS Database Migration Service (DMS), Amazon DynamoDB, Amazon ElastiCache, Amazon Neptune, Amazon Redshift, and
Amazon Relational Database Service (RDS) to send notifications about important events such as data migrations,
maintenance activities, cache updates, and database changes.

These integrations help you to monitor and manage your database environments more
effectively by providing timely alerts on key operational events.

| AWS service                                                                                                                                                                                                                                                                                                             | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS Database Migration Service](../../../dms/latest/userguide/Introduction.md "../../../dms/latest/userguide/Introduction.md")<br>– Migrates data from on-premises databases into the<br>AWS Cloud.                                                                                                                    | Receive notifications when AWS DMS events occur; for example, when a<br>replication instance is created or deleted. For more information,<br>see [Working with events<br>and notifications in AWS Database Migration Service](../../../dms/latest/userguide/CHAP_Events.md "../../../dms/latest/userguide/CHAP_Events.md") in the<br>_AWS Database Migration Service User Guide_. |
| [Amazon DynamoDB](../../../amazondynamodb/latest/developerguide/Introduction.md "../../../amazondynamodb/latest/developerguide/Introduction.md")<br>– Provides fast and predictable performance with seamless<br>scalability in this fully managed NoSQL database service.                                              | Receive notifications when maintenance events occur. For more<br>information, see [Customizing DAX cluster settings](../../../amazondynamodb/latest/developerguide/DAX.md#DAX.cluster-management.custom-settings "../../../amazondynamodb/latest/developerguide/DAX.md#DAX.cluster-management.custom-settings") in the<br>_Amazon DynamoDB Developer Guide_.                      |
| [Amazon ElastiCache](../../../AmazonElastiCache/latest/mem-ug/WhatIs.md "../../../AmazonElastiCache/latest/mem-ug/WhatIs.md")<br>– Provides a high performance, resizeable, and cost-effective<br>in-memory cache, while removing complexity associated with deploying<br>and managing a distributed cache environment. | Receive notifications when significant events occur. For more<br>information, see [Event notifications and Amazon SNS](../../../AmazonElastiCache/latest/mem-ug/ElastiCacheSNS.md "../../../AmazonElastiCache/latest/mem-ug/ElastiCacheSNS.md") in the<br>_Amazon ElastiCache (Memcached) User Guide_.                                                                            |
