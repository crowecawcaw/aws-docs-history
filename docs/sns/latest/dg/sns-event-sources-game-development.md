# Game development services

The following table describes how Amazon SNS integrates with Amazon GameLift Servers to provide notifications
for matchmaking and queue events in session-based multiplayer game servers.

This integration helps game developers automate and monitor the deployment, operation,
and scaling of their game servers, ensuring a seamless gaming experience.

| AWS service                                                                                                                                                                                                                                                                                                                           | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Amazon GameLift Servers](../../../gamelift/latest/developerguide/gamelift-intro.md "../../../gamelift/latest/developerguide/gamelift-intro.md")<br>– Provides solutions for hosting session-based multiplayer<br>game servers in the cloud, including a fully managed service for<br>deploying, operating, and scaling game servers. | Receive matchmaking and queue event notifications. For more<br>information, see the following pages:<br>• For matchmaking notifications, see [Set up FlexMatch event notification](../../../gamelift/latest/flexmatchguide/match-notification.md "../../../gamelift/latest/flexmatchguide/match-notification.md") in the<br>_Amazon GameLift Servers FlexMatch Developer<br>Guide_.<br>• For queue notifications, see [Set up event notification for game session<br>placement](../../../gamelift/latest/developerguide/queue-notification.md "../../../gamelift/latest/developerguide/queue-notification.md") in the _Amazon GameLift Servers Developer<br>Guide_. |
