

# Register an origination ID
<a name="channels-sms-originating-identities-origination-registrations"></a>

Registering an origination ID is important for compliance with country-specific regulations and improving deliverabililty. It ensures that your messages are recognized, trusted, and have a higher chance of successful delivery.

## Step 1: Registration type
<a name="channels-sms-originating-identities-register"></a>

1. Sign in to the [Amazon SNS console](https://console.aws.amazon.com/sns/home).

1. In the navigation pane, choose **Origination Identities**.

1. On the **Origination numbers** tab, in the **Origination ID Registrations** section, select **Start origination ID registration**.

   The **Registration type** page is displayed.

1. For **Registration name**, enter a business-friendly name for the registration.

1. For **Destination country**, choose the country in which you will be sending messages.

1. Select the type of origination ID you would like to register.

1. Choose the AWS Region in which you will be making API requests.

1. Choose **Save and Next**.
