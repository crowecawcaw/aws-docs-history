# Networking & content

delivery services

The following table describes how Amazon SNS integrates with AWS networking
and content delivery services, such as Amazon API Gateway, Amazon CloudFront, Direct Connect, ELB, Amazon
Route 53, and Amazon VPC, to send notifications for events like API messages, CloudFront metric
alarms, connection state changes, load balancer events, health check statuses, and VPC
endpoint activities.

These integrations help you to monitor and manage your network and content delivery
operations by providing timely alerts and updates.

| AWS service                                                                                                                                                                                                                                                                                                                     | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Amazon API Gateway](../../../apigateway/latest/developerguide/welcome.md "../../../apigateway/latest/developerguide/welcome.md") –<br>Enables you to create and deploy your own REST and WebSocket APIs at<br>any scale.                                                                                                       | Receive messages posted to an API Gateway endpoint. For more<br>information, see [Tutorial:<br>Build an API Gateway REST API with AWS integration](../../../apigateway/latest/developerguide/getting-started-aws-proxy.md "../../../apigateway/latest/developerguide/getting-started-aws-proxy.md") in the<br>_API Gateway Developer Guide_.                                                                                                             |
| [Amazon CloudFront](../../../AmazonCloudFront/latest/DeveloperGuide/Introduction.md "../../../AmazonCloudFront/latest/DeveloperGuide/Introduction.md")<br>– Speeds up distribution of your static and dynamic web<br>content, such as .html, .css, .php, image, and media files.                                                | Receive notifications when alarms based on specified CloudFront metrics<br>occur. For more information, see [Setting alarms to<br>receive notifications](../../../AmazonCloudFront/latest/DeveloperGuide/receiving-notifications.md "../../../AmazonCloudFront/latest/DeveloperGuide/receiving-notifications.md") in the<br>_Amazon CloudFront Developer Guide_.                                                                                         |
| [Direct Connect](../../../directconnect/latest/UserGuide/Welcome.md "../../../directconnect/latest/UserGuide/Welcome.md")<br>– Links your internal network to an Direct Connect location over a<br>standard Ethernet fiber-optic cable.                                                                                         | Receive notifications when alarms that monitor the state of an<br>Direct Connect connection change state. For more information, see [Creating CloudWatch alarms to monitor Direct Connect connections](../../../directconnect/latest/UserGuide/monitoring-cloudwatch.md#creating-alarms "../../../directconnect/latest/UserGuide/monitoring-cloudwatch.md#creating-alarms") in<br>the _Direct Connect User Guide_.                                       |
| [Elastic Load Balancing](../../../elasticloadbalancing/latest/classic/welcome.md "../../../elasticloadbalancing/latest/classic/welcome.md") –<br>Automatically distributes your incoming traffic across multiple<br>targets, such as Amazon EC2 instances, containers, and IP addresses, in<br>more or more Availability Zones. | Receive notifications of alarms you've created for load balancer<br>events. For more information, see [Create CloudWatch alarms for your load balancer](../../../elasticloadbalancing/latest/classic/elb-cloudwatch-metrics.md#create_cw_alarms "../../../elasticloadbalancing/latest/classic/elb-cloudwatch-metrics.md#create_cw_alarms") in the<br>_User Guide for Classic Load Balancers_.                                                            |
| [Amazon Route 53](../../../Route53/latest/DeveloperGuide/Welcome.md "../../../Route53/latest/DeveloperGuide/Welcome.md") –<br>Provides domain registration, DNS routing, and health<br>checking.                                                                                                                                | Receive notifications when health check status is unhealthy. For<br>more information, see [To receive an Amazon SNS notification when a health check status is<br>unhealthy (console)](../../../Route53/latest/DeveloperGuide/monitoring-health-checks.md#monitoring-sns-notification-procedure "../../../Route53/latest/DeveloperGuide/monitoring-health-checks.md#monitoring-sns-notification-procedure") in the<br>_Amazon Route 53 Developer Guide_. |
| [Amazon Virtual Private Cloud<br>(Amazon VPC)](../../../vpc/latest/userguide/what-is-amazon-vpc.md "../../../vpc/latest/userguide/what-is-amazon-vpc.md") – Enables you to launch AWS resources<br>into a virtual network that you've defined.                                                                                  | Receive notifications for specific events that occur on interface<br>endpoints. For more information, see [Create and manage a notification for an endpoint<br>service](../../../vpc/latest/userguide/create-notification-endpoint-service.md "../../../vpc/latest/userguide/create-notification-endpoint-service.md") in the<br>_Amazon VPC User Guide_.                                                                                                |
