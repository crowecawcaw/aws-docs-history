# Compute services

The following table describes how Amazon SNS integrates with various AWS
compute services, enabling you to receive notifications for key events such as Amazon EC2 Auto Scaling
actions, EC2 Image Builder completions, Elastic Beanstalk environment changes, Lambda function outputs, and
Lightsail metric thresholds.

You can leverage these integrations to efficiently manage your applications and
resources by staying informed about critical updates and actions across
AWS services.

| AWS service                                                                                                                                                                                                                                                                                                                                                                       | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Amazon EC2 Auto Scaling](../../../autoscaling/ec2/userguide/what-is-amazon-ec2-auto-scaling.md "../../../autoscaling/ec2/userguide/what-is-amazon-ec2-auto-scaling.md") – Helps you have the correct number of<br>Amazon Elastic Compute Cloud (Amazon EC2) instances available for handling your<br>application's load.                                                         | Receive notifications when Amazon EC2 Auto Scaling launches or terminates Amazon EC2<br>instances in your Amazon EC2 Auto Scaling group. For more information, see [Getting Amazon SNS<br>notifications when your Amazon EC2 Auto Scaling group scales](../../../autoscaling/ec2/userguide/ASGettingNotifications.md "../../../autoscaling/ec2/userguide/ASGettingNotifications.md") in the<br>_Amazon EC2 Auto Scaling User Guide_.                                                       |
| [EC2 Image Builder](../../../imagebuilder/latest/userguide/what-is-image-builder.md "../../../imagebuilder/latest/userguide/what-is-image-builder.md") – Helps automate the creation,<br>management, and deployment of customized, secure, and up-to-date<br>server images that are pre-installed and pre-configured with<br>software and settings to meet specific IT standards. | Receive notifications when builds are complete. For more<br>information, see [Tracking the latest server images in EC2 Image Builder pipelines](https://aws.amazon.com/blogs/compute/tracking-the-latest-server-images-in-amazon-ec2-image-builder-pipelines/ "https://aws.amazon.com/blogs/compute/tracking-the-latest-server-images-in-amazon-ec2-image-builder-pipelines/")<br>on the _AWS Compute Blog_.                                                                               |
| [AWS Elastic Beanstalk](../../../elasticbeanstalk/latest/dg/welcome.md "../../../elasticbeanstalk/latest/dg/welcome.md") –<br>Handles the details of capacity provisioning, load balancing, and<br>scaling for your application, and provides application health<br>monitoring.                                                                                                   | Receive notifications of important events that affect your<br>application. For more information, see [Elastic Beanstalk<br>environment notifications with Amazon SNS](../../../elasticbeanstalk/latest/dg/using-features.managing.md "../../../elasticbeanstalk/latest/dg/using-features.managing.md") in the<br>_AWS Elastic Beanstalk Developer Guide_.                                                                                                                                  |
| [AWS Lambda](../../../lambda/latest/dg/welcome.md "../../../lambda/latest/dg/welcome.md") –<br>Lets you run code without provisioning or managing servers.                                                                                                                                                                                                                        | Receive function output data by setting an SNS topic as a Lambda<br>dead-letter queue or a Lambda destination. For more information, see<br>[Asynchronous<br>invocation](../../../lambda/latest/dg/invocation-async.md "../../../lambda/latest/dg/invocation-async.md") in the<br>_AWS Lambda Developer Guide_.                                                                                                                                                                            |
| [Amazon Lightsail](https://lightsail.aws.amazon.com/ls/docs/all "https://lightsail.aws.amazon.com/ls/docs/all")<br>– Helps developers get started using AWS to build websites<br>or web applications.                                                                                                                                                                             | Receive notifications when a metric for one of your instances,<br>databases, or load balancers crosses a specified threshold. For more<br>information, see [Adding notification contacts in Amazon Lightsail](https://lightsail.aws.amazon.com/ls/docs/en_us/articles/amazon-lightsail-adding-editing-notification-contacts "https://lightsail.aws.amazon.com/ls/docs/en_us/articles/amazon-lightsail-adding-editing-notification-contacts") in the<br>_Amazon Lightsail Developer Guide_. |
