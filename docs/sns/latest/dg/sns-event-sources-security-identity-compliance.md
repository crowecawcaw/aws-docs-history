# Security, identity,

& compliance services

The following table describes how Amazon SNS integrates with AWS security,
identity, and compliance services, such as Directory Service, Amazon GuardDuty, Amazon Inspector, and AWS Security Hub, to
provide notifications for directory status changes, security findings, Inspector events,
and security hub announcements.

These integrations help you to maintain robust security practices by offering timely
alerts and updates on security and compliance events.

| AWS service                                                                                                                                                                                                                                                                                     | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS Directory Service](../../../directoryservice/latest/admin-guide/what_is.md "../../../directoryservice/latest/admin-guide/what_is.md")<br>– Provides multiple ways to use Microsoft Active Directory<br>(AD) with other AWS services.                                                       | Receive email or text (SMS) messages when the status of your<br>directory changes. For more information, see [Configure<br>directory status notifications](../../../directoryservice/latest/admin-guide/ms_ad_enable_notifications.md "../../../directoryservice/latest/admin-guide/ms_ad_enable_notifications.md") in the<br>_AWS Directory Service Administration Guide_.                                             |
| [Amazon GuardDuty](../../../guardduty/latest/ug/what-is-guardduty.md "../../../guardduty/latest/ug/what-is-guardduty.md")<br>– Provides continuous security monitoring to help to identify<br>unexpected and potentially unauthorized or malicious activity in<br>your AWS environment.         | Receive notifications about newly released finding types, updates<br>to the existing finding types, and other functionality changes. For<br>more information, see [Subscribing to GuardDuty announcements SNS topic](../../../guardduty/latest/ug/guardduty_sns.md "../../../guardduty/latest/ug/guardduty_sns.md") in the<br>_Amazon GuardDuty User Guide_.                                                            |
| [Amazon Inspector](../../../inspector/latest/userguide/inspector_introduction.md "../../../inspector/latest/userguide/inspector_introduction.md") – Tests the network accessibility of your<br>Amazon EC2 instances and the security state of your applications that run<br>on those instances. | Receive notifications for Amazon Inspector events. For more information, see<br>[Setting up an SNS topic for Amazon Inspector notifications](../../../inspector/latest/userguide/inspector_assessments.md#sns-topic "../../../inspector/latest/userguide/inspector_assessments.md#sns-topic") in the<br>_Amazon Inspector User Guide_.                                                                                  |
| [AWS Security Hub](https://aws.amazon.com/security-hub/ "https://aws.amazon.com/security-hub/") – Automates AWS<br>security checks and centralizes security alerts.                                                                                                                             | Receive notifications about AWS Security Hub announcements, including<br>notifications about AWS Security Hub controls or standards that have been<br>added, edited, or retired. For more information, see [Subscribing to AWS Security Hub announcements with<br>Amazon SNS](../../../securityhub/latest/userguide/securityhub-announcements.md "../../../securityhub/latest/userguide/securityhub-announcements.md"). |
