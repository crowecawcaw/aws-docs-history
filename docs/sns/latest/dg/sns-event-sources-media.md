# Media services

The following table describes how Amazon SNS integrates with Amazon Elastic Transcoder to send notifications
when media transcoding jobs change status, enabling you to efficiently monitor and
manage the conversion of media files stored in Amazon S3 into formats suitable for consumer
playback devices.

This integration helps you streamline media processing workflows by providing
real-time alerts on job status.

| AWS service                                                                                                                                                                                                                                                                                                  | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Amazon Elastic Transcoder](../../../elastictranscoder/latest/developerguide/introduction.md "../../../elastictranscoder/latest/developerguide/introduction.md")<br>– Lets you convert media files that you stored in Amazon S3 into<br>media files in the formats required by consumer playback<br>devices. | Receive notifications when jobs change status. For more<br>information, see [Notifications of job status](../../../elastictranscoder/latest/developerguide/notifications.md "../../../elastictranscoder/latest/developerguide/notifications.md") in the<br>_Amazon Elastic Transcoder Developer Guide_. |
