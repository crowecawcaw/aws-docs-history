# Management & governance

services

The following table describes how Amazon SNS integrates with AWS management
and governance services such as Amazon Q Developer in chat applications, AWS CloudFormation, CloudTrail, CloudWatch, AWS Config, AWS Control Tower, AWS License Manager,
AWS Service Catalog, and AWS Systems Manager, providing notifications for key events like infrastructure
changes, compliance alerts, and operational insights.

These integrations help you monitor and manage your AWS environments
efficiently by delivering timely alerts and updates to relevant teams and
systems.
