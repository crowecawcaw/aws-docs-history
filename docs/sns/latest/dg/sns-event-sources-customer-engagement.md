# Customer engagement

services

The following table describes how Amazon SNS enhances customer engagement services by
integrating with Amazon Connect, AWS End User Messaging SMS, and Amazon Simple Email Service (SES), enabling you to receive alerts
and validations, configure two-way SMS messaging, and monitor email notifications for
bounces, complaints, and deliveries.

These integrations help you manage customer communications across multiple
channels.

| AWS service                                                                                                                                                                                                                                            | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Amazon Connect](../../../connect/latest/adminguide/what-is-amazon-connect.md "../../../connect/latest/adminguide/what-is-amazon-connect.md") – Lets you set up an omnichannel cloud contact center to engage with your customers.                     | Receive alerts and validations. For more information, see [The power of AWS with Amazon Connect](../../../connect/latest/adminguide/related-services-amazon-connect.md "../../../connect/latest/adminguide/related-services-amazon-connect.md") in the _Amazon Connect Administrator Guide_.                                               |
| [AWS End User Messaging SMS](../../../sms-voice/latest/userguide/what-is-service.md "../../../sms-voice/latest/userguide/what-is-service.md") – Helps you engage your customers by sending them email, SMS and voice messages, and push notifications. | Configure two-way SMS, which allows you to receive messages from your customers. For more information, see [Two-way SMS messaging](../../../sms-voice/latest/userguide/phone-pool-two-way-sms.md "../../../sms-voice/latest/userguide/phone-pool-two-way-sms.md") in the _AWS End User Messaging SMS User Guide_.                          |
| [Amazon Simple Email Service (Amazon SES)](../../../ses/latest/DeveloperGuide/Welcome.md "../../../ses/latest/DeveloperGuide/Welcome.md") – Provides cost-effective way for you to send and receive email using your own email addresses and domains.  | Receive notifications of bounces, complaints, and deliveries. For more information, see [Configuring Amazon SNS notifications for Amazon SES](../../../ses/latest/DeveloperGuide/configure-sns-notifications.md "../../../ses/latest/DeveloperGuide/configure-sns-notifications.md") in the _Amazon Simple Email Service Developer Guide_. |
