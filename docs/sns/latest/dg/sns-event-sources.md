# Amazon SNS event sources

Amazon SNS integrates with a wide range of AWS services across various categories, allowing
these services to publish events to Amazon SNS topics. This integration provides real-time
notifications of key events, such as changes in infrastructure, application performance, and
cost management.

###### Note

Amazon SNS introduced [FIFO topics](sns-fifo-topics.md "sns-fifo-topics.md") in October, 2020.
Currently, most AWS services support sending events to standard topics only.
