# Migration & transfer

services

The following table describes how Amazon SNS integrates with AWS migration
and transfer services, such as AWS Application Discovery Service, AWS Database Migration Service (DMS), and AWS Snowball Edge, to
provide notifications for events like server data collection, database migration
activities, and data transfer jobs.

These integrations help you to effectively manage and monitor your Cloud migration
processes by offering real-time alerts and updates on critical migration tasks.

| AWS service                                                                                                                                                                                                                                                                                                              | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS Application Discovery Service](../../../application-discovery/latest/userguide/what-is-appdiscovery.md "../../../application-discovery/latest/userguide/what-is-appdiscovery.md") – Helps you plan your migration to<br>the AWS Cloud by collecting usage and configuration data about<br>your on-premises servers. | Receive notifications of events through AWS CloudTrail. For more<br>information, see [Logging<br>Application Discovery Service API calls with AWS CloudTrail](../../../application-discovery/latest/userguide/logging-using-cloudtrail.md "../../../application-discovery/latest/userguide/logging-using-cloudtrail.md") in the<br>_Application Discovery Service User Guide_.    |
| [AWS Database Migration Service](../../../dms/latest/userguide/Introduction.md "../../../dms/latest/userguide/Introduction.md")<br>– Migrates data from on-premises databases into the<br>AWS Cloud.                                                                                                                     | Receive notifications when AWS DMS events occur; for example, when a<br>replication instance is created or deleted. For more information,<br>see [Working with events<br>and notifications in AWS Database Migration Service](../../../dms/latest/userguide/CHAP_Events.md "../../../dms/latest/userguide/CHAP_Events.md") in the<br>_AWS Database Migration Service User Guide_. |
| [AWS Snowball Edge](../../../snowball/latest/ug/whatissnowball.md "../../../snowball/latest/ug/whatissnowball.md") – Uses physical storage devices to<br>transfer large amounts of data between Amazon S3 and your onsite data<br>storage location at faster-than-internet speeds.                                       | Receive notifications for Snowball Edge jobs. For more information, see<br>[Notifications for Snow Family devices](../../../snowball/latest/snowcone-guide/notifications.md "../../../snowball/latest/snowcone-guide/notifications.md") in the<br>_AWS Snowball Edge User Guide_.                                                                                                 |
