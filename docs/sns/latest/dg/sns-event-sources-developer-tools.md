# Developer tools services

The following table describes how Amazon SNS integrates with AWS developer tools
services, such as AWS CodeBuild, AWS CodeCommit, AWS CodeDeploy, Amazon CodeGuru, and AWS CodePipeline to
provide notifications for critical events such as build status changes, repository
updates, deployment progress, performance anomalies, and pipeline actions.

These integrations helps you efficiently monitor and manage your software development
workflows by receiving timely alerts on important events.

| AWS service                                                                                                                                                                                                                                                                                                            | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS CodeBuild](../../../codebuild/latest/userguide/welcome.md "../../../codebuild/latest/userguide/welcome.md") –<br>Compiles your source code, runs unit tests, and produces artifacts<br>that are ready to deploy.                                                                                                  | Receive notifications when builds succeed, fail, or move from one<br>build phase to another. For more information, see [Build<br>notifications sample for CodeBuild](../../../codebuild/latest/userguide/sample-build-notifications.md "../../../codebuild/latest/userguide/sample-build-notifications.md") in the<br>_AWS CodeBuild User Guide_.                         |
| [AWS CodeCommit](../../../codecommit/latest/userguide/welcome.md "../../../codecommit/latest/userguide/welcome.md") –<br>Provides version control for privately storing and managing assets<br>in the cloud.                                                                                                           | Receive notifications about CodeCommit repository events. For more<br>information, see [Example: Create an AWS CodeCommit trigger for an Amazon SNS topic](../../../codecommit/latest/userguide/how-to-notify-sns.md "../../../codecommit/latest/userguide/how-to-notify-sns.md")<br>in the _AWS CodeCommit User Guide_.                                                  |
| [AWS CodeDeploy](../../../codedeploy/latest/userguide/welcome.md "../../../codedeploy/latest/userguide/welcome.md") –<br>Automates application deployments to Amazon EC2 instances,<br>on-premises instances, serverless Lambda functions, or Amazon ECS<br>services.                                                  | Receive notifications for CodeDeploy deployments or instance events.<br>For more information, see [Create a trigger for a CodeDeploy event](../../../codedeploy/latest/userguide/monitoring-sns-event-notifications-create-trigger.md "../../../codedeploy/latest/userguide/monitoring-sns-event-notifications-create-trigger.md") in the<br>_AWS CodeDeploy User Guide_. |
| [Amazon CodeGuru](../../../codeguru/latest/profiler-ug/what-is-codeguru-profiler.md "../../../codeguru/latest/profiler-ug/what-is-codeguru-profiler.md") – Collects runtime performance<br>data from your live applications, and provides recommendations that<br>can help you fine-tune your application performance. | Receive notifications when anomalies occur. For more information,<br>see [Working with anomalies and recommendation reports](../../../codeguru/latest/profiler-ug/working-with-recommendation-reports.md "../../../codeguru/latest/profiler-ug/working-with-recommendation-reports.md") in<br>the _Amazon CodeGuru User Guide_.                                           |
| [AWS CodePipeline](../../../codepipeline/latest/userguide/welcome.md "../../../codepipeline/latest/userguide/welcome.md") –<br>Automates the steps required to release software changes<br>continuously.                                                                                                               | Receive notifications about approval actions. For more<br>information, see [Manage<br>approval actions in CodePipeline](../../../codepipeline/latest/userguide/approvals.md "../../../codepipeline/latest/userguide/approvals.md") in the<br>_AWS CodePipeline User Guide_.                                                                                               |
