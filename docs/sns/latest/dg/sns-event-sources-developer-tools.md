# Developer tools services

The following table describes how Amazon SNS integrates with AWS developer tools
services, such as AWS CodeBuild, AWS CodeCommit, AWS CodeDeploy, Amazon CodeGuru, and AWS CodePipeline to
provide notifications for critical events such as build status changes, repository
updates, deployment progress, performance anomalies, and pipeline actions.

These integrations helps you efficiently monitor and manage your software development
workflows by receiving timely alerts on important events.

| AWS service                                                                                                                                                                                                                                                                                                      | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS CodeBuild](../../../codebuild/latest/userguide/welcome.md "../../../codebuild/latest/userguide/welcome.md") – Compiles your source code, runs unit tests, and produces artifacts that are ready to deploy.                                                                                                  | Receive notifications when builds succeed, fail, or move from one build phase to another. For more information, see [Build notifications sample for CodeBuild](../../../codebuild/latest/userguide/sample-build-notifications.md "../../../codebuild/latest/userguide/sample-build-notifications.md") in the _AWS CodeBuild User Guide_.                            |
| [AWS CodeCommit](../../../codecommit/latest/userguide/welcome.md "../../../codecommit/latest/userguide/welcome.md") – Provides version control for privately storing and managing assets in the cloud.                                                                                                           | Receive notifications about CodeCommit repository events. For more information, see [Example: Create an AWS CodeCommit trigger for an Amazon SNS topic](../../../codecommit/latest/userguide/how-to-notify-sns.md "../../../codecommit/latest/userguide/how-to-notify-sns.md") in the _AWS CodeCommit User Guide_.                                                  |
| [AWS CodeDeploy](../../../codedeploy/latest/userguide/welcome.md "../../../codedeploy/latest/userguide/welcome.md") – Automates application deployments to Amazon EC2 instances, on-premises instances, serverless Lambda functions, or Amazon ECS services.                                                     | Receive notifications for CodeDeploy deployments or instance events. For more information, see [Create a trigger for a CodeDeploy event](../../../codedeploy/latest/userguide/monitoring-sns-event-notifications-create-trigger.md "../../../codedeploy/latest/userguide/monitoring-sns-event-notifications-create-trigger.md") in the _AWS CodeDeploy User Guide_. |
| [Amazon CodeGuru](../../../codeguru/latest/profiler-ug/what-is-codeguru-profiler.md "../../../codeguru/latest/profiler-ug/what-is-codeguru-profiler.md") – Collects runtime performance data from your live applications, and provides recommendations that can help you fine-tune your application performance. | Receive notifications when anomalies occur. For more information, see [Working with anomalies and recommendation reports](../../../codeguru/latest/profiler-ug/working-with-recommendation-reports.md "../../../codeguru/latest/profiler-ug/working-with-recommendation-reports.md") in the _Amazon CodeGuru User Guide_.                                           |
| [AWS CodePipeline](../../../codepipeline/latest/userguide/welcome.md "../../../codepipeline/latest/userguide/welcome.md") – Automates the steps required to release software changes continuously.                                                                                                               | Receive notifications about approval actions. For more information, see [Manage approval actions in CodePipeline](../../../codepipeline/latest/userguide/approvals.md "../../../codepipeline/latest/userguide/approvals.md") in the _AWS CodePipeline User Guide_.                                                                                                  |
