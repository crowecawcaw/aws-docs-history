# Internet of Things services

The following table descrives how Amazon SNS integrates with AWS IoT services, such as
AWS IoT Core, AWS IoT Device Defender, AWS IoT Events, and AWS IoT Greengrass, to provide notifications for IoT events and alerts.

These integrations allow you to effectively monitor device behavior, receive alerts
for abnormal activities, and manage IoT devices with real-time updates and
actions.

| AWS service                                                                                                                                                                                                                                                                                                                      | Benefit of using with Amazon SNS                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [AWS IoT Core](../../../iot/latest/developerguide/what-is-aws-iot.md "../../../iot/latest/developerguide/what-is-aws-iot.md")<br>– Provides the cloud services that connect your IoT devices<br>to other devices and AWS Cloud services.                                                                                         | Receive notifications of AWS IoT Core events. For more information,<br>see [Creating an Amazon SNS<br>rule](../../../iot/latest/developerguide/iot-sns-rule.md "../../../iot/latest/developerguide/iot-sns-rule.md") in the _AWS IoT Developer Guide_.                                                                                         |
| [AWS IoT Device Defender](../../../iot/latest/developerguide/device-defender.md "../../../iot/latest/developerguide/device-defender.md")<br>– Allows you to audit the configuration of your devices,<br>monitor connected devices to detect abnormal behavior, and mitigate<br>security risks.                                   | Receive alarms when a device violates a behavior. For more<br>information, see [How to use AWS IoT Device Defender detect](../../../iot/latest/developerguide/detect-HowToHowTo.md "../../../iot/latest/developerguide/detect-HowToHowTo.md") in the<br>_AWS IoT Developer Guide_.                                                             |
| [AWS IoT Events](../../../iotevents/latest/developerguide/what-is-iotevents.md "../../../iotevents/latest/developerguide/what-is-iotevents.md") – Lets you monitor your equipment or<br>device fleets for failures or changes in operation, and trigger<br>actions when such events occur.                                       | Receive notifications of AWS IoT Events events. For more information, see<br>[Amazon Simple Notification Service](../../../iotevents/latest/developerguide/iotevents-other-aws-services.md#iotevents-sns "../../../iotevents/latest/developerguide/iotevents-other-aws-services.md#iotevents-sns") in the<br>_AWS IoT Events Developer Guide_. |
| [AWS IoT Greengrass](../../../greengrass/v1/developerguide/what-is-iot-greengrass.md "../../../greengrass/v1/developerguide/what-is-iot-greengrass.md") – Extends AWS onto physical devices<br>so they can act locally on the data they generate, while still using<br>the cloud for management, analytics, and durable storage. | Receive notifications of AWS IoT Greengrass events. For more information, see<br>[SNS<br>connector](../../../greengrass/v1/developerguide/sns-connector.md "../../../greengrass/v1/developerguide/sns-connector.md") in the<br>_AWS IoT Greengrass Version 1 Developer Guide_.                                                                 |
