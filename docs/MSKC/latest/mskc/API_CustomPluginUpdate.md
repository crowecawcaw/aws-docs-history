

# CustomPluginUpdate

Details about a custom plugin to use when you update a connector via `UpdateConnector`.

## Contents
<a name="API_CustomPluginUpdate_Contents"></a>

 ** customPluginArn **   <a name="MSKC-Type-CustomPluginUpdate-customPluginArn"></a>
The Amazon Resource Name (ARN) of the custom plugin.  
Type: String  
Required: Yes

 ** revision **   <a name="MSKC-Type-CustomPluginUpdate-revision"></a>
The revision of the custom plugin.  
Type: Long  
Valid Range: Minimum value of 1. Maximum value of 9223372036854775807.  
Required: Yes
