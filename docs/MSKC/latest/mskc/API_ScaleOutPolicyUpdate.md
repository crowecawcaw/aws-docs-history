

# ScaleOutPolicyUpdate
<a name="API_ScaleOutPolicyUpdate"></a>

An update to the connector's scale-out policy.

## Contents
<a name="API_ScaleOutPolicyUpdate_Contents"></a>

 ** cpuUtilizationPercentage **   <a name="MSKC-Type-ScaleOutPolicyUpdate-cpuUtilizationPercentage"></a>
The target CPU utilization percentage threshold at which you want connector scale out to be triggered.  
Type: Integer  
Valid Range: Minimum value of 1. Maximum value of 100.  
Required: Yes
