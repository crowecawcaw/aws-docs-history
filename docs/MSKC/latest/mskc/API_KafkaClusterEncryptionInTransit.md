# KafkaClusterEncryptionInTransit

Details of encryption in transit to the Apache Kafka cluster.

## Contents

**encryptionType**

The type of encryption in transit to the Apache Kafka cluster.

Type: String

Valid Values: `PLAINTEXT | TLS`

Required: Yes
