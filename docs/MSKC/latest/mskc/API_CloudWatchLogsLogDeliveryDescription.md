

# CloudWatchLogsLogDeliveryDescription
<a name="API_CloudWatchLogsLogDeliveryDescription"></a>

A description of the log delivery settings.

## Contents
<a name="API_CloudWatchLogsLogDeliveryDescription_Contents"></a>

 ** enabled **   <a name="MSKC-Type-CloudWatchLogsLogDeliveryDescription-enabled"></a>
Whether log delivery to Amazon CloudWatch Logs is enabled.  
Type: Boolean  
Required: No

 ** logGroup **   <a name="MSKC-Type-CloudWatchLogsLogDeliveryDescription-logGroup"></a>
The name of the CloudWatch log group that is the destination for log delivery.  
Type: String  
Required: No
