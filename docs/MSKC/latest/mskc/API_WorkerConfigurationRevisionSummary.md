

# WorkerConfigurationRevisionSummary
<a name="API_WorkerConfigurationRevisionSummary"></a>

The summary of a worker configuration revision.

## Contents
<a name="API_WorkerConfigurationRevisionSummary_Contents"></a>

 ** creationTime **   <a name="MSKC-Type-WorkerConfigurationRevisionSummary-creationTime"></a>
The time that a worker configuration revision was created.  
Type: Timestamp  
Required: No

 ** description **   <a name="MSKC-Type-WorkerConfigurationRevisionSummary-description"></a>
The description of a worker configuration revision.  
Type: String  
Required: No

 ** revision **   <a name="MSKC-Type-WorkerConfigurationRevisionSummary-revision"></a>
The revision of a worker configuration.  
Type: Long  
Required: No
