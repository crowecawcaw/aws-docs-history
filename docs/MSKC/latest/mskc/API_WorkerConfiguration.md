

# WorkerConfiguration
<a name="API_WorkerConfiguration"></a>

The configuration of the workers, which are the processes that run the connector logic.

## Contents
<a name="API_WorkerConfiguration_Contents"></a>

 ** revision **   <a name="MSKC-Type-WorkerConfiguration-revision"></a>
The revision of the worker configuration.  
Type: Long  
Valid Range: Minimum value of 1. Maximum value of 9223372036854775807.  
Required: Yes

 ** workerConfigurationArn **   <a name="MSKC-Type-WorkerConfiguration-workerConfigurationArn"></a>
The Amazon Resource Name (ARN) of the worker configuration.  
Type: String  
Required: Yes
