

# S3Location
<a name="API_S3Location"></a>

The location of an object in Amazon S3.

## Contents
<a name="API_S3Location_Contents"></a>

 ** bucketArn **   <a name="MSKC-Type-S3Location-bucketArn"></a>
The Amazon Resource Name (ARN) of an S3 bucket.  
Type: String  
Required: Yes

 ** fileKey **   <a name="MSKC-Type-S3Location-fileKey"></a>
The file key for an object in an S3 bucket.  
Type: String  
Required: Yes

 ** objectVersion **   <a name="MSKC-Type-S3Location-objectVersion"></a>
The version of an object in an S3 bucket.  
Type: String  
Required: No
