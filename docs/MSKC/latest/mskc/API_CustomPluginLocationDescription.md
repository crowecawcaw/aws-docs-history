

# CustomPluginLocationDescription
<a name="API_CustomPluginLocationDescription"></a>

Information about the location of a custom plugin.

## Contents
<a name="API_CustomPluginLocationDescription_Contents"></a>

 ** s3Location **   <a name="MSKC-Type-CustomPluginLocationDescription-s3Location"></a>
The S3 bucket Amazon Resource Name (ARN), file key, and object version of the plugin file stored in Amazon S3.  
Type: [S3LocationDescription](API_S3LocationDescription.md) object  
Required: No
