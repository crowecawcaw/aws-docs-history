

# CustomPluginDescription
<a name="API_CustomPluginDescription"></a>

Details about a custom plugin.

## Contents
<a name="API_CustomPluginDescription_Contents"></a>

 ** customPluginArn **   <a name="MSKC-Type-CustomPluginDescription-customPluginArn"></a>
The Amazon Resource Name (ARN) of the custom plugin.  
Type: String  
Required: No

 ** revision **   <a name="MSKC-Type-CustomPluginDescription-revision"></a>
The revision of the custom plugin.  
Type: Long  
Required: No
