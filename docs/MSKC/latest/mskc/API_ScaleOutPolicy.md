# ScaleOutPolicy

The scale-out policy for the connector.

## Contents

**cpuUtilizationPercentage**

The CPU utilization percentage threshold at which you want connector scale out to be
triggered.

Type: Integer

Valid Range: Minimum value of 1. Maximum value of 100.

Required: Yes
