

# ScaleInPolicyUpdate
<a name="API_ScaleInPolicyUpdate"></a>

An update to the connector's scale-in policy.

## Contents
<a name="API_ScaleInPolicyUpdate_Contents"></a>

 ** cpuUtilizationPercentage **   <a name="MSKC-Type-ScaleInPolicyUpdate-cpuUtilizationPercentage"></a>
The target CPU utilization percentage threshold at which you want connector scale in to be triggered.  
Type: Integer  
Valid Range: Minimum value of 1. Maximum value of 100.  
Required: Yes
