

# FirehoseLogDeliveryDescription
<a name="API_FirehoseLogDeliveryDescription"></a>

A description of the settings for delivering logs to Amazon Kinesis Data Firehose.

## Contents
<a name="API_FirehoseLogDeliveryDescription_Contents"></a>

 ** deliveryStream **   <a name="MSKC-Type-FirehoseLogDeliveryDescription-deliveryStream"></a>
The name of the Kinesis Data Firehose delivery stream that is the destination for log delivery.  
Type: String  
Required: No

 ** enabled **   <a name="MSKC-Type-FirehoseLogDeliveryDescription-enabled"></a>
Specifies whether connector logs get delivered to Amazon Kinesis Data Firehose.  
Type: Boolean  
Required: No
