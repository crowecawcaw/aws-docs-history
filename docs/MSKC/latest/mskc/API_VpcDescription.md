

# VpcDescription
<a name="API_VpcDescription"></a>

The description of the VPC in which the connector resides.

## Contents
<a name="API_VpcDescription_Contents"></a>

 ** securityGroups **   <a name="MSKC-Type-VpcDescription-securityGroups"></a>
The security groups for the connector.  
Type: Array of strings  
Required: No

 ** subnets **   <a name="MSKC-Type-VpcDescription-subnets"></a>
The subnets for the connector.  
Type: Array of strings  
Required: No
