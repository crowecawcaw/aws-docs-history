# LogDelivery

Details about log delivery.

## Contents

**workerLogDelivery**

The workers can send worker logs to different destination types. This configuration
specifies the details of these destinations.

Type: [WorkerLogDelivery](API_WorkerLogDelivery.md "API_WorkerLogDelivery.md") object

Required: Yes
