

# LogDelivery
<a name="API_LogDelivery"></a>

Details about log delivery.

## Contents
<a name="API_LogDelivery_Contents"></a>

 ** workerLogDelivery **   <a name="MSKC-Type-LogDelivery-workerLogDelivery"></a>
The workers can send worker logs to different destination types. This configuration specifies the details of these destinations.  
Type: [WorkerLogDelivery](API_WorkerLogDelivery.md) object  
Required: Yes
