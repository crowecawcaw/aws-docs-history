

# StateDescription
<a name="API_StateDescription"></a>

Details about the state of a resource.

## Contents
<a name="API_StateDescription_Contents"></a>

 ** code **   <a name="MSKC-Type-StateDescription-code"></a>
A code that describes the state of a resource.  
Type: String  
Required: No

 ** message **   <a name="MSKC-Type-StateDescription-message"></a>
A message that describes the state of a resource.  
Type: String  
Required: No
