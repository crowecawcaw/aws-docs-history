# CustomPluginFileDescription

Details about a custom plugin file.

## Contents

**fileMd5**

The hex-encoded MD5 checksum of the custom plugin file. You can use it to validate the
file.

Type: String

Required: No

**fileSize**

The size in bytes of the custom plugin file. You can use it to validate the file.

Type: Long

Required: No
