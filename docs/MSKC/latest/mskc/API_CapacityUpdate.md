# CapacityUpdate

The target capacity for the connector. The capacity can be auto scaled or
provisioned.

## Contents

**autoScaling**

The target auto scaling setting.

Type: [AutoScalingUpdate](API_AutoScalingUpdate.md "API_AutoScalingUpdate.md") object

Required: No

**provisionedCapacity**

The target settings for provisioned capacity.

Type: [ProvisionedCapacityUpdate](API_ProvisionedCapacityUpdate.md "API_ProvisionedCapacityUpdate.md") object

Required: No
