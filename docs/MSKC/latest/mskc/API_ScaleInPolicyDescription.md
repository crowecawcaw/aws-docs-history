

# ScaleInPolicyDescription
<a name="API_ScaleInPolicyDescription"></a>

## Contents
<a name="API_ScaleInPolicyDescription_Contents"></a>

 ** cpuUtilizationPercentage **   <a name="MSKC-Type-ScaleInPolicyDescription-cpuUtilizationPercentage"></a>
Specifies the CPU utilization percentage threshold at which you want connector scale in to be triggered.  
Type: Integer  
Required: No
