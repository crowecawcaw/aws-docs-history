

# WorkerConfigurationRevisionDescription
<a name="API_WorkerConfigurationRevisionDescription"></a>

The description of the worker configuration revision.

## Contents
<a name="API_WorkerConfigurationRevisionDescription_Contents"></a>

 ** creationTime **   <a name="MSKC-Type-WorkerConfigurationRevisionDescription-creationTime"></a>
The time that the worker configuration was created.  
Type: Timestamp  
Required: No

 ** description **   <a name="MSKC-Type-WorkerConfigurationRevisionDescription-description"></a>
The description of the worker configuration revision.  
Type: String  
Required: No

 ** propertiesFileContent **   <a name="MSKC-Type-WorkerConfigurationRevisionDescription-propertiesFileContent"></a>
Base64 encoded contents of the connect-distributed.properties file.  
Type: String  
Required: No

 ** revision **   <a name="MSKC-Type-WorkerConfigurationRevisionDescription-revision"></a>
The description of a revision of the worker configuration.  
Type: Long  
Required: No
