# Monitoring Amazon Verified Permissions API calls

Monitoring is an important part of maintaining the reliability, availability, and
performance of Amazon Verified Permissions and your other AWS solutions. AWS provides the following tools to
monitor Verified Permissions, report when something is wrong, and take automatic actions when
appropriate:

- _AWS CloudTrail_ captures API calls and related events made by or on behalf
  of your AWS account and delivers the log files to an Amazon S3 bucket that you specify. You can
  identify which users and accounts called AWS, the source IP address from which the calls
  were made, and when the calls occurred. For more information, see the [AWS CloudTrail User Guide](../../../awscloudtrail/latest/userguide.md "../../../awscloudtrail/latest/userguide.md").
  For more information about monitoring Verified Permissions with CloudTrail, see [Logging Amazon Verified Permissions API calls using AWS CloudTrail](monitoring-cloudtrail.md "monitoring-cloudtrail.md").
