# Discover and confirm repositories

After [Connect to source code](dotnet-web-connect-source-code.md "dotnet-web-connect-source-code.md"), the agent will scan your source code to discover .NET repositories. In the _Discovery_ phase, you can:

- Review discovered repositories and select which ones to assess for transformation.
- Download a repository report in HTML or JSON.
- [Upload steering documents](dotnet-web-review-and-customize-plan.md "dotnet-web-review-and-customize-plan.md") to customize your transformation.
