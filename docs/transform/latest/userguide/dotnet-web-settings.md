# Transformation settings

## Transformation mode

You can transform in autonomous or interactive mode.

- Use **autonomous mode** for unattended transformation, suitable for overnight or long-running jobs. You'll still have an opportunity to review results and ask for changes after transformation completes.
- Use **interactive mode** to work alongside the agent in chat. This gives you high visibility into transformation, a customizable transformation plan, and [checkpoint reviews](dotnet-web-transform-code.md#working-with-checkpoints "dotnet-web-transform-code.md#working-with-checkpoints") of repositories as the agent transforms them. You can iterate to refine results or change direction until satisfied.

To view or change transformation settings, select the **Transformation settings panel** or choose the **Transformation settings** link in chat. From the right panel, select **Autonomous** or **Interactive** and then **Save Changes**. You can freely switch transformation modes throughout the course of the job. For example, you could begin in interactive mode, review and customize the transformation plan, and then switch to autonomous mode for the remainder.
