# Create a .NET modernization job

After you create or select your workspace, create a .NET modernization job:

1. On the **Jobs** tab, choose **Create job**.
2. In the chat pane, choose **Windows modernization** and then **.NET modernization agent**.
3. Follow the prompts from AWS Transform in the chat pane using natural language.
   After your job starts, a Job Plan tab opens and you are guided to set up your job. This is one of 4 views you can select using the icon buttons at left.

- **Job Plan:** This tab is for job set up, monitoring, and conversing with the agent. You and the agent collaborate on this tab to plan and execute .NET modernizations.
- **Approvals:** Workflow approvals are handled on this tab, such as administrator approval of a repository source code connection.
- **Artifacts:** Artifacts can be downloaded or uploaded to this tab, such as assessment reports, modernization plans, transformed code, transformation report, and next steps.
- **Worklog:** This tab shows the agent's current activity in natural language.
  Take note of the job's browser URL. You can use it to directly return to the job. If you ever need to report an AWS Transform issue, providing the job browser URL helps AWS identify and analyze your job.
