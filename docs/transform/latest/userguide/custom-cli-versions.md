# AWS Transform CLI version history

Review the following table for details about current and past releases of the AWS Transform
CLI. The table includes the version, release date, and release notes for each
version.

| Version        | Release date      | Release notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3.0.0 (latest) | May 21, 2026      | • Added pre-flight transformation name validation<br>that suggests similar names from your registry when a name is<br>not found, helping catch typos without needing a separate list<br>command.<br>• Added optional explanations for shell commands,<br>showing what they do and why.<br>• Improved trust settings banner to include more<br>information about tool permissions.<br>• Added learning-disabled banner when using the<br>do-not-learn flag, giving visibility to the learning feature<br>and how to enable it.<br>• **Breaking change:**<br>Node.js 22 or later is now required. Upgrade from<br>https://nodejs.org/ if you are using an older<br>version.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 2.0.0          | May 14, 2026      | • Added remote MCP server support — connect to<br>HTTP and HTTPS MCP servers with automatic SSE fallback, Bearer<br>token authentication with environment variable expansion in<br>headers, and proxy support<br>(HTTP_PROXY/HTTPS_PROXY).<br>• Added `atx resume` subcommand as alias<br>for `atx --resume`.<br>• Added `grep` tool for multi-file text<br>search with output control — supports regex patterns, file<br>glob filtering, case-insensitive search, configurable<br>depth/result limits, and output truncation.<br>• Improved MCP implementation to use the standard MCP<br>SDK for more consistent behavior and easier support for future<br>MCP features.<br>• Improved shell output handling — output is now<br>gracefully truncated at 30K characters per stream instead of<br>causing a hard error, preserving the beginning and end of output<br>for context.<br>• Fixed an issue where Ctrl+C during an interactive<br>session could prematurely exit the CLI on Linux/macOS instead of<br>aborting the current operation and returning to the<br>prompt.<br>• Fixed trust rejection message to show a dedicated<br>reason for why trust is unavailable, separate from why the<br>command needed authorization.<br>• Fixed dangerous command warning no longer mentions<br>trusting when the command is in<br>`alwaysPromptCommands`. |
| 1.10.0         | April 29, 2026    | • Improved tool descriptions with cross-tool guidance,<br>helping the agent choose the best tool for each task and reducing<br>unnecessary shell usage.<br>• Added `alwaysPromptCommands` in<br>`trust-settings.yaml` — configure shell command<br>patterns that always require explicit permission, regardless of<br>trust settings. Supports glob wildcards and matches against each<br>sub-command in compound expressions.<br>`trustedShellCommands` can override these patterns.<br>Not enforced in non-interactive mode to avoid breaking automated<br>pipelines.<br>• Fixed relative paths not being resolved into absolute<br>paths.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 1.9.0          | April 23, 2026    | • Improved tool approval prompts — each option<br>now shows what it does inline, a “Why” message<br>explains why approval is needed, and trust confirmation includes<br>a hint about `trust-settings.yaml` for permanent<br>trust.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 1.8.0          | April 16, 2026    | • Changed agent output prefix from `>` to<br>`ATX:` for clearer visual distinction between user<br>input and agent output.<br>• Fixed display of resume command when CLI retries are<br>exhausted.<br>• Fixed resume from a different working directory. In<br>interactive mode, prompts for corrected path; in non-interactive<br>mode, fails fast with a descriptive error.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 1.7.1          | April 9, 2026     | • Fixed SSO login failure ("Session token not found or<br>invalid") when the credential provider region differs from the<br>profile's `sso_region`.<br>• Fixed credential caching so long-running sessions no<br>longer fail when credentials are rotated on<br>disk.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 1.7.0          | April 2, 2026     | • Fixed `exec` command to exit with code 1<br>on input validation errors, making the CLI reliable in scripts<br>and CI/CD pipelines.<br>• Added display of warning messages from the<br>service.<br>• Added MFA prompt support for AWS credential<br>profiles.<br>• Fixed STS credential calls to respect HTTP(S) proxy<br>settings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 1.6.0          | March 18, 2026    | • Added `--limit <minutes>` option to<br>set an Agent Minutes budget for `exec` and<br>`interactive` commands. When the limit is reached,<br>the CLI displays usage and exits with resume<br>instructions.<br>• Fixed logging of the initial user message in<br>conversation logs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 1.5.0          | March 11, 2026    | • Added support for concurrent task execution, enabling<br>faster transformations.<br>• Added Agent Minutes usage display at the end of each<br>conversation, and `/usage` command in interactive<br>mode to check usage at any time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 1.4.0          | March 2, 2026     | • Improved error messages when saving transformation<br>definitions with unsupported files.<br>• Added timeout to service calls to prevent the CLI<br>from hanging when the connection is<br>interrupted.<br>• Fixed CLI process hang after successful<br>completion.<br>• Fixed region validation when resuming<br>conversations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 1.3.0          | February 19, 2026 | • Removed restriction for MCP server paths —<br>users may now specify any path for the `command`<br>property in MCP configuration.<br>• Improved stability of MCP server<br>connections.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 1.2.0          | February 9, 2026  | • Added support for proxy configuration via environment<br>variables (`https_proxy`, `no_proxy`,<br>etc.).<br>• General stability improvements and bug<br>fixes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
