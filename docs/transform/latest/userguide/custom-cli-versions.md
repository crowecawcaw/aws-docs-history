# AWS Transform CLI version history

Review the following table for details about current and past releases of the AWS Transform
CLI. The table includes the version, release date, and release notes for each
version.

| Version                 | Release date      | Release notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3.8.0 (latest)          | July 29, 2026     | • Added the `--recurrence` option to<br>`atx ct schedule create`, so you can set a schedule's<br>cadence in plain terms (`daily`,<br>`weekly:<MONDAY..SUNDAY>`, or<br>`monthly:<1..28>`) instead of writing a raw cron<br>expression.<br>• Added the `--existing-scheduler-role-arn`<br>option to `atx ct remote provision`, so you can reuse<br>an IAM role that your administrator has already created for the<br>scheduler instead of having the CLI create one during<br>provisioning.<br>• Added the<br>`--existing-instance-profile-name` option to<br>`atx ct remote provision --mode ec2`, so you can attach<br>an IAM instance profile that your administrator has already created<br>instead of having the CLI create the transform role and instance<br>profile.<br>• Improved transformation selection guidance so that it<br>now uses detection metadata, such as severity and matching<br>criteria, when available. This helps surface the transformations<br>that best fit your project and their relative<br>priority.<br>• Fixed an issue where canceling a scheduled remote<br>analysis stopped the running containers but could leave the<br>analysis stuck in a `running` state. Canceling now<br>reliably marks the analysis as canceled.<br>• Fixed an issue where `atx ct schedule delete`<br>could leave a lingering analysis record behind. Deleting a schedule<br>now also removes the underlying scheduled<br>analysis. |
| 3.7.0                   | July 22, 2026     | • Added the `atx ct remote` command group for<br>running analyses and remediations remotely on EC2 or AWS Batch. You<br>can provision, update, and tear down the remote execution<br>infrastructure, check submission status, detect deployed stacks, and<br>manage source credentials in AWS Secrets Manager.<br>• Added the `atx ct schedule` command group for<br>recurring scheduled analysis and remediation jobs. You can create,<br>list, enable, disable, and delete schedules (job options mirror<br>`remote analysis` and `remote remediation`),<br>plus `setup` and `teardown` for the scheduler<br>infrastructure. Schedules capture local source bundles at create<br>time.<br>• Improved `atx ct analysis run` to consume<br>tech-debt-quick matching rules from the transformation package<br>registry.<br>• Improved long-running `atx ct` commands to<br>show progress output, including per-repo progress during analysis<br>runs (including security analyses) and per-repo failure reasons in<br>remediation status.<br>• Fixed several remote execution reliability issues. EC2<br>status now shows findings and pull request results, matching Batch;<br>EC2 updates no longer fail on stacks missing new parameters; and<br>additional fixes address exit codes, transform handling, tag-based<br>detection, and JSON output.                                                                                               |
| 3.6.0                   | July 17, 2026     | • Added the `atx custom def learnings`<br>subcommand, which opens an interactive TUI session to view and<br>manage the learnings automatically generated for a transformation<br>definition based on previous runs.<br>• Added usage telemetry collection during transformation<br>execution. To disable telemetry, set the<br>`ATX_DISABLE_TELEMETRY=true` environment variable. For<br>more information, see [Usage Telemetry](transform-usage-telemetry.md "transform-usage-telemetry.md").<br>• Fixed an issue on Windows where file operations<br>using `~` (home directory) paths resolved to an<br>unexpected directory. This caused file read/write failures<br>during a session.<br>• Fixed an issue where MCP server and tool names<br>containing special characters could cause connection failures.<br>The CLI now automatically sanitizes names to use only valid<br>characters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 3.5.0                   | July 8, 2026      | • Added native Windows support. You can now run the<br>AWS Transform Custom commands directly on Windows. (The `atx ct` commands<br>are not yet supported on Windows)<br>• Added steering inputs to `atx ct analysis<br>run` so agentic-readiness and modernization-readiness<br>analyses reflect your preferences. Use `--context`<br>for strategic framing, `--agent-scope` to set agent<br>access for agentic-readiness, and<br>`--prefer`/`--avoid` to steer<br>modernization recommendations toward or away from specific<br>technologies.<br>• Transformation definitions in the skill format can<br>now include a `scripts/` folder, letting you bundle<br>helper scripts alongside your `SKILL.md` and<br>references.<br>• Added `--wait` to `atx ct<br>remediation create`, which waits until the remediation<br>completes.<br>• Added headless mode for one-shot execution. Run<br>`atx -x "prompt" -t` to pass a prompt, get a<br>response, and exit with no interactive prompts. Headless mode<br>requires trusting all tools.                                                                                                                                                                                                                                                                                                                                                                                                         |
| 3.4.1                   | July 2, 2026      | • Fixed an interactive-session issue that version<br>3.4.0 introduced. After the agent finishes responding, the CLI<br>might stay on the "Thinking" prompt (shown with an<br>ellipsis in the UI) instead of returning to the input prompt.<br>The CLI now returns you to the input prompt after each<br>response.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 3.4.0 (not recommended) | June 29, 2026     | Known issueIn interactive sessions, the CLI might stay on the<br>"Thinking" prompt (shown with an ellipsis in the UI)<br>after the agent finishes responding. This prevents you from<br>entering your next message. To resolve this issue, upgrade to<br>version 3.4.1 or later by running<br>`atx update`.<br>• Added `atx ct schema`, a<br>machine-readable manifest of the full `atx ct`<br>command surface for scripting and automation.<br>• Added token scope validation when you add or<br>update a source, surfacing credential or permission issues<br>immediately instead of failing later during<br>analysis.<br>• Improved auto-remediation pull requests to include<br>finding context and support draft mode for more reviewable<br>PRs.<br>• Improved CLI progress feedback with real-time<br>context about the current activity, estimated agent minutes,<br>and sub-agent activity.<br>• Added configurable checkpoint commit author<br>identity through the `ATX_GIT_COMMITTER_NAME` and<br>`ATX_GIT_COMMITTER_EMAIL` environment<br>variables.<br>• Various small bug fixes and<br>improvements.                                                                                                                                                                                                                                                                                                                                |
| 3.3.0                   | June 18, 2026     | • Added consistent `--json` and<br>`--help` support across `atx ct`<br>commands.<br>• Fixed security agent setup so the agent space is<br>created during setup and removed on teardown.<br>• Various small bug fixes and<br>improvements.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 3.2.0                   | June 15, 2026     | • Added continuous modernization commands<br>(`atx ct`) to the standard CLI distribution for<br>all users.<br>• Improved sub-agent execution to show a<br>"Thinking..." spinner while waiting for server<br>responses, providing clear visual feedback that work is in<br>progress.<br>• Improved spinner to automatically restart with<br>"Working on it..." after 3 seconds of silence<br>following agent output, so the terminal never appears frozen<br>between processing steps.<br>• Improved thinking spinner with a subtle shimmer<br>animation for a more polished visual<br>appearance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 3.1.0                   | June 3, 2026      | • Added `ATX_MAX_VALIDATION_LOOPS`<br>environment variable to configure maximum validation<br>loops.<br>• Fixed update check no longer shows false<br>"update available" warnings when the installed<br>version is already newer than the registry<br>version.<br>• Fixed `delete<br>--transformation-name ""` no longer shows a<br>nonsensical confirmation prompt; empty values are now rejected<br>with a clear validation error.<br>• Fixed unrecognized subcommands now show<br>"unknown command" instead of a confusing internal<br>error message.<br>• Fixed version comparison to use numeric comparison<br>instead of string inequality for update<br>checks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 3.0.0                   | May 21, 2026      | • Added pre-flight transformation name validation<br>that suggests similar names from your registry when a name is<br>not found, helping catch typos without needing a separate list<br>command.<br>• Added optional explanations for shell commands,<br>showing what they do and why.<br>• Improved trust settings banner to include more<br>information about tool permissions.<br>• Added learning-disabled banner when using the<br>do-not-learn flag, giving visibility to the learning feature<br>and how to enable it.<br>• **Breaking change:**<br>Node.js 22 or later is now required. Upgrade from<br>https://nodejs.org/ if you are using an older<br>version.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 2.0.0                   | May 14, 2026      | • Added remote MCP server support — connect to<br>HTTP and HTTPS MCP servers with automatic SSE fallback, Bearer<br>token authentication with environment variable expansion in<br>headers, and proxy support<br>(HTTP\_PROXY/HTTPS\_PROXY).<br>• Added `atx resume` subcommand as alias<br>for `atx --resume`.<br>• Added `grep` tool for multi-file text<br>search with output control — supports regex patterns, file<br>glob filtering, case-insensitive search, configurable<br>depth/result limits, and output truncation.<br>• Improved MCP implementation to use the standard MCP<br>SDK for more consistent behavior and easier support for future<br>MCP features.<br>• Improved shell output handling — output is now<br>gracefully truncated at 30K characters per stream instead of<br>causing a hard error, preserving the beginning and end of output<br>for context.<br>• Fixed an issue where Ctrl+C during an interactive<br>session could prematurely exit the CLI on Linux/macOS instead of<br>aborting the current operation and returning to the<br>prompt.<br>• Fixed trust rejection message to show a dedicated<br>reason for why trust is unavailable, separate from why the<br>command needed authorization.<br>• Fixed dangerous command warning no longer mentions<br>trusting when the command is in<br>`alwaysPromptCommands`.                                                                                      |
