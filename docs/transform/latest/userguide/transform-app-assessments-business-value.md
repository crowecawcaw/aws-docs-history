

# Business value assessments
<a name="transform-app-assessments-business-value"></a>

AWS Transform evaluates the broader business value of migration beyond infrastructure cost savings. The business value assessment quantifies benefits across the pillars of the AWS Cloud Value Framework, so you can present a business case that reflects the full value of moving to AWS, not just the change in run-rate cost.

You can run the business value assessment alongside your compute, storage, database, and analytics assessments, or on its own from a small set of high-level inputs when you do not yet have a detailed inventory. The assessment is deterministic and benchmark-driven: the same inputs always produce the same result, and the figures are directional estimates rather than commitments.

## Value pillars
<a name="transform-app-assessments-business-value-pillars"></a>

AWS Transform quantifies value across the following pillars:
+ **Staff productivity**—savings from administering fewer servers and less storage after migrating to managed AWS services, based on improvements in the number of virtual machines and terabytes each administrator can manage.
+ **Operational resilience**—savings from reduced unplanned downtime and fewer critical incidents, based on industry benchmarks applied to your annual revenue.
+ **Business agility**—value from faster developer throughput and time to market, based on benchmarks applied to your developer headcount.

AWS Transform reports the value of each pillar and the total quantified benefit as annual figures.

## Inputs
<a name="transform-app-assessments-business-value-inputs"></a>

The business value assessment uses a small set of organizational inputs to select the appropriate benchmarks. You can provide these through chat.
+ Your industry, chosen from a set of supported industry categories
+ Annual revenue
+ Total number of employees
+ Total server count and total storage capacity
+ Your AWS Support level (Business or Enterprise)

You can also adjust optional assumptions, such as the percentage of your workload that is in scope for the migration and the assumed annual IT staff salary used in the staff productivity calculation.

## Sustainability
<a name="transform-app-assessments-business-value-sustainability"></a>

As part of the business case, AWS Transform estimates the carbon footprint reduction that results from migrating to AWS, consistent with the sustainability pillar of the AWS Well-Architected Framework. You can explore sustainability metrics through chat.

## Example prompts
<a name="transform-app-assessments-business-value-prompts"></a>
+ "Estimate the business value of migrating to AWS for my organization"
+ "Estimate staff productivity gains from migrating to AWS"
+ "What resilience improvements can I expect after migration?"
+ "Show me the estimated carbon reduction for this migration"
