# Release notes

This section describes the features, improvements, and bug fixes for the AWS Transform discovery tool, organized by release date.

| Date              | Version  | Release notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| April 7, 2026     | 1.0.1074 | **New features**<br>• Added support for Microsoft Hyper-V discovery, including auto-discovery of VMs from Hyper-V hosts with failover cluster deduplication.<br>• Added support for bare metal (physical) server import through CSV file upload.<br>• Added OS metrics collection with six independent modules: server performance, storage performance, server provisioning, storage provisioning, network interfaces, and running processes.<br>• Added Hyper-V deployment option using a VHD image file.<br>• Improved on-premises security hardening by removing EC2-specific services and blocking access to the instance metadata endpoint. |
| March 26, 2026    | 1.0.1014 | **Bug fixes and improvements**<br>• Moved Kerberos domain capitalization validation from backend to frontend.<br>• Switched from Python-kerberos to Python-pykerberos and made file-based cache the default.<br>• Fixed case-insensitive bulk edit server ID validation.<br>• Fixed export ZIP filename (now `discovery_tool_export.zip`).<br>• Fixed service running check and added debug logs for system credentials.<br>• Added network configuration script to build artifact.                                                                                                                                                               |
| December 16, 2025 | 1.0.718  | **New features and improvements**<br>• Added SMBIOS UUID support to prevent VM duplication in downstream services.<br>• Introduced Min/Max/Avg tracking and expanded storage metrics for improved resource monitoring.<br>• Added API validation improvements.<br>• Added help panel functionality with contextual guidance.<br>• Updated terminology from "collector" to "tool" throughout the interface.                                                                                                                                                                                                                                        |
| October 31, 2025  | 1.0.0    | **Initial release**<br>Initial launch of the AWS Transform discovery tool. This release includes:<br>• Offline collection (no dependency on an AWS account or Application Discovery Service).<br>• VMware discovery and monitoring.<br>• SQL Server database discovery.<br>• Server-to-server communication collection through SSH, WMI, and SNMP.                                                                                                                                                                                                                                                                                                |
