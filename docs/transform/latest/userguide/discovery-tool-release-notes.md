| September 3, 2026 | 1.0.2325 | *_New features_<br>• <br>• Added disk monitoring and storage management. The discovery tool now tracks its own disk usage and warns you as space runs low. It pauses collection at 90% usage to avoid filling the disk. You can set how long the tool keeps data, for all modules or per module. You can also see usage by module and delete older data on the *_Settings_<br>• page.<br>• Added `unmapped_storage_devices.csv` to the export. The discovery tool adds a device to this file when it cannot match the device to a mounted file system, or when the device reports no usable capacity.<br>*_Improvements_<br>• <br>• Improved Kerberos authentication for Windows servers. When the discovery tool knows a server's fully qualified domain name (FQDN), it now uses the FQDN first for Kerberos credentials. That order matches how Active Directory registers service principal names. You can still use IP addresses. The discovery tool maps the IP address to the FQDN with a reverse DNS lookup.<br>• Kerberos authentication now backs off after an unusable credential, such as an incorrect or expired password, instead of retrying every collection cycle. Threads that share one credential now make a single attempt between them. Both changes lower the risk of Active Directory account lockout.<br>• Added 95th percentile (`_p95`) columns to the OS metrics CSV exports.<br>• Renamed the disk throughput columns in the OS metrics CSV exports from `_mbps` to `_mibps`. The values do not change. They were already reported in mebibytes per second (MiBps).<br>• Improved the collection status for a virtual machine that reports no usable address. The discovery tool now reports why it cannot reach the machine, including the status of VMware Tools or Integration Services, instead of reporting only that no valid address was found.<br>*_Bug fixes_<br>• <br>• Fixed Linux disk IOPS and throughput values. The discovery tool now samples a live interval instead of reading the average since the host last started, which underreported both values.<br>• Fixed exports that could fail on a large server inventory. The discovery tool now measures the memory available to its own service, estimates the size of network data more accurately, and runs one export at a time.<br>• Fixed the loss of collected network connection data when the discovery tool service restarts. |
| June 30, 2026     | 1.0.1646 | **New features**<br>• Added Oracle Database discovery. The tool collects CDB and PDB topology, version, edition, installed options, feature usage, and component inventory. The discovery tool supports direct SQL connections (using SELECT\_CATALOG\_ROLE) and OS-level fallback detection through SSH or WinRM.<br>• Added support for multiple Kerberos credentials across different Active Directory domains. Each credential authenticates independently, enabling collection from Windows servers in multiple domains without authentication conflicts.<br>**Improvements**<br>• Improved OS metrics collection for legacy hosts. Added fallback data collection for older operating systems (RHEL 5, SLES 11, Windows Server 2008 R2) where modern commands are unavailable. Storage, performance, and network interface data is now collected using alternative system interfaces.<br>**Bug fixes**<br>• Fixed Kerberos authentication failures for servers discovered through Hyper-V. The discovery tool now correctly resolves the server hostname (FQDN) from Hyper-V guest metadata, which is required for Kerberos SPN matching.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| May 14, 2026      | 1.0.1363 | **New features**<br>• Added Linux installer for deploying the discovery tool on supported Linux distributions (Amazon Linux 2, Amazon Linux 2023, RHEL 8–9, Rocky Linux 8–9, AlmaLinux 9, Ubuntu 20.04–24.04, Debian 10–12, SLES 15 SP5).<br>• Added support for configuring multiple VMware vCenter servers with automatic VM deduplication across vCenters.<br>• Added SSH private key authentication as an alternative to username and password for Linux OS access. Supported key formats include RSA, ECDSA, Ed25519, OpenSSH, and PKCS#8.<br>• Added private address network collection to capture connections to and from RFC 1918 private IP addresses not in your discovered inventory.<br>• Added export options to select a custom date range and choose which data modules to include in the export.<br>**Improvements**<br>• Improved scheduled collection reliability by staggering collector schedules.<br>• Improved OS metrics collection performance through SSH command batching.<br>• Credential changes now immediately retry previously failed servers.<br>• OS metrics collection now reports partial status when some commands return empty results.<br>• Improved error visibility for vCenter connection issues in the dashboard.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
