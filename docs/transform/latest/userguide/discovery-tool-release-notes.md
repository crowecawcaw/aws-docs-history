# Release notes

This section describes the features, improvements, and bug fixes for the AWS Transform discovery tool, organized by release date.

| Date              | Version  | Release notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| June 30, 2026     | 1.0.1646 | **New features**<br>• Added Oracle Database discovery. The tool collects CDB and PDB topology, version, edition, installed options, feature usage, and component inventory. The discovery tool supports direct SQL connections (using SELECT\_CATALOG\_ROLE) and OS-level fallback detection through SSH or WinRM.<br>• Added support for multiple Kerberos credentials across different Active Directory domains. Each credential authenticates independently, enabling collection from Windows servers in multiple domains without authentication conflicts.<br>**Improvements**<br>• Improved OS metrics collection for legacy hosts. Added fallback data collection for older operating systems (RHEL 5, SLES 11, Windows Server 2008 R2) where modern commands are unavailable. Storage, performance, and network interface data is now collected using alternative system interfaces.<br>**Bug fixes**<br>• Fixed Kerberos authentication failures for servers discovered through Hyper-V. The discovery tool now correctly resolves the server hostname (FQDN) from Hyper-V guest metadata, which is required for Kerberos SPN matching.                                                                                                             |
| May 14, 2026      | 1.0.1363 | **New features**<br>• Added Linux installer for deploying the discovery tool on supported Linux distributions (Amazon Linux 2, Amazon Linux 2023, RHEL 8–9, Rocky Linux 8–9, AlmaLinux 9, Ubuntu 20.04–24.04, Debian 10–12, SLES 15 SP5).<br>• Added support for configuring multiple VMware vCenter servers with automatic VM deduplication across vCenters.<br>• Added SSH private key authentication as an alternative to username and password for Linux OS access. Supported key formats include RSA, ECDSA, Ed25519, OpenSSH, and PKCS#8.<br>• Added private address network collection to capture connections to and from RFC 1918 private IP addresses not in your discovered inventory.<br>• Added export options to select a custom date range and choose which data modules to include in the export.<br>**Improvements**<br>• Improved scheduled collection reliability by staggering collector schedules.<br>• Improved OS metrics collection performance through SSH command batching.<br>• Credential changes now immediately retry previously failed servers.<br>• OS metrics collection now reports partial status when some commands return empty results.<br>• Improved error visibility for vCenter connection issues in the dashboard. |
| April 7, 2026     | 1.0.1074 | **New features**<br>• Added support for Microsoft Hyper-V discovery, including auto-discovery of VMs from Hyper-V hosts with failover cluster deduplication.<br>• Added support for server import through CSV file upload.<br>• Added OS metrics collection with six independent modules: server performance, storage performance, server provisioning, storage provisioning, network interfaces, and running processes.<br>• Added Hyper-V deployment option using a VHD image file.<br>• Improved on-premises security hardening by removing EC2-specific services and blocking access to the instance metadata endpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| March 26, 2026    | 1.0.1014 | **Bug fixes and improvements**<br>• Moved Kerberos domain capitalization validation from backend to frontend.<br>• Switched from Python-kerberos to Python-pykerberos and made file-based cache the default.<br>• Fixed case-insensitive bulk edit server ID validation.<br>• Fixed export ZIP filename (now `discovery_tool_export.zip`).<br>• Fixed service running check and added debug logs for system credentials.<br>• Added network configuration script to build artifact.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| December 16, 2025 | 1.0.718  | **New features and improvements**<br>• Added SMBIOS UUID support to prevent VM duplication in downstream services.<br>• Introduced Min/Max/Avg tracking and expanded storage metrics for improved resource monitoring.<br>• Added API validation improvements.<br>• Added help panel functionality with contextual guidance.<br>• Updated terminology from "collector" to "tool" throughout the interface.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| October 31, 2025  | 1.0.0    | **Initial release**<br>Initial launch of the AWS Transform discovery tool. This release includes:<br>• Offline collection (no dependency on an AWS account or Application Discovery Service).<br>• VMware discovery and monitoring.<br>• SQL Server database discovery.<br>• Server-to-server communication collection through SSH, WMI, and SNMP.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
