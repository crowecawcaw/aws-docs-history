

# Document history for the AWS Transform User Guide
<a name="doc-history"></a>

The following table describes the document history for the AWS Transform User Guide.

| Change | Description | Date | 
| --- |--- |--- |
| [Run migrations with the AWS Transform MCP server](#doc-history) | Added a topic describing how to plan and run AWS Transform migrations from an MCP-compatible AI assistant, such as Kiro, Claude Code, Cursor, or Cline, by using the AWS Transform Model Context Protocol (MCP) server. The topic covers setup, authentication, the migration workflow, best practices, and example prompts. For more information, see [Run migrations with the AWS Transform MCP server](https://docs.aws.amazon.com/transform/latest/userguide/transform-migrations-mcp.html). | September 4, 2026 | 
| [Updated discovery tool documentation for release 1.0.2325](#doc-history) | The discovery tool guide now covers disk monitoring and storage management. It also covers using Kerberos with IP addresses. The guide documents the new `unmapped_storage_devices.csv` export file. It also lists the renamed disk throughput columns and the new 95th percentile columns. For more information, see [Managing discovery tool storage](https://docs.aws.amazon.com/transform/latest/userguide/discovery-tool-storage.html). | September 3, 2026 | 
| [Updated .NET agent web application experience](#doc-history) | Restructured the .NET agent documentation to reflect an updated web application experience, connecting to repository by Personal Access Token, and transformation mode, checkpoints, and beaming features. Added guidance for choosing between the web application and IDE experiences. | September 3, 2026 | 
| [Migrations adds Amazon FSx for NetApp ONTAP support](#doc-history) | AWS Transform for migrations now supports Amazon FSx for NetApp ONTAP as a generally available block storage target, alongside Amazon Elastic Block Store (Amazon EBS). This capability is available in all AWS Transform supported target Regions and where Amazon FSx for NetApp ONTAP is supported. See [Configuring FSx for ONTAP as a target storage type](https://docs.aws.amazon.com/mgn/latest/ug/fsx-ontap.html). | August 30, 2026 | 
| [Network migration adds security posture migration to existing VPCs](#doc-history) | You can now apply your source security posture to VPCs you have already provisioned in AWS, instead of creating new VPCs. | [Guided network recommendations add application alignment](#doc-history) | Guided network recommendations can now identify VPCs that host applications from multiple environments and suggest splitting them along subnet boundaries to isolate environments such as development and production. See [Compute options](https://docs.aws.amazon.com/transform/latest/userguide/continuous-modernization.html#ct-compute-aws-managed). | August 7, 2026 | 
| [Continuous modernization adds remote execution, scheduling, and tagging](#doc-history) | Continuous modernization now includes `atx ct remote` commands to provision and run analyses and remediations on Amazon EC2 or AWS Batch, `atx ct schedule` commands to run recurring analyses with Amazon EventBridge Scheduler, and resource tagging for attribute-based access control (ABAC). New AWS managed policies support least-privilege remote and security agent execution. The `atx ct server` command is deprecated. See [Working with continuous modernization](https://docs.aws.amazon.com/transform/latest/userguide/continuous-modernization.html#ct-working-with). | July 28, 2026 | 
| [Continuous modernization portfolio analysis and remediation](#doc-history) | Added new chapter documenting the AWS Transform continuous modernization feature (`atx ct` subcommands) for automated code analysis and remediation.
