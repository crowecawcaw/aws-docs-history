

# Full-stack Windows modernization
<a name="windows-full-stack"></a>

AWS Transform provides full-stack Windows modernization, including .NET modernization and SQL Server modernization.

The [AWS Transform agent for .NET](dotnet.md) can help you modernize your .NET applications for compatibility with cross-platform .NET. You can modernize .NET applications at scale from a web application, or work on individual solutions from Visual Studio IDE.

AWS Transform for [SQL Server modernization](https://docs.aws.amazon.com/transform/latest/userguide/sql-server-modernization.html) is an AI-powered service that automates the full-stack modernization of Microsoft SQL Server databases and their associated .NET applications to Amazon Aurora PostgreSQL. The service orchestrates the entire migration journey from schema conversion, data migration and modifying application code to match the new target PostgreSQL, making your teams more productive by automating complex and labor-intensive tasks.
