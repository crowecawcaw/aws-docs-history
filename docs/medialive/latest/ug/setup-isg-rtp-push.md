# Create an input security group

You must create an input security group. The security group must allow the
_public network IP addresses_ to push to MediaLive.
Following from the earlier example, it must allow these addresses:

203.0.113.19, 203.0.113.58, 203.0.113.25, 198.51.100.19, 198.51.100.59, 198.51.100.21

For details about creating an input security group, see [Creating an input security group](create-input-security-groups.md "create-input-security-groups.md").
