# List of alerts for channels

The following table lists the alerts that MediaLive might generate for a channel. You can view
these alerts in these ways:

- You can view the alerts for each channel on the MediaLive console. For more
  information, see [Alerts tab – Viewing
  alerts](monitoring-console-general.md#view-alerts "monitoring-console-general.md#view-alerts").
- You use your preferred AWS SDK or API to monitor alerts about channel activity.
  For more information, see [Monitoring alerts using the AWS SDKs or API](monitoring-api.md "monitoring-api.md").
- MediaLive turns alerts into CloudWatch events with the detailType set to `MediaLive
Channel Alert`. For an example of the JSON for these events, see [JSON
  for a state change event](monitoring-cloudwatch-json-state-change.md "monitoring-cloudwatch-json-state-change.md").
