# Fields for an input switch

This section describes how to complete the fields for these three types of
input switches:

- A switch to a static live input
- A switch to a static file input
- A switch to a dynamic file input

###### Topics

- [Fields for a switch to a
  static live input](#schedule-fields-ips-static-live "#schedule-fields-ips-static-live")
- [Fields for a switch to a
  static file input](#schedule-fields-ips-static-file "#schedule-fields-ips-static-file")
- [Fields for a switch to a
  dynamic file input](#schedule-fields-ips-static-dynamic "#schedule-fields-ips-static-dynamic")

## Fields for a switch to a

static live input

This table shows the fields that apply for an action to switch to a static
live input.

| Field                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Action name**           | A name for this input switch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Action type**           | Input Switch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Input attachment**      | The live input to switch to. The input must already be<br>set up as an [input<br>attachment](creating-a-channel-step2.md "creating-a-channel-step2.md") in this channel. For example, if<br>you want to switch from input A to input B, specify<br>input B in this field.                                                                                                                                                                                                                                                                                                                          |
| **Start type**            | **Fixed**,<br>**Immediate**, or<br>**Follow**. For information about start<br>types for input prepare, see [Fixed, immediate, and follow switches](ips-switch-types.md "ips-switch-types.md").                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Date and time**         | If the **Start type\*<br>• is<br>**Fixed\*\*, specify the date and time<br>(in UTC format) that the channel must switch to this new<br>input. This time must be at least 30 seconds in the<br>future.Note that the time is the wall clock time,<br>not the timecode in the input.                                                                                                                                                                                                                                                                                                                  |
| **Reference action name** | If the **Start type\*<br>• is<br>**Follow\**, choose the input to<br>switch from, which is the input that precedes this new<br>input. The dropdown list shows all existing input<br>switches that are file inputs. Remember that input B can<br>follow input A only if input A is a file input and the<br>source end behavior for input A is *continue\*.<br>For information about these switching rules, see [Fixed, immediate, and follow switches](ips-switch-types.md "ips-switch-types.md").<br>For example, if you want to switch from input A to<br>input B, specify input A in this field. |
| **Follow point**          | If the **Start type\*<br>• is<br>**Follow**, complete this field. The<br>follow point is always **End**, to indicate<br>that the switch will occur when the input in<br>**Reference action name\*<br>• has<br>finished.                                                                                                                                                                                                                                                                                                                                                                            |

## Fields for a switch to a

static file input

This table shows the fields that apply for an action to switch to a static
file input.

| Field                                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Action name**                                                                   | A name for this input switch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Action type**                                                                   | Input Switch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Input attachment**                                                              | The file input to switch to. The input must already be<br>set up as an [input<br>attachment](creating-a-channel-step2.md "creating-a-channel-step2.md") in this channel. For example, if<br>you want to switch from input A to input B, specify<br>input B in this field.                                                                                                                                                                                                                                                                 |
| **Input clippings settings\*<br>• –<br>**Enable input clipping\*\*                | This field appears only for a file input that is [eligible for input<br>clipping](input-clipping.md "input-clipping.md").Enable the field if you want to<br>clip the file at the start and end, or only at the<br>start, or only at the end.                                                                                                                                                                                                                                                                                              |
| **Input clippings settings\*<br>• –<br>**Input timecode source\*\*                | Choose the source:<br>Zero-based – To set the start and end times<br>relative to the start of the file, which is<br>00:00:00:00.<br>Embedded – To set the times based on the<br>timecode in the file. The file must have a timecode,<br>otherwise the clipping instruction is ignored.                                                                                                                                                                                                                                                    |
| **Input clippings settings\*<br>• –<br>**Start timecode**, **Stop<br>timecode\*\* | Complete one or both fields. Enter values in the<br>format hh:mm:ss:ff.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Input clippings settings\*<br>• –<br>**Last frame clipping<br>behavior\*\*      | This field appears only if you specify a stop timecode.<br>Exclude last frame – Clip the file before<br>the frame specified in the end timecode. For example, if<br>the end timecode is 01:00:30:19, don't include frame<br>19.Include last frame – Don't clip<br>the file. In the preceding example, include frame<br>19.                                                                                                                                                                                                                |
| **Start type**                                                                    | **Fixed**,<br>**Immediate**, or<br>**Follow**. For information about start<br>types for input prepare, see [Fixed, immediate, and follow switches](ips-switch-types.md "ips-switch-types.md").                                                                                                                                                                                                                                                                                                                                            |
| **Date and time**                                                                 | If the **Start type\*<br>• is<br>**Fixed\*\*, specify the date and time<br>(in UTC format) that the channel must switch to this new<br>input. This time must be at least 30 seconds in the<br>future.Note that the time is the wall clock time,<br>not the timecode in the input.                                                                                                                                                                                                                                                         |
| **Reference action name**                                                         | If the **Start type\*<br>• is<br>**Follow\*\*, choose the input to<br>switch from, which is the input that precedes this new<br>input. The dropdown list shows all existing input<br>switches that are file inputs. Remember that input B can<br>follow input A only if input A is a file input. For<br>information about these switching rules, see [Fixed, immediate, and follow switches](ips-switch-types.md "ips-switch-types.md").<br>For example, if you want to switch from input A to<br>input B, specify input A in this field. |
| **Follow point**                                                                  | If the **Start type\*<br>• is<br>**Follow**, complete this field. The<br>follow point is always **End**, to indicate<br>that the switch will occur when the input in<br>**Reference action name\*<br>• has<br>finished.                                                                                                                                                                                                                                                                                                                   |
