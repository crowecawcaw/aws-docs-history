# Handling SMPTE 2038 metadata

You can configure MediaLive to extract specific ancillary data from a SMPTE
2038 stream contained in these inputs:

- Elemental Link inputs
- HLS transport stream (TS) inputs
- MediaConnect inputs
- RTP inputs
- SRT Caller
  inputs
- SRT Listener inputs

###### Note

This section assumes that you are familiar with creating or editing
a channel, as described in [Creating a channel from scratch](creating-channel-scratch.md "creating-channel-scratch.md").
