# Design the selectors for each input

After you follow step 3 to organize sources into different inputs and input types (static
and dynamic), you must identify the content to extract from each MediaLive input.

**Result of This Step**

After this step you have:

- Names for all the inputs
- A list of video, audio, and captions selectors for each input
