# Setting up a CDI input

This section describes how to create a CDI push input. With a CDI source, the upstream
system _pushes_ the content to MediaLive.

To perform this setup, you must work with an Amazon VPC user, with an operator at the
upstream system, and you must work within MediaLive.

###### Note

Make sure that the content provider is using the latest version of the [AWS CDI SDK](https://aws.amazon.com/media-services/resources/cdi/ "https://aws.amazon.com/media-services/resources/cdi/") on
their CDI source device.
