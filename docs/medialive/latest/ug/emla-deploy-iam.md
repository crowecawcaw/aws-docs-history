# Setting up in IAM for MediaLive Anywhere

You must perform some setup in AWS Identity and Access Management. You must perform this setup before you or any
other user can create the network, cluster, and nodes on the MediaLive Console.

A user who is already set up as an IAM user or administrative user performs the tasks in
this section.
