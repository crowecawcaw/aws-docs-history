# Monitoring smart crop activity

You can monitor smart crop activity using these AWS services:

- Metrics that Amazon CloudWatch produces, using data sent by Elemental Inference. See [Monitoring
  AWS Elemental Inference with Amazon CloudWatch](../../../elemental-inference/latest/userguide/monitoring-cloudwatch.md "../../../elemental-inference/latest/userguide/monitoring-cloudwatch.md") in the _AWS Elemental Inference user
  guide_.
- Events that Elemental Inference produces. You can use Amazon EventBridge to work with these events.
  See [Monitoring
  AWS Elemental Inference events with Amazon EventBridge](../../../elemental-inference/latest/userguide/monitoring-events.md "../../../elemental-inference/latest/userguide/monitoring-events.md") in the _AWS Elemental Inference user
  guide_.
- Actions that Amazon EventBridge takes and that are collected by AWS CloudTrail. See [Monitoring Elemental Inference API calls with AWS CloudTrail](../../../elemental-inference/latest/userguide/logging-using-cloudtrail.md "../../../elemental-inference/latest/userguide/logging-using-cloudtrail.md") in the
  _AWS Elemental Inference user guide_.
