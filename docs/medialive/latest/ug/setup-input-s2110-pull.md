# Create a SMPTE 2110 input

After you have obtained information from the upstream system, you can create a
SMPTE 2110 input.

###### To create an SMPTE 2110 input

1. Make sure that you have the information from [step 1](setup-s2110-pull-obtain-info.md "setup-s2110-pull-obtain-info.md").
2. Open the MediaLive console at [https://console.aws.amazon.com/medialive/](https://console.aws.amazon.com/medialive/ "https://console.aws.amazon.com/medialive/").
3. In the navigation pane, choose **Inputs**. On the
   **Inputs** page, choose **Create
   input**.
4. Complete the **SMPTE 2110 Receiver Group** section as
   described in the table that follows this procedure.
5. In the **Tags** section, create tags if you want to
   associate tags with this input. For more information, see [Tagging resources](tagging.md "tagging.md").
6. Choose **Create**.

MediaLive creates the input and adds it to the list of inputs. The input
identifies the locations of the SDP files that contain information about the
SMPTE 2110 streams.

When you start the channel, MediaLive will retrieve the SDP files. It will
obtain the location of the SMPTE 2110 streams from the files. It will
connection to those locations and pull the content that you specified when
you [attach the input to the
channel](creating-a-channel-step2.md "creating-a-channel-step2.md").

| **Audio SDPs**     | Enter information for each for each audio SDP file and audio line combination.See the example after this table.                                                                                                           |
