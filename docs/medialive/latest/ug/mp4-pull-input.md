# Setting up an MP4 input

This section describes how to set up the source content on the upstream system, and
how to create an MP4 input that connects the content source to MediaLive.

With an MP4 input, MediaLive connects to the upstream system when the channel starts and
_pulls_ the sources.

To perform this setup, you must work with an operator at the upstream system.
