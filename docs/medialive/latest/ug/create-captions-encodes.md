# Create captions encodes

As the final step in setting up captions in a MediaLive channel, you must set up the
captions in each output group. For each output and captions format that you identified, follow
the procedure that applies to the format category:

- [Create embedded or object captions
  encodes](output-embedded-and-more.md "output-embedded-and-more.md")
- [Create sidecar or SMPTE-TT captions
  encodes](output-sidecar-and-smptett-mss.md "output-sidecar-and-smptett-mss.md")
