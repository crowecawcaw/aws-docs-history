# Setting up an RTMP pull input

This section describes how to set up the source content on the upstream system, and
how to create an RTMP pull input that connects the upstream system to MediaLive.

With an RTMP Pull input, MediaLive connects to the upstream system when the channel starts
and _pulls_ the sources.

To perform this setup, you must work with an operator at the upstream system.
