# Setup: Creating output encodes in a

channel

This section describes how to create video, audio, and captions output encodes in a MediaLive
channel. You create these encodes as part of the task of [creating the output groups and outputs](medialive-outputs.md "medialive-outputs.md") in a channel. You should have already
[identified](planning-the-channel-in-workflow.md "planning-the-channel-in-workflow.md") and [planned the outputs and encodes to include](plan-encodes.md "plan-encodes.md") in each output
group.

The step of creating encodes is integrated into the step of creating output groups as part
of the channel. If you haven't started to created the output groups yet, see [Setup: Creating output groups and outputs](medialive-outputs.md "medialive-outputs.md").
