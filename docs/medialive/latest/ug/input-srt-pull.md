To verify that the input is set up correctly, look at the **SRT caller
settings** section. It shows the locations of the source video. This is
the locations of the SRT listener. You specified these locations when you created
the input:

- If the channel is set up as a standard channel, you specified two
  locations.
- If the channel is set up as a single-pipeline channel, you specified one.
  For example, the information for one location, when source encryption is disabled:

- **SRT listener address: 192.0.2.120**
- **SRT listener port: 7001**
- **Stream ID: mystream**
