# Pricing to view MediaLive metrics

There is no charge to view metrics on the [Health tab](eml-metrics-view.md "eml-metrics-view.md") of the MediaLive console.

For information about charges to view metrics on the CloudWatch console
or to retrieve metrics using a CloudWatch API, see the [Amazon CloudWatch User Guide](../../../AmazonCloudWatch/latest/monitoring.md "../../../AmazonCloudWatch/latest/monitoring.md").
