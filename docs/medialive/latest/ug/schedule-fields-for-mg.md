# Fields for activating a motion graphics

overlay

This table shows the fields that apply for an action to activate a motion
graphics overlay.

| Field             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Action type**   | Motion Graphics Activate.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Action name**   | A name for this activation action. For example, the name of<br>the motion graphic asset.                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Start type**    | **Fixed\*<br>• or<br>**Immediate\*\*.                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Date and time** | The date and time (in UTC format) that the channel must<br>activate the motion graphics overlay. The time should be at<br>least 60 seconds later than the time that you submit the<br>action.<br>Note that the time is the wall clock time, not the<br>timecode in the input.                                                                                                                                                                                                            |
| **Duration**      | Optional. The duration in milliseconds for the motion graphic<br>to remain on the video. If you omit this field or set it to 0,<br>the duration is unlimited and the motion graphic will remain<br>until you create a deactivate action.                                                                                                                                                                                                                                                 |
| **URL**           | The URL of the motion graphics asset. This asset is always an<br>HTML file. The URL follows this<br>syntax:`<protocol>://<path>/<file>.html`For<br>example:`https://example.com/ticker_tape.html`                                                                                                                                                                                                                                                                                        |
| **Credentials**   | Complete this section only if the server where the motion<br>graphics asset is stored requires user authentication from<br>MediaLive.<br>Enter the user name provided by the owner of the server.<br>For the password, enter the name of the password stored on<br>the AWS Systems Manager Parameter Store. Don't enter the password<br>itself. For more information, see [Requirements for AWS Systems Manager password parameters](requirements-for-EC2.md "requirements-for-EC2.md"). |
