# Setting up a MediaConnect input

This section describes how to create a MediaConnect input. With a MediaConnect input,
the service provider pushes content through AWS Elemental MediaConnect to MediaLive. (From the point of view
of MediaLive, the upstream system is MediaConnect. The upstream system is not the service
provider.)

To perform this setup, you must work with an AWS Elemental MediaConnect user.
