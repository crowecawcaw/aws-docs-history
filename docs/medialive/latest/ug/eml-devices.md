# Working with Link input device

A Link input device is the interface in MediaLive for an AWS Elemental Link
_hardware device_ that's connected to
MediaLive. For general information about this hardware, see [Working with AWS Elemental Link](feature-elink.md "feature-elink.md").

For information about working with the Link input device in
MediaLive, see [Setting up AWS Elemental Link](setup-devices.md "setup-devices.md").
