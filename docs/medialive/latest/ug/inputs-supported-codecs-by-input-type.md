**HLS
inputs**

The audio and video assets can be multiplexed in a single stream. Or the audio can be
in a separate audio rendition group. If you are using audio in a rendition group, the
group can be selected by using the **Group ID** and
**Name** that is in the **#EXT-X-MEDIA**
tag.
