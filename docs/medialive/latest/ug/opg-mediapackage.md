

# Creating a MediaPackage output group
<a name="opg-mediapackage"></a>

When you create a MediaLive channel, you might want to include a MediaPackage output group. This output group supports both MediaPackage v2 (CMAF Ingest) and v1 (HLS ingest). For information about the use cases for a MediaPackage output group, see [Containers, protocols, and downstream systems](outputs-supported-containers-downstream-systems.md). For guidance on choosing the correct output group configuration, see [Delivering to MediaPackage](delivering-to-mediapackage.md).
