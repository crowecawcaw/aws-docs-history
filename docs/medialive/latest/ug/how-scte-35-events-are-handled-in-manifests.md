# How SCTE 35 events are

handled in manifests and sparse tracks

When you enable manifest decoration or sparse track in an HLS or Microsoft Smooth
output group, MediaLive inserts up to three types of information. The triggers for
inserting this information depend on the mode.

## Types of information

| Type of instruction                             | When inserted                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ---------------------------------- | -------------------------------------- | --- |
| Base64                                          | Information about all SCTE 35 messages in the output is incorporated into the manifest; the entire SCTE 35 message is added in base64 format.                                                                                                                                                                                                                                                    |
| Cue-out, cue-in                                 | SCTE 35 messages that are ad avails result in the insertion of cue-out, cue-in instructions.                                                                                                                                                                                                                                                                                                     |
| Blackout                                        | Only applies to the SCTE 35 Enhanced ad marker style (for HLS output; see [Enabling decoration – HLS](procedure-to-enable-decoration-hls.md "procedure-to-enable-decoration-hls.md")).
