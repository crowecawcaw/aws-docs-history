# Changing the roles of the failover pair

When you set up for input failover in a MediaLive channel, you can reverse the roles of
the two failover inputs, so that the primary input becomes the secondary input.

###### To reverse the roles of the inputs

1. From the list of input attachments, choose the first input that you attached.
2. In the **Automatic input failover settings** section, choose
   **Disable automatic input failover settings**.
3. Choose the second input and choose **Enable automatic input failover
   settings** for that input. The second input is now the primary
   input.
