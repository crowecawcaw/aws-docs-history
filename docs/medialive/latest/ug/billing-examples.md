

# Examples
<a name="billing-examples"></a>

The following examples show how to decode MediaLive usage type strings.

`EML2-USE1-IN-AVC-HD-L20`  
Standard (dual) pipeline, US East (N. Virginia), input processing, AVC codec, HD resolution, 10–20 Mbps bitrate, on-demand

`EML1-EUC1-OUT-HEVC-UHD-60-S-R`  
Single pipeline, EU (Frankfurt), output processing, HEVC codec, UHD resolution, 30–60 fps, Standard VQ, reserved

`EML2-APN1-MUX-HEVC-FHD`  
Standard (dual) pipeline, Asia Pacific (Tokyo), multiplex output, HEVC codec, Full HD

`EMLA-USE2-AVC-HD`  
MediaLive Anywhere, US East (Ohio), AVC codec, HD resolution
