# Fields for the output

destination

The following fields configure the location and names of
the Archive output files (the destination).

- **Output group** –
  **Archive group destination**
  section
- **Output group** –
  **Archive settings** –
  **CDN settings**
- **Output group** –
  **Additional settings** –
  **Rollover interval**
- **Archive outputs** –
  **Name modifier**
- **Archive outputs** –
  **Extension**
  You must design the destination path or paths for the
  output. You must then enter the different portions of the
  path into the appropriate fields on the console.
