# Fields for deactivating a

motion graphics overlay

This table shows the fields that apply for an action to deactivate an motion
graphics overlay.

| Field             | Description                                                                                                                                                                                                                                                                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Action type**   | Motion Graphics Deactivate.                                                                                                                                                                                                                                                                                                              |
| **Action name**   | A name for this deactivation action. For example,<br>`deactivate_motion_graphic`.                                                                                                                                                                                                                                                        |
| **Start type**    | **Fixed\*<br>• or<br>**Immediate\*\*.                                                                                                                                                                                                                                                                                                    |
| **Date and time** | If the **Start type\*<br>• is<br>**Fixed\*\*, specify the date and time<br>(in UTC format) that the channel must deactivate the motion<br>graphics overlay. The time should be at least 60 seconds<br>later than the time that you submit the<br>action.<br>Note that the time is the wall clock time, not the<br>timecode in the input. |
