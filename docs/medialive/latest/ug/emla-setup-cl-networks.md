# Create the networks

Create the networks that you identified when you [designed the cluster](emla-deploy-design-cluster.md "emla-deploy-design-cluster.md"). Creating the network
integrates the [resources that you
identified](emla-deploy-identify-network-requirements.md "emla-deploy-identify-network-requirements.md") into AWS Elemental MediaLive Anywhere. You must create the networks before you create other
MediaLive Anywhere resources.

1. Open the MediaLive console at [https://console.aws.amazon.com/medialive/](https://console.aws.amazon.com/medialive/ "https://console.aws.amazon.com/medialive/").
2. In the navigation bar, choose MediaLive Anywhere, then choose **Networks**. On
   the **Networks** page, choose **Create network**.
3. Complete the fields with the information that the network engineer provided you with
   in [Identifying network
   resources](emla-deploy-identify-network-requirements.md "emla-deploy-identify-network-requirements.md").
4. Choose **Create**. MediaLive Anywhere creates the network and adds it to the
   list of networks.
