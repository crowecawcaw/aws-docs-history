# Managing maintenance

notifications

When a channel needs maintenance, you receive notification in the
Health Dashboard, one notification for each channel. In addition, AWS sends an
email to the email address associated with your AWS account.

We recommend that you can set up EventBridge to disseminate these
notifications to people in your organization. See the
[_Health Dashboard user guide_](../../../health/latest/ug/getting-started-health-dashboard.md "../../../health/latest/ug/getting-started-health-dashboard.md")
for more information. The people who receive
those notifications should read this maintenance topic.
