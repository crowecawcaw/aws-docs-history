

# Managing maintenance notifications
<a name="maintenance-setup-notifications"></a>

When a channel needs maintenance, you receive notification in the Health Dashboard, one notification for each channel. In addition, AWS sends an email to the email address associated with your AWS account. 

We recommend that you can set up EventBridge to disseminate these notifications to people in your organization. See the [*Health Dashboard user guide*](https://docs.aws.amazon.com/health/latest/ug/getting-started-health-dashboard.html) for more information. The people who receive those notifications should read this maintenance topic.
