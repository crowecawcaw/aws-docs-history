# Creating a Frame capture output group

When you create a AWS Elemental MediaLive channel, you might want to include a Frame capture output
group. A Frame capture output is a supplement to streaming; it isn't itself a streaming
output. This type of output might be useful for your workflow. For example, you might use a
Frame capture output to create thumbnails of the content. (You can also create thumbnails by
using the [thumbnails feature](thumbnails.md "thumbnails.md").)
