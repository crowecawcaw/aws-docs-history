# Setting up an RTP push input

This section describes how to set up an upstream system that uses the RTP Push
protocol to deliver source content from an upstream system that is in your VPC from
Amazon VPC. It describes how to set up the source content on the upstream system, and how to
create an input that connects the upstream system to MediaLive.

With an RTP push source, the upstream system _pushes_
the content to MediaLive.

To perform this setup, you must work with an operator at the upstream system.
