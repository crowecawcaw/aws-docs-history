# Attach inputs to the channel

Before you started to create the MediaLive channel, you should have [created all of inputs](medialive-inputs.md "medialive-inputs.md") for all the content sources
for the channel.

You must now attach the inputs to the channel. You can attach multiple inputs to the
channel. For detailed information about setting up a channel with more than one input,
see [Setting up for input switching](scheduled-input-switching.md "scheduled-input-switching.md"). There are [specific rules](eml-limitations-and-rules.md#limits-inputs "eml-limitations-and-rules.md#limits-inputs") about the number and type (push versus pull, for example) of
inputs that you can attach to one channel.
