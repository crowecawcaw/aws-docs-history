# Collect the information for

standard MediaPackage

For standard MediaPackage, the two URLs for a channel look like these
examples:

`6d2c.mediapackage.us-west-2.amazonaws.com/in/v2/9dj8/9dj8/channel`

`6d2c.mediapackage.us-west-2.amazonaws.com/in/v2/9dj8/e333/channel`

Where:

`mediapackage` indicates that the input endpoints uses
version 1 of the MediaPackage API

`channel` always appears at the end of the URL. It is the
base filename for all the files for this destination.

The two URLs are always identical except for the folder just before
`channel`.
