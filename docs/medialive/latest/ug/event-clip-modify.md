

# Modifying the event clipping configuration
<a name="event-clip-modify"></a>

To modify the event clipping configuration (for example, to change callback metadata), update the clipping output on the feed in the Elemental Inference console. For more information, see [ Work with existing Elemental Inference feeds](https://docs.aws.amazon.com/elemental-inference/latest/userguide/elemental-inference-modify-delete) in the *AWS Elemental Inference user guide*.
