# Modifying the event clipping configuration

###### Note

This section describes how to modify the event clipping configuration using the
MediaLive console. For information about modifying using an AWS API, see [Work with existing Elemental Inference feeds](../../../elemental-inference/latest/userguide/elemental-inference-modify-delete.md "../../../elemental-inference/latest/userguide/elemental-inference-modify-delete.md") in the _AWS Elemental Inference user
guide_.

You can modify change the callback config field:

1. On the **Create channel** or **Edit channel
   page**, choose **AWS Elemental Inference
   settings**. If necessary, expand the **Event
   clipping** section.
2. Change the value in **Callback config**.
