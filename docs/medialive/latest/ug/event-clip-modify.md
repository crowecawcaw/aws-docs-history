# Modifying the event clipping configuration

To modify the event clipping configuration (for example, to change callback
metadata), update the clipping output on the feed in the Elemental Inference console. For more
information, see [Work
with existing Elemental Inference feeds](../../../elemental-inference/latest/userguide/elemental-inference-modify-delete.md "../../../elemental-inference/latest/userguide/elemental-inference-modify-delete.md") in the _AWS Elemental Inference user
guide_.
