# Updating or removing a channel security group

You can change which input security group is used as the channel security group, or you can remove the channel security group entirely. However, you can only make these changes when the channel is stopped.

###### To update or remove a channel security group

1. Stop the channel if it is running.
2. In the navigation pane, choose **Channels**.
3. Select the channel, and then choose **Edit**.
4. Choose **Channel and input details** in the navigation pane.
5. In the **General settings** section, find the **Channel security groups** field.
6. To change the channel security group, select a different input security group from the dropdown list.

To remove the channel security group, clear the selection. Note that you can only remove the channel security group if you also remove all SRT outputs configured in listener mode from the channel. 7. Choose **Update channel**.
