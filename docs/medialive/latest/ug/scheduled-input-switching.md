# Setting up for input switching

You can set up a MediaLive channel to ingest multiple sequential inputs, rather than setting it
up to ingest only one input. You set up this _multiple-input
channel_ by attaching more than one input to the channel, and then adding actions in
the channel's schedule that specify when to switch from one input to another.
