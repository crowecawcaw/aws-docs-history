# Alerts that MediaLive

generates

MediaLive can generate alerts when a channel is running. For a list of alerts, see [List of alerts for channels](monitor-activity-types-alerts-channels.md "monitor-activity-types-alerts-channels.md").

You can view the alerts for each channel on the MediaLive console. For more information,
see [Alerts tab – Viewing
alerts](monitoring-console-general.md#view-alerts "monitoring-console-general.md#view-alerts").

MediaLive turns alerts into CloudWatch events with the detailType set to `MediaLive Channel
 Alert`. For an example of the JSON for these events, see [JSON
for a state change event](monitoring-cloudwatch-json-state-change.md "monitoring-cloudwatch-json-state-change.md").
