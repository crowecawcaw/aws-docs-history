# Detaching an input

You can detach an input from a MediaLive channel. The channel must be idle.

1. Open the MediaLive console at [https://console.aws.amazon.com/medialive/](https://console.aws.amazon.com/medialive/ "https://console.aws.amazon.com/medialive/").
2. In the navigation pane, choose **Inputs**. Find the input in
   the list and choose its name. On the **Input Details**, find
   the ID of the channel that the input is attached to.
3. Choose that ID. The **Channel details** page for that channel
   appears.
4. Choose **Channel actions**, then choose **Edit
   channel**.
5. In the list of input attachments on the left, find the the name of the input
   to detach. Choose the name.
6. In the **Input attachment details** panel, choose
   **Remove**. The input is detached.
7. Choose **Update channel** at the bottom of the page.
