# Getting ready: Set

the ad avail mode

You must set the mode for SCTE 35 handling. The blanking, blackout, and manifest
decoration features of MediaLive work different depending on the mode.

###### To set the ad avail mode

1. In the channel that you are creating, in the navigation pane, choose
   **General settings**. Choose **Avail
   configuration**.
2. Complete the fields as follows:
