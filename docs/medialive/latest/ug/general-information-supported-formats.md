# General information about

supported captions formats

The following table shows the formats that are supported in MediaLive. It specifies
whether they are supported in inputs or outputs, and specifies the
standard that defines each format.

| Caption          | Supported in input | Supported in output | Description                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------- | ------------------ | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ancillary data   | Yes                |                     | Data that is compliant with “*SMPTE 291M:<br>• *Ancillary Data Package and<br>Space Formatting\*” and that is contained in ancillary<br>data.                                                                                                                                                                                                                                                                                                            |
| ARIB             | Yes                | Yes                 | Captions that are compliant with _ARIB<br>STD-B37 Version 2.4_.                                                                                                                                                                                                                                                                                                                                                                                          |
| Burn-in          |                    | Yes                 | From input: It is technically impossible for<br>the encoder to read burn-in captions. Therefore,<br>from an input viewpoint, they can't be<br>considered to be captions.<br>For output: Burn-in captions are captions that<br>are converted into text and then overlaid on top<br>of the picture directly in the video<br>stream.                                                                                                                        |
| DVB-Sub          | Yes                | Yes                 | Captions that are compliant with ETSI EN 300<br>743.                                                                                                                                                                                                                                                                                                                                                                                                     |
| EBU-TT-D         |                    | Yes                 | Captions that are compliant with EBU Tech<br>3380, EBU-TT-D Subtitling Distribution Format,<br>2018.                                                                                                                                                                                                                                                                                                                                                     |
| Embedded         | Yes                | Yes                 | In most containers: Captions that are compliant with the EIA-608<br>standard (also known as CEA-608 or _line 21<br>captions_) or the CEA-708 standard (also known as<br>EIA-708).<br>In a Link input container: Captions carried as ancillary captions<br>that are compliant with SMPTE 334. The ancillary captions are<br>compliant with EIA-608 standard (also known as CEA-608 or _line 21 captions_) or CEA-708 standard<br>(also known as EIA-708). |
| Embedded+SCTE-20 | Yes                | Yes                 | Captions that have both embedded and SCTE-20<br>in the video. The embedded captions are inserted<br>before the SCTE-20 captions.                                                                                                                                                                                                                                                                                                                         |
| RTMP CaptionInfo |                    | Yes                 | Captions that are compliant with the Adobe<br>onCaptionInfo format.                                                                                                                                                                                                                                                                                                                                                                                      |
| SCTE-20          | Yes                |                     | Captions that are compliant with the standard “_SCTE 20 2012 Methods for Carriage of CEA-608 Closed<br>Captions and Non-Real Time Sampled Video_.”                                                                                                                                                                                                                                                                                                       |
| SCTE-20+Embedded |                    | Yes                 | Captions that are compliant with SCTE-43. The<br>SCTE-20 captions are inserted in the video before<br>the embedded captions.                                                                                                                                                                                                                                                                                                                             |
| SCTE-27          | Yes                |                     | Captions that are compliant with the standard “_SCTE-27 (2011), Subtitling Methods for Broadcast<br>Cable_.”                                                                                                                                                                                                                                                                                                                                             |
| SMPTE-TT         |                    | Yes                 | Captions that are compliant with the standard "_SMPTE ST 2052-1:2010_".                                                                                                                                                                                                                                                                                                                                                                                  |
| Teletext         | Yes                | Yes                 | From TS input: Captions in the EBU Teletext format.From a CDI<br>input, a SMPTE2110 input, or in a Link container: Captions in OP47<br>teletext format, also known as SMPTE RDD-08 (compliant with ITU-R<br>BT.1120-7).                                                                                                                                                                                                                                  |
| TTML             |                    | Yes                 | Captions files that are compliant with the standard “_Timed Text Markup Language 1 (TTML1) (Second<br>Edition)_.”                                                                                                                                                                                                                                                                                                                                        |
| WebVTT           |                    | Yes                 | Captions that are compliant with “_webvtt: The<br>Web Video Text Tracks Format_” ([http://dev.w3.org/html5/webvtt/](http://dev.w3.org/html5/webvtt/ "http://dev.w3.org/html5/webvtt/")).                                                                                                                                                                                                                                                                 |
