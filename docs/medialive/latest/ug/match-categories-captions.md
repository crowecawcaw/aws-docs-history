# Match formats to categories

After you have made a captions outputs list, you must identify the procedure to follow
to create captions encodes in each MediaLive output. The procedure to follow depends on the
_category_ that a captions format belongs to.

1. Consult the table in [Captions categories](categories-captions.md "categories-captions.md") and find each captions
   format that you identified.
2. On the captions outputs list that you created, make a note of the category that each
   captions option belongs to.
