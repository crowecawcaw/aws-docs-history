# Channel

input—SMPTE 2110 input

To verify that the input is set up correctly, look at the
**SMPTE
2110 Receiver Group** section. It shows information
from the SDP files that you specified when you created the input. For
example:

- **Video SDP: http://172.18.8.19/curling\_video.sdp, Media index:
  2**
- **Audio SDPs: http://172.18.8.19/curling\_audio\_1.sdp, Media index:
  0**
  - **http://172.18.8.19/curling\_audio\_2.sdp, Media index:
    0**
  - **http://172.18.8.19/curling\_audio\_2.sdp, Media index:
    1**

- **Ancillary SDPs: http://172.18.8.19/curling\_ancill.sdp, Media
  index: 0**

**Ancillary SDPs: http://172.18.8.19/curling\_ancill.sdp, Media
index: 1**
