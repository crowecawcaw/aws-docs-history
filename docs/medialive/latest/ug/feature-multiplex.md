# Using MediaLive multiplex to create an MPTS

You can set up a MediaLive multiplex to create a multi-program transport stream (MPTS). You might
be interested in MediaLive multiplex if you are a service provider who has experience in
distributing transport stream (TS) content over RTP or UDP.

###### Note

The term _MediaLive multiplex_ refers to an entity in MediaLive. The term MPTS
is a standard term in digital transmission technology. You create and work with a MediaLive
multiplex in order to create an MPTS for distribution.
