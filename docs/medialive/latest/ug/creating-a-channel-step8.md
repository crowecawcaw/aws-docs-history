# Set up the captions encodes

In [Configure outputs](creating-a-channel-step4.md "creating-a-channel-step4.md"), you created the output groups and
outputs that you identified when you planned the channel. Each output section contains a
**Stream settings** section. You must now create all the captions
encodes for the outputs.

###### General procedure

Follow this general procedure to set up the captions encode.

1.  Decide how you're going to create each encode:

        * From scratch.
        * By sharing an encode that already exists in this output or another
         output in the channel.
        * By cloning an encode that already exists in this output or another
         output in the channel.

    You might have already made this decision. If not, you should decide now. For
    more information, see [Design the encodes](designing-encodes.md "designing-encodes.md").

You can share or clone captions encodes within one output, from one output to
another in the same output group, or from one output to an output in another
output group. 2. Read the appropriate sections that follow.
