# Configure read/write capacity modes in Amazon Keyspaces

Amazon Keyspaces has two read/write capacity modes for processing reads and writes on your
tables:

- On-demand (default)
- Provisioned
  The read/write capacity mode that you choose controls how you are charged for read
  and write throughput and how table throughput capacity is managed.
