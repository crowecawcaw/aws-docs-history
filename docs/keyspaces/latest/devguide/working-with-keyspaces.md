# System keyspaces in Amazon Keyspaces

This section provides details about working with system keyspaces in Amazon Keyspaces (for Apache Cassandra).

Amazon Keyspaces uses four system keyspaces:

- `system`
- `system_schema`
- `system_schema_mcs`
- `system_multiregion_info`
  The following sections provide details about the system keyspaces and the system
  tables that are supported in Amazon Keyspaces.

## `system`

This is a Cassandra keyspace. Amazon Keyspaces uses the following tables.

| Table names           | Column names                                                                                                                                                                                                                                                           | Comments                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `local`               | `key, bootstrapped, broadcast_address, cluster_name,<br>cql_version, data_center, gossip_generation, host_id,<br>listen_address, native_protocol_version, partitioner, rack,<br>release_version, rpc_address, schema_version,<br>thrift_version, tokens, truncated_at` | Information about the local keyspace.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `peers`               | `peer, data_center, host_id, preferred_ip, rack,<br>release_version, rpc_address, schema_version,<br>tokens`                                                                                                                                                           | Query this table to see the available endpoints. For example,<br>if you're connecting through a public endpoint, you see a list<br>of nine available IP addresses. If you're connecting through a<br>FIPS endpoint, you see a list of three IP addresses. If you're<br>connecting through an AWS PrivateLink VPC endpoint, you see the<br>list of IP addresses that you have configured. For more<br>information, see [Populating system.peers table entries with<br>interface VPC endpoint information](vpc-endpoints.md#system_peers "vpc-endpoints.md#system_peers"). |
| `size_estimates`      | `keyspace_name, table_name, range_start, range_end,<br>mean_partition_size, partitions_count`                                                                                                                                                                          | This table defines the total size and number of partitions for<br>each token range for every table. This is needed for the Apache<br>Cassandra Spark Connector, which uses the estimated partition size<br>to distribute the work.                                                                                                                                                                                                                                                                                                                                       |
| `prepared_statements` | `prepared_id, logged_keyspace, query_string`                                                                                                                                                                                                                           | This table contains information about saved queries.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## `system_schema`

This is a Cassandra keyspace. Amazon Keyspaces uses the following tables.

| Table names | Column names                                                                                                                                                                                                                                                                                                                           | Comments                                              |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| `keyspaces` | `keyspace_name, durable_writes, replication`                                                                                                                                                                                                                                                                                           | Information about a specific keyspace.                |
| `tables`    | `keyspace_name, table_name, bloom_filter_fp_chance,<br>caching, comment, compaction, compression, crc_check_chance,<br>dclocal_read_repair_chance, default_time_to_live,<br>extensions, flags, gc_grace_seconds, id, max_index_interval,<br>memtable_flush_period_in_ms, min_index_interval,<br>read_repair_chance, speculative_retry` | Information about a specific table.                   |
| `types`     | `keyspace_name, type_name, field_names, field_types`                                                                                                                                                                                                                                                                                   | Information about a specific user-defined type (UDT). |
| `columns`   | `keyspace_name, table_name, column_name,<br>clustering_order, column_name_bytes, kind, position,<br>type`                                                                                                                                                                                                                              | Information about a specific column.                  |

## `system_schema_mcs`

This is an Amazon Keyspaces keyspace that stores information about AWS or Amazon Keyspaces specific
settings.

| Table names      | Column names                                                                                                                                                                                                                                                                                                                                                                                                                        | Comments                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `keyspaces`      | `keyspace_name, durable_writes, replication`                                                                                                                                                                                                                                                                                                                                                                                        | Query this table to find out programmatically if a keyspace<br>has been created. For more information, see [Check keyspace creation status in Amazon Keyspaces](keyspaces-create.md "keyspaces-create.md").                                                                                                                                                                                                                                                                              |
| `tables`         | `keyspace_name, creation_time, speculative_retry, cdc,<br>gc_grace_seconds, crc_check_chance, min_index_interval,<br>bloom_filter_fp_chance, flags, custom_properties,<br>dclocal_read_repair_chance, table_name, caching,<br>default_time_to_live, read_repair_chance,<br>max_index_interval, extensions, compaction, comment, id,<br>compression, memtable_flush_period_in_ms, cdc_specification,<br>latest_stream_arn<br>status` | Query this table to find out the status of a specific table.<br>For more information, see [Check table creation status in Amazon Keyspaces](tables-create.md "tables-create.md").<br>You can also query this table to list settings that are<br>specific to Amazon Keyspaces and are stored as<br>`custom_properties`. For example:<br>• `capacity_mode`<br>• `cdc_specification`<br>• `client_side_timestamps`<br>• `encryption_specification`<br>• `point_in_time_recovery`<br>• `ttl` |
| `tables_history` | `keyspace_name, table_name, event_time, creation_time,<br>custom_properties, event`                                                                                                                                                                                                                                                                                                                                                 | Query this table to learn about schema changes for a specific<br>table.                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `columns`        | `keyspace_name, table_name, column_name,<br>clustering_order, column_name_bytes, kind, position,<br>type`                                                                                                                                                                                                                                                                                                                           | This table is identical to the Cassandra table in the<br>`system_schema` keyspace.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `tags`           | `resource_id, keyspace_name, resource_name,<br>resource_type, tags`                                                                                                                                                                                                                                                                                                                                                                 | Query this table to find out if a keyspace has tags. For more<br>information, see [View the tags of a table](Tagging.Operations.view.md "Tagging.Operations.view.md").                                                                                                                                                                                                                                                                                                                   |
| `types`          | `keyspace_name, type_name, field_names, field_types, max_nesting_depth, last_modified_timestamp,<br>status, direct_referring_tables, direct_parent_types`                                                                                                                                                                                                                                                                           | Query this table to find out information about user-defined types (UDTs). For example you can query<br>this table to list all UDTs for a given keyspace. For more<br>information, see [User-defined types (UDTs) in Amazon Keyspaces](udts.md "udts.md").                                                                                                                                                                                                                                |
| `autoscaling`    | `keyspace_name, table_name,<br>provisioned_read_capacity_autoscaling_update,<br>provisioned_write_capacity_autoscaling_update`                                                                                                                                                                                                                                                                                                      | Query this table to get the auto scaling settings of a<br>provisioned table. Note that these settings won't be available<br>until the table is active. To query this table, you have to<br>specify `keyspace_name` and `table_name`<br>in the `WHERE` clause. For more information, see<br>[View your table's Amazon Keyspaces auto scaling configuration](autoscaling.md "autoscaling.md").                                                                                             |

## `system_multiregion_info`

This is an Amazon Keyspaces keyspace that stores information about multi-Region replication.

| Table names   | Column names                                                                                                                                                      | Comments                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tables`      | `keyspace_name, table_name, region, status`                                                                                                                       | This table contains information about multi-Region<br>tables—for example, the AWS Regions that the table is<br>replicated in and the table's status. You can also query this<br>table to list settings that are specific to Amazon Keyspaces that are<br>stored as `custom_properties`. For example:<br>• `capacity_mode`<br>To query this table, you have to specify<br>`keyspace_name` and `table_name` in<br>the `WHERE` clause. For more information, see [Create a multi-Region keyspace in Amazon Keyspaces](keyspaces-mrr-create.md "keyspaces-mrr-create.md"). |
| `keyspaces`   | `keyspace_name, region, status,<br>tables_replication_progress`                                                                                                   | This table contains information about the progress of an<br>`ALTER KEYSPACE` operation that adds a replica to a<br>keyspace — for example, how many tables have already been<br>created in the new Region, and how many tables are still in<br>progress. For an examples, see [Check the replication progress when adding a new Region to a keyspace](keyspaces-multi-region-replica-status.md "keyspaces-multi-region-replica-status.md").                                                                                                                            |
| `autoscaling` | `keyspace_name, table_name,<br>provisioned_read_capacity_autoscaling_update,<br>provisioned_write_capacity_autoscaling_update,<br>region`                         | Query this table to get the auto scaling settings of a<br>multi-Region provisioned table. Note that these settings won't<br>be available until the table is active. To query this table, you<br>have to specify `keyspace_name` and<br>`table_name` in the `WHERE` clause.<br>For more information, see [Update the provisioned capacity and auto scaling settings for a multi-Region table in Amazon Keyspaces](tables-mrr-autoscaling.md "tables-mrr-autoscaling.md").                                                                                               |
| `types`       | `keyspace_name, type_name, field_names, field_types, max_nesting_depth, last_modified_timestamp,<br>status, direct_referring_tables, direct_parent_types, region` | Query this table to find out information about user-defined types (UDTs) in multi-Region keyspaces.<br>For example, you can query this table to list all table replicas and their respective AWS Regions that use UDTs<br>for a given keyspace. For more<br>information, see [User-defined types (UDTs) in Amazon Keyspaces](udts.md "udts.md").                                                                                                                                                                                                                       |
