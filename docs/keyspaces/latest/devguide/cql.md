# DML statements (data manipulation language) in Amazon Keyspaces

_Data manipulation language_ (DML) is the set of Cassandra Query
Language (CQL) statements that you use to manage data in Amazon Keyspaces (for Apache Cassandra) tables. You use DML
statements to add, modify, or delete data in a table.

You also use DML statements to query data in a table. (Note that CQL doesn't support
joins or subqueries.)
