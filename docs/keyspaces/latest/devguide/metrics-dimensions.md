# Amazon Keyspaces metrics and dimensions

When you interact with Amazon Keyspaces, it sends metrics and dimensions to Amazon CloudWatch.
All metrics are aggregated and reported every minute. The following sections are an
overview of all available metrics for Amazon Keyspaces.

## Dimensions for Amazon Keyspaces metrics

The metrics for Amazon Keyspaces are qualified by the values for the account, table name, or
operation. You can use the CloudWatch console to retrieve Amazon Keyspaces data along any of the
dimensions in the following table.

| Dimension   | Description                                                                                                                                                                                                                            |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Keyspace`  | This dimension limits the data to a specific keyspace. This value can be<br>any keyspace in the current Region and the current AWS account.                                                                                            |
| `Operation` | This dimension limits the data to one of the Amazon Keyspaces CQL operations, such as<br>`INSERT` or `SELECT` operations.                                                                                                              |
| `TableName` | This dimension limits the data to a specific table. This value can be any<br>table name in the current Region and the current AWS account. If the table<br>name is not unique within the account, you must also specify<br>`Keyspace`. |
