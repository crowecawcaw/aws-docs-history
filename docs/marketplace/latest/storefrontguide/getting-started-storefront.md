

# Prerequisites
<a name="getting-started-storefront"></a>

Before you begin using AWS Marketplace Storefront, ensure you meet the following requirements.

## AWS requirements
<a name="gs-aws-requirements"></a>
+ An active AWS account
+ (Optional) AWS Marketplace seller registration. A seller account is not required to create and deploy a storefront. However, connecting a seller account enables you to import your own listings (including limited-visibility products) and link your storefront to your AWS Marketplace account for offer management. For more information, see [Getting started as a seller](https://docs.aws.amazon.com/marketplace/latest/userguide/seller-registration-process.html) in the AWS Marketplace Seller Guide.

## Storefront requirements
<a name="gs-storefront-requirements"></a>
+ A valid business email address for account registration
+ Organization administrator access (to create and configure storefronts)

## Browser requirements
<a name="gs-browser-requirements"></a>

AWS Marketplace Storefront supports the following browsers:
+ Google Chrome (latest two versions)
+ Mozilla Firefox (latest two versions)
+ Microsoft Edge (latest two versions)
+ Safari (latest two versions)

## Network requirements
<a name="gs-network-requirements"></a>
+ HTTPS (port 443) access to the Storefront management console
+ No VPN or firewall restrictions blocking `*.your-storefront-domain.com` domains (for storefront preview and deployment)
