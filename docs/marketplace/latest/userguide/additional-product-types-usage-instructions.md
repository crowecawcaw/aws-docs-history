

# Usage instructions

Usage instructions tell customers the next steps to start using your product. They appear on the product detail page before purchase, and they are shown to the buyer again on the fulfillment page after purchase.

**Topics**
+ [Writing effective usage instructions](#additional-product-types-usage-instructions-writing)
+ [Where usage instructions appear](#additional-product-types-usage-instructions-by-type)

## Writing effective usage instructions
<a name="additional-product-types-usage-instructions-writing"></a>

Provide usage instructions that help ensure that the buyer can successfully configure and use your product. To write effective usage instructions, follow these guidelines:
+ Assume that the reader is interested but uninformed.
+ Include all the information that the buyer needs to configure and use your product, including any configuration settings and special steps.
+ Be clear and complete so that the buyer can get started without contacting you.

## Where usage instructions appear
<a name="additional-product-types-usage-instructions-by-type"></a>

You set usage instructions on the product's delivery option, with the `AddDeliveryOption` operation. The instructions appear on the product detail page before purchase, and where the buyer sees them after purchase.
