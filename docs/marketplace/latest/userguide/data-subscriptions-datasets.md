

# Available datasets

The following table lists the seller datasets that you can subscribe to and the folder that AWS Marketplace uses for each dataset in your bucket. To see a dataset's columns, choose its name on the **Data sharing** page in AWS Partner Central.


**Seller datasets**  

| Dataset | Folder in your bucket | 
| --- | --- | 
| **Marketplace Agreements and Renewals**<br />Active, expired, renewed, and cancelled agreements within 24 hours of signing, with offer details and subscriber, reseller, and ISV relationships. | marketplace\_agreements\_and\_renewals | 
| **Marketplace Usage**<br />Usage records for SaaS and server usage-based products, by dimension key, Region, and product. Revenue is estimated until billing is finalized at the end of the month. | marketplace\_daily\_usage\_report | 

AWS Marketplace adds datasets over time. The **Data sharing** page lists every dataset that you can subscribe to.
