

# Reporting

Learn how to view reports for RTB Fabric module products in AWS Marketplace.

## Reports and data feeds
<a name="additional-product-types-managing-reports"></a>

AWS Marketplace produces reports for your RTB Fabric module products that include data on subscribers, financials, and taxes. Agreements, invoices, and disbursements for RTB Fabric module products appear in the same seller reports, dashboards, and data feeds as other product types. Because RTB Fabric module products use contract pricing only, charges appear as upfront contract charges, with no metered usage. The following table summarizes how financials for RTB Fabric module products are reported.


| Report | RTB Fabric module content | 
| --- | --- | 
| Daily business report | Upfront contract charges appear in the **Fees** section. | 
| Monthly revenue report | Upfront contract charges appear in the **Annual subscriptions** section. | 
| Sales compensation report | Upfront contract charges appear as line items. | 
| Customer subscriber report | New RTB Fabric module contracts appear in the **Annual subscriptions** section. | 

For more information about requesting public visibility for your product, see [Marking your products public](additional-product-types-marking-public.md).
