

# AWS Partner Central Agents

AWS Partner Central Agents answer your AWS Marketplace and AWS Partner Central questions instantly in the AWS assistant panel. The answers draw on your seller account details and on AWS Partner Central and AWS Marketplace guides.

To get support, start a support chat on the [AWS Partner Central and Marketplace Support page](https://us-east-1.console.aws.amazon.com/partnercentral/support?region=us-east-1) in the AWS Partner Central console. If an answer doesn't resolve your issue, the chat helps you create a support case. For more information, see [Getting support for AWS Marketplace](getting-support.md).

To generate product listings with AWS Partner Central Agents, see [AI-assisted product listing](ai-assisted-product-listing.md).
