

# Products Integrated with AWS Services in AWS Marketplace

With products integrated with AWS services, you can publish a listing on AWS Marketplace for software that buyers use through an AWS service. For RTB Fabric module products, buyers use the module through AWS RTB Fabric. Buyers subscribe in AWS Marketplace or in the AWS service console, and the AWS service verifies their entitlement and delivers the software. You are not responsible for account creation, resource provisioning, or access management; the AWS service handles fulfillment, and you remain responsible for the software itself. This chapter covers the following product type:
+ **RTB Fabric module products** let advertising technology vendors sell bid-traffic modules that buyers deploy in the AWS RTB Fabric console.

An RTB Fabric module product is published with a delivery option that defines how the product behaves on AWS Marketplace, including the supported pricing model, which pricing dimensions the AWS service provides, and where buyers go to use the product. After you create your initial product, you can submit change requests and configure its properties in AWS Marketplace, including your product description, pricing, and so on. The following topics provide you with information that you need to get started.

**Note**  
At launch, RTB Fabric module products are available only to a limited, approved set of sellers. For more information or to request access, contact AWS Marketplace Seller Operations on the [AWS Partner Central and Marketplace Support page](https://us-east-1.console.aws.amazon.com/partnercentral/support?region=us-east-1).

For assistance with your products integrated with AWS services, contact the AWS Marketplace Seller Operations team on the AWS Partner Central and Marketplace Support page.
