

# Navigating AWS Partner Central

**Note**  
AWS Marketplace Management Portal is now part of AWS Partner Central.

AWS Partner Central gives you one navigation experience in the AWS Management Console, at [https://us-east-1.console.aws.amazon.com/partnercentral/](https://us-east-1.console.aws.amazon.com/partnercentral/). The left navigation pane lists both AWS Marketplace seller features and AWS Partner Central features.

## The navigation pane
<a name="nav"></a>

Every page shows the same left navigation pane. It has 10 groups.


| Group | Items | 
| --- | --- | 
| (ungrouped) | Dashboard, Business plans, Partner scorecard, News and events, Guides | 
| **Build** | Solutions, AI agents & tools, SaaS products, Server products, Machine learning products, Data products, Professional services, Requests, File upload, Device listings | 
| **Go to Market** | Marketing Central, Case studies, Program navigator, Badge manager | 
| **Sell** | Leads, Opportunities, Offers, Agreements, Selling authorizations, Revenue attribution | 
| **Funding benefits** | Funding dashboard, Wallets, Business value realization | 
| **Channel management** | Channel management with Billing Transfer, Legacy channel management, Distribution engagement requests, Deal registration | 
| **Account connections** | Partner discovery, Partner connections, Subsidiary account connections | 
| **Partner analytics** | At a glance, Opportunity pipeline analysis, Lead pipeline analysis, Funding and investments, Resell revenue and discounts, Marketing campaign analysis, Training and certifications, Attributed revenue, Performance indicators | 
| **Marketplace insights** | Agreements and renewals, Usage, Billed revenue, Collections and disbursements, Tax, Understanding buy with AWS | 
| **Settings** | Profiles, Account, AWS Marketplace notifications, KYC, Tax and invoices, Payment details | 
| **Partner admin** | User onboarding, Partner Central support, AWS Marketplace support, AWS Marketplace refund support | 

### Where your old tasks live now
<a name="where-your-old-tasks-live-now"></a>


| If you used to go to | Now | 
| --- | --- | 
| The Products pages, one per product type | Under **Build**, any product type. They all open the **Products and services** page, which lists every type. See [Creating a product in AWS Marketplace](creating-a-product.md). | 
| The Requests tab of a product page | Under **Build**, choose **Requests**. See [Managing your requests](requests.md). | 
| Settings, for tax, KYC, or bank details | Under **Settings**, choose the specific item: **KYC**, **Tax and invoices**, **Payment details**, or **AWS Marketplace notifications**. The item named **Account** opens AWS Partner Central settings, not your AWS Marketplace seller settings. | 
| Insights, for seller reports and dashboards | Under **Marketplace insights**. | 
| Partners, for selling authorizations | Under **Sell**, choose **Selling authorizations**. | 

## What happens to your existing links
<a name="links"></a>

Your existing AWS Marketplace Management Portal links and bookmarks continue to work. What they open varies:
+ `https://aws.amazon.com/marketplace/management/` opens the AWS Partner Central dashboard.
+ A bookmark to a specific product type opens the **Products and services** page. The product type is not preselected, so filter the **Product type** column.
+ Some links continue to open in AWS Marketplace Management Portal. See the following section.

## Pages that still open in AWS Marketplace Management Portal
<a name="two-shells"></a>

Several navigation items open a page hosted in AWS Marketplace Management Portal rather than in the console. Those pages look different from the console pages around them.

This is expected. It is not a broken link, and you do not need to sign in again.

## If you are an AWS Marketplace seller but not an AWS Partner
<a name="not-partner"></a>

You see navigation items for AWS Partner Central features that you cannot use yet. To use features such as opportunities and funding requests, complete [AWS Partner Central registration](https://docs.aws.amazon.com/partner-central/latest/getting-started/registering.html).

## If you are both an AWS Marketplace seller and an AWS Partner
<a name="both"></a>

Your dashboard might show your Partner Account status as "not registered". Contact your AWS Partner alliance lead to complete AWS Partner Central migration and to get the AWS Partner Central IAM permission policy, which gives you access to the full set of features.
