

# Managing versions for EC2 Image Builder products on AWS Marketplace
<a name="single-ib-versions"></a>

Version management for EC2 Image Builder components can't be done from the UI. For more information, see the following catalog API sections:
+ [Add a new version](https://docs.aws.amazon.com/marketplace/latest/APIReference/work-with-ec2-image-builder-products.html#adding-new-ec2-ib-version-existing-product) 
+ [Update information about an existing version](https://docs.aws.amazon.com/marketplace/latest/APIReference/work-with-ec2-image-builder-products.html#updating-ec2-ib-product-version) 
+ [Restrict a version](https://docs.aws.amazon.com/marketplace/latest/APIReference/work-with-ec2-image-builder-products.html#restricting-ec2-ib-product-version)
