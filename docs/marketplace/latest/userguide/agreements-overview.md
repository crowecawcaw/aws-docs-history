# Using agreements

AWS Marketplace seller agreements are contracts between sellers and buyers for products and services
sold on AWS Marketplace. An agreement is formed when a buyer accepts an offer, public or private.
Agreements also govern how buyers use a seller's products and services. The topics in this
section explain the agreement structure, the types and their statuses, and how to change or
_amend_ agreements.

###### Note

AWS is not a party to any agreements.
