# SaaS product integration

checklist

Before your software as a service (SaaS) product goes live, you must verify that you have completed the
required configuration. You can use the following SaaS integration checklist to verify that you have completed
the required configurations.

| **Category**     | **Requirements**                                                                                                                                                                                                                                                                             |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Access           | Submitted a seller registration form with the desired AWS account for AWS Marketplace<br>usage.                                                                                                                                                                                              |
| Access           | Completed the seller registration, including terms and conditions, bank account,<br>and W8 or W9 tax form.                                                                                                                                                                                   |
| Access           | Configured cross-account roles for the registered AWS Marketplace account.                                                                                                                                                                                                                   |
| Product          | Completed the product request form in the AWS Marketplace Management Portal.                                                                                                                                                                                                                 |
| Product          | Provided AWS account IDs for testing in the **Notes\*<br>• tab of the<br>**Create product\*<br>• wizard in the AMMP.                                                                                                                                                                         |
| Product          | Provided a URL of the EULA in .txt format in the \*_Products_<br>• tab.                                                                                                                                                                                                                      |
| Product          | Received your product code and Amazon SNS topic information from AWS Marketplace.                                                                                                                                                                                                            |
| Product          | Subscribed to the Amazon SNS topic and created an Amazon SQS queue to subscribe to the Amazon SNS<br>topic.                                                                                                                                                                                  |
| Billing Solution | Validated you can send metering records to the `BatchMeterUsage`<br>operation each hour for each customer for SaaS subscriptions products. Can send metering<br>records for additional usage by each customer for SaaS contracts products.                                                   |
| Billing Solution | Validated you can verify customer entitlements from the AWS Marketplace Entitlement<br>Service for SaaS contracts products.                                                                                                                                                                  |
| Billing Solution | Validated that the costs appear as expected on bills generated for test accounts.                                                                                                                                                                                                            |
| Billing Solution | Tested for situations such as invalid customer IDs and canceled subscriptions.                                                                                                                                                                                                               |
| Product          | Submitted the product request back to AWS Marketplace for publishing.                                                                                                                                                                                                                        |
| Registration     | Implemented an HTTPS registration page that can accept HTTP POST requests.                                                                                                                                                                                                                   |
| Registration     | Validated you can accept new customer registrations.                                                                                                                                                                                                                                         |
| Registration     | Validated you are \*not<br>• storing the registration<br>token in a cookie.                                                                                                                                                                                                                  |
| Registration     | Validated you are using `ResolveCustomer` to obtain the<br>`ProductCode` and `CustomerIdentifier` from the AWS token.                                                                                                                                                                        |
| Registration     | Validated you can resolve the registration token received from AWS with no<br>delays.                                                                                                                                                                                                        |
| Registration     | Tested that you aren't blocked from registering with email services addresses such<br>as Gmail.                                                                                                                                                                                              |
| Registration     | Tested that you can accept incomplete registrations and multiple registration<br>attempts.                                                                                                                                                                                                   |
| Subscription     | Test that you can handle `unsubscribe-pending` and<br>`unsubscribe-success` messages.                                                                                                                                                                                                        |
| Subscription     | Validated that you send ﬁnal metering records within an hour of receiving an<br>`unsubscribe-pending` message.                                                                                                                                                                               |
| Security         | Validated the AWS root account doesn't have API keys, has a strong password, and<br>is associated with a hardware multi-factor authentication (MFA) device. All<br>administrative access is through identities created with AWS Identity and Access Management (IAM). No shared<br>accounts. |
| Security         | Validated that IAM roles are used for all programmatic Amazon Elastic Compute Cloud (Amazon EC2) access.<br>Credentials aren't hard-coded into scripts, headers, or source code.                                                                                                             |
| Security         | Validated you maintain comprehensive logging and log consolidation.                                                                                                                                                                                                                          |
| Security         | Verified you have well-deﬁned public and private subnet boundaries that isolate<br>application services and access to database and ﬁle systems. Distinct data class<br>deﬁnitions that demarcate sensitive data and segregate public and private data.                                       |
| Security         | Verified you have private data encryption in transit and at rest with scheduled key<br>rotation.                                                                                                                                                                                             |
| Security         | Validated you have security incident tools and access in place and routinely<br>scheduled incident response exercises that accommodate timely investigation and<br>recovery.                                                                                                                 |
| Reliability      | Verified the system adapts to changes in demand, scaling up and down as required,<br>and employs load balancing to ensure high performance. The system also provides<br>edge-based caching as required.                                                                                      |
| Reliability      | Validated recovery time and point objectives are speciﬁed, and disaster recovery is<br>scheduled at regular intervals. Component failure is self-healing via automated triggers<br>and notiﬁcations.                                                                                         |
