# Welcome to the AWS Marketplace Developer Guide
<a name="welcome"></a>

This developer guide describes how AWS Marketplace sellers can use service APIs to integrate and manage product lifecycles and offers. It also describes how buyers can use service APIs to discover third-party software, data, and services as well as how to govern private marketplaces.
