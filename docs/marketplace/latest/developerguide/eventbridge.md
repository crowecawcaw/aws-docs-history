# Amazon EventBridge notifications for AWS Marketplace Catalog API events

AWS Marketplace is integrated with Amazon EventBridge, formerly called Amazon CloudWatch Events. EventBridge is an event bus
service that you can use to connect your applications with data from a variety of
sources.

For information on how sellers, channel partners, and private marketplace
administrators can receive ChangeSet status events using EventBridge, see [Events
for change sets](../userguide/seller-eventbridge.md#events-changesets "../userguide/seller-eventbridge.md#events-changesets") in the _AWS Marketplace Seller
Guide_.
