# Supported AWS Regions for the AWS Marketplace Entitlement API
<a name="entitlement-regions"></a>

You can access the AWS Marketplace Entitlement Service from the US East (N. Virginia) AWS Region with the following endpoints.

```
entitlement.marketplace.us-east-1.amazonaws.com
```

```
entitlement-marketplace.us-east-1.api.aws
```
