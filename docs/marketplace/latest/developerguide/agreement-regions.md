# Supported AWS Regions for the AWS Marketplace Agreement API

You can access the AWS Marketplace Agreement Service from the US East (N. Virginia) AWS Region
with the following endpoint.

```
agreement-marketplace.us-east-1.api.aws (IPv4, IPv6)
```
