# Supported AWS Regions for the AWS Marketplace Deployment API
<a name="deployment-regions"></a>

You can access the AWS Marketplace Deployment Service from the US East (N. Virginia) AWS Region with the following endpoint.

```
deployment-marketplace.us-east-1.amazonaws.com
```
