# Service quotas for AWS Marketplace Metering API

Your AWS account has the following quotas related to the AWS Marketplace Metering service.

Request quotas| **API action** | **Request rate (per<br>AWS account)** | **Description** |
| --- | --- | --- |
| `BatchMeterUsage` | 10 per second | The maximum number of `BatchMeterUsage` requests that you<br>can make, per second, in this account in the current region. |
| `MeterUsage` | 10 per second | The maximum number of `MeterUsage` requests that you can<br>make, per second, in this account in the current region. |
| `RegisterUsage` | 5 per second | The maximum number of `RegisterUsage` requests that you<br>can make, per second, in this account in the current region. |
