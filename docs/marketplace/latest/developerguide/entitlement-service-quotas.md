# Service quotas for AWS Marketplace Entitlement API
<a name="entitlement-service-quotas"></a>

Your AWS account has the following quotas related to the AWS Marketplace Entitlement Service.


**Request quotas**  

|  **API action**  | **Request rate (per AWS account)** |  **Description**  | 
| --- | --- | --- | 
| GetEntitlements | 20 per second | The maximum number of GetEntitlements requests that you can make, per second, in this account in the current region. |
