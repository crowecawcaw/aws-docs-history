# Access control for the AWS Marketplace Metering API

To integrate the AWS Marketplace Metering API with AWS Marketplace, the service account must have a constrained AWS Identity and Access Management (IAM) policy. For more information, see [AWS Marketplace metering and entitlement API permissions](../userguide/iam-user-policy-for-aws-marketplace-actions.md "../userguide/iam-user-policy-for-aws-marketplace-actions.md").
