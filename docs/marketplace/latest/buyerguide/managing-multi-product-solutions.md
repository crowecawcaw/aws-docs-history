

# Managing Your Multi-Product Solutions
<a name="managing-multi-product-solutions"></a>

## Viewing Your Solutions
<a name="viewing-your-solutions"></a>

 After purchasing a Multi-Product Solution through an offer set, you can view and manage your agreements through the AWS Marketplace console. 

### Manage subscriptions:
<a name="manage-subscriptions"></a>
+ Navigate to the [AWS Marketplace console](https://console.aws.amazon.com/marketplace)
+ Choose Manage subscriptions from the navigation menu
+ On the subscriptions page, you'll see a table displaying all your agreements
+ Agreements purchased as part of an offer set are identified by an **Offer set ID** column

### Agreements Page
<a name="agreements-page"></a>
+ Access consolidated list of agreements under an offer set id
+ Access separate agreements for each product

## Managing Individual Agreements
<a name="managing-individual-agreements"></a>

 Even though you purchased products as part of a offer set, you maintain independent control over each component: 

### Renewals
<a name="renewals"></a>
+ Renew individual products as their terms expire
+ Negotiate new terms for specific components

### Modifications
<a name="modifications"></a>
+ Amend/upgrade agreements for individual products

### Cancellations
<a name="cancellations"></a>
+ Cancel individual products if no longer needed
+ Other offer set components remain active
+ Work with the seller on any dependencies between products

## Invoicing and Payment
<a name="invoicing-and-payment"></a>

### Separate Invoices
<a name="separate-invoices"></a>
+ Receive invoices for individual products as they exist today
+ Track costs per product for budget allocation
+ Process payments according to each agreement's terms

### Usage Monitoring
<a name="usage-monitoring"></a>
+ Monitor usage for products with consumption-based pricing
+ Set up billing alerts for individual products
