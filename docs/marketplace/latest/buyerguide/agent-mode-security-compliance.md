

# Evaluating seller security and compliance in agent mode

Agent mode helps streamline compliance and risk assessment by bringing a seller's compliance information directly into your evaluation. For sellers whose trust center is hosted by a supported third-party provider, agent mode retrieves the security and compliance profile the seller maintains in that trust center. Currently, agent mode supports trust centers powered by Drata or Vanta.

## What you can do
<a name="agent-mode-security-compliance-what-you-can-do"></a>

With agent mode, you can do the following:
+ **View a compliance profile** – See certifications and frameworks, such as SOC 2, ISO 27001, HIPAA, and GDPR, along with publicly available trust center documents.
+ **Find products that meet your requirements** – Include compliance requirements, such as "SOC 2 Type II and HIPAA", when you describe your needs. Agent mode factors them into recommendations and comparisons.
+ **Request access to NDA-gated evidence documents** – Some documents, such as full audit reports and SOC 2 reports, require a nondisclosure agreement (NDA) with the seller. You can request access from within agent mode and start the NDA process. If your organization has an existing NDA, you receive access automatically.
+ **Compare security and compliance across listings** – Compare products on security and access control, certifications, security controls, and resiliency.
+ **Run an assessment** – Run a Consensus Assessments Initiative Questionnaire (CAIQ) assessment against the seller's trust center evidence or your own uploaded evidence. Agent mode maps the evidence to each CAIQ control and highlights gaps.
+ **Download your assessment** – Download your assessment, including links to trust center documents, to share with your security and procurement teams.

## How it works
<a name="agent-mode-security-compliance-how-it-works"></a>

To evaluate a product's security and compliance in agent mode, do the following:

1. **Ask about security and compliance** – For example, ask "Does this product have SOC 2 Type II?" or "Show me the compliance profile for this product." Agent mode displays the product's compliance profile.

1. **Unlock NDA-gated documents (optional)** – Choose to request access, provide your contact information, and accept the seller's NDA through the seller's third-party trust center provider. You receive an email from that provider with an access code or verification link. Share the code or link in agent mode to continue. Retrieving documents can take several minutes. You can keep using agent mode while this runs, and the compliance profile updates when your documents are available.

1. **Start an assessment** – Choose the evidence to assess: the seller's evidence (after you unlock NDA-gated documents) or your own evidence, which you can upload as PDF, DOCX, or TXT files up to 1.5 MB. Both options include public documents. Assessments use the CAIQ, and other questionnaires aren't supported currently. An assessment starts only when you confirm it.

1. **Review the results** – Agent mode generates an assessment that maps the seller's evidence to the CAIQ controls and highlights gaps. Generation runs in the background, and the artifact updates when it is complete. View the background panel to check status and keep using agent mode for other tasks while you wait.

1. **Download or rerun** – Download the assessment before you rerun it. A new assessment replaces the previous one in your session.

## Important considerations
<a name="agent-mode-security-compliance-considerations"></a>

The seller provides compliance information through their trust center provider. AWS doesn't audit, certify, or verify the seller's compliance claims. Agent mode shows certification names as the seller entered them in their trust center, so similar certifications can appear with slightly different names.
