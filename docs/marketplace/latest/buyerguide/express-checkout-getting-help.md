

# Getting help with Express Checkout purchases

If you bought software with AWS Marketplace Express Checkout, AWS Marketplace and the seller each help with different things.

## Who helps with what
<a name="express-checkout-getting-help-who-helps"></a>


| Contact | Helps with | 
| --- | --- | 
| AWS Marketplace | Billing, payments, card updates, invoices, canceling a subscription, charges you don't recognize, signing in to My Account | 
| The seller | Setting up the product, signing in to the product, using the product, product features, refunds under the seller's policy | 

## Contacting AWS Marketplace support
<a name="express-checkout-getting-help-contacting-support"></a>

1. In [My Account](https://expresscheckout.marketplace.aws.com/subscriptions) on the AWS Marketplace Express Checkout catalog, choose **Account settings**, and then choose **Support** in the left menu. AWS Support opens in a new tab, where you can create a case and check existing cases. You can also go directly to [AWS Marketplace support](https://account.global.app.aws/settings/support).

1. Have your Account ID ready. It's in **Account settings** > **My account**. Choose **Copy Account ID**.

1. Describe the issue. Include the product name and, if it's about a charge, the date and amount.

You don't need an AWS Support plan. 

## Contacting the seller
<a name="express-checkout-getting-help-contacting-seller"></a>

Go to [My Account](https://expresscheckout.marketplace.aws.com/subscriptions) on the Express Checkout catalog, choose the subscription, and use the link to the seller's website.

## Common issues
<a name="express-checkout-getting-help-common-issues"></a>
+ **I can't sign in to My Account.** Sign in with the same email or social account you used at checkout. If that doesn't work, contact AWS Marketplace support.
+ **My payment failed.** See [Payment errors with Express Checkout](express-checkout-payment-errors.md).
+ **I want to cancel.** See [Refunds and cancellations for Express Checkout purchases](express-checkout-refunds-cancellations.md).
+ **The Set up product button isn't showing.** Your payment is still being processed. This usually takes a few minutes. Check My Account again later.
+ **I can't sign in to the product.** Contact the seller.
