# Accessing the dashboard programmatically

To create a **Procurement insights** dashboards programmatically, call the following API:
[GetBuyerDashboard](../APIReference/API_marketplace-reporting_GetBuyerDashboard.md "../APIReference/API_marketplace-reporting_GetBuyerDashboard.md").

###### Important

You must create the service-linked role listed in [Activating the dashboard](enabling-procurement-insights.md#integrate-dashboard "enabling-procurement-insights.md#integrate-dashboard") before you enable trusted access to the dashboard.
Otherwise, the activation process fails.
