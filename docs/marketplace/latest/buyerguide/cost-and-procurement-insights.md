# Managing costs

AWS Marketplace provides the following tools to help manage your costs:

- The **Procurement insights** dashboard shows you the cost-analysis and agreement
  data for all of the AWS accounts in your organization.
- Cost allocation tags help you identify and track AWS Marketplace resource usage through AWS Cost Explorer.
  The following topics explain how to use the tools.
