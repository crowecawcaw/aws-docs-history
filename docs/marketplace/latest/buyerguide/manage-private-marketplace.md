# Managing Private Marketplace

You can manage requests from users, approve additional products to their experiences, associate experiences with additional audiences, and update branding to match the needs of your organization.

- To manage user requests, see [Managing user requests](manage-user-requests.md "manage-user-requests.md").
- To bulk approve or decline products in multiple experiences, see [Bulk managing products](bulk-manage-products.md "bulk-manage-products.md").
- To update experiences, see [Managing experiences](manage-experiences.md "manage-experiences.md").
- To update governance for your users, see [Managing audiences](manage-audiences.md "manage-audiences.md").
  For all administration actions, Private Marketplace starts a Catalog API change set with one or more change types. For more information, see [Viewing changes](view-changes.md "view-changes.md") for details on how to track changes.
