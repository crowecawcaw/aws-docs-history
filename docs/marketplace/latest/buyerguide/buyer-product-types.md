# Product types available in AWS Marketplace

AWS Marketplace includes popular open source and commercial software, as well as free and paid data
products. These products are available in different ways: as individual Amazon Machine Images
(AMIs), as a cluster of AMIs deployed through an AWS CloudFormation template, as software as a service
(SaaS), as professional services, and as AWS Data Exchange data products.

For more details about these product types, see the following topics:

- [AMI-based products](buyer-server-products.md "buyer-server-products.md") (including
  AMI and private image products)
- [Container products in AWS Marketplace](buyer-what-is-aws-marketplace-for-containers.md "buyer-what-is-aws-marketplace-for-containers.md")
- [EC2 Image Builder component products in AWS Marketplace](ec2-image-builder-component-product-type.md "ec2-image-builder-component-product-type.md")
- [Machine learning products in AWS Marketplace](product-types-machine-learning-products.md "product-types-machine-learning-products.md")
- [Purchasing professional services products in AWS Marketplace](buyer-proserv-products.md "buyer-proserv-products.md")
- [SaaS products through AWS Marketplace](buyer-saas-products.md "buyer-saas-products.md")
- [AI agent products](buyer-ai-agents-products.md "buyer-ai-agents-products.md")
  You can also use AWS Marketplace to find and subscribe to data products available through AWS Data Exchange. For more
  information, see [Subscribing to Data Products
  on AWS Data Exchange](../../../data-exchange/latest/userguide/subscribe-to-data-sets.md "../../../data-exchange/latest/userguide/subscribe-to-data-sets.md") in the _AWS Data Exchange User Guide_.
