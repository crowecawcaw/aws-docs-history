

# AWS European Sovereign Cloud (ESC) Marketplace
<a name="esc_marketplace"></a>

 The AWS European Sovereign Cloud (ESC) Marketplace provides a modernized, fully integrated console experience for buyers in European sovereign regions. This implementation brings the latest AWS Marketplace buyer functionality while streamlining the user experience with consolidated console-based operations. ESC Marketplace represents a significant advancement in buyer experience design, offering a unified interface that simplifies procurement workflows. 

## Key Distinction in ESC Marketplace
<a name="key-distinction-in-esc-marketplace"></a>

 ESC Marketplace represents a modernized buyer experience that consolidates all purchasing activities within the AWS console, eliminating the legacy separation between the Marketplace website and console that exists in commercial regions. This streamlined approach provides a more integrated and efficient purchasing workflow. 

 If you are using the AWS European Sovereign Cloud (ESC) Marketplace, some features described in this guide may not be available in your region. ESC Marketplace provides a modernized, console-integrated experience with certain feature variations. 

 When using the ESC Marketplace, buyers will experience: 
+ **Console-only navigation**: All purchasing activities occur within the single AWS console environment, eliminating the need to navigate between multiple sites
+ **Modified product detail pages**: Product pages have been redesigned for the integrated console experience
+ **Streamlined workflows**: Purchasing processes are consolidated within a single interface

## What's Still Available
<a name="whats-still-available"></a>

 **Core Purchasing Capabilities Remain Fully Functional** 

 While certain features are unavailable in the initial ESC Marketplace release, all essential purchasing capabilities remain fully operational: 
+ Product discovery and search
+ Subscription management
+ Private offer acceptance (when sent by sellers)
+ All standard payment and billing processes
+ Product fulfillment and deployment
+ Contract and agreement management

## Feature Availability and Workarounds
<a name="feature-availability-and-workarounds"></a>

 The initial ESC Marketplace release does not include certain features available in other AWS Marketplace regions. The following table outlines unavailable features and recommended workarounds: 


| Feature | Status | Workaround | 
| --- | --- | --- | 
|  Vendor Insights  | Not yet available | Contact vendors directly for compliance and security certification status | 
|  SaaS Quick Launch  | Not yet available | Use "How to Integrate" instructions provided by sellers in the documentation section under vendor resources | 
|  Request Demo  | Not yet available | Contact vendors directly using contact information provided in their listing description | 
|  Request Private Offers / Custom Pricing  | Not yet available | Contact vendors directly using contact information provided in their listing description. Note: While the self-service request button is unavailable, sellers can still create and send private offers to buyers through the standard ESC Marketplace private offer process. | 
|  Similar Product Recommendations  | Not yet available | Use external sites for customer reviews or product comparisons | 
|  Product Reviews  | Not yet available | Use external sites for customer reviews or product comparisons | 
|  AWS PrivateLink Functionality  | Not yet available | No workaround available. This feature requires infrastructure not yet deployed in ESC regions. | 

## Important Notes
<a name="important-notes"></a>
+ All purchasing functionality remains available through the console interface
+ Your existing AWS Marketplace subscriptions and agreements are not affected
+ The buyer guide has been updated to reflect these ESC Marketplace-specific changes
+ For questions about ESC Marketplace functionality, contact AWS Support
