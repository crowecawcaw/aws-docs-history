# Exporting snapshots as a buyer using

AWS Marketplace Vendor Insights

A _snapshot_ is a point-in-time posture of a security
profile. Exporting snapshots provides a way to download and review data offline, review evidence
data, and compare products.

You can export to JSON or CSV formats.

###### To export a snapshot

1. Sign in to the AWS Management Console and open the [AWS Marketplace
   console](https://console.aws.amazon.com/marketplace/ "https://console.aws.amazon.com/marketplace/").
2. Choose **Vendor Insights**.
3. From **Vendor Insights**, choose a product.
4. From the **Security and compliance** tab, go to the
   **Summary** section, and then choose **Export**.
5. From the dropdown list, choose **Download (JSON)** or
   **Download (CSV)**.
