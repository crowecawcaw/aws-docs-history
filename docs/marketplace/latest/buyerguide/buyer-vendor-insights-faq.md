

# AWS Marketplace Vendor Insights FAQ for buyers
<a name="buyer-vendor-insights-faq"></a>

**AWS Marketplace Vendor Insights will no longer be available after November 26th, 2026.**  
We're replacing AWS Marketplace Vendor Insights with new compliance validation features, coming soon. As of October 27th, 2026, you can't request access to any AWS Marketplace Vendor Insights profiles you don't already have access to. Any access you already have stays in place until November 26th, 2026. Download any reports or documents you want to keep before then. Your AWS Marketplace subscriptions and purchases are not affected.

AWS Marketplace Vendor Insights will no longer be available after November 26, 2026.

## Can I still request access to a vendor's profile?
<a name="buyer-vi-faq-request-access"></a>

**No.** As of October 27, 2026, you can't request access to profiles that you don't already have access to.

## Can I still view the profiles I already have access to?
<a name="buyer-vi-faq-view-profiles"></a>

**Yes.** Until November 26, 2026, you can view these profiles and download their reports and documents. After November 26, 2026, Vendor Insights is no longer available.

## What happens to my pending access requests?
<a name="buyer-vi-faq-pending-requests"></a>

As of October 27, 2026, AWS Marketplace stops processing access requests, including any requests that are still pending.

## Should I download documents I already have access to?
<a name="buyer-vi-faq-download-documents"></a>

**Yes.** Download any reports or documents that you need for your records before November 26, 2026. After that date, they aren't available in AWS Marketplace.

## How do I get a vendor's compliance information after November 26, 2026?
<a name="buyer-vi-faq-compliance-info"></a>

Contact the vendor directly. Each product's listing page includes the vendor's contact details.

## Does this change affect my subscriptions or purchases?
<a name="buyer-vi-faq-subscriptions"></a>

**No.** This change doesn't affect your subscriptions, purchases, contracts, or other AWS Marketplace features.
