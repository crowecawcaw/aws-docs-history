# Sending diagnostic logs

If something goes wrong with Amazon Chime, you can send diagnostic logs to help troubleshoot any problems.

###### To send diagnostic logs

1. Open the ellipsis menu next to your name and choose **Send diagnostic logs**.
2. In the **Send diagnostic logs** dialog box, choose **Send**.
3. (Optional) To copy the log's ID for later use, in the **Diagnostic logs successfully sent** dialog box, choose
   **Copy reference ID**.
