# Using the Amazon Chime mobile app

The topics in this section explain how to install and use the Amazon Chime mobile app. You can install the Amazon Chime mobile app on Android devices from Google Play, and on iOS devices
from the App Store. Your devices must run a supported version of those operating systems. For more
information about supported operating systems, see
[1. Know the system requirements](chime-requirements.md "chime-requirements.md").
