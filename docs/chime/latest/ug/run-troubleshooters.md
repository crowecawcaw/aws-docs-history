# Running the device troubleshooters

During a meeting, if you have trouble with a mic, speakers, or a Bluetooth connection, you
can start the Microsoft Windows troubleshooters for those items. You can use the troubleshooters
without leaving the meeting.

###### Note

These steps only apply to Windows devices.

###### To start a troubleshooter

1. Choose the **Audio menu** icon, located next to the microphone icon
   (

![Icon of a microphone and caret symbol.](/images/chime/latest/ug/images/icon-mic-caret.png)

). 2. Under **Device Assistance**, choose the desired troubleshooter. 3. Follow the steps in the troubleshooter.

###### Note

If the troubleshooter fails to resolve your problem, contact your system
administrator.
