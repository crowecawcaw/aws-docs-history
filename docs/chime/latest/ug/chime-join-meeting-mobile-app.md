# Joining a meeting using the Amazon Chime

mobile app

After you install the Amazon Chime mobile app, you must sign in to receive calls and
meetings. For more information, see [Signing in to the mobile app](mobile-sign-in.md "mobile-sign-in.md") and
[Using Meetings view](use-meetings-view.md "use-meetings-view.md") in _Using the Amazon Chime mobile app_, later in this guide.
