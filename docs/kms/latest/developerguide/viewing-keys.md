# Identify and view keys

You can use [AWS Management Console](https://console.aws.amazon.com/kms "https://console.aws.amazon.com/kms") or the [AWS Key Management Service (AWS KMS) API](../APIReference.md "../APIReference.md") to view AWS KMS keys in each account and
Region, including KMS keys that you manage and KMS keys that are managed by AWS.
