# UpdatePrimaryRegion

The following example shows the AWS CloudTrail log entries that are generated by calling the
[UpdatePrimaryRegion](../APIReference/API_UpdatePrimaryRegion.md "../APIReference/API_UpdatePrimaryRegion.md")
operation on a [multi-Region key](multi-region-keys-overview.md "multi-region-keys-overview.md").

The `UpdatePrimaryRegion` operation writes two CloudTrail log entries: one in the
Region with the multi-Region primary key that is converted to a replica key, and one in the
Region with a multi-Region replica key that is converted to a primary key.

CloudTrail log entries for this operation recorded on or after December 2022 include the key ARN of the affected KMS key in the `responseElements.keyId` value, even though this operation does not return the key ARN.

The following example shows a CloudTrail log entry for `UpdatePrimaryRegion` in the
Region where the multi-Region key changed from a primary key to a replica key (us-west-2).
The `primaryRegion` field shows the Region that now hosts the primary key
(ap-northeast-1).

            "userName": "Alice"
