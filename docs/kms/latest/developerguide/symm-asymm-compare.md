# Key type reference

AWS KMS supports different features for different _types_ of
KMS keys. For example, you can only use [symmetric encryption
KMS keys](symm-asymm-choose-key-spec.md#symmetric-cmks "symm-asymm-choose-key-spec.md#symmetric-cmks") to [generate symmetric
data keys](../APIReference/API_GenerateDataKey.md "../APIReference/API_GenerateDataKey.md") and [asymmetric data
key pairs](../APIReference/API_GenerateDataKeyPairs.md "../APIReference/API_GenerateDataKeyPairs.md"). Also, [importing key material](importing-keys.md "importing-keys.md") and
[automatic key rotation](rotate-keys.md "rotate-keys.md") are supported only for symmetric
encryption KMS keys, and you can create only symmetric encryption KMS keys in a [custom key store](key-store-overview.md#custom-key-store-overview "key-store-overview.md#custom-key-store-overview").

This reference includes two tables.

- The [Key type table](#key-type-table "#key-type-table") lists the AWS KMS operations that
  are valid for symmetric encryption KMS keys, asymmetric KMS keys, and HMAC KMS keys.
- The [Special features table](#special-features-table "#special-features-table") lists the AWS KMS
  operations that are valid for multi-Region KMS keys, KMS keys with imported key
  material, and KMS keys in custom key stores.
