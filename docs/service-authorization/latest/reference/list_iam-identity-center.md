# Actions, resources, and condition keys for AWS IAM Identity Center

AWS IAM Identity Center (service prefix: `sso`) provides the following
service-specific operations, resources, actions, and condition keys for use in IAM permission
policies.

  this service](../../../singlesignon/latest/APIReference/API_Operations.md "../../../singlesignon/latest/APIReference/API_Operations.md").

  [using IAM](../../../singlesignon/latest/userguide/iam-auth-access.md "../../../singlesignon/latest/userguide/iam-auth-access.md") permission policies.
- View the [programmatic service authorization
  reference](https://servicereference.us-east-1.amazonaws.com/v1/sso/sso.json "https://servicereference.us-east-1.amazonaws.com/v1/sso/sso.json") for this service.
