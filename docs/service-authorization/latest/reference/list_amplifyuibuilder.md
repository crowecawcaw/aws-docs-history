# Actions, resources, and condition keys for AWS Amplify UI Builder

AWS Amplify UI Builder (service prefix: `amplifyuibuilder`) provides the following
service-specific operations, resources, actions, and condition keys for use in IAM permission
policies.

References:

- Learn how to [configure this service](../../../amplify/latest/userguide.md "../../../amplify/latest/userguide.md").
- View a list of the [API operations available for
  this service](../../../amplifyuibuilder/latest/APIReference.md "../../../amplifyuibuilder/latest/APIReference.md").
- Learn how to secure this service and its resources by
  [using IAM](../../../amplify/latest/userguide/security-iam.md "../../../amplify/latest/userguide/security-iam.md") permission policies.
- View the [programmatic service authorization
  reference](https://servicereference.us-east-1.amazonaws.com/v1/amplifyuibuilder/amplifyuibuilder.json "https://servicereference.us-east-1.amazonaws.com/v1/amplifyuibuilder/amplifyuibuilder.json") for this service.
