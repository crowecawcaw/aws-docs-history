## Actions defined by Amazon SageMaker data science assistant
<a name="list_sagemaker-data-science-assistant-actions-as-permissions"></a>

Amazon SageMaker data science assistant has no API operations that can be used in the `Actions` element of an IAM policy statement.

<a name="list_sagemaker-data-science-assistant-permission-only-actions"></a>

The following actions are defined by Amazon SageMaker data science assistant but are not directly invocable through any API operation. They can only be used in IAM policy statements to grant or deny permissions.

## Condition keys for Amazon SageMaker data science assistant
<a name="list_sagemaker-data-science-assistant-policy-keys"></a>
