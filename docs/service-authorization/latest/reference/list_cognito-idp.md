# Actions, resources, and condition keys for Amazon Cognito User Pools

service-specific operations, resources, actions, and condition keys for use in IAM permission
policies.

  [using IAM](../../../cognito/latest/developerguide/security_iam_service-with-iam.md "../../../cognito/latest/developerguide/security_iam_service-with-iam.md") permission policies.

  reference](https://servicereference.us-east-1.amazonaws.com/v1/cognito-idp/cognito-idp.json "https://servicereference.us-east-1.amazonaws.com/v1/cognito-idp/cognito-idp.json") for this service.
