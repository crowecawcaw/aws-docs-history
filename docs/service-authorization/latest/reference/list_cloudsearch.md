## Resource types defined by Amazon CloudSearch

The following resource types are defined by this service and can be used in the
`Resource` element of IAM permission policy statements.

| Resource types                                                                                                                            | ARN                                                                    | Condition keys |
| ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------------- |
| [domain](../../../cloudsearch/latest/developerguide/creating-domains.md "../../../cloudsearch/latest/developerguide/creating-domains.md") | arn:${Partition}:cloudsearch:${Region}:${Account}:domain/${DomainName} |                |

## Condition keys for Amazon CloudSearch

Amazon CloudSearch has no service-specific condition keys that can be used in the
`Condition` element of policy statements.
