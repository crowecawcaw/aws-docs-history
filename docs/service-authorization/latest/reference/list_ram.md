# Actions, resources, and condition keys for AWS Resource Access Manager (RAM)

AWS Resource Access Manager (RAM) (service prefix: `ram`) provides the following
service-specific operations, resources, actions, and condition keys for use in IAM permission
policies.

References:

- Learn how to [configure this service](../../../ram/latest/userguide/what-is.md "../../../ram/latest/userguide/what-is.md").
- View a list of the [API operations available for
  this service](../../../ram/latest/APIReference/API_Operations.md "../../../ram/latest/APIReference/API_Operations.md").
- Learn how to secure this service and its resources by
  [using IAM](../../../ram/latest/userguide/security.md "../../../ram/latest/userguide/security.md") permission policies.
- View the [programmatic service authorization
  reference](https://servicereference.us-east-1.amazonaws.com/v1/ram/ram.json "https://servicereference.us-east-1.amazonaws.com/v1/ram/ram.json") for this service.
