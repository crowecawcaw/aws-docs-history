

# Actions, resources, and condition keys for AWS Elemental Appliances and Software Activation Service

## Actions defined by AWS Elemental Appliances and Software Activation Service
<a name="list_elemental-activations-actions-as-permissions"></a>

AWS Elemental Appliances and Software Activation Service has no API operations that can be used in the `Actions` element of an IAM policy statement.

## Permission-only actions for AWS Elemental Appliances and Software Activation Service
<a name="list_elemental-activations-permission-only-actions"></a>

The following actions are defined by AWS Elemental Appliances and Software Activation Service but are not directly invocable through any API operation. They can only be used in IAM policy statements to grant or deny permissions.



| Actions | Description | Resource types (\*required) | Condition keys | Access level | 
| --- | --- | --- | --- | --- | 
|   [CompleteAccountRegistration](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to complete the process of registering customer account for AWS Elemental Appliances and Software Purchases |  |   | Write | 
|   [CompleteFileUpload](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to complete the process of uploading a Software file for AWS Elemental Appliances and Software Purchases |  |   | Write | 
|   [ConfirmAccount](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to confirm asset ownership |  |   | Write | 
|   [DownloadKickstart](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to download the kickstart files for AWS Elemental Appliances and Software purchases |  |   | Read | 
|   [DownloadSoftware](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to download the Software files for AWS Elemental Appliances and Software Purchases |  |   | Read | 
|   [GenerateLicense](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to generate a software license for an AWS Elemental Appliances and Software purchase |  |   | Write | 
|   [GenerateLicenses](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to generate Software Licenses for AWS Elemental Appliances and Software Purchases |  |   | Write | 
|   [GetArtifactGroupSoftwareVersions](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to describe the software version of an artifact group |  |   | Read | 
|   [GetAsset](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to describe an asset |  |   | Read | 
|   [GetAssets](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to describe assets associated to the requesting account |  |   | Read | 
|   [GetProductAdvisories](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to get all product advisories |  |   | Read | 
|   [GetSoftwareVersions](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to describe available software versions |  |   | Read | 
|   [StartFileUpload](https://docs.aws.amazon.com/elemental-appliances-software/)  | Grants permission to start the process of uploading a Software file for AWS Elemental Appliances and Software Purchases |  |   | Write | 

## Resource types defined by AWS Elemental Appliances and Software Activation Service
<a name="list_elemental-activations-resources-for-iam-policies"></a>

AWS Elemental Appliances and Software Activation Service does not support specifying a resource ARN in the `Resource` element of an IAM policy statement.

## Condition keys for AWS Elemental Appliances and Software Activation Service
<a name="list_elemental-activations-policy-keys"></a>

AWS Elemental Appliances and Software Activation Service has no service-specific condition keys that can be used in the `Condition` element of policy statements.
