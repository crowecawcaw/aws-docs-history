Amazon EC2 Auto Scaling (service prefix: `autoscaling`) provides the following
service-specific operations, resources, actions, and condition keys for use in IAM permission
policies.

- Learn how to secure this service and its resources by
  [using IAM](../../../autoscaling/latest/userguide/IAM.md "../../../autoscaling/latest/userguide/IAM.md") permission policies.
- View the [programmatic service authorization
  reference](https://servicereference.us-east-1.amazonaws.com/v1/autoscaling/autoscaling.json "https://servicereference.us-east-1.amazonaws.com/v1/autoscaling/autoscaling.json") for this service.

## Actions defined by Amazon EC2 Auto Scaling

policy statement. Use policies to grant permissions to perform an operation in AWS. When
you use an action in a policy, you usually allow or deny access to the API operation or CLI
command with the same name. However, in some cases, a single action controls access to more
than one operation. Alternatively, some operations require several different actions.
