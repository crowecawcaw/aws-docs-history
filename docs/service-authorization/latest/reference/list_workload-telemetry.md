

# Actions, resources, and condition keys for AWS Workload Telemetry Service

AWS Workload Telemetry Service (service prefix: `workload-telemetry`) provides the following service-specific operations, resources, actions, and condition keys for use in IAM permission policies.

## Actions defined by AWS Workload Telemetry Service
<a name="list_workload-telemetry-actions-as-permissions"></a>

AWS Workload Telemetry Service has no API operations that can be used in the `Actions` element of an IAM policy statement.

## Permission-only actions for AWS Workload Telemetry Service
<a name="list_workload-telemetry-permission-only-actions"></a>

The following actions are defined by AWS Workload Telemetry Service but are not directly invocable through any API operation. They can only be used in IAM policy statements to grant or deny permissions.



| Actions | Description | Resource types (\*required) | Condition keys | Access level | 
| --- | --- | --- | --- | --- | 
|   [PutCertificateTelemetry](https://docs.aws.amazon.com/acm/latest/userguide/acm-certificate-automation.html)  | Grants permission to put certificate discovery and automation telemetry from the AWS Workload Credentials Provider agent |  |   | Write | 

## Resource types defined by AWS Workload Telemetry Service
<a name="list_workload-telemetry-resources-for-iam-policies"></a>

AWS Workload Telemetry Service does not support specifying a resource ARN in the `Resource` element of an IAM policy statement.

## Condition keys for AWS Workload Telemetry Service
<a name="list_workload-telemetry-policy-keys"></a>

AWS Workload Telemetry Service has no service-specific condition keys that can be used in the `Condition` element of policy statements.
