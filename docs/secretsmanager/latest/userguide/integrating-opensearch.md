# How Amazon OpenSearch

Ingestion uses Secrets Manager

Amazon OpenSearch Ingestion is a fully managed,
serverless data collector that streams real-time logs, metrics, and trace data to
Amazon OpenSearch Service domains and OpenSearch Serverless collections. You can use
OpenSearch Ingestion pipelines with Secrets Manager to securely manage your
credentials. For more information, see:
