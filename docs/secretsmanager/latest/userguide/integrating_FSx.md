# How Amazon FSx uses AWS Secrets Manager secrets

Amazon FSx for Windows File Server provides fully managed Microsoft Windows file
servers, backed by a fully native Windows file system. When you create or manage file
shares, you can pass credentials from an AWS Secrets Manager secret. For more information, see
[File shares](../../../fsx/latest/WindowsGuide/managing-file-shares.md "../../../fsx/latest/WindowsGuide/managing-file-shares.md") and [Migrating file
share configurations to Amazon FSx](../../../fsx/latest/WindowsGuide/migrate-file-share-config-to-fsx.md "../../../fsx/latest/WindowsGuide/migrate-file-share-config-to-fsx.md") in the
_Amazon FSx for Windows File Server User Guide_.
