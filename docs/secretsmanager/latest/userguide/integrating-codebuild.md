# How AWS CodeBuild uses AWS Secrets Manager

AWS CodeBuild is a fully managed build service in the cloud. CodeBuild compiles your source
code, runs unit tests, and produces artifacts ready to deploy.

You can store your private registry credentials using Secrets Manager. For more information, see
[Private registry with
AWS Secrets Manager sample for CodeBuild](../../../codebuild/latest/userguide/sample-private-registry.md "../../../codebuild/latest/userguide/sample-private-registry.md") in the
_AWS CodeBuild User Guide_.
