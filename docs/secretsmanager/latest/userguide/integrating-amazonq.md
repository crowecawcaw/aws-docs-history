# How Amazon Q uses Secrets Manager

To authenticate Amazon Q to access your data source, you provide your data source access
credentials to Amazon Q using an Secrets Manager secret. If you use the console, you can choose to create
a new secret or use an existing one. For more information, see [Concepts – Authentication](../../../amazonq/latest/business-use-dg/connector-concepts.md#connector-authentication "../../../amazonq/latest/business-use-dg/connector-concepts.md#connector-authentication") in the _Amazon Q Developer
Guide_.
