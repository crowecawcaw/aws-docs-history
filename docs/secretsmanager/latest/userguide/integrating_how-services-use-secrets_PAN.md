# How AWS Panorama

uses Secrets Manager

AWS Panorama is a service that brings computer vision to your on-premises
camera network. You use AWS Panorama to register an appliance, update its
software, and deploy applications to it. When you register a video stream as a data
source for your application, if the stream is password protected, AWS Panorama
stores the credentials for it in a Secrets Manager secret. For more information, see [Managing
camera streams in AWS Panorama](../../../panorama/latest/dev/appliance-cameras.md "../../../panorama/latest/dev/appliance-cameras.md") in the _AWS Panorama Developer Guide_.
