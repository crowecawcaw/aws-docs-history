# How AWS Elemental MediaPackage uses

AWS Secrets Manager

AWS Elemental MediaPackage is a just-in-time video packaging and origination service that runs in the
AWS Cloud. With MediaPackage, you can deliver highly secure, scalable, and reliable video streams
to a wide variety of playback devices and content delivery networks (CDNs). For more
information, see [Secrets Manager access for
CDN authorization](../../../mediapackage/latest/ug/setting-up-create-trust-rel-policy-cdn.md "../../../mediapackage/latest/ug/setting-up-create-trust-rel-policy-cdn.md") in the _AWS Elemental MediaPackage User Guide_.
