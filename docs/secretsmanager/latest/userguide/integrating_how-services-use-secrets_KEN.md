# How Amazon Kendra uses

AWS Secrets Manager

Amazon Kendra is a highly accurate and intelligent search service that enables your users to
search unstructured and structured data using natural language processing and advanced
search algorithms.

You can index documents stored in a database by specifying a secret that contains
credentials for the database. For more information, see [Using a database data
source](../../../kendra/latest/dg/data-source-database.md "../../../kendra/latest/dg/data-source-database.md") in the _Amazon Kendra User Guide_.
