# Tutorials for AWS IoT Events uses cases

AWS IoT Events tutorials provide a collection of procedures covering various aspects of AWS IoT Events, from
basic setup to more specific use cases. Each tutorial shows examples of practical scenarios,
helping you build real-world skills in creating detector models, configuring inputs, setting up
actions, and integrating with other AWS services to create powerful IoT solutions.

This chapter shows you how to:

- Get help to decide which states to include in your detector model, and determine whether
  you need one detector instance or several.
- Follow an example that uses the AWS CLI.
- Create an input to receive telemetry data from a device and a detector model to monitor
  and report on the state of the device that sends that data.
- Review restrictions and limitations on inputs, detector models, and the AWS IoT Events
  service.
- See a more complex example of a detector model, with comments included.
