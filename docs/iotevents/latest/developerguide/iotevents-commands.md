# AWS IoT Events commands

This chapter provides a comprehensive guide to all the API operations available in AWS IoT Events. It
offers detailed explanations, including sample requests, responses, and potential errors for
each operation across the supported web services protocols. Understanding these API operations
helps you effectively integrate AWS IoT Events into your IoT applications and automate your event
detection and response workflows.

## AWS IoT Events actions

You can use AWS IoT Events API commands to create, read, update, and delete inputs and detector
models, and to list their versions. For more information, see the [actions](../apireference/API_Operations_AWS_IoT_Events.md "../apireference/API_Operations_AWS_IoT_Events.md") and [data
types](../apireference/API_Types_AWS_IoT_Events.md "../apireference/API_Types_AWS_IoT_Events.md") that are supported by AWS IoT Events in the _AWS IoT Events API
Reference_.

The [AWS IoT Events
sections](../../../cli/latest/reference/iotevents/index.md#cli-aws-iotevents "../../../cli/latest/reference/iotevents/index.md#cli-aws-iotevents") in the _AWS CLI Command Reference_ include the AWS CLI commands that
you can use to administer and manipulate AWS IoT Events.

## AWS IoT Events data

You can use the AWS IoT Events Data API commands to send inputs to detectors, list detectors, and
view or update a detector's status. For more information, see the [actions](../apireference/API_Operations_AWS_IoT_Events_Data.md "../apireference/API_Operations_AWS_IoT_Events_Data.md") and [data
types](../apireference/API_Types_AWS_IoT_Events_Data.md "../apireference/API_Types_AWS_IoT_Events_Data.md") that are supported by AWS IoT Events Data in the _AWS IoT Events API
Reference_.

The [AWS IoT Events data sections](../../../cli/latest/reference/iotevents-data/index.md "../../../cli/latest/reference/iotevents-data/index.md") in
the _AWS CLI Command Reference_ includes the AWS CLI commands that you can use to
process AWS IoT Events data.
