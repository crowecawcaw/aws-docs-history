# What is the End device SDK?

###### What is the End device SDK?

The End device SDK is a collection of source code, libraries, and tools provided by AWS IoT.
Built for resource-constrained environments, the SDK supports devices with as little as 512
KB RAM and 4 MB flash memory, such as cameras and air purifiers running on embedded Linux
and real-time operating systems (RTOS). Download the latest version of the End device SDK from the [AWS IoT Management Console](https://console.aws.amazon.com/iot "https://console.aws.amazon.com/iot").

###### Core components

The SDK combines an MQTT agent for cloud communication,
a jobs handler for task management, and a managed integrations, Data Model Handler. These components work together to provide secure connectivity and
automated data translation between your devices and managed integrations.

For detailed technical requirements, see the [Technical reference](managedintegrations-sdk-device-appendix.md "managedintegrations-sdk-device-appendix.md").
