

# Install and validate the managed integrations Hub SDK
<a name="managedintegrations-sdk-v2-cookbook-deployment"></a>

Choose between the following deployment methods to install the managed integrations Hub SDK on your devices—AWS IoT Greengrass for automated deployment or a manual script installation. This section describes the setup and validation steps for both approaches.

Before you begin, download the [Managed Integrations Hub SDK version 2.4.0 for aarch64](https://d2no7dt1utuyzo.cloudfront.net/IotMI-HubSDK/2.4.0/IoT-managed-integrations-Hub-SDK-aarch64-unknown-linux-gnu-2.4.0.zip). The deployment methods in this section install the SDK from this archive. For more information about running the SDK from a prebuilt Raspberry Pi image instead, see [Managed Integrations Hub SDK image on Raspberry Pi](raspberrypi-device-hub-sdk.md).
