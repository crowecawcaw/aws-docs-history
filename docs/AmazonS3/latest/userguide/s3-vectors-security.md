# Security in S3 Vectors

Amazon S3 Vectors offers highly durable vector storage. Data written to S3 Vectors is stored on S3, which is
designed for 99.999999999% (11 nines) of data durability.

S3 Vectors implements a security approach that includes encryption at rest and secure
data transmission. Whether you're storing millions of vectors for machine learning
applications or building semantic search systems, S3 Vectors provides the security controls
necessary to meet your organization's compliance and data protection requirements.
