# Reference

In addition to the Amazon S3 console, you can work with Amazon S3 programmatically using the Amazon S3 REST APIs, AWS SDKs, or AWS Command Line Interface (AWS CLI).


* [Amazon Simple Storage Service API Reference](../API/Welcome.md "../API/Welcome.md")
* [Code examples](../API/service_code_examples.md "../API/service_code_examples.md") in the *Amazon Simple Storage Service API Reference*
* [AWS Command Line Interface](https://docs.aws.amazon.com/cli/latest/userguide/cli-s3.html "https://docs.aws.amazon.com/cli/latest/userguide/cli-s3.html") in the *AWS Command Line Interface User Guide*.
* [AWS SDKs](https://aws.amazon.com/developer/tools/?nc1=f_dr "https://aws.amazon.com/developer/tools/?nc1=f_dr")
