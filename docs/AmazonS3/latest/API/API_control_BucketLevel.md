# BucketLevel

A container for the bucket-level configuration for Amazon S3 Storage Lens.

For more information about S3 Storage Lens, see [Assessing your storage activity and usage with S3 Storage Lens](../userguide/storage_lens.md "../userguide/storage_lens.md") in the *Amazon S3 User Guide*.


## Contents





**ActivityMetrics** 


A container for the bucket-level activity metrics for S3 Storage Lens.


Type: [ActivityMetrics](API_control_ActivityMetrics.md "API_control_ActivityMetrics.md") data type


Required: No




**AdvancedCostOptimizationMetrics** 


A container for bucket-level advanced cost-optimization metrics for S3 Storage Lens.


Type: [AdvancedCostOptimizationMetrics](API_control_AdvancedCostOptimizationMetrics.md "API_control_AdvancedCostOptimizationMetrics.md") data type


Required: No




**AdvancedDataProtectionMetrics** 


A container for bucket-level advanced data-protection metrics for S3 Storage Lens.


Type: [AdvancedDataProtectionMetrics](API_control_AdvancedDataProtectionMetrics.md "API_control_AdvancedDataProtectionMetrics.md") data type


Required: No




**DetailedStatusCodesMetrics** 


A container for bucket-level detailed status code metrics for S3 Storage Lens.


Type: [DetailedStatusCodesMetrics](API_control_DetailedStatusCodesMetrics.md "API_control_DetailedStatusCodesMetrics.md") data type


Required: No




**PrefixLevel** 


A container for the prefix-level metrics for S3 Storage Lens. 


Type: [PrefixLevel](API_control_PrefixLevel.md "API_control_PrefixLevel.md") data type


Required: No
