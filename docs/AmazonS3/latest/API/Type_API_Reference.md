# S3 API Reference

This section contains the Amazon S3 API Reference documentation, which includes
 *actions* (operations) and data types.

The S3 API reference groups each of its [Actions](API_Operations.md "API_Operations.md") and [Data Types](API_Types.md "API_Types.md") into three sets: *Amazon S3*,
 *Amazon S3 Control*, and *Amazon S3 on Outposts*. There
 is no functional distinction between the three sets. If you don't find an API operation
 or data type that you're looking for in one set, check one of the other sets.

*Actions*


* [Amazon S3](API_Operations_Amazon_Simple_Storage_Service.md "API_Operations_Amazon_Simple_Storage_Service.md") — API
 operations that apply bucket-level and object-level actions.
* [Amazon S3 Control](API_Operations_AWS_S3_Control.md "API_Operations_AWS_S3_Control.md") — API operations for
 managing all other S3 resources.
* [Amazon S3 on Outposts](API_Operations_Amazon_S3_on_Outposts.md "API_Operations_Amazon_S3_on_Outposts.md") — API
 operations for use with Amazon S3 on Outposts. You communicate with your Outposts
 bucket using an access point and endpoint connection over a virtual private
 cloud (VPC).
* [Amazon S3 Tables](API_Operations_Amazon_S3_Tables.md "API_Operations_Amazon_S3_Tables.md") — API operations for use with Amazon S3 Tables.
* [Amazon S3 Vectors](API_Operations_Amazon_S3_Vectors.md "API_Operations_Amazon_S3_Vectors.md") — API operations for use with Amazon S3 Vectors.
*Data types*


* [Amazon S3](API_Types_Amazon_Simple_Storage_Service.md "API_Types_Amazon_Simple_Storage_Service.md") — Data types
 of API operations that apply bucket-level and object-level actions.
* [Amazon S3 Control](API_Types_AWS_S3_Control.md "API_Types_AWS_S3_Control.md") — Data types of API
 operations for managing all other S3 resources.
* [Amazon S3 on Outposts](API_Types_Amazon_S3_on_Outposts.md "API_Types_Amazon_S3_on_Outposts.md") — Data types of API
 operations for use with Amazon S3 on Outposts.
* [Amazon S3 Tables](API_Types_Amazon_S3_Tables.md "API_Types_Amazon_S3_Tables.md") — Data types of API
 operations for use with Amazon S3 Tables.
* [Amazon S3 Vectors](API_Types_Amazon_S3_Vectors.md "API_Types_Amazon_S3_Vectors.md") — Data types of API
 operations for use with Amazon S3 Vectors.
