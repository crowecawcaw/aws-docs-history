# AccountLevel

A container element for the account-level Amazon S3 Storage Lens configuration.

For more information about S3 Storage Lens, see [Assessing your storage activity and usage with S3 Storage Lens](../userguide/storage_lens.md "../userguide/storage_lens.md") in the *Amazon S3 User Guide*. For a complete list of S3 Storage Lens metrics, see [S3 Storage Lens metrics glossary](../userguide/storage_lens_metrics_glossary.md "../userguide/storage_lens_metrics_glossary.md") in the *Amazon S3 User Guide*.
