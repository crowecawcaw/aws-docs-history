# BucketLifecycleConfiguration

Specifies the lifecycle configuration for objects in an Amazon S3 bucket. For more information, see
 [Object Lifecycle
 Management](https://docs.aws.amazon.com/AmazonS3/latest/dev/object-lifecycle-mgmt.html "https://docs.aws.amazon.com/AmazonS3/latest/dev/object-lifecycle-mgmt.html") in the *Amazon S3 User Guide*.


## Contents





**Rules** 


A lifecycle rule for individual objects in an Amazon S3 bucket.


Type: Array of [LifecycleRule](API_LifecycleRule.md "API_LifecycleRule.md") data types


Required: Yes
