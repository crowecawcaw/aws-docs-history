# IcebergCompactionSettings

Contains details about the compaction settings for an Iceberg table.


## Contents





**targetFileSizeMB** 


The target file size for the table in MB.


Type: Integer


Valid Range: Minimum value of 1. Maximum value of 2147483647.


Required: No
