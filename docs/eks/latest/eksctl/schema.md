# Cluster Config Schema

###### Note

The location of the schema is currently being migrated.

You can use a yaml file to create a cluster. [View the schema reference.](https://schema.eksctl.io/ "https://schema.eksctl.io/")

For example:

```
eksctl create cluster -f cluster.yaml
```

[The schema reference for this file is available on GitHub.](https://schema.eksctl.io/ "https://schema.eksctl.io/")

For more information about using the file, see [Creating and managing clusters](creating-and-managing-clusters.md "creating-and-managing-clusters.md").
