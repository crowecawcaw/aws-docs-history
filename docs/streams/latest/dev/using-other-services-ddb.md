# Write to Kinesis Data Streams using Amazon DynamoDB

You can use Amazon Kinesis Data Streams to capture changes to Amazon DynamoDB. Kinesis Data Streams captures item-level
modifications in any DynamoDB table and replicates them to a Kinesis data stream. Your
consumer applications can access this stream to view item-level changes in real time and
deliver those changes downstream or take action based on the content.

For more information, see [how Kinesis Data Streams work with DynamoDB](../../../amazondynamodb/latest/developerguide/kds.md "../../../amazondynamodb/latest/developerguide/kds.md") in the _Amazon DynamoDB Developer Guide_.
