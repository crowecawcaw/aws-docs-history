# Write to Kinesis Data Streams using Amazon EventBridge

Using Kinesis Data Streams, you can send AWS API call [events](../../../eventbridge/latest/userguide/eb-events.md "../../../eventbridge/latest/userguide/eb-events.md") in EventBridge to a stream, build consumer applications, and process large amounts of data. You can also use Kinesis Data Streams as a target in EventBridge Pipes and deliver records a stream from one of the available sources after optional filtering and enrichment.

For more information, see [Send
events to an Amazon Kinesis stream](../../../eventbridge/latest/userguide/eb-relay-events-kinesis-stream.md "../../../eventbridge/latest/userguide/eb-relay-events-kinesis-stream.md") and [EventBridge Pipes](../../../eventbridge/latest/userguide/eb-pipes.md "../../../eventbridge/latest/userguide/eb-pipes.md") in the _Amazon EventBridge User Guide_.
