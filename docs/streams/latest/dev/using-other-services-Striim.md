# Striim

Striim is a complete, end-to-end, in-memory platform for collecting, filtering, transforming, enriching, aggregating, analyzing, and delivering data in real time. For more information on how to write data to Kinesis Data Streams from Striim, see the
[Kinesis Writer](https://www.striim.com/docs/en/kinesis-writer.html "https://www.striim.com/docs/en/kinesis-writer.html").
