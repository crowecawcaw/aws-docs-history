# Read data from Kinesis Data Streams using Amazon Redshift

Amazon Redshift supports streaming ingestion from Amazon Kinesis Data Streams. The Amazon Redshift streaming ingestion feature
provides low-latency, high-speed ingestion of streaming data from Amazon Kinesis Data
Streams into an Amazon Redshift materialized view. Amazon Redshift streaming ingestion
removes the need to stage data in Amazon S3before ingesting into Amazon Redshift.

For more information, see [Streaming ingestion](../../../redshift/latest/dg/materialized-view-streaming-ingestion.md "../../../redshift/latest/dg/materialized-view-streaming-ingestion.md") in the _Amazon Redshift Release Guide_.
