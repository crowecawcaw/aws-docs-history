# Talend

Talend is a data integration and management software that allows users to collect,
transform, and connect data from various sources in a scalable and efficient manner. For
more information on consuming Kinesis data streams using Talend, see [Connect talend to an Amazon Kinesis stream](https://help.talend.com/r/en-US/Cloud/connectors-guide/connector-kinesis "https://help.talend.com/r/en-US/Cloud/connectors-guide/connector-kinesis").
