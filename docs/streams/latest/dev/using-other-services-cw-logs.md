# Write to Kinesis Data Streams using Amazon CloudWatch Logs

You can use CloudWatch subscriptions to get access to a real-time feed of log events from
Amazon CloudWatch Logs and have it delivered to a Kinesis data stream for processing, analysis, and
loading to to other systems.

For more information, see [Real-time processing of log data with subscriptions](../../../AmazonCloudWatch/latest/logs/Subscriptions.md "../../../AmazonCloudWatch/latest/logs/Subscriptions.md") in the _Amazon CloudWatch Logs User Guide_.
