# Debezium

Debezium is an open source distributed platform for change data capture. For more information on writing to Kinesis Data Streams from Debezium, see
[Streaming MySQL Data Changes to Amazon Kinesis](https://debezium.io/blog/2018/08/30/streaming-mysql-data-changes-into-kinesis/ "https://debezium.io/blog/2018/08/30/streaming-mysql-data-changes-into-kinesis/").
