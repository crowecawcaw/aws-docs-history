# Write to Kinesis Data Streams using Amazon Relational Database Service

You can use Amazon Kinesis Data Streams to monitor activities on your Amazon RDS instances. Using Database
Activity Streams, Amazon RDS pushes activities to a Kinesis data stream in real-time. You can
then build applications for compliance management that consume these activities, audit
them and generate alerts. You can also use Amazon Data Firehose to store the data.

For more information, see [Database Activity Streams](../../../AmazonRDS/latest/UserGuide/DBActivityStreams.md "../../../AmazonRDS/latest/UserGuide/DBActivityStreams.md") in the _Amazon RDS Developer Guide_.
