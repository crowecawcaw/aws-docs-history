# Read data from Kinesis Data Streams using Amazon EventBridge Pipes

Amazon EventBridge Pipes supports Kinesis data streams as a source. Amazon EventBridge Pipes helps you
create point-to-point integrations between event producers and consumers with optional
transform, filter and enrich steps. You can use EventBridge Pipes to receive records in a Kinesis
data stream and optionally filter or enhance these records before sending them to one of
the available destinations for processing, including Kinesis Data Streams.

For more information, see [Amazon Kinesis stream as a source](../../../eventbridge/latest/userguide/eb-pipes-kinesis.md "../../../eventbridge/latest/userguide/eb-pipes-kinesis.md") in the _Amazon EventBridge Release Guide_.
