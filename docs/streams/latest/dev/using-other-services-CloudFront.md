# Write to Kinesis Data Streams using Amazon CloudFront

You can use Amazon Kinesis Data Streams with CloudFront real-time logs and get information about requests made
to a distribution in real time. You can then build your own [Kinesis data stream
consumer](building-consumers.md "building-consumers.md"), or use Amazon Data Firehose to send the log data to Amazon S3, Amazon Redshift, Amazon OpenSearch Service, or
a third-party log processing service.

For more information, see [Real-time logs](../../../AmazonCloudFront/latest/DeveloperGuide/real-time-logs.md "../../../AmazonCloudFront/latest/DeveloperGuide/real-time-logs.md") in the _Amazon CloudFront Developer Guide_.
