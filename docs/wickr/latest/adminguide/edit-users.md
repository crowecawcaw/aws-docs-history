# Edit users in AWS Wickr network
<a name="edit-users"></a>

You can edit users in your Wickr network.

Complete the following procedure to edit a user.

1. Open the AWS Management Console for Wickr at [https://console.aws.amazon.com/wickr/](https://console.aws.amazon.com/wickr/).

1. On the **Networks** page, select the network name to navigate to that network.

1. In the navigation pane, choose **User management**.

1. In the **Team directory** tab, select the vertical ellipsis (three dots) icon of the user you want to edit.

1. Choose **Edit**.

1. Edit the user information, and then choose **Save changes**.
