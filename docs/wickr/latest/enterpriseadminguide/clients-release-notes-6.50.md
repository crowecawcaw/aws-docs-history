# Clients 6.50 release
<a name="clients-release-notes-6.50"></a>

The following release notes include information for clients release 6.50. For information on the release timeline, see [Change log](#clients-release-notes-6.50-change-log).

**Platform versions**


|  |  | 
| --- | --- | 
| Android | 6.50.4 | 
| iOS | 6.50.21 | 
| Desktop (Mac, Windows) | 6.50.12 | 
| Linux | 6.50.12 | 

**Android**

New features: 

A dedicated **Files** tab has been added in room conversations to upload and organize files/folders. For more information, see [Manage files in the Wickr client](https://docs.aws.amazon.com/wickr/latest/userguide/room-file-management.html). To enable this feature from Replicated UI, see [File management](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/file-management.html).

Changes, enhancements, and resolved issues: 

General enhancements and bug fixes.

**iOS**

New features: 

A dedicated **Files** tab has been added in room conversations to upload and organize files/folders. For more information, see [Manage files in the Wickr client](https://docs.aws.amazon.com/wickr/latest/userguide/room-file-management.html). To enable this feature from Replicated UI, see [File management](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/file-management.html).

Changes, enhancements, and resolved issues: 

General enhancements and bug fixes.

**Desktop**

New features: 
+ A dedicated **Files** tab has been added in room conversations to upload and organize files/folders. For more information, see [Manage files in the Wickr client](https://docs.aws.amazon.com/wickr/latest/userguide/room-file-management.html). To enable this feature from Replicated UI, see [File management](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/file-management.html).
+ Dark mode support has been added. For more information, see [Dark mode in the Wickr client](https://docs.aws.amazon.com/wickr/latest/userguide/dark-mode.html).

Changes, enhancements, and resolved issues: 

General enhancements and bug fixes.
