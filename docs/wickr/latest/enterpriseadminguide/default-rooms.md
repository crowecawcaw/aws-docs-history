# Default rooms

When the super administrator has enabled the default room option, network administrators
can create rooms managed by a bot. This bot will automatically add users to a room. If users
leave the room, they will be re-added.

A room can be made for all users in the network, for specific security groups, or
both.

In these rooms, there are no other moderators other than the default room bot, so
settings and users can’t be managed within the app by end users.
