# Crash report

Super administrators can generate crash reports in case of failures. Provide the report to
Wickr in the event of failures, however, note that these files and more are available
server-side and replicated.

**To generate a crash report**

1. In the navigation pane of the Wickr Super Administrator Console, choose **Crash
   Report**.
2. On the **Crash Report** page, choose **Download Crash
   Report**.
