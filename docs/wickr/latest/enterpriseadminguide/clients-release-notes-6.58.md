# Clients 6.58 release
<a name="clients-release-notes-6.58"></a>

The following release notes include information for clients release 6.58. For information on the release timeline, see [Change log](#clients-release-notes-6.58-change-log).

**Platform versions**


|  |  | 
| --- | --- | 
| Android | 6.58.3 | 
| iOS | 6.58.12 | 
| Desktop (Mac, Windows) | 6.58.12 | 

**Android**

Changes, enhancements, and resolved issues:
+ Added Calling Ingress support to enable flexible call routing within cluster nodes.
+ Various performance improvements and bug fixes.

**Note**  
Starting with client release version 6.64 (planned for December, 2025), Wickr Enterprise will no longer provide updates or support for the Android client running on OS versions that have reached their end of life. We recommend upgrading to Android version 13 or later.

**iOS**

Changes, enhancements, and resolved issues:
+ Added Calling Ingress support to enable flexible call routing within cluster nodes.
+ Various performance improvements and bug fixes.

**Note**  
Starting with client release version 6.64 (planned for December, 2025), Wickr Enterprise will no longer provide updates or support for the iOS client running on OS versions that have reached their end of life. We recommend upgrading to iOS version 17 or later.

**Desktop**

Changes, enhancements, and resolved issues:
+ Added Calling Ingress support to enable flexible call routing within cluster nodes.
+ Various performance improvements and bug fixes.
