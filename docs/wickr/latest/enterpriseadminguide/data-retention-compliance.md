# Wickr Enterprise Data Retention (Compliance)

Service: Installation, Maintenance, and Examples

The Wickr Enterprise Compliance Service allows a network administrator to record
communications within a single network. Multiple bots can be setup and configured to capture
messages and files across multiple networks. In the current iteration you need one bot per
network, and it must be done at network creation. Bots cannot be added to existing networks at
this time.
