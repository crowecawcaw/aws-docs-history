# Role Based Access Control

Roles are a group of permissions that can be assigned to a member or an admin by a super
administrator.

**To create a role**

1. In the navigation pane of the Wickr Super Administrator Console, choose **Role
   Based Access Control**.
2. On the **Roles** page, choose **+ New Role**.
3. In the **New Role** section, add the name for the role in the
   **Name** text box.
4. Choose **Add Permissions**.
5. In the **Add Permissions** dialog box, select one or more permissions to
   assign to the role.
6. Choose **Save**.
