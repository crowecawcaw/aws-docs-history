# Role Based Access Control
<a name="roles"></a>

Roles are a group of permissions that can be assigned to a member or an admin by a super administrator.

**To create a role**

1. In the navigation pane of the Wickr Super Administrator Console, choose **Role Based Access Control**.

1. On the **Roles** page, choose **\+ New Role**.

1. In the **New Role** section, add the name for the role in the **Name** text box.

1. Choose **Add Permissions**.

1. In the **Add Permissions** dialog box, select one or more permissions to assign to the role.

1. Choose **Save**.
