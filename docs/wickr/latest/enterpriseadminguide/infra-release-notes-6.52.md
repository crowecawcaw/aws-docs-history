# Infrastructure 6.52 release

The following release notes include information for infrastructure release 6.52. For information on the release timeline, see [Change log](#infra-release-notes-6.52-change-log).

**Platform version**


|  |  | 
| --- | --- | 
| Infrastructure | 6.52 <br />Replicated Native Scheduler (2158)<br />Replicated KOTS (1989) | 

**Changes, enhancements, and resolved issues**: 
+ Removed Psiphon Wickr Open Access (WOA) configuration from the administration console.
