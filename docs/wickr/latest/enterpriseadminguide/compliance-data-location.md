# Compliance data location

The compliance bot will save messages and output by default to the following:

`/opt/WickrIO/clients/(bot_name)/integrations/compliance_bot/receivedMessages.log`

The (bot name) is the username entered during [Creating a compliance bot user](initial-network-configuration.md#compliance-bot-user.html "initial-network-configuration.md#compliance-bot-user.html").
