# Clients 6.50 release

The following release notes include information for clients release 6.50. For information on
the release timeline, see [Change log](#clients-release-notes-6.50-change-log "#clients-release-notes-6.50-change-log").

**Platform versions**

|                        |         |
| ---------------------- | ------- |
| Android                | 6.50.4  |
| iOS                    | 6.50.21 |
| Desktop (Mac, Windows) | 6.50.12 |
| Linux                  | 6.50.12 |

**Android**

New features:

A dedicated **Files** tab has been added in room conversations to upload
and organize files/folders. For more information, see [Manage files in the Wickr
client](../userguide/room-file-management.md "../userguide/room-file-management.md"). To enable this feature from Replicated UI, see [File management](file-management.md "file-management.md").

Changes, enhancements, and resolved issues:

General enhancements and bug fixes.

**iOS**

New features:

A dedicated **Files** tab has been added in room conversations to upload
and organize files/folders. For more information, see [Manage files in the Wickr
client](../userguide/room-file-management.md "../userguide/room-file-management.md"). To enable this feature from Replicated UI, see [File management](file-management.md "file-management.md").

Changes, enhancements, and resolved issues:

General enhancements and bug fixes.

**Desktop**

New features:

- A dedicated **Files** tab has been added in room conversations to upload
  and organize files/folders. For more information, see [Manage files in the Wickr
  client](../userguide/room-file-management.md "../userguide/room-file-management.md"). To enable this feature from Replicated UI, see [File management](file-management.md "file-management.md").
- Dark mode support has been added. For more information, see [Dark mode in the Wickr client](../userguide/dark-mode.md "../userguide/dark-mode.md").
  Changes, enhancements, and resolved issues:

General enhancements and bug fixes.
