# Clients 6.62 release

The following release notes include information for clients release 6.62. For information on
the release timeline, see [Change log](#clients-release-notes-6.62-change-log "#clients-release-notes-6.62-change-log").

**Platform versions**

|                        |         |
| ---------------------- | ------- |
| Android                | 6.62.3  |
| iOS                    | 6.62.9  |
| Desktop (Mac, Windows) | 6.62.13 |

**Android**

New features:

You can now choose to limit your search for messages, file names, and starred content within
a room, group, or conversation. For more information, see [Search for files or messages in the Wickr
client](../userguide/room-search.md "../userguide/room-search.md").

Changes, enhancements, and resolved issues:

Fixed call audio stream termination issue [CVE]. For more information, see [CVE-2025-13524](https://www.cve.org/CVERecord?id=CVE-2025-13524 "https://www.cve.org/CVERecord?id=CVE-2025-13524").
