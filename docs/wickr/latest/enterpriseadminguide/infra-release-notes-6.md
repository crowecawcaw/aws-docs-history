# Infrastructure 6.36 release

The following release notes include information for infrastructure release 6.36. For
information on the release timeline, see [Change log](#infra-release-notes-6.36-change-log "#infra-release-notes-6.36-change-log").

**Platform version**

|                |                                                                        |
| -------------- | ---------------------------------------------------------------------- |
| Infrastructure | 6.36.1<br>Replicated Native Scheduler (1940)<br>Replicated KOTS (1486) |

**New features**:

- New logging options for the Admin API and Server API have been added, which include login
  information for network administrators. The logs are located in the service containers.
- An additional option for administrators has been added to allow for read receipts in
  direct messages.
