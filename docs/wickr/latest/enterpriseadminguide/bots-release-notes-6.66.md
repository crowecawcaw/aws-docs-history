# Bots 6.66 release
<a name="bots-release-notes-6.66"></a>

The following release notes include information for bots release 6.66. For information on the release timeline, see [Change log for Bots 6.66](#bots-release-notes-6.66-change-log).


| Component | Version | 
| --- | --- | 
| Bots | 6.66.2 | 

Bots 6.66 includes the following changes, enhancements, and resolved issues:
+ Underlying client SDK update (v6.34 to v6.66)
+ Runtime and OS modernization (Node.js 24, Ubuntu 24.04, Qt6)
+ Security updates and vulnerability fixes
+ FIPS support
+ Bug fixes for message and attachment handling
