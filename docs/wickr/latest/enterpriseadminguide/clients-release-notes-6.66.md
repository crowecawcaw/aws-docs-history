# Clients 6.66 release
<a name="clients-release-notes-6.66"></a>

The following release notes include information for clients release 6.66. For information on the release timeline, see [Change log](#clients-release-notes-6.66-change-log).

**Platform versions**


|  |  | 
| --- | --- | 
| Android | 6.66.4 | 
| iOS | 6.66.10 | 
| Desktop (Mac, Windows) | 6.66.17 | 
| Linux | 6.66.19 | 

**Android**

New features:

You can now forward a message to another room, group, or one-on-one conversation. Long-press a message to find the Forward option.

Changes, enhancements, and resolved issues:

Performance improvements and bug fixes.

**iOS**

New features:

You can now forward a message to another room, group, or one-on-one conversation. Long-press a message to find the Forward option.

Changes, enhancements, and resolved issues:

Performance improvements and bug fixes.

**Desktop**

New features:

You can now forward a message to another room, group, or one-on-one conversation. Access the (three-dot) options menu to find the Forward option for a message.

Changes, enhancements, and resolved issues:

Performance improvements and bug fixes.
