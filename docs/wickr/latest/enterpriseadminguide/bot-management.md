# Bot management

An administrator can:

- Create a bot
- Delete a bot
- Edit the information of a pending bot. Usernames must end with "bot"
  For more information about bot management, see [Wickr IO](https://wickrinc.github.io/wickrio-docs/#wickr-io "https://wickrinc.github.io/wickrio-docs/#wickr-io").
