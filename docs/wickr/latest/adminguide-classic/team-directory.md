# Team directory in AWS Wickr network
<a name="team-directory"></a>

In the **Users** section of the AWS Management Console for Wickr, you have the ability to manage user accounts within the team directory. This includes the ability to view existing users, create new user accounts, make edits to user information, and delete user accounts as needed.
