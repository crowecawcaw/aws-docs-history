# Edit network name in AWS Wickr
<a name="edit-network-name"></a>

You can edit the name of your Wickr network.

Complete the following procedure to edit your Wickr network name.

1. Open the AWS Management Console for Wickr at [https://console.aws.amazon.com/wickr/](https://console.aws.amazon.com/wickr/).

1. Choose **Manage network**.

1. On the **Networks** page, select the checkbox next to the network name you want to edit, and then choose **View details**.  
![Networks page showing a selected network with options to view details or create a new network.](http://docs.aws.amazon.com/wickr/latest/adminguide-classic/images/wickr-network-viewdetails.png)

1. In the **Network overview** section, choose **Edit**.

1. Enter your new network name into the **Network Name** text box.

1. Choose **Save changes** to save your new network name.
