

This guide documents the classic version of the AWS Wickr administration console, released before March 13, 2025. For documentation on the new AWS Wickr administration console, see [ Administration Guide](https://docs.aws.amazon.com/wickr/latest/adminguide/what-is-wickr.html).

# Manage users in AWS Wickr
<a name="managing-users"></a>

In the **Users** section of the AWS Management Console for Wickr, you can view and manage the profiles of current Wickr users and bots. You can make any necessary adjustments to their details, ensuring that the information remains accurate and up to date.
