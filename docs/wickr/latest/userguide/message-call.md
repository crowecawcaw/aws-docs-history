# Start a call in the Wickr client

You can start a call with another Wickr user in the Wickr client.

To start a call with another Wickr user, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2 "getting-started.md#sign-in-step2").
2. In the navigation pane, find and select the name of the user who you want to
   start a call with.
3. Select the call icon (
   ![Call icon](images/icon-wickr-message-call.png)
   ) in the message window to start a call with the
   user.

The **Start Call** window that appears displays your current
camera, microphone, speaker, and a preview of your camera. 4. Choose **Start** to start the call.
