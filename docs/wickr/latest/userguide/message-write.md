

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Write a direct message in the Wickr client
<a name="message-write"></a>

Direct messages are one-on-one conversations between Wickr users. You can send a direct message to another Wickr user in the Wickr client.

To send a direct message to another Wickr user, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, choose the new message icon (![New icon](http://docs.aws.amazon.com/wickr/latest/userguide/images/icon-wickr-new.png)), and then choose **New Direct Message**.  
![The New Direct Message option.](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-emoji-new-direct-message.png)

1. In the **Direct Message** dialog box, search contacts and directory for the user that you want to message.  
![The Direct Message dialog box.](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-emoji-direct-message.png)

1. When you find the contact that you want to message, choose their name to open a new message window.

1. Type your message into the text box and select **Enter** to send it.

   You can also choose the plus icon (![Plus symbol icon representing an addition or new item action.](http://docs.aws.amazon.com/wickr/latest/userguide/images/icon-wickr-message-file-location.png)) to send a file, share your location, or view quick responses.  
![Send file, share your location, or quick responses icon](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-emoji-send-file-option.png)
