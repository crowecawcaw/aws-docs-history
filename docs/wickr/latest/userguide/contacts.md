

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Contacts in the Wickr client
<a name="contacts"></a>

You can find recent contacts and search the directory in the Wickr client.

Complete the following steps to view recent contacts in the Wickr client.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, choose ![Settings icon](http://docs.aws.amazon.com/wickr/latest/userguide/images/icon-wickr-settings-hamburger.png), and then choose **Contacts**.

1. In the **Contacts** pane that appears, enter a keyword to search recent contacts, or search the network directory.
