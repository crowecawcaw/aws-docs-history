

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Release notes for AWS Wickr
<a name="release-notes"></a>

To help you keep track of the ongoing updates and improvements to Wickr, we publish release notices that describe recent changes.

## August 2026
<a name="august-2026-updates"></a>
+ Enhancements
  + **Device sync for password-based accounts** - You can now transfer your account and message history to a new device by scanning a QR code or entering a verification code. Previously, device sync required single sign-on (SSO). For more information, see [AWS Wickr Device sync](device-sync.md).
  + **Need Help link** - A help link is now available on the sign-in and registration screens to provide quick access to support resources.
  + Performance improvements and bug fixes.

## June 2026
<a name="june-2026-updates"></a>
+ Enhancements
  + **Session Timeout support** - The client now enforces admin-configured inactivity timeouts.
  + **Consent Banner support** - Users see and must acknowledge admin-configured consent banners on login.
  + Performance improvements and bug fixes.

## April 2026
<a name="april-2026-updates"></a>
+ Enhancements
  + Users can now customize their app theme from Appearance settings.
  + Password complexity requirements are now displayed during account creation and password changes.
  + Performance improvements and bug fixes.

## December 2025
<a name="december-2025-updates"></a>
+ Enhancements
  + Users can now forward a message to another room, group, or one-on-one conversation. Long-press a message to find the Forward option. For more information, see [Message forwarding in the Wickr client](https://docs.aws.amazon.com/wickr/latest/userguide/message-forwarding.html).
  + General enhancements and bug fixes.

The AWS Wickr client is now only available from the Play Store for users 18 or older.

## November 2025
<a name="november-2025-updates"></a>
+ Enhancements
  + An optional Region selection picker has been added to the sign in flow allowing users to choose the region to use for authentication. 
  + General enhancements and bug fixes.

**Note**  
 Beginning with v6.64 (planned for Dec 2025), AWS Wickr will no longer provide updates for end-of-life Android OSes. Please upgrade to Android 13\+.

## September 2025
<a name="september-2025-updates"></a>
+ Enhancements
  + Users can now use filters to limit search results to the active conversation. For more information, see [Search files or messages](https://docs.aws.amazon.com/wickr/latest/userguide/room-search.html).

## May 2025
<a name="may-2025-updates"></a>
+ Enhancements
  + Mute notification is now available. For more information, see [Mute notifications in the Wickr client](mute-notifications.md).
  + The rollout of the new user interface is complete and the option in Settings for "New User Experience Preview is removed.

## February 2025
<a name="february-2025-updates"></a>
+ Enhancements
  + File management is now available. For more information, see [Manage files in the Wickr client](room-file-management.md).

## February 2024
<a name="february-2024-updates"></a>
+ Enhancements
  + Markdown is now available. For more information, see [Markdown (preview) for AWS Wickr](markdown.md).

## December 2023
<a name="december-2023-updates"></a>
+ Enhancements
  + Wickr supports device sync. For more information, see [AWS Wickr Device sync](device-sync.md).
  + Wickr supports typing indicators. For more information, see [Typing indicators in the Wickr client](typing-indicators.md).
