This guide provides documentation for AWS Wickr. For Wickr
Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](../enterpriseadminguide/what-is-wickr.md "../enterpriseadminguide/what-is-wickr.md").

# Release notes for AWS Wickr

To help you keep track of the ongoing updates and improvements to Wickr, we publish
release notices that describe recent changes.

## September 2025

- Enhancements
  - Users can now use filters to limit search results to the active
    conversation. For more information, see [Search files or
    messages](room-search.md "room-search.md").

## May 2025

- Enhancements
  - Mute notification is now available. For more information, see [Mute notifications in the Wickr client](mute-notifications.md "mute-notifications.md").
  - The rollout of the new user interface is complete and the option in
    Settings for "New User Experience Preview is removed.

## February 2025

- Enhancements
  - File management is now available. For more information, see [Manage files in the Wickr client](room-file-management.md "room-file-management.md").

## February 2024

- Enhancements
  - Markdown is now available. For more information, see [Markdown (preview) for AWS Wickr](markdown.md "markdown.md").

## December 2023

- Enhancements
  - Wickr supports device sync. For more information, see [AWS Wickr Device sync](device-sync.md "device-sync.md").
  - Wickr supports typing indicators. For more information, see [Typing indicators in the Wickr client](typing-indicators.md "typing-indicators.md").

## November 2023

- Enhancements
  - Added support for guest users. Support includes:
    - Ability to report abuse by other Wickr users.
    - The option to delete their accounts.
      For more information, see [AWS Wickr Guest users](guest-users.md "guest-users.md").

## September 2023

- Enhancements
  - Added support for multi-region federation.

## July 2023

- Enhancements
  - Data retention is now available. For more information, see [AWS Wickr Data retention](data-retention.md "data-retention.md").

## May 2023

- Enhancements
  - Added support for guest users. For more information, see [AWS Wickr Guest users](guest-users.md "guest-users.md").

## March 2023

- Enhancements
  - Added support for emoji reactions in messages. For more information,
    see [Emojis in the Wickr client](emoji-reactions.md "emoji-reactions.md").

## February 2023

- Enhancements
  - Added support for the Wickr plugin for Android Tactical Assault Kit
    (ATAK). For more information, see [ATAK for AWS Wickr](atak.md "atak.md").

## January 2023

- Enhancements
  - Improved functionality and tools for moderating content that might
    violate AWS Terms of Use in the Android client. This can be done
    through blocking, muting, and reporting users.
  - Updated translations for the Android client.
