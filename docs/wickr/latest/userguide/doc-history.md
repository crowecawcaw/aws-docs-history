This guide provides documentation for AWS Wickr. For Wickr
Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](../enterpriseadminguide/what-is-wickr.md "../enterpriseadminguide/what-is-wickr.md").

# Document history for AWS Wickr

The following table describes the documentation releases for Wickr.

| Change                            | Description                                                                                                                                                                                                                                                                                                                                                     | Date               |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Search in conversations           | Users can now use filters to limit search results to the active conversation. For more information, see [Search files or messages](room-search.md "room-search.md").                                                                                                                                                                                            | September 18, 2025 |
| Mute notifications                | Users and moderators can pause message alerts for specific conversations. For more information, see [Mute notifications in the Wickr client](mute-notifications.md "mute-notifications.md").                                                                                                                                                                    | May 30, 2025       |
| File management                   | Users and moderators can upload, view, delete, and organize files in group and room conversations. For more information, see [Manage files in the Wickr client](room-file-management.md "room-file-management.md").                                                                                                                                             | February 4, 2025   |
| Markdown                          | Markdown is enabled by default, allowing users to improve message clarity and detail. For more information, see [Markdown (preview)](markdown.md "markdown.md").                                                                                                                                                                                                | February 12, 2024  |
| Device sync and Typing indicators | Users have the option to sync their existing data from their original device to a new device. For more information, see [Device sync](device-sync.md "device-sync.md"). Additionally, users can see and share when messages are being typed with typing indicators. For more information, see [Typing indicators](typing-indicators.md "typing-indicators.md"). | December 18, 2023  |
| Guest users                       | Guest users have the option to delete their accounts and can also report other Wickr users. For more information, see [Guest users](guest-users.md "guest-users.md").                                                                                                                                                                                           | November 8, 2023   |
| Global Federation                 | Wickr networks now have the ability to communicate across AWS Regions.                                                                                                                                                                                                                                                                                          | September 29, 2023 |
| Data retention                    | Data retention is available to both internal and external communication in a Wickr network. For more information, see [Data retention](data-retention.md "data-retention.md").                                                                                                                                                                                  | July 31, 2023      |
| Guest users (preview)             | Guest users can sign in to the Wickr client and collaborate with Wickr network users. For more information, see [Guest users (preview)](guest-users.md "guest-users.md").                                                                                                                                                                                       | May 31, 2023       |
| Emoji reactions                   | Users can now add emoji reactions to messages in the Wickr client. For more information, see [Use emojis](emoji-reactions.md "emoji-reactions.md").                                                                                                                                                                                                             | March 14, 2023     |
| Initial release                   | Initial release of the Wickr User Guide                                                                                                                                                                                                                                                                                                                         | November 28, 2022  |
