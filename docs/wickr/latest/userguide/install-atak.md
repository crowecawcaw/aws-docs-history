

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Install the Wickr plugin for ATAK
<a name="install-atak"></a>

You can install the Wickr plugin for ATAK on an Android device.

Complete the following procedure to install the Wickr plugin for ATAK.

1. Go to the Google Play store, and install the Wickr for ATAK plugin.

1. Open the ATAK application on your Android device.

1. In the ATAK application, choose the menu icon (![Menu icon](http://docs.aws.amazon.com/wickr/latest/userguide/images/icon-wickr-settings-hamburger.png)) at the top-right of the screen, and choose **Plugins**.  
![The Plugins option in the ATAK application.](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-atak-plugins.png)

1. Choose **Import**.  
![Satellite view of western North America with toolbar showing Import option highlighted.](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-atak-import.png)

1. On the **Select Import Type** pop-up, choose **Local SD** and navigate to where you saved the Wickr plugin for ATAK `.apk` file.  
![The Local SD option in the Import Manager pop-up.](http://docs.aws.amazon.com/wickr/latest/userguide/images/wickr-atak-localSD.png)

1. Choose the plugin file and follow the prompts to install it.
**Note**  
If you are asked to send the plugin file for scanning, choose **No**.

1. The ATAK application will ask if you would like to load the plugin. Choose **OK**.  
![The Wickr Plugin option in the ATAK application.](http://docs.aws.amazon.com/wickr/latest/userguide/images/atak_load_plugin_prompt.png)

   The Wickr plugin for ATAK is now installed. Continue to the following [Pair ATAK with Wickr](pair-tak.md) section to finish the process.
