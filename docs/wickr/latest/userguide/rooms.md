# AWS Wickr Rooms and group messages

Create a room or a group message to have conversations with multiple Wickr users. Rooms
can have moderators who are able to add members, add moderators, remove members, configure
room settings, and delete the room. Rooms and groups can have a maximum of 500 members.
Group messages do not have moderators; all members can add additional members and leave the
group on their own. You can configure expiration and burn-on-read timers for rooms and group
messages.
