# Troubleshoot issues with AWS Wickr

The following topics can help you troubleshoot common issues with
AWS Wickr. If the steps in this section don't resolve your issue, contact
your Wickr network administrator.

If you are an administrator, see the [AWS Wickr
Administrator Guide](../adminguide/troubleshoot.md "../adminguide/troubleshoot.md") for additional troubleshooting steps. If you
cannot resolve the issue through self-service, open a case in the [AWS Support Center](https://console.aws.amazon.com/support/home "https://console.aws.amazon.com/support/home").
