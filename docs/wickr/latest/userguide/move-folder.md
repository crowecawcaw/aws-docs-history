

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Move a file or folder in the Wickr client
<a name="move-folder"></a>

Moderators can move folders, or files between folders in the Wickr client.

To move a folder within a room, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, find and choose the room or group where you want to move a folder.

1. Choose the **Files** tab at the top of the room in Wickr client.

1. Select the message options (three-dot) menu on the right side of the folder you want to move.

1. In the message options menu, choose **Move**.

1. Select from the list of folders where you want to move the folder. 

1. Choose **Move**.
**Note**  
Moving a folder also moves all the files and subfolders within the folder.

To move a file between folders, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, find and choose the room or group where you want to move a file or folder.

1. Choose the **Files** tab at the top of the room in Wickr client, and then select the folder with the file you want to move.

1. Select the message options (three-dot) menu on the right side of the file you want to move.

1. In the message options menu, choose **Move**.

1. Select **Files** tab in the upper left corner of the pop-up window, and then select the folder you want to move the file.

1. Choose **Move**.
