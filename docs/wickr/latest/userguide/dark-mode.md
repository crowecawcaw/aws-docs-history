# Dark mode in the Wickr client

Dark mode is an appearance setting that replaces bright backgrounds with dark colors
and light text, creating a softer visual experience.

You can enable dark mode in the Wickr client.

**On desktop**, to enable dark mode, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2 "getting-started.md#sign-in-step2").
2. In the navigation pane, choose the (three-dots) menu, and then choose
   **Settings**.
3. Choose **Appearance**.
4. In the **Appearance** pane, select **Dark
   Theme** in the **Theme** section.

###### Note

Dark mode can be used only if the **New User Experience
Preview** is enabled, which is the default setting.
**On Android**, to enable dark mode, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2 "getting-started.md#sign-in-step2").
2. In the navigation pane, choose the
   ![Settings icon](images/icon-wickr-settings-hamburger.png)
   menu button.
3. At the bottom of the screen, select the sun/moon icon to toggle between light
   and dark modes.
   **On iOS**, the system theme defaults to dark when enabled.
