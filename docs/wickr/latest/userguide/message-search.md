

This guide provides documentation for AWS Wickr. For Wickr Enterprise, which is the on-premises version of Wickr, see [Enterprise Administration Guide](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/what-is-wickr.html).

# Search a message in the Wickr client
<a name="message-search"></a>

You can search messages and files in the Wickr client.

To search messages and files in the Wickr client, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, find and select the name of the user whose message history you want to search.

1. Select the search icon (![Search icon](http://docs.aws.amazon.com/wickr/latest/userguide/images/icon-wickr-message-search.png)) in the message window to open the message search pane.

1. Enter a keyword into the search text box to perform a search. You can choose to search messages or files.
