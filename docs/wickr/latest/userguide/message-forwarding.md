# Message forwarding in the Wickr client

You can forward a message to another recipient, room, or group in the Wickr
client.

To forward a message, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2 "getting-started.md#sign-in-step2").
2. In the navigation pane, select the recipient, room, or group, that contains
   the message you want to forward.
3. On desktop, select the vertical ellipsis icon (three dots) in the message you
   want to forward.

On mobile, long press the message you want to forward. 4. In the menu that appears, choose **Forward**.

###### Note

If the message forwarding option is not available, contact your
administrator. 5. A list of your recent recipients, rooms, and groups appear. Select one or more
chats as your recipients. You may also add multiple individual users to create a
group conversation. 6. You can add an optional message to accompany the forwarded message. 7. Choose **Forward** to send the message to the selected
recipients.
