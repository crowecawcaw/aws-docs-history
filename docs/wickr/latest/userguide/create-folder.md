# Create a new folder in the Wickr client

Moderators can create a folder in a room in the Wickr client.

To create a folder in a room, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2 "getting-started.md#sign-in-step2").
2. In the navigation pane, find and choose the room or group where you want
   to create a folder.
3. Choose the **Files** tab at the top of the room in
   Wickr client.
4. Choose **New folder** to create a folder.
5. In the **New folder** pop-up window, enter the name of
   folder in the **Folder name** text box.
6. Choose **Create**.

###### Note

You can create subfolders within a folder, with a maximum of three
levels for the folder structure.
