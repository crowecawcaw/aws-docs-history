# Rename a file or folder in the Wickr client
<a name="rename-file"></a>

Moderators can rename a file or folder to a room in the Wickr client.

To rename a file or folder in a room, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, choose the room or group where you want to rename a file or folder.

1. On desktop, select the message options (three-dot) menu on the right side of the file or folder you want to rename.

   On mobile, long-press the file you want to rename.

1. In the message options menu, choose **Rename**.

1. In the **Rename File** or **Rename Folder** pop-up window, enter the new name of the file or folder in the **File name** or **Folder name** text box.

1. Choose **Rename**.
