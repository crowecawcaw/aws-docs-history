This guide provides documentation for Wickr IO Integrations. If you're
using AWS Wickr, see [AWS Wickr
Administration Guide](../adminguide/what-is-wickr.md "../adminguide/what-is-wickr.md").

# Prerequisites

Before you start, complete the following before continuing with this guide:

- Sign up for AWS Wickr. For more information, see [Setting up for AWS Wickr](../adminguide/setting-up.md "../adminguide/setting-up.md") in the
  _AWS Wickr Administration Guide_..
- Create and configure your AWS Wickr network. For more information, see [Create a
  network](../adminguide/getting-started-step1.md "../adminguide/getting-started-step1.md") in the _AWS Wickr Administration Guide_.
- Provision a host machine to run the Wickr IO bot Docker container.
