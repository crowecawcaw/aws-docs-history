# Viewing your ingestion history

To view your ingestion history:

1. Go to the main page for your dataset. (Amazon Lookout for Equipment -> Projects -> [asset name] -> Dataset
2. Select the **Ingestion history** tab.
   For each ingestion job that succeeded, you may also view the associated logs in Amazon CloudWatch. See [Monitoring Service Name with Amazon CloudWatch](monitoring-cloudwatch.md "monitoring-cloudwatch.md").
