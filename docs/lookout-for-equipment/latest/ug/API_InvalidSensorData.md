# InvalidSensorData
<a name="API_InvalidSensorData"></a>

 Entity that comprises aggregated information on sensors having insufficient data. 

## Contents
<a name="API_InvalidSensorData_Contents"></a>

 ** AffectedSensorCount **   <a name="LookoutForEquipment-Type-InvalidSensorData-AffectedSensorCount"></a>
 Indicates the number of sensors that have at least some invalid values.   
Type: Integer  
Required: Yes

 ** TotalNumberOfInvalidValues **   <a name="LookoutForEquipment-Type-InvalidSensorData-TotalNumberOfInvalidValues"></a>
 Indicates the total number of invalid values across all the sensors.   
Type: Integer  
Required: Yes
