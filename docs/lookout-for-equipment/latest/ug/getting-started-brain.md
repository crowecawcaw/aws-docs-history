# Setting up your AWS account
<a name="getting-started-brain"></a>

Before you can start with Lookout for Equipment, you must sign up for an AWS account if you don't already have one.

When you sign up for Amazon Web Services (AWS), your Amazon Web Services account is automatically signed up for all AWS services, including Lookout for Equipment. 

If you already have an Amazon Web Services account, skip to the next topic. 

## Sign up for an AWS account
<a name="sign-up-for-aws"></a>

To get started with AWS, you need an AWS account. For information about creating an AWS account, see [Getting started with an AWS account](https://docs.aws.amazon.com/accounts/latest/reference/getting-started.html) in the *AWS Account Management Reference Guide*.
