# Document history

The following table describes the documentation release history of AWS Certificate Manager beginning in 2018.

| Change                                                                                                                                                                  | Description                                                                                                                                                                                                                                                                                                                                                                              | Date             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| [Change to re-importing certificates](import-certificate-prerequisites.md "import-certificate-prerequisites.md")                                                        | ACM allows re-import of a certificate into the same ARN only when the<br>ClientAuth EKU is missing from the previous certificate. This accommodates industry changes where certificate authorities no<br>longer issue certificates with ClientAuth EKU to comply with Chrome's root<br>program requirements.                                                                             | October 22, 2025 |
| [Added note about issuing certificates](acm-concepts.md#concept-acm-cert "acm-concepts.md#concept-acm-cert")                                                            | Added a note to the ACM certificate concept topic detailing changes to ACM<br>certificate issuance with the TLS Web Client Authentication extension.                                                                                                                                                                                                                                     | July 23, 2025    |
| [Removed reference to authentication extension](acm-concepts.md#concept-acm-cert "acm-concepts.md#concept-acm-cert")                                                    | Removed the reference to the TLS Web Client Authentication extension from the<br>example certificate.                                                                                                                                                                                                                                                                                    | July 3, 2025     |
| [AWS Certificate Manager exportable public certificates](acm-exportable-certificates.md "acm-exportable-certificates.md")                                               | You can export ACM public certificates.                                                                                                                                                                                                                                                                                                                                                  | June 17, 2025    |
| [ACM supports HTTP validation with CloudFront](http-validation.md "http-validation.md")                                                                                 | ACM now supports HTTP validation for domain ownership verification when<br>issuing certificates for CloudFront distributions.                                                                                                                                                                                                                                                            | April 24, 2025   |
| [Deprecation of mail exchanger (MX) email validation](email-validation.md "email-validation.md")                                                                        | The ACM console no longer supports mail exchanger (MX).                                                                                                                                                                                                                                                                                                                                  | July 11, 2024    |
| [Adding best practice around account-level separation](acm-bestpractices.md#best-practices-account-separation "acm-bestpractices.md#best-practices-account-separation") | Use account-level separation in your policies wherever possible. If<br>not possible, you can restrict permissions at the account level or<br>through encryption context condition keys in your policies.                                                                                                                                                                                 | June 11, 2024    |
| [Upcoming deprecation of WHOIS email verification](email-validation.md "email-validation.md")                                                                           | Added a note about the deprecation of WHOIS email verification starting in<br>June 2024.                                                                                                                                                                                                                                                                                                 | February 5, 2024 |
| Condition key support added                                                                                                                                             | Added support for IAM Condition keys when requesting ACM certificates. For a list of<br>supported conditions, see [https://docs.aws.amazon.com/acm/latest/userguide/acm-conditions.html#acm-conditions-supported](acm-conditions.md#acm-conditions-supported "acm-conditions.md#acm-conditions-supported").                                                                              | August 24, 2023  |
| ECDSA support added                                                                                                                                                     | Added support for Elliptic Curve Digital Signature Algorithm (ECDSA) when requesting a<br>public ACM certificate. For a list of supported key algorithms, see [https://docs.aws.amazon.com/acm/latest/userguide/acm-certificate.html#algorithms](acm-certificate.md#algorithms "acm-certificate.md#algorithms").                                                                         | November 8, 2022 |
| New CloudWatch Events                                                                                                                                                   | Added ACM Certificate Expired, ACM Certificate Available, and ACM Certificate<br>Renewal Action Required events. For a list of supported CloudWatch Events, see [https://docs.aws.amazon.com/acm/latest/userguide/cloudwatch-events.html](cloudwatch-events.md "cloudwatch-events.md").                                                                                                  | October 27, 2022 |
| Updating key algorithm types for import                                                                                                                                 | Certificates imported into ACM may now have keys with additional RSA and Elliptic<br>Curve algorithms. For a list of currently supported key algorithms, see [https://docs.aws.amazon.com/acm/latest/userguide/import-certificate-prerequisites.html](import-certificate-prerequisites.md "import-certificate-prerequisites.md").                                                        | July 14, 2021    |
| Promoting "Monitoring and Logging" as a separate chapter                                                                                                                | Moved monitoring and logging documentation to its own chapter. This change covers CloudWatch<br>Metrics, CloudWatch Events/EventBridge, and CloudTrail. For more information, see [https://docs.aws.amazon.com/acm/latest/userguide/monitoring-and-logging.html](monitoring-and-logging.md "monitoring-and-logging.md").                                                                 | March 23, 2021   |
| Added CloudWatch Metrics and Events support                                                                                                                             | Added DaysToExpiry metric and event and supporting APIs. For more information, see<br>[https://docs.aws.amazon.com/acm/latest/userguide/cloudwatch-metrics.html](cloudwatch-metrics.md "cloudwatch-metrics.md") and [https://docs.aws.amazon.com/acm/latest/userguide/cloudwatch-events.html](cloudwatch-events.md "cloudwatch-events.md").                                              | March 3, 2021    |
| Added cross-account support                                                                                                                                             | Added cross-account support for using private CAs from AWS Private CA. For more<br>information, see [https://docs.aws.amazon.com/acm/latest/userguide/ca-access.html](ca-access.md "ca-access.md").                                                                                                                                                                                      | August 17, 2020  |
| Added region support                                                                                                                                                    | Added region support for the AWS China (Beijing and Ningxia) Regions. For a complete<br>list of supported regions, see [https://docs.aws.amazon.com/general/latest/gr/rande.html#acm-pca_region](../../../general/latest/gr/rande.md#acm-pca_region "../../../general/latest/gr/rande.md#acm-pca_region").                                                                               | March 4, 2020    |
| Added renewal workflow testing                                                                                                                                          | Customers can now manually test the configuration of their ACM managed renewal<br>workflow. For more information, see [Testing<br>ACM's Managed Renewal Configuration](manual-renewal.md "manual-renewal.md").                                                                                                                                                                           | March 14, 2019   |
| Certificate transparency logging now default                                                                                                                            | Added ability to publish ACM public certificates into certificate transparency logs<br>by default.                                                                                                                                                                                                                                                                                       | April 24, 2018   |
| Launching AWS Private CA                                                                                                                                                | Launched ACM Private Certificate Manager (CM), and extension of AWS Certificate Manager that allows<br>users to establish a secure managed infrastructure for issuing and revoking private<br>digital certificates. For more information, see [AWS Private<br>Certificate Authority](../../../acm-pca/latest/userguide/PcaWelcome.md "../../../acm-pca/latest/userguide/PcaWelcome.md"). | April 4, 2018    |
| Certificate transparency logging                                                                                                                                        | Added certificate transparency logging to Best Practices.                                                                                                                                                                                                                                                                                                                                | March 27, 2018   |
