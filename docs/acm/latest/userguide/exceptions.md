# Handling exceptions

An AWS Certificate Manager command might fail for several reasons. For information about each exception,
see the table below.

## Private certificate exception

handling

The following exceptions can occur when you attempt to renew a private PKI certificate
issued by AWS Private CA.

###### Note

AWS Private CA is not supported in the China (Beijing) Region and the China (Ningxia)
Region.

| ACM failure code         | Comment                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PCA_ACCESS_DENIED`      | The private CA has not granted ACM permissions. This triggers a<br>AWS Private CA `AccessDeniedException` failure code.<br>To remedy the problem, grant the necessary permissions to the ACM service<br>principal using the AWS Private CA [CreatePermission](../../../privateca/latest/APIReference/API_CreatePermission.md "../../../privateca/latest/APIReference/API_CreatePermission.md") operation.                                                                                                                                                                                                                                                                                                                                                                                      |
| `PCA_INVALID_DURATION`   | The validity period of the requested certificate exceeds the validity period<br>of the issuing private CA. This triggers a AWS Private CA<br>`ValidationException` failure code.<br>To remedy the problem, [install a<br>new CA certificate](../../../privateca/latest/userguide/PCACertInstall.md "../../../privateca/latest/userguide/PCACertInstall.md") with an appropriate validity period.                                                                                                                                                                                                                                                                                                                                                                                               |
| `PCA_INVALID_STATE`      | The private CA being called is not in the correct state to perform the<br>requested ACM operation. This triggers a AWS Private CA<br>`InvalidStateException` failure code.<br>Resolve the issue as follows:<br>• If the CA has the status `CREATING`, wait for creation to<br>finish and then install the CA certificate.<br>• If the CA has status `PENDING_CERTIFICATE`, install the CA<br>certificate.<br>• If the CA has status `DISABLED`, update it to<br>`ACTIVE` status.<br>• If the CA has status `DELETED`, restore it.<br>• If the CA has status `EXPIRED`, install a new<br>certificate<br>• If the CA has status `FAILED`, and you cannot resolve the<br>issue, contact [Support](https://console.aws.amazon.com/support/home#/ "https://console.aws.amazon.com/support/home#/"). |
| `PCA_LIMIT_EXCEEDED`     | The private CA has reached an issuance quota. This triggers a AWS Private CA<br>`LimitExceededException` failure code. Try repeating your request<br>before proceeding with this help.<br>If the error persists, contact [Support](https://console.aws.amazon.com/support/home#/ "https://console.aws.amazon.com/support/home#/") to request a quota increase.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `PCA_REQUEST_FAILED`     | A network or system error occurred. This triggers a AWS Private CA<br>`RequestFailedException` failure code. Try repeating your request<br>before proceeding with this help.<br>If the error persists, contact [Support](https://console.aws.amazon.com/support/home#/ "https://console.aws.amazon.com/support/home#/").                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `PCA_RESOURCE_NOT_FOUND` | The private CA has been permanently deleted. This triggers a AWS Private CA<br>`ResourceNotFoundException` failure code. Verify that you used the<br>correct ARN. If that fails, you won't be able to use this CA.<br>To remedy the problem, [create a new<br>CA](../../../privateca/latest/userguide/PcaCreateCa.md "../../../privateca/latest/userguide/PcaCreateCa.md").                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `SLR_NOT_FOUND`          | In order to renew a certificate signed by a private CA that resides in another<br>account, ACM requires a Service Linked Role (SLR) on the account where the<br>certificate resides. If you need to recreate a deleted SLR, see [Creating the SLR for ACM](acm-slr.md#create-slr "acm-slr.md#create-slr").                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
