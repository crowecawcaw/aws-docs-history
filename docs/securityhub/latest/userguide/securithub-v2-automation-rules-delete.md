# Deleting automation rules in Security Hub

###### Note

Security Hub is in preview release and is subject to change.

This topic describes how to delete automation rules.
You can delete automation rules in the AWS Region where you created them.

###### To delete a rule

1. Sign in to your AWS account, and open the Security Hub console at [https://console.aws.amazon.com/securityhub/v2/home](https://console.aws.amazon.com/securityhub/v2/home "https://console.aws.amazon.com/securityhub/v2/home").
2. From the navigation pane, choose **Management**, and then choose **Automations**.
3. Select the automation rule that you want to delete.
   Choose **Actions**, and then choose **Delete**.
4. Choose **Delete**.
