# Tagging snapshots

You can assign your own metadata to each snapshot in the form of tags. Tags enable you to categorize your snapshots in different ways, for example, by purpose, owner, or environment.
This is useful when you have many resources of the same type—you can quickly identify a specific resource based on the tags that you've
assigned to it. For more information, see [Resources you can tag](tagging-resources.md#tagging-your-resources "tagging-resources.md#tagging-your-resources").

Cost allocation tags are a means of tracking your costs across multiple AWS services by grouping
your expenses on invoices by tag values.
To learn more about cost allocation tags, see
[Use cost allocation tags](../../../awsaccountbilling/latest/aboutv2/cost-alloc-tags.md "../../../awsaccountbilling/latest/aboutv2/cost-alloc-tags.md").

Using the MemoryDB console, the AWS CLI, or MemoryDB API you can add, list, modify, remove, or copy cost
allocation tags on your snapshots. For more information, see [Monitoring costs with cost allocation tags](tagging.md "tagging.md").
