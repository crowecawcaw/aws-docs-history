# Preparing a cluster

Following, you can find instructions on creating a cluster using the MemoryDB console, the
AWS CLI, or the MemoryDB API.

Whenever you create a cluster, it is
a good idea to do some preparatory work so you won't need to upgrade or make changes right away.
