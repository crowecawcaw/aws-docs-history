###### Note

Internal metrics will determine the default quotas for concurrent running builds.

Quotas for the maximum number of concurrent running builds vary, depending on the
compute type. For some platforms and compute types, the default is 20. To request a higher concurrent build quota, or if
you get a "Cannot have more than X active builds for the account" error, use the link
above to make the request. For more information on pricing, see [AWS CodeBuild pricing](https://aws.amazon.com/codebuild/pricing/ "https://aws.amazon.com/codebuild/pricing/").
