# Third-party source repository samples for

CodeBuild

This section describes sample integrations between third-party source repositories and
CodeBuild.

| Sample                                                                                                                                                                                                    | Description                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| BitBucket pull request and webhook filter sample – see [Run the 'Bitbucket pull request and webhook filter'<br>sample for CodeBuild](sample-bitbucket-pull-request.md "sample-bitbucket-pull-request.md") | This sample shows you how to create a pull request using a Bitbucket<br>repository. It also shows you how to use a Bitbucket webhook to trigger<br>CodeBuild to create a build of a project.                                                                                                                       |
| GitHub Enterprise Server sample – see [Run the GitHub Enterprise Server sample for CodeBuild](sample-github-enterprise.md "sample-github-enterprise.md")                                                  | This sample shows you how to set up your CodeBuild projects when your<br>GitHub Enterprise Server repository has a certificate installed. It also<br>shows how to enable webhooks so that CodeBuild rebuilds the source code<br>every time a code change is pushed to your GitHub Enterprise Server<br>repository. |
| GitHub pull request and webhook filter sample – see [Run the GitHub pull request and webhook filter sample<br>for CodeBuild](sample-github-pull-request.md "sample-github-pull-request.md")               | This sample shows you how to create a pull request using a GitHub<br>Enterprise Server repository. It also shows how to enable webhooks so<br>that CodeBuild rebuilds the source code every time a code change is pushed<br>to your GitHub Enterprise Server repository.                                           |
