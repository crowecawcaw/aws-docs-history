# Identify a shared project

Owners and consumers can use the AWS CLI to identify shared projects.

###### To identify projects shared with your AWS account or user (AWS CLI)

Use the [list-shared-projects](../../../cli/latest/reference/codebuild/list-shared-projects.md "../../../cli/latest/reference/codebuild/list-shared-projects.md") command to return the projects that are shared
with you.
