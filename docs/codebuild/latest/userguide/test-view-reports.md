# View test reports

You can view details about a test report, such as information about its test cases,
pass and fail numbers, and how long it took for it to run. You can view test reports
grouped by build run, report group, or your AWS account. Choose a test report in the
console to see its details and results of its test cases.

You can see view test reports that are not expired. Test reports expire 30 days after
they are created. You cannot view an expired report in CodeBuild.
