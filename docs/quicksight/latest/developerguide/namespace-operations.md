# Namespace operations

An Amazon Quick Sight _namespace_ is a logical container that you can use to
organize clients, subsidiaries, teams, and so on. By using a namespace, you can isolate the
Amazon Quick Sight users and groups that are registered for that namespace. Users that access the
namespace can share assets only with other users or groups in the same namespace. They can't
see users and groups in other namespaces. For more information about namespaces, see [Supporting
multitenancy with isolated namespaces](../user/namespaces.md "../user/namespaces.md") in the
_Quick Sight User guide_.

To implement namespaces, you use the following Quick Sight API operations.
