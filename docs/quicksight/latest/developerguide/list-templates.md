# ListTemplates

Use the `ListTemplates` operation to list all the templates in the current Quick Sight account.

Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight list-templates
    --aws-account-id `AWSACCOUNTID`
    --page-size `10`
    --max-items `100`
```

For more information about the `ListTemplates` operation, see [ListTemplates](../APIReference/API_ListTemplates.md "../APIReference/API_ListTemplates.md") in the _Quick Sight API Reference_.
