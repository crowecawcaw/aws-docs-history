# ListIngestions

Use the `ListIngestions` operation to list the history of SPICE
ingestioned for a dataset.

Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight list-ingestions
    --data-set-id `DATASETID`
    --aws-account-id `AWSACCOUNTID`
    --page-size `10`
    --max-items `100`
```

For more information about the `ListIngestions` operation, see [ListIngestions](../APIReference/API_ListIngestions.md "../APIReference/API_ListIngestions.md") in the _Quick Sight API Reference_.
