# ListThemes

Use the `ListThemes` operation to list all the themes in the current AWS account.

Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight list-themes
    --aws-account-id `AWSACCOUNTID`
    --type `QUICKSIGHT`
    --page-size `10`
    --max-items `100`
```

For more information about the `ListThemes` operation, see [ListThemes](../APIReference/API_ListThemes.md "../APIReference/API_ListThemes.md") in the _Quick Sight API Reference_.
