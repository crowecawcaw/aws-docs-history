# ListFolders

Use the `ListFolders` operation to list all folders in an Quick Sight account.

Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight list-folders
    --aws-account-id `AWSACCOUNTID`
    --page-size `10`
    --max-items `100`
```

For more information about the `ListFolders` operation, see [ListFolders](../APIReference/API_ListFolders.md "../APIReference/API_ListFolders.md") in the _Quick Sight API Reference_.
