# DescribeNamespace

Use the `DescribeNamespace` API operation to describe a specified namespace. Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight describe-namespace
    --aws-account-id `AWSACCOUNTID`
    --namespace `NAMESPACE`
```

For more information about the `DescribeNamespace` API operation, see [DescribeNamespace](../APIReference/API_DescribeNamespace.md "../APIReference/API_DescribeNamespace.md") in the _Amazon Quick Sight API Reference_.
