# ListAnalyses

Use the `ListAnalyses` API operation to list Amazon Quick Sight analyses that exist in the specified AWS account. Following is an example AWS CLI command for this operation.

AWS CLI

```
aws quicksight list-analyses
    --aws-account-id `555555555555`
    --page-size `10`
    --max-items `10`
```

For more information about the `ListAnalyses` API operation, see [ListAnalyses](../APIReference/API_ListAnalyses.md "../APIReference/API_ListAnalyses.md") in the _Amazon Quick Sight API Reference_.
