# Amazon Resource Names (ARNs) in Quick Sight

Amazon Resource Names (ARNs) uniquely identify AWS resources. An ARN identifies a
resource unambiguously across all of AWS, for example in IAM policies,
Amazon Relational Database Service (Amazon RDS) tags, and API calls. To retrieve the ARN of an Quick Sight resource,
you can use the `Describe` operation on the relevant resource.

You can use this section to learn how ARNs work. The material here provides examples are geared specifically for Quick Sight.
