# Get started with the Amazon Quick Sight API

You can manage most aspects of your deployment with the AWS SDKs to access an API
that's tailored to the programming language or platform that you're using. For more
information, see [AWS SDKs](http://aws.amazon.com/tools/#SDKs "http://aws.amazon.com/tools/#SDKs"). For
more information about specific API operations, see [Quick Sight API
Reference](../../index.md "../../index.md").

Use the topics in this section to get started with the Quick Sight API and SDKs.
