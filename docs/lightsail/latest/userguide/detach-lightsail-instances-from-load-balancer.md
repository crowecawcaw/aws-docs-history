# Detach instances from a

Lightsail load balancer

If you no longer want to have an instance attached to your Amazon Lightsail load balancer,
you can detach it. When you detach a Lightsail instance from a load balancer, we wait until
the specified instances are no longer needed before detaching.

1. In the left navigation pane, choose **Networking**.
2. Choose the load balancer you want to manage.
3. On the **Target instances** tab, choose **Detach**
   next to the load balancer you want to detach.
