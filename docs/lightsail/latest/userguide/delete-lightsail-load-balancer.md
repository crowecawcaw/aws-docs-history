# Delete Lightsail load balancers

You can delete a Lightsail load balancer if you no longer need it. Deleting a load
balancer also detaches any Lightsail instances attached to it but doesn't delete the
Lightsail instances. If you enabled encrypted (HTTPS) traffic using an SSL/TLS certificate,
deleting the load balancer will also permanently delete any SSL/TLS certificates associated with
the load balancer.

###### Important

Deleting a Lightsail load balancer and its associated certificate is final and can't be
undone.

1. In the left navigation pane, choose **Networking**.
2. Choose the load balancer you want to delete.
3. Choose **Delete**.
4. Choose **Delete load balancer**.
5. Choose **Yes, delete**.
