

# Control access to Lightsail resources with resource-level permissions and tag-based authorization
<a name="resource-level-permissions-and-auth-based-on-tags-support"></a>

Lightsail supports resource-level permissions and authorization based on tags for some of its API actions. For more information, see [Actions, Resources, and Condition Keys for Amazon Lightsail ](https://docs.aws.amazon.com/IAM/latest/UserGuide/list_lightsail.html) in the *Service Authorization Reference*.
