

# Customize with agents, skills, flows, and connectors

Customize is where you manage everything that powers your agents in AWS Quick. From one place, you build and manage agents, create reusable skills, connect external applications, give your agents access to your content, and publish the brand assets that shape generated documents and presentations. The following features work together so your agents can answer questions and complete tasks for you.
+ **Discover** is where you browse and install capabilities that Amazon and your organization share, including agents, skills, flows, connectors, and plugins. For more information, see [Discover](working-with-discover.md).
+ **Agents** are configurable AIs that you give instructions, knowledge sources, and tools so they can answer questions and get work done. You can build your own agents, install agents that are shared with you, chat with an agent, and run an agent on a routine. For more information, see [Agents in AWS Quick](working-with-agents.md).
+ **Skills** are reusable instruction sets that teach your agents how to complete common workflows. You can create your own skills and install skills that are shared with you. For more information, see [Teach agents with skills](working-with-skills.md).
+ **Flows** are multi-step automations that run a defined sequence of steps to complete a task. You can build a flow, run it, publish it, and share it. For more information, see [Flows](working-with-flows.md).
+ **Plugins** bundle agents, skills, connectors, and flows into a single installable capability. You can create a plugin, install a plugin that is shared with you, and share your own. For more information, see [Plugins](working-with-plugins.md).
+ **Connectors** link Quick to external applications and services so your agents can access data and act on your behalf. Connectors, data access integrations, and knowledge bases are reachable wherever you use Quick. For more information, see [Work with integrations in AWS Quick](working-with-integrations.md).
+ **Knowledge** gives your agents and chat access to your content so they can find, cite, and reason over it. On the web, you provide knowledge through cloud knowledge bases. Giving Quick access to folders on your computer is a capability of the AWS Quick desktop application. For more information, see [Knowledge](knowledge.md).
+ **Brand assets** are your organization's templates for documents and presentations, along with the rules that generated output follows. For more information, see [Managing brand assets](brand-assets.md).

You can add more agents, skills, and connectors from the Add to Quick catalog, which offers items that are shared with you and, for skills, an official set that Amazon publishes and that you can filter by category.
