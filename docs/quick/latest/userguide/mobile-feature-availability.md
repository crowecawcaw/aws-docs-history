

# Feature availability at a glance
<a name="mobile-feature-availability"></a>

The following tables summarize feature availability on mobile compared to desktop. Availability is one of the following.
+ Available: works on mobile.
+ Limited: partially available on mobile. See the note for details.
+ Not available: not available on mobile. Use the desktop application for this capability.

## Chat
<a name="mobile-availability-chat"></a>


| Feature | Availability | 
| --- | --- | 
| Chatting with Quick | Available | 
| Response modes (Fast, Balanced, Smart) | Available | 
| Thinking effort | Available | 
| Attachments and file uploads | Available | 
| Web search | Available | 
| Mentions (@) | Available | 
| Citations and sources | Available | 
| Editing and retrying messages | Available | 
| Branching conversations | Available | 
| Plan mode | Available | 
| Deep research | Available | 
| Managing conversations (folders, pinning, search, archive) | Available | 
| Approvals | Available | 
| Running work in the background | Available | 
| Incognito mode | Not available | 
| Slash commands | Not available | 
| Attaching a space | Not available | 
| Context meter | Not available | 

**Note**  
Branching conversations is available on Android only. See [Differences between iOS and Android](mobile-ios-android-differences.md). For how these chat capabilities work in detail, see [Working with chat](working-with-chat-desktop.md).

## Your content and data
<a name="mobile-availability-content"></a>


| Feature | Availability | Notes | 
| --- | --- | --- | 
| Dashboards | Available | Browse dashboards natively and open them in a viewer. | 
| Activity feed | Available | Includes your calendar and to-dos. | 
| Library (saved artifacts) | Available | Includes documents and visuals generated in Quick. | 
| Knowledge graph (view and manage) | Not available | The knowledge graph is on by default, but viewing and managing it is not available on mobile. | 
| Memory (view and manage) | Not available | Quick uses the same memories across desktop and mobile, but managing them on mobile is not yet available. |
