

# Library
<a name="library-desktop"></a>

Library is where you browse, search, and pick up where you left off on content and resources. You can search, filter it by content type, and switch between a table view and a thumbnail grid.

## What Library holds
<a name="library-contents"></a>

Library stores typed content, including documents, presentations, spreadsheets, PDF files, HTML, images, audio, video, and Markdown, along with Amazon Quick resources such as apps, spaces, agents, skills, research, datasets, dashboards, analyses, flows, automations, and topics.

## Views and filters
<a name="library-views"></a>

Switch between list and grid views, with columns for type, owner, and last viewed. Filter by ownership, favorites, owned by you, or shared with you, and by content type. You can favorite items with a star.

## Item actions
<a name="library-item-actions"></a>

From an item's menu you open, download, add to a space, share, open in chat, or delete it. Opening an item shows it in a session tab, where you read it and select content to add as context.

## Sharing files
<a name="library-sharing"></a>

Sharing gives view access to that file only. Recipients find the file in their own Library. Choose **Copy link** to get a link to the file that you can send in chat or email. The link works only for people you have already shared the file with.
