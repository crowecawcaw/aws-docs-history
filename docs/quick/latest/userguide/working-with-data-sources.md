# Working with data sources in Amazon Quick Sight

Use a data source to access an external data store. Amazon S3 data sources save the
manifest file information. In contrast, Salesforce and database data sources save
connection information like credentials. In such cases, you can easily create multiple
datasets from the data store without having to re-enter information. Connection
information isn't saved for text or Microsoft Excel files.
