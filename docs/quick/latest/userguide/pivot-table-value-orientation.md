# Orienting pivot table values

You can choose to display a pivot table in a columnar or row-based format.
Columnar is the default. When you change to a row-based format, a column with the
value name is added to the right of the row header column.

###### To change a pivot table format

1. On the analysis page, choose the pivot table visual that you want to
   edit.
2. Expand the **Field wells** pane by choosing the field
   wells at the top of the visual.
3. On the **Values** field well, choose one of the following
   options:
   - Choose **Column** for a columnar format.
   - Choose **Row** for a row format.

   ###### Note

   If you use only one metric, you can eliminate the repeated
   header by formatting the visual and styling it with the
   **Hide single metric** option.
