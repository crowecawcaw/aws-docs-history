

# User profile and preferences in Amazon Quick
<a name="standalone-profile"></a>

This topic describes how to access and configure your personal profile settings, preferences, and related options in Amazon Quick. These settings apply to your individual user experience and are separate from account-level administration settings.

## Accessing the profile menu
<a name="standalone-profile-menu"></a>

To access the profile menu, from the Amazon Quick navigation bar, choose your name or avatar. The profile menu displays your name, email address, and current plan information.

The profile menu contains the following options:


| Menu option | Description | 
| --- | --- | 
| Upgrade plan | Opens the plan management page in a new browser tab where you can change your subscription tier. | 
| Manage account | Opens the Manage Account page within Amazon Quick. Available to account owners and administrators. For more information, see [Managing a Amazon Quick Free or Plus account](https://docs.aws.amazon.com/quicksuite/latest/userguide/standalone-admin.html). | 
| Switch accounts | Allows you to switch between multiple Amazon Quick accounts if you are a member of more than one. | 
| Edit profile | Opens the AWS Builder ID profile management page in a new browser tab. | 
| Preferences | Opens the Preferences dialog where you can configure personalization, chat, and language settings. | 
| Help | Expands a submenu with links to help resources. | 
| Quick anywhere | Expands a submenu with options for accessing Quick on other platforms. | 
| Sign out | Signs you out of your Amazon Quick account. | 

## Edit profile
<a name="standalone-profile-edit"></a>

When you choose **Edit profile** from the profile menu, the AWS Builder ID profile management page opens in a new browser tab. Your AWS Builder ID is the identity you use to sign in to your Amazon Quick Free or Plus account. From this page, you can manage your personal information, security settings, and privacy preferences.

**Topics**
+ [My details](#standalone-profile-my-details)
+ [Security](#standalone-profile-security)
+ [Privacy & data](#standalone-profile-privacy)

### My details
<a name="standalone-profile-my-details"></a>

The My details tab displays and allows you to edit your personal information.
+ **Name** – Your full name. Choose **Edit** to update.
+ **Nickname** – An optional display name. Choose **Edit** to update.
+ **Email address** – The email address associated with your AWS Builder ID. Choose **Edit** to change your email address. A verification step is required for email changes.

### Security
<a name="standalone-profile-security"></a>

The Security tab provides options for managing your account security.
+ **Change password** – Choose this button to update your AWS Builder ID password.
+ **Multi-factor authentication (MFA)** – Manage MFA devices for additional sign-in security. The MFA devices table displays the following columns: Name, Type, Make and Model, and Registered Date.
  + **Register device** – Add a new MFA device (authenticator app or security key).
  + **Rename** – Change the display name of a registered MFA device.
  + **Delete** – Remove a registered MFA device.
+ **Active sessions** – View all currently active sign-in sessions.
  + The sessions table displays the following columns: Device, IP address, and Sign-in date.
  + **Delete all active sessions** – Choose this button to immediately terminate all active sessions. You will be signed out of all devices.

### Privacy & data
<a name="standalone-profile-privacy"></a>

The Privacy & data tab provides options for managing your data and privacy.
+ **AWS Privacy Notice** – A link to the AWS Privacy Notice for information about how AWS handles your data.
+ **Request your Builder ID data** – Choose this button to request a copy of the data associated with your AWS Builder ID.
+ **Request your AWS data** – A link to request a copy of all your AWS data through the AWS Data Subject Access Request process.
+ **Delete AWS Builder ID** – Choose this button to permanently delete your AWS Builder ID.

**Warning**  
Deleting your AWS Builder ID is permanent and cannot be undone. You will lose access to all AWS services and applications that use your Builder ID for authentication, including Amazon Quick.

## Preferences
<a name="standalone-profile-preferences"></a>

When you choose **Preferences** from the profile menu, a dialog opens with three tabs for configuring your personal Amazon Quick experience. Choose **Save** to apply changes or **Cancel** to discard them.

**Topics**
+ [Personalization](#standalone-profile-personalization)
+ [Chat](#standalone-profile-chat)
+ [Language and time](#standalone-profile-language-time)

### Personalization
<a name="standalone-profile-personalization"></a>

The Personalization tab allows you to customize how Amazon Quick tailors its responses to your needs.
+ **Your current work focus** – A text field where you can describe what you are currently working on (for example, "Q3 financial planning" or "Product launch preparation"). Amazon Quick uses this context to provide more relevant suggestions and responses.
+ **Manage memories** – Choose this button to view and manage the information that Amazon Quick has learned about you through your conversations. You can review, edit, or delete individual memories.

### Chat
<a name="standalone-profile-chat"></a>

The Chat tab allows you to configure default behaviors for the Amazon Quick chat experience.
+ **Assistant data access** – A toggle that controls whether My Assistant can access all your connected data sources by default. When enabled, My Assistant can query your connected data, documents, and integrations without you needing to specify the data source for each conversation. You can override this setting on a per-conversation basis.
+ **Choose default data** – A dropdown selector that sets the default data scope for new conversations. You can override the default data scope within any individual conversation by using the data source selector in the chat footer. Options include:
  + **All data** – My Assistant can access all connected data sources and applications.
  + Other options may appear based on your connected integrations and data sources.

### Language and time
<a name="standalone-profile-language-time"></a>

The Language and time tab allows you to configure regional and display preferences.
+ **Timezone** – Choose your preferred timezone from the dropdown selector. This setting affects how dates and times are displayed throughout Amazon Quick.
+ **Language** – Choose your preferred display language from the dropdown selector. This setting controls the language of the Amazon Quick user interface.
+ **Use browser time zone** – Select this checkbox to automatically use your web browser's detected timezone instead of the manually selected timezone above. When enabled, the timezone selector is overridden by your browser setting.

## Quick anywhere
<a name="standalone-profile-quick-anywhere"></a>

When you choose **Quick anywhere** from the profile menu, a submenu expands with options for accessing Amazon Quick on other platforms:


| Platform | Description | 
| --- | --- | 
| Desktop | Download the Amazon Quick desktop application for macOS or Windows. The desktop app provides a native experience with system-level integrations. | 
| Mobile | Access Amazon Quick on your mobile device. | 
| Browser extensions | Install browser extensions that integrate Amazon Quick directly into your web browsing experience. | 

## Private Mode
<a name="standalone-profile-private-mode"></a>

Amazon Quick includes a **Private Mode** toggle, accessible from the top area of the navigation bar. When Private Mode is enabled:
+ Your conversations are not saved to your chat history.
+ Amazon Quick does not learn from or retain information from private conversations.
+ Private conversations do not appear in the Recents section of the navigation.

To enable or disable Private Mode, choose the **Private Mode** button in the navigation bar.
