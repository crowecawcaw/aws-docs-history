

# Customize
<a name="customize-desktop"></a>

Customize is the hub for managing everything that powers your agents. It has five tabs:
+ **Agents**: build and manage agents. For more information, see [Agents](agents-desktop.md).
+ **Skills**: create and manage skills. For more information, see [Skills](skills-desktop.md).
+ **Connectors**: manage web and cloud connectors, MCP servers, and coding agents. For more information, see [Connectors](connections-desktop.md).
+ **Knowledge**: give Quick access to folders on your computer and control how they are indexed. For more information, see [Knowledge](knowledge-desktop.md).
+ **Brand assets**: manage and publish your organization's templates for Word documents and PowerPoint presentations. For more information, see [Brand assets](brand-assets-desktop.md).

Across the Customize tabs you install additional agents, skills, and connectors from the Add to Quick catalog, which offers items shared with you and, for skills, an Official set published by Amazon that you filter by category.
