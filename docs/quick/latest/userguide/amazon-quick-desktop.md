

# Amazon Quick on desktop
<a name="amazon-quick-desktop"></a>

Amazon Quick on desktop is an agentic AI teammate that connects to your local files and the tools you use every day. It builds an understanding of your work that deepens over time, so it provides relevant, personalized assistance. Agents take on work you delegate, follow through independently, and bring you the results.

For the plans that include Amazon Quick on desktop and pricing details, see [Amazon Quick pricing](https://aws.amazon.com/quick/pricing/).
