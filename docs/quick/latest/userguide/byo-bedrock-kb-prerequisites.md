# Prerequisites

- A Amazon Bedrock managed knowledge base that has been created and configured. For
  more information, see [Build a managed
  knowledge base](../../../bedrock/latest/userguide/kb-build-managed.md "../../../bedrock/latest/userguide/kb-build-managed.md") in the _Amazon Bedrock User
  Guide_.
- The managed knowledge base and the Amazon Quick instance are in the same AWS
  Region.
- Administrator-level permissions in Amazon Quick to manage AWS resource
  integrations.
- For cross-account setups: the ability to attach a resource policy to the
  knowledge base, or coordination with the knowledge base owner to attach the
  policy.
