# Remove a dataset from an

analysis

Use the following procedure to delete a dataset from an analysis.

###### To delete a dataset from an analysis

1. On the analysis page, navigate to the **Data** pane and
   expand the **Dataset** dropdown.
2. Choose **Manage datasets**.
3. Choose the ellipsis (three dots) next to the dataset that you want to
   replace, and then choose **Remove**. You can't delete
   a dataset if it's the only one in the analysis.
4. Choose **Close** to close the dialog box.
