

# Creating knowledge bases from Amazon Bedrock managed knowledge bases
<a name="byo-bedrock-kb-creating"></a>

This topic shows you how to create a knowledge base in Amazon Quick from an existing Amazon Bedrock managed knowledge base. After completing the permission setup, administrators can use this procedure to integrate the managed knowledge base into Amazon Quick.

**To create a knowledge base from an Amazon Bedrock managed knowledge base**

1. Sign in to the Amazon Quick console as an administrator.

1. Navigate to **Knowledge bases** > **Set up new knowledge base**.

1. Select **Amazon Bedrock managed knowledge base** as the source type.

1. Complete the form and choose **Create**.

After creation, the managed knowledge base is available in Amazon Quick and can be added to spaces, agents, and automations.
