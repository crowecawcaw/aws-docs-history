# Creating a space

You can create spaces in Amazon Quick from the **Spaces** menu on the
Quick home page. You can directly add files to your space or connect
existing resources to it when you create it. If you upload a file that exceeds the file
size limits, or is of an unsupported file type, Quick displays an error and
asks you to try again. When you create a space, you are assigned as its owner by
default. The following procedure outlines how to create a space.

###### To create a space

1. Log in to the Quick console.
2. From the left navigation menu, select **Spaces**, and then
   select **Create space**.
3. On the space creation page that opens, do the following:
   1. (Optional) Enter a name for your space.
   2. (Optional) Enter a description for your space.
   3. Select **Add knowledge** to begin adding content to
      your space.

   From the dropdown menu, you can select from available resource types
   including **Dashboards**, **Topics**,
   **Knowledge bases**, **Actions**,
   and **File uploads**.

   ###### Note

   You can preview a resource before you choose to add it by clicking
   on its name.After you finish adding resources, **Space knowledge**
   displays a list of all assets and files added to your space.

After your space is created, you can select the sparkle icon from the top left
corner of the screen and start interacting with your space using any available
agent.
