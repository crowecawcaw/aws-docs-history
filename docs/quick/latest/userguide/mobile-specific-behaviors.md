

# Mobile-specific behaviors
<a name="mobile-specific-behaviors"></a>

Some capabilities work differently on mobile than on desktop.
+ Dashboards open in a viewer: on mobile, you browse your dashboards in a native list and open a dashboard in an embedded viewer with mobile controls.
+ On-device file access: Quick can read and write files on your device when you grant access. You approve each request, and you control which folders Quick can use.
+ Approvals as cards: when an agent needs your permission to take an action, the request appears as a card in the conversation that you can allow or deny.
+ Biometric app lock: when biometric lock is on, Amazon Quick requires Face ID, Touch ID, or a fingerprint each time you open the app.
