# Working with datasets in an Quick Sight

topic

|                                            |
| ------------------------------------------ |
| \*_Applies<br>to:_<br>• Enterprise Edition |

|                                                               |
| ------------------------------------------------------------- |
| Intended audience:<br>Amazon Quick administrators and authors |

When you create a topic, you can add additional datasets to it or import datasets from
existing dashboards. At any time, you can edit metadata for a dataset and set a data
refresh schedule. You can also add new fields to a dataset in a topic by creating
calculated fields, filters, or named entities.
