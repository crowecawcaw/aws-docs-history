

# Connecting to AWS Glue Data Catalog
<a name="catalog-integration-glue"></a>

**Note**  
Data catalog integration with AWS Glue Data Catalog is in Preview for Amazon Quick and is subject to change. Preview features are not typically recommended for critical or production workloads.

AWS Glue Data Catalog is available as a data source connector in Quick. It provides direct access to Glue catalog metadata including table names, descriptions, column information, and data quality scores. After you connect, data curators (authors) can use the agentic experience to discover relevant tables, create DirectQuery datasets in bulk, and inherit semantic definitions automatically.
