

# Billing

When using Amazon Q Business indexes in AWS Quick, billing works as follows:

## IDC Implementation Billing
<a name="idc-implementation-billing"></a>
+ You are billed for index and subscription costs in Amazon Q Business (recommended at least 1 user).
+ You are billed for subscription costs in AWS Quick based on your AWS Quick user subscriptions.
+ There are no additional charges for connecting Amazon Q Business indexes to AWS Quick.

## Non-IDC Implementation Billing
<a name="qbiz-implementation-billing"></a>
+ No explicit Amazon Q Business subscription charges apply in this implementation model.
+ You are billed for subscription costs in AWS Quick based on your AWS Quick user subscriptions.

For more information about AWS Quick pricing, see [AWS Quick pricing](https://aws.amazon.com/quicksight/pricing/).
