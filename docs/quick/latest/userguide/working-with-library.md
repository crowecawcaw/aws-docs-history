

# Use Library to find your work

Library is where you find, organize, and reuse your content and AWS Quick resources. You can search it, filter it by content type, and switch between a table view and a thumbnail grid to pick up where you left off.

Library is the new home for your "My stuff." The recently viewed, shared, and favorite items that were spread across the home page now live together in Library, so everything you have created, opened, or saved is in one place.

**Note**  
The metric and dashboard widgets that previously appeared in the home page "My stuff" area do not live in Library. Those widgets now live in Mission Control. For more information, see [Monitor and manage agents and flows with Mission Control](mission-control.md).

## What Library holds
<a name="library-web-contents"></a>

Library stores typed content, including documents, presentations, spreadsheets, PDF files, HTML, images, audio, video, and Markdown, along with AWS Quick resources such as apps, spaces, agents, skills, research, datasets, dashboards, analyses, flows, automations, and topics.

## Your recently viewed, shared, and favorite items
<a name="library-web-my-stuff"></a>

Library brings together the items you work with most.
+ **Recently viewed**: the content and resources you opened or edited most recently, so you can return to them quickly.
+ **Shared**: items that others have shared with you, and items you have shared, gathered in one place.
+ **Favorites**: items you mark with a star to keep close at hand.

## Views and filters
<a name="library-web-views"></a>

Switch between list and grid views, with columns for type, owner, and last viewed. Filter by ownership, favorites, owned by you, or shared with you, and by content type. You can favorite items with a star.

## Item actions
<a name="library-web-item-actions"></a>

From an item's menu you open, download, add to a space, share, open in chat, or delete it. Opening an item shows its contents, where you read it and select content to add as context for a conversation.

## Sharing files
<a name="library-web-sharing"></a>

Sharing gives view access to that file only. Recipients find the file in their own Library. Choose **Copy link** to get a link to the file that you can send in chat or email. The link works only for people you have already shared the file with.
