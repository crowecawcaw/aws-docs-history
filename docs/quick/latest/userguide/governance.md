

# Governance
<a name="governance"></a>

With governance features in Quick, you control actions that affect shared assets. Use approval workflows to require review before the approver grants access, use Smart Approvals to review agent actions and refer consequential actions to a person, and use data loss prevention to govern how sensitive content is handled.
