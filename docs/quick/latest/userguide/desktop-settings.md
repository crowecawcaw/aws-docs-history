

# Settings
<a name="desktop-settings"></a>

Open Settings from the account menu. Settings are organized into tabs: Account, Appearance and language, Chat, General, and Advanced.

## Account
<a name="desktop-settings-account"></a>

Manage account identity and view plan and usage. The Account tab shows your profile, and, for a managed account, an indicator that your organization manages it, a session-usage meter for agent hours, and an Account region selector that controls where account data is stored and processed.

## Appearance and language
<a name="desktop-settings-appearance"></a>
+ Color mode: Light, Dark, or System.
+ Language: the interface language.
+ Timezone: used for schedules, timestamps, and calendar availability.

## Chat
<a name="desktop-settings-chat"></a>
+ Instructions: global instructions sent with every message across all agents, such as preferred language, format, and style.
+ Default agent: the agent used for new chats.

## General
<a name="desktop-settings-general"></a>
+ Desktop notifications: show operating-system notifications when Quick is in the background.
+ Browser: choose the default browser Quick opens for web tasks and automation (System default, Chrome, Edge, Brave, or Firefox), and turn on Use my existing browser to connect Quick to your running browser, where your logins, cookies, and extensions are available.
+ Keyboard shortcuts: a screenshot-capture shortcut and the key combination that sends a message, including a custom option you record.
+ Maximum parallel tasks: a slider from 1 to 20 that controls how many background tasks run at once.
+ Updates: install updates automatically, so Quick downloads new versions in the background and installs them on restart.

### Use my existing browser
<a name="desktop-settings-existing-browser"></a>

When you connect Quick to your running browser, follow the setup steps to enable remote debugging, then test the connection. Enabling remote debugging allows applications on your computer to connect to the browser and access open pages, cookies, and authenticated sessions; turn it off when you are not using this feature. When this option is off, the agent launches a separate browser instance with a copy of your profile.

## Advanced
<a name="desktop-settings-advanced"></a>
+ Export diagnostics: save diagnostic logs for troubleshooting; choose a time range and export.
+ Clear all data: removes all Quick data, including conversations, cached messages, knowledge graph, saved credentials, and preferences. The application quits after cleanup. Clearing all data is irreversible.
