

# Usage limits
<a name="usage-limits-desktop"></a>

Amazon Quick applies the following limits to your account.


| Category | Limit | Value | 
| --- | --- | --- | 
| Sessions | Maximum number of active chat sessions you can run at the same time | 3 | 
| Sessions | Maximum number of concurrent agent runs per user | 30 | 
| Sessions | Maximum number of tools an agent can run at the same time | 20 | 
| Sessions | How long an approval remains valid before Quick asks again | 12 hours | 
| Files and storage | Maximum size of a file you attach to a message | 50 MB | 
| Files and storage | Maximum size of a reference file | 50 MB | 
| Files and storage | Maximum size of a single generated artifact | 500 MB | 
| Files and storage | Maximum total artifact storage per user | 50 GB | 
| Files and storage | Maximum combined size of your memory and knowledge graph | 2 GB | 
| Retention | How long unpinned, unfiled conversations are retained | 365 days | 
| Retention | How long pinned conversations are retained | 750 days | 
| Retention | How long conversations in a folder are retained | 750 days | 
| Retention | How long scheduled task run history is retained | 365 days | 
| Retention | How long custom agent artifacts are retained | 365 days | 
| Scheduled tasks | Maximum number of scheduled tasks per user | 20 | 
| Scheduled tasks | Minimum interval between scheduled task runs | 15 minutes | 
| Scheduled tasks | Maximum length of a scheduled task instruction | 50,000 characters | 
| Agents, skills, and connectors | Maximum number of custom agents (installed and draft) | 100 | 
| Agents, skills, and connectors | Maximum total size of files attached to a custom agent | 1 GB | 
| Agents, skills, and connectors | Maximum length of a custom agent's instructions | 50,000 characters | 
| Agents, skills, and connectors | Maximum number of skills per user | 1,000 | 
| Agents, skills, and connectors | Maximum size of a skill | 6 MB | 
| Agents, skills, and connectors | Maximum number of installed connectors | 100 |
