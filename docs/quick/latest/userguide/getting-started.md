

# Getting started with Amazon Quick
<a name="getting-started"></a>

Amazon Quick is an AI-powered workspace that combines business intelligence, AI-assisted chat, workflow automation, and research capabilities in a single service. Use the topics in this section to get started with the core capabilities of Quick, including AI agents for natural language conversations, Amazon Quick Sight for data visualization, Spaces for team collaboration, Quick Flows for workflow automation, and Research for comprehensive analysis.

You can begin by exploring the platform's features through AI chat, using sample data for visualizations, or connecting to your own data sources to start building real-world solutions.
