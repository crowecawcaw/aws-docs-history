# Sorting dashboard data in Amazon Quick Sight

You can sort data in three ways:

1. You can hover over the label for the field you want to sort by, and choose
   the sort icon.
2. You can choose the filter icon at the upper right of one of the dashboard
   elements.
3. You can click or tap on the field and choose **Sort**
   from the context menu.
   Sorting for pivot tables is different; you specify the sort order by using the
   column sort icon on the pivot table.
