# Making legacy Topics natural-language-friendly

To improve the accuracy of answers in a legacy Topic, configure the following
metadata:

1. **Dataset names and descriptions** — Give
   datasets friendly names so readers can identify them.
2. **Date fields** — Specify default dates and
   time basis for each dataset.
3. **Exclude unused fields** — Remove irrelevant
   fields from the Topic to improve accuracy.
4. **Rename fields** — Give fields
   user-friendly names and descriptions.
5. **Synonyms** — Add alternative names that
   readers might use to refer to fields or values.
6. **Semantic types** — Specify the type of
   information in each field (location, currency, date, person, etc.).
7. **Field roles and aggregations** — Specify
   whether fields are dimensions or measures, and set default
   aggregations.
