

# Creating a legacy Topic
<a name="legacy-topics-creating"></a>

**Note**  
New Topics created going forward use the multi-dataset Topic experience. The following information applies to legacy Topics that were created before this feature launched.

Legacy Topics are collections of one or more datasets that represent a subject area that your business users can ask questions about. When you create a legacy Topic, Quick Sight uses ML-powered automated data prep to help select fields, assign friendly names and synonyms, and detect semantic types.

There are two ways to create a legacy Topic:
+ Create the Topic by selecting a dataset from the Topics page.
+ Create the Topic using an analysis, where automated data prep learns from how you analyze your data.
