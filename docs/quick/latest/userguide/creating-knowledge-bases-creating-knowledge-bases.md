

# Creating knowledge bases in AWS Quick

You can create knowledge bases in AWS Quick to store, organize, and make your data searchable. AWS Quick allows you to create knowledge bases by connecting to data sources.

## Methods for creating knowledge bases
<a name="creating-knowledge-bases-methods-for-creating-knowledge-bases"></a>

You have several options for creating knowledge bases in AWS Quick. The following list describes the available methods.

Choose from the following methods to create a knowledge base:
+ Connect to supported data sources
+ Upload files directly to Spaces

## Creating a knowledge base from supported connectors
<a name="creating-knowledge-bases-creating-knowledge-base-from-connectors"></a>

The following procedure shows you how to create a knowledge base by using one of the native connectors that AWS Quick provides for common data sources.

AWS Quick provides native connectors for common data sources. To create a knowledge base by using a data source connector:

**Note**  
For your first knowledge base, you must create a new data source. After you create your first data source, you can reuse it for additional knowledge bases.

1. Sign in to the AWS Quick console.

1. Choose **Customize**, and then choose **Knowledge**.

1. On the **Knowledge** page, choose **Create**.

1. Choose **Knowledge base**.

1. To create a new data source, choose **Choose data source**.

1. In the **New data source** tab, choose your data source.

1. Choose **Next**.

1. Provide a name for the data source and choose **Submit**.

1. Complete the authentication process and the configuration of your data source. On completion, a knowledge base is created along with your data source. For more information on specific configuration details, see the individual connector sections.
