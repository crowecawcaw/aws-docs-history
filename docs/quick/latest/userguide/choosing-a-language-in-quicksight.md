

# Choosing a language in Amazon Quick
<a name="choosing-a-language-in-quicksight"></a>

You can choose the language that you want to use in the Amazon Quick user interface. This option is set separately for each individual user. The first time a user signs in, Amazon Quick detects and selects a suitable language. This choice is based on the user's browser preferences and interactions with localized AWS websites. 

Quick supports the following languages:


**Languages available in the Amazon Quick user interface**

| Nederlands (Nederland) | nl-NL | Dutch | 
| Norsk bokmål | nb-NO | Norwegian |

| Suomi | fi-FI | Finnish | 
| Svenska (Sverige) | sv-SE | Swedish |

| 中文 (中国) | zh-CN | Simplified Chinese | 
| 中文 (台灣) | zh-TW | Traditional Chinese | 

Choosing a language translates only user interface elements. It doesn't translate the following:
+ Amazon Quick reserved keywords
+ User input
+ Data
+ Date or number formats
+ ML Insights, suggested insights, or computations in narratives (including text)

Use the following procedure to change the language in the Amazon Quick interface.

1. Choose your account name at the top right.

1. Choose **Preferences**.

1. Choose the language that you want to use from the **Preferred Language** dropdown list.
