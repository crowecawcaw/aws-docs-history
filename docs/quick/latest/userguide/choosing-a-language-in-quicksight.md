# Choosing a language in Amazon Quick

You can choose the language that you want to use in the Amazon Quick user interface.
This option is set separately for each individual user. The first time a user signs in,
Amazon Quick detects and selects a suitable language. This choice is based on the user's
browser preferences and interactions with localized AWS websites.

Quick supports the following languages:

| Español                                                | es            | Spanish             |
| Français                                               | fr            | French              |
| Italiano                                               | it            | Italian             |

| Português                                              | pt            | Portuguese          |

| Svenska                                                | sv            | Swedish             |
| 日本語                                                 | ja            | Japanese            |

| 中文 (简体)                                            | zh-CN         | Simplified Chinese  |
| 中文 (繁體)                                            | zh-TW         | Traditional Chinese |

Choosing a language translates only user interface elements. It doesn't translate the
following:

- Amazon Quick reserved keywords
- User input
- Data
- Date or number formats
- ML Insights, suggested insights, or computations in narratives (including
  text)
  Use the following procedure to change the language in the Amazon Quick
  interface.

1. Choose your user name at top right.
2. To open the language options menu, choose the > symbol near the current
   language.
3. Choose the language that you want to use.
