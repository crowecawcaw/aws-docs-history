

# Connecting to data catalogs in Amazon Quick
<a name="catalog-integration"></a>

**Note**  
Data catalog integration is in Preview for Amazon Quick and is subject to change. Preview features are not typically recommended for critical or production workloads.

Amazon Quick data catalog integration connects Quick to upstream data catalogs such as AWS Glue Data Catalog and Databricks Unity Catalog. The integration provides an AI-powered agentic experience that helps data curators (authors such as analysts and business intelligence engineers) rapidly discover relevant tables, bulk-create DirectQuery datasets and topics, and automatically inherit semantic definitions from their catalogs. By reusing the metadata that already exists in your catalog, you can go from a business question to production-ready dashboards and AI-powered Q&A in a fraction of the time, not weeks.

In Quick, a connected catalog is represented as a data source. To access a catalog data source, navigate to the **Create Data Source** page and select the catalog connector for your environment.
