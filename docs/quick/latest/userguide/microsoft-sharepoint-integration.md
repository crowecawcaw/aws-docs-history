# Microsoft SharePoint integration

Use the Microsoft SharePoint integration to perform actions on SharePoint lists, items,
and files, or to create knowledge bases from SharePoint content for AI-powered search and
Q&A.

## What you can do

**Action connector**

Manage SharePoint lists, items, files, and Excel workbooks through
Microsoft Graph API calls.

**Knowledge base**

Index SharePoint document libraries, sites, and pages. Amazon Quick
agents can then search and answer questions about the content.
