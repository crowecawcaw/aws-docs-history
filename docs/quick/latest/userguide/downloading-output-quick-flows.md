# Downloading output in Amazon Quick Flows

Download one or more outputs from your Amazon Quick Flows runs as formatted documents in PDF or Word. You can save downloaded files locally or to shared Amazon Quick spaces for future reference and team collaboration.

This feature allows you to export flow outputs as formatted documents. Instead of manually copying and pasting results into emails or documents, you can download outputs with proper formatting preserved in your preferred file format.

When you run a flow, you can download the outputs to create comprehensive documents without manual copying and pasting. This feature supports:

- **Multiple output selection** – Choose specific steps, all outputs, or a subset of outputs to include in your download.
- **Various file formats** – Export to Word (.docx) or PDF formats with proper formatting maintained.
- **Rich content support** – Includes text results, generated images, detailed Research reports and visuals from Amazon Quick Sight.
- **Space integration** – Save exported files directly to shared spaces for team collaboration.
  Downloaded files maintain the original formatting from your flow outputs, including markdown structure, visual elements, and data tables.

## Before you begin

Before downloading flow outputs, ensure the following:

- Your flow run has completed or generated output for at least one step. The download button only surfaces when there's output to download.
- If saving to a space, you have edit access to the target Space.

## Download flow outputs

To download outputs from a flow run:

1. In the Amazon Quick Flows Run mode, navigate to top right to see a downward arrow icon.
2. Select **Download as**.
3. Select which outputs to include:
   - Select **Select All** to include all steps in chronological order.
   - Use check boxes to select one or more steps from the list.

###### Note

User input and file upload steps are excluded from the selection list and cannot be downloaded. 4. Select your preferred file format:

    1. **Word (docx)** – Editable document format
    2. **PDF** – Fixed-layout document format

5. Choose your download destination:
   - Select **Download** to save the file locally.
   - Select **Save to a space**, then select an existing space or create a new one.

###### Note

You can only save to Spaces where you have edit access.

The system compiles your selected outputs into a single document with proper formatting. If you saved to a space, team members with access can view and collaborate on the exported file.
