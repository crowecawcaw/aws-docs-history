

# Monitor agents

You can monitor an agent's activity in its details pane, or monitor work across all agents in Mission Control.

The agent details pane has the following tabs:

**Overview**  
Shows the agent's description, a **View capabilities** link, and the agent briefing.

**Activity**  
Shows current and past runs. You can search, and filter by **All** or **Needs input**.

**Routines**  
Shows the routines that run this agent. You can search and filter the routines, turn them on or off, and run them. To create a routine, choose **Create**, and then choose **From chat** or **Manually**. For instructions, see [Routines](working-with-routines.md).

**Capabilities**  
Shows the connectors and tools the agent uses, such as web search. You can use the **Needs action** filter.

**Context**  
Shows agent files and agent memory. You can search files, sort them, and expand folders. You can also search memories, and open a memory to edit it, **Forget** it, or **Boost** it.

When an agent needs approval, an approval card appears under **Needs input**. Choose **Approve** or **Deny**.

The agent briefing summarizes the agent's work. You can turn on **Auto-update**, and **Regenerate**, **Download**, or view it in **Full screen**. If the agent has no activity, **Generate** is unavailable.

Each run shows its status, which is one of the following:

**Running**  
The run is in progress.

**Needs input**  
The agent is waiting for your approval to access a tool or resource that requires approval.

**Completed**  
The run finished with no issues.

**Interrupted**  
The run stopped before it finished.

**Failed**  
The run ended with an error.

**No runs yet**  
The agent hasn't run yet.

On the **Agents** tab, each agent's status reflects its most recent run.

To monitor work across all agents, open Mission Control. For more information, see [Monitor and manage agents and flows with Mission Control](mission-control.md). To run an agent on a schedule, see [Routines](working-with-routines.md).
