

# Administering AWS Quick on desktop


|  | 
| --- |
|  Applies to:  Enterprise Edition  | 


|  | 
| --- |
|    Intended audience:  System administrators  | 

As an administrator, you decide who in your organization can use AWS Quick on desktop, how the application reaches their devices, and which capabilities they can use. You do this work in the AWS Quick console and in your device management tools.

Use this section to do the following:
+ Turn on desktop access and set up sign-in.
+ Deploy and update the application on managed devices.
+ Review the architecture, where data is stored, and the network requirements.
+ See which controls administrators, connector owners, and users set.
+ Monitor and audit desktop activity.
