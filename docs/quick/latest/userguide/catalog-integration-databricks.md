

# Connecting to Databricks Unity Catalog
<a name="catalog-integration-databricks"></a>

**Note**  
Data catalog integration with Databricks Unity Catalog is in Preview for Amazon Quick and is subject to change. Preview features are not typically recommended for critical or production workloads.

The existing Databricks connector in Quick has been enhanced with agentic catalog capabilities and identity enforcement support through OAuth 3LO. Data curators (authors) can use the agentic experience on both new and existing Databricks data sources that were created using a Personal Access Token (PAT).
