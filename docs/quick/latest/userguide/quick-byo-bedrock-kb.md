# Bring your own Amazon Bedrock managed knowledge base

Amazon Quick can connect Amazon Bedrock managed knowledge bases as knowledge sources. After
connection, a managed knowledge base is treated like any other knowledge base in
Amazon Quick. You can add it to spaces and it is queried automatically during chat. You can connect up to 2 managed
knowledge bases per Amazon Quick instance. The managed knowledge base can live in the same
AWS account as Amazon Quick or in a different account.
