

# Capabilities
<a name="capabilities-desktop"></a>

The Amazon Quick desktop application provides a set of capabilities that extend what Quick can do on your behalf. You can access and manage these capabilities from **Settings** > **Capabilities**. The Capabilities page has the following tabs:
+ **Connectors** – Manage web connectors, MCP servers, and coding agents.
+ **Schedules** – Manage schedules for recurring agent runs. This tab redirects to Mission Control. For more information, see [Mission Control](mission-control-desktop.md).
+ **Tools** – Enable, disable, and configure permissions for built-in system tools.

For information about agents and skills, see [Skills and agents](skills-and-agents-desktop.md).
