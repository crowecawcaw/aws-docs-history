

# Differences between iOS and Android
<a name="mobile-ios-android-differences"></a>

The mobile experience is consistent across iOS and Android, with a few differences.
+ Mission Control: available on iOS. Not available on Android.
+ Branching conversations: available on Android. Not available on iOS.
+ Attachments: on iOS, you can attach up to three files per message.
+ Creating a connector: on iOS, creating a new connector requires iOS 17.4 or later. You can re-authenticate an existing connector on any supported version.
