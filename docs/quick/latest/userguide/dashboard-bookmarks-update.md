# Updating bookmarks in Amazon Quick Sight

At any time, you can change a bookmark dashboard view and update the bookmark to
always reflect those changes.

###### To update a bookmark

1. Open the published dashboard and make needed changes to the filters or
   parameters, or select a sheet.
2. Choose the bookmark icon at upper right.
3. In the **Bookmarks** pane that opens, choose the context
   menu (the three vertical dots) for the bookmark that you want to update, and
   then choose **Update**.

A message appears, confirming the update.
