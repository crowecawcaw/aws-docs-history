# Shared responsibility for compliance

Your compliance responsibility when using AWS Security Incident Response depends on the sensitivity of your
data, your company's compliance objectives, and applicable laws and regulations. AWS
provides Security Incident Response as a tool to help you investigate and respond to security incidents. You
remain responsible for the following:

- Determining whether Security Incident Response is appropriate for your compliance requirements.
- Configuring Security Incident Response in accordance with your policies.
- Ensuring your use of Security Incident Response complies with applicable regulations.
