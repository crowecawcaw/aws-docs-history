

# Monthly report
<a name="monthly-report"></a>

 AWS Security Incident Response emails a monthly report to all contacts on your Incident Response team. To update who receives these reports, modify the contact list in the AWS Security Incident Response console. Reports are delivered in PDF format and include the metrics described in [Case metrics](case-metrics.md). You can expect delivery within one to two weeks after the month ends. The email subject line is: `AWS Security Incident Response Monthly Report - ({{Month Year}})`. You receive one report per organization defined in AWS Organizations.
