# Integrations and External Tooling Workflow

**AWS Solutions to Integrate JIRA or ServiceNow with Security
Incident Response**

Deploy our fully developed solutions for bi-directional integration with Jira and ServiceNow. These integrations enable two-way communication between AWS Security Incident Response Cases and your ITSM platform, with case updates automatically reflected in corresponding Jira tasks.

**Benefits of Integration**

Integrating AWS Security Incident Response with your existing ITSM platform streamlines your security operations by centralizing incident tracking and response workflows. These pre-built solutions eliminate the need for custom development, allowing your security teams to maintain visibility across both AWS-native and enterprise-wide incident management systems. By leveraging Amazon EventBridge for event-driven automation, updates flow seamlessly between platforms in real-time, ensuring that security incidents are tracked consistently regardless of where they originate. This unified approach reduces context switching for security analysts, improves response times, and provides comprehensive audit trails across your entire incident response lifecycle.

To configure EventBridge rules:

1. Access Amazon EventBridge
2. Select **Rules** from the **Buses**
   dropdown
