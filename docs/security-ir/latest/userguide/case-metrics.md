# Case metrics

- Cases created
  - Dimension name: Type
  - Dimension values: AWS supported, self supported
  - Unit: Count
  - Description: The number of cases created.

- Cases closed
  - Dimension name: Type
  - Dimension values: AWS supported, self-managed
  - Unit: Count
  - Description: A measure of the total number of cases
    closed.

- Opened cases
  - Dimension name: Type
  - Dimension values: AWS supported, self supported
  - Unit: Count
  - Description: The number of open cases.
