# Adding members to AWS Security Incident Response

There is a one to one relationship with AWS Organizations and your AWS Security Incident Response membership.
As accounts are added (or removed) from your Organizations or organizational units (OUs), these changes will be reflected in the
covered accounts for your AWS Security Incident Response membership.

To add an account to your membership, follow one of the options for
[Managing accounts in an organization with AWS Organizations](../../../organizations/latest/userguide/orgs_manage_accounts.md "../../../organizations/latest/userguide/orgs_manage_accounts.md").

You may also add additional OUs to your membership at any time — see [Managing membership with organizational units (OUs)](managing-membership-with-ou.md "managing-membership-with-ou.md").
