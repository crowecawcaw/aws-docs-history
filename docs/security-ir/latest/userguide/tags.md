# Tags

A tag is an optional label that you can assign to your cases to
hold metadata about that resource. Each tag is a label
consisting of a key and an optional value. You can use tags to search,
allocate costs, and authenticate permissions for the resource.

To add a tag, do the following:

1. Choose **Add new tag**.
2. For **Key**, enter the name of the tag.
3. For **Value**, enter the value of the tag.
   To remove a tag, choose the **Remove** option for that tag.
