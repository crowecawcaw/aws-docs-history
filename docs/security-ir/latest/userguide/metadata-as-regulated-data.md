# Metadata as regulated data

While Security Incident Response does not collect your application data, the metadata it collects may fall
under your compliance requirements. Organizations should evaluate the following:

- Whether resource names and identifiers constitute regulated data.
- Whether DNS query logs contain personal information.
- Whether API call patterns reveal protected business information.

Consult with your legal and compliance teams to determine how Security Incident Response metadata should be
classified under your applicable regulations.
